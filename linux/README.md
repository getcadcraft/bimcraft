# BimCraft for Linux

BimCraft comes inside [CadCraft Studio](https://github.com/getcadcraft/studio) (all eight apps in one install) from 0.5 on; there are no separate BimCraft installers any more. Get Studio 0.9 from the [download page](https://getcadcraft.com/download#studio) or its [GitHub release](https://github.com/getcadcraft/studio/releases/tag/studio-v0.9.0). Studio ships as a `.deb` and an AppImage.

## File types

- Opens by default unless another program already does: `.ifc` (IFC model)
- Listed under "Open with": `.rvt` (RVT model), `.rfa` (RFA family), `.rte` (RTE template), `.rft` (RFT family template), `.dwg` (DWG drawing), `.dxf` (DXF drawing), `.bcf` (BCF issues), `.bcfzip` (BCF issues)
