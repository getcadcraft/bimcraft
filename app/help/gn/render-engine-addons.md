Complemento (Configuración › Complementos) ikatu omoĩ motor lísta Motor-pe de {{ui:Render}}. Texto completo autor-kuéra-pe ha’e sección 16 de la especificación del complemento; ñemombe’úvo:

- Complemento omoĩ motor peteĩ id-pe oñepyrũva ipopápe, téra, configuración opcional ha **térã** programa oñemboguejy **térã** función JavaScript-pe oñemoĩva ilustración.
- Motor oñemboguejy programa oikotevẽ **`engine.run`** permiso, ohechauka instalación mboyve ha Configuración-pe. Oñemboguejy Studio-pe añónte; navegador-pe ohechauka archivo ojapy haguã.
- Complemento omoĩ programa (archivo téra añónte; ndaha’éi shell), script **complemento firmado-pe** oĩva, ha argumento-kuéra placeholder ha ñe’ẽ simple-kuéra. Studio ojuhu programa térã ohupyty pe’ẽ peteĩ jey.
- Peteĩ jey complemento oñemboguejy programa, **Studio omombe’u ipo diálogo**: mavapa complemento, mavapa programa, ha script ikatu ohupyty opa mbaʼe programa ikatúva. Ejapo añetehápe complemento ejeupe. Tembiapo ohendu complemento ha programa rehegua.
- Paquete (escena USD ha archivo configuración, glTF ha complemento oikotevẽ jave) ha complemento script ohóta karpeta temporal pyahúpe, programa upépe oñemboguejy, ha imagen ojevolvéta motor téra rehegua complemento.

:::note
Complemento ikatu omoĩ motor render API 1.4-gui. Peteĩ ejemplo comando-línea renderer open-source rehe oĩ ipypeʼỹ repositorio-pe; ndojapói aún upe renderer-pe.
:::
