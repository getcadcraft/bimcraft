## Mba'e rejapóta

Ehechá modelo nde lugar-pe: sitio calle mapa térã aéreo imagen tuichavegua rehe.

## Pasos

1. Pyta peteĩ IFC modelo lugar mapa-pe (conversión de mapa, IfcMapConversion, sistema coordenadas proyectado). Exportador ojapo proyecto coordenadas (punto relevamiento, coordenadas compartidas) oñemoĩvaekue.
2. Eskoge {{ui:Mostrar}} › {{ui:Capas de mapa…}}. Diálogo ohechauka modelo sistema, ejemplo EPSG:28356. Conversión de mapa ndaipóri modelo ndaikatúi mapa capa: diálogo ohechauka.
3. Pyta {{ui:Capas de mapa desde internet}}. Peve nde ndojepyhýi servidor; ojehejáu jave, nde añadido servidor ohecha modelo ári área ha nde internet dirección, modelo ndaha'éi.
4. {{ui:Agregar una capa}}-pe eskoge teja (`{z}`, `{x}` ha `{y}` ndive dirección), WMS, WMTS térã ArcGIS servicio ({{ui:Obtener capas}}, upéi peteĩ eskoge), térã imagen mundo archivo ndive.
5. Diálogo pe'a. Mapa ojeguahẽ modelo punto más bajo ári, modelo huella rehe ha upe ári ambue.

:::note
Mapa solo pantalla-pe; IFC archivo-pe ndojesalva. Capa lista ko navegador-pe oñeñongatu. Ejeruru servicio de mapa solo umi términos oipermitíva.
:::
