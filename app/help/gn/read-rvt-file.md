## Mba'épa ojapóta

Eikuaa mba'e oĩ proyecto térã familia archivo-pe Revit-pe ojeike'ỹre: mba'eichaite versión oguardáva, trabajo compartido-pe ha'e térã ndaha'éi, proyecto información ha mba'épa enlazado. Upéva iporãva archivo oúmi ambue-gui ha ndeikuaái mba'eichaite versión ojeike haguã.

## Pasokuéra

1. Clic {{ui:Choose a file}}.
2. Eiporavo `.rvt`, `.rfa`, `.rte` térã `.rft` archivo.
3. Tiémpo mbykymi. Estado línea ohechauka "Leyendo el archivo…" ha upe rire "Abierto *archivo réra*".
4. Eĩ tarjeta ryepýpe: archivo-pe ojeguardáva vista imagen, archivo tipo ha versión oguardáva, proyecto réra.
5. Pyta tarjeta sección ojehai haguã.

## Mba'épa ehecha

Tarjeta mbytépe, ko sección archivo oguereko jave:

| Sección | Mba'épa ohechauka |
|---|---|
| Archivo | Archivo réra, tamaño, tipo (proyecto, proyecto plantilla, familia térã familia plantilla), versión ha build oguardáva, trabajo compartido, modelo central ruta, mbovéva oguardáva, máva oguardáva, idioma ha documento GUID |
| Información del proyecto | Proyecto campo, ha'e réra, número, cliente, dirección ha estado. Proyecto nuevo ojeikuaa ojehechaukávape ndojeheja. |
| Familia, Familia: … | Familia-pe: réra, categoría, versión, última actualización ha parámetros, grupo-gui grupo |
| Enlazados y referenciados archivo | Enlazado modelo, CAD enlace, imagen ha clave tabla oĩ archivo, guardado ruta ndive |

Ñemboguejy izquierda {{ui:File}} panel repite hechokuéra ha ohechauka **Leído**: BimCraft mboyve ojeleé, tuichave archivo oĩmba 40 KB megabyte-pe.
Derecha, {{ui:Properties}} panel ohechauka elemento propiedad 3D modelo ohaíva.

## Mba'éichapa ndaipóri 3D

3D modelo ha proyecto archivo elementokuéra ojeguardáva formato ndojehechaukavéiva. BimCraft ojeleé tenda ojehechaukáva térã iporãva ojeleéva: archivo información, proyecto información, familia dato, enlace lista ha vista imagen. Ndojekuaái ambuerã. 3D modelo ha elemento propiedad ojehecha haguã, IFC exportar ojapo programa-gui. Ehecha [Proyecto archivo 3D-pe IFC-gui](topic:rvt-to-ifc).

## Ñemboykekuaa

- **3D oipota'ỹ.** Ehecha ko'ápe.
- **Enlaces ohechauka ruta ojeguardáva.** Archivo ojeike ijoavýpe ndaikatúi ohechakuaa enlace oĩ. Carpeta ojeike, BimCraft oñemoĩ enlace ojejuhúva térã ndojuhúiva: [Proyecto carpeta ojeike](topic:open-project-folder).
- **"Este archivo está incompleto…"** Archivo ojeeheja kopia, ojehupyty térã sincronizá jave. Nube ojeeheja "online only" archivo avei. BimCraft ojeike ha ohechauka ojejuhu'ỹva: tarjeta ryepýpe ámbar aviso, **Recuperado de este archivo** sección ohechaukáva archivo mboyve, ha **No está en el archivo** ambuekuérare. Ndojehejávi mboyke parte, upévare versión, vista imagen térã proyecto información ndoikói ikatu. Archivo contenido lista ojeheja jave, ndaikatúi ojeike. Original jey kopia ha ojeike jey.
- **"No hay imagen de vista previa en este archivo".** Heta archivo ndoguerekóiva. Upéva normal.
- **Copia de seguridad ojeike ojeikuaa'ỹre.** `Tower.0004.rvt` réra archivokuéra numerado copia de seguridad. Carpeta ojeike jave, modelo ndive ojegrupoháta.
