BimCraft-pe oguereko pocos atajo. Heta trabajo ojapo ratón ha paneles rupive. Atajo {{key:Mod}} ndive ojeporúva Command Mac-pe ha Ctrl ambue-pe. Ehecha [Teclas, ratones y trackpads](common:keys) mba'éichapa ojehai ko ayuda-pe.

## En todas partes

| Tecla | Qué hace |
|---|---|
| {{key:Ctrl+Shift+F}} | Cambia modos de pantalla: normal, pantalla completa, pantalla completa con barras ocultas. Ctrl opa plataforma-pe, Mac-pe avei |
| {{key:Esc}} | Sale de pantalla completa |
| {{key:Mod+,}} | Abre {{ui:Configuración}}. Ehecha [Configuración de BimCraft](topic:settings) |
| {{key:Tab}} | Ojeho botón, casilla ha valor-kuéra rupi. Control opaite teclado rupive ojeikuaa |

## Vista 3D (modelo IFC)

| Tecla o acción | Qué hace |
|---|---|
| {{key:F}} | Ajusta modelo entero, tres cuartos vista (igual que {{ui:Ajustar}}) |
| {{key:Esc}} | Limpia elegido, térã oipe'a ubicar térã pegar |
| Clic | Elige elemento puntero rovakeha; clic fondo vacío-pe limpia |
| {{key:Mod}}+clic térã {{key:Shift}}+clic | Agrega elemento elección-pe, térã osakã |
| {{key:H}} | Oculta elegido elemento. Ehecha [Ocultar, aislar y ver a través de elementos](topic:hide-and-isolate) |
| {{key:I}} | Muestra solo elegido elemento (aislar) |
| {{key:T}} | Muestra elegido elemento, ambue transparente |
| {{key:Shift+H}} | Muestra opaite elemento jey |
| {{ui:Recorrer}} | Upe rire {{key:W}} {{key:A}} {{key:S}} {{key:D}} térã flecha-kuéra ndive ndereñandu, {{key:Shift}} ojapura, arrastrá mirada, {{key:Esc}} opa. Ehecha [Recorrer modelo](topic:walk) |
| {{key:M}} | Medí distancia ha área de cara. Ehecha [Medir distancias, áreas de cara y ubicaciones en 3D](topic:measure) |
| Arrastrar botón izquierdo | Orbitar |
| Arrastrar botón derecho | Desplazar |
| {{key:Shift}} térã {{key:Mod}} ha arrastrá botón izquierdo | Desplazar (trackpad-pe porã) |
| Rueda de desplazamiento térã arrastrar botón medio | Zoom |
| Desplazamiento dedos mokõi térã pellizco trackpad-pe | Zoom |
| Peteĩ dedo (táctil) | Orbitar; toque elige |
| Dedo mokõi (táctil) | Pellizco zoom, ojeho jey desplazar |

| {{key:X}} | Plano de corte ojehejareiva ha ojepe'a. Ehecha [Cortar modelo IFC con plano de corte](topic:section-plane) |
| {{key:Shift+X}} | Caja de corte elegido elemento rehe, ambiente Configuración-pe ojeporavo |

No oguereko tecla {{ui:Arriba}}, {{ui:Frente}} ha {{ui:Lateral}}; botón ojeporu.

## Editar

Mismo comando ojekuaa barra-pe: {{ui:Deshacer}}, {{ui:Rehacer}}, {{ui:Copiar}}, {{ui:Pegar}} ha {{ui:Más}} menú, ohechauka tecla peteĩteĩ. Oñemomba'e IFC modelo 3D vista-pe, campo-pe ñembohysýi ndojapóiva. Ehecha [Copiar, pegar y duplicar elementos de biblioteca](topic:copy-paste).

| Tecla | Qué hace |
|---|---|
| {{key:Mod+Z}} | Deshace última mudanza |
| {{key:Mod+Y}} térã {{key:Mod+Shift+Z}} | Rehace Deshacer-pe osẽ |
| {{key:Mod+C}} | Copia elegido elemento (nombre ha propiedad avei portapapeles-pe texto-pe) |
| {{key:Mod+X}} | Corta elegido elemento: copia ha upe rire ombogue |
| {{key:Mod+V}} | Pegá ojekopiáva: puntero rupive oho, emboty mboýpe ojehasa |
| {{key:Mod+Shift+V}} | Pegar ojehecha: corte oñe'ẽ ojehu-gui, térã copia rire originales rembe |
| {{key:Mod+D}} | Duplica: copia elegido elemento ha pegar oñepyrũ |
| {{key:Delete}} | Elimina elegido elemento, parte ha abertura ndive. Ehecha [Eliminar, cortar, copiar y pegar elementos](topic:edit-elements) |
| {{key:Mod+A}} | Elegí opaite elemento ohechaukáva |
| {{key:Esc}} | Ndaneelegíi ningo |

Página-pe texto elegido ojeporu ramo, {{key:Mod+C}} copia texto ojeikuaa rangue.

## Vista de plano (Dibujar)

Ko'ã ojapóva {{ui:Dibujar}} oñemboguejy rire ha campo-pe ndereñe'ẽi. Ehecha [Dibujar muros](topic:draw-walls) ha [Puertas y ventanas](topic:doors-and-windows).

| Tecla o acción | Qué hace |
|---|---|
| {{key:V}} | {{ui:Seleccionar}} |
| {{key:W}} | {{ui:Muro}} |
| {{key:D}} | {{ui:Puerta}} |
| {{key:N}} | {{ui:Ventana}} |
| {{key:H}} | {{ui:Puerta}} térã {{ui:Ventana}} rehe: bisagra tambeteguáre |
| {{key:Shift}} muro dibujo rehe | Muro 0°, 90°, 180° térã 270° rehe ojeikotevẽ |
| Número ha pie ha pulgada marca (`'` ha `"`) | Ojepyrũ tipea longitud {{ui:Longitud}} campo-pe; {{key:Enter}} ojeporu |
| {{key:Enter}}, {{key:Esc}}, clic derecho térã doble clic | Muro dibujo fin; {{key:Esc}} jey {{ui:Seleccionar}}-pe ho'ẽ |
| {{key:Delete}} | Elimina elegido muro, puerta ha ventana; muro osẽvape jey ojoaju |
| {{key:F}} plano puntero rehe | Ajusta plano |
| Rueda de desplazamiento | Zoom puntero rupive |
| Arrastrar botón medio térã derecho, térã {{key:Space}} ha arrastrá | Desplazar; {{ui:Seleccionar}} oñemoĩ rire, arrastre simple avei desplaza |
| Arrastrar puerta térã ventana {{ui:Seleccionar}} ndive | Muro rapykuéri mudá, térã ambue muro-pe |
| Dedo mokõi (táctil) | Pellizco zoom, ojeho jey desplazar |

## Ubicar y pegar elementos de biblioteca

| Tecla | Qué hace |
|---|---|
| {{key:R}} | Elemento 90° rombojerovia |
| {{key:Tab}} | Ajuste a muro encendido ha apagado: elemento espalda muro mboýva ojehasa |
| {{key:Enter}} **X, Y (mm)** rehe | Ubica tipeado posición-pe |
| {{key:Esc}} | Oipe'a ubicar térã pegar |

## Editar valores IFC

| Tecla | Qué hace |
|---|---|
| {{key:Enter}} | Tipeado valor oñeñongatu |
| {{key:Esc}} | Oipe'a ha valor vieja oñeme'ẽ jey |
| Clic ambue rehe | Tipeado valor oñeñongatu |
| {{key:Mod+Z}} | Deshace última mudanza. Ndaipórire ndeguardavéi ha campo-pe ndereñe'ẽi rire |
| {{key:Mod+Y}} | Rehace Deshacer-pe osẽ |
| {{key:Mod+S}} | Guarda IFC-pe. Ndaipórire ndeguardavéi cambio; upe ndaipórire navegador guardar comando oñemoĩ |

Teclado ndive oñemoĩ jey: {{key:Tab}} ojepytase peve valor oñemarka, upe rire {{key:Enter}} tipeaʼe hag̃ua.

## Dibujos 2D (DWG ha DXF)

| Tecla o acción | Qué hace |
|---|---|
| {{key:F}} | Ajusta dibujo térã hoja |
| {{key:P}} | Vista de impresión ojehejareiva ha ojepe'a |
| Doble clic | Ajusta |
| Arrastrar cualquier botón | Desplazar |
| Rueda de desplazamiento | Zoom puntero-pe |
| Desplazamiento dedos mokõi térã pellizco trackpad-pe | Zoom puntero-pe. Desplazamiento dedos mokõi ndesplazái |
| Peteĩ dedo (táctil) | Desplazar. Pellizco zoom ndojapóiva dibujo-pe |

## Dibujos en 3D

| Tecla o acción | Qué hace |
|---|---|
| {{key:3}} | 3D ojehejareiva ha ojepe'a (2D vista-pe avei) |
| {{key:F}} | Extensiones: dibujo entero |
| Arrastrar botón medio térã izquierdo | Orbitar |
| Arrastrar botón derecho térã {{key:Shift}} ha arrastrá | Desplazar |
| Rueda de desplazamiento | Zoom puntero rehe ojehechaukáva |
| Desplazamiento dedos mokõi trackpad-pe | Orbitar; {{key:Shift}} ndive, desplazar |
| Pellizco trackpad-pe | Zoom |
| Peteĩ dedo (táctil) | Orbitar |
| Dedo mokõi (táctil) | Pellizco zoom, ojeho jey desplazar |

{{key:F}}, {{key:P}} ha {{key:3}} ndojapói campo-pe tipeando, equipo planilla ohechaukáramo térã {{key:Mod}} térã {{key:Alt}} ojemantene ramo.
