## Estado de las copias

Opavave copia modelo, archivo principal ha copia numerada, oguereko header chequeo.

| Rótulo | Mba'épa ohechauka |
|---|---|
| **Completo** | Archivo header ha índice oike archivo-pe |
| **Incompleto** | Archivo ipukúva iíndice omombe'úvape: ojejoko copia, carga térã sincronización jave, térã nube archivo "solo en línea" |
| **Ilegible** | Archivo ndaha válido archivo compuesto, térã ndojeleíi |

Columna **Estado**-pe modelo ohechauka **Completo**, ámbar "*n* incompleto" peteĩ copia mavále ha ambue ipyahu, térã **Incompleto** rojo copia peteĩ noñeipyahúi.

## Copias de seguridad

Archivo réra `Name.0001.rvt`, `Name.0002.rvt` ha ambue ha'e copia numerada `Name.rvt` rehe. Oñemboguejy modelo rehe, pyahu primero, **Todas … copias**-pe. Tarjeta oñeleí archivo principal-gui oike completo ramo, térã copia numerada pyahu completo rehe ("pyahu completo").

## Roles

Ohechauka *cursiva* modelo réra ári.

| Rol | Mba'épa ohechauka |
|---|---|
| Vinculado por *otro modelo*: fondo | Ambue modelo carpeta-pe ohechakuaa ko modelo, ha'e ambue persona modelo, peteĩ consultor modelo ichupe |
| Archivo inicial o sin título | Réra Blank, Template, Default, Untitled térã Project1: ñepyrũ punto, térã archivo ndojejapóiva réra porã |
| Modelo central | Peteĩ modelo central trabajo compartido. Trabajo oñemba copia local-pe, ndaha ko'ápe |
| Familia (peteĩ pieza) | Archivo `.rfa` térã `.rft`: componente, ndaha proyecto |
| Solo copias de seguridad | Archivo principal oho, oñemoĩ mokõive numerada copia |

## Mba'éichapa oñeelegi Eñepyrũ aquí

BimCraft ojapo peteĩ usuario experimentado ojapóva mba'e:

1. Candidatos ha'e archivo proyecto legible (`.rvt`, `.rte`) ndaha ambue modelo ohechakuaáva ha ndaha inicial.
2. Central ha solo copias de seguridad modelo oikoramo mávante ndaipóri.
3. Candidatos-pe, pyahúva ojeguardáva omano.

Caja omombe'u iñemoñare, ha oñe'ẽ peteĩ archivo oiko jeporu porãva oñanduvaicha ojejapóramo, ambue modelo fondo ohechakuaáramo, ha pick peteĩ central modelo ojeporúramo. Ha'e peteĩ mba'e ñepyrũ; eheka pe ojapo jey proyecto-pe.

## Estado del enlace

| Rótulo | Mba'épa ohechauka |
|---|---|
| **En esta carpeta** | Ojuhu ojeguardavaicha relativo tape-pe, térã tape ipahápe ojeguardavaicha full tape carpeta-pe |
| **Mismo nombre hallado** | Ndaha ipapa-pe, ha peteĩ archivo ojuháva same réra carpeta-pe. Ehecha ha'e pe ojeporúva |
| **Archivo de biblioteca** | Peteĩ tabla código clave térã conjunto. Ha'e ojeguerohóva programa ha computadora-pe |
| **No está en esta carpeta** | Ndojuhúi carpeta ryepe |

Columna **Enlaces hallados** **Modelos**-pe ohechauka mboyve enlace modelo ojuhúva, ojeporavo carpeta-pe oikotevẽva (archivo biblioteca ndojeporaporã).

## Apartados

| Línea | Mba'épa ohechauka |

| Otros archivos | Opavave ambue (mboapy ojehéva réra) |
