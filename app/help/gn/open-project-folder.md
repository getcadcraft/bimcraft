## Mba'épa reñapo

Eabri peteĩ carpeta proyecto kompleta, ojeme'ẽva eimo'ã trabajo-pe, ha eguerovaꞌekue BimCraft-pe ohechauka: mba'e modelo oĩ, mba'e copia ha backup, mba'e ojoaju mba'e, mba'e archivo oñemanduaha, ha mba'e archivo ehasa porãva eabri.

Kilobyte mboýpe ohendu modelo tarjeta-pe, upévare red compartida térã nube sincronizada carpeta-pe ndaguerekói problema.

## Pasos

:::chromium
1. Hacer clic {{ui:Abrir una carpeta}} ári (térã pantalla ryguasu mbytépe).
2. Elegí carpeta proyecto ventana-pe ha hacer clic **Seleccionar** (térã **Subir** térã **Abrir**, sistema rupi).
3. Hacer clic **Ver archivos** navegador ojerure rire "¿Permitir ver archivos?". Ko ndaipóri ojeporú ambue; tab oleé carpeta rupi nomba'éi.
4. Esperá línea de estado ohechauka: "Listando la carpeta: … archivos", upe rire "Revisando archivos Revit: … de …".
:::

:::firefox
1. Hacer clic {{ui:Abrir una carpeta}} ári (térã pantalla ryguasu mbytépe).
2. Elegí carpeta proyecto ventana-pe ha confirmar. Firefox ojerure confirmar tab oleé ta'anga; archivo computadora-pe oĩ.
3. Esperá línea de estado: "Leyendo la carpeta: … archivos", upe rire "Revisando archivos Revit: … de …".
:::

:::safari
1. Hacer clic {{ui:Abrir una carpeta}} ári (térã pantalla ryguasu mbytépe).
2. Elegí carpeta proyecto ventana-pe ha hacer clic **Subir**. Ndaha'éi Mac-gui ndoho: archivo oñeme'ẽ tab-pe nomba'éi.
3. Esperá línea de estado: "Leyendo la carpeta: … archivos", upe rire "Revisando archivos Revit: … de …".
:::

Ikatu avei **arrastrar la carpeta** {{pick:mac=Finder|windows=Explorador de archivos|linux=tu administrador de archivos}} rupi página-pe. Carpeta arrastrada oñemoĩ navegador opa-pe, ndaipóri permiso pregunta.

## Mba'épa rehecha

Carpeta informe ohupyty mbytépe:

- Carpeta réra, modelo, plano CAD, IFC modelo ha archivo cantidad, ha tamaño total.
- Mborevi pytã ha amarillo aviso, archivo ndoguerekói completo térã enlace carpeta-gui ndaipóri.
- {{ui:Start here}} caja: archivo BimCraft ohechauka ehasa porãva, ha mba'éichapa.
- **Modelos**: modelo peteĩ fila, copia ha backup ipype.
- **Archivos enlazados y referenciados**, **Modelos IFC**, **Planos CAD** ha **Apartados**, carpeta-pe oguereko rire.

Ñemuhápe, {{ui:Carpeta}} panel ohechauka resumen; **Problemas** ohechauka "Ninguno" opa copia porã rire.

## Ojeporu Start here caja

Caja peteĩ archivo ohechauka ha mba'éichapa, por ejemplo:

- "Trabajo más reciente guardado en esta carpeta (3 de marzo de 2025)."
- "*Consultor.rvt* oñeenlaza otro modelo-pe, upévare ndaha'éi archivo editar-pe, ha'e background."
- "*Torre.rvt* ohechauka ehasa porã, ha'e ojoaju; copia porã ultimo es de …"
- "Ha'e modelo central: Revit-pe ejapo "Create New Local" ha eeditá copia local-pe."

1. Ehecha mba'éichapa.
2. Hacer clic {{ui:Abrir su ficha}} ficha ehecha hag ua, térã {{ui:Mostrar en la lista}} **Modelos** ári fila ehecha.
3. Ehecha proyecto oñemoĩva ojapo mboveva ántes econfia. Caja avei ohendu: ha'e estimación nombre, fecha ha enlace rupi.

## Eabri archivo informe-gui

1. Hacer clic modelo réra ficha ohechauka. Ficha ojehecha enlace carpeta-gui.
2. Hacer clic {{ui:Volver a}} carpeta réra ficha ibypegui (térã {{ui:Volver a la carpeta}} ñemuhápe) ojevy.
3. Hacer clic IFC archivo **Modelos IFC** ári 3D-pe oabri.
4. Hacer clic DWG térã DXF **Planos CAD** ári 2D-pe oabri. Enlazado plano ha imagen carpeta-pe oñeheka automáticamente.

## Ejeho carpeta peteĩ jey

:::chromium
Carpeta {{ui:Abrir una carpeta}} rupi térã arrastre rupi oñemoĩva ohechauka **{{ui:Carpetas recientes}}** ñemuhápe. Hacer clic **{{ui:Volver a abrir}}** ha carpeta réra eabri jey, ndaikatúi elegi. Navegador oñemboguahẽ rire, Chrome térã Edge peteĩ jey ojerure; ehai "Permitir en cada visita" ndojerure. Lista ko navegador-pe anive, ndojehasái ambue. Hacer clic × carpeta ojejoguýi.
:::

:::firefox safari
Ko navegador ndoikuaái carpeta ohecha jey jave. Elegí carpeta jey {{ui:Abrir una carpeta}} rupi, térã arrastrá.
:::

## Errores comunes

- **Carpeta tuichaiterei.** 20.000 archivo mboyve: "Esta carpeta tiene más de 20.000 archivos. Elegí una carpeta más chica, como un solo proyecto." Elegí carpeta proyecto, ndaha'éi disco entero.
- **Carpeta heta proyecto mbytépe.** {{ui:Start here}} caja ojeporu heta proyecto-pe. Elegí peteĩ proyecto.
- **Revit carpeta ndehechái.** `*_backup`, `*_log` ha `Revit_temp` carpeta housekeeping, ojehechauka **Apartados** ári, ndojeleéi.
- **Ficha-gui modelo 3D-pe oabri jeruré.** Proyecto archivo ha'e ficha añoite. Ejeporu IFC exportación.
- **Teléfono ha tableta.** Heta navegador móvil ndoikuaái carpeta elegi. Ojeporu computadora.
