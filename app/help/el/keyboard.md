Το BimCraft έχει λίγες συντομεύσεις. Οι περισσότερες εργασίες γίνονται με το ποντίκι και τα πλαίσια. Οι συντομεύσεις γραμμένες με {{key:Mod}} χρησιμοποιούν το Command σε Mac και το Ctrl αλλού. Δείτε [Πλήκτρα, ποντίκια και trackpad](common:keys) για το πώς γράφονται τα πλήκτρα σε αυτή τη βοήθεια.

## Παντού

| Πλήκτρο | Τι κάνει |
|---|---|
| {{key:Ctrl+Shift+F}} | Εναλλαγή των λειτουργιών οθόνης: κανονική, πλήρης οθόνη, πλήρης οθόνη με κρυμμένες γραμμές. Ctrl σε κάθε πλατφόρμα, και σε Mac |
| {{key:Esc}} | Έξοδος από την πλήρη οθόνη |
| {{key:Mod+,}} | Άνοιγμα των {{ui:Settings}}. Δείτε [Ρυθμίσεις BimCraft](topic:settings) |
| {{key:Tab}} | Μετακίνηση ανάμεσα σε κουμπιά, πλαίσια ελέγχου και τιμές. Κάθε στοιχείο ελέγχου είναι προσβάσιμο από το πληκτρολόγιο |

## Προβολή 3D (μοντέλα IFC)

| Πλήκτρο ή ενέργεια | Τι κάνει |
|---|---|
| {{key:F}} | Προσαρμογή ολόκληρου του μοντέλου, τρισδιάστατη προβολή τριών τετάρτων (ίδιο με το {{ui:Fit}}) |
| {{key:Esc}} | Καθαρισμός της επιλογής, ή διακοπή της τοποθέτησης ή της επικόλλησης |
| Κλικ | Επιλογή του στοιχείου κάτω από τον δείκτη· κλικ σε κενό φόντο για καθαρισμό |
| {{key:Mod}}+κλικ ή {{key:Shift}}+κλικ | Προσθήκη ενός στοιχείου στην επιλογή, ή αφαίρεσή του |
| {{key:H}} | Απόκρυψη των επιλεγμένων στοιχείων. Δείτε [Απόκρυψη, απομόνωση και διαφάνεια στοιχείων](topic:hide-and-isolate) |
| {{key:I}} | Εμφάνιση μόνο των επιλεγμένων στοιχείων (απομόνωση) |
| {{key:T}} | Εμφάνιση των επιλεγμένων στοιχείων, όλα τα άλλα διάφανα |
| {{key:Shift+H}} | Εμφάνιση ξανά όλων των στοιχείων |
| {{ui:Walk}} | Έπειτα {{key:W}} {{key:A}} {{key:S}} {{key:D}} ή τα βέλη για περπάτημα, {{key:Shift}} για τρέξιμο, σύρσιμο για περιστροφή του βλέμματος, {{key:Esc}} για διακοπή. Δείτε [Περιήγηση σε ένα μοντέλο](topic:walk) |
| {{key:M}} | Μέτρηση αποστάσεων και εμβαδών όψεων. Δείτε [Μέτρηση αποστάσεων, εμβαδών όψεων και θέσεων σε 3D](topic:measure) |
| Σύρσιμο με το αριστερό πλήκτρο | Περιστροφή προβολής |
| Σύρσιμο με το δεξί πλήκτρο | Μετατόπιση |
| {{key:Shift}} ή {{key:Mod}} και σύρσιμο με το αριστερό πλήκτρο | Μετατόπιση (χρήσιμο σε trackpad) |
| Κύλιση τροχού, ή σύρσιμο με το μεσαίο πλήκτρο | Ζουμ |
| Κύλιση δύο δακτύλων ή τσίμπημα σε trackpad | Ζουμ |
| Ένα δάκτυλο (αφή) | Περιστροφή· ένα πάτημα επιλέγει |
| Δύο δάκτυλα (αφή) | Τσίμπημα για ζουμ, μετακίνηση μαζί για μετατόπιση |

| {{key:X}} | Επίπεδο τομής ενεργό και ανενεργό. Δείτε [Κοπή ενός μοντέλου IFC με επίπεδο τομής](topic:section-plane) |
|---|---|
| {{key:Shift+X}} | Κουτί τομής γύρω από τα επιλεγμένα στοιχεία, με τον χώρο που ορίζεται στις Ρυθμίσεις |

Δεν υπάρχουν πλήκτρα για τα {{ui:Top}}, {{ui:Front}} και {{ui:Side}}· χρησιμοποιήστε τα κουμπιά.

## Επεξεργασία

Οι ίδιες εντολές υπάρχουν στη γραμμή εργαλείων: {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}} και το μενού {{ui:More}}, που δείχνει κάθε πλήκτρο. Λειτουργούν στην προβολή 3D ενός μοντέλου IFC, όχι όταν πληκτρολογείτε σε πεδίο. Δείτε [Αντιγραφή, επικόλληση και διπλότυπο στοιχείων βιβλιοθήκης](topic:copy-paste).

| Πλήκτρο | Τι κάνει |
|---|---|
| {{key:Mod+Z}} | Αναίρεση της τελευταίας αλλαγής |
| {{key:Mod+Y}} ή {{key:Mod+Shift+Z}} | Επανάληψη όσων αναιρέθηκαν |
| {{key:Mod+C}} | Αντιγραφή των επιλεγμένων στοιχείων (τα ονόματα και οι ιδιότητές τους μπαίνουν και στο πρόχειρο ως κείμενο) |
| {{key:Mod+X}} | Αποκοπή των επιλεγμένων στοιχείων: αντιγραφή και έπειτα διαγραφή τους |
| {{key:Mod+V}} | Επικόλληση όσων αντιγράψατε: ακολουθούν τον δείκτη, κάντε κλικ όπου θα πάνε |
| {{key:Mod+Shift+V}} | Επικόλληση στην ίδια θέση: εκεί από όπου προήλθε μια αποκοπή, ή δίπλα στα πρωτότυπα μετά από αντιγραφή |
| {{key:Mod+D}} | Δημιουργία διπλότυπου: αντιγραφή των επιλεγμένων στοιχείων και έναρξη της επικόλλησής τους |
| {{key:Delete}} | Διαγραφή των επιλεγμένων στοιχείων, με τα μέρη και τα ανοίγματά τους. Δείτε [Διαγραφή, αποκοπή, αντιγραφή και επικόλληση δομικών στοιχείων](topic:edit-elements) |
| {{key:Mod+A}} | Επιλογή κάθε εμφανιζόμενου στοιχείου |
| {{key:Esc}} | Αποεπιλογή όλων |

Όταν είναι επιλεγμένο κείμενο στη σελίδα, το {{key:Mod+C}} αντιγράφει το κείμενο όπως συνήθως.

## Προβολή κάτοψης (Draw)

Αυτά λειτουργούν όταν το {{ui:Draw}} είναι ενεργό και δεν πληκτρολογείτε σε πεδίο. Δείτε [Σχεδίαση τοίχων](topic:draw-walls) και [Πόρτες και παράθυρα](topic:doors-and-windows).

| Πλήκτρο ή ενέργεια | Τι κάνει |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | Με {{ui:Door}} ή {{ui:Window}}: μεντεσέδες στο άλλο άκρο |
| {{key:Shift}} ενώ σχεδιάζετε τοίχο | Διατήρηση σε 0°, 90°, 180° ή 270° |
| Ψηφία και τα σύμβολα ποδιού και ίντσας (`'` και `"`) | Αρχίστε να πληκτρολογείτε μήκος στο πλαίσιο {{ui:Length}}· το {{key:Enter}} το χρησιμοποιεί |
| {{key:Enter}}, {{key:Esc}}, δεξί κλικ ή διπλό κλικ | Τέλος του τοίχου που σχεδιάζετε· το {{key:Esc}} ξανά επιστρέφει στην {{ui:Select}} |
| {{key:Delete}} | Διαγραφή των επιλεγμένων τοίχων, πορτών και παραθύρων· οι τοίχοι που μένουν ξανανώνονται |
| {{key:F}} με τον δείκτη πάνω στην κάτοψη | Προσαρμογή της κάτοψης |
| Κύλιση τροχού | Ζουμ γύρω από τον δείκτη |
| Σύρσιμο με το μεσαίο ή δεξί πλήκτρο, ή {{key:Space}} και σύρσιμο | Μετατόπιση· με ενεργό το {{ui:Select}}, και ένα απλό σύρσιμο μετατοπίζει |
| Σύρσιμο πόρτας ή παραθύρου με το {{ui:Select}} | Μετακίνηση κατά μήκος του τοίχου της, ή σε άλλον τοίχο |
| Δύο δάκτυλα (αφή) | Τσίμπημα για ζουμ, μετακίνηση μαζί για μετατόπιση |

## Τοποθέτηση και επικόλληση στοιχείων βιβλιοθήκης

| Πλήκτρο | Τι κάνει |
|---|---|
| {{key:R}} | Περιστροφή του στοιχείου κατά 90° |
| {{key:Tab}} | Ενεργοποίηση και απενεργοποίηση της προσκόλλησης σε τοίχο: η πίσω πλευρά του στοιχείου πάει στον κοντινότερο τοίχο |
| {{key:Enter}} στο **X, Y (mm)** | Τοποθέτηση στη θέση που πληκτρολογήσατε |
| {{key:Esc}} | Διακοπή της τοποθέτησης ή της επικόλλησης |

## Επεξεργασία τιμών IFC

| Πλήκτρο | Τι κάνει |
|---|---|
| {{key:Enter}} | Διατήρηση της τιμής που πληκτρολογήσατε |
| {{key:Esc}} | Ακύρωση και επαναφορά της παλιάς τιμής |
| Κλικ αλλού | Διατήρηση της τιμής που πληκτρολογήσατε |
| {{key:Mod+Z}} | Αναίρεση της τελευταίας αλλαγής. Μόνο όταν έχετε μη αποθηκευμένες αλλαγές και δεν πληκτρολογείτε σε πεδίο |
| {{key:Mod+Y}} | Επανάληψη όσων αναιρέθηκαν |
| {{key:Mod+S}} | Αποθήκευση ως IFC. Μόνο όταν έχετε μη αποθηκευμένες αλλαγές· αλλιώς ανοίγει η δική της εντολή αποθήκευσης του προγράμματος περιήγησης |

Για επεξεργασία μόνο με το πληκτρολόγιο: πατήστε {{key:Tab}} έως ότου επισημανθεί μια τιμή, και έπειτα πατήστε {{key:Enter}} για να αρχίσετε να πληκτρολογείτε.

## Σχέδια 2D (DWG και DXF)

| Πλήκτρο ή ενέργεια | Τι κάνει |
|---|---|
| {{key:F}} | Προσαρμογή του σχεδίου ή του φύλλου |
| {{key:P}} | Ενεργοποίηση και απενεργοποίηση της προβολής εκτύπωσης |
| Διπλό κλικ | Προσαρμογή |
| Σύρσιμο με οποιοδήποτε πλήκτρο | Μετατόπιση |
| Κύλιση τροχού | Ζουμ στον δείκτη |
| Κύλιση δύο δακτύλων ή τσίμπημα σε trackpad | Ζουμ στον δείκτη. Η κύλιση δύο δακτύλων δεν μετατοπίζει |
| Ένα δάκτυλο (αφή) | Μετατόπιση. Το τσίμπημα για ζουμ δεν έχει υλοποιηθεί ακόμη για σχέδια |

## Σχέδια σε 3D

| Πλήκτρο ή ενέργεια | Τι κάνει |
|---|---|
| {{key:3}} | 3D ενεργό και ανενεργό (και στη δισδιάστατη προβολή) |
| {{key:F}} | Όρια: ολόκληρο το σχέδιο |
| Σύρσιμο με το μεσαίο ή το αριστερό πλήκτρο | Περιστροφή |
| Σύρσιμο με το δεξί πλήκτρο, ή {{key:Shift}} και σύρσιμο | Μετατόπιση |
| Κύλιση τροχού | Ζουμ προς ό,τι βρίσκεται κάτω από τον δείκτη |
| Σάρωση δύο δακτύλων σε trackpad | Περιστροφή· με {{key:Shift}}, μετατόπιση |
| Τσίμπημα σε trackpad | Ζουμ |
| Ένα δάκτυλο (αφή) | Περιστροφή |
| Δύο δάκτυλα (αφή) | Τσίμπημα για ζουμ, μετακίνηση μαζί για μετατόπιση |

Τα {{key:F}}, {{key:P}} και {{key:3}} δεν κάνουν τίποτα όσο πληκτρολογείτε σε πεδίο, όσο εμφανίζεται ο πίνακας εξοπλισμού, ή όταν κρατάτε {{key:Mod}} ή {{key:Alt}}.
