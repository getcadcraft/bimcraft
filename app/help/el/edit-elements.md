## Τι θα κάνετε

Αλλάξτε το περιεχόμενο ενός μοντέλου IFC: αφαιρέστε στοιχεία που δεν θέλετε, αντιγράψτε έναν τοίχο ή ένα σύνολο επίπλων σε άλλο σημείο ή μετακινήστε στοιχεία με αποκοπή και επικόλληση. Κάθε αλλαγή είναι ένα βήμα που μπορείτε να αναιρέσετε, και η αποθήκευση γράφει νέο αρχείο, ώστε το αρχικό σας να μείνει όπως ήταν.

## Βήματα

1. Ανοίξτε ένα μοντέλο IFC. Δείτε [Άνοιγμα ενός μοντέλου IFC και εξέταση σε 3D](topic:open-ifc-model).
2. Επιλέξτε ό,τι θέλετε να αλλάξετε: κάντε κλικ σε ένα στοιχείο, κρατήστε πατημένο το {{key:Mod}} ή το {{key:Shift}} και κάντε κλικ για να επιλέξετε κι άλλα, ή πατήστε {{key:Mod+A}} ({{ui:More}}, {{ui:Select all}}) για να επιλέξετε όλα τα στοιχεία που φαίνονται.
3. Στη συνέχεια:
   - **Διαγραφή:** πατήστε {{key:Delete}}, ή {{ui:More}}, {{ui:Delete}}.
   - **Αντιγραφή:** πατήστε {{key:Mod+C}} ή κάντε κλικ στο {{ui:Copy}}.
   - **Αποκοπή:** πατήστε {{key:Mod+X}}, ή {{ui:More}}, {{ui:Cut}}. Τα στοιχεία φεύγουν και μπορείτε να τα επικολλήσετε.
4. Για να επικολλήσετε, πατήστε {{key:Mod+V}} ή κάντε κλικ στο {{ui:Paste}}. Ένα διάφανο κουτί στο μέγεθος αυτού που αντιγράψατε ακολουθεί τον δείκτη στον όροφο που έχει επιλεγεί στη γραμμή τοποθέτησης. Πατήστε {{key:R}} για περιστροφή 90°, και μετά κάντε κλικ εκεί που θα μπει. Κάθε κλικ τοποθετεί ένα ακόμη αντίγραφο· πατήστε {{key:Esc}} για να σταματήσετε.
5. Ή πατήστε {{key:Mod+Shift+V}} ({{ui:More}}, {{ui:Paste in place}}): μετά από αποκοπή, τα στοιχεία επιστρέφουν ακριβώς στη θέση τους· μετά από αντιγραφή, το αντίγραφο μπαίνει ακριβώς δίπλα στα αρχικά.
6. Κάντε κλικ στο {{ui:Save as IFC}} για να κατεβάσετε το επεξεργασμένο μοντέλο.

## Τι ακολουθεί ένα στοιχείο

- **Μέρη:** μια σκάλα παίρνει τις βολές της, ένας κουρτινοτοίχος τα πάνελ του, και κάθε στοιχείο φτιαγμένο από μέρη τα παίρνει όλα.
- **Ανοίγματα:** ένας τοίχος παίρνει μαζί του τα ανοίγματα που έχουν κοπεί σε αυτόν. Η διαγραφή μιας πόρτας ή ενός παραθύρου διαγράφει και το άνοιγμα που γέμιζε, ώστε ο τοίχος να κλείνει, όπως και σε ένα πρόγραμμα σχεδίασης κτιρίων. Η διαγραφή ενός τοίχου που σχεδιάστηκε στο BimCraft διαγράφει και τις πόρτες και τα παράθυρά του, και ενώνει ξανά τους τοίχους που μένουν. Η διαγραφή ενός τοίχου από αρχείο που δημιουργήθηκε αλλού αφήνει τις πόρτες και τα παράθυρά του όπου ήταν.
- **Δεδομένα:** ένα αντίγραφο έχει τον ίδιο τύπο, τα ίδια υλικά, σύνολα ιδιοτήτων και ποσότητες με το αρχικό, και νέο GlobalId. Αν αλλάξετε αργότερα μια τιμή στο αντίγραφο, το αρχικό μένει ανέπαφο.
- **Στοιχεία βιβλιοθήκης** διατηρούν τα δεδομένα βιβλιοθήκης τους· ένα αντίγραφο παίρνει τον επόμενο ελεύθερο αριθμό στοιχείου, και ένα αποκομμένο στοιχείο που επικολλάται ξανά κρατά τον δικό του.

## Τι θα δείτε

- «Διαγράφηκε: …» ή «Επικολλήθηκε: …» στη λίστα {{ui:Changes}}. Το {{key:Mod+Z}} αναιρεί την τελευταία αλλαγή· το {{key:Mod+Y}} την επαναφέρει.
- Μετά από διαγραφή, η γραμμή κατάστασης δείχνει πόσα μέρη και πόσα ανοίγματα διαγράφηκαν μαζί.
- Τα επικολλημένα στοιχεία είναι επιλεγμένα, ώστε να μπορείτε να τα επικολλήσετε ξανά στην ίδια θέση για να φτιάξετε μια σειρά, ή να τα διαγράψετε.

## Καλό είναι να γνωρίζετε

- Τα αντίγραφα χρησιμοποιούν την ίδια γεωμετρία με το αρχικό (το IFC επιτρέπει σε στοιχεία να μοιράζονται γεωμετρία), οπότε το αρχείο μεγαλώνει ελάχιστα.
- Τα στοιχεία κτιρίου επικολλώνται στο μοντέλο από το οποίο αντιγράφηκαν, στην ίδια καρτέλα. Για να χρησιμοποιήσετε τοποθετημένα στοιχεία βιβλιοθήκης σε άλλο μοντέλο, αντιγράψτε ένα στοιχείο τη φορά: δείτε [Αντιγραφή, επικόλληση και δημιουργία διπλότυπου στοιχείων βιβλιοθήκης](topic:copy-paste).
- Οι όροφοι, οι χώροι, τα κτίρια και το γήπεδο δεν μπορούν να διαγραφούν ή να αντιγραφούν. Επιλέξτε αντ' αυτών τα στοιχεία που περιέχουν. Ένας χώρος που σχεδιάστηκε στο BimCraft προκύπτει από τους τοίχους γύρω του: διαγράψτε έναν τοίχο για να ενώσετε δύο δωμάτια.
- Οι τοίχοι, οι πόρτες και τα παράθυρα που σχεδιάστηκαν με τα δικά τους εργαλεία του BimCraft δεν μπορούν ακόμη να αντιγραφούν, να αποκοπούν ή να δημιουργηθούν διπλότυπα· η γραμμή κατάστασης το αναφέρει. Σχεδιάστε τα ξανά. Η διαγραφή λειτουργεί.
- Η αντιγραφή βάζει επίσης τα ονόματα και τις ιδιότητες αυτού που αντιγράψατε στο πρόχειρό σας ως κείμενο, για να τα επικολλήσετε σε λογιστικό φύλλο ή σε μήνυμα ηλεκτρονικού ταχυδρομείου.

## Συνηθισμένα λάθη

- **Το {{ui:Delete}} είναι γκρι.** Δεν έχει επιλεγεί τίποτα, ή έχουν επιλεγεί μόνο όροφοι ή χώροι. Τοποθετήστε τον δείκτη πάνω του για να δείτε τον λόγο.
- **Η επικόλληση λέει ότι τα στοιχεία προέρχονται από άλλο μοντέλο.** Έχετε ανοίξει άλλο μοντέλο μετά την αντιγραφή. Ανοίξτε ξανά το πρώτο μοντέλο και αντιγράψτε εκεί.
- **Το επικολλημένο αντίγραφο βρίσκεται σε άλλον όροφο.** Το {{ui:Storey}} της γραμμής τοποθέτησης αποφασίζει πού μπαίνει· επιλέξτε τον όροφο πριν κάνετε κλικ.
