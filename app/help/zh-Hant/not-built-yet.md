目前的 BimCraft 是讀取、檢查與 IFC 資料編輯器，並已開始繪製建築：牆、門與窗、房間、樓板、天花板與屋頂（請參閱[繪製牆](topic:draw-walls)、[門與窗](topic:doors-and-windows)與[房間、樓板、天花板與屋頂](topic:floors-and-roofs)）。以下是尚未支援之功能的誠實清單，並附上目前可用的替代做法。

## 建模與編修

| 尚未支援 | 目前的替代做法 |
|---|---|
| 繪製樑；鋼斷面柱 | 使用建模程式，再於此開啟其 IFC 匯出檔。此處可放置矩形與圓形柱（請參閱[格線與柱](topic:grids-and-columns)）；此處可繪製直線、L 形、U 形、旋轉與螺旋樓梯，以及欄杆（請參閱[樓梯與欄杆](topic:stairs-and-railings)） |
| 老虎窗前牆上的窗；以手繪於屋頂面上的老虎窗；弧形屋頂；已算圖屋頂覆面的紋理 | 以角點繪製屋頂面，並為每面牆設定坡度：請參閱[屋頂：每面牆的坡度、山牆、單坡屋頂與屋頂面](topic:roofs) |
| 變更其他程式建立的牆、門或窗 | 使用其建模程式；繪製工具只會變更它們自己繪製的內容 |
| 牆的輪廓含外伸或孔洞；非矩形的牆開口；在 3D 檢視中新增或移除牆的輪廓點 | 輪廓、附著、傾斜與開口可在特性、立面與剖面、牆面檢視，以及 3D 中的夾點進行設定，適用於直牆與曲牆：請參閱[塑造牆面：附著、輪廓、傾斜與開口](topic:wall-shape) |
| 弧形牆上的{{ui:修剪／延伸}}與{{ui:轉角}}、框架、自動平面標註、沿弧線貼齊（貼齊其端點與弧的中點） | 對這些功能請將牆繪製為直線，或使用直線段。弧形牆請參閱[繪製牆](topic:draw-walls) |
| 在 3D 檢視中拖曳已放置的元件庫項目 | 在平面圖中拖曳，或在{{ui:特性}}中輸入 X、Y 與旋轉：請參閱[從元件庫放置設備與家具](topic:place-from-library) |
| 放置 CivilCraft 景觀工作區植物庫中的植物 | 在 CivilCraft 中種植，或從元件庫的配景中放置樹木與灌木：請參閱[從元件庫放置設備與家具](topic:place-from-library) |
| Plant 附加元件中（開啟前為關閉）：將已規劃路徑的管段繪製進模型、等角圖上的 spool 編號，以及從元件庫放置之設備的配置檢查 | 使用{{ui:管線}}繪製管段（請參閱[管線與風管](topic:pipes-and-ducts)）；配置檢查會讀取附加元件自身的設備表 |
| 轉動、鏡射或陣列單一繪製的牆、門與窗（牆可用移動、偏移與方盒拉伸來移動與複製：請參閱[牆體造型、分割、偏移、拉伸與鎖定](topic:wall-tools)）；弧形牆或三面以上牆相接處的接合樣式（對接、方角修整）（請參閱[牆體造型、分割、偏移、拉伸與鎖定](topic:wall-tools)）；文字工具；帷幕牆 | 使用{{ui:複製此標高…}}複製一個樓層上的所有內容（請參閱[繪製牆](topic:draw-walls#levels)）；否則請重新繪製 |
| 牆組合層在平面與剖面中繪製；剖面與立面中的標註；參照標註至門、窗與其他元件；牆組合與薄膜於明細表與數量中；跨專案共用的材料庫；剖面、立面與 3D 中的層次優先順序，以及三面以上牆的節點（在平面上，轉角、T 形接合與兩面牆的交叉處會依層次優先順序清理：請參閱[牆體造型、分割、偏移、拉伸與鎖定](topic:wall-tools)）；包覆或可變的層；編輯其他程式所建牆的組合 | 各層位於牆的類型及其預覽中（{{ui:牆體組合…}}）；牆以單一外殼量測：請參閱[牆體組合與參照標註](topic:wall-assemblies) |
| 變更元件的形狀或尺寸（此處繪製的牆、門與窗，以及由族放置的元件除外） | 使用建模程式。此處可使用刪除、複製、剪下與貼上：請參閱[刪除、剪下、複製與貼上建築元件](topic:edit-elements) |
| 刪除樓層、空間、建築或基地 | 刪除其中的元件 |
| 將建築元件貼上至另一個模型 | 在同一個模型內複製與貼上；已放置的元件庫項目可貼入任何模型 |
| 新增屬性或屬性集 | 在此填入既有的值，或在建模程式中新增參數後重新匯出 |
| 編輯數量、清單、列舉 | 使用建模程式 |
| 儲存其他程式的專案檔 | BimCraft 儲存 IFC（以及其自身的族檔：請參閱[族及其大小](topic:families)） |
| 族：可從平面放置並於專案間共用的族庫（元件庫）；在 3D 中拖曳已放置元件的熱點（熱點可在族編輯器的預覽與平面圖中拖曳）；依檢視選擇細節層級（專案僅一個層級；圖紙依比例選擇）；在另一族內位於直立平面上的旋轉，以四分之一圈轉動；它們自有的門與窗平面符號（它們會繪製其起始族的符號） | 含型別參數、公式、自有平面符號、熱點、重複、細節層級、族中族、由表格決定的尺寸與各元件參數的族，皆可於此製作：請參閱[編輯族](topic:family-editor)與[族及其大小](topic:families)。複製族即可從既有族開始 |
| 編輯其他程式的型別為族；將元件庫項目轉為族 | 其他程式的型別會列出、依推測分組，並選取其元件。元件庫項目依原樣放置 |
| 廠商的配件、閥與設備（容量、重量、廠商連接尺寸）；鋼製管段的 ASME B16.9 三通與異徑管長度；通過配件的壓力損失、流量與平衡；灑水頭；電纜架；依器具單位計算的立管與通氣管尺寸；拖曳管段的轉角；在牆與樓板中開孔；鬆開固定於埠口的管段端點（刪除設備除外）；從元件庫面板放置之元件庫項目上的埠口；配件重量；風管接縫、規格與連接器 | 此處可繪製含一般標準配件、系統、平面圖、明細表與數量統計的管線與風管：請參閱[管線與風管](topic:pipes-and-ducts)。含埠口的一般設備、相連的管段與連接檢查：[含埠口的 MEP 設備](topic:mep-equipment)、[將管線與風管連接至設備](topic:mep-connections)。碰撞集、淨空與開孔清單：[檢查管線與風管與結構的關係](topic:mep-against-structure)。鋼製管段與管段圖紙、風管切割清單：[鋼管管段與管段圖紙](topic:pipe-spools)。廠商項目請從 MEP 程式以 IFC 匯入 |
| 焊接 I 形斷面、IFC 斷面未命名為 W、S、IPE、HEA 或 HEB 型鋼尺寸之 I 形斷面，以及管材、角鋼與槽鋼的設計規範檢查（它們會回報為未檢查）；挫屈或動態反應（自然頻率在有限元區塊中）（二階僅為 P-Delta：彈性、彎曲，不做剛度折減）；分析中的牆與樓板；由面積產生的載重（每個混凝土樓板上的一個壓力除外） | {{ui:分析}}索引標籤會以一階分析提供梁、柱與斜撐的內力、反力與撓度，並檢查型鋼 I 形斷面，僅供參考，須經工程師審閱：請參閱[分析結構框架](topic:frame-analysis#design-checks) |

## 模型檢視

| 尚未支援 | 目前的替代做法 |
|---|---|
| 來自專案檔的 3D | 匯出 IFC 並開啟。請參閱[透過 IFC 將專案檔載入 3D](topic:rvt-to-ifc) |
| 產生之圖紙集中的室內立面（由房間的特性與自訂圖紙建立）；自訂的立面與剖面標註（會繪製樓層標記、高度、寬度與門窗標籤；註記則寫在檢視中：請參閱[在立面與剖面中編輯](topic:edit-in-elevations)）；在立面中繪製牆（牆會繪製於剖面的平面上）；透過 Studio 的團隊範本 | 由模型產生的圖紙集：請參閱[立面、剖面與圖紙](topic:sheets)。對於任何 IFC 模型：一個{{ui:剖面}}平面或剖面盒；請參閱[以剖面平面切開 IFC 模型](topic:section-plane) |
| 索引視圖、詳圖視圖、製圖視圖與圖例；檢視中繪製的製圖線與圖案填滿；裁切立面或剖面；立面、剖面、天花板平面與 3D 檢視的檢視範本；產生之圖紙集中的天花板平面；將自訂圖紙整組輸出為單一 PDF | 平面與天花板平面具有檢視範圍、裁切區域、比例與底圖（平面也有範本），而自訂圖紙可放置平面、天花板平面、立面、剖面與明細表，每個皆儲存為 PDF：請參閱[檢視、檢視範圍與自訂圖紙](topic:views-and-sheets) |
| 之後再將已放置的燈具移到天花板；傾斜或階梯式天花板；天花板圖案（五種格線除外）；燈具在天花板平面中的自有符號 | 使用**安裝：於天花板**放置它；天花板平面會依其自身形狀繪製燈具：請參閱[從元件庫放置設備與家具](topic:place-from-library) |
| 與他人分享搜尋集，或 IFC 檔案內的集合 | 集合保留在此瀏覽器中；請參閱[依類別、名稱或屬性尋找元件](topic:find) |
| 量測角度，或沿多點路徑量測 | 使用{{ui:量測}}分別量測各部分：請參閱[在 3D 中量測距離、面面積與位置](topic:measure) |
| 即時 3D 檢視中的紋理 | 上色材質會在檢視中顯示其顏色，並在算圖圖片中顯示其紋理：請參閱[算圖模型圖片](topic:render) |
| 任兩組之間的間隙（軟）碰撞、碰撞群組、儲存碰撞結果 | 執行{{ui:碰撞檢查}}，並為重要的碰撞建立問題：請參閱[檢查碰撞](topic:clash-check)。管線與風管對結構的檢查有{{ui:檢查淨空}}：請參閱[檢查管線與風管與結構的關係](topic:mep-against-structure) |
| 將數個模型儲存為一組，或同時編輯兩個模型 | 一次編輯一個模型；每個模型各自儲存其檔案 |
| 指派問題、到期日、標籤、每個問題的多個視點、編輯問題 | 每個問題一個視點；請參閱[問題與 BCF 檔案](topic:issues-bcf) |
| `.ifczip` 與 `.ifcxml` | 解壓縮或匯出一般的 `.ifc` |
| 未設定地圖轉換之模型的地圖圖層，或圖紙檢視中的地圖圖層 | 匯出含座標的模型：請參閱[模型下方的地面地圖](topic:map-layers) |
| 超過 600 萬點或 512 MB 的 E57 掃描；掃描儀廠商自有的檔案（RCP、RCS、FLS、LGS、TZF、ZFS）；圖紙 3D 檢視中的點雲；將點雲的位置與模型一併儲存 | 將掃描匯出為 LAS 或 LAZ，並與 IFC 模型一併開啟：請參閱[點雲格式](topic:point-cloud-formats)與[在模型旁顯示點雲](topic:point-clouds) |
| 掃描註冊：自行在掃描中找出標靶（球體、棋盤格）、一次求解所有掃描（光束法平差）、比例、與模型註冊 | 挑選相符的點或輸入標靶座標，然後以 ICP 逐一精修單一掃描：請參閱[將多個掃描註冊為一個](topic:register-scans) |
| 開啟 `.pln`、`.pla`、`.tpl` 與 `.bpn` 專案檔 | 從中匯出 IFC 與 DWG，或匯出專案套件：請參閱[開啟 .pln 與 .pla 專案檔](topic:pln-project-files)與[開啟專案套件](topic:open-project-bundle) |
| 開啟{{ui:元件}}清單以依類別選取 | 在{{ui:模型樹}}中按一下某類別的群組：請參閱[使用模型樹瀏覽](topic:model-tree) |
| 在 VR 中輸入問題的註解或標題、語音備註、以手在 VR 中移動剖面平面、VR 中的剖面盒 | 在 VR 中放置問題，然後在「問題」索引標籤中加入其文字；進入 VR 前，請先在 3D 檢視中設定剖面平面或盒：請參閱[在 VR 頭戴裝置中檢視模型](topic:vr-review) |
| 在 VR 中看見桌前的人（只會顯示在 VR 中的人），錄製 VR 漫遊 | 請他們加入 VR，或在 3D 檢視中跟隨 |
| 日光模擬（以氣候為基礎的日光、眩光、日照時數）、天窗在日光係數中的計算、依 BS EN 17037 或綠建築標章制度的檢查；ISO 52016-1 能源方法、逐時能源模擬、熱質量與熱橋、氣候檔案 | 設計輔助：平均日光係數、每扇窗的垂直天空分量、某日期穿過窗戶的太陽，以及格網上的日光係數（[估算各房間的日光](topic:daylight-factor)）；熱損失、度日年，以及每個房間的冷卻尖峰（[估算供暖與冷房負荷](topic:heating-and-cooling-loads)）。合規性請使用模擬程式 |
| 代管的建築孿生：關閉 BimCraft 時仍保存讀數並寄送警示、保養到期電子郵件；MQTT 5；讀回 COBie 的工作 | 在模型開啟時，從 CSV 或直接從自有的 MQTT 代理伺服器或位址讀取讀數，以標示資產的上下限、文件，以及 COBie 的匯出與匯入：請參閱[在模型中保存資產資料與保養紀錄](topic:assets-and-maintenance) |
| 適用於 Enscape、Twinmotion 或其他視覺化程式的外掛或即時連結；FBX 或 Datasmith 檔案；每個元件一個物件、已儲存的檢視與漫遊於 .glb 中 | 為讀取 glTF 的算圖程式儲存 .glb，或 USD 檔案（每個元件一個物件，附其 IFC 資料：請參閱[將模型匯出為 USD](topic:usd)），或供在另一個設計程式內執行的 IFC：請參閱[將模型傳送至算圖程式](topic:model-for-rendering)與[在其他程式中開啟場景](topic:render-open-in) |
| 由另一程式在無算圖引擎附加元件下繪製算圖圖片（CadCraft 從不執行 GNU GPL 授權的程式）；另一程式的全景或立體攝影機及天空圖片；Unreal Engine 外掛（檔案會寫出，但開啟它們的外掛尚未釋出） | 我們自有的 Fast 與 Path 追蹤引擎；附加元件的引擎（[以其他程式繪製圖片](topic:render-other-program)）；可從「引擎」清單取得的 USD、glTF 或 Unreal 資料夾檔，帶到任何程式中 |
| 在即時檢視中：散布植物與岩石、分享全景、導覽、離線檢視器或影片 | ModelCraft 的即時檢視具有這些功能；此處可算圖圖片與 360° 全景：請參閱[即時檢視](topic:live-view)與[算圖模型圖片](topic:render) |

## 圖面

| 尚未支援 | 目前的替代做法 |
|---|---|
| 編輯、量測或儲存 DWG 與 DXF | CadCraft 繪圖應用程式（2D 檢視上的{{ui:在 CadCraft 中編輯}}） |
| 列印或匯出 PDF | 從繪製該圖的程式列印；請先使用{{ui:列印視圖}}確認 |
| 繪圖樣式與筆表 | {{ui:列印視圖}}以純黑色並帶線寬顯示 |
| 比 R13 更舊的 DWG 檔，以及二進位 DXF（BimCraft 開啟時會告知） | 將圖面重新儲存為較新的 DWG，或 ASCII DXF |
| 在外部參考內的外部參考 | 直接開啟它們 |
| TIFF 圖片 | 儲存同名的 PNG 或 JPEG 副本並加入 |
| DGN 圖面 | 僅列於資料夾報表中 |
| 列於**尚未繪製**下的物件 | 在繪製該圖的程式中檢視圖面 |
| 圖面中的 ACIS 實體、本體、區域與曲面，以及 3D 中的細分網格 | 從繪製該圖面的程式匯出 IFC 或 3D 面 |
| 圖面的 3D 檢視中的圖片、多重引線與圖紙 | 在{{ui:模型}}索引標籤與圖紙上檢視 |
| 在圖面的 2D 檢視中挑選物件 | 切換至{{ui:3D}}並在其中按一下物件：請參閱[在 3D 中檢視 DWG 或 DXF 圖面](topic:dwg-in-3d) |
| 缺少 `KCL-ITEM` 標籤之圖面的設備明細表 | 無法使用 |
| XLSX 或 PDF 格式的設備明細表 | 按{{ui:下載 CSV}}並在試算表中開啟 |
