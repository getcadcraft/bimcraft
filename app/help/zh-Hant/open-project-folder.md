## 操作內容

開啟整個專案資料夾，例如為某項工作所交付的那個資料夾，並讓 BimCraft 加以整理：有哪些模型、哪些副本是備份、彼此連結了什麼、哪些檔案已損毀，以及最可能需要開啟的檔案。

每張模型卡片只需讀取幾 KB 的資料，因此位於網路磁碟機或同步雲端資料夾中的資料夾也可以使用。

## 步驟

:::chromium
1. 按一下左側的{{ui:開啟資料夾}}（或空白畫面的中央）。
2. 在開啟的視窗中選擇專案資料夾，然後按一下**選取**（視你的系統而定，也可能是**上傳**或**開啟**）。
3. 瀏覽器詢問「讓網站檢視檔案嗎？」時，按一下**檢視檔案**。這只會讓此索引標籤讀取資料夾，不會上傳任何內容。
4. 等待狀態列計數：「正在列出資料夾：…個檔案」，接著是「正在檢查 Revit 檔案：…／…」。
:::

:::firefox
1. 按一下左側的{{ui:開啟資料夾}}（或空白畫面的中央）。
2. 在開啟的視窗中選擇專案資料夾並確認。Firefox 可能會要求確認網頁可以讀取該資料夾中的檔案；這些檔案仍然只會留在你的電腦上。
3. 等待狀態列顯示「正在讀取資料夾：…個檔案」，接著是「正在檢查 Revit 檔案：…／…」。
:::

:::safari
1. 按一下左側的{{ui:開啟資料夾}}（或空白畫面的中央）。
2. 在開啟的視窗中選擇專案資料夾，然後按一下**上傳**。雖然名稱如此，檔案並不會離開 Mac：它們只是交給此索引標籤。
3. 等待狀態列顯示「正在讀取資料夾：…個檔案」，接著是「正在檢查 Revit 檔案：…／…」。
:::

也可以將資料夾從{{pick:mac=Finder|windows=檔案總管|linux=檔案管理程式}}拖曳到頁面上。在每種瀏覽器中，拖曳的資料夾都會直接開啟，不會出現任何權限提示。

## 預期結果

資料夾報告會顯示在中間：

- 資料夾名稱、模型、CAD 圖面、IFC 模型與檔案的數量，以及總大小。
- 若有任何檔案不完整，或有已連結的檔案在資料夾中遺失，會以紅色或琥珀色提示。
- {{ui:從這裡開始}}方塊：BimCraft 建議開啟的檔案，並附上原因。
- **模型**：每個模型一列，其備份歸於其下。
- **已連結與參照的檔案**、**IFC 模型**、**CAD 圖面**與**另行保留**，若資料夾中有這些內容才會顯示。

左側的{{ui:資料夾}}面板會做摘要；若每個副本都完好，**問題**會顯示「無」。

## 使用「從這裡開始」方塊

方塊會指出一個檔案並說明原因，例如：

- 「此資料夾中最新儲存的工作內容（2025 年 3 月 3 日）。」
- 「*Consultant.rvt* 已連結到其他模型，因此它是背景檔案，不是要編輯的檔案。」
- 「*Tower.rvt* 看似最明顯的選擇，但已損毀；其最後一個完好的副本來自……」
- 「這是中央模型：在 Revit 中，請使用「Create New Local」開啟，並在本機副本中工作。」

1. 閱讀原因。
2. 按一下{{ui:開啟其卡片}}以閱讀該檔案的卡片，或按一下{{ui:在清單中顯示}}以在**模型**中找到其列。
3. 依賴它之前，請先與最後處理該專案的人確認。方塊也會提醒此點：它只是根據名稱、日期與連結所做的最佳猜測。

## 從報告開啟檔案

1. 按一下模型名稱以開啟其卡片。卡片會將每個連結與資料夾進行比對。
2. 按一下{{ui:返回}}與卡片頂端的資料夾名稱（或左側的{{ui:回到資料夾}}）即可返回。
3. 在**IFC 模型**下按一下任一 IFC 檔案，即可在 3D 中開啟。
4. 在**CAD 圖面**下按一下任一 DWG 或 DXF，即可在 2D 中開啟。其連結的圖形與圖片會自動在資料夾中找到。

## 稍後重新開啟資料夾

:::chromium
使用{{ui:開啟資料夾}}或拖曳開啟的資料夾，會列在左側的{{ui:最近開啟的資料夾}}下。按一下{{ui:重新開啟}}與資料夾名稱，即可無需重新選擇而再次開啟。瀏覽器重新啟動後，Chrome 或 Edge 會再詢問一次；選擇「每次造訪都允許」即可停止詢問。此清單只保存在此瀏覽器中，絕不會傳送到任何地方。按一下 × 即可忘記某個資料夾。
:::

:::firefox safari
此瀏覽器無法在兩次造訪之間記住資料夾。請再次使用{{ui:開啟資料夾}}選擇資料夾，或將其拖曳進來。
:::

## 常見錯誤

- **選取的資料夾太大。**超過 20,000 個檔案時會顯示：「此資料夾的檔案超過 20,000 個。請選取較小的資料夾，例如單一專案。」請選取專案資料夾，而非整個磁碟。
- **選取了多個專案的上層資料夾。**此時{{ui:從這裡開始}}方塊會跨專案進行選擇。請選取單一專案。
- **Revit 自身的資料夾看起來被忽略。**`*_backup`、`*_log` 與 `Revit_temp` 資料夾屬於維護用資料，會列在**另行保留**下，而不會被讀取。
- **預期能從卡片在 3D 中開啟模型。**專案檔案只是卡片。請開啟其 IFC 匯出檔。
- **手機與平板。**許多行動瀏覽器根本無法選取資料夾。請使用電腦。
