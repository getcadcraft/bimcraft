## 工作內容

將專案檔轉換為可在 BimCraft 中環繞檢視、檢查與編輯的 IFC 檔案。BimCraft 尚無法讀取 `.rvt` 檔案內的 3D 模型，因此匯出必須在建立該檔案的程式（Revit）中進行；BimCraft 負責開啟結果。

## 步驟

1. 在建立專案的程式中開啟該專案。BimCraft 的卡片會顯示其儲存時所用的版本。
2. 開啟顯示要匯出內容的 3D 檢視。
3. 選擇**檔案 > 匯出 > IFC**。
4. 在匯出對話方塊中，選擇一個設定（或按**修改設定…**），並使用以下的設定。
5. 選擇資料夾與檔名，然後匯出。
6. 在 BimCraft 中，按一下{{ui:選擇檔案}}，並選擇新的 `.ifc` 檔案。以獨立檔案匯出的連結模型，可透過{{ui:加入模型}}一起開啟到同一個場景中。

## 效果最佳的設定

| 匯出器中的設定 | 選擇 | 原因 |
|---|---|---|
| IFC 版本 | 檢視、檢查與數量計算用 **IFC4 Reference View**；他人需要 IFC2X3 時用 **IFC2X3 Coordination View 2.0** | 兩者皆可完整開啟。**IFC4 Design Transfer View** 也能開啟，形狀較精確，但檔案較大且較慢。 |
| 檔案類型 | **IFC**（一般格式） | BimCraft 無法開啟 `.ifczip` 或 `.ifcxml`。 |
| 階段／可見元素 | 所需的階段，以及在為 3D 檢視設定時的**僅匯出檢視中可見的元素** | 排除刻意隱藏的內容。 |
| 屬性集 | **匯出 Revit 屬性集**與**匯出 IFC 通用屬性集** | 它們會成為 BimCraft 在{{ui:特性}}中顯示的屬性集，並供{{ui:尋找}}、{{ui:色彩}}與{{ui:模型檢查}}使用。 |
| 基本數量 | **匯出基本數量** | {{ui:數量合計}}與明細表會使用它們（長度、面積、體積），而非自行推算。 |
| 房間與面積 | **在 3D 檢視中匯出房間**（或房間／空間選項） | 房間會以空間的形式匯入：按一下{{ui:空間}}即可看到它們。 |
| 連結檔案 | **將連結檔案匯出為獨立 IFC** | 每個連結成為獨立檔案；以{{ui:加入模型}}一起開啟，它們會對齊。 |
| 座標基準 | **共用座標**（或測量基準點） | 檔案會攜帶其在地圖上的位置（IfcMapConversion），因此「測量 › 位置」、地面上的地圖圖層，以及依地圖座標放置的點雲均可使用。專案基準點可使模型靠近原點，但不會帶有其地圖位置。 |
| 依標高分割牆與柱 | 開啟；於依樓層計算數量時 | 每個樓層的部分為獨立的元件。 |

## 應看到的結果

3D 中的模型，其樓層取自專案的標高，且專案資訊顯示於{{ui:檔案}}面板。**匯出來源**會顯示匯出工具的名稱。

## 匯出保留的內容與不保留的內容

- **保留**：幾何、樓層、元件種類、名稱、類型、大多數參數（以屬性集形式）、需要時的基本數量、以空間形式呈現的房間，以及使用共用座標時的地圖位置。
- **不保留**：檢視、配置、註解、以可編輯族形式存在的族、工作集與設計選項。IFC 檔案是模型元件的快照，而非專案本身。若需要配置，請匯出 DWG，並在 2D 檢視中開啟。

## 常見錯誤

- **BimCraft中缺少參數。** 開啟上述的屬性集選項後重新匯出。
- **房間缺少。** 開啟房間選項，然後按一下{{ui:空間}}。
- **存成 `.ifczip`。** 選擇一般 IFC，或將 `.ifczip` 解壓縮。
- **沒有地圖位置。** 使用共用座標匯出，並確認專案的測量基準點已設定。
- **預期編輯會回寫。** 在 BimCraft 中儲存的編輯會寫入新的 IFC 檔案，不會寫回專案檔。
