BimCraft 的畫面頂端是一條橫列，其下有三個區域：左側的面板、中間的舞台，以及右側的 {{ui:特性}} 面板。每個區域顯示的內容取決於開啟的檔案：IFC 模型、專案或族檔案、圖形或資料夾。

## 應用程式列

頂端的細列屬於 CadCraft 網站，而非 BimCraft 本身。由左至右：

- CadCraft 標誌：前往 CadCraft 首頁。
- 應用程式名稱與版本功能表。在內部組建中，會顯示目前執行的組建，並可切換到已發佈的版本。
- {{ui:關於 BimCraft}}：網站上該應用程式的頁面。
- {{ui:設定}}：BimCraft 本身的設定，以及所有應用程式共用的設定。參閱 [BimCraft 設定](topic:settings)。
- {{ui:全螢幕}}：循環切換畫面模式。參閱下方的[畫面模式](topic:workspace#screen-modes)。
- {{ui:圖紙}} 與 {{ui:模型}}：淺色與深色佈景主題。3D 檢視與 2D 圖形都會依所選的佈景主題呈現。

## 左側面板

左側面板一律以**開啟檔案或資料夾**開頭：

- 拖放區，{{ui:請選擇檔案，或將檔案或資料夾拖放到此處}}。按一下可選擇單一檔案，或將檔案或資料夾拖放到其上（或頁面上的任何位置）。
- {{ui:開啟資料夾}}：選擇整個專案資料夾。參閱[開啟整個專案資料夾](topic:open-project-folder)。
- {{ui:最近開啟的資料夾}}：在 Chrome 與 Edge 中，以資料夾選擇器或拖放方式開啟資料夾後會出現。按一下 {{ui:重新開啟}} 與資料夾名稱即可再次開啟，按一下小小的 × 則會移除記錄。

其下的區段會視情況出現：

| 區段 | 顯示時機 | 內容 |
|---|---|---|
| {{ui:變更}} | 開啟 IFC 模型時 | 尚未儲存的編輯，最新的在前，並附 {{ui:復原}} 與 {{ui:另存為 IFC}} |
| {{ui:檔案}} | 開啟模型或檔案卡時 | 檔案的資訊：大小、結構描述或版本、專案、作者、元素數量 |
| {{ui:圖形}} | 開啟 DWG 或 DXF 時 | 格式、單位、實體與圖層數量、圖紙、連結的圖形、設備 |
| {{ui:資料夾}} | 開啟資料夾時 | 檔案與模型數量、大小、發現的問題 |
| {{ui:回到資料夾}} | 從資料夾中開啟檔案時 | 回到資料夾報告 |
| {{ui:圖層}} | 開啟圖形時 | 每個圖層一個核取方塊，並附 {{ui:全部開啟}} 與 {{ui:全部關閉}} |
| {{ui:樓層}} | 開啟 IFC 模型時 | 每個樓層一個核取方塊，最高樓層在前 |
| {{ui:元件}} | 開啟 IFC 模型時 | 模型中每種元素的數量（最常見的 30 種） |

## 舞台

畫面中間顯示開啟的檔案。

- **空白**：「開啟建築模型。」並附 {{ui:選擇檔案}} 與 {{ui:開啟資料夾}}，以及每種格式的簡短說明。
- **IFC 模型**：3D 檢視，頂端有工具列，與 CadCraft 繪圖應用程式一樣分成具名群組，每個工具的圖示位於其名稱上方：{{ui:檢視}}（{{ui:符合視窗}}、{{ui:俯視}}、{{ui:前視}}、{{ui:側視}}、{{ui:邊線}}、{{ui:空間}}）；{{ui:編輯}}（{{ui:復原}}、{{ui:取消復原}}、{{ui:複製}}、{{ui:貼上}} 與 {{ui:更多}}，參閱[複製、貼上與建立程式庫項目的副本](topic:copy-paste)）；{{ui:模型}}（{{ui:單位}} 與 {{ui:繪圖}}）；{{ui:程式庫}}（{{ui:程式庫}}、{{ui:設備}}、{{ui:更新}}、{{ui:署名}}）；{{ui:審閱}}（{{ui:顯示}}、{{ui:剖面}}、{{ui:漫遊}}、{{ui:量測}}；參閱[以剖面框切開 IFC 模型](topic:section-plane)）；以及 {{ui:輸出}}（算圖、即時檢視、VR、匯出、繪製與儲存的視圖）。{{ui:繪圖}} 開啟時，其下的繪圖列外觀相同：{{ui:檢視}}（標高與平面類型）、{{ui:繪圖}}、{{ui:編輯}} 與 {{ui:程式庫}}。視圖方塊位於右下角。參閱[開啟 IFC 模型並在 3D 中四處檢視](topic:open-ifc-model)。在 {{ui:設定}}、{{ui:一般}} 中可選擇這些按鈕顯示圖示、標籤或兩者皆顯示，也可顯示或隱藏群組名稱；在工具列上按右鍵可排列其工具與群組。視窗較矮時，工具列會省略圖示下方的名稱。
- **專案或族檔案**：檔案卡，含預覽圖、專案資訊與連結的檔案。參閱[讀取專案或族檔案](topic:read-rvt-file)。
- **DWG 或 DXF**：一排索引標籤（{{ui:模型}}，接著每張圖紙一個，圖形含有帶標籤的設備時再加上 {{ui:設備}}，然後是 {{ui:3D}}、{{ui:符合視窗}} 與 {{ui:列印視圖}}）、圖形，以及角落中即時的 X 與 Y 座標。參閱[檢視 DWG 或 DXF 圖形](topic:view-dwg)與[以 3D 檢視 DWG 或 DXF 圖形](topic:dwg-in-3d)。
- **資料夾**：資料夾報告，含 {{ui:從這裡開始}} 方塊，以及模型、連結、IFC 模型與圖形的表格。參閱[開啟整個專案資料夾](topic:open-project-folder)。

舞台底部的**狀態列**會顯示 BimCraft 正在做什麼（「正在讀取模型……」、「正在建立幾何：5400 個元素中的 1200 個」），失敗時則以紅色顯示出了什麼問題。成功的訊息會在幾秒後淡出。

## 屬性面板

右側面板顯示：

- IFC 模型：按一下的元素，含其名稱、類型、標籤、GlobalId 與每個屬性集。可以修改的值看起來像按鈕。參閱[屬性面板欄位](topic:properties-panel)。
- 圖形：如何移動檢視、圖形的連結圖形與影像以及是否找到，還有**尚未繪製**的內容清單。
- 檔案卡或資料夾：接下來要開啟什麼的簡短說明。

## 在小螢幕上

視窗比筆記型電腦螢幕窄時，BimCraft 會將各區域堆疊：舞台在上，面板在下。捲動頁面即可到達面板。在手機上為單欄，在平板上為雙欄。

## 畫面模式

應用程式列中的 {{ui:全螢幕}} 按鈕，或在所有平台上按 {{key:Ctrl+Shift+F}}，會循環切換三種模式：

1. 一般。
2. 全螢幕，列仍顯示。
3. 全螢幕且隱藏應用程式列。將指標移到頂端邊緣，或點一下該處，即可叫出。

按 {{key:Esc}} 可回到一般模式。不支援全螢幕的瀏覽器（例如 iPhone 上的）只會在一般與隱藏列之間切換。
