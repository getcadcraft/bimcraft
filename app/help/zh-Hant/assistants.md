## 本主題內容

如何讓 AI 助理（任何支援 MCP 的助理）查看目前開啟的 IFC 模型並在其中繪圖、助理可做與不可做的事，以及如何停止。

## 助理在 BimCraft 中能做的事

| 助理的要求 | 結果 | 所需權限 |
|---|---|---|
| 尋找元素 | 依類別、樓層、名稱或屬性值取得元素清單，與**尋找**相同 | 讀取 |
| 讀取屬性 | 取得單一元素的屬性、類型、屬性集與數量，即**屬性**面板所示內容 | 讀取 |
| 描述模型、列出牆 | 取得樓層、牆、門、窗、房間、樓板、網格與柱，以及每面牆的端點、類型與高度 | 讀取 |
| 隔離、透視、隱藏或顯示 | 3D 視圖的變化，與使用 {{ui:Show}} 功能表相同 | 變更視圖與繪製 |
| 繪製牆、門、窗、樓板、樓層或網格線 | 模型的變化，與使用 {{ui:Draw}} 工具相同：牆會接合，房間、樓板與屋頂隨之跟隨 | 變更視圖與繪製 |
| 變更名稱或屬性值 | 單一元素的名稱、描述、物件類型或標籤，或一個屬性值。若該值與其他元素共用，會先為該元素複製；類型的值只有在助理明確指示時才會變更，因為該類型的每個元素都會跟隨 | 變更視圖與繪製 |
| 移動、刪除、變更牆、門與窗 | 元素會隨其所承載的物件一起移動或刪除；以 {{ui:Draw}} 工具繪製的牆會依其端點或類型變更，門與窗依其位置、尺寸或類型變更，房間與接合處隨之跟隨 | 變更視圖與繪製 |
| 設定、排列與讀取明細表 | 「依樓層列出門明細表，含防火等級與五金」：助理指定明細表名稱、欄位（屬性或標籤會成為欄位）與分組；BimCraft 會從模型填入並排版，助理未指定的部分則依公司標準。設定會加入明細表清單。助理回傳的每一列都會列出其元素，因此可加以選取 | 讀取以讀取；變更視圖與繪製以儲存設定 |
| 匯出明細表 | CSV、Excel，或可貼至 Google 試算表的定位字元分隔文字（不會傳送至 Google） | 匯出 |
| 讀取與設定房間飾面 | 飾面類型、各房間的地板、牆面與天花板飾面、分區；面積、磚數與基材體積則取自飾面明細表 | 讀取；設定須變更視圖與繪製 |
| 選取元素、復原其自身的步驟 | 在視圖中挑選元素；其最後一個步驟會被復原 | 變更視圖與繪製 |
| 儲存 | 一個包含所有變更的新 IFC 檔案，與 {{ui:Save as IFC}} 所產生的相同（原始檔案永不會被變更） | 儲存 |
| 匯出 USD | 開啟的模型以 OpenUSD 格式（.usda、.usdc 或 .usdz）輸出，與工具列上 {{ui:USD}} 的寫出方式相同 | 匯出 |
| 算圖一張圖片，執行算圖佇列 | 3D 視圖的圖片，依 {{ui:Render}} 對話方塊與算圖設定產生（除非要求其他設定），或將高品質圖片加入對話方塊的佇列並依序算圖（佇列需要 WebGPU）。模型不會變更（[算圖圖片](topic:render)） | 匯出 |

助理所做的每項變更，都是**變更**中的一個步驟，名稱為「助理：…」（例如「助理：新增 4 面牆」），因此 {{key:Mod+Z}} 可復原其整個動作，也能看出是哪個步驟所為。在視窗中，助理無法開啟檔案：由您開啟模型，助理只處理目前開啟的模型。

## 開啟方式

助理會透過您電腦上的 CadCraft Studio 與 BimCraft 連線；一般瀏覽器無法連入。

1. 開啟 {{ui:Settings}}，選擇 **BimCraft** 索引標籤。
2. 在 **助理** 下，勾選 **允許 AI 助理與指令稿使用 BimCraft**。
3. **讀取** 預設已勾選。若助理可隔離與隱藏元素並繪製，請另勾選 **變更視圖與繪製**；若助理可將模型另存為新檔，請另勾選 **儲存**。
4. 在 Studio 中連接助理（Studio 會顯示位址，以及要貼入助理的設定）。

## 助理連線時

右側面板頂端的提示會說明已連線的助理及其可做的事。按 {{ui:Disconnect}} 可立即結束其工作階段；若要繼續，它必須重新連線。

**活動**（位於設定的**助理**下）會列出助理發出的每一次呼叫，最新的在最前，並顯示是否成功。

:::tip
請以白話提問，例如「隔離 Level 1 的外牆」、「哪些門沒有防火等級？」，或「在 Level 1 繪製 6 m × 4 m 的房間，南牆上有一扇門」。助理會尋找元素並在視圖中顯示，或加以繪製。
:::

## 無視窗：指令稿與指令列

相同的繪圖工具可用於您指定之資料夾中的 IFC 檔案，無需開啟視窗：CadCraft 的 MCP 伺服器與指令列可新建建築或開啟 IFC 檔案、描述它、新增牆、門、窗、樓板、樓層與網格、復原，並以新的 `.ifc` 檔案儲存。由您決定其可使用的資料夾，以及是否允許其變更或儲存任何內容。

## 關閉方式

取消勾選 **允許 AI 助理與指令稿使用 BimCraft**。所有助理會立即中斷連線，且此設定會保留至下次使用。
