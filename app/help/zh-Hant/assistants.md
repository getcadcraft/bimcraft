## 學習目標

說明如何讓 AI 助理（任何支援 MCP 的助理）查看你已開啟的 IFC 模型並在其中繪製，它能做與不能做的事，以及如何停止它。

## 助理在 BimCraft 中能做的事

| 助理的要求 | 會發生什麼 | 所需權限 |
|---|---|---|
| 尋找元素 | 依類別、標高、名稱或屬性值取得元素清單，與 **尋找** 的功能相同 | 讀取 |
| 讀取特性 | 取得單一元素的屬性、類型、屬性集與數量，與 **特性** 所顯示的內容相同 | 讀取 |
| 描述模型、列出牆 | 取得標高、牆、門、窗、房間、樓板、軸線與柱，以及每面牆的端點、類型與高度 | 讀取 |
| 隔離、透視、隱藏或顯示 | 3D 視圖會改變，如同你使用 {{ui:顯示}} 功能表 | 變更視圖與繪製 |
| 繪製牆、門、窗、樓板、標高或軸線 | 模型會改變，如同你使用 {{ui:繪製}} 工具；牆會接合，房間、樓板與屋頂會跟著更新 | 變更視圖與繪製 |
| 變更名稱或特性值 | 單一元素的名稱、描述、物件類型或標籤，或單一屬性值。與其他元素共用的值會先為該元素複製一份；類型的值只有在助理明確指定時才會變更，因為該類型的每個元素都會跟著變動 | 變更視圖與繪製 |
| 移動、刪除、變更牆、門與窗 | 元素會連同其所承載的元素一起移動或刪除；以 {{ui:繪製}} 工具繪製的牆會依其端點或類型變更，門與窗會依其位置、尺寸或類型變更，房間與接合會跟著更新 | 變更視圖與繪製 |
| 設定、排列與讀取明細表 | 「依樓層列出門的明細表，含防火等級與五金」：助理會為明細表命名，指定其欄位（特性或標籤會成為欄位）與分組方式；BimCraft 會從模型填入資料並排版，助理未指定的部分則取自事務所標準。此設定會加入你的 **明細表** 清單。助理收到的每一行都會列出其元素，因此它可以選取這些元素 | 讀取：讀取；儲存設定時需要變更視圖與繪製 |
| 匯出明細表 | CSV、Excel，或以 Tab 分隔的文字，可貼至 Google Sheets（不會傳送任何內容至 Google） | 匯出 |
| 讀取並設定房間面材 | 面材類型、每個房間的地板、牆面與天花板面材、分區；面積、磚數與基底體積則取自面材明細表 | 讀取；設定時需要變更視圖與繪製 |
| 選取元素、復原其自身步驟 | 在視圖中挑選元素；它的上一個步驟會被復原 | 變更視圖與繪製 |
| 儲存 | 含所有變更的新 IFC 檔，與 {{ui:另存為 IFC}} 的結果相同（原始檔永遠不會被更動） | 儲存 |
| 匯出 USD | 將開啟的模型匯出為 OpenUSD（.usda、.usdc 或 .usdz），與工具列上的 {{ui:USD}} 寫出的結果相同 | 匯出 |
| 算圖圖片、執行算圖佇列 | 3D 視圖的圖片，與 {{ui:算圖}} 對話方塊依你的算圖設定所產生的相同（除非它要求其他設定），或將高品質圖片加入對話方塊的佇列並依序算圖（佇列需要 WebGPU）。模型不會有任何變動（[算圖圖片](topic:render)） | 匯出 |

助理所做的每項變更都是 **變更** 中的一個步驟，名稱為「助理：…」（例如「助理：新增 4 個牆」），因此 {{key:Mod+Z}} 會復原它的整個動作，你也能看出是哪個步驟所做的。在視窗中，助理無法開啟檔案：由你開啟模型，它只處理已開啟的那一個。

## 開啟方式

助理透過電腦上的 CadCraft Studio 連接 BimCraft；一般瀏覽器無法連入。

1. 開啟 {{ui:設定}}，選擇 **BimCraft** 索引標籤。
2. 在 **助理** 之下，勾選 **讓 AI 助理與指令稿使用 BimCraft**。
3. **讀取** 已為你預先勾選。若助理可以隔離與隱藏元素並進行繪製，請也勾選 **變更視圖與繪製**；若它可以將模型另存為新檔，請勾選 **儲存**。
4. 在 Studio 中連接助理（Studio 會顯示位址與要貼入助理的設定）。

## 助理連線期間

右側面板頂端的提示會說明目前連線的助理，以及它能做什麼。按一下 {{ui:中斷連線}} 可立即結束其工作階段；若要繼續，必須重新連線。

**活動**位於 {{ui:設定}} 中的 **助理** 之下，會依最新到最舊列出助理發出的每次呼叫，並標示該次呼叫是否成功。

:::tip
以白話提問，例如「隔離標高 1 的外牆」、「哪些門沒有防火等級？」或「在標高 1 的南牆上繪製一個 6 × 4 m 的房間，並在牆上設置一扇門」。助理會找到元素並在視圖中顯示，或加以繪製。
:::

## 無視窗時：指令稿與指令列

相同的繪圖工具也能用於你指定資料夾中的 IFC 檔，且無需開啟視窗：CadCraft 的 MCP 伺服器與指令列可以建立新建築或開啟 IFC 檔、描述其內容、新增牆、門、窗、樓板、標高與軸線、復原，並將其儲存為新的 `.ifc` 檔。另有四個工具適用於指令稿：`ifc_batch` 會將最多 200 個編輯步驟合併為一次執行（全部成功或全部不執行：一次復原即可撤回整批，遭拒絕的步驟會復原其餘步驟，並標示該步驟）；`ifc_describe` 列出標高，以及每面牆及其門與窗；`ifc_render_png` 在無視窗的情況下寫出模型的平面著色檢查圖（不含材料、材質或陰影）；`usd_export` 寫出 `.usda`、`.usdc` 或 `.usdz`。在指令列中，`cadcraft bim script.json --from model.ifc -o out.ifc` 會執行一份步驟指令稿，而 `--usd`、`--png` 與 `--plan` 則會從同一次執行寫出 USD 檔、圖片或平面圖。你可以決定它能使用哪些資料夾，以及是否可以變更或儲存任何內容。

## 關閉方式

取消勾選 **讓 AI 助理與指令稿使用 BimCraft**。所有助理會立即中斷連線，此設定會保留至下次使用。
