## 開啟編輯器

開啟族（專案瀏覽器的 **族**，或 {{ui:建置版本}} › {{ui:族…}}），然後點擊 {{ui:編輯族}}。若要從無到有，請點擊 {{ui:新增族}}：為其命名、說明它是什麼（門、窗、家具、設備或其他），若是門或窗，還要選擇其平面符號與把手來自哪個起始族。編輯器會開啟一個具有數個參數與一個實體的族。

編輯起始族只會將變更保留在此模型中。其他模型會保留原來的起始族。

在點擊 {{ui:儲存族}} 之前，模型不會有任何變更。編輯器有自己的復原與取消復原（名稱旁的箭頭按鈕，或 {{key:Mod+Z}} 與 {{key:Mod+Y}}）；儲存則是模型復原中的一個步驟。

## 參數

{{ui:參數}} 索引標籤列出族的參數：名稱、類型與預設值。類型包括：**長度**（毫米）、**角度**（度）、**數字**、**整數**、**是 / 否**、**筆**（1–16），以及三種用於文字而非數字的類型：**文字**、**材料**（專案的其中一種材料）與 **填滿**（平面填滿）。文字不用於公式；它們會為實體上色（其 **材料**）、填滿符號的部件，或在符號的文字中以 `{Name}` 的形式列印。**每個元素** 勾選框會讓每個已放置的元素為自己設定該參數，而非依尺寸設定。

- **公式** 會讓參數隨其他參數變動，例如 `Width / 30` 或 `if(Width > 1200, 2, 1)`。公式中的長度為毫米，或寫明單位：`3'`、`6in`、`50cm`。
- 重新命名參數會在每個使用它的公式與欄位中同時重新命名。仍在使用中的參數無法移除。
- 實體的 **材料** 會採用專案材料的顏色（或材料參數的顏色），**顯示於** 會在較粗略的細節等級隱藏它，**重複** 會製作副本：數量（數字或整數參數，1 至 200）以及它們之間在 x、y、z 方向的間距。重複的實體即為一排木板、橫條或孔洞；用於切割時，副本會一起切割。
- 門或窗族還會從其牆面取得兩個名稱：`WallThickness` 與 `Face`（1 或 −1，即門開啟所朝的那一側）。

## 實體

{{ui:實體}} 索引標籤列出實體。可新增方塊、擠出、旋轉或掃出：

| 實體 | 需設定的內容 |
|---|---|
| 方塊 | 其兩個角點：x0 至 x1、y0 至 y1、z0 至 z1 |
| 擠出 | 工作平面（平面、正面或側面）上的輪廓、平面所在位置，以及深度 |
| 旋轉 | 輪廓、平面上的軸，以及最大 360° 的角度 |
| 掃出 | 點的路徑與半徑（桿或扶手） |

每個數值都可以是輸入的數字，或參數的運算式。每個實體都有顏色與 **顯示條件**：留空則永遠顯示，或指定一個是 / 否參數（或寫出比較式，例如 `Shelves >= 3`），使其僅在該條件成立時顯示。這就是可見性參數。

### 繪製輪廓

擠出或旋轉的輪廓會繪製在預覽下方的工作平面上：

- 在繪圖區上點擊，即可在所選點之後新增一點。
- 拖曳點可移動它。點會貼齊格點；按住 {{key:Shift}} 可自由放置。
- 點擊線段上的小方塊，即可在該處新增一點。按 {{key:Shift}} 並點擊，可將該線段變為圓弧（再次點擊可切換另一方向，然後變回直線）。
- 連按兩下點即可移除該點。

中空的點由參數設定：請在表格中變更，不要拖曳。

## 布林運算

{{ui:布林運算}} 索引標籤會從第一個實體中切除第二個實體，或將兩者接合。布林運算的結果可以再次切割或接合。用於布林運算的實體只會繪製為其中的一部分。

若第二個實體因其是 / 否參數而隱藏，則保留第一個實體的原狀；若第一個實體隱藏，結果即隱藏。

## 平面符號

{{ui:平面符號}} 索引標籤會定義平面為此族顯示的內容，而非實體的切面：直線、矩形、圓、圓弧、多邊形與文字，位於族自身的座標軸中。每個部件都有 **筆**（1–16，運算式或筆參數）、**填滿**（無、實心、斜線、交叉線、混凝土、保溫、土壤，或填滿參數）、**顯示條件** 運算式、以毫米計位於其基準上方的 **切割範圍**（當平面的切割位於其內時以完整線寬繪製，位於其下方時較細，位於其上方時以虛線繪製：高於切割線的櫃子會以虛線顯示）、細節等級與重複。文字可以 `{Name}` 的形式提及參數。**平面顯示：實體的切面** 會讓平面持續切割實體，而符號仍保留在族中。其他程式會將符號讀取為族的佔地（線條與形狀；文字則保留在 BimCraft 中）。

## 內含的族

{{ui:內含的族}} 索引標籤會將另一個族放入此族中：桌子的一隻腳、門的把手。選擇族，然後設定其位置（x、y、z）、旋轉角度（僅限四分之一圈：0、90、180、270）、何時顯示，以及它取得的值（每行一個，格式如 `Height = Height - 40`）。儲存內層族時會重新繪製此族；被其他族持有的族無法刪除；族不能包含自己，即使間接透過另一個族也不行，且巢狀結構最多四層。

## 熱點

熱點是可拖曳以變更參數的點或邊。在 {{ui:熱點}} 索引標籤中新增一個，選擇其拖曳所沿的軸與它所變更的數字參數，並以與實體相同的運算式寫出其位置。在預覽中，於控點下方選擇 **熱點**，即可拖曳它們。在平面圖中的已放置元素上（以 {{ui:選取}} 選取），x 與 y 熱點會顯示為夾點：拖曳其中之一，元素會取得使熱點位於該處的尺寸，並經過兩者之間的任何公式；一次復原即可還原。熱點不能變更受驅動的參數、是 / 否參數或文字。

在 3D 檢視中，相同的熱點會以夾點形式顯示在所選元素上，上下方向（z 軸）的熱點也會顯示於此，這是平面圖無法繪製的。選取元素，沿其軸拖曳夾點後放開：元素會取得使熱點位於該處的尺寸，並作為一個復原步驟。剖面框開啟時會隱藏夾點，因為它使用相同的夾點。

## 連接器

放置在地板上的族（家具、設備等）具有 {{ui:連接器}} 索引標籤：管線或風管與元素相接的點，例如洗手台的水龍頭與排水口。點擊 {{ui:新增連接器}}，並設定：

- **種類**：管線或風管，以及其 **系統**（冷水、衛生排水、送風等）。
- **x**、**y** 與 **z**：其位置，位於族自身的座標軸中。與實體的數值相同，每個都可以是數字或參數的公式，因此連接器會隨尺寸移動。
- **出口方向**：管線或風管離開的方向，沿族的某一座標軸（洗手台下方的排水管為 **向下**）。
- **尺寸 (mm)**：管線的標稱尺寸（DN）或圓形風管的直徑。
- **流向**：**進入** 表示被供水的連接器（水龍頭），**流出** 表示排水的連接器。

預覽會將每個連接器繪製為一個環，並以箭頭表示出口方向。門與窗沒有連接器。

對於衛浴設備，請在 **衛浴設備** 下選擇其種類（馬桶、洗手台、廚房水槽、淋浴、洗衣槽）。起始設備已標明種類。

從該族放置的每個元素，都會在 IFC 檔案中取得其連接器作為連接埠，並在元素變更尺寸或儲存族時重新製作。讀取 IFC 系統的程式可看出每條管線或風管所屬的位置。

## 預覽與控點

預覽是族以 IFC 形式寫出的結果，由將其儲存至模型的同一段程式碼產生，並再次繪製。所見即其他程式取得的內容。在其下方，**顯示尺寸** 會設定預覽所用的參數值。

**控點** 是預覽上的圓點：**尺寸** 會為寬度、深度與高度顯示控點；**所選實體** 會在所選實體的每個面上顯示一個控點。拖曳控點：

- 在由參數設定的面上，顯示的尺寸會變更（族的公式會保留）；
- 在由輸入數字設定的面上，該數字會變更。

## 儲存

{{ui:儲存族}} 會檢查族，接著為它的每個尺寸重新繪製，並重新製作其每個元素，作為一個可復原的步驟。若某個尺寸因此變更而無法繪製（例如某個實體在該尺寸下會沒有寬度），則不會儲存任何內容，編輯器會指出是哪個尺寸。

若在編輯器開啟期間，其他人（在 Live TeamWork 工作階段中，或在另一個視窗中）已儲存同一個族，{{ui:儲存族}} 會拒絕儲存並說明原因，而不會以本次變更覆蓋對方的變更。關閉編輯器，重新開啟族以查看對方的變更，然後再重新製作本次變更。

:::note
幾何會以 IFC 原生的實體儲存：擠出、旋轉、掃出的圓管與布林運算結果。不會轉換為三角面清單，因此檔案較小，其他程式也能將形狀讀取為形狀。在 IFC4 中，含圓弧的輪廓會以圓弧儲存；IFC2X3 的輪廓沒有圓弧線段，因此圓弧會以短直線段儲存。
:::
