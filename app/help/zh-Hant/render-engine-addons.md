外掛（設定 › 外掛）可以在{{ui:算圖}}的引擎清單中新增一個引擎。給外掛作者的完整說明見外掛規格第 16 節，簡述如下：

- 外掛註冊一個引擎，其 ID 以外掛自己的 ID 開頭，並提供名稱、選用的設定，以及**執行程式**或**以 JavaScript 繪製畫面的函式**二者之一。
- 執行程式的引擎需要 **`engine.run`** 權限，安裝前與設定中都會顯示。此引擎只在 Studio 中執行；在瀏覽器中則顯示為可儲存的檔案。
- 外掛指定程式（僅為純檔案名稱，絕不是 shell）、位於**已簽章外掛內**的指令稿，以及由佔位符與一般文字組成的引數。Studio 會找到該程式，或要求指定一次其位置。
- 外掛第一次執行程式時，**Studio 會在其自己的對話方塊中詢問**：哪個外掛、哪個程式，以及指令稿可以做到程式所能做的任何事。只允許你信任的外掛。你的回答會記住該外掛與程式的組合。
- 封裝檔（場景為 USD 與設定檔，外掛要求時另含 glTF 檔）與外掛的指令稿，會放入一個全新的暫存資料夾，程式在其中執行，而完成的畫面會以外掛的引擎名稱標記後傳回。

:::note
外掛只能從外掛 API 1.4 起新增算圖引擎。以開放原始碼命令列算圖器撰寫的實作範例位於其自己的儲存庫中；尚未在該算圖器中實際執行。
:::
