{{ui:算圖}}中的畫面由**我們自己的引擎**繪製：快速與路徑追蹤，在瀏覽器與 CadCraft Studio 中皆可使用。只有當**算圖引擎外掛**提供時，其他程式才能繪製畫面：請見[以外掛新增算圖引擎](topic:render-engine-addons)。若要將場景帶到其他程式並在那裡繼續工作，請使用[在其他程式中開啟場景](topic:render-open-in)或[將場景傳送到遊戲引擎](topic:render-unreal)。

## 以外掛的引擎繪製畫面

1. 在設定 › 外掛中開啟外掛。其引擎會出現在{{ui:算圖}}的引擎清單中。
2. 選取它。其自身的設定會顯示在引擎清單下方。
3. 按下{{ui:算圖}}。在 Studio 中，外掛第一次執行程式時，Studio 會在其自己的對話方塊中詢問。繪製期間會顯示進度；{{ui:停止}}會結束繪製。完成的畫面會標示是哪個引擎繪製的。

以 JavaScript 撰寫的引擎也會在瀏覽器中執行。在此電腦上執行程式的引擎只在 Studio 中執行；在瀏覽器中則顯示為可儲存的檔案。

## 會帶過去的內容

引擎會取得一個**封裝檔**：模型為 USD 檔（若引擎要求，另含 glTF 檔），以及一個設定檔，其中包含精確的材質數值、太陽與天空、每盞已開啟燈具的功率與配光檔、相機與曝光。每個程式都以自己的方式處理光線、色調與取樣，因此畫面在相機、太陽、燈具與曝光上相似，但不會逐像素相同。

## CadCraft 絕不執行的程式

CadCraft 絕不會啟動 GNU GPL 授權下的程式，也絕不會將其列為引擎或「開啟於」的目標。Blender 即是其中之一，因此不在引擎清單中。從{{ui:算圖}}儲存的 USD 或 glTF 檔案，仍可像任何能讀取這些檔案的程式一樣，在其中開啟。

:::note
全景與立體相機，以及天空影像（改用天空的顏色）不會帶到其他程式。在其他程式中所做的任何變更，都不會傳回模型。
:::
