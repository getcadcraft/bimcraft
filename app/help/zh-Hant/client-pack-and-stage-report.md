## 作業內容

依目前的模型製作客戶成果包或階段報告，並以面積與成本並列比較已保留的量體方案。

## 步驟

1. 在左側面板中開啟 **客戶成果包與階段報告**。
2. 在 客戶成果包 或 階段報告 旁選擇 **在文件中開啟**。該文件會從模型出現在「文件」中，可在其中修改文字。
3. 在預覽中，點選某個數據即可選取其背後的元素。
4. 選擇 **建立成果包**。會儲存一個 zip 檔，內含 PDF 格式的文件、3D 檢視的圖片，以及 `figures.csv`。後者列出每個數據及其元素的 GlobalId。

## 欄位

以下欄位可用於任何文件。

| 欄位 | 列印內容 |
|---|---|
| `{{stage}}` | 圖面資訊中的專案階段。 |
| `{{options}}` | 保留的量體方案並列顯示：樓層數、高度、建築覆蓋面積、總樓地板面積、外殼與成本。 |
| `{{areas}}` | 依樓層列出的樓地板面積（取自房間）。 |
| `{{sheets}}` | 圖紙，附上各自目前的修訂版本，以及最後發行的時間。 |
| `{{issues}}` | 發行歷程與圖面變更紀錄。 |
| `{{changes}}` | 自上次發行以來的變更，逐張圖紙列出。 |

## 方案的成本計算

成本僅來自專案的單價表（Energy/Cost, 5D cost），不會替你估算任何項目。

- 單價列只有在其類別包含 `IfcBuildingElementProxy` 時，才會為方案定價。
- 樓地板面積由文字描述方案用途（例如 office）的單價列計價。若沒有，則使用含有 gross floor area 或 building mass 字樣的單價列。以 m² 計價的列會採用總樓地板面積；以 m³ 計價的列則採用體積。
- 外殼（周長乘以高度）由含有 envelope 或 facade 字樣的單價列計價。
- 沒有對應單價列的方案會顯示 **無單價**。只有在所有需要計價的部分都有單價時，才會顯示總計。

## 補充說明

- 在房間計畫的量體清單中，使用 **保留為方案** 即可保留方案。請參閱量體方案。
- PDF 無法選取元素。在 BimCraft 之外，`figures.csv` 會保留每個數據與其元素之間的連結。

## 尚未實作

- 圖紙與繪製的視圖不會放置於文件內。成果包僅包含 3D 視圖的圖片。
