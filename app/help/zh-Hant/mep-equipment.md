## 工作內容

將設備放在管線與風管的末端。每件設備都是一個通用外形，尺寸由你輸入的數值決定，其連接以**連接埠**表示：管線或風管接入的位置、所屬系統、流向與尺寸。從連接埠繪製的管線與風管會採用其尺寸與系統，並固定於該連接埠上：請參閱[將管線與風管連接到設備](topic:mep-connections)。

:::note
這是繪圖與協調的輔助工具，尺寸由工程師決定。設備不是製造商的產品：沒有容量、重量或製造商的連接尺寸。需要時，請從你的機電程式以 IFC 匯入製造商的模型。
:::

## 放置設備

1. 開啟 {{ui:繪製}}，開啟 {{ui:建置版本}}，然後選擇 {{ui:設備}}。
2. 在工具列中選擇類型並輸入尺寸。每種類型需要的內容不同：

| 類型 | 你要輸入 | 其連接埠 |
|---|---|---|
| 空調箱 | 長、寬、高；送風與回風開口；盤管管徑與系統；冷凝水管徑 | 送風風管出口、回風風管入口、盤管入口與出口、冷凝水排出口 |
| 管道風機 | 直徑、長度、系統 | 風管入口與出口 |
| 幫浦 | 管徑、系統 | 入口與出口 |
| 鍋爐 | 長、寬、高、管徑、瓦斯管徑、煙道直徑 | 供暖出水與回水入口、瓦斯入口、煙道出口 |
| 熱水器 | 直徑、高、管徑、瓦斯或電力 | 冷水入口、熱水出口（使用瓦斯時另有瓦斯入口與煙道） |
| 終端機組 | 長、寬、高、圓形入口、出口的寬與高 | 送風入口與出口 |
| 擴散器 | 面、頸部、系統 | 其頸部（送風入口） |
| 風口 | 面的寬與高、頸部的寬與高、系統 | 其頸部（送至回風或排氣風管的出風口） |
| 水箱 | 直徑、高、管徑、系統 | 頂部入口、近底部的出口 |
| 散熱器 | 長、高、深、管徑、系統 | 供水在一端頂部，回水在另一端底部 |
| 對流式／面板式暖氣 | 長、高、深、管徑、系統 | 供水在一端，回水在另一端 |
| 製造商族 | 該族（請參閱[管線規格、閥、風門與製造商族](topic:pipe-specs)） | 該族所設定的連接埠 |

3. 設定**位置**，即其底部高於標高的高度。擴散器或風口的高度指其面：請輸入天花板高度。
4. 若需要，輸入**標籤**（例如 `AHU-1`）；同類型的下一件設備會取得下一個編號。
5. 將指標移到平面上：外框與其連接埠會跟著移動。按 {{key:R}} 旋轉 90°。按一下放置的位置。

管徑為鋼管公稱尺寸（ASME B36.10M）。從幫浦繪製、採用其他材質的管線，會使用相同公稱尺寸的該材質。

## 變更或移除

在平面或 3D 檢視中選取它。屬性面板會顯示你輸入的每個尺寸、其標籤、X、Y、高度與旋轉角度，以及每個連接埠：其尺寸、系統、流向，以及是否已連接任何東西。每項變更都是 {{ui:復原}} 的一步；固定於其連接埠的管段會跟著移動。{{key:Delete}} 會移除它；固定於它的管段會保留，並由連接檢查列出。

## 在 IFC 檔案中

每種類型都會以其 IFC 類別儲存：IfcUnitaryEquipment（空調箱）、IfcFan（風機）、IfcPump（幫浦）、IfcBoiler（鍋爐；熱水器為類型為 water、物件類型為 "Water heater" 的 IfcBoiler）、IfcAirTerminalBox（終端機組）、IfcAirTerminal（擴散器、風口）與 IfcTank（水箱），同類型、同尺寸的每件設備共用一個類型。IFC2X3 檔案會使用 IfcEnergyConversionDevice、IfcFlowMovingDevice、IfcFlowController、IfcFlowTerminal 與 IfcFlowStorageDevice，並搭配相符的類型。每個連接埠都是一個 IfcDistributionPort，放在連接的位置，朝外，並帶有其流向與系統；其他程式會讀取哪一段管線連到哪個連接埠。設備會加入其每個連接埠所屬的系統，並攜帶每個已放置程式庫項目所擁有的程式庫項目集。
