## 作業內容

以 3D 查看圖形的模型空間。直線與聚合線位於其實際高度；具有厚度的物件會呈現為牆；3D 面、網格與 3D 區塊會以可環轉的曲面顯示。圖紙仍維持 2D。

## 步驟

1. 開啟 DWG 或 DXF。請參閱[檢視 DWG 或 DXF 圖形](topic:view-dwg)。除非{{ui:設定}} › {{ui:BimCraft}} › **圖形開啟方式**設為{{ui:模型（2D）}}，否則會以 3D 開啟。
2. 在 2D 狀態下，點選圖形上方列中的{{ui:3D}}，或按{{key:3}}。
3. 第一次使用時請稍候：狀態列會顯示「正在以 3D 建立圖形…」，接著顯示其呈現的線條與面數量。
4. 環轉、平移與縮放（請參閱下表）。
5. 點選第二列中的檢視：{{ui:等角}}、{{ui:上}}、{{ui:下}}、{{ui:前}}、{{ui:後}}、{{ui:左}}或{{ui:右}}。
6. 點選{{ui:透視}}可在透視與平行檢視之間切換。
7. 點選{{ui:範圍}}或按{{key:F}}，可再次檢視整個圖形。
8. 再次點選{{ui:3D}}、按{{key:3}}，或點選{{ui:模型}}或圖紙標籤，即可回到 2D。

## 應呈現的內容

- 3D 模型空間，Z 軸向上，使用圖形本身的顏色。面比其邊緣稍亮。
- 在{{ui:圖層}}中關閉的圖層，也會從 3D 檢視中消失。
- 右側顯示線條與面的數量、圖形在 X、Y、Z 方向的尺寸，以及**僅限 2D 檢視**與**尚未繪製**。

## 以剖面平面切割

點選 3D 工具列上的{{ui:剖面}}，或按{{key:X}}。其下方的工具列與 IFC 模型的用法相同（請參閱[以剖面平面切割 IFC 模型](topic:section-plane)）：可從{{ui:上}}、{{ui:前}}或{{ui:側視}}切割，拖曳或輸入偏移量（此處以圖形本身的單位計），並使用{{ui:翻轉}}保留另一側。被平面切除的部分無法點選。回到 2D 時，切割會取消。

## 查看物件特性

在 3D 檢視中點選物件。該物件會變為點選顏色，而{{ui:特性}}會顯示檔案中關於它的資訊：類型、圖層、顏色、線型與控制代碼，然後是其自身資料，例如直線的起點、終點與長度、圓的圓心與半徑、3D 面的角點，或區塊參照的區塊、插入點、比例、旋轉角度與屬性值。

- 區塊參照會整體被點選，其中巢狀的區塊也一併包含在內。
- 在直線附近幾個像素內點選，即可選取該直線。
- 按住{{key:Mod}}並點選，可加選更多物件，或取消其中一個；此時{{ui:特性}}會依類型計算數量。
- 按{{key:Esc}}或在空白處點選，即可清除選取。
- 位於已關閉圖層上的物件無法被點選。

## 移動檢視

:::mouse
| 目的 | 操作 |
|---|---|
| 環轉 | 以中鍵拖曳，或以左鍵拖曳 |
| 平移 | 以右鍵拖曳，或按住{{key:Shift}}並拖曳 |
| 縮放 | 滾動滾輪；會朝指標下方的位置縮放 |
| 檢視全部 | {{ui:範圍}}或{{key:F}} |
| 從某一側檢視 | 點選右下角檢視方塊的某一面、邊或角 |
:::

檢視方塊可在{{ui:設定}}中改為座標軸圖示，或將其隱藏。請參閱[BimCraft 設定](topic:settings)。

:::mac mouse
在觸控板上，以兩指滑動可環轉，按住{{key:Shift}}並滑動可平移，以捏合縮放。
:::

:::touch
以單指拖曳可環轉。以雙指捏合可縮放，雙指同時移動可平移。
:::

## 3D 中繪製的內容

| 圖形中的內容 | 3D 中的呈現 |
|---|---|
| 直線、3D 聚合線 | 位於其實際高度 |
| 聚合線、圓、圓弧、橢圓 | 位於其自身平面與標高，若圖形傾斜則隨之傾斜 |
| 直線、聚合線、圓與圓弧的厚度 | 該高度的牆；圓的頂部與底部皆封閉 |
| 3D 面、多面網格、多邊形網格 | 帶有可見邊緣的著色曲面 |
| 區塊 | 在 3D 中放置、旋轉並縮放，巢狀區塊亦然 |
| 填滿 | 其輪廓 |
| 純 2D 線條 | 平面呈現，位於繪製的位置 |

## 僅限 2D 檢視

文字、多行文字與區塊中可見的屬性會以其自身平面與高度在 3D 中繪製，並可被點選。寬聚合線會以平面色帶顯示其寬度。多重引線、圖片與填滿圖案會計入**僅限 2D 檢視**：請在{{ui:模型}}標籤或圖紙上查看。

## 尚未繪製

以 ACIS 實體儲存的實體與曲面（3D 實體、本體、區域與曲面），以及細分網格，會列在**尚未繪製**下方並顯示數量。它們會被略過，不會推測其形狀。

## 常見錯誤

- **一切看起來都是平面的。** 圖形為 2D，其線條沒有高度。點選{{ui:前}}進行確認；若為平面圖形，則會顯示為一條線。
- **實體模型不顯示任何內容。** 以實體建模器製作的實體為 ACIS 本體，會列在**尚未繪製**下方。請從製作該模型的軟體匯出為 IFC 或 3D 面。
- **圖形在中間成為一小團。** 模型空間中遠處的內容（例如舊平面圖的副本）會使範圍變大。請以滾輪放大到要查看的位置。
