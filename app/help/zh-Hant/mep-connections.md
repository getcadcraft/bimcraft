## 工作內容

將管段連接到設備，使模型成為一個相連的系統：幫浦的出口接到由它送出的管線，擴散器的頸部接到其分支風管。然後讓 BimCraft 列出尚未相連的部分。

## 從連接埠繪製

1. 選擇 {{ui:管線}} 或 {{ui:風管}}。
2. 將指標移到設備的連接埠上（小圓圈；開放的連接埠以警告色繪製）。指標會貼齊該連接埠並顯示**位於連接埠上**。
3. 按一下：管段會從連接埠的高度開始，並**採用其尺寸與系統**（管線也會採用該系統常用的材質）。狀態列會說明採用了什麼。
4. 照常繪製。管段在另一個連接埠上結束時，也會固定該端。

管段位於連接埠上的一端會**固定**於該連接埠：移動或旋轉設備（在屬性面板中）時，管段的該端會一起移動；編輯管段時，該端仍保留在連接埠上。管段的其他轉角維持原位，因此大幅移動後，第一段可能會以斜角脫離連接埠：請一併移動下一個轉角。

## 檢查連接

開啟 {{ui:建置版本}} 並按一下 {{ui:檢查連接}}。列表會顯示在工具列下方：

| 列 | 意義 |
|---|---|
| 有連接埠未連接 | 某個設備有一個連接，但沒有任何東西連到它 |
| 端點沒有接上 | 管段的一端懸空 |
| 相連的連接埠尺寸不同 | 某一尺寸的管段接到另一尺寸的連接埠或管段，中間沒有縮徑接頭（管線的公稱尺寸、風管的形狀與邊長） |
| 相連的連接埠系統不同 | 例如回風管接到送風擴散器 |
| 管線接到風管 | 兩種不同類型的連接相接 |
| 其網路中沒有設備供應它 | 管段所連接的所有東西，不論相隔多遠，都沒有出口。排水、雨水與通氣不做此檢查：其水源來自衛生器具 |
| 固定於已不在模型中的設備連接埠 | 該設備已被刪除；請重新繪製該端或刪除管段 |

錯誤會排在最前面。按一下某一列即可選取它指出的物件。{{ui:關閉}} 會隱藏列表。檢查只依據已繪製的模型，檢查連接與尺寸，從不檢查流量、壓力或平衡。
