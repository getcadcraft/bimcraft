## 作業內容

修正 IFC 模型中的資料：重新命名元素、修正其標籤、變更特性值。然後儲存含有變更的新 IFC 檔案。已開啟的原始檔案絕不會被更動。

## 可變更的內容

| 欄位 | 可編輯 |
|---|---|
| 名稱、物件類型、標籤、說明 | 是 |
| 單一特性值（文字、數字、是／否） | 是 |
| 類型特性（標示為「(類型)」的屬性集） | 是，且變更會套用至該類型的每個元素 |
| 類型、GlobalId、行號 | 否 |
| 數量（長度、面積、體積、計數） | 否 |
| 清單、列舉與其他多部分值 | 否 |
| 幾何、位置、新增或刪除元素 | 否 |

## 步驟

1. 開啟 IFC 模型，並點選要變更的元素。
2. 在{{ui:特性}}面板中，點選要變更的值。它會變成文字方塊。空值會顯示為*空白*。
3. 輸入新值。
4. 按{{key:Enter}}或點選其他地方以保留變更。按{{key:Esc}}可取消。
5. 查看該值：它會以粗體顯示，且旁邊有藍色條，標示為已編輯的值。
6. 查看左側的{{ui:變更}}區段：變更會以*元素*：*欄位*，舊值改為新值的形式列出。
7. 針對其他值或其他元素重複操作。
8. 點選{{ui:另存為 IFC}}（會顯示等待中的變更數量，例如「Save as IFC (3)」），或按{{key:Mod+S}}。
9. 在下載資料夾中找到「*原始名稱* (edited).ifc」。

## 應呈現的內容

狀態列會顯示「已儲存 *name* (edited).ifc，共 *n* 項變更（… bytes）。原始檔案未變更。」{{ui:變更}}清單會清空，準備下一輪。

## 值的種類

- **文字：**輸入的任何內容都會原樣保留。清除名稱、物件類型、標籤或說明即會移除該值。
- **數字：**以檔案本身的單位輸入單純的數字，例如 `2.4` 或 `1200`。不要輸入單位符號。其他輸入會顯示「須為數字。」
- **整數（數量、整數）：**若輸入小數，會顯示「須為整數。」
- **是／否：**該值會變為含有「是」與「否」的選單。

每個值都保留其 IFC 類型，因此數字仍為數字，其他軟體也能正確讀取。

## 復原

1. 點選{{ui:變更}}區段中的{{ui:復原}}，或在未於欄位中輸入時按{{key:Mod+Z}}。
2. 可重複操作以復原更多。每次復原會移除最新的變更。

儲存後無法復原：儲存後，清單會重新開始。已儲存的檔案會保留所有內容。

## 為何變更只影響一個元素

匯出程式會共用資料以節省空間。一個屬性集可能被二十扇門共用，而一個值（「防火等級：60 分鐘」）可能出現在九十個屬性集中。若 BimCraft 直接變更共用的值，所有共用它的元素都會一併變更。

因此 BimCraft 會在寫入前先複製：

- 若所編輯的屬性集與其他元素共用，該元素會取得屬性集的專屬副本，只有該副本會變更。
- 若該值與其他屬性集共用，該屬性集會取得值的專屬副本。

其他元素保留其原有資料。此做法稱為*寫入時複製（copy-on-write）*。它會在檔案中增加少量項目，所有 IFC 軟體皆可正常讀取。

**類型特性是刻意的例外。** 標示為「(類型)」的屬性集屬於元素的類型，在 IFC 中，該類型的每個元素都從類型讀取它。變更它會變更類型，因此該類型的每個元素都會顯示新值。{{ui:變更}}清單會以「(類型)」標示此類編輯。請參閱[變更某類型所有元素的類型特性](topic:type-vs-instance)。

## 儲存前的警告

- 在有未儲存的變更時開啟其他檔案，會詢問「*file* 尚有 *n* 項未儲存的變更，是否捨棄？」點選{{ui:取消}}可繼續作業，然後儲存。
- 在有未儲存的變更時關閉或重新載入索引標籤，瀏覽器會詢問是否離開。

## 常見錯誤

- **輸入單位。** `2400 mm` 會被拒絕。請輸入 `2400`。
- **想變更單一元素時卻變更了類型特性。** 輸入前請查看「(類型)」註記。若要讓某個元素與眾不同，請改為變更該元素的實例特性，或其標籤或名稱。
- **預期原始檔案會被變更。** 儲存時一律會下載新檔案。若要取代原始檔案，請自行取代，並保留一份副本。
- **在沒有變更時按{{key:Mod+S}}。** BimCraft 只在有內容可儲存時才會儲存；否則可能會開啟瀏覽器的「儲存網頁」。請將其關閉。
- **儲存兩次並預期得到兩個小檔案。** 每次儲存都包含自開啟模型以來的所有編輯。
- **預期編輯會寫回專案檔案。** BimCraft 只寫入 IFC。請像匯入任何 IFC 一樣，將編輯後的 IFC 匯入製作軟體。
