{{ui:算圖}}在{{ui:振態}}上方有一個**引擎**選項。我們自有的兩種引擎一律可用，且在各處都能運作；外掛可以新增更多引擎，而在 CadCraft Studio 中，清單也包含會接管場景的程式。

| 引擎 | 功能 | 可用位置 |
|---|---|---|
| 內建：快速 | 快速的靜態畫面：日光、柔和陰影、玻璃與金屬外觀，數秒即可完成 | 瀏覽器與 Studio |
| 內建：路徑追蹤 | 光線在表面之間反彈，由你的顯示卡或處理器計算，包含算圖佇列及網路上的其他電腦 | 瀏覽器與 Studio |
| 外掛的引擎 | 繪製畫面並將其傳回：請見[用其他程式繪製畫面](topic:render-other-program) | 瀏覽器（以 JavaScript 撰寫的引擎）或 Studio（執行程式的引擎） |
| 會接管場景的程式 | Studio 會將場景放入其資料夾並保持同步 | Studio |
| 開啟於… | 儲存場景並在程式中開啟；不會傳回任何內容：請見[在其他程式中開啟場景](topic:render-open-in) | 網頁版會儲存檔案 |

## 選擇的行為

- 選取快速或路徑追蹤時，{{ui:振態}}會跟著改變，反之亦然。對於從未使用其他引擎的人，對話方塊的其他部分都不會改變。
- 無法使用的引擎會保留在清單中，並附上原因（「找不到」、「需要較新版本」）；你無法選取它。在瀏覽器中，只能在 Studio 執行的引擎會顯示「會儲存檔案」：{{ui:算圖}}接著會將場景及其設定儲存為檔案，供你帶到該程式中。
- 所選的引擎會與檔案的算圖設定一起儲存；對於沒有自身選擇的檔案，最後選用的引擎就是起始引擎。
- 來自其他程式的畫面，會在對話方塊與算圖佇列中標示是哪個程式（及其版本）繪製的。[算圖](topic:render)頁面的說明只涵蓋**我們自有的**引擎：其他程式會以自己的方式處理光線、色調與取樣，因此同一場景的兩張畫面，在相機、太陽、燈具與曝光上相似，但不會逐像素相同。

## 每個引擎都會取得的內容

場景會以**封裝檔**的形式交給其他程式：模型為 USD 檔（與[另存新檔為 USD](topic:usd)寫出的檔案相同），另有一個設定檔，其中包含 USD 匯入器無法可靠處理的內容：精確的材質數值、已開啟燈具的功率與配光檔、太陽、天空、曝光，以及對話方塊中所呈現的相機。不會上傳到任何地方。

## 算圖佇列

其他程式的畫面可以像我們自有的畫面一樣，在[算圖佇列](topic:render#the-render-queue)中等候；其工作會記住它是為哪個引擎準備的。
