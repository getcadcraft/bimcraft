BimCraft 是 CadCraft 系列中的建築模型應用程式。在這個版本中，它能**開啟、讀取並檢查**建築檔案，也能**編輯 IFC 模型中的資料**，但尚不能繪製或建立新元素。可以把它想成模型檢視器兼檢查工具，同時也能修正 IFC 檔案中的名稱、標籤與屬性值。

可開啟的檔案：

| 檔案 | 得到的內容 |
|---|---|
| IFC（`.ifc`） | 完整的 3D 模型：環繞檢視、樓層、元素屬性，以及名稱與屬性值的編輯 |
| 專案與族檔案（`.rvt`、`.rfa`、`.rte`、`.rft`） | 一張檔案卡：儲存時的版本、專案資訊、預覽圖與連結的檔案。沒有 3D。 |
| DWG 與 DXF | 2D 圖形：模型空間與每一張圖紙、圖層、連結的圖形、列印視圖，以及帶標籤的餐飲設備圖形所用的設備明細表 |
| 專案資料夾 | 資料夾中每個模型的報告：備份、連結、損毀的副本，以及建議從哪個檔案開始 |

一切都在瀏覽器中、在自己的電腦上進行。**不會上傳任何內容。** 詳情參閱 [BimCraft 開啟與儲存的檔案](topic:files)。

## 開啟 BimCraft

1. 以最新的瀏覽器開啟 BimCraft。Chrome、Edge、Firefox 與 Safari 都能使用；差異請參閱[瀏覽器、裝置與記憶體](topic:platforms)。
2. 等待出現寫著「開啟建築模型。」的空白畫面。

:::note
BimCraft 在瀏覽器中執行；在桌面上則與其他應用程式一起在 CadCraft Studio 內執行。雲端儲存尚未提供：檔案從電腦開啟，副本也儲存回電腦。
:::

## 開啟第一個模型

想知道 BimCraft 能做什麼，最快的方式是使用 IFC 檔案。

1. 按一下畫面中央的 {{ui:選擇檔案}}。
2. 在{{pick:mac=Finder|windows=檔案總管|linux=檔案管理員}}中選取一個 `.ifc` 檔案並確認。
3. 等待畫面底部的狀態列顯示「正在啟動 IFC 引擎……」，接著顯示「正在建立幾何」。

中間應該會出現 3D 模型，左側有 {{ui:檔案}} 面板與 {{ui:樓層}} 清單，右側則是空白的 {{ui:特性}} 面板。狀態列最後顯示「已開啟」與元素數量。

:::tip
也可以直接從{{pick:mac=Finder|windows=檔案總管|linux=檔案管理員}}將檔案拖曳到頁面上。拖曳時畫面會顯示「放開以開啟」。
:::

:::offline
第一次開啟 IFC 模型時，IFC 引擎會從網站載入，除非 BimCraft 已儲存供離線使用。DWG 與 DXF 圖形、專案檔案與資料夾不需要額外內容：其讀取器已內建於應用程式。應用程式列的按鈕顯示 {{ui:可離線使用}} 時，所有檔案都能離線開啟；否則，除非此分頁中已開啟過一個，否則在重新連線之前無法開啟 IFC 模型。參閱[線上與離線](topic:online-offline)。
:::

:::online
要去沒有網路連線的地方？按一下應用程式列中的 {{ui:儲存供離線使用}}，等到出現 {{ui:可離線使用}}。儲存的副本（約 11 MB）包含 IFC 引擎。參閱[離線工作](common:offline)。
:::

## 四處看看

:::mouse
1. 按住滑鼠左鍵拖曳，環繞模型旋轉。
2. 捲動滾輪縮放。
3. 按住滑鼠右鍵拖曳平移。在 Mac 觸控板上，改為按住 {{key:Shift}} 並拖曳。
4. 按 {{key:F}} 或按一下 {{ui:符合視窗}}，重新看到整個模型。
:::

:::touch
1. 單指拖曳可環繞旋轉。
2. 雙指捏合可縮放，兩指一起移動可平移。
3. 點一下 {{ui:符合視窗}}，重新看到整個模型。
:::

## 做一件實際的事：修正標籤

1. 按一下模型中的牆、門或任何元素。它會變成藍色，其屬性會顯示在右側。
2. 在 {{ui:特性}} 面板中，按一下 **Tag** 旁的值。
3. 輸入新標籤並按 {{key:Enter}}。
4. 看看左側展開的 {{ui:變更}} 區段：變更內容會與舊值、新值一起列出。

## 儲存副本

1. 按一下 {{ui:變更}} 區段中的 {{ui:另存為 IFC}}，或按 {{key:Mod+S}}。
2. 在下載資料夾中找到新檔案。檔名為原檔名加上「 (edited)」，例如 `Clinic (edited).ifc`。

原始檔案絕不會被變更。完整的編輯說明參閱[變更 IFC 屬性並儲存編輯後的副本](topic:edit-ifc-properties)。
