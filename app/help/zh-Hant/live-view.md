即時檢視以即時外觀顯示模型：依基地位置與日期顯示天空與太陽、太陽陰影、為元素指定的油漆與材質、燈具，以及從牆面與地板反射的光線。它會隨操作即時更新：轉動3D檢視時它也跟著轉動，變更模型後稍後即會顯示變更。不會上傳任何內容。

它繪製的場景、油漆、燈具與太陽，與[算圖圖片](topic:render)相同；若需要成品圖片，改用該功能。

## 開啟方式

1. 開啟模型，並在工具列中選擇{{ui:即時檢視}}。面板會開啟於應用程式上方的右下角。
2. 拖曳其標題列即可移動，拖曳其角落即可放大。
3. {{ui:在新視窗中即時檢視}}（旁邊的按鈕）或面板中的{{ui:新視窗}}，會將其移至獨立視窗，供第二螢幕使用。若瀏覽器封鎖彈出視窗，則會以面板方式開啟。
4. 按{{ui:關閉}}即可關閉。

## 控制項

| 控制項 | 功能 |
|---|---|
| {{ui:跟隨視圖}} | 開啟時，即時檢視會朝向3D檢視的方向。漫遊時會將其關閉 |
| {{ui:漫遊}} | 在模型中漫遊（見下文） |
| {{ui:重力}} | 漫遊時：站在樓板上並爬樓梯。關閉時：飛行 |
| {{ui:時間}} | 一天中的時刻。拖曳時太陽隨之移動 |
| {{ui:月份}} | 月份，可查看冬季與夏季的太陽位置 |
| {{ui:品質}} | {{ui:依此電腦}}，或{{ui:低}}、{{ui:中等}}或{{ui:高}} |

底部的一行會顯示繪製檢視所用的技術（WebGPU 或 WebGL 2）、品質與反射光。

## 在模型中漫遊

1. 將3D檢視轉至想站立的方向，然後選擇{{ui:漫遊}}。人物會站在檢視視點下方的地板上，身高1.6 m。
2. 在即時檢視中按一下，然後使用{{key:W}} {{key:A}} {{key:S}} {{key:D}}或方向鍵。按住{{key:Shift}}可奔跑。拖曳即可環視。
3. 高度最多40 cm的台階可攀爬（樓梯）；更高的皆視為牆。牆會阻擋移動，並沿牆滑行。
4. 關閉{{ui:重力}}時即可飛行：{{key:E}}向上，{{key:Q}}向下。
5. 按{{key:Esc}}停止漫遊。

## 反射光

從受陽光照射的牆面反射到地板上的光，以及房間較暗的內部，會在背景中利用每個處理器核心計算。計算期間底部一行顯示{{ui:反射光：40 %}}；計算完成後，檢視即會納入。變更後會重新開始計算。

:::note
這是即時檢視的近似結果，而非算圖圖片：點與點之間的細節會取其附近各點的反射光。
:::

:::note
各瀏覽器有所不同。瀏覽器支援WebGPU時，即時檢視即使用它；否則使用WebGL 2，外觀相同。若兩者皆不支援，面板會提示。
:::
