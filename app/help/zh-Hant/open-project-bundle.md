## 操作內容

開啟一個**專案包**（`.ccbundle.zip`），並依專案原本的組織方式使用它：其視圖、其配置與其特性群組，疊加在模型之上。

專案包包含：

- 以 IFC 格式儲存的模型，
- 以 PDF 與 DWG 格式儲存的配置，
- 一份 IFC 無法保留的清單：視圖（各含其樓層、圖層組合與比例）、配置及放置於其上的圖面、群組中的特性定義、分類，以及圖層、筆型組、線型、填滿、曲面與複合材料等標準。

專案包由一個開源指令稿寫成，該指令稿在 Archicad 內執行，並直接向 Archicad 索取這些清單。BimCraft 從不直接讀取 `.pln` 或 `.tpl` 檔案；請參閱[開啟 .pln 與 .pla 專案檔](topic:pln-project-files)。

## 製作專案包

此指令稿為預覽版：尚未在每個 Archicad 版本上測試過。請從 [github.com/getcadcraft/bim-project-bundle](https://github.com/getcadcraft/bim-project-bundle) 取得。需要 Archicad 24 或更新版本，以及 Python 3.8 或更新版本；不需要安裝其他東西。

1. 將 `archicad_bundle.py` 儲存到一個資料夾，例如 `C:\cc-bundle`。
2. 在 Archicad 中開啟專案，建立一個名稱完全為**CadCraft bundle**的發佈集：3D 視圖以 IFC 發佈，每個配置以 PDF 發佈，每個配置再以 DWG 發佈，全部發佈到磁碟上同一個扁平資料夾中。
3. 開啟專案後，執行一次 `python archicad_bundle.py --probe --out .`。它只會讀取，並寫入 `probe.json`。
4. 執行 `python archicad_bundle.py --out . --translator "IFC4 Reference View"`（請改用所選的 IFC 轉換器）。Archicad 會發佈該發佈集，指令稿隨後寫出 `<project>.ccbundle.zip`。

若透過指令稿發佈失敗，請手動發佈該發佈集，然後執行 `python archicad_bundle.py --out . --no-publish --files <folder>\*.ifc <folder>\*.pdf <folder>\*.dwg`。儲存庫的 README 列有所有選項。若仍有內容未能取得，請在該儲存庫開啟議題，並附上 `probe.json`。

## 開啟專案包

1. 按一下{{ui:選擇檔案}}，或將 `.ccbundle.zip` 拖曳到 BimCraft 上。在使用{{ui:開啟資料夾}}開啟的資料夾中，專案包會列在**專案包**之下；按一下名稱即可開啟。
2. 模型會像任何 IFC 一樣開啟，且左側檔案資訊下方會出現**專案包**區段。

不會上傳任何內容：專案包會在你的電腦上逐一讀取檔案，因此大型模型不會被複製兩次。

## 顯示視圖

在**視圖**下，視圖會依其在專案中所屬的資料夾分組。按一下視圖名稱：

- **平面圖**只顯示其樓層，從上方檢視。
- **其圖層組合**會隱藏該組合所隱藏圖層上的元素。狀態列會顯示因此隱藏了多少個元素。
- **其比例**會顯示在名稱旁及狀態列中。
- **3D 視圖**會顯示所有樓層。

要再次顯示全部內容，請在{{ui:顯示}}中使用{{ui:全部顯示}}，並勾選每個樓層。

:::note
BimCraft 會透過 IFC 檔案的圖層指派找到圖層。若 IFC 匯出時未包含這些指派，圖層組合便不會隱藏任何內容，且狀態列會顯示隱藏 0 個元素。
:::

## 開啟配置

在**配置**下，每個配置會顯示其編號、名稱、紙張大小，以及放置於其上的視圖。

- **PDF** 會從專案包中將該配置的 PDF 儲存出來。
- **DWG** 會在 2D 檢視中開啟該配置的圖形。按一下任一視圖即可回到模型。
- **在…中開啟**會在新索引標籤中，將配置檔案傳送給負責處理它的應用程式：PDF 傳送到 MarkupCraft，DWG 傳送到 CadCraft。只有在該應用程式與 BimCraft 同時開啟時才會顯示。索引標籤載入時會從專案包讀取檔案，且不會上傳任何內容。

沒有任何檔案的配置會顯示**專案包中沒有檔案**。

## 在專案群組中檢視特性

選取一個元素。**特性群組**會在專案所定義的群組下顯示其特性，比對方式為 IFC 定義所給的特性集與名稱，否則依名稱比對。其餘特性仍會照常顯示在{{ui:特性}}中。**特性定義**會列出每個定義，以及其群組、類型與 IFC 名稱。

## 標準與附註

- **標準**會統計專案包中的圖層、圖層組合、筆型組、線型、填滿、曲面、複合材料與材料的數量。
- **附註**會列出指令稿無法從該版本 Archicad 取得的內容、BimCraft 無法讀取的任何欄位，以及專案包列出但未包含的檔案。

## 疑難排解

- **「…是 zip 檔，但不是專案包。」**此 zip 中沒有 `manifest.json`。請將其解壓縮，並開啟其中的 `.ifc` 檔。
- **「…是比此 BimCraft 所能讀取更新的專案包。」**請更新 BimCraft。
- **「…未包含其清單所指名的模型。」**此 zip 被截斷或遭到編輯。請重新製作專案包。
- **某個視圖顯示所有樓層。**其樓層不在模型的 IFC 中（狀態列會說明）。請確認 IFC 匯出時包含該樓層。
