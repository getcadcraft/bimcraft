IFC5 alpha（檔案副檔名為{{ui:.ifcx}}）是 buildingSMART 仍在設計中的檔案格式。它並非最終版本：檔案以及我們對其的解讀都可能變動。因此這是實驗性選項，且須先閱讀。

## 啟用

1. 選擇{{ui:設定}}，然後選擇 BimCraft 索引標籤中的{{ui:IFC5 alpha (IFCX)}}區段。
2. 勾選{{ui:IFC5 alpha (IFCX)：格式仍在變動，建議先閱讀}}。

預設為關閉。在關閉狀態下，開啟 .ifcx 檔案會被拒絕，並顯示指向本頁的說明。啟用後會出現{{ui:開啟 IFC5 alpha (.ifcx)…}}以及{{ui:IFC5 alpha}}匯出按鈕。

## 開啟

- 以{{ui:開啟檔案或資料夾}}選擇 .ifcx 檔案（會取代目前開啟的模型，並依一般流程詢問是否要儲存編輯內容），或
- 選擇{{ui:開啟 IFC5 alpha (.ifcx)…}}並一次選取多個檔案：檔案本身、其圖層，以及它所匯入的結構描述檔案。若已開啟模型，檔案會**加入其旁**；模型清單中的 x 可將其移除，這即是復原操作。

IFCX 檔案會列出節點（路徑、其子項、所繼承的內容，以及其屬性）。多個檔案可描述同一節點：較後的檔案（圖層）會覆寫較早檔案的屬性，而 null 子項會移除子項。BimCraft 會組合這些檔案，然後將結果繪製為一個簡化的 IFC4 模型：專案、場地、建築、樓層與元件，並包含名稱、類別、屬性、數量、顏色與網格。

不會從網路擷取任何內容。檔案所匯入的結構描述檔案（例如 `ifc@v5a.ifcx`）僅在你與該檔案一併選取時才會使用；否則報告會明確說明，並在不進行型別檢查的情況下讀取屬性。

### 報告

開啟後，報告會列出讀取時發現的內容：與其結構描述不符的資料、未提供的結構描述檔案，以及在此無 IFC 對應意義的屬性。沒有對應的屬性會被**保留**於模型中，不會捨棄，並會在匯出時寫回。

## 對應關係

| 在 IFCX 檔案中 | 在 BimCraft 中 |
|---|---|
| 具有 IFC 類別的節點（專案、場地、建築、樓層、牆等） | 對應的 IFC4 元素；此讀取程式未知的類別會成為 building element proxy |
| 節點在其上層下的名稱 | 元素名稱 |
| 具有數量類型的屬性（Length、Area、Volume、Mass 等） | 名為 `Qto_IFCX` 的 IFC4 數量集（IFC4 數量仍保留為 IFC4 `Qto_*` 集） |
| 其他屬性 | 名為 `Pset_IFCX` 的屬性集 |
| 網格與變換屬性 | 元素的三角形與放置位置；不可見的網格不會被繪製 |
| 顏色、不透明度、材料、分類 | 元素的表面樣式、材料與分類 |

單位以公尺計，Z 軸向上：alpha 版規格表示，單位將於日後另行說明。

## 匯出

在工具列中選擇{{ui:IFC5 alpha}}，閱讀說明後，按一下{{ui:匯出 .ifcx}}。檔案會包含我們自己的標頭（作者 CadCraft，版本 ifcx_alpha），並在檔案中標明其為 alpha 格式。每個模型都會以其自身的檔案座標寫入，單位為公尺，並包含名稱、類別、屬性集、數量（以屬性形式附帶其類型）、顏色與三角形。圖層與繼承會以攤平方式寫入。請在接收該檔案的程式中檢查檔案。

## 限制

- 曲線幾何（曲線、曲面）無法讀取：僅支援三角網格。
- 嵌入牆中的門與窗會放置於樓層上；其原來所屬的牆不會建立連結。
- IFC4 `Qto_*` 集合名稱會保留為我們自己的屬性群組（`cadcraft::qto::…`）；標準 alpha 結構描述只包含少數數量名稱。
- 此格式可能會變動；今天製作的檔案明天可能無法讀取。
