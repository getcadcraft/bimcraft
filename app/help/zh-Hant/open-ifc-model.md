## 工作內容

開啟 IFC 模型，在 3D 中移動，並切換至標準檢視。約需五分鐘。

需要一個 `.ifc` 檔案。多數 BIM 程式都能匯出；在 Revit 中為**檔案 > 匯出 > IFC**。請參閱[透過 IFC 將專案檔載入 3D](topic:rvt-to-ifc)。

## 步驟

1. 按一下{{ui:選擇檔案}}（或左上角的拖放區）。
2. 選擇 `.ifc` 檔案並確認。
3. 等待狀態列完成。首次會顯示「正在啟動 IFC 引擎…」，接著為「正在讀取模型…」與「正在建立幾何：… ／ … 個元件」。
4. 查看模型：它會以四分之三視角開啟，並配合螢幕縮放。
5. 按一下模型上方工具列中的{{ui:上}}，即可從正上方俯視。
6. 按一下{{ui:前}}查看正面，再按{{ui:側視}}從側面查看。
7. 按一下{{ui:符合視窗}}，或按 {{key:F}}，即可回到整個模型的四分之三視角。

## 應呈現的畫面

- 模型位於中央，並以細的深色邊線呈現製圖般的外觀。
- 左側的{{ui:檔案}}面板：檔案名稱、大小、IFC 結構描述（例如 IFC2X3 或 IFC4）、專案名稱、階段、匯出所用的程式、作者、匯出日期，以及元件與三角形的數量。
- 其下方為{{ui:樓層}}與{{ui:元件}}清單。
- 狀態列：「已開啟*檔案名稱*：*n* 個元件，耗時 *s* 秒」。

## 移動方式

:::mouse
| 目的 | 操作 |
|---|---|
| 環繞 | 按住左鍵拖曳 |
| 平移 | 按住右鍵拖曳，或按住 {{key:Shift}}（或 {{key:Mod}}）並以左鍵拖曳 |
| 縮放 | 滾動滾輪，或以中鍵拖曳 |
| 檢視全部 | 按 {{key:F}} 或按一下{{ui:符合視窗}} |
:::

:::mac mouse
在觸控板上：單指按住拖曳即可環繞；按住 {{key:Shift}} 或 {{key:Mod}} 並拖曳即可平移；以雙指滾動或捏合即可縮放。雙指點按為右鍵，可用其拖曳來平移，但按住 {{key:Shift}} 再拖曳較為容易。
:::

:::touch
| 目的 | 操作 |
|---|---|
| 環繞 | 以單指拖曳 |
| 縮放 | 以雙指捏合 |
| 平移 | 將雙指一起移動 |
| 檢視全部 | 點按{{ui:符合視窗}} |
:::

環繞總是繞著模型中心的一點旋轉。平移會移動該點，因此長距離平移後，環繞可能會感覺偏離中心：按一下{{ui:符合視窗}}即可重設。

## 陰影、邊線或線框

模型上方的三個小按鈕可選擇模型的繪製方式：{{ui:著色}}、{{ui:著色含邊線}}（預設）與{{ui:線框}}。它們同時也是指令（功能表與「自訂」清單中的{{ui:檢視}}），因此可以指定自己的按鍵。{{ui:平面}}、{{ui:分割}}與{{ui:3D}}位於工具列的{{ui:檢視}}列中。

## 常見錯誤

- **預期有具名檢視。** BimCraft 提供四個固定檢視（{{ui:符合視窗}}、{{ui:上}}、{{ui:前}}、{{ui:側視}}）、右下角的視圖方塊與自由環繞。它不會儲存檢視。
- **尋找平面圖與剖面。** 此版本沒有 2D 平面圖或剖面盒。請以一個{{ui:剖面}}平面切開模型（[以剖面平面切開 IFC 模型](topic:section-plane)），或關閉樓層：[顯示與隱藏樓層、空間與邊線](topic:storeys-and-spaces)。
- **開啟專案檔並預期看到 3D。** 專案檔會以檔案卡開啟。請先匯出 IFC。
- **開啟 `.ifczip`。** 請解壓縮，或匯出一般的 `.ifc`。
- **非常大的模型會使分頁變慢或當機。** 請參閱[瀏覽器、裝置與記憶體](topic:platforms)。
