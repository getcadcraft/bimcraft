BimCraft 的快速鍵很少。大部分工作以滑鼠與面板完成。以{{key:Mod}}標示的快速鍵，在 Mac 上使用 Command，其他系統使用 Ctrl。請參閱[按鍵、滑鼠與觸控板](common:keys)，了解本說明中按鍵的寫法。

## 全域

| 按鍵 | 功能 |
|---|---|
| {{key:Ctrl+Shift+F}} | 切換螢幕模式：一般、全螢幕、隱藏工具列的全螢幕。在所有平台（包括 Mac）皆使用 Ctrl |
| {{key:Esc}} | 離開全螢幕 |
| {{key:Mod+,}} | 開啟{{ui:Settings}}。請參閱[BimCraft 設定](topic:settings) |
| {{key:Tab}} | 在按鈕、核取方塊與值之間移動。所有控制項都可用鍵盤操作 |

## 3D 視圖（IFC 模型）

| 按鍵或操作 | 功能 |
|---|---|
| {{key:F}} | 符合整個模型，四分之三視角（與{{ui:Fit}}相同） |
| {{key:Esc}} | 清除選取，或停止放置或貼上 |
| 點按 | 選取指標下的元素；點按空白背景即清除 |
| 按住{{key:Mod}}或{{key:Shift}}並點按 | 將元素加入選取，或從選取中移除 |
| {{key:H}} | 隱藏選取的元素。請參閱[隱藏、隔離與透視元素](topic:hide-and-isolate) |
| {{key:I}} | 只顯示選取的元素（隔離） |
| {{key:T}} | 顯示選取的元素，其他元素透視 |
| {{key:Shift+H}} | 再次顯示所有元素 |
| {{ui:Walk}} | 然後使用 {{key:W}} {{key:A}} {{key:S}} {{key:D}} 或方向鍵漫遊，{{key:Shift}} 加速，拖曳可環視，{{key:Esc}} 停止。請參閱[在模型中漫遊](topic:walk) |
| {{key:M}} | 量測距離與面積。請參閱[在 3D 中量測距離、面積與位置](topic:measure) |
| 以左鍵拖曳 | 環繞 |
| 以右鍵拖曳 | 平移 |
| 按住{{key:Shift}}或{{key:Mod}}並以左鍵拖曳 | 平移（在觸控板上很方便） |
| 滾動滾輪，或以中鍵拖曳 | 縮放 |
| 觸控板上以兩指捲動或捏合 | 縮放 |
| 單指（觸控） | 環繞；輕點即選取 |
| 雙指（觸控） | 捏合縮放，一起移動則平移 |

| {{key:X}} | 開啟或關閉剖面平面。請參閱[以剖面平面切開 IFC 模型](topic:section-plane) |
| {{key:Shift+X}} | 以選取的元素為中心的剖面框，並使用設定中的房間範圍 |

沒有{{ui:Top}}、{{ui:Front}}與{{ui:Side}}的快速鍵；請使用按鈕。

## 編輯

同樣的指令位於工具列中：{{ui:Undo}}、{{ui:Redo}}、{{ui:Copy}}、{{ui:Paste}}，以及{{ui:More}}功能表，其中會顯示各快速鍵。這些指令適用於 IFC 模型的 3D 視圖，但在欄位中輸入文字時無效。請參閱[複製、貼上與建立程式庫項目副本](topic:copy-paste)。

| 按鍵 | 功能 |
|---|---|
| {{key:Mod+Z}} | 復原上一個變更 |
| {{key:Mod+Y}} 或 {{key:Mod+Shift+Z}} | 取消復原剛才被復原的內容 |
| {{key:Mod+C}} | 複製選取的元素（其名稱與特性也會以文字放入剪貼簿） |
| {{key:Mod+X}} | 剪下選取的元素：先複製，再刪除 |
| {{key:Mod+V}} | 貼上已複製的內容：跟隨指標移動，點按即放置 |
| {{key:Mod+Shift+V}} | 原位貼上：剪下的來源位置，或複製後貼在原件旁 |
| {{key:Mod+D}} | 建立副本：複製選取的元素並開始貼上 |
| {{key:Delete}} | 刪除選取的元素，包括其組件與開口。請參閱[刪除、剪下、複製與貼上建築元素](topic:edit-elements) |
| {{key:Mod+A}} | 選取目前顯示的所有元素 |
| {{key:Esc}} | 取消所有選取 |

頁面上選取文字時，{{key:Mod+C}}會照常複製該文字。

## 平面視圖（繪製）

這些操作在{{ui:Draw}}開啟且未在欄位中輸入時有效。請參閱[繪製牆](topic:draw-walls)與[門和窗](topic:doors-and-windows)。

| 按鍵或操作 | 功能 |
|---|---|
| {{key:V}} | 切換至{{ui:Select}} |
| {{key:W}} | 切換至{{ui:Wall}} |
| {{key:D}} | 切換至{{ui:Door}} |
| {{key:N}} | 切換至{{ui:Window}} |
| {{key:H}} | 使用{{ui:Door}}或{{ui:Window}}時：鉸鏈位於另一端 |
| 繪製牆時按住{{key:Shift}} | 保持在 0°、90°、180° 或 270° |
| 數字與英尺、英吋符號（`'` 與 `"`） | 開始輸入長度至{{ui:Length}}欄位；按{{key:Enter}}即套用 |
| {{key:Enter}}、{{key:Esc}}、右鍵或連按兩下 | 結束正在繪製的牆；再按一次{{key:Esc}}即回到{{ui:Select}} |
| {{key:Delete}} | 刪除選取的牆、門與窗；剩下的牆會重新接合 |
| 指標在平面圖上時按{{key:F}} | 符合平面圖 |
| 滾動滾輪 | 以指標為中心縮放 |
| 以中鍵或右鍵拖曳，或按住{{key:Space}}並拖曳 | 平移；{{ui:Select}}開啟時，一般拖曳也會平移 |
| 在{{ui:Select}}開啟時拖曳門或窗 | 沿其牆移動，或移至另一面牆 |
| 雙指（觸控） | 捏合縮放，一起移動則平移 |

## 放置與貼上程式庫項目

| 按鍵 | 功能 |
|---|---|
| {{key:R}} | 將項目旋轉 90° |
| {{key:Tab}} | 開啟或關閉牆面貼附：項目背面貼向最近的牆 |
| 在 **X, Y (mm)** 中按{{key:Enter}} | 放置於輸入的位置 |
| {{key:Esc}} | 停止放置或貼上 |

## 編輯 IFC 值

| 按鍵 | 功能 |
|---|---|
| {{key:Enter}} | 保留輸入的值 |
| {{key:Esc}} | 取消並還原舊值 |
| 點按其他處 | 保留輸入的值 |
| {{key:Mod+Z}} | 復原上一個變更。僅在有未儲存的變更且未在欄位中輸入時有效 |
| {{key:Mod+Y}} | 取消復原剛才被復原的內容 |
| {{key:Mod+S}} | 另存為 IFC。僅在有未儲存的變更時有效；否則會開啟瀏覽器本身的儲存指令 |

只用鍵盤編輯：按{{key:Tab}}直到某個值被反白，然後按{{key:Enter}}開始輸入。

## 2D 圖面（DWG 與 DXF）

| 按鍵或操作 | 功能 |
|---|---|
| {{key:F}} | 符合圖面或圖紙 |
| {{key:P}} | 開啟或關閉列印視圖 |
| 連按兩下 | 符合 |
| 以任一按鍵拖曳 | 平移 |
| 滾動滾輪 | 以指標位置縮放 |
| 觸控板上以兩指捲動或捏合 | 以指標位置縮放。兩指捲動不會平移 |
| 單指（觸控） | 平移。圖面的捏合縮放尚未實作 |

## 3D 圖面

| 按鍵或操作 | 功能 |
|---|---|
| {{key:3}} | 開啟或關閉 3D（也適用於 2D 視圖） |
| {{key:F}} | 範圍：整張圖面 |
| 以中鍵或左鍵拖曳 | 環繞 |
| 以右鍵拖曳，或按住{{key:Shift}}並拖曳 | 平移 |
| 滾動滾輪 | 朝指標下的物件縮放 |
| 觸控板上以兩指滑動 | 環繞；按住{{key:Shift}}則平移 |
| 觸控板上捏合 | 縮放 |
| 單指（觸控） | 環繞 |
| 雙指（觸控） | 捏合縮放，一起移動則平移 |

在欄位中輸入時、設備表顯示時，或按住{{key:Mod}}或{{key:Alt}}時，{{key:F}}、{{key:P}}與{{key:3}}皆無作用。

## 檔案

| 操作 | 功能 |
|---|---|
