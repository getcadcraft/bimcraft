如果你熟悉 Revit，BimCraft 的大部分用語會讓你感到熟悉，但功能範圍會有所不同。最重要的差異是：**此版本可讀取與檢視模型，並編輯 IFC 資料，目前尚不能像 Revit 那樣建立模型。**你無法繪製牆、放置族、建立視圖或圖紙，也無法儲存專案檔。你可以在任何裝有瀏覽器的電腦上開啟幾乎任何建築檔案、查看其內容、檢查整個專案資料夾，並修正 IFC 模型中的資料。

## 使用習慣對照

| 如果你習慣 | 在 BimCraft 中 |
|---|---|
| 在 Revit 中開啟 `.rvt` 以查看模型 | BimCraft 會將 `.rvt` 以檔案卡片開啟：顯示版本、專案資訊、連結與預覽。若要檢視 3D 模型，請匯出 IFC 並開啟該檔案。[讀取專案或族檔案](topic:read-rvt-file) |
| 開啟前先確認檔案是以哪個版本儲存 | 卡片頂部會顯示「以 Revit … 儲存」，不會升級或變更檔案 |
| 專案瀏覽器 | 沒有視圖與圖紙的瀏覽器。IFC 模型有{{ui:樓層}}與{{ui:元件}}清單；圖形則有圖紙索引標籤 |
| 特性面板 | 右側的{{ui:特性}}面板，顯示你點選的元素。使用 IFC 屬性集，而非參數群組 |
| 個別與類型參數 | 個別屬性集，以及標示「(類型)」的屬性集。變更類型時會套用到該類型的每個元素，與 Revit 相同。[變更類型屬性，套用到該類型的每個元素](topic:type-vs-instance) |
| 編輯類型 | 沒有對話方塊：在「(類型)」屬性集中點選某個值並直接輸入 |
| 選取多個元素、篩選、選取所有實例 | 一次一個元素。尚未實作 |
| 視圖方塊與導覽輪 | 右下角的視圖方塊、四個按鈕（{{ui:符合視窗}}、{{ui:上}}、{{ui:前}}、{{ui:側視}}）以及自由環繞。沒有導覽輪 |
| 按住Shift並中鍵拖曳以環繞，中鍵拖曳以平移 | 左鍵拖曳可環繞，右鍵拖曳（或按住{{key:Shift}}拖曳）可平移，滾輪可縮放。{{ui:BIM 功能區}}功能表樣式會改為以中鍵拖曳平移，並以{{key:Shift}}加中鍵環繞。[功能表、按鍵與滑鼠](topic:menus-keys-and-mouse) |
| 平面圖、剖面、剖面框 | 一次只能使用一個{{ui:剖面}}平面（{{key:X}}）；沒有剖面框或 2D 平面圖。[以剖面平面切開 IFC 模型](topic:section-plane) |
| 在視圖中隱藏、隔離、可見性／圖形 | {{ui:樓層}}可開啟與關閉，另有{{ui:空間}}與{{ui:邊線}}。尚無個別元素隱藏功能 |
| 房間 | IFC 空間，初始為隱藏。點選{{ui:空間}} |
| 儲存、另存新檔、與中央模型同步 | {{ui:另存為 IFC}}會下載一個新的 IFC 檔案。原始檔案絕不會變更。沒有中央模型，也沒有共同作業 |
| 以{{key:Mod+Z}}復原 | 在儲存前對 IFC 編輯有效。[變更 IFC 屬性並儲存編輯後的副本](topic:edit-ifc-properties) |
| 管理連結 | 開啟專案資料夾：每個連結都會被檢查，並標示為 **位於此資料夾**、**找到同名檔案**、**程式庫檔案** 或 **不在此資料夾中**。[開啟整個專案資料夾](topic:open-project-folder) |
| 稽核，或開啟檔案以檢查是否損毀 | 資料夾報告會在數秒內檢查每個副本與備份是否不完整。[檢查資料夾中的損毀副本](topic:check-folder-health) |
| 從雜亂的資料夾中選出正確的檔案 | {{ui:從這裡開始}}方塊會建議一個檔案，並說明理由 |

如果你主要是開啟模型來檢查，就像使用模型檢查或 IFC 檢視程式一樣，請選擇{{ui:檢視器}}功能表樣式：檢視與檢查工具會排在最前面，建築工具則收在同一個功能表中。請參閱[功能表、按鍵與滑鼠](topic:menus-keys-and-mouse)。

## 從檢視 DWG 檔案轉換

如果你習慣在 AutoCAD 或 DWG 檢視器中開啟 DWG：

| 如果你習慣 | 在 BimCraft 中 |
|---|---|
| 底部的模型與配置索引標籤 | 圖形上方的索引標籤：{{ui:模型}}，以及每張圖紙各一個 |
| ZOOM Extents，連按滾輪兩下 | 按兩下、按{{key:F}}或{{ui:符合視窗}} |
| 以中鍵平移 | 以任一按鍵拖曳 |
| 圖層管理員 | {{ui:圖層}}清單：勾選以顯示，取消勾選以隱藏，以及{{ui:全部開啟}}與{{ui:全部關閉}} |
| 外部參考管理員 | 右側的**連結的圖形**，顯示**已顯示**或**找不到**，以及{{ui:加入連結的圖形…}} |
| 列印預覽 | {{ui:列印視圖}}或{{key:P}}：白底黑字並顯示線寬。不會列印 |
| 擷取區塊屬性資料 | 適用於有標籤之餐飲設備圖的{{ui:設備}}索引標籤，並可搭配{{ui:下載 CSV}} |
| 量測、繪製、編輯、另存新檔 | BimCraft 中沒有此功能。CadCraft 繪圖應用程式可進行繪製與編輯 |

## 容易造成困擾的差異

- **它在瀏覽器中執行，而瀏覽器會謹慎處理你的檔案。** BimCraft 只能讀取你透過選擇或拖放提供的檔案與資料夾。它無法自行開啟檔案，也無法覆寫檔案。每次儲存都是下載。
- **不會上傳任何內容。** 某些瀏覽器資料夾對話方塊中出現的「上傳」一詞，是瀏覽器本身的用語。檔案會留在你的電腦上。
- **IFC 是模型格式。** 專案檔會以卡片形式開啟，因為其 3D 內容未有文件說明。請將 IFC 視為模型進入 BimCraft 的方式。
- **編輯採用寫入時複製。** 變更一個元素的值，絕不會影響其相鄰元素，即使匯出程式在它們之間共用了該值。類型屬性是刻意的例外。
- **沒有專案，也沒有視圖。** BimCraft 一次只顯示一個檔案，關閉分頁後不會保留任何相關記憶，只記得 Chrome 與 Edge 中最近的資料夾名稱。
- **Mac 按鍵。** Revit 的 Windows 快捷鍵使用 Ctrl 之處，BimCraft 的快捷鍵則使用{{key:Mod}}：在 Mac 上為 Command。
- **你的滑鼠習慣。** 環繞預設為左鍵，而非 Shift 加中鍵，除非你選擇{{ui:BIM 功能區}}功能表樣式，或在[功能表、按鍵與滑鼠](topic:menus-keys-and-mouse)中自行設定按鍵。

關於目前可改用的功能，請參閱[尚未實作的功能](topic:not-built-yet)。
