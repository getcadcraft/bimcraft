## 此處可開啟的格式

使用{{ui:Open}}開啟這些檔案，或將它們拖放到頁面上（請參閱關於在模型旁顯示點雲的主題）：

| 格式 | 副檔名 | 讀取內容 |
|---|---|---|
| LAS、LAZ | `.las`、`.laz` | LAS 1.0–1.4：點、色彩、強度、LiDAR類別與座標系統。LAZ最大1 GB。 |
| E57 | `.e57` | 檔案中的每次掃描，依其姿態放置；有色彩時讀取色彩，沒有時讀取強度。檔案中的圖片會被略過（會有提示）。目前最多600萬個點、512 MB：較大的掃描請匯出為LAS或LAZ。 |
| PLY | `.ply` | 文字與二進位（兩種位元組順序皆可）：頂點的x y z、色彩與強度。面會被略過（會有提示）。 |
| PCD | `.pcd` | 文字與二進位：x y z、打包或分開的色彩、強度。尚未讀取壓縮的PCD檔：請另存為二進位或文字格式。 |
| PTX | `.ptx` | 一或多次掃描，各依其自身的變換放置；掃描儀未量測的點會被略過。單位為公尺。 |
| PTS、XYZ | `.pts`、`.xyz` | 文字：x y z；欄位存在時會讀取強度與色彩。 |

## 只有掃描儀軟體能讀取的檔案

部分掃描檔是掃描儀廠商自有的格式，未公開說明，也沒有開放的讀取器。BimCraft無法讀取這類檔案，開啟時會顯示一張卡片，說明該檔案是什麼，以及該怎麼做。請從廠商軟體將掃描匯出為E57或LAS（或PTX、PTS），然後開啟匯出的檔案。

| 檔案 | 副檔名 | 匯出來源 |
|---|---|---|
| ReCap專案 | `.rcp` | ReCap：開啟專案並將其匯出。專案只指向其掃描，單獨複製`.rcp`不會得到任何點。 |
| ReCap掃描 | `.rcs` | ReCap：開啟該掃描所屬的專案並將其匯出。 |
| FARO掃描 | `.fls` | FARO SCENE。 |
| Leica掃描 | `.lgs` | Leica Cyclone REGISTER 360。 |
| Trimble掃描 | `.tzf` | Trimble RealWorks或Trimble Business Center。 |
| Z+F掃描 | `.zfs` | Z+F LaserControl。 |

:::tip
匯出時若要求選擇格式，LAS或LAZ能以最小的檔案保留BimCraft所顯示的一切（色彩、強度、類別與座標系統）。
:::

## 這些檔案為何無法讀取

這些格式未公開，唯一的讀取方式是各廠商自己的軟體程式庫，且依其各自的條款使用。BimCraft只讀取能以其本機程式碼讀取的格式，因此掃描不必傳送到任何地方即可開啟。
