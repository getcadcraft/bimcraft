## IFC

| 讀取 | 詳細資料 |
|---|---|
| 幾何 | 每個具有形狀的元素，顏色依檔案所示。房間與空間以透視方式繪製，且一開始為隱藏 |
| 樓層 | 依高程順序排列的建築樓層，以及各樓層上的元素。不在任何樓層上的元素會歸入「不在樓層上」 |
| 元素數量 | 每種元素的數量（牆、門、樓板……），顯示於 {{ui:元件}} 中 |
| 專案資訊 | 專案名稱、完整名稱與階段；結構描述；來自檔案標頭的匯出程式、作者與匯出日期 |
| 元素資料 | 名稱、類型、物件類型、標籤、描述、GlobalId；元素及其類型上的每個特性集與數量集 |

可編輯：名稱、物件類型、標籤、描述，以及單一特性值。儲存為新的 IFC 檔案。IFC2X3、IFC4 與 IFC4X3 結構描述皆可開啟，由 BimCraft 自有的 IFC 引擎讀取；尚無法繪製的內容會列於 {{ui:檔案}} 面板的 **尚未繪製** 之下。模型在開啟時會移至原點，因此放置於遠離原點處的模型仍會顯示在畫面中央。`.ifczip` 與 `.ifcxml` 無法開啟。

## 專案與族檔

`.rvt` 專案、`.rte` 專案範本、`.rfa` 族與 `.rft` 族範本。

| 讀取 | 詳細資料 |
|---|---|
| 檔案資訊 | 版本與建置、共同作業、中央模型路徑、最後儲存路徑、使用者名稱、語系、文件 GUID |
| 專案資訊 | 專案自身的欄位（名稱、編號、客戶、地址、狀態……），不含新專案的預設值 |
| 族資訊 | 族名稱、類別、版本、最後更新，以及依群組列出的參數 |
| 連結 | 檔案所指向的連結模型、CAD 連結、影像與關鍵註解表清單 |
| 預覽圖片 | 檔案中儲存的縮圖 |

不讀取：3D 模型、元素、視圖、配置與明細表。它們以未公開的格式儲存。BimCraft 每個檔案只讀取數十 KB，因此檔案大小幾乎不影響。

## .pln、.pla、.tpl 與 .bpn 專案檔

尚未讀取：BimCraft 開啟時會告知。模型匯出 IFC，圖形匯出 DWG 即可；參見 [開啟 .pln 與 .pla 專案檔](topic:pln-project-files)。

## DWG 與 DXF

| 讀取 | 詳細資料 |
|---|---|
| 空間 | 模型空間與每個配置（依索引標籤順序） |
| 視埠 | 每個配置的視埠，含其比例、旋轉與凍結圖層 |
| 圖層 | 名稱、顏色、開 / 關、凍結、列印旗標與線寬 |
| 物件 | 直線、聚合線、圓弧、圓、橢圓、雲形線、填滿與實體、文字與多行文字、區塊與屬性、標註、引線與多重引線、表格、點、影像 |
| 外部參考 | 找到檔案時，於其插入位置繪製 |
| 影像 | 找到圖片檔時依其繪製（PNG、JPEG、GIF、BMP、WebP；不含 TIFF） |
| 設備標籤 | 餐飲設備項目標籤（`KCL-ITEM` 屬性），用於設備明細表 |

其他內容會計入 **尚未繪製**，絕不加以猜測。已測試的 DWG 格式為 AutoCAD 2000 至 2018（R13 與 R14 檔案亦接受，但測試集中沒有這類檔案；更舊的 DWG 無法開啟）；{{ui:圖形}} 面板會顯示格式代碼（例如 AC1032）。所有版本的 DXF 檔皆可開啟，包括 R12。兩者皆由 BimCraft 自有的讀取器在此索引標籤中讀取。不會將任何內容寫回 DWG 或 DXF。

## 資料夾中的檔案

| 種類 | 副檔名 | 在報告中 |
|---|---|---|
| 模型 | `.rvt` `.rfa` `.rte` `.rft` | 依編號備份分組、進行健康檢查、讀取卡片並檢查連結 |
| IFC | `.ifc` | 列出；可在 3D 中開啟 |
| CAD | `.dwg` `.dxf` `.dgn` | 與連結它們的模型一併列出；DWG 與 DXF 可在 2D 中開啟，DGN 則不能 |
| 殘留檔 | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | 列於 **另行保留** 之下 |
| 管理資料夾 | `*_backup`、`*_log`、`Revit_temp`、隱藏資料夾 | 列於 **另行保留** 之下，不讀取 |

參見 [資料夾報告：角色、狀態與連結](topic:folder-roles)。
