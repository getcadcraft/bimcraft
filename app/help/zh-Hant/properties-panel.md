## IFC元素

{{ui:Properties}}面板頂端會顯示元素的類型（不含「Ifc」前綴，例如「Door」、「WallStandardCase」、「FurnishingElement」）及其名稱；若無名稱則顯示「未命名」。

| 欄位 | 意義 | 可編輯 |
|---|---|---|
| 名稱 | 元素的名稱，通常是匯出工具寫入的族群與類型名稱 | 是 |
| 類型 | 元素類型的名稱（若有） | 否 |
| 物件類型 | 部分匯出工具填入的自由文字類型說明 | 是 |
| 標記 | 元素的標記或標示；許多匯出工具會在此寫入元素ID | 是 |
| 描述 | 自由文字 | 是 |
| GlobalId | 元素永久的22字元IFC識別碼，同一元素每次匯出都相同 | 否 |
| 行 | 元素在此IFC檔案中的行號（`#1234`）。每次匯出都會改變 | 否 |

下方是**屬性集**，依名稱排序：

- 點按集合名稱即可展開或收合。前三個預設為展開。
- 標示「(type)」的集合屬於元素的類型：「類型屬性：此處的變更會套用到此類型的每個元素。」
- 數量集（長度、面積、體積、數量、重量）為唯讀。
- 清單與列舉值會顯示，但為唯讀。
- 是／否值會顯示為**是**或**否**。
- 數字會四捨五入至四位小數顯示。長度（長度特性或數量的長度）會以工具列上所選的{{ui:Units}}顯示，並在旁邊標示單位；可以用該單位或其他單位標記輸入新值（2.4 m、8'-0"）。BimCraft會將檔案原本的數字寫回。其他數字則依檔案原樣顯示。
- 空白值會顯示為*空白*。已編輯的值會以粗體顯示，旁邊有藍色條。

## 複製值

在{{ui:Properties}}中，每個值旁都有一個小型複製按鈕：點按即可將該值依其顯示內容原樣放到剪貼簿，例如GlobalId、序號或任何屬性集的值。複製不會啟動編輯。

在頂端，{{ui:Copy all}}會逐集合將元素的所有值複製為文字；{{ui:Copy as CSV}}會將群組、屬性與值以列的形式複製，可貼到試算表中。空白值會保留，讓每個欄位都有一列。此功能對另一個已開啟模型中的元素同樣有效；開啟多個模型時，CSV會以「模型」欄開頭，列出其檔名。

## 檔案面板（IFC）

| 欄位 | 意義 |
|---|---|
| 檔案、大小 | 所開啟的檔案 |
| 結構描述 | IFC版本，例如IFC2X3或IFC4 |
| 專案 | 專案名稱與完整名稱 |
| 階段 | 專案階段（若匯出工具有寫入） |
| 匯出自 | 匯出的程式，取自檔案標頭 |
| 作者 | 檔案標頭中的作者 |
| 匯出時間 | 檔案標頭中的日期與時間 |
| 元素 | 繪製了多少具有形狀的元素 |
| 三角形 | 其形狀構成的三角形數量；用以衡量模型的負荷程度 |

## 檔案面板（專案與族群檔案）

| 欄位 | 意義 |
|---|---|
| 種類 | 專案、專案範本、族群或族群範本 |
| 儲存於 | 最後一次儲存該檔案的版本 |
| 建置 | 該版本的確切建置 |
| 已讀取 | BimCraft讀取了檔案的多少內容，相對於其大小 |

## 圖形面板（DWG與DXF）

| 欄位 | 意義 |
|---|---|
| 格式 | 圖形儲存時所用的版本，以及其格式代碼，例如AC1032 |
| 單位 | 圖形的插入單位（若已設定） |
| 物件 | 讀取了多少物件 |
| 圖層 | 圖層數量 |
| 配置 | 配置數量，或無 |
| 外部參考 | 找到並載入的外部參考圖形數量 |
| 設備 | 配置上有多少個已標記的設備 |

## 資料夾面板

| 欄位 | 意義 |
|---|---|
| 資料夾、檔案、大小 | 所開啟的資料夾、其包含的檔案數與總大小 |
| 模型 | 專案與族群檔案，每個檔案的備份只計算一次 |
| CAD圖形、IFC模型 | 各有多少 |
| 問題 | 有多少模型副本不完整或無法讀取，或無 |
