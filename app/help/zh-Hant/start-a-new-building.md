## 做什麼

從零開始建立建築模型，而不是開啟現有模型。BimCraft 會建立含專案、基地、建築與各標高的空白 IFC 模型。可以從程式庫在各標高上放置設備與家具，並儲存為 IFC 檔案。

:::note
現在可以繪製牆：參閱[繪製牆](topic:draw-walls)。門、窗、樓板與屋頂是接下來要實作的項目。
:::

## 步驟

1. 在**開啟檔案或資料夾**下方，或在起始頁面上，按一下 {{ui:新建建築}}。
2. 輸入**建築名稱**。
3. 選擇**標高**的數量（1 至 200）。
4. 輸入**標高高度**，即樓層到樓層的高度：例如 `10'-0"`、`10'6"` 或 `3000 mm`。單純的數字在美國視為英尺，其他地區視為公釐。
5. 按一下 {{ui:建立}}。各標高從 0 起向上堆疊，每一層比前一層高出一個標高高度，並命名為 Level 1、Level 2，依此類推。它們會顯示在模型樹狀結構中，Level 1 的平面會在 3D 檢視旁開啟，且 {{ui:繪圖}} 為開啟狀態。
6. 繪製牆：參閱[繪製牆](topic:draw-walls)。在**標高**面板中可重新命名標高或變更其高度。
7. 放置項目：參閱[從程式庫放置設備與家具](topic:place-from-library)。放置列會列出所有標高。
8. 按一下 {{ui:另存為 IFC}}。檔案會以建築名稱命名，例如 `Smith's house.ifc`。

## 注意事項

- 模型以公釐為單位儲存，格式為 IFC4。其他 BIM 程式也能開啟。
- 左側面板中的 {{ui:樓層}} 只列出有內容的標高；模型樹狀結構則列出全部。
- 儲存之前，新建築視為尚未儲存的內容。開啟其他檔案或離開之前，BimCraft 會先詢問，並在此瀏覽器中保留一份複本，以防分頁被關閉。
