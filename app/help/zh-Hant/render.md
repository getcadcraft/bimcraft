{{ui:算圖}}位於工具列上，可為 3D 視圖製作類似日光的畫面：天空、依基地緯度擺放的太陽、柔和陰影、從整個天空射入而使角落變暗的光線，以及能呈現玻璃或金屬質感的色彩。模型與檔案不會被改變。

## 算圖目前的視圖

1. 將 3D 視圖調整成你想要的畫面：旋轉與縮放，隱藏不想要的樓層或元素；若畫面應顯示剖切，則設定[剖面](topic:section-plane)。
2. 按下工具列上的{{ui:算圖}}。
3. 如果所按的{{ui:場景}}不是你想要的，請選擇一個（見[場景預設](topic:render#scene-presets-a-good-picture-in-one-click)），選擇{{ui:大小}}，然後按下對話方塊中的{{ui:算圖}}。

   畫面會隨著算圖逐步顯示，每一輪都會更平滑。{{ui:停止}}（或{{key:Esc}}）會提前結束並保留目前的畫面。

4. 按下{{ui:儲存}}以 PNG 下載，或按下{{ui:另存新檔}}選擇其他格式（見[儲存畫面](topic:render#save-the-picture)）。檔名取自模型的檔案名稱。

:::tip
先以{{ui:目前視圖的大小}}的{{ui:草稿}}檢查相機，再以較大的尺寸算圖{{ui:良好}}或{{ui:最佳}}作為最終畫面。
:::

## 場景預設：一鍵得到好畫面

對話方塊頂部有四個{{ui:場景}}按鈕。每個按鈕會一次設定天空、亮度、地面、邊線、品質與太陽，因此第一張畫面不需要任何學習。按下其中一個，再按下{{ui:算圖}}。

| 場景 | 設定內容 | 用途 |
|---|---|---|
| {{ui:外部}} | 晴空、模型自身的太陽、地面開啟 | 從外部看建築 |
| {{ui:內部}} | 陰天（光線均勻，沒有強烈的陽光斑塊），亮度提高半級 | 從房間內部看 |
| {{ui:剖面視圖}} | 白色攝影棚、無地面、快速算圖中顯示邊線 | 以剖面切開的模型 |
| {{ui:夜間}} | 太陽落下（基地所在半球的仲冬午夜），亮度提高一級 | 以燈具照亮模型。若沒有燈具，畫面會很暗 |

- {{ui:依此視圖選擇}}會替你選擇：有剖切時為{{ui:剖面視圖}}，相機位於模型內部時為{{ui:內部}}，其他情況為{{ui:外部}}。第一次開啟對話方塊時，會自動以此方式開始。
- 下方的每個設定都可以更改。一旦你更改了某項設定，該場景便不再符合，按鈕不再被按下，按鈕下方的文字會說明設定為自訂。再按一次該場景，即可恢復其數值。
- 場景不會影響引擎、模式、大小、材質、相機或燈具。

:::note
各場景在 ModelCraft 與 BimCraft 中給出的數值相同。完成畫面的外觀取決於你的模型與顯示卡。
:::

## 畫面中會顯示什麼

3D 視圖中以實體顯示的內容：隱藏與透視的元素、隱藏的樓層與隱藏的模型都不會包含在內；只有在{{ui:空間}}開啟時才會顯示房間。剖面平面或剖面框會如同切割視圖一樣切割畫面。元素以其本身的顏色顯示：依屬性上色（{{ui:色彩}}索引標籤）不會被使用。

## 設定

| 設定 | 功能 |
|---|---|
| {{ui:大小}} | 視圖的大小、兩倍視圖大小、Full HD、4K 或正方形 |
| {{ui:振態}} | {{ui:快速}}，或下方的{{ui:高品質（路徑追蹤）}}及其{{ui:時間上限}} |
| {{ui:品質}} | 平均多少輪（在高品質中則為取樣數）：{{ui:草稿}} 16、{{ui:良好}} 64、{{ui:最佳}} 256。輪數越多，陰影與邊緣越平滑，但耗時也越長 |
| {{ui:天空}} | {{ui:晴空}}、{{ui:陰天}}、{{ui:黃昏}}或{{ui:白色攝影棚}}（純白背景） |
| {{ui:太陽}} | 6 月 21 日 15:00，位於檔案為其基地提供的緯度（IfcSite），並依模型的真北方向旋轉。勾選{{ui:此圖片使用其他日期與時間}}可設定其他時間 |
| {{ui:亮度}} | 以級（stops）為單位，調整得更亮或更暗 |
| {{ui:模型下方的地面}} | 位於模型最低點的地面，會接收陰影並淡入地平線 |
| {{ui:繪製邊線}} | 在畫面上以細線繪製元素的邊線 |

若在所選時間太陽位於地平線以下，即為夜間：天空變暗，模型的燈具會照亮它。

## 燈具

模型中的每個燈具在畫面中都是一盞燈：IFC 檔案中的燈具（IfcLightFixture，或類型為燈具的元素），包括你從程式庫放置的燈具。每盞燈都從燈具正下方略低之處向下照射。若檔案提供燈具的瓦數，其亮度即由此推算；否則為 800 流明的暖白光。

對話方塊會在{{ui:燈具}}下列出燈具：取消勾選即可關閉某盞燈，或輸入其亮度（以流明為單位）。這些變更會儲存在 IFC 中（燈具的 `CadCraft_Light` 屬性集，你也可以在屬性中變更），而{{key:Ctrl+Z}}可以復原。

當檔案未說明基地位置時，太陽會置於北緯 40°，對話方塊會註明此事。時間為基地的當地時間，依其經度推算，因此在時鐘設定不同的地方可能相差一小時。

這些設定會保存在此瀏覽器中，供下一張畫面使用，而不會儲存在 IFC 檔案中。

## 玻璃與其他材質

在{{ui:材料}}下，螢幕上的每種顏色都有一種外觀：{{ui:啞光}}、{{ui:緞面}}、{{ui:光澤}}、{{ui:金屬}}、{{ui:拋光金屬}}、{{ui:玻璃}}或{{ui:磨砂玻璃}}。IFC 檔案中設為透明的顏色（例如窗玻璃）一開始為{{ui:玻璃}}。

:::note
在{{ui:快速}}模式中，玻璃與金屬會反射天空而非模型的其餘部分，光線也不會穿過玻璃折射。下方的{{ui:高品質（路徑追蹤）}}模式兩者皆會處理。
:::

## 高品質

選擇{{ui:振態}} › {{ui:高品質（路徑追蹤）}}，可得到依照相機視角追蹤光線的畫面：

- 光線在表面之間反彈，因此透過窗戶或燈具照亮的房間，四面都會被照亮，色彩也會溢到相鄰的表面上；
- 玻璃是真正的玻璃：光線會穿過並折射，且會映出模型；
- 金屬與拋光表面會反射模型的其餘部分；
- 光面板以面光源的方式發光，並帶有柔和陰影。

這比{{ui:快速}}慢得多：每一輪都要重新追蹤每個像素的光線。畫面一開始會有顆粒，隨著取樣累積而逐漸清晰，因此請先以小尺寸（{{ui:目前視圖的大小}}、{{ui:草稿}}）開始，並設定{{ui:時間上限}}：時間用完時會保留目前的畫面。按下{{ui:停止}}同樣會保留畫面。第一輪會等待瀏覽器準備路徑追蹤器。

在瀏覽器支援 WebGPU 時，路徑追蹤器為 CadCraft 自有，並在顯示卡上執行；畫面下方的文字會說明此事。在按下{{ui:停止}}或時間用完後，{{ui:繼續}}會沿用同一張畫面繼續算圖，直到完成所有取樣；變更設定或再次按下{{ui:算圖}}則會從頭開始。沒有 WebGPU 時，畫面會改以 WebGL 進行路徑追蹤（文字會說明此事），且不會提供{{ui:繼續}}。

:::linux
Linux 上的 Firefox 與多數 Chrome 設定目前尚無 WebGPU，因此高品質在那裡使用 WebGL。
:::

在此模式中，不繪製邊線，貼圖會顯示其顏色與粗糙度但不顯示凹凸，且剖切會在畫面開始前先套用到模型上。

{{ui:降噪（清除取樣後殘留的雜訊顆粒）}}預設為開啟：畫面完成或停止時，殘留的顆粒會由為此設計的神經網路清除（Intel Open Image Denoise 公開的網路，在你自己的電腦上執行：在顯示卡上，否則在處理器上）。{{ui:顯示}} › {{ui:降噪前的影像}}會顯示未降噪前的算圖結果。

## 顯示卡上的天空與光源配光檔

在 WebGPU 下，高品質還提供兩種天空：

- {{ui:物理天空}}依太陽的高度計算日光：頭頂為深藍，地平線附近為淡色帶，太陽低垂時會變得更暖、更暗。{{ui:霧度}}可從非常清澈的日子（2）調整到霧濛濛的日子（10）。
- {{ui:天空影像（HDRI）}}以一張真實地點的全景圖照亮模型。{{ui:選擇影像…}}可選取等距長方形的 `.hdr` 或 `.exr` 檔案；{{ui:旋轉}}使其繞著模型轉動，{{ui:影像亮度}}則使其更亮或更暗。此影像自帶太陽，因此不會再加入模型的太陽。它只在頁面開啟時保留：重新開啟後須再次選擇。

{{ui:燈具}}清單中的每盞燈都可以套用製造商的光源配光檔：{{ui:IES 配光檔…}}會讀取 IES（LM-63）檔案，之後該燈會依該燈具的方式投光（窄束筒燈、牆面洗牆燈）。所有同名的燈都會使用它，而每盞燈仍保留自己的亮度。按一下配光檔的名稱即可停止使用。

清澈玻璃的窗戶有助於天空的光線進入房間。

{{ui:快速}}模式與 WebGL 路徑追蹤器會將{{ui:物理天空}}與{{ui:天空影像（HDRI）}}顯示為晴空，並忽略光源配光檔。

## 相機

{{ui:相機}}會以照片的方式設定畫面：

- {{ui:曝光}}：保留{{ui:亮度滑桿}}，或選擇{{ui:相機設定}}，並如同在相機上一樣設定{{ui:光圈（f 值）}}、{{ui:快門速度}}與{{ui:ISO}}；旁邊的 EV 即為一般的曝光值。f/16、1/100 秒、ISO 100 相當於晴天；較暗的場景需要較大的光圈、較慢的快門或較高的 ISO。此功能在每種模式中都可使用。
- {{ui:景深}}會依該光圈的鏡頭特性，模糊比{{ui:對焦距離（公尺）}}更近或更遠的部分（留空則對焦於視圖中央的物件）；{{ui:光圈形狀}}可將焦外的亮點呈現為圓形或多葉形。
- {{ui:兩點透視（垂直線保持垂直）}}會將相機調平並移動畫面，如同建築移軸鏡頭，因此在仰視或俯視建築時，牆面不會傾斜。
- {{ui:白平衡}}設定哪種光色被視為白色：較低（例如 3000 K）適用於暖色燈光，較高適用於陰影與陰天。
- {{ui:投影}}：{{ui:360° 全景圖}}會製作相機周圍一切的 2:1 畫面，供全景檢視器使用；{{ui:360° 立體全景}}會堆疊左眼與右眼的全景，供頭戴裝置使用；{{ui:立方體貼圖（6 面）}}會以 3 × 2 的格線製作六個正方形視圖。寬度取自{{ui:大小}}。

投影、景深、兩點透視與白平衡需要顯示卡上的路徑追蹤器（WebGPU），因此僅在{{ui:高品質（路徑追蹤）}}中顯示。

## 完成畫面

{{ui:圖片}}會像照片一樣為高品質畫面調色，而每個控制項都會立即改變完成的畫面，無需重新算圖：

- {{ui:外觀（view transform）}}：{{ui:ACES filmic}}（與之前相同的畫面）、{{ui:AgX}}（較柔和，在極亮的光線中保留色彩）、{{ui:Filmic}}（柔和的膠片曲線）或{{ui:標準}}（單純，極亮的光線會截切為白色）。
- {{ui:對比}}與{{ui:高光壓縮}}（在極亮的部分找回細節）。
- {{ui:泛光（Bloom）}}（亮光周圍的柔和光暈）、{{ui:眩光}}及其{{ui:眩光光芒}}（從最亮點射出的星形光線），以及{{ui:暈影}}（較暗的角落）。
- {{ui:色彩表（.cube）…}}從 `.cube` 檔案套用色彩分級，並可調整{{ui:色彩表強度}}；與天空影像一樣，只在頁面開啟時保留。

## 儲存畫面

{{ui:另存新檔}}位於{{ui:儲存}}旁，用於選擇檔案：{{ui:PNG}}、{{ui:JPEG}}或{{ui:WebP}}適用於分享（JPEG 與 WebP 僅在瀏覽器能寫出時可用）；在顯示卡上完成高品質算圖後，還可選擇：

- {{ui:PNG，16 位元}}：經過調色的畫面，明暗層次更細緻，適合列印或進一步編輯。
- {{ui:EXR，所有圖層（32 位元浮點數）}}：算圖結果原樣（線性光，未調色），每個算圖元素與光源群組各為一個獨立圖層，供合成程式使用。
- {{ui:算圖檔（.ccrender，之後可再調色）}}：對話方塊重新混合與調色畫面所需的一切內容。{{ui:開啟算圖檔…}}會將其載入，連同混合與調色設定，無需重新算圖。

## 算圖後混合燈光

在按下{{ui:算圖}}之前開啟{{ui:光線混合（算圖後可變更每盞燈的顏色與亮度）}}。畫面完成（或停止）後，{{ui:混合畫面}}會依群組列出其燈光：天空、太陽，以及依名稱分組的燈具（同名的每盞燈為同一群組）。關閉某個群組、為其指定顏色，或使其更亮或更暗，畫面會立即改變，無需重新算圖。{{ui:儲存混合}}會以一個名稱保存該混合，以便之後再選擇；{{ui:算圖結果}}則會回到製作時的畫面。{{ui:儲存}}會儲存已混合的畫面。

{{ui:算圖元素（反照率、法線、深度、漫反射、鏡面反射、透射、自發光、ID）}}也會保留畫面的各個部分。{{ui:顯示}}會將視圖切換為其中之一：表面顏色（反照率）、法線、深度、漫反射、鏡面反射與透射光（各分直接與間接）、發光部分與天空，以及依物件或依材質指定的顏色，用於製作遮罩。

兩者都會在顯示卡上保留額外的圖層。在較大的尺寸時，顯示卡可能沒有足夠的空間；對話方塊會告知，此時改用較小的尺寸即可。

## 霧、煙、雜訊與焦散

這些功能位於{{ui:霧、煙與雜訊}}中，在顯示卡上的{{ui:高品質（路徑追蹤）}}中運作；其他引擎不包含這些功能。

- {{ui:霧與霾}}會將空氣充滿至某個高度，形成可被太陽、天空與燈具照亮的薄霧。{{ui:能看多遠，單位為公尺}}設定霧的濃度（約 100 m 為淡霾，20 m 為濃霧）；{{ui:霧的高度（離地面），單位為公尺}}設定霧的上界；{{ui:光束}}則設定霧朝光源發光的程度。陽光會在霧的頂部離開霧層，因此當陽光穿過窗戶或建築之間時，你會看到光束。
- {{ui:煙或雲}}會加入一個與霧一樣受光照明的煙或雲體積。{{ui:類型}}可為{{ui:雲}}、{{ui:煙柱}}或{{ui:來自體積檔（.ccvol）}}（CadCraft 自有的格狀格式）。{{ui:細節}}與{{ui:變化}}會改變已建立的雲或煙柱；{{ui:最長邊的長度，單位為公尺（0 = 模型的大小）}}、{{ui:移動X (m)}}、{{ui:移動Y (m)}}、{{ui:移動Z (m)}}與{{ui:旋轉}}用於放置它（預設從模型中央開始）；{{ui:厚度}}使其更濃密，{{ui:前向光暈}}使其更朝光源發亮，{{ui:色彩}}為其上色。體積檔與天空影像一樣，只在頁面開啟時保留。
- {{ui:畫面乾淨處提早停止（適應性取樣）}}不再為已穩定的像素提供更多取樣。{{ui:可接受的雜訊}}為像素停止時仍殘留的顆粒量。畫面下方的文字會說明每個像素平均取得多少取樣。
- {{ui:焦散（光線經玻璃折射或經鏡面反射）}}會從燈具與太陽追蹤光線，使玻璃球下方的亮斑，或鏡面投射在牆上的光斑，呈現乾淨而非顆粒狀。在霧、煙、光線混合或算圖元素開啟時會關閉；它是為靜態畫面而設計，而非 360° 畫面。

## 算圖佇列
