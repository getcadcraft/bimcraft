## 作業內容

IDS（資訊交付規範，buildingSMART 標準）是 IFC 必須包含內容的清單：哪些類別、哪些屬性與數值、分類、材料，以及物件應位於何處。業主與公共採購通常會隨案件附上 IDS。BimCraft 會將開啟的 IFC 模型與 IDS 比對，並列出每個未達標的元素。

## 步驟

1. 開啟 IFC 模型。
2. 在左側面板的 {{ui:模型檢查}} 下開啟 {{ui:依 IDS 檢查}}，或從所用功能表樣式的功能表中選擇 {{ui:依 IDS 檢查…}}。
3. 點選 {{ui:載入 .ids 檔案…}} 並選取檔案。不會上傳任何內容。
4. 查看結果：每條規範會顯示 {{ui:通過}} 或 {{ui:未通過}}，以及其適用的元素數量。
5. 開啟問題清單（{{key:Ctrl+Shift+M}}），點選一個未通過項目，即可選取該元素並縮放至該元素。

## 應會看到的結果

- 每個元素與每條未達標的要求各一則警告，內含規範名稱、IDS 的要求內容，以及元素實際的值。
- 模型中沒有任何元素符合的必要規範，會單獨產生一則警告。
- 問題清單中的檢查報告以 IDS 開頭：包括其標題、版本、作者，以及每條規範的適用、通過與未通過數量。

## 補充說明

- IFC 只保留 IDS 的參照（名稱、標題、版本與雜湊值），不含 IDS 本身：客戶的 IDS 可能屬機密，而 IFC 會交給其他人。IDS 會與模型一同保存在此瀏覽器中，因此在此重新開啟已儲存的 IFC 時會再次檢查。載入或移除 IDS 都是一個可復原的步驟。
- 若在其他電腦或其他瀏覽器上開啟，問題清單會顯示找不到 IDS 的提示：重新載入即可再次檢查。
- 若要隨 IFC 一併傳送 IDS，請於載入前，在「設定」的「BimCraft」索引標籤中開啟 {{ui:將 IDS 保存在 IFC 內}}。
- 每次編輯、復原與取消復原後，稍後都會重新檢查。
- 數值的比對方式與 IDS 相同：文字須完全相同（區分大小寫）；數字以 SI 單位比較，並允許微小誤差（長度以公尺計，因此毫米單位的模型會先轉換）。
- 若規範是為其他 IFC 版本撰寫（例如模型為 IFC4，而規範為 IFC2X3），仍會檢查，結果會註明此點。
- 若 IDS 檔案有 IDS 稽核會標記的問題，對話方塊會列出，所在規範將判定為未通過。
- 與任何問題相同，可附上理由接受某項未通過。只要元素的數值不變，接受狀態就會保留。

- IDS 中的模式會以整個值來解讀。開頭的 `^` 與結尾的 `$` 同樣視為「整個值」，與多數 IDS 檔案的意義相符。
