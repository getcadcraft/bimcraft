## 作業內容

在模型中放置分離式、多分離式或 VRF 系統的機組及其風機盤管,再以冷媒管組連接:液管與氣管採用 ACR 銅管,並固定於機組的接頭上。這些機組與其他[具接頭的 MEP 設備](topic:mep-equipment)相同:同一個工具列、**特性**、接頭與[連接](topic:mep-connections)。

:::note
這是繪圖與協調用的輔助工具。機組為通用的形狀,尺寸依你輸入的數值而定,並非任何廠商的產品。管徑來自一張 R410A 與 R32 設備的**典型範例值**表,並非來自任何廠商:實際尺寸由機組廠商的安裝手冊決定,長距離配管或大高度差會改變尺寸。請變更該表,或直接輸入尺寸,以符合所用的機組。
:::

## 放置機組

1. 開啟{{ui:Draw}},開啟{{ui:Build}}並選擇{{ui:Equipment}}。
2. 選擇類型並設定其數值:

| 類型 | 設定項目 | 接頭 |
|---|---|---|
| 分離式室內機,壁掛式 | 容量、液管與氣管、長度、深度、高度、冷凝水尺寸 | 冷媒液管與氣管、冷凝水排放(位於右端,靠近牆面) |
| 分離式室內機,卡式 | 容量、液管與氣管、面板、機身、高度、冷凝水尺寸 | 冷媒液管與氣管、冷凝水排放(位於一側,靠近頂部) |
| 分離式室內機,風管式 | 容量、液管與氣管、長度、寬度、高度、送風與回風開口、冷凝水尺寸 | 送風風管出口、回風風管入口、冷媒液管與氣管、冷凝水排放 |
| 分離式室外機 | 容量、液管與氣管、寬度、深度、高度 | 冷媒液管與氣管(位於右側) |
| VRF 室外機 | 容量、液管與氣管、寬度、深度、高度 | 冷媒液管與氣管(位於前方、低處) |
| Refnet 分歧接頭 | 液管或氣管、每個分支的負載、每端的管徑 | 入口、分支 A、分支 B |
| 風機盤管 | 2 管或 4 管、長度、寬度、高度、送風與回風開口、盤管管路與系統、加熱管、冷凝水尺寸 | 送風風管出口、回風風管入口、盤管進與出、加熱進與出(4 管)、冷凝水排放 |

3. 設定**位於**:機組底座高於樓層的高度。壁掛式機組的底座為其底面(通常為 2100 mm);卡式機組則為其在天花板中的面板;分歧接頭則為其管線中心線的高度。
4. 按一下放置位置({{key:R}}可旋轉 90°)。

**容量**為機組的額定冷房容量,單位為 kW,旁邊附有 Btu/h。當**液管**與**氣管**保持在**依表格**時,機組的接頭會採用該容量在表格中的尺寸;若要使用機組自身的管徑,請選擇一種管徑。分歧接頭的入口依兩個分支合計的容量決定尺寸,每個分支則依其自身負載決定尺寸。

冷媒接頭雙向皆可使用(熱泵可在任一方向運轉)。冷凝水排放與其他排水口相同,是以管徑設定。

## 繪製冷媒管組

1. 選取兩個元件({{key:Shift}}加按第二個):一台室外機與一台室內機(單一分離式),或一台室外機與一個分歧接頭、一個分歧接頭與一台室內機,或兩個分歧接頭(VRF)。
2. 開啟{{ui:Build}}並選擇{{ui:Line set}}。

BimCraft 會在兩者的自由接頭之間繪出液管與氣管:從每個接頭伸出後升至共同高度,採用 ACR 銅管(1-5/8 in 以下為退火盤管,以上為拉伸管),並作為一個{{ui:Undo}}步驟。分歧接頭只接自己的管路:從室外側進入其入口,並從朝室內機方向的分支送出。每段管路採用其下游端的尺寸(室內機或分歧接頭入口);若另一端接頭的尺寸不同,{{ui:Check connections}}會列出該處,那裡就需要異徑接頭。兩台室內機之間需要一個分歧接頭。

之後移動管段的方式與其他管線相同,端點會維持在接頭上。跨樓層的管段以{{ui:Pipe}}繪製:由冷媒接頭開始的管線會採用其系統、ACR 銅管與尺寸。

## 變更冷媒管組表格

開啟{{ui:Build}}並選擇{{ui:Line set sizes}}。每列說明:不超過此容量(kW)時,採用此液管與此氣管。

| 不超過 | 液管 | 氣管 |
|---|---|---|
| 2.8 kW | Ø6.35 (1/4") | Ø9.52 (3/8") |
| 5.6 kW | Ø6.35 (1/4") | Ø12.7 (1/2") |
| 16 kW | Ø9.52 (3/8") | Ø15.88 (5/8") |
| 22.4 kW | Ø9.52 (3/8") | Ø19.05 (3/4") |
| 33 kW | Ø9.52 (3/8") | Ø22.22 (7/8") |
| 47 kW | Ø12.7 (1/2") | Ø28.58 (1-1/8") |
| 71 kW | Ø15.88 (5/8") | Ø28.58 (1-1/8") |
| 104 kW | Ø19.05 (3/4") | Ø34.92 (1-3/8") |
| 180 kW | Ø19.05 (3/4") | Ø41.28 (1-5/8") |

這些是起始的典型值。變更某一列、新增或移除列後按{{ui:Save}}:表格會保留在模型中,因此所有使用此檔案的人都會採用它,而{{ui:Undo}}可將其還原。{{ui:Use the typical values}}會還原為起始表格。已放置的元件在變更前會保留原有的接頭。

## 在 IFC 檔案中

split 與 VRF 系統的室內機與室外機為 IfcUnitaryEquipment,類型為 SPLITSYSTEM,物件類型會說明其種類(「Split indoor unit, wall-mounted」、「Split indoor unit, ceiling cassette」、「Split indoor unit, ducted」、「Split outdoor unit」、「VRF outdoor unit」)。風機盤管為 IfcUnitaryEquipment,類型為 AIRHANDLER,物件類型為「Fan coil unit」:IFC4 沒有風機盤管類型,而單一房間內的風扇、盤管與濾網正是 AIRHANDLER 所描述的內容。分歧接頭為 IfcPipeFitting,類型為 JUNCTION(「Refnet joint」)。IFC2X3 檔案會取得具對應類型的 IfcEnergyConversionDevice 與 IfcFlowFitting。

冷媒接頭與管段位於 REFRIGERATION 系統中(液管一個、氣管一個),冷凝水位於 DRAINAGE 系統中。ACR 管段以外徑命名。管組表格為專案上的屬性集 CadCraft_HvacLineSets。

另請參閱[具接頭的 MEP 設備](topic:mep-equipment)、[將管線與風管連接至設備](topic:mep-connections)與[管線與風管](topic:pipes-and-ducts)。
