開啟 {{ui:設定}}（{{key:Mod+,}}），停留在此應用程式自己的索引標籤，並捲動到 {{ui:算圖}}。{{ui:你的電腦}} 會列出此瀏覽器允許應用程式用於算圖的項目。其中的任何內容都不會離開你的電腦。

| 列 | 含義 |
|---|---|
| {{ui:圖形}} | 瀏覽器回報的顯示卡。「WebGPU」表示可以執行算圖工作；「僅 WebGL 2」表示沒有 WebGPU：即時檢視與高品質圖片會透過 WebGL 2 使用顯示卡（圖片使用較舊的 WebGL 路徑追蹤器，缺少需要 WebGPU 的額外功能）；軟體替代品表示所有工作都在處理器上執行 |
| {{ui:處理器}} | 瀏覽器回報的處理器核心數 |
| {{ui:記憶體}} | 電腦約有多少記憶體（若瀏覽器有提供）。部分瀏覽器不提供 |
| {{ui:共享記憶體}} | 頁面是否可在其工作執行緒之間共用記憶體。開啟時，每個核心都能處理同一份場景副本；關閉時，每個核心都需要自己的副本，因此大型場景同時能放入的核心較少 |
| {{ui:快速處理器程式碼}} | 瀏覽器是否執行較快的 WebAssembly 程式碼。未開啟時會使用較慢的備用程式碼 |
| {{ui:樓層}} | {{ui:顯示卡，高階}}、{{ui:顯示卡，基本}} 或 {{ui:僅處理器}}，其下方附有原因 |

## 等級

等級決定算圖的起點，使內建顯示晶片或完全沒有顯示卡的筆電仍能保持流暢。內建或手機顯示晶片，或 4 GB 或更少的記憶體，永遠不會取得 {{ui:顯示卡，高階}}。

:::note
各瀏覽器之間有差異。同一台電腦在一個瀏覽器中可能顯示 WebGPU，在另一個瀏覽器中卻顯示「僅 WebGL 2」。在 Linux 上，多數瀏覽器尚未提供 WebGPU。
:::
