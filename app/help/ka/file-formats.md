## IFC

| რას კითხულობს | დეტალები |
|---|---|
| გეომეტრია | ყოველი ელემენტი, რომელსაც აქვს ფორმა, შეფერილი ისე, როგორც ფაილშია. ოთახები და სივრცეები იხატება გამჭვირვალედ და თავიდან დამალულია |
| სართულები | შენობის სართულები სიმაღლის მიხედვით და ის, თუ რომელ სართულზეა თითო ელემენტი. ელემენტები სართულის გარეშე დაჯგუფდება როგორც „სართულზე არ არის“ |
| ელემენტების რაოდენობა | რამდენი ელემენტია თითო სახეობის (კედლები, კარები, ფილები…), ნაჩვენები {{ui:ელემენტები}}-ში |
| პროექტის მონაცემები | პროექტის სახელი, გრძელი სახელი და ფაზა; სქემა; ფაილის სათაურიდან ექსპორტის პროგრამა, ავტორი და ექსპორტის თარიღი |
| ელემენტის მონაცემები | სახელი, ტიპი, ობიექტის ტიპი, ტეგი, აღწერა, GlobalId; ყოველი თვისებების ნაკრები და რაოდენობრივი ნაკრები ელემენტზე და მის ტიპზე |

რედაქტირებადია: სახელი, ობიექტის ტიპი, ტეგი, აღწერა და ცალკეული თვისების მნიშვნელობები. ინახება როგორც ახალი IFC ფაილი. იხსნება IFC2X3, IFC4 და IFC4X3 სქემები, იკითხება BimCraft-ის საკუთარი IFC ძრავით; ყველაფერი, რის დახატვაც ჯერ არ შეუძლია, ჩამოთვლილია **ჯერ არ იხატება** სექციაში, {{ui:ფაილი}} პანელში. მოდელი გახსნისას გადააქვს სათავეში, ასე რომ შორს განთავსებული მოდელიც ეკრანის შუაში ჩანს. `.ifczip` და `.ifcxml` არ იხსნება.

## პროექტისა და ოჯახის ფაილები

`.rvt` პროექტები, `.rte` პროექტის შაბლონები, `.rfa` ოჯახები და `.rft` ოჯახის შაბლონები.

| რას კითხულობს | დეტალები |
|---|---|
| ფაილის ინფორმაცია | გამოშვება და აგება, ერთობლივი მუშაობა, ცენტრალური მოდელის გზა, ბოლო შენახვის გზა, მომხმარებლის სახელი, ლოკალი, დოკუმენტის GUID |
| პროექტის ინფორმაცია | პროექტის საკუთარი ველები (სახელი, ნომერი, კლიენტი, მისამართი, სტატუსი…), ახალი პროექტის ნაგულისხმევი მნიშვნელობების გარეშე |
| ოჯახის ინფორმაცია | ოჯახის სახელი, კატეგორია, გამოშვება, ბოლო განახლება და მისი პარამეტრები ჯგუფების მიხედვით |
| ბმულები | დაკავშირებული მოდელების, CAD ბმულების, სურათებისა და საკვანძო ცხრილების სია, რომელზეც ფაილი მიუთითებს |
| გადახედვის სურათი | ფაილში შენახული მინიატურა |

არ იკითხება: 3D მოდელი, ელემენტები, ხედები, ფურცლები და სპეციფიკაციები. ისინი შენახულია დოკუმენტირებული არმქონე ფორმატში. BimCraft ყოველი ფაილიდან კითხულობს მხოლოდ რამდენიმე ათეულ კილობაიტს, ამიტომ ფაილის ზომა თითქმის არ აქვს მნიშვნელობას.

## .pln, .pla, .tpl და .bpn პროექტის ფაილები

ჯერ არ იკითხება: BimCraft ამას გეტყვით, როცა მას გახსნით. ექსპორტი გააკეთეთ IFC-ად მოდელისთვის და DWG-ად ნახაზებისთვის; იხილეთ [.pln და .pla პროექტის ფაილების გახსნა](topic:pln-project-files).

## DWG და DXF

| რას კითხულობს | დეტალები |
|---|---|
| სივრცეები | მოდელის სივრცე და ყოველი ფურცელი (განლაგება), ჩანართების თანმიმდევრობით |
| ხედები | ყოველი ფურცლის ხედები თავისი მასშტაბით, ბრუნვით და გაყინული ფენებით |
| ფენები | სახელი, ფერი, ჩართვა/გამორთვა, გაყინვა, დაბეჭდვის ალამი და ხაზის სისქე |
| ობიექტები | ხაზები, პოლიხაზები, რკალები, წრეწირები, ელიფსები, სპლაინები, შტრიხები და მყარი სხეულები, ტექსტი და მრავალსტრიქონიანი ტექსტი, ბლოკები და ატრიბუტები, ზომები, გამომყვანები და მრავალგამომყვანები, ცხრილები, წერტილები, სურათები |
| დაკავშირებული ნახაზები | იხატება იქ, სადაც არის ჩასმული, როცა მათი ფაილები ნაპოვნია |
| სურათები | იხატება სურათის ფაილებიდან, როცა ნაპოვნია (PNG, JPEG, GIF, BMP, WebP; TIFF — არა) |
| მოწყობილობის ტეგები | საკვები ობიექტების ტეგები (`KCL-ITEM` ატრიბუტები), მოწყობილობების სპეციფიკაციისთვის |

ყველაფერი სხვა ითვლება **ჯერ არ იხატება**-ში და არასდროს გამოიცნობა. შემოწმებულია DWG ფორმატები AutoCAD 2000-დან 2018-მდე (R13 და R14 ფაილებიც მიიღება, მაგრამ ტესტურ ნაკრებში არ იყო; უფრო ძველი DWG-ები არ იხსნება); {{ui:ნახაზი}} პანელი აჩვენებს ფორმატის კოდს (მაგალითად AC1032). DXF ფაილები ყველა ვერსიისა იხსნება, R12-ის ჩათვლით. ორივეს კითხულობს BimCraft-ის საკუთარი წამკითხველი, ამ ჩანართში. არაფერი ინახება უკან DWG-ში ან DXF-ში.
