## რას გააკეთებთ

მიანიჭეთ კლასიფიკაციის კოდი კედლებს, იატაკებს, სახურავებს, კარებს, ფანჯრებსა და მოდელში არსებულ ყველაფერს, ერთდროულად სამ სისტემამდე: Uniclass, OmniClass და UniFormat. სხვა დისციპლინები და სხვა პროგრამები კოდს დაეყრდნობიან და არა სახელს, ამიტომ კოდები IFC ფაილში შეინახება, როგორც კლასიფიკაციის მითითებები, რომლებსაც ნებისმიერი BIM პროგრამა კითხულობს.

## ელემენტისთვის კოდის მინიჭება

1. აირჩიეთ ელემენტი (ან რამდენიმე) და გახსენით **თვისებები**. გახსენით {{ui:Classification}} განყოფილება.
2. ჩაწერეთ კოდი მისი სისტემის ველში და დააჭირეთ Enter. თუ კოდების სია ჩატვირთულია, ჩაწერეთ კოდის ნაწილი ან რამდენიმე სიტყვა ("ფარდის კედელი") და აირჩიეთ დამთხვევებიდან: კოდის სათაური თქვენთვის ავტომატურად შეივსება.
3. {{ui:Applies to}} მიუთითებს, სად მიდის კოდი: **ეს ელემენტი** ან **მისი ტიპი (ტიპის ყოველი ელემენტი)**. კედლის ტიპზე დაყენებულ კოდს კითხულობს ყოველი ამ ტიპის კედელი, მათ შორის შემდეგ დახაზულებიც.
4. {{ui:Clear}} კოდს აშორებს.

ყოველი კოდის ქვეშ განყოფილება მიუთითებს, საიდან მოდის: დაყენებულია ამ ელემენტზე, მისი ტიპიდან ან პროექტის ნაგულისხმევიდან მისი კლასისთვის. ელემენტის საკუთარი კოდი ყოველთვის სჯობს ტიპისას, ტიპის კოდი კი — ნაგულისხმევს. როცა რამდენიმე ელემენტია არჩეული და ველი წერს "იცვლება", ისინი ერთ კოდს არ იზიარებენ; ერთის ჩაწერა ყველას მიანიჭებს მას. ყოველი ცვლილება ერთი დაბრუნების ნაბიჯია.

კოდის ჩაწერა ყოველთვის შეიძლება, სია ჩატვირთულია თუ არა. თუ ის არ ჰგავს ამ სისტემის კოდს ან არ არის ჩატვირთულ სიაში, მინიშნება ამას ამბობს და კოდი ისე რჩება, როგორც ჩაწერეთ.

## პროექტის სისტემების არჩევა

გახსენით **Data** მოდელის ზოლში და აირჩიეთ {{ui:Classification}} (ან {{ui:Project classification…}} თვისებების განყოფილებაში).

- მონიშნეთ სისტემები, რომლებსაც ეს პროექტი იყენებს. თვისებებში მხოლოდ ისინი გამოჩნდება.
- **Uniclass**: Elements/ functions (EF), Systems (Ss) და Products (Pr) ცხრილები აპლიკაციასთან ერთად მოდის. მათი © NBS, ლიცენზირებულია Creative Commons Attribution-NoDerivatives 4.0-ით და გადაეცემა უცვლელად. დიალოგი აჩვენებს თითოეული ცხრილის გამოცემასა და იმ დღეს, როცა ის წაიკითხეს. ისინი უახლესი ცხრილები არ არის: გამომცემელი ყოველ კვარტალში გამოსცემს ახლებს თავის საიტზე.
- **OmniClass** და **UniFormat**: კოდების სია აპლიკაციასთან ერთად არ მოდის, რადგან მათი გამომცემელი ლიცენზიის გარეშე ცხრილების გადაცემას არ ნებართავს. ჩაწერეთ ნებისმიერი კოდი ან ჩატვირთეთ თქვენი ოფისის საკუთარი ლიცენზირებული ცხრილი.
- {{ui:Load a table (CSV)…}} კითხულობს თქვენი ოფისის ცხრილს CSV ფაილიდან, კოდის სვეტითა და სათაურის სვეტით (სათაურის რიგს, სახელწოდებით Code, Number ან Identifier და Title, Name ან Description, პროგრამა თავად პოულობს; მის გარეშე გამოიყენება პირველი ორი სვეტი). ცხრილი ამ ბრაუზერში რჩება და პროექტის ფაილში არასდროს ჩაიწერება. ფაილში ინახება მხოლოდ თქვენ მიერ მინიჭებული კოდები. Uniclass-ის უახლესი ცხრილიც ამავე გზით შეგიძლიათ ჩატვირთოთ.
- {{ui:Give elements a default code by their class}} ყოველ კედელს, იატაკს, სახურავს, კარს, ფანჯარას, კიბეს, პანდუსს, სვეტს, კოჭსა და ავეჯს აძლევს საწყის Uniclass კოდს Elements/ functions ცხრილიდან, თუ საკუთარი კოდი არ აქვს. შემდეგ დახაზული ელემენტებიც მიიღებენ.
- {{ui:Show the codes as columns in the schedules}} ამატებს ერთ სვეტს თითო სისტემაზე კარების, ფანჯრების, კედლები ტიპის მიხედვით და ოთახების სპეციფიკაციებში და მათ CSV-ში. რიგი, რომელშიც რამდენიმე ელემენტია, აჩვენებს "იცვლება"-ს, თუ მათი კოდები განსხვავდება.

## კარგი იცოდეთ

- ნაგულისხმევი კოდები CadCraft-ის საკუთარი საწყისი არჩევანია და არა გამომცემლისა; ისინი პრაქტიკოსს არ შეუმოწმებია. შეამოწმეთ ისინი თქვენი პროექტის სტანდარტით.
- ფაილში ნაგულისხმევი კოდი რეალური კლასიფიკაციაა, მონიშნულია ურთიერთობის სახელით "CadCraft default", და ქრება, როგორც კი ელემენტს ან მის ტიპს საკუთარი კოდი მიენიჭება.
- კოდები, რომლებიც უკვე აქვს იმპორტირებულ ფაილს, იკითხება და ჩანს, მიუხედავად იმისა, როგორ წერდა სისტემის სახელს სხვა პროგრამა. სხვა სისტემების კოდები (ოფისის საკუთარი) ჩამოთვლილია და ხელუხლებელი რჩება.
- კოდები ფაილის ხელახლა გახსნისას იკითხება, აქ თუ სხვა პროგრამაში. ისინი ასევე გადადის IFC5 alpha (IFCX) ექსპორტში, როცა ეს ლაბორატორიული პარამეტრი ჩართულია, გარდა სახურავზე დაყენებული კოდისა.
- ჯერ არ არის გაკეთებული: ხის სტრუქტურა, რომლითაც ცხრილი დონეების მიხედვით დაითვალიერება, კოდები დონეებსა და ოთახებზე პროექტის ნაგულისხმევად, და კოდის შემოწმება ფაილში დასახელებულ გამოცემასთან.
