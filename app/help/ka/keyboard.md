BimCraft-ს ცოტა მალსახმობი აქვს. ყველაზე მეტი სამუშაო მაუსითა და პანელებით კეთდება. მალსახმობები, რომლებიც {{key:Mod}}-ით არის ჩაწერილი, Mac-ზე იყენებს Command-ს, სხვაგან კი Ctrl-ს. იხილეთ [კლავიშები, მაუსი და სენსორული პანელი](common:keys), რომ ნახოთ, როგორ არის კლავიშები ამ დახმარებაში ჩაწერილი.

## ყველგან

| კლავიში | რას აკეთებს |
|---|---|
| {{key:Ctrl+Shift+F}} | ეკრანის რეჟიმების გადართვა: ჩვეულებრივი, მთელ ეკრანზე, მთელ ეკრანზე პანელების დამალვით. Ctrl ყველა პლატფორმაზეა, Mac-ის ჩათვლით |
| {{key:Esc}} | მთელი ეკრანიდან გამოსვლა |
| {{key:Mod+,}} | {{ui:Settings}}-ის გახსნა. იხილეთ [BimCraft-ის პარამეტრები](topic:settings) |
| {{key:Tab}} | ღილაკებს, ველებსა და მნიშვნელობებს შორის გადაადგილება. ყველა მართვის ელემენტი კლავიატურიდან მიიწვდება |

კლავიშები {{ui:Top}}, {{ui:Front}} და {{ui:Side}}-სთვის არ არსებობს; გამოიყენეთ ღილაკები.

## რედაქტირება

იგივე ბრძანებები არის ხელსაწყოთა პანელზე: {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}} და {{ui:More}} მენიუ, რომელიც თითოეულ კლავიშს აჩვენებს. ისინი მუშაობს IFC მოდელის 3D ხედში, არა მაშინ, როცა ველში წერთ. იხილეთ [ბიბლიოთეკის ელემენტების კოპირება, ჩასმა და დუბლირება](topic:copy-paste).

| კლავიში | რას აკეთებს |
|---|---|
| {{key:Mod+Z}} | ბოლო ცვლილების გაუქმება |
| {{key:Mod+Y}} ან {{key:Mod+Shift+Z}} | გაუქმებულის დაბრუნება |
| {{key:Mod+C}} | არჩეული ელემენტების კოპირება (მათი სახელები და თვისებები ასევე გადავა ბუფერში ტექსტად) |
| {{key:Mod+X}} | არჩეული ელემენტების ამოჭრა: კოპირება და შემდეგ წაშლა |
| {{key:Mod+V}} | კოპირებულის ჩასმა: მიჰყვება მაჩვენებელს, დააწკაპუნეთ, სადაც უნდა მოხვდეს |
| {{key:Mod+Shift+V}} | ჩასმა ადგილზე: სადაც ამოჭრა მოხდა, ან ორიგინალების გვერდით კოპირების შემდეგ |
| {{key:Mod+D}} | დუბლირება: არჩეული ელემენტების კოპირება და მათი ჩასმის დაწყება |
| {{key:Delete}} | არჩეული ელემენტების წაშლა, მათი ნაწილებითა და ღიობებით. იხილეთ [შენობის ელემენტების წაშლა, ამოჭრა, კოპირება და ჩასმა](topic:edit-elements) |
| {{key:Mod+A}} | ყველა ნაჩვენები ელემენტის არჩევა |
| {{key:Esc}} | არაფრის არჩევა |

როცა გვერდზე ტექსტია არჩეული, {{key:Mod+C}} ტექსტს ჩვეულებრივად აკოპირებს.
