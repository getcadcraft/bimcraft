## რას გააკეთებთ

გაარკვიეთ, რა არის პროექტის ან ოჯახის ფაილში Revit-ში გახსნის გარეშე: რომელმა გამოშვებამ შეინახა, გაზიარებულია თუ არა, პროექტის ინფორმაცია და რას უკავშირდება. სასარგებლოა, როცა ფაილი სხვისგან მოდის და უნდა იცოდეთ, რომელ გამოშვებაში გახსნათ.

## ნაბიჯები

1. დააწკაპუნეთ {{ui:Choose a file}}-ზე.
2. აირჩიეთ `.rvt`, `.rfa`, `.rte` ან `.rft` ფაილი.
3. მოიცადეთ. სტატუსის ხაზი წერს „ფაილი იკითხება…“, შემდეგ კი „გაიხსნა *ფაილის სახელი*“.
4. შეხედეთ ბარათის ზედა ნაწილს: ფაილში შენახულ გადახედვის სურათს, ფაილის ტიპსა და გამოშვებას, რომელშიც ის შეინახეს, და პროექტის სახელს.
5. ჩამოაგორეთ ქვემოთ და წაიკითხეთ ბარათის განყოფილებები.

## რას უნდა ხედავდეთ

ბარათი შუაში, იმ განყოფილებებით, რომლებიც ფაილს აქვს:

| განყოფილება | რას გეუბნებათ |
|---|---|
| File | ფაილის სახელი, ზომა, ტიპი (პროექტი, პროექტის შაბლონი, ოჯახი ან ოჯახის შაბლონი), გამოშვება და build, რომელშიც შეინახა, გაზიარებული მუშაობა, ცენტრალური მოდელის გზა, სად და ვინ იხილა ბოლოს შენახული, ენა (locale) და დოკუმენტის GUID |
| Project information | პროექტის საკუთარი ველები, როგორიცაა სახელი, ნომერი, დამკვეთი, მისამართი და სტატუსი. ველები, რომლებიც ახალი პროექტის ნაგულისხმევ მნიშვნელობაზეა, გამოტოვებულია. |
| Family, Family: … | ოჯახისთვის: მისი სახელი, კატეგორია, გამოშვება, ბოლო განახლება და მისი პარამეტრები, ჯგუფ-ჯგუფად |
| Linked and referenced files | ყველა დაკავშირებული მოდელი, CAD კავშირი, სურათი და საკვანძო ცხრილი, რომელზეც ფაილი მიუთითებს, მისი შენახული გზით |

მარცხნივ {{ui:File}} პანელი იმეორებს ძირითად ცნობებს და ამატებს **წაკითხულს**: რამდენი წაიკითხა BimCraft-მა ფაილიდან, ჩვეულებრივ დაახლოებით 40 KB იმ ფაილიდან, რომელიც მრავალი მეგაბაიტია. მარჯვნივ {{ui:Properties}} პანელი ამბობს, რომ ელემენტის თვისებებს 3D მოდელი სჭირდება.

## რატომ არ არის 3D

3D მოდელი და ელემენტები პროექტის ფაილში დაუდოკუმენტირებელ ფორმატში ინახება. BimCraft კითხულობს მხოლოდ იმ ნაწილებს, რომლებიც დოკუმენტირებულია ან მკაფიოდ იკითხება: ფაილის ინფორმაცია, პროექტის ინფორმაცია, ოჯახის მონაცემები, კავშირების სია და გადახედვის სურათი. ის დანარჩენს არ ვარაუდობს. მოდელის 3D-ში ნახვისა და ელემენტების თვისებების წასაკითხად გაიტანეთ IFC იმ პროგრამიდან, რომელშიც ფაილი შეიქმნა. იხილეთ [პროექტის ფაილის 3D-ში IFC-ით შემოტანა](topic:rvt-to-ifc).

## ხშირი შეცდომები

- **3D-ის მოლოდინი.** იხილეთ ზემოთ.
- **კავშირები მხოლოდ შენახულ გზას აჩვენებს.** ცალკე გახსნილი ფაილი ვერ ამოწმებს, არსებობს თუ არა მისი კავშირები. ამის ნაცვლად გახსენით საქაღალდე, სადაც ის მდებარეობს, და BimCraft თითოეულ კავშირს მონიშნავს როგორც ნაპოვნს ან არა-ნაპოვნს: [პროექტის მთელი საქაღალდის გახსნა](topic:open-project-folder).
- **„This file is incomplete…“** ფაილი კოპირების, ატვირთვის ან სინქრონიზაციის დროს იყო შეწყვეტილი. ღრუბლის დისკზე ფაილი, რომელიც ჯერ კიდევ მხოლოდ „ონლაინ“-ია, ასევე ასე იქცევა. BimCraft მაინც ხსნის მას და აჩვენებს მხოლოდ აღდგენილს: ბარათის ზედა ნაწილში ქარვისფერ შეტყობინებას, განყოფილებას **აღდგენილია ამ ფაილიდან**, რომელიც ჩამოთვლის იმ ნაწილებს, რომელთა ყველა ბაიტი ფაილშია, და **ფაილში არ არის** დანარჩენისთვის. გამოტოვებულ ნაწილს არაფერი ევსება, ასე რომ გამოშვება, გადახედვის სურათი ან პროექტის ინფორმაცია შეიძლება აკლდეს, თუ ისინი შეწყვეტის შემდეგ იყო შენახული. თუ ფაილის შინაარსის სიაც კი იყო შეწყვეტილი, ვერაფერს ვერ გახსნით. ხელახლა დააკოპირეთ ორიგინალი და გახსენით სრული ფაილისთვის.
- **„ამ ფაილში გადახედვის სურათი არ არის“.** ზოგი ფაილი ისე შეინახება, რომ გადახედვის სურათი არ აქვს. ეს ნორმალურია.
- **სარეზერვო ასლის შემთხვევით გახსნა.** ფაილები, სახელად `Tower.0004.rvt`-ის მსგავსი, ნომრიანი სარეზერვო ასლებია. საქაღალდის გახსნისას ისინი თავიანთ მოდელთან ჯგუფდება.
