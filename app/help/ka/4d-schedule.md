## რას გააკეთებთ

უყურებთ, როგორ იზრდება შენობა: გრაფიკის ყოველი დავალება დაკავშირებულია იმ ელემენტებთან, რომელთაც ის აშენებს, და ნაჩვენებია დღეების მიხედვით.

## ნაბიჯები

1. გახსენით IFC მოდელი და მარცხენა პანელში გახსენით {{ui:4D გრაფიკი}}.
2. დააწკაპუნეთ {{ui:შაბლონის ჩამოტვირთვა}}-ზე — დავალებების სია ერთი კვირით სართულზე; შეცვალეთ ის ცხრილში. ან დაწერეთ საკუთარი.
3. დააწკაპუნეთ {{ui:დავალებების სიის გახსნა…}}-ზე და აირჩიეთ CSV.
4. გადაიტანეთ თარიღის სლაიდერი ან დააწკაპუნეთ {{ui:გაშვება}}-ზე.

## დავალებების სია

CSV ფაილი სათაურის მწკრივით და სვეტებით **Task**, **Start**, **Finish**, **Field** და **Value**. მძიმეები ან წერტილ-მძიმეები ორივე მუშაობს.

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| Level 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| Roof | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| Roof | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- თარიღები წერეთ როგორც YYYY-MM-DD.
- მწკრივი აკავშირებს დავალებას ყველა ელემენტთან, რომლის **Field**-ს ზუსტად ეს **Value** აქვს. ველი არის თვისება, მაგალითად Storey, Class, Name, Type, Material, Tag ან GlobalId, ან ნებისმიერი თვისება თავისი ნაკრებისა და სახელის მიხედვით: `Pset_WallCommon.FireRating`.
- გაიმეორეთ დავალება რამდენიმე მწკრივზე, იმავე თარიღებით, რომ მასთან მეტი ელემენტი დააკავშიროთ.

## ეტაპები და სამუშაო პაკეტები

დაამატეთ სვეტი **Stage**, სვეტი **Package** ან ორივე, რომ დავალებები დააჯგუფოთ ეტაპებად და სამუშაო პაკეტებად. Phase და WBS სვეტების სახელებად ასევე მუშაობს.

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| Level 1 slab | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| Level 1 walls | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| Doors | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- დავალება ერთ ეტაპს და ერთ პაკეტს ეკუთვნის. თუ იმავე დავალების მომდევნო მწკრივი სხვას ასახელებს, ის მწკრივი თავისი ხაზის ნომრით ჩამოითვლება და გამოტოვდება.
- ერთი და იგივე პაკეტის სახელი ორ ეტაპში ორ სხვადასხვა პაკეტს ნიშნავს.

როცა სიას ჯგუფები აქვს, თარიღის ზემოთ გამოჩნდება {{ui:ჩვენება}}-ს სია. აირჩიეთ ეტაპი ან პაკეტი და ის ერთ მთლიანობად გაეშვება:

- სლაიდერი და {{ui:გაშვება}} მუშაობს ჯგუფის პირველი დაწყებიდან მის ბოლო დასრულებამდე;
- ჩანს და იხატება მხოლოდ ჯგუფის დავალებები, ყველაფერი დანარჩენი გამჭვირვალეა;
- სიის ქვემოთ ხაზი ამბობს, რამდენი დავალებაა შესრულებული, მიმდინარე და მომავალში იმ თარიღისთვის;
- {{ui:მისი ელემენტების არჩევა}} ირჩევს ჯგუფის ყველა ელემენტს {{ui:ჩვენება}}-სთვის, {{ui:კვეთა}}-სთვის ან სპეციფიკაციისთვის.

აირჩიეთ **ყველა დავალება**, რომ კვლავ ნახოთ მთელი გრაფიკი.

## რას უნდა ნახოთ

- **აშენებული**: ელემენტები, რომელთა ყველა დავალება დასრულებულია, საკუთარი ფერებით.
- **მიმდინარე**: ელემენტები, რომელთანაც იმ დღეს დავალება მიმდინარეობს, ოხრისფერად. დავალება მიმდინარეობს დაწყების თარიღიდან დასრულების თარიღამდე.
- **არ დაწყებული**: გამჭვირვალე.
- ელემენტები, რომლებიც არცერთ დავალებაში არ შედის, რჩება, როგორც არის. სია აჩვენებს, რამდენი ელემენტი იპოვა თითოეულმა დავალებამ. მწკრივები, რომლებიც ვერ ამოიკითხა ან ვერაფერი იპოვა, თავიანთი ხაზის ნომრებით ჩამოითვლება.

## კავშირები, განტის დიაგრამა და MS Project

- გახსენით Microsoft Project XML ფაილი (`.xml`) ან CSV, რომელსაც აქვს სვეტი `Predecessors`. კავშირები შეიძლება იყოს დასრულება-დაწყება, დაწყება-დაწყება, დასრულება-დასრულება ან დაწყება-დასრულება, თითოეული დღეებში წინსვლით ან შეფერხებით.
- დავალებების სიის ქვეშ განტის დიაგრამა ყველა დავალებას ზოლად ხატავს, კავშირებს კი ისრებით. კრიტიკული გზის დავალებები წითელია. კავშირების ციკლი ან არარსებული წინამორბედი პანელში ჩამოითვლება.
- {{ui:Save as MS Project XML}} და {{ui:Save CSV with links}} გრაფიკს კავშირებით წერს უკან.
