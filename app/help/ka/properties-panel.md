## IFC ელემენტი

{{ui:Properties}} პანელის ზედა ნაწილი აჩვენებს ელემენტის სახეობას „Ifc“ პრეფიქსის გარეშე (მაგალითად, „Door“, „WallStandardCase“, „FurnishingElement“) და მის სახელს, ან „უსახელო“-ს.

| ველი | მნიშვნელობა | რედაქტირებადია |
|---|---|---|
| Name | ელემენტის სახელი, ხშირად ექსპორტერიდან წამოსული ოჯახისა და ტიპის სახელი | დიახ |
| Type | ელემენტის ტიპის სახელი, თუ მას აქვს | არა |
| Object type | თავისუფალი ტექსტური ტიპის აღწერა, რომელსაც ზოგი ექსპორტერი ავსებს | დიახ |
| Tag | ელემენტის ტეგი ან მარკა; ბევრი ექსპორტერი აქ ელემენტის ID-ს წერს | დიახ |
| Description | თავისუფალი ტექსტი | დიახ |
| GlobalId | ელემენტის მუდმივი 22-სიმბოლოიანი IFC იდენტიფიკატორი, იგივე ყველა ექსპორტში იმავე ელემენტისთვის | არა |
| Line | ელემენტის ხაზის ნომერი (`#1234`) ამ IFC ფაილში. იცვლება ექსპორტებს შორის | არა |

ქვემოთ მოდის **თვისებათა ნაკრებები**, სახელის მიხედვით დალაგებული:

- თითოეული ნაკრები იხსნება და იხურება, როცა დააწკაპუნებთ მის სახელზე. პირველი სამი ღიაა.
- ნაკრები, რომელსაც მონიშნავს „(type)“, ელემენტის ტიპს ეკუთვნის: „ტიპის თვისება: აქ შეტანილი ცვლილება ამ ტიპის ყველა ელემენტს შეეხება.“
- რაოდენობრივი ნაკრებები (სიგრძეები, ფართობები, მოცულობები, რაოდენობები, წონები) მხოლოდ საკითხავია.
- სიები და ჩამონათვალის მნიშვნელობები ნაჩვენებია, მხოლოდ საკითხავად.
- დიახ/არა მნიშვნელობები ჩანს როგორც **დიახ** ან **არა**.
- რიცხვები ჩვენებისთვის ოთხ ათწილადამდეა დამრგვალებული. სიგრძეები (სიგრძის თვისება ან რაოდენობის სიგრძე) ჩანს ხელსაწყოთა პანელში არჩეულ {{ui:Units}}-ში, გვერდით ერთეულით, და შეგიძლიათ ჩაწეროთ ახალი ამ ერთეულში ან სხვა ერთეულის აღნიშვნით (2.4 m, 8'-0"): BimCraft ფაილის საკუთარ რიცხვს უკან წერს. სხვა რიცხვები ფაილში არსებულის მიხედვით ჩანს.
- ცარიელი მნიშვნელობა ჩანს როგორც *ცარიელი*. შეცვლილი მნიშვნელობა მუქი შრიფტით ჩანს და მის გვერდით ლურჯი ზოლია.

## მნიშვნელობის კოპირება

{{ui:Properties}}-ის ყველა მნიშვნელობას გვერდით აქვს პატარა კოპირების ღილაკი: დააწკაპუნეთ მასზე, რომ ის ზუსტად ისე, როგორც ნაჩვენებია, გაცვლის ბუფერში მოათავსოთ, მაგალითად GlobalId, სერიული ნომერი ან თვისებათა ნაკრების ნებისმიერი მნიშვნელობა. კოპირება არასდროს იწყებს რედაქტირებას.

ზედა ნაწილში {{ui:Copy all}} აკოპირებს ელემენტის ყველა მნიშვნელობას ტექსტად, ნაკრებ-ნაკრებად, ხოლო {{ui:Copy as CSV}} აკოპირებს მათ ჯგუფის, თვისებისა და მნიშვნელობის სტრიქონებად, ცხრილში ჩასასმელად; ცარიელი მნიშვნელობებიც შენარჩუნებულია, რომ ყველა ველს ჰქონდეს სტრიქონი. ეს იგივენაირად მუშაობს სხვა ღია მოდელის ელემენტისთვისაც; როცა ერთზე მეტი მოდელია ღია, CSV იწყება სვეტით „მოდელი“, რომელშიც ფაილის სახელია.

| Schema | IFC ვერსია, მაგალითად IFC2X3 ან IFC4 |

| Phase | პროექტის ფაზა, თუ ექსპორტერმა ჩაწერა |
| Exported from | ექსპორტის პროგრამა, ფაილის სათაურიდან |
| Author | ავტორი ფაილის სათაურიდან |
| Exported | თარიღი და დრო ფაილის სათაურიდან |
| Elements | რამდენი ფორმის მქონე ელემენტი იქნა დახატული |
| Triangles | რამდენი სამკუთხედია მათი ფორმები; მოდელის სიმძიმის საზომი |
