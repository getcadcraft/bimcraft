## ສິ່ງທີ່ທ່ານຈະເຮັດ

ນຳໂປຣເຈັກທີ່ບັນທຶກເປັນ `.pln` (ໂປຣເຈັກ), `.pla` (ໄຟລ໌ເກັບຖາວອນພ້ອມຄັງ), `.tpl` (ແມ່ແບບ) ຫຼື `.bpn` (ສຳຮອງຂໍ້ມູນ) ເຂົ້າ BimCraft. ນີ້ແມ່ນໄຟລ໌ຂອງ Archicad ເອງ.

## ສິ່ງທີ່ເປີດໄດ້ໃນປັດຈຸບັນ

- **ໄຟລ໌ໂປຣເຈັກເອງຍັງເປີດບໍ່ໄດ້.** ຮູບແບບຂອງມັນບໍ່ໄດ້ເຜີຍແຜ່, ແລະ BimCraft ຍັງບໍ່ອ່ານມັນ. ເມື່ອທ່ານເປີດໄຟລ໌, BimCraft ຈະບອກແລະຊີ້ມາບ່ອນນີ້.
- **BimCraft ກວດ bytes ທຳອິດຂອງໄຟລ໌.** ໂປຣເຈັກ Archicad ຕັ້ງແຕ່ເວີຊັນ 17 ຂຶ້ນໄປເລີ່ມດ້ວຍລາຍເຊັນສັ້ນແບບດຽວກັນ ດັ່ງນັ້ນ BimCraft ສາມາດບອກທ່ານໄດ້ແນ່ນອນວ່າໄຟລ໌ເປັນໂປຣເຈັກ Archicad. ໄຟລ໌ທີ່ມີຊື່ Archicad ແຕ່ບໍ່ເລີ່ມແບບນັ້ນ ອາດຖືກປ່ຽນຊື່, ເສຍຫາຍ ຫຼື ມາຈາກເວີຊັນເກົ່າ. ລາຍເຊັນບໍ່ສາມາດແຍກໂປຣເຈັກ, ໄຟລ໌ເກັບຖາວອນ ແລະ ແມ່ແບບອອກຈາກກັນໄດ້.
- **ໄຟລ໌ສົ່ງອອກ IFC ເປີດໄດ້ຄົບ**: ໂມເດວໃນ 3D, ຊັ້ນ, ເຂດເປັນພື້ນທີ່, ຂໍ້ມູນອົງປະກອບ, ຊຸດຄຸນສົມບັດ ແລະ ການຈັດປະເພດ ພ້ອມເຄື່ອງມື BimCraft ທຸກຢ່າງ.
- **ໄຟລ໌ສົ່ງອອກ DWG ເປີດໄດ້** ໃນມຸມມອງ 2D ພ້ອມເລເຢີ ແລະ ແບບຈັດວາງ, ແລະ ໃນ {{ui:3D}}. ເພື່ອແກ້ໄຂ, ໃຫ້ໃຊ້ {{ui:ແກ້ໄຂໃນ CadCraft}}.

ຫຼື ນຳທັງໂປຣເຈັກເຂົ້າເປັນ zip ດຽວ ພ້ອມມຸມມອງ, ແບບຈັດວາງ ແລະ ກຸ່ມຄຸນສົມບັດ: ເບິ່ງ [ເປີດແພັກເກດໂປຣເຈັກ](topic:open-project-bundle).

## ສົ່ງອອກ IFC (ໂມເດວ)

1. ເປີດໂປຣເຈັກໃນ Archicad.
2. ເລືອກ **File > Save As**, ແລ້ວເລືອກ **IFC** ເປັນປະເພດໄຟລ໌.
3. ເລືອກຕົວແປງ IFC (ຊື່ຂອງ Archicad ສຳລັບຊຸດການຕັ້ງຄ່າການສົ່ງອອກ IFC). **IFC4 Reference View** ຫຼື **IFC2X3 Coordination View 2.0** ເໝາະກັບ BimCraft. IFC4X3 ກໍເປີດໄດ້ເຊັ່ນກັນ.
4. ເລືອກສິ່ງທີ່ຈະສົ່ງອອກ: ທັງໂປຣເຈັກ ຫຼື ສະເພາະອົງປະກອບທີ່ເຫັນຢູ່ໃນຊັ້ນທີ່ທ່ານກຳລັງເບິ່ງ.
5. ບັນທຶກ, ແລ້ວກົດ {{ui:Choose a file}} ໃນ BimCraft ແລະ ເລືອກໄຟລ໌ `.ifc`.

ກວດສອບສິ່ງເຫຼົ່ານີ້ໃນການຕັ້ງຄ່າຂອງຕົວແປງກ່ອນສົ່ງອອກ:

- **ເຂດ**: ສົ່ງອອກພວກມັນ ເພື່ອໃຫ້ຫ້ອງເຂົ້າມາເປັນພື້ນທີ່. ກົດ {{ui:Spaces}} ໃນ BimCraft ເພື່ອເບິ່ງພວກມັນ.
- **ຄຸນສົມບັດ ແລະ ການຈັດປະເພດ**: ສົ່ງອອກພວກມັນ ເພື່ອໃຫ້ສະແດງໃນ {{ui:Properties}} ແລະ ນຳໃຊ້ໃນ {{ui:Find}}, {{ui:Color}} ແລະ {{ui:Quantity totals}} ໄດ້.
- **`.ifc` ທຳມະດາ**, ບໍ່ແມ່ນ `.ifczip` ຫຼື `.ifcxml`. BimCraft ເປີດໄດ້ສະເພາະ `.ifc` ທຳມະດາ.

## ສົ່ງອອກ DWG (ແບບແຕ້ມ)

1. ເປີດແຜນ, ໜ້າຕັດ ຫຼື ແບບຈັດວາງທີ່ທ່ານຕ້ອງການ.
2. ເລືອກ **File > Save As**, ແລ້ວເລືອກ **DWG** ເປັນປະເພດໄຟລ໌.
3. ເລືອກຕົວແປງ DXF-DWG ແລ້ວບັນທຶກ.
4. ສຳລັບຊຸດແຜ່ນທັງໝົດ, ບັນທຶກແບບຈັດວາງຈາກ Layout Book ຫຼື ເຜີຍແຜ່ເປັນ DWG.
5. ເປີດ `.dwg` ໃນ BimCraft. ແບບແຕ້ມທີ່ເຊື່ອມໂດຍການສົ່ງອອກຈະເປີດພ້ອມກັນເມື່ອຢູ່ໃນໂຟນເດີດຽວກັນ; ເບິ່ງ [ແບບແຕ້ມ ແລະ ຮູບທີ່ເຊື່ອມ](topic:dwg-linked-files).

## ການແກ້ໄຂບັນຫາ

- **"… ເປັນໂປຣເຈັກ Archicad: bytes ທຳອິດຂອງມັນບອກແບບນັ້ນ."** ສົ່ງອອກ IFC ຫຼື DWG ຕາມຂ້າງເທິງ ແລ້ວເປີດໄຟລ໌ນັ້ນ.
- **"… ຖືກຕັ້ງຊື່ຄືໄຟລ໌ Archicad ແຕ່ບໍ່ເລີ່ມຄືແບບນັ້ນ."** ກວດເບິ່ງວ່າໄຟລ໌ມາຈາກໃສ: ອາດເປັນໄຟລ໌ປະເພດອື່ນທີ່ປ່ຽນຊື່ໃໝ່ (ລອງເປີດດ້ວຍນາມສະກຸນຈິງ), ສຳເນົາທີ່ບໍ່ສຳເລັດ, ຫຼື ໂປຣເຈັກຈາກກ່ອນເວີຊັນ 17. ຖ້າເປັນໄປໄດ້ ໃຫ້ເປີດໃນ Archicad ແລ້ວສົ່ງອອກ IFC ຫຼື DWG.
- **ໂມເດວເປີດໂດຍບໍ່ມີຫ້ອງ.** ເຂດບໍ່ໄດ້ຖືກສົ່ງອອກ. ເປີດມັນໃນຕົວແປງ IFC ແລ້ວສົ່ງອອກອີກຄັ້ງ.
- **ຊ່ອງເປີດບໍ່ຖືກຕັດ.** BimCraft ບອກໃນ **ຍັງບໍ່ໄດ້ແຕ້ມ** ໃນແຜງ {{ui:File}}. ສົ່ງອອກອີກຄັ້ງ; ຖ້າຍັງເປັນແບບນັ້ນ ໃຫ້ເປີດໂມເດວໃນໂປຣແກຣມທີ່ສ້າງມັນ ແລ້ວກວດເບິ່ງຊ່ອງເປີດຢູ່ບ່ອນນັ້ນ.
- **ຕົວໜັງສືໃນ DWG ເບິ່ງຕ່າງກັນ.** ການສົ່ງອອກອາດເກັບຟອນຕ໌ທີ່ BimCraft ບໍ່ມີ; BimCraft ແຕ້ມຕົວໜັງສືດ້ວຍຟອນ sans-serif ທຳມະດາ.
