## ສິ່ງທີ່ທ່ານຈະເຮັດ

ແກ້ຂໍ້ມູນທີ່ບໍ່ຖືກຕ້ອງໃນແບບ IFC: ປ່ຽນຊື່ອົງປະກອບ, ແກ້ແທັກຂອງມັນ, ປ່ຽນຄ່າຄຸນສົມບັດ. ຈາກນັ້ນບັນທຶກໄຟລ໌ IFC ໃໝ່ພ້ອມການປ່ຽນແປງຂອງທ່ານ. ໄຟລ໌ທີ່ທ່ານເປີດຈະບໍ່ຖືກແຕະຕ້ອງເລີຍ.

## ສິ່ງທີ່ທ່ານສາມາດປ່ຽນໄດ້

| ຊ່ອງ | ແກ້ໄດ້ |
|---|---|
| ຊື່, ປະເພດວັດຖຸ, ແທັກ, ຄຳອະທິບາຍ | ໄດ້ |
| ຄ່າຄຸນສົມບັດດຽວ (ຂໍ້ຄວາມ, ຕົວເລກ, ແມ່ນ/ບໍ່ແມ່ນ) | ໄດ້ |
| ຊຸດຄຸນສົມບັດປະເພດ (ຊຸດທີ່ໝາຍ "(type)") | ໄດ້, ແລະ ການປ່ຽນແປງໃຊ້ກັບທຸກອົງປະກອບຂອງປະເພດນັ້ນ |
| ປະເພດ, GlobalId, ແຖວ | ບໍ່ໄດ້ |
| ປະລິມານ (ຄວາມຍາວ, ເນື້ອທີ່, ບໍລິມາດ, ຈຳນວນ) | ບໍ່ໄດ້ |
| ລາຍການ, ການແຈກແຈງ ແລະ ຄ່າຫຼາຍສ່ວນອື່ນ | ບໍ່ໄດ້ |
| ເລຂາຄະນິດ, ຕຳແໜ່ງ, ການເພີ່ມ ຫຼື ລຶບອົງປະກອບ | ບໍ່ໄດ້ |

## ຂັ້ນຕອນ

1. ເປີດແບບ IFC ແລ້ວຄລິກອົງປະກອບທີ່ທ່ານຕ້ອງການປ່ຽນ.
2. ໃນແຜງ {{ui:Properties}}, ຄລິກຄ່າທີ່ທ່ານຕ້ອງການປ່ຽນ. ມັນກາຍເປັນກ່ອງຂໍ້ຄວາມ. ຄ່າຫວ່າງສະແດງເປັນ *ຫວ່າງ*.
3. ພິມຄ່າໃໝ່.
4. ກົດ {{key:Enter}}, ຫຼື ຄລິກບ່ອນອື່ນ, ເພື່ອຮັກສາມັນ. ກົດ {{key:Esc}} ເພື່ອຍົກເລີກ.
5. ເບິ່ງຄ່າ: ຕອນນີ້ມັນເປັນຕົວໜາພ້ອມແຖບສີຟ້າຢູ່ຂ້າງ, ເຊິ່ງໝາຍເຖິງຄ່າທີ່ຖືກແກ້ໄຂ.
6. ເບິ່ງສ່ວນ {{ui:Changes}} ທາງຊ້າຍ: ການປ່ຽນແປງຖືກລາຍຊື່ເປັນ *ອົງປະກອບ*: *ຊ່ອງ*, ຄ່າເກົ່າ ເປັນ ຄ່າໃໝ່.
7. ເຮັດຊ້ຳສຳລັບຄ່າອື່ນ ຫຼື ອົງປະກອບອື່ນ.
8. ຄລິກ {{ui:Save as IFC}} (ມັນສະແດງຈຳນວນການປ່ຽນແປງທີ່ລໍຖ້າຢູ່, ຕົວຢ່າງ "Save as IFC (3)"), ຫຼື ກົດ {{key:Mod+S}}.
9. ຊອກ "*ຊື່ເດີມ* (edited).ifc" ໃນໂຟນເດີດາວໂຫຼດຂອງທ່ານ.

## ສິ່ງທີ່ທ່ານຄວນເຫັນ

ແຖບສະຖານະບອກວ່າ "ບັນທຶກ *name* (edited).ifc ດ້ວຍການປ່ຽນແປງ *n* ຄັ້ງ (… bytes). ໄຟລ໌ເດີມຂອງທ່ານບໍ່ປ່ຽນ." ລາຍການ {{ui:Changes}} ຫວ່າງເປົ່າ, ພ້ອມສຳລັບຮອບຕໍ່ໄປ.

## ປະເພດຄ່າ

- **ຂໍ້ຄວາມ**: ສິ່ງໃດທີ່ທ່ານພິມຈະຖືກເກັບໄວ້ຕາມທີ່ເປັນ. ການລຶບ ຊື່, ປະເພດວັດຖຸ, ແທັກ ຫຼື ຄຳອະທິບາຍ ຈະເອົາຄ່ານັ້ນອອກ.
- **ຕົວເລກ**: ພິມຕົວເລກທຳມະດາ, ເຊັ່ນ `2.4` ຫຼື `1200`, ໃນໜ່ວຍຂອງໄຟລ໌ເອງ. ບໍ່ມີສັນຍາລັກໜ່ວຍ. ອັນອື່ນຈະສະແດງ "ໃຊ້ຕົວເລກ."
- **ຈຳນວນເຕັມ** (ການນັບ, ຈຳນວນເຕັມ): "ໃຊ້ຈຳນວນເຕັມ." ຖ້າທ່ານພິມທົດສະນິຍົມ.
- **ແມ່ນ/ບໍ່ແມ່ນ**: ຄ່າກາຍເປັນເມນູທີ່ມີແມ່ນ ແລະ ບໍ່ແມ່ນ.

ແຕ່ລະຄ່າຮັກສາປະເພດ IFC ຂອງມັນ, ດັ່ງນັ້ນຕົວເລກຍັງເປັນຕົວເລກ ແລະ ໂປຣແກຣມອື່ນອ່ານມັນຖືກຕ້ອງ.

## ຍ້ອນກັບ

1. ຄລິກ {{ui:Undo}} ໃນສ່ວນ {{ui:Changes}}, ຫຼື ກົດ {{key:Mod+Z}} ໃນຂະນະທີ່ທ່ານບໍ່ໄດ້ພິມໃນຊ່ອງ.
2. ເຮັດຊ້ຳເພື່ອຍ້ອນກັບເພີ່ມເຕີມ. ແຕ່ລະການຍ້ອນກັບເອົາການປ່ຽນແປງໃໝ່ສຸດອອກ.

ທ່ານບໍ່ສາມາດຍ້ອນກັບຜ່ານການບັນທຶກໄດ້: ຫຼັງຈາກບັນທຶກແລ້ວ ລາຍການເລີ່ມໃໝ່. ໄຟລ໌ທີ່ບັນທຶກແລ້ວເກັບທຸກຢ່າງໄວ້.

## ເປັນຫຍັງການແກ້ໄຂຂອງທ່ານປ່ຽນພຽງອົງປະກອບດຽວ

ຕົວສົ່ງອອກປະຢັດພື້ນທີ່ໂດຍການແບ່ງປັນຂໍ້ມູນ. ຊຸດຄຸນສົມບັດໜຶ່ງອາດຖືກແບ່ງປັນໂດຍປະຕູ 20 ບານ, ແລະ ຄ່າໜຶ່ງ ("Fire rating: 60 min") ອາດຖືກລາຍຊື່ໃນ 90 ຊຸດ. ຖ້າ BimCraft ປ່ຽນຄ່າທີ່ແບ່ງປັນພຽງແຕ່ງ່າຍໆ, ທຸກອົງປະກອບທີ່ແບ່ງປັນມັນກໍຈະປ່ຽນຕາມ.

ສະນັ້ນ BimCraft ສຳເນົາກ່ອນຂຽນ:

- ຖ້າຊຸດຄຸນສົມບັດທີ່ທ່ານແກ້ຖືກແບ່ງປັນກັບອົງປະກອບອື່ນ, ອົງປະກອບຂອງທ່ານຈະໄດ້ສຳເນົາຂອງຕົນເອງ, ແລະ ມີພຽງສຳເນົານັ້ນທີ່ປ່ຽນ.
- ຖ້າຄ່າຖືກແບ່ງປັນກັບຊຸດອື່ນ, ຊຸດຂອງທ່ານຈະໄດ້ສຳເນົາຂອງຄ່ານັ້ນ.

ເພື່ອນບ້ານຮັກສາຂໍ້ມູນເກົ່າຂອງພວກມັນ. ນີ້ເອີ້ນວ່າ *copy-on-write*. ມັນເພີ່ມລາຍການນ້ອຍໆບໍ່ເທົ່າໃດໃນໄຟລ໌, ເຊິ່ງໂປຣແກຣມ IFC ທຸກອັນອ່ານໄດ້ປົກກະຕິ.

**ຄຸນສົມບັດປະເພດເປັນຂໍ້ຍົກເວັ້ນໂດຍເຈດຕະນາ.** ຊຸດທີ່ໝາຍ "(type)" ເປັນຂອງປະເພດຂອງອົງປະກອບ, ແລະ ໃນ IFC ທຸກອົງປະກອບຂອງປະເພດນັ້ນອ່ານມັນຈາກບ່ອນນັ້ນ. ການປ່ຽນມັນຈະປ່ຽນປະເພດ, ດັ່ງນັ້ນທຸກອົງປະກອບຂອງປະເພດສະແດງຄ່າໃໝ່. ລາຍການ {{ui:Changes}} ໝາຍການແກ້ໄຂແບບນັ້ນດ້ວຍ "(type)". ເບິ່ງ [ປ່ຽນຄຸນສົມບັດປະເພດສຳລັບທຸກອົງປະກອບຂອງປະເພດ](topic:type-vs-instance).

## ຄຳເຕືອນກ່ອນທ່ານສູນເສຍວຽກ

- ການເປີດອີກໄຟລ໌ໃນຂະນະທີ່ມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກຈະຖາມວ່າ "ທ່ານມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ *n* ຢ່າງໃນ *file*. ຍົກເລີກພວກມັນບໍ?" ຄລິກ Cancel ເພື່ອສືບຕໍ່ເຮັດວຽກ, ແລ້ວບັນທຶກ.
- ການປິດ ຫຼື ໂຫຼດແຖບຄືນໃໝ່ທີ່ມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ ເຮັດໃຫ້ບຣາວເຊີຖາມວ່າຈະອອກບໍ.

## ຄວາມຜິດພາດທົ່ວໄປ

- **ພິມໜ່ວຍ.** `2400 mm` ຖືກປະຕິເສດ. ພິມ `2400`.
- **ປ່ຽນຄຸນສົມບັດປະເພດໃນຂະນະທີ່ທ່ານຕັ້ງໃຈໃຫ້ອົງປະກອບດຽວ.** ເບິ່ງໝາຍເຫດ "(type)" ກ່ອນທ່ານພິມ. ຖ້າທ່ານຢາກໃຫ້ອົງປະກອບໜຶ່ງແຕກຕ່າງ, ໃຫ້ປ່ຽນຄຸນສົມບັດອິນສະແຕນຊ໌ ຫຼື ແທັກ ຫຼື ຊື່ແທນ.
- **ຄາດຫວັງວ່າໄຟລ໌ເດີມຈະປ່ຽນ.** ການບັນທຶກດາວໂຫຼດໄຟລ໌ໃໝ່ສະເໝີ. ແທນທີ່ຕົ້ນສະບັບດ້ວຍຕົນເອງຖ້ານັ້ນແມ່ນສິ່ງທີ່ທ່ານຕ້ອງການ, ແລະ ເກັບສຳເນົາໄວ້.
