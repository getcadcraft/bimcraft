## ສິ່ງທີ່ທ່ານຈະໄດ້ຮຽນ

ວິທີໃຫ້ຜູ້ຊ່ວຍ AI (ຜູ້ຊ່ວຍໃດກໍ່ຕາມທີ່ເວົ້າ MCP) ເບິ່ງເຂົ້າໄປໃນໂມເດວ IFC ທີ່ທ່ານເປີດຢູ່ ແລະ ແຕ້ມໃນມັນ, ມັນເຮັດໄດ້ຫຍັງ ແລະ ເຮັດບໍ່ໄດ້ຫຍັງ, ແລະ ວິທີຢຸດມັນ.

## ເປີດມັນ

ຜູ້ຊ່ວຍເຂົ້າເຖິງ BimCraft ຜ່ານ CadCraft Studio ໃນຄອມພິວເຕີຂອງທ່ານ; ເບຣົວເຊີທຳມະດາບໍ່ມີທາງເຂົ້າ.

1. ເປີດ {{ui:Settings}} ແລ້ວເລືອກແທັບ **BimCraft**.
2. ພາຍໃຕ້ **Assistants**, ໃຫ້ໝາຍ **ອະນຸຍາດໃຫ້ຜູ້ຊ່ວຍ AI ແລະ ສະຄຣິບໃຊ້ BimCraft**.
3. **ອ່ານ** ຖືກໝາຍໃຫ້ທ່ານແລ້ວ. ໃຫ້ໝາຍ **ປ່ຽນມຸມມອງ ແລະ ແຕ້ມ** ດ້ວຍ ຖ້າຜູ້ຊ່ວຍອາດແຍກ ແລະ ເຊື່ອງອົງປະກອບ ແລະ ແຕ້ມ, ແລະ **ບັນທຶກ** ຖ້າມັນອາດບັນທຶກໂມເດວເປັນໄຟລ໌ໃໝ່.
4. ເຊື່ອມຕໍ່ຜູ້ຊ່ວຍໃນ Studio (Studio ສະແດງທີ່ຢູ່ ແລະ ການຕັ້ງຄ່າທີ່ຈະວາງໃສ່ມັນ).

## ໃນຂະນະທີ່ຜູ້ຊ່ວຍເຊື່ອມຕໍ່

ໝາຍເຫດຢູ່ເທິງສຸດຂອງແຜງຂວາບອກວ່າຜູ້ຊ່ວຍໃດເຊື່ອມຕໍ່ຢູ່ ແລະ ມັນເຮັດໄດ້ຫຍັງ. ກົດ {{ui:Disconnect}} ເພື່ອຈົບເຊດຊັນຂອງມັນທັນທີ; ມັນຕ້ອງເຊື່ອມຕໍ່ໃໝ່ເພື່ອສືບຕໍ່.

**ກິດຈະກຳ**, ພາຍໃຕ້ **Assistants** ໃນການຕັ້ງຄ່າ, ລາຍຊື່ທຸກການເອີ້ນທີ່ຜູ້ຊ່ວຍເຮັດ, ໃໝ່ສຸດກ່ອນ, ພ້ອມວ່າມັນສຳເລັດຫຼືບໍ່.

ຖາມດ້ວຍຄຳເວົ້າທຳມະດາ, ຕົວຢ່າງ "ແຍກຝາດ້ານນອກຢູ່ຊັ້ນ 1", "ປະຕູໃດບໍ່ມີຄ່າທົນໄຟ?" ຫຼື "ແຕ້ມຫ້ອງຂະໜາດ 6 x 4 m ຢູ່ຊັ້ນ 1 ພ້ອມປະຕູໃນຝາທິດໃຕ້". ຜູ້ຊ່ວຍຊອກອົງປະກອບ ແລະ ສະແດງໃນມຸມມອງຂອງທ່ານ, ຫຼື ແຕ້ມພວກມັນ.

## ບໍ່ມີໜ້າຕ່າງ: ສະຄຣິບ ແລະ command line

ເຄື່ອງມືແຕ້ມດຽວກັນເຮັດວຽກກັບໄຟລ໌ IFC ໃນໂຟນເດີທີ່ທ່ານລະບຸ, ໂດຍບໍ່ມີໜ້າຕ່າງເປີດ: MCP server ແລະ command line ຂອງ CadCraft ສາມາດເລີ່ມອາຄານໃໝ່ ຫຼື ເປີດໄຟລ໌ IFC, ອະທິບາຍມັນ, ເພີ່ມຝາ, ປະຕູ, ປ່ອງຢ້ຽມ, ພື້ນ, ລະດັບ ແລະ ເສັ້ນຕາຕະລາງ, ຍ້ອນກັບ ແລະ ບັນທຶກເປັນໄຟລ໌ `.ifc` ໃໝ່. ທ່ານຕັດສິນໃຈວ່າມັນໃຊ້ໂຟນເດີໃດໄດ້ ແລະ ມັນປ່ຽນ ຫຼື ບັນທຶກຫຍັງໄດ້ບໍ່.

## ປິດມັນ

ບໍ່ໝາຍ **ອະນຸຍາດໃຫ້ຜູ້ຊ່ວຍ AI ແລະ ສະຄຣິບໃຊ້ BimCraft**. ຜູ້ຊ່ວຍທຸກຄົນຈະຖືກຕັດການເຊື່ອມຕໍ່ທັນທີ, ແລະ ການຕັ້ງຄ່າຈະຖືກເກັບໄວ້ຄັ້ງໜ້າ.
