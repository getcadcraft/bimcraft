## ສິ່ງທີ່ເປີດໄດ້ທີ່ນີ້

ເປີດໄຟລ໌ເຫຼົ່ານີ້ດ້ວຍ {{ui:Open}} ຫຼື ລາກວາງໃສ່ໜ້າ (ເບິ່ງຫົວຂໍ້ກ່ຽວກັບການສະແດງກ້ອນຈຸດຄຽງຂ້າງໂມເດວ):

| ຮູບແບບ | ນາມສະກຸນ | ສິ່ງທີ່ອ່ານ |
|---|---|---|
| LAS, LAZ | `.las`, `.laz` | LAS 1.0–1.4: ຈຸດ, ສີ, ຄວາມເຂັ້ມ, ປະເພດ LiDAR, ລະບົບພິກັດ. LAZ ສູງສຸດ 1 GB. |
| E57 | `.e57` | ທຸກການສະແກນໃນໄຟລ໌, ແຕ່ລະອັນວາງຕາມທ່າທາງຂອງມັນ; ສີ, ຫຼື ຄວາມເຂັ້ມເມື່ອໄຟລ໌ບໍ່ມີສີ. ຮູບພາບໃນໄຟລ໌ຖືກຂ້າມ (ມີການແຈ້ງ). ສູງສຸດ 6 ລ້ານຈຸດ ແລະ 512 MB ໃນຕອນນີ້: ການສະແກນທີ່ໃຫຍ່ກວ່ານັ້ນໃຫ້ສົ່ງອອກເປັນ LAS ຫຼື LAZ. |
| PLY | `.ply` | ທັງແບບຂໍ້ຄວາມ ແລະ ໄບນາຣີ (ລຳດັບ byte ທັງສອງແບບ): x y z ຂອງ vertices, ສີ ແລະ ຄວາມເຂັ້ມ. ໜ້າ (faces) ຖືກຂ້າມ (ມີການແຈ້ງ). |
| PCD | `.pcd` | ແບບຂໍ້ຄວາມ ແລະ ໄບນາຣີ: x y z, ສີແບບລວມ ຫຼື ແຍກກັນ, ຄວາມເຂັ້ມ. ໄຟລ໌ PCD ທີ່ຖືກບີບອັດຍັງອ່ານບໍ່ໄດ້: ໃຫ້ບັນທຶກເປັນໄບນາຣີ ຫຼື ຂໍ້ຄວາມ. |
| PTX | `.ptx` | ໜຶ່ງ ຫຼື ຫຼາຍການສະແກນ, ແຕ່ລະອັນວາງດ້ວຍ transform ຂອງມັນເອງ; ຈຸດທີ່ເຄື່ອງສະແກນບໍ່ໄດ້ວັດຖືກຂ້າມ. ໜ່ວຍເປັນ m. |
| PTS, XYZ | `.pts`, `.xyz` | ແບບຂໍ້ຄວາມ: x y z, ພ້ອມຄວາມເຂັ້ມ ແລະ ສີເມື່ອມີຖັນເຫຼົ່ານັ້ນ. |

## ໄຟລ໌ທີ່ມີແຕ່ຊອບແວຂອງເຄື່ອງສະແກນເທົ່ານັ້ນທີ່ອ່ານໄດ້

ໄຟລ໌ສະແກນບາງອັນເປັນຮູບແບບຂອງຜູ້ຜະລິດເຄື່ອງສະແກນ ທີ່ບໍ່ມີຄຳອະທິບາຍເຜີຍແຜ່ ແລະ ບໍ່ມີໂປຣແກຣມອ່ານແບບເປີດ. BimCraft ອ່ານບໍ່ໄດ້, ແລະ ເມື່ອເປີດແລ້ວຈະສະແດງກາດທີ່ບອກວ່າມັນແມ່ນຫຍັງ ແລະ ຕ້ອງເຮັດຫຍັງ. ໃຫ້ສົ່ງອອກການສະແກນຈາກຊອບແວຂອງຜູ້ຜະລິດເປັນ E57 ຫຼື LAS (ຫຼື PTX, PTS), ແລ້ວເປີດໄຟລ໌ທີ່ສົ່ງອອກນັ້ນ.

| ໄຟລ໌ | ນາມສະກຸນ | ສົ່ງອອກຈາກ |
|---|---|---|
| ໂປຣເຈັກ ReCap | `.rcp` | ReCap: ເປີດໂປຣເຈັກ ແລ້ວສົ່ງອອກ. ໄຟລ໌ `.rcp` ພຽງແຕ່ຊີ້ໄປຫາການສະແກນຂອງມັນ, ດັ່ງນັ້ນການສຳເນົາ `.rcp` ດ່ຽວໆ ບໍ່ໄດ້ຈຸດມາເລີຍ. |
| ການສະແກນ ReCap | `.rcs` | ReCap: ເປີດໂປຣເຈັກທີ່ການສະແກນນັ້ນເປັນສ່ວນໜຶ່ງ ແລ້ວສົ່ງອອກ. |
| ການສະແກນ FARO | `.fls` | FARO SCENE. |
| ການສະແກນ Leica | `.lgs` | Leica Cyclone REGISTER 360. |
| ການສະແກນ Trimble | `.tzf` | Trimble RealWorks ຫຼື Trimble Business Center. |
| ການສະແກນ Z+F | `.zfs` | Z+F LaserControl. |

:::tip
ເມື່ອການສົ່ງອອກຖາມຫາຮູບແບບ, LAS ຫຼື LAZ ຮັກສາທຸກຢ່າງທີ່ BimCraft ສະແດງ (ສີ, ຄວາມເຂັ້ມ, ປະເພດ ແລະ ລະບົບພິກັດ) ໄວ້ໃນໄຟລ໌ທີ່ນ້ອຍທີ່ສຸດ.
:::

## ເປັນຫຍັງໄຟລ໌ເຫຼົ່ານີ້ຈຶ່ງອ່ານບໍ່ໄດ້

ຮູບແບບເຫຼົ່ານັ້ນບໍ່ໄດ້ເຜີຍແຜ່, ແລະ ວິທີດຽວທີ່ຈະອ່ານມັນແມ່ນຜ່ານຄັງໂຄ້ດຂອງຊອບແວຂອງຜູ້ຜະລິດແຕ່ລະຄົນ ພາຍໃຕ້ເງື່ອນໄຂຂອງຕົນເອງ. BimCraft ອ່ານພຽງແຕ່ຮູບແບບທີ່ມັນອ່ານໄດ້ດ້ວຍໂຄ້ດຂອງຕົນເອງໃນຄອມພິວເຕີຂອງທ່ານ, ດັ່ງນັ້ນການສະແກນຈຶ່ງບໍ່ຕ້ອງຖືກສົ່ງໄປບ່ອນໃດເພື່ອເປີດມັນ.
