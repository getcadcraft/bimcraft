## ສິ່ງທີ່ທ່ານຈະເຮັດ

ໃສ່ລະຫັດການຈັດປະເພດໃຫ້ຝາ, ພື້ນ, ຫຼັງຄາ, ປະຕູ, ປ່ອງຢ້ຽມ ແລະ ທຸກສິ່ງອື່ນໃນໂມເດວ, ໃນສູງສຸດສາມລະບົບຄຽງຂ້າງກັນ: Uniclass, OmniClass ແລະ UniFormat. ສາຂາອື່ນ ແລະ ຊອບແວອື່ນອີງໃສ່ລະຫັດ ບໍ່ແມ່ນຊື່, ດັ່ງນັ້ນລະຫັດຖືກບັນທຶກໃນໄຟລ໌ IFC ເປັນການອ້າງອີງການຈັດປະເພດທີ່ໂປຣແກຣມ BIM ໃດກໍອ່ານໄດ້.

## ໃສ່ລະຫັດໃຫ້ອົງປະກອບ

1. ເລືອກອົງປະກອບ (ຫຼື ຫຼາຍອັນ) ແລ້ວເປີດ **ຄຸນສົມບັດ**. ເປີດພາກ {{ui:ການຈັດປະເພດ}}.
2. ພິມລະຫັດໃນຊ່ອງຂອງລະບົບຂອງມັນ ແລ້ວກົດ Enter. ເມື່ອໂຫຼດລາຍການລະຫັດແລ້ວ, ພິມບາງສ່ວນຂອງລະຫັດ ຫຼື ບາງຄຳ ("curtain wall") ແລ້ວເລືອກຈາກຜົນທີ່ກົງ: ຊື່ຂອງລະຫັດຈະຖືກຕື່ມໃຫ້ອັດຕະໂນມັດ.
3. {{ui:ໃຊ້ກັບ}} ບອກວ່າລະຫັດໄປຢູ່ໃສ: **ອົງປະກອບນີ້**, ຫຼື **ປະເພດຂອງມັນ (ທຸກອົງປະກອບຂອງປະເພດ)**. ລະຫັດໃສ່ປະເພດຝາຈະຖືກອ່ານໂດຍທຸກຝາຂອງປະເພດນັ້ນ, ລວມທັງອັນທີ່ທ່ານຈະວາດໃນພາຍຫຼັງ.
4. {{ui:ລຶບ}} ເອົາລະຫັດອອກ.

ທາງລຸ່ມຂອງແຕ່ລະລະຫັດ ພາກບອກວ່າມັນມາຈາກໃສ: ກຳນົດໃນອົງປະກອບນີ້, ມາຈາກປະເພດຂອງມັນ, ຫຼື ຄ່າເລີ່ມຕົ້ນຂອງໂຄງການສຳລັບຄລາສຂອງມັນ. ລະຫັດຂອງອົງປະກອບເອງຈະຊະນະສະເໝີ, ແລະ ຂອງປະເພດຈະຊະນະຄ່າເລີ່ມຕົ້ນ. ເມື່ອເລືອກຫຼາຍອົງປະກອບ, ຊ່ອງທີ່ບອກ "varies" ໝາຍຄວາມວ່າພວກມັນບໍ່ມີລະຫັດດຽວກັນ; ການພິມລະຫັດໜຶ່ງຈະໃຫ້ທຸກອັນ. ແຕ່ລະການປ່ຽນແປງເປັນໜຶ່ງຂັ້ນຍ້ອນກັບ.

ລະຫັດສາມາດພິມໄດ້ສະເໝີ, ບໍ່ວ່າຈະໂຫຼດລາຍການແລ້ວຫຼືບໍ່. ຖ້າມັນບໍ່ເບິ່ງຄືລະຫັດຂອງລະບົບນັ້ນ, ຫຼື ບໍ່ຢູ່ໃນລາຍການທີ່ໂຫຼດ, ຈະມີຄຳແນະນຳບອກ ແລະ ລະຫັດຈະຖືກເກັບໄວ້ຕາມທີ່ທ່ານພິມ.

## ເລືອກລະບົບຂອງໂຄງການ

ເປີດ **ຂໍ້ມູນ** ໃນແຖບໂມເດວ ແລ້ວເລືອກ {{ui:ການຈັດປະເພດ}} (ຫຼື {{ui:ການຈັດປະເພດໂຄງການ…}} ໃນພາກຄຸນສົມບັດ).

- ໝາຍລະບົບທີ່ໂຄງການນີ້ໃຊ້. ຄຸນສົມບັດຈະສະແດງພຽງລະບົບເຫຼົ່ານັ້ນ.
- **Uniclass**: ຕາຕະລາງ Elements/ functions (EF), Systems (Ss) ແລະ Products (Pr) ມາພ້ອມແອັບ. ມີລິຂະສິດຂອງ © NBS, ໃບອະນຸຍາດ Creative Commons Attribution-NoDerivatives 4.0, ແລະ ຖືກສົ່ງຕໍ່ໄປໂດຍບໍ່ປ່ຽນແປງ. ກ່ອງໂຕ້ຕອບສະແດງສະບັບ ແລະ ວັນທີທີ່ອ່ານຂອງແຕ່ລະຕາຕະລາງ. ມັນບໍ່ແມ່ນຕາຕະລາງຫຼ້າສຸດ: ຜູ້ເຜີຍແຜ່ອອກໃໝ່ທຸກໄຕມາດໃນເວັບໄຊຂອງຕົນເອງ.
- **OmniClass** ແລະ **UniFormat**: ບໍ່ມີລາຍການລະຫັດມາພ້ອມແອັບ ເພາະຜູ້ເຜີຍແຜ່ບໍ່ອະນຸຍາດໃຫ້ສົ່ງຕໍ່ຕາຕະລາງໂດຍບໍ່ມີໃບອະນຸຍາດ. ພິມລະຫັດໃດກໍໄດ້, ຫຼື ໂຫຼດຕາຕະລາງທີ່ມີໃບອະນຸຍາດຂອງສຳນັກງານທ່ານ.
- {{ui:ໂຫຼດຕາຕະລາງ (CSV)…}} ອ່ານຕາຕະລາງຂອງສຳນັກງານທ່ານຈາກໄຟລ໌ CSV ທີ່ມີຖັນລະຫັດ ແລະ ຖັນຊື່ (ແຖວຫົວທີ່ຊື່ Code, Number ຫຼື Identifier ແລະ Title, Name ຫຼື Description ຈະຖືກພົບເອງ; ຖ້າບໍ່ມີ, ຈະໃຊ້ສອງຖັນທຳອິດ). ຕາຕະລາງຢູ່ໃນບຣາວເຊີນີ້ ແລະ ບໍ່ເຄີຍຖືກໃສ່ໃນໄຟລ໌ໂຄງການ. ມີແຕ່ລະຫັດທີ່ທ່ານມອບໝາຍເທົ່ານັ້ນທີ່ຖືກບັນທຶກໃນໄຟລ໌. ທ່ານສາມາດໂຫຼດຕາຕະລາງ Uniclass ໃໝ່ກວ່າດ້ວຍວິທີດຽວກັນ.
- {{ui:ໃຫ້ອົງປະກອບມີລະຫັດເລີ່ມຕົ້ນຕາມປະເພດ}} ໃຫ້ທຸກຝາ, ພື້ນ, ຫຼັງຄາ, ປະຕູ, ປ່ອງຢ້ຽມ, ບັນໄດ, ທາງລາດ, ເສົາ, ຄານ ແລະ ເຟີນີເຈີ ມີລະຫັດ Uniclass ເລີ່ມຕົ້ນຈາກຕາຕະລາງ Elements/ functions ເມື່ອມັນບໍ່ມີລະຫັດຂອງຕົນເອງ. ອົງປະກອບທີ່ທ່ານວາດພາຍຫຼັງກໍຈະໄດ້ຮັບເຊັ່ນກັນ.
- {{ui:ສະແດງລະຫັດເປັນຖັນໃນຕາຕະລາງ}} ເພີ່ມໜຶ່ງຖັນຕໍ່ລະບົບໃນຕາຕະລາງ ປະຕູ, ປ່ອງຢ້ຽມ, ຝາຕາມປະເພດ ແລະ ຫ້ອງ ພ້ອມ CSV ຂອງມັນ. ແຖວທີ່ມີຫຼາຍອົງປະກອບຈະສະແດງ "varies" ເມື່ອລະຫັດຂອງພວກມັນແຕກຕ່າງກັນ.

## ຄວນຮູ້

- ຄ່າເລີ່ມຕົ້ນເປັນທາງເລືອກເບື້ອງຕົ້ນຂອງ CadCraft ເອງ, ບໍ່ແມ່ນຂອງຜູ້ເຜີຍແຜ່, ແລະ ຍັງບໍ່ໄດ້ຖືກກວດໂດຍຜູ້ປະຕິບັດວິຊາຊີບ. ໃຫ້ກວດມັນກັບມາດຕະຖານຂອງໂຄງການທ່ານ.
- ໃນໄຟລ໌ ຄ່າເລີ່ມຕົ້ນເປັນການຈັດປະເພດຈິງ, ໝາຍດ້ວຍຊື່ຄວາມສຳພັນ "CadCraft default", ແລະ ມັນຈະຫາຍໄປທັນທີທີ່ອົງປະກອບ ຫຼື ປະເພດຂອງມັນໄດ້ຮັບລະຫັດຂອງຕົນເອງ.
- ລະຫັດທີ່ໄຟລ໌ນຳເຂົ້າມີຢູ່ແລ້ວຈະຖືກອ່ານ ແລະ ສະແດງ, ບໍ່ວ່າໂປຣແກຣມອື່ນຈະສະກົດຊື່ລະບົບຢ່າງໃດ. ລະຫັດຂອງລະບົບອື່ນໃດ (ຂອງສຳນັກງານໃດໜຶ່ງ) ຈະຖືກລາຍການ ແລະ ປ່ອຍໄວ້ຕາມເດີມ.
- ລະຫັດຈະຖືກອ່ານຄືນເມື່ອເປີດໄຟລ໌ອີກຄັ້ງ, ທີ່ນີ້ ຫຼື ໃນໂປຣແກຣມອື່ນ. ມັນຍັງຖືກນຳໄປໃນການສົ່ງອອກ IFC5 alpha (IFCX) ເມື່ອຕົວເລືອກທົດລອງນັ້ນເປີດຢູ່, ຍົກເວັ້ນລະຫັດທີ່ຕັ້ງໃສ່ຫຼັງຄາ.
- ຍັງບໍ່ໄດ້ສ້າງ: ຕົ້ນໄມ້ສຳລັບເບິ່ງຕາຕະລາງເປັນຊັ້ນໆ, ລະຫັດໃສ່ຊັ້ນ ແລະ ຫ້ອງເປັນຄ່າເລີ່ມຕົ້ນຂອງໂຄງການ, ແລະ ການກວດລະຫັດກັບສະບັບທີ່ລະບຸໃນໄຟລ໌.
