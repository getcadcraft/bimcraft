## ສິ່ງທີ່ທ່ານຈະເຮັດ

ແຕ້ມເສັ້ນ ແລະ ຕົວໜັງສືທີ່ເປັນສ່ວນໜຶ່ງຂອງໂມເດວ, ບໍ່ແມ່ນຂອງມຸມມອງດຽວ.

## ຂັ້ນຕອນ

1. ຕັ້ງແຜ່ນເຮັດວຽກກ່ອນ (ເບິ່ງ **ແຜ່ນເຮັດວຽກ**). ແຜ່ນລະດັບຖືກແຕ້ມໃນແຜນ; ແຜ່ນຕັ້ງຖືກແຕ້ມໃນ Work Plane Viewer.
2. ສຳລັບເສັ້ນ ເລືອກ **ເສັ້ນໂມເດວ** ໃນເມນູ **Build** ແລ້ວເລືອກ **Line**, **Polyline** ຫຼື **Arc (three points)**:
   - ເສັ້ນແມ່ນສອງຄລິກ;
   - ໂພລີລາຍແມ່ນຄລິກໜຶ່ງຄັ້ງສຳລັບແຕ່ລະຈຸດ, ແລ້ວກົດ Enter ຫຼື ດັບເບີ້ລຄລິກ. ການຄລິກໃສ່ຈຸດທຳອິດຈະປິດມັນ;
   - ເສັ້ນໂຄ້ງແມ່ນສາມຄລິກ: ຈຸດເລີ່ມ, ຈຸດທີ່ມັນຜ່ານ, ແລະ ຈຸດສິ້ນສຸດ.
3. ສຳລັບຂໍ້ຄວາມ ເລືອກ **Model Text**. ພິມຄຳ, ຕັ້ງຄວາມສູງຕົວພິມໃຫຍ່ ແລະ ຄວາມເລິກ, ແລ້ວຄລິກບ່ອນທີ່ຂໍ້ຄວາມເລີ່ມ (ປາຍຊ້າຍຂອງເສັ້ນຖານ).
4. ເລືອກເສັ້ນ ຫຼື ຂໍ້ຄວາມເພື່ອເບິ່ງໃນ **Properties**. ຄຳ, ຄວາມສູງ ແລະ ຄວາມເລິກຂອງຂໍ້ຄວາມສາມາດປ່ຽນໄດ້ບ່ອນນັ້ນ. **Delete** ຈະເອົາມັນອອກ.

## ສະແດງຢູ່ໃສ

- ເສັ້ນໂມເດວສະແດງໃນແຜນຂອງລະດັບມັນ, ໃນມຸມມອງ 3D, ໃນແຜງຮູບດ້ານ ແລະ ສ່ວນຕັດ, ແລະ ໃນ Work Plane Viewer ເມື່ອມັນຢູ່ເທິງແຜ່ນເຮັດວຽກ. ເສັ້ນຮ່າງ (Annotate, Line) ເປັນຂອງມຸມມອງດຽວເທົ່ານັ້ນ.
- ຂໍ້ຄວາມໂມເດວເປັນເລຂາຄະນິດແຂງ: ມັນສະແດງທຸກບ່ອນທີ່ໂມເດວສະແດງ, ໃນແຜນ, 3D, ຮູບດ້ານ ແລະ ສ່ວນຕັດ, ແລະ ໃນແຜ່ນ.
- ເສັ້ນໂມເດວຍັງບໍ່ຖືກແຕ້ມໃນແຜ່ນທີ່ພິມ. ຂໍ້ຄວາມໂມເດວຖືກແຕ້ມ.

## ຟອນ

ຂໍ້ຄວາມໂມເດວໃຊ້ຟອນດຽວກັນກັບແຜ່ນ ແລະ PDF: Liberation Sans, ພາຍໃຕ້ SIL Open Font License. ຕົວອັກສອນທີ່ຟອນບໍ່ມີຈະຖືກແຕ້ມເປັນເຄື່ອງໝາຍຄຳຖາມ ແລະ ທ່ານຈະຖືກບອກວ່າຕົວໃດ. ມີຟອນດຽວ ແລະ ນ້ຳໜັກດຽວ. ຕົວອັກສອນຖືກຈັດໄລຍະຕາມຄວາມກວ້າງຂອງຟອນເອງ, ບໍ່ມີ kerning.

## ໃນໄຟລ໌ IFC

- ເສັ້ນໂມເດວເປັນ IfcAnnotation ທີ່ມີ object type ModelLine. ຮູບຮ່າງຂອງມັນເປັນເສັ້ນໂຄ້ງ 3D: ໂພລີລາຍ, ຫຼື ວົງມົນທີ່ຕັດແລ້ວສຳລັບເສັ້ນໂຄ້ງ.
- ຂໍ້ຄວາມໂມເດວເປັນ IfcBuildingElementProxy ທີ່ມີ object type ModelText. ຮູບຮ່າງຂອງມັນເປັນຂອງແຂງໜຶ່ງອັນທີ່ດັນອອກສຳລັບແຕ່ລະສ່ວນຂອງຕົວອັກສອນ, ພ້ອມຮູພາຍໃນຂອງຕົວອັກສອນເຊັ່ນ O ແລະ B. ປະລິມານຂອງມັນແມ່ນເນື້ອທີ່ໜ້າ ແລະ ບໍລິມາດ (ເນື້ອທີ່ໜ້າຄູນຄວາມເລິກ).

## ຄວນຮູ້

- ຂະໜາດໃດກໍໄດ້ຖືກສ້າງຕາມທີ່ທ່ານຂໍ. ມີແຕ່ເສັ້ນທີ່ບໍ່ມີຄວາມຍາວ, ເສັ້ນໂຄ້ງທີ່ສາມຈຸດຢູ່ໃນເສັ້ນດຽວກັນ, ຫຼື ຂໍ້ຄວາມທີ່ບໍ່ມີຕົວອັກສອນ ທີ່ຖືກປະຕິເສດ, ເພາະບໍ່ມີຫຍັງໃຫ້ສ້າງ.
- ແຕ່ລະເສັ້ນ, ແລະ ແຕ່ລະຂໍ້ຄວາມ ຫຼື ການປ່ຽນແປງຂອງມັນ, ເປັນໜຶ່ງຂັ້ນຕອນຂອງ Undo.
