## ສິ່ງທີ່ທ່ານຈະເຮັດ

ວາງໜ່ວຍຂອງລະບົບແບບແຍກ, ແບບແຍກຫຼາຍໜ່ວຍ ຫຼື VRF ແລະ ຊຸດຄອຍລ໌ພັດລົມໃນແບບ, ແລ້ວເຊື່ອມພວກມັນດ້ວຍຊຸດທໍ່ສານເຢັນ: ທໍ່ນ້ຳຢອດເຫຼວ ແລະ ທໍ່ແກັສໃນທອງແດງ ACR, ຍຶດຕິດກັບພອດຂອງໜ່ວຍ. ໜ່ວຍເຮັດວຽກຄືກັບອົງປະກອບອື່ນໃນ [ອຸປະກອນ MEP ທີ່ມີພອດ](topic:mep-equipment): ແຖບດຽວກັນ, ຄຸນສົມບັດ, ພອດ ແລະ [ການຕໍ່](topic:mep-connections).

:::note
ນີ້ແມ່ນເຄື່ອງມືຊ່ວຍຮ່າງແບບ ແລະ ປະສານງານ. ໜ່ວຍເປັນຮູບຮ່າງທົ່ວໄປ ທີ່ມີຂະໜາດຕາມຄ່າທີ່ທ່ານພິມ, ບໍ່ແມ່ນສິນຄ້າຂອງຜູ້ຜະລິດໃດໆ. ຂະໜາດທໍ່ຂອງພວກມັນມາຈາກຕາຕະລາງ **ຄ່າຕົວຢ່າງທົ່ວໄປ** ສຳລັບອຸປະກອນ R410A ແລະ R32, ບໍ່ແມ່ນຈາກຜູ້ຜະລິດ: ຄູ່ມືການຕິດຕັ້ງຂອງຜູ້ຜະລິດໜ່ວຍຈະກຳນົດຂະໜາດຈິງ, ແລະ ທໍ່ທີ່ຍາວ ຫຼື ຕ່າງລະດັບສູງຫຼາຍຈະປ່ຽນຂະໜາດ. ໃຫ້ປ່ຽນຕາຕະລາງ ຫຼື ພິມຂະໜາດທໍ່ເອງ ເພື່ອໃຫ້ກົງກັບໜ່ວຍທີ່ທ່ານໃຊ້.
:::

## ວາງໜ່ວຍ

1. ເປີດ {{ui:ແຕ້ມ}}, ເປີດ {{ui:Build}} ແລ້ວເລືອກ {{ui:ອຸປະກອນ}}.
2. ເລືອກປະເພດ ແລະ ຕັ້ງຄ່າຂອງມັນ:

| ປະເພດ | ທ່ານຕັ້ງ | ພອດຂອງມັນ |
|---|---|---|
| ໜ່ວຍພາຍໃນແບບແຍກ, ຕິດຝາ | ຄວາມສາມາດ, ທໍ່ນ້ຳຢອດເຫຼວ ແລະ ທໍ່ແກັສ, ຄວາມຍາວ, ຄວາມເລິກ, ຄວາມສູງ, ຂະໜາດທໍ່ນ້ຳຄວບແໜ້ນ | ສານເຢັນນ້ຳຢອດເຫຼວ ແລະ ແກັສ, ທໍ່ລະບາຍນ້ຳຄວບແໜ້ນ (ປາຍດ້ານຂວາ, ໃກ້ຝາ) |
| ໜ່ວຍພາຍໃນແບບແຍກ, ແບບຝັງເພດານ | ຄວາມສາມາດ, ທໍ່ນ້ຳຢອດເຫຼວ ແລະ ທໍ່ແກັສ, ແຜງໜ້າ, ຕົວເຄື່ອງ, ຄວາມສູງ, ຂະໜາດທໍ່ນ້ຳຄວບແໜ້ນ | ສານເຢັນນ້ຳຢອດເຫຼວ ແລະ ແກັສ, ທໍ່ລະບາຍນ້ຳຄວບແໜ້ນ (ດ້ານໜຶ່ງ, ໃກ້ດ້ານເທິງ) |
| ໜ່ວຍພາຍໃນແບບແຍກ, ແບບທໍ່ລົມ | ຄວາມສາມາດ, ທໍ່ນ້ຳຢອດເຫຼວ ແລະ ທໍ່ແກັສ, ຄວາມຍາວ, ຄວາມກວ້າງ, ຄວາມສູງ, ປາກທໍ່ລົມສົ່ງ ແລະ ປາກທໍ່ລົມກັບ, ຂະໜາດທໍ່ນ້ຳຄວບແໜ້ນ | ທໍ່ລົມສົ່ງອອກ, ທໍ່ລົມກັບເຂົ້າ, ສານເຢັນນ້ຳຢອດເຫຼວ ແລະ ແກັສ, ທໍ່ລະບາຍນ້ຳຄວບແໜ້ນ |
| ໜ່ວຍພາຍນອກແບບແຍກ | ຄວາມສາມາດ, ທໍ່ນ້ຳຢອດເຫຼວ ແລະ ທໍ່ແກັສ, ຄວາມກວ້າງ, ຄວາມເລິກ, ຄວາມສູງ | ສານເຢັນນ້ຳຢອດເຫຼວ ແລະ ແກັສ (ດ້ານຂວາ) |
| ໜ່ວຍພາຍນອກ VRF | ຄວາມສາມາດ, ທໍ່ນ້ຳຢອດເຫຼວ ແລະ ທໍ່ແກັສ, ຄວາມກວ້າງ, ຄວາມເລິກ, ຄວາມສູງ | ສານເຢັນນ້ຳຢອດເຫຼວ ແລະ ແກັສ (ດ້ານໜ້າ, ຕ່ຳ) |
| ຈຸດຕໍ່ refnet | ທໍ່ນ້ຳຢອດເຫຼວ ຫຼື ແກັສ, ພາລະຂອງແຕ່ລະສາຂາ, ທໍ່ຢູ່ແຕ່ລະປາຍ | ປາກເຂົ້າ, ສາຂາ A, ສາຂາ B |
| ຊຸດຄອຍລ໌ພັດລົມ | 2 ທໍ່ ຫຼື 4 ທໍ່, ຄວາມຍາວ, ຄວາມກວ້າງ, ຄວາມສູງ, ປາກທໍ່ລົມສົ່ງ ແລະ ປາກທໍ່ລົມກັບ, ທໍ່ຄອຍລ໌ ແລະ ລະບົບ, ທໍ່ຄວາມຮ້ອນ, ຂະໜາດທໍ່ນ້ຳຄວບແໜ້ນ | ທໍ່ລົມສົ່ງອອກ, ທໍ່ລົມກັບເຂົ້າ, ຄອຍລ໌ເຂົ້າ ແລະ ອອກ, ຄວາມຮ້ອນເຂົ້າ ແລະ ອອກ (4 ທໍ່), ທໍ່ລະບາຍນ້ຳຄວບແໜ້ນ |

3. ຕັ້ງ **ທີ່**: ຄວາມສູງຂອງຖານໜ່ວຍເໜືອລະດັບ. ຖານຂອງໜ່ວຍຝາແມ່ນດ້ານລຸ່ມຂອງມັນ (ມັກ 2100 mm); ຖານຂອງແບບຝັງເພດານແມ່ນໜ້າຂອງມັນໃນເພດານ; ຂອງ refnet ແມ່ນຄວາມສູງຂອງເສັ້ນກາງທໍ່ຂອງມັນ.
4. ຄລິກບ່ອນທີ່ມັນຈະໄປ ({{key:R}} ໝຸນມັນ 90°).

**ຄວາມສາມາດ** ແມ່ນຄວາມສາມາດເຮັດຄວາມເຢັນທີ່ລະບຸຂອງໜ່ວຍເປັນ kW, ພ້ອມ Btu/h ຢູ່ຂ້າງ. ເມື່ອ **ທໍ່ນ້ຳຢອດເຫຼວ** ແລະ **ທໍ່ແກັສ** ຍັງຢູ່ທີ່ **ຈາກຕາຕະລາງ**, ການຕໍ່ຂອງໜ່ວຍຈະໃຊ້ຂະໜາດຈາກຕາຕະລາງສຳລັບຄວາມສາມາດນັ້ນ; ເລືອກຂະໜາດທໍ່ເພື່ອໃຊ້ຂະໜາດຂອງໜ່ວຍທ່ານເອງ. ປາກເຂົ້າຂອງ refnet ຖືກກຳນົດຂະໜາດສຳລັບທັງສອງສາຂາຮ່ວມກັນ, ແລະ ແຕ່ລະສາຂາຕາມພາລະຂອງຕົນ.

ພອດສານເຢັນເຮັດວຽກໄດ້ທັງສອງທິດທາງ (ປໍ້າຄວາມຮ້ອນເຮັດວຽກໄດ້ທັງສອງທິດ). ທໍ່ລະບາຍນ້ຳຄວບແໜ້ນແມ່ນຂະໜາດທໍ່ ຄືກັບທໍ່ລະບາຍອື່ນໆ.

## ແຕ້ມຊຸດທໍ່ສານເຢັນ

1. ເລືອກສອງອົງປະກອບ ({{key:Shift}}+ຄລິກອັນທີ່ສອງ): ໜ່ວຍພາຍນອກ ແລະ ໜ່ວຍພາຍໃນ (ແບບແຍກດຽວ), ຫຼື ໜ່ວຍພາຍນອກ ແລະ refnet, refnet ແລະ ໜ່ວຍພາຍໃນ, ຫຼື refnet ສອງຕົວ (VRF).
2. ເປີດ {{ui:Build}} ແລ້ວເລືອກ {{ui:ຊຸດທໍ່ສານເຢັນ}}.

BimCraft ແຕ້ມທໍ່ນ້ຳຢອດເຫຼວ ແລະ ທໍ່ແກັສລະຫວ່າງພອດວ່າງຂອງພວກມັນ, ອອກຈາກແຕ່ລະພອດ ແລະ ຂຶ້ນໄປຫາລະດັບສູງຮ່ວມກັນ, ໃນທອງແດງ ACR (ຂົດອ່ອນເຖິງ 1-5/8 in, ທໍ່ດຶງເໜືອນັ້ນ), ເປັນຂັ້ນຕອນດຽວຂອງ {{ui:ຍ້ອນກັບ}}. refnet ຮັບແຕ່ເສັ້ນຂອງຕົນເອງ, ເຂົ້າປາກເຂົ້າຈາກດ້ານນອກ ແລະ ອອກສາຂາໄປຫາໜ່ວຍພາຍໃນ. ແຕ່ລະເສັ້ນເອົາຂະໜາດຂອງປາຍດ້ານໄຫຼລົງ (ໜ່ວຍພາຍໃນ ຫຼື ປາກເຂົ້າຂອງ refnet); ເມື່ອພອດອີກປາຍເປັນຂະໜາດອື່ນ, {{ui:ກວດການເຊື່ອມຕໍ່}} ຈະບອກ: ນັ້ນແມ່ນບ່ອນທີ່ຕ້ອງໃສ່ຕົວຫຼຸດ. ໜ່ວຍພາຍໃນສອງຕົວຕ້ອງມີ refnet ຢູ່ລະຫວ່າງ.

ຍ້າຍເສັ້ນພາຍຫຼັງໄດ້ຄືກັບເສັ້ນທໍ່ທົ່ວໄປ; ປາຍຂອງມັນຍັງຕິດຢູ່ກັບພອດ. ເສັ້ນລະຫວ່າງຊັ້ນແມ່ນແຕ້ມດ້ວຍ {{ui:ທໍ່}}: ທໍ່ທີ່ເລີ່ມຈາກພອດສານເຢັນຈະໄດ້ລະບົບ, ທອງແດງ ACR ແລະ ຂະໜາດຂອງມັນ.

## ໃນໄຟລ໌ IFC

ໜ່ວຍພາຍໃນ ແລະ ພາຍນອກຂອງລະບົບແບບແຍກ ແລະ VRF ເປັນ IfcUnitaryEquipment ປະເພດ SPLITSYSTEM, ໂດຍ object type ບອກວ່າແມ່ນອັນໃດ ("Split indoor unit, wall-mounted", "Split indoor unit, ceiling cassette", "Split indoor unit, ducted", "Split outdoor unit", "VRF outdoor unit"). ຊຸດຄອຍລ໌ພັດລົມແມ່ນ IfcUnitaryEquipment ປະເພດ AIRHANDLER ທີ່ມີ object type "Fan coil unit": IFC4 ບໍ່ມີປະເພດຊຸດຄອຍລ໌ພັດລົມ, ແລະ ພັດລົມ, ຄອຍລ໌ ແລະ ໄສ້ກອງສຳລັບຫ້ອງດຽວ ແມ່ນສິ່ງທີ່ AIRHANDLER ອະທິບາຍ. ຈຸດຕໍ່ refnet ແມ່ນ IfcPipeFitting ປະເພດ JUNCTION ("Refnet joint"). ໄຟລ໌ IFC2X3 ໄດ້ IfcEnergyConversionDevice ແລະ IfcFlowFitting ທີ່ມີປະເພດທີ່ກົງກັນ.

ພອດ ແລະ ເສັ້ນສານເຢັນຢູ່ໃນລະບົບ REFRIGERATION (ໜຶ່ງລະບົບສຳລັບທໍ່ນ້ຳຢອດເຫຼວ, ໜຶ່ງລະບົບສຳລັບທໍ່ແກັສ), ນ້ຳຄວບແໜ້ນຢູ່ໃນລະບົບ DRAINAGE. ເສັ້ນ ACR ຖືກຕັ້ງຊື່ຕາມເສັ້ນຜ່າສູນກາງນອກ. ຕາຕະລາງຊຸດທໍ່ແມ່ນ property set CadCraft_HvacLineSets ໃນໂຄງການ.
