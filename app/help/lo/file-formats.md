## IFC

| ອ່ານ | ລາຍລະອຽດ |
|---|---|
| ຮູບຮ່າງ | ທຸກອົງປະກອບທີ່ມີຮູບຮ່າງ, ມີສີຕາມທີ່ໄຟລ໌ບອກ. ຫ້ອງ ແລະ ພື້ນທີ່ແຕ້ມໂປ່ງໃສ ແລະ ຖືກເຊື່ອງໄວ້ໃນຕອນທຳອິດ |
| ຊັ້ນ | ຊັ້ນອາຄານຕາມລຳດັບລະດັບຄວາມສູງ, ແລະ ອົງປະກອບໃດຢູ່ແຕ່ລະຊັ້ນ. ອົງປະກອບທີ່ບໍ່ຢູ່ຊັ້ນໃດຖືກຈັດກຸ່ມເປັນ "Not on a storey" |
| ຈຳນວນອົງປະກອບ | ມີອົງປະກອບປະເພດໃດກີ່ອັນ (ຝາ, ປະຕູ, ແຜ່ນພື້ນ…), ສະແດງໃນ {{ui:Elements}} |
| ຂໍ້ມູນໂຄງການ | ຊື່ໂຄງການ, ຊື່ຍາວ ແລະ ໄລຍະ; schema; ໂປຣແກຣມທີ່ສົ່ງອອກ, ຜູ້ຂຽນ ແລະ ວັນທີສົ່ງອອກຈາກສ່ວນຫົວຂອງໄຟລ໌ |
| ຂໍ້ມູນອົງປະກອບ | ຊື່, ປະເພດ, ປະເພດວັດຖຸ, ປ້າຍ, ຄຳອະທິບາຍ, GlobalId; ທຸກຊຸດຄຸນສົມບັດ ແລະ ຊຸດປະລິມານໃນອົງປະກອບ ແລະ ໃນປະເພດຂອງມັນ |

ແກ້ໄຂໄດ້: ຊື່, ປະເພດວັດຖຸ, ປ້າຍ, ຄຳອະທິບາຍ, ແລະ ຄ່າຄຸນສົມບັດດຽວ. ບັນທຶກເປັນໄຟລ໌ IFC ໃໝ່. ສະກີມາ IFC2X3, IFC4 ແລະ IFC4X3 ເປີດໄດ້, ອ່ານໂດຍເຄື່ອງຈັກ IFC ຂອງ BimCraft ເອງ; ສິ່ງທີ່ມັນຍັງແຕ້ມບໍ່ໄດ້ຈະຖືກລາຍການໃຕ້ **Not drawn yet** ໃນແຜງ {{ui:File}}. ໂມເດວຖືກຍ້າຍໄປຈຸດເລີ່ມຕົ້ນເມື່ອເປີດ, ດັ່ງນັ້ນໂມເດວທີ່ຕັ້ງໄວ້ໄກຈາກມັນຍັງສະແດງຢູ່ກາງໜ້າຈໍ. `.ifczip` ແລະ `.ifcxml` ເປີດບໍ່ໄດ້.

## ໄຟລ໌ໂຄງການ ແລະ ຕະກູນ

`.rvt` ໂຄງການ, `.rte` ແມ່ແບບໂຄງການ, `.rfa` ຕະກູນ ແລະ `.rft` ແມ່ແບບຕະກູນ.

| ອ່ານ | ລາຍລະອຽດ |
|---|---|
| ຂໍ້ມູນໄຟລ໌ | ການປ່ອຍ ແລະ ເວີຊັນ, ການເຮັດວຽກຮ່ວມ, ເສັ້ນທາງໂມເດວກາງ, ເສັ້ນທາງທີ່ບັນທຶກຄັ້ງສຸດທ້າຍ, ຊື່ຜູ້ໃຊ້, locale, GUID ຂອງເອກະສານ |
| ຂໍ້ມູນໂຄງການ | ຊ່ອງຂອງໂຄງການເອງ (ຊື່, ເລກທີ່, ລູກຄ້າ, ທີ່ຢູ່, ສະຖານະ…), ໂດຍບໍ່ມີຄ່າເລີ່ມຕົ້ນຂອງໂຄງການໃໝ່ |
| ຂໍ້ມູນຕະກູນ | ຊື່ຕະກູນ, ປະເພດ, ການປ່ອຍ, ການອັບເດດຄັ້ງສຸດທ້າຍ, ແລະ ພາຣາມິເຕີຕາມກຸ່ມ |
| ການເຊື່ອມໂຍງ | ລາຍການໂມເດວທີ່ເຊື່ອມໂຍງ, ການເຊື່ອມ CAD, ຮູບພາບ ແລະ ຕາຕະລາງ keynote ທີ່ໄຟລ໌ຊີ້ໄປຫາ |
| ຮູບຕົວຢ່າງ | ຮູບຍ່ອຍທີ່ບັນທຶກໄວ້ໃນໄຟລ໌ |

ບໍ່ອ່ານ: ໂມເດວ 3D, ອົງປະກອບ, ມຸມມອງ, ແຜ່ນ ແລະ ຕາຕະລາງ. ມັນຖືກເກັບໄວ້ໃນຮູບແບບທີ່ບໍ່ໄດ້ບັນທຶກໄວ້. BimCraft ອ່ານພຽງບໍ່ເທົ່າໃດສິບກິໂລໄບຕ໌ຈາກແຕ່ລະໄຟລ໌, ດັ່ງນັ້ນຂະໜາດໄຟລ໌ແທບບໍ່ມີຜົນ.

## ໄຟລ໌ໂຄງການ .pln, .pla, .tpl ແລະ .bpn

ຍັງບໍ່ໄດ້ອ່ານ: BimCraft ບອກເມື່ອທ່ານເປີດໜຶ່ງ. ສົ່ງອອກ IFC ສຳລັບໂມເດວ ແລະ DWG ສຳລັບແບບແຕ້ມ; ເບິ່ງ [ເປີດໄຟລ໌ໂຄງການ .pln ແລະ .pla](topic:pln-project-files).

## DWG ແລະ DXF

| ອ່ານ | ລາຍລະອຽດ |
|---|---|
| ພື້ນທີ່ | ພື້ນທີ່ໂມເດວ ແລະ ທຸກແຜ່ນ (layout), ຕາມລຳດັບແຖບ |
| Viewport | Viewport ຂອງແຕ່ລະແຜ່ນ, ພ້ອມມາດຕາສ່ວນ, ການບິດ ແລະ ເລເຢີທີ່ຖືກຄ້າງ |
| ເລເຢີ | ຊື່, ສີ, ເປີດ/ປິດ, ຄ້າງ, ທຸງການພິມ ແລະ ນ້ຳໜັກເສັ້ນ |
| ອອບເຈັກ | ເສັ້ນ, polyline, ສ່ວນໂຄ້ງ, ວົງມົນ, ellipse, spline, hatch ແລະ solid, ຂໍ້ຄວາມ ແລະ ຂໍ້ຄວາມຫຼາຍແຖວ, ບລັອກ ແລະ attribute, ຂະໜາດ, leader ແລະ multileader, ຕາຕະລາງ, ຈຸດ, ຮູບ |
| ແບບແຕ້ມທີ່ເຊື່ອມໂຍງ | ແຕ້ມຕາມບ່ອນທີ່ມັນຖືກແຊກ, ເມື່ອພົບໄຟລ໌ຂອງມັນ |
| ຮູບ | ແຕ້ມຈາກໄຟລ໌ຮູບເມື່ອພົບ (PNG, JPEG, GIF, BMP, WebP; ບໍ່ແມ່ນ TIFF) |
| ປ້າຍອຸປະກອນ | ປ້າຍອຸປະກອນບໍລິການອາຫານ (attribute `KCL-ITEM`), ສຳລັບຕາຕະລາງອຸປະກອນ |

ສິ່ງອື່ນຖືກນັບໄວ້ໃຕ້ **Not drawn yet**, ບໍ່ເຄີຍເດົາ. ຮູບແບບ DWG ຈາກ AutoCAD 2000 ຫາ 2018 ແມ່ນທີ່ຖືກທົດສອບ (ໄຟລ໌ R13 ແລະ R14 ຍອມຮັບເຊັ່ນກັນ, ແຕ່ບໍ່ມີໃນຊຸດທົດສອບ; DWG ເກົ່າກວ່ານັ້ນເປີດບໍ່ໄດ້); ແຜງ {{ui:Drawing}} ສະແດງລະຫັດຮູບແບບ (ເຊັ່ນ AC1032). ໄຟລ໌ DXF ທຸກເວີຊັນເປີດໄດ້, ລວມທັງ R12. ທັງສອງຖືກອ່ານໂດຍເຄື່ອງອ່ານຂອງ BimCraft ເອງ, ໃນແຖບນີ້. ບໍ່ມີຫຍັງຖືກບັນທຶກກັບຄືນເປັນ DWG ຫຼື DXF.
