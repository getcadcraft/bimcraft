IFC5 alpha (ໄຟລ໌ທີ່ລົງທ້າຍດ້ວຍ {{ui:.ifcx}}) ແມ່ນຮູບແບບໄຟລ໌ທີ່ buildingSMART ຍັງກຳລັງອອກແບບຢູ່. ມັນຍັງບໍ່ເປັນທີ່ສຸດ: ໄຟລ໌ ແລະ ການອ່ານຂອງພວກເຮົາກ່ຽວກັບມັນສາມາດປ່ຽນແປງໄດ້. ນັ້ນແມ່ນເຫດຜົນທີ່ນີ້ເປັນຕົວເລືອກທົດລອງ ແລະ ເປັນເຫດຜົນທີ່ຕ້ອງອ່ານກ່ອນ.

## ເປີດໃຊ້

1. ເລືອກ {{ui:ການຕັ້ງຄ່າ}}, ແລ້ວພາກ {{ui:IFC5 alpha (IFCX)}} ຂອງແຖບ BimCraft.
2. ໝາຍເລືອກ {{ui:IFC5 alpha (IFCX) - ຮູບແບບຍັງປ່ຽນແປງຢູ່; ອ່ານກ່ອນ}}.

ມັນປິດຢູ່ໂດຍຄ່າເລີ່ມຕົ້ນ. ໃນຂະນະທີ່ມັນປິດ, ໄຟລ໌ .ifcx ຈະຖືກປະຕິເສດພ້ອມປະໂຫຍກທີ່ຊີ້ມາບ່ອນນີ້. {{ui:ເປີດ IFC5 alpha (.ifcx)…}} ແລະ ປຸ່ມສົ່ງອອກ {{ui:IFC5 alpha}} ຈະປາກົດເມື່ອມັນເປີດ.

## ເປີດ

- ເລືອກໄຟລ໌ .ifcx ດ້ວຍ {{ui:ເປີດໄຟລ໌ ຫຼື ໂຟນເດີ}} (ມັນຈະແທນທີ່ໂມເດວທີ່ເປີດຢູ່, ຫຼັງຈາກຄຳຖາມປົກກະຕິກ່ຽວກັບການແກ້ໄຂ), ຫຼື
- ເລືອກ {{ui:ເປີດ IFC5 alpha (.ifcx)…}} ແລ້ວເລືອກຫຼາຍໄຟລ໌ພ້ອມກັນ: ໄຟລ໌, ເລເຢີຂອງມັນ, ແລະ ໄຟລ໌ schema ທີ່ມັນນຳເຂົ້າ. ເມື່ອມີໂມເດວເປີດຢູ່ແລ້ວ, ໄຟລ໌ຈະຖືກ **ເພີ່ມຄຽງຂ້າງ** ມັນ; ເຄື່ອງໝາຍ x ໃນລາຍການໂມເດວຈະເອົາມັນອອກອີກ, ນັ້ນແມ່ນການຍ້ອນກັບ.

ໄຟລ໌ IFCX ລະບຸ node (ເສັ້ນທາງ, ລູກຂອງມັນ, ສິ່ງທີ່ມັນສືບທອດ, ຄຸນລັກສະນະຂອງມັນ). ຫຼາຍໄຟລ໌ສາມາດອະທິບາຍ node ດຽວກັນໄດ້: ໄຟລ໌ທີ່ມາທີຫຼັງ (ເລເຢີ) ຈະທັບຄຸນລັກສະນະຂອງໄຟລ໌ທີ່ມາກ່ອນ, ແລະ ລູກ null ຈະເອົາລູກອອກ. BimCraft ປະກອບພວກມັນເຂົ້າກັນ, ແລ້ວແຕ້ມຜົນເປັນໂມເດວ IFC4 ນ້ອຍໆ: ໂຄງການ, ໄຊຕ໌, ອາຄານ, ຊັ້ນ ແລະ ອົງປະກອບທີ່ມີຊື່, ປະເພດ, ຄຸນສົມບັດ, ປະລິມານ, ສີ ແລະ ແມຊ໌.

ບໍ່ມີຫຍັງຖືກດຶງຈາກເຄືອຂ່າຍ. ໄຟລ໌ schema ທີ່ໄຟລ໌ນຳເຂົ້າ (ຕົວຢ່າງ `ifc@v5a.ifcx`) ຈະຖືກໃຊ້ພຽງແຕ່ເມື່ອທ່ານເລືອກພວກມັນພ້ອມກັບໄຟລ໌; ຖ້າບໍ່ດັ່ງນັ້ນ ບົດລາຍງານຈະບອກແບບນັ້ນ ແລະ ຄຸນລັກສະນະຈະຖືກອ່ານໂດຍບໍ່ກວດປະເພດ.

### ບົດລາຍງານ

ຫຼັງເປີດ, ບົດລາຍງານຈະລາຍການສິ່ງທີ່ການອ່ານພົບ: ຂໍ້ມູນທີ່ບໍ່ກົງກັບ schema ຂອງມັນ, ໄຟລ໌ schema ທີ່ບໍ່ໄດ້ໃຫ້, ຄຸນລັກສະນະທີ່ບໍ່ມີຄວາມໝາຍ IFC ທີ່ນີ້. ຄຸນລັກສະນະທີ່ບໍ່ມີການແມັບປິ້ງຈະ **ຖືກເກັບໄວ້** ໃນໂມເດວ, ບໍ່ຖືກຖິ້ມ, ແລະ ຈະຖືກຂຽນກັບຄືນເມື່ອສົ່ງອອກ.

## ອັນໃດກາຍເປັນອັນໃດ

| ໃນໄຟລ໌ IFCX | ໃນ BimCraft |
|---|---|
| node ທີ່ມີປະເພດ IFC (ໂຄງການ, ໄຊຕ໌, ອາຄານ, ຊັ້ນ, ຝາ …) | ອົງປະກອບ IFC4 ທີ່ກົງກັນ; ປະເພດທີ່ການອ່ານນີ້ບໍ່ຮູ້ຈະກາຍເປັນ building element proxy |
| ຊື່ທີ່ node ມີພາຍໃຕ້ພໍ່ແມ່ຂອງມັນ | ຊື່ອົງປະກອບ |
| ຄຸນລັກສະນະທີ່ມີປະເພດປະລິມານ (Length, Area, Volume, Mass …) | ຊຸດປະລິມານ IFC4 ຊື່ `Qto_IFCX` (ຊຸດປະລິມານ IFC4 ຍັງເປັນຊຸດ `Qto_*` ຂອງ IFC4) |
| ຄຸນລັກສະນະຄຸນສົມບັດອື່ນ | ຊຸດຄຸນສົມບັດຊື່ `Pset_IFCX` |
| ຄຸນລັກສະນະຕາໜ່າງ ແລະ ການແປງ | ສາມແຈຂອງອົງປະກອບ ແລະ ການວາງ; ຕາໜ່າງທີ່ເບິ່ງບໍ່ເຫັນຈະບໍ່ຖືກແຕ້ມ |
| ສີ, ຄວາມໂປ່ງ, ວັດສະດຸ, ການຈັດປະເພດ | ຮູບແບບພື້ນຜິວ, ວັດສະດຸ ແລະ ການຈັດປະເພດຂອງອົງປະກອບ |

ຫົວໜ່ວຍຖືກເອົາເປັນແມັດ, ໂດຍແກນ Z ຊີ້ຂຶ້ນ: ທີ່ alpha ບອກວ່າຫົວໜ່ວຍຈະຖືກບັນທຶກໄວ້ພາຍຫຼັງ.

## ສົ່ງອອກ

ເລືອກ {{ui:IFC5 alpha}} ໃນແຖບເຄື່ອງມື, ອ່ານໝາຍເຫດ, ແລ້ວ {{ui:ສົ່ງອອກ .ifcx}}. ໄຟລ໌ມີສ່ວນຫົວຂອງພວກເຮົາເອງ (ຜູ້ຂຽນ CadCraft, ເວີຊັນ ifcx_alpha) ແລະ ລະບຸໃນຕົວມັນເອງວ່າເປັນຮູບແບບ alpha. ແຕ່ລະໂມເດວຖືກຂຽນໃນພິກັດໄຟລ໌ຂອງມັນເອງ, ເປັນແມັດ, ພ້ອມຊື່, ປະເພດ, ຊຸດຄຸນສົມບັດ, ປະລິມານ (ເປັນຄຸນລັກສະນະພ້ອມປະເພດຂອງມັນ), ສີ ແລະ ສາມແຈ. ເລເຢີ ແລະ ການສືບທອດຖືກຂຽນແບບແຜ່ລາບ. ກວດສອບໄຟລ໌ໃນໂປຣແກຣມທີ່ທ່ານສົ່ງໃຫ້.

## ຂໍ້ຈຳກັດ

- ຮູບຮ່າງໂຄ້ງ (ເສັ້ນໂຄ້ງ, ພື້ນຜິວ) ບໍ່ຖືກອ່ານ: ມີແຕ່ຕາໜ່າງສາມແຈເທົ່ານັ້ນ.
- ປະຕູ ແລະ ປ່ອງຢ້ຽມທີ່ຢູ່ໃນຝາຈະຖືກວາງໄວ້ໃນຊັ້ນ; ຝາທີ່ມັນມາຈາກບໍ່ໄດ້ຖືກເຊື່ອມໂຍງ.
- ຊື່ຊຸດ `Qto_*` ຂອງ IFC4 ຖືກເກັບໄວ້ເປັນກຸ່ມຄຸນລັກສະນະຂອງພວກເຮົາເອງ (`cadcraft::qto::…`); schema alpha ມາດຕະຖານມີຊື່ປະລິມານພຽງບໍ່ເທົ່າໃດ.
- ຮູບແບບອາດປ່ຽນແປງໄປ; ໄຟລ໌ທີ່ສ້າງມື້ນີ້ອາດອ່ານບໍ່ໄດ້ມື້ອື່ນ.
