## ສິ່ງທີ່ທ່ານຈະເຮັດ

ເບິ່ງອາຄານຂຶ້ນ: ແຕ່ລະໜ້າວຽກໃນຕາຕະລາງຂອງທ່ານເຊື່ອມກັບອົງປະກອບທີ່ມັນສ້າງ, ສະແດງເປັນລາຍວັນ.

## ຂັ້ນຕອນ

1. ເປີດໄຟລ໌ IFC ແລ້ວເປີດ {{ui:4D schedule}} ໃນແຜງດ້ານຊ້າຍ.
2. ກົດ {{ui:Download a template}} ເພື່ອໄດ້ລາຍການໜ້າວຽກທີ່ມີໜຶ່ງອາທິດຕໍ່ຊັ້ນ ແລ້ວແກ້ໄຂໃນສະເປຣດຊີດ. ຫຼື ຂຽນເອງກໍ່ໄດ້.
3. ກົດ {{ui:Open a task list…}} ແລ້ວເລືອກໄຟລ໌ CSV.
4. ລາກແຖບເລື່ອນວັນທີ ຫຼື ກົດ {{ui:Play}}.

## ລາຍການໜ້າວຽກ

ໄຟລ໌ CSV ທີ່ມີແຖວຫົວຂໍ້ ແລະ ຄໍລຳ **Task**, **Start**, **Finish**, **Field** ແລະ **Value**. ໃຊ້ເຄື່ອງໝາຍຄອມມາ ຫຼື ເຄື່ອງໝາຍຈຸດຕໍ່ກັນກໍ່ໄດ້.

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| Level 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| Roof | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| Roof | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- ຂຽນວັນທີເປັນ YYYY-MM-DD.
- ແຖວໜຶ່ງເຊື່ອມໜ້າວຽກກັບທຸກອົງປະກອບທີ່ **Field** ມີ **Value** ຄືກັນພໍດີ. Field ແມ່ນຄຸນສົມບັດ ເຊັ່ນ Storey, Class, Name, Type, Material, Tag ຫຼື GlobalId, ຫຼື ຄຸນສົມບັດໃດໜຶ່ງທີ່ຂຽນເປັນຊື່ຊຸດ ແລະ ຊື່ຂອງມັນ: `Pset_WallCommon.FireRating`.
- ເຮັດໜ້າວຽກດຽວກັນໃນຫຼາຍແຖວ, ດ້ວຍວັນທີດຽວກັນ, ເພື່ອເຊື່ອມອົງປະກອບເພີ່ມເຕີມ.

## ຂັ້ນ ແລະ ຊຸດວຽກ

ເພີ່ມຄໍລຳ **Stage**, ຄໍລຳ **Package**, ຫຼື ທັງສອງ, ເພື່ອລວມໜ້າວຽກເຂົ້າເປັນຂັ້ນ ແລະ ຊຸດວຽກ. Phase ແລະ WBS ກໍ່ໃຊ້ເປັນຊື່ຄໍລຳໄດ້ເຊັ່ນກັນ.

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| Level 1 slab | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| Level 1 walls | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| Doors | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- ໜ້າວຽກໜຶ່ງຢູ່ໃນຂັ້ນດຽວ ແລະ ຊຸດວຽກດຽວ. ຖ້າແຖວຕໍ່ມາຂອງໜ້າວຽກດຽວກັນລະບຸອັນອື່ນ, ແຖວນັ້ນຈະຖືກລາຍຊື່ພ້ອມເລກແຖວ ແລະ ຖືກຂ້າມ.
- ຊື່ຊຸດວຽກດຽວກັນໃນສອງຂັ້ນແມ່ນສອງຊຸດວຽກ.

ເມື່ອລາຍການມີກຸ່ມ, ລາຍການ {{ui:Show}} ຈະປາກົດຢູ່ເໜືອວັນທີ. ເລືອກຂັ້ນ ຫຼື ຊຸດວຽກ ແລ້ວມັນຈະຫຼິ້ນເປັນໜຶ່ງດຽວ:

- ແຖບເລື່ອນ ແລະ {{ui:Play}} ແລ່ນຈາກວັນເລີ່ມຕົ້ນທຳອິດຂອງກຸ່ມຫາວັນສິ້ນສຸດສຸດທ້າຍ,
- ມີພຽງໜ້າວຽກຂອງກຸ່ມເທົ່ານັ້ນທີ່ຖືກລາຍຊື່ ແລະ ລົງສີ, ແລະ ສິ່ງທີ່ຢູ່ນອກກຸ່ມຈະເປັນແບບໂປ່ງ,
- ເສັ້ນທີ່ຢູ່ໃຕ້ລາຍການບອກວ່າມີກີ່ໜ້າວຽກສຳເລັດ, ກຳລັງດຳເນີນຢູ່ ແລະ ຍັງຈະມາເຖິງໃນວັນທີນັ້ນ,
- {{ui:Select its elements}} ເລືອກທຸກອົງປະກອບຂອງກຸ່ມ, ເພື່ອ {{ui:Show}}, {{ui:Section}} ຫຼື ຕາຕະລາງ.

ເລືອກ **Every task** ເພື່ອເບິ່ງຕາຕະລາງທັງໝົດອີກຄັ້ງ.

## ສິ່ງທີ່ທ່ານຄວນເຫັນ

- **ສ້າງແລ້ວ**: ອົງປະກອບທີ່ໜ້າວຽກທັງໝົດສຳເລັດແລ້ວ, ດ້ວຍສີຂອງມັນເອງ.
- **ກຳລັງດຳເນີນ**: ອົງປະກອບທີ່ມີໜ້າວຽກກຳລັງດຳເນີນໃນວັນນັ້ນ, ດ້ວຍສີເຫຼືອງດິນ. ໜ້າວຽກກຳລັງດຳເນີນນັບແຕ່ວັນເລີ່ມຕົ້ນຈົນເຖິງວັນສິ້ນສຸດ.
- **ຍັງບໍ່ເລີ່ມ**: ແບບໂປ່ງ.
- ອົງປະກອບທີ່ບໍ່ຢູ່ໃນໜ້າວຽກໃດເລີຍຄົງເດີມ. ລາຍການບອກວ່າແຕ່ລະໜ້າວຽກພົບອົງປະກອບຈັກອັນ. ແຖວທີ່ອ່ານບໍ່ໄດ້, ຫຼື ບໍ່ພົບຫຍັງ, ຈະຖືກລາຍຊື່ພ້ອມເລກແຖວ.

## ການເຊື່ອມ, ແຜນພູມ Gantt ແລະ MS Project

- ເປີດໄຟລ໌ Microsoft Project XML (`.xml`) ຫຼື CSV ທີ່ມີຄໍລຳ `Predecessors`. ການເຊື່ອມສາມາດເປັນ finish to start, start to start, finish to finish ຫຼື start to finish, ແຕ່ລະອັນມີການລ່ວງໜ້າ (lead) ຫຼື ການລ່າຊ້າ (lag) ເປັນວັນ.
- ໃຕ້ລາຍການໜ້າວຽກ, ແຜນພູມ Gantt ແຕ້ມທຸກໜ້າວຽກເປັນແຖບ ພ້ອມລູກສອນສຳລັບການເຊື່ອມ. ໜ້າວຽກໃນເສັ້ນທາງວິກິດເປັນສີແດງ. ການວົນຊ້ຳຂອງການເຊື່ອມ ຫຼື ໜ້າວຽກກ່ອນໜ້າທີ່ບໍ່ມີຢູ່ຈະຖືກລາຍຊື່ໃນແຜງ.
- {{ui:Save as MS Project XML}} ແລະ {{ui:Save CSV with links}} ຂຽນຕາຕະລາງກັບຄືນພ້ອມການເຊື່ອມ.
