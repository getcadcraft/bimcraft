## ສິ່ງທີ່ທ່ານຈະເຮັດ

ເຮັດໃຫ້ແບບສົມບູນ: ສະແດງແບບທີ່ມັນເຊື່ອມໄປຫາ (external references, ຫຼື xrefs) ແລະ ຮູບພາບທີ່ມັນໃຊ້, ເຊັ່ນ ໂລໂກ້ໃນບລັອກຊື່ເລື່ອງ.

## ວິທີງ່າຍ: ເປີດໂຟນເດີ

1. ຄລິກ {{ui:Open a folder}} ແລ້ວເລືອກໂຟນເດີທີ່ເກັບແບບ ແລະ ການເຊື່ອມຂອງມັນ, ຕົວຢ່າງ ໂຟນເດີ `Cad` ທັງໝົດຂອງໂຄງການ.
2. ໃນລາຍງານໂຟນເດີ, ເລື່ອນໄປທີ່ **ແບບ CAD**.
3. ຄລິກແບບ.
4. ເບິ່ງແຜງ {{ui:Properties}} ທາງຂວາ, ພາຍໃຕ້ **ແບບທີ່ເຊື່ອມໂຍງ** ແລະ **ຮູບພາບ**.

BimCraft ຊອກແບບທີ່ເຊື່ອມແຕ່ລະອັນດ້ວຍຊື່ຂອງມັນ ("*name*.dwg"), ໃນໂຟນເດີດຽວກັນກັບແບບກ່ອນ, ແລ້ວຈຶ່ງຊອກຢູ່ບ່ອນໃດກໍໄດ້ໃນໂຟນເດີທີ່ທ່ານເປີດ. ຮູບພາບຖືກຊອກດ້ວຍວິທີດຽວກັນ, ແລະ ດ້ວຍຊື່ທີ່ຄ້າຍກັນ: ການສົ່ງອອກ eTransmit ຫຼື Revit ມັກເພີ່ມຊື່ໂຄງການໄວ້ໜ້າ, ສະນັ້ນ `logo.png` ຖືກພົບເປັນ `Tower-logo-5425051.png`.

## ວິທີອື່ນ: ເພີ່ມໄຟລ໌ດ້ວຍມື

1. ເປີດແບບດ່ຽວໆ.
2. ທາງຂວາ, ພາຍໃຕ້ **ແບບທີ່ເຊື່ອມໂຍງ**, ຄລິກ {{ui:Add linked drawings…}}. ພາຍໃຕ້ **ຮູບພາບ**, ປຸ່ມແມ່ນ {{ui:Add pictures…}}; ທັງສອງເປີດຕົວເລືອກດຽວກັນ.
3. ເລືອກໄຟລ໌ `.dwg` ທີ່ເຊື່ອມ ແລະ ໄຟລ໌ຮູບພາບ. ທ່ານສາມາດເລືອກຫຼາຍອັນພ້ອມກັນໄດ້.
4. ລໍຖ້າໃນຂະນະ BimCraft ເປີດແບບອີກຄັ້ງພ້ອມກັບພວກມັນ.

## ສິ່ງທີ່ທ່ານຄວນເຫັນ

ແບບທີ່ເຊື່ອມແຕ່ລະອັນ ແລະ ຮູບພາບຖືກລາຍຊື່ພ້ອມປ້າຍ:

| ປ້າຍ | ໝາຍຄວາມວ່າ |
|---|---|
| **ສະແດງ** | ພົບ ແລະ ວາດແລ້ວ. ເສັ້ນທາງທີ່ຢູ່ລຸ່ມມັນບອກວ່າມາຈາກໃສ, ຫຼື "ເພີ່ມໂດຍທ່ານ". |
| **ສະແດງ, ຊື່ຄ້າຍກັນ** | ຮູບພາບທີ່ພົບດ້ວຍຊື່ຄ້າຍກັນ. ກວດວ່າມັນເປັນອັນທີ່ຖືກຕ້ອງ. |
| **ບໍ່ພົບ** | ບໍ່ຢູ່ໃນໂຟນເດີ ຫຼື ໄຟລ໌ທີ່ທ່ານເພີ່ມ. ຮູບພາບທີ່ຫາຍໄປສະແດງເປັນກອບເປົ່າ. |
| **TIFF ບໍ່ສາມາດສະແດງໃນບຣາວເຊີໄດ້** | ຮູບພາບເປັນໄຟລ໌ TIFF, ເຊິ່ງບຣາວເຊີບໍ່ວາດ. ບັນທຶກເປັນ PNG ດ້ວຍຊື່ດຽວກັນ ແລ້ວເພີ່ມມັນ. |
| **ອ່ານບໍ່ໄດ້** | ພົບໄຟລ໌ແຕ່ເປີດເປັນຮູບພາບບໍ່ໄດ້. |

ແຜງ {{ui:Drawing}} ທາງຊ້າຍສະແດງ "*n* ຈາກ *m* ໂຫຼດແລ້ວ" ສຳລັບແບບທີ່ເຊື່ອມ. ເລເຢີຂອງແບບທີ່ເຊື່ອມປາກົດໃນ {{ui:Layers}} ເປັນ "*link name*|*layer*".

## ຄວາມຜິດພາດທົ່ວໄປ

- **ເປີດແຕ່ແບບ.** "ແບບນີ້ສະແດງແຕ່ເນື້ອຫາຂອງມັນເອງ ຈົນກວ່າແບບທີ່ເຊື່ອມຈະຖືກເພີ່ມ. ການເປີດໂຟນເດີໂຄງການທັງໝົດຈະຊອກພວກມັນໂດຍອັດຕະໂນມັດ."
- **ເປີດໂຟນເດີນ້ອຍເກີນ.** ຖ້າການເຊື່ອມຢູ່ໂຟນເດີອ້າຍນ້ອງ, ໃຫ້ເປີດໂຟນເດີແມ່ແທນ.
- **ການເຊື່ອມທີ່ປ່ຽນຊື່.** BimCraft ຈັບຄູ່ແບບທີ່ເຊື່ອມດ້ວຍຊື່. ການເຊື່ອມທີ່ຖືກປ່ຽນຊື່ໃນດິສກ໌ຈະບໍ່ພົບ; ເພີ່ມມັນດ້ວຍມື.
- **ການເຊື່ອມຂອງການເຊື່ອມ.** BimCraft ໂຫຼດແບບທີ່ແບບທີ່ເປີດຢູ່ເຊື່ອມໄປຫາ. ແບບທີ່ເຊື່ອມຢູ່ພາຍໃນພວກມັນຈະບໍ່ຖືກຊອກຫາ, ສະນັ້ນໂດຍທົ່ວໄປພວກມັນບໍ່ສະແດງໃນເວີຊັນນີ້.
