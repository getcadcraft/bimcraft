## ສິ່ງທີ່ທ່ານຈະເຮັດ

ນຳປະເພດຝາຂອງທ່ານຈາກໂຄງການໜຶ່ງໄປອີກໂຄງການໜຶ່ງ, ຫຼື ສົ່ງໃຫ້ຜູ້ທີ່ເຮັດວຽກໃນໂປຣແກຣມອື່ນ. ຊຸດປະເພດມີແຕ່ລະປະເພດຝາພ້ອມຊັ້ນ, ຄວາມໜາ, ວັດສະດຸ, ແກນ, ຊ່ອງວ່າງ, ລຳດັບຄວາມສຳຄັນຂອງຊັ້ນ, ລະດັບການພັດທະນາ, ຂໍ້ມູນປະລິມານ ແລະ ລະຫັດການຈັດປະເພດ, ພ້ອມ family ໃດໆທີ່ທ່ານເພີ່ມ. ມັນເປັນໄຟລ໌ເປີດ: ເປັນຂໍ້ຄວາມ JSON ທຳມະດາທີ່ທຸກຄົນອ່ານໄດ້, ຫຼື ເປັນໄຟລ໌ IFC. ບໍ່ມີຫຍັງໃນມັນຖືກລັອກໄວ້ກັບບໍລິສັດ, ປະເທດ ຫຼື ບັນຊີໃດໆ.

## ບັນທຶກປະເພດຈາກໂຄງການ

1. ເປີດ **Data** ໃນແຖບໂມເດວ ແລ້ວເລືອກ {{ui:Type packs}}.
2. ພາຍໃຕ້ {{ui:Save types from this project}}, ໃສ່ເຄື່ອງໝາຍໃນປະເພດຝາທີ່ຈະໃສ່. ປະເພດຂອງໂຄງການເອງຖືກໃສ່ເຄື່ອງໝາຍໄວ້ແລ້ວ; ປະເພດເລີ່ມຕົ້ນສາມາດເພີ່ມເຂົ້າໄດ້ ແລະ ຈະຖືກໃສ່ເປັນສຳເນົາ. ໃສ່ເຄື່ອງໝາຍໃນ family ຖ້າທ່ານຕ້ອງການໃຫ້ມັນຢູ່ນຳ.
3. ພິມ {{ui:Pack name}}.
4. {{ui:Save as a pack (.json)}} ຈະດາວໂຫລດໄຟລ໌ `.cctypes.json`. {{ui:Save as IFC (.ifc)}} ຈະດາວໂຫລດໄຟລ໌ IFC ທີ່ມີແຕ່ປະເພດເທົ່ານັ້ນ: ແຕ່ລະປະເພດຝາເປັນ IfcWallType ພ້ອມຊຸດຊັ້ນວັດສະດຸ, ວັດສະດຸ ແລະ ການຈັດປະເພດ, ສຳລັບໂປຣແກຣມ BIM ໃດກໍໄດ້.

## ເພີ່ມປະເພດເຂົ້າໃນໂຄງການ

1. ໃນກ່ອງໂຕ້ຕອບດຽວກັນ, ເລືອກ {{ui:Open a pack or an IFC file…}} ແລ້ວເລືອກໄຟລ໌ pack `.json` ຫຼື ໄຟລ໌ `.ifc`.
2. ກ່ອງໂຕ້ຕອບຈະລາຍການສິ່ງທີ່ໄຟລ໌ມີ: ແຕ່ລະປະເພດຝາພ້ອມຄວາມໜາ, ຈຳນວນຊັ້ນ ແລະ ລະຫັດ, ວັດສະດຸ ແລະ families.
3. ເລືອກສິ່ງທີ່ຈະເກີດຂຶ້ນກັບ {{ui:A type this project already has}}: **Keep the project's** (ເກັບຂອງໂຄງການໄວ້), **Add the pack's as a copy** (ເພີ່ມຂອງ pack ເປັນສຳເນົາ, ມັນຈະໄດ້ຊື່ໃໝ່ລົງທ້າຍດ້ວຍ "(2)"), ຫຼື **Replace it (only when no wall uses it)** (ແທນທີ່ ສະເພາະເມື່ອບໍ່ມີຝາໃດໃຊ້ມັນ).
4. {{ui:Add to the project}}. ກ່ອງໂຕ້ຕອບຈະລາຍການສິ່ງທີ່ຖືກເພີ່ມ, ຄັດລອກ, ແທນທີ່ ຫຼື ເກັບໄວ້. ມັນເປັນໜຶ່ງຂັ້ນຕອນ undo.

ປະເພດໃໝ່ຢູ່ໃນລາຍການປະເພດຂອງເຄື່ອງມືຝາທັນທີ.

## ປະເພດພື້ນ, ຫຼັງຄາ ແລະ ເພດານ

ລາຍການປະເພດທີ່ຈະບັນທຶກຍັງມີປະເພດພື້ນ, ຫຼັງຄາ ແລະ ເພດານຂອງໂຄງການ ພ້ອມປະເພດເລີ່ມຕົ້ນຂອງມັນ (ໝາຍດ້ວຍ Floor, Roof, Ceiling). Pack ສາມາດບັນຈຸທັງສີ່ປະເພດ; ແຕ່ລະປະເພດລະບຸຊັ້ນ IFC ຂອງມັນ (IfcWallType, IfcSlabType, IfcCoveringType). ປະເພດພື້ນ, ຫຼັງຄາ ຫຼື ເພດານທີ່ອົງປະກອບໃຊ້ຢູ່ຈະບໍ່ຖືກແທນທີ່ຈາກ pack: ໃຫ້ປ່ຽນມັນໃນຕົວແກ້ໄຂປະເພດ.

## ປະເພດໜຶ່ງເປັນລາຍການຄັງ

ໃສ່ເຄື່ອງໝາຍໃສ່ປະເພດໜຶ່ງພຽງອັນດຽວ ແລ້ວເລືອກ **Save as a Library item…**. ມັນຈະບັນທຶກໄຟລ໌ `.cctype.json`: ລາຍການຄັງປະເພດ Types ທີ່ເກັບປະເພດນັ້ນໄວ້ (ຊັ້ນ, ວັດສະດຸ, LOD ແລະ ລະຫັດການຈັດປະເພດ). ອັບໂຫຼດໃນຄັງເພື່ອແບ່ງປັນ. **Open a pack or an IFC file** ກໍອ່ານລາຍການແບບນີ້ເຊັ່ນກັນ ແລະ ເພີ່ມປະເພດຂອງມັນເຂົ້າໃນໂຄງການຄືກັບ pack.

## ຂໍ້ຄວນຮູ້

- ໄຟລ໌ IFC ຈາກໂປຣແກຣມອື່ນກໍສາມາດເປີດທີ່ນີ້ໄດ້. ປະເພດຝາທີ່ມີຊັ້ນວັດສະດຸຈະຖືກອ່ານທຸກອັນ: ຊື່, ວັດສະດຸ ແລະ ຄວາມໜາຂອງຊັ້ນ ແລະ ຊ່ອງວ່າງໃດໆແມ່ນຂອງໄຟລ໌ເອງ. ຊັ້ນໃດເປັນແກນ ແລະ ແຕ່ລະຊັ້ນເຮັດໜ້າທີ່ຫຍັງ (ຜິວສຳເລັດ, ໂຄງສ້າງ, ເກັບຄວາມຮ້ອນ) ຖືກຄາດເດົາ, ປະເພດຈະຖືກໝາຍວ່າ **(guessed)**, ແລະ ທ່ານຄວນກວດມັນໃນຕົວແກ້ໄຂປະເພດຝາ. ປະເພດຝາທີ່ບໍ່ມີຊັ້ນຈະຖືກຂ້າມໄປ ແລະ ຖືກລະບຸຊື່.
- ວັດສະດຸທີ່ໂຄງການມີຢູ່ແລ້ວຈະຖືກເກັບໄວ້ຕາມເດີມ. ວັດສະດຸໃໝ່ທີ່ຊື່ຖືກໃຊ້ແລ້ວຈະໄດ້ "(pack)" ຕໍ່ທ້າຍຊື່.
- ປະເພດທີ່ຝາໃຊ້ຢູ່ຈະບໍ່ຖືກແທນທີ່ຈາກ pack ເລີຍ. ໃຫ້ປ່ຽນມັນໃນຕົວແກ້ໄຂປະເພດຝາ, ທີ່ຈະຍ້າຍຝາຂອງມັນຢ່າງຖືກຕ້ອງ.
- ລະຫັດທີ່ຕັ້ງໃສ່ຝາໜຶ່ງຈະບໍ່ເດີນທາງໄປກັບມັນ: ມັນເປັນຂອງຝານັ້ນ. ລະຫັດທີ່ຕັ້ງໃສ່ປະເພດຈະເດີນທາງໄປໄດ້.
- ໄຟລ໌ທີ່ມີຟິລ໌ດທີ່ຮູບແບບບໍ່ມີ, ຊັ້ນທີ່ວັດສະດຸຫາຍໄປ, ຫຼື ສິ່ງທີ່ບໍ່ແມ່ນຂໍ້ຄວາມທຳມະດາ ຈະຖືກປະຕິເສດ, ແລະ ຂໍ້ຄວາມຈະບອກວ່າຢູ່ໃສ ແລະ ເພາະຫຍັງ.
- ຍັງບໍ່ໄດ້ສ້າງ: ປະເພດພື້ນ, ຫຼັງຄາ ແລະ ເພດານ (ພວກມັນບໍ່ມີປະເພດໃນເວີຊັນນີ້: ແຕ່ລະອັນມີຄວາມໜາຂອງມັນເອງ), ປະເພດປະຕູ ແລະ ປ່ອງຢ້ຽມນອກຈາກ family, ແລະ ແຮ໌ຊ ຫຼື ສີຈາກໄຟລ໌ຂອງໂປຣແກຣມອື່ນ.
