## ສິ່ງທີ່ທ່ານຈະເຮັດ

ຍ້າຍໂມເດວລະຫວ່າງສອງໂປຣແກຣມ BIM, ເຊັ່ນຈາກ Revit ໄປ Archicad ແລະ ກັບຄືນ, ຜ່ານ IFC, ໂດຍມີ BimCraft ຢູ່ກາງເພື່ອກວດ, ເພີ່ມເຕີມ ແລະ ລາຍງານວ່າຫຍັງລອດໄປໄດ້. ບໍ່ມີໄຟລ໌ຮູບແບບຂອງໂປຣແກຣມໃດຖືກອ່ານ: ທຸກຢ່າງເດີນທາງເປັນ IFC.

## BimCraft ເກັບຮັກສາຫຍັງ

ເມື່ອທ່ານປ່ຽນໂມເດວໃນ BimCraft ແລ້ວຄລິກ {{ui:Save as IFC}}, ທຸກແຖວທີ່ທ່ານບໍ່ໄດ້ປ່ຽນຈະຖືກຂຽນກັບຄືນໄປຕາມເດີມທຸກປະການ. ດັ່ງນັ້ນ:

- **GlobalId** ຍັງຄືເກົ່າ, ແລະ ໂປຣແກຣມອື່ນສາມາດຈັບຄູ່ແຕ່ລະອົງປະກອບກັບອັນທີ່ມັນສົ່ງໄປ.
- **ຊຸດຄຸນສົມບັດ** ແລະ ຄ່າຂອງມັນຍັງຢູ່, ຍົກເວັ້ນຄ່າທີ່ທ່ານປ່ຽນ.
- **ການຈັດປະເພດ** ຍັງຕິດຢູ່ກັບອົງປະກອບຂອງມັນ.

## ຕັ້ງຄ່າທັງສອງໂປຣແກຣມໃຫ້ໃຊ້ຄຸນສົມບັດດຽວກັນ

1. ເປີດໂມເດວໃນ BimCraft (ແລະ ຊຸດໂຄງການ, ຖ້າທ່ານມີ: ກຸ່ມຄຸນສົມບັດຂອງມັນຈະຖືກເພີ່ມເຂົ້າ).
2. ໃນແຜງດ້ານຊ້າຍ, ເປີດ {{ui:Between two BIM programs}}.
3. ພາຍໃຕ້ **Property mapping**, ດາວໂຫລດສິ່ງທີ່ແຕ່ລະໂປຣແກຣມຕ້ອງການ:
   - {{ui:Shared parameters}}: ໄຟລ໌ພາລາມິເຕີຮ່ວມ. ໃນ Revit, ໂຫຼດມັນດ້ວຍ Manage › Shared Parameters ແລ້ວເພີ່ມພາລາມິເຕີເຂົ້າໃນໝວດທີ່ຕ້ອງການ.
   - {{ui:IFC export property sets}}: ໄຟລ໌ຊຸດຄຸນສົມບັດທີ່ຜູ້ໃຊ້ກຳນົດ. ໃນການຕັ້ງຄ່າການສົ່ງອອກ IFC ຂອງ Revit, ເລືອກມັນພາຍໃຕ້ user-defined property sets, ເພື່ອໃຫ້ IFC ທີ່ສົ່ງອອກມີຊຸດ ແລະ ຊື່ຄຸນສົມບັດດຽວກັນ.
   - {{ui:Mapping table (CSV)}}: ທຸກຄຸນສົມບັດພ້ອມຊຸດ IFC ແລະ ຊື່ຂອງມັນ, ປະເພດຂອງມັນ, ແລະ ຊື່ທີ່ກົງກັນໃນແຕ່ລະໂປຣແກຣມ. ໄຟລ໌ການຈັບຄູ່ຂອງ Archicad ບໍ່ແມ່ນຮູບແບບທີ່ເປີດເຜີຍ, ດັ່ງນັ້ນໃຫ້ຕັ້ງຄ່າ IFC translator ແລະ property manager ຂອງມັນດ້ວຍຕົນເອງຈາກຕາຕະລາງນີ້.
   - {{ui:Mapping file}}: ການຈັບຄູ່ທັງໝົດເປັນໄຟລ໌ດຽວ, ເພື່ອເກັບໄວ້ກັບໂຄງການ.

ຊຸດມາດຕະຖານ (Pset_ ແລະ Qto_) ຖືກຍົກເວັ້ນຈາກໄຟລ໌ພາລາມິເຕີຮ່ວມ: ທັງສອງໂປຣແກຣມຂຽນພວກມັນຈາກຂໍ້ມູນຂອງຕົນເອງ.

## ສົ່ງໂມເດວ ແລະ ນຳມັນກັບຄືນ

1. ສົ່ງອອກ IFC ຈາກໂປຣແກຣມທຳອິດໂດຍເກັບ GlobalId ໄວ້ (Revit: ເປີດ "Store the IFC GUID in an element parameter after export").
2. ເປີດມັນໃນ BimCraft, ກວດມັນ ({{ui:Model checks}}, {{ui:Clash check}}), ເພີ່ມບັນຫາ ({{ui:Issues}}, BCF), ປ່ຽນຄ່າຖ້າທ່ານຕ້ອງການ, ແລະ {{ui:Save as IFC}}.
3. ເປີດ IFC ທີ່ບັນທຶກແລ້ວໃນໂປຣແກຣມທີ່ສອງ, ເຮັດວຽກກັບມັນ, ແລ້ວສົ່ງອອກ IFC ຈາກນັ້ນໂດຍເກັບ GlobalId ໄວ້ (translator ຂອງ Archicad: "Global Unique Identifiers: Keep existing").
4. ກັບມາທີ່ BimCraft, ເປີດໂມເດວທີ່ສົ່ງອອກໄປ, ແລ້ວເພີ່ມອັນທີ່ກັບມາ (**Add a model** ພາຍໃຕ້ Models).
5. ໃນ {{ui:Between two BIM programs}}, ເລືອກ **Went out** ແລະ **Came back**, ແລ້ວຄລິກ {{ui:Make the report}}.

## ອ່ານລາຍງານ

- **ອົງປະກອບ**: ມີຈັກອັນທີ່ກັບມາດ້ວຍ GlobalId ດຽວກັນ, ຈັກອັນທີ່ຫາຍໄປ, ແລະ ຈັກອັນທີ່ໃໝ່. ອົງປະກອບທີ່ມີ GlobalId ໃໝ່ຈະປາກົດເປັນໜຶ່ງອັນທີ່ຫາຍໄປ ແລະ ໜຶ່ງອັນໃໝ່: ໂປຣແກຣມອື່ນບໍ່ໄດ້ເກັບມັນໄວ້.
- **ປະເພດ IFC ປ່ຽນ**: ອົງປະກອບທີ່ກັບມາເປັນປະເພດອົງປະກອບອື່ນ.
- **ຄ່າຄຸນສົມບັດທີ່ເກັບໄວ້**: ສັດສ່ວນຂອງຄ່າທີ່ກັບມາໂດຍບໍ່ປ່ຽນ. ລາຍການຂ້າງລຸ່ມສະແດງຄຸນສົມບັດທີ່ມີຄ່າປ່ຽນແປງ ຫຼື ຫາຍໄປຫຼາຍທີ່ສຸດ.
- **ການຈັດປະເພດ**: ເກັບໄວ້, ປ່ຽນແປງ (ລະບົບດຽວກັນ, ລະຫັດອື່ນ) ຫຼື ຫາຍໄປ.

{{ui:Download the report (CSV)}} ໃຫ້ທຸກຄຸນສົມບັດພ້ອມຈຳນວນຂອງມັນ. ເພື່ອເບິ່ງວ່າອົງປະກອບໃດຍ້າຍ ຫຼື ປ່ຽນຮູບຮ່າງ, ໃຊ້ {{ui:Compare versions}} ກັບໂມເດວສອງອັນດຽວກັນ.

:::note
BimCraft ບໍ່ໄດ້ດຳເນີນການໂປຣແກຣມທັງສອງ. ການຕັ້ງຄ່າໃດທີ່ສົ່ງຄ່າໄປໄດ້ຂຶ້ນກັບການຕັ້ງຄ່າ IFC ຂອງແຕ່ລະໂປຣແກຣມ: ລາຍງານສະແດງສິ່ງທີ່ກັບມາຈິງ, ດັ່ງນັ້ນໃຫ້ລອງການຕັ້ງຄ່າ, ສົ່ງອອກໃໝ່ ແລະ ປຽບທຽບ.
:::

## ບັນຫາເດີນທາງເປັນ BCF

ບັນຫາທີ່ທ່ານຍົກຂຶ້ນໃນ BimCraft ຈະສົ່ງອອກເປັນ BCF ({{ui:Issues}}), ເຊິ່ງທັງສອງໂປຣແກຣມສາມາດອ່ານດ້ວຍເຄື່ອງມື BCF ຂອງພວກມັນ, ດັ່ງນັ້ນຄຳຖາມກ່ຽວກັບອົງປະກອບຈະໄປເຖິງຜູ້ທີ່ເຮັດວຽກໃນອີກໂປຣແກຣມໜຶ່ງພ້ອມມຸມມອງຂອງມັນ.
