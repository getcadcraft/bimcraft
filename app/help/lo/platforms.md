BimCraft ເຮັດວຽກໃນເວີຊັນປັດຈຸບັນຂອງ Chrome, Edge, Firefox ແລະ Safari, ໃນ Mac, Windows ແລະ Linux. ມຸມມອງ 3D ຕ້ອງການ WebGL, ເຊິ່ງທຸກບຣາວເຊີປັດຈຸບັນມີ. ເບິ່ງ [ບຣາວເຊີ ແລະຄອມພິວເຕີ](common:browsers) ສຳລັບສິ່ງທີ່ແອັບຕ້ອງການໂດຍທົ່ວໄປ.

## ເປີດໂຟນເດີ

| ບຣາວເຊີ | {{ui:Open a folder}} ເຮັດຫຍັງ | ລາກໂຟນເດີເຂົ້າມາ | {{ui:Recent folders}} |
|---|---|---|---|
| Chrome, Edge | ຕົວເລືອກໂຟນເດີຂອງບຣາວເຊີ, ແລ້ວ "Let site view files?": ຄລິກ **View files** | ເປີດໂດຍບໍ່ມີຄຳຖາມ | ມີ, ສຳລັບໂຟນເດີທີ່ເລືອກ ຫຼືລາກເຂົ້າມາ |
| Firefox | ຕົວເລືອກໂຟນເດີຂອງລະບົບ | ເປີດໂດຍບໍ່ມີຄຳຖາມ | ບໍ່ມີ |
| Safari | ຕົວເລືອກໂຟນເດີຂອງລະບົບ, ມີປຸ່ມ **Upload** (ບໍ່ມີຫຍັງຖືກອັບໂຫຼດ) | ເປີດໂດຍບໍ່ມີຄຳຖາມ | ບໍ່ມີ |

ຢູ່ເບື້ອງຫຼັງ: Chrome ແລະ Edge ໃຊ້ຕົວເລືອກ File System Access ແລະສາມາດຈື່ໂຟນເດີໄດ້. Firefox ແລະ Safari ໃຊ້ຕົວເລືອກໂຟນເດີແບບເກົ່າ, ທີ່ສົ່ງທຸກໄຟລ໌ໃນໂຟນເດີໃຫ້ພ້ອມກັນ ແລະຈື່ບໍ່ໄດ້. ໂຟນເດີທີ່ລາກເຂົ້າມາຖືກອ່ານທີລະລາຍການໃນທຸກບຣາວເຊີ.

:::chromium
Brave ແລະບຣາວເຊີ Chromium ອື່ນບາງອັນປິດຕົວເລືອກໂຟນເດີ. ຫຼັງຈາກນັ້ນ BimCraft ໃຊ້ຕົວເລືອກໂຟນເດີຂອງລະບົບແທນ, ແລະບຣາວເຊີອາດຖາມວ່າ "Upload *n* files to this site?". ບໍ່ມີຫຍັງຖືກອັບໂຫຼດ; ໄຟລ໌ພຽງແຕ່ໄປຫາແທັບ. ການລາກໂຟນເດີເຂົ້າມາຊ່ວຍຫຼີກເວັ້ນຄຳຖາມນີ້.
:::

## Mac, Windows ແລະ Linux

- ທາງລັດທີ່ຂຽນ {{key:Mod+S}} ແລະ {{key:Mod+Z}} ແມ່ນ Command ໃນ Mac ແລະ Ctrl ໃນ Windows ແລະ Linux.
- {{key:Ctrl+Shift+F}} (ໂໝດໜ້າຈໍ) ແມ່ນ Control ໃນທຸກແພລດຟອມ, ລວມທັງ Mac.
- ກ່ອງໂຕ້ຕອບໄຟລ໌ ແລະໂຟນເດີດາວໂຫຼດແມ່ນຂອງລະບົບຂອງທ່ານເອງ.

## ເມົ້າສ໌, ແທັກແພດ ແລະການສຳຜັດ

| ອຸປະກອນປ້ອນ | ມຸມມອງ 3D | ການແຕ້ມ 2D |
|---|---|---|
| ເມົ້າສ໌ | ລາກຊ້າຍເພື່ອໝຸນ, ລາກຂວາເພື່ອເລື່ອນ, ລໍ້ເພື່ອຊູມ, ຄລິກເພື່ອເລືອກ | ລາກໃດກໍໄດ້ເພື່ອເລື່ອນ, ລໍ້ເພື່ອຊູມ, ດັບເບີ້ນຄລິກເພື່ອພໍດີ |
| ແທັກແພດ | ຄລິກ-ລາກເພື່ອໝຸນ; {{key:Shift}} ຫຼື {{key:Mod}} ແລະລາກເພື່ອເລື່ອນ; ເລື່ອນສອງນິ້ວ ຫຼືຢິກເພື່ອຊູມ | ຄລິກ-ລາກເພື່ອເລື່ອນ; ເລື່ອນສອງນິ້ວ ຫຼືຢິກເພື່ອຊູມ |
| ການສຳຜັດ | ນິ້ວດຽວເພື່ອໝຸນ, ສອງນິ້ວຢິກ ແລະເລື່ອນ, ແຕະເພື່ອເລືອກ | ນິ້ວດຽວເພື່ອເລື່ອນ; ຍັງບໍ່ມີການຢິກເພື່ອຊູມ; ແຕະ {{ui:Fit}} |

ໃນແທັກແພດ Mac, ຄລິກຂວາແມ່ນການຄລິກສອງນິ້ວ (ຫຼື Control-click). ເບິ່ງ [ແປ້ນພິມ, ເມົ້າສ໌ ແລະແທັກແພດ](common:keys).

ແທັບເລັດ ແລະໂທລະສັບສາມາດເປີດໄຟລ໌ດຽວ ແລະເບິ່ງມັນໄດ້, ແຕ່ໜ້າຈໍນ້ອຍ, ບຣາວເຊີມືຖືຫຼາຍອັນບໍ່ສາມາດເລືອກໂຟນເດີໄດ້, ແລະໂມເດວໃຫຍ່ອາດບໍ່ພໍດີກັບໜ່ວຍຄວາມຈຳຂອງມັນ. ຄອມພິວເຕີເຮັດວຽກໄດ້ດີທີ່ສຸດ.

## ໄຟລ໌ໃຫຍ່ ແລະໜ່ວຍຄວາມຈຳ

ທຸກສິ່ງທີ່ BimCraft ອ່ານຢູ່ໃນໜ່ວຍຄວາມຈຳຂອງແທັບບຣາວເຊີ. ແທັບສາມາດໃຊ້ໄດ້ຫຼາຍເທົ່າໃດ ຂຶ້ນຢູ່ກັບບຣາວເຊີ ແລະຄອມພິວເຕີຂອງທ່ານ, ຫຼາຍກວ່າຂຶ້ນກັບ BimCraft.

| ໄຟລ໌ | ອ່ານເທົ່າໃດ | ຄາດຫວັງຫຍັງ |
|---|---|---|
| IFC | ທັງໝົດຂອງໄຟລ໌, ພ້ອມຮູບຮ່າງ 3D ທີ່ສ້າງຈາກມັນ | ຂຶ້ນກັບຄອມພິວເຕີ ແລະບຣາວເຊີຂອງທ່ານ; ໂມເດວຫຼາຍຮ້ອຍເມກາໄບຕ໌ອາດຫຼາຍເກີນໄປສຳລັບແລັບທັອບ. ເກີນ 1.5 ລ້ານສາມຫຼ່ຽມ, ຂອບຖືກປິດ |
| ໄຟລ໌ໂຄງການ ແລະຕະກູນ | ປະມານ 40 KB ຫາ 100 KB, ບໍ່ວ່າຂະໜາດໃດ | ແມ້ໂມເດວສູນກາງທີ່ໃຫຍ່ຫຼາຍຈະເປີດໃນໄວ, ເຖິງຈາກໄດຣຟ໌ເຄືອຂ່າຍ |
| DWG ແລະ DXF | ທັງໝົດຂອງໄຟລ໌ | ແບບແຕ້ມທີ່ໃຫຍ່ຫຼາຍສະແດງ "This drawing is very large; only part of it is shown." |
| ໂຟນເດີ | ລາຍຊື່ໄຟລ໌, ບວກກັບບໍ່ເທົ່າໃດກິໂລໄບຕ໌ຕໍ່ໂມເດວ | ເຖິງ 20,000 ໄຟລ໌ |

ຖ້າແທັບໝົດໜ່ວຍຄວາມຈຳ, ບຣາວເຊີສະແດງໜ້າຜິດພາດຂອງມັນເອງ ("Aw, Snap!" ໃນ Chrome, ຕົວຢ່າງ). ປິດແທັບອື່ນ, ໂຫຼດ BimCraft ໃໝ່ ແລະລອງອີກ, ຫຼືໃຊ້ຄອມພິວເຕີທີ່ມີໜ່ວຍຄວາມຈຳຫຼາຍກວ່າ.
