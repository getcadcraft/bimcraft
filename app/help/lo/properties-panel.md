## ອົງປະກອບ IFC

ສ່ວນເທິງຂອງແຜງ {{ui:Properties}} ສະແດງປະເພດຂອງອົງປະກອບໂດຍບໍ່ມີຄຳນຳໜ້າ "Ifc" (ຕົວຢ່າງ "Door", "WallStandardCase", "FurnishingElement") ແລະ ຊື່ຂອງມັນ, ຫຼື "Unnamed".

| ຊ່ອງ | ຄວາມໝາຍ | ແກ້ໄຂໄດ້ |
|---|---|---|
| Name (ຊື່) | ຊື່ຂອງອົງປະກອບ, ມັກເປັນຊື່ຄອບຄົວ ແລະ ຊື່ປະເພດຈາກຕົວສົ່ງອອກ | ແມ່ນ |
| ຊະນິດ | ຊື່ຂອງປະເພດອົງປະກອບ, ເມື່ອມີ | ບໍ່ແມ່ນ |
| ຊະນິດວັດຖຸ | ຄຳອະທິບາຍປະເພດເປັນຂໍ້ຄວາມອິດສະຫຼະ ທີ່ຕົວສົ່ງອອກບາງອັນໃສ່ໃຫ້ | ແມ່ນ |
| Tag (ແທັກ) | ແທັກ ຫຼື ເຄື່ອງໝາຍຂອງອົງປະກອບ; ຕົວສົ່ງອອກຫຼາຍອັນຂຽນລະຫັດອົງປະກອບໄວ້ບ່ອນນີ້ | ແມ່ນ |
| Description (ຄຳອະທິບາຍ) | ຂໍ້ຄວາມອິດສະຫຼະ | ແມ່ນ |
| GlobalId | ລະຫັດ IFC ຖາວອນ 22 ຕົວອັກສອນຂອງອົງປະກອບ, ຄືກັນໃນທຸກການສົ່ງອອກຂອງອົງປະກອບດຽວກັນ | ບໍ່ແມ່ນ |
| Line (ແຖວ) | ເລກແຖວຂອງອົງປະກອບ (`#1234`) ໃນໄຟລ໌ IFC ນີ້. ມັນປ່ຽນໄປລະຫວ່າງການສົ່ງອອກ | ບໍ່ແມ່ນ |

ດ້ານລຸ່ມມີ **ຊຸດຄຸນສົມບັດ**, ຈັດຕາມຊື່:

- ແຕ່ລະຊຸດເປີດ ແລະ ປິດເມື່ອທ່ານກົດຊື່ຂອງມັນ. ສາມອັນທຳອິດເປີດຢູ່.
- ຊຸດທີ່ມີ "(type)" ເປັນຂອງປະເພດອົງປະກອບ: "Type property: ການປ່ຽນແປງຢູ່ນີ້ໃຊ້ກັບທຸກອົງປະກອບຂອງປະເພດນີ້."
- ຊຸດປະລິມານ (ຄວາມຍາວ, ເນື້ອທີ່, ບໍລິມາດ, ຈຳນວນ, ນ້ຳໜັກ) ອ່ານໄດ້ຢ່າງດຽວ.
- ລາຍການ ແລະ ຄ່າແບບກຳນົດໄວ້ແລ້ວ ສະແດງ ແຕ່ອ່ານໄດ້ຢ່າງດຽວ.
- ຄ່າ Yes/No ສະແດງເປັນ **ແມ່ນ** ຫຼື **ບໍ່ແມ່ນ**.
- ຕົວເລກຖືກປັດເປັນສີ່ຕຳແໜ່ງທົດສະນິຍົມເພື່ອສະແດງ. ຄວາມຍາວ (ຄຸນສົມບັດຄວາມຍາວ ຫຼື ຄວາມຍາວຂອງປະລິມານ) ສະແດງໃນ {{ui:Units}} ທີ່ເລືອກໃນແຖບເຄື່ອງມື, ພ້ອມໜ່ວຍຂ້າງໆ, ແລະ ທ່ານສາມາດພິມຄ່າໃໝ່ໃນໜ່ວຍນັ້ນ ຫຼື ດ້ວຍເຄື່ອງໝາຍໜ່ວຍອື່ນ (2.4 m, 8'-0"): BimCraft ຂຽນເລກຂອງໄຟລ໌ຄືນໃຫ້. ຕົວເລກອື່ນສະແດງຕາມທີ່ໄຟລ໌ເກັບໄວ້.
- ຄ່າວ່າງສະແດງເປັນ *ວ່າງ*. ຄ່າທີ່ແກ້ໄຂແລ້ວເປັນໂຕໜາ ແລະ ມີແຖບສີຟ້າຢູ່ຂ້າງ.

## ສຳເນົາຄ່າ

ທຸກຄ່າໃນ {{ui:Properties}} ມີປຸ່ມສຳເນົານ້ອຍຢູ່ຂ້າງ: ກົດມັນເພື່ອໃສ່ຄ່ານັ້ນໃສ່ຄລິບບອດຕາມທີ່ສະແດງ, ຕົວຢ່າງ GlobalId, ເລກລຳດັບ ຫຼື ຄ່າຊຸດຄຸນສົມບັດໃດກໍໄດ້. ການສຳເນົາບໍ່ເຄີຍເລີ່ມການແກ້ໄຂ.

ດ້ານເທິງ, {{ui:Copy all}} ສຳເນົາທຸກຄ່າຂອງອົງປະກອບເປັນຂໍ້ຄວາມ, ຈັດຕາມຊຸດ, ແລະ {{ui:Copy as CSV}} ສຳເນົາເປັນແຖວຂອງກຸ່ມ, ຄຸນສົມບັດ ແລະ ຄ່າ ເພື່ອວາງໃນສະເປຣດຊີດ; ຄ່າວ່າງຖືກເກັບໄວ້ ເພື່ອໃຫ້ທຸກຊ່ອງມີແຖວ. ວິທີນີ້ໃຊ້ໄດ້ກັບອົງປະກອບຂອງໂມເດວອື່ນທີ່ເປີດຢູ່ເຊັ່ນກັນ; ເມື່ອມີຫຼາຍໂມເດວເປີດ, CSV ເລີ່ມດ້ວຍຖັນ Model ທີ່ລະບຸຊື່ໄຟລ໌.
