## ສິ່ງທີ່ທ່ານຈະເຮັດ

ເປີດ **ຊຸດໂຄງການ (project bundle)** (`.ccbundle.zip`) ແລະ ເຮັດວຽກກັບໂຄງການຕາມທີ່ມັນຖືກຈັດໄວ້: ມຸມມອງ, ແບບຈັດວາງ ແລະ ກຸ່ມຄຸນສົມບັດ, ຢູ່ເທິງໂມເດວ.

ຊຸດໂຄງການປະກອບມີ:

- ໂມເດວເປັນ IFC,
- ແບບຈັດວາງເປັນ PDF ແລະ DWG,
- ລາຍການສິ່ງທີ່ IFC ບໍ່ໄດ້ລວມໄວ້: ມຸມມອງ (ແຕ່ລະອັນພ້ອມຊັ້ນ, ການລວມເລເຢີ ແລະ ມາດຕາສ່ວນ), ແບບຈັດວາງ ແລະ ແບບທີ່ວາງຢູ່ເທິງມັນ, ນິຍາມຄຸນສົມບັດໃນກຸ່ມຂອງມັນ, ການຈັດປະເພດ, ແລະ ມາດຕະຖານເຊັ່ນ ເລເຢີ, ຊຸດປາກກາ, ປະເພດເສັ້ນ, ການເຕີມ, ພື້ນຜິວ ແລະ ອົງປະກອບປະສົມ.

ຊຸດເຫຼົ່ານີ້ຖືກສ້າງໂດຍສະຄຣິບໂອເພນຊອດທີ່ແລ່ນຢູ່ໃນ Archicad ແລະ ຂໍລາຍການເຫຼົ່ານີ້ຈາກ Archicad ເອງ. BimCraft ບໍ່ອ່ານໄຟລ໌ `.pln` ຫຼື `.tpl` ໂດຍກົງ; ເບິ່ງ [ເປີດໄຟລ໌ໂຄງການ .pln ແລະ .pla](topic:pln-project-files).

## ສ້າງຊຸດໂຄງການ

ສະຄຣິບນີ້ຢູ່ໃນຂັ້ນທົດລອງ: ມັນຍັງບໍ່ໄດ້ຖືກທົດສອບກັບທຸກເວີຊັນຂອງ Archicad. ດາວໂຫຼດຈາກ [github.com/getcadcraft/bim-project-bundle](https://github.com/getcadcraft/bim-project-bundle). ທ່ານຕ້ອງໃຊ້ Archicad 24 ຫຼື ໃໝ່ກວ່າ ແລະ Python 3.8 ຫຼື ໃໝ່ກວ່າ; ບໍ່ມີອັນອື່ນທີ່ຕ້ອງຕິດຕັ້ງ.

1. ບັນທຶກ `archicad_bundle.py` ໄວ້ໃນໂຟນເດີ, ຕົວຢ່າງ `C:\cc-bundle`.
2. ໃນ Archicad, ເປີດໂຄງການ ແລ້ວສ້າງຊຸດ publisher ຊື່ **CadCraft bundle** ໃຫ້ຖືກຕ້ອງຕາມນີ້: ມຸມມອງ 3D ເປັນ IFC, ທຸກແບບຈັດວາງເປັນ PDF, ແລະ ທຸກແບບຈັດວາງອີກຄັ້ງເປັນ DWG, ເຜີຍແຜ່ເປັນໄຟລ໌ໃນດິດສະກ໌ ໃນໂຟນເດີດຽວທີ່ບໍ່ມີໂຟນເດີຍ່ອຍ.
3. ເມື່ອໂຄງການເປີດຢູ່, ແລ່ນ `python archicad_bundle.py --probe --out .` ໜຶ່ງຄັ້ງ. ມັນອ່ານຢ່າງດຽວ ແລະ ຂຽນ `probe.json`.
4. ແລ່ນ `python archicad_bundle.py --out . --translator "IFC4 Reference View"` (ໃຊ້ translator IFC ທີ່ທ່ານເລືອກ). Archicad ເຜີຍແຜ່ຊຸດນັ້ນ ແລະ ສະຄຣິບຂຽນ `<project>.ccbundle.zip`.

ຖ້າການເຜີຍແຜ່ຜ່ານສະຄຣິບລົ້ມເຫຼວ, ໃຫ້ເຜີຍແຜ່ຊຸດດ້ວຍມື ແລ້ວແລ່ນ `python archicad_bundle.py --out . --no-publish --files <folder>\*.ifc <folder>\*.pdf <folder>\*.dwg`. README ຂອງ repository ມີທຸກຕົວເລືອກ. ຖ້າມີສິ່ງໃດບໍ່ເຂົ້າມາ, ໃຫ້ເປີດ issue ໃນ repository ນັ້ນ ແລະ ແນບ `probe.json`.

## ເປີດຊຸດ

1. ຄລິກ {{ui:ເລືອກໄຟລ໌}}, ຫຼື ລາກ `.ccbundle.zip` ໃສ່ BimCraft. ໃນໂຟນເດີທີ່ທ່ານເປີດດ້ວຍ {{ui:ເປີດໂຟນເດີ}}, ຊຸດຈະຖືກລາຍການພາຍໃຕ້ **ຊຸດໂຄງການ**; ຄລິກຊື່ຂອງມັນ.
2. ໂມເດວຈະເປີດຄືກັບ IFC ທົ່ວໄປ, ແລະ ພາກ **ຊຸດໂຄງການ** ຈະປາກົດທາງຊ້າຍ ໃຕ້ຂໍ້ມູນຂອງໄຟລ໌.

ບໍ່ມີຫຍັງຖືກອັບໂຫຼດ: ຊຸດຖືກອ່ານໃນຄອມພິວເຕີຂອງທ່ານ ເທື່ອລະໄຟລ໌, ດັ່ງນັ້ນໂມເດວຂະໜາດໃຫຍ່ຈະບໍ່ຖືກສຳເນົາສອງຄັ້ງ.

## ສະແດງມຸມມອງ

ພາຍໃຕ້ **ມຸມມອງ**, ມຸມມອງຖືກຈັດກຸ່ມຕາມໂຟນເດີທີ່ພວກມັນມີໃນໂຄງການ. ຄລິກຊື່ຂອງມຸມມອງ:

- **ແຜນຜັງຊັ້ນ** ສະແດງສະເພາະຊັ້ນຂອງມັນ, ເບິ່ງຈາກເທິງ.
- **ການລວມເລເຢີຂອງມັນ** ເຊື່ອງອົງປະກອບໃນເລເຢີທີ່ການລວມນັ້ນເຊື່ອງ. ແຖບສະຖານະບອກວ່າເຊື່ອງໄດ້ກີ່ອົງປະກອບ.
- **ມາດຕາສ່ວນຂອງມັນ** ສະແດງຢູ່ຂ້າງຊື່ ແລະ ໃນແຖບສະຖານະ.
- **ມຸມມອງ 3D** ສະແດງທຸກຊັ້ນ.

ເພື່ອສະແດງທຸກຢ່າງອີກຄັ້ງ ໃຫ້ໃຊ້ {{ui:ສະແດງທັງໝົດ}} ໃນ {{ui:ສະແດງ}} ແລ້ວໃສ່ເຄື່ອງໝາຍທຸກຊັ້ນ.

:::note
BimCraft ຊອກເລເຢີຜ່ານການກຳນົດເລເຢີຂອງໄຟລ໌ IFC. ຖ້າ IFC ຖືກສົ່ງອອກໂດຍບໍ່ມີສິ່ງນີ້, ການລວມເລເຢີຈະບໍ່ເຊື່ອງຫຍັງເລີຍ ແລະ ແຖບສະຖານະຈະບອກວ່າເຊື່ອງ 0 ອົງປະກອບ.
:::

## ເປີດແບບຈັດວາງ

ພາຍໃຕ້ **ແບບຈັດວາງ**, ແຕ່ລະແບບສະແດງເລກ, ຊື່, ຂະໜາດເຈ້ຍ ແລະ ມຸມມອງທີ່ວາງຢູ່ເທິງມັນ.

- **PDF** ບັນທຶກ PDF ຂອງແບບຈັດວາງຈາກຊຸດ.
- **DWG** ເປີດແບບຂອງແບບຈັດວາງໃນມຸມມອງ 2D. ຄລິກມຸມມອງໃດກໍໄດ້ເພື່ອກັບໄປທີ່ໂມເດວ.
- **ເປີດໃນ …** ສົ່ງໄຟລ໌ຂອງແບບຈັດວາງໄປຫາແອັບທີ່ເຮັດວຽກກັບມັນ ໃນແຖບໃໝ່: PDF ໄປ MarkupCraft, DWG ໄປ CadCraft. ມັນສະແດງພຽງບ່ອນທີ່ແອັບນັ້ນເປີດຢູ່ຄຽງຂ້າງ BimCraft. ໄຟລ໌ຖືກອ່ານຈາກຊຸດໃນຂະນະທີ່ແຖບກຳລັງໂຫຼດ ແລະ ບໍ່ມີການອັບໂຫຼດ.

ແບບຈັດວາງທີ່ບໍ່ມີທັງສອງຢ່າງຈະສະແດງ **ບໍ່ມີໄຟລ໌ໃນຊຸດ**.

## ເບິ່ງຄຸນສົມບັດໃນກຸ່ມຂອງໂຄງການ

ເລືອກອົງປະກອບໜຶ່ງ. **ກຸ່ມຄຸນສົມບັດ** ສະແດງຄຸນສົມບັດຂອງມັນພາຍໃຕ້ກຸ່ມທີ່ໂຄງການກຳນົດ, ຈັບຄູ່ຜ່ານຊຸດຄຸນສົມບັດ ແລະ ຊື່ທີ່ນິຍາມໃຫ້ IFC, ຫຼື ຖ້າບໍ່ມີ ກໍຈັບດ້ວຍຊື່ຂອງມັນ. ສ່ວນທີ່ເຫຼືອຍັງຢູ່ໃນ {{ui:ຄຸນສົມບັດ}} ຕາມປົກກະຕິ. **ນິຍາມຄຸນສົມບັດ** ລາຍການນິຍາມທຸກອັນພ້ອມກຸ່ມ, ປະເພດ ແລະ ຊື່ IFC ຂອງມັນ.

## ມາດຕະຖານ ແລະ ໝາຍເຫດ

- **ມາດຕະຖານ** ນັບເລເຢີ, ການລວມເລເຢີ, ຊຸດປາກກາ, ປະເພດເສັ້ນ, ການເຕີມ, ພື້ນຜິວ, ອົງປະກອບປະສົມ ແລະ ວັດສະດຸໃນຊຸດ.
- **ໝາຍເຫດ** ລາຍການສິ່ງທີ່ສະຄຣິບບໍ່ສາມາດເອົາຈາກເວີຊັນ Archicad ນັ້ນ, ຊ່ອງໃດກໍໄດ້ທີ່ BimCraft ອ່ານບໍ່ໄດ້, ແລະ ໄຟລ໌ໃດກໍໄດ້ທີ່ຊຸດອ້າງຊື່ແຕ່ບໍ່ມີຢູ່.

## ການແກ້ບັນຫາ

- **"… is a zip but not a project bundle."** ໄຟລ໌ zip ບໍ່ມີ `manifest.json`. ໃຫ້ແຕກໄຟລ໌ zip ແລ້ວເປີດ `.ifc` ທີ່ຢູ່ຂ້າງໃນ.
- **"… is a newer project bundle than this BimCraft reads."** ໃຫ້ອັບເດດ BimCraft.
- **"… does not hold the model its manifest names."** ໄຟລ໌ zip ຖືກຕັດສັ້ນ ຫຼື ຖືກແກ້ໄຂ. ໃຫ້ສ້າງຊຸດໃໝ່.
- **ມຸມມອງສະແດງທຸກຊັ້ນ.** ຊັ້ນຂອງມັນບໍ່ຢູ່ໃນ IFC ຂອງໂມເດວ (ແຖບສະຖານະບອກແບບນັ້ນ). ໃຫ້ກວດວ່າການສົ່ງອອກ IFC ລວມຊັ້ນນັ້ນ.

ເບິ່ງເພີ່ມເຕີມ [ເຮັດວຽກລະຫວ່າງສອງໂປຣແກຣມ BIM](topic:two-bim-programs) ແລະ [BimCraft ອ່ານຫຍັງຈາກແຕ່ລະຮູບແບບ](topic:file-formats).
