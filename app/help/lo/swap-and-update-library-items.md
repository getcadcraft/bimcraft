## ສິ່ງທີ່ທ່ານຈະເຮັດ

ປ່ຽນໃຈກ່ຽວກັບລາຍການໂດຍບໍ່ຕ້ອງຍ້າຍມັນອີກ, ແລະ ຮັກສາລາຍການຄັງໃນແບບໃຫ້ທັນສະໄໝ.

## ປ່ຽນລາຍການໜຶ່ງ

1. ຄລິກລາຍການຄັງທີ່ວາງແລ້ວໃນແບບ.
2. ໃນ {{ui:ຄຸນສົມບັດ}}, ຄລິກ {{ui:ປ່ຽນລາຍການ…}} ໃນກ່ອງ **ລາຍການຄັງ**. ແຖບ {{ui:ຄັງ}} ຈະເປີດ.
3. ຊອກລາຍການໃໝ່ ແລ້ວຄລິກບັດຂອງມັນ.
4. ຄລິກ **ປ່ຽນ … ເປັນອັນນີ້**.

ອົງປະກອບຮັກສາຕຳແໜ່ງ, ການຫັນ, ຊັ້ນ, ເລກລາຍການ, ປະລິມານ ແລະ ໝາຍເຫດຂອງມັນ. ປະເພດ, ຮູບຮ່າງ ແລະ ຂໍ້ມູນຂອງມັນປ່ຽນເປັນລາຍການໃໝ່. ລາຍການທີ່ວາງໄວ້ດ້ວຍວິທີດຽວກັນຈະໃຊ້ປະເພດດຽວກັນ, ຄືກັບຕອນທີ່ທ່ານວາງ.

ລາຍການທີ່ມີ variant (ເບິ່ງ [ວາງ ແລະ ປ່ຽນລາຍການຄັງທີ່ມີ variant](topic:library-variants)) ຈະລາຍຊື່ variant ອື່ນຂອງມັນຢູ່ເທິງສຸດຂອງແຖບ {{ui:ຄັງ}} ເມື່ອທ່ານປ່ຽນມັນ: ຄລິກໜຶ່ງເທື່ອຕໍ່ອັນ.

ເມື່ອລາຍການໃໝ່ເປັນສິ່ງຄົນລະປະເພດ, ເຊັ່ນ ອ່າງລ້າງໃນບ່ອນຂອງໂຕະ, ຄລາດ IFC ຂອງອົງປະກອບຈະປ່ຽນໃຫ້ກົງກັນ (ຈາກ furnishing element ເປັນ sanitary terminal ໃນຕົວຢ່າງນີ້), ເພື່ອໃຫ້ຊອບແວອື່ນຈັດຕາຕະລາງມັນໄດ້ຖືກຕ້ອງ. ມັນຍັງເປັນອົງປະກອບດຽວກັນ, ມີ GlobalId ດຽວກັນ, ດັ່ງນັ້ນການເຊື່ອມໂຍງກັບມັນຍັງໃຊ້ໄດ້. {{key:Mod+Z}} ເອົາຄລາດເກົ່າ ແລະ ລາຍການເກົ່າກັບຄືນ.

## ກວດການອັບເດດ

1. ຄລິກ {{ui:ອັບເດດ}} ໃນແຖບເຄື່ອງມື (ຫຼື {{ui:ກວດກາການອັບເດດ}} ໃນກ່ອງຂອງລາຍການຄັງ).
2. ອ່ານລາຍຊື່: ແຕ່ລະລາຍການຄັງໃນແບບພ້ອມເວີຊັນໃນແບບ, ເວີຊັນຫຼ້າສຸດ ແລະ ສະຖານະ: **ເປັນປັດຈຸບັນ**, **ເວີຊັນໃໝ່**, **ຖອນອອກແລ້ວ** ຫຼື **ບໍ່ພົບ**. ມັນຍັງບອກວ່າອັນໃດປ່ຽນ (ເລຂາຄະນິດ, ຂໍ້ມູນ, ໃບອະນຸຍາດ ຫຼື ການແກ້ໄຂ).
3. ຄລິກ {{ui:ອັບເດດ}} ຢູ່ແຖວ, ຫຼື {{ui:ອັບເດດທັງໝົດ}}.

## ສິ່ງທີ່ທ່ານຄວນເຫັນ

- "ອັບເດດແລ້ວ *n* ຕຳແໜ່ງ. ຕຳແໜ່ງ, ເລກລາຍການ, ປະລິມານ ແລະ ໝາຍເຫດຖືກຮັກສາໄວ້."
- ແຖວ "ອັບເດດແລ້ວ: *item*" ໃນລາຍການການປ່ຽນແປງ. {{key:Mod+Z}} ຍ້ອນກັບແຕ່ລະອັນ.

## ຄວນຮູ້

- ມີແຕ່ລາຍການທີ່ມາຈາກຄັງເທົ່ານັ້ນທີ່ກວດໄດ້. ລາຍການຈາກໄຟລ໌ບໍ່ມີ id ຄັງ.
- ເມື່ອໃບອະນຸຍາດປ່ຽນ, ສຳເນົາທີ່ທ່ານວາງໄວ້ແລ້ວຈະຄົງໃບອະນຸຍາດທີ່ມາກັບມັນ ຈົນກວ່າທ່ານຈະອັບເດດມັນ.
- ລາຍການ **ຖອນອອກແລ້ວ** ຈະບໍ່ຖືກສະເໜີສຳລັບການວາງໃໝ່. ອັນທີ່ຖອນອອກເພາະລິຂະສິດບໍ່ສາມາດດາວໂຫຼດໄດ້ເລີຍ; ໃຫ້ແທນທີ່ມັນດ້ວຍ {{ui:ປ່ຽນລາຍການ…}}.
- variant ທີ່ວາງໄວ້ຈະຍັງເປັນ variant ນັ້ນ ຖ້າເວີຊັນໃໝ່ຂອງລາຍການຍັງມີມັນ; ບໍ່ດັ່ງນັ້ນມັນຈະເອົາ variant ເລີ່ມຕົ້ນຂອງລາຍການ.
- ການກວດສົ່ງແຕ່ id ແລະ ເວີຊັນຂອງລາຍການເທົ່ານັ້ນ, ບໍ່ເຄີຍສົ່ງແບບຂອງທ່ານ.
