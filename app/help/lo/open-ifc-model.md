## ສິ່ງທີ່ທ່ານຈະເຮັດ

ເປີດໂມເດວ IFC, ເຄື່ອນທີ່ຮອບມັນໃນ 3D ແລະ ໄປຫາມຸມມາດຕະຖານ. ປະມານຫ້ານາທີ.

ທ່ານຕ້ອງການໄຟລ໌ `.ifc`. ໂປຣແກຣມ BIM ສ່ວນໃຫຍ່ສົ່ງອອກໄດ້ໜຶ່ງອັນ; ໃນ Revit ມັນຢູ່ທີ່ **File > Export > IFC**. ເບິ່ງ [ເອົາໄຟລ໌ໂຄງການເຂົ້າ 3D ຜ່ານ IFC](topic:rvt-to-ifc).

## ຂັ້ນຕອນ

1. ຄລິກ {{ui:Choose a file}} (ຫຼື ເຂດວາງທີ່ມຸມເທິງຊ້າຍ).
2. ເລືອກໄຟລ໌ `.ifc` ຂອງທ່ານ ແລ້ວຢືນຢັນ.
3. ລໍຖ້າແຖບສະຖານະໃຫ້ສຳເລັດ. ມັນສະແດງ "ກຳລັງເລີ່ມເຄື່ອງຈັກ IFC…" ຄັ້ງທຳອິດ, ແລ້ວ "ກຳລັງອ່ານໂມເດວ…" ແລະ "ກຳລັງສ້າງເລຂາຄະນິດ: … ຈາກ … ອົງປະກອບ".
4. ເບິ່ງໂມເດວ: ມັນເປີດໃນມຸມສາມສ່ວນສີ່, ພໍດີກັບໜ້າຈໍ.
5. ຄລິກ {{ui:Top}} ໃນແຖບເຄື່ອງມືເໜືອໂມເດວ ເພື່ອເບິ່ງລົງກົງໆ.
6. ຄລິກ {{ui:Front}} ເພື່ອເບິ່ງດ້ານໜ້າ, ແລ້ວ {{ui:Side}} ເພື່ອເບິ່ງຈາກດ້ານຂ້າງ.
7. ຄລິກ {{ui:Fit}}, ຫຼື ກົດ {{key:F}}, ເພື່ອກັບໄປມຸມສາມສ່ວນສີ່ຂອງໂມເດວທັງໝົດ.

## ສິ່ງທີ່ທ່ານຄວນເຫັນ

- ໂມເດວຢູ່ກາງ, ມີຂອບສີເຂັ້ມບາງໆເພື່ອໃຫ້ຄືຮູບແຕ້ມ.
- ແຜງ {{ui:File}} ຢູ່ເບື້ອງຊ້າຍ: ຊື່ໄຟລ໌, ຂະໜາດ, schema IFC (ເຊັ່ນ IFC2X3 ຫຼື IFC4), ຊື່ໂຄງການ, ໄລຍະ, ໂປຣແກຣມທີ່ສົ່ງອອກມາຈາກມັນ, ຜູ້ຂຽນ, ວັນທີສົ່ງອອກ, ແລະ ຈຳນວນອົງປະກອບ ແລະ ສາມຫຼ່ຽມ.
- ລາຍການ {{ui:Storeys}} ແລະ {{ui:Elements}} ຢູ່ໃຕ້ມັນ.
- ແຖບສະຖານະ: "ເປີດ *ຊື່ໄຟລ໌*: *n* ອົງປະກອບໃນ *s* s".

## ການເຄື່ອນທີ່

:::mouse
| ເພື່ອ | ເຮັດແນວນີ້ |
|---|---|
| ໝຸນ | ລາກດ້ວຍປຸ່ມຊ້າຍ |
| ເລື່ອນ | ລາກດ້ວຍປຸ່ມຂວາ, ຫຼື ກົດຄ້າງ {{key:Shift}} (ຫຼື {{key:Mod}}) ແລ້ວລາກດ້ວຍປຸ່ມຊ້າຍ |
| ຊູມ | ໝຸນລໍ້ເມົ້າ, ຫຼື ລາກດ້ວຍປຸ່ມກາງ |
| ເບິ່ງທຸກຢ່າງ | ກົດ {{key:F}} ຫຼື ຄລິກ {{ui:Fit}} |
:::

:::mac mouse
ຢູ່ trackpad: ລາກດ້ວຍນິ້ວດຽວທີ່ກົດຄ້າງເພື່ອໝຸນ; ກົດຄ້າງ {{key:Shift}} ຫຼື {{key:Mod}} ແລ້ວລາກເພື່ອເລື່ອນ; ເລື່ອນດ້ວຍສອງນິ້ວ ຫຼື ບີບເພື່ອຊູມ. ການຄລິກດ້ວຍສອງນິ້ວແມ່ນຄລິກຂວາ, ແລະ ທ່ານສາມາດລາກດ້ວຍມັນເພື່ອເລື່ອນໄດ້, ແຕ່ {{key:Shift}} ແລະ ລາກງ່າຍກວ່າ.
:::

:::touch
| ເພື່ອ | ເຮັດແນວນີ້ |
|---|---|
| ໝຸນ | ລາກດ້ວຍນິ້ວດຽວ |
| ຊູມ | ບີບດ້ວຍສອງນິ້ວ |
| ເລື່ອນ | ຍ້າຍສອງນິ້ວຮ່ວມກັນ |
| ເບິ່ງທຸກຢ່າງ | ແຕະ {{ui:Fit}} |
:::

ການໝຸນຈະໝຸນຮອບຈຸດກາງຂອງໂມເດວສະເໝີ. ການເລື່ອນຈະຍ້າຍຈຸດນັ້ນ, ດັ່ງນັ້ນຫຼັງຈາກເລື່ອນດົນ ການໝຸນອາດຮູ້ສຶກບໍ່ຢູ່ກາງ: ຄລິກ {{ui:Fit}} ເພື່ອຕັ້ງຄືນ.

## ມີເງົາ, ຂອບ ຫຼື ໂຄງຮ່າງລວດ

ປຸ່ມນ້ອຍສາມອັນຢູ່ເໜືອ view cube ເລືອກວິທີແຕ້ມໂມເດວ: {{ui:Shaded}}, {{ui:Shaded with edges}} (ຄ່າເລີ່ມຕົ້ນ) ແລະ {{ui:Wireframe}}. ພວກມັນຍັງເປັນຄຳສັ່ງ (View ໃນເມນູ ແລະ ລາຍການ Customize), ດັ່ງນັ້ນພວກມັນສາມາດມີປຸ່ມລັດຂອງຕົນເອງ. {{ui:Plan}}, {{ui:Split}} ແລະ {{ui:3D}} ຢູ່ໃນແຖວ {{ui:View}} ຂອງແຖບເຄື່ອງມື.

## ຄວາມຜິດພາດທົ່ວໄປ

- **ຄາດຫວັງມຸມມອງທີ່ມີຊື່.** BimCraft ມີສີ່ມຸມມອງຄົງທີ່ ({{ui:Fit}}, {{ui:Top}}, {{ui:Front}}, {{ui:Side}}), view cube ຢູ່ມຸມລຸ່ມຂວາ ແລະ ການໝຸນອິດສະຫຼະ. ມັນບໍ່ບັນທຶກມຸມມອງ.
- **ຊອກຫາແຜນ ແລະ ສ່ວນຕັດ.** ບໍ່ມີແຜນ 2D ຫຼື ກ່ອງສ່ວນຕັດໃນການສ້າງນີ້. ຕັດໂມເດວດ້ວຍແຜ່ນ {{ui:Section}} ແຜ່ນດຽວ ([ຕັດໂມເດວ IFC ດ້ວຍແຜ່ນສ່ວນຕັດ](topic:section-plane)), ຫຼື ປິດຊັ້ນ: [ສະແດງ ແລະ ເຊື່ອງຊັ້ນ, ພື້ນທີ່ ແລະ ຂອບ](topic:storeys-and-spaces).
- **ເປີດໄຟລ໌ໂຄງການ ແລະ ຄາດຫວັງ 3D.** ໄຟລ໌ໂຄງການເປີດເປັນບັດໄຟລ໌. ສົ່ງອອກ IFC ກ່ອນ.
- **ເປີດ `.ifczip`.** ແຕກໄຟລ໌ຊິບອອກ, ຫຼື ສົ່ງອອກ `.ifc` ທຳມະດາ.
- **ໂມເດວໃຫຍ່ຫຼາຍເຮັດໃຫ້ແທັບຊ້າ ຫຼື ຢຸດເຮັດວຽກ.** ເບິ່ງ [ເບຣົວເຊີ, ອຸປະກອນ ແລະ ໜ່ວຍຄວາມຈຳ](topic:platforms).
