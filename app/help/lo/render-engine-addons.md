ສ່ວນເສີມ (ການຕັ້ງຄ່າ › ສ່ວນເສີມ) ສາມາດເພີ່ມເອັນຈິນເຂົ້າລາຍການ **ເອັນຈິນ** ຂອງ {{ui:Render}} ໄດ້. ເນື້ອຫາເຕັມສຳລັບຜູ້ຂຽນສ່ວນເສີມແມ່ນຢູ່ໃນພາກທີ 16 ຂອງສະເປັກສ່ວນເສີມ; ໂດຍສັງເຂບ:

- ສ່ວນເສີມລົງທະບຽນເອັນຈິນດ້ວຍ id ທີ່ເລີ່ມດ້ວຍຊື່ຂອງມັນເອງ, ຊື່, ການຕັ້ງຄ່າທາງເລືອກ ແລະ **ຢ່າງໃດຢ່າງໜຶ່ງ** ໂປຣແກຣມທີ່ຈະເປີດ **ຫຼື** ຟັງຊັນ JavaScript ທີ່ແຕ້ມຮູບ.
- ເອັນຈິນທີ່ເປີດໂປຣແກຣມຕ້ອງການສິດ **`engine.run`**, ສະແດງກ່ອນການຕິດຕັ້ງ ແລະ ໃນການຕັ້ງຄ່າ. ມັນເຮັດວຽກພຽງໃນ Studio; ໃນບຣາວເຊີ ມັນສະແດງເປັນໄຟລ໌ໃຫ້ບັນທຶກ.
- ສ່ວນເສີມລະບຸໂປຣແກຣມ (ຊື່ໄຟລ໌ທຳມະດາ, ບໍ່ແມ່ນ shell), ສະຄຣິບທີ່ **ຢູ່ພາຍໃນສ່ວນເສີມທີ່ລົງລາຍເຊັນ**, ແລະ ອາກິວເມນຕ໌ທີ່ປະກອບດ້ວຍຕົວຍຶດຕຳແໜ່ງ ແລະ ຄຳທຳມະດາ. Studio ຊອກຫາໂປຣແກຣມ ຫຼື ຂໍໃຫ້ທ່ານຊີ້ບອກຕຳແໜ່ງຂອງມັນຄັ້ງດຽວ.
- ຄັ້ງທຳອິດທີ່ສ່ວນເສີມເປີດໂປຣແກຣມ, **Studio ຈະຖາມທ່ານໃນກ່ອງໂຕ້ຕອບຂອງມັນເອງ**: ສ່ວນເສີມໃດ, ໂປຣແກຣມໃດ, ແລະ ສະຄຣິບສາມາດເຮັດສິ່ງໃດກໍໄດ້ທີ່ໂປຣແກຣມເຮັດໄດ້. ອະນຸຍາດສະເພາະສ່ວນເສີມທີ່ທ່ານເຊື່ອຖື. ຄຳຕອບຂອງທ່ານຈະຖືກຈື່ໄວ້ສຳລັບສ່ວນເສີມ ແລະ ໂປຣແກຣມນັ້ນ.
- ແພັກເກດ (ສາກເປັນ USD ແລະ ໄຟລ໌ການຕັ້ງຄ່າ, ພ້ອມໄຟລ໌ glTF ເມື່ອສ່ວນເສີມຮ້ອງຂໍ) ແລະ ສະຄຣິບຂອງສ່ວນເສີມຈະຖືກວາງໃນໂຟນເດີຊົ່ວຄາວໃໝ່, ໂປຣແກຣມເຮັດວຽກຢູ່ບ່ອນນັ້ນ, ແລະ ຮູບຈະກັບມາພ້ອມໝາຍຊື່ເອັນຈິນຂອງສ່ວນເສີມ.

:::note
ສ່ວນເສີມສາມາດເພີ່ມເອັນຈິນເຣັນເດີໄດ້ພຽງຈາກ API ຂອງສ່ວນເສີມ 1.4 ຂຶ້ນໄປ. ຕົວຢ່າງການເຮັດວຽກສຳລັບເຄື່ອງມືເຣັນເດີແບບ command-line ທີ່ເປີດໃຫ້ໃຊ້ແບບ open-source ຢູ່ໃນ repository ຂອງມັນເອງ; ມັນຍັງບໍ່ໄດ້ຖືກທົດລອງໃນເຄື່ອງມືເຣັນເດີນັ້ນເທື່ອ.
:::
