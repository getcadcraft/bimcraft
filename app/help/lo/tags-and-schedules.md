## ສິ່ງທີ່ທ່ານຈະເຮັດ

ແທັກແມ່ນຄຸນສົມບັດຂອງທ່ານເອງ, ເຊັ່ນ *Finish* ຫຼື *Fire rating*. ທ່ານກຳນົດມັນຄັ້ງດຽວສຳລັບໂຄງການ, ຕັ້ງໃຫ້ອົງປະກອບຫຼາຍອັນພ້ອມກັນ, ແລະ ທຸກຕາຕະລາງໃນ BimCraft ອ່ານມັນໄດ້: ຕາຕະລາງແທັກຢູ່ບ່ອນນີ້, {{ui:ປະລິມານ}}, ຄົ້ນຫາ, ສີຕາມຄຸນສົມບັດ ແລະ [ເອກະສານຈາກແບບ](topic:documents-from-the-model).

## ຂັ້ນຕອນ

1. ເປີດແບບ IFC, ຫຼື ເລີ່ມອາຄານໃໝ່.
2. ໃນແຜງດ້ານຊ້າຍ, ພາຍໃຕ້ {{ui:ປະລິມານ}}, ເປີດ {{ui:ແທັກ}}.
3. ຄລິກ {{ui:ເພີ່ມປ້າຍ}}. ຕັ້ງຊື່ໃຫ້ມັນ, ເລືອກປະເພດ, ແລະ ຖ້າຕ້ອງການ ລາຍຊື່ຄ່າທີ່ອະນຸຍາດ (ແຍກດ້ວຍຈຸລະພາກ) ແລະ ຄລາດທີ່ມັນໃຊ້ (`IfcDoor`, `IfcWall` ...). ຄລິກ {{ui:ເພີ່ມແທັກ}}.
4. ເລືອກອົງປະກອບໃນແບບ (ການຄົ້ນຫາຊ່ວຍໄດ້: ເລືອກປະຕູທັງໝົດພ້ອມກັນ).
5. ພາຍໃຕ້ {{ui:ຕິດແທັກໃສ່ສ່ວນທີ່ເລືອກ}}, ເລືອກ ຫຼື ພິມຄ່າສຳລັບແທັກແຕ່ລະອັນທີ່ທ່ານຕ້ອງການຕັ້ງ, ປ່ອຍອັນອື່ນໄວ້ຄືເດີມ, ແລ້ວຄລິກ **ນຳໄປໃຊ້ກັບ … ອົງປະກອບທີ່ເລືອກ**.
6. ພາຍໃຕ້ {{ui:ຕາຕະລາງແທັກ}}, ໃສ່ເຄື່ອງໝາຖັນ, ເພີ່ມຕົວກອງ, ເລືອກ {{ui:ຈັດກຸ່ມຕາມ}}, ແລ້ວ {{ui:ດາວໂຫຼດ CSV}}.

## ສິ່ງທີ່ທ່ານຄວນເຫັນ

- ໜຶ່ງຂັ້ນຕອນໃນລາຍການການປ່ຽນແປງສຳລັບແຕ່ລະນິຍາມທີ່ບັນທຶກ ແລະ ການໃສ່ແທັກແຕ່ລະຄັ້ງ; {{ui:ຍ້ອນກັບ}} ເອົາມັນຄືນ.
- ອົງປະກອບຂອງຄລາດທີ່ແທັກບໍ່ໄດ້ໃຊ້ຈະຖືກຍົກເວັ້ນຈາກແທັກນັ້ນ, ແລະ ແຖບສະຖານະຈະບອກຈຳນວນ.
- ຕາຕະລາງແທັກລາຍຊື່ໜຶ່ງແຖວຕໍ່ອົງປະກອບ, ຈັດກຸ່ມຕາມຊ່ອງທີ່ທ່ານເລືອກ; ຄລິກຊ່ອງທຳອິດຂອງແຖວເພື່ອເລືອກອົງປະກອບນັ້ນ.
- {{ui:ປະລິມານ}} ລາຍຊື່ແທັກພາຍໃຕ້ `CadCraft_Tags`, ເພື່ອໃຫ້ທ່ານລວມເນື້ອທີ່ ຫຼື ຈຳນວນຕາມແທັກໄດ້ຢູ່ບ່ອນນັ້ນ.

## ປະເພດ

ປະເພດແມ່ນລາຍການດຽວກັນກັບພາລາມິເຕີຄອບຄົວ: Length (ມິນລິແມັດ), Angle (ອົງສາ), Number, Whole number, Yes / No, Pen (1–16), Text, Material ແລະ Fill. ຄ່າທີ່ບໍ່ເໝາະກັບປະເພດຂອງມັນ, ຫຼື ບໍ່ແມ່ນໜຶ່ງໃນຄ່າທີ່ອະນຸຍາດ, ຈະຖືກປະຕິເສດພ້ອມຂໍ້ຄວາມ ແລະ ບໍ່ມີຫຍັງປ່ຽນ.

## ຄວນຮູ້

- ທຸກຢ່າງເປັນ IFC ທຳມະດາ, ດັ່ງນັ້ນໂປຣແກຣມອື່ນອ່ານຄ່າໄດ້: ນິຍາມຢູ່ໃນ property set `CadCraft_TagDefs` ຂອງໂຄງການ, ຄ່າຢູ່ໃນ property set `CadCraft_Tags` ຂອງແຕ່ລະອົງປະກອບ (ໜຶ່ງຄຸນສົມບັດຕໍ່ແທັກ). ຄວາມຍາວຖືກຂຽນເປັນໜ່ວຍຄວາມຍາວຂອງໄຟລ໌.
- `IfcWall` ໃນຄລາດຂອງແທັກກໍລວມຝາ standard-case ແລະ ຝາ elemented ດ້ວຍ.
- ການປ່ຽນຊື່ແທັກຈະປ່ຽນຊື່ຄ່າຂອງມັນໃນທຸກອົງປະກອບໃນຂັ້ນຕອນດຽວກັນ. ການລຶບແທັກເອົາພຽງນິຍາມຂອງມັນອອກ: ຄ່າທີ່ຕັ້ງໄວ້ແລ້ວຍັງຢູ່ໃນອົງປະກອບເປັນຄຸນສົມບັດທຳມະດາ. ລຶບພວກມັນກ່ອນ (ເລືອກ {{ui:ລຶບ}}) ເພື່ອເອົາອອກ.
- ແທັກໃນແອັບຮ່າງ CadCraft (ຄຸນລັກສະນະບລັອກ) ຍັງບໍ່ໄດ້ສ້າງ.
