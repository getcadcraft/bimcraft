## ສິ່ງທີ່ທ່ານຈະເຮັດ

ເປີດແຜງດຽວທີ່ລາຍຊື່ສັນຍາລັກໄຟຟ້າ ແລະ ສັນຍາລັກແຜນປະປາ ພ້ອມຮູບ ແລະ ຊື່ຂອງພວກມັນ, ຊອກອັນທີ່ທ່ານຕ້ອງການ ແລ້ວວາງໃສ່ແຜນ. ບໍ່ມີສ່ວນໃດຕ້ອງການອິນເຕີເນັດ: ສັນຍາລັກມາພ້ອມແອັບ.

## ເປີດມັນ ແລະ ວາງສັນຍາລັກ

1. ເປີດແບບ ແລະ ເປີດ {{ui:Build}} › {{ui:ແຖບສັນຍາລັກ}} (ຄຳສັ່ງທີ່ພິມ: SYMBOLS). ປຸ່ມດຽວກັນຢູ່ໃນເມນູເຄື່ອງມືຂອງແຖບ {{ui:ແຕ້ມ}} ແລະ ເປັນ **ສັນຍາລັກ** ໃນກຸ່ມຄັງຂອງແຖບເຄື່ອງມື.
2. ເລືອກຊຸດ: **ໄຟຟ້າ** ຫຼື **ປະປາ**, ຫຼື **ທຸກຊຸດ**. ພິມໃນຊ່ອງຄົ້ນຫາເພື່ອຈຳກັດລາຍຊື່. ທ່ານສາມາດຄົ້ນຫາດ້ວຍຊື່ ຫຼື ດ້ວຍຕົວຫຍໍ້ (WC, CW, HB).
3. ຄລິກສັນຍາລັກ. ແຜນພ້ອມທີ່ຈະວາງມັນ.
   - ສັນຍາລັກ **ໄຟຟ້າ** ເລີ່ມເຄື່ອງມືໄຟຟ້າພ້ອມອຸປະກອນນັ້ນທີ່ເລືອກແລ້ວ, ດັ່ງນັ້ນທຸກຢ່າງໃນ [ແຜນໄຟຟ້າ](topic:electrical-plan) ໃຊ້ໄດ້: ຄລິກແຜນ, ໜຶ່ງຂັ້ນຕອນຍ້ອນກັບ.
   - ສັນຍາລັກ **ປະປາ** ເລີ່ມເຄື່ອງມືສັນຍາລັກແຜນ. ຄລິກແຜນ. ອຸປະກອນທີ່ຕິດຝາ (ສ້ວມ, ອ່າງລ້າງໜ້າ, ອ່າງອາບນ້ຳ, ອ່າງລ້າງ, ກອກນ້ຳສວນ) ຈະຈັບເຂົ້າກັບໜ້າຝາທີ່ໃກ້ທີ່ສຸດ ໂດຍມີດ້ານຫຼັງຫັນເຂົ້າຝາ; ທໍ່ລະບາຍ, ວາວ, ເຄື່ອງເຮັດນ້ຳອຸ່ນ ແລະ ແບບເສັ້ນຈະໄປຕາມບ່ອນທີ່ທ່ານຄລິກ.
4. ກົດ {{key:R}} ເພື່ອໝຸນສັນຍາລັກ 90 ອົງສາ ({{key:Shift}}+{{key:R}} ໝຸນອີກທາງ), ຫຼື ພິມມຸມໃນ **ການໝຸນ** ໃນແຖບຕົວເລືອກ. ກົດ {{key:Esc}} ເພື່ອຢຸດ.

ອຸປະກອນ ຫຼື ກອກນ້ຳສວນທີ່ຈັບໜ້າຝາຈະຈື່ຝານັ້ນ: ເມື່ອຝາຍ້າຍ, ສັນຍາລັກຍ້າຍຕາມ (ໜ້າດຽວກັນ, ໄລຍະຫ່າງດຽວກັນຕາມຝາ) ໃນຂັ້ນຕອນຍ້ອນກັບດຽວກັນ. ຖ້າທ່ານລຶບຝາ, ສັນຍາລັກຢູ່ບ່ອນເກົ່າ ແລະ Problems ຈະລາຍຊື່ "ສູນເສຍຝາຂອງມັນ"; ຍ້າຍ ຫຼື ລຶບມັນ. ສັນຍາລັກທີ່ວາງຫ່າງຈາກຝາບໍ່ຜູກກັບຫຍັງ.

ສັນຍາລັກແຕ່ລະອັນທີ່ທ່ານວາງ ເປັນຂັ້ນຕອນຍ້ອນກັບໜຶ່ງຂັ້ນ. ສັນຍາລັກທີ່ວາງແລ້ວເປັນໝາຍເຫດແຜນໃນໄຟລ໌ IFC ພ້ອມແທັກຂອງມັນ (WC1, WC2, ...). ເລືອກມັນເພື່ອປ່ຽນແທັກ ຫຼື ການໝຸນໃນ {{ui:ຄຸນສົມບັດ}}, ຫຼື ກົດ {{key:Delete}}.

## ອຸປະກອນໃນຊຸດປະປາ

ອຸປະກອນ (ສ້ວມ, ໂຖປັດສະວະ, ອ່າງລ້າງໜ້າ, ອ່າງອາບນ້ຳ, ຝັກບົວ, ອ່າງລ້າງຈານໃນຄົວ, ອ່າງລ້າງດຽວ), ທໍ່ລະບາຍພື້ນ, ທໍ່ລ້າງພື້ນ ແລະ ຝາ, ກອກນ້ຳສວນ, ຫົວກະຈາຍນ້ຳຝາ, ເຄື່ອງເຮັດນ້ຳອຸ່ນ, ວາວ (ປະຕູ, ລູກໂລກ, ລູກບານ, ກັນກັບ, ຜີເສື້ອ, ຫຼຸດຄວາມດັນ) ແລະ ແບບເສັ້ນພ້ອມຕົວຫຍໍ້: ນ້ຳເຢັນ (CW), ນ້ຳຮ້ອນ (HW), ນ້ຳຮ້ອນກັບຄືນ (HWR), ນ້ຳເສຍ (W), ລະບາຍອາກາດ (V), ທໍ່ລະບາຍຝົນ (SD) ແລະ ແກັສ (G). ແບບຮູບປັບຕາມແຜນ ດັ່ງນັ້ນພວກມັນຮັກສາຂະໜາດໄວ້ເມື່ອພິມໃນແຜ່ນ. ແບບເສັ້ນແມ່ນເສັ້ນສັ້ນໆເພື່ອສະແດງແບບຂອງເສັ້ນໃນແຜນ; ແຕ້ມເສັ້ນທໍ່ຈິງດ້ວຍເຄື່ອງມືທໍ່.

:::note
ເຫຼົ່ານີ້ແມ່ນຂໍ້ຕົກລົງສັນຍາລັກແຜນປະປາທົ່ວໄປ, ແຕ້ມໂດຍພວກເຮົາ; ບໍ່ໄດ້ຮັບຮອງຕາມ ISO 4067-1 ຫຼື ASME Y32.4. ພວກມັນຖືກປຽບທຽບກັບຄຳອະທິບາຍແບບສາທາລະນະ ແລະ ເອກະສານຝຶກອົບຮົມ (ລາຍຊື່ຢູ່ໃນໝາຍເຫດແຫຼ່ງຂອງຊຸດ, ທີ່ບອກວ່າພວກເຮົາກົງໃສ່ໃດ ແລະ ແຕກຕ່າງໃສ່ໃດ), ບໍ່ໄດ້ຄັດລອກຈາກຜະລິດຕະພັນໃດ, ແລະ ໃຊ້ໄດ້ຟຣີ (Apache-2.0). ຊຸດແບບແຕກຕ່າງກັນ, ດັ່ງນັ້ນຈົ່ງກວດຄຳອະທິບາຍຂອງໂຄງການຂອງທ່ານເອງ. ພວກມັນເປັນສັນຍາລັກແຜນ, ບໍ່ແມ່ນການອອກແບບປະປາ: ພວກມັນບໍ່ກຳນົດຂະໜາດທໍ່ ຫຼື ກວດກົດລະບຽບ.
:::

:::tip
ຖ້າໄຟລ໌ໃຊ້ຊຸດສັນຍາລັກທີ່ບິວນີ້ບໍ່ມີ, ແຜນຈະສະແດງກ່ອງແທນສັນຍາລັກນັ້ນ ແລະ Problems ຈະລາຍຊື່ມັນ.

## ລາຍການທີ່ມັກ ແລະ ແປ້ນພິມ

- ຄລິກດາວຂອງສັນຍາລັກ (ຫຼື ກົດ {{key:F}} ເທິງມັນ) ເພື່ອເກັບໄວ້ເປັນລາຍການທີ່ມັກ. ລາຍການທີ່ມັກຈະຢູ່ທຳອິດ ແລະ ຄົງຢູ່ໃນບຣາວເຊີນີ້. **ສະເພາະລາຍການທີ່ມັກ** ສະແດງສະເພາະພວກມັນ.
- {{key:Down}} ຈາກຊ່ອງຄົ້ນຫາຈະຍ້າຍເຂົ້າສູ່ສັນຍາລັກ; ປຸ່ມລູກສອນ, {{key:Home}} ແລະ {{key:End}} ຍ້າຍລະຫວ່າງພວກມັນ; {{key:Enter}} ເລືອກອັນທີ່ມີຈຸດສຸມ; {{key:Esc}} ປິດແຖບ.
- ໃນໂທລະສັບ ແຖບເປັນແຜ່ນຢູ່ລຸ່ມຈໍ; ມັນຈະຫຼີກທາງເມື່ອທ່ານເລືອກສັນຍາລັກ ເພື່ອໃຫ້ເຫັນແຜນ. ເປີດມັນອີກຈາກເມນູ Build ຫຼື ປຸ່ມ **ແຖບ** ໃນແຖບຕົວເລືອກ.

## ເຊື່ອມອົງປະກອບທີ່ວາງກັບສັນຍາລັກ

ໂຄມໄຟຈາກຄັງເປັນອົງປະກອບ 3D, ແຕ່ແຜນໄຟຟ້າສະແດງມັນເປັນສັນຍາລັກ. ທ່ານວາງມັນ **ໜຶ່ງເທື່ອ** ແລ້ວເຊື່ອມມັນ:

1. ເລືອກ Build › **ການເຊື່ອມສັນຍາລັກ** (ຫຼື ພິມ SYMBOLLINK). ແຜງການເຊື່ອມສັນຍາລັກເປີດຢູ່ແຜງດ້ານຊ້າຍ.
2. ເລືອກອົງປະກອບທີ່ວາງໄວ້ໃນແຜນ ຫຼື ໃນ 3D. ແຜງບອກວ່າເລືອກຈັກອັນ ແລະ ພວກມັນເຊື່ອມກັບຫຍັງ.
3. ເລືອກ **ສັນຍາລັກ** (ຈາກຊຸດສັນຍາລັກໃດກໍໄດ້: ໄຟຟ້າ, ປະປາ) ແລ້ວເລືອກ **ເຊື່ອມ**.

ອົງປະກອບຍັງເປັນອົງປະກອບດຽວ, ແລະ ທຸກຕາຕະລາງນັບມັນໜຶ່ງຄັ້ງ:

- **3D** ສະແດງຕົວຂອງມັນສະເໝີ.
- **ແຜນ** ສະແດງຮູບແບບແຜນຂອງມັນ ຄືເກົ່າ.
- ແຜນທີ່ **ມຸມມອງນີ້ສະແດງອົງປະກອບທີ່ເຊື່ອມເປັນ** ຕັ້ງເປັນ **ສັນຍາລັກຂອງມັນ (ແຜນການບໍລິການ)** ຈະສະແດງສັນຍາລັກແທນທີ່. ການຄລິກສັນຍາລັກຈະເລືອກອົງປະກອບ. ການເລືອກນີ້ຖືກເກັບໄວ້ສຳລັບມຸມມອງນັ້ນ (ແຜນຊັ້ນ, ແຜນເພດານ ຫຼື callout) ໃນໄຟລ໌.

**ໝຸນສັນຍາລັກ 90°** ໝຸນສັນຍາລັກທຽບກັບອົງປະກອບຂອງມັນ. **ລຶບການເຊື່ອມ** ເອົາການເຊື່ອມອອກ; ອົງປະກອບຍັງຢູ່. ຕາຕະລາງ **ສັນຍາລັກທີ່ເຊື່ອມ** ລາຍຊື່ແຕ່ລະອົງປະກອບທີ່ເຊື່ອມໜຶ່ງເທື່ອ ພ້ອມຊັ້ນ ແລະ ຫ້ອງທີ່ມັນຢູ່.

ຍັງບໍ່ໄດ້ສ້າງ: ການເລືອກມຸມມອງຂອງແຜ່ນແມ່ນການເລືອກແຜນຊັ້ນທີ່ມັນສະແດງ; ອຸປະກອນທີ່ວາງດ້ວຍເຄື່ອງມືໄຟຟ້າເປັນສັນຍາລັກໃນທຸກແຜນ, ຄືເກົ່າ.
