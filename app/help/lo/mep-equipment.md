## ສິ່ງທີ່ທ່ານຈະເຮັດ

ວາງອຸປະກອນໄວ້ທີ່ປາຍຂອງທໍ່ ແລະ ທໍ່ລົມຂອງທ່ານ. ແຕ່ລະຊິ້ນເປັນຮູບຮ່າງທົ່ວໄປທີ່ມີຂະໜາດຕາມຄ່າທີ່ທ່ານພິມ, ພ້ອມກັບການເຊື່ອມຕໍ່ເປັນ **ພອດ**: ບ່ອນທີ່ທໍ່ ຫຼື ທໍ່ລົມເຊື່ອມເຂົ້າ, ລະບົບໃດ, ການໄຫຼໄປທາງໃດ ແລະ ຂະໜາດເທົ່າໃດ. ທໍ່ ແລະ ທໍ່ລົມທີ່ແຕ້ມຈາກພອດຈະຮັບຂະໜາດ ແລະ ລະບົບຂອງມັນ ແລະ ຕິດຢູ່ກັບມັນ: ເບິ່ງ [ເຊື່ອມຕໍ່ທໍ່ ແລະ ທໍ່ລົມກັບອຸປະກອນ](topic:mep-connections).

:::note
ນີ້ແມ່ນເຄື່ອງຊ່ວຍການຮ່າງ ແລະ ການປະສານງານ, ກຳນົດຂະໜາດໂດຍວິສະວະກອນ. ອຸປະກອນບໍ່ແມ່ນຜະລິດຕະພັນຂອງຜູ້ຜະລິດ: ບໍ່ມີຄວາມສາມາດ, ນ້ຳໜັກ ຫຼື ຂະໜາດການເຊື່ອມຕໍ່ຂອງຜູ້ຜະລິດ. ນຳໂມເດວຂອງຜູ້ຜະລິດຈາກໂປຣແກຣມ MEP ຂອງທ່ານເຂົ້າມາເປັນ IFC ເມື່ອທ່ານຕ້ອງການ.
:::

## ວາງຊິ້ນ

1. ເປີດ {{ui:ແຕ້ມ}}, ເປີດ {{ui:Build}} ແລ້ວເລືອກ {{ui:ອຸປະກອນ}}.
2. ໃນແຖບ, ເລືອກປະເພດ ແລ້ວພິມຂະໜາດຂອງມັນ. ແຕ່ລະປະເພດຖາມຂະໜາດຂອງຕົນເອງ:

| ປະເພດ | ທ່ານພິມ | ພອດຂອງມັນ |
|---|---|---|
| ເຄື່ອງຈັດການອາກາດ | ຄວາມຍາວ, ຄວາມກວ້າງ, ຄວາມສູງ; ຊ່ອງຈ່າຍ ແລະ ຊ່ອງກັບຄືນ; ຂະໜາດທໍ່ຄອຍ ແລະ ລະບົບ; ຂະໜາດນ້ຳຄວບແໜ້ນ | ທໍ່ລົມຈ່າຍອອກ, ທໍ່ລົມກັບຄືນເຂົ້າ, ຄອຍເຂົ້າ ແລະ ອອກ, ທໍ່ລະບາຍນ້ຳຄວບແໜ້ນ |
| ພັດລົມຕໍ່ໃນທໍ່ | ເສັ້ນຜ່າສູນກາງ, ຄວາມຍາວ, ລະບົບ | ທໍ່ລົມເຂົ້າ ແລະ ອອກ |
| ປັ໊ມ | ຂະໜາດທໍ່, ລະບົບ | ທາງເຂົ້າ ແລະ ທາງອອກ |
| ເຕົາຕົ້ມ | ຄວາມຍາວ, ຄວາມກວ້າງ, ຄວາມສູງ, ຂະໜາດທໍ່, ຂະໜາດແກ໊ສ, ເສັ້ນຜ່າສູນກາງທໍ່ຄວັນ | ຈ່າຍຄວາມຮ້ອນອອກ ແລະ ກັບຄືນເຂົ້າ, ແກ໊ສເຂົ້າ, ທໍ່ຄວັນອອກ |
| ເຄື່ອງເຮັດນ້ຳຮ້ອນ | ເສັ້ນຜ່າສູນກາງ, ຄວາມສູງ, ຂະໜາດທໍ່, ແກ໊ສ ຫຼື ໄຟຟ້າ | ນ້ຳເຢັນເຂົ້າ, ນ້ຳຮ້ອນອອກ (ແລະ ແກ໊ສເຂົ້າ ແລະ ທໍ່ຄວັນເມື່ອມັນເຜົາແກ໊ສ) |
| ຊຸດໜ່ວຍປາຍທາງ | ຄວາມຍາວ, ຄວາມກວ້າງ, ຄວາມສູງ, ຫົວເຂົ້າກົມ, ຄວາມກວ້າງ ແລະ ຄວາມສູງຂອງທາງອອກ | ອາກາດຈ່າຍເຂົ້າ ແລະ ອອກ |
| ຕົວກະຈາຍລົມ | ໜ້າ, ຄໍ, ລະບົບ | ຄໍຂອງມັນ (ອາກາດເຂົ້າ) |
| ຕະແກງລົມ | ຄວາມກວ້າງ ແລະ ຄວາມສູງຂອງໜ້າ, ຄວາມກວ້າງ ແລະ ຄວາມສູງຂອງຄໍ, ລະບົບ | ຄໍຂອງມັນ (ອາກາດອອກໄປທໍ່ກັບຄືນ ຫຼື ທໍ່ລະບາຍ) |
| ຖັງ | ເສັ້ນຜ່າສູນກາງ, ຄວາມສູງ, ຂະໜາດທໍ່, ລະບົບ | ທາງເຂົ້າຢູ່ດ້ານເທິງ, ທາງອອກໃກ້ດ້ານລຸ່ມ |
| ຕົວຄາຍຄວາມຮ້ອນ | ຄວາມຍາວ, ຄວາມສູງ, ຄວາມເລິກ, ຂະໜາດທໍ່, ລະບົບ | ນ້ຳໄຫຼເຂົ້າຢູ່ດ້ານເທິງຂອງປາຍໜຶ່ງ, ນ້ຳກັບຄືນອອກຢູ່ດ້ານລຸ່ມຂອງອີກປາຍ |
| ເຄື່ອງເຮັດຄວາມຮ້ອນແບບພາ / ແຜງ | ຄວາມຍາວ, ຄວາມສູງ, ຄວາມເລິກ, ຂະໜາດທໍ່, ລະບົບ | ນ້ຳເຂົ້າຢູ່ປາຍໜຶ່ງ, ນ້ຳກັບຄືນອອກຢູ່ອີກປາຍ |
| ຄອບຄົວຂອງຜູ້ຜະລິດ | ຄອບຄົວ (ເບິ່ງ [ຂໍ້ກຳນົດທໍ່, ວາວ, ລິ້ນປັບ ແລະ ຄອບຄົວຂອງຜູ້ຜະລິດ](topic:pipe-specs)) | ພອດທີ່ຄອບຄົວຂອງມັນຖືກໃຫ້ |

3. ຕັ້ງ **ຕຳແໜ່ງ**, ຄວາມສູງຂອງຖານຂອງມັນເໜືອລະດັບ. ຄວາມສູງຂອງຕົວກະຈາຍລົມ ຫຼື ຕະແກງລົມແມ່ນໜ້າຂອງມັນ: ພິມຄວາມສູງເພດານ.
4. ພິມ **ປ້າຍ** ຖ້າທ່ານຕ້ອງການ (`AHU-1`); ຊິ້ນຕໍ່ໄປຂອງປະເພດດຽວກັນຈະໄດ້ເລກຖັດໄປ.
5. ເລື່ອນຕົວຊີ້ເທິງແຜນຜັງ: ຮອຍຕີນ ແລະ ພອດຂອງມັນຈະຕາມໄປ. ກົດ {{key:R}} ເພື່ອໝຸນ 90°. ຄລິກບ່ອນທີ່ມັນຈະໄປ.

ຂະໜາດທໍ່ແມ່ນຂະໜາດທໍ່ເຫຼັກ (ASME B36.10M). ທໍ່ທີ່ແຕ້ມຈາກປັ໊ມໃນວັດສະດຸອື່ນຈະຮັບຂະໜາດນາມດຽວກັນໃນວັດສະດຸຂອງມັນເອງ.

## ປ່ຽນ ຫຼື ລຶບມັນ

ເລືອກມັນໃນແຜນຜັງ ຫຼື ມຸມມອງ 3D. {{ui:ຄຸນສົມບັດ}} ສະແດງທຸກຂະໜາດທີ່ທ່ານພິມ, ປ້າຍ, X, Y, ຄວາມສູງ ແລະ ການໝຸນ, ແລະ ແຕ່ລະພອດ: ຂະໜາດ, ລະບົບ, ການໄຫຼໄປທາງໃດ, ແລະ ມີຫຍັງເຊື່ອມຕໍ່ຢູ່ຫຼືບໍ່. ແຕ່ລະການປ່ຽນແປງເປັນຂັ້ນຕອນໜຶ່ງຂອງ {{ui:ຍ້ອນກັບ}}; ເສັ້ນທາງທີ່ຕິດກັບພອດຂອງມັນຈະຍ້າຍໄປນຳ. {{key:Delete}} ລຶບມັນ; ເສັ້ນທາງທີ່ເຄີຍຕິດກັບມັນຈະຢູ່, ແລະ ການກວດການເຊື່ອມຕໍ່ຈະລາຍການພວກມັນ.

## ໃນໄຟລ໌ IFC

ແຕ່ລະປະເພດຖືກບັນທຶກເປັນຊັ້ນ IFC ຂອງມັນ: IfcUnitaryEquipment (ເຄື່ອງຈັດການອາກາດ), IfcFan, IfcPump, IfcBoiler (ເຕົາຕົ້ມ; ເຄື່ອງເຮັດນ້ຳຮ້ອນແມ່ນ IfcBoiler ປະເພດນ້ຳ ທີ່ມີ object type "ເຄື່ອງເຮັດນ້ຳຮ້ອນ"), IfcAirTerminalBox (ຊຸດໜ່ວຍປາຍທາງ), IfcAirTerminal (ຕົວກະຈາຍລົມ, ຕະແກງລົມ) ແລະ IfcTank, ພ້ອມປະເພດທີ່ໃຊ້ຮ່ວມກັນໂດຍທຸກຊິ້ນຂອງປະເພດດຽວກັນ ແລະ ຂະໜາດ. ໄຟລ໌ IFC2X3 ໄດ້ IfcEnergyConversionDevice, IfcFlowMovingDevice, IfcFlowController, IfcFlowTerminal ແລະ IfcFlowStorageDevice ພ້ອມປະເພດທີ່ກົງກັນ. ແຕ່ລະພອດແມ່ນ IfcDistributionPort ທີ່ຕັ້ງຢູ່ບ່ອນທີ່ການເຊື່ອມຕໍ່ຢູ່, ຫັນອອກ, ພ້ອມທິດທາງການໄຫຼ ແລະ ລະບົບ; ໂປຣແກຣມອື່ນອ່ານໄດ້ວ່າເສັ້ນທາງໃດເຊື່ອມກັບພອດໃດ. ຊິ້ນນັ້ນເຂົ້າລະບົບຂອງແຕ່ລະພອດຂອງມັນ, ແລະ ມີຊຸດລາຍການຄັງທີ່ແຕ່ລະລາຍການຄັງທີ່ວາງແລ້ວມີ.
