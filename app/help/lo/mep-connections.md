## ສິ່ງທີ່ທ່ານຈະເຮັດ

ເຊື່ອມເສັ້ນທາງເຂົ້າກັບອຸປະກອນ ເພື່ອໃຫ້ໂມເດວເປັນລະບົບທີ່ເຊື່ອມກັນແຫ່ງດຽວ: ທາງອອກຂອງປັ໊ມໄປຫາທໍ່ທີ່ອອກຈາກມັນ, ຄໍຂອງຕົວກະຈາຍລົມໄປຫາທໍ່ລົມສາຂາ. ຈາກນັ້ນໃຫ້ BimCraft ລາຍການສິ່ງທີ່ບໍ່ໄດ້ເຊື່ອມຕໍ່.

## ແຕ້ມຈາກພອດ

1. ເລືອກ {{ui:ທໍ່}} ຫຼື {{ui:ທໍ່ລົມ}}.
2. ເລື່ອນຕົວຊີ້ໄປຫາພອດຂອງອຸປະກອນ (ວົງມົນນ້ອຍ; ພອດເປີດຖືກແຕ້ມດ້ວຍສີເຕືອນ). ຕົວຊີ້ຈະດູດໄປຫາມັນ ແລະ ຂຶ້ນວ່າ **ຢູ່ພອດ**.
3. ຄລິກ: ເສັ້ນທາງເລີ່ມທີ່ລະດັບຄວາມສູງຂອງພອດ ແລະ **ຮັບຂະໜາດ ແລະ ລະບົບ** ຂອງມັນ (ທໍ່ກໍຮັບວັດສະດຸປົກກະຕິຂອງລະບົບນັ້ນເຊັ່ນກັນ). ແຖບສະຖານະບອກວ່າມັນຮັບເອົາຫຍັງ.
4. ແຕ້ມຕໍ່ຕາມປົກກະຕິ. ການສິ້ນສຸດເສັ້ນທາງຢູ່ພອດອື່ນກໍຈະຕິດປາຍນັ້ນເຊັ່ນກັນ.

ປາຍຂອງເສັ້ນທາງຢູ່ພອດ **ຖືກຕິດ** ກັບມັນ: ຍ້າຍ ຫຼື ໝຸນອຸປະກອນ (ໃນ {{ui:ຄຸນສົມບັດ}}) ແລ້ວປາຍເສັ້ນທາງກໍໄປນຳ; ແກ້ໄຂເສັ້ນທາງ ແລະ ປາຍນັ້ນຍັງຢູ່ທີ່ພອດ. ມຸມອື່ນຂອງເສັ້ນທາງຍັງຢູ່ບ່ອນເກົ່າ, ດັ່ງນັ້ນຫຼັງຈາກຍ້າຍໃຫຍ່ ຂາທຳອິດອາດຫຼຸດອອກຈາກພອດດ້ວຍມຸມ: ຍ້າຍມຸມຕໍ່ໄປນຳ.

## ກວດການເຊື່ອມຕໍ່

ເປີດ {{ui:Build}} ແລ້ວຄລິກ {{ui:ກວດການເຊື່ອມຕໍ່}}. ລາຍການຢູ່ໃຕ້ແຖບສະແດງ:

| ແຖວ | ມັນໝາຍເຖິງຫຍັງ |
|---|---|
| ພອດບໍ່ໄດ້ເຊື່ອມຕໍ່ | ອຸປະກອນຊິ້ນໜຶ່ງມີການເຊື່ອມຕໍ່ທີ່ບໍ່ມີຫຍັງຖືກແຕ້ມໄປຫາ |
| ບໍ່ມີຫຍັງຢູ່ປາຍຂອງມັນ | ເສັ້ນທາງສິ້ນສຸດລອຍຢູ່ໃນອາກາດ |
| ພອດທີ່ເຊື່ອມຕໍ່ມີຂະໜາດຕ່າງກັນ | ເສັ້ນທາງຂະໜາດໜຶ່ງພົບກັບພອດ ຫຼື ເສັ້ນທາງອີກຂະໜາດໜຶ່ງໂດຍບໍ່ມີຕົວຫຼຸດ (ຂະໜາດນາມຂອງທໍ່, ຮູບຮ່າງ ແລະ ດ້ານຂອງທໍ່ລົມ) |
| ພອດທີ່ເຊື່ອມຕໍ່ມີລະບົບຕ່າງກັນ | ຕົວຢ່າງ ທໍ່ລົມກັບຄືນທີ່ຕໍ່ເຂົ້າຕົວກະຈາຍລົມຈ່າຍ |
| ທໍ່ເຊື່ອມກັບທໍ່ລົມ | ການເຊື່ອມຕໍ່ສອງປະເພດທີ່ຕ່າງກັນມາພົບກັນ |
| ບໍ່ມີອຸປະກອນໃນເຄືອຂ່າຍຂອງມັນທີ່ສະໜອງໃຫ້ | ບໍ່ມີຫຍັງທີ່ເສັ້ນທາງເຊື່ອມຢູ່, ບໍ່ວ່າຈະໄກເທົ່າໃດຕາມທາງ, ທີ່ມີທາງອອກ. ທໍ່ລະບາຍ, ທໍ່ນ້ຳຝົນ ແລະ ທໍ່ລະບາຍອາກາດບໍ່ຖືກຖາມເລື່ອງນີ້: ນ້ຳຂອງພວກມັນມາຈາກອຸປະກອນ |
| ຕິດຢູ່ພອດຂອງອຸປະກອນທີ່ບໍ່ຢູ່ໃນໂມເດວອີກແລ້ວ | ອຸປະກອນຖືກລຶບ; ແຕ້ມປາຍນັ້ນໃໝ່ ຫຼື ລຶບເສັ້ນທາງ |

ຂໍ້ຜິດພາດຢູ່ກ່ອນ. ຄລິກແຖວເພື່ອເລືອກສິ່ງທີ່ມັນລະບຸ. {{ui:ປິດ}} ເຊື່ອງລາຍການ. ການກວດອ່ານໂມເດວຕາມທີ່ແຕ້ມ: ມັນກວດການເຊື່ອມຕໍ່ ແລະ ຂະໜາດເທົ່ານັ້ນ, ບໍ່ເຄີຍກວດອັດຕາການໄຫຼ, ຄວາມດັນ ຫຼື ການປັບສົມດຸນ.
