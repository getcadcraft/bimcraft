## ສິ່ງທີ່ທ່ານຈະເຮັດ

ບອກ BimCraft ວ່າອາຄານໃໝ່ຄວນເລີ່ມດ້ວຍຫຍັງ ເພື່ອບໍ່ໃຫ້ທຸກຄົນໃນສຳນັກງານຕ້ອງປ່ຽນສິ່ງດຽວກັນທຸກຄັ້ງ. ນີ້ແມ່ນ add-on: ມັນປິດຢູ່ຈົນກວ່າທ່ານຈະເປີດມັນ, ແລະ ນະໂຍບາຍທີ່ທ່ານບໍ່ໄດ້ກຳນົດຈະປ່ອຍໃຫ້ຄ່າເລີ່ມຕົ້ນຂອງ BimCraft ເອງຢູ່ຄືເກົ່າ.

:::note
ນີ້ແມ່ນຄ່າເລີ່ມຕົ້ນສຳລັບອາຄານ **ໃໝ່** ແລະ ສິ່ງ **ໃໝ່**. ໂຄງການທີ່ທ່ານເລີ່ມໄປແລ້ວຈະບໍ່ຖືກປ່ຽນ.
:::

## ຂັ້ນຕອນ

1. ເປີດການຕັ້ງຄ່າ, ໄປທີ່ {{ui:Add-ons}} ແລ້ວເປີດ {{ui:Default Policies}}.
2. ໃນການຕັ້ງຄ່າ, ເປີດແຖບ **BimCraft** ແລ້ວເລືອກ {{ui:Default Policies}} ໃນລາຍການເບື້ອງຊ້າຍ.
3. ກຳນົດນະໂຍບາຍທີ່ທ່ານຕ້ອງການ. ແຕ່ລະອັນເລີ່ມທີ່ **ຂອງ BimCraft** ພ້ອມສິ່ງທີ່ມັນເປັນໃນວົງເລັບ. ນະໂຍບາຍທີ່ມີກ່ອງ **Metric** ແລະ **Imperial** ຈະໃຊ້ຄ່າໜຶ່ງສຳລັບແຕ່ລະປະເພດໂຄງການ; ໃຫ້ຕື່ມສະເພາະອັນທີ່ທ່ານຕ້ອງການ.
4. ບໍ່ມີປຸ່ມບັນທຶກ: ແຕ່ລະການປ່ຽນແປງຖືກບັນທຶກທັນທີທີ່ທ່ານເຮັດ. ຄ່າທີ່ໃຊ້ບໍ່ໄດ້ຈະຖືກປະຕິເສດພ້ອມຄຳອະທິບາຍ ແລະ ຄ່າເກົ່າຈະຢູ່ຄືເດີມ.
5. ກົດ {{ui:New building}}. ກ່ອງໂຕ້ຕອບຈະຖືກຕື່ມຈາກນະໂຍບາຍຂອງທ່ານ, ແລະ ແຕ່ລະຄ່າທີ່ນະໂຍບາຍກຳນົດຈະມີຂໍ້ຄວາມ **from your Default Policies** ຢູ່ຂ້າງ. ທ່ານຍັງສາມາດປ່ຽນຄ່າໃດກໍໄດ້ກ່ອນ {{ui:Create}}.

## ນະໂຍບາຍ

- **ຫົວໜ່ວຍຂອງອາຄານໃໝ່**: ຫົວໜ່ວຍຈະປ່ຽນເປັນອັນນີ້ເມື່ອກົດ Create.
- **ຈຳນວນຊັ້ນ**, **ຊື່ຊັ້ນ** ແລະ **ຄວາມສູງຊັ້ນ**. ໃນຊື່, `{n}` ນັບ 1, 2, 3; `{n0}` ນັບ 0, 1, 2; `{nn}` ແລະ `{nn0}` ເຮັດແບບດຽວກັນດ້ວຍສອງຕົວເລກ. ດັ່ງນັ້ນ `Floor {nn0}` ຈະໄດ້ Floor 00, Floor 01, Floor 02.
- **ປະເພດຝາທຳອິດ**: ອັນທີ່ເຄື່ອງມືຝາແຕ້ມກ່ອນ. ສຳນັກງານເມຕຣິກອາດເລີ່ມດ້ວຍ Exterior masonry 300 mm ໃນຂະນະທີ່ໂຄງການອິມພີເຣຍລຍັງຄົງ Exterior 2×6.
- **ປ້າຍ LOD ຂອງປະເພດຝາເລີ່ມຕົ້ນ**: ລະດັບການພັດທະນາ (LOD 100 ຫາ 500) ທີ່ປະເພດເລີ່ມຕົ້ນ 9 ອັນສະແດງ ທຸກບ່ອນທີ່ປະເພດຖືກລາຍການ. ເບິ່ງ [ສ້າງຊຸດປະກອບຝາ](topic:wall-assemblies).
- **LOD ຂອງປະເພດຝາໃໝ່ທີ່ສ້າງ**: ປ້າຍທີ່ປະເພດໃໝ່ເລີ່ມດ້ວຍໃນຕົວແກ້ໄຂປະເພດ. ທ່ານປ່ຽນໄດ້ທີ່ນັ້ນ.
- **ແຜ່ນທຳອິດ**: ເຈ້ຍ, ມາດຕາສ່ວນ, ໝາຍເລກແຜ່ນ ແລະ ຊື່ (ໃຊ້ `{level}` ສຳລັບຊື່ຂອງຊັ້ນຕ່ຳສຸດ), ຫຼື ບໍ່ມີແຜ່ນທຳອິດເລີຍ.
- **ຂະໜາດຂໍ້ຄວາມເທິງເຈ້ຍ** (Settings › Global › Default Policies): ຄວາມສູງຂອງສຳນັກງານ, ເປັນມິນລີແມັດຕາມທີ່ພິມອອກ, ສຳລັບໝາຍເຫດ, ຂໍ້ຄວາມຂະໜາດ, ປ້າຍ, ຊື່ຫ້ອງ, ຕົວອັກສອນຂອງວົງກົມຕາຕະລາງ, ຫົວຂໍ້ມຸມມອງ ແລະ ຂໍ້ຄວາມຕາຕະລາງ. ອາຄານໃໝ່ຈະເອົາມັນໄປໃຊ້ເມື່ອກົດ Create ແລະ ເກັບໄວ້ໃນໄຟລ໌ຂອງມັນ. ເບິ່ງ [ແຕ້ມໃນຂະໜາດເຕັມ, ໝາຍໃນມາດຕາສ່ວນ](topic:annotation-sizes).
- **ເຄື່ອງມືທີ່ຢູ່ໃນສະຖານະໃຊ້ງານຫຼັງ Create**: Select ຕາມທີ່ BimCraft ເຮັດເອງ, ຫຼື Wall ເພື່ອໃຫ້ສອງການກົດທຳອິດໃນແຜນຜັງແຕ້ມຝາໄດ້ເລີຍ.

## ຮູບແບບຕາຕະລາງ: ມາດຕະຖານສຳນັກງານ

ໃນ **Settings › Global › Default Policies**, ພາຍໃຕ້ **Schedule layout (the office standard)**, ກຳນົດວ່າທຸກຕາຕະລາງຖືກຈັດກຸ່ມແນວໃດ, ມີຜົນລວມຍ່ອຍ ແລະ ຜົນລວມທັງໝົດຫຼືບໍ່, ຫົວຂໍ້ ແລະ ຮູບແບບຕົວພິມໃຫຍ່ຂອງຫົວຖັນ. ທຸກຕາຕະລາງທີ່ບໍ່ໄດ້ລະບຸຂອງຕົນເອງຈະໃຊ້ຄ່າເຫຼົ່ານີ້, ໂດຍໃຜກໍຕາມທີ່ຕັ້ງມັນ. ເບິ່ງ [ຈັດວາງ, ບັນທຶກ ແລະ ສົ່ງອອກຕາຕະລາງ](topic:schedule-layouts).

## ແບ່ງປັນໃນສຳນັກງານ

1. ໃນການຕັ້ງຄ່າ, ເປີດແຖບ **Global** ແລ້ວເລືອກ {{ui:Default Policies}}.
2. ພິມ **Office name** ຖ້າທ່ານຕ້ອງການ. ມັນຈະຖືກຂຽນລົງໃນໄຟລ໌.
3. ກົດ {{ui:Save to a file}}. ທ່ານຈະໄດ້ໄຟລ໌ນ້ອຍໜຶ່ງທີ່ລົງທ້າຍດ້ວຍ `.ccdefaults.json`.
4. ໃນຄອມພິວເຕີອີກເຄື່ອງ, ເປີດ add-on, ເປີດບ່ອນດຽວກັນ ແລ້ວກົດ {{ui:Load from a file}}. ນະໂຍບາຍໃນໄຟລ໌ຈະແທນທີ່ນະໂຍບາຍໃນຄອມພິວເຕີເຄື່ອງນັ້ນ.

ແຖບ Global ຍັງມີ **Unit system of a new project** ທີ່ໃຊ້ກັບທຸກແອັບທີ່ມີ add-on, ແລະ {{ui:Reset every policy}}. {{ui:Reset to BimCraft's own defaults}} ໃນແຖບ BimCraft ລຶບພຽງຂອງ BimCraft ເທົ່ານັ້ນ.

## ຄວນຮູ້

- ໄຟລ໌ເປັນ JSON ທຳມະດາທີ່ເປີດອ່ານໄດ້: ລາຍການຊື່ນະໂຍບາຍ ແລະ ຄ່າ. ນະໂຍບາຍທີ່ໄຟລ໌ລະບຸ ແຕ່ເວີຊັນນີ້ບໍ່ຮູ້ຈັກ ຈະຖືກຂ້າມ ແລະ ຖືກລະບຸຊື່ໃນຂໍ້ຄວາມ; ສ່ວນທີ່ເຫຼືອຍັງຖືກໂຫຼດ.
- ນະໂຍບາຍຖືກເກັບໄວ້ໃນບຣາວເຊີນີ້ ສຳລັບທຸກແອັບ CadCraft ໃນຄອມພິວເຕີເຄື່ອງນີ້. ພວກມັນບໍ່ໄດ້ຖືກເກັບໄວ້ໃນໄຟລ໌ອາຄານ ແລະ ບໍ່ຖືກຊິ້ງລະຫວ່າງຄອມພິວເຕີ: ໃຫ້ໃຊ້ໄຟລ໌.
- ປ້າຍ LOD ຂອງປະເພດເລີ່ມຕົ້ນມາຈາກນະໂຍບາຍໃນຄອມພິວເຕີເຄື່ອງນີ້. ປະເພດທີ່ທ່ານສ້າງເປັນສຳເນົາຂອງປະເພດເລີ່ມຕົ້ນຈະມີປ້າຍຂອງມັນຢູ່ໃນໄຟລ໌ອາຄານ.
- BimCraft ບໍ່ມີການຕັ້ງຄ່າຄວາມແມ່ນຍຳ, ດັ່ງນັ້ນບໍ່ມີນະໂຍບາຍຄວາມແມ່ນຍຳຢູ່ນີ້.
- ອາຄານທີ່ເລີ່ມຈາກແມ່ແບບຈະໄດ້ຊັ້ນ ແລະ ແຜ່ນຂອງແມ່ແບບນັ້ນເອງ. ນະໂຍບາຍປະເພດຝາ ແລະ ຫົວໜ່ວຍຍັງໃຊ້ຢູ່.
- ປິດ add-on ແລ້ວທຸກຢ່າງຈະກັບເປັນຂອງ BimCraft ເອງ. ນະໂຍບາຍຂອງທ່ານຖືກເກັບໄວ້ເພື່ອໃຊ້ເມື່ອເປີດອີກຄັ້ງ.
