BimCraft ມີປຸ່ມລັດໜ້ອຍ. ການເຮັດວຽກສ່ວນໃຫຍ່ເຮັດດ້ວຍເມົ້າສ໌ ແລະ ແຖບຕ່າງໆ. ປຸ່ມລັດທີ່ຂຽນດ້ວຍ {{key:Mod}} ໃຊ້ Command ໃນ Mac ແລະ Ctrl ໃນບ່ອນອື່ນ. ເບິ່ງ [ປຸ່ມ, ເມົ້າສ໌ ແລະ ທຣັກແພດ](common:keys) ເພື່ອເບິ່ງວ່າປຸ່ມຖືກຂຽນໃນຄູ່ມືນີ້ແນວໃດ.

## ທົ່ວໄປ

| ປຸ່ມ | ມັນເຮັດຫຍັງ |
|---|---|
| {{key:Ctrl+Shift+F}} | ປ່ຽນໂໝດໜ້າຈໍ: ປົກກະຕິ, ເຕັມຈໍ, ເຕັມຈໍໂດຍຊ່ອນແຖບ. ໃຊ້ Ctrl ໃນທຸກແພລດຟອມ ລວມທັງ Mac |
| {{key:Esc}} | ອອກຈາກເຕັມຈໍ |
| {{key:Mod+,}} | ເປີດ {{ui:Settings}}. ເບິ່ງ [ການຕັ້ງຄ່າ BimCraft](topic:settings) |
| {{key:Tab}} | ເລື່ອນລະຫວ່າງປຸ່ມ, ຊ່ອງຕິກ ແລະ ຄ່າ. ທຸກການຄວບຄຸມສາມາດເຂົ້າເຖິງດ້ວຍແປ້ນພິມ |

## ແກ້ໄຂ

ຄຳສັ່ງດຽວກັນຢູ່ໃນແຖບເຄື່ອງມື: {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}} ແລະ ເມນູ {{ui:More}} ທີ່ສະແດງແຕ່ລະປຸ່ມ. ພວກມັນເຮັດວຽກໃນມຸມມອງ 3D ຂອງໂມເດວ IFC, ບໍ່ແມ່ນຕອນທີ່ທ່ານກຳລັງພິມໃນຊ່ອງ. ເບິ່ງ [ສຳເນົາ, ວາງ ແລະ ສຳເນົາຊ້ຳລາຍການຄັງ](topic:copy-paste).

| ປຸ່ມ | ມັນເຮັດຫຍັງ |
|---|---|
| {{key:Mod+Z}} | ຍ້ອນກັບການປ່ຽນແປງຄັ້ງສຸດທ້າຍ |
| {{key:Mod+Y}} ຫຼື {{key:Mod+Shift+Z}} | ເຮັດຊ້ຳສິ່ງທີ່ Undo ເອົາກັບຄືນ |
| {{key:Mod+C}} | ສຳເນົາອົງປະກອບທີ່ເລືອກ (ຊື່ ແລະ ຄຸນສົມບັດຂອງພວກມັນຖືກສົ່ງໄປ clipboard ເປັນຂໍ້ຄວາມເຊັ່ນກັນ) |
| {{key:Mod+X}} | ຕັດອົງປະກອບທີ່ເລືອກ: ສຳເນົາ ແລ້ວລຶບ |
| {{key:Mod+V}} | ວາງສິ່ງທີ່ທ່ານສຳເນົາ: ມັນຕາມຕົວຊີ້, ຄລິກບ່ອນທີ່ມັນຈະໄປ |
| {{key:Mod+Shift+V}} | ວາງໃນຕຳແໜ່ງເດີມ: ບ່ອນທີ່ການຕັດມາ, ຫຼື ຂ້າງຕົ້ນສະບັບຫຼັງຈາກສຳເນົາ |
| {{key:Mod+D}} | ສຳເນົາຊ້ຳ: ສຳເນົາອົງປະກອບທີ່ເລືອກ ແລະ ເລີ່ມວາງມັນ |
| {{key:Delete}} | ລຶບອົງປະກອບທີ່ເລືອກ ພ້ອມພາກສ່ວນ ແລະ ຊ່ອງເປີດຂອງມັນ. ເບິ່ງ [ລຶບ, ຕັດ, ສຳເນົາ ແລະ ວາງອົງປະກອບອາຄານ](topic:edit-elements) |
| {{key:Mod+A}} | ເລືອກທຸກອົງປະກອບທີ່ສະແດງ |
| {{key:Esc}} | ບໍ່ເລືອກອັນໃດເລີຍ |

ເມື່ອມີຂໍ້ຄວາມຖືກເລືອກໃນໜ້າ, {{key:Mod+C}} ຈະສຳເນົາຂໍ້ຄວາມນັ້ນຕາມປົກກະຕິ.
