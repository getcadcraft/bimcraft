## ສິ່ງທີ່ທ່ານຈະເຮັດ

ແມ່ແບບແມ່ນຂໍ້ຄວາມໃນ Markdown ທີ່ມີຊ່ອງຢູ່ໃນວົງເລັບປີກຄູ່. BimCraft ຕື່ມຊ່ອງເຫຼົ່ານັ້ນຈາກໂມເດວທີ່ເປີດ (ຈຳນວນ, ປະລິມານຕາມປະເພດ, ຄຸນສົມບັດ, [ແທັກ](topic:tags-and-schedules) ຂອງທ່ານ) ແລ້ວບັນທຶກຜົນເປັນ PDF, ເອກະສານ Word (.docx) ຫຼື Markdown.

## ຂັ້ນຕອນ

1. ເປີດໂມເດວ IFC.
2. ໃນແຜງດ້ານຊ້າຍ, ພາຍໃຕ້ {{ui:Quantities}}, ເປີດ {{ui:Documents from the model}}.
3. ເລືອກແມ່ແບບ: {{ui:Doors and hardware}} ຫຼື {{ui:Walls, linings and finishes}}, ຫຼື {{ui:Load a template (.md)…}} ສຳລັບແມ່ແບບຂອງທ່ານເອງ.
4. ຖ້າແມ່ແບບອ່ານແທັກທີ່ໂມເດວຍັງບໍ່ໄດ້ກຳນົດ, ໃຫ້ກົດ {{ui:Add this template’s tags}} ແລ້ວໃສ່ແທັກໃຫ້ອົງປະກອບພາຍໃຕ້ {{ui:Tags}}.
5. ແກ້ໄຂຂໍ້ຄວາມຕາມທີ່ທ່ານຕ້ອງການ ແລ້ວກົດ {{ui:Show the document}}.
6. ກົດ {{ui:PDF}} (ເລືອກ A4 ຫຼື Letter ກ່ອນ) ຫຼື {{ui:Word (.docx)}}.

## ສິ່ງທີ່ທ່ານຄວນເຫັນ

- ເອກະສານທີ່ຕື່ມແລ້ວຢູ່ໃຕ້ປຸ່ມ, ພ້ອມຕາຕະລາງ.
- ລາຍການຄຳເຕືອນເມື່ອຊ່ອງໃດອ່ານບໍ່ໄດ້ (ແທັກທີ່ບໍ່ໄດ້ກຳນົດ, ຄຸນສົມບັດທີ່ໂມເດວບໍ່ມີ, ບລັອກທີ່ບໍ່ເຄີຍປິດ); ຊ່ອງດັ່ງກ່າວຈະພິມເປັນ `[?…]`.
- ໜ້າ PDF ທີ່ມີຊື່ເອກະສານ ແລະ "Page 1 of 3" ຢູ່ລຸ່ມຂອງແຕ່ລະໜ້າ; ຕາຕະລາງຍາວຈະຂ້າມໄປໜ້າຕໍ່ໄປພ້ອມແຖວຫົວ.

## ຊ່ອງ

| ຊ່ອງ | ໃຫ້ຜົນ |
|---|---|
| `{{project}}`, `{{project description}}`, `{{file}}`, `{{date}}` | ຊື່ ແລະ ລາຍລະອຽດຂອງໂຄງການ, ຊື່ໄຟລ໌, ວັນນີ້ |
| `{{count IfcDoor}}` | ມີປະຕູຈັກບານ |
| `{{sum IfcWall NetSideArea}}` | ຜົນລວມ, ພ້ອມຫົວໜ່ວຍ |
| `{{calc [sum IfcWall NetSideArea] * 1.1 round 1 unit m²}}` | ການຄຳນວນ (`+ - * /` ແລະ ວົງເລັບ) ເທິງເງື່ອນໄຂໃນວົງເລັບເຫຼັ່ມ: `[sum …]`, `[count …]`, ແລະ ພາຍໃນ each ໃຊ້ `[qty Width]`. `round n` ກຳນົດຈຳນວນທົດສະນິຍົມ, `unit` ເພີ່ມຫົວໜ່ວຍ. ສິ່ງທີ່ອ່ານບໍ່ໄດ້, ຫຼື ການຫານດ້ວຍສູນ, ຈະພິມເປັນ `[?…]` ແລະ ເຕືອນ |
| `{{qty IfcWall NetSideArea by Type}}` | ຕາຕະລາງ: ໜຶ່ງແຖວຕໍ່ປະເພດ ພ້ອມຈຳນວນ ແລະ ຜົນລວມ, ແລະ ແຖວຜົນລວມ |
| `{{table IfcDoor cols Mark, Type, Width, tag:Fire rating}}` | ຕາຕະລາງ, ໜຶ່ງແຖວຕໍ່ອົງປະກອບ |
| `{{tag Finish}}` | ໃນ loop, ຄ່າຂອງອົງປະກອບ; ບ່ອນອື່ນ ທຸກຄ່າທີ່ໃຊ້ (Oak, Paint) |
| `{{tags}}` | ຄຳນິຍາມແທັກເປັນຕາຕະລາງ |
| `{{#each IfcDoor}} … {{else}} … {{/each}}` | ຂໍ້ຄວາມໜຶ່ງຄັ້ງຕໍ່ອົງປະກອບ; ສ່ວນຫຼັງ `{{else}}` ເມື່ອບໍ່ມີ |
| `{{#group IfcWall by Type}} … {{/group}}` | ຂໍ້ຄວາມໜຶ່ງຄັ້ງຕໍ່ປະເພດ, ພ້ອມ `{{value}}`, `{{count}}`, `{{sum Length}}` ແລະ `{{#each}}` ທຳມະດາພາຍໃນ |

ພາຍໃນ `{{#each}}`: `{{name}}`, `{{type}}`, `{{storey}}`, `{{class}}`, `{{material}}`, `{{mark}}` (IFC Tag), `{{guid}}`, `{{n}}` (1, 2, 3 …), `{{prop Pset_DoorCommon.FireRating}}`, `{{qty Width}}` (ຂອງອົງປະກອບເອງ, ພ້ອມຫົວໜ່ວຍ).

ຄລາດໜຶ່ງອາດມີຫຼາຍອັນ (`IfcDoor|IfcWindow`) ຫຼື ທຸກອົງປະກອບ (`*`). ຈຳກັດດ້ວຍ `where`: `{{#each IfcDoor where Fire rating >= 60}}`, `{{count IfcWall where Wall finish hasnot}}`. ເງື່ອນໄຂແມ່ນ `=`, `!=`, `~` (ມີ), `>`, `<`, `>=`, `<=`, `has` ແລະ `hasnot`; ເຊື່ອມຫຼາຍເງື່ອນໄຂດ້ວຍ `and`; ໃສ່ຄ່າທີ່ມີຍະຫວ່າງໃນ "ເຄື່ອງໝາຍຄຳພັງ". `sort Name` ຈັດລຽງ loop.

## ຕາຕະລາງ ແລະ ຂໍ້ມູນຈຳເພາະໃນເອກະສານ

`{{schedule doors}}` ພິມຕາຕະລາງຂອງໂມເດວເປັນຕາຕະລາງ, ຕາມການຈັດວາງຂອງສຳນັກງານທ່ານ: `doors`, `windows`, `walls`, `rooms`, `floors`, `roomfinishes`, `wallfinishes`, `zonefinishes`, `finishtotals`, `layers`, ຫຼື ຊື່ຂອງການຕັ້ງຄ່າທີ່ທ່ານບັນທຶກໄວ້ໃນ Schedules. `{{specification}}` ພິມຂໍ້ມູນຈຳເພາະຂອງໂຄງການ. ແມ່ແບບ **Working drawing schedules** ແລະ **Specification** ໃຊ້ສິ່ງເຫຼົ່ານີ້. ໃນການສະແດງຕົວຢ່າງ, ກົດໃສ່ຕົວເລກຂອງຕາຕະລາງດັ່ງກ່າວເພື່ອເລືອກອົງປະກອບທີ່ມາຈາກມັນ. ເບິ່ງ [ຈັດວາງ, ບັນທຶກ ແລະ ສົ່ງອອກຕາຕະລາງ](topic:schedule-layouts) ແລະ [ຂຽນຂໍ້ມູນຈຳເພາະຈາກໂມເດວ](topic:specification).

## ຄວນຮູ້

- ຊ່ອງໜຶ່ງລະບຸຊື່ໃນຕົວ (Name, Type, Storey, Class, Material, Mark), ແທັກ (`tag:Fire rating`, ຫຼື ຊື່ຂອງມັນ), ຄຸນສົມບັດ (`Pset_WallCommon.FireRating`) ຫຼື ພຽງແຕ່ຊື່ຄຸນສົມບັດ (`NetSideArea`, `Width`): ຊື່ເປົ່າຈະອ່ານຊຸດຂອງແຕ່ລະອົງປະກອບ, ໂດຍຊຸດປະລິມານມາກ່ອນ, ດັ່ງນັ້ນ `Width` ຂອງປະຕູແມ່ນຄວາມກວ້າງຂອງປະຕູ, ບໍ່ແມ່ນຄວາມໜາຂອງຝາ. ພາຍໃນ `where`, ຊື່ເປົ່າຈະອ່ານຊຸດທີ່ອົງປະກອບທີ່ເລືອກສ່ວນໃຫຍ່ມີ.
- ປະລິມານແມ່ນສິ່ງທີ່ຊຸດປະລິມານຂອງໄຟລ໌ບອກ (BimCraft ຂຽນໃຫ້ສຳລັບສິ່ງທີ່ມັນແຕ້ມ); ຫົວໜ່ວຍມາຈາກການຕັ້ງຄ່າຫົວໜ່ວຍຂອງໄຟລ໌.
- ຄຳຂອງຊ່ອງ (`count`, `sum`, `qty`, `by`, `cols`, `where`, `each`, `group` ແລະ ອື່ນໆ) ຄົງເປັນພາສາອັງກິດໃນທຸກພາສາ. ແມ່ແບບຕົວຢ່າງເປັນພາສາອັງກິດ.
- ຂໍ້ຄວາມຈາກໂມເດວບໍ່ເຄີຍກາຍເປັນການຈັດຮູບແບບ: ຊື່ທີ່ມີ `*` ຫຼື `|` ຈະພິມຕາມທີ່ມັນເປັນ.
- ເກັບແມ່ແບບທີ່ທ່ານແກ້ໄຂດ້ວຍ {{ui:Keep in this browser}} (ມີພຽງບຣາວເຊີນີ້) ຫຼື {{ui:Download the template}}.
- ຂໍ້ຄວາມ PDF ໃຊ້ຟອນ PDF ມາດຕະຖານ: ອັກຂະລະທີ່ຢູ່ນອກຂໍ້ຄວາມເອີຣົບຕາເວັນຕົກຈະພິມເປັນ "?" ແລະ ແຖບສະຖານະຈະບອກຈຳນວນ.
- ແມ່ແບບຕາມສາຂາຢູ່ໃນຄັງ (ປະເພດ Document template). ໃນ Documents from the model, ເລືອກ From the Library…, ເລືອກໜຶ່ງອັນ, ແລ້ວຂໍ້ຄວາມ ແລະ ແທັກທີ່ມັນອ່ານຈະເຂົ້າມາ; ແກ້ໄຂໄດ້ຕາມໃຈ. ການເຜີຍແຜ່ແມ່ແບບຂອງທ່ານໄປຄັງກໍເປັນການອັບໂຫຼດແບບດຽວກັບລາຍການອື່ນ. ຍັງບໍ່ໄດ້ສ້າງ: ການຄຳນວນນອກເໜືອຈາກຈຳນວນ ແລະ ຜົນລວມ.
