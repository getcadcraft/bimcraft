ຮູບໃນ {{ui:Render}} ຖືກແຕ້ມໂດຍ**ເອັນຈິນຂອງພວກເຮົາ**: ໄວ ແລະ Path tracer, ໃນບຣາວເຊີ ແລະ ໃນ CadCraft Studio. ໂປຣແກຣມອື່ນສາມາດແຕ້ມໄດ້ພຽງເມື່ອ**ສ່ວນເສີມເອັນຈິນເຣັນເດີ**ນຳມາ: ເບິ່ງ [ເພີ່ມເອັນຈິນເຣັນເດີດ້ວຍສ່ວນເສີມ](topic:render-engine-addons). ເພື່ອນຳສາກໄປໂປຣແກຣມອື່ນ ແລະ ເຮັດວຽກຕໍ່ທີ່ນັ້ນ, ໃຊ້ [ເປີດສາກໃນໂປຣແກຣມອື່ນ](topic:render-open-in) ຫຼື [ສົ່ງສາກໄປເອັນຈິນເກມ](topic:render-unreal).

## ແຕ້ມຮູບດ້ວຍເອັນຈິນຂອງສ່ວນເສີມ

1. ເປີດສ່ວນເສີມໃນ ການຕັ້ງຄ່າ › ສ່ວນເສີມ. ເອັນຈິນຂອງມັນຈະປາກົດໃນລາຍການເອັນຈິນຂອງ {{ui:Render}}.
2. ເລືອກມັນ. ການຕັ້ງຄ່າຂອງມັນເອງຈະສະແດງຢູ່ໃຕ້ລາຍການເອັນຈິນ.
3. ຄລິກ {{ui:Render}}. ໃນ Studio, ຄັ້ງທຳອິດທີ່ສ່ວນເສີມເປີດໂປຣແກຣມ, Studio ຈະຖາມທ່ານໃນກ່ອງໂຕ້ຕອບຂອງມັນເອງ. ຄວາມຄືບໜ້າສະແດງໃນຂະນະທີ່ມັນແຕ້ມ; {{ui:Stop}} ຢຸດມັນ. ຮູບຈະປາກົດພ້ອມໝາຍຊື່ເອັນຈິນທີ່ແຕ້ມມັນ.

ເອັນຈິນທີ່ຂຽນດ້ວຍ JavaScript ກໍເຮັດວຽກໃນບຣາວເຊີເຊັ່ນກັນ. ເອັນຈິນທີ່ເປີດໂປຣແກຣມຢູ່ຄອມພິວເຕີເຄື່ອງນີ້ເຮັດວຽກພຽງໃນ Studio; ໃນບຣາວເຊີ ມັນສະແດງເປັນໄຟລ໌ໃຫ້ບັນທຶກ.

## ສິ່ງທີ່ຖືກນຳໄປນຳ

ເອັນຈິນໄດ້ຮັບ**ແພັກເກດ**: ໂມເດວເປັນໄຟລ໌ USD (ແລະ ໄຟລ໌ glTF ເມື່ອມັນຮ້ອງຂໍ), ແລະ ໄຟລ໌ການຕັ້ງຄ່າທີ່ມີຄ່າວັດສະດຸທີ່ແນ່ນອນ, ດວງອາທິດ ແລະ ທ້ອງຟ້າ, ທຸກໂຄມໄຟທີ່ເປີດຢູ່ພ້ອມກຳລັງ ແລະ ໂປຣໄຟລ໌ແສງ, ກ້ອງ ແລະ ການເປີດຮັບແສງ. ແຕ່ລະໂປຣແກຣມໃຫ້ແສງ, ປັບໂທນ ແລະ ເກັບຕົວຢ່າງໃນແບບຂອງມັນເອງ, ສະນັ້ນຮູບຈະຄ້າຍກັນໃນກ້ອງ, ດວງອາທິດ, ໂຄມໄຟ ແລະ ການເປີດຮັບແສງ, ແຕ່ບໍ່ຄືກັນທຸກ pixel.

## ໂປຣແກຣມທີ່ CadCraft ບໍ່ເຄີຍເລີ່ມ

CadCraft ບໍ່ເຄີຍເລີ່ມໂປຣແກຣມພາຍໃຕ້ໃບອະນຸຍາດ GNU GPL, ແລະ ບໍ່ເຄີຍລະບຸມັນເປັນເອັນຈິນ ຫຼື ເປົ້າໝາຍ ເປີດໃນ. Blender ເປັນໜຶ່ງໃນນັ້ນ, ສະນັ້ນມັນບໍ່ຢູ່ໃນລາຍການເອັນຈິນ. ໄຟລ໌ USD ຫຼື glTF ທີ່ບັນທຶກຈາກ {{ui:Render}} ຍັງເປີດໃນມັນໄດ້ ເໝືອນໂປຣແກຣມໃດກໍໄດ້ທີ່ອ່ານໄຟລ໌ເຫຼົ່ານັ້ນ.

:::note
ກ້ອງ panorama ແລະ stereo ແລະ ຮູບທ້ອງຟ້າ (ສີຂອງທ້ອງຟ້າຖືກໃຊ້ແທນ) ບໍ່ຖືກນຳໄປໂປຣແກຣມອື່ນ. ສິ່ງທີ່ເຮັດໃນໂປຣແກຣມອື່ນຈະບໍ່ກັບຄືນມາຫາໂມເດວ.
:::
