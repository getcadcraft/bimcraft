ໃນ CadCraft Studio ລາຍການເອັນຈິນສາມາດມີ**ລິ້ງ**ໄປຫາໂປຣເຈັກ Unreal Engine. ທາງດຽວເທົ່ານັ້ນ: ຈາກ CadCraft ໄປ Unreal.

## ສົ່ງສາກ

1. ເລືອກລາຍການ Unreal ໃນລາຍການເອັນຈິນ. ຄັ້ງທຳອິດ, Studio ຈະຂໍໃຫ້ທ່ານເລືອກໂຟນເດີຂອງໂປຣເຈັກ (ອັນທີ່ມີໄຟລ໌ `.uproject`); ມັນຈະຈື່ໄວ້.
2. ຄລິກ {{ui:Send}}. Studio ຂຽນ `CadCraft/<file name>/` ພາຍໃນໂປຣເຈັກ: ສາກເປັນໄຟລ໌ USD, ໄຟລ໌ການຕັ້ງຄ່າ, ໂປຣໄຟລ໌ແສງ, ແລະ ໄຟລ໌ layer ນ້ອຍສອງໄຟລ໌.
3. ປ່ຽນໂມເດວ, ບັນທຶກ ແລ້ວສົ່ງອີກຄັ້ງ. ມີພຽງສາກ ແລະ ໄຟລ໌ການຕັ້ງຄ່າເທົ່ານັ້ນທີ່ຖືກແທນທີ່.

## ການແກ້ໄຂຂອງທ່ານປອດໄພ

Stage ທີ່ Unreal ເປີດແມ່ນ root layer ນ້ອຍທີ່ສ້າງຄັ້ງດຽວ, ມີສອງ layer ຢູ່ລຸ່ມ: **ຂອງທ່ານ** ຢູ່ເທິງສຸດ (`<name>.user.usda`, ເລີ່ມຕົ້ນວ່າງ, ບໍ່ເຄີຍຂຽນທັບໂດຍ CadCraft) ແລະ ສາກຂອງ CadCraft ຢູ່ລຸ່ມ. ການແກ້ໄຂທີ່ທ່ານບັນທຶກໃນ layer ຂອງທ່ານເອງຈະຢູ່ຕໍ່ເມື່ອສົ່ງສາກອີກຄັ້ງ. ແສງ ແລະ actor ອື່ນທີ່ທ່ານວາງໃນ level ຂອງ Unreal ຢູ່ນອກ stage ແລະ ກໍບໍ່ຖືກແຕະຕ້ອງເຊັ່ນກັນ.

## ໂດຍບໍ່ມີ Studio

ໃນບຣາວເຊີ, ຫຼື ໃນຄອມພິວເຕີທີ່ Studio ບໍ່ພົບ Unreal, ເລືອກ **ໂຟນເດີໂປຣເຈັກ Unreal (.zip)** ໃນລາຍການເອັນຈິນ ແລ້ວຄລິກ {{ui:Render}}. ມັນບັນທຶກໂຟນເດີດຽວກັນເປັນ zip: ແຕກມັນເຂົ້າໃນໂຟນເດີ `CadCraft` ຂອງໂປຣເຈັກ. ເປີດ **ລວມໄຟລ໌ stage** ໄວ້ໃນຄັ້ງທຳອິດ; ປິດມັນສຳລັບການບັນທຶກຕໍ່ໆໄປ, ເພື່ອໃຫ້ zip ມີພຽງສາກ ແລະ ໄຟລ໌ການຕັ້ງຄ່າ ແລະ layer ຂອງທ່ານບໍ່ຖືກແທນທີ່.

:::note
ປລັກອິນ Unreal ທີ່ເປີດ stage, ນຳໃຊ້ດວງອາທິດ, ໂຄມໄຟ, ກ້ອງ ແລະ ການເປີດຮັບແສງ, ຕິດຕາມແຕ່ລະການສົ່ງ ແລະ ເຣັນເດີກ້ອງ ຍັງ**ບໍ່ໄດ້ເປີດໃຫ້ໃຊ້**, ແລະ ຍັງບໍ່ໄດ້ທົດລອງໃນ Unreal. ຈົນກວ່າມັນຈະພ້ອມ, ການສົ່ງຈະວາງໄຟລ໌ໄວ້ໃນໂປຣເຈັກ ແລະ ເຄື່ອງມື USD ຂອງ Unreal ເອງສາມາດເປີດມັນໄດ້. Windows ເປັນລະບົບທຳອິດ; macOS ຕາມມາ.
:::
