## ສະຖານະສຳເນົາ

ທຸກສຳເນົາຂອງໂມເດວ, ທັງໄຟລ໌ຫຼັກ ແລະ ໄຟລ໌ສຳຮອງທີ່ມີໝາຍເລກ, ຈະໄດ້ຮັບການກວດ header.

| ປ້າຍ | ຄວາມໝາຍ |
|---|---|
| **ສົມບູນ** | Header ແລະ index ຂອງໄຟລ໌ຢູ່ພາຍໃນໄຟລ໌ |
| **ບໍ່ສົມບູນ** | ໄຟລ໌ສັ້ນກວ່າທີ່ index ຂອງມັນບອກ: ມັນຖືກຕັດອອກລະຫວ່າງການຄັດລອກ, ອັບໂຫຼດ ຫຼື ຊິງຄ໌, ຫຼື ມັນເປັນໄຟລ໌ຄລາວທີ່ຍັງເປັນ "online only" |
| **ອ່ານບໍ່ໄດ້** | ໄຟລ໌ບໍ່ແມ່ນ compound file ທີ່ຖືກຕ້ອງ ຫຼື ອ່ານບໍ່ໄດ້ |

ໃນຄໍລຳ **ສະຖານະ** ໂມເດວຈະສະແດງ **ສົມບູນ**, ສີເຫຼືອງ "*n* ບໍ່ສົມບູນ" ເມື່ອມີສຳເນົາຢ່າງໜ້ອຍໜຶ່ງອັນເສຍ ແຕ່ອີກອັນດີ, ຫຼື **ບໍ່ສົມບູນ** ສີແດງ ເມື່ອບໍ່ມີສຳເນົາໃດດີ.

## ໄຟລ໌ສຳຮອງ

ໄຟລ໌ທີ່ຊື່ `Name.0001.rvt`, `Name.0002.rvt` ແລະ ອື່ນໆ ແມ່ນໄຟລ໌ສຳຮອງທີ່ມີໝາຍເລກຂອງ `Name.rvt`. ພວກມັນຖືກຈັດກຸ່ມພາຍໃຕ້ໂມເດວ, ໃໝ່ສຸດກ່ອນ, ໃນ **All … copies**. ຂໍ້ມູນໃນບັດຈະອ່ານຈາກໄຟລ໌ຫຼັກເມື່ອມັນສົມບູນ, ຖ້າບໍ່ດັ່ງນັ້ນຈະອ່ານຈາກໄຟລ໌ສຳຮອງທີ່ສົມບູນໃໝ່ສຸດ ("newest complete").

## ບົດບາດ

ສະແດງເປັນຕົວໜັງສືອຽງໃຕ້ຊື່ຂອງໂມເດວ.

| ບົດບາດ | ຄວາມໝາຍ |
|---|---|
| ເຊື່ອມໂດຍ *ໂມເດວອື່ນ*: ພື້ນຫຼັງ | ມີໂມເດວອື່ນໃນໂຟນເດີເຊື່ອມໂຍງກັບອັນນີ້, ດັ່ງນັ້ນມັນອາດເປັນພື້ນຫຼັງຂອງຄົນອື່ນ ເຊັ່ນ ໂມເດວຂອງທີ່ປຶກສາ |
| ໄຟລ໌ເລີ່ມຕົ້ນ ຫຼື ບໍ່ມີຊື່ | ຊື່ເຊັ່ນ Blank, Template, Default, Untitled ຫຼື Project1: ຈຸດເລີ່ມຕົ້ນ ຫຼື ໄຟລ໌ທີ່ບໍ່ເຄີຍຖືກຕັ້ງຊື່ຢ່າງຖືກຕ້ອງ |
| ໂມເດວສູນກາງ | ໂມເດວສູນກາງທີ່ໃຊ້ຮ່ວມກັນ. ການເຮັດວຽກເກີດຂຶ້ນໃນສຳເນົາທ້ອງຖິ່ນ, ບໍ່ແມ່ນທີ່ນີ້ |
| ຊຸດ (ຊິ້ນສ່ວນ) | ໄຟລ໌ `.rfa` ຫຼື `.rft`: ເປັນຊິ້ນສ່ວນ ບໍ່ແມ່ນໂຄງການ |
| ສຳຮອງເທົ່ານັ້ນ | ໄຟລ໌ຫຼັກຫາຍໄປແລ້ວ ແລະ ເຫຼືອພຽງໄຟລ໌ສຳຮອງທີ່ມີໝາຍເລກ |

## ວິທີເລືອກ ເລີ່ມທີ່ນີ້

BimCraft ໃຊ້ເຫດຜົນເໝືອນຜູ້ໃຊ້ທີ່ມີປະສົບການ:

1. ໄຟລ໌ໂຄງການທີ່ອ່ານໄດ້ (`.rvt`, `.rte`) ທີ່ບໍ່ຖືກເຊື່ອມໂດຍໂມເດວອື່ນ ແລະ ບໍ່ແມ່ນໄຟລ໌ເລີ່ມຕົ້ນ ແມ່ນຜູ້ສະໝັກ.
2. ໂມເດວສູນກາງ ແລະ ໂມເດວສຳຮອງເທົ່ານັ້ນຈະນັບ ກໍຕໍ່ເມື່ອບໍ່ມີທາງເລືອກທີ່ດີກວ່າ.
3. ໃນບັນດາຜູ້ສະໝັກ, ອັນທີ່ບັນທຶກລ່າສຸດຈະໄດ້ຮັບເລືອກ.

ກ່ອງຈະບອກເຫດຜົນຂອງມັນ ແລະ ເຕືອນເມື່ອໄຟລ໌ທີ່ເບິ່ງຄືເປັນທາງເລືອກທີ່ຊັດເຈນເສຍຫາຍ, ເມື່ອໂມເດວອື່ນເປັນພື້ນຫຼັງ ແລະ ເມື່ອທີ່ເລືອກເປັນໂມເດວສູນກາງ. ນີ້ເປັນການຄາດເດົາທີ່ດີທີ່ສຸດ; ໃຫ້ກວດກັບຜູ້ທີ່ເຮັດວຽກກັບໂຄງການເປັນຄົນສຸດທ້າຍ.

## ສະຖານະການເຊື່ອມຕໍ່

| ປ້າຍ | ຄວາມໝາຍ |
|---|---|
| **ຢູ່ໃນໂຟນເດີນີ້** | ພົບຢູ່ເສັ້ນທາງສຳພັນທີ່ບັນທຶກໄວ້, ຫຼື ທ້າຍເສັ້ນທາງເຕັມທີ່ບັນທຶກໄວ້ພາຍໃນໂຟນເດີ |
| **ພົບຊື່ດຽວກັນ** | ບໍ່ຢູ່ເສັ້ນທາງຂອງມັນ, ແຕ່ມີໄຟລ໌ທີ່ຊື່ດຽວກັນຢູ່ໃນໂຟນເດີ. ໃຫ້ກວດວ່າເປັນອັນທີ່ຖືກຕ້ອງ |
| **ໄຟລ໌ຄັງ** | ຕາຕະລາງ keynote ຫຼື ລະຫັດການປະກອບ. ອັນເຫຼົ່ານີ້ມາພ້ອມໂປຣແກຣມໃນແຕ່ລະຄອມພິວເຕີ |
| **ບໍ່ຢູ່ໃນໂຟນເດີນີ້** | ບໍ່ພົບຢູ່ບ່ອນໃດໃນໂຟນເດີ |

ຄໍລຳ **ການເຊື່ອມຕໍ່ທີ່ພົບ** ໃນ **ໂມເດວ** ສະແດງວ່າພົບການເຊື່ອມຕໍ່ຂອງໂມເດວເທົ່າໃດ, ຈາກຈຳນວນທີ່ຄາດວ່າຈະຢູ່ໃນໂຟນເດີ (ໄຟລ໌ຄັງບໍ່ນັບ).
