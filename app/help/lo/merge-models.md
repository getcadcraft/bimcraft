ສອງຄົນເອົາສຳເນົາຂອງອາຄານດຽວກັນ, ຄົນໜຶ່ງແຕ້ມປີກຕາເວັນອອກ ແລະ ອີກຄົນແຕ້ມປີກຕາເວັນຕົກ, ແລ້ວຕໍ່ມາສຳເນົາຕ້ອງກາຍເປັນອັນດຽວ. ຖ້າພວກເຂົາແຕະວັດຖຸຕ່າງກັນ, ໂປຣແກຣມສາມາດເຮັດມັນແທນຄົນໄດ້.

## ສິ່ງທີ່ເຮັດໃຫ້ມັນເຮັດວຽກ

ທຸກຝາ, ປະຕູ, ລະດັບ, ຫ້ອງ ແລະ ຊຸດຄຸນສົມບັດໃນໄຟລ໌ IFC ມີ GlobalId ທີ່ບໍ່ປ່ຽນແປງ. ການລວມຊອກວັດຖຸດ້ວຍລະຫັດນັ້ນ, ບໍ່ແມ່ນດ້ວຍເລກທີ່ໄຟລ໌ໃຫ້ (`#123`), ເພາະເລກປ່ຽນເມື່ອໂປຣແກຣມບັນທຶກ. ສ່ວນທີ່ຕິດກັບວັດຖຸແຕ່ບໍ່ມີລະຫັດຂອງຕົນເອງ (ການວາງຕຳແໜ່ງ, ຮູບຮ່າງ, ໜ່ວຍ) ຖືກປຽບທຽບດ້ວຍສິ່ງທີ່ມັນບັນຈຸ.

ທັງສອງສຳເນົາຕ້ອງເປັນເວີຊັນ IFC ດຽວກັນ (2x3, 4 ຫຼື 4.3). ການລວມຮັກສາໄຟລ໌ຂອງທ່ານໄວ້ຕາມເດີມ, ລຳດັບ ແລະ ເລກຂອງມັນ, ແລະ ເພີ່ມສິ່ງໃໝ່, ດັ່ງນັ້ນ git diff ຂອງການລວມສະແດງພຽງສິ່ງທີ່ການລວມປ່ຽນ.

## ຕັ້ງຄ່າ

Git ຕ້ອງການສອງແຖວຄັ້ງດຽວຕໍ່ repository:

```
# .gitattributes
*.ifc merge=cadcraft

# ເທື່ອດຽວ, ໃນແຕ່ລະຄອມພິວເຕີ
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

ຖ້າບໍ່ມີ git, ແລ່ນ `cadcraft merge <base> <ours> <theirs>`. Fossil ແລະ Mercurial ໃຊ້ສາມໄຟລ໌ດຽວກັນໃນການຕັ້ງຄ່າເຄື່ອງມືລວມຂອງພວກມັນເອງ. ບໍ່ມີຫຍັງຖືກອັບໂຫຼດ; ທຸກຢ່າງເຮັດວຽກຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ.

## ກົດ

- ແອັດທຣິບິວທີ່ປ່ຽນດ້ານດຽວຈະຖືກເອົາ. ການປ່ຽນແປງຄືກັນທັງສອງດ້ານຖືກເອົາຄັ້ງດຽວ.
- ແອັດທຣິບິວດຽວກັນທີ່ປ່ຽນສອງວິທີ (ລະດັບດຽວກັນຖືກປ່ຽນຊື່ສອງວິທີ) ແມ່ນ **ຂໍ້ຂັດແຍ້ງ**: ດ້ານຂອງທ່ານຈະຢູ່, ແລະ ລາຍງານລາຍການທັງສອງ. ເປີດຜົນລັບ ແລະ ແກ້ດ້ວຍມື.
- ລາຍການຂອງສິ່ງຕ່າງໆ (ຝາຂອງລະດັບ, ຄຸນສົມບັດຂອງຊຸດ) ລວມເປັນຊຸດ: ສິ່ງທີ່ດ້ານໃດດ້ານໜຶ່ງເພີ່ມຈະຖືກເກັບໄວ້ ແລະ ສິ່ງທີ່ດ້ານໃດດ້ານໜຶ່ງລຶບຈະຖືກລຶບ. ສອງຄົນທີ່ເພີ່ມຝາໃສ່ລະດັບດຽວກັນຈະບໍ່ຂັດແຍ້ງ.
- ວັດຖຸທີ່ເພີ່ມດ້ານໃດກໍໄດ້ຖືກເກັບໄວ້, ພ້ອມຮູບຮ່າງ ແລະ ຄຸນສົມບັດຂອງມັນ. ລຶບດ້ານໜຶ່ງ ແລະ ບໍ່ຖືກແຕະດ້ານອື່ນ: ຖືກລຶບ. ລຶບດ້ານໜຶ່ງ ແລະ ປ່ຽນດ້ານອື່ນ: ຖືກລຶບ ແລະ ລາຍງານ.
- ເວລາປະທັບ ແລະ ຜູ້ຂຽນຂອງໄຟລ໌, ແລະ ປະຫວັດເຈົ້າຂອງຂອງແຕ່ລະວັດຖຸ, ຄົງເປັນຂອງທ່ານ.

ການຮູບຮ່າງຖືກລວມທັງໝົດ: ຮູບຮ່າງຂອງຝາມາຈາກດ້ານໜຶ່ງ, ບໍ່ເຄີຍປະສົມຈຸດຕໍ່ຈຸດ. ໄຟລ໌ IFC ທີ່ບີບອັດ ແລະ IFCX ບໍ່ຖືກລວມ. ຫຼັງການລວມ, ເປີດຜົນລັບໃນ BimCraft ແລະ ເບິ່ງແຜງ {{ui:ບັນຫາ}} ກ່ອນທີ່ທ່ານຈະບັນທຶກ.
