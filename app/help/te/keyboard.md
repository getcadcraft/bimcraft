BimCraft లో కొన్ని షార్ట్‌కట్‌లు మాత్రమే ఉన్నాయి. చాలా పని మౌస్ మరియు ప్యానెల్‌లతో జరుగుతుంది. {{key:Mod}} తో రాసిన షార్ట్‌కట్‌లు Mac పై Command, మరెక్కడైనా Ctrl ఉపయోగిస్తాయి. ఈ సహాయంలో కీలు ఎలా రాయబడ్డాయో చూడడానికి [కీలు, మౌస్‌లు మరియు ట్రాక్‌ప్యాడ్‌లు](common:keys) చూడు.

## ప్రతిచోటా

| కీ | ఏమి చేస్తుంది |
|---|---|
| {{key:Ctrl+Shift+F}} | స్క్రీన్ మోడ్‌లను మార్చు: సాధారణ, పూర్తి స్క్రీన్, బార్‌లు దాచిన పూర్తి స్క్రీన్. అన్ని ప్లాట్‌ఫామ్‌లపై Ctrl, Mac తో సహా |
| {{key:Esc}} | పూర్తి స్క్రీన్ నుండి బయటకు రా |
| {{key:Mod+,}} | {{ui:Settings}} తెరువు. [BimCraft సెట్టింగ్‌లు](topic:settings) చూడండి |
| {{key:Tab}} | బటన్‌లు, చెక్‌బాక్స్‌లు మరియు విలువల మధ్య కదులు. ప్రతి నియంత్రణను కీబోర్డ్ నుండి చేరవచ్చు |

## 3D వీక్షణ (IFC మోడల్‌లు)

| {{key:Esc}} | ఎంపిక తీసివేయి, లేదా ఉంచడం లేదా అతికించడం ఆపు |
| క్లిక్ | పాయింటర్ కింద ఉన్న ఎలిమెంట్‌ను ఎంచుకో; ఖాళీ నేపథ్యంపై క్లిక్ చేస్తే ఎంపిక తీసివేయబడుతుంది |
| {{key:Mod}}+క్లిక్ లేదా {{key:Shift}}+క్లిక్ | ఎంపికకు ఎలిమెంట్ జోడించు, లేదా తీసివేయి |

| {{key:I}} | ఎంచుకున్న ఎలిమెంట్‌లను మాత్రమే చూపు (వేరుగా) |
| {{key:T}} | ఎంచుకున్న ఎలిమెంట్‌లను చూపు, మిగతావన్నీ ద్వారా చూడగలిగేలా |
| {{key:Shift+H}} | ప్రతి ఎలిమెంట్‌ను మళ్ళీ చూపు |
| {{ui:Walk}} | తర్వాత {{key:W}} {{key:A}} {{key:S}} {{key:D}} లేదా బాణం కీలు నడిపిస్తాయి, {{key:Shift}} పరుగెత్తిస్తుంది, లాగితే చుట్టూ చూస్తారు, {{key:Esc}} ఆపుతుంది. [మోడల్ ద్వారా నడువు](topic:walk) చూడండి |
| {{key:M}} | దూరాలు మరియు ఫేస్ ప్రాంతాలను కొలవు. [3Dలో దూరాలు, ఫేస్ ప్రాంతాలు మరియు స్థానాలను కొలవు](topic:measure) చూడండి |
| ఎడమ బటన్‌తో లాగు | ఆర్బిట్ |
| కుడి బటన్‌తో లాగు | ప్యాన్ |
| {{key:Shift}} లేదా {{key:Mod}} మరియు ఎడమ బటన్‌తో లాగు | ప్యాన్ (ట్రాక్‌ప్యాడ్‌పై ఉపయోగకరం) |
| వీల్ స్క్రోల్ చేయి, లేదా మధ్య బటన్‌తో లాగు | జూమ్ |
| ట్రాక్‌ప్యాడ్‌పై రెండు వేళ్ల స్క్రోల్ లేదా పిన్చ్ | జూమ్ |
| ఒక వేలు (టచ్) | ఆర్బిట్; ట్యాప్ ఎంచుకుంటుంది |
| రెండు వేళ్లు (టచ్) | పిన్చ్ చేసి జూమ్, కలిసి కదిలిస్తే ప్యాన్ |

| {{key:X}} | సెక్షన్ ప్లేన్ ఆన్ మరియు ఆఫ్. [సెక్షన్ ప్లేన్‌తో IFC మోడల్‌ను కత్తిరించు](topic:section-plane) చూడండి |
| {{key:Shift+X}} | ఎంచుకున్న ఎలిమెంట్‌ల చుట్టూ సెక్షన్ బాక్స్, సెట్టింగ్‌లలో అమర్చిన గదితో |

{{ui:Top}}, {{ui:Front}} మరియు {{ui:Side}} కోసం కీలు లేవు; బటన్‌లు ఉపయోగించు.

## సవరణ

అవే కమాండ్‌లు టూల్‌బార్‌లో ఉన్నాయి: {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}} మరియు {{ui:More}} మెనూ, ఇది ప్రతి కీని చూపుతుంది. అవి IFC మోడల్ 3D వీక్షణలో పని చేస్తాయి, ఒక ఫీల్డ్‌లో టైప్ చేస్తున్నప్పుడు కాదు. [లైబ్రరీ అంశాలను కాపీ, అతికించు మరియు డూప్లికేట్ చేయి](topic:copy-paste) చూడండి.

| కీ | ఏమి చేస్తుంది |
|---|---|
| {{key:Mod+Z}} | చివరి మార్పును రద్దు చేయి |
| {{key:Mod+Y}} లేదా {{key:Mod+Shift+Z}} | రద్దు చేసినదాన్ని మళ్ళీ చేయి |
| {{key:Mod+C}} | ఎంచుకున్న ఎలిమెంట్‌లను కాపీ చేయి (వాటి పేర్లు మరియు ప్రాపర్టీలు టెక్స్ట్‌గా క్లిప్‌బోర్డ్‌కు కూడా వెళ్తాయి) |
| {{key:Mod+X}} | ఎంచుకున్న ఎలిమెంట్‌లను కత్తిరించు: వాటిని కాపీ చేసి, తర్వాత తొలగించు |
| {{key:Mod+V}} | మీరు కాపీ చేసినదాన్ని అతికించు: అది పాయింటర్‌ను అనుసరిస్తుంది, ఎక్కడ వెళ్తుందో అక్కడ క్లిక్ చేయి |
| {{key:Mod+Shift+V}} | అదే చోట అతికించు: కత్తిరించినది ఎక్కడ నుండి వచ్చిందో, లేదా కాపీ తర్వాత అసలు వాటి పక్కన |
| {{key:Mod+D}} | డూప్లికేట్: ఎంచుకున్న ఎలిమెంట్‌లను కాపీ చేసి అతికించడం మొదలుపెట్టు |
| {{key:Delete}} | ఎంచుకున్న ఎలిమెంట్‌లను, వాటి భాగాలు మరియు ఓపెనింగ్‌లతో తొలగించు. [బిల్డింగ్ ఎలిమెంట్‌లను తొలగించు, కత్తిరించు, కాపీ చేయి మరియు అతికించు](topic:edit-elements) చూడండి |
| {{key:Mod+A}} | కనిపించే ప్రతి ఎలిమెంట్‌ను ఎంచుకో |
| {{key:Esc}} | ఏదీ ఎంచుకోకు |

పేజీలో టెక్స్ట్ ఎంచుకుని ఉంటే, {{key:Mod+C}} ఆ టెక్స్ట్‌ను సాధారణంగా కాపీ చేస్తుంది.

## ప్లాన్ వీక్షణ (డ్రా)

{{ui:Draw}} ఆన్ ఉండి, మీరు ఫీల్డ్‌లో టైప్ చేయనప్పుడు ఇవి పని చేస్తాయి. [గోడలు గీయి](topic:draw-walls) మరియు [తలుపులు మరియు కిటికీలు](topic:doors-and-windows) చూడండి.

| కీ లేదా చర్య | ఏమి చేస్తుంది |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | {{ui:Door}} లేదా {{ui:Window}} తో: కీలు మరొక చివరన |
| గోడ గీస్తున్నప్పుడు {{key:Shift}} | దానిని 0°, 90°, 180° లేదా 270° వద్ద ఉంచు |
| అంకెలు మరియు అడుగు, అంగుళం గుర్తులు (`'` మరియు `"`) | {{ui:Length}} బాక్స్‌లో పొడవు టైప్ చేయడం మొదలుపెట్టు; {{key:Enter}} దానిని ఉపయోగిస్తుంది |
| {{key:Enter}}, {{key:Esc}}, రైట్-క్లిక్ లేదా డబుల్-క్లిక్ | మీరు గీస్తున్న గోడను ముగించు; {{key:Esc}} మళ్ళీ నొక్కితే {{ui:Select}} కి వెళ్తుంది |
| {{key:Delete}} | ఎంచుకున్న గోడలు, తలుపులు మరియు కిటికీలను తొలగించు; మిగిలిన గోడలు మళ్ళీ కలుస్తాయి |
| పాయింటర్ ప్లాన్ మీద ఉన్నప్పుడు {{key:F}} | ప్లాన్‌ను అమర్చు |
| వీల్ స్క్రోల్ చేయి | పాయింటర్ చుట్టూ జూమ్ చేయి |
| మధ్య లేదా కుడి బటన్‌తో లాగు, లేదా {{key:Space}} మరియు లాగు | ప్యాన్; {{ui:Select}} ఆన్ ఉంటే, సాదా లాగడం కూడా ప్యాన్ చేస్తుంది |
| {{ui:Select}} తో తలుపు లేదా కిటికీని లాగు | దాని గోడ వెంట, లేదా మరో గోడపైకి కదిలించు |
| రెండు వేళ్లు (టచ్) | పిన్చ్ చేసి జూమ్, కలిసి కదిలిస్తే ప్యాన్ |

## IFC విలువలను సవరించడం

| కీ | ఏమి చేస్తుంది |
|---|---|
| {{key:Enter}} | టైప్ చేసిన విలువను ఉంచు |
| {{key:Esc}} | రద్దు చేసి పాత విలువను తిరిగి ఉంచు |
| మరెక్కడైనా క్లిక్ | టైప్ చేసిన విలువను ఉంచు |
| {{key:Mod+Z}} | చివరి మార్పును రద్దు చేయి. సేవ్ చేయని మార్పులు ఉన్నప్పుడు మరియు ఫీల్డ్‌లో టైప్ చేయనప్పుడు మాత్రమే |
| {{key:Mod+Y}} | రద్దు చేసినదాన్ని మళ్ళీ చేయి |
| {{key:Mod+S}} | IFCగా సేవ్ చేయి. సేవ్ చేయని మార్పులు ఉన్నప్పుడు మాత్రమే; లేకపోతే బ్రౌజర్ సొంత సేవ్ కమాండ్ తెరుచుకుంటుంది |

కీబోర్డ్ మాత్రమే ఉపయోగించి సవరించడానికి: ఒక విలువ హైలైట్ అయ్యే వరకు {{key:Tab}} నొక్కు, తర్వాత టైప్ చేయడం మొదలుపెట్టడానికి {{key:Enter}} నొక్కు.

| ఒక వేలు (టచ్) | ప్యాన్. డ్రాయింగ్‌లకు పిన్చ్ జూమ్ ఇంకా తయారు కాలేదు |

## 3Dలో డ్రాయింగ్‌లు

| కీ లేదా చర్య | ఏమి చేస్తుంది |
|---|---|
| {{key:3}} | 3D ఆన్ మరియు ఆఫ్ (2D వీక్షణపై కూడా) |
| {{key:F}} | ఎక్స్‌టెంట్స్: మొత్తం డ్రాయింగ్ |
| మధ్య లేదా ఎడమ బటన్‌తో లాగు | ఆర్బిట్ |
| కుడి బటన్‌తో లాగు, లేదా {{key:Shift}} మరియు లాగు | ప్యాన్ |
| వీల్ స్క్రోల్ చేయి | పాయింటర్ కింద ఉన్న దాని వైపు జూమ్ |
| ట్రాక్‌ప్యాడ్‌పై రెండు వేళ్ల స్వైప్ | ఆర్బిట్; {{key:Shift}} తో ప్యాన్ |
| ట్రాక్‌ప్యాడ్‌పై పిన్చ్ | జూమ్ |
| ఒక వేలు (టచ్) | ఆర్బిట్ |
| రెండు వేళ్లు (టచ్) | పిన్చ్ చేసి జూమ్, కలిసి కదిలిస్తే ప్యాన్ |

{{key:F}}, {{key:P}} మరియు {{key:3}} ఫీల్డ్‌లో టైప్ చేస్తున్నప్పుడు, పరికరాల షెడ్యూల్ కనిపిస్తున్నప్పుడు, లేదా {{key:Mod}} లేదా {{key:Alt}} పట్టుకున్నప్పుడు ఏమీ చేయవు.
