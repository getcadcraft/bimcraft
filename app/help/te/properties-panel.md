## IFC ఎలిమెంట్

{{ui:Properties}} ప్యానెల్ పైభాగం ఎలిమెంట్ రకాన్ని చూపుతుంది, "Ifc" ఉపసర్గ లేకుండా (ఉదాహరణకు "Door", "WallStandardCase", "FurnishingElement"), మరియు దాని పేరు, లేదా పేరులేనిది అయితే "Unnamed".

| ఫీల్డ్ | అర్థం | మార్చగలరా |
|---|---|---|
| Name | ఎలిమెంట్ పేరు, తరచుగా ఎక్స్‌పోర్టర్ నుండి ఫ్యామిలీ మరియు టైప్ పేరు | అవును |
| Type | ఎలిమెంట్ యొక్క టైప్ పేరు, దానికి ఉన్నప్పుడు | లేదు |
| Object type | కొన్ని ఎక్స్‌పోర్టర్లు నింపే ఉచిత-టెక్స్ట్ టైప్ వివరణ | అవును |
| Tag | ఎలిమెంట్ యొక్క tag లేదా mark; అనేక ఎక్స్‌పోర్టర్లు ఇక్కడ ఎలిమెంట్ ID రాస్తారు | అవును |
| Description | ఉచిత టెక్స్ట్ | అవును |
| GlobalId | ఎలిమెంట్ యొక్క శాశ్వత 22-అక్షరాల IFC గుర్తింపు; అదే ఎలిమెంట్ యొక్క ప్రతి ఎక్స్‌పోర్ట్‌లో ఒకేలా ఉంటుంది | లేదు |
| Line | ఈ IFC ఫైల్‌లో ఎలిమెంట్ యొక్క లైన్ నంబర్ (`#1234`). ఎక్స్‌పోర్ట్‌ల మధ్య ఇది మారుతుంది | లేదు |

కింద **ప్రాపర్టీ సెట్‌లు** పేరు ప్రకారం క్రమబద్ధీకరించబడి వస్తాయి:

- ప్రతి సెట్ దాని పేరుపై క్లిక్ చేస్తే తెరుచుకుంటుంది, మూసుకుంటుంది. మొదటి మూడు తెరిచి ఉంటాయి.
- "(type)" అని గుర్తించబడిన సెట్ ఎలిమెంట్ టైప్‌కు చెందుతుంది: "Type property: ఇక్కడ మార్పు ఈ టైప్ యొక్క ప్రతి ఎలిమెంట్‌కు వర్తిస్తుంది."
- క్వాంటిటీ సెట్‌లు (పొడవులు, ప్రాంతాలు, ఘనపరిమాణాలు, లెక్కలు, బరువులు) చదవడానికి మాత్రమే.
- జాబితాలు మరియు ఎన్యూమరేటెడ్ విలువలు చూపబడతాయి, చదవడానికి మాత్రమే.
- అవును/కాదు విలువలు **Yes** లేదా **No** గా చూపబడతాయి.
- సంఖ్యలు ప్రదర్శన కోసం నాలుగు దశాంశాలకు రౌండ్ చేయబడతాయి. పొడవులు (పొడవు ప్రాపర్టీ లేదా క్వాంటిటీ యొక్క పొడవు) టూల్‌బార్‌లో ఎంచుకున్న {{ui:Units}} లో చూపబడతాయి, పక్కన యూనిట్‌తో; మీరు ఆ యూనిట్‌లో లేదా మరో యూనిట్ గుర్తుతో (2.4 m, 8'-0") కొత్త విలువను టైప్ చేయవచ్చు: BimCraft ఫైల్ యొక్క సొంత సంఖ్యను తిరిగి రాస్తుంది. ఇతర సంఖ్యలు ఫైల్‌లో ఉన్నట్లుగా చూపబడతాయి.
- ఖాళీ విలువ *empty* గా చూపబడుతుంది. మార్చిన విలువ బోల్డ్‌గా, పక్కన నీలి బార్‌తో ఉంటుంది.

## విలువ కాపీ చేయండి

{{ui:Properties}} లో ప్రతి విలువ పక్కన ఒక చిన్న కాపీ బటన్ ఉంటుంది: దానిపై క్లిక్ చేస్తే ఆ విలువ చూపిన విధంగానే క్లిప్‌బోర్డ్‌కు వెళ్తుంది, ఉదాహరణకు GlobalId, సీరియల్ నంబర్ లేదా ఏదైనా ప్రాపర్టీ సెట్ విలువ. కాపీ చేయడం ఎప్పుడూ ఎడిట్ మొదలుపెట్టదు.

పైన, {{ui:Copy all}} ఎలిమెంట్ యొక్క ప్రతి విలువను టెక్స్ట్‌గా, సెట్ వారీగా కాపీ చేస్తుంది. {{ui:Copy as CSV}} వాటిని group, property మరియు value వరుసలుగా కాపీ చేస్తుంది, స్ప్రెడ్‌షీట్‌లో అతికించడానికి; ఖాళీ విలువలు ఉంచబడతాయి, తద్వారా ప్రతి ఫీల్డ్‌కు ఒక వరుస ఉంటుంది. ఇది తెరిచి ఉన్న మరో మోడల్ ఎలిమెంట్‌కు కూడా అదే విధంగా పనిచేస్తుంది; ఒకటి కంటే ఎక్కువ మోడల్‌లు తెరిచి ఉంటే CSV ఒక Model కాలమ్‌తో మొదలవుతుంది, అది ఫైల్ పేరు చెబుతుంది.

## File ప్యానెల్ (IFC)

| ఫీల్డ్ | అర్థం |
|---|---|
| File, Size | మీరు తెరిచిన ఫైల్ |
| Schema | IFC వెర్షన్, ఉదాహరణకు IFC2X3 లేదా IFC4 |
| Project | ప్రాజెక్ట్ పేరు మరియు పొడవైన పేరు |
| Phase | ప్రాజెక్ట్ దశ, ఎక్స్‌పోర్టర్ రాస్తే |
| Exported from | ఎక్స్‌పోర్ట్ చేసిన ప్రోగ్రామ్, ఫైల్ హెడర్ నుండి |
| Author | ఫైల్ హెడర్‌లోని రచయిత |
| Exported | ఫైల్ హెడర్‌లోని తేదీ మరియు సమయం |
| Elements | ఆకారం ఉన్న ఎన్ని ఎలిమెంట్లు గీయబడ్డాయి |
| Triangles | వాటి ఆకారాలు ఎన్ని ట్రయాంగిల్స్ చేస్తాయి; మోడల్ ఎంత బరువుందో కొలమానం |

| Layers | ఎన్ని లేయర్లు |
| Sheets | ఎన్ని షీట్‌లు (లేఅవుట్‌లు), లేదా లేదు |
| Linked drawings | దాని లింక్ చేయబడిన డ్రాయింగ్‌లలో ఎన్ని కనుగొని లోడ్ చేయబడ్డాయి |
| Equipment | షీట్‌లపై ట్యాగ్ చేయబడిన ఎన్ని equipment ఐటమ్‌లు ఉన్నాయి |
