BimCraft má málo skratiek. Väčšinu práce robíte myšou a panelmi. Skratky zapísané s {{key:Mod}} používajú Command na Macu a Ctrl inde. Pozri [Klávesy, myši a touchpady](common:keys), ako sa klávesy zapisujú v tejto pomoci.

## Všade

| Klávesa | Čo robí |
|---|---|
| {{key:Ctrl+Shift+F}} | Prepína režimy obrazovky: normálny, celá obrazovka, celá obrazovka so skrytými lištami. Ctrl na každej platforme vrátane Macu |
| {{key:Esc}} | Ukončí celú obrazovku |
| {{key:Mod+,}} | Otvorí {{ui:Nastavenia}}. Pozri [Nastavenia BimCraft](topic:settings) |
| {{key:Tab}} | Presun medzi tlačidlami, začiarkavacími políčkami a hodnotami. Ku každému ovládaciemu prvku sa dá dostať z klávesnice |

## 3D pohľad (modely IFC)

| Klávesa alebo akcia | Čo robí |
|---|---|
| {{key:F}} | Prispôsobí celý model, trojštvrťový pohľad (rovnako ako {{ui:Prispôsobiť}}) |
| {{key:Esc}} | Zruší výber, alebo zastaví umiestňovanie či prilepovanie |
| Kliknutie | Vyberie prvok pod ukazovateľom; kliknutím na prázdne pozadie výber zrušíte |
| {{key:Mod}}+kliknutie alebo {{key:Shift}}+kliknutie | Pridá prvok do výberu alebo ho z neho odoberie |
| {{key:H}} | Skryje vybrané prvky. Pozri [Skrytie, izolácia a priehľadnosť prvkov](topic:hide-and-isolate) |
| {{key:I}} | Zobrazí iba vybrané prvky (izolácia) |
| {{key:T}} | Zobrazí vybrané prvky, všetko ostatné priehľadné |
| {{key:Shift+H}} | Znova zobrazí každý prvok |
| {{ui:Prechádzka}} | Potom {{key:W}} {{key:A}} {{key:S}} {{key:D}} alebo šípky chodia, {{key:Shift}} beží, potiahnutie sa rozhliada, {{key:Esc}} zastaví. Pozri [Prechádzka modelom](topic:walk) |
| {{key:M}} | Meria vzdialenosti a obsahy plôch. Pozri [Meranie vzdialeností, plôch a polôh v 3D](topic:measure) |
| Potiahnutie ľavým tlačidlom | Obieha |
| Potiahnutie pravým tlačidlom | Posúva |
| {{key:Shift}} alebo {{key:Mod}} a potiahnutie ľavým tlačidlom | Posúva (výhodné na touchpade) |
| Rolovanie kolieska alebo potiahnutie stredným tlačidlom | Zväčšuje |
| Rolovanie dvoma prstami alebo roztiahnutie na touchpade | Zväčšuje |
| Jeden prst (dotyk) | Obieha; ťuknutie vyberie |
| Dva prsty (dotyk) | Roztiahnutím zväčší; posunutím prstov spolu posúva |

| {{key:X}} | Rovina rezu zapnutá a vypnutá. Pozri [Rozrezanie modelu IFC rovinou rezu](topic:section-plane) |
| {{key:Shift+X}} | Škatuľa rezu okolo vybraných prvkov, s miestnosťou nastavenou v Nastaveniach |

Pre {{ui:Zhora}}, {{ui:Spredu}} a {{ui:Bok}} nie sú klávesy; použite tlačidlá.

## Úpravy

Rovnaké príkazy sú na paneli nástrojov: {{ui:Späť}}, {{ui:Znova}}, {{ui:Kopírovať}}, {{ui:Prilepiť}} a ponuka {{ui:Viac}}, ktorá zobrazuje každú klávesu. Fungujú v 3D pohľade modelu IFC, nie keď píšete do poľa. Pozri [Kopírovanie, prilepenie a duplikovanie položiek knižnice](topic:copy-paste).

| Klávesa | Čo robí |
|---|---|
| {{key:Mod+Z}} | Späť posledná zmena |
| {{key:Mod+Y}} alebo {{key:Mod+Shift+Z}} | Znova to, čo krok Späť vzal späť |
| {{key:Mod+C}} | Skopíruje vybrané prvky (ich názvy a vlastnosti sa tiež pošlú do schránky ako text) |
| {{key:Mod+X}} | Vystrihne vybrané prvky: skopíruje ich a potom zmaže |
| {{key:Mod+V}} | Prilepí to, čo ste skopírovali: nasleduje ukazovateľ, kliknite, kam to má ísť |
| {{key:Mod+Shift+V}} | Prilepí na rovnaké miesto: tam, odkiaľ bolo vystrihnuté, alebo vedľa originálov po kopírovaní |
| {{key:Mod+D}} | Duplikuje: skopíruje vybrané prvky a spustí ich prilepovanie |
| {{key:Delete}} | Zmaže vybrané prvky aj s ich časťami a otvormi. Pozri [Zmazanie, vystrihnutie, kopírovanie a prilepenie stavebných prvkov](topic:edit-elements) |
| {{key:Mod+A}} | Vyberie každý zobrazený prvok |
| {{key:Esc}} | Zruší výber |

Keď je na stránke vybraný text, {{key:Mod+C}} skopíruje tento text ako obvykle.

## Pohľad na pôdorys (Kresliť)

Tieto fungujú, keď je {{ui:Kresliť}} zapnuté a nepíšete do poľa. Pozri [Kreslenie stien](topic:draw-walls) a [Dvere a okná](topic:doors-and-windows).

| Klávesa alebo akcia | Čo robí |
|---|---|
| {{key:V}} | {{ui:Vybrať}} |
| {{key:W}} | {{ui:Stena}} |
| {{key:D}} | {{ui:Dvere}} |
| {{key:N}} | {{ui:Okno}} |
| {{key:H}} | S {{ui:Dvere}} alebo {{ui:Okno}}: závesy na druhom konci |
| {{key:Shift}} pri kreslení steny | Udrží ju na 0°, 90°, 180° alebo 270° |
| Číslice a znaky stopy a palca (`'` a `"`) | Začne písať dĺžku do poľa {{ui:Dĺžka}}; {{key:Enter}} ju použije |
| {{key:Enter}}, {{key:Esc}}, pravé tlačidlo alebo dvojklik | Ukončí stenu, ktorú kreslíte; ďalší {{key:Esc}} prepne na {{ui:Vybrať}} |
| {{key:Delete}} | Zmaže vybrané steny, dvere a okná; zostávajúce steny sa znova spoja |
| {{key:F}} s ukazovateľom nad pôdorysom | Prispôsobí pôdorys |
| Rolovanie kolieska | Zväčšuje okolo ukazovateľa |
| Potiahnutie stredným alebo pravým tlačidlom, alebo {{key:Space}} a potiahnutie | Posúva; keď je zapnuté {{ui:Vybrať}}, obyčajné potiahnutie tiež posúva |
| Potiahnutie dverí alebo okna pri {{ui:Vybrať}} | Presunie ich pozdĺž steny alebo na inú stenu |
| Dva prsty (dotyk) | Roztiahnutím zväčší; posunutím prstov spolu posúva |

## Umiestňovanie a prilepovanie položiek knižnice

| Klávesa | Čo robí |
|---|---|
| {{key:R}} | Otočí položku o 90° |
| {{key:Tab}} | Prichytávanie ku stene zapnuté a vypnuté: zadná strana položky sa prichytí k najbližšej stene |
| {{key:Enter}} v **X, Y (mm)** | Umiestni položku na napísanú pozíciu |
| {{key:Esc}} | Zastaví umiestňovanie alebo prilepovanie |

## Úprava hodnôt IFC

| Klávesa | Čo robí |
|---|---|
| {{key:Enter}} | Ponechá hodnotu, ktorú ste napísali |
| {{key:Esc}} | Zruší zmenu a vráti pôvodnú hodnotu |
| Kliknutie inde | Ponechá hodnotu, ktorú ste napísali |
| {{key:Mod+Z}} | Späť posledná zmena. Iba keď máte neuložené zmeny a nepíšete do poľa |
| {{key:Mod+Y}} | Znova to, čo krok Späť vzal späť |
| {{key:Mod+S}} | Uloží ako IFC. Iba keď máte neuložené zmeny; inak sa otvorí príkaz uloženia prehliadača |

Na úpravu iba z klávesnice: stláčajte {{key:Tab}}, kým nie je zvýraznená hodnota, potom stlačte {{key:Enter}}, aby ste začali písať.

## 2D výkresy (DWG a DXF)

| Klávesa alebo akcia | Čo robí |
|---|---|
| {{key:F}} | Prispôsobí výkres alebo list |
| {{key:P}} | Zobrazenie tlače zapnuté a vypnuté |
| Dvojklik | Prispôsobí |
| Potiahnutie ktorýmkoľvek tlačidlom | Posúva |
| Rolovanie kolieska | Zväčšuje pri ukazovateli |
| Rolovanie dvoma prstami alebo roztiahnutie na touchpade | Zväčšuje pri ukazovateli. Rolovanie dvoma prstami nevykonáva posun |
| Jeden prst (dotyk) | Posúva. Zväčšenie roztiahnutím pre výkresy ešte nie je hotové |

## Výkresy v 3D

| Klávesa alebo akcia | Čo robí |
|---|---|
| {{key:3}} | 3D zapnuté a vypnuté (aj v 2D pohľade) |
| {{key:F}} | Rozsah: celý výkres |
| Potiahnutie stredným alebo ľavým tlačidlom | Obieha |
| Potiahnutie pravým tlačidlom alebo {{key:Shift}} a potiahnutie | Posúva |
| Rolovanie kolieska | Zväčšuje smerom k tomu, čo je pod ukazovateľom |
| Potiahnutie dvoma prstami na touchpade | Obieha; s {{key:Shift}} posúva |
| Roztiahnutie na touchpade | Zväčšuje |
| Jeden prst (dotyk) | Obieha |
| Dva prsty (dotyk) | Roztiahnutím zväčší; posunutím prstov spolu posúva |

{{key:F}}, {{key:P}} a {{key:3}} nič nerobia, keď píšete do poľa, keď je zobrazená tabuľka vybavenia, alebo keď podržíte {{key:Mod}} alebo {{key:Alt}}.
