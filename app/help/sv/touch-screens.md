BimCraft fungerar med fingrar såväl som med en mus. Första gången du rör skärmen växer knappar, flikar och listrader till fingerstorlek.

## 3D-modellen

| För att | Gör så här |
|---|---|
| Kretsa | Dra med ett finger |
| Zooma | Nyp med två fingrar isär eller ihop |
| Panorera | Dra med två fingrar tillsammans |
| Markera ett element | Tryck på det |
| Lägg till ett element i markeringen, eller ta bort det | Tryck och håll på det i en halv sekund (samma som {{key:Ctrl}}+klick) |
| Markera inget | Tryck på tomt utrymme |

Ett nyp eller en tvåfingerdrag markerar aldrig något, även när ett finger lyfter över ett element.

## Ritningar (DWG och DXF)

| För att | Gör så här |
|---|---|
| Panorera | Dra med ett finger |
| Zooma | Nyp; punkten mellan fingrarna står kvar |
| Visa hela bladet | Dubbeltryck, eller tryck på {{ui:Anpassa}} |

I ritningens {{ui:3D}}-vy gäller modellens gester: ett finger kretsar, två nyper och panorerar, ett tryck markerar, ett långt tryck lägger till i markeringen.

## Gå

Tryck på {{ui:Vandra}}, tryck sedan på golvet där du vill stå. En rad pilknappar visas i gångfältet:

- Håll en pil för att gå framåt, bakåt eller ett steg åt sidan.
- Med {{ui:Tyngdkraft}} av stiger och sjunker de dubbla pilarna.
- Dra med ett finger på modellen för att titta runt.
- Tryck på {{ui:Klar}} för att sluta.

## Placera biblioteksobjekt

Tryck där objektet ska stå. {{ui:Vrid 90°}} på placeringsfältet vrider det ({{key:R}}-tangenten på ett tangentbord), {{ui:Väggfångst}} fäster dess baksida mot närmaste vägg, och {{ui:Sluta placera}} avslutar.

## Mät

Tryck på första punkten, sedan på andra. Punkter fångas mot hörn och kanter nära din tryckning.

:::tip
Med ett tangentbord kopplat till en surfplatta fungerar varje kortkommando som på en dator. Se [Kortkommandon](topic:keyboard).
:::
