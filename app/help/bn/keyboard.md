BimCraft-এ শর্টকাট খুব কম। বেশিরভাগ কাজ মাউস ও প্যানেল দিয়ে করা হয়। {{key:Mod}} দিয়ে লেখা শর্টকাটগুলো Mac-এ Command ব্যবহার করে, এবং অন্য সব জায়গায় Ctrl। এই সহায়িকায় কী কীভাবে লেখা হয় তা দেখতে [কী, মাউস ও ট্র্যাকপ্যাড](common:keys) দেখুন।

## সব জায়গায়

| কী | যা করে |
|---|---|
| {{key:Ctrl+Shift+F}} | স্ক্রিন মোড ঘোরান: স্বাভাবিক, পূর্ণ স্ক্রিন, বা বার লুকানো পূর্ণ স্ক্রিন। Ctrl সব প্ল্যাটফর্মে, Mac-সহ |
| {{key:Esc}} | পূর্ণ স্ক্রিন থেকে বের হন |
| {{key:Mod+,}} | {{ui:সেটিংস}} খুলুন। দেখুন [BimCraft সেটিংস](topic:settings) |
| {{key:Tab}} | বোতাম, চেকবক্স ও মানের মধ্যে যান। প্রতিটি নিয়ন্ত্রণ কীবোর্ড দিয়ে পৌঁছানো যায় |

## 3D ভিউ (IFC মডেল)

| কী বা অ্যাকশন | যা করে |
|---|---|
| {{key:F}} | পুরো মডেল ফিট করুন, তিন-চতুর্থাংশ ভিউ ({{ui:ফিট}}-এর মতোই) |
| {{key:Esc}} | নির্বাচন মুছুন, বা স্থাপন বা পেস্ট বন্ধ করুন |
| ক্লিক | পয়েন্টারের নিচের এলিমেন্ট বেছে নিন; খালি ব্যাকগ্রাউন্ডে ক্লিক করলে নির্বাচন মুছে যায় |
| {{key:Mod}}+ক্লিক বা {{key:Shift}}+ক্লিক | নির্বাচনে একটি এলিমেন্ট যোগ করুন, বা তা বাদ দিন |
| {{key:H}} | বেছে নেওয়া এলিমেন্ট লুকান। দেখুন [এলিমেন্ট লুকানো, আলাদা করা ও স্বচ্ছ করে দেখা](topic:hide-and-isolate) |
| {{key:I}} | শুধু বেছে নেওয়া এলিমেন্ট দেখান (আলাদা করা) |
| {{key:T}} | বেছে নেওয়া এলিমেন্ট দেখান, বাকি সব স্বচ্ছ |
| {{key:Shift+H}} | প্রতিটি এলিমেন্ট আবার দেখান |
| {{ui:হাঁটা}} | তারপর {{key:W}} {{key:A}} {{key:S}} {{key:D}} বা তীর কী দিয়ে হাঁটুন, {{key:Shift}} দৌড়ায়, টেনে চারদিকে তাকান, {{key:Esc}} থামায়। দেখুন [মডেলের মধ্য দিয়ে হাঁটা](topic:walk) |
| {{key:M}} | দূরত্ব ও ফেসের ক্ষেত্রফল মাপুন। দেখুন [3D-তে দূরত্ব, ফেসের ক্ষেত্রফল ও অবস্থান মাপা](topic:measure) |
| বাঁ বোতাম টেনে ধরুন | ঘোরান |
| ডান বোতাম টেনে ধরুন | প্যান |
| {{key:Shift}} বা {{key:Mod}} ধরে বাঁ বোতাম টেনে ধরুন | প্যান (ট্র্যাকপ্যাডে সুবিধাজনক) |
| মাউস হুইল ঘোরান, বা মধ্য বোতাম টেনে ধরুন | জুম |
| ট্র্যাকপ্যাডে দুই আঙুল স্ক্রল বা পিঞ্চ | জুম |
| এক আঙুল (টাচ) | ঘোরান; ট্যাপ করলে বেছে নেওয়া হয় |
| দুই আঙুল (টাচ) | পিঞ্চ করে জুম, একসঙ্গে সরালে প্যান |

| {{key:X}} | সেকশন প্লেন চালু ও বন্ধ। দেখুন [সেকশন প্লেন দিয়ে একটি IFC মডেল কাটা](topic:section-plane) |
| {{key:Shift+X}} | বেছে নেওয়া এলিমেন্টের চারপাশে সেকশন বক্স, সেটিংসে সেট করা রুমসহ |

{{ui:ওপর}}, {{ui:সামনে}} ও {{ui:পাশ}}-এর জন্য কোনো কী নেই; বোতাম ব্যবহার করুন।

## সম্পাদনা

একই কমান্ডগুলো টুলবারে আছে: {{ui:পূর্বাবস্থায় ফিরুন}}, {{ui:আবার করুন}}, {{ui:কপি করুন}}, {{ui:পেস্ট করুন}} এবং {{ui:আরও}} মেনু, যেখানে প্রতিটি কী দেখানো হয়। এগুলো IFC মডেলের 3D ভিউতে কাজ করে, কোনো ঘরে লেখার সময় নয়। দেখুন [লাইব্রেরি আইটেম কপি, পেস্ট ও ডুপ্লিকেট করা](topic:copy-paste)।

| কী | যা করে |
|---|---|
| {{key:Mod+Z}} | শেষ পরিবর্তন পূর্বাবস্থায় ফেরান |
| {{key:Mod+Y}} বা {{key:Mod+Shift+Z}} | পূর্বাবস্থায় ফেরানো যা নিয়েছিল তা আবার করুন |
| {{key:Mod+C}} | বেছে নেওয়া এলিমেন্ট কপি করুন (তাদের নাম ও প্রপার্টি টেক্সট হিসেবেও ক্লিপবোর্ডে যায়) |
| {{key:Mod+X}} | বেছে নেওয়া এলিমেন্ট কাটুন: কপি করে তারপর মুছে ফেলুন |
| {{key:Mod+V}} | যা কপি করেছেন তা পেস্ট করুন: এটি পয়েন্টারের সঙ্গে চলে, যেখানে যাবে সেখানে ক্লিক করুন |
| {{key:Mod+Shift+V}} | একই জায়গায় পেস্ট করুন: কাটার জায়গায়, বা কপির পর মূলের পাশে |
| {{key:Mod+D}} | ডুপ্লিকেট: বেছে নেওয়া এলিমেন্ট কপি করুন এবং পেস্ট শুরু করুন |
| {{key:Delete}} | বেছে নেওয়া এলিমেন্ট মুছুন, তাদের অংশ ও ফাঁকসহ। দেখুন [বিল্ডিং এলিমেন্ট মোছা, কাটা, কপি ও পেস্ট করা](topic:edit-elements) |
| {{key:Mod+A}} | দেখানো প্রতিটি এলিমেন্ট বেছে নিন |
| {{key:Esc}} | কিছুই বেছে নেবেন না |

পৃষ্ঠায় লেখা নির্বাচিত থাকলে, {{key:Mod+C}} সেই লেখা স্বাভাবিকভাবে কপি করে।

## প্ল্যান ভিউ (আঁকা)

এগুলো তখন কাজ করে যখন {{ui:আঁকা}} চালু থাকে এবং আপনি কোনো ঘরে লিখছেন না। দেখুন [দেয়াল আঁকা](topic:draw-walls) এবং [দরজা ও জানালা](topic:doors-and-windows)।

| কী বা অ্যাকশন | যা করে |
|---|---|
| {{key:V}} | {{ui:নির্বাচন}} |
| {{key:W}} | {{ui:দেয়াল}} |
| {{key:D}} | {{ui:দরজা}} |
| {{key:N}} | {{ui:জানালা}} |
| {{key:H}} | {{ui:দরজা}} বা {{ui:জানালা}}-এর সঙ্গে: কব্জা অন্য প্রান্তে |
| দেয়াল আঁকার সময় {{key:Shift}} | তা 0°, 90°, 180° বা 270°-এ রাখে |
| সংখ্যা এবং ফুট ও ইঞ্চি চিহ্ন (`'` ও `"`) | {{ui:দৈর্ঘ্য}} বক্সে দৈর্ঘ্য লেখা শুরু করুন; {{key:Enter}} সেটি ব্যবহার করে |
| {{key:Enter}}, {{key:Esc}}, ডান-ক্লিক বা ডাবল-ক্লিক | যে দেয়াল আঁকছেন তা শেষ করুন; {{key:Esc}} আবার চাপলে {{ui:নির্বাচন}}-এ ফেরত যান |
| {{key:Delete}} | বেছে নেওয়া দেয়াল, দরজা ও জানালা মুছুন; বাকি দেয়ালগুলো আবার জোড়া লাগে |
| প্ল্যানের ওপর পয়েন্টার থাকা অবস্থায় {{key:F}} | প্ল্যান ফিট করুন |
| মাউস হুইল ঘোরান | পয়েন্টারের চারপাশে জুম |
| মধ্য বা ডান বোতাম টেনে ধরুন, বা {{key:Space}} ধরে টেনে ধরুন | প্যান; {{ui:নির্বাচন}} চালু থাকলে সাধারণ টেনে ধরাও প্যান করে |
| {{ui:নির্বাচন}} দিয়ে দরজা বা জানালা টেনে ধরুন | তাদের দেয়াল বরাবর সরান, বা অন্য দেয়ালে নিন |
| দুই আঙুল (টাচ) | পিঞ্চ করে জুম, একসঙ্গে সরালে প্যান |

## লাইব্রেরি আইটেম স্থাপন ও পেস্ট

| কী | যা করে |
|---|---|
| {{key:R}} | আইটেমটি 90° ঘোরান |
| {{key:Tab}} | দেয়াল স্ন্যাপ চালু ও বন্ধ: আইটেমের পেছন নিকটতম দেয়ালে লাগে |
| **X, Y (mm)**-এ {{key:Enter}} | লেখা অবস্থানে স্থাপন করুন |
| {{key:Esc}} | স্থাপন বা পেস্ট বন্ধ করুন |

## IFC মান সম্পাদনা

| কী | যা করে |
|---|---|
| {{key:Enter}} | আপনার লেখা মান রাখুন |
| {{key:Esc}} | বাতিল করুন ও পুরোনো মান ফিরিয়ে দিন |
| অন্য কোথাও ক্লিক | আপনার লেখা মান রাখুন |
| {{key:Mod+Z}} | শেষ পরিবর্তন পূর্বাবস্থায় ফেরান। শুধু যখন অসংরক্ষিত পরিবর্তন আছে এবং আপনি ঘরে লিখছেন না |
| {{key:Mod+Y}} | পূর্বাবস্থায় ফেরানো যা নিয়েছিল তা আবার করুন |
| {{key:Mod+S}} | IFC হিসেবে সংরক্ষণ। শুধু অসংরক্ষিত পরিবর্তন থাকলে; নয়তো ব্রাউজারের নিজস্ব সংরক্ষণ কমান্ড খোলে |

শুধু কীবোর্ড দিয়ে সম্পাদনা করতে: একটি মান হাইলাইট না হওয়া পর্যন্ত {{key:Tab}} চাপুন, তারপর লেখা শুরু করতে {{key:Enter}} চাপুন।

## 2D ড্রয়িং (DWG ও DXF)

| কী বা অ্যাকশন | যা করে |

## 3D-তে ড্রয়িং

| কী বা অ্যাকশন | যা করে |
|---|---|
| {{key:3}} | 3D চালু ও বন্ধ (2D ভিউতেও) |
| {{key:F}} | পুরো ড্রয়িং দেখুন |
| মধ্য বা বাঁ বোতাম টেনে ধরুন | ঘোরান |
| ডান বোতাম টেনে ধরুন, বা {{key:Shift}} ধরে টেনে ধরুন | প্যান |
| মাউস হুইল ঘোরান | পয়েন্টারের নিচের দিকে জুম |
| ট্র্যাকপ্যাডে দুই আঙুল সোয়াইপ | ঘোরান; {{key:Shift}} সহ, প্যান |
| ট্র্যাকপ্যাডে পিঞ্চ | জুম |
| এক আঙুল (টাচ) | ঘোরান |
| দুই আঙুল (টাচ) | পিঞ্চ করে জুম, একসঙ্গে সরালে প্যান |

{{key:F}}, {{key:P}} ও {{key:3}} কোনো কাজ করে না যখন আপনি ঘরে লিখছেন, যখন সরঞ্জামের শিডিউল দেখানো হচ্ছে, বা যখন {{key:Mod}} বা {{key:Alt}} ধরে রাখেন।
