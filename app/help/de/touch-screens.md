BimCraft funktioniert mit den Fingern ebenso wie mit der Maus. Beim ersten Berühren des Bildschirms werden Schaltflächen, Registerkarten und Listenzeilen fingergerecht vergrößert.

## Das 3D-Modell

| Ziel | So geht es |
|---|---|
| Orbit | Mit einem Finger ziehen |
| Zoomen | Zwei Finger auseinander oder zusammenziehen |
| Verschieben | Zwei Finger zusammen ziehen |
| Ein Element wählen | Es antippen |
| Ein Element zur Auswahl hinzufügen oder daraus entfernen | Es für eine halbe Sekunde gedrückt halten (wie {{key:Ctrl}}+Klick) |
| Nichts wählen | Auf eine leere Stelle tippen |

Ein Zusammenziehen oder Ziehen mit zwei Fingern wählt nie etwas aus, auch wenn ein Finger über einem Element angehoben wird.

## Zeichnungen (DWG und DXF)

| Ziel | So geht es |
|---|---|
| Verschieben | Mit einem Finger ziehen |
| Zoomen | Zusammenziehen; der Punkt zwischen Ihren Fingern bleibt stehen |
| Das ganze Blatt zeigen | Doppeltippen oder auf {{ui:Einpassen}} tippen |

In der Ansicht {{ui:3D}} einer Zeichnung gelten die Gesten des Modells: Ein Finger kreist um das Modell, zwei Finger zoomen und verschieben, ein Tippen wählt, ein langes Drücken fügt zur Auswahl hinzu.

## Rundgang

Tippen Sie auf {{ui:Rundgang}} und dann auf den Boden, auf dem Sie stehen möchten. In der Rundgangsleiste erscheint eine Reihe von Pfeiltasten:

- Halten Sie einen Pfeil gedrückt, um vorwärts, rückwärts oder seitlich zu gehen.
- Bei ausgeschalteter {{ui:Schwerkraft}} heben und senken sich die Doppelpfeile.
- Ziehen Sie mit einem Finger über das Modell, um sich umzusehen.
- Tippen Sie auf {{ui:Fertig}}, um zu beenden.

## Bibliothekselemente platzieren

Tippen Sie an die Stelle, an die das Element soll. {{ui:90° drehen}} in der Platzierungsleiste dreht es (entspricht der Taste {{key:R}} auf einer Tastatur), {{ui:Wandfang}} rastet seine Rückseite an der nächsten Wand ein, und {{ui:Platzieren beenden}} beendet den Vorgang.

## Messen

Tippen Sie auf den ersten Punkt und dann auf den zweiten. Punkte rasten an Ecken und Kanten in der Nähe Ihres Tippens ein.

:::tip
Mit einer an ein Tablet angeschlossenen Tastatur funktioniert jede Tastenkombination wie an einem Computer. Siehe [Tastenkürzel](topic:keyboard).
:::
