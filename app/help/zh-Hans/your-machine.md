打开{{ui:设置}}（{{key:Mod+,}}），停留在本应用自己的选项卡上，并滚动到{{ui:渲染}}。{{ui:本机}}列出此浏览器允许应用用于渲染的内容。其中的任何信息都不会离开你的计算机。

| 行 | 含义 |
|---|---|
| {{ui:图形}} | 浏览器报告的显卡。“WebGPU”表示它可以执行渲染工作；“仅 WebGL 2”表示没有 WebGPU：实时视图和高质量图片通过 WebGL 2 使用显卡（使用较旧 WebGL 路径追踪器生成的图片，不含需要 WebGPU 的附加功能）；软件替代表示一切都在处理器上运行 |
| {{ui:处理器}} | 浏览器报告的处理器内核数 |
| {{ui:内存}} | 计算机大约拥有的内存量（当浏览器报告时）。有些浏览器不报告 |
| {{ui:共享内存}} | 页面是否可以在其工作线程之间共享内存。开启时，每个内核都可以处理同一份场景副本；关闭时，每个内核都需要自己的副本，因此大型场景能同时在较少的内核上运行 |
| {{ui:快速处理器代码}} | 浏览器是否运行更快的 WebAssembly 代码。若无此项，则使用较慢的备用代码 |
| {{ui:楼层}} | {{ui:显卡，高}}、{{ui:显卡，基础}}或{{ui:仅处理器}}，其下附有原因 |

## 渲染级别

级别决定渲染从何处开始，使带有内置显卡芯片或完全没有显卡的笔记本电脑依然保持流畅。内置显卡芯片或手机显卡芯片，或 4 GB 或更少内存的设备，永远不会获得{{ui:显卡，高}}。

:::note
各浏览器有所不同。同一台计算机在一个浏览器中可能显示 WebGPU，在另一个浏览器中则显示“仅 WebGL 2”。在 Linux 上，大多数浏览器尚不支持 WebGPU。
:::
