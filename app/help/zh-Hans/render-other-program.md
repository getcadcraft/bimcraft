{{ui:Render}} 中的图像由**我们自带的引擎**绘制：快速和路径追踪器，在浏览器和 CadCraft Studio 中均可使用。只有当**渲染引擎插件**提供时，其他程序才能绘制图像：见 [用插件添加渲染引擎](topic:render-engine-addons)。若要将场景交给其他程序并在那里继续工作，请使用 [在另一程序中打开场景](topic:render-open-in) 或 [将场景发送到游戏引擎](topic:render-unreal)。

## 用插件引擎绘制图像

1. 在 设置 › 插件 中启用该插件。其引擎会出现在 {{ui:Render}} 的引擎列表中。
2. 选择它。其自身的设置会显示在引擎列表下方。
3. 点击 {{ui:Render}}。在 Studio 中，插件第一次运行程序时，Studio 会在其自身的对话框中询问你。绘制期间会显示进度；{{ui:Stop}} 可终止绘制。图像出现时会标注绘制它的引擎。

用 JavaScript 编写的引擎也会在浏览器中运行。运行本机程序的引擎仅在 Studio 中运行；在浏览器中则显示为一个可保存的文件。

## 会带过去的内容

引擎获得一个**打包文件**：模型为 USD 文件（若其要求，还有 glTF 文件），以及一个设置文件，其中包含精确的材质数值、太阳和天空、每盏已开启的灯具及其功率和配光文件、相机和曝光。每个程序以自己的方式处理光照、色调和采样，因此图像在相机、太阳、灯具和曝光上相似，但并非逐像素一致。

## CadCraft 从不运行的程序

CadCraft 从不启动 GNU GPL 许可证下的程序，也从不将其列为引擎或“在…中打开”的目标。Blender 就是其中之一，因此不会出现在引擎列表中。从 {{ui:Render}} 保存的 USD 或 glTF 文件仍可在 Blender 中打开，与其他能读取这些文件的程序一样。

:::note
全景和立体相机，以及天空图片（改用天空的颜色）不会带到其他程序中。在其他程序中所做的任何更改都不会返回到模型中。
:::
