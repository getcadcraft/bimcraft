## 操作内容

以三维方式查看图形的模型空间。直线和多段线位于其实际高度，具有厚度的对象会竖立为墙体，三维面、网格和三维块则显示为可围绕旋转的曲面。图纸仍保持二维。

## 步骤

1. 打开 DWG 或 DXF 文件。参见[查看 DWG 或 DXF 图形](topic:view-dwg)。除非{{ui:Settings}} › {{ui:BimCraft}} › **图形打开方式**设为{{ui:Model (2D)}}，否则将以三维方式打开。
2. 在二维视图中，点击图形上方栏中的{{ui:3D}}，或按{{key:3}}。
3. 首次切换需稍候：状态栏会显示“正在三维构建图形…”，随后显示其中显示的线条和面的数量。
4. 进行旋转、平移和缩放（参见下表）。
5. 点击第二栏中的某个视图：{{ui:Iso}}、{{ui:Top}}、{{ui:Bottom}}、{{ui:Front}}、{{ui:Back}}、{{ui:Left}}或{{ui:Right}}。
6. 点击{{ui:Perspective}}，可在透视视图与平行视图之间切换。
7. 点击{{ui:Extents}}或按{{key:F}}，可再次查看整个图形。
8. 再次点击{{ui:3D}}、按{{key:3}}，或点击{{ui:Model}}或某个图纸标签，即可返回二维视图。

## 应看到的内容

- 三维模型空间，Z 轴朝上，使用图形自身的颜色。面比其边线略亮。
- 在{{ui:Layers}}中关闭的图层，在三维视图中也会隐藏。
- 右侧显示：线条和面的数量、图形在 X、Y 和 Z 方向的尺寸，以及**仅二维视图中显示**和**尚未绘制**。

## 使用剖切面剖切

点击三维栏上的{{ui:Section}}，或按{{key:X}}。其下方的栏与 IFC 模型的操作方式相同（参见[使用剖切面剖切 IFC 模型](topic:section-plane)）：从{{ui:Top}}、{{ui:Front}}或{{ui:Side}}方向剖切，拖动或输入偏移量（此处以图形自身的单位为准），并使用{{ui:Flip}}保留另一侧。被剖切面切除的部分无法被拾取。返回二维视图时，剖切即被取消。

## 查看对象特性

在三维视图中点击某个对象。该对象会变为拾取颜色，{{ui:Properties}}会显示文件中关于它的信息：其类型、图层、颜色、线型和句柄，随后是其自身的数据，例如直线的起点、终点和长度，圆的圆心和半径，三维面的角点，或块参照的块、插入点、比例、旋转及属性值。

- 块参照作为整体被拾取，其中嵌套的块也一并被拾取。
- 点击距直线几个像素范围内的位置，即可拾取该直线。
- 按住{{key:Mod}}并点击，可拾取更多对象，或取消拾取其中某个对象；此时{{ui:Properties}}会按类型统计数量。
- 按{{key:Esc}}，或点击空白处，即可清除拾取。
- 位于已关闭图层上的对象无法被拾取。

## 移动视图

:::mouse
| 目的 | 操作 |
|---|---|
| 旋转 | 按住中键拖动，或按住左键拖动 |
| 平移 | 按住右键拖动，或按住{{key:Shift}}并拖动 |
| 缩放 | 滚动滚轮；缩放以指针下方的位置为中心 |
| 查看全部 | {{ui:Extents}}或{{key:F}} |
| 从某一侧查看 | 点击右下角视图立方体的某个面、边或角 |
:::

在{{ui:Settings}}中，可将视图立方体替换为坐标轴图标，或将其隐藏。参见[BimCraft 设置](topic:settings)。

:::mac mouse
在触控板上，用两指滑动可旋转，按住{{key:Shift}}并滑动可平移，捏合可缩放。
:::

:::touch
用一根手指拖动可旋转。用两根手指捏合可缩放，两指同时移动可平移。
:::

## 三维中的绘制内容

| 图形中 | 三维中 |
|---|---|
| 直线、三维多段线 | 位于其实际高度 |
| 多段线、圆、圆弧、椭圆 | 位于其所在平面和标高处；图形倾斜时随之倾斜 |
| 直线、多段线、圆和圆弧上的厚度 | 该高度的墙体；圆的顶部和底部封闭 |
| 三维面、多面网格、多边形网格 | 带有可见边线的着色曲面 |
| 块 | 在三维中放置、旋转和缩放，嵌套块同样适用 |
| 填充 | 其轮廓 |
| 普通二维线条 | 保持平面，位于其绘制位置 |

## 仅二维视图中显示

文字、多行文字以及块的可见属性会在三维中绘制，位于其自身所在的平面和高度，点击即可拾取。宽多段线以平面带状显示其宽度。多重引线、图像和图案填充计入**仅二维视图中显示**：请在{{ui:Model}}选项卡或图纸中查看。

## 尚未绘制

以 ACIS 实体形式存储的实体和曲面（三维实体、实体、面域和曲面）以及细分网格，会列在**尚未绘制**下并注明数量。这些内容会被跳过，而不会进行推测。

## 常见错误

- **看起来全部是平的。**该图形为二维图形：其线条没有高度。点击{{ui:Front}}进行检查；若为平面图形，则只会显示为一条线。
- **实体模型不显示任何内容。**使用实体建模器创建的实体属于 ACIS 实体，会列在**尚未绘制**下。请从生成该模型的程序中以 IFC 格式或三维面形式导出。
- **图形在中间呈现为一小团。**模型空间中远处的某些内容（例如旧平面图的副本）会使范围变得很大。请在需要查看的位置用滚轮放大。
