## 你将完成的操作

将项目文件转换为可在 BimCraft 中环视、查看、检查和编辑的 IFC 文件。BimCraft 目前尚不能读取 `.rvt` 文件中的三维模型，因此导出须在创建该文件的程序（Revit）中完成；BimCraft 负责打开导出结果。

## 步骤

1. 在创建该项目的程序中打开项目。BimCraft 的卡片会注明其保存时所用的版本。
2. 打开一个三维视图，显示要导出的内容。
3. 选择 **文件 > 导出 > IFC**。
4. 在导出对话框中选择一个设置方案（或点击 **修改设置…**），并应用下述设置。
5. 选择文件夹和文件名，然后导出。
6. 在 BimCraft 中，点击{{ui:选择文件}}，并选择新的 `.ifc` 文件。作为独立文件导出的链接模型，可使用{{ui:添加模型}}并入同一场景中打开。

## 最适合在此打开的设置

| 导出器中的设置 | 选择 | 原因 |
|---|---|---|
| IFC 版本 | 查看、检查和算量时选择 **IFC4 Reference View**；需要他人使用 IFC2X3 时选择 **IFC2X3 Coordination View 2.0** | 两者都能完整打开。**IFC4 Design Transfer View** 也能打开，几何形状更精确，但文件更大，速度更慢。 |
| 文件类型 | **IFC**（普通） | BimCraft 不能打开 `.ifczip` 或 `.ifcxml`。 |
| 阶段 / 可见元素 | 所需的阶段，以及在为其设置三维视图时选择 **仅导出视图中可见的元素** | 排除有意隐藏的内容。 |
| 属性集 | **导出 Revit 属性集** 和 **导出 IFC 通用属性集** | 它们会成为 BimCraft 在{{ui:特性}}中显示的属性集，并被{{ui:查找}}、{{ui:颜色}}和{{ui:模型检查}}使用。 |
| 基础量 | **导出基础量** | {{ui:工程量汇总}}和明细表会使用它们（长度、面积、体积），而不是估算。 |
| 房间与区域 | **在三维视图中导出房间**（或房间 / 空间选项） | 房间以空间形式导入：点击{{ui:空间}}即可查看。 |
| 链接文件 | **将链接文件导出为独立 IFC** | 每个链接成为一个独立文件；用{{ui:添加模型}}将它们一起打开后，会互相对齐。 |
| 坐标基准 | **共享坐标**（或测量点） | 这样文件会携带其在地图上的位置（IfcMapConversion），因此测量 › 位置、地面上的地图图层以及按地图坐标放置的点云均可使用。项目基点可使模型靠近原点，但不包含其地图位置。 |
| 按楼层拆分墙和柱 | 开启，按楼层计算工程量时 | 每层的部分都成为独立构件。 |

## 你应看到的内容

三维模型，楼层取自项目的标高，项目信息显示在{{ui:文件}}面板中。**导出自** 标明导出程序。

## 导出保留与不保留的内容

- **保留**：几何、楼层、构件类型、名称、类型、大部分参数（以属性集形式）、需要时的基础量、作为空间保留的房间，以及使用共享坐标时的地图位置。
- **不保留**：视图、图纸、注释、可编辑族形式的族、工作集和设计选项。IFC 文件是模型构件的快照，而非项目本身。图纸请导出为 DWG，然后在二维视图中打开。

## 常见错误

- **BimCraft 中缺少参数。** 开启上述属性集选项后重新导出。
- **缺少房间。** 开启房间选项，然后点击{{ui:空间}}。
- **保存为 `.ifczip`。** 选择普通 IFC，或将 `.ifczip` 解压。
- **没有地图位置。** 使用共享坐标导出；请确认已设置项目的测量点。
- **期望编辑回写。** 在 BimCraft 中保存的编辑会写入新的 IFC 文件，而不会写回项目文件。
