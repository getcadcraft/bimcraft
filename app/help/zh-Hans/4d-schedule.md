## 操作目标

观看建筑逐步建成：把进度表中的每项任务与其所建的构件关联起来，并按天显示。

## 步骤

1. 打开 IFC 模型，并在左侧面板中打开 {{ui:4D进度表}}。
2. 点击 {{ui:下载模板}}，获取每个楼层一周的任务清单，然后在电子表格中修改。也可以自行编写。
3. 点击 {{ui:打开任务清单…}}，选择 CSV 文件。
4. 拖动日期滑块，或点击 {{ui:播放}}。

## 任务清单

包含标题行的 CSV 文件，列为 **Task**、**Start**、**Finish**、**Field** 和 **Value**。逗号或分号均可。

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| Level 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| Roof | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| Roof | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- 日期写作 YYYY-MM-DD。
- 每一行会把任务关联到 **Field** 的 **Value** 与之完全相同的所有构件。字段可以是 Storey、Class、Name、Type、Material、Tag 或 GlobalId 等属性，也可以是带属性集和名称的属性，例如 `Pset_WallCommon.FireRating`。
- 同一任务可在多行中重复出现，日期保持一致，以关联更多构件。

## 阶段与工作包

添加 **Stage** 列、**Package** 列或两者，即可把任务归入阶段和工作包。**Phase** 和 **WBS** 也可以作为列名使用。

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| Level 1 slab | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| Level 1 walls | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| Doors | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- 每项任务只属于一个阶段和一个工作包。如果同一任务的后续行指定了另一个阶段或工作包，该行会连同行号一起列出并被忽略。
- 两个阶段中同名的工作包是两个不同的工作包。

清单中有分组时，日期上方会出现 {{ui:显示}} 列表。选择某个阶段或工作包后，即可作为一个整体播放：

- 滑块和 {{ui:播放}} 从该分组的最早开始日期运行到最晚完成日期，
- 仅列出并着色该分组的任务，分组之外的内容均为透明，
- 列表下方的文字说明该日期有多少任务已完成、正在施工和尚未开始，
- {{ui:选择其构件}} 会选中该分组的所有构件，以便用于 {{ui:显示}}、{{ui:剖切}} 或明细表。

选择 **所有任务**，即可再次查看整个进度表。

## 应看到的效果

- **已建成**：所有任务均已完成的构件，以其自身颜色显示。
- **施工中**：当天有任务正在进行的构件，以赭色显示。任务从开始日期到完成日期均属于施工中。
- **未开始**：透明显示。
- 不属于任何任务的构件保持原样。列表会显示每项任务找到的构件数量。无法读取或未找到任何构件的行会连同行号一起列出。

## 关联、甘特图与 MS Project

- 可以打开 Microsoft Project XML 文件（`.xml`），或包含 `Predecessors` 列的 CSV。链接可以是完成到开始、开始到开始、完成到完成或开始到完成，并可设置以天为单位的提前量或滞后量。
- 任务清单下方的甘特图以条形显示每项任务，并用箭头显示链接。关键路径上的任务显示为红色。面板中会列出链接循环或不存在的前置任务。
- {{ui:另存为 MS Project XML}} 和 {{ui:保存带链接的 CSV}} 会把带链接的进度表写回文件。
