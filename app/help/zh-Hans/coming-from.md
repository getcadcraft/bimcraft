如果熟悉 Revit，BimCraft 的大部分内容在文字上会感觉熟悉，但在功能范围上会感到陌生。最重要的一点区别：**此版本用于读取和检查模型，并编辑 IFC 数据，尚不能像 Revit 那样建模。** 无法绘制墙体、放置族、创建视图或图纸，也无法保存项目文件。可以做的是：在任何带浏览器的电脑上打开几乎任何建筑文件，查看其中的内容，检查整个项目文件夹，并修正 IFC 模型中的数据。

## 对应习惯

| 习惯的做法 | 在 BimCraft 中 |
|---|---|
| 在 Revit 中打开 `.rvt` 以查看模型 | BimCraft 会将 `.rvt` 显示为文件卡片：版本、项目信息、链接、预览。若要查看三维模型，请导出 IFC 并打开它。[阅读项目或族文件](topic:read-rvt-file) |
| 打开文件前检查其保存的版本 | 卡片顶部会显示“保存于 Revit …”，且不会升级或改动文件 |
| 项目浏览器 | 没有视图和图纸的浏览器。IFC 模型有{{ui:楼层}}和{{ui:构件}}列表；图形则有布局标签页。 |
| 特性面板 | 右侧的{{ui:特性}}面板，针对所点击的构件。使用 IFC 属性集，而非参数组。 |
| 实例参数和类型参数 | 实例属性集，以及标记为“（类型）”的属性集。修改类型属性会应用于该类型的所有构件，与 Revit 一致。[为某类型的所有构件更改类型属性](topic:type-vs-instance) |
| 编辑类型 | 没有对话框：点击标有“（类型）”的属性集中的值并输入即可 |
| 选择多个构件、过滤器、选择所有实例 | 一次只能选择一个构件。尚未实现。 |
| 视图立方体和导航盘 | 右下角的视图立方体、四个按钮（{{ui:适合}}、{{ui:顶}}、{{ui:前}}、{{ui:侧视}}）以及自由环绕。没有导航盘。 |
| 按 Shift 并中键拖动以环绕，中键拖动以平移 | 左键拖动环绕，右键拖动（或按住{{key:Shift}}并拖动）平移，滚轮缩放。{{ui:BIM功能区}}菜单样式会切换为中键拖动平移，以及按住{{key:Shift}}并用中键环绕。[菜单、按键与鼠标](topic:menus-keys-and-mouse) |
| 平面图、剖面图、剖面框 | 一次只有一个{{ui:剖切}}剖切面（{{key:X}}）；没有剖面框或二维平面图。[使用剖切面剖切 IFC 模型](topic:section-plane) |
| 视图中隐藏、隔离、可见性/图形替代 | {{ui:楼层}}的开与关、{{ui:空间}}和{{ui:边线}}。尚不支持按单个构件隐藏。 |
| 房间 | IFC 空间，初始为隐藏。点击{{ui:空间}}。 |
| 保存、另存为、与中心文件同步 | {{ui:另存为IFC}}会下载新的 IFC 文件。原文件从不改动。没有中心文件，也没有工作共享。 |
| 使用{{key:Mod+Z}}撤销 | 在保存之前，可用于 IFC 编辑的撤销。[更改 IFC 属性并保存编辑后的副本](topic:edit-ifc-properties) |
| 管理链接 | 打开项目文件夹：每个链接都会被检查，并标记为**位于此文件夹中**、**找到同名文件**、**库文件**或**不在此文件夹中**。[打开整个项目文件夹](topic:open-project-folder) |
| 审核，或打开文件以查看是否损坏 | 文件夹报告会在几秒内检查每个副本和备份是否被截断。[检查文件夹中是否有损坏的副本](topic:check-folder-health) |
| 从杂乱的文件夹中选出正确的文件 | {{ui:从这里开始}}框会根据理由推荐一个文件。 |

若主要用于打开模型进行检查（如模型检查或 IFC 查看程序），请选择{{ui:查看器}}菜单样式：查看与检查工具排在最前，建模工具收纳在一个菜单中。参见[菜单、按键与鼠标](topic:menus-keys-and-mouse)。

## 从查看 DWG 文件转来

如果在 AutoCAD 或 DWG 查看器中打开 DWG：

| 习惯的做法 | 在 BimCraft 中 |
|---|---|
| 底部的模型和布局标签页 | 图形上方的标签页：{{ui:模型}}以及每个布局各一个 |
| ZOOM 范围缩放，双击滚轮 | 双击、{{key:F}}或{{ui:适合}} |
| 用中键平移 | 用任意按键拖动 |
| 图层管理器 | {{ui:图层}}列表：勾选以显示，取消勾选以隐藏，{{ui:全部打开}}和{{ui:全部关闭}} |
| 外部参照管理器 | 右侧的**链接图形**，显示**已显示**或**未找到**，以及{{ui:添加外部参照图形…}} |
| 打印预览 | {{ui:打印视图}}或{{key:P}}：白底黑线并显示线宽。不会打印。 |
| 块属性数据提取 | 用于带标记的餐饮图纸的{{ui:设备}}选项卡，并带{{ui:下载CSV}} |
| 测量、绘制、编辑、另存为 | BimCraft 中没有。CadCraft 绘图应用负责绘制和编辑。 |

## 容易出错的差异

- **它在浏览器中运行，浏览器会谨慎处理文件。** BimCraft 只能读取用户通过选择或拖入提供的文件和文件夹。它无法自行打开文件，也无法覆盖保存。每次保存都是下载。
- **不会上传任何内容。** 某些浏览器的文件夹对话框中的“上传”一词是浏览器自身的措辞。文件保留在本机上。
- **IFC 是模型格式。** 项目文件以卡片形式打开，因为其三维内容没有公开文档。请将 IFC 视为模型导入 BimCraft 的方式。
- **编辑采用写时复制。** 更改一个构件的值绝不会影响其相邻构件，即使导出程序在它们之间共享了该值。类型属性是有意的例外。
- **没有项目，也没有视图。** BimCraft 一次显示一个文件，关闭标签页后不会保留关于它的任何信息，除了 Chrome 和 Edge 中最近文件夹的名称。
- **Mac 按键。** Revit 的 Windows 快捷键使用 Ctrl，BimCraft 的快捷键则使用{{key:Mod}}：在 Mac 上为 Command。
- **鼠标习惯。** 旋转默认是左键，而非 Shift 加中键，除非选择{{ui:BIM功能区}}菜单样式，或在[菜单、按键与鼠标](topic:menus-keys-and-mouse)中自行设置按键。

参见[BimCraft 尚未实现的功能](topic:not-built-yet)，了解目前可用的替代方法。
