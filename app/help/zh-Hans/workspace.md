BimCraft 的界面顶部是一条横栏，其下有三个区域：左侧的面板、中间的舞台和右侧的{{ui:特性}}面板。每个区域显示的内容取决于你打开了什么：IFC 模型、项目或族文件、图形或文件夹。

## 应用栏

顶部的细长栏属于 CadCraft 网站，而不是 BimCraft 本身。从左到右依次为：

- CadCraft 标志：转到 CadCraft 首页。
- 应用名称和版本菜单。在内部构建中，它显示当前运行的构建，并可切换到已发布的版本。
- {{ui:关于 BimCraft}}：该应用在网站上的页面。
- {{ui:设置}}：BimCraft 自己的设置以及各应用共用的设置。参见 [BimCraft 设置](topic:settings)。
- {{ui:全屏}}：循环切换屏幕模式。参见下面的[屏幕模式](topic:workspace#screen-modes)。
- {{ui:图纸}}和{{ui:模型}}：浅色和深色主题。三维视图和二维图形会跟随你选择的主题。

## 左侧面板

左侧面板始终以**打开文件或文件夹**开头：

- 拖放区域，{{ui:选择文件，或将文件或文件夹拖到此处}}。点击它可选择一个文件，或将文件或文件夹拖放到它上面（或页面上的任何位置）。
- {{ui:打开文件夹}}：选择整个项目文件夹。参见[打开整个项目文件夹](topic:open-project-folder)。
- {{ui:最近的文件夹}}：在 Chrome 和 Edge 中，使用文件夹选择器或通过拖放打开文件夹后出现。点击{{ui:重新打开}}和文件夹名称可再次打开它，点击小 × 则忘记它。

其下会根据情况出现各个部分：

| 部分 | 何时显示 | 内容 |
|---|---|---|
| {{ui:更改}} | 打开了 IFC 模型 | 你尚未保存的编辑，最新的在前，带有{{ui:撤销}}和{{ui:另存为IFC}} |
| {{ui:文件}} | 打开了模型或文件卡片 | 文件的信息：大小、模式或版本、项目、作者、构件数量 |
| {{ui:图形}} | 打开了 DWG 或 DXF | 格式、单位、实体和图层数量、布局、外部参照图形、设备 |
| {{ui:文件夹}} | 打开了文件夹 | 文件和模型数量、大小、发现的问题 |
| {{ui:返回文件夹}} | 你从文件夹中打开了文件 | 返回文件夹报告 |
| {{ui:图层}} | 打开了图形 | 每个图层一个复选框，带有{{ui:全部打开}}和{{ui:全部关闭}} |
| {{ui:楼层}} | 打开了 IFC 模型 | 每个楼层一个复选框，顶层在前 |
| {{ui:构件}} | 打开了 IFC 模型 | 模型中每种构件的数量（最常见的 30 种） |

## 舞台

屏幕中间显示打开的文件。

- **空白**：“打开建筑模型。”，带有{{ui:选择文件}}和{{ui:打开文件夹}}，以及对每种格式的简短说明。
- **IFC 模型**：三维视图，顶部有工具栏，按命名分组，类似 CadCraft 绘图应用，每个工具的图标位于其名称之上：{{ui:视图}}（{{ui:适合}}、{{ui:顶}}、{{ui:前}}、{{ui:侧视}}、{{ui:边线}}、{{ui:空间}}）；{{ui:编辑}}（{{ui:撤销}}、{{ui:重做}}、{{ui:复制}}、{{ui:粘贴}}和{{ui:更多}}，参见[复制、粘贴和创建库项目副本](topic:copy-paste)）；{{ui:模型}}（{{ui:单位}}和{{ui:绘制}}）；{{ui:库}}（{{ui:图库}}、{{ui:设备}}、{{ui:更新}}、{{ui:致谢}}）；{{ui:查看}}（{{ui:显示}}、{{ui:剖切}}、{{ui:漫游}}、{{ui:测量}}；参见[用剖切面剖切 IFC 模型](topic:section-plane)）；以及{{ui:输出}}（渲染、实时视图、VR、导出、上材质和已保存的视图）。{{ui:绘制}}开启时，其下的绘制栏外观相同：{{ui:视图}}（楼层和平面类型）、{{ui:绘制}}、{{ui:编辑}}和{{ui:库}}。视图立方体位于右下角。参见[打开 IFC 模型并在三维中查看](topic:open-ifc-model)。{{ui:设置}}中的{{ui:常规}}可为这些按钮选择图标、标签或两者都显示，显示或隐藏分组名称；在工具栏上点击右键可排列其工具和分组。窗口较矮时，工具栏会去掉图标下方的名称。
- **项目或族文件**：文件卡片，带有预览图片、项目信息和链接文件。参见[读取项目或族文件](topic:read-rvt-file)。
- **DWG 或 DXF**：一排选项卡（{{ui:模型}}，然后每张布局一个，图形含有带标记的设备时再加{{ui:设备}}，然后是{{ui:三维}}、{{ui:适合}}和{{ui:打印视图}}）、图形本身，以及角落里实时显示的 X 和 Y 坐标。参见[查看 DWG 或 DXF 图形](topic:view-dwg)和[在三维中查看 DWG 或 DXF 图形](topic:dwg-in-3d)。
- **文件夹**：文件夹报告，带有{{ui:从这里开始}}框以及模型、链接、IFC 模型和图形的表格。参见[打开整个项目文件夹](topic:open-project-folder)。

舞台底部的**状态行**告诉你 BimCraft 正在做什么（“正在读取模型…”、“正在生成几何：1200 / 5400 个构件”），并在出错时以红色显示出了什么问题。成功的消息几秒钟后消失。

## 特性面板

右侧面板显示：

- IFC 模型：你点击的构件，包括其名称、类型、标签、GlobalId 和每个属性集。可以修改的值看起来像按钮。参见[特性面板字段](topic:properties-panel)。
- 图形：如何浏览，图形的外部参照图形和图像以及是否找到，还有**尚未绘制**的内容列表。
- 文件卡片或文件夹：关于接下来打开什么的简短说明。

## 在小屏幕上

当窗口比笔记本电脑屏幕窄时，BimCraft 会把各区域堆叠起来：舞台在上，面板在下。滚动页面即可到达面板。在手机上它们排成一列；在平板上排成两列。

## 屏幕模式

应用栏中的{{ui:全屏}}按钮，或在所有平台上按{{key:Ctrl+Shift+F}}，可循环切换三种模式：

1. 正常。
2. 全屏，栏仍显示。
3. 全屏且隐藏应用栏。将指针移到顶部边缘，或在那里点按，即可使其重新出现。

按{{key:Esc}}返回正常。不支持全屏的浏览器（例如 iPhone 上的浏览器）只在正常和隐藏栏之间切换。
