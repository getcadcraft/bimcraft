BimCraft的快捷键很少。大多数操作通过鼠标和面板完成。使用{{key:Mod}}的快捷键在Mac上为Command，在其他平台上为Ctrl。按键的书写方式参见[按键、鼠标和触控板](common:keys)。

## 全局

| 按键 | 作用 |
|---|---|
| {{key:Ctrl+Shift+F}} | 循环切换屏幕模式：普通、全屏、隐藏工具栏的全屏。在所有平台（包括Mac）上均使用Ctrl |
| {{key:Esc}} | 退出全屏 |
| {{key:Mod+,}} | 打开{{ui:Settings}}。参见[BimCraft设置](topic:settings) |
| {{key:Tab}} | 在按钮、复选框和数值之间移动。所有控件均可通过键盘访问 |

## 三维视图（IFC模型）

| 按键或操作 | 作用 |
|---|---|
| {{key:F}} | 适合整个模型，三分之二视角（与{{ui:Fit}}相同） |
| {{key:Esc}} | 清除选择，或停止放置或粘贴 |
| 点击 | 选择指针下的构件；点击空白背景可清除选择 |
| {{key:Mod}}+点击或{{key:Shift}}+点击 | 将构件加入选择，或从选择中移除 |
| {{key:H}} | 隐藏所选构件。参见[隐藏、隔离和透视构件](topic:hide-and-isolate) |
| {{key:I}} | 仅显示所选构件（隔离） |
| {{key:T}} | 显示所选构件，其余构件透视显示 |
| {{key:Shift+H}} | 重新显示所有构件 |
| {{ui:Walk}} | 然后用{{key:W}} {{key:A}} {{key:S}} {{key:D}}或方向键漫游，{{key:Shift}}加速，拖动可环视，{{key:Esc}}停止。参见[在模型中漫游](topic:walk) |
| {{key:M}} | 测量距离和面面积。参见[在三维中测量距离、面面积和位置](topic:measure) |
| 左键拖动 | 动态观察 |
| 右键拖动 | 平移 |
| {{key:Shift}}或{{key:Mod}}并左键拖动 | 平移（适用于触控板） |
| 滚动滚轮，或中键拖动 | 缩放 |
| 触控板双指滚动或捏合 | 缩放 |
| 单指（触摸） | 动态观察；轻触可选择 |
| 双指（触摸） | 捏合缩放，并排移动可平移 |

| {{key:X}} | 开关剖切面。参见[用剖切面剖切IFC模型](topic:section-plane) |
| {{key:Shift+X}} | 围绕所选构件的剖切框；剖切框的留空范围在设置中设定 |

没有{{ui:Top}}、{{ui:Front}}和{{ui:Side}}的按键，请使用按钮。

## 编辑

工具栏中提供相同的命令：{{ui:Undo}}、{{ui:Redo}}、{{ui:Copy}}、{{ui:Paste}}，以及{{ui:More}}菜单（其中显示各命令的按键）。它们适用于IFC模型的三维视图，在字段中输入文字时不可用。参见[复制、粘贴和创建库项目副本](topic:copy-paste)。

| 按键 | 作用 |
|---|---|
| {{key:Mod+Z}} | 撤销上一次更改 |
| {{key:Mod+Y}}或{{key:Mod+Shift+Z}} | 重做被撤销的操作 |
| {{key:Mod+C}} | 复制所选构件（其名称和属性也会以文本形式放入剪贴板） |
| {{key:Mod+X}} | 剪切所选构件：先复制，然后删除 |
| {{key:Mod+V}} | 粘贴已复制的内容：跟随指针，点击放置位置 |
| {{key:Mod+Shift+V}} | 原位粘贴：剪切时的原位置，或复制后紧挨原件 |
| {{key:Mod+D}} | 创建副本：复制所选构件并开始粘贴 |
| {{key:Delete}} | 删除所选构件及其部件和开孔。参见[删除、剪切、复制和粘贴建筑构件](topic:edit-elements) |
| {{key:Mod+A}} | 选择所有显示的构件 |
| {{key:Esc}} | 取消选择 |

当页面中选中了文字时，{{key:Mod+C}}照常复制该文字。

## 平面视图（绘制）

开启{{ui:Draw}}且未在字段中输入文字时，以下操作有效。参见[绘制墙](topic:draw-walls)和[门和窗](topic:doors-and-windows)。

| 按键或操作 | 作用 |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | 使用{{ui:Door}}或{{ui:Window}}时：铰链位于另一端 |
| 绘制墙时按住{{key:Shift}} | 保持0°、90°、180°或270° |
| 数字以及英尺和英寸符号（`'`和`"`） | 开始在{{ui:Length}}框中输入长度；{{key:Enter}}确认该长度 |
| {{key:Enter}}、{{key:Esc}}、右键单击或双击 | 结束正在绘制的墙；再按一次{{key:Esc}}返回{{ui:Select}} |
| {{key:Delete}} | 删除所选墙、门和窗；剩余的墙会重新连接 |
| 指针位于平面图上时按{{key:F}} | 适合平面图 |
| 滚动滚轮 | 以指针为中心缩放 |
| 中键或右键拖动，或按住{{key:Space}}并拖动 | 平移；开启{{ui:Select}}时，普通拖动也会平移 |
| 使用{{ui:Select}}拖动门或窗 | 沿其墙移动，或移到另一面墙上 |
| 双指（触摸） | 捏合缩放，并排移动可平移 |

## 放置和粘贴库项目

| 按键 | 作用 |
|---|---|
| {{key:R}} | 将项目旋转90° |
| {{key:Tab}} | 开启或关闭墙面吸附：项目背面贴靠最近的墙 |
| 在**X, Y (mm)**中按{{key:Enter}} | 放置到输入的位置 |
| {{key:Esc}} | 停止放置或粘贴 |

## 编辑IFC值

| 按键 | 作用 |
|---|---|
| {{key:Enter}} | 保留输入的值 |
| {{key:Esc}} | 取消并恢复原值 |
| 在其他位置点击 | 保留输入的值 |
| {{key:Mod+Z}} | 撤销上一次更改。仅在有未保存的更改且未在字段中输入文字时有效 |
| {{key:Mod+Y}} | 重做被撤销的操作 |
| {{key:Mod+S}} | 另存为IFC。仅在有未保存的更改时有效；否则将打开浏览器自身的保存命令 |

仅用键盘编辑：按{{key:Tab}}直到某个值高亮，然后按{{key:Enter}}开始输入。

## 2D图纸（DWG和DXF）

| 按键或操作 | 作用 |
|---|---|
| {{key:F}} | 适合图形或图纸 |
| {{key:P}} | 开启或关闭打印视图 |
| 双击 | 适合 |
| 用任意鼠标键拖动 | 平移 |
| 滚动滚轮 | 以指针为中心缩放 |
| 触控板双指滚动或捏合 | 以指针为中心缩放。双指滚动不平移 |
| 单指（触摸） | 平移。图纸的捏合缩放尚未实现 |

## 三维中的图纸

| 按键或操作 | 作用 |
|---|---|
| {{key:3}} | 开启或关闭三维（同样适用于二维视图） |
| {{key:F}} | 范围：整张图纸 |
| 中键或左键拖动 | 动态观察 |
| 右键拖动，或按住{{key:Shift}}并拖动 | 平移 |
| 滚动滚轮 | 向指针下的内容缩放 |
| 触控板双指滑动 | 动态观察；按住{{key:Shift}}则平移 |
| 触控板捏合 | 缩放 |
| 单指（触摸） | 动态观察 |
| 双指（触摸） | 捏合缩放，并排移动可平移 |

在字段中输入文字、显示设备明细表时，或按住{{key:Mod}}或{{key:Alt}}时，{{key:F}}、{{key:P}}和{{key:3}}均无效。

## 文件

| 操作 | 作用 |
|---|---|
| 将文件拖到页面上 | 打开该文件 |
| 将文件夹拖到页面上 | 将其作为项目文件夹打开，无需权限提示 |
