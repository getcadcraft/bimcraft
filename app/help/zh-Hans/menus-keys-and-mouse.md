BimCraft的命令无论通过哪种方式调用都相同。**菜单样式**只决定命令在屏幕上的位置、在那里显示的名称以及由哪些按键执行，因此可以保留原有的操作习惯。在{{ui:设置}}（{{key:Mod+,}}）› {{ui:BimCraft}} › {{ui:菜单、按键和鼠标}}中选择一种样式；更改立即生效，此浏览器会记住该设置。

## 五种样式

| 样式 | 包含内容 |
|---|---|
| {{ui:CadCraft}} | BimCraft自有的工具栏和按键（{{key:W}}墙、{{key:D}}门、{{key:N}}窗、{{key:X}}剖面、{{key:F}}适合窗口）。这是起始样式。 |
| {{ui:家装设计}} | 一个菜单栏（文件、编辑、构建、库、3D、CAD、工具、视图），上方是一排建筑工具，布局与住宅家装设计程序一致。使用相同的单键，另外 {{key:Mod+L}} 打开库，{{key:F9}} 切换到三维视图，{{key:F10}} 切换到平面，{{key:F11}} 同时显示两者。 |
| {{ui:BIM功能区}} | 大按钮选项卡（建筑、插入、注释、修改、视图、输出），右侧为文件菜单和快速按钮。双字母键：{{key:W}} 再 {{key:A}} 放置墙，{{key:D}} {{key:R}} 门，{{key:W}} {{key:N}} 窗，{{key:S}} {{key:C}} 剖面，{{key:Z}} {{key:F}} 适合窗口。中键平移；{{key:Shift}} 加中键环绕。 |
| {{ui:经典绘图}} | 一个小型功能区和一个命令行，供习惯键入命令的用户使用：WALL、DOOR、WINDOW、ROOF、U（撤销）、ZOOM、SECTION、PLOT、INSERT、HELP。直接在任意位置开始键入，字母会进入命令行；{{key:Enter}} 执行，空白时按 {{key:Enter}} 重复上一条命令，{{key:Esc}} 清除输入。 |
| {{ui:查看器}} | 用于打开和检查模型，而非绘制：{{ui:文件}}、{{ui:视图}}、{{ui:显示}}、{{ui:检查}}和{{ui:编辑}}菜单，上方是一排查看工具（适合窗口、俯视、前视、侧视、剖面、测量、隐藏、隔离、透明、全部显示、漫游）。建筑工具位于末尾的{{ui:模型}}菜单中。按键与BimCraft自有样式相同。 |

菜单和功能区在打开模型或开始新建建筑后显示；在此之前，左侧面板用于打开文件和开始建筑。

:::tip
不属于所选样式的 BimCraft 自有布局按键不起作用，状态行会说明其命令所在位置（例如“在BIM功能区中，剖面为SC”）。{{key:Delete}}、{{key:Esc}}、{{key:Enter}}、{{key:Tab}}、{{key:Space}} 和方向键始终保持其含义，正在运行的工具保留自身的按键：放置时的 {{key:R}} 和 {{key:Tab}}，漫游时的 {{key:W}} {{key:A}} {{key:S}} {{key:D}}，门和窗工具中的 {{key:H}}，以及键入长度时的数字。
:::

## 自定义

1. 选择最接近所需的样式，然后点击{{ui:自定义…}}。
2. 在{{ui:按键和菜单}}中查找命令（搜索框可以帮助查找）。点击{{ui:添加按键}}并按下该键，或连按两个键设置双字母键。点击某个按键即可将其移除。
3. 对于菜单栏或功能区，{{ui:所在位置}}可将命令移至另一个菜单或面板，或改为{{ui:仅按键}}。
4. 在{{ui:鼠标}}中设置滚轮、用于平移平面的按钮，以及三维视图中每个按钮的功能。
5. 为其命名并点击{{ui:保存}}。

保存内置样式会生成一份自定义副本（“我的家装设计”），内置样式本身永不更改。同一按键分配给两个命令，或某个按键会在双字母键输入完成前执行，都会以红色显示，必须修正后才能保存。

## 鼠标

- **鼠标滚轮**：{{ui:向上滚动为放大}}（初始设置）或{{ui:向上滚动为缩小}}，以及缩放速度。触控板捏合操作始终按手指移动的方向缩放。
- **平移平面和图纸使用**：左键、中键和右键中的任一按钮。按住{{key:Space}}并拖动同样可以平移；只有在单击不会选取或绘制时，左键拖动才会平移。
- **在三维视图中拖动**：{{ui:各视图自有}}保留 BimCraft 的按钮设置（左键环绕，右键平移）。也可以将每个按钮设为环绕、平移、缩放或无；{{key:Shift}} 与按钮配合可交换环绕和平移。不拖动的单击仍会选取对象。

## 随身携带

{{ui:导出}}会将当前使用的样式保存为一个小的 `.ccinput.json` 文件；{{ui:导入…}}可从另一台计算机或同事处添加该文件。导入的文件只能指向 BimCraft 自身的命令：文件中的其他内容（本版本没有的命令、此处无法使用的按键）会被省略，并在状态行中计数。{{ui:删除此样式}}可删除一个自定义样式。

:::note
这些设置仅保存在此浏览器中。样式卡片下方的{{ui:在所有应用中使用此样式}}会使每个应用都以与之匹配的样式打开（其自有工具栏、菜单栏、功能区或经典绘图；{{ui:查看器}}仅属于BimCraft自有，其他应用中没有对应样式），并保留在各应用中所做的更改；没有匹配样式的应用则保留其自有设置。在一个应用中选择其他样式只会更改该应用。
:::
