## 你将完成的工作

在模型中放置分体式、多联分体式或 VRF 系统的各机组及其风机盘管，然后用连管将它们连接起来：液管和气管均采用 ACR 紫铜管，并固定到机组的接口上。这些机组与[带接口的 MEP 设备](topic:mep-equipment)中的其他部件操作方式相同：使用同一工具栏、**特性**、接口以及[连接](topic:mep-connections)。

:::note
本功能为绘图与协调辅助工具。机组为通用图形，尺寸由你输入的数值决定，并非任何厂家的产品。其管径取自 R410A 和 R32 设备的**典型示例值**表，并非来自任何厂家：机组厂家的安装手册决定实际尺寸，较长的管路或较大的高差会改变尺寸。请修改该表，或直接输入管径，以匹配你所用的机组。
:::

## 放置机组

1. 开启{{ui:绘制}}，打开{{ui:构建}}，并选择{{ui:设备}}。
2. 选择类型并设置其数值：

| 类型 | 需设置 | 接口 |
|---|---|---|
| 分体式室内机，壁挂 | 制冷量、液管和气管、长度、深度、高度、冷凝水管径 | 制冷剂液管和气管、冷凝水排出口（位于右端，靠近墙面） |
| 分体式室内机，天花嵌入式 | 制冷量、液管和气管、面板、机身、高度、冷凝水管径 | 制冷剂液管和气管、冷凝水排出口（位于一侧，靠近顶部） |
| 分体式室内机，风管式 | 制冷量、液管和气管、长度、宽度、高度、送风和回风口、冷凝水管径 | 送风风管出口、回风风管入口、制冷剂液管和气管、冷凝水排出口 |
| 分体式室外机 | 制冷量、液管和气管、宽度、深度、高度 | 制冷剂液管和气管（位于右侧） |
| VRF 室外机 | 制冷量、液管和气管、宽度、深度、高度 | 制冷剂液管和气管（位于前方，较低处） |
| Refnet 分歧管 | 液管或气管、每个支路的负荷、两端的管径 | 进口、支路 A、支路 B |
| 风机盘管 | 双管或四管、长度、宽度、高度、送风和回风口、盘管管路和系统、加热管、冷凝水管径 | 送风风管出口、回风风管入口、盘管进出水、加热进出水（四管）、冷凝水排出口 |

3. 设置 **At**：机组底座相对于标高的高度。壁挂机组的底座为其下表面（通常为 2100 mm）；天花嵌入式机组的底座为其在吊顶内的表面；Refnet 分歧管的底座为其管道中心线的高度。
4. 点击放置位置（{{key:R}} 将其旋转 90°）。

**制冷量**为机组的额定制冷量，单位为 kW，旁边附有 Btu/h。当**液管**和**气管**保持为**取自表格**时，机组接口采用表格中该制冷量对应的管径；如需使用你所用机组自身的管径，请选择一个管径。Refnet 分歧管的进口按两个支路合计负荷确定管径，每个支路则按其自身负荷确定管径。

制冷剂接口双向有效（热泵可以向任一方向运行）。冷凝水排出口与任何排水口一样，只是一个管径。

## 绘制连管

1. 选择两个对象（按住{{key:Shift}}并点击第二个）：一台室外机和一台室内机（单台分体式），或一台室外机和一个 Refnet 分歧管，一个 Refnet 分歧管和一台室内机，或两个 Refnet 分歧管（VRF）。
2. 打开{{ui:构建}}，并选择{{ui:连管}}。

BimCraft 在两者之间未连接的接口之间绘制液管和气管：从各接口引出后升至共同高度，采用 ACR 紫铜管（直径 1-5/8 in 及以下为退火盘管，以上为拉制管），作为{{ui:撤销}}的一个步骤。Refnet 分歧管只接入其自身所属的管路：从室外侧进入其进口，并从某个支路接向室内机。每段管路采用其下游一端（室内机，或 Refnet 分歧管的进口）的管径；若另一端的接口为其他管径，{{ui:检查连接}}会将其列出，这正是需要设置异径接头的位置。两台室内机之间需要设置一个 Refnet 分歧管。

连管绘制完成后，可像其他管路一样移动；其端点仍保持在接口上。跨楼层的管路使用{{ui:管道}}绘制：从制冷剂接口开始绘制的管道，将采用其系统、ACR 紫铜材质及其管径。

## 更改连管表

打开{{ui:构建}}，并选择{{ui:连管尺寸}}。每一行的含义为：制冷量不超过此值（kW）时，采用此液管和此气管。

| 制冷量上限 | 液管 | 气管 |
|---|---|---|
| 2.8 kW | Ø6.35 (1/4") | Ø9.52 (3/8") |
| 5.6 kW | Ø6.35 (1/4") | Ø12.7 (1/2") |
| 16 kW | Ø9.52 (3/8") | Ø15.88 (5/8") |
| 22.4 kW | Ø9.52 (3/8") | Ø19.05 (3/4") |
| 33 kW | Ø9.52 (3/8") | Ø22.22 (7/8") |
| 47 kW | Ø12.7 (1/2") | Ø28.58 (1-1/8") |
| 71 kW | Ø15.88 (5/8") | Ø28.58 (1-1/8") |
| 104 kW | Ø19.05 (3/4") | Ø34.92 (1-3/8") |
| 180 kW | Ø19.05 (3/4") | Ø41.28 (1-5/8") |

这些是起始的典型值。修改某一行、增加或删除行，然后选择{{ui:保存}}：该表保存在模型中，因此处理此文件的所有人都使用同一张表，且{{ui:撤销}}可将其恢复。{{ui:使用典型值}}可将起始表恢复。已放置的部件在你修改之前仍保留其接口。

## 在 IFC 文件中

分体式和 VRF 系统的室内机与室外机为类型 SPLITSYSTEM 的 IfcUnitaryEquipment，其对象类型注明具体种类（"Split indoor unit, wall-mounted"、"Split indoor unit, ceiling cassette"、"Split indoor unit, ducted"、"Split outdoor unit"、"VRF outdoor unit"）。风机盘管为类型 AIRHANDLER 的 IfcUnitaryEquipment，其对象类型为 "Fan coil unit"：IFC4 没有风机盘管类型，而一个房间的风机、盘管和过滤器恰好是 AIRHANDLER 所描述的内容。Refnet 分歧管为类型 JUNCTION 的 IfcPipeFitting（"Refnet joint"）。IFC2X3 文件则使用 IfcEnergyConversionDevice 和 IfcFlowFitting，并带有相应的类型。

制冷剂接口与管路位于 REFRIGERATION 系统中（液管和气管各一个系统），冷凝水位于 DRAINAGE 系统中。ACR 管路以外径命名。连管表为项目上的属性集 CadCraft_HvacLineSets。

另请参阅[带接口的 MEP 设备](topic:mep-equipment)、[将管道和风管连接到设备](topic:mep-connections)以及[管道和风管](topic:pipes-and-ducts)。
