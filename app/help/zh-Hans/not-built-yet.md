目前的 BimCraft 是一个阅读器、检查器和 IFC 数据编辑器，并已开始绘制建筑：墙、门和窗、房间、楼板、吊顶和屋顶（参见[绘制墙体](topic:draw-walls)、[门和窗](topic:doors-and-windows)以及[房间、楼板、吊顶和屋顶](topic:floors-and-roofs)）。以下是尚未实现的功能的完整清单，并说明可以改用何种方式。

## 建模与创建

| 尚未实现 | 目前的替代方法 |
|---|---|
| 绘制梁；钢型材柱 | 使用建模程序，然后在此打开其导出的 IFC 文件。矩形和圆形柱可在此放置（参见[轴网和柱](topic:grids-and-columns)）；直跑、L 形、U 形、扇形踏步和螺旋楼梯以及栏杆可在此绘制（参见[楼梯和栏杆](topic:stairs-and-railings)） |
| 老虎窗正面的窗；在屋面上手绘的老虎窗；曲面屋顶；渲染的屋面覆层纹理 | 通过角点绘制屋面，并为每面墙设置坡度：参见[屋顶：每面墙的坡度、山墙、单坡屋顶和屋面](topic:roofs) |
| 修改其他程序创建的墙、门或窗 | 使用建模程序；绘图工具仅修改其自身绘制的内容 |
| 带挑出或孔洞的墙体轮廓；非矩形的墙洞；在三维视图中添加或删除墙体轮廓点 | 轮廓、附着、倾斜和墙洞可在特性中、立面和剖面中、墙面视图中以及三维中通过夹点进行设置，适用于直墙和曲墙：参见[塑造墙体：附着、轮廓、倾斜和墙洞](topic:wall-shape) |
| 对于曲墙：{{ui:修剪 / 延伸}}和{{ui:转角}}、框架、自动平面尺寸、沿圆弧捕捉（仅捕捉其端点和圆弧中点） | 对于这些功能，请将墙体绘制为直线，或使用直线段。曲墙参见[绘制墙体](topic:draw-walls) |
| 在三维视图中拖动已放置的库项目 | 在平面图中拖动，或在{{ui:特性}}中输入 X、Y 和旋转：参见[从库中放置设备和家具](topic:place-from-library) |
| 从 CivilCraft 景观工作空间的植物库中放置植物 | 在 CivilCraft 中种植，或从库的配景中放置乔木和灌木：参见[从库中放置设备和家具](topic:place-from-library) |
| 在 Plant 插件中（开启前处于关闭状态）：将走线绘制到模型中、其轴测图上的管段编号，以及对从库中放置的设备进行布局检查 | 使用{{ui:管道}}绘制走线（参见[管道和风管](topic:pipes-and-ducts)）；布局检查读取插件自身的设备表 |
| 旋转、镜像或阵列单独绘制的墙、门和窗（墙体可通过{{ui:移动}}、偏移和框选拉伸进行移动和复制：参见[墙体形状、拆分、偏移、拉伸和锁定](topic:wall-tools)）；曲墙或三面及以上墙相交处的连接样式（平接、直角切齐）（参见[墙体形状、拆分、偏移、拉伸和锁定](topic:wall-tools)）；文字工具；幕墙 | 使用{{ui:复制此标高……}}复制某一楼层上的所有内容（参见[绘制墙体](topic:draw-walls#levels)）；否则请重新绘制 |
| 在平面图和剖面中绘制的墙体构造层；剖面和立面中的尺寸；到门、窗及其他构件的参照尺寸；明细表和工程量中的构造和膜层；项目之间共享的材料库；剖面、立面和三维中以及三面或更多墙相交节点处的层优先级（在平面图上，转角、T 形连接和两墙交叉由层优先级清理：参见[墙体形状、拆分、偏移、拉伸和锁定](topic:wall-tools)）；包裹层或可变层；编辑其他程序创建的墙的构造 | 各层位于墙体类型及其预览中（{{ui:墙体构造…}}）；墙体按一个外包络整体计量：参见[墙体构造和参照尺寸](topic:wall-assemblies) |
| 更改构件的形状或尺寸（此处绘制的墙、门和窗以及从族放置的构件除外） | 使用建模程序。此处可进行删除、复制、剪切和粘贴：参见[删除、剪切、复制和粘贴建筑构件](topic:edit-elements) |
| 删除楼层、空间、建筑或场地 | 删除其中的构件 |
| 将建筑构件粘贴到另一模型中 | 在同一模型内复制和粘贴；已放置的库项目可粘贴到任意模型中 |
| 添加新的属性或属性集 | 在此填写现有值，或在建模程序中添加参数后重新导出 |
| 编辑工程量、列表、枚举 | 建模程序 |
| 保存其他程序的项目文件 | BimCraft 保存 IFC（及其自身的族文件：参见[族及其尺寸](topic:families)） |
| 族：从平面图放置并在项目之间共享的族库（库），在三维视图中拖动已放置构件的热点（它们在族编辑器的预览和平面图中拖动），按视图选择的详细程度（项目统一一个级别；图纸按比例选择），在另一族中绕竖直平面旋转四分之一圈的旋转体，门和窗自带的平面符号（它们绘制其起始族的符号） | 带类型参数、公式、自有平面符号、热点、重复项、详细程度、族中嵌套族、由表格生成的尺寸和逐构件参数的族，在此创建：参见[编辑族](topic:family-editor)和[族及其尺寸](topic:families)。复制族即可以其为起点 |
| 将其他程序的类型作为族进行编辑；将库项目转换为族 | 其他程序的类型会被列出，按推测进行分组，并可选取其构件。库项目按原样放置 |
| 制造商的配件、阀门和设备（容量、重量、制造商连接尺寸）；钢管段上的 ASME B16.9 三通和异径管长度；通过配件的压力损失、流量和平衡；喷淋头；电缆桥架；按器具单位确定立管和通气管尺寸；拖动管线的转角；在墙和楼板上开洞；松开固定在端口上的管线端点（删除设备除外）；从库面板放置的库项目上的端口；配件重量；风管接缝、板厚和连接件 | 带有通用标准配件、系统、平面图、明细表和工程量的管道和风管管线在此绘制：参见[管道和风管](topic:pipes-and-ducts)。带端口的通用设备、已连接管线以及连接检查：[带端口的 MEP 设备](topic:mep-equipment)、[将管道和风管连接到设备](topic:mep-connections)。碰撞集、净距和开洞清单：[检查管道和风管与结构的关系](topic:mep-against-structure)。钢管段和图纸、风管切割清单：[钢管段和管段图纸](topic:pipe-spools)。制造商的构件请从 MEP 程序以 IFC 形式导入 |
| 焊接工字形的设计规范校核，以及 IFC 截面未命名为轧制 W、S、IPE、HEA 或 HEB 型号的工字形、以及管、角钢和槽钢的校核（它们返回未校核）；屈曲或动力响应（固有频率位于有限元模块中）（二阶仅为 P-Delta：弹性、弯曲、无刚度折减）；分析中的墙和楼板；由面积生成的荷载（每块混凝土楼板上的一个压力除外） | {{ui:分析}}选项卡通过一阶分析给出梁、柱和支撑的内力、反力和挠度，并对轧制工字形进行校核，这仅作为辅助工具，须经工程师审核：参见[分析结构框架](topic:frame-analysis#design-checks) |

## 模型查看

| 尚未实现 | 目前的替代方法 |

| 生成的图纸集中的内部立面（可从房间的特性生成，也可在自定图纸上生成）；立面和剖面上自定义的尺寸（标高标记、高度、宽度以及门/窗标记会绘制；注释在视图中书写：参见[在立面和剖面中编辑](topic:edit-in-elevations)）；在立面中绘制墙（它们绘制在剖面平面内）；通过 Studio 的团队模板 | 由模型生成的图纸集：参见[立面、剖面和图纸](topic:sheets)。适用于任何 IFC 模型：一个{{ui:剖切}}平面或剖面框；参见[用剖切平面剖切 IFC 模型](topic:section-plane) |
| 索引视图、详图视图、绘图视图和图例；在视图中绘制的绘图线和填充；裁剪立面或剖面；立面、剖面、天花板平面和三维视图的视图样板；生成的图纸集中的天花板平面；将自定义图纸整体输出为一个 PDF | 平面图和天花板平面具有视图范围、裁剪区域、比例和底图（平面图还具有样板），自定义图纸可包含平面图、天花板平面、立面、剖面和明细表，每个均保存为 PDF：参见[视图、视图范围和自定义图纸](topic:views-and-sheets) |
| 之后将已放置的灯具移动到天花板上；斜面或阶梯式天花板；五种网格以外的天花板图案；灯具在天花板平面中的自有符号 | 使用**安装：位于天花板**进行放置；天花板平面根据其自身形状绘制灯具：参见[从库中放置设备和家具](topic:place-from-library) |
| 与他人共享搜索集，IFC 文件中的集合 | 集合保存在此浏览器中；参见[按类别、名称或属性查找构件](topic:find) |
| 测量角度，或沿多点路径测量 | 使用{{ui:测量}}分段测量：参见[在三维中测量距离、面面积和位置](topic:measure) |
| 实时三维视图中的纹理 | 已上色的材质在视图中显示其颜色，在渲染图片中显示其纹理：参见[渲染模型图片](topic:render) |
| 任意两个集合之间的净距（软）碰撞、碰撞组、保存碰撞结果 | 运行{{ui:碰撞检查}}，并将重要的碰撞转为问题：参见[检查碰撞](topic:clash-check)。管道和风管与结构的检查使用{{ui:检查净距}}：参见[检查管道和风管与结构的关系](topic:mep-against-structure) |
| 将多个模型保存为一个集合，或同时编辑两个模型 | 一次编辑一个模型；每个模型保存其自身文件 |
| 为问题分配负责人、截止日期、标签，每个问题多个视点，编辑问题 | 每个问题一个视点；参见[问题和 BCF 文件](topic:issues-bcf) |
| `.ifczip` 和 `.ifcxml` | 解压缩，或导出普通的 `.ifc` 文件 |
| 没有地图转换的模型中，或图纸视图中的地图图层 | 导出带坐标的模型：参见[模型下方地面上的地图](topic:map-layers) |
| 超过 600 万个点或 512 MB 的 E57 扫描；扫描仪制造商自有格式的文件（RCP、RCS、FLS、LGS、TZF、ZFS）；图纸三维视图中的点云；随模型保存点云的位置 | 将扫描导出为 LAS 或 LAZ，并在 IFC 模型旁打开：参见[点云格式](topic:point-cloud-formats)和[在模型旁显示点云](topic:point-clouds) |
| 扫描配准：自动在扫描中查找标靶（球体、棋盘格），同时求解所有扫描（光束法平差），比例，与模型配准 | 选取匹配点或输入标靶坐标，然后使用 ICP 逐次优化一个扫描：参见[将多个扫描配准为一个](topic:register-scans) |
| 打开 `.pln`、`.pla`、`.tpl` 和 `.bpn` 项目文件 | 从中导出 IFC 和 DWG，或导出项目包：参见[打开 .pln 和 .pla 项目文件](topic:pln-project-files)和[打开项目包](topic:open-project-bundle) |
| 打开{{ui:构件}}列表按类别选取 | 在{{ui:模型树}}中单击某一类别的组：参见[用模型树查找位置](topic:model-tree) |
| 在 VR 中为问题输入注释或标题、语音备注、在 VR 中手动移动剖切平面、在 VR 中使用剖面框 | 在 VR 中放置问题，然后在问题选项卡中添加文字；进入 VR 前在三维视图中设置剖切平面或剖面框：参见[在 VR 头显中审阅模型](topic:vr-review) |

| 托管的建筑数字孪生：BimCraft 关闭时保存读数并通过电子邮件发送警报，维护到期的电子邮件；MQTT 5；读回 COBie 的任务 | 模型打开时，从 CSV 或直接从自有代理服务器或地址读取数据，设置标记资产的限值，文档、COBie 的导入和导出：参见[在模型中保存资产数据和维护记录](topic:assets-and-maintenance) |
| 用于 Enscape、Twinmotion 或其他可视化程序的插件或实时链接；FBX 或 Datasmith 文件；.glb 中的每个构件一个对象、保存的视图和漫游 | 保存供读取 glTF 的渲染程序使用的 .glb，保存 USD 文件（每个构件一个对象，并带有其 IFC 数据：参见[将模型导出为 USD](topic:usd)），或为在其他设计程序中运行的程序保存 IFC：参见[将模型发送到渲染程序](topic:model-for-rendering)和[在其他程序中打开场景](topic:render-open-in) |

## 图形

| 尚未实现 | 目前的替代方法 |
|---|---|
| 编辑、测量或保存 DWG 和 DXF | CadCraft 绘图应用（二维视图中的{{ui:在CadCraft中编辑}}） |
| 打印或导出 PDF | 从创建图形的程序中打印；先用{{ui:打印视图}}检查 |
| 打印样式和笔表 | {{ui:打印视图}}以带线宽的纯黑色显示 |
| 早于 R13 的 DWG 文件，以及二进制 DXF（打开时 BimCraft 会提示） | 将图形重新保存为较新的 DWG，或保存为 ASCII DXF |
| 在外部参照图形中再链接的图形 | 直接打开它们 |
| TIFF 图片 | 保存同名的 PNG 或 JPEG 副本并添加它 |
| DGN 图形 | 仅在文件夹报告中列出 |
| 列在**尚未绘制**下的对象 | 在创建图形的程序中查看图形 |
| 三维中的 ACIS 实体、体、面域和曲面，以及细分网格 | 从创建图形的程序导出 IFC 或三维面 |
| 图形三维视图中的图像、多重引线和图纸 | 在{{ui:模型}}选项卡和图纸中查看 |
| 在图形的二维视图中选取对象 | 切换到{{ui:三维}}并在其中点击对象：参见[在三维中查看 DWG 或 DXF 图形](topic:dwg-in-3d) |
| 没有 `KCL-ITEM` 标记的图形中的设备明细表 | 不可用 |
| 设备明细表为 XLSX 或 PDF | 使用{{ui:下载CSV}}下载后在电子表格中打开 |

## 文件和平台

| 尚未实现 | 目前的替代方法 |
