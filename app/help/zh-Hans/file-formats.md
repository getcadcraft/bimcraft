## IFC

| 读取内容 | 详情 |
|---|---|
| 几何 | 每个带有形状的构件，颜色与文件中所定义的相同。房间和空间以半透明方式绘制，且初始时隐藏 |
| 楼层 | 按高程顺序排列的建筑楼层，以及各楼层上的构件。不在任何楼层上的构件归入"不在楼层上" |
| 构件数量 | 每种构件（墙、门、楼板……）的数量，显示在 {{ui:构件}} 中 |
| 项目信息 | 项目名称、全称和阶段；架构；文件头中的导出程序、作者和导出日期 |
| 构件数据 | 名称、类型、对象类型、标签、描述、GlobalId；构件及其类型上的每个属性集和数量集 |

可编辑：名称、对象类型、标签、描述以及单个属性值。保存为新的 IFC 文件。IFC2X3、IFC4 和 IFC4X3 架构均可打开，由 BimCraft 自带的 IFC 引擎读取；目前无法绘制的内容会列在 {{ui:文件}} 面板的 **尚未绘制** 下。模型在打开时会移至原点，因此放置在远离原点处的模型仍会显示在屏幕中央。`.ifczip` 和 `.ifcxml` 无法打开。

## 项目和族文件

`.rvt` 项目、`.rte` 项目样板、`.rfa` 族和 `.rft` 族样板。

| 读取内容 | 详情 |
|---|---|
| 文件信息 | 发布版本和构建号、工作共享、中心模型路径、最后保存路径、用户名、语言区域、文档 GUID |
| 项目信息 | 项目自身的字段（名称、编号、客户、地址、状态……），不包括新项目的默认值 |
| 族信息 | 族名称、类别、发布版本、最后更新时间，以及按组划分的参数 |
| 链接 | 文件所指向的链接模型、CAD 链接、图像和注释表列表 |
| 预览图 | 文件中保存的缩略图 |

未读取：三维模型、构件、视图、图纸和明细表。它们以未公开的格式存储。BimCraft 仅读取每个文件的几十 KB，因此文件大小几乎无影响。

## .pln、.pla、.tpl 和 .bpn 项目文件

尚未读取：打开时 BimCraft 会提示此情况。请为模型导出 IFC，为图形导出 DWG；参见 [打开 .pln 和 .pla 项目文件](topic:pln-project-files)。

## DWG 和 DXF

| 读取内容 | 详情 |
|---|---|
| 空间 | 模型空间和每张布局，按标签页顺序 |
| 视口 | 每张布局的视口，包括其比例、旋转角度和冻结图层 |
| 图层 | 名称、颜色、开 / 关、冻结、打印标志和线宽 |
| 对象 | 直线、多段线、圆弧、圆、椭圆、样条曲线、填充和实体、文字和多行文字、块及属性、标注、引线和多重引线、表格、点、图像 |
| 外部参照 | 在其插入位置绘制，前提是找到其文件 |
| 图像 | 找到图片文件时进行绘制（PNG、JPEG、GIF、BMP、WebP；不支持 TIFF） |
| 设备标注 | 餐饮设备项目标注（`KCL-ITEM` 属性），用于设备明细表 |

其他内容均计入 **尚未绘制**，从不猜测。已检查的 DWG 版本为 AutoCAD 2000 至 2018 格式（也接受 R13 和 R14 文件，但测试集中没有这些文件；更早的 DWG 无法打开）；{{ui:图形}} 面板显示格式代码（如 AC1032）。所有版本的 DXF 文件均可打开，包括 R12。两者均由 BimCraft 自带的读取器读取，在本选项卡中进行。不会将任何内容保存回 DWG 或 DXF。

## 文件夹中

| 类别 | 扩展名 | 在报告中 |
|---|---|---|
| 模型 | `.rvt` `.rfa` `.rte` `.rft` | 按带编号的备份分组，进行健康检查，读取卡片信息，检查链接 |
| IFC | `.ifc` | 列出；可在三维中打开 |
| CAD | `.dwg` `.dxf` `.dgn` | 列出，并列出链接它们的模型；DWG 和 DXF 可在二维中打开，DGN 不能 |
| 残留文件 | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | 列在 **另行存放** 下 |
| 辅助文件夹 | `*_backup`、`*_log`、`Revit_temp`、隐藏文件夹 | 列在 **另行存放** 下，不读取 |

参见 [文件夹报告：角色、状态和链接](topic:folder-roles)。
