{{ui:Render}} 在上方的 {{ui:Mode}} 处有一个 **引擎** 选项。我们自带的两种引擎始终可用，在任何地方都能工作；插件可以添加更多引擎，在 CadCraft Studio 中，该列表还包含接管场景的程序。

| 引擎 | 作用 | 适用位置 |
|---|---|---|
| 内置：快速 | 快速静态图：日光、柔和阴影、玻璃和金属质感，几秒内完成 | 浏览器和 Studio |
| 内置：路径追踪器 | 在显卡或处理器上计算表面之间的光线反弹，并使用渲染队列以及网络上的其他计算机 | 浏览器和 Studio |
| 插件的引擎 | 绘制图像并返回：见 [用其他程序绘制图像](topic:render-other-program) | 浏览器（用 JavaScript 编写的引擎）或 Studio（运行程序的引擎） |
| 接管场景的程序 | Studio 将场景放入其文件夹并保持同步 | Studio |
| 在…中打开 | 保存场景并在某程序中打开；不会返回任何结果：见 [在另一程序中打开场景](topic:render-open-in) | 网页版会保存文件 |

## 选择的行为

- 选择快速或路径追踪器时，模式会随之切换，反之亦然。对于从不使用其他引擎的用户，对话框的其他部分不会发生变化。
- 不可用的引擎会保留在列表中，并附上原因（“未找到”“需要较新的版本”）；你无法选择它。在浏览器中，仅在 Studio 中运行的引擎会显示“保存文件”：此时 {{ui:Render}} 会将场景及其设置保存为一个文件，你可以将其带到该程序中。
- 所选的引擎会随文件的渲染设置一起保存；对于没有自身选择的文件，最近选择的引擎即为起始引擎。
- 来自其他程序的图像会在对话框和渲染队列中注明绘制它的程序及其版本。[渲染](topic:render) 页面中的承诺仅涵盖**我们自带的**引擎：其他程序以自己的方式处理光照、色调和采样，因此同一场景的两张图像在相机、太阳、灯具和曝光上相似，但并非逐像素一致。

## 每个引擎获得的内容

场景以**打包文件**的形式交给其他程序：模型为 USD 文件（与 [另存为 USD](topic:usd) 写入的文件相同），以及一个设置文件，其中包含 USD 导入器不宜单独依赖的内容：精确的材质数值、已开启的灯具及其功率和配光文件、太阳、天空、曝光，以及对话框所示的相机。任何内容都不会上传。

## 渲染队列

供其他程序使用的图像可以像我们自己的图像一样在 [渲染队列](topic:render#the-render-queue) 中等待；其任务会记住它所对应的引擎。
