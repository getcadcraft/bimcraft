## IFC 构件

{{ui:特性}}面板顶部显示构件的类型（不含“Ifc”前缀，例如“Door”“WallStandardCase”“FurnishingElement”）及其名称；若无名称，则显示“Unnamed”。

| 字段 | 含义 | 可编辑 |
|---|---|---|
| Name | 构件名称，通常为导出程序中的族和类型名称 | 是 |
| Type | 构件类型的名称（若有） | 否 |
| Object type | 自由文本的类型描述，部分导出程序会填写 | 是 |
| Tag | 构件的标记或编号；许多导出程序在此写入构件 ID | 是 |
| Description | 自由文本 | 是 |
| GlobalId | 构件永久的 22 位 IFC 标识符，同一构件每次导出时都相同 | 否 |
| Line | 构件在此 IFC 文件中的行号（`#1234`）。每次导出都会变化 | 否 |

下方为按名称排序的**属性集**：

- 点击属性集名称可展开或收起该集。前三个属性集默认展开。
- 标有“(type)”的属性集属于构件的类型：“类型属性：此处的更改将应用于该类型的所有构件。”
- 数量集（长度、面积、体积、数量、重量）为只读。
- 列表和枚举值仅显示，为只读。
- 是/否值显示为**是**或**否**。
- 数值显示时四舍五入到小数点后四位。长度（长度属性或数量的长度）按工具栏中选择的{{ui:单位}}显示，单位显示在其旁边；可以用该单位或其他单位符号输入新值（2.4 m、8'-0"），BimCraft 会将文件中的数值写回。其他数值按文件中的原样显示。
- 空值显示为*空*。已编辑的值以粗体显示，旁边带有蓝色竖条。

## 复制值

{{ui:特性}}中的每个值旁边都有一个小的复制按钮：点击即可将该值按显示内容原样复制到剪贴板，例如 GlobalId、序列号或任何属性集的值。复制操作不会开始编辑。

顶部的{{ui:全部复制}}会按属性集逐一将构件的所有值以文本形式复制；{{ui:复制为CSV}}会将其按分组、属性和值的行复制，便于粘贴到电子表格中；空值保留，使每个字段都有一行。打开的其他模型中的构件同样适用；当打开多个模型时，CSV 以“Model”列开头，列出其所属文件。

## 文件面板（IFC）

| 字段 | 含义 |
|---|---|
| 文件、大小 | 已打开的文件 |
| Schema | IFC 版本，例如 IFC2X3 或 IFC4 |
| 项目 | 项目名称及其全称 |
| 阶段 | 项目阶段（若导出程序已写入） |
| 导出自 | 文件头中记录的导出程序 |
| 作者 | 文件头中的作者 |
| 导出时间 | 文件头中的日期和时间 |
| 构件 | 绘制的带有形状的构件数量 |
| 三角形 | 其形状构成的三角形数量，用于衡量模型的复杂程度 |

## 文件面板（项目和族文件）

| 字段 | 含义 |
|---|---|
| 类型 | 项目、项目样板、族或族样板 |
| 保存版本 | 最后保存该文件的版本 |
| 构建号 | 该版本的具体构建 |
| 读取量 | BimCraft 读取的文件量及文件总大小 |

## 图形面板（DWG 和 DXF）

| 字段 | 含义 |
|---|---|
| 格式 | 图形保存的版本及其格式代码，例如 AC1032 |
| 单位 | 图形的插入单位（若已设置） |
| 实体 | 读取的对象数量 |
| 图层 | 图层数量 |
| 布局 | 布局数量，或无 |
| 外部参照 | 找到并加载的外部参照数量 |
| 设备 | 布局中带标记的设备数量 |

## 文件夹面板

| 字段 | 含义 |
|---|---|
| 文件夹、文件、大小 | 已打开的文件夹、其中包含的文件数量及总大小 |
| 模型 | 项目和族文件，每个文件的备份只计算一次 |
| CAD 图形、IFC 模型 | 各自的数量 |
| 问题 | 不完整或无法读取的模型副本数量，或无 |
