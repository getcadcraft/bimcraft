## 操作内容

使图形完整：显示其链接的图形（外部参照，即 xref）以及其所用的图像，例如标题栏中的徽标。

## 简便方法：打开文件夹

1. 点击{{ui:Open a folder}}，选择包含该图形及其链接文件的文件夹，例如某个项目的整个 `Cad` 文件夹。
2. 在文件夹报告中，滚动至**CAD 图形**。
3. 点击该图形。
4. 查看右侧{{ui:Properties}}面板中**链接图形**和**图像**下的内容。

BimCraft 按名称（“*name*.dwg”）查找每个链接图形，先在与该图形相同的文件夹中查找，然后再在所打开文件夹的任意位置查找。图像的查找方式相同，并且也会按相似名称查找：eTransmit 或 Revit 导出时通常会在名称前添加项目名称，因此 `logo.png` 会被识别为 `Tower-logo-5425051.png`。

## 另一种方法：手动添加文件

1. 单独打开该图形。
2. 在右侧**链接图形**下，点击{{ui:Add linked drawings…}}。在**图像**下，按钮为{{ui:Add pictures…}}；两者都会打开同一个选择器。
3. 选择链接的 `.dwg` 文件和图像文件。可一次选择多个。
4. 等待 BimCraft 使用这些文件重新打开图形。

## 应看到的内容

每个链接图形和图像都会附带以下标签之一：

| 标签 | 含义 |
|---|---|
| **已显示** | 已找到并绘制。其下方的路径表示来源，或显示“手动添加”。 |
| **已显示，名称相似** | 按相似名称找到的图像。请确认其正确。 |
| **未找到** | 不在文件夹中，也不在所添加的文件中。缺失的图像显示为空白框。 |
| **浏览器无法显示 TIFF** | 该图像为 TIFF 文件，浏览器无法绘制。请将其以相同名称另存为 PNG 并添加。 |
| **无法读取** | 已找到文件，但无法作为图像打开。 |

左侧的{{ui:Drawing}}面板会以“*n* / *m* 已加载”的形式显示链接图形的加载情况。链接图形的图层会以“*link name*|*layer*”的形式出现在{{ui:Layers}}中。

## 常见错误

- **只打开了图形。**“此图形在添加其链接图形之前只显示自身内容。打开整个项目文件夹即可自动找到这些图形。”
- **打开的文件夹范围过小。**若链接位于同级文件夹中，请改为打开父文件夹。
- **链接已重命名。**BimCraft 按名称匹配链接图形。在磁盘上重命名的链接将无法找到；请手动添加。
- **链接的链接。**BimCraft 会加载当前图形所链接的图形。这些图形内部再链接的图形不会被查找，因此在此版本中通常不会显示。
