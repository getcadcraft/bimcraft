## 打开编辑器

打开一个族（项目浏览器中的 **族**，或 {{ui:构建}} › {{ui:族…}}），然后单击 {{ui:编辑族}}。要从零开始，请单击 {{ui:新建族}}：为其命名，说明它是什么（门、窗、家具、固定装置或其他），对于门或窗，还需选择其平面符号和把手来自哪个入门族。编辑器会打开一个包含若干参数和一个实体的族。

编辑入门族的更改仅保存在此模型中；其他模型保持入门族不变。

在单击 {{ui:保存族}} 之前，模型不会有任何变化。编辑器有自己的撤销和重做（名称旁边的箭头按钮，或 {{key:Mod+Z}} 和 {{key:Mod+Y}}）；保存则作为模型撤销中的一步。

## 参数

{{ui:参数}} 选项卡列出族的参数：名称、类型和默认值。类型包括：**长度**（毫米）、**角度**（度）、**数字**、**整数**、**是/否**、**笔号**（1–16），以及三种保存文字而非数字的类型：**文本**、**材料**（项目中的一种材料）和 **填充**（平面填充）。文字不用于公式；它们用于为实体着色（其 **材料**）、填充符号的部件，或以 `{Name}` 形式打印在符号文本中。**按构件** 复选框使每个已放置构件可为自身设置该参数，而不是按尺寸设置。

- **公式** 使参数随其他参数变化，例如 `Width / 30` 或 `if(Width > 1200, 2, 1)`。公式中的长度以毫米计，也可写明单位：`3'`、`6in`、`50cm`。
- 重命名参数会在使用它的每个公式和字段中同时重命名。仍在使用的参数无法删除。
- 实体的 **材料** 采用项目材料的颜色（或材料参数的颜色）；**显示于** 可在较粗略的详细程度下隐藏它；**重复** 用于生成副本：指定数量（数字或整数参数，1 至 200）以及它们在 x、y、z 方向上的间距。重复的实体即一排木板、杆件或孔洞；用于剪切时，副本将一同被剪切。
- 门或窗族还会从其墙体获得两个名称：`WallThickness` 和 `Face`（1 或 −1，即门开启的一侧）。

## 实体

{{ui:实体}} 选项卡列出实体。可添加长方体、拉伸体、旋转体或扫掠体：

| 实体 | 需设置的内容 |
|---|---|
| 长方体 | 其两个角点：x0 至 x1，y0 至 y1，z0 至 z1 |
| 拉伸体 | 工作平面（平面、正立面或侧立面）上的轮廓、平面所在位置以及深度 |
| 旋转体 | 轮廓、平面上的轴线，以及最大为 360° 的角度 |
| 扫掠体 | 点的路径以及半径（杆或导轨） |

每个数值既可以是输入的数字，也可以是参数的表达式。每个实体都有颜色和 **显示条件**：留空则始终显示；或指定一个是 / 否参数（或写出比较式，如 `Shelves >= 3`），使其仅在该条件下显示。这就是可见性参数。

### 绘制轮廓

拉伸体或旋转体的轮廓绘制在预览下方的工作平面上：

- 单击图纸可在所选点之后添加一个点。
- 拖动点可移动它。点会捕捉到栅格；按住 {{key:Shift}} 可自由放置。
- 单击线段上的小方块可在该处添加一个点。按 {{key:Shift}} 并单击该方块，可将该线段设为圆弧（再次单击可切换方向，然后切换为直线）。
- 双击某个点可将其删除。

空心点由参数设置：请在表格中修改，而非拖动。

## 布尔运算

{{ui:布尔运算}} 选项卡用第二个实体从第一个实体中剪除，或将两者合并。布尔运算的结果可以再次剪切或合并。用于布尔运算的实体仅作为其一部分绘制。

当第二个实体因其是 / 否参数而隐藏时，保留第一个实体不变；当第一个实体被隐藏时，结果也隐藏。

## 平面符号

{{ui:平面符号}} 选项卡绘制该族在平面图中的显示效果，而不是其实体的剖面：在族自身坐标轴中绘制线、矩形、圆、圆弧、多边形和文字。每个部件都有一个 **笔号**（1–16，表达式或笔号参数）、一个 **填充**（无、实心、斜线、交叉线、混凝土、保温、土壤，或填充参数）、一个 **显示条件** 表达式、以基准面以上毫米为单位的 **剖切范围**（当平面剖切位于其内时以全粗绘制，位于其下方时以细线绘制，位于其上方时以虚线绘制：位于剖切面以上的柜子显示为虚线）、一个详细程度以及重复设置。文字可用 `{Name}` 引用参数。**平面显示：实体的剖切** 使平面继续显示实体的剖切，而符号仍保留在族中。其他程序将该符号读取为族的占地范围（线条和形状；文字仅保留在 BimCraft 中）。

## 内嵌族

{{ui:内嵌族}} 选项卡将另一个族放入此族中：例如桌子中的桌腿，或门上的把手。选择族，然后设定其位置（x、y、z）、旋转角度（仅限四分之一圈：0、90、180、270）、显示条件，以及其接收的值（每行一个，格式为 `Height = Height - 40`）。保存内嵌族会重新绘制此族；被其他族引用的族无法删除；族不能包含自身，即使通过其他族间接包含也不行，且嵌套最多四层。

## 热点

热点是您拖动以更改参数的点或边。在 {{ui:热点}} 选项卡中添加热点，选择其拖动的轴以及它所更改的数字参数，并以与实体相同的表达式写出其位置。在预览中，选择手柄下方的 **热点** 即可拖动它们。在平面图中选中的已放置构件（使用 {{ui:选择}} 选中）上，x 和 y 热点显示为夹点：拖动其中一个，构件会取得使热点位于该处的尺寸，并经过两者之间的所有公式；一次撤销即可恢复。热点不能更改由公式驱动的参数、是 / 否参数或文字。

在三维视图中，相同的热点在选中的构件上显示为夹点，上下方向的热点（z 轴）也会显示在那里，这是平面图无法绘制的。选中构件，沿其轴拖动夹点并松开：构件会取得使热点位于该处的尺寸，作为一步撤销。开启剖面框时夹点会隐藏，因为两者使用相同的夹点。

## 连接件

放置在地面上的族（家具、固定装置及其他）有一个 {{ui:连接件}} 选项卡：管道或风管与构件相连的点，例如洗脸盆的水龙头和排水口。单击 {{ui:添加连接件}} 并设置：

- **类型**：管道或风管，及其 **系统**（冷水、污水排水、送风等）。
- **x**、**y** 和 **z**：其位置，位于族自身的坐标轴中。与实体的数值一样，每项可以是数字或参数的公式，因此连接件会随尺寸移动。
- **出口方向**：管道或风管离开的方向，沿族的一条坐标轴（洗脸盆下方的排水管为 **向下**）。
- **尺寸 (mm)**：管道的公称尺寸（DN）或圆形风管的直径。
- **流向**：**输入** 表示被供给的连接件（如水龙头），**输出** 表示排出的连接件。

预览会将每个连接件绘制为一个带有出口方向箭头的圆环。门和窗没有连接件。

对于卫生洁具，请在 **卫生洁具** 下选择其类型（坐便器、洗脸盆、厨房水槽、淋浴、洗衣池）。入门固定装置已注明其类型。

从该族放置的每个构件都会在 IFC 文件中获得其连接件作为端口，并在构件尺寸改变或保存族时重新生成。读取 IFC 系统的程序可看到每根管道或风管所属的位置。

## 预览及其手柄

预览是以 IFC 格式写出的族，由保存到模型中的相同代码生成，再绘制回来。所见即其他程序所获得的内容。预览下方的 **显示尺寸** 设置预览所用的参数值。

**手柄** 是预览上的圆点：**尺寸** 为宽度、深度和高度显示手柄；**所选实体** 则在所选实体的每个面上显示一个手柄。拖动手柄：

- 对于由参数设定的面，所显示的尺寸会随之更改（保留族的公式）；
- 对于由输入数字设定的面，该数字会更改。

## 保存

{{ui:保存族}} 会检查族，然后重新绘制它的每个尺寸并重新生成其每个构件，作为一步可撤销的操作。如果某个尺寸无法随此更改绘制（例如某实体在该尺寸下宽度为零），则不会保存任何内容，编辑器会指出是哪个尺寸。

如果在编辑器打开期间，其他人保存了同一族（在实时协作会话中，或在另一个窗口中），{{ui:保存族}} 会拒绝保存并说明原因，而不会用当前的更改覆盖对方的更改。关闭编辑器，重新打开族以查看对方的更改，然后重新进行修改。

:::note
几何体以 IFC 自带的实体形式保存：拉伸体、旋转体、扫掠圆盘和布尔运算结果。不会转换为三角面列表，因此文件较小，其他程序也可将形状作为形状读取。包含圆弧的轮廓在 IFC4 中以圆弧保存；IFC2X3 的轮廓不支持圆弧段，因此在该格式中圆弧会被保存为短直线段。
:::
