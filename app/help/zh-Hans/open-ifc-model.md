## 操作内容

打开 IFC 模型，在三维中环视，并跳转到标准视图。约需五分钟。

需要一个 `.ifc` 文件。大多数 BIM 程序都可以导出该文件；在 Revit 中为**文件 > 导出 > IFC**。参见[通过 IFC 将项目文件转为三维](topic:rvt-to-ifc)。

## 步骤

1. 点击{{ui:选择文件}}（或左上角的拖放区域）。
2. 选择 `.ifc` 文件并确认。
3. 等待状态栏完成。首次会显示“正在启动 IFC 引擎…”，然后显示“正在读取模型…”和“正在生成几何图形：… / … 个构件”。
4. 查看模型：它以四分之三视图打开，并适合屏幕大小。
5. 点击模型上方工具栏中的{{ui:顶}}，以垂直向下查看。
6. 点击{{ui:前}}查看正面，然后点击{{ui:侧视}}从侧面查看。
7. 点击{{ui:适合}}或按{{key:F}}，返回整个模型的四分之三视图。

## 应看到的效果

- 模型位于中央，带有细的深色边线，呈现类似图纸的外观。
- 左侧的{{ui:文件}}面板：文件名、大小、IFC 架构（例如 IFC2X3 或 IFC4）、项目名称、阶段、导出程序、作者、导出日期，以及构件和三角形的数量。
- 其下方的{{ui:楼层}}和{{ui:构件}}列表。
- 状态栏显示：“已打开 *文件名*：*n* 个构件，耗时 *s* 秒”。

## 移动视图

:::mouse
| 目标 | 操作 |
|---|---|
| 环绕 | 按住左键拖动 |
| 平移 | 按住右键拖动，或按住{{key:Shift}}（或{{key:Mod}}）并用左键拖动 |
| 缩放 | 滚动滚轮，或用中键拖动 |
| 查看全部 | 按{{key:F}}或点击{{ui:适合}} |
:::

:::mac mouse
在触控板上：单指按住拖动可环绕；按住{{key:Shift}}或{{key:Mod}}并拖动可平移；双指滑动或捏合可缩放。双指点击即为右键点击，也可用它拖动以平移，但{{key:Shift}}加拖动更方便。
:::

:::touch
| 目标 | 操作 |
|---|---|
| 环绕 | 单指拖动 |
| 缩放 | 双指捏合 |
| 平移 | 双指一起移动 |
| 查看全部 | 点击{{ui:适合}} |
:::

环绕始终围绕模型中部的一个点进行。平移会移动该点，因此长距离平移后环绕可能显得偏离中心：点击{{ui:适合}}即可重置。

## 着色、边线或线框

视图立方体上方的三个小按钮用于选择模型的绘制方式：{{ui:着色}}、{{ui:带边线着色}}（默认）和{{ui:线框}}。它们也是命令（位于菜单中的{{ui:视图}}和“自定义”列表中），因此可以设置各自的快捷键。{{ui:平面}}、{{ui:拆分}}和{{ui:三维}}位于工具栏的{{ui:视图}}行中。

## 常见错误

- **期望使用命名视图。** BimCraft 有四个固定视图（{{ui:适合}}、{{ui:顶}}、{{ui:前}}、{{ui:侧视}}）、右下角的视图立方体以及自由环绕。它不保存视图。
- **查找平面图和剖面。** 本版本中没有二维平面图或剖面框。使用一个{{ui:剖切}}平面剖切模型（[用剖切平面剖切 IFC 模型](topic:section-plane)），或关闭楼层显示：[显示和隐藏楼层、空间和边线](topic:storeys-and-spaces)。
- **打开项目文件并期望看到三维。** 项目文件会以文件卡片形式打开。请先导出 IFC。
- **打开 `.ifczip`。** 请解压缩，或导出普通的 `.ifc` 文件。
- **模型过大导致标签页变慢或崩溃。** 参见[浏览器、设备和内存](topic:platforms)。
