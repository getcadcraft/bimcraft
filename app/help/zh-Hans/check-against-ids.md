## 操作内容

IDS（Information Delivery Specification，buildingSMART 标准）列出 IFC 必须包含的内容：哪些类别、哪些属性及其取值、分类、材料，以及各构件应归属的位置。客户和公共采购方会随项目一并提供 IDS。BimCraft 会按 IDS 检查打开的 IFC 模型，并列出每个未达标的构件。

## 步骤

1. 打开一个 IFC 模型。
2. 在左侧面板中，于{{ui:Model checks}}下打开{{ui:Check against an IDS}}，或在所选菜单样式的菜单中选择{{ui:Check against IDS…}}。
3. 点击{{ui:Load an .ids file…}}并选择文件。文件不会被上传。
4. 查看结果：每条规范会显示{{ui:Pass}}或{{ui:Fail}}，以及它适用于多少个构件。
5. 打开问题面板（{{key:Ctrl+Shift+M}}），点击某个未通过项，即可选中该构件并缩放至它。

## 应看到的结果

- 每个构件每不满足一项要求，就有一条警告，包含规范名称、IDS 的要求以及构件的实际取值。
- 模型中没有任何构件匹配的必需规范，会单独产生一条警告。
- 检查报告（位于问题面板中）开头列出 IDS 的标题、版本和作者，以及每条规范适用、通过和未通过的构件数量。

## 注意事项

- IFC 仅保存对 IDS 的引用（其名称、标题、版本和哈希值），不保存 IDS 本身：客户的 IDS 可能属于保密内容，而 IFC 会发送给其他人。IDS 保存在本浏览器中，与模型放在一起，因此在此处再次打开已保存的 IFC 时会重新检查。加载或移除 IDS 都是一步操作，可以撤销。
- 在其他计算机或其他浏览器中打开时，问题面板会提示未找到 IDS：重新加载即可再次检查。
- 若要将 IDS 随 IFC 一同发送，请在加载之前，于“设置”的“BimCraft”选项卡中开启{{ui:Keep the IDS inside the IFC}}。
- 每次编辑、撤销和重做后，都会稍后重新检查。
- 取值按 IDS 的方式比较：文本严格比较（区分大小写），数值以 SI 单位比较并允许微小误差（长度以米计，因此毫米制模型需先换算）。
- 为其他 IFC 版本编写的规范（例如模型为 IFC4 时使用 IFC2X3 的规范）仍会检查，结果中会注明。
- 若 IDS 文件存在 IDS 审核会标记的问题，对话框会列出这些问题，所在规范将判定为未通过。
- 与其他问题一样，可以为某个未通过项附上原因并予以接受。只要构件的取值保持不变，该接受状态就会保留。

- IDS 中的模式按整个值读取。开头的 `^` 和结尾的 `$` 同样视为“整个值”，这也是大多数 IDS 文件的本意。
