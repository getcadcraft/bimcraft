BimCraft 是 CadCraft 系列中的建筑模型应用。在此版本中，它可以**打开、读取和检查**建筑文件，并**编辑 IFC 模型中的数据**。它还不能绘制或创建新构件。可以把它看作模型查看器和检查器，同时允许你更正 IFC 文件中的名称、标签和属性值。

它可以打开的内容：

| 文件 | 你得到什么 |
|---|---|
| IFC（`.ifc`） | 完整的三维模型：环绕、楼层、构件属性，以及名称和属性值的编辑 |
| 项目和族文件（`.rvt`、`.rfa`、`.rte`、`.rft`） | 一张文件卡片：保存时的版本、项目信息、预览图片和链接文件。没有三维。 |
| DWG 和 DXF | 二维图形：模型空间和每张布局、图层、外部参照图形、打印视图，以及带标记的餐饮设备图形的设备明细表 |
| 项目文件夹 | 文件夹中每个模型的报告：备份、链接、损坏的副本，以及从哪个文件开始的建议 |

一切都在你的浏览器中、在你的电脑上完成。**不会上传任何内容。**详情参见[BimCraft 可打开和保存的文件](topic:files)。

## 打开 BimCraft

1. 在最新的浏览器中打开 BimCraft。Chrome、Edge、Firefox 和 Safari 都可以使用；[浏览器、设备和内存](topic:platforms)列出了差异。
2. 等待出现写着“打开建筑模型。”的空白屏幕。

:::note
BimCraft 在浏览器中运行，在桌面上则与其他应用一起在 CadCraft Studio 内运行。云端保存尚不可用：你从自己的电脑打开文件，并将副本保存回电脑。
:::

## 打开第一个模型

了解 BimCraft 功能的最快方法是使用 IFC 文件。

1. 点击屏幕中间的{{ui:选择文件}}。
2. 在{{pick:mac=访达|windows=文件资源管理器|linux=文件管理器}}中选择一个 `.ifc` 文件并确认。
3. 等待屏幕底部的状态行先显示“正在启动IFC引擎…”，然后显示“正在生成几何”。

你应该看到中间是三维模型，左侧是{{ui:文件}}面板和{{ui:楼层}}列表，右侧是空的{{ui:特性}}面板。状态行末尾显示“已打开”和构件数量。

:::tip
你也可以将文件从{{pick:mac=访达|windows=文件资源管理器|linux=文件管理器}}直接拖到页面上。拖动时屏幕显示“松开即可打开”。
:::

:::offline
第一次打开 IFC 模型时，IFC 引擎会从网站加载，除非 BimCraft 已保存供离线使用。DWG 和 DXF 图形、项目文件和文件夹不需要任何额外内容：它们的读取器是应用的一部分。如果应用栏上的按钮显示{{ui:离线可用}}，则所有内容都能离线打开。否则，除非此标签页中已打开过 IFC 模型，否则在重新联网之前 IFC 模型无法打开。参见[在线和离线](topic:online-offline)。
:::

:::online
要去没有网络的地方？点击应用栏中的{{ui:保存以供离线使用}}，并等待显示{{ui:离线可用}}。保存的副本（约 11 MB）包含 IFC 引擎。参见[离线工作](common:offline)。
:::

## 四处查看

:::mouse
1. 按住鼠标左键拖动，围绕模型环绕。
2. 滚动滚轮缩放。
3. 按住鼠标右键拖动平移。在 Mac 触控板上，改为按住{{key:Shift}}并拖动。
4. 按{{key:F}}或点击{{ui:适合}}重新查看整个模型。
:::

:::touch
1. 单指拖动进行环绕。
2. 双指捏合缩放，双指一起移动平移。
3. 点按{{ui:适合}}重新查看整个模型。
:::

## 做一件实际的事：修正标签

1. 点击模型中的墙、门或任何构件。它变为蓝色，其属性显示在右侧。
2. 在{{ui:特性}}面板中，点击**标签**旁边的值。
3. 输入新的标签并按{{key:Enter}}。
4. 查看左侧展开的{{ui:更改}}部分：你的修改连同旧值和新值都列在其中。

## 保存副本

1. 点击{{ui:更改}}部分中的{{ui:另存为IFC}}，或按{{key:Mod+S}}。
2. 在下载文件夹中找到新文件。它以原文件名命名并加上“ (edited)”，例如 `Clinic (edited).ifc`。

你的原始文件从不会被修改。[修改 IFC 属性并保存编辑后的副本](topic:edit-ifc-properties)对编辑有完整说明。
