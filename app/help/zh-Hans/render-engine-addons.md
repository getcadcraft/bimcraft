插件（设置 › 插件）可以在 {{ui:Render}} 的引擎列表中添加一个引擎。面向插件作者的完整说明见插件规范第 16 节；简要如下：

- 插件注册一个引擎，其 id 以插件自身的前缀开头，并包含名称、可选的设置，以及**要么**一个要运行的程序，**要么**一个在 JavaScript 中绘制图像的函数。
- 运行程序的引擎需要 **`engine.run`** 权限，该权限会在安装前和设置中显示。它只在 Studio 中运行；在浏览器中则显示为一个可保存的文件。
- 插件需指定程序（仅为普通文件名，绝不使用 shell）、**位于已签名插件内**的脚本，以及由占位符和普通词语组成的参数。Studio 会查找该程序，或请你指定一次其位置。
- 插件第一次运行程序时，**Studio 会在其自身的对话框中询问你**：哪个插件、哪个程序，并说明脚本可以执行程序能做的任何操作。只对你信任的插件允许此操作。你的选择会针对该插件和该程序被记住。
- 打包内容（场景的 USD 及设置文件，若插件要求则包含 glTF 文件）和插件的脚本会放入一个全新的临时文件夹，程序在该文件夹中运行，结果图像返回时会标注为该插件的引擎名称。

:::note
插件只能从插件 API 1.4 开始添加渲染引擎。一个面向开源命令行渲染器的完整示例位于其自身的代码仓库中；该示例尚未在该渲染器中运行过。
:::
