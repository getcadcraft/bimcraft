## 任务概述

同一场地的多次扫描（每次在各自的扫描仪位置）最初各自使用自己的坐标。配准就是为每次扫描指定一个放置位置，使它们都处于同一坐标框架中；然后将其保存为项目，并把配准后的点云写入为一个 LAS 或 E57 文件。

## 放置扫描

1. 打开对话框（起始面板上的 {{ui:Register scans…}}，或在打开模型后选择 {{ui:Show}} › {{ui:Register scans…}}）。{{ui:Add scans…}} 可添加 LAS、LAZ、E57、PLY、PCD、PTX、PTS 或 XYZ 文件，也可将文件拖放到对话框上。单位不同的扫描会被拒绝并给出提示：需先转换其中一个。
2. 选择 {{ui:Scan to move}} 和 {{ui:Place against}}。图中以每个扫描一种颜色显示当前位置下的全部扫描，视图可为 {{ui:Plan}}、{{ui:Front}} 或 {{ui:Side}}；拖动可平移，滚轮可缩放。
3. **按点对。** 点击 {{ui:Pick a pair}}，然后在待移动的扫描上点一个点，再在另一扫描的同一位置上点一个点（例如一个角点、一个目标、一根柱的底部）。至少重复三次，所选的点不能位于同一直线上，且应尽量分散。点击 {{ui:Place by pairs}}：扫描将通过最小二乘拟合放置，**剩余偏差** 显示每一对仍存在的偏差。数值较大的点对是错误的拾取：用叉号将其移除后重新放置。
4. **按目标。** 若某点的真实坐标已知（例如测量的目标点），点击 {{ui:Pick, then type target}}，在其扫描上点击该点，然后在该行中输入目标的 X、Y 和 Z。点对与输入的目标可以自由混用。

## 使用 ICP 精配准

点对给出粗略的放置。{{ui:Refine}} 会移动扫描，直至其表面与另一扫描的表面贴合：先按 **点到点**，再按 **点到面**。表格列出每一步的误差和匹配的点数；其上方的线条显示误差逐步下降。{{ui:Stop}} 会在当前步骤结束后终止运行，并保留已达到的结果。{{ui:Undo}} 会撤销整个运行（或最后一次放置）；{{ui:Reset}} 会将扫描恢复到其文件坐标。

为了在笔记本电脑上保持速度，ICP 只使用部分点（{{ui:Points used}}，5,000至60,000），并忽略超过 {{ui:Largest match distance}} 的匹配（默认为扫描尺寸的 5%，随收敛逐渐缩小）。它需要先有粗略的放置：几乎不重叠的扫描会报告无法匹配。仅为平面或仅为直线的表面无法沿其自身方向确定位置；此时请添加点对。

## 保存与导出

- {{ui:Save project}} 会写入一个较小的 `.ccscans.json` 文件：包含每个扫描的名称、尺寸，以及其前 64 KB 的指纹，并附带其变换。文件中不包含点。{{ui:Open project…}} 会根据这些引用找到扫描文件（文件必须先添加），并恢复每一个变换。
- {{ui:Export LAS}} 和 {{ui:Export E57}} 会将所有扫描按其配准位置写入一个文件。原始文件中的点不会被改写；变换在输出时应用。开启 {{ui:Read every point from the files}} 时，每个文件会为每个点重新读取（每个扫描最多 2,000 万个点）；关闭时，只写入查看器中显示的点。
- {{ui:Show registered cloud}}（BimCraft）会写入 LAS，并像其他点云一样在模型旁边的三维视图中打开。

:::note
未上传任何内容。配准在文件自身的单位下进行，并保留毫米精度：LAS 以能容纳的比例写入（精度可达 0.1 mm），E57 以双精度写入。只有当所有扫描都指定了相同的 EPSG 代码时，坐标系才会写入 LAS。E57 写入器为自研；其文件已通过本读取器和 libE57Format 读回检查。
:::
