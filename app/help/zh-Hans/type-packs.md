## 操作内容

将墙体类型从一个项目带到另一个项目，或交给使用其他程序的人员。类型包保存每个墙体类型，包括其层、厚度、材料、核心、空腔、层优先级、开发等级、工程量数据和分类代码，以及您添加的任何族。它是一个开放文件：任何人都可以阅读的纯 JSON 文本，或一个 IFC 文件。其中的内容不会绑定到某家公司、某个国家或某个账户。

## 从项目中保存类型

1. 在模型栏中打开**数据**，然后选择{{ui:Type packs}}。
2. 在{{ui:Save types from this project}}下，勾选要放入的墙体类型。项目自身的类型默认已勾选；可以添加入门类型，它将以副本的形式放入。若要包含族，请勾选族。
3. 输入{{ui:Pack name}}。
4. {{ui:Save as a pack (.json)}}会下载一个`.cctypes.json`文件。{{ui:Save as IFC (.ifc)}}会下载一个仅包含类型的IFC文件：每个墙体类型为一个IfcWallType，并带有其材料层集、材料和分类，可供任何BIM程序使用。

## 将类型添加到项目

1. 在同一对话框中，选择{{ui:Open a pack or an IFC file…}}，然后选取一个`.json`包或`.ifc`文件。
2. 对话框会列出该文件包含的内容：每个墙体类型及其厚度、层数和代码、材料和族。
3. 选择如何处理{{ui:A type this project already has}}：**保留项目的**、**将包中的类型作为副本添加**（它会获得一个以“(2)”结尾的新名称），或**替换（仅当没有墙体使用它时）**。
4. {{ui:Add to the project}}。对话框会列出已添加、已复制、已替换或已保留的内容。这是一个撤销步骤。

新类型会立即出现在墙体工具的类型列表中。

## 楼板、屋顶和天花板类型

要保存的类型列表还包括项目的楼板、屋顶和天花板类型及其入门类型（标记为“楼板”、“屋顶”、“天花板”）。一个包可以携带全部四种类型；每个类型都指明其IFC类（IfcWallType、IfcSlabType、IfcCoveringType）。构件正在使用的楼板、屋顶或天花板类型不会被包替换：请在类型编辑器中更改它。

## 将一个类型保存为库项目

仅勾选一个类型，然后选择**保存为库项目…**。它会保存一个`.cctype.json`文件：一个“类型”类别的库项目，包含该类型（其层、材料、开发等级和分类代码）。在库中上传它即可共享。**打开包或IFC文件**同样可以读取此类项目，并像包一样将其类型添加到项目中。

## 注意事项

- 来自其他程序的IFC文件也可以在此打开。其中每个带有材料层的墙体类型都会被读取：名称、各层的材料和厚度以及任何空腔均取自该文件本身。哪些层为核心，以及每层的作用（饰面、结构、保温）是推测的；该类型会标记为**（推测）**，您应在墙体类型编辑器中进行检查。没有任何层的墙体类型会被略去，并会注明名称。
- 项目已有的材料会保持原样。名称已被占用的新材料，会在其名称后添加 (pack)。
- 墙体正在使用的类型绝不会被包替换。请在墙体类型编辑器中更改它，编辑器会妥善移动其墙体。
- 在一面墙上设置的代码不会随包传递：它属于该墙。在类型上设置的代码会传递。
- 包含格式不支持的字段、材料缺失的层，或任何非纯文本内容的文件会被拒绝，消息会说明位置和原因。
- 尚未实现：楼板、屋顶和天花板类型（在此版本中它们没有类型：每个都有自己的厚度）、除族之外的门和窗类型，以及来自其他程序文件的图案填充或颜色。
