## 可在此打开的格式

使用{{ui:未解决}}打开这些文件，或将其拖放到页面上（请参阅关于在模型旁显示点云的主题）：

| 格式 | 扩展名 | 读取内容 |
|---|---|---|
| LAS、LAZ | `.las`、`.laz` | LAS 1.0–1.4：点、颜色、强度、LiDAR 类别和坐标系。LAZ 最大 1 GB。 |
| E57 | `.e57` | 文件中的每次扫描，均按其位姿放置；读取颜色，文件无颜色时读取强度。文件中的图片会被忽略（会有提示）。目前最多 600 万个点、512 MB：更大的扫描请导出为 LAS 或 LAZ。 |
| PLY | `.ply` | 文本和二进制（两种字节序）：顶点的 x y z、颜色和强度。面会被忽略（会有提示）。 |
| PCD | `.pcd` | 文本和二进制：x y z、打包或分开存储的颜色、强度。压缩的 PCD 文件暂不读取：请保存为二进制或文本格式。 |
| PTX | `.ptx` | 一次或多次扫描，每次按其自身的变换放置；扫描仪未测量的点会被忽略。单位为米。 |
| PTS、XYZ | `.pts`、`.xyz` | 文本：x y z，列存在时包含强度和颜色。 |

## 仅能由扫描仪软件读取的文件

部分扫描文件是扫描仪厂商自有的格式，没有公开的说明，也没有开放的读取器。BimCraft 无法读取这些文件，打开时会显示一张卡片，说明文件类型及处理方法。请用厂商的软件将扫描导出为 E57 或 LAS（或 PTX、PTS），然后打开导出的文件。

| 文件 | 扩展名 | 导出方式 |
|---|---|---|
| ReCap 项目 | `.rcp` | ReCap：打开该项目并导出。项目文件只指向其扫描数据，因此仅复制 `.rcp` 无法得到任何点。 |
| ReCap 扫描 | `.rcs` | ReCap：打开该扫描所属的项目并导出。 |
| FARO 扫描 | `.fls` | FARO SCENE。 |
| Leica 扫描 | `.lgs` | Leica Cyclone REGISTER 360。 |
| Trimble 扫描 | `.tzf` | Trimble RealWorks 或 Trimble Business Center。 |
| Z+F 扫描 | `.zfs` | Z+F LaserControl。 |

:::tip
导出时选择格式，LAS 或 LAZ 可以用最小的文件保留 BimCraft 显示的全部内容（颜色、强度、类别和坐标系）。
:::

## 为何这些文件无法读取

这些格式没有公开，读取它们的唯一方式是使用各厂商自己的软件库，并遵循其各自的条款。BimCraft 只读取能用其自有代码在本机上读取的格式，因此打开扫描时无需将其发送到任何地方。
