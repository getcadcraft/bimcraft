## 你将完成的操作

根据屋顶下方的墙体来塑造屋顶。每面墙都有自己的设置，因此同一个屋顶可以在前面做成四坡、在两端做成山墙，并在后面平齐地贴住较高的墙体。对于门廊或自动屋顶无法生成的任何面，请通过其角点绘制屋面坡面。

## 添加屋顶

1. 在屋顶所依附墙体所在的楼层上，点击{{ui:屋顶}}。
2. 输入 **坡度**（`6/12`，或 `30` 之类的角度值，单位为度）和 **挑檐**。
3. 选择预设：**四坡屋顶**、**短边设山墙**、**长边设山墙**，或 **单坡**（离指针最近的一侧为低檐口，其他侧为山墙端）。
4. 如需带封檐板的封闭檐口，保持 **封檐板和檐底板** 勾选；如需裸露的屋顶边缘，则取消勾选。
5. 在建筑内部指向：檐口、屋脊、斜脊和天沟会显示在平面图上。然后点击。

任何轮廓都适用：L 形、T 形、U 形和十字形、倾斜转角以及缺口。斜脊、屋脊和天沟在屋面坡面相交处自动确定。

## 逐面墙设置

选择屋顶（在墙体上方的楼层上，点击其轮廓内部），然后在 **特性** 中查看 **每面墙** 下的设置。将指针指向某一行会在平面图上标示该面墙。

- **坡屋面**：该墙体上方有一个倾斜的屋面。在其旁边输入该墙自己的坡度，例如在 `6/12` 的屋顶上为陡峭的山墙端输入 `12/12`。
- **山墙端**：屋顶在该墙上方止于一个垂直的端面，墙体一直砌至屋面，屋顶会沿 **山墙挑檐** 越过该墙。
- **无（齐平收头）**：屋顶在该墙处止住，没有挑檐也没有山墙墙体，适用于屋顶紧贴较高墙体的情况。

顶部的 **端部** 列表可一次性设置所有墙体；当墙体不再与某个预设一致时，会显示 **逐墙设置**。

## 修改已添加的屋顶

选择屋顶后，**特性** 中会显示屋顶工具中的相同设置：**坡度**、**挑檐**、**山墙挑檐**、**檐口高度**、**封檐板高度**、**封闭檐口** 和 **厚度**。每项更改都会立即在平面图和三维视图中显示，并执行与工具相同的检查（坡度达到或超过 80 度会被拒绝，无法生成屋顶的设置同样会被拒绝）。输入数值后按{{key:Enter}}键，或离开该输入框。

每次更改为一个撤销步骤。对同一输入框连续进行的多次更改（依次输入 `6/12`、`7/12`、`8/12`）会合并为一个步骤，因此按一次{{key:Ctrl}}+{{key:Z}}即可恢复该系列更改之前的屋顶状态；更改其他输入框则会开始新的步骤。

## 檐口高度、封檐板与檐底板

- **檐口高度**是屋面坡面与墙体外侧相交处的高度，自本层楼面量起。留空则屋顶坐于墙顶；输入较大的值可得到抬高的檐口。
- **封檐板高度**是沿檐口及山墙斜边设置的木板高度。输入 `0` 表示不设置。
- **封闭檐口**会在每个檐口下方设置一个水平的檐底板，自墙面延伸至封檐板背面。

每个屋面坡面都在檐口高度处与墙体相交，因此不同坡度的墙体保持同一条檐口线，其檐口端的高度则各不相同，与实际搭建方式一致。

## 绘制屋面坡面

1. 在屋面坡面所依附墙体所在的楼层上，打开{{ui:构建}}，然后选择{{ui:屋面坡面}}。
2. 输入 **坡度**；如果檐口不在墙顶，则再输入 **檐口高度**。
3. 依次点击各角点。绘制的第一条边为檐口，屋面坡面由此向图形其余部分升起。
4. 再次点击第一个角点、双击或按{{key:Enter}}键即可完成。按{{key:Esc}}键放弃已点击的角点。

屋面坡面不跟随墙体。在上一层中选中它（点击其内部），即可更改其坡度、檐口高度或厚度；按{{key:Delete}}键可将其删除。

## 添加老虎窗

1. 显示屋顶所在的楼层。
2. 打开{{ui:构建}}，然后选择{{ui:老虎窗}}。
3. 在选项行中选择 **老虎窗类型**（**山墙式** 或 **单坡式**），并设置 **宽度**、**前墙**（从屋顶顶部至老虎窗檐口的前墙高度）、**坡度** 和 **挑檐**。
4. 在屋面上，点击老虎窗前部中心所在的位置。

BimCraft 会生成前墙、两侧颊墙以及老虎窗屋顶，并将其向后延伸直至与主屋顶相交。山墙式老虎窗有两个在屋脊处相交的坡面。单坡式老虎窗只有一个坡面，且其坡度必须小于主屋顶。老虎窗下方的屋面会被切除。墙体移动时，老虎窗会随屋顶一同调整。

选中老虎窗后，可在 **特性** 中更改其类型、宽度、前墙、坡度或挑檐。按{{key:Delete}}键可删除老虎窗，屋顶随之重新闭合。老虎窗必须位于单个屋面之内，并避开斜脊、天沟和屋脊；只有使用{{ui:屋顶}}工具生成的屋顶才能设置老虎窗，手绘的屋面坡面则不行。尚未实现：老虎窗前部的窗户，以及手绘屋面坡面上的老虎窗。

## 保存的内容

屋顶以 IFC 屋顶的形式保存：每个坡面对应一块屋顶楼板，并包含山墙、一个封檐板构件和一个檐底板覆盖层。屋顶记录其屋脊、斜脊、天沟、檐口和山墙斜边的长度以及面积，供算量使用。屋面坡面是只含一块楼板的 IFC 屋顶。

:::tip
撤销可一步撤回任何屋顶更改，包括会改变每面墙的预设。
:::
