BimCraft 在浏览器标签页中读取计算机上的文件。**不会上传任何内容**到 CadCraft 或其他任何人。保存时，BimCraft 会向浏览器提供一个新文件供下载；它从不覆盖打开的文件。

## 可打开的内容

| 格式 | 扩展名 | 得到的内容 |
|---|---|---|
| IFC | `.ifc` | 三维模型、楼层、构件数量以及每个构件的属性。名称、标记和单个属性值可以修改。 |
| 项目和族文件 | `.rvt` `.rfa` `.rte` `.rft` | 文件卡片：版本、构建号、工作共享、项目信息、族参数、链接文件和预览图片。没有三维模型。 |
| DWG | `.dwg` | 二维图形：模型空间、每张布局、图层、外部参照、图像和打印视图。模型空间也可显示三维。已检验的是 AutoCAD 2000 至 2018 的格式。 |
| DXF | `.dxf` | 与 DWG 相同。 |
| STEP | `.step` `.stp` | 三维零件、一件设备或供应商模型（AP203、AP214、AP242）：每个实体成为一个小型 IFC 模型中的一个构件（建筑构件代理），该模型位于同一楼层，以其真实尺寸作为三角形读取；装配体中的每个零件位于文件所放置的位置。此后与任何 IFC 一样使用：属性、剖面、测量、另存为 IFC。颜色和装配树不会被读取。 |
| 点云 | `.las` `.laz` `.e57` `.ply` `.pcd` `.ptx` `.pts` `.xyz` | 扫描结果显示在三维视图中，可与模型并排或单独显示：参见[在模型旁显示点云](topic:point-clouds)。 |
| 项目包 | `.ccbundle.zip` | 包含视图、布局和属性组的模型：参见[打开项目包](topic:open-project-bundle)。 |
| 文件夹 | 任意 | 列出其中每个模型、图形和项目包的报告。报告中的任何 IFC、模型、图形或项目包点击即可打开。 |

[BimCraft 从各格式读取的内容](topic:file-formats)有详细说明。

BimCraft 通过文件开头的字节以及文件名来判断文件类型，因此扩展名不常见的项目文件仍会以文件卡片形式打开。

### 无法打开的文件

- `.ifczip` 和 `.ifcxml`：BimCraft 会提示“.ifczip 尚不受支持。请将模型保存或导出为普通的 .ifc 文件。”请解压 `.ifczip`（其中包含普通的 `.ifc`），或重新导出为普通 IFC。
- DGN 图形会列在文件夹报告中，但无法打开。
- PDF、图像和办公文件无法单独打开。图像在 DWG 中作为图片使用；{{ui:Build}} › {{ui:From a drawing…}} 可将 PDF 或扫描件的页面转换为墙体：参见[由一组图纸生成墙体](topic:walls-from-plans)。

## 保存的内容

| 点击 | 得到的内容 | 位置 |
|---|---|---|
| {{ui:Save as IFC}} | 包含编辑内容的新 IFC 文件，命名为“*原文件名* (edited).ifc” | 浏览器的下载文件夹 |
| 设备明细表中的{{ui:Download CSV}} | 列表中项目的 CSV，命名为“*图形名称* equipment.csv” | 浏览器的下载文件夹 |

其他内容在生成的位置保存，各有专门的主题：{{ui:USD}}（[将模型导出为 USD](topic:usd)）、{{ui:Collada}}（[将模型导出为 Collada 或用于 Google Earth](topic:collada)）、{{ui:For rendering}}的 .glb、渲染图片、以 PDF 保存的布局和平面图、以 CSV 保存的明细表和列表、BCF 问题、COBie 电子表格、族文件，以及已登记扫描件的 LAS 或 E57 格式。BimCraft 不保存 DWG、DXF 或项目文件，也从不更改打开的文件。

:::chromium
Chrome 和 Edge 将下载内容保存到其设置中指定的文件夹，通常为“下载”。若要在每次下载前询问保存位置，请在浏览器的下载设置中开启“下载前询问每个文件的保存位置”。
:::

:::firefox
Firefox 默认保存到“下载”文件夹，除非在其设置中选择了“总是询问保存文件的位置”。
:::

:::safari
Safari 默认保存到“下载”，除非在 **Safari > 设置 > 通用 > 文件下载位置** 中选择其他文件夹。
:::

## 再次保存

每次保存都会下载整个模型，包含**自打开以来的每一次编辑**，而不仅是上次保存后的编辑。每次保存后，{{ui:Changes}}列表都会重新清空，因此无法撤销到保存之前。若要从原始状态重新开始，请重新打开原始文件。

## 大文件与内存

- **IFC** 文件会完整读入标签页的内存，三维几何数据还需额外占用内存。几百兆字节的模型对笔记本电脑可能过大。超过 1.5 million 个三角面时，边线会关闭以节省内存（“超大模型已关闭边线”）。
- **项目文件**不会完整读取。无论文件多大，BimCraft 只读取所需的小部分，约 40 KB至100 KB，因此位于网络驱动器上的 500 MB 中心文件可以立即打开。
- **DWG 和 DXF** 文件会完整读取。非常大的图形会显示“此图形过大，仅显示其中一部分。”
- **文件夹**最多可打开 20,000 个文件。仅读取每个模型卡片所需的几千字节。

更多信息请参见[浏览器、设备与内存](topic:platforms)。

## 在线与离线

打开文件从不需要互联网。有一个读取器会在首次需要时从网站加载：IFC 引擎，即首次打开 IFC 模型时加载（“正在启动 IFC 引擎…”）。DWG 和 DXF 读取器是应用的一部分。

:::offline
当前处于离线状态。如果应用栏中的按钮显示{{ui:Offline ready}}，所有格式都可照常打开。否则，除非该标签页中已打开过某个 IFC 模型，否则无法打开 IFC 模型：请先重新连接。参见[在线与离线](topic:online-offline)。
:::

要在无连接时使用 BimCraft，请在联网时点击应用栏中的{{ui:Save for offline}}，并等待{{ui:Offline ready}}显示。保存的副本约 33 MB，其中包含 IFC 引擎，因此 IFC 模型也可离线打开。[离线工作](common:offline)一文总体说明了保存的副本。

## 云端保存

云端保存尚不可用。请将编辑后的副本保存在本机或办公室的文件服务器上，与保存其他任何文件的方式相同。参见[文件](common:your-files)。
