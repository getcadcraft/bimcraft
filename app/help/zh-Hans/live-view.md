实时视图以实时效果显示模型：根据场地的位置和日期显示天空和太阳、太阳阴影、为构件赋予的油漆和材质、灯具，以及从墙面和地面反射的光线。它会跟随您的操作：转动3D视图时它也随之转动，修改模型时稍后即会显示变化。不会上传任何内容。

它绘制的场景、油漆、灯光和太阳与[渲染图片](topic:render)相同；如需最终成图，请使用该功能。

## 打开

1. 打开模型，并在工具栏中选择 {{ui:实时视图}}。面板会在应用上方打开，位于右下角。
2. 拖动其标题栏可移动它，拖动其角可调整大小。
3. {{ui:在新窗口中打开实时视图}}（其旁边的按钮）或面板中的 {{ui:新窗口}} 会将其移到独立窗口中，以便用于第二块屏幕。如果浏览器阻止弹出窗口，则将以面板形式打开。
4. {{ui:关闭}} 即可关闭它。

## 控件

| 控件 | 作用 |
|---|---|
| {{ui:跟随视图}} | 开启时：实时视图朝向与3D视图相同的方向。漫游时会将其关闭 |
| {{ui:漫游}} | 在模型中漫游（见下文） |
| {{ui:重力}} | 漫游时：站在楼面上并可爬楼梯。关闭时：飞行 |
| {{ui:时间}} | 一天中的小时。拖动时太阳随之移动 |
| {{ui:月份}} | 月份，以便查看冬季和夏季的太阳 |
| {{ui:质量}} | {{ui:适合此电脑}}，或 {{ui:低}}、{{ui:中等}} 或 {{ui:高}} |

底部一行说明绘制视图所用的方式（WebGPU 或 WebGL 2）、质量以及间接光。

## 在模型中漫游

1. 将3D视图转到想站立的位置，然后选择 {{ui:漫游}}。您将站在视点下方的地面上，身高1.6m。
2. 点击实时视图，然后使用 {{key:W}} {{key:A}} {{key:S}} {{key:D}} 或方向键。按住 {{key:Shift}} 可跑步。拖动可环顾四周。
3. 高度不超过40cm的台阶会被攀登（楼梯）；更高的则视为墙。墙会阻挡移动，并沿墙滑动。
4. 关闭 {{ui:重力}} 后即为飞行：{{key:E}} 向上，{{key:Q}} 向下。
5. 按 {{key:Esc}} 停止漫游。

## 间接光

从被阳光照射的墙面反射到地面的光线，以及房间较暗的内部，会在后台利用每个处理器核心进行计算。计算期间底部一行显示 {{ui:间接光：40 %}}；计算完成后视图会采用该光线。每次更改后会重新开始计算。

:::note
这是实时视图的近似效果，而非渲染图片：各点之间的细小细节会采用其附近各点的间接光。
:::

:::note
各浏览器有所不同。若浏览器支持 WebGPU，实时视图将使用它；否则使用 WebGL 2，效果相同。两者都不支持时，面板会予以说明。
:::
