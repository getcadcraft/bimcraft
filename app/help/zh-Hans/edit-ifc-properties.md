## 操作内容

更正 IFC 模型中的数据：重命名构件、修正其标记、更改特性值。然后将更改保存为新的 IFC 文件。所打开的文件始终不会被修改。

## 可更改的内容

| 字段 | 可编辑 |
|---|---|
| 名称、对象类型、标记、描述 | 是 |
| 单个特性值（文本、数字、是/否） | 是 |
| 类型特性（标记为“(type)”的集合） | 是，更改将应用于该类型的每个构件 |
| 类型、GlobalId、行号 | 否 |
| 数量（长度、面积、体积、计数） | 否 |
| 列表、枚举及其他多部分值 | 否 |
| 几何、位置、添加或删除构件 | 否 |

## 步骤

1. 打开 IFC 模型，并点击要更改的构件。
2. 在{{ui:Properties}}面板中，点击要更改的值。它会变为文本框。空值显示为*空*。
3. 输入新值。
4. 按{{key:Enter}}或点击其他位置以确认。按{{key:Esc}}取消。
5. 查看该值：它现在为粗体，并在旁边显示蓝色竖条，表示该值已被编辑。
6. 查看左侧的{{ui:Changes}}部分：更改会以*构件*：*字段*，旧值改为新值的形式列出。
7. 对其他值或其他构件重复上述操作。
8. 点击{{ui:Save as IFC}}（按钮会显示待保存的更改数量，例如“另存为IFC (3)”），或按{{key:Mod+S}}。
9. 在下载文件夹中找到“*original name* (edited).ifc”。

## 应看到的内容

状态栏显示“已保存 *name* (edited).ifc，共 *n* 项更改（… 字节）。原始文件未更改。”{{ui:Changes}}列表会被清空，准备进行下一轮。

## 值的类型

- **文本：**输入的任何内容都会按原样保存。清空名称、对象类型、标记或描述将删除该值。
- **数字：**以文件自身的单位输入普通数字，例如 `2.4` 或 `1200`。不要输入单位符号。其他输入会显示“请输入数字。”
- **整数（计数、整数值）：**若输入小数，将显示“请输入整数。”
- **是/否：**该值变为包含“是”和“否”的菜单。

每个值保留其 IFC 类型，因此数字仍为数字，其他程序可正确读取。

## 撤销

1. 点击{{ui:Changes}}部分中的{{ui:Undo}}，或在未输入文本时按{{key:Mod+Z}}。
2. 重复操作以撤销更多。每次撤销会移除最新的更改。

保存后无法撤销到保存之前：保存后，列表将重新开始。已保存的文件保留所有更改。

## 为何编辑只会改变一个构件

导出程序通过共享数据来节省空间。一个属性集可能被二十扇门共享，一个值（“防火等级：60 min”）也可能出现在九十个属性集中。如果 BimCraft 直接修改共享的值，共享该值的每个构件都会随之改变。

因此 BimCraft 在写入前会先进行复制：

- 若所编辑的属性集与其他构件共享，则该构件会获得该属性集自己的副本，仅修改副本。
- 若该值与其他集合共享，则该属性集会获得该值自己的副本。

相邻构件保留其原有数据。这称为*写时复制*。它会在文件中增加少量条目，所有 IFC 程序均可正常读取。

**类型特性是有意设置的例外。**标记为“(type)”的属性集属于构件的类型，在 IFC 中，该类型的每个构件都从类型处读取它。更改它即更改类型，因此该类型的每个构件都会显示新值。{{ui:Changes}}列表会以“(type)”标记此类编辑。参见[为某类型的每个构件更改类型特性](topic:type-vs-instance)。

## 丢失工作前的警告

- 在有未保存的更改时打开其他文件，会提示“您有 *n* 项对 *file* 的未保存更改。是否放弃？”。点击取消即可继续工作，然后保存。
- 在有未保存更改时关闭或重新加载标签页，浏览器会询问是否离开。

## 常见错误

- **输入单位。**`2400 mm`会被拒绝。请输入 `2400`。
- **本意只更改一个构件，却更改了类型特性。**输入前请查找“(type)”标注。若希望某个构件有所不同，请改为更改实例特性，或其标记或名称。
- **期望原始文件被更改。**保存时总会下载新文件。如需替换原文件，请自行替换，并保留副本。
- **没有更改时按{{key:Mod+S}}。**BimCraft 仅在有内容需要保存时才会保存；否则可能会打开浏览器自带的“保存页面”。请将其关闭。
- **保存两次，却期望得到两个较小的文件。**每次保存都包含自打开模型以来的所有编辑。
- **期望编辑内容写回项目文件。**BimCraft 仅写入 IFC。请像导入任何 IFC 文件一样，将编辑后的 IFC 导入创作程序。
