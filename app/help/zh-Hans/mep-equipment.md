## 操作内容

将设备放置在管道和风管的末端。每件设备都是按输入数值确定尺寸的通用形状，其连接以**接口**形式呈现：管道或风管连接的位置、所属系统、流向及尺寸。从接口绘制的管道和风管会采用其尺寸和系统，并固定于其上：参见[连接管道和风管到设备](topic:mep-connections)。

:::note
这是由工程师确定尺寸的绘图和协调辅助工具。设备并非厂商产品：不提供容量、重量或厂商连接尺寸。需要时，请从MEP程序导入厂商模型（IFC格式）。
:::

## 放置设备

1. 开启{{ui:绘制}}，打开{{ui:构建}}并选择{{ui:设备}}。
2. 在工具栏中选择类型并输入其尺寸。每种类型需要各自的参数：

| 类型 | 需输入 | 其接口 |
|---|---|---|
| 空气处理机组 | 长、宽、高；送风和回风口；盘管管径和系统；冷凝水管径 | 送风风管出口、回风风管入口、盘管进口和出口、冷凝水排水口 |
| 管道风机 | 直径、长度、系统 | 风管入口和出口 |
| 水泵 | 管径、系统 | 入口和出口 |
| 锅炉 | 长、宽、高、管径、燃气管径、烟道直径 | 供暖供水出口和回水入口、燃气入口、烟道出口 |
| 热水器 | 直径、高度、管径、燃气或电 | 冷水入口、热水出口（燃烧燃气时另有燃气入口和烟道） |
| 末端装置 | 长、宽、高；圆形入口；出风口宽和高 | 送风入口和出口 |
| 散流器 | 面板、颈部、系统 | 其颈部（送风入口） |
| 风口 | 面板宽和高、颈部宽和高、系统 | 其颈部（回风或排风出口） |
| 水箱 | 直径、高度、管径、系统 | 顶部入口，底部附近出口 |
| 散热器 | 长、高、深、管径、系统 | 一端顶部进供水，另一端底部出回水 |
| 对流器 / 面板式采暖器 | 长、高、深、管径、系统 | 一端进供水，另一端出回水 |
| 厂商族 | 族（参见[管道规格、阀门、风阀和厂商族](topic:pipe-specs)） | 其族所定义的接口 |

3. 设置**安装高度**，即其底座高出标高的距离。散流器或风口的高度指其面板：输入吊顶高度。
4. 如需标签，请输入**标签**（如 `AHU-1`）；同类下一件设备将获得下一个编号。
5. 将指针移到平面上：其占地和接口会随之移动。按{{key:R}}转动90°，然后单击放置位置。

管道尺寸为钢管尺寸（ASME B36.10M）。从其他材质的水泵引出的管道，采用其自身材质的相同公称尺寸。

## 更改或删除

在平面或三维视图中选中它。属性面板会显示所输入的全部尺寸、其标签、X、Y、高度和转动角度，以及每个接口：其尺寸、系统、流向以及是否有连接。每次更改都是{{ui:撤销}}的一步；固定于其接口的管线随之移动。{{key:Delete}}可删除设备；固定于它的管线会保留，并由{{ui:检查连接}}列出。

## 在IFC文件中

每种类型均保存为其对应的 IFC 类：IfcUnitaryEquipment（空气处理机组）、IfcFan（风机）、IfcPump（水泵）、IfcBoiler（锅炉；热水器为类型为水的 IfcBoiler，对象类型为“Water heater”）、IfcAirTerminalBox（末端装置）、IfcAirTerminal（散流器、风口）和 IfcTank（水箱），同类设备共享一个类型并带有尺寸。IFC2X3 文件则使用 IfcEnergyConversionDevice、IfcFlowMovingDevice、IfcFlowController、IfcFlowTerminal 和 IfcFlowStorageDevice，并附带对应类型。每个接口为一个 IfcDistributionPort，位于连接位置，朝外，并带有其流向和系统；其他程序据此读取哪条管线连接到哪个接口。设备会加入其各接口所属的系统，并携带每个已放置库项目所具有的库项目集。
