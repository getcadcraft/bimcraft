## 操作内容

根据当前模型生成客户资料包或阶段报告，并按面积和造价并排比较已保留的体量方案。

## 步骤

1. 在左侧面板中打开**客户资料包和阶段报告**。
2. 在“客户资料包”或“阶段报告”旁选择**在文档中打开**。该文档会出现在“文档”中，并由模型生成，可在其中修改文字。
3. 在预览中点击某个数字，即可选中其所依据的构件。
4. 选择**生成资料包**。系统会保存一个 zip 文件，内含：PDF 格式的文档、三维视图的图片，以及 `figures.csv`（列出每个数字及其构件的 GlobalId）。

## 字段

可在任何文档中使用以下字段。

| 字段 | 输出内容 |
|---|---|
| `{{stage}}` | 图纸详情中的项目阶段。 |
| `{{options}}` | 已保留的体量方案并排显示：层数、高度、占地面积、总建筑面积、围护结构和造价。 |
| `{{areas}}` | 按楼层统计的面积，来自房间。 |
| `{{sheets}}` | 图纸，以及每张图纸当前的修订版本和最后发布时间。 |
| `{{issues}}` | 发布历史和图纸变更记录。 |
| `{{changes}}` | 自上次发布以来的变化，按图纸逐一列出。 |

## 方案造价的计算方式

造价仅来自项目的价格表（Energy/Cost，5D 造价）。系统不会为你估算任何数字。

- 只有当价格行的类别包含 `IfcBuildingElementProxy` 时，该行才会为方案定价。
- 楼面面积由其用途词与方案用途相符的价格行定价，例如“办公”。若没有这样的行，则使用包含“总建筑面积”或“建筑体量”字样的行。按 m² 计价的行使用总建筑面积；按 m³ 计价的行使用体积。
- 围护结构（周长乘以高度）由包含“围护结构”或“立面”字样的价格行定价。
- 没有匹配价格行的方案显示**无单价**。只有当所需的每个部分都有单价时，才会显示合计。

## 注意事项

- 在房间方案的体量列表中，使用**保留为方案**即可保留方案。参见体量方案。
- PDF 无法选中构件。在 BimCraft 之外，`figures.csv` 提供了从每个数字到其构件的链接。
