## 操作内容

为墙、楼板、屋顶、门、窗以及模型中的其他所有构件赋予分类编码，可同时使用三个体系：Uniclass、OmniClass 和 UniFormat。其他专业和其他软件依赖的是编码而非名称，因此编码会以分类引用的形式保存在 IFC 文件中，任何 BIM 程序都能读取。

## 为构件赋予编码

1. 选择一个（或多个）构件，并打开**属性面板**。打开{{ui:Classification}}部分。
2. 在对应体系的输入框中输入编码，然后按 Enter。若已加载编码列表，可输入编码的一部分或几个词（例如“幕墙”），然后从匹配项中选择：编码的名称会自动填入。
3. {{ui:Applies to}}用于指定编码的适用范围：**此构件**，或**其类型（该类型的每个构件）**。赋予墙类型的编码会被该类型的每面墙读取，包括之后绘制的墙。
4. 点击{{ui:Clear}}可移除编码。

每个编码下方的部分会说明其来源：直接设置在此构件上、来自其类型，还是来自其所属类别的项目默认值。构件自身的编码始终优先于其类型的编码，类型的编码优先于默认值。选中多个构件时，若某个输入框显示“不一致”，表示它们没有相同的编码；输入一个编码即可赋予全部构件。每次更改都是一个撤销步骤。

无论是否加载了列表，都可以直接输入编码。若编码看起来不属于该体系，或不在已加载的列表中，会有提示，并保留你输入的编码。

## 选择项目的体系

在模型栏中打开**数据**，然后选择{{ui:Classification}}（或属性面板中的{{ui:Project classification…}}）。

- 勾选本项目使用的体系。属性面板随后只显示这些体系。
- **Uniclass**：构件/功能（EF）、系统（Ss）和产品（Pr）表格随应用提供。它们版权归 NBS 所有，依据知识共享署名-禁止演绎 4.0（Creative Commons Attribution-NoDerivatives 4.0）许可授权，并原样分发。对话框会显示每个表格的版本及其读取日期。这些并非最新版本：出版方每季度会在其网站上发布新版本。
- **OmniClass** 和 **UniFormat**：应用不附带编码列表，因为出版方不允许未经授权转发这些表格。可以输入任意编码，或加载你所在公司自有的授权表格。
- {{ui:Load a table (CSV)…}}从 CSV 文件中读取你所在公司自有的表格。该文件需包含编码列和标题列：表头行名为 Code、Number 或 Identifier，以及 Title、Name 或 Description 时会被自动识别；若没有表头，则使用前两列。该表格保存在本浏览器中，不会写入项目文件，文件中只保存你赋予的编码。可以用同样的方式加载较新的 Uniclass 表格。
- {{ui:Give elements a default code by their class}}会为每个墙、楼板、屋顶、门、窗、楼梯、坡道、柱、梁和家具（若其自身没有编码），从构件/功能表中赋予一个初始 Uniclass 编码。之后绘制的构件也会获得该编码。
- {{ui:Show the codes as columns in the schedules}}会在门、窗、按类型统计的墙和房间明细表及其 CSV 中，为每个体系各添加一列。当一行中的多个构件编码不同时，将显示“不一致”。

## 注意事项

- 默认编码是 CadCraft 自身的初始选择，并非出版方的标准，也未经专业人员核实。请根据项目的标准进行核对。
- 在文件中，默认值是一项真实的分类，并标记为关系名“CadCraft default”；一旦构件或其类型获得自身的编码，该默认值便会被替换。
- 已导入文件中已有的编码会被读取并显示，无论其他程序对该体系名称使用何种拼写。其他任何体系（公司自有的体系）的编码会被列出，但不作改动。
- 再次打开文件（在此处或其他程序中）时，编码会被读回。启用相应的实验选项时，它们也会被带入 IFC5 alpha（IFCX）导出，但设置在屋顶上的编码除外。
- 尚未实现：按层级浏览表格的树状视图、在楼层和房间上设置项目默认编码，以及对照文件中所注明的版本检查编码。
