## 将要完成的操作

打开整个项目文件夹（例如为某项工作提供的那个），让BimCraft自动整理：有哪些模型，哪些副本是备份，哪些文件相互链接，哪些文件已损坏，以及最可能需要打开的文件是哪一个。

仅读取每张模型卡片所需的几千字节，因此位于网络驱动器或已同步云文件夹中的文件夹也可以正常使用。

## 步骤

:::chromium
1. 点击左侧的{{ui:打开文件夹}}（或空白屏幕中央）。
2. 在打开的窗口中选择项目文件夹，然后点击**选择**（或**上传**或**打开**，取决于系统）。
3. 浏览器询问“允许网站查看文件？”时，点击**查看文件**。这只允许标签页读取该文件夹；不会上传任何内容。
4. 等待状态行计数：“正在列出文件夹：…个文件”，然后是“正在检查Revit文件：… / …”。
:::

:::firefox
1. 点击左侧的{{ui:打开文件夹}}（或空白屏幕中央）。
2. 在打开的窗口中选择项目文件夹并确认。Firefox可能会请求确认该页面可以读取文件夹中的文件；这些文件仍保留在本机上。
3. 等待状态行显示“正在读取文件夹：…个文件”，然后显示“正在检查Revit文件：… / …”。
:::

:::safari
1. 点击左侧的{{ui:打开文件夹}}（或空白屏幕中央）。
2. 在打开的窗口中选择项目文件夹，然后点击**上传**。尽管按钮如此命名，文件并不会离开Mac：它们只是交给标签页。
3. 等待状态行显示“正在读取文件夹：…个文件”，然后显示“正在检查Revit文件：… / …”。
:::

也可以将文件夹从{{pick:mac=Finder|windows=File Explorer|linux=文件管理器}}拖到页面上。在所有浏览器中，拖入的文件夹都无需任何权限提示即可打开。

## 结果

文件夹报告显示在中间区域：

- 文件夹名称、模型、CAD图形、IFC模型和文件的数量，以及总大小。
- 若有文件不完整，或有链接文件缺失于文件夹中，会显示红色或琥珀色的注释。
- {{ui:从这里开始}}框：BimCraft建议打开的文件，并附带理由。
- **模型**：每个模型一行，其备份归在其下。
- **链接和引用的文件**、**IFC模型**、**CAD图形**以及**搁置**（当文件夹中有这些内容时显示）。

左侧的{{ui:文件夹}}面板会对其进行汇总；若所有副本都完好，**问题**会显示“无”。

## 使用“从这里开始”框

该框会指出一个文件并说明原因，例如：

- “此文件夹中最新保存的工作（2025年3月3日）。”
- “*Consultant.rvt*被链接到其他模型中，因此它是背景文件，而非应编辑的文件。”
- “*Tower.rvt*看起来是显而易见的选择，但它已损坏；其最后一个完好副本来自……”
- “这是一个中心模型：在Revit中，使用“Create New Local”打开它，并在本地副本中工作。”

1. 阅读这些理由。
2. 点击{{ui:打开其卡片}}以查看该文件的卡片，或点击{{ui:在列表中显示}}以在**模型**中找到其所在行。
3. 在依赖该文件之前，先与最后处理该项目的人员核实。该框同样会说明：它只是根据名称、日期和链接作出的最佳猜测。

## 从报告中打开文件

1. 点击模型的名称以打开其卡片。卡片会对照文件夹检查每个链接。
2. 点击{{ui:返回}}以及卡片顶部的文件夹名称（或左侧的{{ui:返回文件夹}}）即可返回。
3. 点击**IFC模型**下的任意IFC文件，即可在3D中打开它。
4. 点击**CAD图形**下的任意DWG或DXF，即可在2D中打开它。其链接的图形和图像会自动在文件夹中查找。

## 稍后重新打开文件夹

:::chromium
通过{{ui:打开文件夹}}或拖放打开的文件夹会列在左侧的{{ui:最近的文件夹}}下。点击{{ui:重新打开}}和文件夹名称即可再次打开，无需重新选择。浏览器重启后，Chrome或Edge会再询问一次；选择“每次访问时允许”即可不再询问。该列表仅保存在此浏览器中，绝不会发送到任何地方。点击×可忘记某个文件夹。
:::

:::firefox safari
此浏览器无法在访问之间记住文件夹。再次用{{ui:打开文件夹}}选择文件夹，或将其拖入。
:::

## 常见错误

- **选择的文件夹过大。** 超过20,000个文件时会显示：“此文件夹包含超过20,000个文件。请选择较小的文件夹，例如单个项目的文件夹。”选择项目文件夹，而不是整个驱动器。
- **选择了多个项目的上级文件夹。** 此时{{ui:从这里开始}}框会跨项目进行选择。请选择单个项目。
- **Revit自身的文件夹看起来被忽略了。** `*_backup`、`*_log`和`Revit_temp`文件夹属于系统维护文件，会列在**搁置**下，而不会被读取。
- **期望从卡片中以3D打开模型。** 项目文件仅作为卡片显示。打开其IFC导出文件。
- **手机和平板电脑。** 许多移动浏览器根本无法选择文件夹。请改用计算机。

另请参阅[检查文件夹中是否有损坏副本、缺失链接和遗留文件](topic:check-folder-health)和[文件夹报告：角色、状态和链接](topic:folder-roles)。
