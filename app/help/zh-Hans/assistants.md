## 学习内容

如何允许 AI 助手（任何支持 MCP 的助手）查看您打开的 IFC 模型并在其中绘制，它能做什么、不能做什么，以及如何将其停止。

## BimCraft 中助手可执行的操作

| 请求 | 结果 | 所需权限 |
|---|---|---|
| 查找构件 | 按类、楼层、名称或属性值获取构件列表，与 **查找** 的结果相同 | 读取 |
| 读取属性 | 获取一个构件的属性、类型、属性集和数量，与 **属性** 面板所示相同 | 读取 |
| 描述模型，列出墙体 | 获取楼层、墙、门、窗、房间、楼板、轴网和柱，以及每面墙的端点、类型和高度 | 读取 |
| 隔离、透明显示、隐藏或显示 | 三维视图的变化，与使用 {{ui:显示}} 菜单的效果相同 | 更改视图和绘制 |
| 绘制墙、门、窗、楼板、楼层或轴网线 | 模型的变化，与使用 {{ui:绘制}} 工具的效果相同：墙体相接，房间、楼板和屋顶随之调整 | 更改视图和绘制 |
| 更改名称或属性值 | 单个构件的名称、说明、对象类型或标记，或单个属性值。与其他构件共享的值会先为该构件复制一份；类型的属性值只有在助手明确要求时才会更改，因为该类型的每个构件都会随之变化 | 更改视图和绘制 |
| 移动、删除、更改墙、门和窗 | 构件随其所依附的主体一同移动或删除；使用 {{ui:绘制}} 工具绘制的墙可通过端点或类型更改，门和窗可通过位置、尺寸或类型更改，房间和连接处随之调整 | 更改视图和绘制 |
| 设置、排列和读取明细表 | 例如“按楼层列出门明细表，包含防火等级和五金件”：助手命名明细表、其列（属性或标记将成为列）及分组；BimCraft 根据模型填充并排版，助手未指定的内容则取自办公室标准。设置会加入您的 {{ui:明细表}} 列表。返回的每一行都会列出其构件，因此助手可以选中它们 | 读取以读取；更改视图和绘制以保存设置 |
| 导出明细表 | CSV、Excel 或制表符分隔文本，可粘贴到 Google Sheets 中（不会发送给 Google） | 导出 |
| 读取并设置房间装修 | 装修类型，每个房间的地面、墙面和顶棚装修，分区；面积、瓷砖数量和基层体积随后取自装修明细表 | 读取；设置需要更改视图和绘制 |
| 选择构件，撤销其自身的步骤 | 在视图中拾取构件；其最后一步将被撤销 | 更改视图和绘制 |
| 保存 | 生成包含所有更改的新 IFC 文件，与 {{ui:另存为IFC}} 的效果相同（原文件永不更改） | 保存 |
| 导出 USD | 将打开的模型导出为 OpenUSD（.usda、.usdc 或 .usdz），与工具栏上的 {{ui:USD}} 导出效果相同 | 导出 |
| 渲染图片，运行渲染队列 | 三维视图的图片，与 {{ui:渲染}} 对话框按渲染设置生成的效果相同（除非助手要求其他设置），或将高质量图片添加到对话框的队列中并依次渲染（队列需要 WebGPU）。模型不会发生任何变化（[渲染图片](topic:render)） | 导出 |

助手所做的每项更改都是 **更改** 中的一个步骤，名称为 "Assistant: …"（例如 "Assistant: add 4 walls"），因此 {{key:Mod+Z}} 可撤销其整个操作，并且您可以看出是哪个助手的步骤。在窗口中，助手无法打开文件：由您打开模型，助手只处理当前打开的模型。

## 启用

助手通过计算机上的 CadCraft Studio 访问 BimCraft；普通浏览器无法接入。

1. 打开 {{ui:设置}}，选择 **BimCraft** 选项卡。
2. 在 **助手** 下，勾选 **允许 AI 助手和脚本使用 BimCraft**。
3. **读取** 已默认勾选。如果助手可以隔离、隐藏构件并绘制，请也勾选 **更改视图和绘制**；如果它可以将模型另存为新文件，请勾选 **保存**。
4. 在 Studio 中连接助手（Studio 会显示地址以及需要粘贴到助手中的设置）。

## 助手连接期间

右侧面板顶部的提示会显示已连接的助手及其可执行的操作。点击 {{ui:断开连接}} 可立即结束其会话；如需继续，助手必须重新连接。

设置中 **助手** 下的 **活动**，按时间倒序列出助手发出的每一次调用，并显示是否成功。

:::tip
用通俗的语言提问，例如“隔离 1 层的外墙”、“哪些门没有防火等级？”或“在 1 层绘制一个 6 × 4 米的房间，南墙上设一扇门”。助手会找到相关构件，并在视图中显示，或直接绘制。
:::

## 无窗口：脚本与命令行

相同的绘图工具也可用于您指定文件夹中的 IFC 文件，无需打开窗口：CadCraft 的 MCP 服务器和命令行可以新建建筑或打开 IFC 文件，描述它，添加墙、门、窗、楼板、楼层和轴网，撤销操作，并将其另存为新的 `.ifc` 文件。由您决定它可以使用哪些文件夹，以及是否允许其更改或保存任何内容。

## 关闭

取消勾选 **允许 AI 助手和脚本使用 BimCraft**。所有助手将立即断开连接，该设置会保留到下次使用。
