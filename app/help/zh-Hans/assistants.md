## 学习内容

如何让 AI 助手（任何支持 MCP 的助手）查看你打开的 IFC 模型并在其中绘图，它能做什么、不能做什么，以及如何将其断开。

## BimCraft 中助手能做什么

| 助手请求 | 发生的情况 | 所需权限 |
|---|---|---|
| 查找构件 | 按类别、楼层、名称或特性值获取构件列表，与 **查找** 的效果相同 | 读取 |
| 读取特性 | 获取一个构件的属性、类型、特性集和数量，与 **特性** 中显示的内容相同 | 读取 |
| 描述模型、列出墙体 | 获取楼层、墙、门、窗、房间、楼板、轴网和柱，以及每面墙的端点、类型和高度 | 读取 |
| 隔离、透视、隐藏或显示 | 三维视图随之变化，与使用 {{ui:显示}} 菜单相同 | 更改视图与绘制 |
| 绘制墙、门、窗、楼板、楼层或轴线 | 模型随之变化，与使用 {{ui:绘制}} 工具相同：墙会相连，房间、楼板和屋顶随之调整 | 更改视图与绘制 |
| 更改名称或特性值 | 一个构件的名称、说明、对象类型或标记，或一个特性值。与其他构件共享的值会先为其单独复制；类型的值只有在助手明确要求时才会改变，因为该类型的每个构件都会随之变化 | 更改视图与绘制 |
| 移动、删除、更改墙、门和窗 | 构件随其所依附的构件一起移动或删除；使用 {{ui:绘制}} 工具绘制的墙会随端点或类型变化，门和窗会随位置、尺寸或类型变化，房间和连接随之调整 | 更改视图与绘制 |
| 设置、排列和读取明细表 | "按楼层排列的门明细表，包含防火等级和五金件"：助手命名明细表、其列（特性或标记成为一列）及分组；BimCraft 从模型中填充并排版，助手未指定的内容取自办公室标准。设置会加入你的明细表列表。助手返回的每一行都会注明其构件，因此它可以选中这些构件 | 读取以读取；保存设置需要更改视图与绘制 |
| 导出明细表 | CSV、Excel 或以制表符分隔的文本，可粘贴到 Google 表格（不会发送到 Google） | 导出 |
| 读取并设置房间装修 | 装修类型、每个房间的地面、墙面和顶棚装修、分区；面积、瓷砖数量和基层体积随后取自装修明细表 | 读取；设置需要更改视图与绘制 |
| 选择构件、撤销其自身步骤 | 在视图中拾取构件；撤销其最近一步 | 更改视图与绘制 |
| 保存 | 生成一个包含所有更改的新 IFC 文件，与 {{ui:另存为IFC}} 的效果相同（原文件永不更改） | 保存 |
| 导出 USD | 将打开的模型导出为 OpenUSD（.usda、.usdc 或 .usdz），与工具栏上的 {{ui:USD}} 相同 | 导出 |
| 渲染图片、运行渲染队列 | 生成三维视图的图片，与 {{ui:渲染}} 对话框的效果相同，使用你的渲染设置，除非助手要求其他设置；或将高质量图片加入对话框的队列，逐一渲染（队列需要 WebGPU）。模型不会改变（[渲染图片](topic:render)） | 导出 |

助手对 BimCraft 所做的每一次更改，都会在 **更改** 中记为一步，名称为"助手：…"（例如"助手：添加 4 面墙"），因此 {{key:Mod+Z}} 可撤销其整个操作，你也能看出是哪一步由谁做出。在窗口中，助手无法打开文件；你需要先打开模型，它只处理当前已打开的那个。

## 开启

助手通过你电脑上的 CadCraft Studio 连接 BimCraft；普通浏览器无法接入。

1. 打开 {{ui:设置}}，选择 **BimCraft** 选项卡。
2. 在 **助手** 下，勾选 **允许 AI 助手和脚本使用 BimCraft**。
3. **读取** 已为你勾选。如果助手可能隔离和隐藏构件并进行绘制，也请勾选 **更改视图与绘制**；如果它可能将模型另存为新文件，还需勾选 **保存**。
4. 在 Studio 中连接助手（Studio 会显示地址以及需要粘贴到助手中的设置）。

## 助手连接时

右侧面板顶部的提示会说明已连接的助手及其可执行的操作。点击 {{ui:断开连接}} 可立即结束其会话；如需继续，它必须重新连接。

**活动**（位于设置中的 **助手** 下）按时间从新到旧列出助手发出的每一次调用，并显示是否成功。

:::tip
用简单的语言提问即可，例如"隔离 1 层的外墙"、"哪些门没有防火等级？"或"在 1 层绘制一个 6 米 × 4 米的房间，南墙上设一扇门"。助手会找到构件并在视图中显示，或直接绘制。
:::

## 无窗口：脚本与命令行

相同的绘图工具也可用于你指定文件夹中的 IFC 文件，无需打开窗口：CadCraft 的 MCP 服务器和命令行可以新建建筑或打开 IFC 文件，对其进行描述，添加墙、门、窗、楼板、楼层和轴网，撤销操作，并另存为新的 `.ifc` 文件。另有四个工具适用于脚本：`ifc_batch` 可将最多 200 个编辑步骤作为一个整体运行（全部成功或全部不执行：一次撤销即可撤回整个批次，被拒绝的步骤会撤销其余步骤并指出该步骤）；`ifc_describe` 列出楼层以及每面墙及其门窗；`ifc_render_png` 在无窗口的情况下生成模型的平面着色检查图（无材质、纹理或阴影）；`usd_export` 写出 `.usda`、`.usdc` 或 `.usdz`。在命令行中，`cadcraft bim script.json --from model.ifc -o out.ifc` 运行一个步骤脚本，`--usd`、`--png` 和 `--plan` 可在同一次运行中分别写出 USD 文件、图片或平面图。你决定它可以使用哪些文件夹，以及是否允许它更改或保存任何内容。

## 关闭

取消勾选 **允许 AI 助手和脚本使用 BimCraft**。所有助手会立即断开连接，该设置会被保留，下次使用时依然有效。
