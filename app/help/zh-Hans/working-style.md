## 你将完成

按你的工作方式设置 BimCraft，复制视图，以你期望的方式打印，按构件的真实类型统计，并从办公室的模板开始每个项目。

## 选择工作方式

1. 打开{{ui:设置}}，然后打开 **BimCraft** 选项卡。找到{{ui:工作方式}}。
2. 选择一项：
   - {{ui:各视图独立}}（默认选项）：复制的视图会复制其注释，且注释仍归该视图所有；图纸按屏幕所示打印。
   - {{ui:共享注释和笔表}}：复制的视图共享注释；打印通过笔表进行。
3. 选项下方是它所设置的四项内容。单独更改其中任一项；此时工作方式会显示为{{ui:自定义}}。

工作方式保存在此浏览器中，与工作区布局一样。模板会将其带到新模型中。

## 复制视图

1. 在{{ui:项目浏览器}}中，每个楼层平面、天花板平面、索引、立面和剖面都有一个{{ui:创建副本}}按钮（两张叠放的图纸图标）。
2. 为副本命名并选择其行为：
   - {{ui:独立副本}}：其绘图、标注、裁剪、隐藏构件和笔设置都会被复制，并保持为其自身所有。编辑任一视图都不会改变另一个，因此已发布图纸上的视图会保持发布时的样子。
   - {{ui:已链接}}：显示同一视图，共享一组注释和设置。
3. 副本会列在{{ui:已复制的视图}}下。点击即可打开；平面图上方的栏会说明它是副本，并带有{{ui:上一级}}按钮，可返回其所属视图。
4. 其滑块按钮可打开其设置：名称、{{ui:视图范围}}（独立副本有自己的范围）、用于链接副本的{{ui:设为独立副本}}，以及{{ui:删除}}。

立面和剖面的副本与其来源视图一样放在你自己的图纸上。复制是一个撤销步骤，副本与索引一起保存在 IFC 中。

## 与视图一起保存的笔，并按所见打印

1. 开启{{ui:绘制}}，然后选择{{ui:画笔}}。
2. {{ui:对象}}现在会列出每个类别：墙、门和窗、楼板、屋顶、柱、楼梯、家具及其余，以及绘图和标注。
3. {{ui:应用}}会将笔保存在 IFC 中，并与其所显示的视图一同保存：平面图、天花板平面、索引或复制的视图。0.9 版之前的笔保存在浏览器中；{{ui:保存到文件中}}会将其移入文件。
4. 图纸和 PDF 会按屏幕所示绘制每一支笔。

若要改为通过笔表打印，请将“画笔”行中的{{ui:打印}}设为{{ui:通过笔表}}，然后选择一个表（颜色、单色、灰度）或{{ui:编辑笔表…}}：每种颜色都有其打印时使用的颜色、线宽和网点。该表是 CadCraft 的打印样式文件，因此{{ui:导入…}}可读取在 CadCraft 应用中制作的表，{{ui:导出}}则会生成一个表。模型会保留其选择；若无选择，则由工作方式决定。

## 将构件报告为另一个类

被绘制为道路的楼板、被用作面板的墙、被塑造成坡道的屋顶：保留你绘制时所用的工具，并将其报告为它实际的类。

1. 选择构件并打开{{ui:特性}}。打开{{ui:报告为}}。
2. 在搜索框中输入以查找符合形状的类，然后选择它及其预定义类型。若需自定义类型，请选择 USERDEFINED 并为其命名。
3. 点击{{ui:应用}}（一个撤销步骤）。{{ui:清除}}会将其恢复为按绘制时的方式报告。

你仍使用绘制它时的工具进行编辑。保存的 IFC 会将其写为所报告的类，因此其他程序、{{ui:工程量}}算量、查找、按颜色着色、模型检查和{{ui:问题}}都会将其计为该类。明细表会将报告为面板的墙排除在墙明细表之外，而{{ui:按报告类统计的构件}}会列出所有此类构件。该功能适用于 IFC4 和 IFC2X3 文件；列表只提供该文件 IFC 版本所支持的类。门、窗、楼梯、房间和楼层保留其自身的类。

## 将项目保存为模板，并从其开始

1. 在打开项目的情况下，点击{{ui:保存}}旁的{{ui:另存为模板}}。
2. 为其命名。勾选{{ui:同时下载模板文件}}可将其作为 IFC 文件分享，勾选{{ui:新建模型从此模板开始}}可将其设为默认。
3. 模板会保留楼层、视图模板和视图设置、已复制的视图和索引、绘图、画笔和笔表、标记、族和类型、图纸、图纸尺寸、标题栏以及工作方式。墙、楼板、门及所有其他模型构件均不包含。
4. 点击{{ui:新建建筑}}并在{{ui:起始模板}}下选择它，或选择{{ui:模板文件…}}以使用你收到的模板。新项目会有其自己的名称和项目标识；其他内容与模板一致。

:::note
模板保存在此浏览器中。通过 CadCraft Studio 分享的团队模板尚未实现：请改为发送模板文件。
:::
