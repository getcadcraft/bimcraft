BimCraft-da az qısayol var. Əsas iş siçan və panellərlə görülür. {{key:Mod}} ilə yazılmış qısayollar Mac-də Command, qalan yerlərdə Ctrl işlədir. Bu yardımda düymələrin necə yazıldığını görmək üçün bax: [Düymələr, siçanlar və trackpadlər](common:keys).

## Hər yerdə

| Düymə | Nə edir |
|---|---|
| {{key:Ctrl+Shift+F}} | Ekran rejimlərini dəyişir: normal, tam ekran, panelləri gizlədilmiş tam ekran. Mac daxil hər platformada Ctrl |
| {{key:Esc}} | Tam ekrandan çıxır |
| {{key:Mod+,}} | {{ui:Parametrlər}} açır. Bax: [BimCraft parametrləri](topic:settings) |
| {{key:Tab}} | Düymələr, qutular və dəyərlər arasında keçir. Hər idarəetmə klaviaturadan əldə edilə bilər |

## 3D görünüş (IFC modelləri)

| Düymə və ya hərəkət | Nə edir |
|---|---|
| {{key:F}} | Bütün modeli üçdə-bir görünüşdə sığdırır (eyni {{ui:Sığdır}} ilə) |
| {{key:Esc}} | Seçimi ləğv edir, ya da yerləşdirməni və ya yapışdırmanı dayandırır |
| Klik | Göstəricinin altındakı elementi seçir; boş fonda klik seçimi ləğv edir |
| {{key:Mod}}+klik və ya {{key:Shift}}+klik | Seçimə element əlavə edir və ya ondan çıxarır |
| {{key:H}} | Seçilmiş elementləri gizlədir. Bax: [Elementləri gizlədin, təcrid edin və şəffaf göstərin](topic:hide-and-isolate) |
| {{key:I}} | Yalnız seçilmiş elementləri göstərir (təcrid) |
| {{key:T}} | Seçilmiş elementləri göstərir, qalan hər şeyi şəffaf edir |
| {{key:Shift+H}} | Bütün elementləri yenidən göstərir |
| {{ui:Gəz}} | Sonra {{key:W}} {{key:A}} {{key:S}} {{key:D}} və ya oxlarla gəzin, {{key:Shift}} qaçır, sürükləmək ətrafa baxır, {{key:Esc}} dayandırır. Bax: [Modeldə gəzin](topic:walk) |
| {{key:M}} | Məsafələri və üz sahələrini ölçür. Bax: [3D-də məsafələri, üz sahələrini və yerləri ölçün](topic:measure) |
| Sol düyməni sürüklə | Orbit |
| Sağ düyməni sürüklə | Sürüşdür |
| {{key:Shift}} və ya {{key:Mod}} basılı, sol düyməni sürüklə | Sürüşdür (trackpad-də rahatdır) |
| Çarxı fırlat və ya orta düyməni sürüklə | Miqyas |
| Trackpad-də iki barmaqla sürüşdürmə və ya sıxma | Miqyas |
| Bir barmaq (toxunma) | Orbit; toxunma seçir |
| İki barmaq (toxunma) | Barmaqları açıb-yığmaqla miqyas, birlikdə hərəkət etdirməklə sürüşdürmə |

| {{key:X}} | Kəsik müstəvisini açır və bağlayır. Bax: [IFC modelini kəsik müstəvisi ilə kəsin](topic:section-plane) |
|---|---|
| {{key:Shift+X}} | Seçilmiş elementlərin ətrafında kəsik qutusu, boşluğu Parametrlərdə təyin olunub |

{{ui:Üst}}, {{ui:Ön}} və {{ui:Yan}} üçün düymə yoxdur; düymələrdən istifadə edin.

## Redaktə

Eyni əmrlər alətlər panelindədir: {{ui:Geri qaytar}}, {{ui:Təkrarla}}, {{ui:Kopyala}}, {{ui:Yapışdır}} və hər düymənin göstərdiyi {{ui:Daha çox}} menyusu. Onlar IFC modelinin 3D görünüşündə işləyir, sahəyə yazarkən yox. Bax: [Kitabxana elementlərini kopyalayın, yapışdırın və surət çıxarın](topic:copy-paste).

| Düymə | Nə edir |
|---|---|
| {{key:Mod+Z}} | Son dəyişikliyi geri qaytarır |
| {{key:Mod+Y}} və ya {{key:Mod+Shift+Z}} | Geri qaytarmanın geri aldığını təkrarlayır |
| {{key:Mod+C}} | Seçilmiş elementləri kopyalayır (adları və xassələri mətn kimi buferə də gedir) |
| {{key:Mod+X}} | Seçilmiş elementləri kəsir: kopyalayır, sonra silir |
| {{key:Mod+V}} | Kopyaladığınızı yapışdırır: göstəricini izləyir, yerinə klik edin |
| {{key:Mod+Shift+V}} | Yerində yapışdırır: kəsilmiş yerdə, ya da kopyadan sonra orijinalların yanında |
| {{key:Mod+D}} | Dublikat: seçilmiş elementləri kopyalayır və yapışdırmağa başlayır |
| {{key:Delete}} | Seçilmiş elementləri, onların hissələri və açılışları ilə silir. Bax: [Tikinti elementlərini silin, kəsin, kopyalayın və yapışdırın](topic:edit-elements) |
| {{key:Mod+A}} | Göstərilən bütün elementləri seçir |
| {{key:Esc}} | Heç nə seçmir |

Səhifədə mətn seçiləndə {{key:Mod+C}} həmin mətni adi qayda ilə kopyalayır.

## Plan görünüşü ({{ui:Çək}})

Bunlar {{ui:Çək}} aktiv olduqda və sahəyə yazmadığınız zaman işləyir. Bax: [Divarları çəkin](topic:draw-walls) və [Qapılar və pəncərələr](topic:doors-and-windows).

| Düymə və ya hərəkət | Nə edir |
|---|---|
| {{key:V}} | {{ui:Seç}} |
| {{key:W}} | {{ui:Divar}} |
| {{key:D}} | {{ui:Qapı}} |
| {{key:N}} | {{ui:Pəncərə}} |
| {{key:H}} | {{ui:Qapı}} və ya {{ui:Pəncərə}} ilə: menteşələr digər ucda |
| {{key:Shift}} divar çəkərkən | Onu 0°, 90°, 180° və ya 270°də saxlayır |
| Rəqəmlər və fut və düym işarələri (`'` və `"`) | {{ui:Uzunluq}} qutusuna uzunluq yazmağa başlayın; {{key:Enter}} onu istifadə edir |
| {{key:Enter}}, {{key:Esc}}, sağ klik və ya ikiqat klik | Çəkdiyiniz divarı bitirir; {{key:Esc}} yenidən {{ui:Seç}} rejiminə qaytarır |
| {{key:Delete}} | Seçilmiş divarları, qapıları və pəncərələri silir; qalan divarlar yenidən birləşir |
| Göstərici planın üzərindəykən {{key:F}} | Planı sığdırır |
| Çarx | Göstəricinin ətrafında miqyas |
| Orta və ya sağ düyməni sürüklə, ya da {{key:Space}} basıb sürüklə | Sürüşdür; {{ui:Seç}} aktivdirsə, adi sürükləmə də sürüşdürür |
| {{ui:Seç}} ilə qapı və ya pəncərəni sürüklə | Onu öz divarı boyunca və ya başqa divara köçürür |
| İki barmaq (toxunma) | Barmaqları açıb-yığmaqla miqyas, birlikdə hərəkət etdirməklə sürüşdürmə |

## Kitabxana elementlərini yerləşdirmək və yapışdırmaq

| Düymə | Nə edir |
|---|---|
| {{key:R}} | Elementi 90° fırladır |
| {{key:Tab}} | Divara bağlanmanı açır və bağlayır: elementin arxası ən yaxın divara düşür |
| {{key:Enter}} **X, Y (mm)** qutusunda | Yazılmış mövqeyə yerləşdirir |
| {{key:Esc}} | Yerləşdirməni və ya yapışdırmanı dayandırır |

## IFC dəyərlərinin redaktəsi

| Düymə | Nə edir |
|---|---|
| {{key:Enter}} | Yazdığınız dəyəri saxlayır |
| {{key:Esc}} | Ləğv edir və köhnə dəyəri geri qaytarır |
| Başqa yerə klik | Yazdığınız dəyəri saxlayır |
| {{key:Mod+Z}} | Son dəyişikliyi geri qaytarır. Yalnız saxlanmamış dəyişiklikləriniz olduqda və sahəyə yazmadığınız zaman |
| {{key:Mod+Y}} | Geri qaytarmanın geri aldığını təkrarlayır |
| {{key:Mod+S}} | IFC kimi saxlayır. Yalnız saxlanmamış dəyişiklikləriniz olduqda; əks halda brauzerin öz saxlama əmri açılır |

Yalnız klaviatura ilə redaktə etmək üçün dəyər seçilənə qədər {{key:Tab}} basın, sonra yazmağa başlamaq üçün {{key:Enter}} basın.

## 2D çertyojlar (DWG və DXF)

| Düymə və ya hərəkət | Nə edir |
|---|---|
| {{key:F}} | Çertyoju və ya vərəqi sığdırır |
| {{key:P}} | Çap görünüşünü açır və bağlayır |
| İkiqat klik | Sığdırır |
| İstənilən düymə ilə sürüklə | Sürüşdür |
| Çarx | Göstəricidə miqyas |
| Trackpad-də iki barmaqla sürüşdürmə və ya sıxma | Göstəricidə miqyas. İki barmaqla sürüşdürmə sürüşdürmür |
| Bir barmaq (toxunma) | Sürüşdürür. Çertyojlar üçün barmaqları açıb-yığmaqla miqyas hələ hazır deyil |

## 3D-də çertyojlar

| Düymə və ya hərəkət | Nə edir |
|---|---|
| {{key:3}} | 3D-ni açır və bağlayır (2D görünüşdə də) |
| {{key:F}} | Hüdudlar: bütün çertyoj |
| Orta və ya sol düyməni sürüklə | Orbit |
| Sağ düyməni sürüklə və ya {{key:Shift}} basıb sürüklə | Sürüşdür |
| Çarx | Göstəricinin altındakıya doğru miqyas |
| Trackpad-də iki barmaqla sürüşdürmə | Orbit; {{key:Shift}} ilə sürüşdür |
| Trackpad-də sıxma | Miqyas |
| Bir barmaq (toxunma) | Orbit |
