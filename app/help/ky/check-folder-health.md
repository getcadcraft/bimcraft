## Эмне кыласыз

Долбоордун папкасын тапшыруудан же аны менен иштөөнү баштоодон мурун текшериңиз: ар бир модель толукпу, кайсы резервдик көчүрмө акыркы жакшы экени жана бардык шилтеме кылынган файлдар бар бекен?

## Кадамдар: бузулган көчүрмөлөр

1. Долбоордун папкасын ачыңыз. Караңыз: [Долбоордун бүт папкасын ачуу](topic:open-project-folder).
2. Папка атынын астындагы эскертмелерди окуңуз. "2 файл толук эмес же окула албайт. Төмөндөгү моделдерди караңыз." деген жазуу бир нерсеге көңүл буруу керектигин билдирет.
3. **Модельдер** бөлүмүндөгү **Абал** мамычасын караңыз. **Толук** — жакшы. Сары "1 толук эмес" бир көчүрмө бузулган, бирок башка көчүрмө сапаттуу дегенди билдирет. Кызыл **Толук эмес** — сапаттуу көчүрмө табылган жок дегенди билдирет.
4. Көйгөйү бар моделдин астындагы **Бардык … көчүрмөлөр** баскычын ачыңыз. Ал негизги файлды жана ар бир номерленген резервдик көчүрмөнү, эң жаңысы биринчи болуп, өлчөмү, датасы жана абалы менен тизмелейт.
5. Тизменин үстүндөгү эскертмени окуңуз, мисалы: "Tower.rvt толук эмес (183.2 MB, кеминде 214.0 MB болушу керек). Карточка эң жаңы толук көчүрмөнү көрсөтөт: Tower.0012.rvt (Mar 3, 2025)."
6. Каалаган көчүрмөнү басып ачыңыз. Басууга болот, болгону толук көчүрмөлөр.

## Текшерүү эмнени кылат

Ар бир модельдин ар бир көчүрмөсүнүн башынын тез текшерүүсү жүрөт, ар бири 512 байт, ошондуктан ири моделдердин папкасы да секунддарда текшерилет. Өзүнүн индекси аягынан ашып кеткен файл көчүрүү, жүктөө же синхрондоо учурунда кесилген. Булут дискиндеги "онлайн гана" абалындагы файл да ушундай көрүнөт.

Модель картасы негизги файл сапаттуу болсо андан, болбосо эң жаңы сапаттуу резервдик көчүрмөдөн окулат.

## Кадамдар: жоголгон шилтемелер

1. Папка атынын астындагы "*n* шилтеме кылынган файл бул папкада жок." деген эскертмени табыңыз.
2. **Шилтеме кылынган жана шилтеме берилген файлдар** бөлүмүнө өтүңүз. Жоголгон шилтемелер биринчи тизмеленет.
3. Ар бир шилтеме үчүн **Кайда** мамычасын окуңуз:
   - **Бул папкада**: модель сактаган жолдо табылды.
   - **Бирдей аттуу табылды**: папкада башка жерде ушул аттагы файл бар. Туура экенин текшериңиз.
   - **Китепкана файлы**: ачкычтык тексттердин (keynote) же жыйнак коддорунун таблицасы. Алар ар бир компьютерде программа менен бирге келет, ошондуктан папкада күтүлбөйт.
   - **Бул папкада жок**: папканын ичинен эч жерден табылган жок.
4. Ар бир файлды кайсы моделдер шилтеме кылганын **Колдонулат** мамычасынан окуңуз.

BimCraft ар бир шилтемени адегенде салыштырмалуу жолу боюнча, андан кийин сакталган жолдун аягы боюнча (мисалы, `\\server\jobs\Tower\Cad\X-Refs\site.dwg` `Cad` папкасын тандасаңыз `X-Refs/site.dwg` катары табылат), анан папканын ичинде файл аты боюнча издейт.

## Кадамдар: калдыктар

1. Отчеттун аягындагы **Бөлүнгөн** бөлүмүнө өтүңүз.
2. Пайда болушу мүмкүн болгон үч сапты окуңуз:
   - Кызмат папкалары (`*_backup`, `*_log`, `Revit_temp`): окулбайт.
   - Кулпу, журнал жана резервдик калдыктар: `.dwl`, `.dwl2`, `.bak`, `.err`, `.log`, `.tmp`, `.sv$` сыяктуу файлдар. Аларды папка көчүрүлгөндө кулаган же ачык турган программалар калтырат. Файлдарды эч ким ачпаган болсо, адатта аларды өчүрүүгө коопсуз.
   - Башка файлдар: BimCraft окубаган бардык башка нерселер.

## Кеңири таралган каталар

- **Бузулган негизги файлды, сапаттуу резервдик көчүрмө сакталганга чейин өчүрүү.** Адегенде эң жаңы толук резервдик көчүрмөнү көчүрүңүз, андан кийин бузулган файл менен иш кылыңыз.
- **"Бирдей аттуу табылды" дегенге так ишенүү.** Эки башка чийме бир атты бөлүшүшү мүмкүн. Шектенсеңиз, экөөн тең ачыңыз.
- **Жоголгон китепкана файлын көйгөй деп ойлоо.** Ачкычтык тексттердин жана жыйнак коддорунун таблицалары ар бир компьютердеги программа менен бирге жашайт.
- **Файлдардын саны браузерлерде ар башка.** Firefox жана Safari'де {{ui:Папканы ачуу}} кызмат папкаларынын ичиндегилерди кошо бардык файлдарды берет, ошондуктан санына (жана 20,000 файлдык чекке) алар да кирет. Папканы сүйрөп киргизсе, Chrome жана Edge сыяктуу алар өткөрүлүп жиберилет. Отчет башка жагынан бирдей.
