## Көчүрмөнүн статусу

Модлинин ар бир көчүрмөсү — негизги файл да, номерленген резервдик көчүрмөлөр да — башчы текшерүүдөн өтөт.

| Белги | Мааниси |
|---|---|
| **Толук** | Файлдын башы жана индекси файлдын ичине сыйат |
| **Толук эмес** | Файл өзүнүн индексинде айтылгандан кыска: ал көчүрүлгөндө, жүктөлгөндө же синхрондолгондо кесилген, же ал али «онлайн гана» болгон булут файлы |
| **Окулбай турат** | Файл жараксыз компаунд файл же окулган эмес |

**Статус** мамычасында модель **Толук** көрсөтөт; эгер бир көчүрмө начар, бирок башкасы сапаттуу болсо — сары «*n* толук эмес»; эч бир көчүрмө сапаттуу болбосо — кызыл **Толук эмес**.

## Резервдик көчүрмөлөр

`Name.0001.rvt`, `Name.0002.rvt` ж.б. сандалган файлдар `Name.rvt` файлынын резервдик көчүрмөлөрү. Алар моделинин астында, эң жаңысы биринчи, **Бардык … көчүрмө** бөлүмүндө топтолот. Карта негизги файлдан окулат, эгер ал толук болсо, же болбосо эң жаңы толук резервдик көчүрмөдөн («эң жаңы толук»).

## Ролдор

Модлинин аты астында *курсив* менен көрсөтүлөт.

| Роль | Мааниси |
|---|---|
| *Башка модель* тарабынан шилтемеленген: фон | Папкадагы башка модель муну шилтемелейт, ошондуктан бул башка адамдын фону болушу мүмкүн, мисалы кеңешчинин модели |
| Баштапкы же аталбаган файл | `Blank`, `Template`, `Default`, `Untitled` же `Project1` сыяктуу ат: баштапкы чекит же так аталбаган файл |
| Борбордук модель | Бирге иштелген борбордук модель. Иш жергиликтүү көчүрмөдө жүрөт, бул жерде эмес |
| Бөлүк (детали) | `.rfa` же `.rft` файлы: проект эмес, компонент |
| Резервдик көчүрмөлөр гана | Негизги файл жок, бир гана номерленген резервдик көчүрмөлөр калды |

## Бул жерден баштаңыз кантип тандалат

BimCraft тажрыйбалуу колдонуучу колдонгон жүйөөнү колдонот:

1. Талапкерлер — башка модель шилтемелебеген жана баштапкы эмес окула турган долбоор файлдары (`.rvt`, `.rte`).
2. Борбордук жана резервдик көчүрмөлөрдөн гана турган моделдер, жакшыраак эч нерсе жок болсо гана эсепке алынат.
3. Талапкерлердин ичинен акыркы сакталган жеңет.

Кутуда тандоонун себептери тизмеленет жана көрүнүктүү тандоо болуп көрүнгөн файл бузулган болсо, башка модельдер фон болсо же тандоо борбордук модель болсо, эскертет. Бул эң жакшы болжол; долбоор акыркы жолу ким иштегенин текшериңиз.

## Шилтеме статусу

| Белги | Мааниси |
|---|---|
| **Бул папкада** | Сакталган салыштырма жол боюнча же папканын ичинде сакталган толук жолдун аягында табылды |
| **Ошол эле ат табылды** | Өз жолунда эмес, бирок папкада ошол эле аттагы файл бар. Туура экенин текшериңиз |
| **Китепкана файлы** | Ачкыч сөздөрдүн же курулуш коддорунун таблицасы. Алар ар бир компьютерде программа менен бирге келет |
| **Бул папкада жок** | Папканын бир жеринен да табылган жок |

**Табылган шилтемелер** мамычасы **Моделдер** бөлүмүндө моделдин шилтемелеринин канчасы табылганын көрсөтөт, папкада күтүлгөндөрдүн арасынан (китепкана файлдары эсепке алынбайт).
