Кошумча (**Жөндөөлөр › Кошумчалар**) {{ui:Рендер}} диалогунун Механизмдер тизмесине механизм кошо алат. Кошумча авторлору үчүн толук текст кошумчанын спецификациясынын 16-бөлүмүндө; кыскача:

- Кошумча механизмди өзүнүкү менен башталган id, аталыш, милдетсиз жөндөөлөр жана **же** иштетилүүчү программа, **же** сүрөттү тарткан JavaScript функциясы менен катташтырат.
- Программаны иштеткен механизмге **`engine.run`** уруксаты керек; ал орнотуудан мурун жана Жөндөөлөрдө көрсөтүлөт. Ал бир гана Studio'до иштейт; браузерде ал сактоо үчүн файл катары көрүнөт.
- Кошумча программанын атын (жөнөкөй файл аты гана, эч качан кабык эмес), **кол коюлган кошумчанын ичиндеги** скриптти жана орун басар белгилерден жана жөнөкөй сөздөрдөн турган аргументтерди аныктайт. Studio программаны табат же аны бир жолу көрсөтүп коюуңузду сурайт.
- Кошумча программаны биринчи жолу иштеткенде, **Studio өзүнүн диалогунда сурайт**: кайсы кошумча, кайсы программа жана скрипт программа кыла ала турган бардык нерсени кыла аларын. Аны бир гана ишенимдүү кошумчага уруксат бериңиз. Сиздин жообуңуз ошол кошумча жана программа үчүн эсте калат.
- Пакет (сахна USD катары жана жөндөөлөр файлы, кошумча сураганда glTF файлы менен) жана кошумчанын скрипти жаңы убактылуу папкага салынат, программа ошол жерде иштейт, ал эми сүрөт кошумчанын механизминин аты менен белгиленип кайтып келет.

:::note
Кошумчалар рендер механизмдерин бир гана кошумча API 1.4ден баштап коше алат. Ачык булактуу буйрук сабынан иштеген рендерер үчүн мисал өзүнчө репозиторийде; ал али ошол рендерерде иштетилген эмес.
:::
