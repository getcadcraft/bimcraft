## Эмне кыласыз

**Долбоордун топтомун** (`.ccbundle.zip`) ачып, долбоор уюшулгандай иштеңиз: анын көрүнүштөрү, макеттери жана касиеттер топтомдору, модельдин үстүндө.

Топтомдо:

- модель IFC катары,
- макеттер PDF жана DWG катары,
- IFC калтырган нерселердин тизмеси: көрүнүштөр (ар бири кабаты, катмарлардын айкалышы жана масштаби менен), макеттер жана алардын үстүнө коюлган чиймелер, касиеттердин аныктамалары топтомдорунда, классификациялар жана стандарттар: катмарлар, калем топтомдору, сызык түрлөрү, штриховкалар, беттер жана композиттер.

Топтомдорду ачык булактуу скрипт жазат; ал Archicad ичинде иштеп, тизмелерди Archicad'дын өзүнөн сурайт. BimCraft `.pln` же `.tpl` файлдарын түз окубайт; караңыз: [.pln жана .pla долбоор файлдарын ачуу](topic:pln-project-files).

## Топтом жасоо

Скрипт алдын ала көрүү: ал дагы бардык Archicad версияларында сыналган эмес. Аны [github.com/getcadcraft/bim-project-bundle](https://github.com/getcadcraft/bim-project-bundle) дарегинен алыңыз. Archicad 24 же андан жаңы версиясы жана Python 3.8 же андан жаңы версиясы керек; башка эч нерсе орнотулбайт.

1. `archicad_bundle.py` файлын папкага сактаңыз, мисалы `C:\cc-bundle`.
2. Archicad'та долбоорду ачып, так **CadCraft bundle** аталышындагы жарыялоо жыйнагын түзүңүз: 3D көрүнүш IFC катары, ар бир макет PDF катары, жана ар бир макет дагы DWG катары, бир жалпак папкада диск файлдарына жарыяланат.
3. Долбоор ачык турганда `python archicad_bundle.py --probe --out .` буйругун бир жолу иштетиңиз. Ал окуу гана жасайт жана `probe.json` файлын жазат.
4. `python archicad_bundle.py --out . --translator "IFC4 Reference View"` иштетиңиз (тандаган IFC которгучту колдонуңуз). Archicad жыйнакты жарыялайт, ал эми скрипт `<project>.ccbundle.zip` файлын жазат.

Скрипт аркылуу жарыялоо ийгиликсиз болсо, жыйнакты кол менен жарыялаңыз жана `python archicad_bundle.py --out . --no-publish --files <folder>\*.ifc <folder>\*.pdf <folder>\*.dwg` иштетиңиз. Бардык опциялар репозиторийдин README файлында. Бир нерсе жетпесе, ошол жерде көйгөй ачып, `probe.json` тиркеңиз.

## Топтомду ачуу

1. {{ui:Choose a file}} баскычын басыңыз же `.ccbundle.zip` файлын BimCraft'ка таштаңыз. {{ui:Open a folder}} менен ачкан папкада топтомдор **Долбоордун топтомдору** астында тизилет; аты менен басыңыз.
2. Модель кадимкидей IFC сыяктуу ачылат, ал эми **Долбоордун топтому** бөлүмү сол жагында, файлдын фактыларынын астында пайда болот.

Эч нерсе жүктөлбөйт: топтом сиздин компьютериңизде бир файл-бир файлдан окулат, ошондуктан чоң модель эки жолу көчүрүлбөйт.

## Көрүнүштү көрсөтүү

**Көрүнүштөр** астында көрүнүштөр долбоордогу папкалар боюнча топтолот. Көрүнүштүн атын басыңыз:

- **Кабаттын планы** анын кабатын гана көрсөтөт, үстүнөн караганда.
- **Анын катмарлардын айкалышы** ошол айкалыш жашырган катмарлардагы элементтерди жашырат. Абал сабы канча элемент жашырылганын айтат.
- **Анын масштаби** аттын жанында жана абал сабында көрүнөт.
- **3D көрүнүш** бардык кабаттарды көрсөтөт.

Баарын кайра көрсөтүү үчүн {{ui:Show}} ичиндеги {{ui:Show all}} баскычын колдонуп, бардык кабаттарды белгилеңиз.

:::note
BimCraft катмарларды IFC файлынын катмар дайындоолору аркылуу табат. IFC алар жок экспорттолгон болсо, катмарлардын айкалышы эч нерсени жашырбайт, жана абал сабы 0 элемент жашырылганын көрсөтөт.
:::

## Макетти ачуу

**Макеттер** астында ар бир макет өзүнүн номерин, атын, кагаз өлчөмүн жана ага коюлган көрүнүштөрдү көрсөтөт.

- **PDF** макеттин PDF файлын топтомдон сактайт.
- **DWG** макеттин чиймесин 2D көрүнүштө ачат. Моделге кайтуу үчүн каалаган көрүнүштү басыңыз.
- **Ичинде ачуу …** макеттин файлын аны иштеткен колдонмого жаңы өтмөктө жөнөтөт: PDF — MarkupCraft'ка, DWG — CadCraft'ка. Бул колдонмо BimCraft'тын жанында ачык болгондо гана көрүнөт. Файл өтмөк жүктөлүп жатканда топтомдон окулат, эч нерсе жүктөлбөйт.

Эч файлы жок макетте **Топтомдо файл жок** деп жазылат.

## Касиеттерди долбоордун топтомдорунда көрүү

Элементти тандаңыз. **Касиеттер топтомдору** анын касиеттерин долбоор аныктаган топтомдордун астында көрсөтөт; алар касиет топтому жана аты аркылуу дал келтирилет, же аныктама IFC үчүн берген аты боюнча, же аты боюнча. Калгандары адаттагыдай {{ui:Properties}} бөлүмүндө калат. **Касиеттердин аныктамалары** ар бир аныктаманы анын тобу, түрү жана IFC аты менен тизет.

## Стандарттар жана эскертмелер

- **Стандарттар** топтомдогу катмарларды, катмар айкалыштарын, калем топтомдорун, сызык түрлөрүн, штриховкаларды, беттерди, композиттерди жана материалдарды санайт.
- **Эскертмелер** скрипт ошол Archicad версиясынан ала албаган нерселерди, BimCraft окуй албаган ар бир талааны жана топтом аты атаган, бирок ичинде жок файлдарды тизет.

## Көйгөйлөрдү чечүү

- **« … zip, бирок долбоордун топтому эмес. »** Zip'те `manifest.json` жок. Ачып, ичиндеги `.ifc` файлын ачыңыз.
- **« … BimCraft окуй турган версиядан жаңы долбоордун топтому. »** BimCraft'ты жаңыртыңыз.
- **« … манифест аттаган модельди камтыбайт. »** Zip кыска кесилген же өзгөртүлгөн. Топтомду кайра жасаңыз.
- **Көрүнүш бардык кабаттарды көрсөтөт.** Анын кабаты модельдин IFC файлында жок (абал сабы ушуну айтат). IFC экспорту ошол кабатты камтыганын текшериңиз.
