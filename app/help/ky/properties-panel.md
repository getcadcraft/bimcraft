## IFC элемент

{{ui:Касиеттер}} панелинин жогору жагында элементтин түрү «Ifc» префиксисиз көрсөтүлөт (мисалы, "Door", "WallStandardCase", "FurnishingElement") жана анын аты, же «Аты жок».

| Талаа | Мааниси | Өзгөртсө болот |
|---|---|---|
| Аты | Элементтин аты, көбүнчө экспорттоочудан үй-бүлө жана түрдүн аты | Ооба |
| Түрү | Элементтин түрүнүн аты, эгер бар болсо | Жок |
| Объекттин түрү | Кээ бир экспорттоочулар толтурган эркин текст түрүнүн сүрөттөмөсү | Ооба |
| Белги | Элементтин белгиси же маркасы; көп экспорттоочулар бул жерге элементтин ID жазышат | Ооба |
| Сүрөттөмө | Эркин текст | Ооба |
| GlobalId | Элементтин туруктуу 22 белгилүү IFC идентификатору, бир эле элементтин ар бир экспортунда бирдей | Жок |
| Сап | Элементтин саптык номери (`#1234`) бул IFC файлында. Экспорттор арасында өзгөрөт | Жок |

Андан кийин **касиеттер топтомдору** аты боюнча иреттелип көрсөтүлөт:

- Ар бир топтом аты басылганда ачылат же жабылат. Биринчи үчөө ачык.
- «(type)» белгиси менен топтом элементтин түрүнө таандык: «Түр касиети: бул жердеги өзгөртүү ушул түрдөгү ар бир элементке колдонулат».
- Саны топтомдору (узундуктар, аянттар, көлөмдөр, саналар, салмактар) окууга гана.
- Тизмелер жана санаалуу маанилер көрсөтүлөт, окууга гана.
- Ооба/Жок маанилер **Ооба** же **Жок** болуп көрсөтүлөт.
- Сандар көрсөтүү үчүн төрт ондук орунга чейин тегеректелет. Узундуктар (узундук касиети же саны топтомунун узундугу) {{ui:Бирдиктер}} менен көрсөтүлөт, жанында бирдик белгиси менен, жана ошол бирдикте же башка бирдик белгиси менен (2.4 m, 8'-0") жаңы маани жаза аласыз: BimCraft файлдын өз санын кайра жазат. Башка сандар файлдагыдай көрсөтүлөт.
- Бош маани *бош* деп көрсөтүлөт. Өзгөртүлгөн маани калың жана жанында көк тилке менен болот.

## Маанини көчүрүү

{{ui:Касиеттер}} панелиндеги ар бир маанинин жанында кичине көчүрүү баскычы бар: аны басканда ал маани көрсөтүлгөндөй буферге көчүрүлөт, мисалы GlobalId, сериялык номер же ар кандай касиет топтомунун мааниси. Көчүрүү эч качан түзөтүүнү баштабайт.

Жогоруда {{ui:Баарын көчүрүү}} элементтин бардык маанилерин топтом-топтом текст катары көчүрөт; {{ui:CSV катары көчүрүү}} топтом, касиет жана маани катарлары катары көчүрөт, электрондук таблицага чаптоо үчүн; бош маанилер сакталат, ар бир талаа катарга ээ болот. Бул башка ачык моделдин элементи үчүн дагы бирдей иштейт; бир нече модель ачык болсо, CSV «Модель» тилкеси менен башталат, ал файлдын атын көрсөтөт.

## Файл панели (IFC)

| Талаа | Мааниси |
|---|---|
| Файл, Өлчөмү | Сиз ачкан файл |
| Схема | IFC версиясы, мисалы IFC2X3 же IFC4 |
| Долбоор | Долбоордун аты жана узун аты |
| Фаза | Долбоордун фазасы, эгер экспорттоочу жазган болсо |
| Экспорттолгон программа | Файлдын башындагы экспорттоочу программа |
| Автор | Файлдын башындагы автор |
| Экспорттолгон күнү | Файлдын башындагы дата жана убакыт |
| Элементтер | Формасы менен чийилген элементтердин саны |
| Үч бурчтуктар | Алардын формалары канча үч бурчтук жасайт; моделдин канчалык оор экенин өлчөө |

## Файл панели (долбоор жана семейство файлдары)

| Талаа | Мааниси |
|---|---|
| Түрү | Долбоор, Долбоордун үлгүсү, Семейство же Семейство үлгүсү |
| Сакталган версия | Акыркы сактаган релиз |
| Курама | Ошол релиздин так курамасы |
| Окулду | BimCraft файлдын канчасын окуганы, анын өлчөмүнө карата |

## Чийме панели (DWG жана DXF)

| Талаа | Мааниси |
|---|---|
| Формат | Чийме сакталган релиз, формат коду менен, мисалы AC1032 |
| Бирдиктер | Чийменин киргизүү бирдиктери, эгер коюлган болсо |
| Объекттер | Канча объект окулду |
| Катмарлар | Канча катмар |
| Барактар | Канча барак (макеттер), же Жок |
| Байланышкан чиймелер | Анын байланышкан чиймелеринен канчасы табылып жүктөлдү |
| Жабдуулар | Барактарда канча белгиленген жабдуу бар |

## Папка панели

| Талаа | Мааниси |
|---|---|
| Папка, Файлдар, Өлчөмү | Ачкан папкаңыз, анда канча файл бар жана алардын жалпы өлчөмү |
| Моделдер | Долбоор жана семейство файлдары, ар бири резервдик көчүрмөлөрү менен бир эсепте |
| CAD чиймелери, IFC моделдери | Ар биринен канча |
| Көйгөйлөр | Канча модель көчүрмөсү толук эмес же окулбайт, же Жок |
