BimCraft'та ыкчам жолдор аз. Көп иш чычкан жана панелдер менен жасалат. {{key:Mod}} менен жазылган ыкчам жолдор Mac'те Command, башка жерлерде Ctrl колдонот. Баскычтар бул жардамда кандай жазылганын [Баскычтар, чычкандар жана сенсордук панельдер](common:keys) бөлүмүнөн караңыз.

## Бардык жерде

| Баскыч | Эмне кылат |
|---|---|
| {{key:Ctrl+Shift+F}} | Экран режимдерин айлантат: кадимки, толук экран, баштыктар жашырылган толук экран. Ctrl бардык платформада, Mac'те да |
| {{key:Esc}} | Толук экрандан чыгат |
| {{key:Mod+,}} | {{ui:Жөндөөлөр}} ачат. [BimCraft жөндөөлөрү](topic:settings) караңыз |
| {{key:Tab}} | Баскычтардын, белгилер кутучаларынын жана маанилердин ортосунда жылат. Ар бир башкаруу элементине клавиатура менен жетсе болот |

## 3D көрүнүш (IFC моделдери)

| Баскыч же аракет | Эмне кылат |
|---|---|
| {{key:F}} | Бүт моделди үч чейрек көрүнүштө сыйдырат ({{ui:Сыйдыруу}} менен бирдей) |
| {{key:Esc}} | Тандоону тазалайт же жайгаштырууну/чаптоону токтотот |
| Басуу | Көрсөткүч астындагы элементти тандайт; бош фонду басуу тандоону тазалайт |
| {{key:Mod}}+басуу же {{key:Shift}}+басуу | Элементти тандоого кошот же андан чыгарат |
| {{key:H}} | Тандалган элементтерди жашырат. [Элементтерди жашыруу, бөлүү жана аркылуу көрүү](topic:hide-and-isolate) караңыз |
| {{key:I}} | Тандалган элементтерди гана көрсөтөт (бөлүү) |
| {{key:T}} | Тандалган элементтерди көрсөтөт, калгандары аркылуу көрүнөт |
| {{key:Shift+H}} | Бардык элементтерди кайра көрсөтөт |
| {{ui:Сейилдөө}} | Андан кийин {{key:W}} {{key:A}} {{key:S}} {{key:D}} же жебе баскычтары менен сейилдейсиз, {{key:Shift}} чуркатат, сүйрөө айланат, {{key:Esc}} токтотот. [Модель боюнча сейилдөө](topic:walk) караңыз |
| {{key:M}} | Аралыктарды жана бет аянттарын өлчөйт. [Аралыктарды, бет аянттарын жана 3D жайгашууларды өлчөө](topic:measure) караңыз |
| Сол баскыч менен сүйрөө | Айлантуу |
| Оң баскыч менен сүйрөө | Жылдыруу |
| {{key:Shift}} же {{key:Mod}} жана сол баскыч менен сүйрөө | Жылдыруу (сенсордук панелде ыңгайлуу) |
| Дөңгөлөктү жылдыруу же орто баскыч менен сүйрөө | Чоңойтуу |
| Сенсордук панелде эки манжа менен жылдыруу же кысуу | Чоңойтуу |
| Бир манжа (сенсор) | Айлантуу; басуу тандайт |
| Эки манжа (сенсор) | Кысып чоңойтуу, бирге жылдырганда жылдыруу |

| {{key:X}} | Кесим тегиздигин күйгүзөт/өчүрөт. [IFC моделин кесим тегиздиги менен кесүү](topic:section-plane) караңыз |
| {{key:Shift+X}} | Тандалган элементтердин айланасында кесим кутусу, Жөндөөлөрдөгү бөлмө менен |

{{ui:Үстү}}, {{ui:Алды}} жана {{ui:Капталы}} үчүн баскычтар жок; баскычтарды колдонуңуз.

## Оңдоо

Ошол эле буйруктор куралдар тилкесинде бар: {{ui:Артка кайтаруу}}, {{ui:Кайра аткаруу}}, {{ui:Көчүрүү}}, {{ui:Чаптоо}} жана {{ui:Дагы}} менюсу, ал ар бир баскычты көрсөтөт. Алар IFC моделинин 3D көрүнүшүндө иштейт, талаага текст терип жатканда эмес. [Китепкана элементтерин көчүрүү, чаптоо жана көчүрмөсүн түзүү](topic:copy-paste) караңыз.

| Баскыч | Эмне кылат |
|---|---|
| {{key:Mod+Z}} | Акыркы өзгөртүүнү артка кайтарат |
| {{key:Mod+Y}} же {{key:Mod+Shift+Z}} | Артка кайтарылганды кайра аткарат |
| {{key:Mod+C}} | Тандалган элементтерди көчүрөт (аттары жана касиеттери текст катары алмашуу буферине да барат) |
| {{key:Mod+X}} | Тандалган элементтерди кесет: көчүрүп, андан кийин өчүрөт |
| {{key:Mod+V}} | Көчүргөнүңүздү чаптайт: көрсөткүчтү ээрчийт, басып койгон жериңизге барат |
| {{key:Mod+Shift+V}} | Ордунда чаптайт: кесилген жерге, же көчүргөндөн кийин түп нускалардын жанына |
| {{key:Mod+D}} | Көчүрмө түзөт: тандалган элементтерди көчүрүп, чаптоону баштайт |
| {{key:Delete}} | Тандалган элементтерди, алардын бөлүктөрү жана тешиктери менен өчүрөт. [Курулуш элементтерин өчүрүү, кесүү, көчүрүү жана чаптоо](topic:edit-elements) караңыз |
| {{key:Mod+A}} | Көрсөтүлгөн ар бир элементти тандайт |
| {{key:Esc}} | Эч нерсе тандабайт |

Беттеги текст тандалганда, {{key:Mod+C}} ал текстти адаттагыдай көчүрөт.

## План көрүнүшү (Чийүү)

Булар {{ui:Чийүү}} күйгүзүлүп турганда жана талаага текст терип жатпаганыңызда иштейт. [Дубалдарды чийүү](topic:draw-walls) жана [Эшиктер жана терезелер](topic:doors-and-windows) караңыз.

| Баскыч же аракет | Эмне кылат |
|---|---|
| {{key:V}} | {{ui:Тандоо}} |
| {{key:W}} | {{ui:Дубал}} |
| {{key:D}} | {{ui:Эшик}} |
| {{key:N}} | {{ui:Терезе}} |
| {{key:H}} | {{ui:Эшик}} же {{ui:Терезе}} менен: топсалар башка учунда |
| Дубалды чийип жатканда {{key:Shift}} | Аны 0°, 90°, 180° же 270° бурчта кармайт |
| Сандар жана фут/дюйм белгилери (`'` жана `"`) | {{ui:Узундугу}} кутучасына узундукту терип баштайт; {{key:Enter}} аны колдонот |
| {{key:Enter}}, {{key:Esc}}, оң баскыч же эки жолу басуу | Чийип жаткан дубалды бүтүрөт; {{key:Esc}} дагы бир жолу {{ui:Тандоо}} режимине кайтарат |
| {{key:Delete}} | Тандалган дубалдарды, эшиктерди жана терезелерди өчүрөт; калган дубалдар кайра туташат |
| Көрсөткүч план үстүндө болгондо {{key:F}} | Планды сыйдырат |
| Дөңгөлөктү жылдыруу | Көрсөткүч тушунда чоңойтуу |
| Орто же оң баскыч менен сүйрөө, же {{key:Space}} жана сүйрөө | Жылдыруу; {{ui:Тандоо}} күйгүзүлгөндө жөнөкөй сүйрөө да жылдырат |
| {{ui:Тандоо}} менен эшик же терезени сүйрөө | Аны дубалы боюнча же башка дубалга жылдырат |
| Эки манжа (сенсор) | Кысып чоңойтуу, бирге жылдырганда жылдыруу |

## Китепкана элементтерин жайгаштыруу жана чаптоо

| Баскыч | Эмне кылат |
|---|---|
| {{key:R}} | Элементти 90° бурат |
| {{key:Tab}} | Дубалга жабышууну күйгүзөт/өчүрөт: элементтин арткы бети эң жакын дубалга тийет |
| **X, Y (mm)** талаасында {{key:Enter}} | Терилген жайгашууга коёт |
| {{key:Esc}} | Жайгаштырууну же чаптоону токтотот |

## IFC маанилерин өзгөртүү

| Баскыч | Эмне кылат |
|---|---|
| {{key:Enter}} | Терилген маанини сактайт |
| {{key:Esc}} | Токтотуп, эски маанини калыбына келтирет |
| Башка жерди басуу | Терилген маанини сактайт |
| {{key:Mod+Z}} | Акыркы өзгөртүүнү артка кайтарат. Сакталбаган өзгөртүүлөр бар учурда гана жана талаага текст терип жатпаганыңызда |
| {{key:Mod+Y}} | Артка кайтарылганды кайра аткарат |
| {{key:Mod+S}} | IFC катары сактайт. Сакталбаган өзгөртүүлөр бар учурда гана; болбосо браузердин өз сактоо буйругу ачылат |

Клавиатура менен гана өзгөртүү үчүн: маани белгиленгенче {{key:Tab}} басыңыз, андан кийин терүүнү баштоо үчүн {{key:Enter}} басыңыз.

## 2D чиймелер (DWG жана DXF)

| Баскыч же аракет | Эмне кылат |
|---|---|
| {{key:F}} | Чиймени же баракты сыйдырат |
| {{key:P}} | Басып чыгаруу көрүнүшүн күйгүзөт/өчүрөт |
| Эки жолу басуу | Сыйдыруу |
| Каалаган баскыч менен сүйрөө | Жылдыруу |
| Дөңгөлөктү жылдыруу | Көрсөткүч жанында чоңойтуу |
| Сенсордук панелде эки манжа менен жылдыруу же кысуу | Көрсөткүч жанында чоңойтуу. Эки манжа менен жылдыруу жылдырбайт |
| Бир манжа (сенсор) | Жылдыруу. Чиймелер үчүн кысып чоңойтуу али жок |

## 3D чиймелер

| Баскыч же аракет | Эмне кылат |
|---|---|
| {{key:3}} | 3D күйгүзөт/өчүрөт (2D көрүнүштө да) |
| {{key:F}} | Чектер: бүт чийме |
| Орто же сол баскыч менен сүйрөө | Айлантуу |
| Оң баскыч менен сүйрөө, же {{key:Shift}} жана сүйрөө | Жылдыруу |
| Дөңгөлөктү жылдыруу | Көрсөткүч астындагыга карай чоңойтуу |
| Сенсордук панелде эки манжа менен сыпыруу | Айлантуу; {{key:Shift}} менен жылдыруу |
| Сенсордук панелде кысуу | Чоңойтуу |
| Бир манжа (сенсор) | Айлантуу |
| Эки манжа (сенсор) | Кысып чоңойтуу, бирге жылдырганда жылдыруу |

{{key:F}}, {{key:P}} жана {{key:3}} талаага текст терип жатканда, жабдуулар таблицасы көрсөтүлүп турганда же {{key:Mod}} же {{key:Alt}} кармап турганыңызда эч нерсе кылбайт.
