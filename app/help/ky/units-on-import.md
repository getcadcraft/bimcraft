## Эмне кыласыз

Файлды киргизип, ал туура өлчөмдө келерине ынаныңыз.

## Кадамдар

1. Файлды адаттагыдай ачыңыз же кошуңуз: {{ui:Ачык}}, Китепкананын {{ui:Файлдар}}, {{ui:Чекиттик булуттар}}, же Куруу › Чиймеден.
2. Эгер файл өз бирдиктерин көрсөтсө, эч нерсе суралбайт. Статус сабында файл кайсы бирдиктерди көрсөткөнү айтылат.
3. Көрсөтпөсө, диалог **файлдын бирдиктерин** сурайт. Файлдагы бир бирдик эмне экенин тандап, {{ui:Бул бирдиктерди колдонуу}} баскычын басыңыз. Жообуңузду бергенге чейин эч нерсе жайгаштырылбайт.
4. {{ui:Жокко чыгаруу}} (же {{key:Esc}}) эч нерсени киргизбейт.

## Кайсы файлдар бирдиктерин көрсөтөт

- **IFC**: узундук бирдигин көрсөтөт, «Ачылды» деген жазуу кайсынысы экенин айтат. Бирдикти көрсөтпөгөн IFC ачылардан мурун сурралат; жообуңуз моделге жазылат, ошондуктан сактагандан кийин файл аны бир жолу көрсөтөт.
- **DWG жана DXF**: чийменин киргизүү бирдиктери. Аларсыз чийме сурайт (Китепкананын файлдары, Куруу › Чиймеден, контурлардан рельеф).
- **Рельеф үчүн чекиттердин тизмелери**: бирдик көрсөтпөйт. Сизден сурашат.
- **Чекиттик булуттар**: координаттар системасы бар LAS жана LAZ, E57, PTX жана PLY өз бирдиктерин көрсөтөт. Калгандары жөнүндө сурашат.
- **OBJ жана STL**: эч качан бирдик көрсөтпөйт. Сизден сурашат.
- **glTF жана GLB**: метр, формттун өз эрежеси боюнча.
- **Сүрөттөр**: өз өлчөмү жок. Сүрөт көрүнүшкө ылайыкташтырылат, анын өлчөмүн **Эки чекит боюнча масштабдоо** менен коюңуз. Берген өлчөмүңүз ошол файл үчүн эстелет: кайра жайгаштырганда ал ошол өлчөмдө киргизилет жана статус саты муну билдирет.
- **Чекиттик булуттар кошумчасы**: бирдик көрсөтпөгөн файлдан булут курганда сурайт жана булуттун сандарын ал алып жүргөн бирдикте белгилейт.

## Пайдалуу маалымат

- Жооп ошол файл үчүн (анын аты, өлчөмү жана датасы) ушул компьютерде, бардык CadCraft колдонмолорунда эстелет. Ошол эле файл кийинки жолу киргизилгенде сурашпайт, жана статус сабы эстелген бирдиктер колдонулганын билдирет.
- Кайра суроо үчүн: буйрук палитрасы ({{key:Mod+K}}) › **Киргизилген файлдардын бирдиктерин кайра суроо**.
- Импорт учурунда бар бирдиктер тизмелери (Китепкананын **Бирдиктери**, булут тилкесинин **Бирдиктери**, Куруу › Чиймеден ичиндеги **Чийменин бирдиктери**) импорттон кийин да бирдиктерди өзгөртөт. Рельеф куралынын **Бирдиктер** тизмеси азыр жөн гана суроонун башталыш нуктасы.
