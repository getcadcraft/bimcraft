## Эмнени аткарасыз

Долбоор же семейство файлында эмне бар экенин Revit'те ачпай туруп билиңиз: аны кайсы релиз сактаганын, бирге иштөө бар-жогун, долбоор маалыматын жана эмнеге шилтеме жасаганын. Башка адамдан файл келгенде, аны кайсы релизде ачуу керектигин билүү үчүн пайдалуу.

## Кадамдар

1. {{ui:Файлды тандоо}} баскычын басыңыз.
2. `.rvt`, `.rfa`, `.rte` же `.rft` файлын тандаңыз.
3. Бир аз күтүңүз. Статус сабы «Файл окулуп жатат…» дейт, андан кийин «Ачылды *файлдын аты*».
4. Карточканын үстүндө караңыз: файлда сакталган алдын ала көрүү сүрөтү, файлдын түрү жана сакталган релиз, долбоордун аты.
5. Карточканын бөлүмдөрүн окуу үчүн ылдый жылдырыңыз.

## Эмнени көрөсүз

Ортодогу карточка, файлда бар болсо, бул бөлүмдөр менен:

| Бөлүм | Эмне айтат |
|---|---|
| Файл | Файлдын аты, өлчөмү, түрү (долбоор, долбоордун үлгүсү, семейство же семейство үлгүсү), сакталган релиз жана курама, бирге иштөө, борбордук модельдин жолу, акыркы сакталган жер, ким сактаган, тил жана документтин GUID |
| Долбоор маалыматы | Долбоордун өз талаалары, мисалы аты, номери, кардар, дарек жана статус. Жаңы долбоордун демейки маанилеринде калган талаалар алынып салынат. |
| Семейство, Семейство: … | Семейство үчүн: аты, категориясы, релизи, акыркы жаңыртуусу жана анын параметрлери, топ-топ менен |
| Шилтеме берилген жана шилтеме файлдары | Файл шилтеме кылган ар бир модель, CAD шилтемеси, сүрөт жана ачкыч таблица, сакталган жолу менен |

Сол жакта {{ui:Файл}} панели негизги фактыларды кайталайт жана **Окулду** кошот: BimCraft файлдын канчасын так окуганы, адатта көп мегабайттык файлдын болжол менен 40 KB. Оң жакта {{ui:Касиеттер}} панели элементтин касиеттери 3D модель керек экенин айтат.

## Эмне үчүн 3D жок

3D модель жана долбоор файлындагы элементтер документтелбеген форматта сакталат. BimCraft файлдын документтелген же ачык окулуучу бөлүктөрүн гана окуйт: файлдын маалыматы, долбоор маалыматы, семейство маалыматы, шилтемелердин тизмеси жана алдын ала көрүү сүрөтү. Калганын ойлоп таппайт. 3D'де модель көрүү жана элементтин касиеттерин окуу үчүн, файлды түзгөн программадан IFC экспорттоңуз. Караңыз: [Долбоор файлын IFC аркылуу 3D'ге киргизүү](topic:rvt-to-ifc).

## Жалпы каталар

- **3D күтүү.** Жогоруну караңыз.
- **Шилтемелер гана сакталган жолун көрсөтөт.** Өз алдында ачылган файл анын шилтемелери бар-жогун текшере албайт. Анын ордуна ал жашаган папканы ачыңыз, анда BimCraft ар бир шилтемени табылган же табылбаган деп белгилейт: [Бүт долбоор папкасын ачуу](topic:open-project-folder).
- **«Бул файл толук эмес…»** Файл көчүрүлүп, жүктөлүп же шайкештирилип жатканда кесилген. Булут дискиндеги «онлайн гана» файл дагы ушундай кылат. BimCraft дагы эле ачат жана калыбына келтирилген гана бөлүктү көрсөтөт: карточканын үстүндө сары эскертүү, файлдагы толук байттары бар бөлүктөрдү тизген **Файлдан калыбына келтирилген** бөлүмү жана калганы үчүн **Файлда жок**. Жоголгон бөлүккө эч нерсе толтурулбайт, андыктан релиз, алдын ала көрүү сүрөтү же долбоор маалыматы кесилген жерден кийин сакталган болсо, жок болушу мүмкүн. Эгер файлдын мазмундар тизмеси да кесилсе, эч нерсе ачылбайт. Толук файл үчүн оригиналды кайра көчүрүп, кайра ачыңыз.
- **«Бул файлда алдын ала көрүү сүрөтү жок».** Айрым файлдар аныксыз сакталат. Бул кадимки.
- **Резервдик көчүрмөнү абайсыздан ачуу.** `Tower.0004.rvt` сыяктуу аталган файлдар номерленген резервдик көчүрмөлөр. Папканы ачканда алар моделдери менен топтошот.
