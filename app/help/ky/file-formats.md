## IFC

| Окулат | Чоо-жайы |
|---|---|
| Геометрия | Формасы бар ар бир элемент, файл айткандай түстө. Бөлмөлөр жана мейкиндиктер тунук чийилет жана башында жашырылат |
| Кабаттар | Имараттын кабаттары бийиктиги боюнча тартиби менен, жана ар бирине кайсы элементтер турганы. Кабаты жок элементтер «Кабатта эмес» деп топтолот |
| Элементтердин саны | Ар бир түрдөгү элементтердин саны (дубалдар, эшиктер, плиталар…), {{ui:Элементтер}} бөлүмүндө көрсөтүлөт |
| Долбоор маалыматы | Долбоордун аты, толук аты жана фазасы; схема; файлдын башынан экспорттоочу программа, автор жана экспорттун датасы |
| Элементтин маалыматы | Аты, түрү, объекттин түрү, белгиси, сүрөттөмөсү, GlobalId; элементте жана анын түрүндө коюлган ар бир касиеттер топтому жана саны топтому |

Өзгөртүүгө болот: аты, объекттин түрү, белгиси, сүрөттөмөсү жана жекече касиеттердин маанилери. Жаңы IFC файлы катары сакталат. IFC2X3, IFC4 жана IFC4X3 схемалары ачылат, BimCraft'тын өз IFC кыймылдаткычы окуйт; ал азырынча чийе албаган нерселер {{ui:Файл}} панелинде **Азырынча чийилген эмес** астында тизмеленет. Модель ачылганда башталышка жылдырылат, ошондуктан андан алыс жайгашкан модель дагы экрандын ортосунда көрүнөт. `.ifczip` жана `.ifcxml` ачылбайт.

## Долбоор жана үй-бүлө файлдары

`.rvt` долбоорлор, `.rte` долбоор шаблондору, `.rfa` үй-бүлөлөр жана `.rft` үй-бүлө шаблондору.

| Окулат | Чоо-жайы |
|---|---|
| Файл маалыматы | Чыгарылышы жана курулушу, бирге иштөө, борбордук модельдин жолу, акыркы сакталган жол, колдонуучунун аты, локаль, документтин GUID'и |
| Долбоордун маалыматы | Долбоордун өз талаалары (аты, номери, кардар, дареги, статусу…), жаңы долбоордун демейки маанилеринен тышкары |
| Үй-бүлөнүн маалыматы | Үй-бүлөнүн аты, категориясы, чыгарылышы, акыркы жаңылануусу жана анын параметрлери топтор боюнча |
| Шилтемелер | Файл көрсөткөн байланышкан моделдердин, CAD шилтемелеринин, сүрөттөрдүн жана ачкыч сөздөрдүн таблицаларынын тизмеси |
| Алдын ала көрүү сүрөтү | Файлда сакталган кичине сүрөт |

Окулбайт: 3D модель, элементтер, көрүнүштөр, барактар жана таблицалар. Алар документтелбеген форматта сакталат. BimCraft ар бир файлдан бир нече ондогон килобайтты гана окуйт, ошондуктан файлдын өлчөмү деги эле маанилүү эмес.

## `.pln`, `.pla`, `.tpl` жана `.bpn` долбоор файлдары

Азырынча окулбайт: ачканыңызда BimCraft муну айтат. Модель үчүн IFC, чиймелер үчүн DWG экспорттоңуз; караңыз [.pln жана .pla долбоор файлдарын ачуу](topic:pln-project-files).

## DWG жана DXF

| Окулат | Чоо-жайы |
|---|---|
| Мейкиндиктер | Модель мейкиндиги жана ар бир барак (макет), өтмөктүн тартибинде |
| Көрүнүш терезелери | Ар бир барактын көрүнүш терезелери, алардын масштабы, буралышы жана тоңдурулган катмарлары |
| Катмарлар | Аты, түсү, күйүк/өчүк, тоңдурулган, басып чыгаруу белгиси жана сызыктын жоондугу |
| Объекттер | Сызыктар, полисызыктар, жаалар, айланалар, эллипстер, сплайндар, штриховкалар жана катуу телолор, текст жана көп сапты текст, блоктор жана атрибуттар, өлчөмдөр, көрсөткүчтөр жана көп көрсөткүчтөр, таблицалар, чекиттер, сүрөттөр |
| Байланышкан чиймелер | Коюлган жеринде чийилет, алардын файлдары табылганда |
| Сүрөттөр | Табылганда сүрөт файлдарынан чийилет (PNG, JPEG, GIF, BMP, WebP; TIFF эмес) |
| Жабдуулар белгилери | Тамак-аш предметтеринин белгилери (`KCL-ITEM` атрибуттары), жабдуулар таблицасы үчүн |

Башка нерсе **Азырынча чийилген эмес** астында эсептелет, эч качан божомолдонбойт. Текшерилген DWG форматтары — AutoCAD 2000ден 2018ге чейин (R13 жана R14 файлдары да кабыл алынат, бирок сыноо топтомунда эч бири болгон эмес; эски DWG'лер ачылбайт); {{ui:Чийме}} панели форматтын кодун көрсөтөт (мисалы AC1032). Ар бир версиядагы DXF файлдары ачылат, R12 кошо. Экөө тең BimCraft'тын өз окургучтары менен, ушул өтмөктө окулат. DWG же DXF'ке эч нерсе кайра сакталбайт.

## Папкада

| Түрү | Кеңейтүүлөр | Отчетто |
|---|---|---|
| Модельдер | `.rvt` `.rfa` `.rte` `.rft` | Номерленген резервдик көчүрмөлөр менен топтолот, бүтүндүгү текшерилет, маалымат карточкасы окулат, шилтемелер текшерилет |
| IFC | `.ifc` | Тизмеленет; 3D'де ачылат |
| CAD | `.dwg` `.dxf` `.dgn` | Аларды шилтемелеген модельдер менен тизмеленет; DWG жана DXF 2D'де ачылат, DGN ачылбайт |
| Калдыктар | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | **Четке коюлгандар** астында тизмеленет |
| Тейлөө папкалары | `*_backup`, `*_log`, `Revit_temp`, жашыруун папкалар | **Четке коюлгандар** астында тизмеленет, окулбайт |
