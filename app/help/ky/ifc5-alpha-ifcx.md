IFC5 alpha ({{ui:.ifcx}} файл аягы) — buildingSMART дагы иштеп чыгып жаткан файл форматы. Ал али акыркы эмес: файлдар жана биздин аларды окуубуз өзгөрүшү мүмкүн. Ошондуктан бул эксперименталдык параметр жана адегенде окуу керек.

## Күйгүзүү

1. {{ui:Жөндөөлөр}} тандап, андан кийин BimCraft өтмөгүндөгү {{ui:IFC5 альфа (IFCX)}} бөлүмүн тандаңыз.
2. {{ui:IFC5 альфа (IFCX) – формат али өзгөрүүдө; адегенде окуңуз}} белгисин коюңуз.

Ал демейки боюнча өчүк. Ал өчүк турганда, .ifcx файлы бул жерди көрсөткөн сүйлөм менен четке кагылат. {{ui:IFC5 alpha (.ifcx) ачуу…}} жана {{ui:IFC5 alpha}} экспорттоо баскычы күйгөндө пайда болот.

## Ачуу

- {{ui:Файлды же папканы ачуу}} менен .ifcx файлын тандаңыз (ал ачык моделди алмаштырат, өзгөртүүлөр жөнүндөгү адаттагы суроодон кийин), же
- {{ui:IFC5 alpha (.ifcx) ачуу…}} баскычын басып, бир нече файлды бирге тандаңыз: файлдын өзүн, анын катмарларын жана ал импорттогон схема файлдарын. Модель ачык турганда файл ага **катар кошулат**; моделдер тизмесиндеги x аны кайра алып салат — бул артка кайтаруу.

IFCX файлы түйүндөрдү тизмелейт (жол, анын балдары, эмнени мурастайт, атрибуттар). Бир нече файл бир эле түйүндү сүрөттөй алат: кийинки файл (катмар) мурунку файлдын атрибуттарын басат, ал эми null бала баланы алып салат. BimCraft аларды бириктирет, андан кийин натыйжаны кичинекей IFC4 модели катары чийет: долбоор, участок, имарат, кабаттар жана элементтер, аттары, классы, касиеттери, көлөмдөрү, түстөрү жана торлору менен.

Тармактан эч нерсе алынбайт. Файл импорттогон схема файлдары (мисалы, `ifc@v5a.ifcx`) сиз аларды файл менен бирге тандаган учурда гана колдонулат; болбосо отчет муну айтат жана атрибуттар түрүн текшербей окулат.

### Отчет

Ачкандан кийин отчет окуу эмнени тапканын тизмелейт: схемасына туура келбеген маалымат, берилбеген схема файлдары, бул жерде IFC маанисиз атрибуттар. Картасы жок атрибуттар модельде **сакталат**, таштабайт, жана экспортто кайра жазылат.

## Эмне эмнеге айланат

| IFCX файлындагы | BimCraft'та |
|---|---|
| IFC классы бар түйүн (долбоор, участок, имарат, кабат, дубал …) | Ага туура келген IFC4 элементи; бул окуу тааныбаган класс building element proxy болот |
| Түйүндүн ата-энесинин астындагы аты | Элементтин аты |
| Көлөм түрү бар атрибуттар (Length, Area, Volume, Mass …) | `Qto_IFCX` деп аталган IFC4 көлөм топтому (IFC4 `Qto_*` көлөмдөрү IFC4 бойдон калат) |
| Башка касиет атрибуттары | `Pset_IFCX` деп аталган касиет топтому |
| Тор жана трансформация атрибуттары | Элементтин үч бурчтуктары жана жайгашуусу; көрүнбөгөн торлор чийилбейт |
| Түс, мөлдүрдүк, материал, классификация | Элементтин беттик стили, материалы жана классификациясы |

Бирдиктер метр катары алынат, Z огу өйдө карай: альфа бирдиктер кийинчерээк документтелет деп айтат.

## Экспорт

Куралдар тилкесинен {{ui:IFC5 alpha}} тандап, эскертүүнү окуп, андан кийин {{ui:Экспорттоо .ifcx}} тандаңыз. Файлда биздин башкы маалымат бар (автор CadCraft, версия ifcx_alpha) жана ал өзү IFC5 alpha форматы экенин айтат. Ар бир модель өз файлынын координаттарында, метр менен жазылат: аттары, классы, касиет топтомдору, көлөмдөр (түрү менен атрибуттар катары), түстөр жана үч бурчтуктар менен. Катмарлар жана мурас жалпакталып жазылат. Файлды аны жөнөткөн программада текшериңиз.

## Чектөөлөр

- Ийри геометрия (ийри сызыктар, беттер) окулбайт: үч бурчтуктардан турган торлор гана.
- Дубалга салынган эшиктер жана терезелер кабатка коюлат; алар келген дубал менен байланышпайт.
- IFC4 `Qto_*` топтомунун аттары биздин атрибут топтору катары сакталат (`cadcraft::qto::…`); стандарттык альфа схемасында көлөмдүн бир нече аты гана бар.
- Формат өзгөрүшү мүмкүн; бүгүн жасалган файл эртең окулбашы мүмкүн.
