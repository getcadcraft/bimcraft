## Эмне кыласыз

Үлгү — кош фигуралуу скобкалардагы талаалары бар Markdown тексти. BimCraft талааларды ачык модельден толтурат (саны, түрү боюнча саны, касиеттер, сиздин [тегтериңиз](topic:tags-and-schedules)) жана натыйжаны PDF, Word документи (.docx) же Markdown катары сактайт.

## Кадамдар

1. Ачык IFC модель ачыңыз.
2. Сол панелде, {{ui:Саны}} астында, {{ui:Модель боюнча документтер}} ачыңыз.
3. Үлгү тандаңыз: {{ui:Эшиктер жана фурнитура}} же {{ui:Дубалдар, каптоолор жана бүтөөлөр}}, же өзүңүздүкүн {{ui:Үлгүнү жүктөө (.md)…}}.
4. Үлгү модель аныктабаган тегдерди окуса, {{ui:Бул үлгүнүн тегдерин кошуу}} басыңыз, андан кийин {{ui:Тегтер}} астында элементтерди белгилеңиз.
5. Текстти каалагандай өзгөртүп, {{ui:Документти көрсөтүү}} басыңыз.
6. {{ui:PDF}} басыңыз (алдын ала A4 же Letter тандаңыз) же {{ui:Word (.docx)}}.

## Эмнени көрөсүз

- Толтурулган документ баскычтардын астында, таблицалары менен.
- Талаа окулбаганда эскертүүлөрдүн тизмеси (аныкталбаган тег, модельде жок касиет, жабылбаган блок); мындай талаа `[?…]` болуп басылат.
- PDF беттеринде документтин аталышы жана ар бир беттин астында "Бет 1 / 3" жазуусу; узун таблицалар сабын менен кийинки бетке өтөт.

## Талаалар

| Талаа | Берет |
|---|---|
| `{{project}}`, `{{project description}}`, `{{file}}`, `{{date}}` | долбоордун аты жана сүрөттөмөсү, файлдын аты, бүгүн |
| `{{count IfcDoor}}` | канча эшик |
| `{{sum IfcWall NetSideArea}}` | жалпы сумма, анын бирдиги менен |
| `{{calc [sum IfcWall NetSideArea] * 1.1 round 1 unit m²}}` | арифметика (`+ - * /` жана кашаалар) шайкеш терминдер үстүндө: `[sum …]`, `[count …]`, жана each ичинде `[qty Width]`. `round n` ондук сандарды орнотот, `unit` бирдикти кошот. Окуй албаган нерсе же нөлгө бөлүү `[?…]` болуп басылат жана эскертет |
| `{{qty IfcWall NetSideArea by Type}}` | таблица: ар бир түр үчүн бир катар, анын саны жана суммасы, жана жалпы катар |
| `{{table IfcDoor cols Mark, Type, Width, tag:Fire rating}}` | таблица, ар бир элемент үчүн бир катар |
| `{{tag Finish}}` | цикл ичинде элементтин мааниси; башка жерде колдонулган ар бир маани (Oak, Paint) |
| `{{tags}}` | тегдердин аныктамалары таблица катары |
| `{{#each IfcDoor}} … {{else}} … {{/each}}` | текст ар бир элемент үчүн бир жолу; `{{else}}` кийинки бөлүгү элемент жок болгондо |
| `{{#group IfcWall by Type}} … {{/group}}` | текст ар бир түр үчүн бир жолу, `{{value}}`, `{{count}}`, `{{sum Length}}` жана ичинде жөнөкөй `{{#each}}` менен |

`{{#each}}` ичинде: `{{name}}`, `{{type}}`, `{{storey}}`, `{{class}}`, `{{material}}`, `{{mark}}` (IFC Tag), `{{guid}}`, `{{n}}` (1, 2, 3 …), `{{prop Pset_DoorCommon.FireRating}}`, `{{qty Width}}` (элементтин өз, бирдиги менен).

Класс бир нече болушу мүмкүн (`IfcDoor|IfcWindow`) же бардык элементтер (`*`). Аларды `where` менен тардаңыз: `{{#each IfcDoor where Fire rating >= 60}}`, `{{count IfcWall where Wall finish hasnot}}`. Текшерүүлөр: `=`, `!=`, `~` (камтыйт), `>`, `<`, `>=`, `<=`, `has` жана `hasnot`; бир нече шартты `and` менен бириктириңиз; боштуктары бар маанини "тырмакчаларга" коюңуз. `sort Name` цикли ырааттайт.

## Таблицалар жана документтеги спецификация

`{{schedule doors}}` модель таблицасын өз кеңсеңиздин жайгашуусу боюнча таблица катары басат: `doors`, `windows`, `walls`, `rooms`, `floors`, `roomfinishes`, `wallfinishes`, `zonefinishes`, `finishtotals`, `layers`, же Таблицаларда сактаган жайгашуунун аты. `{{specification}}` долбоордун спецификациясын басат. **Иш чийме таблицалары** жана **Спецификация** үлгүлөрү аларды колдонот. Алдын ала көрүүдө мындай таблицанын сандарынын бирин басканда, ал келген элементтер тандалат. Караңыз: [Таблицаны жайгаштыруу, сактоо жана экспорттоо](topic:schedule-layouts) жана [Модель боюнча спецификацияны жазуу](topic:specification).

## Билип коюңуз

- Талаа ички курулган атты (Name, Type, Storey, Class, Material, Mark), тегди (`tag:Fire rating`, же анын аты), касиетти (`Pset_WallCommon.FireRating`) же касиеттин атын гана (`NetSideArea`, `Width`) билдирет: жөнөкөй ат ар бир элементтин өз топтомун окуйт, санынын топтомдору биринчи, ошондуктан эшиктеги `Width` эшиктин туурасы, дубалдын калыңдыгы эмес. `where` ичинде жөнөкөй ат тандалган элементтердин көбүнүн топтомун окуйт.
- Сандар — файлдын сандык топтомдорунун айтканы (BimCraft аларды чийгенине жазат); бирдиктер файлдын бирдик жөндөөлөрүнөн келет.
- Талаа сөздөрү (`count`, `sum`, `qty`, `by`, `cols`, `where`, `each`, `group` …) ар бир тилде англисче калат. Үлгү мисалдары англисче.
- Модельден келген текст форматтоо болуп калбайт: аты `*` же `|` менен болсо, ал ошондой басылат.
- Өзгөрткөн үлгүңүздү {{ui:Бул браузерде сактоо}} (ал ушул браузерде гана) же {{ui:Үлгүнү жүктөп алуу}} менен сактаңыз.
- PDF тексти стандарттуу PDF шрифттерин колдонот: Батыш Европа тексттеринин сыртындагы белги "?" болуп басылат, жана статус сабы канча экенин айтат.
- Адис тармагы боюнча үлгүлөр Китепканада жашайт (түрү: Документ үлгүсү). Модель боюнча документтерде **Китепканадан…** тандаңыз, бирин тандаңыз, анын тексти жана ал окуган тегдер келет; аны каалагандай түзөтүңүз. Өзүңүздүн үлгүңүздү Китепканага жарыялоо башка ар кандай элемент жүктөө менен бирдей. Азырынча курулган эмес: саналардан жана жыйынтыктардан тышкары эсептөөлөр.
