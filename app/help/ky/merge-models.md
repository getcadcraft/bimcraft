Эки адам бир курулуштун көчүрмөсүн алат, бири чыгыш канатын, экинчиси батыш канатын чийет, кийинчерээк көчүрмөлөр бир болушу керек. Эгер алар ар кандай объекттерге тийишкен болсо, программа адамдын ордуна аны жасай алат.

## Ал кантип иштейт

IFC файлындагы ар бир дубал, эшик, деңгээл, бөлмө жана касиеттер топтому өзгөрбөгөн GlobalId ээ. Бириктирүү объекттерди файл берген номери (`#123`) менен эмес, ушул id менен издейт, анткени программа сактаганда номерлер өзгөрөт. Объекттин өзүнүн id'си жок бөлүктөр (жайгаштыруулар, формалар, бирдиктер) мазмуну боюнча салыштырылат.

Эки көчүрмө бирдей IFC версиясында болушу керек (2x3, 4 же 4.3). Бириктирүү сиздин файлыңызды өз абалында, тартибинде жана номерлери менен сактайт жана жаңысын кошот, ошондуктан бириктирүүнүн git diff'и бириктирүү эмне өзгөрткөнүн гана көрсөтөт.

## Орнотуу

Git үчүн ар бир репозиторий үчүн бир жолу эки сап керек:

```
# .gitattributes
*.ifc merge=cadcraft

# бир жолу, ар бир компьютерде
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git жок болсо, `cadcraft merge <base> <ours> <theirs>` иштетиңиз. Fossil жана Mercurial ушул үч файлды өз бириктирүү куралынын орнотуусунда да кабыл алат. Эч нерсе жүктөлбөйт; баары сиздин компьютерде иштейт.

## Эрежелер

- Бир тарапта гана өзгөртүлгөн атрибут алынат. Эки тарапта бирдей өзгөртүү бир жолу алынат.
- Бир атрибут эки жол менен өзгөртүлсө (бир деңгээл эки жол менен аталышы өзгөртүлсө) — бул **карама-каршылык**: сиздин тарап калат жана отчет экөөнү тең тизмелейт. Натыйжаны ачып, аны колуңуз менен оңдоңуз.
- Нерселердин тизмеси (деңгээлдин дубалдары, топтомдун касиеттери) топтом катары бириктирилет: эки тараптын кошкону сакталат, эки тараптын алып салганы алынып салынат. Эки адам тең бир деңгээлге дубал кошсо, карама-каршылык болбойт.
- Эки тараптын бирөөсүндө кошулган объект формасы жана касиеттери менен сакталат. Бир тарапта алынып салынып, экинчисинде тийилбесе: алынып салынат. Бир тарапта алынып салынып, экинчисинде өзгөртүлсө: алынып салынат жана отчетто көрсөтүлөт.
- Файлдын убакыт белгиси жана автору, ар бир объекттин ээлик тарыхы сиздикинде калат.

Геометрия бүтүндөй бириктирилет: дубалдын формасы бир тараптан келет, эч качан чекит-чекит аралаштырылбайт. Zip менен кысылган IFC жана IFCX файлдары бириктирилбейт. Бириктиргенден кийин натыйжаны BimCraft'та ачып, сактоодон мурун Көйгөйлөр панелине карап көрүңүз.
