## Ce veți face

Construiți o singură arhivă zip pentru o depunere legală (când lista autorității vine dintr-un pachet de reglementări, arhiva conține și pașii de aprobare și formatul de depunere): o copertă, comentariile pe care un verificator le-ar face probabil (scrise din verificări, nu ghicite), raportul de reglementări când suplimentul Reglementări de construcție este activ, modelul și lista documentelor justificative pe care autoritatea de aprobare le cere.

Acesta este un ghid făcut din model. Inginerul autorizat și autoritatea decid ce este cerut și ce este acceptat.

## Pași

1. Cu un model deschis, deschideți {{ui:Dosar pentru autorizare}} din panoul din stânga.
2. Scrieți numele proiectului, adresa și solicitantul și enumerați planșele și formularele, câte unul pe rând.
3. Sub {{ui:Documente justificative}}, alegeți {{ui:Lista autorității}}. Listele vin din pachetele de reglementări: adăugați suplimentul Reglementări de construcție și bifați pachetul pentru zona în care se află proiectul, în Setări › Reglementări de construcție (un pachet poate conține regulile, un proces de aprobare, un format de depunere, convenții de desen și note standard). Lista generală funcționează și fără el.
4. Citiți lista. Fiecare document este {{ui:Legat}} (cu planșa și motivul), {{ui:Furnizat direct}}, {{ui:Nu se aplică}} sau {{ui:Lipsă}}.
5. Pentru o hârtie pe care o furnizați singur (un formular, un act de proprietate, o chitanță de taxă), alegeți {{ui:Furnizat de mine}}. Pentru un element marcat „dacă se aplică” care nu se aplică, alegeți {{ui:Nu se aplică aici}}. Ca să legați singur un document de o planșă, alegeți planșa.
6. Deschideți {{ui:Proces de aprobare}} și {{ui:Format de depunere}} sub listă, pentru a citi pașii și ce trebuie depus (dimensiuni de planșe, formate de fișiere, exemplare). O taxă sau un termen apare doar când sursa pachetului le precizează, cu pagina și data la care a fost citită.
7. Faceți clic pe {{ui:Creați dosarul pentru autorizare (zip)}}. Pașii și formatul apar și pe copertă.

## Cum este legat un document

Un document este legat de o planșă care conține tipul potrivit de vizualizare (un plan de nivel, o elevație, o secțiune), de o planșă care conține tabelul potrivit (tabelul de uși, pentru un tabel de uși) sau de o planșă al cărei titlu spune asta (o planșă intitulată „Plan de situație”). Când modelul are rândurile, dar niciun tabel nu se află pe nicio planșă, sau când terenul este desenat, dar nicio planșă nu are titlul de plan de situație, elementul rămâne lipsă și spune de ce.

## De reținut

- **Fiecare listă a unei autorități este neverificată de un practician local.** Fiecare a fost citită din sursa publicată pe care o citează, la data arătată, și scrisă în cuvinte proprii. Cerințele se schimbă: verificați lista actuală a autorității.
- Ce îi mai lipsește setului, sau o planșă care nu are dimensiunea, orientarea ori scara cerute de pachet, apare în lista Probleme ca notă. Notele sunt sfaturi: nu opresc niciodată pachetul.
- Documentele lipsă nu opresc pachetul. Sunt listate pe copertă și în `04-supporting-documents.csv`.
- Listele sunt date, nu cod, în pachetele de reglementări: Africa de Sud (National Building Regulations, regula A2), Cape Town (cu regiunea Africa de Sud adăugată din Bibliotecă), Anglia (cerințe naționale de informații), Portland în Oregon, un pachet didactic FICTIV și o listă generală care nu aparține niciunei autorități. Oricine poate scrie un pachet pentru locul său.
- Alegerile făcute sunt păstrate în model, deci sunt acolo când îl deschideți din nou, iar fiecare este o etapă pe care o puteți anula.
