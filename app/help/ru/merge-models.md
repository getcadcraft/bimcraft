Два человека берут копии одного здания: один чертит восточное крыло, другой — западное, а потом копии нужно свести в одну. Если они трогали разные объекты, это может сделать программа вместо человека.

## Как это работает

У каждой стены, двери, уровня, помещения и набора свойств в файле IFC есть GlobalId, который никогда не меняется. Слияние ищет объекты по этому идентификатору, а не по номеру, который файл им присваивает (`#123`), потому что номера меняются при сохранении программой. Части, прикрепленные к объекту, у которых нет собственного идентификатора (размещения, формы, единицы), сравниваются по содержимому.

Обе копии должны быть одной версии IFC (2x3, 4 или 4.3). Слияние сохраняет ваш файл таким, как он есть, с его порядком и номерами, и добавляет новое, поэтому diff git для слияния показывает только то, что изменило слияние.

## Настройка

Git нужны две строки один раз на репозиторий:

```
# .gitattributes
*.ifc merge=cadcraft

# один раз, на каждом компьютере
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Без git запустите `cadcraft merge <base> <ours> <theirs>`. Fossil и Mercurial принимают те же три файла в своей настройке средства слияния. Ничего не загружается; всё выполняется на вашем компьютере.

## Правила

- Атрибут, измененный только с одной стороны, берется. Одинаковое изменение с обеих сторон учитывается один раз.
- Один и тот же атрибут, измененный двумя способами (тот же уровень переименован по-разному), — это **конфликт**: остается ваша сторона, а отчет перечисляет обе версии. Откройте результат и исправьте вручную.
- Список (стены уровня, свойства набора) сливается как множество: сохраняется то, что добавила любая сторона, и удаляется то, что удалила любая сторона. Два человека, каждый из которых добавил стены на один уровень, не конфликтуют.
- Объект, добавленный с любой стороны, сохраняется вместе со своей формой и свойствами. Удален с одной стороны и не тронут с другой: удален. Удален с одной стороны и изменен с другой: удален и указан в отчете.
- Отметка времени и автор файла, а также история владельца каждого объекта остаются вашими.

Геометрия сливается целиком: форма стены берется с одной стороны и никогда не смешивается поточечно. Упакованные (zip) файлы IFC и IFCX не сливаются. После слияния откройте результат в BimCraft и посмотрите панель проблем, прежде чем сохранять.
