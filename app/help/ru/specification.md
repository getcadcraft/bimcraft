## Что вы сделаете

Получите спецификацию, которая следует модели: раздел для каждого типа, который действительно есть в здании, каждый со своим составом и количествами, считанными из модели, и текстом, который вы напишете для него.

## Шаги

1. Включите {{ui:Черчение}}, откройте **Спецификации** на левой панели и нажмите **Спецификация**.
2. Диалог перечисляет по одному разделу для каждого типа стены, типа двери, типа окна, перекрытия и отделки помещений, которые используются. Под каждым заголовком — его **данные**, считанные из модели: толщина, слои по одному, уровень проработки, размеры, сколько штук и сколько. Раздел, у элементов которого есть код классификации, показывает этот код в заголовке.
3. Напишите текст спецификации в поле под разделом. **Выбрать его элементы** показывает, к чему относится раздел.
4. Нажмите **Сохранить**. Это один шаг отмены, а текст сохраняется в файле здания.
5. Откройте **Документы из модели**, выберите шаблон **Спецификация** и нажмите **Предпросмотр**, затем сохраните как PDF, Word или Markdown. См. [Документы из модели](topic:documents-from-the-model).

## Ведомости рабочих чертежей как документ

Шаблон **Ведомости рабочих чертежей** печатает ведомости дверей, окон и отделки прямо из модели в макете вашего бюро. В собственном шаблоне напишите `{{schedule doors}}`, `{{schedule windows}}`, `{{schedule roomfinishes}}`, `{{schedule finishtotals}}` или название сохранённого набора настроек, например `{{schedule Door schedule by floor}}`. `{{specification}}` печатает спецификацию.

## Полезно знать

- Данные принадлежат модели. Они меняются при изменении модели; ваш текст — нет.
- BimCraft не пишет пункты каких-либо стандартов и текст производителя. Раздел без текста печатает «Текст спецификации ещё не написан.»
- Текст, написанный для типа, которого больше нет в модели, сохраняется и перечисляется под заголовком «Текст для типов, которых больше нет в модели».
- Чтобы заменить общий тип на конкретный состав, см. [Инструменты стен](topic:wall-tools) (Заменить тип).
