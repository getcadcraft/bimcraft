## Что вы будете делать

Исправляйте данные в модели IFC: переименовывайте элемент, исправляйте его метку, меняйте значение свойства. Затем сохраните новый файл IFC с вашими изменениями. Открытый вами файл никогда не трогается.

## Что можно изменить

| Поле | Можно изменить |
|---|---|
| Имя, Тип объекта, Метка, Описание | Да |
| Одиночные значения свойств (текст, числа, Да/Нет) | Да |
| Свойства типа (наборы с пометкой «(type)») | Да, и изменение применяется ко всем элементам этого типа |
| Тип, GlobalId, Номер строки | Нет |
| Количества (длины, площади, объемы, количества штук) | Нет |
| Списки, перечисления и другие многочастные значения | Нет |
| Геометрия, положение, добавление или удаление элементов | Нет |

## Шаги

1. Откройте модель IFC и щелкните элемент, который хотите изменить.
2. В панели {{ui:Свойства}} щелкните значение, которое хотите изменить. Оно превратится в текстовое поле. Пустое значение показано как *пусто*.
3. Введите новое значение.
4. Нажмите {{key:Enter}} или щелкните в другом месте, чтобы сохранить. Нажмите {{key:Esc}}, чтобы отменить.
5. Посмотрите на значение: теперь оно жирное, с синей полосой рядом, что отмечает измененное значение.
6. Посмотрите раздел {{ui:Изменения}} слева: изменение указано как *элемент*: *поле*, старое значение на новое значение.
7. Повторите для других значений или других элементов.
8. Щелкните {{ui:Сохранить как IFC}} (там показано, сколько изменений ждут, например «Сохранить как IFC (3)») или нажмите {{key:Mod+S}}.
9. Найдите «*исходное имя* (edited).ifc» в папке загрузок.

## Что вы должны видеть

В строке состояния написано «Сохранено *имя* (edited).ifc с *n* изменениями (… байт). Ваш исходный файл не изменен.» Список {{ui:Изменения}} очищается, готовый к следующему раунду.

## Виды значений

- **Текст**: всё, что вы введете, сохраняется как есть. Очистка полей Имя, Тип объекта, Метка или Описание удаляет значение.
- **Числа**: введите обычное число, например `2.4` или `1200`, в собственных единицах файла. Без обозначений единиц. Всё остальное выдает «Введите число.».
- **Целые числа** (количества, целые): «Введите целое число.», если вы ввели дробь.
- **Да/Нет**: значение становится меню с Да и Нет.

Каждое значение сохраняет свой тип IFC, поэтому число остается числом, и другие программы читают его правильно.

## Отмена

1. Щелкните {{ui:Отменить}} в разделе {{ui:Изменения}} или нажмите {{key:Mod+Z}}, когда вы не печатаете в поле.
2. Повторите, чтобы отменить больше. Каждая отмена убирает самое новое изменение.

Нельзя отменить что-то раньше сохранения: после сохранения список начинается заново. Сохраненный файл содержит всё.

## Почему ваша правка меняет только один элемент

Экспортеры экономят место, разделяя данные. Один набор свойств может быть общим для двадцати дверей, а одно значение («Огнестойкость: 60 мин») может быть перечислено в девяноста наборах. Если BimCraft просто изменил бы общее значение, все элементы, которые его разделяют, тоже изменились бы.

Поэтому BimCraft копирует перед записью:

- Если редактируемый набор свойств общий с другими элементами, ваш элемент получает собственную копию набора, и меняется только копия.
- Если значение общее с другими наборами, ваш набор получает собственную копию значения.

Соседи сохраняют свои старые данные. Это называется *копированием при записи*. Это добавляет в файл несколько небольших записей, которые любая программа IFC читает нормально.

**Свойства типа — исключение, намеренно.** Набор с пометкой «(type)» принадлежит типу элемента, и в IFC каждый элемент этого типа читает его оттуда. Изменение меняет тип, поэтому у каждого элемента типа показывается новое значение. В списке {{ui:Изменения}} такие правки отмечены «(type)». См. [Изменение свойства типа для всех элементов типа](topic:type-vs-instance).

## Предупреждения перед потерей работы

- Открытие другого файла при несохраненных изменениях спрашивает «У вас *n* несохраненных изменений в *файле*. Отбросить их?» Нажмите «Отмена», чтобы продолжить работу, затем сохраните.
- Закрытие или перезагрузка вкладки с несохраненными изменениями заставляет браузер спросить, уходить ли.

## Частые ошибки

- **Ввод единиц.** `2400 mm` отклоняется. Введите `2400`.
- **Изменение свойства типа, когда вы хотели один элемент.** Ищите пометку «(type)», прежде чем печатать. Если хотите, чтобы один элемент отличался, измените свойство экземпляра или его метку или имя.
- **Ожидание, что исходный файл изменится.** Сохранение всегда скачивает новый файл. Замените оригинал сами, если хотите, и сохраните копию.
- **Нажатие {{key:Mod+S}} без изменений.** BimCraft сохраняет только тогда, когда есть что сохранять; иначе может открыться собственное окно браузера «Сохранить страницу». Закройте его.
- **Сохранение дважды с ожиданием двух маленьких файлов.** Каждое сохранение содержит все правки с момента открытия модели.
- **Ожидание, что правки вернутся в файл проекта.** BimCraft пишет только IFC. Импортируйте измененный IFC в авторскую программу, как любой IFC.
