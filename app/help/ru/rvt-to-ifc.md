## Что вы сделаете

Превратите файл проекта в файл IFC, который можно вращать, осматривать, проверять и редактировать в BimCraft. BimCraft пока не читает 3D-модель внутри файла `.rvt`, поэтому экспорт выполняется в программе, которая создала файл (Revit), а BimCraft открывает результат.

## Шаги

1. Откройте проект в программе, в которой он создан. Карточка BimCraft называет версию, в которой он был сохранен.
2. Откройте 3D-вид, который показывает то, что вы хотите экспортировать.
3. Выберите **File > Export > IFC**.
4. В диалоге экспорта выберите настройку (или **Modify setup…**) с параметрами ниже.
5. Выберите папку и имя файла и выполните экспорт.
6. В BimCraft нажмите {{ui:Выбрать файл}} и выберите новый файл `.ifc`. Связанные модели, экспортированные как собственные файлы, открываются в ту же сцену с помощью {{ui:Добавить модель}}.

## Настройки, которые лучше всего открываются здесь

| Параметр в экспортере | Выбрать | Зачем |
|---|---|---|
| IFC version | **IFC4 Reference View** для просмотра, проверки и подсчета объемов; **IFC2X3 Coordination View 2.0**, когда другим нужен IFC2X3 | Оба открываются полностью. **IFC4 Design Transfer View** тоже открывается, с более точными формами, но файл больше и медленнее. |
| File type | **IFC** (обычный) | BimCraft не открывает `.ifczip` или `.ifcxml`. |
| Phase / visible elements | Нужная вам фаза и **Export only elements visible in view**, когда вы настраиваете для этого 3D-вид | Исключает то, что вы скрыли намеренно. |
| Property sets | **Export Revit property sets** и **Export IFC common property sets** | Они становятся наборами свойств, которые BimCraft показывает в {{ui:Свойства}} и которыми пользуются {{ui:Поиск}}, {{ui:Цвет}} и {{ui:Проверка модели}}. |
| Base quantities | **Export base quantities** | {{ui:Итоги по количествам}} и ведомости используют их (длины, площади, объемы) вместо предположений. |
| Rooms and areas | **Export rooms in 3D views** (или опция Rooms / Spaces) | Помещения приходят как пространства: нажмите {{ui:Помещения}}, чтобы увидеть их. |
| Linked files | **Export linked files as separate IFCs** | Каждая связь становится собственным файлом; откройте их вместе с {{ui:Добавить модель}}, и они совпадут. |
| Coordinate base | **Shared coordinates** (или точка съемки) | Файл тогда несет свое место на карте (IfcMapConversion), поэтому работают Measure › Location, картографические слои на местности и облака точек, размещенные по координатам карты. Базовая точка проекта держит модель около начала координат, но без ее места на карте. |
| Split walls and columns by level | Включено, если вы считаете объемы по этажам | Часть каждого этажа становится отдельным элементом. |

## Что вы должны увидеть

Модель в 3D, с этажами из уровней проекта и сведениями о проекте на панели {{ui:Файл}}. **Exported from** указывает экспортер.

## Что сохраняет экспорт, а что нет

- **Сохраняется**: геометрия, этажи, виды элементов, названия, типы, большинство параметров (как наборы свойств), базовые величины, если они запрошены, помещения как пространства и место на карте при общих координатах.
- **Не сохраняется**: виды, листы, аннотации, семейства как редактируемые семейства, рабочие наборы и варианты проектирования. Файл IFC — это снимок элементов модели, а не проекта. Для листов экспортируйте DWG и откройте его в 2D-виде.

## Частые ошибки

- **В BimCraft не хватает параметров.** Включите указанные выше опции наборов свойств и экспортируйте снова.
- **Не хватает помещений.** Включите опцию помещений, затем нажмите {{ui:Помещения}}.
- **Сохранение как `.ifczip`.** Выберите обычный IFC или распакуйте `.ifczip`.
- **Нет места на карте.** Экспортируйте с общими координатами и проверьте, что задана исходная точка съемки проекта.
- **Ожидание, что правки вернутся в проект.** Правки, которые вы сохраняете в BimCraft, попадают в новый файл IFC, а не в файл проекта.
