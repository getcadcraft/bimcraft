## Что вы сделаете

Передумайте насчет элемента, не перемещая его снова, и поддерживайте элементы библиотеки в модели в актуальном состоянии.

## Замена одного элемента

1. Щелкните размещенный элемент библиотеки в модели.
2. В {{ui:Свойства}} щелкните {{ui:Заменить элемент…}} в поле **Элемент библиотеки**. Откроется вкладка {{ui:Библиотека}}.
3. Найдите новый элемент и щелкните его карточку.
4. Щелкните {{ui:Заменить … на этот}}.

Элемент сохраняет свое место, поворот, этаж, номер позиции, количество и заметки. Его тип, форма и данные меняются на новый элемент. Элементы, размещенные одинаковым способом, имеют общий тип, как и при размещении.

Элемент с вариантами (см. [Размещение и замена элемента библиотеки с вариантами](topic:library-variants)) при замене перечисляет свои другие варианты вверху вкладки {{ui:Библиотека}}: по одному щелчку на каждый.

Если новый элемент — другой вид объекта, например раковина вместо стола, класс IFC элемента меняется соответственно (здесь с элемента обстановки на санитарный прибор), чтобы другие программы правильно учитывали его в спецификациях. Это остается тем же элементом, с тем же GlobalId, поэтому ссылки на него продолжают работать. {{key:Mod+Z}} возвращает прежний класс вместе со старым элементом.

## Проверка обновлений

1. Щелкните {{ui:Обновления}} на панели инструментов (или {{ui:Проверить обновления}} в поле элемента библиотеки).
2. Прочитайте список: каждый элемент библиотеки в модели с его версией в модели, последней версией и статусом: **Актуально**, **Новая версия**, **Снят с публикации** или **Не найдено**. Также указано, что изменилось: геометрия, данные, лицензия или исправление.
3. Щелкните {{ui:Обновить}} в строке или {{ui:Обновить все}}.

## Что вы должны увидеть

- «Обновлено размещений: *n*. Места, номера позиций, количества и заметки сохранены.»
- Строки «Обновлено: *item*» в списке изменений. {{key:Mod+Z}} отменяет каждое.

## Полезно знать

- Проверить можно только элементы, пришедшие из Библиотеки. Элементы из файлов не имеют id библиотеки.
- Если лицензия изменилась, уже размещенная копия сохраняет лицензию, с которой пришла, пока вы её не обновите.
- **Снятый с публикации** элемент не предлагается для новых размещений. Элемент, снятый по причинам авторского права, нельзя скачать вовсе; замените его с помощью {{ui:Заменить элемент…}}.
- Размещенный вариант остается этим вариантом, если новая версия элемента его еще содержит; иначе он получает вариант по умолчанию.
- Проверка отправляет только id и версии элементов, но никогда не вашу модель.
