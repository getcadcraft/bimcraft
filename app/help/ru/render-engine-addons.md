Дополнение (Настройки › Дополнения) может добавить движок в список движков {{ui:Render}}. Полный текст для авторов дополнений — раздел 16 спецификации дополнений; коротко:

- Дополнение регистрирует движок с идентификатором, который начинается с его собственного, с именем, необязательными настройками и **либо** программой для запуска, **либо** функцией на JavaScript, которая рисует изображение.
- Движку, который запускает программу, нужно разрешение **`engine.run`**; оно показывается до установки и в настройках. Такой движок работает только в Studio; в браузере он показывается как файл для сохранения.
- Дополнение называет программу (простое имя файла, никогда не командная оболочка), скрипт, который находится **внутри подписанного дополнения**, и аргументы из заполнителей и простых слов. Studio находит программу или один раз просит вас указать путь к ней.
- Когда дополнение впервые запускает программу, **Studio спрашивает вас в собственном диалоге**: какое дополнение, какая программа и что скрипт может делать все, что может программа. Разрешайте это только для дополнения, которому вы доверяете. Ваш ответ запоминается для этого дополнения и программы.
- Пакет (сцена в формате USD и файл настроек, а также файл glTF, если дополнение его запрашивает) и скрипт дополнения помещаются во временную папку, программа запускается там, и изображение возвращается с отметкой имени движка дополнения.

:::note
Дополнения могут добавлять движки рендеринга только начиная с API дополнений 1.4. Разобранный пример для консольного рендерера с открытым кодом находится в его собственном репозитории; в этом рендерере его пока не запускали.
:::
