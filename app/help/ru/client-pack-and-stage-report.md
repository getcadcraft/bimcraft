## Что вы сделаете

Создайте пакет для заказчика или отчет по стадии из модели в ее текущем виде и сравните сохраненные варианты объемной концепции рядом по площади и стоимости.

## Шаги

1. В левой панели откройте **Пакет для заказчика и отчет по стадии**.
2. Выберите **Открыть в Документах** рядом с Пакетом для заказчика или Отчетом по стадии. Документ появится в Документах на основе модели, где вы можете изменить его текст.
3. В предпросмотре нажмите на цифру, чтобы выбрать элементы, на которых она основана.
4. Выберите **Собрать пакет**. Сохраняется один zip-архив: документ в PDF, изображение 3D-вида и `figures.csv`, в котором перечислена каждая цифра с GlobalId ее элементов.

## Поля

Их можно использовать в любом документе.

| Поле | Что выводит |
|---|---|
| `{{stage}}` | Стадия проекта из данных чертежа. |
| `{{options}}` | Сохраненные варианты объемной концепции рядом: этажи, высота, площадь застройки, валовая площадь этажей, оболочка и стоимость. |
| `{{areas}}` | Площадь этажей по уровням, по помещениям. |
| `{{sheets}}` | Листы с ревизией, на которой каждый стоит, и датой последнего выпуска. |
| `{{issues}}` | История выпусков и журнал изменений чертежей. |
| `{{changes}}` | Что изменилось с последнего выпуска, лист за листом. |

## Как рассчитывается стоимость

Стоимость берется только из таблицы цен вашего проекта (Energy/Cost, 5D cost). Ничего не оценивается за вас.

- Строка цен назначает цену варианту, только если ее классы называют `IfcBuildingElementProxy`.
- Площадь этажей оценивается строкой, в словах которой назван вариант использования, например «офис». Без такой строки используется строка со словами «gross floor area» или «building mass»; строка за m² использует валовую площадь этажей, строка за m³ использует объем.
- Оболочка (периметр, умноженный на высоту) оценивается строкой со словом envelope или facade.
- Вариант без подходящей строки показывает **Нет расценки**. Итог показывается, только если у каждой запрошенной части есть расценка.

## Полезно знать

- Сохраняйте варианты кнопкой **Сохранить как вариант** в списке вариантов объемной концепции в программе помещений. См. Варианты объемной концепции.
- PDF не умеет выбирать элементы. Вне BimCraft `figures.csv` содержит связь от каждой цифры к ее элементам.

## Пока не реализовано

- Листы и виды на чертежах не размещаются внутри документа. Пакет содержит только изображение 3D-вида.
