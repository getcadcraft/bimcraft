## Что вы сделаете

Перенесите типы стен из одного проекта в другой или передайте их тому, кто работает в другой программе. Набор типов содержит каждый тип стены с его слоями, толщинами, материалами, основой, полостями, приоритетом слоев, уровнем проработки, данными для подсчета объемов и кодами классификации, а также любые добавленные семейства. Это открытый файл: обычный текст JSON, который может прочитать любой, или файл IFC. Ничто в нем не привязано к фирме, стране или учетной записи.

## Сохранение типов из проекта

1. Откройте **Данные** на панели модели и выберите {{ui:Наборы типов}}.
2. В разделе {{ui:Сохранить типы из этого проекта}} отметьте типы стен, которые нужно включить. Собственные типы проекта уже отмечены; стартовый тип можно добавить, и он попадет как копия. Отметьте семейства, если хотите их включить.
3. Введите {{ui:Название набора}}.
4. {{ui:Сохранить как набор (.json)}} скачивает файл `.cctypes.json`. {{ui:Сохранить как IFC (.ifc)}} скачивает файл IFC, который содержит только типы: каждый тип стены как IfcWallType с его набором слоев материала, материалами и классификацией, для любой программы BIM.

## Добавление типов в проект

1. В том же окне выберите {{ui:Открыть набор или файл IFC…}} и укажите файл набора `.json` или файл `.ifc`.
2. Диалог показывает, что содержит файл: каждый тип стены с его толщиной, числом слоев и кодами, а также материалы и семейства.
3. Выберите, что делать с {{ui:Тип, который уже есть в этом проекте}}: **Оставить тип проекта**, **Добавить тип из набора как копию** (он получит новое имя, оканчивающееся на «(2)»), или **Заменить (только если ни одна стена его не использует)**.
4. {{ui:Добавить в проект}}. Диалог перечисляет, что добавлено, скопировано, заменено или оставлено. Это один шаг отмены.

Новые типы сразу появляются в списке типов инструмента «Стена».

## Типы перекрытий, кровель и потолков

Список типов для сохранения также содержит типы перекрытий, кровель и потолков проекта и их стартовые типы (отмечены как «Перекрытие», «Кровля», «Потолок»). Набор может содержать все четыре вида; каждый тип называет свой класс IFC (IfcWallType, IfcSlabType, IfcCoveringType). Тип перекрытия, кровли или потолка, который используют элементы, не заменяется из набора: измените его в редакторе типов.

## Один тип как элемент библиотеки

Отметьте ровно один тип и выберите **Сохранить как элемент библиотеки…**. Это сохраняет файл `.cctype.json`: элемент библиотеки вида «Типы», который содержит только этот тип (его слои, материалы, LOD и коды классификации). Загрузите его в библиотеку, чтобы поделиться. **Открыть набор или файл IFC** читает и такой элемент и добавляет его тип в проект, как набор.

## Полезно знать

- Файл IFC другой программы тоже можно открыть здесь. Каждый его тип стены, у которого есть слои материала, читается: название, материалы слоев, их толщины и любая полость берутся из самого файла. Какие слои являются основой и что делает каждый слой (отделка, конструкция, утеплитель), угадывается; тип помечается **(угадано)**, и его нужно проверить в редакторе типов стены. Тип стены без слоев пропускается и называется в сообщении.
- Материал, который уже есть в проекте, сохраняется как есть. Новый материал, чье имя занято, получает «(набор)» после имени.
- Тип, который используют стены, никогда не заменяется из набора. Измените его в редакторе типов стены, который правильно переместит их стены.
- Код, заданный для одной стены, не переносится: он принадлежит этой стене. Код, заданный для типа, переносится.
- Файл с полем, которого нет в формате, слоем без материала или чем-то, что не является простым текстом, отклоняется, и сообщение говорит, где и почему.
- Пока не реализовано: типы перекрытий, кровель и потолков (в этой версии у них нет типов: у каждого своя толщина), типы дверей и окон, кроме семейств, а также штриховки или цвета из файла другой программы.
