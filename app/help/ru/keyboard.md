В BimCraft немного сочетаний клавиш. Большая часть работы выполняется мышью и панелями. Сочетания, записанные как {{key:Mod}}, на Mac используют Command, в остальных системах — Ctrl. См. [Клавиши, мыши и трекпады](common:keys), как клавиши записаны в этой справке.

## Везде

| Клавиша | Что делает |
|---|---|
| {{key:Ctrl+Shift+F}} | Переключает режимы экрана: обычный, полноэкранный, полноэкранный со скрытыми панелями. Ctrl на всех платформах, включая Mac |
| {{key:Esc}} | Выход из полноэкранного режима |
| {{key:Mod+,}} | Открыть {{ui:Настройки}}. См. [Настройки BimCraft](topic:settings) |
| {{key:Tab}} | Переход между кнопками, флажками и значениями. До любого элемента управления можно добраться с клавиатуры |

## 3D-вид (модели IFC)

| Клавиша или действие | Что делает |
|---|---|
| {{key:F}} | Вписать всю модель, вид в три четверти (то же, что {{ui:Вписать}}) |
| {{key:Esc}} | Снять выбор или прекратить размещение и вставку |
| Щелчок | Выбрать элемент под указателем; щелчок по пустому фону снимает выбор |
| {{key:Mod}}+щелчок или {{key:Shift}}+щелчок | Добавить элемент в выбор или убрать его |
| {{key:H}} | Скрыть выбранные элементы. См. [Скрытие, изоляция и прозрачность элементов](topic:hide-and-isolate) |
| {{key:I}} | Показать только выбранные элементы (изоляция) |
| {{key:T}} | Показать выбранные элементы, остальное сделать прозрачным |
| {{key:Shift+H}} | Снова показать все элементы |
| {{ui:Обход}} | Затем {{key:W}} {{key:A}} {{key:S}} {{key:D}} или стрелки — движение; {{key:Shift}} — бег, перетаскивание — поворот взгляда, {{key:Esc}} — остановка. См. [Обход модели](topic:walk) |
| {{key:M}} | Измерение расстояний и площадей граней. См. [Измерение расстояний, площадей граней и положений в 3D](topic:measure) |
| Перетаскивание левой кнопкой | Орбита |
| Перетаскивание правой кнопкой | Панорама |
| {{key:Shift}} или {{key:Mod}} и перетаскивание левой кнопкой | Панорама (удобно на трекпаде) |
| Прокрутка колеса или перетаскивание средней кнопкой | Масштаб |
| Прокрутка двумя пальцами или сведение на трекпаде | Масштаб |
| Один палец (касание) | Орбита; касание выбирает |
| Два пальца (касание) | Сведение для масштаба, совместное движение для панорамы |

| {{key:X}} | Секущая плоскость включена и выключена. См. [Разрез модели IFC секущей плоскостью](topic:section-plane) |
| {{key:Shift+X}} | Секущая коробка вокруг выбранных элементов, с комнатой, заданной в Настройках |

Для {{ui:Сверху}}, {{ui:Спереди}} и {{ui:Сбоку}} клавиш нет; используйте кнопки.

## Правка

Те же команды есть на панели инструментов: {{ui:Отменить}}, {{ui:Вернуть}}, {{ui:Копировать}}, {{ui:Вставить}} и меню {{ui:Ещё}}, где показана каждая клавиша. Они работают в 3D-виде модели IFC, но не тогда, когда вы вводите текст в поле. См. [Копирование, вставка и дублирование элементов библиотеки](topic:copy-paste).

| Клавиша | Что делает |
|---|---|
| {{key:Mod+Z}} | Отменить последнее изменение |
| {{key:Mod+Y}} или {{key:Mod+Shift+Z}} | Вернуть то, что было отменено |
| {{key:Mod+C}} | Копировать выбранные элементы (их имена и свойства также попадают в буфер обмена как текст) |
| {{key:Mod+X}} | Вырезать выбранные элементы: скопировать их, затем удалить |
| {{key:Mod+V}} | Вставить скопированное: оно следует за указателем, щелкните, куда его поставить |
| {{key:Mod+Shift+V}} | Вставить на то же место: откуда был вырезан, или рядом с оригиналами после копирования |
| {{key:Mod+D}} | Дублировать: скопировать выбранные элементы и начать их вставку |
| {{key:Delete}} | Удалить выбранные элементы вместе с их частями и проемами. См. [Удаление, вырезание, копирование и вставка строительных элементов](topic:edit-elements) |
| {{key:Mod+A}} | Выбрать все видимые элементы |
| {{key:Esc}} | Снять выбор |

Когда на странице выбран текст, {{key:Mod+C}} копирует этот текст, как обычно.

## Вид плана (Черчение)

Эти клавиши работают, когда включено {{ui:Черчение}} и вы не вводите текст в поле. См. [Черчение стен](topic:draw-walls) и [Двери и окна](topic:doors-and-windows).

| Клавиша или действие | Что делает |
|---|---|
| {{key:V}} | {{ui:Выбрать}} |
| {{key:W}} | {{ui:Стена}} |
| {{key:D}} | {{ui:Дверь}} |
| {{key:N}} | {{ui:Окно}} |
| {{key:H}} | Для {{ui:Дверь}} или {{ui:Окно}}: петли на другом конце |
| {{key:Shift}} при черчении стены | Держать её под углом 0°, 90°, 180° или 270° |
| Цифры и знаки футов и дюймов (`'` и `"`) | Начать ввод длины в поле {{ui:Длина}}; {{key:Enter}} применяет её |
| {{key:Enter}}, {{key:Esc}}, правая кнопка или двойной щелчок | Завершить чертимую стену; {{key:Esc}} еще раз возвращает к {{ui:Выбрать}} |
| {{key:Delete}} | Удалить выбранные стены, двери и окна; оставшиеся стены снова соединяются |
| {{key:F}} при указателе над планом | Вписать план |
| Прокрутка колеса | Масштаб относительно указателя |
| Перетаскивание средней или правой кнопкой либо {{key:Space}} и перетаскивание | Панорама; при включенном {{ui:Выбрать}} обычное перетаскивание тоже панорамирует |
| Перетаскивание двери или окна при {{ui:Выбрать}} | Перемещение вдоль стены или на другую стену |
| Два пальца (касание) | Сведение для масштаба, совместное движение для панорамы |

## Размещение и вставка элементов библиотеки

| Клавиша | Что делает |
|---|---|
| {{key:R}} | Повернуть элемент на 90° |
| {{key:Tab}} | Привязка к стене включена и выключена: задняя сторона элемента прилегает к ближайшей стене |
| {{key:Enter}} в поле **X, Y (mm)** | Разместить в введенной позиции |
| {{key:Esc}} | Прекратить размещение или вставку |

## Редактирование значений IFC

| Клавиша | Что делает |
|---|---|
| {{key:Enter}} | Сохранить введенное значение |
| {{key:Esc}} | Отменить и вернуть старое значение |
| Щелчок в другом месте | Сохранить введенное значение |
| {{key:Mod+Z}} | Отменить последнее изменение. Только когда есть несохраненные изменения и вы не вводите текст в поле |
| {{key:Mod+Y}} | Вернуть то, что было отменено |
| {{key:Mod+S}} | Сохранить как IFC. Только при несохраненных изменениях; иначе открывается собственная команда сохранения браузера |

Чтобы редактировать только с клавиатуры: нажимайте {{key:Tab}}, пока значение не будет выделено, затем нажмите {{key:Enter}}, чтобы начать ввод.

## 2D-чертежи (DWG и DXF)

| Клавиша или действие | Что делает |
|---|---|
| {{key:F}} | Вписать чертеж или лист |
| {{key:P}} | Вид печати включен и выключен |
| Двойной щелчок | Вписать |
| Перетаскивание любой кнопкой | Панорама |
| Прокрутка колеса | Масштаб у указателя |
| Прокрутка двумя пальцами или сведение на трекпаде | Масштаб у указателя. Прокрутка двумя пальцами не панорамирует |
| Один палец (касание) | Панорама. Масштабирование сведением для чертежей еще не создано |

## Чертежи в 3D

| Клавиша или действие | Что делает |
|---|---|
| {{key:3}} | 3D включается и выключается (также на 2D-виде) |
| {{key:F}} | Границы: весь чертеж |
| Перетаскивание средней или левой кнопкой | Орбита |
| Перетаскивание правой кнопкой или {{key:Shift}} и перетаскивание | Панорама |
| Прокрутка колеса | Масштаб к тому, что под указателем |
| Прокрутка двумя пальцами на трекпаде | Орбита; с {{key:Shift}} — панорама |
| Сведение на трекпаде | Масштаб |
| Один палец (касание) | Орбита |
| Два пальца (касание) | Сведение для масштаба, совместное движение для панорамы |

{{key:F}}, {{key:P}} и {{key:3}} ничего не делают, пока вы вводите текст в поле, пока показана ведомость оборудования или когда вы удерживаете {{key:Mod}} или {{key:Alt}}.
