В CadCraft Studio список движков может содержать **связь** с проектом Unreal Engine. Только в одну сторону: из CadCraft в Unreal.

## Отправить сцену

1. Выберите пункт Unreal в списке движков. В первый раз Studio просит вас выбрать папку проекта (ту, в которой есть файл `.uproject`); она ее запоминает.
2. Нажмите {{ui:Send}}. Studio записывает `CadCraft/<file name>/` внутрь проекта: сцену в виде файла USD, файл настроек, профили света и два небольших файла слоев.
3. Измените модель, сохраните и отправьте снова. Заменяются только сцена и файл настроек.

## Ваши правки в безопасности

Stage, который открывает Unreal, — это небольшой корневой слой, созданный один раз, с двумя слоями под ним: **ваш** сверху (`<name>.user.usda`, сначала пустой, CadCraft его никогда не перезаписывает) и сцена CadCraft ниже. Правки, которые вы сохраняете в свой слой, остаются при повторной отправке сцены. Свет и другие акторы, которые вы размещаете на уровне Unreal, находятся вне stage и тоже не затрагиваются.

## Без Studio

В браузере или на компьютере, где Studio не находит Unreal, выберите **Папка проекта Unreal (.zip)** в списке движков и нажмите {{ui:Render}}. Сохраняется та же папка в виде zip: распакуйте ее в папку `CadCraft` вашего проекта. При первом сохранении оставьте **Включить файлы stage** включенным; для последующих сохранений выключите его, чтобы zip содержал только сцену и файл настроек, а ваш слой никогда не заменялся.

:::note
Плагин Unreal, который открывает stage, применяет солнце, лампы, камеры и экспозицию, следит за каждой отправкой и рендерит камеру, **еще не выпущен** и в Unreal не запускался. Пока он не выпущен, Отправить помещает файлы в проект, и собственные инструменты USD в Unreal могут их открыть. Windows — первая система; macOS будет следующей.
:::
