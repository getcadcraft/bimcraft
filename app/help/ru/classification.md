## Что вы сделаете

Присвойте код классификации стенам, полам, крышам, дверям, окнам и любому другому элементу модели сразу в трех системах, расположенных рядом: Uniclass, OmniClass и UniFormat. Другие дисциплины и другое программное обеспечение опираются на код, а не на название, поэтому коды сохраняются в файле IFC как ссылки на классификацию, которые читает любая BIM-программа.

## Присвоить элементу код

1. Выберите элемент (или несколько) и откройте **Свойства**. Откройте раздел {{ui:Классификация}}.
2. Введите код в поле его системы и нажмите Enter. Когда загружена таблица кодов, введите часть кода или несколько слов («витраж») и выберите из совпадений: название кода будет заполнено автоматически.
3. {{ui:Применяется к}} показывает, куда идет код: **Этот элемент** или **Его тип (каждый элемент этого типа)**. Код у типа стены читается каждой стеной этого типа, в том числе теми, что вы нарисуете позже.
4. {{ui:Очистить}} удаляет код.

Под каждым кодом раздел указывает, откуда он: задан для этого элемента, взят из его типа или является кодом проекта по умолчанию для его класса. Собственный код элемента всегда важнее кода его типа, а код типа важнее значения по умолчанию. При выборе нескольких элементов поле с надписью «varies» означает, что у них нет одного кода; если ввести один, он присвоится всем. Каждое изменение — один шаг отмены.

Код всегда можно ввести, загружена таблица или нет. Если он не похож на код этой системы или его нет в загруженном списке, подсказка это сообщит, и код сохранится так, как вы его ввели.

## Выбор систем проекта

Откройте **Данные** на панели модели и выберите {{ui:Классификация}} (или {{ui:Классификация проекта…}} в разделе «Свойства»).

- Отметьте системы, которые использует проект. В разделе Свойства тогда показываются только они.
- **Uniclass**: таблицы Elements/ functions (EF), Systems (Ss) и Products (Pr) поставляются с приложением. Они © NBS, лицензированы по Creative Commons Attribution-NoDerivatives 4.0 и передаются без изменений. Диалог показывает редакцию каждой таблицы и день, когда она была прочитана. Это не самые новые таблицы: издатель выпускает новые каждый квартал на своем сайте.
- **OmniClass** и **UniFormat**: список кодов с приложением не поставляется, потому что издатель не разрешает передавать таблицы без лицензии. Введите любой код или загрузите собственную лицензированную таблицу вашего офиса.
- {{ui:Загрузить таблицу (CSV)…}} читает таблицу вашего офиса из файла CSV с колонкой кодов и колонкой названий (строка заголовка с названием Code, Number или Identifier и Title, Name или Description находится автоматически; без нее используются первые два столбца). Таблица остается в этом браузере и никогда не попадает в файл проекта. В файле сохраняются только назначенные вами коды. Более новую таблицу Uniclass можно загрузить так же.
- {{ui:Назначать элементам код по умолчанию по их классу}} присваивает каждой стене, полу, крыше, двери, окну, лестнице, пандусу, колонне, балке и предмету мебели стартовый код Uniclass из таблицы Elements/ functions, если у него нет собственного. Элементы, которые вы нарисуете позже, тоже получат его.
- {{ui:Показывать коды столбцами в спецификациях}} добавляет по столбцу на каждую систему в спецификации дверей, окон, стен по типам и помещений, а также в их CSV. Строка из нескольких элементов показывает «varies», когда их коды различаются.

## Полезно знать

- Коды по умолчанию — это собственный стартовый выбор CadCraft, а не издателя, и их не проверял практикующий специалист. Сверьте их со стандартом вашего проекта.
- В файле значение по умолчанию — настоящая классификация с отметкой имени связи «CadCraft default»; оно уходит, как только элемент или его тип получает собственный код.
- Коды, которые уже есть в импортированном файле, читаются и показываются независимо от того, как другая программа написала название системы. Коды любых других систем (собственные системы офиса) выводятся в списке и не трогаются.
- Коды читаются снова при открытии файла, здесь или в другой программе. Они также переносятся в экспорт IFC5 alpha (IFCX), когда включен этот экспериментальный параметр, кроме кода, заданного для крыши.
- Пока не реализовано: дерево для просмотра таблицы по уровням, коды на уровнях и в помещениях как значения проекта по умолчанию и проверка кода по редакции, указанной в файле.
