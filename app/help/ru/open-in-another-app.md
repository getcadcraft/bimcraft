## Что вы сделаете

Продолжите работу с файлом в приложении, предназначенном для следующей задачи, не сохраняя его и не открывая снова.

## Шаги

1. Откройте чертеж DWG или DXF для редактирования в приложении для черчения либо модель IFC для детализации в приложении для детализации.
2. Нажмите {{ui:Изменить в CadCraft}} на 2D-виде чертежа или {{ui:Открыть в DetailCraft}} на панели инструментов модели.
3. Другое приложение откроется в новой вкладке с уже открытым файлом.

## Что должно появиться

- Файл в новой вкладке. BimCraft тоже оставляет его открытым.
- Модель с несохраненными изменениями переходит вместе с этими изменениями. Ваша собственная копия не сохраняется.
- Чертеж переходит без связанных чертежей.

## Полезно знать

- Файл передается между двумя вкладками внутри вашего браузера. Ничего не загружается.
- Кнопка появляется, только если другое приложение открыто там, где вы работаете, и может принять файл таким способом.
- Если ничего не открывается, браузер заблокировал новую вкладку: разрешите всплывающие окна для этого сайта и нажмите кнопку ещё раз.
