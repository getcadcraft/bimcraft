## Что вы сделаете

Увидеть одним взглядом, как свойство распределено по модели: какие стены наружные, какие материалы где используются, у каких элементов нет огнестойкости. Каждый элемент получает цвет своего значения, а легенда показывает, что означает каждый цвет и сколько элементов его имеют.

## Шаги

1. Откройте модель IFC.
2. Щелкните вкладку {{ui:Color}} справа.
3. Выберите свойство в списке. Первые относятся к каждому элементу ({{ui:Class}}, {{ui:Type}}, {{ui:Storey}}, {{ui:Material}}, {{ui:Name}}…); остальные берутся из наборов свойств и наборов величин модели, под именем набора. Число после каждого — сколько элементов его имеют.
4. Прочитайте легенду: цвет, значение и сколько элементов его имеют.
5. Щелкните значение, чтобы показать только эти элементы. Удерживайте {{key:Mod}} и щелкайте, чтобы добавить значения. Нажмите {{key:Shift+H}}, чтобы снова показать все.
6. Щелкните {{ui:Off}}, чтобы вернуться к собственным цветам модели.

## Что вы должны увидеть

- До семи значений получают каждое свой цвет, начиная с самого частого. Остальные значения делят один серый и перечисляются как **другие значения**.
- Число с множеством разных значений делится на шесть равных диапазонов от светлого (низкое) к темному (высокое).
- Элементы без свойства — бледно-серые, перечислены как **Нет значения**, чтобы окрашенные выделялись.
- Цвета меняются при переключении между «Лист» и «Модель» и сохраняются при редактировании модели.
- Свойство типа учитывается для каждого элемента этого типа; если у элемента есть собственное значение того же свойства, побеждает собственное значение.

## Изменение цветов и сохранение схемы

- Щелкните образец цвета значения в легенде, чтобы выбрать для него другой цвет. Модель сразу перекрашивается.
- {{ui:Save scheme}} скачивает цвета как небольшой файл `.json` с именем по свойству, например `Class colors.json`.
- На другой модели или на компьютере коллеги нажмите {{ui:Open scheme…}} и выберите этот файл. Каждое значение из схемы получает свой цвет, поэтому одна и та же огнестойкость или система имеет одинаковый цвет во всех моделях.
- Значение, которого нет в схеме, окрашивается в серый и перечисляется как «нет в схеме»; значения схемы, которых нет в этой модели, остаются в списке с 0, чтобы вы видели всю схему.
- Схема сохраняет свои цвета в обеих темах. Выбор свойства в списке начинает с автоматических цветов заново.

## Частые ошибки

- **«В этой модели нет значений …».** Схема сохранена для свойства, которого нет в этой модели (например, для другого имени набора свойств). Откройте схему, сделанную для такой модели, или выберите свойство в списке.

- **Свойства нет в списке.** Ни у одного элемента с формой в модели его нет. Свойства самих этажей и пространств не перечисляются.
- **Все одного цвета.** У всех элементов одно и то же значение или его нет: посмотрите на числа в легенде.
