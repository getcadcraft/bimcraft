## Что вы сделаете

Укажите BimCraft, с чего должно начинаться новое здание, чтобы никто в офисе не менял одно и то же каждый раз. Это дополнение: оно выключено, пока вы его не включите, а политика, которую вы не задали, остается значением BimCraft по умолчанию без изменений.

:::note
Это значения по умолчанию для **новых** зданий и **новых** объектов. Уже начатый проект не меняется.
:::

## Шаги

1. Откройте Настройки, перейдите в {{ui:Дополнения}} и включите {{ui:Политики по умолчанию}}.
2. В Настройках откройте вкладку **BimCraft** и выберите {{ui:Политики по умолчанию}} в списке слева.
3. Задайте нужные политики. Каждая начинается с **собственного значения BimCraft**, которое указано в скобках. Политика с полями **Метрическая** и **Имперская** принимает по одному значению для каждого типа проекта; заполняйте только нужные.
4. Кнопки «Сохранить» нет: каждое изменение сохраняется сразу после ввода. Недопустимое значение отклоняется с пояснением, а старое значение остается.
5. Нажмите {{ui:Новое здание}}. Диалог заполняется по вашим политикам, и рядом с каждым значением, которое задала политика, стоит пометка **из ваших политик по умолчанию**. Любое значение можно изменить до {{ui:Создать}}.

## Политики

- **Единицы нового здания**: при создании единицы переключаются на это значение.
- **Количество уровней**, **Имена уровней** и **Высота уровня**. В имени `{n}` считает 1, 2, 3; `{n0}` считает 0, 1, 2; `{nn}` и `{nn0}` делают то же с двумя цифрами. Так `Этаж {nn0}` дает Этаж 00, Этаж 01, Этаж 02.
- **Первый тип стены**: то, что инструмент «Стена» рисует первым. Метрический офис может начинать с Exterior masonry 300 mm, а имперские проекты остаются на Exterior 2×6.
- **Тег LOD на стартовых типах стен**: уровень проработки (LOD 100–500), который девять стартовых типов показывают везде, где перечисляется тип. См. [Построение составов стен](topic:wall-assemblies).
- **LOD нового типа стены**: тег, с которым начинается новый тип в редакторе типов. Его можно изменить там.
- **Первый лист**: его формат, масштаб, номер листа и имя (используйте `{level}` для имени нижнего уровня) или вообще без первого листа.
- **Размеры аннотаций на бумаге** (Настройки › Общие › Политики по умолчанию): высоты офиса в миллиметрах, как они напечатаны, для примечаний, текста размеров, обозначений, названий помещений, букв маркеров осей, заголовков видов и текста ведомостей. Новое здание берет их при создании и хранит в своем файле. См. [Чертеж в натуральную величину, аннотирование по масштабу](topic:annotation-sizes).
- **Инструмент, активный после создания**: «Выбрать», как BimCraft делает сам по себе, или «Стена», чтобы первые два щелчка на плане уже рисовали стену.

## Оформление ведомостей: стандарт офиса

В **Настройки › Общие › Политики по умолчанию**, в разделе **Оформление ведомостей (стандарт офиса)**, задайте, как группируется каждая ведомость, есть ли промежуточные итоги и общий итог, ее заголовок и регистр заголовков столбцов. Каждая ведомость, которая не задает свое, берет их, кто бы ее ни настраивал. См. [Оформление, сохранение и экспорт ведомости](topic:schedule-layouts).

## Передача по офису

1. В Настройках откройте вкладку **Общие** и выберите {{ui:Политики по умолчанию}}.
2. При желании введите **Название офиса**. Оно записывается в файл.
3. Нажмите {{ui:Сохранить в файл}}. Вы получите небольшой файл с расширением `.ccdefaults.json`.
4. На другом компьютере включите дополнение, откройте то же место и нажмите {{ui:Загрузить из файла}}. Политики из файла заменят те, что на этом компьютере.

На вкладке **Общие** также есть **Систему единиц нового проекта**, которая действует во всех приложениях с этим дополнением, и {{ui:Сбросить все политики}}. {{ui:Сбросить до значений BimCraft по умолчанию}} на вкладке BimCraft очищает только политики BimCraft.

## Полезно знать

- Файл — обычный открытый JSON: список имен политик и их значений. Политика, которую файл называет, но которой нет в этой версии, пропускается и называется в сообщении; остальные загружаются.
- Политики хранятся в этом браузере и действуют для каждого приложения CadCraft на этом компьютере. Они не сохраняются в файле здания и не синхронизируются между компьютерами: для переноса используйте файл.
- Тег LOD стартового типа берется из политики этого компьютера. Тип, который вы создали как копию стартового, хранит свой тег в файле здания.
- У BimCraft нет настройки точности, поэтому политики точности здесь нет.
- Здание, начатое из шаблона, получает уровни и листы шаблона. Тип стены и политика единиц по-прежнему применяются.
- Выключите дополнение, и все снова станет собственным значением BimCraft. Ваши политики сохраняются, чтобы вернуть их при включении.
