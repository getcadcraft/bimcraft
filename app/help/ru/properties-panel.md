## Элемент IFC

Вверху панели {{ui:Свойства}} показывается вид элемента без префикса «Ifc» (например, Door, WallStandardCase, FurnishingElement) и его имя или «Без имени».

| Поле | Описание | Редактируется |
|---|---|---|
| Name | Имя элемента, часто название семейства и типа от экспортера | Да |
| Type | Название типа элемента, если он есть | Нет |
| Object type | Свободное текстовое описание типа, которое заполняют некоторые экспортеры | Да |
| Tag | Метка или марка элемента; многие экспортеры записывают сюда ID элемента | Да |
| Description | Свободный текст | Да |
| GlobalId | Постоянный 22-символьный идентификатор элемента IFC, одинаковый во всех экспортах этого элемента | Нет |
| Line | Номер строки элемента (`#1234`) в этом файле IFC. Меняется между экспортами | Нет |

Ниже идут **наборы свойств**, отсортированные по имени:

- Каждый набор раскрывается и сворачивается по щелчку на его имени. Первые три открыты.
- Набор с пометкой «(тип)» принадлежит типу элемента: «Свойство типа: изменение здесь применяется ко всем элементам этого типа».
- Наборы величин (длины, площади, объемы, количества, веса) доступны только для чтения.
- Списки и перечисляемые значения показываются только для чтения.
- Значения Да/Нет показываются как **Да** или **Нет**.
- Числа округляются до четырех знаков после запятой для показа. Длины (свойство длины или длина величины) показываются в {{ui:Единицы}}, выбранных на панели инструментов, с обозначением единицы рядом. Можно ввести новое значение в этой единице или с другим обозначением единицы (2.4 m, 8'-0"): BimCraft записывает обратно собственное число файла. Другие числа показываются так, как они есть в файле.
- Пустое значение показывается как *пусто*. Измененное значение выделяется жирным шрифтом и синей полосой рядом.

## Копирование значения

Рядом с каждым значением в {{ui:Свойства}} есть небольшая кнопка копирования: нажмите ее, чтобы поместить значение в буфер обмена точно в том виде, в каком оно показано, например GlobalId, серийный номер или любое значение набора свойств. Копирование никогда не начинает редактирование.

Наверху {{ui:Копировать всё}} копирует все значения элемента как текст, набор за набором, а {{ui:Копировать как CSV}} копирует их строками «группа, свойство, значение» для вставки в таблицу. Пустые значения сохраняются, чтобы у каждого поля была строка. Это работает так же для элемента другой открытой модели; когда открыто больше одной модели, CSV начинается со столбца «Модель» с именем ее файла.

## Панель файла (IFC)

| Поле | Описание |
|---|---|
| File, Size | Открытый файл и его размер |
| Schema | Версия IFC, например IFC2X3 или IFC4 |
| Project | Название проекта и его полное название |
| Phase | Фаза проекта, если экспортер ее записал |
| Exported from | Экспортирующая программа из заголовка файла |
| Author | Автор из заголовка файла |
| Exported | Дата и время из заголовка файла |
| Elements | Сколько элементов с формой было нарисовано |
| Triangles | Сколько треугольников составляют их формы; мера того, насколько тяжелая модель |

## Панель файла (проект и семейство)

| Поле | Описание |
|---|---|
| Kind | Проект, Шаблон проекта, Семейство или Шаблон семейства |
| Saved in | Версия, которая последней сохранила файл |
| Build | Точная сборка этой версии |
| Read | Какая часть файла прочитана BimCraft, из его размера |

## Панель чертежа (DWG и DXF)

| Поле | Описание |
|---|---|
| Format | Версия, в которой сохранен чертеж, с кодом формата, например AC1032 |
| Units | Единицы вставки чертежа, если они заданы |
| Entities | Сколько объектов прочитано |
| Layers | Сколько слоев |
| Sheets | Сколько листов (макетов) или «Нет» |
| Linked drawings | Сколько связанных чертежей найдено и загружено |
| Equipment | Сколько помеченных единиц оборудования размещено на листах |

## Панель папки

| Поле | Описание |
|---|---|
| Folder, Files, Size | Открытая папка, сколько файлов в ней и их общий размер |
| Models | Файлы проектов и семейств, каждый со своими резервными копиями, учтенными один раз |
| CAD drawings, IFC models | Сколько чертежей CAD и сколько моделей IFC |
| Problems | Сколько копий моделей неполные или нечитаемые, или «Нет» |
