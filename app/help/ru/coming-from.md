Если вы знаете Revit, большая часть BimCraft покажется знакомой по словам и незнакомой по объему. Самое важное различие: **эта сборка читает и проверяет модели и редактирует данные IFC. Пока она не создает модели, как Revit.** Вы не можете чертить стены, размещать семейства, создавать виды или листы, сохранять файл проекта. Зато можно открыть почти любой файл здания на любом компьютере с браузером, увидеть, что в нем есть, проверить всю папку проекта и исправить данные модели IFC.

## Привычки и их аналоги

| Если вы привыкли к | В BimCraft |
|---|---|
| Открывать `.rvt` в Revit, чтобы увидеть модель | BimCraft открывает `.rvt` как карточку файла: выпуск, сведения о проекте, связи, предпросмотр. Для трехмерной модели экспортируйте IFC и откройте его. [Прочитайте файл проекта или семейства](topic:read-rvt-file) |
| Проверять, в какой версии сохранен файл, перед открытием | Карточка сверху пишет «сохранено в Revit …», не обновляя и не меняя файл |
| Обозреватель проекта | Нет обозревателя видов и листов. В модели IFC есть списки {{ui:Storeys}} и {{ui:Elements}}; у чертежа — вкладки листов |
| Палитра свойств | Панель {{ui:Properties}} справа, для щелкнутого элемента. Наборы свойств IFC вместо групп параметров |
| Параметры экземпляра и типа | Наборы свойств экземпляра и наборы с пометкой «(тип)». Изменение типа применяется ко всем элементам этого типа, как в Revit. [Измените свойство типа для всех элементов типа](topic:type-vs-instance) |
| Edit Type | Диалога нет: щелкните значение в наборе с пометкой «(тип)» и введите новое |
| Выбор многих элементов, фильтры, Select All Instances | Один элемент за раз. Еще не создано |
| ViewCube и колесо навигации | ViewCube в правом нижнем углу, четыре кнопки ({{ui:Fit}}, {{ui:Top}}, {{ui:Front}}, {{ui:Side}}) и свободное вращение. Колеса навигации нет |
| Shift и перетаскивание средней кнопкой для вращения, средней кнопкой для панорамы | Левая кнопка вращает, правая (или {{key:Shift}} и перетаскивание) панорамирует, колесо масштабирует. Стиль меню {{ui:BIM ribbon}} переключает панораму на среднюю кнопку, а вращение — на {{key:Shift}} со средней кнопкой. [Меню, клавиши и мышь](topic:menus-keys-and-mouse) |
| Планы этажей, разрезы, секущие коробки | Одна плоскость {{ui:Section}} за раз ({{key:X}}); секущей коробки и 2D-планов нет. [Разрежьте модель IFC секущей плоскостью](topic:section-plane) |
| Скрытие в виде, изоляция, видимость и графика | Включение и отключение {{ui:Storeys}}, {{ui:Spaces}} и {{ui:Edges}}. Скрытия отдельных элементов пока нет |
| Помещения | Пространства IFC, сначала скрытые. Щелкните {{ui:Spaces}} |
| Сохранить, Сохранить как, синхронизация с центральным файлом | {{ui:Save as IFC}} скачивает новый файл IFC. Исходный файл никогда не меняется. Центрального файла и совместной работы нет |
| Отмена через {{key:Mod+Z}} | Работает с правками IFC до сохранения. [Измените свойства IFC и сохраните исправленную копию](topic:edit-ifc-properties) |
| Manage Links | Откройте папку проекта: каждая связь проверяется и отмечается как **В этой папке**, **Найден файл с тем же именем**, **Файл библиотеки** или **Нет в этой папке**. [Откройте всю папку проекта](topic:open-project-folder) |
| Аудит или открытие файла, чтобы проверить, не поврежден ли он | Отчет по папке проверяет каждую копию и резервную копию на обрыв, за несколько секунд. [Проверьте папку на поврежденные копии](topic:check-folder-health) |
| Выбор нужного файла в беспорядочной папке | Поле {{ui:Start here}} предлагает один файл с причинами |

Если вы в основном открываете модели для проверки, как в программе проверки или просмотра IFC, выберите стиль меню {{ui:Viewer}}: инструменты просмотра и проверки стоят первыми, а инструменты построения собраны в одном меню. См. [Меню, клавиши и мышь](topic:menus-keys-and-mouse).

## Из просмотра файлов DWG

Если вы открываете DWG в AutoCAD или в просмотрщике DWG:

| Если вы привыкли к | В BimCraft |
|---|---|
| Вкладки «Модель» и «Лист» внизу | Вкладки над чертежом: {{ui:Model}} и по одной на каждый лист |
| ZOOM Extents, двойной щелчок колесом | Двойной щелчок, {{key:F}} или {{ui:Fit}} |
| Панорама средней кнопкой | Перетаскивание любой кнопкой |
| Менеджер слоев | Список {{ui:Layers}}: отметьте, чтобы показать, снимите, чтобы скрыть; {{ui:All on}} и {{ui:All off}} |
| Менеджер внешних ссылок | **Связанные чертежи** справа, со статусами **Показан** или **Не найден**, и {{ui:Add linked drawings…}} |
| Предпросмотр печати | {{ui:Print view}} или {{key:P}}: черным по белому с весами линий. Печать не выполняется |
| Извлечение данных атрибутов блоков | Вкладка {{ui:Equipment}} для размеченных чертежей оборудования общепита, с {{ui:Download CSV}} |
| Измерение, черчение, редактирование, сохранить как | Не в BimCraft. Приложение CadCraft для черчения рисует и редактирует чертежи |

## Различия, которые сбивают с толку

- **Работает в браузере, и браузер бережно относится к вашим файлам.** BimCraft читает только те файлы и папки, которые вы ему передали, выбрав или перетащив их. Он не может открыть файл сам и не может сохранить поверх него. Каждое сохранение — это скачивание.
- **Ничего не загружается на сервер.** Слово «Загрузить» в диалогах выбора папок некоторых браузеров — это формулировка самого браузера. Файлы остаются на вашем компьютере.
- **IFC — формат моделей.** Файл проекта открывается карточкой, потому что его трехмерное содержимое не документировано. Считайте IFC способом, которым модели попадают в BimCraft.
- **Правки не затрагивают соседей.** Изменение значения одного элемента никогда не меняет его соседей, даже если экспортер использовал это значение совместно. Свойства типа — намеренное исключение.
- **Нет проекта, нет видов.** BimCraft показывает один файл за раз и ничего о нем не помнит после закрытия вкладки, кроме имен недавних папок в Chrome и Edge.
- **Клавиши Mac.** Там, где сочетания Revit для Windows используют Ctrl, сочетания BimCraft используют {{key:Mod}}: это Command на Mac.
- **Привычки мыши.** Вращение выполняется левой кнопкой, а не Shift и средней кнопкой, если только вы не выберете стиль меню {{ui:BIM ribbon}} или не назначите кнопки сами в [Меню, клавиши и мышь](topic:menus-keys-and-mouse).
