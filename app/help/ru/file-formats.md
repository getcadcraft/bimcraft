## IFC

| Что читается | Подробности |
|---|---|
| Геометрия | Каждый элемент с формой, окрашенный так, как указано в файле. Помещения и пространства рисуются полупрозрачными и сначала скрыты |
| Этажи | Строительные этажи по порядку высот и элементы на каждом этаже. Элементы без этажа группируются как «Не на этаже» |
| Количество элементов | Сколько элементов каждого вида (стены, двери, перекрытия…), показано в {{ui:Элементы}} |
| Сведения о проекте | Название проекта, полное название и стадия; схема; программа-экспортер, автор и дата экспорта из заголовка файла |
| Данные элемента | Имя, тип, тип объекта, метка, описание, GlobalId; каждый набор свойств и набор величин элемента и его типа |

Редактируемые: имя, тип объекта, метка, описание и отдельные значения свойств. Сохраняется как новый файл IFC. Открываются схемы IFC2X3, IFC4 и IFC4X3, читаются собственным движком IFC BimCraft; все, что он пока не может нарисовать, перечисляется в разделе **Пока не нарисовано** на панели {{ui:Файл}}. Модель переносится в начало координат при открытии, поэтому модель, расположенная далеко от него, все равно показывается в центре экрана. `.ifczip` и `.ifcxml` не открываются.

## Файлы проектов и семейств

`.rvt` — проекты, `.rte` — шаблоны проектов, `.rfa` — семейства и `.rft` — шаблоны семейств.

| Что читается | Подробности |
|---|---|
| Сведения о файле | Версия и сборка, совместная работа, путь к центральной модели, путь последнего сохранения, имя пользователя, язык, GUID документа |
| Сведения о проекте | Собственные поля проекта (название, номер, заказчик, адрес, статус…) без значений по умолчанию для нового проекта |
| Сведения о семействе | Название семейства, категория, версия, последнее обновление и его параметры по группам |
| Ссылки | Список связанных моделей, CAD-ссылок, изображений и таблиц ключевых примечаний, на которые указывает файл |
| Картинка предпросмотра | Миниатюра, сохраненная в файле |

Не читаются: 3D-модель, элементы, виды, листы и спецификации. Они хранятся в недокументированном формате. BimCraft читает из каждого файла лишь несколько десятков килобайт, поэтому размер файла почти не важен.

## Файлы проектов .pln, .pla, .tpl и .bpn

Пока не читаются: BimCraft сообщает об этом при открытии. Экспортируйте IFC для модели и DWG для чертежей; см. [Открытие файлов проектов .pln и .pla](topic:pln-project-files).

## DWG и DXF

| Что читается | Подробности |
|---|---|
| Пространства | Пространство модели и каждый лист (раскладка) в порядке вкладок |
| Видовые экраны | Видовые экраны каждого листа с их масштабом, поворотом и замороженными слоями |
| Слои | Имя, цвет, вкл./выкл., заморожен, флаг печати и вес линии |
| Объекты | Линии, полилинии, дуги, окружности, эллипсы, сплайны, штриховки и тела, текст и многострочный текст, блоки и атрибуты, размеры, выноски и мультивыноски, таблицы, точки, изображения |
| Связанные чертежи | Рисуются там, где вставлены, если их файлы найдены |
| Изображения | Рисуются по файлам изображений, если найдены (PNG, JPEG, GIF, BMP, WebP; TIFF — нет) |
| Метки оборудования | Метки позиций кухонного оборудования (атрибуты `KCL-ITEM`) для спецификации оборудования |

Все остальное учитывается в разделе **Пока не нарисовано** и никогда не угадывается. Проверены файлы DWG форматов AutoCAD с 2000 по 2018 (файлы R13 и R14 тоже принимаются, но в тестовом наборе их не было; более старые DWG не открываются); на панели {{ui:Чертеж}} показан код формата (например, AC1032). Файлы DXF всех версий открываются, включая R12. Оба формата читаются собственными модулями чтения BimCraft на этой вкладке. Ничего не записывается обратно в DWG или DXF.

## В папке

| Вид | Расширения | В отчете |
|---|---|---|
| Модели | `.rvt` `.rfa` `.rte` `.rft` | Сгруппированы с пронумерованными резервными копиями, проверены на исправность, карточка прочитана, ссылки проверены |
| IFC | `.ifc` | Перечисляются; открываются в 3D |
| CAD | `.dwg` `.dxf` `.dgn` | Перечисляются вместе с моделями, которые на них ссылаются; DWG и DXF открываются в 2D, DGN — нет |
| Остатки | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | Перечисляются в разделе **Отложено** |
| Служебные папки | `*_backup`, `*_log`, `Revit_temp`, скрытые папки | Перечисляются в разделе **Отложено**, не читаются |

См. [Отчет по папке: роли, статусы и ссылки](topic:folder-roles).
