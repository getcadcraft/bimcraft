BimCraft da bir nechta tezkor tugma bor. Asosiy ish sichqoncha va panellar bilan bajariladi. {{key:Mod}} bilan yozilgan tugmalar Mac da Command, boshqa joyda Ctrl ni bildiradi. Bu yerda tugmalar qanday yozilishi uchun qarang: [Tugmalar, sichqonchalar va sensorli panellar](common:keys).

## Hamma joyda

| Tugma | Nima qiladi |
|---|---|
| {{key:Ctrl+Shift+F}} | Ekran rejimlarini almashtirish: oddiy, toʻliq ekran, panellar yashirilgan toʻliq ekran. Ctrl barcha platformalarda, shu jumladan Mac da ham |
| {{key:Esc}} | Toʻliq ekrandan chiqish |
| {{key:Mod+,}} | {{ui:Sozlamalar}} ni ochish. Qarang: [BimCraft sozlamalari](topic:settings) |
| {{key:Tab}} | Tugmalar, belgilash qutilari va qiymatlar orasida harakatlanish. Har bir boshqaruv elementiga klaviaturadan yetish mumkin |

## 3D koʻrinish (IFC modellari)

| Tugma yoki amal | Nima qiladi |
|---|---|
| {{key:F}} | Butun modelni uch chorak koʻrinishda moslash (xuddi {{ui:Moslash}} kabi) |
| {{key:Esc}} | Tanlovni tozalash yoki joylashtirish va qoʻyishni toʻxtatish |
| Bosish | Koʻrsatkich ostidagi elementni tanlash; boʻsh fonga bosish tanlovni tozalaydi |
| {{key:Mod}}+bosish yoki {{key:Shift}}+bosish | Elementni tanlovga qoʻshish yoki undan chiqarish |
| {{key:H}} | Tanlangan elementlarni yashirish. Qarang: [Elementlarni yashirish, ajratish va orqali koʻrish](topic:hide-and-isolate) |
| {{key:I}} | Faqat tanlangan elementlarni koʻrsatish (ajratish) |
| {{key:T}} | Tanlangan elementlarni koʻrsatish, qolgan hammasi shaffof |
| {{key:Shift+H}} | Har bir elementni yana koʻrsatish |
| {{ui:Sayr}} | Soʻng {{key:W}} {{key:A}} {{key:S}} {{key:D}} yoki oʻqlar bilan yurish, {{key:Shift}} yugurtiradi, sudrash atrofga qarashga imkon beradi, {{key:Esc}} toʻxtatadi. Qarang: [Model boʻylab sayr](topic:walk) |
| {{key:M}} | Masofalar va yuza maydonlarini oʻlchash. Qarang: [3D da masofa, yuza maydoni va joylarni oʻlchash](topic:measure) |
| Chap tugma bilan sudrash | Aylantirish |
| Oʻng tugma bilan sudrash | Surish |
| {{key:Shift}} yoki {{key:Mod}} va chap tugma bilan sudrash | Surish (sensorli panelda qulay) |
| Gʻildirakni aylantirish yoki oʻrta tugma bilan sudrash | Kattalashtirish |
| Sensorli panelda ikki barmoq bilan aylantirish yoki siqish | Kattalashtirish |
| Bitta barmoq (teginish) | Aylantirish; bir marta teginish tanlaydi |
| Ikki barmoq (teginish) | Siqib kattalashtirish, birga siljitib surish |

| {{key:X}} | Kesim tekisligini yoqish va oʻchirish. Qarang: [IFC modelini kesim tekisligi bilan kesish](topic:section-plane) |
| {{key:Shift+X}} | Tanlangan elementlar atrofida kesim qutisi; xona Sozlamalarda belgilanadi |

{{ui:Yuqori}}, {{ui:Old}} va {{ui:Yon}} uchun tugmalar yoʻq; tugmalardan foydalaning.

## Tahrirlash

Xuddi shu buyruqlar asboblar panelida: {{ui:Ortga qaytarish}}, {{ui:Qayta bajarish}}, {{ui:Nusxalash}}, {{ui:Qoʻyish}} va har bir tugmani koʻrsatadigan {{ui:Qoʻshimcha}} menyusi. Ular IFC modelining 3D koʻrinishida ishlaydi, maydonga matn yozayotganda emas. Qarang: [Kutubxona elementlarini nusxalash, qoʻyish va dublikat qilish](topic:copy-paste).

| Tugma | Nima qiladi |
|---|---|
| {{key:Mod+Z}} | Oxirgi oʻzgarishni ortga qaytarish |
| {{key:Mod+Y}} yoki {{key:Mod+Shift+Z}} | Ortga qaytarilganni qayta bajarish |
| {{key:Mod+C}} | Tanlangan elementlarni nusxalash (ularning nomlari va xossalari matn sifatida buferga ham tushadi) |
| {{key:Mod+X}} | Tanlangan elementlarni kesish: nusxalash, soʻng oʻchirish |
| {{key:Mod+V}} | Nusxalanganni qoʻyish: u koʻrsatkichga ergashadi, joyini tanlash uchun bosing |
| {{key:Mod+Shift+V}} | Joyida qoʻyish: kesilgan joyda yoki nusxalashdan keyin asllari yonida |
| {{key:Mod+D}} | Dublikat: tanlangan elementlarni nusxalash va ularni qoʻyishni boshlash |
| {{key:Delete}} | Tanlangan elementlarni, ularning qismlari va teshiklari bilan oʻchirish. Qarang: [Qurilish elementlarini oʻchirish, kesish, nusxalash va qoʻyish](topic:edit-elements) |
| {{key:Mod+A}} | Koʻrinib turgan har bir elementni tanlash |
| {{key:Esc}} | Hech narsani tanlamaslik |

Sahifada matn tanlangan boʻlsa, {{key:Mod+C}} oddiy holatdagidek oʻsha matnni nusxalaydi.

## Reja koʻrinishi (Chizish)

Bular {{ui:Chizish}} yoqilgan va maydonga matn yozmayotgan paytda ishlaydi. Qarang: [Devorlarni chizish](topic:draw-walls) va [Eshiklar va derazalar](topic:doors-and-windows).

| Tugma yoki amal | Nima qiladi |
|---|---|
| {{key:V}} | {{ui:Tanlash}} |
| {{key:W}} | {{ui:Devor}} |
| {{key:D}} | {{ui:Eshik}} |
| {{key:N}} | {{ui:Deraza}} |
| {{key:H}} | {{ui:Eshik}} yoki {{ui:Deraza}} bilan: menteşalar narigi uchida boʻladi |
| Devor chizayotganda {{key:Shift}} | Uni 0°, 90°, 180° yoki 270° da ushlab turish |
| Raqamlar va fut hamda dyuym belgilari (`'` va `"`) | {{ui:Uzunlik}} qutisiga uzunlik yozishni boshlash; {{key:Enter}} uni ishlatadi |
| {{key:Enter}}, {{key:Esc}}, oʻng tugma yoki ikki marta bosish | Chizilayotgan devorni tugatish; {{key:Esc}} yana bosilsa {{ui:Tanlash}} ga qaytadi |
| {{key:Delete}} | Tanlangan devorlar, eshiklar va derazalarni oʻchirish; qolgan devorlar yana bogʻlanadi |
| Koʻrsatkich reja ustida turganda {{key:F}} | Rejani moslash |
| Gʻildirakni aylantirish | Koʻrsatkich atrofida kattalashtirish |
| Oʻrta yoki oʻng tugma bilan sudrash, yoki {{key:Space}} va sudrash | Surish; {{ui:Tanlash}} yoqilgan boʻlsa, oddiy sudrash ham suradi |
| {{ui:Tanlash}} bilan eshik yoki derazani sudrash | Uni devori boʻylab yoki boshqa devorga siljitish |
| Ikki barmoq (teginish) | Siqib kattalashtirish, birga siljitib surish |

## Kutubxona elementlarini joylashtirish va qoʻyish

| Tugma | Nima qiladi |
|---|---|
| {{key:R}} | Elementni 90° ga burish |
| {{key:Tab}} | Devorga tortishni yoqish va oʻchirish: elementning orqa tomoni eng yaqin devorga tegadi |
| **X, Y (mm)** maydonida {{key:Enter}} | Kiritilgan joyga joylashtirish |
| {{key:Esc}} | Joylashtirish yoki qoʻyishni toʻxtatish |

## IFC qiymatlarini tahrirlash

| Tugma | Nima qiladi |
|---|---|
| {{key:Enter}} | Kiritilgan qiymatni saqlash |
| {{key:Esc}} | Bekor qilish va eski qiymatni qaytarish |
| Boshqa joyga bosish | Kiritilgan qiymatni saqlash |
| {{key:Mod+Z}} | Oxirgi oʻzgarishni ortga qaytarish. Faqat saqlanmagan oʻzgarishlar boʻlganda va maydonga matn yozmayotganda |
| {{key:Mod+Y}} | Ortga qaytarilganni qayta bajarish |
| {{key:Mod+S}} | IFC sifatida saqlash. Faqat saqlanmagan oʻzgarishlar boʻlganda; aks holda brauzerning oʻz saqlash buyrugʻi ochiladi |

Faqat klaviatura bilan tahrirlash uchun: qiymat ajratilguncha {{key:Tab}} ni bosing, soʻng yozishni boshlash uchun {{key:Enter}} ni bosing.

## 2D chizmalar (DWG va DXF)

| Tugma yoki amal | Nima qiladi |
|---|---|
| {{key:F}} | Chizmani yoki varaqni moslash |
| {{key:P}} | Chop etish koʻrinishini yoqish va oʻchirish |
| Ikki marta bosish | Moslash |
| Istalgan tugma bilan sudrash | Surish |
| Gʻildirakni aylantirish | Koʻrsatkich joyida kattalashtirish |
| Sensorli panelda ikki barmoq bilan aylantirish yoki siqish | Koʻrsatkich joyida kattalashtirish. Ikki barmoq bilan aylantirish surmaydi |
| Bitta barmoq (teginish) | Surish. Chizmalar uchun siqib kattalashtirish hali qilinmagan |

## 3D da chizmalar

| Tugma yoki amal | Nima qiladi |
|---|---|
| {{key:3}} | 3D ni yoqish va oʻchirish (2D koʻrinishda ham) |
| {{key:F}} | Chegaralar: butun chizma |
| Oʻrta yoki chap tugma bilan sudrash | Aylantirish |
| Oʻng tugma yoki {{key:Shift}} va sudrash | Surish |
| Gʻildirakni aylantirish | Koʻrsatkich ostidagi narsaga qarab kattalashtirish |
| Sensorli panelda ikki barmoq bilan surish | Aylantirish; {{key:Shift}} bilan surish |
| Sensorli panelda siqish | Kattalashtirish |
| Bitta barmoq (teginish) | Aylantirish |
| Ikki barmoq (teginish) | Siqib kattalashtirish, birga siljitib surish |

{{key:F}}, {{key:P}} va {{key:3}} maydonga matn yozayotganda, jihozlar jadvali koʻrsatilayotganda yoki {{key:Mod}} yoki {{key:Alt}} ushlab turilganda hech narsa qilmaydi.
