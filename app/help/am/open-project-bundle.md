## ምን ያደርጋሉ

**የፕሮጀክት ጥቅል** (`.ccbundle.zip`) ይክፈቱ እና ፕሮጀክቱን እንደተደራጀ ይጠቀሙበት፤ እይታዎቹን፣ ሉሆቹንና የባህሪ ቡድኖቹን፣ በሞዴሉ ላይ።

ጥቅሉ የሚይዘው፦

- ሞዴሉን እንደ IFC፣
- ሉሆቹን እንደ PDF እና DWG፣
- IFC የማይይዘውን ዝርዝር፦ እይታዎቹን (እያንዳንዱ ከፎቁ፣ ከንብርብር ጥምረቱና ከመለኪያው ጋር)፣ ሉሆቹንና ላይ የተቀመጡ ንድፎችን፣ በቡድኖቻቸው ውስጥ ያሉ የባህሪ ትርጓሜዎችን፣ ምደባዎችን፣ እና እንደ ንብርብሮች፣ የብዕር ስብስቦች፣ የመስመር ዓይነቶች፣ ሙሌቶች፣ ገጽታዎችና ውሁዶች ያሉ ደረጃዎችን።

ጥቅሎቹ የሚጻፉት በክፍት ምንጭ ስክሪፕት ነው፤ ይህም በ Archicad ውስጥ ይሠራና ዝርዝሮቹን ከ Archicad ራሱ ይጠይቃል። BimCraft `.pln` ወይም `.tpl` ፋይሎችን በቀጥታ አያነብም፤ [.pln እና .pla የፕሮጀክት ፋይሎችን ክፈት](topic:pln-project-files) ይመልከቱ።

## ጥቅል ይፍጠሩ

ስክሪፕቱ ቅድመ-እይታ ነው፤ በእያንዳንዱ የ Archicad ስሪት ገና አልተሞከረም። ከ[github.com/getcadcraft/bim-project-bundle](https://github.com/getcadcraft/bim-project-bundle) ያውርዱት። Archicad 24 ወይም አዲስ እና Python 3.8 ወይም አዲስ ያስፈልጎታል፤ ሌላ ምንም መጫን አያስፈልግም።

1. `archicad_bundle.py` ወደ አንድ አቃፊ ያስቀምጡ፣ ለምሳሌ `C:\cc-bundle`።
2. በ Archicad ፕሮጀክቱን ይክፈቱ እና በትክክል **CadCraft bundle** የሚል ስም ያለው የአሳታሚ ስብስብ ይፍጠሩ፦ 3D እይታው እንደ IFC፣ እያንዳንዱ ሉህ እንደ PDF፣ እና እያንዳንዱ ሉህ እንደገና እንደ DWG፣ ሁሉም በዲስክ ላይ ወደ አንድ ጠፍጣፋ አቃፊ ይታተማሉ።
3. ፕሮጀክቱ ክፍት ሆኖ `python archicad_bundle.py --probe --out .` አንድ ጊዜ ያሂዱ። ማንበብ ብቻ ያደርጋል እና `probe.json` ይጽፋል።
4. `python archicad_bundle.py --out . --translator "IFC4 Reference View"` ያሂዱ (የመረጡትን IFC ተርጓሚ ይጠቀሙ)። Archicad ስብስቡን ያትማል እና ስክሪፕቱ `<project>.ccbundle.zip` ይጽፋል።

ስክሪፕቱ በኩል ማተም ካልተሳካ ስብስቡን በእጅ ያትሙና `python archicad_bundle.py --out . --no-publish --files <folder>\*.ifc <folder>\*.pdf <folder>\*.dwg` ያሂዱ። ሁሉም አማራጮች በማከማቻው README ውስጥ አሉ። የሆነ ነገር ካልመጣ በማከማቻው ላይ ጉዳይ ይክፈቱና `probe.json` ያያይዙ።

## ጥቅል ክፈት

1. {{ui:ፋይል ይምረጡ}} ጠቅ ያድርጉ፣ ወይም `.ccbundle.zip` ን በBimCraft ላይ ይጣሉ። በ{{ui:አቃፊ ክፈት}} የከፈቱት አቃፊ ውስጥ ጥቅሎች በ**የፕሮጀክት ጥቅሎች** ስር ይዘረዘራሉ፤ በስማቸው አንዱን ጠቅ ያድርጉ።
2. ሞዴሉ ልክ እንደ ማንኛውም IFC ይከፈታል፣ እና **የፕሮጀክት ጥቅል** ክፍል ከፋይሉ እውነታዎች በታች በግራ በኩል ይታያል።

ምንም አይሰቀልም፡ ጥቅሉ በኮምፒውተርዎ ላይ ይነበባል፣ በአንድ ፋይል በአንድ ጊዜ፣ ስለዚህ ትልቅ ሞዴል ሁለት ጊዜ አይገለበጥም።

## እይታ አሳይ

በ**እይታዎች** ስር እይታዎች በፕሮጀክቱ ውስጥ የነበራቸው አቃፊዎች ተሰባስበዋል። የእይታውን ስም ጠቅ ያድርጉ፦

- **የወለል ፕላን** የራሱን ፎቅ ብቻ ከላይ ሆኖ ያሳያል።
- **የንብርብር ጥምረቱ** ያንን ጥምረት የሚደብቃቸውን ንብርብሮች ላይ ያሉ ነገሮችን ይደብቃል። የሁኔታ መስመሩ ስንት ነገር እንደተደበቀ ይናገራል።
- **መለኪያው** ከስሙ ጎን እና በሁኔታ መስመሩ ላይ ይታያል።
- **የ3D እይታ** ሁሉንም ፎቆች ያሳያል።

ሁሉንም እንደገና ለማሳየት በ{{ui:አሳይ}} ውስጥ {{ui:ሁሉንም አሳይ}} ይጠቀሙና ሁሉንም ፎቆች ምልክት ያድርጉ።

:::note
BimCraft ንብርብሮቹን የሚያገኘው በIFC ፋይሉ የንብርብር ምደባዎች በኩል ነው። IFC ያለእነሱ ከተላከ የንብርብር ጥምረት ምንም አይደብቅም፤ የሁኔታ መስመሩ 0 ነገሮች ተደብቀዋል ይላል።
:::

## ሉህ ክፈት

በ**ሉሆች** ስር እያንዳንዱ ሉህ ቁጥሩን፣ ስሙን፣ የወረቀት መጠኑንና ላይ የተቀመጡትን እይታዎች ያሳያል።

- **PDF** የሉሁን PDF ከጥቅሉ ያስቀምጣል።
- **DWG** የሉሁን ንድፍ በ2D እይታ ይከፍታል። ወደ ሞዴሉ ለመመለስ ማንኛውንም እይታ ጠቅ ያድርጉ።
- **በ… ክፈት** የሉሁን ፋይል ለሚሰራበት መተግበሪያ በአዲስ ትር ይልካል፦ PDF ወደ MarkupCraft፣ DWG ወደ CadCraft። ያ መተግበሪያ ከBimCraft ጎን ክፍት ሲሆን ብቻ ይታያል። ፋይሉ ትሩ ሲጫን ከጥቅሉ ይነበባል፤ ምንም አይሰቀልም።

ሁለቱም የሌለው ሉህ **ጥቅሉ ውስጥ ፋይል የለም** ይላል።

## ባህሪያትን በፕሮጀክቱ ቡድኖች ይመልከቱ

አንድ ነገር ይምረጡ። **የባህሪ ቡድኖች** ባህሪያቱን በፕሮጀክቱ በተገለጹ ቡድኖች ስር ያሳያል፤ ትርጓሜው ለIFC በሰጠው የባህሪ ስብስብና ስም፣ ወይም ካልሆነ በስሙ ይጣጣማል። ቀሪዎቹ በተለመደው መንገድ በ{{ui:ባህሪያት}} ውስጥ ይቀራሉ። **የባህሪ ትርጓሜዎች** እያንዳንዱን ትርጓሜ ከቡድኑ፣ ከዓይነቱና ከIFC ስሙ ጋር ይዘረዝራል።

## መደበኛ ደረጃዎችና ማስታወሻዎች

- **ደረጃዎች** በጥቅሉ ውስጥ ያሉትን ንብርብሮች፣ የንብርብር ጥምረቶች፣ የብዕር ስብስቦች፣ የመስመር ዓይነቶች፣ ሙሌቶች፣ ገጽታዎች፣ ውሁዶችና ቁሳቁሶች ይቆጥራል።
- **ማስታወሻዎች** ስክሪፕቱ ከዚያ የArchicad ስሪት ማግኘት ያልቻለውን፣ BimCraft ማንበብ ያልቻለውን ማንኛውንም መስክ፣ እና ጥቅሉ የሚጠቅሰው ግን የማይይዘውን ፋይል ይዘረዝራል።
