ተጨማሪ ፕሮግራም (ቅንብሮች › ተጨማሪ) በ{{ui:Render}} የሞተር ዝርዝር ላይ ሞተር ማከል ይችላል። ለተጨማሪ ፕሮግራም ጸሐፊዎች ሙሉው ጽሑፍ በተጨማሪው መግለጫ ክፍል 16 ላይ ነው፤ በአጭሩ:

- ተጨማሪው ሞተርን ይመዘግባል፤ መታወቂያው በራሱ ስም ይጀምራል፤ ስም፣ ከተፈለገ ቅንብሮች፣ እና **ወይ** የሚሮጥ ፕሮግራም **ወይም** ስዕሉን የሚስል JavaScript ተግባር ይይዛል።
- ፕሮግራም የሚያሄድ ሞተር **`engine.run`** ፈቃድ ያስፈልገዋል፤ ይህም ከመጫን በፊትና በቅንብሮች ውስጥ ይታያል። የሚሰራው በStudio ብቻ ነው፤ በአሳሹ ውስጥ እንደ ሊቀመጥ የሚችል ፋይል ይታያል።
- ተጨማሪው ፕሮግራሙን በስሙ ይጠቅሳል (ተራ የፋይል ስም ብቻ፤ ሼል ፈጽሞ አይደለም)፣ በ**የተፈረመው ተጨማሪ ውስጥ** ያለ ስክሪፕት፣ እና ከቦታ ያዥ እና ከተራ ቃላት የተሰሩ ነጋሪ እሴቶችን። Studio ፕሮግራሙን ያገኛል ወይም አንድ ጊዜ እንዲጠቁሙት ይጠይቃል።
- ተጨማሪ ፕሮግራም ለመጀመሪያ ጊዜ ሲያሄድ **Studio በራሱ ንግግር ይጠይቅዎታል**: የትኛው ተጨማሪ፣ የትኛው ፕሮግራም፣ እና ስክሪፕቱ ፕሮግራሙ የሚችለውን ሁሉ ሊያደርግ እንደሚችል። የሚያምኑበትን ተጨማሪ ብቻ ይፍቀዱ። መልስዎ ለዚያ ተጨማሪና ፕሮግራም ይታወሳል።
- ጥቅሉ (ትዕይንቱ በUSD ፎርማት እና የቅንብሮች ፋይል፣ ተጨማሪው ሲጠይቅ የglTF ፋይል ጋር) እና የተጨማሪው ስክሪፕት አዲስ ጊዜያዊ አቃፊ ውስጥ ይገባሉ፤ ፕሮግራሙ እዚያ ይሰራል፤ ስዕሉም በተጨማሪው ሞተር ስም ምልክት ተደርጎበት ይመለሳል።

:::note
ተጨማሪዎች ሬንደር ሞተሮችን መጨመር የሚችሉት ከ add-on API 1.4 ጀምሮ ብቻ ነው። ለክፍት ምንጭ የትእዛዝ-መስመር ሬንደር ፕሮግራም የተዘጋጀ ምሳሌ የራሱ ማከማቻ ውስጥ አለ፤ በዚያ ሬንደር ፕሮግራም ገና አልተሞከረም።
:::
