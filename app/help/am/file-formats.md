| ፎቆች | የሕንፃ ፎቆች በከፍታ ቅደም ተከተል፣ እና የትኞቹ አካላት በየትኛው ላይ እንዳሉ። በየትኛውም ፎቅ ላይ ያልሆኑ አካላት "ፎቅ ላይ ያልሆነ" ተብለው ይሰበሰባሉ |
| የአካላት ብዛት | እያንዳንዱ ዓይነት ስንት አካል እንዳለው (ግድግዳዎች፣ በሮች፣ ስላቦች…)፣ በ{{ui:አካላት}} ውስጥ ይታያል |
| የፕሮጀክት መረጃ | የፕሮጀክት ስም፣ ረጅም ስም እና ደረጃ፤ ሼማ፤ ፋይሉን ያወጣው ፕሮግራም፣ ደራሲ እና የማውጫ ቀን ከፋይሉ ራስጌ |
| የአካል መረጃ | ስም፣ ዓይነት፣ የነገር ዓይነት፣ መለያ፣ መግለጫ፣ GlobalId፤ በአካሉና በዓይነቱ ላይ ያለ እያንዳንዱ የባህሪ ስብስብና የብዛት ስብስብ |

ሊስተካከል የሚችል፦ ስም፣ የነገር ዓይነት፣ መለያ፣ መግለጫ፣ እና ነጠላ የባህሪ እሴቶች። እንደ አዲስ IFC ፋይል ይቀመጣል። IFC2X3፣ IFC4 እና IFC4X3 ሼማዎች ይከፈታሉ፤ በBimCraft የራሱ IFC ሞተር ይነበባሉ። ገና መሳል ያልቻለው ማንኛውም ነገር በ{{ui:ፋይል}} ፓኔል ውስጥ **ገና አልተሳለም** ስር ይዘረዘራል። ሞዴሉ ሲከፈት ወደ መነሻው ይንቀሳቀሳል፤ ስለዚህ ከእሱ ርቆ የተቀመጠ ሞዴል አሁንም በማያ ገጹ መሃል ላይ ይታያል። `.ifczip` እና `.ifcxml` አይከፈቱም።

| ይነበባል | ዝርዝሮች |
|---|---|
| የፋይል መረጃ | የተለቀቀና የግንባታ ስሪት፣ የጋራ ሥራ፣ ማዕከላዊ ሞዴል መንገድ፣ መጨረሻ የተቀመጠ መንገድ፣ የተጠቃሚ ስም፣ ቋንቋ፣ የሰነድ GUID |
| የፕሮጀክት መረጃ | የፕሮጀክቱ የራሱ መስኮች (ስም፣ ቁጥር፣ ደንበኛ፣ አድራሻ፣ ሁኔታ…)፣ ያለ አዲስ-ፕሮጀክት ነባሪዎች |
| የቤተሰብ መረጃ | የቤተሰብ ስም፣ ምድብ፣ ስሪት፣ መጨረሻ የተዘመነበት፣ እና ፓራሜትሮቹ በቡድን |
| ማገናኛዎች | ፋይሉ የሚጠቁማቸው የተገናኙ ሞዴሎች፣ የCAD ማገናኛዎች፣ ምስሎችና የቁልፍ ቃል ሰንጠረዦች ዝርዝር |
| የቅድመ-እይታ ስዕል | በፋይሉ ውስጥ የተቀመጠው ድንክዬ |

ያልተነበበ፦ 3D ሞዴሉ፣ አካላት፣ እይታዎች፣ ሉሆችና ሰንጠረዦች። በማይታወቅ ቅርጸት ተቀምጠዋል። BimCraft ከእያንዳንዱ ፋይል ጥቂት አስር ኪሎባይት ብቻ ያነባል፤ ስለዚህ የፋይሉ መጠን ብዙ ጉዳይ አይደለም።

| ቪውፖርቶች | የእያንዳንዱ ሉህ ቪውፖርቶች፣ ከመጠናቸው፣ ከማዞሪያቸውና ከቀዘቀዙ ንብርብሮቻቸው ጋር |
| ንብርብሮች | ስም፣ ቀለም፣ በርቷል/ጠፍቷል፣ ቀዝቅዟል፣ የማተሚያ ምልክት እና የመስመር ውፍረት |
| ነገሮች | መስመሮች፣ ፖሊላይኖች፣ ቅስቶች፣ ክቦች፣ ኤሊፕሶች፣ ስፕላይኖች፣ ሃቾችና ሶሊዶች፣ ጽሑፍና ባለ-ብዙ መስመር ጽሑፍ፣ ብሎኮችና ባህሪያት፣ ልኬቶች፣ መሪዎችና ባለ-ብዙ መሪዎች፣ ሰንጠረዦች፣ ነጥቦች፣ ምስሎች |
| የተገናኙ ስዕሎች | ሲገቡ ባሉበት ይሳላሉ፣ ፋይሎቻቸው ሲገኙ |
| ምስሎች | ከሥዕል ፋይሎቻቸው ይሳላሉ፣ ሲገኙ (PNG፣ JPEG፣ GIF፣ BMP፣ WebP፤ TIFF አይደለም) |
| የመሣሪያ መለያዎች | የምግብ አገልግሎት ዕቃ መለያዎች (`KCL-ITEM` ባህሪያት)፣ ለመሳሪያ ሰንጠረዡ |

ሌላ ማንኛውም ነገር በ**ገና አልተሳለም** ስር ይቆጠራል፤ ፈጽሞ አይገመትም። የDWG ቅርጸቶች ከAutoCAD 2000 እስከ 2018 ተፈትነዋል (R13 እና R14 ፋይሎችም ይቀበላሉ፣ ግን በፈተና ስብስቡ ውስጥ አልነበሩም፤ የቆዩ DWGs አይከፈቱም)። የ{{ui:ንድፍ}} ፓኔል የቅርጸቱን ኮድ ያሳያል (እንደ AC1032)። የሁሉም ስሪት DXF ፋይሎች ይከፈታሉ፣ R12ንም ጨምሮ። ሁለቱም በBimCraft የራሱ አንባቢዎች ይነበባሉ፣ በዚህ ትር። ወደ DWG ወይም DXF ምንም ተመልሶ አይቀመጥም።
