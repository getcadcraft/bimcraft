## ምን ያደርጋሉ

በግድግዳዎች፣ ወለሎች፣ ጣሪያዎች፣ በሮች፣ መስኮቶችና በሞዴሉ ውስጥ ባለ ማንኛውም ነገር ላይ የምደባ ኮድ አስቀምጥ፤ እስከ ሦስት ስርዓቶች ጎን ለጎን፦ Uniclass፣ OmniClass እና UniFormat። ሌሎች ዘርፎችና ሌሎች ሶፍትዌሮች በኮዱ ላይ ይመካሉ፣ በስሙ አይደለም፤ ስለዚህ ኮዶቹ ማንኛውም የBIM ፕሮግራም የሚያነበው የምደባ ማጣቀሻ ሆነው በ IFC ፋይሉ ውስጥ ይቀመጣሉ።

## ለኤለመንት ኮድ ስጥ

1. ኤለመንቱን (ወይም ብዙዎቹን) ምረጥና **ባህሪያት**ን ክፈት። የ{{ui:Classification}} ክፍሉን ክፈት።
2. ኮዱን በስርዓቱ ሳጥን ውስጥ ጻፍና Enter ተጫን። የኮድ ዝርዝር ሲጫን፣ የኮዱን ክፍል ወይም ጥቂት ቃላት ጻፍ ("curtain wall") እና ከተዛማጆቹ ምረጥ፤ የኮዱ ርዕስ ለአንተ ይሞላል።
3. {{ui:Applies to}} ኮዱ የሚሄድበትን ይናገራል፦ **ይህ ኤለመንት**፣ ወይም **የዓይነቱ (የዓይነቱ ሁሉም ኤለመንት)**። በግድግዳ ዓይነት ላይ ያለ ኮድ በዚያ ዓይነት ያሉ ግድግዳዎች ሁሉ ያነባሉ፣ ወደፊት የምትስላቸውንም ጨምሮ።
4. {{ui:Clear}} ኮዱን ያነሳል።

ከእያንዳንዱ ኮድ በታች ክፍሉ ከየት እንደመጣ ይናገራል፦ በዚህ ኤለመንት ላይ ተዘጋጅቷል፣ ከዓይነቱ ነው፣ ወይም ለክፍሉ የፕሮጀክት ነባሪ ነው። የኤለመንቱ የራሱ ኮድ ሁልጊዜ ከዓይነቱ ያሸንፋል፤ የዓይነቱም ከነባሪው ያሸንፋል። ብዙ ኤለመንቶች ሲመረጡ "ይለያያል" የሚል ሳጥን ማለት ኮድ አይጋሩም ማለት ነው፤ አንድ ሲጽፉ ለሁሉም ይሰጣል። እያንዳንዱ ለውጥ አንድ ቀልብስ እርምጃ ነው።

ኮዱን ዝርዝር ቢጫንም ባይጫንም ሁልጊዜ መጻፍ ይቻላል። የዚያ ስርዓት ኮድ የማይመስል ወይም በተጫነው ዝርዝር ውስጥ ከሌለ፣ ፍንጭ ይነግራል እና ኮዱ እንደጻፍከው ይቀራል።

## የፕሮጀክቱን ስርዓቶች ምረጥ

በሞዴል አሞሌው ላይ **ዳታ**ን ክፈትና {{ui:Classification}} ምረጥ (ወይም በባህሪያት ክፍሉ ውስጥ {{ui:Project classification…}})።

- ይህ ፕሮጀክት የሚጠቀምባቸውን ስርዓቶች ምልክት አድርግ። ባህሪያት ከዚያ በኋላ እነዚያን ብቻ ያሳያል።
- **Uniclass**፦ የ Elements/ functions (EF)፣ Systems (Ss) እና Products (Pr) ሰንጠረዦች ከመተግበሪያው ጋር ይመጣሉ። የ NBS ናቸው፣ በ Creative Commons Attribution-NoDerivatives 4.0 ፈቃድ ስር፣ ሳይለወጡ ይተላለፋሉ። ንግግሩ የእያንዳንዱን ሰንጠረዥ እትምና የተነበበበትን ቀን ያሳያል። እነሱ አዲሶቹ ሰንጠረዦች አይደሉም፤ አሳታሚው በየሩብ ዓመቱ በራሱ ጣቢያ ላይ አዳዲሶችን ያወጣል።
- **OmniClass** እና **UniFormat**፦ ከመተግበሪያው ጋር የኮድ ዝርዝር አይመጣም፤ ምክንያቱም አሳታሚያቸው ያለ ፈቃድ ሰንጠረዦቹን እንዲተላለፉ አይፈቅድም። ማንኛውንም ኮድ ጻፍ፣ ወይም የቢሮህን ፈቃድ ያለው ሰንጠረዥ ጫን።
- {{ui:Load a table (CSV)…}} የቢሮህን ሰንጠረዥ ከ CSV ፋይል ያነባል፤ የኮድ ዓምድና የርዕስ ዓምድ ያለው (ራስጌ ረድፉ Code፣ Number ወይም Identifier እና Title፣ Name ወይም Description ከሆነ በራሱ ይገኛል፤ ከሌለ የመጀመሪያዎቹ ሁለት ዓምዶች ይጠቀማሉ)። ሰንጠረዡ በዚህ አሳሽ ውስጥ ይቆያል እና በፕሮጀክት ፋይሉ ውስጥ በጭራሽ አይገባም። ብቻ የመደብካቸው ኮዶች በፋይሉ ውስጥ ይቀመጣሉ። አዲስ የ Uniclass ሰንጠረዥ በዚሁ መንገድ መጫን ትችላለህ።
- {{ui:Give elements a default code by their class}} ከ Elements/ functions ሰንጠረዥ የራሱ ኮድ ለሌለው ለእያንዳንዱ ግድግዳ፣ ወለል፣ ጣሪያ፣ በር፣ መስኮት፣ ደረጃ፣ ራምፕ፣ አምድ፣ ጨረርና የቤት ዕቃ የመጀመሪያ የ Uniclass ኮድ ይሰጣል። ከዚያ በኋላ የምትስላቸው ኤለመንቶችም ያገኙታል።
- {{ui:Show the codes as columns in the schedules}} ለእያንዳንዱ ስርዓት አንድ ዓምድ ወደ በሮች፣ መስኮቶች፣ በዓይነት የተከፋፈሉ ግድግዳዎች እና ክፍሎች ሰንጠረዦችና ወደ CSV ያክላል። ብዙ ኤለመንቶች ያሉበት ረድፍ ኮዶቻቸው ሲለያዩ "ይለያያል" ያሳያል።

## ማወቅ ጠቃሚ

- ነባሪ ኮዶቹ የ CadCraft የራሱ መነሻ ምርጫ ናቸው፤ የአሳታሚው አይደሉም፤ በባለሙያ አልተፈተሹም። ከፕሮጀክትህ ደረጃ ጋር አረጋግጣቸው።
- በፋይሉ ውስጥ ነባሪ ኮድ እውነተኛ ምደባ ነው፣ በ«CadCraft default» የግንኙነት ስም ምልክት የተደረገበት፤ ኤለመንቱ ወይም ዓይነቱ የራሱን ኮድ እንደተቀበለ ይወጣል።
- ቀደም ብሎ በተመጣ ፋይል ውስጥ ያሉ ኮዶች ይነበባሉ እና ይታያሉ፣ ሌላ ፕሮግራም ለስርዓቱ ስም የተጠቀመው ፊደል ምንም ይሁን። የሌሎች ስርዓቶች ኮዶች (የቢሮ የራሳቸው) ተዘርዝረው አይነኩም።
- ኮዶቹ ፋይሉ እንደገና ሲከፈት፣ እዚህ ወይም በሌላ ፕሮግራም፣ ይነበባሉ። በላብ አማራጩ ሲበራ ወደ IFC5 alpha (IFCX) ወጪም ይገባሉ፤ በጣሪያ ላይ የተዘጋጀ ኮድ ብቻ ካልሆነ።
- ያልተገነቡ፦ ሰንጠረዥን ደረጃ በደረጃ የሚያሰስ ዛፍ፣ በደረጃዎችና በክፍሎች ላይ የፕሮጀክት ነባሪ ኮዶች፣ እና ኮድን በፋይሉ ውስጥ ከተጠቀሰው እትም ጋር ማረጋገጥ።
