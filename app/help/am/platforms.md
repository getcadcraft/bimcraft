BimCraft በአሁኑ ጊዜ በChrome፣ በEdge፣ በFirefox እና በSafari ስሪቶች፣ በMac፣ በWindows እና በLinux ላይ ይሠራል። የ3D እይታ WebGL ይፈልጋል፤ እያንዳንዱ ወቅታዊ አሳሽ አለው። አብዛኛውን ጊዜ መተግበሪያዎቹ ምን እንደሚያስፈልጋቸው [አሳሾችና ኮምፒውተሮች](common:browsers) ይመልከቱ።

## አቃፊ መክፈት

| አሳሽ | {{ui:አቃፊ ክፈት}} የሚያደርገው | አቃፊ መጎተት | {{ui:የቅርብ ጊዜ አቃፊዎች}} |
|---|---|---|---|
| Chrome, Edge | የአሳሹ የአቃፊ መምረጫ፣ ከዚያ "Let site view files?"፦ **View files**ን ጠቅ ያድርጉ | ያለ ጥያቄ ይከፈታል | አዎ፣ ለተመረጡ ወይም ለተጎተቱ አቃፊዎች |
| Firefox | የሲስተሙ የአቃፊ መምረጫ | ያለ ጥያቄ ይከፈታል | አይ |
| Safari | የሲስተሙ የአቃፊ መምረጫ፣ **Upload** ቁልፍ ያለው (ምንም አይሰቀልም) | ያለ ጥያቄ ይከፈታል | አይ |

ከመድረክ ጀርባ፦ Chrome እና Edge File System Access መምረጫውን ይጠቀማሉ እና አቃፊውን ማስታወስ ይችላሉ። Firefox እና Safari የቆየውን የአቃፊ መምረጫ ይጠቀማሉ፣ እሱም ሁሉንም ፋይሎች በአንድ ጊዜ ያቀርባል እና ማስታወስ አይችልም። የተጎተተ አቃፊ በእያንዳንዱ አሳሽ ግቤት በግቤት ይነበባል።

:::chromium
Brave እና ሌሎች የChromium አሳሾች የአቃፊ መምረጫውን ያጠፋሉ። BimCraft ከዚያ የሲስተሙን የአቃፊ መምረጫ ይጠቀማል፤ አሳሹ "*n* ፋይሎችን ወደዚህ ጣቢያ ይሰቀሉ?" ብሎ ሊጠይቅ ይችላል። ምንም አይሰቀልም፤ ፋይሎቹ ወደ ትሩ ብቻ ይሄዳሉ። አቃፊውን መጎተት ጥያቄውን ያስቀራል።
:::

## Mac፣ Windows እና Linux

- {{key:Mod+S}} እና {{key:Mod+Z}} የተጻፉ አቋራጮች በMac ላይ Command ናቸው፤ በWindows እና Linux ላይ Ctrl።
- {{key:Ctrl+Shift+F}} (የማያ ሁነታዎች) በMac ላይም ጨምሮ በሁሉም መድረክ Control ነው።
- የፋይል መገናኛዎችና የማውረጃ አቃፊው የሲስተምዎ የራሳቸው ናቸው።

## መዳፊት፣ ትራክፓድና ንክኪ

| ግብዓት | 3D እይታ | 2D ሥዕል |
|---|---|---|
| መዳፊት | በግራ መጎተት ያዞራል፣ በቀኝ መጎተት ያንቀሳቅሳል፣ ዊል ያጎላል፣ ጠቅ መምረጥ | ማንኛውም መጎተት ያንቀሳቅሳል፣ ዊል ያጎላል፣ ሁለቴ ጠቅ ያስማማል |
| ትራክፓድ | ጠቅ-መጎተት ያዞራል፤ {{key:Shift}} ወይም {{key:Mod}} እና መጎተት ያንቀሳቅሳል፤ ባለሁለት ጣት ማሸብለል ወይም መጭመቅ ያጎላል | ጠቅ-መጎተት ያንቀሳቅሳል፤ ባለሁለት ጣት ማሸብለል ወይም መጭመቅ ያጎላል |
| ንክኪ | አንድ ጣት ያዞራል፤ ሁለት ጣቶች ይጨምቃሉና ያንቀሳቅሳሉ፤ መንካት ይመርጣል | አንድ ጣት ያንቀሳቅሳል፤ እስካሁን የመጭመቅ ማጉላት የለም፤ {{ui:አስማማ}}ን ይንኩ |

በMac ትራክፓድ ላይ የቀኝ ጠቅ ባለሁለት ጣት ጠቅ (ወይም Control-ጠቅ) ነው። [ቁልፎች፣ መዳፊቶችና ትራክፓዶች](common:keys) ይመልከቱ።

ታብሌቶችና ስልኮች ነጠላ ፋይሎችን ከፍተው ማየት ይችላሉ፤ ግን ማያው ትንሽ ነው፣ ብዙ የሞባይል አሳሾች አቃፊ መምረጥ አይችሉም፣ ትላልቅ ሞዴሎችም በማህደረ ትውስታቸው ላይገቡ ይችላሉ። ኮምፒውተር የተሻለ ይሠራል።

## ትላልቅ ፋይሎችና ማህደረ ትውስታ

BimCraft የሚያነበው ሁሉ በአሳሹ ትር ማህደረ ትውስታ ውስጥ ይኖራል። ትሩ ምን ያህል ሊጠቀም እንደሚችል በአሳሹና በኮምፒውተርዎ ላይ ይወሰናል፤ ከBimCraft የበለጠ።

| ፋይል | ምን ያህል ይነበባል | ምን ይጠበቅ |
|---|---|---|
| IFC | ሙሉ ፋይሉ፣ ከእሱ የተሠራው የ3D ጂኦሜትሪ ጋር | ምን ያህል እንደሚሆን በኮምፒውተርዎና በአሳሹ ላይ ይወሰናል፤ በበርካታ መቶ ሜጋባይት ያለ ሞዴል ለላፕቶፕ ሊበዛ ይችላል። ከ1.5 ሚሊዮን ትሪያንግሎች በላይ ጠርዞች ይጠፋሉ |
| ፕሮጀክትና ቤተሰብ ፋይሎች | ከ40 KB እስከ 100 KB ገደማ፣ መጠናቸው ምንም ቢሆን | በጣም ትላልቅ ማዕከላዊ ሞዴሎች እንኳ ከኔትዎርክ ድራይቭ ጭምር በቅጽበት ይከፈታሉ |
| DWG እና DXF | ሙሉ ፋይሉ | በጣም ትላልቅ ንድፎች "ይህ ንድፍ በጣም ትልቅ ነው፤ ክፍሉ ብቻ ይታያል።" ይላሉ |
| አቃፊዎች | የፋይል ዝርዝር፣ በሞዴል ጥቂት ኪሎባይት | እስከ 20,000 ፋይሎች |

የአሳሽ ትር ማህደረ ትውስታው ካለቀ፣ አሳሹ የራሱን ስህተት ገጽ ያሳያል (ለምሳሌ Chrome ላይ "Aw, Snap!")። ሌሎች ትሮችን ይዝጉ፣ BimCraft ን ዳግም ይጫኑና እንደገና ይሞክሩ፤ ወይም ተጨማሪ ማህደረ ትውስታ ያለው ኮምፒውተር ይጠቀሙ።
