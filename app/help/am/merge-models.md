ሁለት ሰዎች የአንድ ህንፃ ቅጂ ይወስዳሉ፤ አንዱ ምስራቃዊውን ክንፍ፣ ሌላው ምዕራባዊውን ይስላል፣ በኋላም ቅጂዎቹ አንድ መሆን አለባቸው። የተለያዩ ነገሮችን ነክተው ከሆነ፣ ፕሮግራም ሰውን ሳይሆን ይህን ማድረግ ይችላል።

## ይህ እንዴት ይሰራል

በIFC ፋይል ውስጥ ያለ እያንዳንዱ ግድግዳ፣ በር፣ ደረጃ፣ ክፍል እና የባህሪ ስብስብ የማይለወጥ GlobalId አለው። ማዋሃዱ ነገሮቹን በዚያ መለያ ይፈልጋል፣ ፋይሉ በሚሰጣቸው ቁጥር (`#123`) አይደለም፤ ቁጥሮቹ ፕሮግራም በሚያስቀምጥበት ጊዜ ስለሚለወጡ። ከነገሩ የተንጠለጠሉ፣ የራሳቸው መለያ የሌላቸው ክፍሎች (አቀማመጥ፣ ቅርጾች፣ ዩኒቶች) በያዙት ነገር ይነጻጸራሉ።

ሁለቱም ቅጂዎች ተመሳሳይ የIFC ስሪት (2x3፣ 4 ወይም 4.3) መሆን አለባቸው። ማዋሃዱ ፋይልዎን እንዳለ፣ በቅደም ተከተሉና በቁጥሮቹ፣ ያቆያል፣ እና አዲስ የሆነውን ይጨምራል፤ ስለዚህ የማዋሃዱ git diff የሚያሳየው ማዋሃዱ የለወጠውን ብቻ ነው።

## ማዘጋጀት

Git በእያንዳንዱ ማከማቻ አንድ ጊዜ ሁለት መስመሮች ያስፈልጉታል:

```
# .gitattributes
*.ifc merge=cadcraft

# በአንድ ጊዜ፣ በእያንዳንዱ ኮምፒውተር ላይ
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

ያለ git `cadcraft merge <base> <ours> <theirs>` ያሂዱ። Fossil እና Mercurial ተመሳሳዩን ሶስት ፋይሎች በራሳቸው የማዋሃጃ መሳሪያ ቅንብር ይወስዳሉ። ምንም አይሰቀልም፤ ሁሉም በኮምፒውተርዎ ላይ ይሰራል።

## ህጎቹ

- በአንድ ወገን ብቻ የተለወጠ ባሕሪ ይወሰዳል። በሁለቱም ወገን አንድ ዓይነት ለውጥ አንድ ጊዜ ይወሰዳል።
- ተመሳሳይ ባሕሪ በሁለት መንገድ የተለወጠ (ተመሳሳይ ደረጃ በሁለት መንገድ ተቀይሮ) **ግጭት** ነው: የእርስዎ ወገን ይቆያል እና ሪፖርቱ ሁለቱንም ይዘረዝራል። ውጤቱን ከፍተው በእጅ ያስተካክሉት።
- የነገሮች ዝርዝር (የአንድ ደረጃ ግድግዳዎች፣ የአንድ ስብስብ ባሕሪያት) እንደ ስብስብ ይዋሃዳል: ማንኛውም ወገን የጨመረው ይቆያል፣ ማንኛውም ወገን ያስወገደው ይወገዳል። በአንድ ደረጃ ላይ ሁለት ሰዎች እያንዳንዳቸው ግድግዳ ቢጨምሩ አይጋጩም።
- በማንኛውም ወገን የተጨመረ ነገር ከቅርጹና ከባሕሪያቱ ጋር ይቆያል። በአንድ ወገን ተወግዶ በሌላኛው ካልተነካ: ይወገዳል። በአንድ ወገን ተወግዶ በሌላኛው ከተለወጠ: ይወገዳል፣ እና ሪፖርት ይደረጋል።
- የፋይሉ የጊዜ ማህተምና ደራሲ፣ እና የእያንዳንዱ ነገር የባለቤት ታሪክ፣ የእርስዎ ሆነው ይቆያሉ።

ጂኦሜትሪ ሙሉ በሙሉ ይዋሃዳል: የግድግዳ ቅርጽ ከአንድ ወገን ይመጣል፣ ነጥብ በነጥብ አይቀላቀልም። የተጨመቁ (zipped) IFC እና IFCX ፋይሎች አይዋሃዱም። ከማዋሃድ በኋላ ውጤቱን በBimCraft ይክፈቱና ከማስቀመጥዎ በፊት የ**ችግሮች** ፓነልን ይመልከቱ።
