BimCraft ដំណើរការនៅកំណែបច្ចុប្បន្ននៃ Chrome, Edge, Firefox និង Safari នៅលើ Mac, Windows និង Linux។ ទិដ្ឋភាព 3D ត្រូវការ WebGL ដែលកម្មវិធីរុករកបច្ចុប្បន្នទាំងអស់មាន។ មើល [កម្មវិធីរុករក និងកុំព្យូទ័រ](common:browsers) សម្រាប់អ្វីដែលកម្មវិធីត្រូវការជាទូទៅ។

## Mac, Windows និង Linux

- ផ្លូវកាត់ដែលសរសេរ {{key:Mod+S}} និង {{key:Mod+Z}} គឺ Command នៅលើ Mac និង Ctrl នៅលើ Windows និង Linux។
- {{key:Ctrl+Shift+F}} (របៀបអេក្រង់) គឺ Control នៅគ្រប់វេទិកា រួមទាំង Mac។
- ប្រអប់ឯកសារ និងថតទាញយកជារបស់ប្រព័ន្ធរបស់អ្នក។

នៅលើផ្ទាំងចុច Mac ការចុចខាងស្ដាំគឺជាការចុចពីរម្រាមដៃ (ឬ Control-click)។ មើល [គន្លឹះ កណ្ដុរ និងផ្ទាំងចុច](common:keys)។

ថេប្លេត និងទូរស័ព្ទអាចបើកឯកសារតែមួយ ហើយមើលពួកវា ប៉ុន្តែអេក្រង់តូច កម្មវិធីរុករកចល័តជាច្រើនមិនអាចជ្រើសថតបានទេ ហើយម៉ូដែលធំអាចមិនសមនឹងអង្គចងចាំរបស់ពួកវា។ កុំព្យូទ័រដំណើរការល្អបំផុត។

## ឯកសារធំ និងអង្គចងចាំ

អ្វីគ្រប់យ៉ាងដែល BimCraft អានស្ថិតនៅក្នុងអង្គចងចាំនៃផ្ទាំងកម្មវិធីរុករក។ ផ្ទាំងអាចប្រើប៉ុន្មាន អាស្រ័យលើកម្មវិធីរុករក និងកុំព្យូទ័ររបស់អ្នក ច្រើនជាង BimCraft។

| ឯកសារ | ចំនួនដែលត្រូវបានអាន | អ្វីដែលត្រូវរំពឹង |
|---|---|---|
| IFC | ឯកសារទាំងមូល ជាមួយធរណីមាត្រ 3D ដែលបង្កើតពីវា | ទំហំអាស្រ័យលើកុំព្យូទ័រ និងកម្មវិធីរុករករបស់អ្នក; ម៉ូដែលរាប់រយមេហ្កាបៃអាចច្រើនពេកសម្រាប់ឡាបតុប។ លើសពី 1.5 លានត្រីកោណ គែមត្រូវបានបិទ |

| ថត | បញ្ជីឯកសារ បូកពីរបីគីឡូបៃក្នុងម៉ូដែលម្ដងៗ | រហូតដល់ 20,000 ឯកសារ |
