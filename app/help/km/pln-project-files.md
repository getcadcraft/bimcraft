## អ្វីដែលអ្នកនឹងធ្វើ

នាំយកគម្រោងដែលបានរក្សាទុកជា `.pln` (គម្រោង), `.pla` (ឯកសាររក្សាទុកជាមួយបណ្ណាល័យរបស់វា), `.tpl` (គំរូ) ឬ `.bpn` (បម្រុងទុក) ចូលទៅក្នុង BimCraft។ ទាំងនេះជាឯកសាររបស់ Archicad ផ្ទាល់។

## អ្វីដែលបើកបានសព្វថ្ងៃ

- **ឯកសារគម្រោងខ្លួនឯងមិនទាន់បើកបាននៅឡើយទេ។** ទម្រង់របស់វាមិនត្រូវបានផ្សព្វផ្សាយ ហើយ BimCraft មិនទាន់អានវានៅឡើយ។ នៅពេលអ្នកបើកមួយ BimCraft នឹងប្រាប់ដូច្នេះ ហើយចង្អុលមកទំព័រនេះ។
- **BimCraft ពិនិត្យបៃដំបូងនៃឯកសារ។** គម្រោង Archicad ចាប់ពីកំណែ 17 ឡើងចាប់ផ្តើមដោយសញ្ញាសម្គាល់ខ្លីដូចគ្នា ដូច្នេះ BimCraft អាចប្រាប់អ្នកដោយជឿជាក់ថាឯកសារជាគម្រោង Archicad។ ឯកសារដែលមានឈ្មោះ Archicad ប៉ុន្តែមិនចាប់ផ្តើមបែបនោះ ទំនងជាត្រូវបានប្តូរឈ្មោះ ខូច ឬមកពីកំណែចាស់។ សញ្ញាសម្គាល់មិនអាចបែងចែកគម្រោង ឯកសាររក្សាទុក និងគំរូចេញពីគ្នាបានទេ។
- **ការនាំចេញ IFC បើកបានពេញលេញ**៖ ម៉ូដែលក្នុង 3D ជាន់ តំបន់ជាកន្លែង ទិន្នន័យធាតុ សំណុំលក្ខណៈសម្បត្តិ និងការចាត់ថ្នាក់ ជាមួយគ្រប់ឧបករណ៍ BimCraft។
- **ការនាំចេញ DWG បើក** នៅក្នុងទិដ្ឋភាព 2D ជាមួយស្រទាប់ និងប្លង់បង្ហាញរបស់វា ហើយនៅក្នុង {{ui:3D}}។ ដើម្បីកែវា ប្រើ {{ui:កែក្នុង CadCraft}}។

ឬនាំគម្រោងទាំងមូលជាឯកសារ zip តែមួយ ជាមួយទិដ្ឋភាព ប្លង់បង្ហាញ និងក្រុមលក្ខណៈសម្បត្តិរបស់វា៖ សូមមើល [បើកកញ្ចប់គម្រោង](topic:open-project-bundle)។

## នាំចេញ IFC (ម៉ូដែល)

1. បើកគម្រោងក្នុង Archicad។
2. ជ្រើស **File > Save As** ហើយជ្រើស **IFC** ជាប្រភេទឯកសារ។
3. ជ្រើសឧបករណ៍បកប្រែ IFC (ឈ្មោះរបស់ Archicad សម្រាប់ក្រុមការកំណត់នាំចេញ IFC)។ មួយសម្រាប់ **IFC4 Reference View** ឬ **IFC2X3 Coordination View 2.0** សមនឹង BimCraft។ IFC4X3 ក៏បើកបានដែរ។
4. ជ្រើសអ្វីដែលត្រូវនាំចេញ៖ គម្រោងទាំងមូល ឬតែធាតុដែលមើលឃើញនៅលើជាន់ដែលអ្នកកំពុងមើល។
5. រក្សាទុក បន្ទាប់មកចុច {{ui:ជ្រើសរើសឯកសារ}} ក្នុង BimCraft ហើយជ្រើសឯកសារ `.ifc`។

ពិនិត្យទាំងនេះក្នុងការកំណត់របស់ឧបករណ៍បកប្រែ មុនពេលនាំចេញ៖

- **តំបន់**៖ នាំចេញវា ដើម្បីឱ្យបន្ទប់ទៅដល់ជាកន្លែង។ ចុច {{ui:កន្លែង}} ក្នុង BimCraft ដើម្បីមើលវា។
- **លក្ខណៈសម្បត្តិ និងការចាត់ថ្នាក់**៖ នាំចេញវា ដើម្បីឱ្យបង្ហាញក្នុង {{ui:លក្ខណៈសម្បត្តិ}} ហើយអាចប្រើក្នុង {{ui:ស្វែងរក}}, {{ui:ពណ៌}} និង {{ui:ផលបូកបរិមាណ}}។
- **`.ifc` ធម្មតា** មិនមែន `.ifczip` ឬ `.ifcxml` ទេ។ BimCraft បើកតែ `.ifc` ធម្មតាប៉ុណ្ណោះ។

## នាំចេញ DWG (គំនូរ)

1. បើកប្លង់ ប្លង់កាត់ ឬប្លង់បង្ហាញដែលអ្នកចង់បាន។
2. ជ្រើស **File > Save As** ហើយជ្រើស **DWG** ជាប្រភេទឯកសារ។
3. ជ្រើសឧបករណ៍បកប្រែ DXF-DWG ហើយរក្សាទុក។
4. សម្រាប់សន្លឹកទាំងមូល រក្សាទុកប្លង់ពី Layout Book ឬផ្សព្វផ្សាយពួកវាជា DWG។
5. បើក `.dwg` ក្នុង BimCraft។ គំនូរដែលភ្ជាប់ដោយការនាំចេញនឹងបើកជាមួយ ប្រសិនបើនៅក្នុងថតដូចគ្នា៖ សូមមើល [គំនូរ និងរូបភាពដែលភ្ជាប់](topic:dwg-linked-files)។

## ការដោះស្រាយបញ្ហា

- **«… គឺជាគម្រោង Archicad៖ បៃដំបូងរបស់វាបញ្ជាក់ដូច្នេះ។»** នាំចេញ IFC ឬ DWG ដូចខាងលើ ហើយបើកឯកសារនោះ។
- **«… មានឈ្មោះដូចឯកសារ Archicad ប៉ុន្តែមិនចាប់ផ្តើមដូចវាទេ។»** ពិនិត្យថាឯកសារមកពីណា៖ វាអាចជាប្រភេទឯកសារផ្សេងដែលត្រូវបានដាក់ឈ្មោះថ្មី (សាកបើកវាក្រោមនាមបន្ទាប់ពិតរបស់វា) ច្បាប់ចម្លងដែលមិនបានបញ្ចប់ ឬគម្រោងពីកំណែមុនកំណែ 17។ បើកវាក្នុង Archicad បើអាចធ្វើបាន បន្ទាប់មកនាំចេញ IFC ឬ DWG។
- **ម៉ូដែលបើកដោយគ្មានបន្ទប់។** តំបន់មិនត្រូវបាននាំចេញទេ។ បើកវានៅក្នុងឧបករណ៍បកប្រែ IFC ហើយនាំចេញឡើងវិញ។
- **ច្រកចូលមិនត្រូវបានកាត់។** BimCraft បញ្ជាក់នេះនៅក្រោម **មិនទាន់គូរ** ក្នុងផ្ទាំង {{ui:ឯកសារ}}។ នាំចេញឡើងវិញ បើនៅតែមាន សូមបើកម៉ូដែលក្នុងកម្មវិធីដែលបង្កើតវា ហើយពិនិត្យច្រកចូលនៅទីនោះ។
- **អត្ថបទនៅលើ DWG មើលទៅខុសគ្នា។** ការនាំចេញអាចរក្សាពុម្ពអក្សរដែល BimCraft គ្មាន; BimCraft គូរអត្ថបទជាពុម្ពអក្សរ sans-serif ធម្មតា។
