## អ្វីដែលអ្នកនឹងធ្វើ

ផ្លាស់ទីម៉ូដែលរវាងកម្មវិធី BIM ពីរ ឧទាហរណ៍ពី Revit ទៅ Archicad ហើយត្រឡប់មកវិញ តាមរយៈ IFC ដោយ BimCraft នៅកណ្តាលដើម្បីពិនិត្យ បន្ថែម និងរាយការណ៍អ្វីដែលរស់រានមានជីវិត។ មិនមានទ្រង់ទ្រាយឯកសាររបស់កម្មវិធីណាមួយត្រូវបានអានទេ៖ អ្វីៗទាំងអស់ធ្វើដំណើរជា IFC។

## អ្វីដែល BimCraft រក្សាទុក

ពេលអ្នកផ្លាស់ប្តូរម៉ូដែលក្នុង BimCraft ហើយចុច {{ui:Save as IFC}} ខ្សែនីមួយៗដែលអ្នកមិនបានផ្លាស់ប្តូរត្រូវបានសរសេរត្រឡប់ទៅវិញដូចដើមបេះបិទ។ ដូច្នេះ:

- **GlobalIds** នៅដដែល ហើយកម្មវិធីផ្សេងអាចផ្គូផ្គងធាតុនីមួយៗទៅធាតុដែលខ្លួនបានផ្ញើ។
- **សំណុំទ្រព្យសម្បត្តិ** និងតម្លៃរបស់វានៅដដែល លើកលែងតែតម្លៃដែលអ្នកបានផ្លាស់ប្តូរ។
- **ការចាត់ថ្នាក់** នៅតែភ្ជាប់ជាមួយធាតុរបស់ពួកវា។

## កំណត់កម្មវិធីទាំងពីរឱ្យមានទ្រព្យសម្បត្តិដូចគ្នា

1. បើកម៉ូដែលក្នុង BimCraft (និងកញ្ចប់គម្រោង ប្រសិនបើអ្នកមាន: ក្រុមទ្រព្យសម្បត្តិរបស់វាត្រូវបានបន្ថែម)។
2. នៅក្នុងបន្ទះខាងឆ្វេង បើក {{ui:Between two BIM programs}}។
3. ក្រោម **ការផ្គូផ្គងទ្រព្យសម្បត្តិ** ទាញយកអ្វីដែលកម្មវិធីនីមួយៗត្រូវការ៖
   - {{ui:Shared parameters}}: ឯកសារប៉ារ៉ាម៉ែត្រចែករំលែក។ នៅក្នុង Revit ផ្ទុកវាជាមួយ Manage › Shared Parameters ហើយបន្ថែមប៉ារ៉ាម៉ែត្រទៅប្រភេទដែលត្រូវការពួកវា។
   - {{ui:IFC export property sets}}: ឯកសារសំណុំទ្រព្យសម្បត្តិដែលអ្នកកំណត់។ នៅក្នុងការកំណត់នាំចេញ IFC របស់ Revit ជ្រើសវានៅក្រោម user-defined property sets ដូច្នេះ IFC ដែលនាំចេញមានសំណុំ និងឈ្មោះទ្រព្យសម្បត្តិដូចគ្នា។
   - {{ui:Mapping table (CSV)}}: ទ្រព្យសម្បត្តិនីមួយៗជាមួយសំណុំ IFC និងឈ្មោះ ប្រភេទរបស់វា និងឈ្មោះដែលត្រូវគ្នានៅក្នុងកម្មវិធីនីមួយៗ។ ឯកសារផ្គូផ្គងរបស់ Archicad មិនមែនជាទ្រង់ទ្រាយដែលបានបោះពុម្ពផ្សាយទេ ដូច្នេះកំណត់ IFC translator និង property manager របស់វាពីតារាងនេះដោយដៃ។
   - {{ui:Mapping file}}: ការផ្គូផ្គងទាំងមូលជាឯកសារមួយ ដើម្បីរក្សាទុកជាមួយគម្រោង។

សំណុំស្តង់ដារ (Pset_ និង Qto_) ត្រូវបានដកចេញពីឯកសារប៉ារ៉ាម៉ែត្រចែករំលែក: កម្មវិធីទាំងពីរសរសេរវាពីទិន្នន័យរបស់ខ្លួនផ្ទាល់។

## ផ្ញើម៉ូដែល និងនាំវាត្រឡប់មកវិញ

1. នាំចេញ IFC ពីកម្មវិធីទីមួយដោយរក្សា GlobalIds (Revit: "Store the IFC GUID in an element parameter after export" បើក)។
2. បើកវាក្នុង BimCraft ពិនិត្យវា ({{ui:Model checks}}, {{ui:Clash check}}), បន្ថែមបញ្ហា ({{ui:Issues}}, BCF), ផ្លាស់ប្តូរតម្លៃប្រសិនបើត្រូវការ ហើយ {{ui:Save as IFC}}។
3. បើក IFC ដែលបានរក្សាទុកក្នុងកម្មវិធីទីពីរ ធ្វើការលើវា ហើយនាំចេញ IFC ពីទីនោះដោយរក្សា GlobalIds (អ្នកបកប្រែរបស់ Archicad: "Global Unique Identifiers: Keep existing")។
4. ត្រឡប់ទៅ BimCraft វិញ បើកម៉ូដែលដែលបានចេញ បន្ទាប់មកបន្ថែមម៉ូដែលដែលត្រឡប់មកវិញ ({{ui:Add a model}} នៅក្រោម **ម៉ូដែល**)។
5. នៅក្នុង {{ui:Between two BIM programs}} ជ្រើស **បានចេញ** និង **បានត្រឡប់មក** ហើយចុច {{ui:Make the report}}។

## អានរបាយការណ៍

- **ធាតុ**: តើមានប៉ុន្មានត្រឡប់មកជាមួយ GlobalId ដដែល, មានប៉ុន្មានបាត់, និងមានប៉ុន្មានថ្មី។ ធាតុដែលមាន GlobalId ថ្មីបង្ហាញជាមួយមួយបាត់ និងមួយថ្មី៖ កម្មវិធីផ្សេងមិនបានរក្សាវាទេ។
- **ថ្នាក់ IFC បានផ្លាស់ប្តូរ**: ធាតុដែលត្រឡប់មកជាប្រភេទធាតុផ្សេង។
- **តម្លៃទ្រព្យសម្បត្តិដែលបានរក្សា**: សមាមាត្រនៃតម្លៃដែលត្រឡប់មកដោយមិនផ្លាស់ប្តូរ។ បញ្ជីខាងក្រោមបង្ហាញទ្រព្យសម្បត្តិដែលមានតម្លៃផ្លាស់ប្តូរ ឬបាត់ច្រើនបំផុត។
- **ការចាត់ថ្នាក់**: បានរក្សា ផ្លាស់ប្តូរ (ប្រព័ន្ធដូចគ្នា លេខកូដផ្សេង) ឬបាត់។

{{ui:Download the report (CSV)}} ផ្តល់ទ្រព្យសម្បត្តិនីមួយៗជាមួយចំនួនរបស់វា។ ដើម្បីមើលថាតើធាតុណាបានផ្លាស់ទី ឬផ្លាស់ប្តូររូបរាង ប្រើ {{ui:Compare versions}} លើម៉ូដែលពីរដដែល។

## បញ្ហាធ្វើដំណើរជា BCF

បញ្ហាដែលអ្នកលើកឡើងក្នុង BimCraft នាំចេញជា BCF ({{ui:Issues}}) ដែលកម្មវិធីទាំងពីរអាចអានជាមួយឧបករណ៍ BCF របស់ពួកវា ដូច្នេះសំណួរអំពីធាតុមួយទៅដល់អ្នកដែលធ្វើការក្នុងកម្មវិធីផ្សេងជាមួយទិដ្ឋភាពរបស់វា។
