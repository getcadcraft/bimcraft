## អ្វីដែលអ្នកនឹងធ្វើ

ដាក់ឧបករណ៍នៅចុងបំពង់ និងបំពង់ខ្យល់របស់អ្នក។ ម្យ៉ាងៗជារាងទូទៅដែលមានទំហំតាមតម្លៃដែលអ្នកវាយ ជាមួយការភ្ជាប់របស់វាជា **ចំណុចភ្ជាប់**៖ កន្លែងដែលបំពង់ ឬបំពង់ខ្យល់ភ្ជាប់ទៅវា ប្រព័ន្ធណា ទិសដៅលំហូរ និងទំហំ។ បំពង់ និងបំពង់ខ្យល់ដែលគូរចេញពីចំណុចភ្ជាប់ យកទំហំ និងប្រព័ន្ធរបស់វា ហើយនៅជាប់ជាមួយវា៖ មើល [ភ្ជាប់បំពង់ និងបំពង់ខ្យល់ទៅឧបករណ៍](topic:mep-connections)។

:::note
នេះជាជំនួយសម្រាប់ការគូរ និងការសម្របសម្រួល ដែលវិស្វករជាអ្នកកំណត់ទំហំ។ ឧបករណ៍មិនមែនជាផលិតផលរបស់ក្រុមហ៊ុនផលិតទេ៖ គ្មានសមត្ថភាព ទម្ងន់ ឬទំហំភ្ជាប់របស់ក្រុមហ៊ុនផលិតទេ។ នាំម៉ូដែលពីកម្មវិធី MEP របស់អ្នកចូលជា IFC នៅពេលអ្នកត្រូវការ។
:::

## ដាក់ធាតុមួយ

2. នៅក្នុងរបារ ជ្រើសប្រភេទ ហើយវាយទំហំរបស់វា។ ម្យ៉ាងៗតម្រូវឱ្យទំហំផ្ទាល់របស់វា៖

| ប្រភេទ | អ្វីដែលអ្នកវាយ | ចំណុចភ្ជាប់របស់វា |
|---|---|---|
| ឧបករណ៍ដោះខ្យល់ (Air handler) | ប្រវែង ទទឹង កម្ពស់; ច្រកផ្គត់ផ្គង់ និងត្រឡប់; ទំហំបំពង់ coil និងប្រព័ន្ធ; ទំហំទឹកភាយ | បំពង់ខ្យល់ផ្គត់ផ្គង់ចេញ, បំពង់ខ្យល់ត្រឡប់ចូល, coil ចូល និងចេញ, ច្រកបង្ហូរទឹកភាយ |
| កង្ហារក្នុងខ្សែ (Inline fan) | អង្កត់ផ្ចិត ប្រវែង ប្រព័ន្ធ | បំពង់ខ្យល់ចូល និងចេញ |
| ឧបករណ៍បូម (Pump) | ទំហំបំពង់ ប្រព័ន្ធ | ច្រកចូល និងច្រកចេញ |
| ចង្ក្រានទឹក (Boiler) | ប្រវែង ទទឹង កម្ពស់ ទំហំបំពង់ ទំហំឧស្ម័ន អង្កត់ផ្ចិតផ្សែង | ការផ្គត់ផ្គង់កម្ដៅចេញ និងត្រឡប់ចូល, ឧស្ម័នចូល, ផ្សែងចេញ |
| ឧបករណ៍កម្ដៅទឹក (Water heater) | អង្កត់ផ្ចិត កម្ពស់ ទំហំបំពង់ ឧស្ម័ន ឬអគ្គិសនី | ទឹកត្រជាក់ចូល, ទឹកក្ដៅចេញ (និងឧស្ម័នចូល និងផ្សែង នៅពេលវាដុតឧស្ម័ន) |
| ឯកតាស្ថានី (Terminal unit) | ប្រវែង ទទឹង កម្ពស់ ច្រកចូលមូល ទទឹង និងកម្ពស់ច្រកចេញ | ខ្យល់ផ្គត់ផ្គង់ចូល និងចេញ |
| Diffuser | មុខ កក ប្រព័ន្ធ | កក (ខ្យល់ចូល) |
| ក្រឡា (Grille) | ទទឹង និងកម្ពស់មុខ ទទឹង និងកម្ពស់កក ប្រព័ន្ធ | កក (ខ្យល់ចេញទៅបំពង់ខ្យល់ត្រឡប់ ឬបំពង់ចេញ) |
| ធុង (Tank) | អង្កត់ផ្ចិត កម្ពស់ ទំហំបំពង់ ប្រព័ន្ធ | ច្រកចូលនៅខាងលើ ច្រកចេញនៅជិតខាងក្រោម |
| រេឌីយ៉ាទ័រ (Radiator) | ប្រវែង កម្ពស់ ជម្រៅ ទំហំបំពង់ ប្រព័ន្ធ | លំហូរចូលនៅកំពូលនៃចុងម្ខាង ត្រឡប់ចេញនៅបាតនៃចុងម្ខាងទៀត |
| កុងវ៉ិកទ័រ / ឧបករណ៍កម្ដៅផ្ទាំង (Convector / panel heater) | ប្រវែង កម្ពស់ ជម្រៅ ទំហំបំពង់ ប្រព័ន្ធ | លំហូរចូលនៅចុងម្ខាង ត្រឡប់ចេញនៅចុងម្ខាងទៀត |
| គ្រួសារផលិតករ (Manufacturer's family) | គ្រួសារ (សូមមើល [ស្តង់ដារបំពង់ វ៉ាល់ ឧបករណ៍បិទបើក និងគ្រួសារផលិតករ](topic:pipe-specs)) | ចំណុចភ្ជាប់ដែលគ្រួសារនោះត្រូវបានផ្ដល់ |

3. កំណត់ **At** ជាកម្ពស់នៃមូលដ្ឋានរបស់វាពីកម្រិត។ កម្ពស់នៃ diffuser ឬក្រឡាគឺជាមុខរបស់វា៖ វាយកម្ពស់ពិដាន។
4. វាយ **Tag** បើអ្នកចង់បាន (`AHU-1`); ធាតុបន្ទាប់នៃប្រភេទដូចគ្នាទទួលបានលេខបន្ទាប់។
5. ផ្លាស់ទីកណ្ដុរលើប្លង់៖ ជើងឧបករណ៍ និងចំណុចភ្ជាប់របស់វាដើរតាម។ ចុច {{key:R}} ដើម្បីបង្វិល 90°។ ចុចកន្លែងដែលវាត្រូវទៅ។

ទំហំបំពង់គឺជាទំហំបំពង់ដែកស្តង់ដារ (ASME B36.10M)។ បំពង់ដែលគូរចេញពីឧបករណ៍បូមក្នុងសម្ភារៈផ្សេង យកទំហំឈ្មោះដូចគ្នានៅក្នុងសម្ភារៈរបស់វា។

## ផ្លាស់ប្ដូរ ឬលុបវា

ជ្រើសវានៅក្នុងប្លង់ ឬទិដ្ឋភាព 3D។ លក្ខណៈសម្បត្តិបង្ហាញទំហំទាំងអស់ដែលអ្នកវាយ ស្លាក X, Y, កម្ពស់ និងការបង្វិល ហើយចំណុចភ្ជាប់នីមួយៗ៖ ទំហំ ប្រព័ន្ធ ទិសដៅលំហូរ និងថាតើមានអ្វីភ្ជាប់ឬអត់។ ការផ្លាស់ប្ដូរនីមួយៗគឺជាជំហានមួយនៃ {{ui:Undo}}; ខ្សែដែលជួសជុលទៅចំណុចភ្ជាប់របស់វា ផ្លាស់ទីជាមួយវា។ {{key:Delete}} លុបវា; ខ្សែដែលជួសជុលទៅវានៅតែនៅ ហើយការពិនិត្យការភ្ជាប់រាយពួកវា។

## នៅក្នុងឯកសារ IFC

ម្យ៉ាងៗត្រូវបានរក្សាទុកជាថ្នាក់ IFC របស់វា៖ IfcUnitaryEquipment (ឧបករណ៍ដោះខ្យល់), IfcFan (កង្ហារ), IfcPump (ឧបករណ៍បូម), IfcBoiler (ចង្ក្រានទឹក; ឧបករណ៍កម្ដៅទឹកគឺជា IfcBoiler ប្រភេទ water ជាមួយប្រភេទវត្ថុ "Water heater"), IfcAirTerminalBox (ឯកតាស្ថានី), IfcAirTerminal (diffuser, ក្រឡា) និង IfcTank, ជាមួយប្រភេទមួយដែលចែករំលែកដោយធាតុគ្រប់ទាំងអស់នៃប្រភេទដូចគ្នា និងទំហំ។ ឯកសារ IFC2X3 ទទួលបាន IfcEnergyConversionDevice, IfcFlowMovingDevice, IfcFlowController, IfcFlowTerminal និង IfcFlowStorageDevice ជាមួយប្រភេទដែលត្រូវគ្នា។ ចំណុចភ្ជាប់នីមួយៗជា IfcDistributionPort ដែលដាក់ត្រង់កន្លែងដែលការភ្ជាប់នោះ ងាកមុខចេញ ជាមួយទិសដៅលំហូរ និងប្រព័ន្ធរបស់វា; កម្មវិធីផ្សេងទៀតអានថាខ្សែមួយណាភ្ជាប់ទៅចំណុចភ្ជាប់មួយណា។ ធាតុនោះចូលរួមប្រព័ន្ធនៃចំណុចភ្ជាប់នីមួយៗរបស់វា ហើយផ្ទុកសំណុំធាតុបណ្ណាល័យដែលធាតុបណ្ណាល័យដែលបានដាក់ទាំងអស់មាន។
