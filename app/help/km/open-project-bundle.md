## អ្វីដែលអ្នកនឹងធ្វើ

បើក**បាច់គម្រោង** (`.ccbundle.zip`) ហើយធ្វើការជាមួយគម្រោងតាមរបៀបដែលវាត្រូវបានរៀបចំ៖ ទិដ្ឋភាព ទម្រង់បោះពុម្ព និងក្រុមលក្ខណៈសម្បត្តិរបស់វា នៅលើម៉ូដែល។

បាច់មាន៖

- ម៉ូដែលជា IFC,
- ទម្រង់បោះពុម្ពជា PDF និង DWG,
- បញ្ជីអ្វីដែល IFC មិនរក្សា៖ ទិដ្ឋភាព (ម្នាក់ៗមានជាន់ ការផ្សំស្រទាប់ និងមាត្រដ្ឋានរបស់វា) ទម្រង់បោះពុម្ព និងគំនូរដែលដាក់លើវា និយមន័យលក្ខណៈសម្បត្តិក្នុងក្រុមរបស់ពួកវា ការចាត់ថ្នាក់ និងស្តង់ដារ ដូចជាស្រទាប់ ឈុតប៊ិច ប្រភេទបន្ទាត់ លំនាំបំពេញ ផ្ទៃ និងសមាសធាតុ។

បាចត្រូវបានសរសេរដោយស្គ្រីបកូដបើកចំហ ដែលដំណើរការនៅក្នុង Archicad ហើយសុំបញ្ជីទាំងនេះពី Archicad ដោយផ្ទាល់។ BimCraft មិនអានឯកសារ `.pln` ឬ `.tpl` ដោយផ្ទាល់ទេ; សូមមើល [បើកឯកសារគម្រោង .pln និង .pla](topic:pln-project-files)។

## បង្កើតបាច់

ស្គ្រីបនេះជាការមើលជាមុន ហើយវាមិនទាន់ត្រូវបានសាកល្បងលើគ្រប់កំណែ Archicad ទេ។ ទាញយកវាពី [github.com/getcadcraft/bim-project-bundle](https://github.com/getcadcraft/bim-project-bundle)។ អ្នកត្រូវការ Archicad 24 ឬថ្មីជាង និង Python 3.8 ឬថ្មីជាង; គ្មានអ្វីផ្សេងទៀតត្រូវដំឡើងទេ។

1. រក្សាទុក `archicad_bundle.py` ទៅក្នុងថតមួយ ឧទាហរណ៍ `C:\cc-bundle`។
2. នៅក្នុង Archicad បើកគម្រោង ហើយបង្កើតឈុតបោះពុម្ពដែលមានឈ្មោះដូចគ្នាបេះបិទ **CadCraft bundle**៖ ទិដ្ឋភាព 3D ជា IFC ទម្រង់បោះពុម្ពគ្រប់ទាំងអស់ជា PDF និងទម្រង់បោះពុម្ពគ្រប់ទាំងអស់ម្ដងទៀតជា DWG ដែលបោះពុម្ពទៅជាឯកសារនៅលើថតតែមួយ។
3. ពេលគម្រោងបើក ដំណើរការ `python archicad_bundle.py --probe --out .` ម្ដង។ វាគ្រាន់តែអាន ហើយសរសេរ `probe.json`។
4. ដំណើរការ `python archicad_bundle.py --out . --translator "IFC4 Reference View"` (ប្រើកម្មវិធីបកប្រែ IFC ដែលអ្នកបានជ្រើស)។ Archicad បោះពុម្ពឈុត ហើយស្គ្រីបសរសេរ `<project>.ccbundle.zip`។

ប្រសិនបើការបោះពុម្ពតាមស្គ្រីបបរាជ័យ សូមបោះពុម្ពឈុតដោយដៃ ហើយដំណើរការ `python archicad_bundle.py --out . --no-publish --files <folder>\*.ifc <folder>\*.pdf <folder>\*.dwg`។ README របស់ repository មានជម្រើសទាំងអស់។ ប្រសិនបើអ្វីមួយមិនមកដល់ សូមបើក issue នៅទីនោះ ហើយភ្ជាប់ `probe.json`។

## បើកបាច់

1. ចុច {{ui:Choose a file}} ឬទម្លាក់ `.ccbundle.zip` លើ BimCraft។ នៅក្នុងថតដែលអ្នកបានបើកជាមួយ {{ui:Open a folder}} បាចនឹងបង្ហាញនៅក្រោម **បាច់គម្រោង**; ចុចឈ្មោះមួយ។
2. ម៉ូដែលបើកដូច IFC ណាមួយ ហើយផ្នែក **បាច់គម្រោង** លេចឡើងនៅខាងឆ្វេង នៅក្រោមព័ត៌មានរបស់ឯកសារ។

មិនមានការផ្ទុកឡើងទេ៖ បាចត្រូវបានអាននៅលើកុំព្យូទ័ររបស់អ្នក ម្ដងមួយឯកសារ ដូច្នេះម៉ូដែលធំមិនត្រូវបានចម្លងពីរដង។

## បង្ហាញទិដ្ឋភាព

នៅក្រោម **ទិដ្ឋភាព** ទិដ្ឋភាពត្រូវបានជ្រុះតាមថតដែលវាមាននៅក្នុងគម្រោង។ ចុចឈ្មោះទិដ្ឋភាព៖

- **ប្លង់ជាន់** បង្ហាញតែជាន់របស់វា មើលពីលើ។
- **ការផ្សំស្រទាប់** របស់វាលាក់ធាតុនៅលើស្រទាប់ដែលការផ្សំនោះលាក់។ បន្ទាត់ស្ថានភាពប្រាប់ថាតើធាតុប៉ុន្មានត្រូវបានលាក់។
- **មាត្រដ្ឋាន** របស់វាបង្ហាញនៅក្បែរឈ្មោះ និងនៅក្នុងបន្ទាត់ស្ថានភាព។
- **ទិដ្ឋភាព 3D** បង្ហាញគ្រប់ជាន់ទាំងអស់។

ដើម្បីបង្ហាញអ្វីៗទាំងអស់ម្ដងទៀត ប្រើ {{ui:Show all}} នៅក្នុង {{ui:Show}} ហើយធីកគ្រប់ជាន់។

:::note
BimCraft រកស្រទាប់តាមការកំណត់ស្រទាប់របស់ឯកសារ IFC។ ប្រសិនបើ IFC ត្រូវបាននាំចេញដោយគ្មានវា ការផ្សំស្រទាប់នឹងមិនលាក់អ្វីទេ ហើយបន្ទាត់ស្ថានភាពនឹងនិយាយថាធាតុដែលត្រូវបានលាក់មាន 0។
:::

## បើកទម្រង់បោះពុម្ព

នៅក្រោម **ទម្រង់បោះពុម្ព** ទម្រង់នីមួយៗបង្ហាញលេខ ឈ្មោះ ទំហំក្រដាស និងទិដ្ឋភាពដែលដាក់លើវា។

- **PDF** រក្សាទុក PDF របស់ទម្រង់ពីបាច់។
- **DWG** បើកគំនូររបស់ទម្រង់នៅទិដ្ឋភាព 2D។ ចុចទិដ្ឋភាពណាមួយដើម្បីត្រឡប់ទៅម៉ូដែល។
- **បើកក្នុង …** ផ្ញើឯកសាររបស់ទម្រង់ទៅកម្មវិធីដែលធ្វើការលើវា ក្នុងផ្ទាំងថ្មី៖ PDF ទៅ MarkupCraft, DWG ទៅ CadCraft។ វាបង្ហាញតែនៅពេលកម្មវិធីនោះបើកនៅជាប់ BimCraft។ ឯកសារត្រូវបានអានពីបាចពេលផ្ទាំងកំពុងផ្ទុក ហើយគ្មានអ្វីត្រូវបានផ្ទុកឡើងទេ។

ទម្រង់ដែលគ្មានទាំងពីរនឹងនិយាយថា **គ្មានឯកសារក្នុងបាច់**។

## មើលលក្ខណៈសម្បត្តិក្នុងក្រុមរបស់គម្រោង

ជ្រើសធាតុមួយ។ **ក្រុមលក្ខណៈសម្បត្តិ** បង្ហាញលក្ខណៈសម្បត្តិរបស់វានៅក្រោមក្រុមដែលគម្រោងបានកំណត់ ផ្គូផ្គងតាមឈុតលក្ខណៈសម្បត្តិ និងឈ្មោះដែលនិយមន័យផ្ដល់សម្រាប់ IFC ឬបើមិនដូច្នេះ តាមឈ្មោះ។ លក្ខណៈសម្បត្តិដែលនៅសល់នៅតែស្ថិតក្នុង {{ui:Properties}} ដូចធម្មតា។ **និយមន័យលក្ខណៈសម្បត្តិ** បង្ហាញបញ្ជីនិយមន័យទាំងអស់ជាមួយក្រុម ប្រភេទ និងឈ្មោះ IFC របស់វា។

## ស្តង់ដារ និងកំណត់ចំណាំ

- **ស្តង់ដារ** រាប់ស្រទាប់ ការផ្សំស្រទាប់ ឈុតប៊ិច ប្រភេទបន្ទាត់ លំនាំបំពេញ ផ្ទៃ សមាសធាតុ និងសម្ភារៈនៅក្នុងបាច់។
- **កំណត់ចំណាំ** បង្ហាញអ្វីដែលស្គ្រីបមិនអាចទទួលបានពីកំណែ Archicad នោះ វាលណាមួយដែល BimCraft មិនអាចអាន និងឯកសារណាមួយដែលបាចនិយាយដល់ តែមិនមានក្នុងវា។

## ការដោះស្រាយបញ្ហា

- **"… គឺជា zip ប៉ុន្តែមិនមែនជាបាច់គម្រោង។"** ឯកសារ zip មិនមាន `manifest.json` ។ ដោះ zip ហើយបើក `.ifc` ដែលនៅខាងក្នុង។
- **"… គឺជាបាច់គម្រោងថ្មីជាង BimCraft នេះអាន។"** ធ្វើបច្ចុប្បន្នភាព BimCraft។
- **"… មិនមានម៉ូដែលដែល manifest របស់វាដាក់ឈ្មោះ។"** ឯកសារ zip ត្រូវបានកាត់ ឬកែសម្រួល។ បង្កើតបាចឡើងវិញ។
