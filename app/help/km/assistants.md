## បើកវា

ជំនួយការចូល BimCraft តាមរយៈ CadCraft Studio នៅលើកុំព្យូទ័ររបស់អ្នក; កម្មវិធីរុករកធម្មតាគ្មានផ្លូវចូលឡើយ។

1. បើក {{ui:Settings}} ហើយជ្រើសផ្ទាំង **BimCraft**។
2. នៅក្រោម **ជំនួយការ** ធីក **អនុញ្ញាតឱ្យជំនួយការ AI និងស្គ្រីបប្រើ BimCraft**។
3. **អាន** ត្រូវបានធីករួចហើយសម្រាប់អ្នក។ ធីក **ផ្លាស់ប្តូរទិដ្ឋភាព និងគូរ** ផងដែរ ប្រសិនបើជំនួយការអាចញែក និងលាកធាតុ ហើយគូរ ហើយ **រក្សាទុក** ប្រសិនបើវាអាចរក្សាទុកម៉ូដែលជាឯកសារថ្មី។
4. ភ្ជាប់ជំនួយការក្នុង Studio (Studio បង្ហាញអាសយដ្ឋាន និងការកំណត់ដែលត្រូវបិទភ្ជាប់ទៅក្នុងវា)។

ចំណាំនៅផ្នែកខាងលើនៃបន្ទះខាងស្តាំ និយាយថាជំនួយការណាត្រូវបានភ្ជាប់ និងវាអាចធ្វើអ្វីខ្លះ។ ចុច {{ui:Disconnect}} ដើម្បីបញ្ចប់វគ្គរបស់វាភ្លាម; វាត្រូវតែភ្ជាប់ឡើងវិញដើម្បីបន្ត។

**សកម្មភាព** នៅក្រោម **ជំនួយការ** ក្នុង ការកំណត់ រាយការហៅទាំងអស់ដែលជំនួយការបានធ្វើ ថ្មីបំផុតមុន ជាមួយថាតើវាដំណើរការឬអត់។

## ដោយគ្មានបង្អួច៖ ស្គ្រីប និងបន្ទាត់ពាក្យបញ្ជា

ឧបករណ៍គូរដដែលដំណើរការលើឯកសារ IFC នៅក្នុងថតដែលអ្នកដាក់ឈ្មោះ ដោយគ្មានបង្អួចបើក៖ CadCraft's MCP server និង command line អាចចាប់ផ្តើមអាគារថ្មី ឬបើកឯកសារ IFC ពិពណ៌នាវា បន្ថែមជញ្ជាំង ទ្វារ បង្អួច កម្រាល ជាន់ និងក្រឡាចត្រង្គ មិនធ្វើវិញ និងរក្សាទុកវាជាឯកសារ `.ifc` ថ្មី។ អ្នកសម្រេចថាថតណាវាអាចប្រើ និងថាតើវាអាចផ្លាស់ប្តូរ ឬរក្សាទុកអ្វីឬអត់។
