កម្មវិធីបន្ថែម (ការកំណត់ › កម្មវិធីបន្ថែម) អាចបន្ថែមម៉ាស៊ីនទៅ បញ្ជីម៉ាស៊ីន របស់ {{ui:រេនឌ័រ}}។ អត្ថបទពេញសម្រាប់អ្នកនិពន្ធកម្មវិធីបន្ថែមគឺ ផ្នែកទី 16 នៃ ស្តង់ដារកម្មវិធីបន្ថែម; សរុបមក៖

- កម្មវិធីបន្ថែមចុះបញ្ជីម៉ាស៊ីនមួយ ដោយមាន id ដែលចាប់ផ្តើមដោយ id របស់វាផ្ទាល់ ឈ្មោះ ការកំណត់ជាជម្រើស និង **ឬ** កម្មវិធីដែលត្រូវដំណើរការ **ឬ** មុខងារ JavaScript ដែលគូររូបភាព។
- ម៉ាស៊ីនដែលដំណើរការកម្មវិធីត្រូវការការអនុញ្ញាត **`engine.run`** ដែលបង្ហាញមុនការដំឡើង និងក្នុងការកំណត់។ វាដំណើរការតែនៅ Studio; នៅក្នុងកម្មវិធីរុករក វាបង្ហាញជាឯកសារដើម្បីរក្សាទុក។
- កម្មវិធីបន្ថែមដាក់ឈ្មោះកម្មវិធី (ឈ្មោះឯកសារធម្មតា មិនដែលជា shell ឡើយ) script ដែល **នៅក្នុងកម្មវិធីបន្ថែមដែលបានចុះហត្ថលេខា** និងអាគុយម៉ង់ដែលបង្កើតពីកន្លែងដាក់ និងពាក្យធម្មតា។ Studio រកកម្មវិធីនោះ ឬសួររកវាមួយដង។
- នៅពេលកម្មវិធីបន្ថែមដំណើរការកម្មវិធីលើកដំបូង **Studio សួរអ្នកនៅក្នុងប្រអប់របស់វាផ្ទាល់**៖ កម្មវិធីបន្ថែមណា កម្មវិធីណា និងថា script អាចធ្វើអ្វីគ្រប់យ៉ាងដែលកម្មវិធីអាចធ្វើបាន។ អនុញ្ញាតតែសម្រាប់កម្មវិធីបន្ថែមដែលអ្នកទុកចិត្តប៉ុណ្ណោះ។ ចម្លើយរបស់អ្នកត្រូវបានចងចាំសម្រាប់កម្មវិធីបន្ថែម និងកម្មវិធីនោះ។
- កញ្ចប់ (ឈុតជា USD និងឯកសារការកំណត់ ជាមួយឯកសារ glTF នៅពេលកម្មវិធីបន្ថែមស្នើ) និង script របស់កម្មវិធីបន្ថែម ត្រូវដាក់ក្នុងថតបណ្ដោះអាសន្នថ្មី កម្មវិធីដំណើរការនៅទីនោះ ហើយរូបភាពត្រឡប់មកវិញដោយមានសម្គាល់ឈ្មោះម៉ាស៊ីនរបស់កម្មវិធីបន្ថែម។

កម្មវិធីបន្ថែមអាចបន្ថែមម៉ាស៊ីនរេនឌ័របានតែចាប់ពី API កម្មវិធីបន្ថែម 1.4 ឡើងទៅ។ ឧទាហរណ៍ដែលបានធ្វើសម្រាប់កម្មវិធីរេនឌ័រតាមបន្ទាត់ពាក្យបញ្ជាបើកចំហ មាននៅក្នុងឃ្លាំងផ្ទាល់របស់វា; វាមិនទាន់ត្រូវបានដំណើរការនៅក្នុងកម្មវិធីរេនឌ័រនោះនៅឡើយទេ។
