## អ្វីដែលបើកនៅទីនេះ

បើកទាំងនេះដោយ {{ui:បើក}} ឬដោយទម្លាក់ពួកវាលើទំព័រ (សូមមើលប្រធានបទអំពីការបង្ហាញពពកចំណុចនៅក្បែរម៉ូដែល)៖

| ទម្រង់ | នាមបន្ទាប់ | អ្វីដែលត្រូវបានអាន |
|---|---|---|
| LAS, LAZ | `.las`, `.laz` | LAS 1.0–1.4៖ ចំណុច ពណ៌ កម្រិតពន្លឺ ថ្នាក់ LiDAR ប្រព័ន្ធកូអរដោនេ។ LAZ រហូតដល់ 1 GB។ |
| E57 | `.e57` | ការស្កេនទាំងអស់ក្នុងឯកសារ ម្យ៉ាងៗត្រូវបានដាក់តាមទីតាំងរបស់វា; ពណ៌ ឬកម្រិតពន្លឺនៅពេលឯកសារគ្មានពណ៌។ រូបភាពក្នុងឯកសារត្រូវបានលុបចេញ (ដែលត្រូវបានបញ្ជាក់)។ រហូតដល់ 6 លានចំណុច និង 512 MB សម្រាប់ពេលនេះ៖ នាំចេញការស្កេនធំជា LAS ឬ LAZ។ |
| PLY | `.ply` | អក្សរ និងគោលពីរ (លំដាប់បៃទាំងពីរ)៖ x y z នៃចំណុចកំពូល ពណ៌ និងកម្រិតពន្លឺ។ ផ្ទៃត្រូវបានលុបចេញ (ដែលត្រូវបានបញ្ជាក់)។ |
| PCD | `.pcd` | អក្សរ និងគោលពីរ៖ x y z ពណ៌ដែលបញ្ចូលគ្នា ឬដាច់ដោយឡែក កម្រិតពន្លឺ។ ឯកសារ PCD ដែលបានបង្ហាប់មិនទាន់អានទេ៖ រក្សាទុកវាជាគោលពីរ ឬអក្សរ។ |
| PTX | `.ptx` | ការស្កេនមួយ ឬច្រើន ម្យ៉ាងៗត្រូវបានដាក់តាមការបំប្លែងរបស់វា; ចំណុចដែលឧបករណ៍ស្កេនមិនបានវាស់ត្រូវបានលុបចេញ។ ម៉ែត្រ។ |
| PTS, XYZ | `.pts`, `.xyz` | អក្សរ៖ x y z ជាមួយកម្រិតពន្លឺ និងពណ៌ នៅពេលជួរទាំងនោះមាន។ |

## ឯកសារដែលមានតែកម្មវិធីរបស់ឧបករណ៍ស្កេនអាន

ឯកសារស្កេនមួយចំនួនជាទម្រង់ផ្ទាល់ខ្លួនរបស់ក្រុមហ៊ុនផលិតឧបករណ៍ស្កេន ដោយគ្មានការពិពណ៌នាដែលបានផ្សព្វផ្សាយ និងគ្មានកម្មវិធីអានបើក។ BimCraft មិនអាចអានពួកវាបានទេ ហើយការបើកមួយនឹងបង្ហាញកាតដែលប្រាប់ថាវាជាអ្វី និងត្រូវធ្វើអ្វី។ នាំចេញការស្កេនពីកម្មវិធីរបស់ក្រុមហ៊ុនផលិតជា E57 ឬ LAS (ឬ PTX, PTS) ហើយបើកឯកសារដែលបាននាំចេញ។

| ឯកសារ | នាមបន្ទាប់ | នាំចេញពី |
|---|---|---|
| ReCap project | `.rcp` | ReCap៖ បើកគម្រោង ហើយនាំចេញវា។ គម្រោងគ្រាន់តែចង្អុលទៅការស្កេនរបស់វា ដូច្នេះការចម្លង `.rcp` តែមួយមិនផ្តល់ចំណុចទេ។ |
| ReCap scan | `.rcs` | ReCap៖ បើកគម្រោងដែលការស្កេននេះជារបស់ ហើយនាំចេញវា។ |
| FARO scan | `.fls` | FARO SCENE។ |
| Leica scan | `.lgs` | Leica Cyclone REGISTER 360។ |
| Trimble scan | `.tzf` | Trimble RealWorks ឬ Trimble Business Center។ |
| Z+F scan | `.zfs` | Z+F LaserControl។ |

:::tip
នៅពេលការនាំចេញសួរទម្រង់ LAS ឬ LAZ រក្សាទុកអ្វីៗទាំងអស់ដែល BimCraft បង្ហាញ (ពណ៌ កម្រិតពន្លឺ ថ្នាក់ និងប្រព័ន្ធកូអរដោនេ) ក្នុងឯកសារតូចបំផុត។
:::

## ហេតុអ្វីឯកសារទាំងនេះមិនត្រូវបានអាន

ទម្រង់ទាំងនោះមិនត្រូវបានផ្សព្វផ្សាយ ហើយវិធីតែមួយគត់ដើម្បីអានពួកវាគឺតាមបណ្ណាល័យកម្មវិធីរបស់ក្រុមហ៊ុនផលិតនីមួយៗ ក្រោមលក្ខខណ្ឌរបស់ពួកគេ។ BimCraft អានតែទម្រង់ដែលវាអាចអានដោយកូដរបស់ខ្លួនផ្ទាល់នៅលើកុំព្យូទ័ររបស់អ្នក ដូច្នេះការស្កេនមិនត្រូវបានផ្ញើទៅកន្លែងណាមួយដើម្បីបើកឡើយ។
