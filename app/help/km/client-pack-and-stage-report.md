## អ្វីដែលអ្នកនឹងធ្វើ

បង្កើតកញ្ចប់អតិថិជន ឬរបាយការណ៍ដំណាក់កាលពីម៉ូដែលដូចដែលវាស្ថិតនៅឥឡូវ ហើយប្រៀបធៀបជម្រើសម៉ាស់អគារដែលបានរក្សាទុកក្បែរគ្នាតាមផ្ទៃក្រឡា និងតម្លៃ។

## ជំហាន

1. នៅក្នុងផ្ទាំងខាងឆ្វេង បើក **កញ្ចប់អតិថិជននិងរបាយការណ៍ដំណាក់កាល**។
2. ជ្រើស **បើកក្នុងឯកសារ** នៅក្បែរ Client pack ឬ Stage report។ ឯកសារថ្មីបង្ហាញនៅក្នុងផ្ទាំងឯកសារ ពីម៉ូដែល ដែលអ្នកអាចផ្លាស់ប្តូរអត្ថបទរបស់វាបាន។
3. នៅក្នុងការមើលជាមុន ចុចលើតួលេខមួយដើម្បីជ្រើសរើសធាតុដែលនៅពីក្រោយវា។
4. ជ្រើស **សាងសង់កញ្ចប់**។ zip មួយត្រូវបានរក្សាទុក៖ ឯកសារជា PDF រូបភាពនៃទិដ្ឋភាព 3D និង `figures.csv` ដែលរាយតួលេខនីមួយៗជាមួយ GlobalIds នៃធាតុរបស់វា។

## វាលទិន្នន័យ

អ្នកអាចប្រើទាំងនេះនៅក្នុងឯកសារណាមួយ។

| វាល | អ្វីដែលវាបោះពុម្ព |
|---|---|
| `{{stage}}` | ដំណាក់កាលគម្រោងពីព័ត៌មានលម្អិតនៃគំនូរ។ |
| `{{options}}` | ជម្រើសម៉ាស់អគារដែលបានរក្សាទុក ក្បែរគ្នា៖ ជាន់ កម្ពស់ ផ្ទៃជើង ផ្ទៃក្រឡាជាន់សរុប សំណង់ព័ទ្ធជុំ និងតម្លៃ។ |
| `{{areas}}` | ផ្ទៃក្រឡាជាន់ តាមកម្រិត ពីបន្ទប់។ |
| `{{sheets}}` | សន្លឹកជាមួយការកែប្រែដែលវាស្ថិតនៅ និងពេលវាត្រូវបានចេញចុងក្រោយ។ |
| `{{issues}}` | ប្រវត្តិបញ្ហា និងកំណត់ហេតុការផ្លាស់ប្តូរគំនូរ។ |
| `{{changes}}` | អ្វីដែលបានផ្លាស់ប្តូរចាប់តាំងពីការចេញចុងក្រោយ តាមសន្លឹកម្តងមួយៗ។ |

## របៀបគិតតម្លៃជម្រើស

តម្លៃមកតែពីតារាងតម្លៃរបស់គម្រោងអ្នកប៉ុណ្ណោះ (Energy/Cost, 5D cost)។ គ្មានអ្វីត្រូវបានប៉ាន់ស្មានសម្រាប់អ្នកទេ។

- ជួរតម្លៃកំណត់តម្លៃជម្រើសតែនៅពេលថ្នាក់របស់វាដាក់ឈ្មោះ `IfcBuildingElementProxy`។
- ផ្ទៃក្រឡាជាន់ត្រូវបានកំណត់តម្លៃដោយជួរដែលពាក្យរបស់វាដាក់ឈ្មោះការប្រើប្រាស់របស់ជម្រើស ដូចជា office។ បើគ្មាន ជួរដែលមានពាក្យ gross floor area ឬ building mass ត្រូវបានប្រើ។ ជួរតាម m² ប្រើផ្ទៃក្រឡាជាន់សរុប។ ជួរតាម m³ ប្រើបរិមាណ។
- សំណង់ព័ទ្ធជុំ (បរិមាត្រគុណនឹងកម្ពស់) ត្រូវបានកំណត់តម្លៃដោយជួរដែលមានពាក្យ envelope ឬ facade។
- ជម្រើសដែលគ្មានជួរដែលត្រូវគ្នាបង្ហាញ **No rate**។ សរុបត្រូវបានបង្ហាញតែនៅពេលគ្រប់ផ្នែកទាំងអស់ដែលបានស្នើសុំមានអត្រា។

## ត្រូវដឹង

- រក្សាជម្រើសជាមួយ **Keep as an option** នៅក្នុងបញ្ជីម៉ាស់អគាររបស់កម្មវិធីបន្ទប់។ សូមមើល ជម្រើសម៉ាស់អគារ។
- PDF មិនអាចជ្រើសធាតុបានទេ។ នៅខាងក្រៅ BimCraft `figures.csv` ផ្ទុកតំណភ្ជាប់ពីតួលេខនីមួយៗទៅធាតុរបស់វា។

## មិនទាន់បានបង្កើតនៅឡើយ

- សន្លឹក និងទិដ្ឋភាពគូសមិនត្រូវបានដាក់ក្នុងឯកសារទេ។ កញ្ចប់មានរូបភាពនៃទិដ្ឋភាព 3D តែប៉ុណ្ណោះ។
