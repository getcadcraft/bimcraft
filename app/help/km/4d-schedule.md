## អ្វីដែលអ្នកនឹងធ្វើ

មើលអាគារកើនឡើង៖ បញ្ជីភារកិច្ចក្នុងកាលវិភាគរបស់អ្នកភ្ជាប់ទៅធាតុដែលវាសាងសង់ បង្ហាញជារៀងរាល់ថ្ងៃ។

## ជំហាន

1. បើកម៉ូដែល IFC ហើយបើក {{ui:4D schedule}} ក្នុងបន្ទះខាងឆ្វេង។
2. ចុច {{ui:Download a template}} សម្រាប់បញ្ជីភារកិច្ចដែលមានមួយសប្តាហ៍ក្នុងមួយជាន់ ហើយកែវាក្នុងកម្មវិធីសៀវភៅគណនេយ្យ។ ឬសរសេររបស់អ្នកផ្ទាល់។
3. ចុច {{ui:Open a task list…}} ហើយជ្រើសរើស CSV។
4. អូសរបារកាលបរិច្ឆេទ ឬចុច {{ui:Play}}។

## បញ្ជីភារកិច្ច

CSV ដែលមានជួរក្បាល និងជួរ **Task**, **Start**, **Finish**, **Field** និង **Value**។ សញ្ញាក្បៀស (,) ឬសញ្ញា (;) ដំណើរការទាំងពីរ។

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| ជាន់ 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| ដំបូល | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| ដំបូល | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- សរសេរកាលបរិច្ឆេទជា YYYY-MM-DD។
- ជួរមួយភ្ជាប់ភារកិច្ចទៅធាតុគ្រប់ដែលមាន **Field** ដែល **Value** ត្រូវគ្នាបេះបិទ។ Field គឺជាលក្ខណៈសម្បត្តិ ដូចជា Storey, Class, Name, Type, Material, Tag ឬ GlobalId ឬលក្ខណៈសម្បត្តិណាមួយដែលសរសេរជាឈ្មោះសំណុំ និងឈ្មោះ៖ `Pset_WallCommon.FireRating`។
- ធ្វើម្តងទៀតនូវភារកិច្ចនៅជួរច្រើន ជាមួយកាលបរិច្ឆេទដដែល ដើម្បីភ្ជាប់ធាតុបន្ថែមទៅវា។

## ដំណាក់កាល និងកញ្ចប់ការងារ

បន្ថែមជួរ **Stage** ជួរ **Package** ឬទាំងពីរ ដើម្បីប្រមូលភារកិច្ចទៅជាដំណាក់កាល និងកញ្ចប់ការងារ។ Phase និង WBS ក៏ដំណើរការជាឈ្មោះជួរដែរ។

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| កម្រាលខណ្ឌជាន់ 1 | 2026-11-02 | 2026-11-04 | Class | IfcSlab | រចនាសម្ព័ន្ធ | ស៊ុម |
| ជញ្ជាំងជាន់ 1 | 2026-11-05 | 2026-11-13 | Storey | Level 1 | រចនាសម្ព័ន្ធ | ស៊ុម |
| ទ្វារ | 2026-11-30 | 2026-12-04 | Class | IfcDoor | ការតុបតែង | ការងារឈើ |

- ភារកិច្ចមួយជារបស់ដំណាក់កាលមួយ និងកញ្ចប់មួយ។ បើជួរក្រោយនៃភារកិច្ចដដែលដាក់ឈ្មោះផ្សេង ជួរនោះត្រូវបានរាយជាមួយលេខជួរ ហើយមិនយកមកប្រើទេ។
- ឈ្មោះកញ្ចប់ដដែលនៅក្នុងដំណាក់កាលពីរ គឺជាកញ្ចប់ពីរ។

នៅពេលបញ្ជីមានក្រុម បញ្ជី {{ui:Show}} លេចឡើងពីលើកាលបរិច្ឆេទ។ ជ្រើសដំណាក់កាល ឬកញ្ចប់ ហើយវាចាក់ជាមួយគ្នាទាំងមូល៖

- របារកាលបរិច្ឆេទ និង {{ui:Play}} ដំណើរការពីថ្ងៃចាប់ផ្តើមដំបូងនៃក្រុម ដល់ថ្ងៃបញ្ចប់ចុងក្រោយ
- មានតែភារកិច្ចរបស់ក្រុមប៉ុណ្ណោះដែលត្រូវបានរាយ និងលាបពណ៌ ហើយអ្វីដែលនៅក្រៅក្រុមមើលឆ្លងកាត់បាន
- បន្ទាត់ខាងក្រោមបញ្ជីប្រាប់ថាភារកិច្ចរបស់ក្រុមប៉ុន្មានត្រូវបានបញ្ចប់ កំពុងដំណើរការ និងនៅត្រូវធ្វើ នៅថ្ងៃនោះ
- {{ui:Select its elements}} ជ្រើសធាតុទាំងអស់របស់ក្រុម សម្រាប់ {{ui:Show}}, {{ui:Section}} ឬតារាង

ជ្រើស **ភារកិច្ចទាំងអស់** ដើម្បីមើលកាលវិភាគទាំងមូលម្តងទៀត។

## អ្វីដែលអ្នកគួរឃើញ

- **បានសាងសង់**៖ ធាតុដែលភារកិច្ចទាំងអស់របស់វាបានបញ្ចប់ ជាមួយពណ៌ផ្ទាល់របស់វា។
- **កំពុងដំណើរការ**៖ ធាតុដែលមានភារកិច្ចកំពុងដំណើរការនៅថ្ងៃនោះ ជាពណ៌ត្នោតមាស។ ភារកិច្ចកំពុងដំណើរការពីកាលបរិច្ឆេទចាប់ផ្តើមរបស់វា ដល់កាលបរិច្ឆេទបញ្ចប់របស់វា។
- **មិនទាន់ចាប់ផ្តើម**៖ មើលឆ្លងកាត់បាន។
- ធាតុដែលមិននៅក្នុងភារកិច្ចណាមួយ នៅតែដូចដើម។ បញ្ជីបង្ហាញថាធាតុប៉ុន្មានដែលភារកិច្ចនីមួយៗបានរក។ ជួរដែលអានមិនបាន ឬរកមិនឃើញអ្វី ត្រូវបានរាយជាមួយលេខជួរ។

## ការភ្ជាប់ ក្រាហ្វ Gantt និង MS Project

- បើកឯកសារ Microsoft Project XML (`.xml`) ឬ CSV ដែលមានជួរ `Predecessors`។ ការភ្ជាប់អាចជាបញ្ចប់ទៅចាប់ផ្តើម ចាប់ផ្តើមទៅចាប់ផ្តើម បញ្ចប់ទៅបញ្ចប់ ឬចាប់ផ្តើមទៅបញ្ចប់ ដែលនីមួយៗមានការនាំមុខ ឬពន្យារពេលជាថ្ងៃ។
- ក្រោមបញ្ជីភារកិច្ច ក្រាហ្វ Gantt គូរភារកិច្ចនីមួយៗជាแถบ ជាមួយព្រួញសម្រាប់ការភ្ជាប់។ ភារកិច្ចលើផ្លូវសំខាន់ជាពណ៌ក្រហម។ វដ្តភ្ជាប់ ឬ predecessor ដែលមិនមាន ត្រូវបានរាយក្នុងផ្ទាំង។
