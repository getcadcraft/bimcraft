## ធាតុ IFC

ផ្នែកខាងលើនៃផ្ទាំង {{ui:លក្ខណៈសម្បត្តិ}} បង្ហាញប្រភេទធាតុដោយគ្មានបុព្វបទ "Ifc" (ឧទាហរណ៍ "Door", "WallStandardCase", "FurnishingElement") និងឈ្មោះរបស់វា ឬ "គ្មានឈ្មោះ"។

| វាល | អត្ថន័យ | អាចកែបាន |
|---|---|---|
| ឈ្មោះ | ឈ្មោះធាតុ ជារឿយៗជាឈ្មោះគ្រួសារ និងប្រភេទពីឧបករណ៍នាំចេញ | បាទ |
| ប្រភេទ | ឈ្មោះប្រភេទរបស់ធាតុ នៅពេលវាមាន | ទេ |
| ប្រភេទវត្ថុ | ការពិពណ៌នាប្រភេទជាអត្ថបទសេរី ដែលឧបករណ៍នាំចេញមួយចំនួនបំពេញ | បាទ |
| សញ្ញាសម្គាល់ | សញ្ញាសម្គាល់ ឬសញ្ញាតំណាងរបស់ធាតុ; ឧបករណ៍នាំចេញជាច្រើនសរសេរលេខសម្គាល់ធាតុនៅទីនេះ | បាទ |
| ការពិពណ៌នា | អត្ថបទសេរី | បាទ |
| GlobalId | លេខសម្គាល់ IFC អក្សរ 22 ថេររបស់ធាតុ ដូចគ្នានៅគ្រប់ការនាំចេញនៃធាតុដូចគ្នា | ទេ |
| បន្ទាត់ | លេខបន្ទាត់ (`#1234`) របស់ធាតុនៅក្នុងឯកសារ IFC នេះ។ វាផ្លាស់ប្តូររវាងការនាំចេញ | ទេ |

នៅខាងក្រោមមាន **សំណុំលក្ខណៈសម្បត្តិ** តាមលំដាប់ឈ្មោះ៖

- សំណុំនីមួយៗបើក និងបិទនៅពេលអ្នកចុចឈ្មោះរបស់វា។ បីដំបូងត្រូវបានបើក។
- សំណុំដែលសម្គាល់ "(type)"ជារបស់ប្រភេទធាតុ៖ "លក្ខណៈសម្បត្តិប្រភេទ៖ ការផ្លាស់ប្តូរនៅទីនេះអនុវត្តចំពោះធាតុគ្រប់ទាំងអស់នៃប្រភេទនេះ។"
- សំណុំបរិមាណ (ប្រវែង ផ្ទៃក្រឡា មាឌ ចំនួន ទម្ងន់) គឺអាន-តែប៉ុណ្ណោះ។
- បញ្ជី និងតម្លៃរាប់បានត្រូវបានបង្ហាញ ជាអាន-តែប៉ុណ្ណោះ។
- តម្លៃបាទ/ទេ បង្ហាញជា **បាទ** ឬ **ទេ**។
- លេខត្រូវបានបង្គត់ដល់ទសភាគបួនសម្រាប់ការបង្ហាញ។ ប្រវែង (លក្ខណៈសម្បត្តិប្រវែង ឬប្រវែងនៃបរិមាណ) បង្ហាញក្នុង {{ui:ឯកតា}} ដែលបានជ្រើសនៅលើរបារឧបករណ៍ ជាមួយឯកតាក្បែរវា ហើយអ្នកអាចវាយតម្លៃថ្មីក្នុងឯកតានោះ ឬជាមួយសញ្ញាឯកតាផ្សេង (2.4 m, 8'-0"): BimCraft សរសេរលេខរបស់ឯកសារវិញ។ លេខផ្សេងទៀតបង្ហាញតាមដែលឯកសារមាន។
- តម្លៃទទេបង្ហាញជា *ទទេ*។ តម្លៃដែលបានកែត្រូវបានធ្វើអក្សរដិត ជាមួយរបារពណ៌ខៀវនៅក្បែរ។

## ចម្លងតម្លៃ

តម្លៃនីមួយៗក្នុង {{ui:លក្ខណៈសម្បត្តិ}} មានប៊ូតុងចម្លងតូចមួយនៅក្បែរវា៖ ចុចវាដើម្បីដាក់តម្លៃនោះទៅក្លីបបតដូចដែលបានបង្ហាញ ឧទាហរណ៍ GlobalId លេខស៊េរី ឬតម្លៃសំណុំលក្ខណៈសម្បត្តិណាមួយ។ ការចម្លងមិនដែលចាប់ផ្តើមការកែឡើយ។

នៅខាងលើ {{ui:ចម្លងទាំងអស់}} ចម្លងតម្លៃទាំងអស់នៃធាតុជាអក្សរ ម្តងមួយសំណុំ ហើយ {{ui:ចម្លងជា CSV}} ចម្លងវាជាជួរនៃក្រុម លក្ខណៈសម្បត្តិ និងតម្លៃ ដើម្បីបិទភ្ជាប់ទៅក្នុងតារាងគណនា; តម្លៃទទេត្រូវបានរក្សាទុក ដូច្នេះវាលនីមួយៗមានជួរ។ វាដំណើរការដូចគ្នាសម្រាប់ធាតុនៃម៉ូដែលបើកមួយទៀត; នៅពេលមានម៉ូដែលបើកច្រើនជាងមួយ CSV ចាប់ផ្តើមដោយជួរ Model ដែលដាក់ឈ្មោះឯកសាររបស់វា។

| ត្រីកោណ | ចំនួនត្រីកោណដែលរូបរាងរបស់វាបង្កើត; ជារង្វាស់ថាម៉ូដែលធ្ងន់ប៉ុណ្ណា |

## ផ្ទាំងឯកសារ (ឯកសារគម្រោង និងគ្រួសារ)

| វាល | អត្ថន័យ |
|---|---|
| ប្រភេទ | គម្រោង, គំរូគម្រោង, គ្រួសារ ឬគំរូគ្រួសារ |
| រក្សាទុកក្នុង | កំណែចេញផ្សាយដែលបានរក្សាទុកឯកសារចុងក្រោយ |
| ការបង្កើត | ការបង្កើតពិតប្រាកដនៃកំណែចេញផ្សាយនោះ |
| អាន | BimCraft បានអានប៉ុន្មានរបស់ឯកសារ ធៀបនឹងទំហំរបស់វា |

## ផ្ទាំងគំនូរ (DWG និង DXF)

| វាល | អត្ថន័យ |
|---|---|
| ទម្រង់ | កំណែដែលគំនូរត្រូវបានរក្សាទុកជា ជាមួយកូដទម្រង់របស់វា ដូចជា AC1032 |
| ឯកតា | ឯកតាបញ្ចូលរបស់គំនូរ នៅពេលកំណត់ |
| វត្ថុ | ចំនួនវត្ថុដែលបានអាន |
| ស្រទាប់ | ចំនួនស្រទាប់ |
| សន្លឹក | ចំនួនសន្លឹក (ប្លង់) ឬ គ្មាន |
| គំនូរដែលភ្ជាប់ | ចំនួនគំនូរដែលភ្ជាប់ដែលត្រូវបានរកឃើញ និងផ្ទុក |
| ឧបករណ៍ | ចំនួនឧបករណ៍ដែលមានសញ្ញាសម្គាល់នៅលើសន្លឹក |
