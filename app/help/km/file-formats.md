## ឯកសារគម្រោង និងក្រុម

`.rvt` គម្រោង, `.rte` ពុម្ពគម្រោង, `.rfa` ក្រុម និង `.rft` ពុម្ពក្រុម។

| អាន | ព័ត៌មានលម្អិត |
|---|---|
| ព័ត៌មានឯកសារ | ការចេញផ្សាយ និងការសាងសង់ ការធ្វើការរួម ផ្លូវម៉ូដែលកណ្តាល ផ្លូវដែលបានរក្សាទុកចុងក្រោយ ឈ្មោះអ្នកប្រើ ភាសា GUID ឯកសារ |
| ព័ត៌មានគម្រោង | វាលផ្ទាល់ខ្លួនរបស់គម្រោង (ឈ្មោះ លេខ អតិថិជន អាសយដ្ឋាន ស្ថានភាព…) ដោយគ្មានលំនាំដើមគម្រោងថ្មី |
| ព័ត៌មានក្រុម | ឈ្មោះក្រុម ប្រភេទ ការចេញផ្សាយ ការធ្វើបច្ចុប្បន្នភាពចុងក្រោយ និងប៉ារ៉ាម៉ែត្ររបស់វាតាមក្រុម |
| តំណភ្ជាប់ | បញ្ជីម៉ូដែលដែលភ្ជាប់, តំណ CAD, រូបភាព និងតារាងកូនសោដែលឯកសារចង្អុលទៅ |
| រូបភាពមើលជាមុន | រូបតូចដែលបានរក្សាទុកក្នុងឯកសារ |

មិនអាន៖ ម៉ូដែល 3D ធាតុ ទិដ្ឋភាព សន្លឹក និងតារាង។ ពួកវាត្រូវបានរក្សាទុកក្នុងទម្រង់ដែលមិនមានឯកសារ។ BimCraft អានតែពីរបីដប់គីឡូបៃត៍ពីឯកសារនីមួយៗ ដូច្នេះទំហំឯកសារស្ទើរតែមិនសំខាន់។

| ទិដ្ឋភាព | ទិដ្ឋភាពនៃសន្លឹកនីមួយៗ ជាមួយមាត្រដ្ឋាន ការបង្វិល និងស្រទាប់ដែលត្រូវបានកកចាក់ |
| ស្រទាប់ | ឈ្មោះ ពណ៌ បើក/បិទ កក ទង់បោះពុម្ព និងទំហំបន្ទាត់ |
| វត្ថុ | បន្ទាត់ ពហុបន្ទាត់ ធ្នូ រង្វង់ អេលីប ខ្សែកោងស្ប្លាញ ហាច់ និងវត្ថុរឹង អត្ថបទ និងអត្ថបទច្រើនបន្ទាត់ ប្លុក និងគុណលក្ខណៈ វិមាត្រ ព្រួញចង្អុល និងពហុព្រួញ តារាង ចំណុច រូបភាព |
| គំនូរដែលភ្ជាប់ | គូសនៅកន្លែងដែលវាត្រូវបានបញ្ចូល នៅពេលរកឃើញឯកសាររបស់វា |
| រូបភាព | គូសពីឯកសាររូបភាពនៅពេលរកឃើញ (PNG, JPEG, GIF, BMP, WebP; មិនមែន TIFF) |
| ស្លាកឧបករណ៍ | ស្លាកធាតុចម្អិនអាហារ (លក្ខណៈ `KCL-ITEM`) សម្រាប់តារាងឧបករណ៍ |

អ្វីផ្សេងទៀតត្រូវបានរាប់ក្រោម **Not drawn yet** ឥតមានការទាយឡើយ។ ទម្រង់ DWG ពី AutoCAD 2000 ដល់ 2018 គឺជាអ្វីដែលបានពិនិត្យ (ឯកសារ R13 និង R14 ក៏ទទួលយកដែរ ប៉ុន្តែគ្មានមួយនៅក្នុងសំណុំសាកល្បង; DWG ចាស់មិនបើក); ផ្ទាំង {{ui:Drawing}} បង្ហាញកូដទម្រង់ (ដូចជា AC1032)។ ឯកសារ DXF គ្រប់កំណែបើក រួមទាំង R12 ផង។ ទាំងពីរត្រូវបានអានដោយកម្មវិធីអានរបស់ BimCraft ផ្ទាល់ ក្នុងផ្ទាំងនេះ។ គ្មានអ្វីត្រូវបានរក្សាទុកត្រឡប់ទៅ DWG ឬ DXF ទេ។
