## អ្វីដែលអ្នកនឹងធ្វើ

ដឹកប្រភេទជញ្ជាំងរបស់អ្នកពីគម្រោងមួយទៅមួយទៀត ឬផ្តល់ឱ្យអ្នកដែលធ្វើការក្នុងកម្មវិធីផ្សេង។ កញ្ចប់ប្រភេទមានប្រភេទជញ្ជាំងនីមួយៗជាមួយស្រទាប់ កម្រាស់ សម្ភារៈ ស្នូល ចន្លោះ អាទិភាពស្រទាប់ កម្រិតនៃការអភិវឌ្ឍ ទិន្នន័យការគណនាបរិមាណ និងលេខកូដចាត់ថ្នាក់ និងគ្រួសារណាមួយដែលអ្នកបន្ថែម។ វាជាឯកសារបើកចំហ៖ អត្ថបទ JSON ធម្មតាដែលនរណាក៏អាចអាន ឬជាឯកសារ IFC។ គ្មានអ្វីក្នុងវាត្រូវបានចាក់សោទៅក្រុមហ៊ុន ប្រទេស ឬគណនីណាមួយឡើយ។

## រក្សាទុកប្រភេទពីគម្រោង

1. បើក **ទិន្នន័យ** នៅរបារម៉ូដែល ហើយជ្រើស {{ui:Type packs}}។
2. នៅក្រោម {{ui:Save types from this project}} ធីកប្រភេទជញ្ជាំងដែលត្រូវដាក់។ ប្រភេទផ្ទាល់ខ្លួនរបស់គម្រោងត្រូវបានធីករួច; ប្រភេទចាប់ផ្តើមអាចបន្ថែមបាន ហើយចូលជាច្បាប់ចម្លង។ ធីកគ្រួសារ ប្រសិនបើអ្នកចង់ឱ្យវាចូលផង។
3. វាយ {{ui:Pack name}}។
4. {{ui:Save as a pack (.json)}} ទាញយកឯកសារ `.cctypes.json`។ {{ui:Save as IFC (.ifc)}} ទាញយកឯកសារ IFC ដែលមានតែប្រភេទប៉ុណ្ណោះ: ប្រភេទជញ្ជាំងនីមួយៗជា IfcWallType ជាមួយសំណុំស្រទាប់សម្ភារៈ សម្ភារៈ និងការចាត់ថ្នាក់ សម្រាប់កម្មវិធី BIM ណាមួយ។

## បញ្ចូលប្រភេទទៅគម្រោង

1. នៅក្នុងបង្អួចដដែល ជ្រើស {{ui:Open a pack or an IFC file…}} ហើយជ្រើសកញ្ចប់ `.json` ឬឯកសារ `.ifc`។
2. បង្អួចបង្ហាញអ្វីដែលឯកសារមាន: ប្រភេទជញ្ជាំងនីមួយៗជាមួយកម្រាស់ ចំនួនស្រទាប់ និងលេខកូដ សម្ភារៈ និងគ្រួសារ។
3. ជ្រើសអ្វីដែលកើតឡើងចំពោះ {{ui:A type this project already has}}: **រក្សាទុករបស់គម្រោង**, **បន្ថែមរបស់កញ្ចប់ជាច្បាប់ចម្លង** (វាទទួលឈ្មោះថ្មីដែលបញ្ចប់ដោយ "(2)"), ឬ **ជំនួសវា (តែនៅពេលគ្មានជញ្ជាំងណាប្រើវា)**។
4. {{ui:Add to the project}}។ បង្អួចបង្ហាញអ្វីដែលបានបន្ថែម ចម្លង ជំនួស ឬរក្សាទុក។ វាជាជំហានមិនធ្វើវិញតែមួយ។

ប្រភេទថ្មីស្ថិតក្នុងបញ្ជីប្រភេទនៃឧបករណ៍ជញ្ជាំងភ្លាមៗ។

## ប្រភេទកម្រាល ដំបូល និងពិដាន

បញ្ជីប្រភេទដែលត្រូវរក្សាទុកក៏មានប្រភេទកម្រាល ដំបូល និងពិដានរបស់គម្រោង និងចាប់ផ្តើមរបស់ពួកវាផងដែរ (សម្គាល់ថា "កម្រាល" "ដំបូល" "ពិដាន")។ កញ្ចប់អាចផ្ទុកប្រភេទទាំងបួនបាន; ប្រភេទនីមួយៗដាក់ឈ្មោះថ្នាក់ IFC របស់វា (IfcWallType, IfcSlabType, IfcCoveringType)។ ប្រភេទកម្រាល ដំបូល ឬពិដានដែលធាតុប្រើ មិនត្រូវបានជំនួសពីកញ្ចប់ទេ: ផ្លាស់ប្តូរវានៅក្នុងកម្មវិធីកែប្រភេទ។

## ប្រភេទមួយជាធាតុបណ្ណាល័យ

ធីកប្រភេទតែមួយ ហើយជ្រើស **រក្សាទុកជាធាតុបណ្ណាល័យ…**។ វារក្សាទុកឯកសារ `.cctype.json`: ធាតុបណ្ណាល័យនៃប្រភេទ Types ដែលមានប្រភេទមួយនោះ (ស្រទាប់ សម្ភារៈ LOD និងលេខកូដចាត់ថ្នាក់របស់វា)។ ផ្ទុកឡើងក្នុងបណ្ណាល័យដើម្បីចែករំលែក។ **បើកកញ្ចប់ ឬឯកសារ IFC** អានធាតុបណ្ណាល័យបែបនេះផងដែរ ហើយបន្ថែមប្រភេទរបស់វាទៅគម្រោងដូចកញ្ចប់។

## ដែលគួរដឹង

- ឯកសារ IFC ពីកម្មវិធីផ្សេងក៏អាចបើកនៅទីនេះបានដែរ។ ប្រភេទជញ្ជាំងនីមួយៗរបស់វាដែលមានស្រទាប់សម្ភារៈត្រូវបានអាន៖ ឈ្មោះ សម្ភារៈ និងកម្រាស់របស់ស្រទាប់ និងចន្លោះណាមួយគឺជារបស់ឯកសារ។ ស្រទាប់ណាជាស្នូល និងស្រទាប់នីមួយៗធ្វើអ្វី (ការបញ្ចប់ រចនាសម្ព័ន្ធ អ៊ីសូឡង់) ត្រូវបានទាយ ប្រភេទត្រូវបានសម្គាល់ **(ទាយ)** ហើយអ្នកគួរពិនិត្យវានៅក្នុងកម្មវិធីកែប្រភេទជញ្ជាំង។ ប្រភេទជញ្ជាំងដែលគ្មានស្រទាប់ត្រូវបានចោល ហើយត្រូវបានដាក់ឈ្មោះ។
- សម្ភារៈដែលគម្រោងមានរួចត្រូវបានរក្សាទុកដូចដើម។ សម្ភារៈថ្មីដែលឈ្មោះត្រូវបានយកហើយ ទទួលបាន "(pack)" បន្ទាប់ពីឈ្មោះរបស់វា។
- ប្រភេទដែលជញ្ជាំងប្រើមិនត្រូវបានជំនួសពីកញ្ចប់ឡើយ។ ផ្លាស់ប្តូរវានៅក្នុងកម្មវិធីកែប្រភេទជញ្ជាំង ដែលផ្លាស់ទីជញ្ជាំងរបស់វាត្រឹមត្រូវ។
- លេខកូដដែលកំណត់លើជញ្ជាំងមួយមិនធ្វើដំណើរទេ: វាជារបស់ជញ្ជាំងនោះ។ លេខកូដដែលកំណត់លើប្រភេទធ្វើដំណើរ។
- ឯកសារដែលមានវាលដែលទ្រង់ទ្រាយមិនមាន ស្រទាប់ដែលសម្ភារៈបាត់ ឬអ្វីមួយដែលមិនមែនជាអត្ថបទធម្មតា ត្រូវបានបដិសេធ ហើយសារប្រាប់ថានៅកន្លែងណា និងហេតុអ្វី។
- មិនទាន់បង្កើត៖ ប្រភេទកម្រាល ដំបូល និងពិដាន (ពួកវាមិនមានប្រភេទក្នុងកំណែនេះ: ម្នាក់ៗមានកម្រាស់របស់ខ្លួន), ប្រភេទទ្វារ និងបង្អួចផ្សេងពីគ្រួសារ, និងហាច់ ឬពណ៌ពីឯកសារកម្មវិធីផ្សេង។
