## អ្វីដែលអ្នកនឹងធ្វើ

ដាក់កូដចាត់ថ្នាក់លើជញ្ជាំង កម្រាល ដំបូល ទ្វារ បង្អួច និងអ្វីផ្សេងទៀតក្នុងម៉ូដែល ជាមួយប្រព័ន្ធច្រើនរហូតដល់បីដោយគ្នា៖ Uniclass, OmniClass និង UniFormat។ វិស័យផ្សេងទៀត និងកម្មវិធីផ្សេងទៀតពឹងលើកូដ មិនមែនលើឈ្មោះទេ ដូច្នេះកូដត្រូវបានរក្សាទុកក្នុងឯកសារ IFC ជាឯកសារយោងការចាត់ថ្នាក់ ដែលកម្មវិធី BIM ណាមួយអានបាន។

## ដាក់កូដឱ្យធាតុ

1. ជ្រើសរើសធាតុ (ឬច្រើន) ហើយបើក **លក្ខណសម្បត្តិ**។ បើកផ្នែក {{ui:ការចាត់ថ្នាក់}}។
2. វាយកូដក្នុងប្រអប់នៃប្រព័ន្ធរបស់វា ហើយចុច Enter។ ពេលមានបញ្ជីកូដផ្ទុក វាយផ្នែកនៃកូដ ឬពាក្យពីរបីឃ្លា ("curtain wall") ហើយជ្រើសរើសពីការផ្គូផ្គង៖ ចំណងជើងកូដត្រូវបានបំពេញឱ្យអ្នក។
3. {{ui:អនុវត្តចំពោះ}} និយាយថាកូដទៅណា៖ **ធាតុនេះ** ឬ **ប្រភេទរបស់វា (ធាតុគ្រប់ប្រភេទ)**។ កូដនៅលើប្រភេទជញ្ជាំងត្រូវបានអានដោយជញ្ជាំងទាំងអស់នៃប្រភេទនោះ រួមទាំងដែលអ្នកគូសពេលក្រោយ។
4. {{ui:សម្អាត}} យកកូដចេញ។

នៅក្រោមកូដនីមួយៗ ផ្នែកនិយាយថាវាមកពីណា៖ កំណត់លើធាតុនេះ ពីប្រភេទរបស់វា ឬលំនាំដើមគម្រោងសម្រាប់ថ្នាក់របស់វា។ កូដផ្ទាល់របស់ធាតុតែងតែឈ្នះលើប្រភេទ ហើយរបស់ប្រភេទឈ្នះលើលំនាំដើម។ ពេលជ្រើសធាតុច្រើន ប្រអប់ដែលនិយាយ "ប្រែប្រួល" មានន័យថាពួកវាមិនមានកូដដូចគ្នាទេ; ការវាយមួយនឹងផ្តល់ឱ្យទាំងអស់។ ការផ្លាស់ប្តូរនីមួយៗគឺជាជំហានមិនធ្វើវិញមួយ។

អ្នកអាចវាយកូដជានិច្ច ទោះបីបញ្ជីត្រូវបានផ្ទុកឬអត់។ ប្រសិនបើវាមិនមើលទៅដូចកូដនៃប្រព័ន្ធនោះ ឬមិនមាននៅក្នុងបញ្ជីដែលបានផ្ទុក ការណែនាំនិយាយដូច្នេះ ហើយកូដត្រូវបានរក្សាទុកដូចដែលអ្នកបានវាយ។

## ជ្រើសរើសប្រព័ន្ធគម្រោង

បើក **ទិន្នន័យ** នៅរបារម៉ូដែល ហើយជ្រើសរើស {{ui:ការចាត់ថ្នាក់}} (ឬ {{ui:ការចាត់ថ្នាក់គម្រោង…}} នៅក្នុងផ្នែក លក្ខណសម្បត្តិ)។

- ធីកប្រព័ន្ធដែលគម្រោងនេះប្រើ។ លក្ខណសម្បត្តិបន្ទាប់មកបង្ហាញតែពួកវាប៉ុណ្ណោះ។
- **Uniclass**៖ តារាងធាតុ/មុខងារ (EF) ប្រព័ន្ធ (Ss) និងផលិតផល (Pr) មកជាមួយកម្មវិធី។ ពួកវាជា © NBS ដែលមានអាជ្ញាប័ណ្ណ Creative Commons Attribution-NoDerivatives 4.0 ហើយត្រូវបានផ្ទេរដោយមិនផ្លាស់ប្តូរ។ ប្រអប់បង្ហាញកំណែនៃតារាងនីមួយៗ និងថ្ងៃដែលវាត្រូវបានអាន។ ពួកវាមិនមែនជាតារាងថ្មីបំផុតទេ៖ អ្នកបោះពុម្ពចេញតារាងថ្មីរៀងរាល់ត្រីមាស នៅលើគេហទំព័ររបស់ខ្លួន។
- **OmniClass** និង **UniFormat**៖ គ្មានបញ្ជីកូដមកជាមួយកម្មវិធីទេ ព្រោះអ្នកបោះពុម្ពមិនអនុញ្ញាតឱ្យតារាងត្រូវបានផ្ទេរដោយគ្មានអាជ្ញាប័ណ្ណ។ វាយកូដណាមួយ ឬផ្ទុកតារាងដែលមានអាជ្ញាប័ណ្ណរបស់ការិយាល័យអ្នក។
- {{ui:ផ្ទុកតារាង (CSV)…}} អានតារាងរបស់ការិយាល័យអ្នកពីឯកសារ CSV ដែលមានជួរកូដ និងជួរចំណងជើង (ជួរក្បាលដែលមានឈ្មោះ Code, Number ឬ Identifier និង Title, Name ឬ Description ត្រូវបានរកឃើញដោយខ្លួនឯង; បើគ្មានវា ជួរពីរដំបូងត្រូវបានប្រើ)។ តារាងនៅក្នុងកម្មវិធីរុករកនេះ ហើយមិនដែលដាក់ក្នុងឯកសារគម្រោងទេ។ មានតែកូដដែលអ្នកកំណត់ប៉ុណ្ណោះត្រូវបានរក្សាទុកក្នុងឯកសារ។ អ្នកអាចផ្ទុកតារាង Uniclass ថ្មីជាងតាមវិធីដូចគ្នា។
- {{ui:កំណត់កូដលំនាំដើមឱ្យធាតុតាមថ្នាក់របស់វា}} ផ្តល់កូដ Uniclass ចាប់ផ្តើមដល់ជញ្ជាំង កម្រាល ដំបូល ទ្វារ បង្អួច ជណ្ដើរ ផ្លូវជម្រាល សសរ ធ្នឹម និងគ្រឿងសង្ហារិមនីមួយៗ ពីតារាង Elements/ functions នៅពេលវាមិនមានកូដផ្ទាល់។ ធាតុដែលអ្នកគូសបន្ទាប់ពីនោះក៏ទទួលបានវាដែរ។
- {{ui:បង្ហាញកូដជាជួរឈរនៅក្នុងតារាង}} បន្ថែមជួរមួយក្នុងមួយប្រព័ន្ធ ទៅតារាង ទ្វារ បង្អួច ជញ្ជាំងតាមប្រភេទ និងបន្ទប់ និង CSV របស់វា។ ជួរនៃធាតុច្រើនបង្ហាញ "ប្រែប្រួល" នៅពេលកូដរបស់ពួកវាខុសគ្នា។

## ត្រូវដឹង

- កូដលំនាំដើមគឺជាជម្រើសចាប់ផ្តើមរបស់ CadCraft ខ្លួនឯង មិនមែនរបស់អ្នកបោះពុម្ពទេ ហើយមិនត្រូវបានពិនិត្យដោយអ្នកជំនាញទេ។ ពិនិត្យពួកវាធៀបនឹងស្តង់ដារគម្រោងរបស់អ្នក។
- នៅក្នុងឯកសារ លំនាំដើមគឺជាការចាត់ថ្នាក់ពិតប្រាកដ ដែលសម្គាល់ដោយឈ្មោះទំនាក់ទំនង "CadCraft default" ហើយវាបាត់នៅពេលធាតុ ឬប្រភេទរបស់វាទទួលបានកូដផ្ទាល់ខ្លួន។
- កូដដែលឯកសារដែលបាននាំចូលមានស្រាប់ត្រូវបានអាន និងបង្ហាញ មិនថាការសរសេរឈ្មោះប្រព័ន្ធដោយកម្មវិធីផ្សេងទេ។ កូដនៃប្រព័ន្ធផ្សេងណាមួយ (របស់ការិយាល័យ) ត្រូវបានរាយ ហើយទុកចោលដដែល។
- កូដត្រូវបានអានឡើងវិញនៅពេលបើកឯកសារម្តងទៀត នៅទីនេះ ឬក្នុងកម្មវិធីផ្សេង។ ពួកវាក៏ត្រូវបានយកទៅក្នុងការនាំចេញ IFC5 alpha (IFCX) នៅពេលជម្រើសមន្ទីរពិសោធន៍នោះបើក លើកលែងតែកូដដែលកំណត់លើដំបូល។
- មិនទាន់បានបង្កើត៖ ដើមឈើសម្រាប់រុករកតារាងតាមកម្រិត កូដលើជាន់ និងបន្ទប់ជាលំនាំដើមគម្រោង និងការពិនិត្យកូដធៀបនឹងកំណែដែលបានដាក់ឈ្មោះក្នុងឯកសារ។
