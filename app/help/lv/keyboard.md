BimCraft ir maz īsinājumtaustiņu. Lielāko daļu darbu veic ar peli un paneļiem. Īsinājumtaustiņi, kas rakstīti ar {{key:Mod}}, izmanto Command operētājsistēmā Mac un Ctrl citur. Skatiet [Taustiņi, peles un skārienpaneļi](common:keys), lai uzzinātu, kā šajā palīdzībā ir rakstīti taustiņi.

## Visur

| Taustiņš | Ko tas dara |
|---|---|
| {{key:Ctrl+Shift+F}} | Pārslēgt ekrāna režīmus: parasto, pilnekrāna un pilnekrāna režīmu ar paslēptām joslām. Ctrl visās platformās, arī Mac |
| {{key:Esc}} | Iziet no pilnekrāna |
| {{key:Mod+,}} | Atvērt {{ui:Iestatījumi}}. Skatiet [BimCraft iestatījumi](topic:settings) |
| {{key:Tab}} | Pārvietoties starp pogām, izvēles rūtiņām un vērtībām. Uz katru vadības elementu var nokļūt ar tastatūru |

## 3D skats (IFC modeļi)

| Taustiņš vai darbība | Ko tas dara |
|---|---|
| {{key:F}} | Pielāgot visu modeli, trīs ceturtdaļu skats (tas pats, kas {{ui:Pielāgot}}) |
| {{key:Esc}} | Notīrīt atlasi vai pārtraukt novietošanu vai ielīmēšanu |
| Klikšķis | Atlasīt elementu zem kursora; noklikšķiniet tukšā fonā, lai notīrītu atlasi |
| {{key:Mod}}+klikšķis vai {{key:Shift}}+klikšķis | Pievienot elementu atlasei vai to izņemt |
| {{key:H}} | Paslēpt atlasītos elementus. Skatiet [Paslēpt, izolēt un redzēt caur elementiem](topic:hide-and-isolate) |
| {{key:I}} | Rādīt tikai atlasītos elementus (izolēt) |
| {{key:T}} | Rādīt atlasītos elementus, pārējie — caurredzami |
| {{key:Shift+H}} | Parādīt visus elementus vēlreiz |
| {{ui:Staigāt}} | Pēc tam {{key:W}} {{key:A}} {{key:S}} {{key:D}} vai bultiņas staigā, {{key:Shift}} skrien, vilkšana skatās apkārt, {{key:Esc}} aptur. Skatiet [Staigāt pa modeli](topic:walk) |
| {{key:M}} | Mērīt attālumus un virsmu laukumus. Skatiet [Mērīt attālumus, virsmu laukumus un atrašanās vietas 3D](topic:measure) |
| Vilkt ar kreiso pogu | Orbitēt |
| Vilkt ar labo pogu | Panoramēt |
| {{key:Shift}} vai {{key:Mod}} un vilkt ar kreiso pogu | Panoramēt (ērti uz skārienpaneļa) |
| Ritināt ritentiņu vai vilkt ar vidējo pogu | Tālummaiņa |
| Divu pirkstu ritināšana vai saspiešana uz skārienpaneļa | Tālummaiņa |
| Viens pirksts (skāriens) | Orbitēt; pieskaršanās atlasa |
| Divi pirksti (skāriens) | Saspiest tālummaiņai, pārvietot kopā panoramēšanai |

| {{key:X}} | Griezuma plakne ieslēgta un izslēgta. Skatiet [Sagriezt IFC modeli ar griezuma plakni](topic:section-plane) |
| {{key:Shift+X}} | Griezuma kārba ap atlasītajiem elementiem ar telpu, kas iestatīta Iestatījumos |

Taustiņu nav {{ui:Augša}}, {{ui:Priekšpuse}} un {{ui:Sāns}} skatiem; izmantojiet pogas.

## Rediģēšana

Tās pašas komandas ir rīkjoslā: {{ui:Atsaukt}}, {{ui:Atkārtot}}, {{ui:Kopēt}}, {{ui:Ielīmēt}} un izvēlne {{ui:Vairāk}}, kurā redzams katrs taustiņš. Tās darbojas IFC modeļa 3D skatā, nevis kamēr rakstāt laukā. Skatiet [Kopēt, ielīmēt un dublēt bibliotēkas vienumus](topic:copy-paste).

| Taustiņš | Ko tas dara |
|---|---|
| {{key:Mod+Z}} | Atsaukt pēdējo izmaiņu |
| {{key:Mod+Y}} vai {{key:Mod+Shift+Z}} | Atkārtot to, ko atsaukšana atsauca |
| {{key:Mod+C}} | Kopēt atlasītos elementus (to nosaukumi un rekvizīti tiek ievietoti arī starpliktuvē kā teksts) |
| {{key:Mod+X}} | Izgriezt atlasītos elementus: nokopēt un pēc tam dzēst |
| {{key:Mod+V}} | Ielīmēt to, ko nokopējāt: tas seko kursoram; noklikšķiniet, kur tam jāiet |
| {{key:Mod+Shift+V}} | Ielīmēt vietā: tur, no kurienes izgriezts, vai blakus oriģināliem pēc kopēšanas |
| {{key:Mod+D}} | Dublēt: kopēt atlasītos elementus un sākt tos ielīmēt |
| {{key:Delete}} | Dzēst atlasītos elementus kopā ar to daļām un atverēm. Skatiet [Dzēst, griezt, kopēt un ielīmēt būvelementus](topic:edit-elements) |
| {{key:Mod+A}} | Atlasīt visus redzamos elementus |
| {{key:Esc}} | Neatlasīt nevienu |

Kad lapā ir atlasīts teksts, {{key:Mod+C}} kopē šo tekstu kā parasti.

## Plāna skats (Zīmēšana)

Šie darbojas, kamēr {{ui:Zīmēšana}} ir ieslēgta un jūs nerakstāt laukā. Skatiet [Zīmēt sienas](topic:draw-walls) un [Durvis un logi](topic:doors-and-windows).

| Taustiņš vai darbība | Ko tas dara |
|---|---|
| {{key:V}} | {{ui:Atlasīt}} |
| {{key:W}} | {{ui:Siena}} |
| {{key:D}} | {{ui:Durvis}} |
| {{key:N}} | {{ui:Logs}} |
| {{key:H}} | Ar {{ui:Durvis}} vai {{ui:Logs}}: vira atvēršanās puse otrā galā |
| {{key:Shift}}, zīmējot sienu | Turēt to 0°, 90°, 180° vai 270° |
| Cipari un pēdu un collu zīmes (`'` un `"`) | Sākt rakstīt garumu lodziņā {{ui:Garums}}; {{key:Enter}} to izmanto |
| {{key:Enter}}, {{key:Esc}}, labā poga vai dubultklikšķis | Beigt sienu, ko zīmējat; {{key:Esc}} vēlreiz atgriež {{ui:Atlasīt}} |
| {{key:Delete}} | Dzēst atlasītās sienas, durvis un logus; atlikušās sienas atkal savienojas |
| {{key:F}}, kad kursors ir virs plāna | Pielāgot plānu |
| Ritināt ritentiņu | Tālummaiņa ap kursoru |
| Vilkt ar vidējo vai labo pogu, vai {{key:Space}} un vilkt | Panoramēt; ar ieslēgtu {{ui:Atlasīt}} parasta vilkšana arī panoramē |
| Vilkt durvis vai logu ar {{ui:Atlasīt}} | Pārvietot to pa sienu vai uz citu sienu |
| Divi pirksti (skāriens) | Saspiest tālummaiņai, pārvietot kopā panoramēšanai |

## Bibliotēkas vienumu novietošana un ielīmēšana

| Taustiņš | Ko tas dara |
|---|---|
| {{key:R}} | Pagriezt vienumu par 90° |
| {{key:Tab}} | Sienas piesaiste ieslēgta un izslēgta: vienuma aizmugure pieskaras tuvākajai sienai |
| {{key:Enter}} laukā **X, Y (mm)** | Novietot ierakstītajā pozīcijā |
| {{key:Esc}} | Pārtraukt novietošanu vai ielīmēšanu |

## IFC vērtību rediģēšana

| Taustiņš | Ko tas dara |
|---|---|
| {{key:Enter}} | Saglabāt ierakstīto vērtību |
| {{key:Esc}} | Atcelt un atjaunot veco vērtību |
| Noklikšķināt citur | Saglabāt ierakstīto vērtību |
| {{key:Mod+Z}} | Atsaukt pēdējo izmaiņu. Tikai tad, kad ir nesaglabātas izmaiņas un jūs nerakstāt laukā |
| {{key:Mod+Y}} | Atkārtot to, ko atsaukšana atsauca |
| {{key:Mod+S}} | Saglabāt kā IFC. Tikai tad, kad ir nesaglabātas izmaiņas; citādi atveras pārlūka pašas saglabāšanas komanda |

Lai rediģētu tikai ar tastatūru: nospiediet {{key:Tab}}, līdz vērtība ir izcelta, pēc tam nospiediet {{key:Enter}}, lai sāktu rakstīt.

## 2D rasējumi (DWG un DXF)

| Taustiņš vai darbība | Ko tas dara |
|---|---|
| {{key:F}} | Pielāgot rasējumu vai lapu |
| {{key:P}} | Drukas skats ieslēgts un izslēgts |
| Dubultklikšķis | Pielāgot |
| Vilkt ar jebkuru pogu | Panoramēt |
| Ritināt ritentiņu | Tālummaiņa pie kursora |
| Divu pirkstu ritināšana vai saspiešana uz skārienpaneļa | Tālummaiņa pie kursora. Divu pirkstu ritināšana nepanoramē |
| Viens pirksts (skāriens) | Panoramēt. Saspiešanas tālummaiņa rasējumiem vēl nav izveidota |

## Rasējumi 3D skatā

| Taustiņš vai darbība | Ko tas dara |
|---|---|
| {{key:3}} | 3D ieslēgts un izslēgts (arī 2D skatā) |
| {{key:F}} | Robežas: viss rasējums |
| Vilkt ar vidējo vai kreiso pogu | Orbitēt |
| Vilkt ar labo pogu vai {{key:Shift}} un vilkt | Panoramēt |
| Ritināt ritentiņu | Tālummaiņa uz to, kas atrodas zem kursora |
| Divu pirkstu vilkšana uz skārienpaneļa | Orbitēt; ar {{key:Shift}} — panoramēt |
| Saspiest uz skārienpaneļa | Tālummaiņa |
| Viens pirksts (skāriens) | Orbitēt |
| Divi pirksti (skāriens) | Saspiest tālummaiņai, pārvietot kopā panoramēšanai |

{{key:F}}, {{key:P}} un {{key:3}} neko nedara, kamēr rakstāt laukā, kamēr redzama aprīkojuma specifikācija vai kad turat {{key:Mod}} vai {{key:Alt}}.
