BimCraft มีปุ่มลัดน้อยมาก งานส่วนใหญ่ทำด้วยเมาส์และพาเนล ปุ่มลัดที่เขียนด้วย {{key:Mod}} ใช้ Command บน Mac และ Ctrl บนระบบอื่น ดู [ปุ่ม เมาส์ และแทร็กแพด](common:keys) เพื่อดูวิธีเขียนปุ่มในคู่มือนี้

## ทุกที่

| ปุ่ม | หน้าที่ |
|---|---|
| {{key:Ctrl+Shift+F}} | สลับโหมดหน้าจอ: ปกติ เต็มหน้าจอ และเต็มหน้าจอโดยซ่อนแถบ ใช้ Ctrl ทุกระบบ รวมถึง Mac |
| {{key:Esc}} | ออกจากโหมดเต็มหน้าจอ |
| {{key:Mod+,}} | เปิด {{ui:การตั้งค่า}} ดู [การตั้งค่า BimCraft](topic:settings) |
| {{key:Tab}} | เลื่อนระหว่างปุ่ม ช่องทำเครื่องหมาย และค่า ทุกการควบคุมเข้าถึงได้ด้วยคีย์บอร์ด |

## มุมมอง 3D (โมเดล IFC)

| ปุ่มหรือการกระทำ | หน้าที่ |
|---|---|
| {{key:F}} | พอดีกับโมเดลทั้งหมด มุมมองสามในสี่ (เหมือน {{ui:พอดี}}) |
| {{key:Esc}} | ล้างการเลือก หรือหยุดการวางหรือการวาง |
| คลิก | เลือกองค์ประกอบใต้ตัวชี้ คลิกพื้นหลังว่างเพื่อล้าง |
| {{key:Mod}}+คลิก หรือ {{key:Shift}}+คลิก | เพิ่มองค์ประกอบเข้าในการเลือก หรือนำออก |
| {{key:H}} | ซ่อนองค์ประกอบที่เลือก ดู [ซ่อน แยก และมองทะลุองค์ประกอบ](topic:hide-and-isolate) |
| {{key:I}} | แสดงเฉพาะองค์ประกอบที่เลือก (แยก) |
| {{key:T}} | แสดงองค์ประกอบที่เลือก ส่วนอื่นทั้งหมดมองทะลุ |
| {{key:Shift+H}} | แสดงทุกองค์ประกอบอีกครั้ง |
| {{ui:เดิน}} | จากนั้นกด {{key:W}} {{key:A}} {{key:S}} {{key:D}} หรือปุ่มลูกศรเพื่อเดิน {{key:Shift}} ใช้วิ่ง ลากเพื่อมองรอบตัว {{key:Esc}} เพื่อหยุด ดู [เดินผ่านโมเดล](topic:walk) |
| {{key:M}} | วัดระยะทางและพื้นที่หน้า ดู [วัดระยะทาง พื้นที่หน้า และตำแหน่งใน 3D](topic:measure) |
| ลากด้วยปุ่มซ้าย | หมุนรอบ |
| ลากด้วยปุ่มขวา | แพน |
| {{key:Shift}} หรือ {{key:Mod}} แล้วลากด้วยปุ่มซ้าย | แพน (สะดวกบนแทร็กแพด) |
| เลื่อนล้อ หรือลากด้วยปุ่มกลาง | ซูม |
| เลื่อนสองนิ้วหรือบีบบนแทร็กแพด | ซูม |
| นิ้วเดียว (สัมผัส) | หมุนรอบ; แตะเพื่อเลือก |
| สองนิ้ว (สัมผัส) | บีบเพื่อซูม เลื่อนพร้อมกันเพื่อแพน |

| {{key:X}} | เปิดและปิดระนาบตัด ดู [ตัดโมเดล IFC ด้วยระนาบตัด](topic:section-plane) |
| {{key:Shift+X}} | กล่องตัดรอบองค์ประกอบที่เลือก โดยมีพื้นที่ว่างที่ตั้งค่าไว้ในการตั้งค่า |

ไม่มีปุ่มลัดสำหรับ {{ui:บน}} {{ui:หน้า}} และ {{ui:ด้านข้าง}} ให้ใช้ปุ่มแทน

## แก้ไข

คำสั่งเดียวกันอยู่บนแถบเครื่องมือ: {{ui:เลิกทำ}} {{ui:ทำซ้ำ}} {{ui:คัดลอก}} {{ui:วาง}} และเมนู {{ui:เพิ่มเติม}} ซึ่งแสดงปุ่มลัดของแต่ละคำสั่ง ใช้ได้ในมุมมอง 3D ของโมเดล IFC ไม่ใช้ขณะพิมพ์ในช่อง ดู [คัดลอก วาง และทำสำเนารายการในไลบรารี](topic:copy-paste)

| ปุ่ม | หน้าที่ |
|---|---|
| {{key:Mod+Z}} | เลิกทำการเปลี่ยนแปลงล่าสุด |
| {{key:Mod+Y}} หรือ {{key:Mod+Shift+Z}} | ทำซ้ำสิ่งที่การเลิกทำนำกลับไป |
| {{key:Mod+C}} | คัดลอกองค์ประกอบที่เลือก (ชื่อและคุณสมบัติจะถูกส่งไปยังคลิปบอร์ดเป็นข้อความด้วย) |
| {{key:Mod+X}} | ตัดองค์ประกอบที่เลือก: คัดลอกแล้วลบ |
| {{key:Mod+V}} | วางสิ่งที่คัดลอกไว้: จะตามตัวชี้ คลิกตรงที่ต้องการให้วาง |
| {{key:Mod+Shift+V}} | วางที่เดิม: ตำแหน่งที่ถูกตัดมา หรือข้างต้นฉบับหลังการคัดลอก |
| {{key:Mod+D}} | ทำสำเนา: คัดลอกองค์ประกอบที่เลือกและเริ่มวาง |
| {{key:Delete}} | ลบองค์ประกอบที่เลือก พร้อมส่วนประกอบและช่องเปิด ดู [ลบ ตัด คัดลอก และวางองค์ประกอบอาคาร](topic:edit-elements) |
| {{key:Mod+A}} | เลือกทุกองค์ประกอบที่แสดงอยู่ |
| {{key:Esc}} | ยกเลิกการเลือก |

เมื่อเลือกข้อความบนหน้า {{key:Mod+C}} จะคัดลอกข้อความนั้นตามปกติ

## มุมมองผังพื้น (วาด)

ใช้ได้เมื่อเปิด {{ui:วาด}} และไม่ได้พิมพ์ในช่อง ดู [วาดผนัง](topic:draw-walls) และ [ประตูและหน้าต่าง](topic:doors-and-windows)

| ปุ่มหรือการกระทำ | หน้าที่ |
|---|---|
| {{key:V}} | {{ui:เลือก}} |
| {{key:W}} | {{ui:ผนัง}} |
| {{key:D}} | {{ui:ประตู}} |
| {{key:N}} | {{ui:หน้าต่าง}} |
| {{key:H}} | เมื่อใช้ {{ui:ประตู}} หรือ {{ui:หน้าต่าง}}: บานพับอยู่ที่ปลายอีกด้าน |
| {{key:Shift}} ขณะวาดผนัง | คงผนังไว้ที่ 0°, 90°, 180° หรือ 270° |
| ตัวเลขและเครื่องหมายฟุตและนิ้ว (`'` และ `"`) | เริ่มพิมพ์ความยาวลงในช่อง {{ui:ความยาว}} {{key:Enter}} จะใช้ค่านั้น |
| {{key:Enter}}, {{key:Esc}}, คลิกขวา หรือดับเบิลคลิก | จบผนังที่กำลังวาด; {{key:Esc}} อีกครั้งจะกลับไป {{ui:เลือก}} |
| {{key:Delete}} | ลบผนัง ประตู และหน้าต่างที่เลือก ผนังที่เหลือจะต่อกันอีกครั้ง |
| {{key:F}} เมื่อตัวชี้อยู่เหนือผัง | พอดีกับผัง |
| เลื่อนล้อ | ซูมรอบตัวชี้ |
| ลากด้วยปุ่มกลางหรือปุ่มขวา หรือกด {{key:Space}} แล้วลาก | แพน; เมื่อเปิด {{ui:เลือก}} การลากธรรมดาก็แพนได้เช่นกัน |
| ลากประตูหรือหน้าต่างด้วย {{ui:เลือก}} | เลื่อนไปตามผนัง หรือย้ายไปยังผนังอื่น |
| สองนิ้ว (สัมผัส) | บีบเพื่อซูม เลื่อนพร้อมกันเพื่อแพน |

## การวางและวางรายการในไลบรารี

| ปุ่ม | หน้าที่ |
|---|---|
| {{key:R}} | หมุนรายการ 90° |
| {{key:Tab}} | เปิดและปิดการสแนปกับผนัง: ด้านหลังของรายการจะชิดกับผนังที่ใกล้ที่สุด |
| {{key:Enter}} ใน **X, Y (mm)** | วางที่ตำแหน่งที่พิมพ์ |
| {{key:Esc}} | หยุดการวางหรือการวาง |

## การแก้ไขค่า IFC

| ปุ่ม | หน้าที่ |
|---|---|
| {{key:Enter}} | เก็บค่าที่พิมพ์ |
| {{key:Esc}} | ยกเลิกและคืนค่าเดิม |
| คลิกที่อื่น | เก็บค่าที่พิมพ์ |
| {{key:Mod+Z}} | เลิกทำการเปลี่ยนแปลงล่าสุด เฉพาะเมื่อมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก และไม่ได้พิมพ์ในช่อง |
| {{key:Mod+Y}} | ทำซ้ำสิ่งที่การเลิกทำนำกลับไป |
| {{key:Mod+S}} | บันทึกเป็น IFC เฉพาะเมื่อมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก มิฉะนั้นคำสั่งบันทึกของเบราว์เซอร์จะเปิดขึ้น |

หากต้องการแก้ไขด้วยคีย์บอร์ดอย่างเดียว กด {{key:Tab}} จนกว่าค่าจะถูกเน้น จากนั้นกด {{key:Enter}} เพื่อเริ่มพิมพ์

## แบบ 2D (DWG และ DXF)

| ปุ่มหรือการกระทำ | หน้าที่ |
|---|---|
| {{key:F}} | พอดีกับแบบหรือแผ่น |
| {{key:P}} | เปิดและปิดมุมมองพิมพ์ |
| ดับเบิลคลิก | พอดี |
| ลากด้วยปุ่มใดก็ได้ | แพน |
| เลื่อนล้อ | ซูมที่ตัวชี้ |
| เลื่อนสองนิ้วหรือบีบบนแทร็กแพด | ซูมที่ตัวชี้ การเลื่อนสองนิ้วไม่แพน |
| นิ้วเดียว (สัมผัส) | แพน การบีบซูมสำหรับแบบยังไม่ได้สร้าง |

## แบบใน 3D

| ปุ่มหรือการกระทำ | หน้าที่ |
|---|---|
| {{key:3}} | เปิดและปิด 3D (ทำได้ในมุมมอง 2D ด้วย) |
| {{key:F}} | ขอบเขต: ทั้งแบบ |
| ลากด้วยปุ่มกลางหรือปุ่มซ้าย | หมุนรอบ |
| ลากด้วยปุ่มขวา หรือกด {{key:Shift}} แล้วลาก | แพน |
| เลื่อนล้อ | ซูมเข้าหาสิ่งที่อยู่ใต้ตัวชี้ |
| เลื่อนสองนิ้วบนแทร็กแพด | หมุนรอบ; กับ {{key:Shift}} คือแพน |
| บีบบนแทร็กแพด | ซูม |
| นิ้วเดียว (สัมผัส) | หมุนรอบ |
| สองนิ้ว (สัมผัส) | บีบเพื่อซูม เลื่อนพร้อมกันเพื่อแพน |

{{key:F}} {{key:P}} และ {{key:3}} จะไม่ทำงานขณะพิมพ์ในช่อง ขณะแสดงตารางอุปกรณ์ หรือเมื่อกด {{key:Mod}} หรือ {{key:Alt}} ค้างไว้
