## สิ่งที่จะทำ

แม่แบบคือข้อความใน Markdown ที่มีช่องอยู่ในวงเล็บปีกกาคู่ BimCraft เติมช่องจากโมเดลที่เปิดอยู่ (จำนวน ปริมาณตามชนิด คุณสมบัติ และ[แท็ก](topic:tags-and-schedules)ของคุณ) แล้วบันทึกผลเป็น PDF เอกสาร Word (.docx) หรือ Markdown

## ขั้นตอน

1. เปิดโมเดล IFC
2. ในพาเนลทางซ้าย ภายใต้{{ui:ปริมาณ}} เปิด{{ui:เอกสารจากโมเดล}}
3. เลือกแม่แบบ: {{ui:ประตูและอุปกรณ์ประกอบ}} หรือ{{ui:ผนัง วัสดุบุผนัง และงานผิว}} หรือ{{ui:โหลดแม่แบบ (.md)…}} สำหรับแม่แบบของคุณเอง
4. หากแม่แบบอ่านแท็กที่โมเดลยังไม่กำหนด ให้คลิก{{ui:เพิ่มแท็กของแม่แบบนี้}} แล้วใส่แท็กให้องค์ประกอบภายใต้{{ui:แท็ก}}
5. แก้ไขข้อความตามต้องการ แล้วคลิก{{ui:แสดงเอกสาร}}
6. คลิก{{ui:PDF}} (เลือก A4 หรือ Letter ก่อน) หรือ{{ui:Word (.docx)}}

## สิ่งที่คุณควรเห็น

- เอกสารที่เติมแล้วอยู่ใต้ปุ่ม พร้อมตารางต่างๆ
- รายการคำเตือนเมื่อช่องใดอ่านไม่ได้ (แท็กที่ไม่ได้กำหนด คุณสมบัติที่โมเดลไม่มี บล็อกที่ไม่ได้ปิด) ช่องดังกล่าวจะพิมพ์เป็น `[?…]`
- หน้า PDF ที่มีชื่อเอกสารและ "หน้า 1 จาก 3" ที่ท้ายทุกหน้า ตารางยาวจะขึ้นหน้าใหม่พร้อมแถวหัวตาราง

## ช่อง

| ช่อง | ให้ผล |
|---|---|
| `{{project}}`, `{{project description}}`, `{{file}}`, `{{date}}` | ชื่อและคำอธิบายของโครงการ ชื่อไฟล์ วันนี้ |
| `{{count IfcDoor}}` | จำนวนประตู |
| `{{sum IfcWall NetSideArea}}` | ผลรวม พร้อมหน่วย |
| `{{calc [sum IfcWall NetSideArea] * 1.1 round 1 unit m²}}` | การคำนวณ (`+ - * /` และวงเล็บ) บนพจน์ในวงเล็บเหลี่ยม: `[sum …]`, `[count …]` และภายใน each คือ `[qty Width]` `round n` กำหนดทศนิยม `unit` เพิ่มหน่วย สิ่งที่อ่านไม่ได้หรือการหารด้วยศูนย์จะพิมพ์เป็น `[?…]` และแจ้งเตือน |
| `{{qty IfcWall NetSideArea by Type}}` | ตาราง: หนึ่งแถวต่อชนิด พร้อมจำนวนและผลรวม และแถวรวม |
| `{{table IfcDoor cols Mark, Type, Width, tag:Fire rating}}` | ตาราง หนึ่งแถวต่อองค์ประกอบ |
| `{{tag Finish}}` | ในลูป เป็นค่าขององค์ประกอบนั้น นอกลูปเป็นทุกค่าที่ใช้ (Oak, Paint) |
| `{{tags}}` | นิยามแท็กเป็นตาราง |
| `{{#each IfcDoor}} … {{else}} … {{/each}}` | ข้อความหนึ่งครั้งต่อองค์ประกอบ ส่วนหลัง `{{else}}` ใช้เมื่อไม่มีองค์ประกอบ |
| `{{#group IfcWall by Type}} … {{/group}}` | ข้อความหนึ่งครั้งต่อชนิด พร้อม `{{value}}`, `{{count}}`, `{{sum Length}}` และ `{{#each}}` แบบธรรมดาอยู่ข้างใน |

ภายใน `{{#each}}`: `{{name}}`, `{{type}}`, `{{storey}}`, `{{class}}`, `{{material}}`, `{{mark}}` (IFC Tag), `{{guid}}`, `{{n}}` (1, 2, 3 …), `{{prop Pset_DoorCommon.FireRating}}`, `{{qty Width}}` (ของตัวองค์ประกอบเอง พร้อมหน่วย)

คลาสอาจมีหลายชนิด (`IfcDoor|IfcWindow`) หรือทุกองค์ประกอบ (`*`) จำกัดด้วย `where` ได้: `{{#each IfcDoor where Fire rating >= 60}}`, `{{count IfcWall where Wall finish hasnot}}` การทดสอบคือ `=`, `!=`, `~` (มีคำ), `>`, `<`, `>=`, `<=`, `has` และ `hasnot` เชื่อมหลายเงื่อนไขด้วย `and` ใส่ค่าที่มีช่องว่างไว้ใน "เครื่องหมายคำพูด" `sort Name` เรียงลำดับลูป

## ตารางรายการและข้อกำหนดในเอกสาร

`{{schedule doors}}` พิมพ์ตารางรายการของโมเดลเป็นตาราง ตามการจัดวางของสำนักงาน: `doors`, `windows`, `walls`, `rooms`, `floors`, `roomfinishes`, `wallfinishes`, `zonefinishes`, `finishtotals`, `layers` หรือชื่อการจัดวางที่คุณบันทึกไว้ในตารางรายการ `{{specification}}` พิมพ์ข้อกำหนดของโครงการ แม่แบบ **ตารางแบบงานก่อสร้าง** และ **ข้อกำหนด** ใช้ช่องเหล่านี้ ในการแสดงตัวอย่าง คลิกตัวเลขของตารางรายการดังกล่าวเพื่อเลือกองค์ประกอบที่มาจากนั้น ดู [จัดวาง บันทึก และส่งออกตารางรายการ](topic:schedule-layouts) และ [เขียนข้อกำหนดจากโมเดล](topic:specification)

## ควรทราบ

- ช่องหนึ่งระบุได้ทั้งตัวที่มีในตัว (Name, Type, Storey, Class, Material, Mark) แท็ก (`tag:Fire rating` หรือชื่อของแท็ก) คุณสมบัติ (`Pset_WallCommon.FireRating`) หรือชื่อคุณสมบัติเพียงอย่างเดียว (`NetSideArea`, `Width`) ชื่อเปล่าจะอ่านชุดของแต่ละองค์ประกอบ โดยชุดปริมาณมาก่อน ดังนั้น `Width` ของประตูคือความกว้างของประตู ไม่ใช่ความหนาของผนัง ภายใน `where` ชื่อเปล่าจะอ่านชุดที่องค์ประกอบที่เลือกส่วนใหญ่มี
- ปริมาณคือสิ่งที่ชุดปริมาณในไฟล์ระบุ (BimCraft เขียนให้กับสิ่งที่วาด) หน่วยมาจากการตั้งค่าหน่วยของไฟล์
- คำของช่อง (`count`, `sum`, `qty`, `by`, `cols`, `where`, `each`, `group` ฯลฯ) คงเป็นภาษาอังกฤษในทุกภาษา แม่แบบตัวอย่างเป็นภาษาอังกฤษ
- ข้อความจากโมเดลจะไม่กลายเป็นรูปแบบ ชื่อที่มี `*` หรือ `|` จะพิมพ์ตามที่เป็น
- เก็บแม่แบบที่คุณแก้ไขด้วย{{ui:เก็บในเบราว์เซอร์นี้}} (มีเฉพาะเบราว์เซอร์นี้) หรือ{{ui:ดาวน์โหลดแม่แบบ}}
- ข้อความ PDF ใช้ฟอนต์มาตรฐานของ PDF อักขระนอกข้อความยุโรปตะวันตกจะพิมพ์เป็น "?" และบรรทัดสถานะจะบอกจำนวน
- แม่แบบตามงานช่างอยู่ในไลบรารี (ชนิดแม่แบบเอกสาร) ใน เอกสารจากโมเดล เลือก จากไลบรารี… เลือกหนึ่งรายการ ข้อความและแท็กที่อ่านจะถูกนำเข้า แล้วแก้ไขตามต้องการ การเผยแพร่แม่แบบของคุณเองไปยังไลบรารีคืออัปโหลดแบบเดียวกับรายการอื่น ยังไม่รองรับการคำนวณนอกเหนือจากจำนวนและผลรวม
