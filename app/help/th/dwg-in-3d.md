## สิ่งที่จะทำ

ดูพื้นที่โมเดลของแบบเป็น 3D เส้นและโพลีไลน์อยู่ที่ความสูงจริงของมัน วัตถุที่มีความหนาจะตั้งขึ้นเป็นผนัง ส่วนหน้า 3D เมช และบล็อก 3D แสดงเป็นพื้นผิวที่คุณหมุนรอบได้ แผ่นยังคงเป็น 2D

## ขั้นตอน

1. เปิด DWG หรือ DXF ดู [ดูแบบ DWG หรือ DXF](topic:view-dwg) แบบจะเปิดเป็น 3D เว้นแต่ {{ui:Settings}} › BimCraft › **แบบเปิดใน** ระบุ {{ui:Model (2D)}}
2. จาก 2D คลิก {{ui:3D}} บนแถบเหนือแบบ หรือกด {{key:3}}
3. รอสักครู่ในครั้งแรก แถบสถานะจะแสดงข้อความ "กำลังสร้างแบบเป็น 3D…" แล้วจำนวนเส้นและหน้าที่แสดง
4. หมุน แพน และซูม (ดูตารางด้านล่าง)
5. คลิกมุมมองในแถบที่สอง: {{ui:Iso}}, {{ui:Top}}, {{ui:Bottom}}, {{ui:Front}}, {{ui:Back}}, {{ui:Left}} หรือ {{ui:Right}}
6. คลิก {{ui:Perspective}} เพื่อสลับระหว่างมุมมองทัศนียภาพและมุมมองขนาน
7. คลิก {{ui:Extents}} หรือกด {{key:F}} เพื่อดูทั้งแบบอีกครั้ง
8. คลิก {{ui:3D}} อีกครั้ง กด {{key:3}} หรือคลิก {{ui:Model}} หรือแท็บแผ่นเพื่อกลับไปยัง 2D

## สิ่งที่ควรเห็น

- พื้นที่โมเดลใน 3D โดยแกน Z ชี้ขึ้น ใช้สีของแบบเอง หน้าจะสว่างกว่าขอบเล็กน้อย
- เลเยอร์ที่คุณปิดใน {{ui:Layers}} จะหายไปจากมุมมอง 3D ด้วย
- ทางขวา: จำนวนเส้นและหน้า ขนาดของแบบในแกน X, Y และ Z รวมถึงส่วน **เฉพาะมุมมอง 2D** และ **ยังไม่ได้วาด**

## ตัดด้วยระนาบตัด

คลิก {{ui:Section}} บนแถบ 3D หรือกด {{key:X}} แถบด้านล่างทำงานเหมือนกับโมเดล IFC (ดู [ตัดโมเดล IFC ด้วยระนาบตัด](topic:section-plane)): ตัดจาก {{ui:Top}}, {{ui:Front}} หรือ {{ui:Side}} ลากหรือพิมพ์ระยะเยื้อง โดยใช้หน่วยของแบบเอง และ {{ui:Flip}} เพื่อเก็บอีกด้านไว้ สิ่งที่ระนาบตัดออกจะหยิบไม่ได้ การกลับไปยัง 2D จะเอาการตัดออก

## ดูคุณสมบัติของวัตถุ

คลิกวัตถุในมุมมอง 3D วัตถุจะเปลี่ยนเป็นสีที่หยิบ และ {{ui:Properties}} แสดงสิ่งที่ไฟล์ระบุเกี่ยวกับมัน ได้แก่ ประเภท เลเยอร์ สี ชนิดเส้น และ handle จากนั้นเป็นข้อมูลของมันเอง เช่น จุดเริ่ม จุดจบ และความยาวของเส้น จุดศูนย์กลางและรัศมีของวงกลม มุมของหน้า 3D หรือบล็อกที่ถูกอ้างอิง พร้อมบล็อก จุดแทรก มาตราส่วน การหมุน และค่าแอตทริบิวต์

- การอ้างอิงบล็อกจะถูกหยิบทั้งก้อน รวมถึงบล็อกที่ซ้อนอยู่ข้างใน
- การคลิกห่างจากเส้นไม่กี่พิกเซลจะหยิบเส้นนั้น
- กด {{key:Mod}} ค้างแล้วคลิกเพื่อหยิบวัตถุเพิ่ม หรือเอาออกหนึ่งชิ้น {{ui:Properties}} จะนับจำนวนแยกตามประเภท
- {{key:Esc}} หรือคลิกพื้นที่ว่างเพื่อล้างการเลือก
- วัตถุบนเลเยอร์ที่คุณปิดไว้จะหยิบไม่ได้

## การเคลื่อนที่

:::mouse
| เพื่อ | ทำอย่างนี้ |
|---|---|
| หมุน | ลากด้วยปุ่มกลาง หรือด้วยปุ่มซ้าย |
| แพน | ลากด้วยปุ่มขวา หรือกด {{key:Shift}} ค้างแล้วลาก |
| ซูม | เลื่อนล้อ ซูมไปยังสิ่งที่อยู่ใต้ตัวชี้ |
| ดูทั้งหมด | {{ui:Extents}} หรือ {{key:F}} |
| มองจากด้านข้าง | คลิกหน้า ขอบ หรือมุมของคิวบ์มุมมองที่มุมขวาล่าง |
:::

คิวบ์มุมมองสามารถเปลี่ยนเป็นไอคอนแกน หรือซ่อนได้ในการตั้งค่า ดู [การตั้งค่า BimCraft](topic:settings)

:::mac mouse
บนแทร็กแพด ใช้สองนิ้วปัดเพื่อหมุน กด {{key:Shift}} ค้างแล้วปัดเพื่อแพน และบีบเพื่อซูม
:::

ลากด้วยหนึ่งนิ้วเพื่อหมุน บีบด้วยสองนิ้วเพื่อซูม และขยับสองนิ้วไปด้วยกันเพื่อแพน
:::

## สิ่งที่วาดใน 3D

| ในแบบ | ใน 3D |
|---|---|
| เส้น โพลีไลน์ 3D | อยู่ที่ความสูงจริง |
| โพลีไลน์ วงกลม ส่วนโค้ง วงรี | อยู่บนระนาบของมันเอง ที่ระดับความสูงของมัน เอียงเมื่อแบบเอียง |
| ความหนาบนเส้น โพลีไลน์ วงกลม และส่วนโค้ง | เป็นผนังที่มีความสูงนั้น วงกลมปิดทั้งด้านบนและด้านล่าง |
| หน้า 3D เมชแบบ polyface เมชแบบ polygon | พื้นผิวมีเงาพร้อมขอบที่มองเห็น |
| บล็อก | วางไว้ หมุน และปรับขนาดใน 3D รวมบล็อกที่ซ้อนอยู่ด้วย |
| แฮตช์ | เส้นขอบของมัน |
| เส้น 2D ธรรมดา | แบนราบ ตรงตำแหน่งที่วาดไว้ |

## เฉพาะมุมมอง 2D

ข้อความ ข้อความหลายบรรทัด และแอตทริบิวต์ที่มองเห็นของบล็อกจะถูกวาดใน 3D บนระนาบของมันเองที่ความสูงของมัน และการคลิกที่มันจะหยิบมัน โพลีไลน์ที่กว้างจะแสดงความกว้างเป็นแถบแบน มัลติลีดเดอร์ รูปภาพ และลายแฮตช์จะถูกนับในส่วน **เฉพาะมุมมอง 2D**: ดูได้ที่แท็บ {{ui:Model}} หรือบนแผ่น

## ยังไม่ได้วาด

โซลิดและพื้นผิวที่เก็บเป็นวัตถุ ACIS (โซลิด 3D วัตถุ รีเจียน และพื้นผิว) และเมชแบบ subdivision จะถูกระบุภายใต้ **ยังไม่ได้วาด** พร้อมจำนวน สิ่งเหล่านี้จะถูกข้าม ไม่ได้คาดเดาขึ้นมา

## ข้อผิดพลาดที่พบบ่อย

- **ทุกอย่างดูแบนราบ** แบบเป็น 2D เส้นของมันไม่มีความสูง คลิก {{ui:Front}} เพื่อตรวจ แบบแบนจะแสดงเป็นเส้น
- **โมเดลโซลิดไม่แสดงอะไร** โซลิดที่สร้างด้วยโปรแกรมโมเดลโซลิดเป็นวัตถุ ACIS และจะแสดงภายใต้ **ยังไม่ได้วาด** ส่งออกโมเดลเป็น IFC หรือเป็นหน้า 3D จากโปรแกรมที่สร้างมัน
- **แบบเป็นกลุ่มเล็กๆ อยู่ตรงกลาง** มีบางอย่างที่ไกลออกไปในพื้นที่โมเดล เช่นสำเนาผังเก่า ทำให้ขอบเขตใหญ่ ซูมด้วยล้อไปยังจุดที่ต้องการดู
