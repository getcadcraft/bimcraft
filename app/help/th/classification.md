## สิ่งที่จะทำ

ใส่รหัสการจัดประเภทให้ผนัง พื้น หลังคา ประตู หน้าต่าง และทุกอย่างในโมเดล ได้สูงสุดสามระบบพร้อมกัน ได้แก่ Uniclass, OmniClass และ UniFormat งานสาขาอื่นและซอฟต์แวร์อื่นอาศัยรหัส ไม่ใช่ชื่อ ดังนั้นรหัสจะถูกบันทึกในไฟล์ IFC เป็นการอ้างอิงการจัดประเภทที่โปรแกรม BIM ใดก็อ่านได้

## กำหนดรหัสให้องค์ประกอบ

1. เลือกองค์ประกอบ (หนึ่งหรือหลายชิ้น) แล้วเปิด **คุณสมบัติ** เปิดส่วน {{ui:การจัดประเภท}}
2. พิมพ์รหัสในช่องของระบบและกด Enter เมื่อโหลดรายการรหัสไว้แล้ว พิมพ์บางส่วนของรหัสหรือคำไม่กี่คำ เช่น "curtain wall" แล้วเลือกจากรายการที่ตรงกัน ชื่อเรื่องของรหัสจะถูกกรอกให้
3. {{ui:ใช้กับ}} บอกว่ารหัสใช้กับอะไร ได้แก่ **องค์ประกอบนี้** หรือ **ประเภทของมัน (ทุกองค์ประกอบในประเภท)** รหัสบนประเภทผนังจะถูกอ่านโดยผนังทุกผนังของประเภทนั้น รวมถึงผนังที่วาดภายหลัง
4. {{ui:ล้าง}} เอารหัสออก

ใต้แต่ละรหัส ส่วนนี้จะบอกที่มา ได้แก่ ตั้งที่องค์ประกอบนี้ มาจากประเภท หรือค่าเริ่มต้นของโครงการสำหรับคลาส รหัสของตัวองค์ประกอบเองจะชนะรหัสของประเภทเสมอ และรหัสของประเภทชนะค่าเริ่มต้น เมื่อเลือกหลายองค์ประกอบ กล่องที่ขึ้นว่า "ต่างกัน" หมายความว่าไม่มีรหัสร่วมกัน การพิมพ์รหัสหนึ่งจะให้แก่ทุกชิ้น แต่ละการเปลี่ยนแปลงเป็นขั้นตอนเลิกทำหนึ่งขั้น

รหัสสามารถพิมพ์ได้เสมอ ไม่ว่าจะโหลดรายการหรือไม่ หากรหัสไม่เหมือนรหัสของระบบนั้น หรือไม่อยู่ในรายการที่โหลด จะมีคำแนะนำแจ้ง และเก็บรหัสตามที่พิมพ์

## เลือกระบบของโครงการ

เปิด **ข้อมูล** ในแถบโมเดล แล้วเลือก {{ui:การจัดประเภท}} (หรือ {{ui:การจำแนกประเภทโครงการ…}} ในส่วนคุณสมบัติ)

- ติ๊กระบบที่โครงการนี้ใช้ คุณสมบัติจะแสดงเฉพาะระบบเหล่านั้น
- **Uniclass**: ตาราง Elements/ functions (EF), Systems (Ss) และ Products (Pr) มาพร้อมแอป ตารางเหล่านี้เป็นลิขสิทธิ์ของ NBS อนุญาตภายใต้ Creative Commons Attribution-NoDerivatives 4.0 และส่งต่อโดยไม่เปลี่ยนแปลง กล่องโต้ตอบแสดงฉบับของแต่ละตารางและวันที่ที่อ่าน ตารางเหล่านี้ไม่ใช่ฉบับล่าสุด ผู้เผยแพร่ออกฉบับใหม่ทุกไตรมาสบนเว็บไซต์ของตนเอง
- **OmniClass** และ **UniFormat**: ไม่มีรายการรหัสมาพร้อมแอป เพราะผู้เผยแพร่ไม่อนุญาตให้ส่งต่อตารางโดยไม่มีใบอนุญาต พิมพ์รหัสใดก็ได้ หรือโหลดตารางที่ได้รับอนุญาตของสำนักงาน
- {{ui:โหลดตาราง (CSV)…}} อ่านตารางของสำนักงานจากไฟล์ CSV ที่มีคอลัมน์รหัสและคอลัมน์ชื่อ (แถวหัวคอลัมน์ที่ชื่อ Code, Number หรือ Identifier และ Title, Name หรือ Description จะถูกหาเองอัตโนมัติ หากไม่มี จะใช้สองคอลัมน์แรก) ตารางจะอยู่ในเบราว์เซอร์นี้และไม่ถูกใส่ในไฟล์โครงการ เฉพาะรหัสที่กำหนดเท่านั้นที่บันทึกในไฟล์ โหลดตาราง Uniclass ฉบับใหม่กว่าได้ด้วยวิธีเดียวกัน
- {{ui:กำหนดรหัสเริ่มต้นให้องค์ประกอบตามคลาส}} ให้รหัส Uniclass เริ่มต้นจากตาราง Elements/ functions แก่ทุกผนัง พื้น หลังคา ประตู หน้าต่าง บันได ทางลาด เสา คาน และเฟอร์นิเจอร์ ที่ยังไม่มีรหัสของตัวเอง องค์ประกอบที่วาดภายหลังจะได้รับรหัสนี้ด้วย
- {{ui:แสดงรหัสเป็นคอลัมน์ในตาราง}} เพิ่มหนึ่งคอลัมน์ต่อระบบในตารางประตู ตารางหน้าต่าง ตารางผนังตามประเภท และตารางห้อง รวมถึงไฟล์ CSV ของตารางเหล่านั้น แถวที่มีหลายองค์ประกอบจะแสดง "ต่างกัน" เมื่อรหัสไม่เหมือนกัน

## ข้อควรทราบ

- รหัสเริ่มต้นเป็นตัวเลือกเริ่มต้นของ CadCraft เอง ไม่ใช่ของผู้เผยแพร่ และยังไม่ได้รับการตรวจโดยผู้ปฏิบัติงาน ควรตรวจกับมาตรฐานของโครงการ
- ในไฟล์ ค่าเริ่มต้นคือการจัดประเภทจริงที่มีชื่อความสัมพันธ์ว่า "CadCraft default" และจะหายไปทันทีที่องค์ประกอบหรือประเภทได้รับรหัสของตัวเอง
- รหัสที่ไฟล์นำเข้ามีอยู่แล้วจะถูกอ่านและแสดง ไม่ว่าอีกโปรแกรมจะสะกดชื่อระบบอย่างไร รหัสของระบบอื่น (ของสำนักงาน) จะถูกแสดงรายการและปล่อยไว้ตามเดิม
- รหัสจะถูกอ่านกลับเมื่อเปิดไฟล์อีกครั้ง ทั้งที่นี่หรือในโปรแกรมอื่น รหัสจะถูกนำไปใส่ในการส่งออก IFC5 alpha (IFCX) เมื่อเปิดตัวเลือกทดลองนั้น ยกเว้นรหัสที่ตั้งบนหลังคา
- ยังไม่ได้สร้าง: ต้นไม้สำหรับเรียกดูตารางทีละระดับ รหัสบนระดับและห้องเป็นค่าเริ่มต้นของโครงการ และการตรวจรหัสกับฉบับที่ระบุในไฟล์
