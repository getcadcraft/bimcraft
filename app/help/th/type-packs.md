## สิ่งที่จะทำ

นำประเภทผนังจากโครงการหนึ่งไปอีกโครงการ หรือส่งให้ผู้ที่ทำงานในโปรแกรมอื่น ชุดประเภทเก็บประเภทผนังแต่ละอันพร้อมชั้น ความหนา วัสดุ แกนกลาง ช่องว่าง ลำดับความสำคัญของชั้น ระดับการพัฒนา ข้อมูล takeoff และรหัสการจัดประเภท รวมถึงแฟมิลีที่เพิ่มเข้ามา เป็นไฟล์เปิด ได้แก่ ข้อความ JSON ธรรมดาที่ใครก็อ่านได้ หรือไฟล์ IFC ไม่มีอะไรในไฟล์ที่ผูกกับบริษัท ประเทศ หรือบัญชีใดๆ

## บันทึกประเภทจากโครงการ

1. เปิด **ข้อมูล** บนแถบโมเดล แล้วเลือก {{ui:Type packs}}
2. ภายใต้ {{ui:Save types from this project}} ติ๊กประเภทผนังที่จะใส่ ประเภทของโครงการเองจะถูกติ๊กไว้ ประเภทเริ่มต้นเพิ่มได้และจะเข้าไปเป็นสำเนา ติ๊กแฟมิลีหากต้องการใส่ด้วย
3. พิมพ์ {{ui:Pack name}}
4. {{ui:Save as a pack (.json)}} ดาวน์โหลดไฟล์ `.cctypes.json` และ {{ui:Save as IFC (.ifc)}} ดาวน์โหลดไฟล์ IFC ที่มีเฉพาะประเภท: ประเภทผนังแต่ละอันเป็น IfcWallType พร้อมชุดชั้นวัสดุ วัสดุ และการจัดประเภท สำหรับโปรแกรม BIM โปรแกรมใดก็ได้

## เพิ่มประเภทเข้าโครงการ

1. ในกล่องโต้ตอบเดียวกัน เลือก {{ui:Open a pack or an IFC file…}} แล้วเลือกไฟล์ pack `.json` หรือไฟล์ `.ifc`
2. กล่องโต้ตอบจะแสดงสิ่งที่ไฟล์มี: ประเภทผนังแต่ละอันพร้อมความหนา จำนวนชั้นและรหัส วัสดุ และแฟมิลี
3. เลือกว่าจะทำอย่างไรกับ {{ui:A type this project already has}}: **Keep the project's** › **เก็บของโครงการ**, **Add the pack's as a copy** › **เพิ่มของชุดเป็นสำเนา** (จะได้ชื่อใหม่ลงท้ายด้วย "(2)") หรือ **Replace it (only when no wall uses it)** › **แทนที่ (เฉพาะเมื่อไม่มีผนังใช้)**
4. {{ui:Add to the project}} กล่องโต้ตอบจะแสดงสิ่งที่ถูกเพิ่ม คัดลอก แทนที่ หรือเก็บไว้ เป็นหนึ่งขั้นเลิกทำ

ประเภทใหม่จะปรากฏในรายการประเภทของเครื่องมือผนังทันที

## ประเภทพื้น หลังคา และเพดาน

รายการประเภทที่จะบันทึกยังมีประเภทพื้น หลังคา และเพดานของโครงการ รวมทั้งประเภทเริ่มต้นของสิ่งเหล่านั้น (มีเครื่องหมาย Floor, Roof, Ceiling) ชุดประเภทรองรับได้ครบสี่ชนิด และแต่ละประเภทระบุคลาส IFC ของตน (IfcWallType, IfcSlabType, IfcCoveringType) ประเภทพื้น หลังคา หรือเพดานที่องค์ประกอบใช้อยู่จะไม่ถูกแทนที่จากชุด ให้เปลี่ยนในตัวแก้ไขประเภท

## ประเภทเดียวเป็นรายการในไลบรารี

ติ๊กเลือกประเภทเดียวแล้วเลือก **Save as a Library item…** › **บันทึกเป็นรายการในไลบรารี…** จะบันทึกไฟล์ `.cctype.json` ซึ่งเป็นรายการในไลบรารีชนิดประเภทที่มีประเภทนั้นเพียงอันเดียว (ชั้น วัสดุ LOD และรหัสการจัดประเภท) อัปโหลดในไลบรารีเพื่อแชร์ **Open a pack or an IFC file** › **เปิดชุดหรือไฟล์ IFC** ก็อ่านรายการนี้ได้ และเพิ่มประเภทเข้าโครงการเหมือนชุด

## ควรทราบ

- ไฟล์ IFC จากโปรแกรมอื่นเปิดที่นี่ได้เช่นกัน ประเภทผนังแต่ละอันที่มีชั้นวัสดุจะถูกอ่าน ชื่อ วัสดุและความหนาของชั้น และช่องว่างใดๆ เป็นของไฟล์นั้น ส่วนว่าชั้นใดเป็นแกนกลาง และแต่ละชั้นทำหน้าที่อะไร (ผิวเคลือบ โครงสร้าง ฉนวน) จะเป็นการคาดเดา ประเภทจะมี **(guessed)** กำกับ และควรตรวจในตัวแก้ไขประเภทผนัง ประเภทผนังที่ไม่มีชั้นจะถูกละไว้และระบุชื่อ
- วัสดุที่โครงการมีอยู่แล้วจะคงไว้ วัสดุใหม่ที่ชื่อซ้ำจะได้ "(pack)" ต่อท้ายชื่อ
- ประเภทที่ผนังใช้อยู่จะไม่ถูกแทนที่จากชุดเลย ให้เปลี่ยนในตัวแก้ไขประเภทผนัง ซึ่งจะย้ายผนังไปอย่างถูกต้อง
- รหัสที่ตั้งบนผนังหนึ่งผืนจะไม่ไปกับชุด รหัสนั้นเป็นของผนังนั้น ส่วนรหัสที่ตั้งบนประเภทจะไป
- ไฟล์ที่มีฟิลด์ซึ่งรูปแบบไม่มี ชั้นที่วัสดุหายไป หรือสิ่งที่ไม่ใช่ข้อความธรรมดา จะถูกปฏิเสธ และข้อความจะบอกว่าอยู่ที่ไหนและเพราะอะไร
- ยังไม่ได้สร้าง: ประเภทพื้น หลังคา และเพดาน (ในเวอร์ชันนี้ไม่มีประเภทเหล่านี้: แต่ละอันมีความหนาของตนเอง) ประเภทประตูและหน้าต่างนอกเหนือจากแฟมิลี และแฮตช์หรือสีจากไฟล์ของโปรแกรมอื่น
