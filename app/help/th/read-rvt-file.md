## สิ่งที่คุณจะทำ

ค้นหาว่ามีอะไรอยู่ในไฟล์โครงการหรือไฟล์แฟมิลีโดยไม่ต้องเปิดใน Revit: รุ่นใดเป็นผู้บันทึก ไฟล์เป็นแบบทำงานร่วมกันหรือไม่ ข้อมูลโครงการ และสิ่งที่ไฟล์เชื่อมโยงไปถึง มีประโยชน์เมื่อไฟล์มาจากคนอื่นและคุณต้องรู้ว่าควรเปิดในรุ่นใด

## ขั้นตอน

1. คลิก {{ui:เลือกไฟล์}}
2. เลือกไฟล์ `.rvt`, `.rfa`, `.rte` หรือ `.rft`
3. รอสักครู่ บรรทัดสถานะจะขึ้นว่า "กำลังอ่านไฟล์…" แล้วตามด้วย "เปิด *ชื่อไฟล์* แล้ว"
4. ดูด้านบนของการ์ด: ภาพตัวอย่างที่บันทึกในไฟล์ ชนิดของไฟล์และรุ่นที่บันทึก และชื่อโครงการ
5. เลื่อนลงเพื่ออ่านส่วนต่างๆ ของการ์ด

## สิ่งที่คุณควรเห็น

การ์ดตรงกลาง พร้อมส่วนเหล่านี้เมื่อไฟล์มีข้อมูล:

| ส่วน | สิ่งที่บอกคุณ |
|---|---|
| File | ชื่อไฟล์ ขนาด ชนิด (โครงการ เทมเพลตโครงการ แฟมิลี หรือเทมเพลตแฟมิลี) รุ่นและบิลด์ที่บันทึก การทำงานร่วมกัน เส้นทางของโมเดลกลาง ตำแหน่งที่บันทึกล่าสุด ผู้บันทึก โลแคลและ GUID ของเอกสาร |
| Project information | ช่องของโครงการเอง เช่น ชื่อ หมายเลข ลูกค้า ที่อยู่ และสถานะ ช่องที่ยังเป็นค่าเริ่มต้นของโครงการใหม่จะไม่แสดง |
| Family, Family: … | สำหรับแฟมิลี: ชื่อ หมวดหมู่ รุ่น การอัปเดตล่าสุด และพารามิเตอร์ แยกทีละกลุ่ม |
| Linked and referenced files | ทุกโมเดลที่เชื่อมโยง ลิงก์ CAD รูปภาพ และตารางคีย์โน้ตที่ไฟล์ชี้ไปถึง พร้อมเส้นทางที่บันทึกไว้ |

ทางด้านซ้าย พาเนล {{ui:ไฟล์}} แสดงข้อมูลสำคัญซ้ำและเพิ่ม **อ่านแล้ว**: BimCraft อ่านไฟล์ไปเท่าไร มักประมาณ 40 KB จากไฟล์ที่มีขนาดหลาย MB ทางด้านขวา พาเนล {{ui:คุณสมบัติ}} แจ้งว่าคุณสมบัติขององค์ประกอบต้องใช้โมเดล 3D

## ทำไมจึงไม่มี 3D

โมเดล 3D และองค์ประกอบภายในไฟล์โครงการถูกเก็บในรูปแบบที่ไม่มีเอกสาร BimCraft อ่านเฉพาะส่วนของไฟล์ที่มีเอกสารหรืออ่านได้อย่างชัดเจน ได้แก่ ข้อมูลไฟล์ ข้อมูลโครงการ ข้อมูลแฟมิลี รายการลิงก์ และภาพตัวอย่าง มันไม่เดาส่วนที่เหลือ หากต้องการดูโมเดลใน 3D และอ่านคุณสมบัติขององค์ประกอบ ให้ส่งออก IFC จากโปรแกรมที่สร้างไฟล์ ดู [ดึงไฟล์โครงการเข้า 3D ผ่าน IFC](topic:rvt-to-ifc)

## ข้อผิดพลาดที่พบบ่อย

- **คาดว่าจะเห็น 3D** ดูด้านบน
- **ลิงก์แสดงเฉพาะเส้นทางที่บันทึกไว้** ไฟล์ที่เปิดแยกเดี่ยวไม่สามารถตรวจสอบว่าลิงก์มีอยู่หรือไม่ ให้เปิดโฟลเดอร์ที่ไฟล์อยู่แทน BimCraft จะทำเครื่องหมายแต่ละลิงก์ว่าพบหรือไม่พบ: [เปิดโฟลเดอร์โครงการทั้งหมด](topic:open-project-folder)
- **"This file is incomplete…"** ให้แปลว่า **"ไฟล์นี้ไม่สมบูรณ์…"** ไฟล์ถูกตัดระหว่างการคัดลอก อัปโหลด หรือซิงก์ ไฟล์ในไดรฟ์คลาวด์ที่ยังเป็น "online only" ก็เกิดกรณีนี้เช่นกัน BimCraft ยังเปิดและแสดงเฉพาะส่วนที่กู้คืนได้: แถบสีเหลืองอำพันที่ด้านบนของการ์ด ส่วน **กู้คืนจากไฟล์นี้** ที่แสดงส่วนที่ทุกไบต์อยู่ในไฟล์ และ **ไม่มีในไฟล์** สำหรับส่วนที่เหลือ จะไม่มีการเติมค่าให้ส่วนที่หายไป ดังนั้นรุ่น ภาพตัวอย่าง หรือข้อมูลโครงการอาจหายไปเมื่อถูกเก็บไว้หลังจุดที่ถูกตัด หากแม้แต่รายการเนื้อหาของไฟล์ยังถูกตัด จะไม่สามารถเปิดอะไรได้ ให้คัดลอกต้นฉบับใหม่แล้วเปิดอีกครั้งเพื่อให้ได้ไฟล์เต็ม
- **"ไม่มีภาพตัวอย่างในไฟล์นี้"** ไฟล์บางไฟล์ถูกบันทึกโดยไม่มีภาพตัวอย่าง ซึ่งเป็นเรื่องปกติ
- **เปิดไฟล์สำรองโดยไม่ตั้งใจ** ไฟล์ที่ชื่อเช่น `Tower.0004.rvt` คือไฟล์สำรองที่มีหมายเลข การเปิดโฟลเดอร์จะจัดกลุ่มไฟล์เหล่านี้ไว้กับโมเดลของมัน
