นี่คือสิ่งที่เปลี่ยนแปลงใน BimCraft 0.9 เมื่อเทียบกับ 0.8.1 ประเด็นหลักสองเรื่องคือเครื่องมือผนังที่ใช้งานได้จริง และมุมมองที่ทำงานตามที่ผู้ที่มาจากโปรแกรม BIM ขนาดใหญ่คาดหวัง นอกจากนั้นมีการส่งออก Collada ผู้ช่วยที่เพิ่มอุปกรณ์ไฟฟ้าได้ Scan to BIM และการวิเคราะห์แรงลม แผ่นดินไหว และไฟไนต์เอลิเมนต์ในแท็บ {{ui:Analysis}}

## ใหม่

### ผนัง

- **วาดรูปร่างทั้งชิ้น.** ใน {{ui:Draw}} เปิด {{ui:Shapes}} (หรือเลือกรูปร่างในรายการ Shape ของแถวผนัง) เพื่อวาดสี่เหลี่ยมผืนผ้า สี่เหลี่ยมผืนผ้าที่หมุนแล้ว รูปหลายเหลี่ยม 3 ถึง 64 ด้าน ส่วนโค้งจากจุดศูนย์กลาง ส่วนโค้งสัมผัส ผนังบนเส้นที่เลือก หรือผนังรอบพื้นที่ปิดที่คลิกภายใน สี่เหลี่ยมผืนผ้าคือผนังสี่ด้านที่ต่อกันที่มุมทั้งสี่ และใช้หนึ่งขั้นตอนเลิกทำ ดู [รูปร่างผนัง แบ่ง ออฟเซ็ต ยืด และล็อก](topic:wall-tools)
- **ตั้งค่าก่อนวาด เปลี่ยนแปลงภายหลัง.** แถวผนังมี {{ui:Offset}} และ {{ui:Join}} (ยกเลิกการเลือกเพื่อวาดผนังที่ไม่ต่อกับผนังอื่น) หลังจากนั้นใช้ {{ui:Offset}} {{ui:Box stretch}} และ {{ui:Align and lock}} กับผนังที่วาดแล้ว ผนังที่ถูกย้ายหรือยืดยังคงมีประตู หน้าต่าง และไดเมนชันของมัน ทุกสูตรใช้หนึ่งขั้นตอนเลิกทำ
- **ตัดผนัง.** {{ui:Split}} {{ui:Gap}} {{ui:Free ends}} {{ui:Delete segment}} และ {{ui:Rejoin}} ตัดผนังด้วยการคลิกหรือตรงจุดที่ผนังอื่นตัดผ่าน การตัดผ่านประตูจะไม่ถูกดำเนินการ ดู [รูปร่างผนัง แบ่ง ออฟเซ็ต ยืด และล็อก](topic:wall-tools)
- **ล็อกผนังกับเส้นกริด.** เลือกผนังที่อยู่ตามเส้นกริดแล้วเลือก {{ui:Lock to grid}} ใน {{ui:Properties}} เมื่อเปิดเครื่องมือกริด พิมพ์ระยะใน {{ui:Move by}} สำหรับเส้นที่เลือก แล้วผนังที่ล็อกจะเคลื่อนตามในหนึ่งขั้นตอนเลิกทำ
- **กำหนดรูปร่างผนังหนึ่งชิ้น.** ใน {{ui:Properties}} ของผนังหนึ่งชิ้น คุณสามารถผูกด้านบนหรือด้านล่างของผนังกับหลังคา พื้น หรือเพดาน แก้ไขเส้นรอบรูปด้านความสูง เอียงผนัง หรือเจาะช่องเปิดในผนังโดยไม่มีประตูหรือหน้าต่าง ดู [รูปร่างผนัง](topic:wall-shape)
- **ความยาวบอกว่าปลายใดคงที่.** {{ui:Grow from}} กำหนดว่าจุดเริ่ม จุดสิ้นสุด หรือจุดศูนย์กลางจะคงที่เมื่อเปลี่ยนความยาว
- **ความยาวและไดเมนชันบนผังตรงกัน.** {{ui:Measure from}} (เส้นกึ่งกลาง ผิวด้านใน หรือผิวด้านนอก) ควบคุมทั้งช่องความยาวและไดเมนชันผนังบนผัง เริ่มต้นที่เส้นกึ่งกลาง ดังนั้นไดเมนชันผนังบนผังจะอ่านค่าจากเส้นกึ่งกลาง จากเดิมที่อ่านจากผิวด้านนอก เปลี่ยนได้ในแถวผนัง ใน {{ui:Properties}} หรือใน {{ui:Settings}} › BimCraft › {{ui:Walls}}

### ชั้น กริด และการวัด

- **เพิ่มชั้นด้านล่าง.** {{ui:Add a level below}} ในพาเนล {{ui:Levels}} เพิ่มชั้นใต้ชั้นที่ต่ำที่สุด โดยมีความสูงเท่ากับชั้นนั้น ที่ระดับความสูงติดลบ (Level -1, Level -2) ไม่มีสิ่งอื่นเคลื่อนที่ {{ui:Add levels…}} รับค่าความสูงติดลบได้แล้ว การพิมพ์ LEVEL, LEVELS, STOREY หรือ STOREYS ในบรรทัดคำสั่งจะเปิด {{ui:Add levels…}} และมีปุ่ม {{ui:Levels}} ในเมนูและแท็บริบบอน ดู [ไซต์ อาคาร และชั้น](topic:site-building-and-levels)
- **ไดเมนชันกริดบนผัง.** เมื่อเปิดเครื่องมือ {{ui:Grid}} เลือก {{ui:Dimensions}} เพื่อวาดระยะห่างระหว่างเส้นข้างเคียงและขนาดรวมเลยวงกลมปลายเส้นออกไปบนผังของทุกชั้น ดู [ไดเมนชันกริด](topic:grid-dimensions)
- **วัดบนผัง.** {{ui:Measure}} ในกลุ่ม {{ui:Draw}} ให้ระยะทางพร้อมผลต่างแกน X และ Y ระหว่างสองการคลิก ไม่มีการบันทึกลงในโมเดล ดู [วัดบนผัง](topic:measure-on-the-plan)
- **เปลี่ยนคอลัมน์หลายต้นพร้อมกัน.** เลือกคอลัมน์ร่วมกับผนัง รายการที่เลือกจะแสดงแต่ละประเภทพร้อม {{ui:Keep only these}} การคลิกหนึ่งครั้งจะเก็บคอลัมน์ไว้และแสดงช่องที่ใช้ร่วมกัน
- **หนึ่งหน่วยการแสดงผลทุกที่.** พิกัด การวัด ภาคตัด มาตราส่วนแผ่น แท็บโหลดและผลลัพธ์ของเฟรม และข้อความใน Problems จะใช้หน่วยที่คุณเลือก การส่งออกยังคงเป็น SI

### มุมมอง แผ่น และการพิมพ์

- **รูปแบบการทำงาน.** {{ui:Settings}} › BimCraft › {{ui:Working style}} เลือกระหว่างให้แต่ละมุมมองมีคำอธิบายประกอบและตารางปากกาของตัวเอง หรือใช้ร่วมกัน ดู [รูปแบบการทำงาน มุมมองที่ทำสำเนา ปากกาบนกระดาษ รายงานเป็น และเทมเพลต](topic:working-style)
- **ทำสำเนามุมมอง.** ผัง ผังเพดาน ค่าเรียก ด้านและภาคตัดสามารถทำสำเนาเป็น {{ui:Own copy}} หรือ {{ui:Linked}} ได้ {{ui:Make own copy}} ทำให้มุมมองที่เชื่อมโยงเป็นอิสระ ดู [รูปแบบการทำงาน มุมมองที่ทำสำเนา ปากกาบนกระดาษ รายงานเป็น และเทมเพลต](topic:working-style)
- **พิมพ์ตามที่แสดง หรือผ่านตารางปากกา.** การแทนที่ปากกาถูกเก็บไว้ใน IFC พร้อมมุมมอง และแผ่นกับ PDF จะวาดตามที่หน้าจอแสดง หัวข้อเดียวกันครอบคลุมตารางปากกาด้วย
- **รายงานเป็น.** {{ui:Report as}} ใน {{ui:Properties}} เขียนพื้นที่ที่วาดเป็นถนน ผนังเป็นแผง หรือหลังคาเป็นทางลาด ลงใน IFC ตามคลาสที่คุณเลือก และนับแบบนั้นในตารางรายการ Quantities, Find, Color by และ Problems
- **แก้ไขในด้านและภาคตัด.** วาดและย้ายผนัง ช่องเปิด ชั้น ไดเมนชัน และหมายเหตุได้ตรงในด้านหรือภาคตัด พร้อมขนาดแผ่นและกรอบชื่อเรื่องของคุณเอง ดู [แก้ไขในด้านและภาคตัด](topic:edit-in-elevations)
- **แผ่น.** แต่ละแผ่นเป็นแนวนอนหรือแนวตั้งได้ กล่อง {{ui:Type a scale}} อยู่ข้างรายการมาตราส่วนในแต่ละมุมมองที่วางแล้ว (1:64, 2:1, 1/4" = 1'-0") คุณลากแบบที่วางแล้วหรือขยับด้วยปุ่มลูกศรได้ และ {{ui:Formats…}} › {{ui:Import SVG…}} เปลี่ยนการออกแบบแผ่นของคุณเองเป็นกรอบชื่อเรื่องพร้อมช่องที่พิมพ์ได้ในแต่ละแผ่น
- **เครดิตไลบรารีบนแผ่น.** ชุดแบบที่มีรายการ {{ui:Library}} จะได้ตารางเครดิตไลบรารีที่วางบนแผ่นใดก็ได้ ดู [เครดิตไลบรารี](topic:library-credits)

### ไลบรารี: การวาง

- **การวางตามมุมมอง.** ในมุมมองผัง {{ui:Library}} แสดง {{ui:Place in plan}} ในมุมมอง 3D แสดง {{ui:Place in model}} และใน Split แสดงปุ่มแยกที่มี {{ui:Place in plan}} เป็นการกระทำหลัก ทั้งสองวิธีเขียนองค์ประกอบ IFC เดียวกัน คุณยังลางานการ์ดไลบรารีไปวางบนผังหรือมุมมอง 3D ได้ด้วย เมื่อใช้ปากกาหรือนิ้ว ให้กดค้างแล้วลาก ดู [วางจากไลบรารี](topic:place-from-library)

### ไฟล์และผู้ช่วย

- **Collada และ Google Earth.** {{ui:Collada}} บนแถบเครื่องมือ (เมนู File ในรูปแบบเมนู) เขียนไฟล์ .dae หรือไฟล์ .kmz ที่วางตามตำแหน่งของโมเดลบนแผนที่ ดู [ส่งออกโมเดลเป็น Collada หรือสำหรับ Google Earth](topic:collada)
- **ผู้ช่วยเพิ่มอุปกรณ์ไฟฟ้าได้.** ผู้ช่วยที่เชื่อมต่อของคุณมีเครื่องมือใหม่สำหรับเพิ่ม แสดงรายการ เปลี่ยน และลบอุปกรณ์ และตั้งค่าโคมไฟ ผู้ช่วยปิดอยู่จนกว่าคุณจะเปิดใน {{ui:Settings}} ดู [ให้ผู้ช่วย AI ทำงานกับโมเดลของคุณ](topic:assistants)
- **Scan to BIM (ส่วนเสริม).** ปิดเป็นค่าเริ่มต้น และต้องใช้ส่วนเสริม Point clouds เสนอพื้น ผนัง ประตู และหน้าต่างจากการสแกน พร้อมค่าเบี่ยงเบนที่วัดได้ของแต่ละรายการ การยอมรับใช้หนึ่งขั้นตอนเลิกทำ

### การวิเคราะห์

- **ข้อมูลไซต์ลมและแผ่นดินไหว.** ในแท็บ {{ui:Analysis}}: แรงลมตาม ASCE 7-10 หรือ 7-16 สำหรับอาคารปิดแข็งแรง พร้อมแรงบนทุกชั้นเป็นกรณีโหลด และข้อมูลไซต์แผ่นดินไหวพร้อมการค้นหา USGS และสเปกตรัมการออกแบบ
- **การตามผลเชิงโครงสร้างและไฟไนต์เอลิเมนต์.** การตรวจสอบคอนกรีตตาม ACI 318-19 แรงด้านข้างเทียบเท่าตาม ASCE 7-22 การเคลื่อนตัวด้านข้างของชั้น พื้นและผนังเป็นแผ่น และการรวมโหลดจาก ASCE 7 และ EN 1990 เอนจินไฟไนต์เอลิเมนต์ของเราเองรองรับเปลือก เตตระฮีดรอน และการวิเคราะห์โหมด ดู [ตรวจสอบชิ้นส่วนคอนกรีตและสร้างแรงแผ่นดินไหว](topic:concrete-and-seismic) และ [การวิเคราะห์โครงสร้าง](topic:frame-analysis)

### ส่วนเสริมอื่นและเอกสาร

- **แสงสว่างภายใน (ส่วนเสริม).** วางโคมไฟและเขียนค่าลักซ์เป็นตัวเลขลงในผังของแต่ละชั้น พร้อมการประมาณแสงจ้าและรายงานที่พิมพ์ได้
- **พาเนลเอกสาร.** {{ui:File}} › {{ui:Documents…}} มีการยืมและคืนพร้อมไฟล์ล็อก ตัวอักษรแก้ไข สถานะการเผยแพร่ และประวัติ
- **ภูมิภาคและเหล็ก.** ชุดแบบและข้อกำหนดอาคารของแอฟริกาใต้ในส่วนเสริม Regulations และขนาดเหล็กของสหราชอาณาจักร 976 รายการในตารางหน้าตัดร่วม
- **ส่วนเสริมการพิมพ์เรซินฟรี.** ตัวตัดแบ่งชั้น ตัวรองรับและแพลต การทดสอบการเปิดรับแสง และรูปแบบไฟล์ GOO, SL1, Chitubox และ Anycubic ทั้งหมดปิดเป็นค่าเริ่มต้น

## ในทุกแอป

- เมื่อวางเมาส์บนปุ่มหรือตัวควบคุม จะแสดงคำแนะนำแบบ Bootstrap
- เคล็ดลับเริ่มต้นบนพื้นที่วาดที่ว่างมีปุ่มปิด BimCraft จำไว้ว่าถูกปิดแล้ว
- แถบแท็บของพาเนลที่ไม่พอดีจะเลื่อนได้แทนที่จะถูกตัด
- เมื่อเปิดเอกสาร แท็บเบราว์เซอร์จะแสดง "<document> - BimCraft | CadCraft"
- ใน {{ui:Settings}} › {{ui:General}} › {{ui:Layout}} เลย์เอาต์เป็นรายการแบบดรอปดาวน์ที่มีตัวเลือกสองบรรทัด
- รายการภาษาใน {{ui:Settings}} มีภาษามากกว่าใน 0.8 ภาษาอื่นนอกจากภาษาอังกฤษเป็นฉบับร่างจากเครื่อง

## แก้ไขแล้ว

- **การย้ายทำงานบนบันได** และบนทางลาด ราวกั้น ระนาบหลังคา อุปกรณ์ที่วางอิสระ รูปภาพ และเส้นทาง
- **การลากผนังไม่ทำให้ห้องเบี้ยวอีกต่อไป.** ที่จับกลางจะย้ายผนังให้ตั้งฉากกับตัวมันเอง และมุมจะเลื่อนไปตามผนังที่ต่อกัน กด {{key:Mod}} ค้างเพื่อย้ายอิสระแบบเดิม {{ui:Square up}} คืนมุม 90 องศา
- **การเปลี่ยนความหนาหรือประเภทที่จุดต่อ** จะคงมุมให้ปิดที่รูป L รูป T จุดผนังสามด้าน และติดกับผนังโค้ง
- **การย้ายหรือคัดลอกกลุ่มห้อง** จะคงผนังที่ต่อกันนอกกลุ่มให้ต่อกันอยู่
- **Redo คงเอกลักษณ์ของไดเมนชันผนัง**
- **การเลือกผนังเมื่อปิด Draw** ไม่ทำให้เกิดข้อผิดพลาดใน Properties อีกต่อไป
- **Render ถอยไปใช้ WebGL** เมื่อ GPU เริ่มทำงานไม่ได้ แทนที่จะหยุด
- **การตรวจ EnergyPlus** เปิดใช้งานได้อีกครั้ง
- **Documents เปิดเป็นกล่องโต้ตอบตรงกลาง** {{key:Esc}} ปุ่ม X หรือการคลิกหน้าที่มืดจะปิดกล่องนี้
- **ปุ่ม {{ui:Plan}} {{ui:Split}} และ {{ui:3D}} แสดง** ทันทีที่เปิดโมเดล ไม่ใช่หลังจากเปิด Draw เพียงครั้งเดียว

## ข้อจำกัดที่แท้จริง

- ยังไม่มีการพิมพ์บนฮาร์ดแวร์จริง รองรับการพิมพ์เรซินยังใหม่และยังไม่ได้พิสูจน์
- ผลลัพธ์ลม แผ่นดินไหว คอนกรีต และไฟไนต์เอลิเมนต์เป็นเครื่องมือตรวจสอบสำหรับวิศวกร ตรวจกับสูตรปิดแล้ว ไม่ได้ตรวจกับอาคารจริง
- Scan to BIM ทดสอบกับอาคารสังเคราะห์ ไม่ใช่การสแกนจริง และพบเฉพาะห้องที่เป็นเส้นตรง
- Collada ยังไม่ได้เปิดใน Blender หรือ Google Earth ที่นี่
- การประมาณแสงตรวจกับการติดตามของเราเอง ไม่ได้ตรวจกับโปรแกรมแสงสว่างอื่น
- ตัวเลขของแอฟริกาใต้ยังไม่ได้ตรวจสอบ
- รูปแบบการต่อผนัง (butt, mitre, square off) และลำดับความสำคัญของเลเยอร์ยังไม่ได้สร้าง มุมจะเป็นแบบ mitre
- ภาษาอื่นนอกจากภาษาอังกฤษเป็นฉบับร่างจากเครื่อง

สิ่งอื่นทั้งหมดอยู่ใน [ยังไม่ได้สร้างอะไร](topic:not-built-yet) การเปลี่ยนแปลงก่อนหน้าอยู่ในบันทึก 0.8 และ 0.8.1 ด้านล่างของหน้านี้

## ก่อนหน้า: 0.8 และ 0.8.1

นี่คือสิ่งที่เปลี่ยนแปลงใน BimCraft 0.8 (2026-11-01) และ 0.8.1 (2026-11-02) เมื่อเทียบกับ 0.7 BimCraft ตอบคำถามเกี่ยวกับอาคารและทดสอบได้แล้ว ทั้งเรื่องคน เสียง น้ำ ลม และแผ่นดินไหว และวาดได้ด้วยเครื่องมือมากขึ้น 0.8.1 เป็นรุ่นแก้ไข

### ใหม่

**ทดสอบอาคาร**

- **คนในอาคาร.** ส่วน {{ui:People in the building}} ของพาเนลซ้ายพาคนเดินผ่านห้อง ประตู และบันไดของคุณในการอพยพหรือการมาถึงตามปกติของวัน คุณจะเห็นคิวตรงจุดที่อาคารแคบลง ทางเดินที่ไกลที่สุดไปยังทางออกจากแต่ละห้อง และเวลาที่คนสุดท้ายใช้ เลือก {{ui:Shut}} ที่ประตูเพื่อดูว่าจะเปลี่ยนอย่างไร และเลือก {{ui:Show the people in the 3D view}} เพื่อดูผู้เดิน ผลการตรวจไปที่ Problems เป็นแบบจำลองฝูงชนแบบหยาบสำหรับการตัดสินใจเชิงออกแบบ ไม่ใช่ใบรับรองความปลอดภัยจากอัคคีภัย ดู [พาคนผ่านอาคาร](topic:people-in-the-building)
- **อะคูสติกห้อง และฟังได้.** ส่วน {{ui:Room acoustics}} ให้เวลาสะท้อนก้องของแต่ละห้องตามแถบออกเตฟ (Sabine และ Eyring) จากขนาดและวัสดุผิวที่คุณเลือก และเมื่อกำหนดเป้าหมายเอง จะบอกว่าต้องดูดซับเพิ่มเท่าใดเพื่อให้ถึงเป้าหมาย {{ui:Play it in this room}} เล่นเสียงพูด เสียงปรบมือ โน้ตดีด หรือไฟล์เสียงของคุณเองผ่านการตอบสนองต่อแรงกระตุ้นที่คำนวณสำหรับห้องนั้น ตัวเลขการดูดซับเป็นค่าที่เผยแพร่โดยทั่วไปให้คุณแทนที่ได้ ดู [อะคูสติกห้อง](topic:room-acoustics)
- **เล่นน้ำท่วม ลม และแผ่นดินไหว.** {{ui:Hazard playback}} เล่นน้ำที่ท่วมขึ้นในห้อง แรงดันลมบนแต่ละชั้น และแผ่นดินไหวที่สั่นชั้นต่างๆ บนผังหรือด้านพร้อมแถบเวลา โมเดลอย่างง่ายพร้อมสมมติฐานบนพาเนล ไม่ใช่การตรวจตามข้อกำหนด ดู [เล่นน้ำท่วม ลม หรือแผ่นดินไหว](topic:hazard-playback)
- **สิ่งที่สึกหรอในห้าสิบปี.** {{ui:Life-cycle view}} แสดงรายการหน้าต่าง ประตู วัสดุตกแต่ง และหลังคา พร้อมอายุการใช้งานของแต่ละรายการ ปีที่ต้องเปลี่ยน และเมื่อคุณพิมพ์ต้นทุนต่อหน่วย ต้นทุนรายปีและมูลค่าปัจจุบัน {{ui:Save the schedule (CSV)}} เขียนออกมา อายุการใช้งานเป็นตัวเลขสำหรับการวางแผน ดู [ดูสิ่งที่สึกหรอในห้าสิบปี](topic:life-cycle-view)
- **การตรวจคอนกรีตและแผ่นดินไหว.** บล็อก {{ui:Concrete members}} และ {{ui:Seismic loads}} ของแท็บ {{ui:Analysis}} ตรวจคานและเสาคอนกรีตตาม ACI 318-19 และสร้างแรงด้านข้างเทียบเท่าตาม ASCE 7-22 บนพื้นแข็ง พร้อมการเคลื่อนตัวด้านข้างของชั้น สำหรับให้วิศวกรตรวจ ดู [ตรวจสอบชิ้นส่วนคอนกรีตและสร้างแรงแผ่นดินไหว](topic:concrete-and-seismic)

**ตรวจสอบและรายงาน**

- **ตรวจสอบกับ IDS.** โหลดไฟล์ `.ids` ที่ลูกค้าให้มาและดูทุกองค์ประกอบที่ไม่เป็นไปตามใน Problems ก่อนส่งมอบ IFC เปิด {{ui:Check against an IDS}} ภายใต้ {{ui:Model checks}} ดู [ตรวจสอบโมเดลกับ IDS ของลูกค้า](topic:check-against-ids)
- **แท็กและตารางรายการ.** กำหนดแท็กของคุณเองและตั้งให้องค์ประกอบจำนวนมากพร้อมกัน และทำตารางรายการที่คอลัมน์ ตัวกรอง และการจัดกลุ่มอ่านแท็กเหล่านั้น แท็กถูกเก็บไว้ใน IFC ดู [แท็กและตารางรายการ](topic:tags-and-schedules)
- **เอกสารจากโมเดล.** {{ui:Documents from the model}} กรอกแม่แบบข้อกำหนดจาก IFC ที่เปิดอยู่ และบันทึกเป็น PDF เอกสาร Word หรือ Markdown ดู [เอกสารจากโมเดล](topic:documents-from-the-model)
- **เปรียบเทียบการสแกนกับโมเดล.** เมื่อเปิดกลุ่มจุดเมฆ {{ui:Compare}} ตัดสินแต่ละองค์ประกอบว่าสร้างแล้ว สร้างบางส่วน ขาดหาย หรือยังไม่ถึง และแสดงเปอร์เซ็นต์ที่สร้างแล้ว ดู [เปรียบเทียบการสแกนกับโมเดล](topic:compare-scan-with-model)
- **คาร์บอนและต้นทุน.** แผงคาร์บอนรวมคาร์บอนที่ฝังอยู่จากตารางตัวคูณที่คุณแก้ไขได้ และแผงต้นทุนกระจายราคาไปตามตารางเวลา 4D ตัวคูณที่มาพร้อม BimCraft เป็นแบบทั่วไปและมีเครื่องหมายว่ายังไม่ได้ตรวจ ดู [คาร์บอนที่ฝังอยู่และต้นทุน](topic:embodied-carbon-and-5d-cost)
- **การฉายแผนที่ใดก็ได้.** {{ui:Measure}} › {{ui:Coordinate system…}} รับหมายเลข EPSG โซน UTM ชื่อ หรือนิยามการฉายของคุณเอง ดู [จัดตำแหน่งภูมิศาสตร์ด้วยการฉายใดก็ได้](topic:georeference-any-projection)

**วาดและแก้ไข**

- **Move, Align และ Distribute.** ภายใต้ {{ui:Build}} {{key:Shift+M}} เริ่ม Move (ปุ่ม {{key:M}} เปล่ายังเป็น Measure) Move คัดลอกขณะเคลื่อนด้วย {{key:C}} แต่ละขั้นตอนคือหนึ่งการเลิกทำ และทำงานในเซสชัน Live TeamWork ได้ ดู [ย้าย คัดลอก จัดแนว และกระจาย](topic:move-align-distribute)
- **รูปภาพใต้ผัง.** {{ui:Build}} › {{ui:Picture}} วาง PNG, JPEG หรือ WebP ใต้ผังของชั้นหรือบนระนาบแนวตั้ง กำหนดมาตราส่วนด้วยสองจุด และย้าย หมุน ทำให้จางและล็อกได้ พื้นที่ที่คัดลอกจาก MarkupCraft จะวางในมาตราส่วนของแผ่นนั้น ดู [วางรูปภาพใต้ผัง](topic:pictures-as-backgrounds)
- **ผนังจากการสแกน.** เมื่อเปิดการสแกน ผนัง ประตู และห้องจะมาเป็นข้อเสนอที่คุณเก็บหรือปฏิเสธทีละรายการ ในหนึ่งขั้นตอนเลิกทำ พบเฉพาะผนังในสองทิศทางที่ตั้งฉากกัน ดู [เปลี่ยนการสแกนเป็นผนัง](topic:scan-to-walls)
- **Trace, pens และ sketch stair.** {{ui:Trace}} แสดงอีกชั้นแบบเส้นประใต้ผัง {{ui:Pens}} ให้ผนัง ประตู และหน้าต่างมีความหนาเส้นของตัวเองในมุมมองเดียว และ {{ui:Sketch stair}} เปลี่ยนเส้นทางเดินเป็นบันได เปิดตาข่าย Wavefront OBJ ได้ ดู [ลอกชั้น ปากกา และบันไดจากสเกตช์](topic:trace-pens-stairs-obj)
- **อาคารรอบที่อยู่.** อาคารและแปลงที่ดินที่ Address to site ของ CivilCraft พบจะมาเป็นข้อเสนอ คุณเลือกอันที่ต้องการเพิ่ม ดู [เริ่มจากไซต์ของ CivilCraft](topic:site-from-civilcraft)
- **แบบแผง.** {{ui:Build}} › {{ui:Panel drawings}} สร้างกรอบผนัง พื้น และหลังคาในไม้หรือเหล็กรูปพรรณบาง และบันทึกรายการตัดเป็น CSV และแบบขยายเป็น PDF เป็นค่าเริ่มต้น ไม่ใช่การออกแบบโครงสร้าง ดู [แบบแผง](topic:panel-drawings)
- **พาเนลสัญลักษณ์และพืช.** {{ui:Build}} › {{ui:Symbol palette}} ค้นหาสัญลักษณ์ไฟฟ้าและประปาตามชื่อ ส่วน {{ui:Plants}} ของ {{ui:Library}} มีพืชประมาณ 400 ชนิดพร้อมสัญลักษณ์บนผัง ดู [พาเนลสัญลักษณ์](topic:symbol-palette) และ [วางพืช](topic:plant-list)

**ท่อ ท่อลม และพลังงาน**

- **Split, VRF และ fan coil.** หน่วยในอาคารและนอกอาคารพร้อมการเชื่อมต่อ และชุดสายที่กำหนดขนาดจากตารางค่าตัวอย่างทั่วไปที่คุณเปลี่ยนได้ ดู [Split, VRF และ fan coil](topic:split-vrf-fan-coils)
- **การคำนวณ.** แผงการคำนวณตรวจขนาดท่อจ่ายและท่อลมพร้อมแรงดันตก ผ่านสายเคเบิลในรางและท่อร้อยสายและแสดงการบรรจุ และคำนวณความส่องสว่างจากไฟล์ IES หรือ EULUMDAT ค่าเริ่มต้นมีป้ายกำกับ พิมพ์ค่าตามข้อกำหนดของคุณ ดู [การคำนวณท่อ ท่อลม สายเคเบิล และแสง](topic:mep-calculations)
- **ไฟล์ PCF.** **Export PCF** ของเครื่องมือท่อเขียนเส้นท่อให้โปรแกรมวิเคราะห์ความเค้นท่อและไอโซเมตริก และไฟล์ PCF ที่อ่านกลับมาจะวาดท่อของมัน ดู [ไฟล์ส่วนประกอบท่อ](topic:piping-pcf)
- **โซลาร์ PV.** ติดตั้งอาร์เรย์บนหลังคาหรือพื้นดิน ทำเงาจากโมเดล ประมาณพลังงานรายปี ตรวจสตริง และสร้างข้อมูลไดอะแกรมเส้นเดียว โมดูลเริ่มต้นและการสูญเสียเป็นแบบทั่วไป ดู [โซลาร์ PV](topic:solar-pv)
- **ไฟล์ EnergyPlus.** แผง Check with EnergyPlus เขียนโมเดลเป็น IDF เพื่อรันใน EnergyPlus ของคุณเอง การรันในเบราว์เซอร์ต้องใช้บิลด์ที่คุณโฮสต์เองและพิมพ์ที่อยู่ BimCraft ไม่ได้รวมมา ดู [ตรวจสอบการทำความร้อนและความเย็นด้วย EnergyPlus](topic:check-with-energyplus)

**รูปภาพและไฟล์**

- **เลือกเอนจินเรนเดอร์.** {{ui:Render}} มีตัวเลือก {{ui:Engine}} เอนจินในตัวสองตัวของเรา (Fast และ Path tracer) ยังเป็นค่าเริ่มต้น **Open in** บันทึกฉากเป็นไฟล์ USD หรือ glTF และโฟลเดอร์โปรเจกต์ Unreal เป็น .zip ใน CadCraft Studio ส่วนเสริมเพิ่มเอนจินได้ ปลั๊กอิน Unreal ที่เปิดโปรเจกต์ยังไม่ได้เผยแพร่ ดู [เลือกโปรแกรมที่วาดภาพ](topic:render-engines)
- **เลิกทำใน Studio.** ภายใน CadCraft Studio BimCraft แจ้ง Studio ทุกขั้นตอนที่เสร็จ เพื่อให้ Studio เลิกทำขั้นตอนล่าสุดของคุณในหน้าต่างที่คุณใช้ล่าสุด ดู [เลิกทำข้ามแอป](topic:undo-across-apps)
- **ส่วนเสริมในไฟล์ของคุณ.** IFC บันทึกว่าส่วนเสริมใดเขียนลงไป และเสนอส่วนที่คุณไม่มีเมื่อเปิดไฟล์ ดู [ส่วนเสริมในไฟล์ของคุณ](topic:add-ons-in-your-file)

**ในทุกแอป**

- **เชื่อมต่อ AI ของคุณ.** ผู้ช่วยของคุณเองสามารถควบคุม BimCraft ผ่านการเชื่อมต่อของ Studio และตอบคำถามเกี่ยวกับโมเดล เช่นห้องใดอยู่ใต้พื้นที่ที่กำหนด Studio ไม่มี AI ของตัวเอง ดู [ให้ผู้ช่วย AI ทำงานกับโมเดลของคุณ](topic:assistants)
- **แถวของแถบเครื่องมือ.** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} เสนอ Wrap, 2 rows หรือ 1 row โดย Wrap ยังเป็นค่าเริ่มต้น
- **อุปกรณ์ป้อนข้อมูล.** การตั้งค่าแทร็กแพด ปากกา เมาส์ 3 มิติ คอนโทรลเลอร์ และ MIDI ใช้ร่วมกันทุกแอป
- **Problems และ Live.** พาเนลคำเตือนและเซสชัน Live ทำงานเหมือนเดิม โดยการตรวจใหม่ข้างต้นป้อนข้อมูลให้ Problems
- **ภาษา.** 54 ภาษา สิบภาษาเป็นภาษาใหม่ ภาษาอื่นนอกจากภาษาอังกฤษเป็นฉบับร่างจากเครื่องที่ผู้พูดภาษานั้นยังไม่ได้อ่าน หัวข้อช่วยเหลือส่วนใหญ่เป็นภาษาอังกฤษ

### แก้ไขใน 0.8.1

- **เลย์เอาต์ Ribbon + Project browser.** Insert › Import CAD, Insert › Image และ Manage › Project Units เคยแสดง "Not built in BimCraft yet" ตอนนี้ Image เปิดเครื่องมือ Picture, Import CAD เปิด {{ui:Build}} › {{ui:From a drawing…}} (DWG, DXF, PDF หรือการสแกน) และ Project Units เปิด {{ui:Settings}} › {{ui:Global}} › {{ui:Units}} Move และ Align รันเครื่องมือ Move และ Align, Level เปิด {{ui:Add levels…}} Phases เปิดส่วนระยะการปรับปรุง และ Materials เปิดคลังวัสดุ
- **ส่วน DWG classes.** อ่านเป็นประเภทที่ผิด แก้ไขแล้วใน BimCraft และแอปอื่นที่อ่าน DWG
- **ภาษาขณะทำงาน.** Studio และรุ่นแพ็กเกจสามารถเปลี่ยนภาษาได้โดยไม่ต้องเริ่มใหม่ ยังไม่ได้ทดสอบทุกแพลตฟอร์ม โปรดแจ้งเราหากภาษาไม่เปลี่ยน
- **สคริปต์ Archicad bundle.** `archicad_bundle.py` ซึ่งดาวน์โหลดแยกต่างหาก ตอนนี้หาพาธของ Archicad เฝ้าดูโฟลเดอร์นานถึง 20 วินาที และลองใหม่ข้างบันเดิล

### ยังไม่มีในรุ่นนี้

- **เครื่องมือความปลอดภัยและการออกแบบ.** คนในอาคารไม่มีขีดจำกัดระยะทางเดินจากข้อกำหนดอาคาร (คุณพิมพ์ขีดจำกัดเอง) และยังไม่ได้ตรวจด้วยมือกับแผนจริง ตัวเลขอะคูสติก วงจรชีวิต และภัยพิบัติเป็นค่าสำหรับการวางแผน ไม่ใช่การตรวจตามข้อกำหนด
- **อนาคตภูมิอากาศและ EnergyPlus.** ไม่มีอนาคตภูมิอากาศในตัว คุณโหลดไฟล์สถานการณ์สำหรับการรันน้ำท่วมได้ การรัน EnergyPlus ในเบราว์เซอร์ไม่อยู่ในรุ่นนี้
- **เลย์เอาต์ Ribbon.** Material Takeoff ยังแสดง "Not built" เพราะ BimCraft ไม่มีรายการปริมาณวัสดุ และเครื่องมือริบบอนสีเทาอีก 54 รายการยังไม่มีเครื่องมือ BimCraft รองรับ
- **การลงนามและแพลตฟอร์ม.** ตัวติดตั้ง Windows และไฟล์ .dmg ของ macOS ไม่ได้ลงนาม SmartScreen จึงแสดง {{ui:More info}} แล้ว {{ui:Run anyway}} และ macOS ต้องคลิกขวาแล้ว {{ui:Open}} บิลด์ iPad และ iPhone ไม่ได้สร้างใหม่สำหรับ 0.8.1
- **การทดสอบหน้าจริง.** การทดสอบเบราว์เซอร์ BimCraft รุ่นเก่าบางรายการยังล้มเหลวในหน้าทดสอบของเรา เหมือนก่อน 0.8.1

สิ่งอื่นทั้งหมดอยู่ใน [ยังไม่ได้สร้างอะไร](topic:not-built-yet) การเปลี่ยนแปลงก่อนหน้านี้อยู่ใน [มีอะไรใหม่ใน 0.7](topic:whats-new-0-7)
