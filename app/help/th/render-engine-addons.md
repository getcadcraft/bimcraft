ส่วนเสริม (การตั้งค่า › ส่วนเสริม) สามารถเพิ่มเอนจินลงในรายการเอนจินของ {{ui:Render}} ได้ ข้อความฉบับเต็มสำหรับผู้เขียนส่วนเสริมอยู่ในส่วนที่ 16 ของข้อกำหนดส่วนเสริม โดยสรุปดังนี้:

- ส่วนเสริมลงทะเบียนเอนจินที่มีรหัสขึ้นต้นด้วยรหัสของตัวเอง มีชื่อ การตั้งค่าเพิ่มเติม (ไม่บังคับ) และ **อย่างใดอย่างหนึ่ง** คือโปรแกรมที่จะรัน **หรือ** ฟังก์ชันใน JavaScript ที่วาดภาพ
- เอนจินที่รันโปรแกรมต้องมีสิทธิ์ **`engine.run`** ซึ่งจะแสดงก่อนการติดตั้งและในการตั้งค่า เอนจินนี้ทำงานเฉพาะใน Studio ในเบราว์เซอร์จะแสดงเป็นไฟล์ที่ต้องบันทึก
- ส่วนเสริมระบุโปรแกรม (ชื่อไฟล์แบบธรรมดา ไม่ใช่เชลล์) สคริปต์ที่ **อยู่ภายในส่วนเสริมที่ลงนามดิจิทัลแล้ว** และอาร์กิวเมนต์ที่ประกอบจากตัวยึดตำแหน่งและคำธรรมดา Studio จะค้นหาโปรแกรมหรือถามให้ชี้ตำแหน่งหนึ่งครั้ง
- ครั้งแรกที่ส่วนเสริมรันโปรแกรม **Studio จะถามในกล่องโต้ตอบของตัวเอง**: ส่วนเสริมใด โปรแกรมใด และสคริปต์สามารถทำอะไรก็ได้ที่โปรแกรมทำได้ อนุญาตเฉพาะส่วนเสริมที่เชื่อถือได้ คำตอบจะถูกจำไว้สำหรับส่วนเสริมและโปรแกรมนั้น
- แพ็กเกจ (ฉากเป็น USD และไฟล์การตั้งค่า พร้อมไฟล์ glTF เมื่อส่วนเสริมขอ) และสคริปต์ของส่วนเสริมจะถูกนำไปไว้ในโฟลเดอร์ชั่วคราวใหม่ โปรแกรมทำงานที่นั่น และภาพจะกลับมาพร้อมชื่อเอนจินของส่วนเสริมกำกับ

:::note
ส่วนเสริมจะเพิ่มเอนจินเรนเดอร์ได้เฉพาะตั้งแต่ API ส่วนเสริมเวอร์ชัน 1.4 เป็นต้นไป ตัวอย่างการทำงานสำหรับตัวเรนเดอร์บรรทัดคำสั่งโอเพนซอร์สอยู่ในที่เก็บของตัวเอง ยังไม่เคยรันในตัวเรนเดอร์นั้น
:::
