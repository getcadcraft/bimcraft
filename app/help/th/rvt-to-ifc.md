## สิ่งที่จะทำ

แปลงไฟล์โปรเจกต์เป็นไฟล์ IFC ที่หมุนดู ตรวจสอบ ตรวจทาน และแก้ไขใน BimCraft ได้ BimCraft ยังอ่านโมเดล 3D ภายในไฟล์ `.rvt` ไม่ได้ ดังนั้นการส่งออกจึงทำในโปรแกรมที่สร้างไฟล์นั้น (Revit) และ BimCraft เปิดผลลัพธ์

## ขั้นตอน

1. เปิดโปรเจกต์ในโปรแกรมที่สร้างมัน การ์ดของ BimCraft จะระบุรุ่นที่บันทึกไว้
2. เปิดมุมมอง 3D ที่แสดงสิ่งที่ต้องการส่งออก
3. เลือก **File > Export > IFC**
4. ในกล่องโต้ตอบการส่งออก เลือกการตั้งค่า (หรือ **แก้ไขการตั้งค่า…**) ที่มีการตั้งค่าด้านล่าง
5. เลือกโฟลเดอร์และชื่อไฟล์ แล้วส่งออก
6. ใน BimCraft คลิก {{ui:เลือกไฟล์}} แล้วเลือกไฟล์ `.ifc` ใหม่ โมเดลที่เชื่อมโยงซึ่งส่งออกเป็นไฟล์แยกจะเปิดเข้าฉากเดียวกันด้วย {{ui:เพิ่มโมเดล}}

## การตั้งค่าที่เปิดได้ดีที่สุดที่นี่

| การตั้งค่าในตัวส่งออก | เลือก | เหตุผล |
|---|---|---|
| เวอร์ชัน IFC | **IFC4 Reference View** สำหรับการดู ตรวจสอบ และการคำนวณปริมาณ; **IFC2X3 Coordination View 2.0** เมื่อผู้อื่นต้องการ IFC2X3 | ทั้งสองเปิดได้เต็มรูปแบบ **IFC4 Design Transfer View** ก็เปิดได้ โดยมีรูปทรงที่แม่นยำกว่า แต่ไฟล์ใหญ่กว่าและช้ากว่า |
| ประเภทไฟล์ | **IFC** (ธรรมดา) | BimCraft ไม่เปิด `.ifczip` หรือ `.ifcxml` |
| เฟส / องค์ประกอบที่มองเห็น | เฟสที่ต้องการ และ **Export only elements visible in view** เมื่อตั้งค่ามุมมอง 3D ไว้สำหรับสิ่งนี้ | ไม่รวมสิ่งที่ซ่อนไว้โดยตั้งใจ |
| ชุดคุณสมบัติ | **Export Revit property sets** และ **Export IFC common property sets** | ชุดเหล่านี้จะกลายเป็นชุดคุณสมบัติที่ BimCraft แสดงใน {{ui:คุณสมบัติ}} และที่ {{ui:ค้นหา}}, {{ui:สี}} และ {{ui:ตรวจสอบโมเดล}} ใช้งาน |
| ปริมาณพื้นฐาน | **Export base quantities** | {{ui:ผลรวมปริมาณ}} และตารางรายการใช้ค่าเหล่านี้ (ความยาว พื้นที่ ปริมาตร) แทนการคาดเดา |
| ห้องและพื้นที่ | **Export rooms in 3D views** (หรือตัวเลือก Rooms / Spaces) | ห้องจะเข้ามาเป็นพื้นที่: คลิก {{ui:พื้นที่}} เพื่อดูห้องเหล่านั้น |
| ไฟล์ที่เชื่อมโยง | **Export linked files as separate IFCs** | แต่ละลิงก์จะกลายเป็นไฟล์ของตัวเอง เปิดพร้อมกันด้วย {{ui:เพิ่มโมเดล}} แล้วจะเรียงตรงกัน |
| ฐานพิกัด | **Shared coordinates** (หรือจุดสำรวจ) | ไฟล์จะมีตำแหน่งบนแผนที่ (IfcMapConversion) ดังนั้น Measure › Location, เลเยอร์แผนที่บนพื้นดิน และจุดกลุ่มเมฆที่วางด้วยพิกัดแผนที่จะใช้งานได้ จุดฐานโปรเจกต์ทำให้โมเดลอยู่ใกล้จุดกำเนิด แต่ไม่มีตำแหน่งบนแผนที่ |
| แยกผนังและเสาตามระดับ | เปิด เมื่อคำนวณปริมาณแยกตามชั้น | ส่วนของแต่ละชั้นเป็นองค์ประกอบของตัวเอง |

## สิ่งที่ควรเห็น

โมเดล 3D โดยมีชั้นที่นำมาจากระดับของโปรเจกต์ และข้อมูลโปรเจกต์ในแผง {{ui:ไฟล์}} **ส่งออกจาก** ระบุตัวส่งออก

## สิ่งที่การส่งออกเก็บไว้ และสิ่งที่ไม่เก็บ

- **เก็บไว้**: รูปทรงเรขาคณิต ชั้น ประเภทองค์ประกอบ ชื่อ ประเภท พารามิเตอร์ส่วนใหญ่ (เป็นชุดคุณสมบัติ) ปริมาณพื้นฐานเมื่อขอ ห้องเป็นพื้นที่ และตำแหน่งบนแผนที่เมื่อใช้พิกัดร่วม
- **ไม่เก็บไว้**: มุมมอง แผ่นงาน คำอธิบายประกอบ แฟมิลี่ในรูปแบบที่แก้ไขได้ ชุดงาน (workset) และตัวเลือกการออกแบบ ไฟล์ IFC คือภาพรวมขององค์ประกอบของโมเดล ไม่ใช่โปรเจกต์ สำหรับแผ่นงาน ให้ส่งออก DWG แล้วเปิดในมุมมอง 2D

## ข้อผิดพลาดที่พบบ่อย

- **พารามิเตอร์หายไปใน BimCraft** เปิดตัวเลือกชุดคุณสมบัติด้านบนแล้วส่งออกอีกครั้ง
- **ไม่มีห้อง** เปิดตัวเลือกห้อง แล้วคลิก {{ui:พื้นที่}}
- **บันทึกเป็น `.ifczip`** เลือก IFC ธรรมดา หรือแตกไฟล์ `.ifczip`
- **ไม่มีตำแหน่งบนแผนที่** ส่งออกด้วยพิกัดร่วม และตรวจว่าตั้งจุดสำรวจของโปรเจกต์แล้ว
- **คาดหวังว่าการแก้ไขจะย้อนกลับ** การแก้ไขที่บันทึกใน BimCraft จะไปอยู่ในไฟล์ IFC ใหม่ ไม่ใช่ไฟล์โปรเจกต์
