## สิ่งที่จะทำ

ดูอาคารค่อย ๆ ถูกสร้างขึ้น: แต่ละงานในตารางงานเชื่อมกับองค์ประกอบที่งานนั้นสร้าง แสดงทีละวัน

## ขั้นตอน

1. เปิดโมเดล IFC แล้วเปิด {{ui:4D schedule}} ในพาเนลด้านซ้าย
2. คลิก {{ui:Download a template}} เพื่อรับรายการงานที่มีหนึ่งสัปดาห์ต่อชั้น แล้วแก้ไขในโปรแกรมสเปรดชีต หรือจะเขียนเองก็ได้
3. คลิก {{ui:Open a task list…}} แล้วเลือกไฟล์ CSV
4. ลากแถบเลื่อนวันที่ หรือคลิก {{ui:Play}}

## รายการงาน

ไฟล์ CSV ที่มีแถวหัวและคอลัมน์ **Task**, **Start**, **Finish**, **Field** และ **Value** ใช้จุลภาคหรืออัฒภาคก็ได้

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| ชั้น 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| หลังคา | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| หลังคา | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- เขียนวันที่เป็น YYYY-MM-DD
- แถวหนึ่งจะเชื่อมงานกับทุกองค์ประกอบที่มีค่า **Field** ตรงกับ **Value** พอดี Field คือคุณสมบัติ เช่น Storey, Class, Name, Type, Material, Tag หรือ GlobalId หรือคุณสมบัติใดที่เขียนเป็นชุดและชื่อ เช่น `Pset_WallCommon.FireRating`
- ทำซ้ำงานในหลายแถวด้วยวันที่เดียวกัน เพื่อเชื่อมองค์ประกอบเพิ่มเติมกับงานนั้น

## ระยะและแพ็กเกจงาน

เพิ่มคอลัมน์ **Stage** คอลัมน์ **Package** หรือทั้งสองคอลัมน์ เพื่อรวมงานเป็นระยะและแพ็กเกจงาน ใช้ Phase และ WBS เป็นชื่อคอลัมน์ได้เช่นกัน

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| พื้นชั้น 1 | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| ผนังชั้น 1 | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| ประตู | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- งานหนึ่งอยู่ในระยะเดียวและแพ็กเกจเดียว หากแถวถัดไปของงานเดียวกันระบุอีกค่าหนึ่ง แถวนั้นจะถูกแสดงพร้อมหมายเลขบรรทัดและถูกข้าม
- ชื่อแพ็กเกจเดียวกันในสองระยะถือเป็นสองแพ็กเกจ

เมื่อรายการมีกลุ่ม รายการ {{ui:Show}} จะปรากฏเหนือวันที่ เลือกระยะหรือแพ็กเกจหนึ่งรายการ แล้วจะเล่นเป็นหนึ่งเดียว:

- แถบเลื่อนและ {{ui:Play}} ทำงานตั้งแต่วันเริ่มต้นแรกของกลุ่มถึงวันสิ้นสุดสุดท้ายของกลุ่ม
- แสดงเฉพาะงานของกลุ่ม และทาสีเฉพาะงานนั้น ส่วนที่อยู่นอกกลุ่มจะโปร่งใส
- บรรทัดใต้รายการบอกจำนวนงานของกลุ่มที่เสร็จแล้ว กำลังดำเนินการ และยังไม่เริ่มในวันนั้น
- {{ui:Select its elements}} เลือกทุกองค์ประกอบของกลุ่ม เพื่อใช้กับ {{ui:Show}}, {{ui:Section}} หรือตารางรายการ

เลือก **ทุกงาน** เพื่อดูตารางงานทั้งหมดอีกครั้ง

## สิ่งที่ควรเห็น

- **สร้างแล้ว**: องค์ประกอบที่งานทั้งหมดเสร็จแล้ว แสดงด้วยสีของตัวเอง
- **กำลังดำเนินการ**: องค์ประกอบที่มีงานกำลังทำอยู่ในวันนั้น แสดงด้วยสีโอคร์ งานจะดำเนินการตั้งแต่วันเริ่มจนถึงวันเสร็จ
- **ยังไม่เริ่ม**: โปร่งใส
- องค์ประกอบที่ไม่อยู่ในงานใดจะคงสภาพเดิม รายการจะแสดงจำนวนองค์ประกอบที่แต่ละงานพบ แถวที่อ่านไม่ได้หรือไม่พบอะไรจะถูกแสดงพร้อมหมายเลขบรรทัด

## การเชื่อมโยง แผนภูมิแกนต์ และ MS Project

- เปิดไฟล์ Microsoft Project XML (`.xml`) หรือไฟล์ CSV ที่มีคอลัมน์ `Predecessors` การเชื่อมโยงเป็นได้ทั้งแบบจบถึงเริ่ม เริ่มถึงเริ่ม จบถึงจบ หรือเริ่มถึงจบ โดยแต่ละแบบกำหนดการล่วงหน้าหรือหน่วงเป็นวันได้
- ใต้รายการงาน แผนภูมิแกนต์จะวาดทุกงานเป็นแท่ง พร้อมลูกศรสำหรับการเชื่อมโยง งานบนเส้นทางวิกฤตเป็นสีแดง การวนลูปของการเชื่อมโยงหรือ predecessor ที่ไม่มีอยู่จะแสดงในพาเนล
- {{ui:Save as MS Project XML}} และ {{ui:Save CSV with links}} เขียนตารางงานกลับพร้อมการเชื่อมโยง
