## สิ่งที่คุณจะได้เรียนรู้

วิธีให้ผู้ช่วย AI ใด ๆ ที่พูด MCP มองดูโมเดล IFC ที่คุณเปิดอยู่และวาดในโมเดลนั้น สิ่งที่ทำได้และทำไม่ได้ และวิธีหยุดการทำงาน

## สิ่งที่ผู้ช่วยทำได้ใน BimCraft

| ผู้ช่วยขอ | สิ่งที่เกิดขึ้น | ต้องการสิทธิ์ |
|---|---|---|
| ค้นหาองค์ประกอบ | ได้รายการองค์ประกอบตามคลาส ชั้น ชื่อ หรือค่าคุณสมบัติ เหมือนที่ **ค้นหา** ทำ | อ่าน |
| อ่านคุณสมบัติ | ได้แอตทริบิวต์ ประเภท ชุดคุณสมบัติ และปริมาณขององค์ประกอบหนึ่ง เหมือนที่ **คุณสมบัติ** แสดง | อ่าน |
| อธิบายโมเดล แสดงรายการผนัง | ได้ชั้น ผนัง ประตู หน้าต่าง ห้อง พื้น กริด และเสา พร้อมปลายผนัง ประเภท และความสูงของผนังแต่ละด้าน | อ่าน |
| แยก ทำให้โปร่งใส ซ่อน หรือแสดง | มุมมอง 3D เปลี่ยนเหมือนคุณใช้เมนู {{ui:Show}} | เปลี่ยนมุมมองและวาด |
| วาดผนัง ประตู หน้าต่าง พื้น ชั้น หรือเส้นกริด | โมเดลเปลี่ยนเหมือนคุณใช้เครื่องมือ {{ui:Draw}}: ผนังเชื่อมกัน ห้อง พื้น และหลังคาตามไป | เปลี่ยนมุมมองและวาด |
| เปลี่ยนชื่อหรือค่าคุณสมบัติ | ชื่อ คำอธิบาย Object type หรือ Tag ขององค์ประกอบหนึ่ง หรือค่าคุณสมบัติหนึ่งค่า ค่าที่ใช้ร่วมกับองค์ประกอบอื่นจะถูกคัดลอกให้ก่อน ค่าของประเภทจะเปลี่ยนเฉพาะเมื่อผู้ช่วยระบุไว้ เพราะทุกองค์ประกอบของประเภทนั้นจะตามไป | เปลี่ยนมุมมองและวาด |
| ย้าย ลบ เปลี่ยนผนัง ประตู และหน้าต่าง | องค์ประกอบถูกย้ายหรือลบพร้อมกับสิ่งที่มันยึดอยู่ ผนังที่วาดด้วยเครื่องมือ {{ui:Draw}} เปลี่ยนตามปลายหรือประเภท ประตูและหน้าต่างเปลี่ยนตามตำแหน่ง ขนาด หรือประเภท และห้องกับจุดเชื่อมจะตามไป | เปลี่ยนมุมมองและวาด |
| ตั้งค่า จัดเรียง และอ่านตารางรายการ | "ตารางประตูตามชั้น พร้อมค่าการทนไฟและอุปกรณ์ติดตั้ง": ผู้ช่วยตั้งชื่อตาราง คอลัมน์ (คุณสมบัติหรือแท็กจะกลายเป็นคอลัมน์) และการจัดกลุ่ม BimCraft จะกรอกจากโมเดลและจัดวาง โดยใช้มาตรฐานของสำนักงานสำหรับสิ่งที่ผู้ช่วยไม่ได้ระบุ การตั้งค่านี้จะเข้าไปอยู่ในรายการ **ตารางรายการ** ของคุณ แต่ละบรรทัดที่ได้รับกลับมาจะระบุองค์ประกอบของตน เพื่อให้เลือกได้ | อ่านเพื่ออ่าน; เปลี่ยนมุมมองและวาดเพื่อบันทึกการตั้งค่า |
| ส่งออกตารางรายการ | CSV, Excel หรือข้อความคั่นด้วยแท็บเพื่อวางใน Google Sheets (ไม่มีการส่งอะไรไปยัง Google) | ส่งออก |
| อ่านและกำหนดงานตกแต่งห้อง | ประเภทงานตกแต่ง งานตกแต่งพื้น ผนัง และเพดานของแต่ละห้อง โซน จากนั้นพื้นที่ จำนวนกระเบื้อง และปริมาตรวัสดุรองพื้นจะมาจากตารางงานตกแต่ง | อ่าน; เปลี่ยนมุมมองและวาดเพื่อกำหนด |
| เลือกองค์ประกอบ เลิกทำขั้นตอนของตัวเอง | องค์ประกอบถูกเลือกในมุมมอง ขั้นตอนสุดท้ายของผู้ช่วยจะถูกเลิกทำ | เปลี่ยนมุมมองและวาด |
| บันทึก | ไฟล์ IFC ใหม่ที่มีการเปลี่ยนแปลงทั้งหมด เหมือนที่ {{ui:Save as IFC}} ทำ (ต้นฉบับจะไม่ถูกเปลี่ยนแปลง) | บันทึก |
| ส่งออก USD | โมเดลที่เปิดอยู่เป็น OpenUSD (.usda, .usdc หรือ .usdz) เหมือนที่ {{ui:USD}} บนแถบเครื่องมือเขียน | ส่งออก |
| เรนเดอร์ภาพ หรือเรียกใช้คิวการเรนเดอร์ | ภาพของมุมมอง 3D เหมือนที่กล่องโต้ตอบ {{ui:Render}} ทำด้วยการตั้งค่าการเรนเดอร์ของคุณ เว้นแต่จะขอค่าอื่น หรือภาพคุณภาพสูงที่เพิ่มเข้าคิวในกล่องโต้ตอบและเรนเดอร์ทีละภาพ (คิวต้องใช้ WebGPU) ไม่มีการเปลี่ยนแปลงในโมเดล ([เรนเดอร์ภาพ](topic:render)) | ส่งออก |

การเปลี่ยนแปลงแต่ละครั้งที่ผู้ช่วยทำจะเป็นหนึ่งขั้นตอนใน **การเปลี่ยนแปลง** ชื่อว่า "Assistant: …" (เช่น "Assistant: add 4 walls") ดังนั้น {{key:Mod+Z}} จะเลิกทำการกระทำทั้งหมดของมัน และคุณจะเห็นว่าขั้นตอนนั้นเป็นของใคร ในหน้าต่างนี้ผู้ช่วยเปิดไฟล์ไม่ได้: คุณเปิดโมเดล และผู้ช่วยจะทำงานกับโมเดลที่เปิดอยู่

## เปิดใช้งาน

ผู้ช่วยเชื่อมต่อกับ BimCraft ผ่าน CadCraft Studio บนคอมพิวเตอร์ของคุณ เบราว์เซอร์ธรรมดาไม่มีช่องทางเข้า

1. เปิด {{ui:Settings}} แล้วเลือกแท็บ **BimCraft**
2. ภายใต้ **ผู้ช่วย** ทำเครื่องหมาย **อนุญาตให้ผู้ช่วย AI และสคริปต์ใช้ BimCraft**
3. **อ่าน** ถูกทำเครื่องหมายให้คุณแล้ว ทำเครื่องหมาย **เปลี่ยนมุมมองและวาด** ด้วยหากผู้ช่วยอาจแยกและซ่อนองค์ประกอบและวาดได้ และทำเครื่องหมาย **บันทึก** หากผู้ช่วยอาจบันทึกโมเดลเป็นไฟล์ใหม่
4. เชื่อมต่อผู้ช่วยใน Studio (Studio จะแสดงที่อยู่และการตั้งค่าที่ต้องวางลงในผู้ช่วย)

## เมื่อผู้ช่วยเชื่อมต่ออยู่

ข้อความที่ด้านบนของพาเนลด้านขวาจะบอกว่าผู้ช่วยตัวใดเชื่อมต่ออยู่และทำอะไรได้ คลิก {{ui:Disconnect}} เพื่อจบเซสชันของมันทันที มันต้องเชื่อมต่อใหม่จึงจะทำงานต่อได้

**กิจกรรม** ภายใต้ **ผู้ช่วย** ในการตั้งค่า แสดงทุกการเรียกที่ผู้ช่วยทำ เรียงจากใหม่สุดขึ้นก่อน พร้อมระบุว่าทำสำเร็จหรือไม่

:::tip
ถามด้วยคำพูดธรรมดา เช่น "แยกผนังภายนอกบนชั้น 1", "ประตูบานใดไม่มีค่าการทนไฟ?" หรือ "วาดห้องขนาด 6 คูณ 4 เมตรบนชั้น 1 พร้อมประตูที่ผนังด้านใต้" ผู้ช่วยจะค้นหาองค์ประกอบและแสดงในมุมมอง หรือวาดให้
:::

## ไม่ต้องมีหน้าต่าง: สคริปต์และบรรทัดคำสั่ง

เครื่องมือวาดชุดเดียวกันทำงานกับไฟล์ IFC ในโฟลเดอร์ที่คุณระบุ โดยไม่ต้องเปิดหน้าต่างใด ๆ: เซิร์ฟเวอร์ MCP และบรรทัดคำสั่งของ CadCraft สามารถเริ่มอาคารใหม่หรือเปิดไฟล์ IFC อธิบายไฟล์ เพิ่มผนัง ประตู หน้าต่าง พื้น ชั้น และกริด เลิกทำ และบันทึกเป็นไฟล์ `.ifc` ใหม่ได้ คุณเป็นผู้กำหนดว่าจะใช้โฟลเดอร์ใด และอนุญาตให้เปลี่ยนแปลงหรือบันทึกหรือไม่

## ปิดการใช้งาน

ยกเลิกการเลือก **อนุญาตให้ผู้ช่วย AI และสคริปต์ใช้ BimCraft** ผู้ช่วยทุกตัวจะถูกยกเลิกการเชื่อมต่อทันที และการตั้งค่าจะถูกเก็บไว้สำหรับครั้งหน้า
