## IFC

| อ่าน | รายละเอียด |
|---|---|
| รูปทรง | ทุกองค์ประกอบที่มีรูปร่าง มีสีตามที่ไฟล์กำหนด ห้องและพื้นที่วาดแบบโปร่งใส และซ่อนไว้ในตอนแรก |
| ชั้น | ชั้นอาคารเรียงตามลำดับความสูง และองค์ประกอบใดอยู่บนชั้นใด องค์ประกอบที่ไม่อยู่บนชั้นใดจะถูกจัดกลุ่มเป็น "ไม่อยู่บนชั้น" |
| จำนวนองค์ประกอบ | จำนวนองค์ประกอบของแต่ละชนิด (ผนัง ประตู พื้น…) แสดงใน {{ui:Elements}} |
| ข้อมูลโครงการ | ชื่อโครงการ ชื่อยาว และเฟส สคีมา โปรแกรมที่ส่งออก ผู้เขียน และวันที่ส่งออกจากส่วนหัวของไฟล์ |
| ข้อมูลองค์ประกอบ | ชื่อ ชนิด ชนิดออบเจ็กต์ แท็ก คำอธิบาย GlobalId ทุกชุดคุณสมบัติและชุดปริมาณบนองค์ประกอบและบนประเภทของมัน |

แก้ไขได้: ชื่อ ชนิดออบเจ็กต์ แท็ก คำอธิบาย และค่าคุณสมบัติเดี่ยว บันทึกเป็นไฟล์ IFC ใหม่ เปิดได้สคีมา IFC2X3, IFC4 และ IFC4X3 อ่านด้วยเอ็นจิน IFC ของ BimCraft เอง สิ่งใดที่ยังวาดไม่ได้จะแสดงภายใต้ **ยังไม่วาด** ในพาเนล {{ui:File}} โมเดลจะถูกย้ายไปที่จุดกำเนิดเมื่อเปิด ดังนั้นโมเดลที่วางห่างจากจุดนั้นก็ยังแสดงตรงกลางหน้าจอ ไฟล์ `.ifczip` และ `.ifcxml` เปิดไม่ได้

## ไฟล์โครงการและแฟมิลี

`.rvt` โครงการ, `.rte` เทมเพลตโครงการ, `.rfa` แฟมิลี และ `.rft` เทมเพลตแฟมิลี

| อ่าน | รายละเอียด |
|---|---|
| ข้อมูลไฟล์ | รุ่นและบิลด์ การทำงานร่วมกัน พาธของโมเดลกลาง พาธที่บันทึกล่าสุด ชื่อผู้ใช้ โลแคล และ GUID ของเอกสาร |
| ข้อมูลโครงการ | ฟิลด์ของโครงการเอง (ชื่อ หมายเลข ลูกค้า ที่อยู่ สถานะ…) โดยไม่รวมค่าเริ่มต้นของโครงการใหม่ |
| ข้อมูลแฟมิลี | ชื่อแฟมิลี หมวดหมู่ รุ่น การอัปเดตล่าสุด และพารามิเตอร์แยกตามกลุ่ม |
| การเชื่อมโยง | รายการโมเดลที่เชื่อมโยง ลิงก์ CAD รูปภาพ และตารางคีย์โน้ตที่ไฟล์ชี้ไป |
| ภาพตัวอย่าง | ภาพย่อที่บันทึกอยู่ในไฟล์ |

ไม่ได้อ่าน: โมเดล 3D องค์ประกอบ มุมมอง แผ่น และตารางรายการ ข้อมูลเหล่านี้เก็บในรูปแบบที่ไม่มีเอกสาร BimCraft อ่านเพียงไม่กี่สิบ KB จากแต่ละไฟล์ ดังนั้นขนาดไฟล์แทบไม่มีผล

## ไฟล์โครงการ .pln, .pla, .tpl และ .bpn

ยังไม่ได้อ่าน BimCraft จะแจ้งให้ทราบเมื่อเปิดไฟล์หนึ่ง ให้ส่งออก IFC สำหรับโมเดล และ DWG สำหรับแบบ ดู [เปิดไฟล์โครงการ .pln และ .pla](topic:pln-project-files)

## DWG และ DXF

| อ่าน | รายละเอียด |
|---|---|
| พื้นที่ | พื้นที่โมเดลและทุกแผ่น (เลย์เอาต์) ตามลำดับแท็บ |
| วิวพอร์ต | วิวพอร์ตของแต่ละแผ่น พร้อมมาตราส่วน การบิด และเลเยอร์ที่แช่แข็ง |
| เลเยอร์ | ชื่อ สี เปิดหรือปิด แช่แข็ง ธงการพล็อต และความหนาเส้น |
| ออบเจ็กต์ | เส้น โพลีไลน์ ส่วนโค้ง วงกลม วงรี สไปลน์ แฮตช์ และโซลิด ข้อความและข้อความหลายบรรทัด บล็อกและแอตทริบิวต์ ไดเมนชัน ลีดเดอร์และมัลติลีดเดอร์ ตาราง จุด รูปภาพ |
| แบบที่เชื่อมโยง | วาดตรงตำแหน่งที่แทรกไว้ เมื่อพบไฟล์ |
| รูปภาพ | วาดจากไฟล์รูปภาพเมื่อพบ (PNG, JPEG, GIF, BMP, WebP; ไม่รวม TIFF) |
| แท็กอุปกรณ์ | แท็กรายการงานบริการอาหาร (แอตทริบิวต์ `KCL-ITEM`) สำหรับตารางอุปกรณ์ |

สิ่งอื่นจะนับไว้ภายใต้ **ยังไม่วาด** โดยไม่มีการเดา รูปแบบ DWG จาก AutoCAD 2000 ถึง 2018 เป็นรูปแบบที่ตรวจสอบแล้ว (ไฟล์ R13 และ R14 ก็รับได้ แต่ไม่มีในชุดทดสอบ DWG รุ่นเก่ากว่านั้นเปิดไม่ได้) พาเนล {{ui:Drawing}} แสดงรหัสรูปแบบ (เช่น AC1032) ไฟล์ DXF ทุกเวอร์ชันเปิดได้ รวมถึง R12 ทั้งสองแบบอ่านด้วยตัวอ่านของ BimCraft เองในแท็บนี้ ไม่มีการบันทึกกลับเป็น DWG หรือ DXF

## ในโฟลเดอร์

| ชนิด | นามสกุล | ในรายงาน |
|---|---|---|
| โมเดล | `.rvt` `.rfa` `.rte` `.rft` | จัดกลุ่มพร้อมไฟล์สำรองที่มีหมายเลข ตรวจสุขภาพ อ่านการ์ดข้อมูล และตรวจลิงก์ |
| IFC | `.ifc` | แสดงรายการ เปิดใน 3D |
| CAD | `.dwg` `.dxf` `.dgn` | แสดงรายการพร้อมโมเดลที่เชื่อมโยงไฟล์เหล่านี้ DWG และ DXF เปิดใน 2D DGN ไม่เปิด |
| ไฟล์ที่หลงเหลือ | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | แสดงภายใต้ **แยกออก** |
| โฟลเดอร์ระบบ | `*_backup`, `*_log`, `Revit_temp`, โฟลเดอร์ซ่อน | แสดงภายใต้ **แยกออก** ไม่อ่าน |
