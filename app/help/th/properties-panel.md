## องค์ประกอบ IFC

ด้านบนของพาเนล {{ui:คุณสมบัติ}} จะแสดงชนิดขององค์ประกอบโดยไม่มีคำนำหน้า "Ifc" (เช่น "Door", "WallStandardCase", "FurnishingElement") และชื่อ หรือ "ไม่มีชื่อ" หากไม่มีชื่อ

| ช่อง | ความหมาย | แก้ไขได้ |
|---|---|---|
| Name | ชื่อขององค์ประกอบ มักเป็นชื่อแฟมิลีและชนิดจากตัวส่งออก | ใช่ |
| Type | ชื่อของชนิดขององค์ประกอบ เมื่อมีชนิด | ไม่ |
| Object type | คำอธิบายชนิดแบบข้อความอิสระที่ตัวส่งออกบางตัวกรอกไว้ | ใช่ |
| Tag | แท็กหรือเครื่องหมายขององค์ประกอบ ตัวส่งออกหลายตัวเขียนรหัสองค์ประกอบไว้ที่นี่ | ใช่ |
| Description | ข้อความอิสระ | ใช่ |
| GlobalId | รหัส IFC ถาวรความยาว 22 อักขระขององค์ประกอบ เหมือนกันในทุกการส่งออกขององค์ประกอบเดียวกัน | ไม่ |
| Line | หมายเลขบรรทัด (`#1234`) ขององค์ประกอบในไฟล์ IFC นี้ เปลี่ยนไปทุกครั้งที่ส่งออก | ไม่ |

ด้านล่างคือ **ชุดคุณสมบัติ** เรียงตามชื่อ:

- แต่ละชุดจะเปิดและปิดเมื่อคุณคลิกชื่อ สามชุดแรกจะเปิดอยู่
- ชุดที่มี "(type)" เป็นของชนิดขององค์ประกอบ: "คุณสมบัติของชนิด: การเปลี่ยนแปลงตรงนี้มีผลกับทุกองค์ประกอบของชนิดนี้"
- ชุดปริมาณ (ความยาว พื้นที่ ปริมาตร จำนวน น้ำหนัก) อ่านอย่างเดียว
- รายการและค่าแบบแจกแจงจะแสดงและอ่านอย่างเดียว
- ค่าใช่/ไม่ใช่จะแสดงเป็น **ใช่** หรือ **ไม่ใช่**
- ตัวเลขถูกปัดเป็นทศนิยมสี่ตำแหน่งเพื่อแสดง ความยาว (คุณสมบัติความยาวหรือความยาวของปริมาณ) จะแสดงในหน่วยที่เลือกที่ {{ui:หน่วย}} บนแถบเครื่องมือ พร้อมเครื่องหมายหน่วยข้างๆ และคุณพิมพ์ค่าใหม่ในหน่วยนั้นหรือด้วยเครื่องหมายหน่วยอื่นได้ (2.4 m, 8'-0") BimCraft จะเขียนตัวเลขของไฟล์กลับไปเอง ตัวเลขอื่นแสดงตามที่ไฟล์เก็บไว้
- ค่าว่างแสดงเป็น *ว่าง* ค่าที่ถูกแก้ไขแล้วจะเป็นตัวหนาและมีแถบสีน้ำเงินอยู่ข้างๆ

## คัดลอกค่า

ทุกค่าใน {{ui:คุณสมบัติ}} มีปุ่มคัดลอกเล็กๆ อยู่ข้างๆ คลิกเพื่อใส่ค่านั้นลงคลิปบอร์ดตามที่แสดง เช่น GlobalId หมายเลขซีเรียล หรือค่าของชุดคุณสมบัติใดก็ได้ การคัดลอกจะไม่เริ่มการแก้ไข

ที่ด้านบน {{ui:คัดลอกทั้งหมด}} คัดลอกทุกค่าขององค์ประกอบเป็นข้อความ แยกตามชุด และ {{ui:คัดลอกเป็น CSV}} คัดลอกเป็นแถวของกลุ่ม คุณสมบัติ และค่า เพื่อวางในสเปรดชีต ค่าว่างจะถูกเก็บไว้เพื่อให้ทุกช่องมีแถว วิธีนี้ทำงานเหมือนกันสำหรับองค์ประกอบของโมเดลอื่นที่เปิดอยู่ เมื่อเปิดหลายโมเดล CSV จะเริ่มด้วยคอลัมน์โมเดลที่ระบุชื่อไฟล์

## พาเนลไฟล์ (IFC)

| ช่อง | ความหมาย |
|---|---|
| File, Size | ไฟล์ที่คุณเปิด |
| Schema | เวอร์ชัน IFC เช่น IFC2X3 หรือ IFC4 |
| Project | ชื่อโครงการและชื่อยาวของโครงการ |
| Phase | เฟสของโครงการ หากตัวส่งออกเขียนไว้ |
| Exported from | โปรแกรมที่ส่งออก จากส่วนหัวของไฟล์ |
| Author | ผู้เขียนในส่วนหัวของไฟล์ |
| Exported | วันที่และเวลาในส่วนหัวของไฟล์ |
| Elements | มีองค์ประกอบที่มีรูปทรงกี่ชิ้นที่ถูกวาด |
| Triangles | รูปทรงของพวกมันประกอบเป็นสามเหลี่ยมกี่รูป เป็นตัวบอกว่าโมเดลหนักแค่ไหน |

## พาเนลไฟล์ (ไฟล์โครงการและไฟล์แฟมิลี)

| ช่อง | ความหมาย |
|---|---|
| Kind | Project, Project template, Family หรือ Family template |
| Saved in | รุ่นที่บันทึกไฟล์ล่าสุด |
| Build | บิลด์ที่แน่นอนของรุ่นนั้น |
| Read | BimCraft อ่านไฟล์ไปเท่าไรเมื่อเทียบกับขนาดของไฟล์ |

## พาเนลแบบ (DWG และ DXF)

| ช่อง | ความหมาย |
|---|---|
| Format | รุ่นที่บันทึกแบบ พร้อมรหัสรูปแบบ เช่น AC1032 |
| Units | หน่วยการแทรกของแบบ เมื่อตั้งไว้ |
| Entities | มีวัตถุที่อ่านได้กี่ชิ้น |
| Layers | มีเลเยอร์กี่เลเยอร์ |
| Sheets | มีแผ่น (เลย์เอาต์) กี่แผ่น หรือ ไม่มี |
| Linked drawings | แบบที่เชื่อมโยงกี่แบบที่พบและโหลดแล้ว |
| Equipment | มีอุปกรณ์ที่ติดแท็กบนแผ่นกี่ชิ้น |

## พาเนลโฟลเดอร์

| ช่อง | ความหมาย |
|---|---|
| Folder, Files, Size | โฟลเดอร์ที่คุณเปิด มีไฟล์กี่ไฟล์ และขนาดรวมเท่าใด |
| Models | ไฟล์โครงการและไฟล์แฟมิลี แต่ละไฟล์นับสำเนาสำรองไว้หนึ่งครั้ง |
| CAD drawings, IFC models | มีแต่ละชนิดกี่ไฟล์ |
| Problems | มีสำเนาโมเดลกี่ชุดที่ไม่สมบูรณ์หรืออ่านไม่ได้ หรือ ไม่มี |
