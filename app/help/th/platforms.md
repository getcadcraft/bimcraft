BimCraft ทำงานบนเวอร์ชันปัจจุบันของ Chrome, Edge, Firefox และ Safari บน Mac, Windows และ Linux มุมมอง 3D ต้องใช้ WebGL ซึ่งเบราว์เซอร์ปัจจุบันทุกตัวรองรับ ดู [เบราว์เซอร์และคอมพิวเตอร์](common:browsers) สำหรับสิ่งที่แอปต้องการโดยทั่วไป

## เปิดโฟลเดอร์

| เบราว์เซอร์ | {{ui:เปิดโฟลเดอร์}} ทำดังนี้ | การลากโฟลเดอร์เข้ามา | {{ui:โฟลเดอร์ล่าสุด}} |
|---|---|---|---|
| Chrome, Edge | ตัวเลือกโฟลเดอร์ของเบราว์เซอร์ จากนั้น "Let site view files?" คลิก **View files** | เปิดได้เลยโดยไม่มีคำถาม | ใช่ สำหรับโฟลเดอร์ที่เลือกหรือลากเข้ามา |
| Firefox | ตัวเลือกโฟลเดอร์ของระบบ | เปิดได้เลยโดยไม่มีคำถาม | ไม่ |
| Safari | ตัวเลือกโฟลเดอร์ของระบบ พร้อมปุ่ม **Upload** (ไม่มีการอัปโหลดอะไร) | เปิดได้เลยโดยไม่มีคำถาม | ไม่ |

เบื้องหลัง: Chrome และ Edge ใช้ตัวเลือกการเข้าถึงระบบไฟล์ (File System Access) และจดจำโฟลเดอร์ไว้ได้ Firefox และ Safari ใช้ตัวเลือกโฟลเดอร์รุ่นเก่า ซึ่งส่งไฟล์ทั้งหมดในโฟลเดอร์มาพร้อมกันและจดจำไม่ได้ โฟลเดอร์ที่ลากเข้ามาจะถูกอ่านทีละรายการในทุกเบราว์เซอร์

:::chromium
Brave และเบราว์เซอร์ Chromium บางตัวปิดตัวเลือกโฟลเดอร์ BimCraft จึงใช้ตัวเลือกโฟลเดอร์ของระบบแทน และเบราว์เซอร์อาจถามว่า "Upload *n* files to this site?" ไม่มีการอัปโหลดอะไร ไฟล์จะถูกส่งไปที่แท็บเท่านั้น การลากโฟลเดอร์เข้ามาจะหลีกเลี่ยงคำถามนี้ได้
:::

## Mac, Windows และ Linux

- คำลัดที่เขียนเป็น {{key:Mod+S}} และ {{key:Mod+Z}} คือ Command บน Mac และ Ctrl บน Windows และ Linux
- {{key:Ctrl+Shift+F}} (โหมดหน้าจอ) คือ Control บนทุกแพลตฟอร์ม รวมถึง Mac
- กล่องโต้ตอบไฟล์และโฟลเดอร์ดาวน์โหลดเป็นของระบบของคุณเอง

## เมาส์ แทร็กแพด และการสัมผัส

| อุปกรณ์ป้อนข้อมูล | มุมมอง 3D | แบบ 2D |
|---|---|---|
| เมาส์ | ลากซ้ายเพื่อหมุน ลากขวาเพื่อแพน ล้อเลื่อนเพื่อซูม คลิกเพื่อเลือก | ลากเพื่อแพน ล้อเลื่อนเพื่อซูม ดับเบิลคลิกเพื่อ{{ui:พอดี}} |
| แทร็กแพด | คลิกแล้วลากเพื่อหมุน; {{key:Shift}} หรือ {{key:Mod}} แล้วลากเพื่อแพน; เลื่อนสองนิ้วหรือบีบนิ้วเพื่อซูม | คลิกแล้วลากเพื่อแพน; เลื่อนสองนิ้วหรือบีบนิ้วเพื่อซูม |
| สัมผัส | นิ้วเดียวหมุน สองนิ้วบีบเพื่อซูมและแพน แตะเพื่อเลือก | นิ้วเดียวแพน ยังไม่มีการบีบเพื่อซูม; แตะ {{ui:พอดี}} |

บนแทร็กแพดของ Mac การคลิกขวาคือการคลิกด้วยสองนิ้ว (หรือ Control-click) ดู [คีย์ เมาส์ และแทร็กแพด](common:keys)

แท็บเล็ตและโทรศัพท์เปิดไฟล์เดี่ยวและดูได้ แต่หน้าจอเล็ก เบราว์เซอร์มือถือหลายตัวเลือกโฟลเดอร์ไม่ได้ และโมเดลขนาดใหญ่อาจไม่พอในหน่วยความจำ คอมพิวเตอร์ทำงานได้ดีที่สุด

## ไฟล์ขนาดใหญ่และหน่วยความจำ

BimCraft เก็บทุกอย่างที่อ่านไว้ในหน่วยความจำของแท็บเบราว์เซอร์ ปริมาณที่แท็บใช้ได้ขึ้นอยู่กับเบราว์เซอร์และคอมพิวเตอร์ของคุณมากกว่าตัว BimCraft

| ไฟล์ | ปริมาณที่ถูกอ่าน | สิ่งที่ควรคาดหวัง |
|---|---|---|
| IFC | ทั้งไฟล์ รวมรูปทรง 3D ที่สร้างจากไฟล์ | ขึ้นอยู่กับคอมพิวเตอร์และเบราว์เซอร์ของคุณ โมเดลหลายร้อย MB อาจมากเกินไปสำหรับแล็ปท็อป เมื่อมีเกิน 1.5 ล้านสามเหลี่ยม เส้นขอบจะถูกปิด |
| ไฟล์โครงการและไฟล์แฟมิลี | ประมาณ 40 KB ถึง 100 KB ไม่ว่าไฟล์จะมีขนาดเท่าใด | แม้โมเดลกลางขนาดใหญ่มากก็เปิดได้ในพริบตา แม้จากไดรฟ์เครือข่าย |
| DWG และ DXF | ทั้งไฟล์ | แบบขนาดใหญ่มากจะแสดงข้อความ "แบบนี้มีขนาดใหญ่มาก แสดงเพียงบางส่วนของแบบ" |
| โฟลเดอร์ | รายการไฟล์ บวกไม่กี่ KB ต่อโมเดล | สูงสุด 20,000 ไฟล์ |

หากแท็บหน่วยความจำหมด เบราว์เซอร์จะแสดงหน้าข้อผิดพลาดของตัวเอง ("Aw, Snap!" ใน Chrome เป็นตัวอย่าง) ปิดแท็บอื่น โหลด BimCraft ใหม่แล้วลองอีกครั้ง หรือใช้คอมพิวเตอร์ที่มีหน่วยความจำมากกว่า
