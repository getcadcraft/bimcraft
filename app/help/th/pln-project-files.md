## สิ่งที่คุณจะทำ

นำโครงการที่บันทึกเป็น `.pln` (โครงการ), `.pla` (อาร์ไคฟ์พร้อมไลบรารี), `.tpl` (เทมเพลต) หรือ `.bpn` (สำรองข้อมูล) เข้าสู่ BimCraft ไฟล์เหล่านี้เป็นไฟล์ของ Archicad เอง

## สิ่งที่เปิดได้ในปัจจุบัน

- **ไฟล์โครงการเองยังเปิดไม่ได้** รูปแบบของไฟล์ยังไม่ได้เผยแพร่ และ BimCraft ยังอ่านไม่ได้ เมื่อคุณเปิดไฟล์ BimCraft จะแจ้งและชี้มาที่หน้านี้
- **BimCraft ตรวจสอบไบต์แรกของไฟล์** โครงการ Archicad ตั้งแต่เวอร์ชัน 17 ขึ้นไปจะเริ่มด้วยลายเซ็นสั้นแบบเดียวกัน ดังนั้น BimCraft จึงบอกได้แน่นอนว่าไฟล์เป็นโครงการ Archicad ไฟล์ที่มีชื่อแบบ Archicad แต่ไม่ได้เริ่มด้วยลายเซ็นนั้น น่าจะถูกเปลี่ยนชื่อ เสียหาย หรือมาจากเวอร์ชันเก่า ลายเซ็นไม่สามารถแยกโครงการ อาร์ไคฟ์ และเทมเพลตออกจากกันได้
- **ไฟล์ส่งออก IFC เปิดได้เต็มรูปแบบ**: โมเดลใน 3D ชั้น โซนเป็นพื้นที่ ข้อมูลองค์ประกอบ ชุดคุณสมบัติ และการจัดประเภท พร้อมเครื่องมือ BimCraft ทุกตัว
- **ไฟล์ส่งออก DWG เปิดได้** ในมุมมอง 2D พร้อมเลเยอร์และเลย์เอาต์ และใน {{ui:3D}} หากต้องการแก้ไข ให้ใช้ {{ui:แก้ไขใน CadCraft}}

หรือนำโครงการทั้งหมดเข้ามาเป็นไฟล์ zip เดียว พร้อมมุมมอง เลย์เอาต์ และกลุ่มคุณสมบัติ ดู [เปิดชุดโครงการ](topic:open-project-bundle)

## ส่งออก IFC (โมเดล)

1. เปิดโครงการใน Archicad
2. เลือก **File > Save As** และเลือก **IFC** เป็นชนิดไฟล์
3. เลือกตัวแปลง IFC (ชื่อของ Archicad สำหรับชุดการตั้งค่าการส่งออก IFC) ตัวที่เหมาะกับ BimCraft คือ **IFC4 Reference View** หรือ **IFC2X3 Coordination View 2.0** IFC4X3 ก็เปิดได้เช่นกัน
4. เลือกสิ่งที่จะส่งออก: โครงการทั้งหมด หรือเฉพาะองค์ประกอบที่มองเห็นบนชั้นที่คุณกำลังดู
5. บันทึก จากนั้นคลิก {{ui:เลือกไฟล์}} ใน BimCraft และเลือกไฟล์ `.ifc`

ตรวจสอบค่าเหล่านี้ในการตั้งค่าของตัวแปลงก่อนส่งออก:

- **โซน**: ส่งออกไว้ เพื่อให้ห้องเข้ามาเป็นพื้นที่ คลิก {{ui:พื้นที่}} ใน BimCraft เพื่อดูพื้นที่เหล่านั้น
- **คุณสมบัติและการจัดประเภท**: ส่งออกไว้ เพื่อให้แสดงใน {{ui:คุณสมบัติ}} และใช้กับ {{ui:ค้นหา}} {{ui:สี}} และ {{ui:ผลรวมปริมาณ}} ได้
- **`.ifc` ธรรมดา** ไม่ใช่ `.ifczip` หรือ `.ifcxml` BimCraft เปิดได้เฉพาะ `.ifc` ธรรมดา

## ส่งออก DWG (แบบ)

1. เปิดผัง ภาพตัด หรือเลย์เอาต์ที่ต้องการ
2. เลือก **File > Save As** และเลือก **DWG** เป็นชนิดไฟล์
3. เลือกตัวแปลง DXF-DWG แล้วบันทึก
4. สำหรับชุดแผ่นทั้งชุด ให้บันทึกเลย์เอาต์จาก Layout Book หรือเผยแพร่เป็น DWG
5. เปิด `.dwg` ใน BimCraft แบบที่เชื่อมโยงซึ่งถูกส่งออกมาจะเปิดตามไปด้วยเมื่ออยู่ในโฟลเดอร์เดียวกัน ดู [แบบและภาพที่เชื่อมโยง](topic:dwg-linked-files)

## การแก้ไขปัญหา

- **"… is an Archicad project: its first bytes say so."** ให้แปลว่า **"… เป็นโครงการ Archicad: ไบต์แรกของไฟล์ระบุเช่นนั้น"** ส่งออก IFC หรือ DWG ตามข้างต้น แล้วเปิดไฟล์นั้น
- **"… is named like an Archicad file but does not start like one."** ให้แปลว่า **"… มีชื่อเหมือนไฟล์ Archicad แต่ไม่ได้เริ่มต้นเหมือนไฟล์ Archicad"** ตรวจสอบว่าไฟล์มาจากไหน: อาจเป็นไฟล์ชนิดอื่นที่เปลี่ยนชื่อใหม่ (ลองเปิดด้วยนามสกุลจริง) สำเนาที่คัดลอกไม่สมบูรณ์ หรือโครงการจากเวอร์ชันก่อน 17 หากทำได้ ให้เปิดใน Archicad แล้วส่งออก IFC หรือ DWG
- **โมเดลเปิดขึ้นโดยไม่มีห้อง** โซนไม่ได้ถูกส่งออก เปิดใช้งานในตัวแปลง IFC แล้วส่งออกอีกครั้ง
- **ช่องเปิดไม่ถูกตัด** BimCraft แจ้งไว้ภายใต้ **ยังไม่ได้วาด** ในพาเนล {{ui:ไฟล์}} ให้ส่งออกอีกครั้ง หากยังเป็นเช่นนี้ ให้เปิดโมเดลในโปรแกรมที่สร้างมันและตรวจสอบช่องเปิดที่นั่น
- **ข้อความใน DWG ดูต่างไป** การส่งออกอาจคงฟอนต์ที่ BimCraft ไม่มี BimCraft วาดข้อความด้วยฟอนต์ sans-serif ธรรมดา
