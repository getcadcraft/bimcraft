คนสองคนคัดลอกอาคารหลังเดียวกัน คนหนึ่งวาดปีกตะวันออกและอีกคนวาดปีกตะวันตก ภายหลังสำเนาทั้งสองต้องกลายเป็นหนึ่งเดียว ถ้าพวกเขาแตะวัตถุต่างกัน โปรแกรมก็ทำแทนคนได้

## ทำงานอย่างไร

ผนัง ประตู ระดับ ห้อง และชุดคุณสมบัติทุกชิ้นในไฟล์ IFC มี GlobalId ที่ไม่เปลี่ยน การรวมจะค้นหาวัตถุด้วย id นั้น ไม่ใช่ด้วยตัวเลขที่ไฟล์กำหนดให้ (`#123`) เพราะตัวเลขเปลี่ยนเมื่อโปรแกรมบันทึก ส่วนที่แขวนอยู่กับวัตถุและไม่มี id ของตัวเอง (การวางตำแหน่ง รูปร่าง หน่วย) จะถูกเปรียบเทียบจากเนื้อหาที่บรรจุอยู่

สำเนาทั้งสองต้องเป็น IFC เวอร์ชันเดียวกัน (2x3, 4 หรือ 4.3) การรวมจะคงไฟล์ของคุณไว้ตามเดิม ทั้งลำดับและตัวเลข และเพิ่มสิ่งใหม่เข้าไป ดังนั้น git diff ของการรวมจะแสดงเฉพาะสิ่งที่การรวมเปลี่ยน

## ตั้งค่า

Git ต้องการสองบรรทัดต่อหนึ่งรีโพซิทอรี ทำครั้งเดียว:

```
# .gitattributes
*.ifc merge=cadcraft

# ทำครั้งเดียวบนแต่ละเครื่อง
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

ถ้าไม่ใช้ git ให้รัน `cadcraft merge <base> <ours> <theirs>` Fossil และ Mercurial รับไฟล์สามไฟล์เดียวกันในการตั้งค่าเครื่องมือรวมของตัวเอง ไม่มีการอัปโหลดอะไร ทุกอย่างทำงานบนคอมพิวเตอร์ของคุณ

## กฎ

- แอตทริบิวต์ที่เปลี่ยนเพียงด้านเดียวจะถูกนำมา การเปลี่ยนแปลงเดียวกันทั้งสองด้านจะนำมาเพียงครั้งเดียว
- แอตทริบิวต์เดียวกันที่เปลี่ยนสองแบบ (ระดับเดียวกันถูกเปลี่ยนชื่อสองแบบ) คือ **ความขัดแย้ง** ด้านของคุณจะคงอยู่และรายงานจะแสดงทั้งสองด้าน เปิดผลลัพธ์แล้วแก้ไขด้วยมือ
- รายการของสิ่งต่างๆ (ผนังของระดับ คุณสมบัติของชุด) รวมกันเป็นเซ็ต: สิ่งที่ด้านใดด้านหนึ่งเพิ่มจะถูกเก็บไว้ และสิ่งที่ด้านใดด้านหนึ่งนำออกจะถูกนำออก สองคนที่ต่างเพิ่มผนังให้ระดับเดียวกันจะไม่ขัดแย้งกัน
- วัตถุที่ด้านใดด้านหนึ่งเพิ่มจะถูกเก็บไว้พร้อมรูปร่างและคุณสมบัติ ถูกนำออกด้านหนึ่งและไม่เปลี่ยนอีกด้าน: นำออก ถูกนำออกด้านหนึ่งและเปลี่ยนอีกด้าน: นำออกและรายงาน
- เวลาและผู้เขียนของไฟล์ และประวัติเจ้าของของแต่ละวัตถุ จะคงเป็นของคุณ

รูปร่างจะถูกรวมทั้งชิ้น รูปร่างของผนังมาจากด้านหนึ่งด้านใด ไม่ผสมจุดต่อจุด ไฟล์ IFC แบบบีบอัดและไฟล์ IFCX ไม่ถูกรวม หลังการรวม ให้เปิดผลลัพธ์ใน BimCraft และดูพาเนล ปัญหา ก่อนบันทึก
