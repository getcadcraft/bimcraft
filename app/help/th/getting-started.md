BimCraft คือแอปโมเดลอาคารในตระกูล CadCraft ในรุ่นนี้ BimCraft **เปิด อ่าน และตรวจสอบ** ไฟล์อาคาร และ**แก้ไขข้อมูลในโมเดล IFC** ยังไม่วาดหรือสร้างองค์ประกอบใหม่ ให้มองว่าเป็นโปรแกรมดูและตรวจโมเดลที่ให้คุณแก้ชื่อ แท็ก และค่าคุณสมบัติในไฟล์ IFC ได้ด้วย

สิ่งที่เปิดได้:

| ไฟล์ | สิ่งที่คุณได้ |
|---|---|
| IFC (`.ifc`) | โมเดลเต็มใน 3D: หมุนดู ชั้น คุณสมบัติขององค์ประกอบ และการแก้ไขชื่อและค่าคุณสมบัติ |
| ไฟล์โครงการและไฟล์แฟมิลี (`.rvt`, `.rfa`, `.rte`, `.rft`) | การ์ดไฟล์: รุ่นที่บันทึก ข้อมูลโครงการ ภาพตัวอย่าง และไฟล์ที่เชื่อมโยง ไม่มี 3D |
| DWG และ DXF | แบบใน 2D: พื้นที่โมเดลและทุกแผ่น เลเยอร์ แบบที่เชื่อมโยง มุมมองพิมพ์ และตารางอุปกรณ์สำหรับแบบงานครัวที่ติดแท็ก |
| โฟลเดอร์โครงการ | รายงานของทุกโมเดลในโฟลเดอร์: ไฟล์สำรอง ลิงก์ สำเนาที่เสียหาย และคำแนะนำว่าควรเริ่มจากไฟล์ใด |

ทุกอย่างเกิดขึ้นในเบราว์เซอร์บนคอมพิวเตอร์ของคุณ **ไม่มีการอัปโหลดอะไร** ดูรายละเอียดใน [ไฟล์ที่ BimCraft เปิดและบันทึก](topic:files)

## เปิด BimCraft

1. เปิด BimCraft ในเบราว์เซอร์รุ่นปัจจุบัน Chrome, Edge, Firefox และ Safari ใช้ได้ทั้งหมด [เบราว์เซอร์ อุปกรณ์ และหน่วยความจำ](topic:platforms) ระบุความแตกต่าง
2. รอหน้าจอว่างที่เขียนว่า "เปิดโมเดลอาคาร"

:::note
BimCraft ทำงานในเบราว์เซอร์ และบนเดสก์ท็อปภายใน CadCraft Studio ร่วมกับแอปอื่น ๆ ยังไม่มีการบันทึกบนคลาวด์: คุณเปิดไฟล์จากคอมพิวเตอร์ของคุณและบันทึกสำเนากลับลงไป
:::

## เปิดโมเดลแรกของคุณ

วิธีที่เร็วที่สุดในการดูว่า BimCraft ทำอะไรได้คือไฟล์ IFC

1. คลิก {{ui:เลือกไฟล์}} ตรงกลางหน้าจอ
2. เลือกไฟล์ `.ifc` ใน {{pick:mac=Finder|windows=File Explorer|linux=ตัวจัดการไฟล์ของคุณ}} แล้วยืนยัน
3. รอขณะที่บรรทัดสถานะที่ด้านล่างหน้าจอแสดง "กำลังเริ่มเครื่องยนต์ IFC…" แล้วจึง "กำลังสร้างรูปทรง"

คุณควรเห็นโมเดลใน 3D ตรงกลาง พาเนล {{ui:ไฟล์}} และรายการ {{ui:ชั้น}} ทางซ้าย และพาเนล {{ui:คุณสมบัติ}} ว่างทางขวา บรรทัดสถานะลงท้ายด้วย "เปิด" และจำนวนองค์ประกอบ

:::tip
คุณลากไฟล์จาก {{pick:mac=Finder|windows=File Explorer|linux=ตัวจัดการไฟล์ของคุณ}} ไปวางบนหน้าได้โดยตรงด้วย หน้าจอจะแสดง "วางเพื่อเปิด" ขณะที่คุณลาก
:::

:::offline
เครื่องยนต์ IFC โหลดจากไซต์ครั้งแรกที่คุณเปิดโมเดล IFC เว้นแต่ BimCraft ถูกบันทึกไว้สำหรับใช้ออฟไลน์ แบบ DWG และ DXF ไฟล์โครงการ และโฟลเดอร์ไม่ต้องการอะไรเพิ่ม: ตัวอ่านของมันเป็นส่วนหนึ่งของแอป หากปุ่มของแถบแอปเขียนว่า {{ui:พร้อมใช้ออฟไลน์}} ทุกอย่างเปิดได้ออฟไลน์ หากไม่ใช่ โมเดล IFC จะเปิดไม่ได้จนกว่าคุณจะเชื่อมต่ออีกครั้ง เว้นแต่มีโมเดลหนึ่งเปิดไว้แล้วในแท็บนี้ ดู [ออนไลน์และออฟไลน์](topic:online-offline)
:::

:::online
จะไปที่ที่ไม่มีการเชื่อมต่อใช่ไหม คลิก {{ui:บันทึกสำหรับออฟไลน์}} ในแถบแอปและรอ {{ui:พร้อมใช้ออฟไลน์}} สำเนาที่บันทึก (ประมาณ 11 MB) รวมเครื่องยนต์ IFC ไว้ด้วย ดู [การทำงานแบบออฟไลน์](common:offline)
:::

## ดูรอบ ๆ

:::mouse
1. ลากด้วยปุ่มซ้ายของเมาส์เพื่อหมุนรอบโมเดล
2. เลื่อนล้อเพื่อซูม
3. ลากด้วยปุ่มขวาของเมาส์เพื่อแพน บน Mac trackpad ให้กด {{key:Shift}} ค้างแล้วลากแทน
4. กด {{key:F}} หรือคลิก {{ui:พอดี}} เพื่อดูทั้งโมเดลอีกครั้ง
:::

:::touch
1. ลากด้วยนิ้วเดียวเพื่อหมุน
2. ถ่างสองนิ้วเพื่อซูม และเลื่อนสองนิ้วพร้อมกันเพื่อแพน
3. แตะ {{ui:พอดี}} เพื่อดูทั้งโมเดลอีกครั้ง
:::

## ทำสิ่งจริงหนึ่งอย่าง: แก้แท็ก

1. คลิกผนัง ประตู หรือองค์ประกอบใดก็ได้ในโมเดล องค์ประกอบจะเป็นสีน้ำเงิน และคุณสมบัติของมันปรากฏทางขวา
2. ในพาเนล {{ui:คุณสมบัติ}} คลิกค่าถัดจาก **แท็ก**
3. พิมพ์แท็กใหม่แล้วกด {{key:Enter}}
4. ดูส่วน {{ui:การเปลี่ยนแปลง}} ที่เปิดขึ้นทางซ้าย: การเปลี่ยนแปลงของคุณแสดงเป็นรายการพร้อมค่าเดิมและค่าใหม่

## บันทึกสำเนา

1. คลิก {{ui:บันทึกเป็น IFC}} ในส่วน {{ui:การเปลี่ยนแปลง}} หรือกด {{key:Mod+S}}
2. หาไฟล์ใหม่ในโฟลเดอร์ดาวน์โหลดของคุณ ไฟล์ตั้งชื่อตามต้นฉบับพร้อมเติม " (edited)" เช่น `Clinic (edited).ifc`

ไฟล์ต้นฉบับของคุณจะไม่ถูกเปลี่ยนเลย [เปลี่ยนคุณสมบัติ IFC และบันทึกสำเนาที่แก้ไข](topic:edit-ifc-properties) อธิบายการแก้ไขอย่างครบถ้วน
