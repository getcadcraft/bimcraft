## สิ่งที่จะทำ

เปิด**บันเดิลโครงการ** (`.ccbundle.zip`) และทำงานกับโครงการตามที่จัดระเบียบไว้ ได้แก่ มุมมอง เลย์เอาต์ และกลุ่มคุณสมบัติ ซ้อนอยู่บนโมเดล

บันเดิลประกอบด้วย:

- โมเดลในรูปแบบ IFC
- เลย์เอาต์ในรูปแบบ PDF และ DWG
- รายการสิ่งที่ IFC ไม่ได้เก็บไว้: มุมมอง (แต่ละมุมมองพร้อมชั้น การรวมเลเยอร์ และมาตราส่วน) เลย์เอาต์และแบบที่วางบนเลย์เอาต์ นิยามคุณสมบัติในกลุ่มของแต่ละชุด การจัดประเภท และมาตรฐาน เช่น เลเยอร์ ชุดปากกา ชนิดเส้น การเติม พื้นผิว และคอมโพสิต

บันเดิลถูกสร้างโดยสคริปต์โอเพนซอร์สที่ทำงานภายใน Archicad และขอรายการเหล่านี้จาก Archicad โดยตรง BimCraft ไม่อ่านไฟล์ `.pln` หรือ `.tpl` โดยตรง ดู [เปิดไฟล์โครงการ .pln และ .pla](topic:pln-project-files)

## สร้างบันเดิล

สคริปต์นี้เป็นเวอร์ชันตัวอย่าง ยังไม่ได้ทดสอบกับ Archicad ทุกเวอร์ชัน ดาวน์โหลดได้จาก [github.com/getcadcraft/bim-project-bundle](https://github.com/getcadcraft/bim-project-bundle) ต้องใช้ Archicad 24 ขึ้นไปและ Python 3.8 ขึ้นไป ไม่ต้องติดตั้งอย่างอื่น

1. บันทึก `archicad_bundle.py` ลงในโฟลเดอร์ เช่น `C:\cc-bundle`
2. ใน Archicad เปิดโครงการ แล้วสร้างชุดตัวเผยแพร่ชื่อ **CadCraft bundle** ให้ตรงทุกตัวอักษร ได้แก่ มุมมอง 3D เป็น IFC ทุกเลย์เอาต์เป็น PDF และทุกเลย์เอาต์อีกครั้งเป็น DWG เผยแพร่เป็นไฟล์บนดิสก์ในโฟลเดอร์เดียวแบบไม่มีโฟลเดอร์ย่อย
3. เมื่อโครงการเปิดอยู่ รัน `python archicad_bundle.py --probe --out .` หนึ่งครั้ง คำสั่งนี้อ่านอย่างเดียว และเขียนไฟล์ `probe.json`
4. รัน `python archicad_bundle.py --out . --translator "IFC4 Reference View"` (ใช้ตัวแปลง IFC ที่เลือกไว้) Archicad จะเผยแพร่ชุดนั้น และสคริปต์จะเขียน `<project>.ccbundle.zip`

หากการเผยแพร่ผ่านสคริปต์ล้มเหลว ให้เผยแพร่ชุดนั้นด้วยตนเอง แล้วรัน `python archicad_bundle.py --out . --no-publish --files <folder>\*.ifc <folder>\*.pdf <folder>\*.dwg` README ของที่เก็บโค้ดมีตัวเลือกทั้งหมด หากมีบางอย่างไม่ถูกนำเข้า ให้เปิด issue ที่นั่นและแนบ `probe.json`

## เปิดบันเดิล

1. คลิก {{ui:Choose a file}} หรือลาก `.ccbundle.zip` มาวางบน BimCraft ในโฟลเดอร์ที่เปิดด้วย {{ui:Open a folder}} บันเดิลจะแสดงอยู่ภายใต้ **บันเดิลโครงการ** คลิกชื่อของบันเดิลนั้น
2. โมเดลจะเปิดเหมือน IFC ทุกไฟล์ และส่วน **บันเดิลโครงการ** จะปรากฏทางด้านซ้าย ใต้ข้อมูลของไฟล์

ไม่มีการอัปโหลด บันเดิลถูกอ่านบนคอมพิวเตอร์ทีละไฟล์ จึงไม่มีการคัดลอกโมเดลขนาดใหญ่ซ้ำสองครั้ง

## แสดงมุมมอง

ภายใต้ **มุมมอง** จะจัดกลุ่มตามโฟลเดอร์ที่มีในโครงการ คลิกชื่อของมุมมอง:

- **ผังพื้น** แสดงเฉพาะชั้นของมัน มองจากด้านบน
- **การรวมเลเยอร์** ซ่อนองค์ประกอบบนเลเยอร์ที่การรวมนั้นซ่อน แถบสถานะบอกจำนวนองค์ประกอบที่ถูกซ่อน
- **มาตราส่วน** แสดงข้างชื่อและในแถบสถานะ
- **มุมมอง 3D** แสดงทุกชั้น

หากต้องการแสดงทุกอย่างอีกครั้ง ให้ใช้ {{ui:Show all}} ใน {{ui:Show}} แล้วติ๊กทุกชั้น

:::note
BimCraft หาเลเยอร์จากการกำหนดเลเยอร์ในไฟล์ IFC หากไฟล์ IFC ถูกส่งออกโดยไม่มีข้อมูลนี้ การรวมเลเยอร์จะไม่ซ่อนอะไรเลย และแถบสถานะจะแสดงว่าซ่อนไว้ 0 องค์ประกอบ
:::

## เปิดเลย์เอาต์

ภายใต้ **เลย์เอาต์** แต่ละเลย์เอาต์จะแสดงหมายเลข ชื่อ ขนาดกระดาษ และมุมมองที่วางอยู่บนนั้น

- **PDF** บันทึกไฟล์ PDF ของเลย์เอาต์จากบันเดิล
- **DWG** เปิดแบบของเลย์เอาต์ในมุมมอง 2D คลิกมุมมองใดก็ได้เพื่อกลับไปที่โมเดล
- **เปิดใน …** ส่งไฟล์ของเลย์เอาต์ไปยังแอปที่ทำงานกับไฟล์นั้น ในแท็บใหม่: PDF ไปยัง MarkupCraft และ DWG ไปยัง CadCraft จะแสดงเฉพาะเมื่อแอปนั้นเปิดอยู่ข้าง BimCraft ไฟล์จะถูกอ่านจากบันเดิลตอนแท็บโหลด และไม่มีการอัปโหลด

เลย์เอาต์ที่ไม่มีทั้งสองอย่างจะแสดง **ไม่มีไฟล์ในบันเดิล**

## ดูคุณสมบัติในกลุ่มของโครงการ

เลือกองค์ประกอบ **กลุ่มคุณสมบัติ** จะแสดงคุณสมบัติขององค์ประกอบภายใต้กลุ่มที่โครงการกำหนดไว้ จับคู่ผ่านชุดคุณสมบัติและชื่อที่นิยามให้กับ IFC หรือถ้าไม่มีก็จับคู่ด้วยชื่อ ส่วนที่เหลือยังคงอยู่ใน {{ui:Properties}} ตามปกติ **นิยามคุณสมบัติ** แสดงทุกนิยามพร้อมกลุ่ม ประเภท และชื่อ IFC

## มาตรฐานและหมายเหตุ

- **มาตรฐาน** นับเลเยอร์ การรวมเลเยอร์ ชุดปากกา ชนิดเส้น การเติม พื้นผิว คอมโพสิต และวัสดุในบันเดิล
- **หมายเหตุ** แสดงสิ่งที่สคริปต์ดึงจาก Archicad เวอร์ชันนั้นไม่ได้ ฟิลด์ใดก็ตามที่ BimCraft อ่านไม่ได้ และไฟล์ใดก็ตามที่บันเดิลระบุไว้แต่ไม่มีอยู่จริง

## การแก้ปัญหา

- **"… เป็นไฟล์ zip แต่ไม่ใช่บันเดิลโครงการ"** ไฟล์ zip ไม่มี `manifest.json` ให้แตกไฟล์แล้วเปิด `.ifc` ที่อยู่ข้างใน
- **"… เป็นบันเดิลโครงการที่ใหม่กว่าที่ BimCraft นี้อ่านได้"** อัปเดต BimCraft
- **"… ไม่มีโมเดลที่ manifest ระบุไว้"** ไฟล์ zip ถูกตัดหรือถูกแก้ไข ให้สร้างบันเดิลใหม่
- **มุมมองแสดงทุกชั้น** ชั้นของมุมมองไม่มีอยู่ใน IFC ของโมเดล (แถบสถานะจะบอก) ตรวจสอบว่าการส่งออก IFC รวมชั้นนั้นไว้ด้วย
