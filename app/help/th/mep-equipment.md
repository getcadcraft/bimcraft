## สิ่งที่คุณจะทำ

วางอุปกรณ์ที่ปลายของท่อและท่อลม แต่ละชิ้นเป็นรูปทรงทั่วไปที่กำหนดขนาดด้วยค่าที่คุณพิมพ์ โดยมีการเชื่อมต่อเป็น **พอร์ต**: ตรงไหนที่ท่อหรือท่อลมต่อเข้ามา ระบบใด ทิศทางการไหลไปทางไหน และขนาดเท่าไร ท่อและท่อลมที่วาดจากพอร์ตจะรับขนาดและระบบของพอร์ต และยึดติดกับพอร์ต ดู [เชื่อมท่อและท่อลมเข้ากับอุปกรณ์](topic:mep-connections)

:::note
นี่เป็นตัวช่วยในการร่างและประสานงาน ขนาดกำหนดโดยวิศวกร อุปกรณ์นี้ไม่ใช่ผลิตภัณฑ์ของผู้ผลิต: ไม่มีความจุ น้ำหนัก หรือขนาดการเชื่อมต่อของผู้ผลิต นำโมเดลของผู้ผลิตจากโปรแกรม MEP ของคุณเข้ามาเป็น IFC เมื่อจำเป็น
:::

## วางชิ้นส่วน

1. เปิด {{ui:วาด}} เปิด {{ui:บิลด์}} แล้วเลือก {{ui:อุปกรณ์}}
2. ในแถบ เลือกประเภทและพิมพ์ขนาด แต่ละประเภทต้องการขนาดของตัวเอง:

| ประเภท | คุณพิมพ์ | พอร์ตของมัน |
|---|---|---|
| ชุดจ่ายลม (AHU) | ยาว, กว้าง, สูง; ช่องจ่ายและช่องกลับ; ขนาดท่อคอยล์และระบบ; ขนาดท่อน้ำทิ้ง | ท่อลมจ่ายออก, ท่อลมกลับเข้า, คอยล์เข้าและออก, ท่อน้ำทิ้ง |
| พัดลมในแนวท่อ | เส้นผ่านศูนย์กลาง, ยาว, ระบบ | ท่อลมเข้าและออก |
| ปั๊ม | ขนาดท่อ, ระบบ | ทางเข้าและทางออก |
| หม้อต้มน้ำ | ยาว, กว้าง, สูง, ขนาดท่อ, ขนาดแก๊ส, เส้นผ่านศูนย์กลางปล่องไอเสีย | น้ำร้อนจ่ายออกและกลับเข้า, แก๊สเข้า, ปล่องไอเสียออก |
| เครื่องทำน้ำอุ่น | เส้นผ่านศูนย์กลาง, สูง, ขนาดท่อ, แก๊สหรือไฟฟ้า | น้ำเย็นเข้า, น้ำร้อนออก (และแก๊สเข้ากับปล่องไอเสียเมื่อใช้แก๊ส) |
| ยูนิตเทอร์มินัล | ยาว, กว้าง, สูง, ทางเข้ากลม, ความกว้างและความสูงของทางออก | ลมจ่ายเข้าและออก |
| ดิฟฟิวเซอร์ | หน้า, คอ, ระบบ | คอของมัน (ลมเข้า) |
| กริลล์ | ความกว้างและความสูงของหน้า, ความกว้างและความสูงของคอ, ระบบ | คอของมัน (ลมออกไปยังท่อลมกลับหรือท่อระบาย) |
| ถัง | เส้นผ่านศูนย์กลาง, สูง, ขนาดท่อ, ระบบ | ทางเข้าด้านบน, ทางออกใกล้ด้านล่าง |
| หม้อน้ำ | ยาว, สูง, ลึก, ขนาดท่อ, ระบบ | น้ำไหลเข้าด้านบนของปลายด้านหนึ่ง น้ำกลับออกด้านล่างของอีกปลายหนึ่ง |
| คอนเวคเตอร์ / เครื่องทำความร้อนแบบแผง | ยาว, สูง, ลึก, ขนาดท่อ, ระบบ | น้ำไหลเข้าปลายด้านหนึ่ง น้ำกลับออกอีกปลายหนึ่ง |
| ตระกูลของผู้ผลิต | ตระกูล (ดู [ข้อกำหนดท่อ วาล์ว ดัมเปอร์ และตระกูลของผู้ผลิต](topic:pipe-specs)) | พอร์ตที่ตระกูลนั้นกำหนดให้ |

3. ตั้ง **ที่ความสูง** คือความสูงของฐานเหนือระดับ ความสูงของดิฟฟิวเซอร์หรือกริลล์คือความสูงของหน้า: พิมพ์ความสูงของเพดาน
4. พิมพ์ **แท็ก** ถ้าต้องการ (`AHU-1`) ชิ้นถัดไปของประเภทเดียวกันจะได้หมายเลขถัดไป
5. เลื่อนตัวชี้ไปบนผัง รอยเท้าและพอร์ตจะตามไป กด {{key:R}} เพื่อหมุน 90° คลิกตรงที่ต้องการวาง

ขนาดท่อเป็นขนาดท่อเหล็กมาตรฐาน (ASME B36.10M) ท่อที่วาดจากปั๊มด้วยวัสดุอื่นจะรับขนาดระบุเดียวกันในวัสดุของตัวเอง

## เปลี่ยนหรือลบ

เลือกชิ้นส่วนบนผังหรือในมุมมอง 3D คุณสมบัติจะแสดงขนาดทุกค่าที่คุณพิมพ์ แท็ก X, Y, ความสูงและการหมุน และพอร์ตแต่ละพอร์ต: ขนาด ระบบ ทิศทางการไหล และว่ามีอะไรเชื่อมต่ออยู่หรือไม่ การเปลี่ยนแปลงแต่ละครั้งคือหนึ่งขั้นของ {{ui:เลิกทำ}} ช่วงท่อที่ยึดกับพอร์ตจะเคลื่อนที่ไปด้วย {{key:Delete}} ลบชิ้นนั้น ช่วงท่อที่เคยยึดอยู่จะคงอยู่ และการตรวจการเชื่อมต่อจะแสดงรายการไว้

## ในไฟล์ IFC

แต่ละประเภทบันทึกเป็นคลาส IFC ของมัน: IfcUnitaryEquipment (ชุดจ่ายลม) IfcFan IfcPump IfcBoiler (หม้อต้มน้ำ; เครื่องทำน้ำอุ่นคือ IfcBoiler ประเภท water ที่มี object type "Water heater") IfcAirTerminalBox (ยูนิตเทอร์มินัล) IfcAirTerminal (ดิฟฟิวเซอร์ กริลล์) และ IfcTank พร้อมประเภทที่ใช้ร่วมกันสำหรับทุกชิ้นของประเภทและขนาดเดียวกัน ไฟล์ IFC2X3 จะได้ IfcEnergyConversionDevice, IfcFlowMovingDevice, IfcFlowController, IfcFlowTerminal และ IfcFlowStorageDevice พร้อมประเภทที่ตรงกัน แต่ละพอร์ตเป็น IfcDistributionPort วางตรงตำแหน่งการเชื่อมต่อ หันออก พร้อมทิศทางการไหลและระบบ โปรแกรมอื่นจึงอ่านได้ว่าช่วงท่อใดเชื่อมกับพอร์ตใด ชิ้นนั้นเข้าร่วมระบบของทุกพอร์ต และมีชุดรายการไลบรารีเช่นเดียวกับรายการไลบรารีที่วางทุกรายการ
