ใน CadCraft Studio รายการเอนจินสามารถมี**การเชื่อมโยง**ไปยังโปรเจกต์ Unreal Engine ได้ ทางเดียวเท่านั้น คือจาก CadCraft ไปยัง Unreal

## ส่งฉาก

1. เลือกรายการ Unreal ในรายการเอนจิน ครั้งแรก Studio จะขอให้เลือกโฟลเดอร์ของโปรเจกต์ (โฟลเดอร์ที่มีไฟล์ `.uproject`) และจำไว้
2. คลิก {{ui:Send}} Studio จะเขียน `CadCraft/<file name>/` ไว้ในโปรเจกต์: ฉากเป็นไฟล์ USD ไฟล์การตั้งค่า ไฟล์โปรไฟล์แสง และไฟล์เลเยอร์เล็กสองไฟล์
3. เปลี่ยนโมเดล บันทึก แล้วส่งอีกครั้ง มีเพียงฉากและไฟล์การตั้งค่าที่ถูกแทนที่

## การแก้ไขของคุณปลอดภัย

สเตจที่ Unreal เปิดคือรูทเลเยอร์เล็กๆ ที่สร้างครั้งเดียว มีเลเยอร์สองชั้นอยู่ข้างใต้: **ของคุณ** อยู่ด้านบน (`<name>.user.usda` ว่างตอนแรก และ CadCraft ไม่เขียนทับ) และฉากของ CadCraft อยู่ด้านล่าง การแก้ไขที่บันทึกลงในเลเยอร์ของคุณเองจะคงอยู่เมื่อส่งฉากอีกครั้ง ไฟ และแอ็กเตอร์อื่นที่วางในเลเวลของ Unreal อยู่นอกสเตจ และก็ไม่ถูกแตะต้องเช่นกัน

## หากไม่มี Studio

ในเบราว์เซอร์ หรือบนคอมพิวเตอร์ที่ Studio ไม่พบ Unreal ให้เลือก **โฟลเดอร์โปรเจกต์ Unreal (.zip)** ในรายการเอนจิน แล้วคลิก {{ui:Render}} ระบบจะบันทึกโฟลเดอร์เดียวกันเป็น zip: แตกไฟล์ลงในโฟลเดอร์ `CadCraft` ของโปรเจกต์ เปิด **รวมไฟล์สเตจ** ไว้ในครั้งแรก และปิดไว้สำหรับการบันทึกครั้งต่อๆ ไป zip จะมีเพียงฉากและไฟล์การตั้งค่า และเลเยอร์ของคุณจะไม่ถูกแทนที่

:::note
ปลั๊กอิน Unreal ที่เปิดสเตจ ใช้ดวงอาทิตย์ โคมไฟ กล้อง และการเปิดรับแสง ติดตามการส่งแต่ละครั้ง และเรนเดอร์จากกล้อง ยังไม่ได้เผยแพร่ และยังไม่เคยรันใน Unreal จนกว่าจะเผยแพร่ ระหว่างนี้ Send จะวางไฟล์ไว้ในโปรเจกต์ และเครื่องมือ USD ของ Unreal เองสามารถเปิดไฟล์เหล่านั้นได้ ระบบแรกที่รองรับคือ Windows ตามด้วย macOS
:::
