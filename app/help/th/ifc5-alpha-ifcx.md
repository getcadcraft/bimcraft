IFC5 alpha (ไฟล์ที่ลงท้ายด้วย {{ui:.ifcx}}) คือรูปแบบไฟล์ที่ buildingSMART ยังคงออกแบบอยู่ ยังไม่เป็นทางการ ไฟล์และการตีความของเราต่อไฟล์เหล่านั้นอาจเปลี่ยนแปลงได้ นี่คือเหตุผลที่เป็นตัวเลือกทดลอง และควรอ่านก่อน

## เปิดใช้งาน

1. เลือก {{ui:Settings}} แล้วเลือกส่วน {{ui:IFC5 alpha (IFCX)}} ในแท็บ BimCraft
2. ทำเครื่องหมาย {{ui:IFC5 alpha (IFCX) - the format is still changing; read first}}

ตัวเลือกนี้ปิดเป็นค่าเริ่มต้น ขณะปิดอยู่ ไฟล์ .ifcx จะถูกปฏิเสธพร้อมประโยคที่ชี้มายังหน้านี้ {{ui:Open IFC5 alpha (.ifcx)…}} และปุ่มส่งออก {{ui:IFC5 alpha}} จะปรากฏเมื่อเปิดใช้งาน

## เปิด

- เลือกไฟล์ .ifcx ด้วย {{ui:Open a file or folder}} (จะแทนที่โมเดลที่เปิดอยู่ หลังจากถามเรื่องการแก้ไขตามปกติ) หรือ
- เลือก {{ui:Open IFC5 alpha (.ifcx)…}} แล้วเลือกหลายไฟล์พร้อมกัน ได้แก่ ไฟล์นั้น เลเยอร์ และไฟล์สคีมาที่ไฟล์นั้นนำเข้า เมื่อมีโมเดลเปิดอยู่แล้ว ไฟล์ใหม่จะถูก**เพิ่มไว้ข้างกัน** เครื่องหมาย x ในรายการโมเดลจะนำออก ซึ่งเป็นการย้อนกลับ

ไฟล์ IFCX แสดงรายการโหนด (พาธ โหนดลูก สิ่งที่สืบทอด และแอตทริบิวต์) ไฟล์หลายไฟล์อาจอธิบายโหนดเดียวกันได้ ไฟล์ที่มาทีหลัง (เลเยอร์) จะทับแอตทริบิวต์ของไฟล์ก่อนหน้า และโหนดลูกแบบ null จะลบลูกนั้นออก BimCraft จะประกอบไฟล์เหล่านี้เข้าด้วยกัน แล้ววาดผลลัพธ์เป็นโมเดล IFC4 ขนาดเล็ก ได้แก่ โครงการ ไซต์ อาคาร ชั้น และองค์ประกอบ พร้อมชื่อ คลาส คุณสมบัติ ปริมาณ สี และเมช

ไม่มีการดึงข้อมูลจากเครือข่าย ไฟล์สคีมาที่ไฟล์นำเข้า (เช่น `ifc@v5a.ifcx`) จะถูกใช้เฉพาะเมื่อเลือกมาพร้อมกับไฟล์เท่านั้น มิฉะนั้นรายงานจะแจ้งไว้ และแอตทริบิวต์จะถูกอ่านโดยไม่ตรวจสอบชนิดข้อมูล

### รายงาน

หลังเปิดไฟล์ รายงานจะแสดงสิ่งที่การอ่านพบ ได้แก่ ข้อมูลที่ไม่ตรงกับสคีมา ไฟล์สคีมาที่ไม่ได้ให้มา และแอตทริบิวต์ที่ไม่มีความหมายใน IFC ที่นี่ แอตทริบิวต์ที่ไม่มีการแมปจะถูก**เก็บไว้**ในโมเดล ไม่ถูกทิ้ง และจะถูกเขียนกลับเมื่อส่งออก

## สิ่งที่แปลงเป็นอะไร

| ในไฟล์ IFCX | ใน BimCraft |
|---|---|
| โหนดที่มีคลาส IFC (project, site, building, storey, wall …) | องค์ประกอบ IFC4 ที่ตรงกัน คลาสที่การอ่านนี้ไม่รู้จักจะกลายเป็น building element proxy |
| ชื่อที่โหนดมีภายใต้พาเรนต์ | ชื่อขององค์ประกอบ |
| แอตทริบิวต์ที่มีชนิดปริมาณ (Length, Area, Volume, Mass …) | ชุดปริมาณ IFC4 ชื่อ `Qto_IFCX` (ชุด `Qto_*` ของ IFC4 ยังคงเป็นชุด IFC4) |
| แอตทริบิวต์คุณสมบัติอื่น | ชุดคุณสมบัติชื่อ `Pset_IFCX` |
| แอตทริบิวต์เมชและการแปลง | สามเหลี่ยมและตำแหน่งขององค์ประกอบ เมชที่มองไม่เห็นจะไม่ถูกวาด |
| สี ความทึบ วัสดุ การจำแนกประเภท | สไตล์พื้นผิว วัสดุ และการจำแนกประเภทขององค์ประกอบ |

หน่วยถือเป็นเมตร และแกน Z ชี้ขึ้น alpha ระบุว่าจะมีการบันทึกหน่วยในภายหลัง

## ส่งออก

เลือก {{ui:IFC5 alpha}} บนแถบเครื่องมือ อ่านหมายเหตุ แล้วคลิก {{ui:Export .ifcx}} ไฟล์จะมีส่วนหัวของ CadCraft (ผู้เขียน CadCraft เวอร์ชัน ifcx_alpha) และระบุในตัวเองว่าเป็นรูปแบบ alpha แต่ละโมเดลจะถูกเขียนในพิกัดของไฟล์เอง หน่วยเป็นเมตร พร้อมชื่อ คลาส ชุดคุณสมบัติ ปริมาณ (เป็นแอตทริบิวต์พร้อมชนิด) สี และสามเหลี่ยม เลเยอร์และการสืบทอดจะถูกเขียนแบบรวมเป็นชั้นเดียว ควรตรวจสอบไฟล์ในโปรแกรมที่จะส่งไปให้

## ข้อจำกัด

- เรขาคณิตโค้ง (เส้นโค้ง พื้นผิว) จะไม่ถูกอ่าน: อ่านเฉพาะเมชสามเหลี่ยม
- ประตูและหน้าต่างที่ซ้อนอยู่ในผนังจะถูกวางบนชั้น และไม่ได้เชื่อมโยงกับผนังที่เป็นต้นทาง
- ชื่อชุด `Qto_*` ของ IFC4 จะถูกเก็บไว้เป็นกลุ่มแอตทริบิวต์ของเอง (`cadcraft::qto::…`) เพราะสคีมา alpha มาตรฐานมีชื่อปริมาณเพียงไม่กี่ชื่อ
- รูปแบบอาจเปลี่ยนแปลงโดยที่เราควบคุมไม่ได้ ไฟล์ที่สร้างวันนี้อาจอ่านไม่ได้ในวันพรุ่งนี้
