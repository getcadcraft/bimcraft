## สิ่งที่ทำได้

ใน CadCraft Studio แต่ละหน้าต่างของแอปจะแจ้ง Studio เมื่อขั้นตอนเสร็จ (เช่น วาดผนังเสร็จ หรือยอมรับชุดผนังจากการสแกน) Studio เก็บขั้นตอนเหล่านั้นตามลำดับที่ทำ และสามารถขอให้หน้าต่างที่สร้างขั้นตอนล่าสุดเลิกทำขั้นตอนนั้นได้ โดยใช้ระบบเลิกทำของหน้าต่างนั้นเอง {{key:Ctrl+Z}} ภายใน BimCraft ยังคงเป็นของ BimCraft และแจ้งให้ Studio ทราบด้วย

## ข้อควรทราบ

- Studio จะขอให้หน้าต่างเลิกทำก็ต่อเมื่อรายการเลิกทำของหน้าต่างนั้นยังตรงกับตอนที่ขั้นตอนนั้นทิ้งไว้ หลังจากบันทึก (ซึ่งเริ่มรายการการเปลี่ยนแปลงใหม่) หรือหลังจากสลับโมเดลที่แก้ไข BimCraft จะตอบว่ารายการเปลี่ยนไปแล้ว และ Studio จะข้ามหน้าต่างนี้ ไม่มีการบังคับ
- การเลิกทำผลของแอปหนึ่งในอีกแอปหนึ่งยังไม่ได้สร้าง
- นอก Studio ไม่มีการเปลี่ยนแปลงใด ๆ
- รายการเมนู Studio ที่ขอให้เลิกทำจะมาพร้อมบิลด์ Studio หากยังไม่มี ขั้นตอนจะถูกรายงาน แต่ไม่มีรายการเมนูใดใช้ขั้นตอนเหล่านั้น
