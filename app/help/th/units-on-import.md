## สิ่งที่ทำได้

นำไฟล์เข้ามาและให้แน่ใจว่าไฟล์เข้ามาในขนาดที่ถูกต้อง

## ขั้นตอน

1. เปิดหรือเพิ่มไฟล์ตามปกติ: {{ui:Open}}, {{ui:Files}} ของไลบรารี, {{ui:Point clouds}} หรือ Build › From a drawing
2. หากไฟล์ระบุหน่วยไว้ จะไม่มีการถาม แถบสถานะจะบอกว่าไฟล์ระบุหน่วยใด
3. หากไม่ระบุ กล่องโต้ตอบจะถาม **หน่วยของ** ไฟล์ เลือกว่าหนึ่งหน่วยในไฟล์คือหน่วยใด แล้วคลิก {{ui:Use these units}} จะยังไม่มีอะไรถูกวางจนกว่าจะตอบ
4. {{ui:Cancel}} (หรือ {{key:Esc}}) จะไม่นำอะไรเข้ามา

## ไฟล์ใดระบุหน่วยไว้

- **IFC**: ระบุหน่วยความยาว และ "เปิดแล้ว" จะบอกว่าเป็นหน่วยใด IFC ที่ไม่ระบุหน่วยจะถูกถามก่อนเปิด คำตอบจะถูกเขียนลงในโมเดล ดังนั้นไฟล์จะระบุหน่วยไว้เมื่อบันทึกแล้ว
- **DWG และ DXF**: หน่วยการแทรกของแบบ แบบที่ไม่มีหน่วยนี้จะถูกถาม (ไฟล์ในไลบรารี, Build › From a drawing, ภูมิประเทศจากเส้นชั้นความสูง)
- **รายการจุด** สำหรับภูมิประเทศ ไม่ระบุหน่วย จึงถูกถาม
- **จุดกลุ่มเมฆ**: LAS และ LAZ ที่มีระบบพิกัด, E57, PTX และ PLY ระบุหน่วยของตนเอง ไฟล์อื่นจะถูกถาม
- **OBJ และ STL**: ไม่เคยระบุหน่วย จึงถูกถามเสมอ
- **glTF และ GLB**: เป็นเมตร ตามกฎของรูปแบบไฟล์
- **รูปภาพ**: ไม่มีขนาดของตัวเอง รูปภาพจะพอดีกับมุมมอง และตั้งขนาดด้วย Scale by two points ขนาดที่กำหนดจะถูกจำไว้สำหรับไฟล์นั้น เมื่อวางอีกครั้ง ไฟล์จะเข้ามาในขนาดนั้น และแถบสถานะจะแจ้งเช่นนั้น
- **ส่วนเสริมจุดกลุ่มเมฆ**: จะถามเมื่อสร้างกลุ่มจุดจากไฟล์ที่ไม่ระบุหน่วย และแสดงตัวเลขของกลุ่มจุดในหน่วยที่กลุ่มจุดนั้นมี

## ควรทราบ

- คำตอบจะถูกจำไว้สำหรับไฟล์นั้น (ชื่อ ขนาด และวันที่) บนคอมพิวเตอร์เครื่องนี้ ในทุกแอปของ CadCraft เมื่อไฟล์เดิมเข้ามาอีกครั้ง จะไม่มีการถาม และแถบสถานะจะบอกว่าใช้หน่วยที่จำไว้
- เพื่อให้ถามอีกครั้ง: เปิดพาเลตคำสั่ง ({{key:Mod+K}}) › **ถามหน่วยของไฟล์ที่นำเข้าอีกครั้ง**
- รายการหน่วยที่การนำเข้ามีอยู่แล้ว (หน่วยของไลบรารี หน่วยของแถบกลุ่มจุด หน่วยของแบบใน From a drawing) ยังเปลี่ยนหน่วยหลังจากนั้นได้ รายการหน่วยของเครื่องมือภูมิประเทศตอนนี้เป็นเพียงค่าที่คำถามเริ่มต้นด้วย
