ถ้าคุณรู้จัก Revit ส่วนใหญ่ของ BimCraft จะคุ้นเคยในแง่ของคำศัพท์ แต่จะต่างในแง่ขอบเขต ความแตกต่างที่สำคัญที่สุดคือ **บิลด์นี้อ่านและตรวจสอบโมเดล และแก้ไขข้อมูล IFC ได้ แต่ยังไม่สร้างงานแบบเหมือน Revit** คุณวาดผนัง วางตระกูล สร้างมุมมองหรือแผ่น หรือบันทึกไฟล์โครงการไม่ได้ สิ่งที่ทำได้คือเปิดไฟล์อาคารเกือบทุกชนิดบนคอมพิวเตอร์เครื่องใดก็ได้ที่มีเบราว์เซอร์ ดูว่ามีอะไรอยู่ข้างใน ตรวจสอบทั้งโฟลเดอร์โครงการ และแก้ข้อมูลในโมเดล IFC ได้

## การจับคู่นิสัย

| ถ้าคุณคุ้นกับ | ใน BimCraft |
|---|---|
| การเปิด `.rvt` ใน Revit เพื่อดูโมเดล | BimCraft เปิด `.rvt` เป็นการ์ดไฟล์: รุ่น ข้อมูลโครงการ ลิงก์ และตัวอย่าง สำหรับโมเดล 3 มิติ ให้ส่งออก IFC แล้วเปิดไฟล์นั้น [อ่านไฟล์โครงการหรือไฟล์ตระกูล](topic:read-rvt-file) |
| การตรวจว่าไฟล์บันทึกด้วยรุ่นใดก่อนเปิด | การ์ดแสดงข้อความ "บันทึกใน Revit …" ที่ด้านบน โดยไม่อัปเกรดหรือแตะต้องไฟล์ |
| Project Browser | ไม่มีเบราว์เซอร์ของมุมมองและแผ่น โมเดล IFC มีรายการ {{ui:ชั้น}} และ {{ui:องค์ประกอบ}} ส่วนแบบจะมีแท็บแผ่น |
| พาเนลคุณสมบัติ (Properties palette) | พาเนล {{ui:คุณสมบัติ}} ทางด้านขวา สำหรับองค์ประกอบที่คุณคลิก ใช้ชุดคุณสมบัติ IFC แทนกลุ่มพารามิเตอร์ |
| พารามิเตอร์ของอินสแตนซ์และชนิด | ชุดคุณสมบัติของอินสแตนซ์ และชุดที่มีเครื่องหมาย "(type)" การเปลี่ยนชนิดจะใช้กับทุกองค์ประกอบของชนิดนั้น เหมือนใน Revit [เปลี่ยนคุณสมบัติชนิดให้ทุกองค์ประกอบของชนิด](topic:type-vs-instance) |
| แก้ไขชนิด | ไม่มีกล่องโต้ตอบ คลิกค่าในชุดที่มี "(type)" แล้วพิมพ์ |
| การเลือกหลายองค์ประกอบ ตัวกรอง เลือกอินสแตนซ์ทั้งหมด | ทีละหนึ่งองค์ประกอบ ยังไม่ได้สร้าง |
| คิวบ์มุมมองและวงล้อนำทาง | คิวบ์มุมมองที่มุมขวาล่าง ปุ่มสี่ปุ่ม ({{ui:พอดี}}, {{ui:บน}}, {{ui:หน้า}}, {{ui:ด้านข้าง}}) และการหมุนอิสระ ไม่มีวงล้อนำทาง |
| Shift และลากปุ่มกลางเพื่อหมุน ลากปุ่มกลางเพื่อแพน | ลากซ้ายเพื่อหมุน ลากขวา (หรือ {{key:Shift}} แล้วลาก) เพื่อแพน ล้อเลื่อนเพื่อซูม รูปแบบเมนู {{ui:ริบบอน BIM}} จะสลับเป็นลากปุ่มกลางเพื่อแพน และ {{key:Shift}} กับปุ่มกลางเพื่อหมุน [เมนู คีย์ และเมาส์](topic:menus-keys-and-mouse) |
| แปลนพื้น ภาพตัด กล่องตัด | ทีละหนึ่งระนาบ {{ui:ภาคตัด}} ({{key:X}}) ไม่มีกล่องตัดหรือผังพื้น 2 มิติ [ตัดโมเดล IFC ด้วยระนาบตัด](topic:section-plane) |
| ซ่อนในมุมมอง แยก การมองเห็นหรือกราฟิก | {{ui:ชั้น}} เปิดและปิดได้ {{ui:พื้นที่}} และ {{ui:ขอบ}} ยังไม่มีการซ่อนรายองค์ประกอบ |
| ห้อง | พื้นที่ IFC ซ่อนอยู่ตอนแรก คลิก {{ui:พื้นที่}} |
| บันทึก บันทึกเป็น ซิงค์กับเซ็นทรัล | {{ui:บันทึกเป็น IFC}} ดาวน์โหลดไฟล์ IFC ใหม่ ต้นฉบับไม่เปลี่ยนแปลงเลย ไม่มีเซ็นทรัลและไม่มีการทำงานร่วมกันแบบแชร์ไฟล์ |
| เลิกทำด้วย {{key:Mod+Z}} | ใช้ได้กับการแก้ไข IFC จนกว่าคุณจะบันทึก [เปลี่ยนคุณสมบัติ IFC และบันทึกสำเนาที่แก้ไข](topic:edit-ifc-properties) |
| จัดการลิงก์ | เปิดโฟลเดอร์โครงการ ทุกลิงก์จะถูกตรวจและทำเครื่องหมายเป็น **อยู่ในโฟลเดอร์นี้**, **พบชื่อเดียวกัน**, **ไฟล์ไลบรารี** หรือ **ไม่อยู่ในโฟลเดอร์นี้** [เปิดโฟลเดอร์โครงการทั้งโฟลเดอร์](topic:open-project-folder) |
| การตรวจสอบ หรือการเปิดไฟล์เพื่อดูว่าเสียหายหรือไม่ | รายงานโฟลเดอร์จะตรวจทุกสำเนาและการสำรองว่าถูกตัดทอนหรือไม่ ภายในไม่กี่วินาที [ตรวจโฟลเดอร์หาสำเนาที่เสียหาย](topic:check-folder-health) |
| การเลือกไฟล์ที่ถูกต้องจากโฟลเดอร์ที่รกรุงรัง | กล่อง {{ui:เริ่มที่นี่}} แนะนำไฟล์หนึ่งไฟล์พร้อมเหตุผล |

หากคุณเปิดโมเดลส่วนใหญ่เพื่อตรวจสอบ เช่นในโปรแกรมตรวจโมเดลหรือดู IFC ให้เลือกรูปแบบเมนู {{ui:ตัวดู}} เครื่องมือดูและตรวจสอบจะขึ้นก่อน ส่วนเครื่องมือสร้างอาคารจะรออยู่ในเมนูเดียว ดู [เมนู คีย์ และเมาส์](topic:menus-keys-and-mouse)

## จากการดูไฟล์ DWG

หากคุณเปิดไฟล์ DWG ใน AutoCAD หรือตัวดู DWG:

| ถ้าคุณคุ้นกับ | ใน BimCraft |
|---|---|
| แท็บโมเดลและเลย์เอาต์ที่ด้านล่าง | แท็บเหนือแบบ: {{ui:โมเดล}} และหนึ่งแท็บต่อแผ่น |
| ZOOM Extents ดับเบิลคลิกล้อ | ดับเบิลคลิก, {{key:F}} หรือ {{ui:พอดี}} |
| แพนด้วยปุ่มกลาง | ลากด้วยปุ่มใดก็ได้ |
| ตัวจัดการเลเยอร์ | รายการ {{ui:เลเยอร์}}: ติ๊กเพื่อแสดง ยกเลิกการติ๊กเพื่อซ่อน {{ui:เปิดทั้งหมด}} และ {{ui:ปิดทั้งหมด}} |
| ตัวจัดการ xref | **แบบที่เชื่อมโยง** ทางด้านขวา พร้อม **แสดง** หรือ **ไม่พบ** และ {{ui:เพิ่มแบบที่เชื่อมโยง…}} |
| ตัวอย่างการพล็อต | {{ui:มุมมองพิมพ์}} หรือ {{key:P}}: สีดำบนพื้นขาว พร้อมความหนาเส้น ไม่ได้พิมพ์จริง |
| การดึงข้อมูลแอตทริบิวต์ของบล็อก | แท็บ {{ui:อุปกรณ์}} สำหรับแบบงานบริการอาหารที่มีแท็ก พร้อม {{ui:ดาวน์โหลด CSV}} |
| วัด เขียน แก้ไข บันทึกเป็น | ไม่มีใน BimCraft แอปเขียนแบบ CadCraft เป็นตัววาดและแก้ไข |

## ความแตกต่างที่ทำให้หลายคนสะดุด

- **ทำงานในเบราว์เซอร์ และเบราว์เซอร์ระวังไฟล์ของคุณ** BimCraft อ่านได้เฉพาะไฟล์และโฟลเดอร์ที่คุณส่งให้ โดยเลือกหรือลากเข้ามา มันเปิดไฟล์เองไม่ได้ และบันทึกทับไฟล์ไม่ได้ การบันทึกทุกครั้งคือการดาวน์โหลด
- **ไม่มีการอัปโหลดอะไรเลย** คำว่า "อัปโหลด" ในกล่องโต้ตอบโฟลเดอร์ของบางเบราว์เซอร์เป็นถ้อยคำของเบราว์เซอร์เอง ไฟล์ยังอยู่บนคอมพิวเตอร์ของคุณ
- **IFC คือรูปแบบโมเดล** ไฟล์โครงการจะเปิดเป็นการ์ดเพราะเนื้อหา 3 มิติไม่มีเอกสารกำกับ ให้ถือว่า IFC คือวิธีที่โมเดลเข้าสู่ BimCraft
- **การแก้ไขเป็นแบบการเขียนสำเนา** การเปลี่ยนค่าขององค์ประกอบหนึ่งจะไม่เปลี่ยนองค์ประกอบข้างเคียง แม้ตัวส่งออกจะใช้ค่านั้นร่วมกัน คุณสมบัติของชนิดเป็นข้อยกเว้นโดยตั้งใจ
- **ไม่มีโครงการ ไม่มีมุมมอง** BimCraft แสดงทีละหนึ่งไฟล์ และไม่จำอะไรเกี่ยวกับไฟล์นั้นหลังจากคุณปิดแท็บ ยกเว้นชื่อโฟลเดอร์ล่าสุดใน Chrome และ Edge
- **คีย์บน Mac** ทางลัดของ Revit บน Windows ใช้ Ctrl ส่วนทางลัดของ BimCraft ใช้ {{key:Mod}} ซึ่งคือ Command บน Mac
- **นิสัยการใช้เมาส์ของคุณ** การหมุนใช้ปุ่มซ้าย ไม่ใช่ Shift กับปุ่มกลาง เว้นแต่คุณจะเลือกรูปแบบเมนู {{ui:ริบบอน BIM}} หรือตั้งปุ่มเองใน [เมนู คีย์ และเมาส์](topic:menus-keys-and-mouse)
