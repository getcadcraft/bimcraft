BimCraft อ่านไฟล์บนคอมพิวเตอร์ของคุณในแท็บเบราว์เซอร์ **ไม่มีการอัปโหลดอะไรไปยัง CadCraft หรือใครทั้งสิ้น** เมื่อคุณบันทึก BimCraft จะส่งไฟล์ใหม่ให้เบราว์เซอร์ดาวน์โหลด และจะไม่เขียนทับไฟล์ที่คุณเปิดไว้เลย

## สิ่งที่เปิดได้

| รูปแบบ | นามสกุล | สิ่งที่คุณจะได้ |
|---|---|---|
| IFC | `.ifc` | โมเดลในรูป 3D ชั้น จำนวนองค์ประกอบ และคุณสมบัติของทุกองค์ประกอบ เปลี่ยนชื่อ แท็ก และค่าคุณสมบัติเดี่ยวได้ |
| ไฟล์โปรเจกต์และไฟล์แฟมิลี | `.rvt` `.rfa` `.rte` `.rft` | การ์ดไฟล์: รุ่น บิลด์ การทำงานร่วมกัน ข้อมูลโปรเจกต์ พารามิเตอร์แฟมิลี ไฟล์ที่เชื่อมโยง และภาพตัวอย่าง ไม่มี 3D |
| DWG | `.dwg` | แบบในรูป 2D: พื้นที่โมเดล ทุกแผ่น เลเยอร์ แบบที่เชื่อมโยง รูปภาพ และมุมมองพิมพ์ พื้นที่โมเดลแสดงเป็น 3D ได้ด้วย รูปแบบจาก AutoCAD 2000 ถึง 2018 คือรูปแบบที่ได้รับการตรวจสอบแล้ว |
| DXF | `.dxf` | เหมือน DWG |
| STEP | `.step` `.stp` | ชิ้นส่วน อุปกรณ์ หรือโมเดลของซัพพลายเออร์ (AP203, AP214, AP242) ใน 3D: แต่ละโซลิดจะกลายเป็นองค์ประกอบหนึ่งชิ้น (building element proxy) ของโมเดล IFC ขนาดเล็กที่อยู่บนชั้นเดียว อ่านเป็นสามเหลี่ยมในขนาดจริง และเป็นชุดประกอบที่มีทุกชิ้นส่วนอยู่ตามตำแหน่งที่ไฟล์กำหนด หลังจากนั้นทำงานเหมือน IFC ทั่วไป: คุณสมบัติ หน้าตัด การวัด บันทึกเป็น IFC สีและโครงสร้างต้นไม้ของชุดประกอบจะไม่ถูกอ่าน |
| จุดกลุ่มเมฆ (point cloud) | `.las` `.laz` `.e57` `.ply` `.pcd` `.ptx` `.pts` `.xyz` | ภาพสแกนในมุมมอง 3D ควบคู่กับโมเดลหรือแยกต่างหาก ดู [แสดง point cloud ควบคู่กับโมเดล](topic:point-clouds) |
| ชุดโปรเจกต์ | `.ccbundle.zip` | โมเดลพร้อมมุมมอง เลย์เอาต์ และกลุ่มคุณสมบัติ ดู [เปิดชุดโปรเจกต์](topic:open-project-bundle) |
| โฟลเดอร์ | ใดก็ได้ | รายงานของทุกโมเดล แบบ และชุดโปรเจกต์ในโฟลเดอร์นั้น IFC โมเดล แบบ หรือชุดใดๆ ในรายงานเปิดได้ด้วยการคลิกเพียงครั้งเดียว |

[สิ่งที่ BimCraft อ่านจากแต่ละรูปแบบ](topic:file-formats) อธิบายรายละเอียดไว้

BimCraft ตัดสินว่าไฟล์เป็นชนิดใดจากไบต์แรกของไฟล์ควบคู่กับชื่อไฟล์ ดังนั้นไฟล์โปรเจกต์ที่มีนามสกุลผิดปกติก็ยังเปิดเป็นการ์ดไฟล์ได้

### ที่ไม่เปิด

- `.ifczip` และ `.ifcxml`: BimCraft แสดงข้อความ "ยังไม่รองรับ .ifczip กรุณาบันทึกหรือส่งออกโมเดลเป็นไฟล์ .ifc ธรรมดา" แตกไฟล์ `.ifczip` (ข้างในมี `.ifc` ธรรมดา) หรือส่งออกใหม่เป็น IFC ธรรมดา
- แบบ DGN จะแสดงในรายงานโฟลเดอร์ แต่ไม่เปิด
- ไฟล์ PDF รูปภาพ และไฟล์สำนักงานไม่เปิดได้ด้วยตัวเอง รูปภาพใช้เป็นรูปข้างในไฟล์ DWG ได้ และ {{ui:บิลด์}} › {{ui:จากแบบ…}} จะเปลี่ยนหน้าของ PDF หรือภาพสแกนให้เป็นผนัง ดู [ผนังจากชุดแบบ](topic:walls-from-plans)

## สิ่งที่บันทึก

| คุณคลิก | คุณจะได้ | ที่ไหน |
|---|---|---|
| {{ui:Save as IFC}} | ไฟล์ IFC ใหม่ที่มีการแก้ไขของคุณ ตั้งชื่อเป็น "*ชื่อเดิม* (edited).ifc" | โฟลเดอร์ดาวน์โหลดของเบราว์เซอร์ |
| {{ui:Download CSV}} ในตารางรายการอุปกรณ์ | CSV ของรายการในลิสต์ ตั้งชื่อเป็น "*ชื่อแบบ* equipment.csv" | โฟลเดอร์ดาวน์โหลดของเบราว์เซอร์ |

สิ่งอื่นบันทึกในที่ที่สร้างขึ้น แต่ละอย่างมีหัวข้อของตัวเอง: {{ui:USD}} ([ส่งออกโมเดลเป็น USD](topic:usd)), {{ui:Collada}} (.dae และ .kmz ของ Google Earth: [ส่งออกโมเดลเป็น Collada หรือสำหรับ Google Earth](topic:collada)), ไฟล์ .glb ของ {{ui:สำหรับเรนเดอร์}}, ภาพที่เรนเดอร์แล้ว แผ่นงานและผังพื้นเป็น PDF, ตารางรายการและรายการเป็น CSV, ประเด็น BCF, สเปรดชีต COBie, ไฟล์แฟมิลี และสแกนที่ลงทะเบียนแล้วเป็น LAS หรือ E57 BimCraft ไม่บันทึก DWG, DXF หรือไฟล์โปรเจกต์ และไม่เปลี่ยนแปลงไฟล์ที่คุณเปิดไว้เลย

:::chromium
Chrome และ Edge บันทึกดาวน์โหลดไปยังโฟลเดอร์ที่ตั้งไว้ในการตั้งค่า ซึ่งโดยปกติคือ Downloads หากต้องการให้ถามว่าจะบันทึกที่ไหนทุกครั้ง ให้เปิด "Ask where to save each file before downloading" ในการตั้งค่าการดาวน์โหลดของเบราว์เซอร์
:::

:::firefox
Firefox บันทึกไปยังโฟลเดอร์ Downloads เว้นแต่คุณตั้งค่าเป็น "Always ask you where to save files" ในการตั้งค่า
:::

:::safari
Safari บันทึกไปยัง Downloads เว้นแต่คุณเลือกโฟลเดอร์อื่นภายใต้ **Safari > Settings > General > File download location**
:::

## การบันทึกครั้งที่สอง

การบันทึกแต่ละครั้งดาวน์โหลดโมเดลทั้งหมดพร้อม**การแก้ไขทุกอย่างตั้งแต่คุณเปิดไฟล์** ไม่ใช่เฉพาะการแก้ไขหลังการบันทึกครั้งก่อน รายการ {{ui:การเปลี่ยนแปลง}} จะว่างใหม่ทุกครั้งหลังการบันทึก ดังนั้นคุณย้อนกลับไปก่อนการบันทึกไม่ได้ หากต้องการเริ่มใหม่จากต้นฉบับ ให้เปิดไฟล์ต้นฉบับอีกครั้ง

## ไฟล์ขนาดใหญ่และหน่วยความจำ

- **ไฟล์ IFC** ถูกอ่านทั้งไฟล์เข้าหน่วยความจำของแท็บ และข้อมูลเรขาคณิต 3D ใช้หน่วยความจำเพิ่มอีก โมเดลขนาดหลายร้อย MB อาจมากเกินไปสำหรับแล็ปท็อป เมื่อมากกว่า 1.5 ล้านสามเหลี่ยม เส้นขอบจะถูกปิดเพื่อประหยัดหน่วยความจำ ("ปิดเส้นขอบสำหรับโมเดลขนาดใหญ่มาก")
- **ไฟล์โปรเจกต์** ไม่ถูกอ่านทั้งไฟล์ BimCraft อ่านเฉพาะส่วนเล็กๆ ที่จำเป็น ประมาณ 40 KB ถึง 100 KB ไม่ว่าไฟล์จะใหญ่แค่ไหน ดังนั้นโมเดลส่วนกลางขนาด 500 MB บนไดรฟ์เครือข่ายจึงเปิดได้ในพริบตา
- **ไฟล์ DWG และ DXF** ถูกอ่านทั้งไฟล์ แบบที่ใหญ่มากจะแสดงข้อความ "แบบนี้ใหญ่มาก แสดงเพียงบางส่วน"
- **โฟลเดอร์** เปิดได้ถึง 20,000 ไฟล์ อ่านเฉพาะไม่กี่ KB ที่การ์ดโมเดลแต่ละใบต้องการ

ดู [เบราว์เซอร์ อุปกรณ์ และหน่วยความจำ](topic:platforms) เพิ่มเติม

## ออนไลน์และออฟไลน์

การเปิดไฟล์ไม่ต้องใช้อินเทอร์เน็ตเลย ตัวอ่านหนึ่งตัวจะโหลดจากเว็บไซต์ในครั้งแรกที่ต้องใช้: เอนจิน IFC ในครั้งแรกที่คุณเปิดโมเดล IFC ("กำลังเริ่มเอนจิน IFC…") ตัวอ่าน DWG และ DXF เป็นส่วนหนึ่งของแอป

:::offline
คุณกำลังออฟไลน์ หากปุ่มบนแถบแอปแสดง {{ui:พร้อมใช้ออฟไลน์}} ทุกรูปแบบจะเปิดได้ตามปกติ หากไม่แสดง โมเดล IFC จะเปิดไม่ได้ เว้นแต่เคยเปิดไว้แล้วในแท็บนี้: เชื่อมต่ออินเทอร์เน็ตใหม่ก่อน ดู [ออนไลน์และออฟไลน์](topic:online-offline)
:::

หากต้องการใช้ BimCraft โดยไม่มีการเชื่อมต่อ ให้คลิก {{ui:บันทึกสำหรับออฟไลน์}} บนแถบแอปขณะออนไลน์ แล้วรอจนเห็น {{ui:พร้อมใช้ออฟไลน์}} สำเนาที่บันทึกมีขนาดประมาณ 33 MB และมีเอนจิน IFC รวมอยู่ด้วย จึงเปิดโมเดล IFC แบบออฟไลน์ได้เช่นกัน [การทำงานแบบออฟไลน์](common:offline) อธิบายสำเนาที่บันทึกไว้โดยทั่วไป

## การบันทึกบนคลาวด์

การบันทึกบนคลาวด์ยังไม่พร้อมใช้งาน บันทึกสำเนาที่แก้ไขแล้วไว้บนคอมพิวเตอร์ของคุณหรือเซิร์ฟเวอร์ไฟล์ของสำนักงาน เหมือนไฟล์อื่นๆ ดู [ไฟล์ของคุณ](common:your-files)
