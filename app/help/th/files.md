BimCraft อ่านไฟล์บนคอมพิวเตอร์ของคุณในแท็บเบราว์เซอร์ **ไม่มีการอัปโหลดอะไร** ไปยัง CadCraft หรือใคร ๆ เมื่อคุณบันทึก BimCraft ส่งไฟล์ใหม่ให้เบราว์เซอร์ดาวน์โหลด และไม่เคยเขียนทับไฟล์ที่คุณเปิด

## สิ่งที่เปิดได้

| รูปแบบ | นามสกุล | สิ่งที่คุณได้ |
|---|---|---|
| IFC | `.ifc` | โมเดลใน 3D ชั้น จำนวนองค์ประกอบ และคุณสมบัติของทุกองค์ประกอบ เปลี่ยนชื่อ แท็ก และค่าคุณสมบัติรายค่าได้ |
| ไฟล์โครงการและไฟล์แฟมิลี | `.rvt` `.rfa` `.rte` `.rft` | การ์ดไฟล์: รุ่น บิลด์ การทำงานร่วมกัน ข้อมูลโครงการ พารามิเตอร์แฟมิลี ไฟล์ที่เชื่อมโยง และภาพตัวอย่าง ไม่มี 3D |
| DWG | `.dwg` | แบบใน 2D: พื้นที่โมเดล ทุกแผ่น เลเยอร์ แบบที่เชื่อมโยง รูปภาพ และมุมมองพิมพ์ พื้นที่โมเดลใน 3D ด้วย รูปแบบตั้งแต่ AutoCAD 2000 ถึง 2018 คือรูปแบบที่ตรวจสอบแล้ว |
| DXF | `.dxf` | เหมือนกับ DWG |
| STEP | `.step` `.stp` | ชิ้นส่วน อุปกรณ์ หรือโมเดลของผู้จัดจำหน่าย (AP203, AP214, AP242) ใน 3D: โซลิดแต่ละชิ้นกลายเป็นองค์ประกอบหนึ่งชิ้น (building element proxy) ของโมเดล IFC ขนาดเล็กบนหนึ่งชั้น อ่านเป็นสามเหลี่ยมในขนาดจริง และแอสเซมบลีมีทุกชิ้นส่วนตามที่ไฟล์วางไว้ จากนั้นใช้งานได้เหมือน IFC ทั่วไป: คุณสมบัติ ภาพตัด วัด บันทึกเป็น IFC ยังไม่อ่านสีและแผนผังแอสเซมบลี |
| กลุ่มจุดเมฆ | `.las` `.laz` `.e57` `.ply` `.pcd` `.ptx` `.pts` `.xyz` | การสแกนในมุมมอง 3D ข้างโมเดลหรือเดี่ยว ๆ: ดู [แสดงกลุ่มจุดเมฆข้างโมเดล](topic:point-clouds) |
| ชุดโครงการ | `.ccbundle.zip` | โมเดลพร้อมมุมมอง เลย์เอาต์ และกลุ่มคุณสมบัติ: ดู [เปิดชุดโครงการ](topic:open-project-bundle) |
| โฟลเดอร์ | ใด ๆ | รายงานของทุกโมเดล แบบ และชุดโครงการในโฟลเดอร์ IFC โมเดล แบบ หรือชุดโครงการใด ๆ ในรายงานเปิดได้ด้วยการคลิก |

[สิ่งที่ BimCraft อ่านจากแต่ละรูปแบบ](topic:file-formats) อธิบายรายละเอียด

BimCraft ตัดสินว่าไฟล์เป็นชนิดใดโดยดูไบต์แรกของไฟล์ด้วย ไม่ใช่แค่ชื่อ ไฟล์โครงการที่มีนามสกุลผิดปกติจึงยังเปิดเป็นการ์ดไฟล์ได้

### ที่เปิดไม่ได้

- `.ifczip` และ `.ifcxml`: BimCraft บอกว่า "ยังไม่รองรับ .ifczip บันทึกหรือส่งออกโมเดลเป็นไฟล์ .ifc ธรรมดา" ให้แตกไฟล์ `.ifczip` (ข้างในเป็น `.ifc` ธรรมดา) หรือส่งออกใหม่เป็น IFC ธรรมดา
- แบบ DGN แสดงอยู่ในรายงานโฟลเดอร์แต่เปิดไม่ได้
- PDF รูปภาพ และไฟล์สำนักงานเปิดเองไม่ได้ รูปภาพใช้เป็นภาพภายใน DWG และ {{ui:สร้าง}} › {{ui:จากแบบ…}} เปลี่ยนหน้าของ PDF หรือการสแกนให้เป็นผนัง: ดู [ผนังจากชุดแปลน](topic:walls-from-plans)

## สิ่งที่บันทึก

| คุณคลิก | คุณได้ | ที่ไหน |
|---|---|---|
| {{ui:บันทึกเป็น IFC}} | ไฟล์ IFC ใหม่พร้อมการแก้ไขของคุณ ตั้งชื่อว่า "*ชื่อเดิม* (edited).ifc" | โฟลเดอร์ดาวน์โหลดของเบราว์เซอร์ |
| {{ui:ดาวน์โหลด CSV}} ในตารางอุปกรณ์ | CSV ของรายการในรายการ ตั้งชื่อว่า "*ชื่อแบบ* equipment.csv" | โฟลเดอร์ดาวน์โหลดของเบราว์เซอร์ |

สิ่งอื่นบันทึกในที่ที่สร้าง แต่ละอย่างอยู่ในหัวข้อของตัวเอง: {{ui:USD}} ([ส่งออกโมเดลเป็น USD](topic:usd)), ไฟล์ .glb {{ui:สำหรับเรนเดอร์}}, ภาพที่เรนเดอร์, แผ่นงานและผังเป็น PDF, ตารางรายการและรายการเป็น CSV, ประเด็น BCF, สเปรดชีต COBie, ไฟล์แฟมิลี และการสแกนที่ลงทะเบียนแล้วเป็น LAS หรือ E57 BimCraft ไม่บันทึกไฟล์ DWG, DXF หรือไฟล์โครงการ และไม่เคยเปลี่ยนไฟล์ที่คุณเปิด

:::chromium
Chrome และ Edge บันทึกไฟล์ดาวน์โหลดลงโฟลเดอร์ที่ตั้งไว้ในการตั้งค่าของเบราว์เซอร์ ซึ่งมักเป็น Downloads หากต้องการให้ถามทุกครั้งว่าจะบันทึกที่ไหน ให้เปิด "Ask where to save each file before downloading" ในการตั้งค่าดาวน์โหลดของเบราว์เซอร์
:::

:::firefox
Firefox บันทึกลงโฟลเดอร์ Downloads เว้นแต่คุณตั้งเป็น "Always ask you where to save files" ในการตั้งค่า
:::

:::safari
Safari บันทึกลง Downloads เว้นแต่คุณเลือกโฟลเดอร์อื่นที่ **Safari > Settings > General > File download location**
:::

## การบันทึกครั้งที่สอง

การบันทึกแต่ละครั้งดาวน์โหลดทั้งโมเดลพร้อม**การแก้ไขทุกอย่างตั้งแต่คุณเปิด** ไม่ใช่เฉพาะการแก้ไขหลังการบันทึกครั้งล่าสุด รายการ {{ui:การเปลี่ยนแปลง}} เริ่มว่างอีกครั้งหลังการบันทึกทุกครั้ง คุณจึงเลิกทำย้อนผ่านการบันทึกไม่ได้ หากต้องการเริ่มใหม่จากต้นฉบับ ให้เปิดไฟล์ต้นฉบับอีกครั้ง

## ไฟล์ใหญ่และหน่วยความจำ

- ไฟล์ **IFC** อ่านทั้งหมดเข้าหน่วยความจำของแท็บ และรูปทรง 3D ใช้หน่วยความจำเพิ่มขึ้นอีก โมเดลขนาดหลายร้อยเมกะไบต์อาจมากเกินไปสำหรับแล็ปท็อป เมื่อเกิน 1.5 ล้านสามเหลี่ยม ขอบจะถูกปิดเพื่อประหยัดหน่วยความจำ ("ขอบปิดอยู่สำหรับโมเดลที่ใหญ่มาก")
- **ไฟล์โครงการ**ไม่ถูกอ่านทั้งหมด BimCraft อ่านเฉพาะส่วนเล็ก ๆ ที่ต้องใช้ ประมาณ 40 KB ถึง 100 KB ไม่ว่าไฟล์จะใหญ่เพียงใด โมเดลกลางขนาด 500 MB บนไดรฟ์เครือข่ายจึงเปิดได้ในพริบตา
- ไฟล์ **DWG และ DXF** อ่านทั้งหมด แบบที่ใหญ่มากจะแสดง "แบบนี้ใหญ่มาก แสดงได้เพียงบางส่วน"
- **โฟลเดอร์**ที่มีไฟล์ไม่เกิน 20,000 ไฟล์เปิดได้ อ่านเฉพาะไม่กี่กิโลไบต์ที่การ์ดโมเดลแต่ละใบต้องใช้

ดู [เบราว์เซอร์ อุปกรณ์ และหน่วยความจำ](topic:platforms) เพิ่มเติม

## ออนไลน์และออฟไลน์

การเปิดไฟล์ไม่ต้องใช้อินเทอร์เน็ตเลย มีตัวอ่านเดียวที่โหลดจากไซต์ครั้งแรกที่คุณต้องใช้: เครื่องยนต์ IFC ครั้งแรกที่คุณเปิดโมเดล IFC ("กำลังเริ่มเครื่องยนต์ IFC…") ตัวอ่าน DWG และ DXF เป็นส่วนหนึ่งของแอป

:::offline
คุณออฟไลน์อยู่ หากปุ่มของแถบแอปเขียนว่า {{ui:พร้อมใช้ออฟไลน์}} ทุกรูปแบบเปิดได้ตามปกติ หากไม่ใช่ โมเดล IFC จะเปิดไม่ได้ เว้นแต่มีโมเดลหนึ่งเปิดไว้แล้วในแท็บนี้: เชื่อมต่อใหม่ก่อน ดู [ออนไลน์และออฟไลน์](topic:online-offline)
:::

หากต้องการใช้ BimCraft โดยไม่มีการเชื่อมต่อ ให้คลิก {{ui:บันทึกสำหรับออฟไลน์}} ในแถบแอปขณะที่ออนไลน์ แล้วรอ {{ui:พร้อมใช้ออฟไลน์}} สำเนาที่บันทึกมีขนาดประมาณ 33 MB และรวมเครื่องยนต์ IFC ไว้ด้วย โมเดล IFC จึงเปิดออฟไลน์ได้เช่นกัน [การทำงานแบบออฟไลน์](common:offline) อธิบายสำเนาที่บันทึกโดยทั่วไป

## การบันทึกบนคลาวด์

ยังไม่มีการบันทึกบนคลาวด์ ให้บันทึกสำเนาที่แก้ไขไว้ในคอมพิวเตอร์ของคุณเองหรือเซิร์ฟเวอร์ไฟล์ของสำนักงาน เหมือนกับไฟล์อื่น ๆ ดู [ไฟล์ของคุณ](common:your-files)
