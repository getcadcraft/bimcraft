## สิ่งที่จะทำ

ย้ายโมเดลระหว่างโปรแกรม BIM สองโปรแกรม เช่น จาก Revit ไป Archicad และกลับมา ผ่าน IFC โดยมี BimCraft คั่นกลางเพื่อตรวจ เพิ่มเติม และรายงานว่าอะไรรอดมาได้ ไม่มีการอ่านไฟล์รูปแบบของโปรแกรมใดๆ ทุกอย่างเดินทางเป็น IFC

## สิ่งที่ BimCraft เก็บไว้

เมื่อเปลี่ยนแปลงโมเดลใน BimCraft และคลิก {{ui:Save as IFC}} ทุกบรรทัดที่ไม่ได้เปลี่ยนจะถูกเขียนกลับไปเหมือนเดิม ดังนั้น:

- **GlobalId** คงเดิม และโปรแกรมอื่นจับคู่แต่ละองค์ประกอบกับที่ส่งไปได้
- **ชุดคุณสมบัติ** และค่าต่างๆ คงอยู่ ยกเว้นค่าที่เปลี่ยนแปลง
- **การจัดประเภท** ยังติดอยู่กับองค์ประกอบของมัน

## ตั้งค่าทั้งสองโปรแกรมให้ใช้คุณสมบัติเดียวกัน

1. เปิดโมเดลใน BimCraft (และ project bundle ถ้ามี: กลุ่มคุณสมบัติของมันจะถูกเพิ่มเข้ามา)
2. ในแผงซ้าย เปิด {{ui:Between two BIM programs}}
3. ภายใต้ **Property mapping** › **การจับคู่คุณสมบัติ** ดาวน์โหลดสิ่งที่แต่ละโปรแกรมต้องการ:
   - {{ui:Shared parameters}}: ไฟล์พารามิเตอร์ที่ใช้ร่วมกัน ใน Revit โหลดด้วย Manage › Shared Parameters แล้วเพิ่มพารามิเตอร์ในหมวดที่ต้องการ
   - {{ui:IFC export property sets}}: ไฟล์ชุดคุณสมบัติที่ผู้ใช้กำหนดเอง ในการตั้งค่าส่งออก IFC ของ Revit เลือกไฟล์นี้ภายใต้ชุดคุณสมบัติที่ผู้ใช้กำหนด เพื่อให้ IFC ที่ส่งออกมีชุดและชื่อคุณสมบัติเดียวกัน
   - {{ui:Mapping table (CSV)}}: ทุกคุณสมบัติพร้อมชุด IFC และชื่อ ชนิด และชื่อที่ตรงกันในแต่ละโปรแกรม ไฟล์การจับคู่ของ Archicad ไม่ใช่รูปแบบที่เผยแพร่ จึงต้องตั้งค่าตัวแปลง IFC และตัวจัดการคุณสมบัติจากตารางนี้ด้วยตนเอง
   - {{ui:Mapping file}}: การจับคู่ทั้งหมดเป็นไฟล์เดียว เก็บไว้กับโครงการ

ชุดมาตรฐาน (Pset_ และ Qto_) ไม่รวมอยู่ในไฟล์พารามิเตอร์ที่ใช้ร่วมกัน เพราะทั้งสองโปรแกรมเขียนชุดเหล่านี้จากข้อมูลของตนเอง

## ส่งโมเดลและนำกลับมา

1. ส่งออก IFC จากโปรแกรมแรกโดยเก็บ GlobalId ไว้ (Revit: เปิด "Store the IFC GUID in an element parameter after export")
2. เปิดใน BimCraft ตรวจสอบ ({{ui:Model checks}}, {{ui:Clash check}}) เพิ่มประเด็น ({{ui:Issues}}, BCF) เปลี่ยนค่าตามต้องการ แล้ว {{ui:Save as IFC}}
3. เปิด IFC ที่บันทึกไว้ในโปรแกรมที่สอง ทำงานต่อ แล้วส่งออก IFC จากที่นั่นโดยเก็บ GlobalId ไว้ (ตัวแปลงของ Archicad: "Global Unique Identifiers: Keep existing")
4. กลับมาที่ BimCraft เปิดโมเดลที่ส่งออกไป แล้วเพิ่มโมเดลที่กลับมา ({{ui:Add a model}} ภายใต้ โมเดล)
5. ใน {{ui:Between two BIM programs}} เลือก **Went out** › **ส่งออกไป** และ **Came back** › **กลับมาแล้ว** แล้วคลิก {{ui:Make the report}}

## อ่านรายงาน

- **Elements** › **องค์ประกอบ**: กลับมากี่ชิ้นพร้อม GlobalId เดิม หายไปกี่ชิ้น และใหม่กี่ชิ้น องค์ประกอบที่มี GlobalId ใหม่จะแสดงเป็นหนึ่งชิ้นหายไปและหนึ่งชิ้นใหม่ เพราะอีกโปรแกรมไม่ได้เก็บค่านั้นไว้
- **IFC class changed** › **เปลี่ยนคลาส IFC**: องค์ประกอบที่กลับมาเป็นชนิดอื่น
- **Property values kept** › **ค่าคุณสมบัติที่คงอยู่**: สัดส่วนของค่าที่กลับมาโดยไม่เปลี่ยน รายการด้านล่างแสดงคุณสมบัติที่มีค่าเปลี่ยนหรือหายมากที่สุด
- **Classifications** › **การจัดประเภท**: คงอยู่ เปลี่ยน (ระบบเดียวกัน รหัสอื่น) หรือหายไป

{{ui:Download the report (CSV)}} ให้ทุกคุณสมบัติพร้อมจำนวน เพื่อดูว่าองค์ประกอบใดย้ายหรือเปลี่ยนรูปร่าง ใช้ {{ui:Compare versions}} กับโมเดลสองเวอร์ชันเดียวกัน

:::note
BimCraft ไม่ได้รันโปรแกรมทั้งสองตัว การตั้งค่าใดจะส่งค่าผ่านขึ้นอยู่กับการตั้งค่า IFC ของแต่ละโปรแกรม รายงานแสดงสิ่งที่กลับมาจริง จึงควรลองตั้งค่า ส่งออกใหม่ และเปรียบเทียบ
:::

## ประเด็นส่งผ่านเป็น BCF

ประเด็นที่ยกขึ้นใน BimCraft ส่งออกเป็น BCF ({{ui:Issues}}) ซึ่งทั้งสองโปรแกรมอ่านได้ด้วยเครื่องมือ BCF ของตน คำถามเกี่ยวกับองค์ประกอบจึงไปถึงผู้ทำงานในอีกโปรแกรมพร้อมมุมมองของมัน
