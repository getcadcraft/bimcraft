{{ui:Collada}} บนแถบเครื่องมือ (หรือ {{ui:Export Collada (.dae, .kmz)…}} ในเมนูไฟล์ของรูปแบบเมนูและริบบอน) เขียนสิ่งที่เปิดอยู่เป็น Collada 1.4.1 คือทุกโมเดลที่แสดงอยู่ รวมถึงโมเดลที่รวมกันซึ่งคุณวางไว้ในตำแหน่งที่วาง

## ส่งออก

1. เลือก {{ui:Collada}}
2. เลือกรูปแบบ:
   - {{ui:Collada file (.dae), for Blender and other 3D programs}}
   - {{ui:Google Earth package (.kmz): the model placed where it is on the map}} แสดงให้เลือกเฉพาะเมื่อโมเดลมีตำแหน่ง
3. เลือกตัวเลือก แล้วกด {{ui:Export}} ไฟล์จะถูกดาวน์โหลด และแถบสถานะจะบอกจำนวนองค์ประกอบที่ถูกส่งออก

| ตัวเลือก | หน้าที่ |
|---|---|
| {{ui:Write the location into the file}} | เพิ่มละติจูด ลองจิจูด ความสูง และทิศทางของจุดกำเนิดของไฟล์ลงใน .dae |
| {{ui:Height}} | {{ui:On the ground: the model’s level 0 sits on the terrain}} หรือ {{ui:The model’s own height above sea level}} |
| {{ui:Include rooms and spaces}} | ใส่พื้นที่ด้วย (ปกติจะไม่รวม) |
| {{ui:Include hidden elements}} | เขียนองค์ประกอบที่คุณซ่อนไว้ด้วย (ปกติเขียนเฉพาะที่คุณเห็น) |

## สิ่งที่อยู่ในไฟล์

| ในโมเดล | ในไฟล์ Collada |
|---|---|
| อาคาร ชั้น | โนดซ้อนกัน เรียงชั้นตามระดับความสูง องค์ประกอบที่ไม่อยู่ในชั้นใดจะอยู่ภายใต้ "Unplaced" |
| แต่ละองค์ประกอบ | หนึ่งโนดพร้อมเมชของตัวเอง ตั้งชื่อตามในโมเดล (ชื่อของมัน ถ้าไม่มีใช้คลาสและแท็ก) |
| คลาส, GlobalId, ประเภทที่กำหนดไว้ล่วงหน้า | อยู่ในข้อมูลเพิ่มเติมของโนด (โปรไฟล์ IFC) พร้อมชื่อที่เขียนตรงทุกตัวอักษร (โปรไฟล์ ModelCraft) |
| สี | วัสดุ พร้อมความโปร่งใส |
| หน่วยและแกน | เมตร แกน Z ชี้ขึ้น ระดับ 0 ของโมเดลที่เปิดอยู่ด้านหน้าอยู่ที่ความสูง 0 |

โมเดลจะอยู่ใกล้จุดกำเนิดบนพื้นดิน เพื่อให้โปรแกรมที่ทำงานด้วยความแม่นยำแบบ single precision แสดงผลได้โดยไม่สั่น ModelCraft เขียนไฟล์ Collada ด้วยตัวเขียนเดียวกัน และเปิดไฟล์เหล่านี้พร้อมชื่อองค์ประกอบ

## ตำแหน่งมาจากไหน

โมเดลที่เปิดอยู่ด้านหน้าให้ตำแหน่ง ด้วยวิธีเดียวกับที่ {{ui:Measure}} คำนวณละติจูดและลองจิจูดของจุด:

- การแปลงแผนที่ (IFC4 IfcMapConversion หรือชุดคุณสมบัติ IFC2X3) ผ่านระบบพิกัดของโมเดล ระบบที่คุณเลือกให้โมเดลจะมาก่อนระบบที่ไฟล์ระบุไว้
- มิฉะนั้นใช้ละติจูดและลองจิจูดของพื้นที่โครงการ (โดยประมาณ ใช้ได้ดีทั่วทั้งพื้นที่)

ทิศทางถูกวัดจริง ไม่ได้สมมติ โดยคำนึงถึงการหมุนของแผนที่ ทิศเหนือแท้ และค่าการลู่เข้าของแผนที่ หากต้องการกำหนดตำแหน่งให้โมเดล ใช้ {{ui:Map origin…}} ใน {{ui:Measure}}

## ในโปรแกรมอื่น

- **Google Earth** อ่านไฟล์ .kmz โมเดลจะปรากฏที่ตำแหน่งนั้น หันไปทางทิศเหนือ ไฟล์ .dae ธรรมดาไม่มีที่ที่ Google Earth อ่านตำแหน่งได้ ให้ใช้ .kmz
- **Blender** (4.x และเก่ากว่า): File, Import, Collada (.dae) แต่ละองค์ประกอบจะเข้ามาเป็นออบเจกต์ของตัวเองพร้อมวัสดุ ตำแหน่งถูกเก็บไว้ในข้อมูลเพิ่มเติมของไฟล์ ซึ่ง Blender ไม่อ่าน Blender 5.0 ตัดตัวนำเข้า Collada ในตัวออกแล้ว ในกรณีนั้นให้ใช้ {{ui:USD}} หรือส่งออก glTF แทน หรือเปิด .dae ใน Blender 4.5 แล้วบันทึกเป็น .blend

การทดสอบของเราตรวจทุกไฟล์กับสคีมา Collada 1.4.1 และอ่านกลับด้วยตัวอ่าน Collada อิสระ แต่ยังไม่ได้เปิดในโปรแกรม Blender หรือ Google Earth
