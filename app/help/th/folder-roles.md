## สถานะสำเนา

ทุกสำเนาของโมเดล ทั้งไฟล์หลักและไฟล์สำรองที่มีหมายเลข จะได้รับการตรวจสอบส่วนหัว

| ป้ายกำกับ | ความหมาย |
|---|---|
| **สมบูรณ์** | ส่วนหัวและดัชนีของไฟล์พอดีอยู่ภายในไฟล์ |
| **ไม่สมบูรณ์** | ไฟล์สั้นกว่าที่ดัชนีของตัวเองระบุ: ถูกตัดระหว่างการคัดลอก อัปโหลด หรือซิงก์ หรือเป็นไฟล์คลาวด์ที่ยังเป็น "ออนไลน์เท่านั้น" |
| **อ่านไม่ได้** | ไฟล์ไม่ใช่ compound file ที่ถูกต้อง หรืออ่านไม่ได้ |

ในคอลัมน์ **สถานะ** โมเดลจะแสดง **สมบูรณ์** หรือ "*n* ไม่สมบูรณ์" สีอำพันเมื่อมีอย่างน้อยหนึ่งสำเนาที่เสียแต่อีกสำเนาใช้ได้ หรือ **ไม่สมบูรณ์** สีแดงเมื่อไม่มีสำเนาใดที่ใช้ได้

## ไฟล์สำรอง

ไฟล์ชื่อ `Name.0001.rvt`, `Name.0002.rvt` และต่อ ๆ ไป คือไฟล์สำรองที่มีหมายเลขของ `Name.rvt` ไฟล์เหล่านี้จะถูกจัดกลุ่มไว้ใต้โมเดลของตน เรียงจากใหม่ไปเก่า ใน **ทั้งหมด … สำเนา** การ์ดจะอ่านจากไฟล์หลักเมื่อสมบูรณ์ มิฉะนั้นจะอ่านจากไฟล์สำรองที่สมบูรณ์และใหม่ที่สุด ("สมบูรณ์ล่าสุด")

## บทบาท

แสดงเป็นตัวเอียงใต้ชื่อโมเดล

| บทบาท | ความหมาย |
|---|---|
| ถูกลิงก์โดย *โมเดลอื่น*: พื้นหลัง | โมเดลอื่นในโฟลเดอร์ลิงก์โมเดลนี้ จึงน่าจะเป็นพื้นหลังของคนอื่น เช่น โมเดลของที่ปรึกษา |
| ไฟล์ตัวอย่างเริ่มต้นหรือไม่มีชื่อ | ชื่อเช่น Blank, Template, Default, Untitled หรือ Project1: จุดเริ่มต้น หรือไฟล์ที่ยังไม่เคยตั้งชื่ออย่างเหมาะสม |
| โมเดลส่วนกลาง | โมเดลส่วนกลางแบบแชร์งาน งานทำในสำเนาท้องถิ่น ไม่ใช่ที่นี่ |
| แฟมิลี (ชิ้นส่วน) | ไฟล์ `.rfa` หรือ `.rft`: เป็นองค์ประกอบ ไม่ใช่โครงการ |
| มีแต่ไฟล์สำรอง | ไม่พบไฟล์หลักแล้ว เหลือเพียงไฟล์สำรองที่มีหมายเลข |

## วิธีเลือก เริ่มที่นี่

BimCraft ใช้เหตุผลเหมือนผู้ใช้ที่มีประสบการณ์:

1. ตัวเลือกคือไฟล์โครงการที่อ่านได้ (`.rvt`, `.rte`) ที่ไม่ถูกลิงก์โดยโมเดลอื่นและไม่ใช่ตัวอย่างเริ่มต้น
2. โมเดลส่วนกลางและโมเดลที่มีแต่ไฟล์สำรองจะนับเมื่อไม่มีตัวเลือกที่ดีกว่า
3. ในบรรดาตัวเลือก ไฟล์ที่บันทึกล่าสุดจะชนะ

กล่องจะแสดงเหตุผล และเตือนเมื่อไฟล์ที่ดูเหมือนตัวเลือกที่ชัดเจนเสียหาย เมื่อโมเดลอื่นเป็นพื้นหลัง และเมื่อตัวเลือกเป็นโมเดลส่วนกลาง นี่เป็นการเดาที่ดีที่สุด โปรดตรวจสอบกับผู้ที่ทำงานกับโครงการล่าสุด

## สถานะลิงก์

| ป้ายกำกับ | ความหมาย |
|---|---|
| **ในโฟลเดอร์นี้** | พบที่เส้นทางสัมพัทธ์ที่บันทึกไว้ หรือท้ายเส้นทางเต็มที่บันทึกไว้ภายในโฟลเดอร์ |
| **พบชื่อเดียวกัน** | ไม่อยู่ที่เส้นทางเดิม แต่มีไฟล์ชื่อเดียวกันในโฟลเดอร์ ตรวจสอบว่าเป็นไฟล์ที่ถูกต้อง |
| **ไฟล์ไลบรารี** | ตารางคีย์โน้ตหรือรหัสชุดงาน ไฟล์เหล่านี้มาพร้อมโปรแกรมในทุกคอมพิวเตอร์ |
| **ไม่อยู่ในโฟลเดอร์นี้** | ไม่พบในโฟลเดอร์ใดเลย |

คอลัมน์ **ลิงก์ที่พบ** ในแท็บ **โมเดล** แสดงจำนวนลิงก์ของโมเดลที่พบ จากจำนวนที่คาดว่าจะอยู่ในโฟลเดอร์ (ไม่นับไฟล์ไลบรารี)

## ที่แยกไว้

| บรรทัด | ความหมาย |
|---|---|
| โฟลเดอร์บำรุงรักษา Revit (ไม่อ่าน) | โฟลเดอร์ `*_backup`, `*_log` และ `Revit_temp` รวมถึงโฟลเดอร์ที่ซ่อนและ `__MACOSX` |
| ไฟล์ล็อก บันทึก และสำรองที่หลงเหลือ | ไฟล์ `.dwl`, `.dwl2`, `.bak`, `.err`, `.log`, `.tmp`, `.sv$`, `.ac$`, `.lck` และ `.slog` |
| ไฟล์อื่น | ทุกอย่างที่เหลือ (40 รายการแรกระบุชื่อ) |
