{{ui:Render}} มี **เอนจิน** ให้เลือกอยู่เหนือ {{ui:Mode}} เอนจินของเราสองตัวมีอยู่เสมอและใช้ได้ทุกที่ ส่วนเสริมเพิ่มได้อีก และใน CadCraft Studio รายการยังมีโปรแกรมที่รับฉากไปดำเนินการต่อด้วย

| เอนจิน | ทำอะไร | ที่ใช้ได้ |
|---|---|---|
| ในตัว: เร็ว | ภาพนิ่งที่รวดเร็ว: แสงกลางวัน เงาอ่อน ลักษณะของกระจกและโลหะ ภายในไม่กี่วินาที | เบราว์เซอร์และ Studio |
| ในตัว: Path tracer | แสงที่สะท้อนไปมาระหว่างพื้นผิว ทำบนการ์ดจอหรือโปรเซสเซอร์ของคุณ พร้อมคิวการเรนเดอร์และคอมพิวเตอร์เครื่องอื่นในเครือข่ายของคุณ | เบราว์เซอร์และ Studio |
| เอนจินของส่วนเสริม | วาดและส่งภาพกลับมา ดู [วาดภาพด้วยโปรแกรมอื่น](topic:render-other-program) | เบราว์เซอร์ (เอนจินที่เขียนด้วย JavaScript) หรือ Studio (เอนจินที่รันโปรแกรม) |
| โปรแกรมที่รับฉากไปดำเนินการ | Studio วางฉากไว้ในโฟลเดอร์ของมันและทำให้ตรงกันอยู่เสมอ | Studio |
| เปิดใน… | บันทึกฉากและเปิดในโปรแกรม ไม่มีอะไรส่งกลับมา ดู [เปิดฉากในโปรแกรมอื่น](topic:render-open-in) | เว็บจะบันทึกไฟล์ |

## วิธีที่ตัวเลือกทำงาน

- การเลือก เร็ว หรือ Path tracer จะเปลี่ยน {{ui:Mode}} ตามไปด้วย และในทางกลับกัน ส่วนอื่นของกล่องโต้ตอบไม่เปลี่ยนสำหรับผู้ที่ไม่เคยใช้เอนจินอื่น
- เอนจินที่ใช้ไม่ได้จะยังอยู่ในรายการพร้อมเหตุผล ("ไม่พบ", "ต้องใช้เวอร์ชันใหม่กว่า") และเลือกไม่ได้ ในเบราว์เซอร์ เอนจินที่ทำงานได้เฉพาะใน Studio จะแสดงว่า "บันทึกไฟล์" ซึ่ง {{ui:Render}} จะบันทึกฉากและการตั้งค่าเป็นไฟล์ที่นำไปเปิดในโปรแกรมนั้น
- ตัวเลือกจะถูกบันทึกพร้อมการตั้งค่าการเรนเดอร์ของไฟล์ และเอนจินที่เลือกล่าสุดจะเป็นเอนจินเริ่มต้นสำหรับไฟล์ที่ไม่มีตัวเลือกของตัวเอง
- ภาพจากโปรแกรมอื่นจะระบุว่าโปรแกรมใดเป็นผู้วาดและเวอร์ชันของโปรแกรม ทั้งในกล่องโต้ตอบและในคิวการเรนเดอร์ คำมั่นสัญญาของหน้า [เรนเดอร์](topic:render) ครอบคลุม**เอนจินของเราเองเท่านั้น** โปรแกรมอื่นจัดแสง ปรับโทน และสุ่มตัวอย่างในแบบของตัวเอง ภาพสองภาพของฉากเดียวกันจึงเหมือนกันในมุมกล้อง ดวงอาทิตย์ โคมไฟ และการเปิดรับแสง แต่ไม่เหมือนกันทุกพิกเซล

## สิ่งที่ทุกเอนจินได้รับ

ฉากจะถูกส่งไปยังโปรแกรมอื่นเป็น **แพ็กเกจ** ได้แก่ โมเดลเป็นไฟล์ USD (ไฟล์เดียวกับที่ [บันทึกเป็น USD](topic:usd) เขียน) และไฟล์การตั้งค่าที่เก็บสิ่งที่ตัวนำเข้า USD ไม่สามารถจัดการได้อย่างเชื่อถือได้ ได้แก่ ค่าวัสดุที่แม่นยำ โคมไฟที่เปิดอยู่พร้อมกำลังไฟและโปรไฟล์แสง ดวงอาทิตย์ ท้องฟ้า การเปิดรับแสง และกล้องตามที่กล่องโต้ตอบจะวาด ไม่มีการอัปโหลดข้อมูลไปที่ใด

## คิวการเรนเดอร์

ภาพสำหรับโปรแกรมอื่นสามารถรอใน [คิวการเรนเดอร์](topic:render#the-render-queue) ได้เหมือนเอนจินของเรา งานของมันจะจำไว้ว่าเป็นของเอนจินใด
