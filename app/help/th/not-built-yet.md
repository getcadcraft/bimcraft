BimCraft ในตอนนี้เป็นตัวอ่าน ตัวตรวจ และตัวแก้ไขข้อมูล IFC ที่เริ่มวาดอาคารได้แล้ว: ผนัง ประตูและหน้าต่าง ห้อง พื้น เพดาน และหลังคา (ดู [วาดผนัง](topic:draw-walls) [ประตูและหน้าต่าง](topic:doors-and-windows) และ [ห้อง พื้น เพดาน และหลังคา](topic:floors-and-roofs)) นี่คือรายการที่ซื่อตรงของสิ่งที่ยังไม่ทำ พร้อมสิ่งที่ควรทำแทน

## การสร้างและการเขียนโมเดล

| ยังไม่มี | ทางเลือกในตอนนี้ |
|---|---|
| การวาดคาน; เสาของหน้าตัดเหล็ก | ใช้โปรแกรมสร้างแบบของคุณ แล้วเปิดไฟล์ส่งออก IFC ที่นี่ เสาสี่เหลี่ยมและเสาทรงกลมวางได้ที่นี่ (ดู [ตารางกริดและเสา](topic:grids-and-columns)); บันไดตรง บันไดรูปตัว L, U, บันไดเวียนและบันไดเกลียว และราวบันไดวาดได้ที่นี่ (ดู [บันไดและราวบันได](topic:stairs-and-railings)) |
| หน้าต่างบนด้านหน้าของหลังคาเล็ก (dormer); หลังคาเล็กบนระนาบหลังคาที่วาดด้วยมือ; หลังคาโค้ง; ลายผิววัสดุมุงหลังคาที่เรนเดอร์แล้ว | ระนาบหลังคาที่วาดตามมุม และความลาดชันของแต่ละผนัง: ดู [หลังคา: ความลาดชันของแต่ละผนัง จั่ว หลังคาเพิง และระนาบหลังคา](topic:roofs) |
| การเปลี่ยนผนัง ประตู หรือหน้าต่างที่โปรแกรมอื่นสร้าง | โปรแกรมสร้างแบบของคุณ; เครื่องมือวาดเปลี่ยนเฉพาะสิ่งที่วาดไว้เท่านั้น |
| โปรไฟล์ผนังที่ยื่นออกหรือมีรู; ช่องเปิดผนังที่ไม่ใช่สี่เหลี่ยม; การเพิ่มหรือลบจุดโปรไฟล์ของผนังในมุมมอง 3D | โปรไฟล์ การเชื่อม ความเอียง และช่องเปิดทำงานใน Properties ในภาพด้านและภาพตัด บนมุมมองหน้าของผนัง และด้วยกริปใน 3D สำหรับผนังตรงและโค้ง: ดู [ปรับรูปร่างผนัง: เชื่อม โปรไฟล์ ความเอียง และช่องเปิด](topic:wall-shape) |
| บนผนังโค้ง: {{ui:Trim / extend}} และ {{ui:Corner}}, โครงสร้าง, ไดเมนชันในผังอัตโนมัติ, การสแนปตามส่วนโค้ง (สแนปไปยังปลายและจุดกึ่งกลางของส่วนโค้ง) | วาดผนังเป็นเส้นตรงสำหรับงานเหล่านั้น หรือใช้ช่วงเส้นตรง ผนังโค้งอยู่ใน [วาดผนัง](topic:draw-walls) |
| การลากรายการไลบรารีที่วางแล้วในมุมมอง 3D | ลากในผัง หรือพิมพ์ X, Y และ Rotation ใน {{ui:Properties}}: ดู [วางอุปกรณ์และเฟอร์นิเจอร์จากไลบรารี](topic:place-from-library) |
| การวางพืชจากไลบรารีพืชของพื้นที่ทำงาน Landscape ของ CivilCraft | ปลูกใน CivilCraft หรือวางต้นไม้และพุ่มไม้จาก entourage ของไลบรารี: ดู [วางอุปกรณ์และเฟอร์นิเจอร์จากไลบรารี](topic:place-from-library) |
| ในส่วนเสริม Plant (ปิดอยู่จนกว่าคุณจะเปิด): การวาดท่อเดินเป็นเส้นเข้าไปในโมเดล หมายเลขม้วนท่อบนภาพไอโซเมตริก การตรวจผังของอุปกรณ์ที่วางจากไลบรารี | วาดเส้นด้วย {{ui:Pipe}} (ดู [ท่อและดักต์](topic:pipes-and-ducts)); การตรวจผังอ่านตารางอุปกรณ์ของส่วนเสริมเอง |
| การหมุน การสะท้อน หรือการทำอาร์เรย์ผนัง ประตู และหน้าต่างที่วาดทีละชิ้น (ผนังย้าย คัดลอก และยืดได้ด้วย Move, Offset และ Box stretch: ดู [รูปร่างผนัง การแบ่ง ออฟเซ็ต การยืด และการล็อก](topic:wall-tools)); รูปแบบการต่อ (butt, square off) ที่มุมของผนังโค้งหรือผนังสามเส้นขึ้นไป (ดู [รูปร่างผนัง การแบ่ง ออฟเซ็ต การยืด และการล็อก](topic:wall-tools)); เครื่องมือข้อความ; ผนังม่าน | คัดลอกทุกอย่างในชั้นด้วย {{ui:Copy this level…}} (ดู [วาดผนัง](topic:draw-walls#levels)); หรือวาดใหม่ |
| ชั้นของชุดผนังที่วาดในผังและภาพตัด; ไดเมนชันในภาพตัดและภาพด้าน; ไดเมนชันอ้างอิงถึงประตู หน้าต่าง และส่วนประกอบอื่น; ชุดและเมมเบรนในตารางและปริมาณ; ไลบรารีวัสดุที่ใช้ร่วมกันระหว่างโครงการ; ลำดับความสำคัญของชั้นในภาพตัด ภาพด้าน และ 3D และที่จุดของผนังสามเส้นขึ้นไป (บนผัง มุม จุดต่อ T และจุดตัดของผนังสองเส้นถูกจัดการด้วยลำดับความสำคัญของชั้น: ดู [รูปร่างผนัง การแบ่ง ออฟเซ็ต การยืด และการล็อก](topic:wall-tools)); ชั้นแบบห่อหรือแปรผัน; การแก้ไขชุดของผนังที่โปรแกรมอื่นสร้าง | ชั้นอยู่ในชนิดของผนังและในการแสดงตัวอย่าง ({{ui:Wall assemblies…}}); ผนังถูกวัดเป็นซองเดียว: ดู [ชุดผนังและไดเมนชันอ้างอิง](topic:wall-assemblies) |
| การเปลี่ยนรูปร่างหรือขนาดขององค์ประกอบ (นอกจากผนัง ประตู และหน้าต่างที่วาดที่นี่ และองค์ประกอบที่วางจากตระกูล) | โปรแกรมสร้างแบบของคุณ การลบ คัดลอก ตัด และวางทำงานที่นี่: ดู [ลบ ตัด คัดลอก และวางองค์ประกอบอาคาร](topic:edit-elements) |
| การลบชั้น พื้นที่ อาคาร หรือที่ตั้ง | ลบองค์ประกอบที่อยู่ในนั้น |
| การวางองค์ประกอบอาคารลงในโมเดลอื่น | คัดลอกและวางภายในโมเดลเดียวกัน; รายการไลบรารีที่วางแล้ววางได้ในโมเดลใดก็ได้ |
| การเพิ่มคุณสมบัติหรือชุดคุณสมบัติใหม่ | กรอกค่าที่มีอยู่ที่นี่ หรือเพิ่มพารามิเตอร์ในโปรแกรมสร้างแบบแล้วส่งออกใหม่ |
| การแก้ไขปริมาณ รายการ และการแจงนับ | โปรแกรมสร้างแบบของคุณ |
| การบันทึกไฟล์โครงการของโปรแกรมอื่น | BimCraft บันทึก IFC (และไฟล์ตระกูลของตนเอง: ดู [ตระกูลและขนาด](topic:families)) |
| ตระกูล: ไลบรารีของตระกูลที่วางจากผังและใช้ร่วมกันระหว่างโครงการ (Library), ฮอตสปอตที่ลากในมุมมอง 3D ขององค์ประกอบที่วาง (ลากในพรีวิวของตัวแก้ไขตระกูลและในผังได้), ระดับรายละเอียดที่เลือกต่อมุมมอง (ระดับเดียวสำหรับโครงการ; แผ่นงานเลือกตามมาตราส่วน), การหมุนแบบหมุนรอบแกน (revolve) บนระนาบตั้งในตระกูลอื่นที่หมุนหนึ่งในสี่รอบ, สัญลักษณ์ผังประตูและหน้าต่างของตนเอง (ใช้สัญลักษณ์ของตัวเริ่มต้น) | ตระกูลที่มีพารามิเตอร์แบบมีชนิด สูตร สัญลักษณ์ผังของตนเอง ฮอตสปอต การทำซ้ำ ระดับรายละเอียด ตระกูลภายในตระกูล ขนาดจากตาราง และพารามิเตอร์รายองค์ประกอบ ทำได้ที่นี่: ดู [แก้ไขตระกูล](topic:family-editor) และ [ตระกูลและขนาด](topic:families) ทำซ้ำตระกูลเพื่อเริ่มจากตระกูลได้ |
| การแก้ไขประเภทของโปรแกรมอื่นเป็นตระกูล; การเปลี่ยนรายการไลบรารีเป็นตระกูล | ประเภทของโปรแกรมอื่นจะแสดงเป็นรายการ จัดกลุ่มตามการเดา และเลือกองค์ประกอบของมัน รายการไลบรารีวางตามที่เป็น |
| อุปกรณ์ วาล์ว และเครื่องจักรของผู้ผลิต (ความจุ น้ำหนัก ขนาดการเชื่อมต่อของผู้ผลิต); ความยาวข้อต่อทีและตัวลดตาม ASME B16.9 บนม้วนเหล็ก; การสูญเสียแรงดันผ่านข้อต่อ การไหลและการปรับสมดุล; หัวสปริงเกลอร์; รางสายไฟ; การกำหนดขนาดสแต็กและท่อระบายตามหน่วยอุปกรณ์; การลากมุมของเส้นท่อ; การตัดช่องเปิดในผนังและพื้น; การปล่อยปลายเส้นที่ยึดกับพอร์ต (ยกเว้นโดยการลบอุปกรณ์); พอร์ตบนรายการไลบรารีที่วางจากพาเนลไลบรารี; น้ำหนักข้อต่อ; ตะเข็บ เกจ และตัวเชื่อมของดักต์ | เส้นท่อและดักต์ที่มีข้อต่อมาตรฐานทั่วไป ระบบ ผัง ตาราง และการคำนวณปริมาณ วาดที่นี่: ดู [ท่อและดักต์](topic:pipes-and-ducts) อุปกรณ์ทั่วไปที่มีพอร์ต เส้นที่เชื่อมต่อ และการตรวจการเชื่อมต่อ: [อุปกรณ์ MEP ที่มีพอร์ต](topic:mep-equipment), [เชื่อมท่อและดักต์เข้ากับอุปกรณ์](topic:mep-connections) ชุดการชน ระยะห่าง และรายการช่องเปิด: [ตรวจสอบท่อและดักต์กับโครงสร้าง](topic:mep-against-structure) ม้วนท่อเหล็กและแผ่นม้วน รายการตัดดักต์: [ม้วนท่อ (pipe spools)](topic:pipe-spools) นำอุปกรณ์ของผู้ผลิตเข้าจากโปรแกรม MEP ของคุณเป็น IFC |
| การตรวจการออกแบบโครงสร้างของ I-shape เชื่อม, I-shape ที่ชื่อโปรไฟล์ IFC ไม่ได้ระบุเป็นขนาดรีด W, S, IPE, HEA หรือ HEB, และท่อ เหล็กมุม และรางนำ (จะคืนค่าว่าไม่ได้ตรวจ); การโก่งตัวหรือการตอบสนองแบบไดนามิก (ความถี่ธรรมชาติอยู่ในบล็อก Finite elements) (ลำดับที่สองคือ P-Delta เท่านั้น: ยืดหยุ่น ดัด ไม่มีการลดความแข็ง); ผนังและพื้นในการวิเคราะห์; แรงที่มาจากพื้นที่ (ยกเว้นแรงดันหนึ่งค่าบนพื้นคอนกรีตทุกแผ่น) | แท็บ {{ui:Analysis}} ให้แรง แรงปฏิกิริยา และการโก่งตัวของคาน เสา และค้ำยันด้วยการวิเคราะห์ลำดับแรก และตรวจ I-shape รีด เป็นเครื่องช่วยจนกว่าวิศวกรจะตรวจทาน: ดู [วิเคราะห์โครงสร้างเฟรม](topic:frame-analysis#design-checks) |

## การดูโมเดล

| ยังไม่มี | ทางเลือกในตอนนี้ |
|---|---|
| 3D จากไฟล์โครงการ | ส่งออก IFC แล้วเปิด ดู [นำไฟล์โครงการเข้า 3D ผ่าน IFC](topic:rvt-to-ifc) |
| ภาพด้านภายในในชุดแบบที่สร้าง (สร้างได้จาก Properties ของห้อง และบนแผ่นงานของคุณเอง); ไดเมนชันของคุณเองบนภาพด้านและภาพตัด (เครื่องหมายระดับ ความสูง ความกว้าง และป้ายประตู/หน้าต่างถูกวาด; หมายเหตุเขียนในมุมมอง: ดู [แก้ไขในภาพด้านและภาพตัด](topic:edit-in-elevations)); การวาดผนังในภาพด้าน (วาดในระนาบของภาพตัด); เทมเพลตทีมผ่าน Studio | ชุดแบบที่สร้างจากโมเดล: ดู [ภาพด้าน ภาพตัด และแผ่นงาน](topic:sheets) สำหรับโมเดล IFC ใดก็ได้: ระนาบ {{ui:Section}} เดียว หรือกล่องตัด; ดู [ตัดโมเดล IFC ด้วยระนาบตัด](topic:section-plane) |
| มุมมองเรียกใช้ (callout), มุมมองรายละเอียด, มุมมองการร่าง และสัญลักษณ์; เส้นและเฮตช์ที่วาดในมุมมอง; การครอบภาพด้านหรือภาพตัด; เทมเพลตมุมมองสำหรับภาพด้าน ภาพตัด มุมมองเพดาน และ 3D; มุมมองเพดานในชุดแบบที่สร้าง; ชุดแผ่นงานของคุณทั้งหมดในไฟล์ PDF เดียว | ผังและมุมมองเพดานมีช่วงมุมมอง พื้นที่ครอบ มาตราส่วน และพื้นหลัง (ผังมีเทมเพลตด้วย) และแผ่นงานของคุณรับผัง มุมมองเพดาน ภาพด้าน ภาพตัด และตารางได้ แต่ละแผ่นบันทึกเป็น PDF: ดู [มุมมอง ช่วงมุมมอง และแผ่นงานของคุณ](topic:views-and-sheets) |
| การย้ายโคมไฟที่วางไว้ขึ้นเพดานภายหลัง; เพดานลาดหรือเป็นขั้น; ลายเพดานอื่นนอกจากกริดห้าแบบ; สัญลักษณ์ของโคมไฟเองในผังเพดาน | วางด้วย **Mount: At the ceiling**; ผังเพดานวาดอุปกรณ์จากรูปร่างของตนเอง: ดู [วางอุปกรณ์และเฟอร์นิเจอร์จากไลบรารี](topic:place-from-library) |

## แบบ

| ยังไม่มี | ทางเลือกในตอนนี้ |
|---|---|
| การแก้ไข วัด หรือบันทึก DWG และ DXF | แอปการร่าง CadCraft (ปุ่ม {{ui:Edit in CadCraft}} บนมุมมอง 2D) |

| ไฟล์ DWG เก่ากว่า R13 และ DXF แบบไบนารี (BimCraft จะแจ้งเมื่อคุณเปิด) | บันทึกแบบอีกครั้งเป็น DWG รุ่นใหม่ หรือเป็น ASCII DXF |
| แบบที่เชื่อมโยงอยู่ภายในแบบที่เชื่อมโยง | เปิดโดยตรง |
| ภาพ TIFF | บันทึกสำเนา PNG หรือ JPEG ชื่อเดียวกันแล้วเพิ่ม |
| แบบ DGN | แสดงในรายงานโฟลเดอร์เท่านั้น |
| อ็อบเจกต์ที่อยู่ภายใต้ **Not drawn yet** | ดูแบบในโปรแกรมที่สร้างมัน |
| โซลิด ACIS, บอดี้ รีเจียน และพื้นผิว, และเมช subdivision ใน 3D | ส่งออก IFC หรือ 3D faces จากโปรแกรมที่สร้างแบบ |
