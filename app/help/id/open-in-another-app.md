## Yang akan Anda lakukan

Lanjutkan pekerjaan pada file di aplikasi yang dibuat untuk pekerjaan berikutnya, tanpa menyimpannya dan membukanya kembali.

## Langkah

1. Buka gambar DWG atau DXF untuk mengeditnya di aplikasi drafting, atau model IFC untuk mendetailkannya di aplikasi detailing.
2. Klik {{ui:Edit di CadCraft}} pada tampilan 2D gambar, atau {{ui:Buka di DetailCraft}} di bilah alat model.
3. Aplikasi lain terbuka di tab baru dengan file sudah terbuka.

## Yang harus Anda lihat

- File di tab baru. BimCraft juga tetap membukanya.
- Model dengan perubahan yang belum disimpan ikut terbawa beserta perubahannya. Salinan Anda sendiri tidak disimpan.
- Gambar terbawa tanpa gambar tertautnya.

## Yang perlu diketahui

- File berpindah antara kedua tab di dalam peramban Anda. Tidak ada yang diunggah.
- Tombol hanya muncul ketika aplikasi lain terbuka di tempat Anda dan dapat menerima file dengan cara ini.
- Jika tidak ada yang terbuka, peramban memblokir tab baru: izinkan pop-up untuk situs ini, lalu klik lagi.
