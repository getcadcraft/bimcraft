BimCraft כיום הוא קורא, בודק ועורך נתוני IFC, שהתחיל לשרטט בניינים: קירות, דלתות וחלונות, חדרים, רצפות, תקרות וגגות (ראו [שרטוט קירות](topic:draw-walls), [דלתות וחלונות](topic:doors-and-windows) ו-[חדרים, רצפות, תקרות וגגות](topic:floors-and-roofs)). זו הרשימה הכנה של מה שהוא עדיין אינו עושה, עם מה להשתמש במקומו.

## מידול ויצירה

| טרם נבנה | במקום, כיום |
|---|---|
| שרטוט קורות; עמודים של פרופילי פלדה | השתמשו בתוכנית היצירה שלכם, ואז פתחו כאן את יצוא ה-IFC שלה. עמודים מלבניים ועגולים מוצבים כאן (ראו [רשתות ועמודים](topic:grids-and-columns)); מדרגות ישרות, בצורת L, U, פיתול וספירליות, וכן מעקות, מצוירים כאן (ראו [מדרגות ומעקות](topic:stairs-and-railings)) |
| חלון בחזית של אשנב גג; אשנבים על מישורי גג שצוירו ביד; גגות מעוקלים; מרקם כיסוי גג מרונדר | מישורי גג שמצוירים לפי פינותיהם, ושיפוע לכל קיר: ראו [גגות: שיפוע לכל קיר, גמלונים, סככות ומישורי גג](topic:roofs) |
| שינוי קירות, דלתות או חלונות שתוכנית אחרת יצרה | תוכנית היצירה שלכם; כלי השרטוט משנים רק את מה שהם שרטטו |
| פרופילי קיר עם בליטות או חורים; פתחי קיר שאינם מלבנים; הוספה או הסרה של נקודות פרופיל של קיר בתצוגה התלת-ממדית | פרופיל, חיבור, שיפוע ופתחים עובדים ב-{{ui:מאפיינים}}, בחזיתות ובחתכים, בתצוגת הפנים של הקיר ובידיות בתלת-ממד, לקירות ישרים ומעוקלים: ראו [עיצוב קיר: חיבור, פרופיל, שיפוע ופתחים](topic:wall-shape) |
| בקירות מעוקלים: {{ui:חיתוך / הארכה}} ו-{{ui:פינה}}, מסגור, מידות תוכנית אוטומטיות, נעיצה לאורך הקשת (נועצים בקצותיה ובאמצע הקשת) | שרטטו את הקיר ישר לאלה, או השתמשו בקטעים ישרים. קירות מעוקלים מתוארים ב-[שרטוט קירות](topic:draw-walls) |
| גרירת פריט ספרייה שהוצב בתצוגה התלת-ממדית | גררו אותו בתוכנית, או הקלידו X, Y ו-Rotation ב-{{ui:מאפיינים}}: ראו [הצבת ציוד וריהוט מהספרייה](topic:place-from-library) |
| הצבת צמחים מספריית הצמחים של סביבת העבודה Landscape של CivilCraft | שתלו אותם ב-CivilCraft, או הציבו עצים ושיחים מ-entourage של הספרייה: ראו [הצבת ציוד וריהוט מהספרייה](topic:place-from-library) |
| בתוסף Plant (כבוי עד שמפעילים אותו): שרטוט קו מנותב לתוך המודל, מספרי ספול באיזומטריות שלו, בדיקת פריסה של ציוד שהוצב מהספרייה | שרטטו את הקו עם {{ui:צינור}} (ראו [צינורות ותעלות](topic:pipes-and-ducts)); בדיקת הפריסה קוראת את טבלת הציוד של התוסף עצמו |
| סיבוב, שיקוף או מערך של קירות, דלתות וחלונות בודדים שצוירו (קירות זזים ומועתקים עם הזזה, היסט ומתיחה בתיבה: ראו [צורות קירות, פיצול, היסט, מתיחה ונעילה](topic:wall-tools)); סגנון חיבור (butt, square off) בפינות עם קיר מעוקל או שלושה קירות ומעלה (ראו [צורות קירות, פיצול, היסט, מתיחה ונעילה](topic:wall-tools)); כלי טקסט; קירות מסך | העתיקו הכול ברמה עם {{ui:העתקת מפלס זה…}} (ראו [שרטוט קירות](topic:draw-walls#levels)); אחרת שרטטו אותם מחדש |
| שכבות הרכבת קיר שמצוירות בתוכנית ובחתך; מידות בחתכים ובחזיתות; מידות ייחוס לדלתות, לחלונות ולרכיבים אחרים; הרכבות וקרומים בלוחות ובכמויות; ספריית חומרים משותפת בין פרויקטים; עדיפות שכבות בחתכים, בחזיתות, בתלת-ממד ובצמתים של שלושה קירות ומעלה (בתוכנית, פינות, חיבורי T וחיתוכים של שני קירות מנוקים לפי עדיפות שכבות: ראו [צורות קירות, פיצול, היסט, מתיחה ונעילה](topic:wall-tools)); שכבות עטופות או משתנות; עריכת הרכבה של קיר שתוכנית אחרת יצרה | השכבות נמצאות בסוג הקיר ובתצוגה המקדימה שלו ({{ui:הרכבות קירות…}}); קירות נמדדים כמעטפת אחת: ראו [הרכבות קירות ומידות ייחוס](topic:wall-assemblies) |
| שינוי צורה או גודל של רכיב (למעט קירות, דלתות וחלונות שצוירו כאן, ורכיבים שהוצבו ממשפחה) | תוכנית היצירה שלכם. מחיקה, גזירה, העתקה והדבקה עובדים כאן: ראו [מחיקה, גזירה, העתקה והדבקה של רכיבי בניין](topic:edit-elements) |
| מחיקת קומות, חללים, בניינים או האתר | מחקו את הרכיבים שבתוכם |
| הדבקת רכיבי בניין למודל אחר | העתקה והדבקה בתוך מודל אחד; פריטי ספרייה שהוצבו מודבקים לכל מודל |
| הוספת מאפיינים חדשים או קבוצות מאפיינים | מלאו ערכים קיימים כאן, או הוסיפו את הפרמטר בתוכנית היצירה ויצאו שוב |
| עריכת כמויות, רשימות, ערכים מוגדרים (enumerations) | תוכנית היצירה שלכם |
| שמירת קובצי פרויקט של תוכניות אחרות | BimCraft שומר IFC (וקובצי המשפחות שלו: ראו [משפחות וגדליהן](topic:families)) |
| משפחות: ספרייה של משפחות שמוצבות מהתוכנית ומשותפות בין פרויקטים (Library), נקודה חמה שנגררת בתצוגה התלת-ממדית של רכיב שהוצב (הן נגררות בתצוגה המקדימה של עורך המשפחות ובתוכנית), רמות פירוט שנבחרות לכל תצוגה (רמה אחת לפרויקט; גיליונות בוחרים לפי קנה מידה), סיבוב על מישור אנכי בתוך משפחה אחרת שמסובבת ברבע סיבוב, סמלי תוכנית משלהן לדלתות ולחלונות (הם מצוירים לפי הסמל ההתחלתי שלהם) | משפחות עם פרמטרים מוקלדים, נוסחאות, סמל תוכנית משלהן, נקודות חמות, חזרות, רמות פירוט, משפחות בתוך משפחות, גדלים מטבלה ופרמטרים לכל רכיב נוצרות כאן: ראו [עריכת משפחה](topic:family-editor) ו-[משפחות וגדליהן](topic:families). שכפלו משפחה כדי להתחיל ממנה |
| עריכת טיפוסים של תוכניות אחרות כמשפחות; הפיכת פריט ספרייה למשפחה | טיפוסים של תוכניות אחרות מוצגים, מקובצים לפי ניחוש, והרכיבים שלהם נבחרים. פריטי ספרייה מוצבים כמו שהם |
| אביזרים, שסתומים וציוד של יצרנים (יכולות, משקלים, גדלי חיבור של היצרן); אורכי מחבר T ומצמצם לפי ASME B16.9 בספולים מפלדה; אובדן לחץ באביזרים, זרימות ואיזון; ספרינקלרים; מסילות כבלים; מיון מחסניות ואוורורים לפי יחידות אביזר; גרירת פינות של קו; חיתוך פתחים בקירות ובתקרות; שחרור קצה של קו המחובר לפורט (חוץ ממחיקת הציוד); פורטים על פריטי ספרייה שהוצבו מהחלונית ספרייה; משקלי אביזרים; תפרי תעלות, מדי עובי וחיברים | קווי צינורות ותעלות עם אביזרים סטנדרטיים כלליים, מערכות, תוכניות, לוחות והכמויות מצוירים כאן: ראו [צינורות ותעלות](topic:pipes-and-ducts). ציוד כללי עם פורטים, קווים מחוברים ובדיקת חיבורים: [ציוד MEP עם פורטים](topic:mep-equipment), [חיבור צינורות ותעלות לציוד](topic:mep-connections). קבוצות התנגשות, מרווחים ורשימת פתחים: [בדיקת צינורות ותעלות מול המבנה](topic:mep-against-structure). ספולים ודפי ספולים מפלדה, רשימת חיתוך של תעלות: [ספולי צינורות פלדה](topic:pipe-spools). פריטים של יצרנים הביאו מתוכנית ה-MEP שלכם כ-IFC |
| בדיקות קוד תכנון של I-shapes מרותכים, של I-shapes שפרופיל ה-IFC שלהם אינו מוגדר כגודל W, S, IPE, HEA או HEB מגולגל, ושל צינורות, זוויות ותעלות (הם חוזרים לא נבדקים); קריסה או תגובה דינמית (תדירויות טבעיות נמצאות בבלוק Finite elements) (סדר שני הוא P-Delta בלבד: אלסטי, כיפוף, בלי הפחתת קשיחות); קירות ורצפות בניתוח; עומסים שנוצרים משטחים (חוץ מלחץ אחד על כל רצפת בטון) | הלשונית {{ui:ניתוח}} נותנת כוחות, תגובות ותזוזות של קורות, עמודים וחיזוקים בניתוח מסדר ראשון, ובודקת I-shapes מגולגלים, כעזר עד שמהנדס בדק את התוצאה: ראו [ניתוח שלד מבני](topic:frame-analysis#design-checks) |

## צפייה במודלים

| טרם נבנה | במקום, כיום |
|---|---|
| תלת-ממד מקובצי פרויקט | יצאו IFC ופתחו אותו. ראו [קבלת קובץ פרויקט לתלת-ממד דרך IFC](topic:rvt-to-ifc) |
| חזיתות פנימיות בסט השרטוטים שנוצר (מתוך מאפייני חדר ובגיליונות שלכם הן נבנות); מידות משלכם בחזיתות ובחתכים (סימוני מפלס, גבהים, רוחב ותגיות דלתות וחלונות מצוירים; הערות נכתבות בתצוגה: ראו [עריכה בחזיתות ובחתכים](topic:edit-in-elevations)); שרטוט קירות בחזית (הם מצוירים במישור של חתך); תבניות צוות דרך Studio | סט השרטוטים שנוצר מהמודל: ראו [חזיתות, חתכים וגיליונות](topic:sheets). לכל מודל IFC: מישור {{ui:חתך}} אחד, או קופסת חתך; ראו [חיתוך מודל IFC במישור חתך](topic:section-plane) |
| תצוגות הסבר (callout), תצוגות פירוט, תצוגות שרטוט ומקרא; קווי שרטוט וקווקוו שצוירו בתצוגה; חיתוך חזית או חתך; תבניות תצוגה לחזיתות, לחתכים, לתוכניות תקרה ולתצוגות תלת-ממד; תוכניות תקרה בסט השרטוטים שנוצר; סט שלם של גיליונות משלכם ב-PDF אחד | לתוכניות ולתוכניות תקרה יש טווחי תצוגה, אזור חיתוך, קנה מידה ונספח (לתוכניות גם תבניות), והגיליונות שלכם מקבלים תוכניות, תוכניות תקרה, חזיתות, חתכים וטבלאות, וכל אחד נשמר כ-PDF: ראו [תצוגות, טווחי תצוגה וגיליונות משלכם](topic:views-and-sheets) |
| העברת נורה שהוצבה לתקרה אחר כך; תקרות משופעות או מדורגות; דפוסי תקרה מלבד חמש הרשתות; סמל משלה של נורה בתוכנית התקרה | הציבו אותה עם **הרכבה: בתקרה**; תוכנית התקרה מציירת גוף תאורה לפי הצורה שלו: ראו [הצבת ציוד וריהוט מהספרייה](topic:place-from-library) |
| שיתוף קבוצות חיפוש עם אחרים, קבוצות בתוך קובץ ה-IFC | הקבוצות נשארות בדפדפן הזה; ראו [חיפוש רכיבים לפי מחלקה, שם או מאפיין](topic:find) |
| מדידת זוויות, או לאורך מסלול של כמה נקודות | מדדו כל חלק בנפרד עם {{ui:מדידה}}: ראו [מדידת מרחקים, שטחי פנים ומיקומים בתלת-ממד](topic:measure) |
| טקסטורות בתצוגה התלת-ממדית החיה | חומרים צבועים מציגים את הצבע שלהם בתצוגה ואת המרקם שלהם בתמונות מרונדרות: ראו [רינדור תמונה של המודל](topic:render) |
| התנגשויות מרווח (רכות) בין כל שתי קבוצות, קבוצות התנגשות, שמירת תוצאות התנגשות | הריצו {{ui:בדיקת התנגשויות}} וצרו בעיות מהחשובות: ראו [בדיקת התנגשויות](topic:clash-check). לצינורות ותעלות מול המבנה יש {{ui:בדיקת מרווחים}}: ראו [בדיקת צינורות ותעלות מול המבנה](topic:mep-against-structure) |
| שמירת כמה מודלים כקבוצה אחת, או עריכת שני מודלים בו-זמנית | ערכו מודל אחד בכל פעם; כל אחד שומר את הקובץ שלו |
| הקצאת בעיות, תאריכי יעד, תוויות, כמה נקודות מבט לכל בעיה, עריכת בעיה | נקודת מבט אחת לכל בעיה; ראו [בעיות וקובצי BCF](topic:issues-bcf) |
| `.ifczip` ו-`.ifcxml` | חלצו אותו, או יצאו `.ifc` רגיל |
| שכבות מפה למודל ללא המרת מפה, או בתצוגות של שרטוט | יצאו את המודל עם הקואורדינטות שלו: ראו [מפה על הקרקע מתחת למודל](topic:map-layers) |
| סריקות E57 מעל 6 מיליון נקודות או 512 MB; קובצי סורקים של היצרנים עצמם (RCP, RCS, FLS, LGS, TZF, ZFS); ענני נקודות בתצוגה התלת-ממדית של שרטוט; שמירת מיקומו של ענן עם המודל | יצאו את הסריקה כ-LAS או LAZ ופתחו אותה לצד מודל IFC: ראו [פורמטים של ענני נקודות](topic:point-cloud-formats) ו-[הצגת ענן נקודות לצד המודל](topic:point-clouds) |
| רישום סריקות: מציאת מטרות (כדורים, לוחות שחור-לבן) בסריקה לבדה, פתרון כל הסריקות יחד (bundle adjustment), קנה מידה, רישום מול מודל | בחרו נקודות תואמות או הקלידו קואורדינטות מטרה, ואז דייקו סריקה אחת בכל פעם עם ICP: ראו [רישום כמה סריקות לאחת](topic:register-scans) |
| פתיחת קובצי פרויקט `.pln`, `.pla`, `.tpl` ו-`.bpn` | יצאו IFC ו-DWG מהם, או חבילת פרויקט: ראו [פתיחת קובצי .pln ו-.pla](topic:pln-project-files) ו-[פתיחת חבילת פרויקט](topic:open-project-bundle) |
