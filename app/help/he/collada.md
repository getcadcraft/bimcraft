{{ui:Collada}} בסרגל הכלים (או {{ui:Export Collada (.dae, .kmz)…}} בתפריט קובץ בסגנונות התפריט והרצועה) כותב את מה שפתוח כ-Collada 1.4.1: כל מודל שמוצג, ומודלים נוספים במקום שבו מיקמתם אותם.

## ייצוא

1. בחרו {{ui:Collada}}.
2. בחרו את הפורמט:
   - {{ui:Collada file (.dae), for Blender and other 3D programs}}.
   - {{ui:Google Earth package (.kmz): the model placed where it is on the map}}. מוצע רק כשלמודל יש מיקום.
3. בחרו את האפשרויות, ואז {{ui:Export}}. הקובץ יורד, ושורת המצב מציינת כמה אלמנטים נכנסו.

| אפשרות | מה היא עושה |
|---|---|
| {{ui:Write the location into the file}} | מוסיפה ל-.dae את קו הרוחב, קו האורך, הגובה והכיוון של נקודת המוצא של הקובץ |
| {{ui:Height}} | {{ui:On the ground: the model’s level 0 sits on the terrain}}, או {{ui:The model’s own height above sea level}} |
| {{ui:Include rooms and spaces}} | החללים נכללים גם הם (הם מושמטים כברירת מחדל) |
| {{ui:Include hidden elements}} | אלמנטים שהסתרתם נכתבים גם הם (כברירת מחדל נכתב רק מה שרואים) |

## מה יש בקובץ

| במודל | בקובץ Collada |
|---|---|
| בניין, קומות | צמתים מקוננים, קומות לפי סדר הגובה; אלמנטים שאינם על קומה תחת "Unplaced" |
| כל אלמנט | צומת אחד עם רשת משלו, בשם כמו במודל (שמו, ואם אין שם — המחלקה והתג שלו) |
| מחלקה, GlobalId, סוג מוגדר מראש | בנתונים הנוספים של הצומת (פרופיל IFC), עם השם המדויק (פרופיל ModelCraft) |
| צבעים | חומרים, עם שקיפות |
| יחידות וצירים | מטרים, Z כלפי מעלה. מפלס 0 של המודל שמלפנים נמצא בגובה 0 |

המודל נשאר קרוב לנקודת המוצא על פני הקרקע, כך שתוכנות שעובדות בדיוק יחיד מציגות אותו בלי רעידות. ModelCraft כותב את קובצי ה-Collada שלו באותו כותב, ופותח את הקבצים האלה עם שמות האלמנטים שלהם.

## מאיפה מגיע המיקום

המודל שמלפנים נותן את המיקום, באותה דרך שבה {{ui:Measure}} מחשב קו רוחב וקו אורך של נקודה:

- המרת מפה (IFC4 IfcMapConversion, או קבוצות המאפיינים של IFC2X3) דרך מערכת הקואורדינטות של המודל. מערכת שבחרתם למודל גוברת על זו שהקובץ מציין.
- אחרת, קו הרוחב וקו האורך של האתר (משוערים: מספיקים בתוך אתר).

הכיוון נמדד ולא מונח מראש: הוא לוקח בחשבון את סיבוב המפה, הצפון האמיתי והתכנסות המפה. כדי לתת למודל מיקום, השתמשו ב-{{ui:Map origin…}} תחת {{ui:Measure}}.

## במערכות אחרות

- ב-**Google Earth** נקרא ה-.kmz: המודל מופיע במיקומו, מסובב לצפון. לקובץ .dae רגיל אין מקום ש-Google Earth קורא ממנו מיקום; השתמשו ב-.kmz.
- ב-**Blender** (4.x ומוקדם יותר): File, Import, Collada (.dae). כל אלמנט נכנס כאובייקט משלו עם החומר שלו. המיקום נשמר בנתונים הנוספים של הקובץ, ש-Blender אינו קורא. Blender 5.0 הסיר את מייבא Collada המובנה שלו; שם השתמשו ב-{{ui:USD}} או בייצוא glTF, או פתחו את ה-.dae ב-Blender 4.5 ושמרו כ-.blend.

הבדיקות שלנו בודקות כל קובץ מול סכמת Collada 1.4.1 וקוראות אותו בחזרה בעזרת קורא Collada עצמאי. הקבצים טרם נפתחו ב-Blender או ב-Google Earth.
