## מה תעשו

הפכו קובץ פרויקט לקובץ IFC שאפשר לסובב, לבדוק, לבקר ולערוך ב-BimCraft. BimCraft עדיין אינו קורא את המודל התלת-ממדי שבתוך קובץ `.rvt`, ולכן הייצוא נעשה בתוכנה שיצרה את הקובץ (Revit); BimCraft פותח את התוצאה.

## שלבים

1. פתחו את הפרויקט בתוכנה שיצרה אותו. הכרטיס של BimCraft מציין את הגרסה שבה נשמר.
2. פתחו תצוגה תלת-ממדית שמראה את מה שאתם רוצים לייצא.
3. בחרו **File > Export > IFC**.
4. בחלון הייצוא בחרו הגדרה (או **Modify setup…**) עם ההגדרות שלהלן.
5. בחרו תיקייה ושם קובץ, וייצאו.
6. ב-BimCraft לחצו על {{ui:Choose a file}} ובחרו את קובץ `.ifc` החדש. מודלים מקושרים שיוצאו כקבצים נפרדים נפתחים לאותה סצנה עם הוספת מודל.

## ההגדרות שנפתחות הכי טוב כאן

| הגדרה בייצוא | בחרו | למה |
|---|---|---|
| גרסת IFC | **IFC4 Reference View** לצפייה, לבדיקה ולהוצאת כמויות; **IFC2X3 Coordination View 2.0** כאשר אחרים צריכים IFC2X3 | שניהם נפתחים במלואם. **IFC4 Design Transfer View** נפתח גם הוא, עם צורות מדויקות יותר, אבל הקובץ גדול יותר ואיטי יותר. |
| סוג קובץ | **IFC** (פשוט) | BimCraft אינו פותח `.ifczip` או `.ifcxml`. |
| שלב / אלמנטים גלויים | השלב שאתם מתכוונים אליו, ו-**Export only elements visible in view** כאשר הגדרתם את התצוגה התלת-ממדית לכך | משאיר בחוץ מה שהסתרתם בכוונה. |
| סטי מאפיינים | **Export Revit property sets** ו-**Export IFC common property sets** | הם הופכים לסטי המאפיינים ש-BimCraft מציג ב-{{ui:Properties}}, ושבהם משתמשים {{ui:Find}}, {{ui:Color}} ו-{{ui:Model checks}}. |
| כמויות בסיס | **Export base quantities** | {{ui:Quantity totals}} וטבלאות משתמשים בהן (אורכים, שטחים, נפחים) במקום לנחש. |
| חדרים ושטחים | **Export rooms in 3D views** (או האפשרות Rooms / Spaces) | החדרים מגיעים כחללים: לחצו על {{ui:Spaces}} כדי לראות אותם. |
| קבצים מקושרים | **Export linked files as separate IFCs** | כל קישור הופך לקובץ משלו; פתחו אותם יחד עם הוספת מודל והם מתיישרים. |
| בסיס קואורדינטות | **Shared coordinates** (או נקודת המדידה) | הקובץ נושא אז את מקומו במפה (IfcMapConversion), כך שפועלים מדידה › Location, שכבות מפה על הקרקע ונקודות ענן שמוצבות לפי קואורדינטות מפה. נקודת בסיס הפרויקט משאירה את המודל קרוב לראשית, אבל בלי מקומו במפה. |
| פיצול קירות ועמודים לפי מפלס | פעיל, כאשר לוקחים כמויות לפי קומה | לכל חלק של קומה יש אלמנט משלו. |

## מה אתם אמורים לראות

המודל בתלת-ממד, עם קומות שנלקחו ממפלסי הפרויקט, ומידע הפרויקט בלוח {{ui:File}}. השדה **Exported from** מציין את המייצא.

## מה הייצוא שומר ומה לא

- **נשמר**: גיאומטריה, קומות, סוגי אלמנטים, שמות, טיפוסים, רוב הפרמטרים (כסטי מאפיינים), כמויות בסיס כשמבקשים, חדרים כחללים, ומקום המפה עם קואורדינטות משותפות.
- **לא נשמר**: תצוגות, גיליונות, הערות, משפחות כמשפחות הניתנות לעריכה, סדרות עבודה ואפשרויות תכנון. קובץ IFC הוא צילום של אלמנטי המודל, לא של הפרויקט. עבור הגיליונות, ייצאו DWG ופתחו אותו בתצוגה הדו-ממדית.

## טעויות נפוצות

- **פרמטרים חסרים ב-BimCraft.** הפעילו את אפשרויות סטי המאפיינים שלמעלה וייצאו שוב.
- **חדרים חסרים.** הפעילו את אפשרות החדרים, ואז לחצו על {{ui:Spaces}}.
- **שמירה כ-`.ifczip`.** בחרו IFC פשוט, או פרקו את קובץ ה-`.ifczip`.
- **אין מקום במפה.** ייצאו עם קואורדינטות משותפות; ודאו שנקודת המדידה של הפרויקט מוגדרת.
- **ציפייה שעריכות יחזרו.** עריכות שתשמרו ב-BimCraft נכנסות לקובץ IFC חדש, ולא לקובץ הפרויקט.
