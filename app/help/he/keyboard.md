ל-BimCraft יש מעט קיצורי מקלדת. רוב העבודה נעשית בעכבר ובחלונות. קיצורים שכתובים עם {{key:Mod}} משתמשים ב-Command במק וב-Ctrl בשאר המערכות. ראו [מקשים, עכבר ולוחות מגע](common:keys) כדי לראות איך מקשים כתובים בעזרה הזו.

## בכל מקום

| מקש | מה הוא עושה |
|---|---|
| {{key:Ctrl+Shift+F}} | מעבר בין מצבי המסך: רגיל, מסך מלא, ומסך מלא עם הסרגלים מוסתרים. Ctrl בכל המערכות, כולל במק |
| {{key:Esc}} | יציאה ממסך מלא |
| {{key:Mod+,}} | פתיחת {{ui:הגדרות}}. ראו [הגדרות BimCraft](topic:settings) |
| {{key:Tab}} | מעבר בין לחצנים, תיבות סימון וערכים. אפשר להגיע לכל פקד במקלדת |

## תצוגה תלת-ממדית (מודלי IFC)

| מקש או פעולה | מה הוא עושה |
|---|---|
| {{key:F}} | התאמת המודל כולו, במבט של שלושה רבעים (כמו {{ui:התאמה}}) |
| {{key:Esc}} | ביטול הבחירה, או עצירת הצבה או הדבקה |
| לחיצה | בחירת הרכיב שמתחת לסמן; לחיצה על רקע ריק מבטלת את הבחירה |
| {{key:Mod}}+לחיצה או {{key:Shift}}+לחיצה | הוספת רכיב לבחירה, או הוצאתו ממנה |
| {{key:H}} | הסתרת הרכיבים שנבחרו. ראו [הסתרה, בידוד ורכיבים שקופים](topic:hide-and-isolate) |
| {{key:I}} | הצגת הרכיבים שנבחרו בלבד (בידוד) |
| {{key:T}} | הצגת הרכיבים שנבחרו, וכל השאר שקוף |
| {{key:Shift+H}} | הצגה מחדש של כל הרכיבים |
| {{ui:הליכה}} | ואז {{key:W}} {{key:A}} {{key:S}} {{key:D}} או מקשי החיצים מהלכים, {{key:Shift}} מריץ, גרירה מסובבת את המבט, {{key:Esc}} עוצר. ראו [הליכה במודל](topic:walk) |
| {{key:M}} | מדידת מרחקים ושטחי פאות. ראו [מדידת מרחקים, שטחי פאות ומיקומים בתלת-ממד](topic:measure) |
| גרירה בלחצן השמאלי | סיבוב סביב המודל |
| גרירה בלחצן הימני | הזזה |
| {{key:Shift}} או {{key:Mod}} וגרירה בלחצן השמאלי | הזזה (נוח בלוח מגע) |
| גלילת הגלגלת, או גרירה בלחצן האמצעי | זום |
| גלילה בשתי אצבעות או צביטה בלוח מגע | זום |
| אצבע אחת (מגע) | סיבוב; הקשה בוחרת |
| שתי אצבעות (מגע) | צביטה לזום, הזזה יחד להזזה |

| {{key:X}} | מתג מישור חתך, פועל וכבוי. ראו [חיתוך מודל IFC במישור חתך](topic:section-plane) |
| {{key:Shift+X}} | קופסת חתך סביב הרכיבים שנבחרו, עם החדר שמוגדר בהגדרות |

אין מקשים ל-{{ui:למעלה}}, ל-{{ui:מלפנים}} ול-{{ui:צד}}; השתמשו בלחצנים.

## עריכה

הפקודות זהות נמצאות בסרגל הכלים: {{ui:ביטול}}, {{ui:ביצוע חוזר}}, {{ui:העתקה}}, {{ui:הדבקה}} ותפריט {{ui:עוד}}, שמציג את המקש של כל פקודה. הן פועלות בתצוגה התלת-ממדית של מודל IFC, ולא כשמקלידים בשדה. ראו [העתקה, הדבקה ושכפול של פריטים מהספרייה](topic:copy-paste).

| מקש | מה הוא עושה |
|---|---|
| {{key:Mod+Z}} | ביטול השינוי האחרון |
| {{key:Mod+Y}} או {{key:Mod+Shift+Z}} | ביצוע חוזר של מה שהביטול החזיר |
| {{key:Mod+C}} | העתקת הרכיבים שנבחרו (השמות והמאפיינים שלהם נשלחים גם ללוח כטקסט) |
| {{key:Mod+X}} | גזירת הרכיבים שנבחרו: העתקה ואז מחיקה |
| {{key:Mod+V}} | הדבקה של מה שהעתקתם: היא עוקבת אחרי הסמן, לחצו במקום שבו היא צריכה להיות |
| {{key:Mod+Shift+V}} | הדבקה במקום: היכן שבוצעה גזירה, או לצד המקורות אחרי העתקה |
| {{key:Mod+D}} | שכפול: העתקת הרכיבים שנבחרו והתחלת הדבקתם |
| {{key:Delete}} | מחיקת הרכיבים שנבחרו, יחד עם החלקים והפתחים שלהם. ראו [מחיקה, גזירה, העתקה והדבקה של רכיבי בניין](topic:edit-elements) |
| {{key:Mod+A}} | בחירת כל הרכיבים המוצגים |
| {{key:Esc}} | ביטול כל הבחירה |

כשמסומן טקסט בעמוד, {{key:Mod+C}} מעתיק את הטקסט כרגיל.

## תצוגת תוכנית (שרטוט)

פועלים כש-{{ui:שרטוט}} פעיל ואתם לא מקלידים בשדה. ראו [שרטוט קירות](topic:draw-walls) ו[דלתות וחלונות](topic:doors-and-windows).

| מקש או פעולה | מה הוא עושה |
|---|---|
| {{key:V}} | {{ui:בחירה}} |
| {{key:W}} | {{ui:קיר}} |
| {{key:D}} | {{ui:דלת}} |
| {{key:N}} | {{ui:חלון}} |
| {{key:H}} | עם {{ui:דלת}} או {{ui:חלון}}: הצירים בקצה השני |
| {{key:Shift}} בזמן שרטוט קיר | שמירה על 0°, 90°, 180° או 270° |
| ספרות וסימני הרגל והאינץ' (`'` ו-`"`) | התחלת הקלדת אורך בתיבה {{ui:אורך}}; {{key:Enter}} משתמש בו |
| {{key:Enter}}, {{key:Esc}}, לחיצה ימנית או לחיצה כפולה | סיום הקיר שמשרטטים; {{key:Esc}} נוספת חוזרת ל-{{ui:בחירה}} |
| {{key:Delete}} | מחיקת הקירות, הדלתות והחלונות שנבחרו; הקירות שנשארו מתחברים מחדש |
| {{key:F}} כשהסמן מעל התוכנית | התאמת התוכנית |
| גלילת הגלגלת | זום סביב הסמן |
| גרירה בלחצן האמצעי או הימני, או {{key:Space}} וגרירה | הזזה; כש-{{ui:בחירה}} פעיל, גרירה רגילה גם מזיזה |
| גרירת דלת או חלון כש-{{ui:בחירה}} פעיל | הזזה לאורך הקיר שלהם, או לקיר אחר |
| שתי אצבעות (מגע) | צביטה לזום, הזזה יחד להזזה |

## הצבה והדבקה של פריטים מהספרייה

| מקש | מה הוא עושה |
|---|---|
| {{key:R}} | סיבוב הפריט ב-90° |
| {{key:Tab}} | הצמדה לקיר, מופעלת וכבויה: גב הפריט נשען על הקיר הקרוב |
| {{key:Enter}} ב-**X, Y (mm)** | הצבה במיקום שהוקלד |
| {{key:Esc}} | עצירת הצבה או הדבקה |

## עריכת ערכי IFC

| מקש | מה הוא עושה |
|---|---|
| {{key:Enter}} | שמירה של הערך שהוקלד |
| {{key:Esc}} | ביטול והחזרת הערך הישן |
| לחיצה במקום אחר | שמירה של הערך שהוקלד |
| {{key:Mod+Z}} | ביטול השינוי האחרון. רק כשיש שינויים שלא נשמרו ואתם לא מקלידים בשדה |
| {{key:Mod+Y}} | ביצוע חוזר של מה שהביטול החזיר |
| {{key:Mod+S}} | שמירה כ-IFC. רק כשיש שינויים שלא נשמרו; אחרת נפתחת פקודת השמירה של הדפדפן |

כדי לערוך רק במקלדת: לחצו על {{key:Tab}} עד שערך מסומן, ואז לחצו על {{key:Enter}} כדי להתחיל להקליד.

## שרטוטים דו-ממדיים (DWG ו-DXF)

| מקש או פעולה | מה הוא עושה |
|---|---|
| {{key:F}} | התאמת השרטוט או הגיליון |
| {{key:P}} | תצוגת הדפסה, מופעלת וכבויה |
| לחיצה כפולה | התאמה |
| גרירה בכל לחצן | הזזה |
| גלילת הגלגלת | זום בסמן |
| גלילה בשתי אצבעות או צביטה בלוח מגע | זום בסמן. גלילה בשתי אצבעות לא מזיזה |
| אצבע אחת (מגע) | הזזה. זום בצביטה עוד לא נבנה לשרטוטים |

## שרטוטים בתלת-ממד

| מקש או פעולה | מה הוא עושה |
|---|---|
| {{key:3}} | תלת-ממד, מופעל וכבוי (גם בתצוגה הדו-ממדית) |
| {{key:F}} | גבולות: כל השרטוט |
| גרירה בלחצן האמצעי או השמאלי | סיבוב |
| גרירה בלחצן הימני, או {{key:Shift}} וגרירה | הזזה |
| גלילת הגלגלת | זום לעבר מה שנמצא מתחת לסמן |
| גלילה בשתי אצבעות בלוח מגע | סיבוב; עם {{key:Shift}}, הזזה |
| צביטה בלוח מגע | זום |
| אצבע אחת (מגע) | סיבוב |
| שתי אצבעות (מגע) | צביטה לזום, הזזה יחד להזזה |

{{key:F}}, {{key:P}} ו-{{key:3}} אינם פועלים כשמקלידים בשדה, כשטבלת הציוד מוצגת, או כשמחזיקים {{key:Mod}} או {{key:Alt}}.
