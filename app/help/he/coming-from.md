אם אתם מכירים את Revit, רוב BimCraft ירגיש מוכר במילים ולא מוכר בהיקף. ההבדל החשוב ביותר: **הגרסה הנוכחית קוראת ובודקת מודלים ועורכת נתוני IFC. היא עדיין לא יוצרת מודלים כמו Revit.** אי אפשר לשרטט קירות, להציב משפחות, ליצור תצוגות או גיליונות, או לשמור קובץ פרויקט. מה שאפשר לעשות: לפתוח כמעט כל קובץ בניין בכל מחשב עם דפדפן, לראות מה יש בו, לבדוק תיקיית פרויקט שלמה, ולתקן את הנתונים במודל IFC.

## הרגלים וההתאמה שלהם

| אם אתם רגילים ל | ב-BimCraft |
|---|---|
| פתיחת `.rvt` ב-Revit כדי לראות את המודל | הכרטיס של `.rvt` ב-BimCraft מציג גרסה, מידע על הפרויקט, קישורים ותצוגה מקדימה. למודל התלת-ממדי, ייצאו IFC ופתחו אותו. [קריאת קובץ פרויקט או משפחה](topic:read-rvt-file) |
| בדיקת הגרסה שבה נשמר הקובץ לפני פתיחתו | הכרטיס מציין "נשמר ב-Revit …" בראשו, בלי לשדרג או לגעת בקובץ |
| דפדפן הפרויקט | אין דפדפן של תצוגות וגיליונות. למודל IFC יש את הרשימות {{ui:Storeys}} ו-{{ui:Elements}}; לשרטוט יש לשוניות גיליון |
| לוח המאפיינים | החלונית {{ui:Properties}} מימין, לאלמנט שלחצתם עליו. קבוצות מאפייני IFC במקום קבוצות פרמטרים |
| פרמטרים של מופע ושל סוג | קבוצות מאפייני מופע, וקבוצות שמסומנות "(type)". שינוי סוג חל על כל אלמנט מאותו סוג, כמו ב-Revit. [שינוי מאפיין סוג לכל אלמנטים מאותו סוג](topic:type-vs-instance) |
| Edit Type | אין תיבת דו-שיח: לחצו על ערך בקבוצה "(type)" והקלידו |
| בחירת אלמנטים רבים, מסננים, Select All Instances | אלמנט אחד בכל פעם. טרם נבנה |
| קובית התצוגה וגלגל הניווט | קובייה לתצוגה בפינה הימנית התחתונה, ארבעה כפתורים ({{ui:Fit}}, {{ui:Top}}, {{ui:Front}}, {{ui:Side}}) וסיבוב חופשי. אין גלגל ניווט |
| Shift וגרירה בכפתור האמצעי כדי לסובב, גרירה בכפתור האמצעי כדי להזיז | גרירה בכפתור השמאלי מסובבת, גרירה בכפתור הימני (או {{key:Shift}} וגרירה) מזיזה, והגלגלת מגדילה. סגנון התפריט {{ui:BIM ribbon}} מעביר להזזה בגרירה בכפתור האמצעי ולסיבוב עם {{key:Shift}} ועם הכפתור האמצעי. [תפריטים, מקשים ועכבר](topic:menus-keys-and-mouse) |
| תוכניות קומה, חתכים, תיבות חתך | מישור {{ui:Section}} אחד בכל פעם ({{key:X}}); אין תיבת חתך ואין תוכניות דו-ממדיות. [חיתוך מודל IFC במישור חתך](topic:section-plane) |
| הסתרה בתצוגה, בידוד, נראות וגרפיקה | הדלקה וכיבוי של {{ui:Storeys}}, {{ui:Spaces}} ו-{{ui:Edges}}. אין עדיין הסתרה לפי אלמנט |
| חדרים | חללי IFC, מוסתרים בהתחלה. לחצו על {{ui:Spaces}} |
| שמירה, שמירה בשם, סנכרון עם המרכזי | {{ui:Save as IFC}} מוריד קובץ IFC חדש. המקור לא משתנה לעולם. אין מרכזי ואין שיתוף עבודה |
| ביטול עם {{key:Mod+Z}} | פועל על עריכות IFC עד השמירה. [שינוי מאפייני IFC ושמירת עותק ערוך](topic:edit-ifc-properties) |
| Manage Links | פתחו את תיקיית הפרויקט: כל קישור נבדק ומסומן **בתיקייה זו**, **נמצא שם זהה**, **קובץ ספרייה** או **לא בתיקייה זו**. [פתיחת תיקיית פרויקט שלמה](topic:open-project-folder) |
| ביקורת, או פתיחת קובץ כדי לראות אם הוא פגום | דוח התיקייה בודק כל עותק וגיבוי אם נקטע, תוך שניות. [בדיקת תיקייה לעותקים פגומים](topic:check-folder-health) |
| בחירת הקובץ הנכון מתיקייה עמוסה | התיבה {{ui:Start here}} מציעה קובץ אחד, עם הנימוקים |

אם אתם פותחים מודלים בעיקר כדי לבדוק אותם, כמו בתוכנה לבדיקת מודלים או לצפייה ב-IFC, בחרו בסגנון התפריט {{ui:Viewer}}: כלי הצפייה והבדיקה באים ראשונים, וכלי הבנייה ממתינים בתפריט אחד. ראו [תפריטים, מקשים ועכבר](topic:menus-keys-and-mouse).

## ממעבר על קבצי DWG

אם אתם פותחים DWG ב-AutoCAD או בצופה DWG:

| אם אתם רגילים ל | ב-BimCraft |
|---|---|
| לשוניות מודל ופריסה בתחתית | לשוניות מעל השרטוט: {{ui:Model}} ולשונית לכל גיליון |
| ZOOM Extents, לחיצה כפולה על הגלגלת | לחיצה כפולה, {{key:F}} או {{ui:Fit}} |
| הזזה בכפתור האמצעי | גרירה בכל כפתור |
| מנהל השכבות | הרשימה {{ui:Layers}}: סמנו כדי להציג, בטלו הסימון כדי להסתיר, {{ui:All on}} ו-{{ui:All off}} |
| מנהל ה-xref | **שרטוטים מקושרים** מימין, עם **מוצג** או **לא נמצא**, ו-{{ui:Add linked drawings…}} |
| תצוגה מקדימה להדפסה | {{ui:Print view}} או {{key:P}}: שחור על לבן עם עובי קווים. אין הדפסה |
| חילוץ נתונים של מאפייני בלוק | הכרטיסייה {{ui:Equipment}} לשרטוטי מטבח מתויגים, עם {{ui:Download CSV}} |
| מדידה, ציור, עריכה, שמירה בשם | לא ב-BimCraft. אפליקציית השרטוט של CadCraft מציירת ועורכת |

## ההבדלים שמפתיעים

- **הוא פועל בדפדפן, והדפדפן זהיר עם הקבצים שלכם.** BimCraft יכול לקרוא רק קבצים ותיקיות שאתם מוסרים לו, בבחירה או בגרירה. הוא לא פותח קובץ בעצמו, ולא יכול לשמור עליו. כל שמירה היא הורדה.
- **שום דבר לא עולה לרשת.** המילה "העלאה" בתיבות תיקייה של חלק מהדפדפנים היא הניסוח של הדפדפן עצמו. הקבצים נשארים במחשב שלכם.
- **IFC הוא פורמט המודל.** קובץ פרויקט נפתח ככרטיס, כי התוכן התלת-ממדי שלו לא מתועד. התייחסו ל-IFC כדרך שבה מודלים נכנסים ל-BimCraft.
- **עריכות הן העתק-בעת-כתיבה.** שינוי ערך של אלמנט אחד לא משנה את שכניו, גם כשהמייצא שיתף את הערך ביניהם. מאפייני סוג הם החריג המכוון.
- **בלי פרויקט, בלי תצוגות.** BimCraft מציג קובץ אחד בכל פעם, ולא זוכר עליו דבר אחרי שסגרתם את הלשונית, חוץ משמות התיקיות האחרונות ב-Chrome וב-Edge.
- **מקשי Mac.** במקום שבו קיצורי Revit ב-Windows משתמשים ב-Ctrl, קיצורי BimCraft משתמשים ב-{{key:Mod}}: Command ב-Mac.
- **הרגלי העכבר שלכם.** סיבוב הוא בכפתור השמאלי, ולא ב-Shift ובכפתור האמצעי, אלא אם בחרתם בסגנון התפריט {{ui:BIM ribbon}} או הגדרתם את הכפתורים בעצמכם ב-[תפריטים, מקשים ועכבר](topic:menus-keys-and-mouse).

ראו [מה טרם נבנה](topic:not-built-yet) למה להשתמש במקום זאת היום.
