BimCraft funciona con los dedos tanto como con el ratón. La primera vez que toque la pantalla, los botones, las pestañas y las filas de las listas crecerán al tamaño de un dedo.

## El modelo 3D

| Para | Haga esto |
|---|---|
| Orbitar | Arrastre un dedo |
| Hacer zoom | Pellizque con dos dedos, separándolos o juntándolos |
| Encuadrar | Arrastre con dos dedos juntos |
| Seleccionar un elemento | Toque el elemento |
| Agregar un elemento a la selección, o quitarlo | Mantenga presionado sobre él medio segundo (igual que hacer clic con {{key:Ctrl}}) |
| No seleccionar nada | Toque un espacio vacío |

Un pellizco o un arrastre con dos dedos nunca selecciona nada, aunque un dedo se levante sobre un elemento.

## Dibujos (DWG y DXF)

| Para | Haga esto |
|---|---|
| Encuadrar | Arrastre un dedo |
| Hacer zoom | Pellizque; el punto entre sus dedos se queda fijo |
| Mostrar toda la hoja | Toque dos veces, o toque {{ui:Encuadrar}} |

En la vista {{ui:3D}} de un dibujo se aplican los gestos del modelo: un dedo orbita, dos pellizcan y encuadran, un toque selecciona y una pulsación larga agrega a la selección.

## Recorrido

Toque {{ui:Recorrido}} y luego toque el piso donde quiere pararse. Aparece una fila de botones de flecha en la barra de recorrido:

- Mantenga presionada una flecha para avanzar, retroceder o desplazarse hacia un costado.
- Con {{ui:Gravedad}} desactivada, las flechas dobles suben y bajan.
- Arrastre un dedo sobre el modelo para mirar alrededor.
- Toque {{ui:Listo}} para detener el recorrido.

## Colocar elementos de biblioteca

Toque el lugar donde irá el elemento. {{ui:Girar 90°}} en la barra de colocación lo gira (la tecla {{key:R}} en un teclado), {{ui:Ajuste a muro}} ajusta su parte posterior al muro más cercano, y {{ui:Dejar de colocar}} termina la acción.

## Medir

Toque el primer punto y luego el segundo. Los puntos se ajustan a las esquinas y aristas cercanas a su toque.

:::tip
Con un teclado conectado a una tableta, todos los atajos funcionan como en una computadora. Vea [Atajos de teclado](topic:keyboard).
:::
