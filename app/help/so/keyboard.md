BimCraft waxa uu leeyahay gaadho-furayaal yar. Shaqada badan waxaa lagu sameeyaa mouse-ka iyo panels-ka. Gaadho-furayaasha lagu qoro {{key:Mod}} waxay isticmaalaan Command ee Mac iyo Ctrl meelaha kale. Eeg [Furayaasha, mice-ka iyo trackpads-ka](common:keys) si aad u aragto sida furayaasha loogu qoro caawintan.

## Meel kasta

| Fur | Waxa uu sameeyo |
|---|---|
| {{key:Ctrl+Shift+F}} | Wareeji qaababka shaashadda: caadi, shaashad buuxa, shaashad buuxa oo bararka qarsan. Ctrl wuxuu ku shaqeeyaa nidaamyada oo dhan, oo ay ku jiraan Mac |
| {{key:Esc}} | Ka bax shaashad buuxa |
| {{key:Mod+,}} | Fur {{ui:Settings}}. Eeg [Dejinta BimCraft](topic:settings) |
| {{key:Tab}} | U dhaqaaq badhamada, sanduuqyada hubinta iyo qiyamka. Kontoroolka oo dhan waxaa laga gaari karaa kiiboodhka |

## Aragtida 3D (moodeelada IFC)

| Fur ama ficil | Waxa uu sameeyo |
|---|---|
| {{key:F}} | Ku habee moodeelka oo dhan, aragta saddex meelood meel (isku mid sida {{ui:Fit}}) |
| {{key:Esc}} | Nadiifi dooridda, ama jooji dhigista ama dhajinta |
| Guji | Dooro walxa hoosteeda mouse-ku yaal; guji dhabarka madhan si aad u nadiifiso |
| {{key:Mod}}+guji ama {{key:Shift}}+guji | Ku dar walax dooridda, ama ka saar |
| {{key:H}} | Qari walxaha la doortay. Eeg [Qari, kala saar oo ilaali walxaha](topic:hide-and-isolate) |
| {{key:I}} | Muuji walxaha la doortay oo keliya (kala saar) |
| {{key:T}} | Muuji walxaha la doortay, wax kale oo dhan ilaa ay ilaali karaan |
| {{key:Shift+H}} | Mar kale muuji walax kasta |
| {{ui:Walk}} | Kadibna {{key:W}} {{key:A}} {{key:S}} {{key:D}} ama fallaadhaha ayaa socdaa, {{key:Shift}} wuu orodaa, jiidista ayaa eegaysa, {{key:Esc}} wuu joojiyaa. Eeg [Soco moodeel](topic:walk) |
| {{key:M}} | Cabbir masaafooyin iyo aagga wejiyada. Eeg [Cabbir masaafooyin, aagga wejiyada iyo goobaha 3D](topic:measure) |
| Jiid batoonka bidix | Wareegid |
| Jiid batoonka midig | Guuri |
| {{key:Shift}} ama {{key:Mod}} oo jiid batoonka bidix | Guuri (waa fiican trackpad-ka) |
| Ku dhaqaaji tuubada wheel-ka, ama jiid batoonka dhexe | Weynee |
| Scroll laba farood ama pinch trackpad-ka | Weynee |
| Hal farood (taabasho) | Wareegid; taabasho wuu dooraa |
| Laba farood (taabasho) | Pinch si aad u weyneyso, wada dhaqaaq si aad u guurto |

| {{key:X}} | Diyaarada goynta oo furan iyo xidhan. Eeg [Goy moodeelka IFC diyaarad goyn](topic:section-plane) |
| {{key:Shift+X}} | Sanduuqa goynta ee walxaha la doortay, oo qolka lagu dejiyay Dejinta |

Ma jiraan furayaal {{ui:Top}}, {{ui:Front}} iyo {{ui:Side}}; isticmaal badhamada.

## Tafatir

Isla amarradaas waxaa lagu helaa toolbar-ka: {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}} iyo menu-ga {{ui:More}}, kaas oo muujinaya fur kasta. Waxay ku shaqeeyaan aragta 3D ee moodeelka IFC, ee ma aha markaad qoraal ku qorayso goob. Eeg [Koobiyee, dhaji iyo nuqul walxaha maktabadda](topic:copy-paste).

| Fur | Waxa uu sameeyo |
|---|---|
| {{key:Mod+Z}} | Ka noqo isbedelkii ugu dambeeyay |
| {{key:Mod+Y}} ama {{key:Mod+Shift+Z}} | Samee mar kale waxa Ka noqo ka qaaday |
| {{key:Mod+C}} | Koobiyee walxaha la doortay (magacyadooda iyo hantidooda sidoo kale waxay u gudbaan clipboard-ka qoraal ahaan) |
| {{key:Mod+X}} | Gooy walxaha la doortay: koobiyee, kadibna tirtir |
| {{key:Mod+V}} | Dhaji waxa aad koobiyeeday: wuu raacaa mouse-ka, guji meesha uu tago |
| {{key:Mod+Shift+V}} | Dhaji meeshiisii: meesha ay goynta ka timid, ama dhinaca asalka kadib koobiyeynta |
| {{key:Mod+D}} | Nuqul: koobiyee walxaha la doortay oo bilow dhajinta |
| {{key:Delete}} | Tirtir walxaha la doortay, qaybahooda iyo furitaankooda. Eeg [Tirtir, goo, koobiyee iyo dhaji walxaha dhismaha](topic:edit-elements) |
| {{key:Mod+A}} | Dooro walax kasta oo la muujiyay |
| {{key:Esc}} | Ma dooro midna |

Marka qoraal bogga lagu doortay, {{key:Mod+C}} wuxuu koobiyeeyaa qoraalkaas sida caadiga ah.

## Aragta qorshaha (Sawir)

Kuwan waxay shaqeeyaan intii {{ui:Draw}} uu furan yahay oo aanad qoraal ku qorin goob. Eeg [Sawir darbiyada](topic:draw-walls) iyo [Albaabbada iyo daaqadaha](topic:doors-and-windows).

| Fur ama ficil | Waxa uu sameeyo |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | Marka {{ui:Door}} ama {{ui:Window}} uu furan yahay: loo-ka dhig dhamaadka kale |
| {{key:Shift}} marka darbi la sawirayo | Ku hay 0°, 90°, 180° ama 270° |
| Lambarrada iyo calaamadaha lugta iyo inchiga (`'` iyo `"`) | Bilow qorista dherer sanduuqa {{ui:Length}}; {{key:Enter}} ayaa isticmaala |
| {{key:Enter}}, {{key:Esc}}, guji midig ama laba jeer guji | Dhamee darbiga aad sawirayso; {{key:Esc}} mar kale wuxuu dib ugu noqdaa {{ui:Select}} |
| {{key:Delete}} | Tirtir darbiyada, albaabbada iyo daaqadaha la doortay; darbiyada hadhay mar kale way isku xidhmaan |
| {{key:F}} marka mouse-ku qorshaha ku jiro | Ku habee qorshaha |
| Ku dhaqaaji tuubada wheel-ka | Weynee, oo wareeg mouse-ka |
| Jiid batoonka dhexe ama midig, ama {{key:Space}} oo jiid | Guuri; marka {{ui:Select}} uu furan yahay, jiid fudud ayaa sidoo kale guuraa |
| Jiid albaab ama daaqad oo {{ui:Select}} furan | U guuri darbigeeda, ama u kaxee darbi kale |
| Laba farood (taabasho) | Pinch si aad u weyneyso, wada dhaqaaq si aad u guurto |

## Dhigida iyo dhajinta walxaha maktabadda

| Fur | Waxa uu sameeyo |
|---|---|
| {{key:R}} | Walxa 90° u leexi |
| {{key:Tab}} | Ku tiirsii darbiga on iyo off: dhabarka walxa wuxuu u soo wada darbiga ugu dhow |
| {{key:Enter}} ku jira **X, Y (mm)** | Ku dhig meesha la qoray |
| {{key:Esc}} | Jooji dhigista ama dhajinta |

## Tafatirka qiyamka IFC

| Fur | Waxa uu sameeyo |
|---|---|
| {{key:Enter}} | Hay qiimaha aad qortay |
| {{key:Esc}} | Jooji oo soo celi qiimihii hore |
| Guji meel kale | Hay qiimaha aad qortay |
| {{key:Mod+Z}} | Ka noqo isbedelkii ugu dambeeyay. Keliya inta aad isbedel aan la kaydin ku leedahay, oo aadan qoraal ku qorin goob |
| {{key:Mod+Y}} | Samee mar kale waxa Ka noqo ka qaaday |
| {{key:Mod+S}} | Kaydi sida IFC. Keliya inta aad isbedel aan la kaydin ku leedahay; haddii kale kaydinta browser-ka ayaa furmaysa |

Si aad ugu tafatirto kiiboodhka keliya: taabo {{key:Tab}} ilaa qiime la iftiimiyo, kadibna taabo {{key:Enter}} si aad u bilowdo qorista.

## Sawirada 2D (DWG iyo DXF)

| Fur ama ficil | Waxa uu sameeyo |
|---|---|
| {{key:F}} | Ku habee sawirka ama xaashida |
| {{key:P}} | Aragta daabacaadda on iyo off |
| Laba jeer guji | Ku habee |
| Jiid batoon kasta | Guuri |
| Scroll-ka tuubada wheel-ka | Weynee mouse-ka ku jira |
| Scroll laba farood ama pinch trackpad-ka | Weynee mouse-ka ku jira. Scroll laba farood ma guurto |
| Hal farood (taabasho) | Guuri. Pinch weynee sawirada weli lama dhisin |

## Sawirada 3D

| Fur ama ficil | Waxa uu sameeyo |
|---|---|
| {{key:3}} | 3D on iyo off (sidoo kale aragta 2D) |
| {{key:F}} | Xadka: sawirka oo dhan |
| Jiid batoonka dhexe ama bidix | Wareegid |
| Jiid batoonka midig, ama {{key:Shift}} oo jiid | Guuri |
| Ku dhaqaaji tuubada wheel-ka | Weynee ilaa wax kasta oo mouse-ku hoosteeda yaal |
| Laba farood oo trackpad-ka ku dhaqaaji | Wareegid; {{key:Shift}} oo leh, guuri |
| Pinch trackpad-ka | Weynee |
| Hal farood (taabasho) | Wareegid |
| Laba farood (taabasho) | Pinch si aad u weyneyso, wada dhaqaaq si aad u guurto |

{{key:F}}, {{key:P}} iyo {{key:3}} waxba ma sameeyaan markaad qoraal ku qorayso sanduuq, marka jadwalka qalabka muuqdo, ama marka aad hayso {{key:Mod}} ama {{key:Alt}}.
