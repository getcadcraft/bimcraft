BimCraft maanta waa akhriye, hubiye iyo tafatire xog IFC ah, oo bilaabay inuu sawiro dhismayaasha: darbiyada, albaabyada iyo daaqadaha, qolalka, sagxadaha, saqaf hoosaha iyo saqafyada (eeg [Darbiyada sawir](topic:draw-walls), [Albaabyada iyo daaqadaha](topic:doors-and-windows) iyo [Qolalka, sagxadaha, saqafyada](topic:floors-and-roofs)). Kani waa liiska run ee waxa aanu weli samayn, iyo waxa halkiisa lagu sameeyo.
