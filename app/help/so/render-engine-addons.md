Kordhin (Dejinta › Kordhinada) wuxuu ku dari karaa injin liiska Injinka ee {{ui:Render}}. Qoraalka oo dhan ee loogu talagalay qorayaasha kordhinada waa qaybta 16 ee qeexidda kordhinka; si kooban:

- Kordhinku wuxuu diiwaangeliyaa injin leh id uu ku bilaabmo sidiisa, magac, dejin ikhtiyaari ah, iyo **mid kamid ah** barnaamij la socodsiiyo **ama** function JavaScript ah oo sawirka sameeya.
- Injin barnaamij socodsiiya wuxuu u baahan yahay ogolaanshaha **`engine.run`**, kaas oo la tusayo ka hor rakibista iyo ku dhex jirta Dejinta. Wuxuu ku shaqeeyaa Studio kaliya; browser-ka wuxuu u muuqdaa sida fayl la kaydiyo.
- Kordhinku wuxuu magacaabaa barnaamijka (magac fayl oo fudud oo keliya: ma aha shell), script ku jira **kordhinka saxiixa leh**, iyo arguments oo ka kooban meel-hayeyaal iyo erayo fudud. Studio wuxuu helaa barnaamijka ama wuxuu kaa weydiinayaa inaad hal mar tilmaamto.
- Markii ugu horreysay ee kordhin barnaamij socodsiiyo, **Studio wuxuu kaa weydiinayaa dialog gaar ah**: magaca kordhinka, magaca barnaamijka, iyo in script-ku uu samayn karo wax kasta oo barnaamijku samayn karo. Ogolow kaliya kordhin aad isku kalsoonahay. Jawaabtaadu waa la xasuustaa kordhinkaas iyo barnaamijkaas.
- Xirmada (muuqaalka sidii USD iyo fayl dejin, iyo fayl glTF marka kordhinku weydiyo) iyo script-ka kordhinku waxay galaan folder cusub oo ku meel gaar ah. Barnaamijku wuxuu ku socdaa halkaas, sawirkuna wuxuu soo noqdaa isagoo calaamad ku leh magaca injinka kordhinka.

:::note
Kordhinku wuxuu ku dari karaa injinada rendar oo keliya API kordhinka 1.4 ka bilaabmaya. Tusaale shaqeynaya oo ku saabsan injin amarka-socda oo furan ayaa ku jira kaydkiisa gaarka ah; weli lama isticmaalin injinkaas.
:::
