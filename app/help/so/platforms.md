BimCraft wuxuu ku shaqeeyaa nooca hadda jira ee Chrome, Edge, Firefox iyo Safari, Mac, Windows iyo Linux. Muuqaalka 3D wuxuu u baahan yahay WebGL, oo browser kasta oo hadda jira leh. Eeg [Browser-yada iyo kombuyuutarrada](common:browsers) waxa apps-ka u baahan yahay guud ahaan.

## Furidda folder-ka

| Browser | {{ui:Fur gal}} wuxuu sameeyaa | Jiidida folder-ka | {{ui:Galalka dhawaan la furay}} |
|---|---|---|---|
| Chrome, Edge | Dooraha folder-ka ee browser-ka, kadibna "Let site view files?": guji **View files** | Wuxuu furmaa iyada oo aan wax la weydiin | Haa, folder-yada la doortay ama la jiiday |
| Firefox | Dooraha folder-ka ee nidaamka | Wuxuu furmaa iyada oo aan wax la weydiin | Maya |
| Safari | Dooraha folder-ka ee nidaamka, oo leh badhanka **Upload** (wax lama soo rarayo) | Wuxuu furmaa iyada oo aan wax la weydiin | Maya |

Dabadiisa: Chrome iyo Edge waxay isticmaalaan File System Access picker-ka waxayna xusuusan karaan folder-ka. Firefox iyo Safari waxay isticmaalaan dooraha folder-ka hore, kaas oo siiya faylal kasta hal mar, mana xusuusan karo. Folder la jiiday wuxuu akhriyaa entry kasta mid mid browser kasta.

:::chromium
Brave iyo browser-yada Chromium kale qaar ayaa damiya dooraha folder-ka. BimCraft markaas wuxuu isticmaalaa dooraha folder-ka nidaamka, browser-kuna wuxuu ku weydiin karaa "Upload *n* files to this site?". Wax lama soo rarayo; faylalka waxay u gaaraan bogga keliya. Folder-ka jiidida waxay ka fogaysaa su'aasha.
:::

## Mac, Windows iyo Linux

- Gaadhooyinka {{key:Mod+S}} iyo {{key:Mod+Z}} waa Command Mac-ka, Ctrl Windows iyo Linux-ka.
- {{key:Ctrl+Shift+F}} (habka shaashadda) waa Control dhammaan nidaamyada, oo ay ku jiraan Mac.
- Wada-hadalada faylka iyo folder-ka download-ka waa kuwa nidaamkaaga.

## Mouse, trackpad iyo touch

| Gelinta | Aragtida 3D | Rasmeynta 2D |
|---|---|---|
| Mouse | Jiidida bidix waa wareeg, jiidida midig waa dhex-u-dhaq, tuubada waa zoom, riix waa dooro | Jiid kasta waa dhex-u-dhaq, tuubada waa zoom, laba jeer riix waa ku habee |
| Trackpad | Riix-jiid waa wareeg; {{key:Shift}} ama {{key:Mod}} iyo jiid waa dhex-u-dhaq; dhex-u-dhaq laba farood ama pinch waa zoom | Riix-jiid waa dhex-u-dhaq; dhex-u-dhaq laba farood ama pinch waa zoom |
| Touch | Hal farood waa wareeg, laba farood waa pinch iyo dhex-u-dhaq, tap waa dooro | Hal farood waa dhex-u-dhaq; weli pinch zoom ma jiro; tap {{ui:Ku habee}} |

Trackpad-ka Mac-ka, midig-riix waa laba farood-riix (ama Control-riix). Eeg [Furayaasha, mouse-ka iyo trackpad-ka](common:keys).

Taabletyada iyo telefoonadu waxay furi karaan faylal keli ah oo eegi karaan, laakiin shaashaddu way yar tahay, browser-yo badan oo mobile ah ma dooran karaan folder-yo, moodeelada waaweyn xusuustooda ma ku filan karaan. Kombuyuutarku ayuu ugu fiican yahay.

## Faylalka waaweyn iyo xusuusta

Wax kasta oo BimCraft akhriyo waxay ku nool yihiin xusuusta tab-ka browser-ka. Inta uu tab-ku qaadi karo waxay ku xidhan tahay browser-ka iyo kombuyuutarkaaga, intaas ka badan BimCraft.

| Faylka | Inta la akhriyo | Waxa la filan karo |
|---|---|---|
| IFC | Faylka oo dhan, iyo geometry 3D ee laga dhisay | Inta ay weyn tahay waxay ku xidhan tahay kombuyuutarkaaga iyo browser-ka; moodeel dhowr boqol megabytes ah ayaa laga yaabaa inuu ka badan yahay laptop. Ka badan 1.5 milyan triangle, edges waa la damiyaa |
| Faylalka mashruuca iyo qoyska | Qiyaastii 40 KB ilaa 100 KB, iyadoon loo eegin cabbirka | Moodeelada dhexe ee waaweyn mar ayay furmaan, xitaa network drive-ka |
| DWG iyo DXF | Faylka oo dhan | Sawirada aad u waaweyn waxay muujiyaan "This drawing is very large; only part of it is shown." (Sawirkan aad buu u weyn yahay; qayb keliya ayaa la muujinayaa.) |
| Folders | Liiska faylalka, iyo dhowr kilobyte moodel kasta | Ilaa 20,000 fayl |

Haddii tab-ku xusuusta ka dhammaado, browser-ku wuxuu muujiyaa bogga khaladkiisa ("Aw, Snap!" Chrome-ka, tusaale ahaan). Xir tabaha kale, dib u bilow BimCraft oo isku day mar kale, ama isticmaal kombuyuutar xusuus badan.
