## Хуулбарын статус

Загварын бүх хуулбар — үндсэн файл ба дугаарласан нөөцүүд адилхан — толгойн шалгалт авна.

| Шошго | Утга |
|---|---|
| **Бүрэн** | Файлын толгой ба индекс нь файлын дотор багтана |
| **Дутуу** | Файл түүний өөрийн индексээс богино: хуулах, илгээх эсвэл синк хийх явцад таслагдсан, эсвэл «зөвхөн онлайн» гэсэн үүлэн файл |
| **Уншигдахгүй** | Файл хүчинтэй compound файл биш, эсвэл уншиж чадсангүй |

**Статус** багананд загвар **Бүрэн** гэж харагдана; хэрэв хуулбарын нэг нь муу боловч нөгөө нь сайн бол шар «*n* дутуу», сайн хуулбар огт байхгүй бол улаан **Дутуу** гэж харагдана.

## Нөөц хуулбарууд

`Name.0001.rvt`, `Name.0002.rvt` гэх мэт файлууд нь `Name.rvt`-ийн дугаарласан нөөцүүд юм. Тэдгээрийг загвараар нь бүлэглэж, хамгийн шинэ нь эхэндээ байхаар **All … copies**-д байрлуулна. Карт нь үндсэн файл бүрэн бол түүнээс, эс бөгөөс хамгийн сүүлийн бүрэн нөөцөөс («newest complete») уншигдана.

## Үүрэг

Загварын нэрний доор *налуу* үсгээр харагдана.

| Үүрэг | Утга |
|---|---|
| *Өөр загвараар* холбогдсон: фон | Хавтасны өөр загвар үүнийг холбосон тул магадгүй өөр хүний фон загвар, жишээ нь зөвлөхийн загвар |
| Эхлэх эсвэл нэргүй файл | Blank, Template, Default, Untitled эсвэл Project1 гэх мэт нэр: эхлэх цэг, эсвэл зөв нэр өгөгдөөгүй файл |
| Төв загвар | Хамтран ажилладаг төв загвар. Ажил орон нутгийн хуулбарт хийгдэнэ, энд биш |
| Гэр бүл (эд анги) | `.rfa` эсвэл `.rft` файл: бүрэлдэхүүн хэсэг, төсөл биш |
| Зөвхөн нөөцүүд | Үндсэн файл алга, зөвхөн дугаарласан нөөцүүд үлдсэн |

## Энд эхэл-г хэрхэн сонгох вэ

BimCraft туршлагатай хэрэглэгчийн ухаалаг бодлыг хэрэглэнэ:

1. Нэр дэвшигчид нь өөр загварт холбогдоогүй, эхлэл биш, уншигдах төслийн файлууд (`.rvt`, `.rte`).
2. Төв загварууд болон зөвхөн нөөц загварууд нь илүү сайн зүйл байхгүй үед л тооцогдоно.
3. Нэр дэвшигчдийн хамгийн сүүлд хадгалагдсан нь ялна.

Жагсаалт нь шалтгаанаа жагсаана, мөн үнэмлэхүй сонголт мэт харагдах файл гэмтсэн, бусад загварууд фон, эсвэл сонголт нь төв загвар бол анхааруулна. Энэ нь хамгийн сайн таамаг; төслийг хамгийн сүүлд засварласан хүнтэйгээ шалгана уу.

## Холбоосын статус

| Шошго | Утга |
|---|---|
| **Энэ хавтаст** | Хадгалсан харьцангуй замаар, эсвэл хавтасны дотор хадгалсан бүтэн замын төгсгөлд олдсон |
| **Ижил нэртэй олдсон** | Замдаа байхгүй, гэхдээ хавтаст ижил нэртэй файл байна. Зөв эсэхийг шалгана уу |
| **Номын сангийн файл** | Түлхүүр үгийн эсвэл угсралтын кодын хүснэгт. Эдгээр нь компьютер бүрт программтай хамт ирдэг |
| **Энэ хавтаст байхгүй** | Хавтаснаас хаана ч олдсонгүй |

**Олдсон холбоосууд** багана **Загварууд** дотор загварын холбоосуудын хэд нь олдсоныг, хавтаст хүлээгдсэн холбоосуудаас тооцож харуулна (номын сангийн файлууд тоологдохгүй).

## Тусгаарласан

| Мөр | Утга |
|---|---|
| Revit-ийн засвар үйлчилгээний хавтаснууд (уншигдахгүй) | `*_backup`, `*_log` ба `Revit_temp` хавтаснууд, мөн нуугдсан хавтаснууд ба `__MACOSX` |
| Түгжээ, лог ба нөөцийн үлдэгдэл | `.dwl`, `.dwl2`, `.bak`, `.err`, `.log`, `.tmp`, `.sv$`, `.ac$`, `.lck` ба `.slog` файлууд |
| Бусад файлууд | Бусад бүгд (эхний 40-ийг нэрээр нь өгнө) |
