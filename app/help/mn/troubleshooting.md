Мессежүүд дэлгэцийн доод талд, статус мөрөнд гарна; юм бүтэлгүйтэх үед улаанаар гарна. Доорх мессежээ олно уу.

## Файл нээх

**"*name* is not an IFC, RVT, RFA, DWG or DXF file."**
**"*name* IFC, RVT, RFA, DWG эсвэл DXF файл биш байна."**
BimCraft файлыг таньсангүй. Өргөтгөлийг нь болон файл хоосон биш эсэхийг шалгана уу. PDF, зураг, оффисын файлууд нээгдэхгүй.

**".ifczip is not supported yet. Save or export the model as a plain .ifc file."** (мөн `.ifcxml`-д)
**".ifczip одоохондоо дэмжигдэхгүй байна. Загварыг энгийн .ifc файлаар хадгалах эсвэл экспортлоно уу."** (мөн `.ifcxml`-д)
`.ifczip`-ийг задлана (энэ нь `.ifc` агуулсан энгийн zip) эсвэл энгийн IFC экспортлоно.

**"… is a project file BimCraft does not read yet."**
**"… BimCraft одоохондоо уншдаггүй төслийн файл байна."**
`.pln`, `.pla`, `.tpl` эсвэл `.bpn` файл. Түүнээс IFC эсвэл DWG экспортлоод тэрийгээ нээнэ үү: харна уу: [`.pln` ба `.pla` төслийн файлыг нээх](topic:pln-project-files).

**"This IFC file could not be read."**
**"Энэ IFC файлыг уншиж чадсангүй."**
IFC файл эвдэрсэн эсвэл жинхэнэ IFC биш байна. Текст засварлагчаар нээгээрэй: жинхэнэ IFC файл `ISO-10303-21;`-ээр эхэлнэ. Дахин экспортлоно уу.

**"This file is incomplete: it is … MB, but its own index points to data at least … MB in. …"**
**"Энэ файл бүрэн бус байна: энэ нь … MB, гэвч түүний өөрийн индекс нь хамгийн багадаа … MB-д өгөгдөл заана. …"**
Төсөл эсвэл гэр бүлийн файлыг хуулах, илгээх эсвэл синк хийх явцад таслагдсан байна. Үүлэн дискний "зөвхөн онлайн" файл ч мөн адилхан харагдана. Ганцаараа нээгдсэн файл нээгдэх боловч картын дээд хэсэгт энэ мессеж, мөн "Олдсон зүйлсийг харуулж байна; бүрэн загварын төлөө эх файлыг дахин хуулна уу." гарна: карт зөвхөн файлд байгаа байт бүрнээ бүрэн байгаа хэсгүүдийг харуулж, үлдсэнийг **Файлд байхгүй** дор жагсаана. Үүлэн дискэндээ файлыг офлайн боломжтой болгож эсвэл эх файлыг дахин хуулж, дахин нээнэ үү. Хавтсанд BimCraft хамгийн шинэ бүрэн нөөц хуулбарыг харуулна.

**"… The file's own list of contents is in the missing part too, so nothing in it can be opened."**
**"… Файлын өөрийн агуулгын жагсаалт ч дутуу хэсэгт байгаа тул түүний аль ч зүйлийг нээх боломжгүй."**
Файл хэт эрт тасарсан тул агуулгын жагсаалт ч байхгүй. Энэ хуулбараас юу ч сэргээх боломжгүй. Эх файлыг дахин хуулж, дахин нээнэ үү.

**"This compound file has no BasicFileInfo stream, so it is not a Revit file."**
**"Энэ нийлмэл файлд BasicFileInfo урсгал байхгүй тул Revit файл биш."**
Файл өөр төрлийн нийлмэл файл байна (хуучин оффисын баримтууд ижил савыг ашигладаг). Зөв файлыг сонгосон эсэхээ шалгана уу.

**"Still working on the last one…"**
**"Сүүлийнхийг нь одоо ч боловсруулж байна…"**
BimCraft өмнөх файл эсвэл хавтсаар завгүй байна. Статус мөр дуусахыг хүлээгээд дахин оролдоно уу.

**The file chooser greys out my file.**
**Файл сонгогч миний файлыг саарал болгож байна.**
Сонгогч зөвхөн `.ifc`, `.rvt`, `.rfa`, `.rte`, `.rft`, `.dwg` ба `.dxf`-ийг санал болгодог. Бусад файлыг хуудас руу чирнэ үү; тэгвэл BimCraft уншиж чадах эсэхээ хэлнэ.

## Хавтас нээх

**"This folder has more than 20,000 files. Pick a smaller folder, such as one project."**
**"Энэ хавтсанд 20,000-аас олон файл байна. Бага хавтас сонгоно уу, жишээлбэл нэг төслийн хавтас."**
Та хэт дээд түвшний хавтас сонгосон, жишээ нь бүхэл диск. Нэг төслийн хавтас сонгоно уу.

**"The browser did not give access to *name*. Choose it again with Open a folder."**
**"Хөтөч *name*-д хандах зөвшөөрөл өгөөгүй. Хавтас нээх-ээр дахин сонгоно уу."**
Та саяхны хавтсан дээр {{ui:Дахин нээх}}-ийг дарсан, гэвч хөтчийн зөвшөөрөл татгалзагдсан эсвэл хугацаа нь дууссан. Хавтсыг дахин сонгох эсвэл чирнэ үү.

**The browser says it will "upload" files.**
**Хөтөч файлуудыг "илгээх" гэж хэлдэг.**
Энэ нь хөтчийн өөрийн үг: файлыг хуудас руу шилжүүлэхийг хэлнэ. BimCraft тэдгээрийг хаашаа ч илгээдэггүй. Асуултаас зайлсхийхийн тулд хавтсыг чирж оруулна уу.

**Nothing happens on a phone or tablet.**
**Утас эсвэл таблет дээр юу ч болохгүй байна.**
Олон мобайл хөтөч хавтас сонгож чаддаггүй. Ганц файл нээнэ үү, эсвэл компьютер ашиглана уу.

## IFC хөдөлгүүр анх удаа ачаалагдана

**The status line stays on "Starting the IFC engine…", or shows an error such as "Failed to fetch".**
**Статус мөр "IFC хөдөлгүүрийг эхлүүлж байна…" дээр үлдэх эсвэл "Failed to fetch" зэрэг алдаа харуулах.**
IFC хөдөлгүүрийг татаж чадсангүй. Та офлайн байж магадгүй, эсвэл галт ханын хамгаалалт эсвэл контент блоклогч түүнийг зогсоож байна.

:::offline
Та офлайн байна. Аппын товчлуур {{ui:Офлайнд бэлэн}} гэж хэлэхгүй байвал IFC хөдөлгүүр энэ хөтөчид хэзээ ч хадгалагдаагүй байна. Интернэтэд холбогдоод файлыг дахин нээгээд, дараа нь {{ui:Офлайнд хадгалах}}-ыг дарвал дараагийн удаа офлайнд ажиллана. Харна уу: [Онлайн ба офлайн](topic:online-offline).
:::

:::online
Хуудсаа дахин ачаалаад дахин оролдоно уу. Ажлын сүлжээнд сайтын `.wasm` файлуудыг зөвшөөрүүлэхийг IT багаасаа хүсээрэй.
:::

## Офлайн хэрэглээнд хадгалах

**The button says {{ui:Could not save}}.**
**Товчлуур {{ui:Хадгалж чадсангүй}} гэж хэлж байна.**
Зарим файл татагдаагүй, ихэвчлэн холбоо тасарснаас. Холболтоо шалгаад товчийг дахин дарна уу. Шинэ хуулбар бүрэн болох хүртэл өмнөх офлайн хуулбар хадгалагдана.

**The button says {{ui:Offline not available}}.**
**Товчлуур {{ui:Офлайн боломжгүй}} гэж хэлж байна.**
Энэ цонх офлайн хуулбар хадгалж чадахгүй, жишээлбэл хувийн цонх эсвэл удирддаг ажлын компьютер. Харна уу: [Офлайнаар ажиллах](common:offline).

**The button stays on "Saving *n* of *m*" for a while.**
**Товчлуур "Хадгалж байна *n* / *m*" дээр удаан үлдэх.**
BimCraft-ийн хуулбар ойролцоогоор 11 MB, ихэнх нь IFC хөдөлгүүр. {{ui:Офлайнд бэлэн}} гэж хэлэх хүртэл табыг нээлттэй байлгана уу.

**BimCraft opened offline but looks out of date.**
**BimCraft офлайнаар нээгдсэн боловч хуучирсан харагдаж байна.**
Таны хадгалсан хуулбар өмнөх зочлолтоос үлдсэн. Интернэтэд холбогдсон үед {{ui:Офлайнд бэлэн}}-г дарж, {{ui:Дахин хадгалах (хамгийн шинэ хувилбарыг авах)}}-ыг сонгоно уу.

## 3D харагдац

**The model is not where I expected, or it is tiny.**
**Загвар хүлээснээрээ биш байрлаж байна, эсвэл маш жижиг байна.**
{{key:F}}-ийг дарна уу эсвэл {{ui:Багтаах}}-ыг дарна. Багтаах нь үргэлж загварын бүх зүйлийг багтаадаг, тэр дундаа тэмдэглээгүй давхрууд болон барилгаас алслагдсан тарсан элементүүдийг, тиймээс барилга жижиг харагдаж болно. Тэндээс томруулна уу.

**Clicking does not pick anything.**
**Дарахад юу ч сонгогдохгүй байна.**
Дарах үедээ хулганыг хөдөлгөөнгүй барина уу: жижиг чирэлт нь эргүүлдэг. Тэмдэглээгүй давхрын элементүүдийг сонгож болохгүй. {{ui:Орон зай}} асаалттай үед гэрэл нэвтрүүлдэг орон зайнууд доторх зүйлсээс өмнө сонгогдоно.

**The {{ui:Edges}} button is greyed out: "Edges are off for very large models".**
**{{ui:Ирмэг}} товчлуур саарал байна: "Маш том загваруудад ирмэг унтарсан".**
Загварт 1.5 сая гурвалжингаас илүү байна. Санах ойг хэмнэхийн тулд ирмэгийг унтраасан.

**The tab turns slow, white, or shows the browser's crash page.**
**Таб удаашрах, цагаан болох эсвэл хөтчийн гацалтын хуудас харуулах.**
Загвар табанд өгөгдсөн санах ойноос хэт том байна. Бусад табуудыг хааж дахин ачаална уу. Жижиг IFC экспортлоно уу: нэг барилга, нэг мэргэжил эсвэл цөөн давхар. Харна уу: [Хөтөч, төхөөрөмж ба санах ой](topic:platforms).

**The 3D view stays blank.**
**3D харагдац хоосон хэвээр байна.**
WebGL унтарсан эсвэл хориглогдсон байж магадгүй. Хөтчийн тохиргоонд техник хангамжийн хурдатгал (эсвэл график хурдатгал)-ыг асааж, хөтчөө дахин эхлүүлнэ үү.

## IFC засах

**"Use a number."**
**"Тоо ашиглана уу."**
Утга тоон. Нэгжгүй энгийн тоо бичнэ үү, жишээ нь `2.4`.

**"Use a whole number."**
**"Бүхэл тоо ашиглана уу."**
Утга тоо эсвэл бүхэл. Аравтын бутархайг хасна уу.

**"Only single-value properties can be edited."**
**"Зөвхөн нэг утгатай шинж чанарыг засах боломжтой."**
Жагсаалт, тооллын утга ба хэмжээг зөвхөн унших боломжтой.

**{{key:Mod+S}} opens the browser's "Save page" window.**
**{{key:Mod+S}} хөтчийн "Хуудсыг хадгалах" цонхыг нээнэ.**
Хадгалаагүй өөрчлөлт байхгүй тул BimCraft товчлолыг хөтөчид үлдээсэн. Цонхыг хаана уу.

**{{key:Mod+Z}} does nothing.**
**{{key:Mod+Z}} юу ч хийхгүй байна.**
Зөвхөн хадгалаагүй өөрчлөлттэй, талбарт бичээгүй үед ажиллана. Хадгалсны дараа буцаах зүйл үлдэхгүй.

**The {{ui:Changes}} list still shows edits after I discarded them and opened a drawing or a folder.**
**Хасаад зураг эсвэл хавтас нээсний дараа {{ui:Өөрчлөлтүүд}} жагсаалт засварыг харуулсаар байна.**
"Хасах уу?" асуултад OK гэж хариулаад IFC загвараас өөр зүйл нээвэл хуучин засварууд санах ойд хадгалагдана, {{ui:IFC-ээр хадгалах}} тэдгээрийг хадгална. Үнэхээр шинээр эхлэхийн тулд анхны IFC-ээ дахин нээх эсвэл хуудсаа дахин ачаална уу.

**My edit changed more elements than I picked.**
**Миний засвар сонгосноосоо илүү элемент өөрчилсөн.**
Та "(type)" гэж тэмдэглэгдсэн багцын шинж чанарыг өөрчилсөн. Төрлийн шинж чанар нь тэр төрлийн бүх элементэд хамаарна. {{ui:Буцаах}}-ыг дарна уу. Харна уу: [Төрлийн шинж чанарыг төрлийн бүх элементэд өөрчлөх](topic:type-vs-instance).

## Зурагууд

**"*name* could not be read. It may be damaged, or saved in a format the reader does not handle yet (…)."**
**"*name* уншиж чадсангүй. Энэ эвдэрсэн, эсвэл уншигч одоохондоо боловсруулдаггүй форматаар хадгалагдсан байж болно (…)."**
Зургийг үүсгэсэн програмаас хуучин DWG (2018 ба түүнээс өмнөх) эсвэл DXF хэлбэрээр хадгалаад дахин оролдоно уу.

**"This drawing has nothing to show."** or **"*name* is an empty drawing: it holds no lines, text or blocks."**
**"Энэ зураг харуулах зүйлгүй байна."** эсвэл **"*name* хоосон зураг байна: тэнд шугам, текст эсвэл блок байхгүй."**
Зураг хоосон, эсвэл BimCraft одоохондоо зурдаггүй зүйлс л агуулна (баруун талын **Одоохондоо зурагдаагүй** хэсгийг харна уу).

**"This drawing is very large; only part of it is shown."**
**"Энэ зураг маш том; зөвхөн хэсгийг нь харуулж байна."**
BimCraft хариу өгөх чадвараа хадгалахын тулд зурахаа зогсоосон. Хэрэггүй давхаргуудыг унтраах, эсвэл хэрэгтэй хуудсуудаа жижиг зургаас нээнэ үү.

**Parts of a sheet are missing.**
**Хуудасны хэсгүүд дутуу байна.**
Холбогдсон зургууд дутуу байж магадгүй: баруун талын **Холбогдсон зургууд** хэсгийг харна уу. Харна уу: [Холбогдсон зураг ба зургуудыг олох](topic:dwg-linked-files). Давхаргууд унтарсан байж магадгүй: {{ui:Бүгдийг асаах}}-ыг дарна уу.

**A picture shows as an empty frame.**
**Зураг хоосон хүрээ болж харагдана.**
Файл нь олдсонгүй, эсвэл TIFF ("TIFF cannot be shown in a browser") байна. {{ui:Зураг нэмэх…}}-ээр PNG эсвэл JPEG хуулбар нэмнэ үү.

**Scrolling on my trackpad zooms instead of moving the drawing.**
**Трекпад дээр гүйлгэхэд зураг шилжихийн оронд томрох.**
BimCraft-д зургууд ийм л ажилладаг. Шилжүүлэхийн тулд дарж чирнэ үү.
