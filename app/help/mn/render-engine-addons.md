Нэмэлт (Тохиргоо › Нэмэлтүүд) нь {{ui:Рендер}}-ийн Хөдөлгүүр жагсаалтад хөдөлгүүр нэмж чадна. Нэмэлт зохиогчдод зориулсан бүрэн текст нь нэмэлтийн тодорхойлолтын 16-р хэсэгт байна; товчхондоо:

- Нэмэлт өөрийнхөө нэрээр эхэлсэн id, нэр, заавал биш тохиргоо, мөн **аль нэг нь**: ажиллуулах програм **эсвэл** зургийг зурах JavaScript функцийг бүртгэнэ.
- Програм ажиллуулдаг хөдөлгүүрт **`engine.run`** зөвшөөрөл хэрэгтэй; энэ нь суулгахаас өмнө болон Тохиргоонд харагдана. Зөвхөн Studio дээр ажиллана; вэб дээр хадгалах файл болж харагдана.
- Нэмэлт програмын нэрийг (энгийн файлын нэр, shell биш), **гарын үсэгтэй нэмэлтийн дотор** байрлах скриптийг, мөн орлуулагч болон энгийн үгнээс бүрдсэн аргументуудыг зааж өгнө. Studio програмыг олох эсвэл нэг удаа заахыг танаас хүснэ.
- Нэмэлт анх програм ажиллуулахдаа **Studio өөрийн харилцах цонхоор танаас асууна**: аль нэмэлт, аль програм, мөн скрипт програмын чадах бүхнийг хийж чадна гэдгийг. Зөвхөн найдвартай нэмэлтэд зөвшөөрнө үү. Таны хариулт тухайн нэмэлт ба програмд хадгалагдана.
- Багц (загвар USD хэлбэрээр ба тохиргооны файл, нэмэлт шаардвал glTF файлтай хамт) болон нэмэлтийн скрипт шинэ түр хавтсанд орно, програм тэнд ажиллана, зураг нэмэлтийн хөдөлгүүрийн нэрээр тэмдэглэгдэн буцаж ирнэ.

:::note
Нэмэлтүүд зөвхөн нэмэлт API 1.4-өөс эхлэн рендерийн хөдөлгүүр нэмж чадна. Нээлттэй эхтэй командын мөрийн рендерлэгчийн жишээ тайлбар түүний өөрийн репозиторид байгаа; тэр рендерлэгч дээр одоохондоо ажиллуулаагүй байна.
:::
