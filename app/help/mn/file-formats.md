## IFC

| Уншина | Дэлгэрэнгүй |
|---|---|
| Геометр | Хэлбэртэй элемент бүр, файлд заасан өнгөтэй. Өрөө ба орон зай нь тунгалаг зурагдаж, эхэндээ нуугдсан |
| Давхар | Давхрыг өндрийн дарааллаар, элемент бүр аль давхарт байгаа. Давхарт байхгүй элементүүд "Давхарт биш" гэж бүлэглэгдэнэ |
| Элементийн тоо | Элементийн төрөл бүрийн тоо (хана, хаалга, таваг…), **{{ui:Elements}}**-д харагдана |
| Төслийн мэдээлэл | Төслийн нэр, урт нэр ба шат; схем; файлын толгойгоос экспортлогч програм, зохиогч, экспортын огноо |
| Элементийн өгөгдөл | Нэр, төрөл, объектын төрөл, тэмдэг, тайлбар, GlobalId; элемент болон түүний төрөл дээрх шинж чанарын багц ба хэмжээний багц бүр |

Засварлаж болно: нэр, объектын төрөл, тэмдэг, тайлбар, ба ганц шинж чанарын утга. Шинэ IFC файл болгон хадгална. IFC2X3, IFC4 ба IFC4X3 схемүүд нээгдэнэ, BimCraft-ийн өөрийн IFC хөдөлгүүрээр уншина; одоохондоо зурж чадахгүй зүйлүүд **{{ui:File}}** самбарт **Одоохондоо зурагдаагүй** гэж жагсаагдана. Загварыг нээхэд эх дээр шилжинэ, тиймээс эх сурвалжаас хол байрласан загвар дэлгэцийн дунд харагдана. `.ifczip` ба `.ifcxml` нээгдэхгүй.

## Төсөл ба гэр бүлийн файлууд

`.rvt` төслүүд, `.rte` төслийн загварууд, `.rfa` гэр бүлүүд ба `.rft` гэр бүлийн загварууд.

| Уншина | Дэлгэрэнгүй |
|---|---|
| Файлын мэдээлэл | Хувилбар ба build, хамтын ажил, төв загварын зам, сүүлд хадгалсан зам, хэрэглэгчийн нэр, локал, баримтын GUID |
| Төслийн мэдээлэл | Төслийн өөрийн талбарууд (нэр, дугаар, захиалагч, хаяг, статус…), шинэ төслийн өгөгдмөлгүйгээр |
| Гэр бүлийн мэдээлэл | Гэр бүлийн нэр, ангилал, хувилбар, сүүлийн шинэчлэлт, параметрүүд бүлгээр |
| Холбоосууд | Файл заасан холбогдсон загваруудын жагсаалт, CAD холбоос, зураг ба түлхүүр үгийн хүснэгт |
| Урьдчилан харах зураг | Файлд хадгалагдсан жижиг зураг |

Уншихгүй: 3D загвар, элементүүд, харагдац, хуудас ба хүснэгт. Тэд баримтжуулаагүй форматад хадгалагдана. BimCraft файл бүрээс хэдхэн арван килобайт л уншдаг тул файлын хэмжээ бараг хамаагүй.

## .pln, .pla, .tpl ба .bpn төслийн файлууд

Одоохондоо уншихгүй: та нээхэд BimCraft үүнийг хэлнэ. Загварыг IFC, зургуудыг DWG-ээр экспортлоорой; харах [.pln ба .pla төслийн файлуудыг нээх](topic:pln-project-files).

## DWG ба DXF

| Уншина | Дэлгэрэнгүй |
|---|---|
| Орон зай | Загварын орон зай ба хуудас бүр (layout), табын дарааллаар |
| Харагдац | Хуудас бүрийн харагдац, масштаб, эргэлт ба хөлдөөсөн давхаргууд |
| Давхарга | Нэр, өнгө, асаалттай/унтраалттай, хөлдөөсөн, хэвлэх тэмдэг ба шугамын зузаан |
| Объектууд | Шугам, полишугам, нум, тойрог, эллипс, сплайн, штрихлэл ба солид, текст ба олон мөрт текст, блок ба атрибут, хэмжээс, тайлбарын шугам ба олон тайлбарын шугам, хүснэгт, цэг, зураг |
| Холбогдсон зурагнууд | Оруулсан газартаа зурагдана, файлыг олдсон үед |
| Зургууд | Зургийн файлуудаас зурагдана, олдсон үед (PNG, JPEG, GIF, BMP, WebP; TIFF биш) |
| Тоног төхөөрөмжийн тэмдэг | Хоолны үйлчилгээний зүйлийн тэмдэг (`KCL-ITEM` атрибут), тоног төхөөрөмжийн хүснэгтэд |

Бусад бүх зүйлийг **Одоохондоо зурагдаагүй** гэж тоолно, хэзээ ч таамаглахгүй. DWG форматуудаас AutoCAD 2000-аас 2018 хүртэлх нь шалгагдсан (R13 ба R14 файлууд ч хүлээн авагдана, гэхдээ туршилтын багцад байгаагүй; хуучин DWG нээгдэхгүй); **{{ui:Drawing}}** самбар форматын кодыг харуулна (жишээ нь AC1032). DXF файлууд бүх хувилбарынх нь нээгдэнэ, R12-ийг оруулаад. Хоёулаа BimCraft-ийн өөрийн уншигчаар, энэ табд уншигдана. DWG эсвэл DXF руу юу ч буцаан хадгалагдахгүй.

## Хавтсан дотор

| Төрөл | Өргөтгөл | Тайланд |
|---|---|---|
| Загварууд | `.rvt` `.rfa` `.rte` `.rft` | Дугаарлагдсан нөөцтэй бүлэглэгдэж, эрүүл байдал шалгагдаж, карт уншигдаж, холбоосууд шалгагдана |
| IFC | `.ifc` | Жагсаагдана; 3D-д нээгдэнэ |
| CAD | `.dwg` `.dxf` `.dgn` | Тэдгээрийг холбосон загваруудтай хамт жагсаагдана; DWG ба DXF 2D-ээр нээгдэнэ, DGN нээгдэхгүй |
| Үлдэгдэл | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | **Тусгаарласан** гэж жагсаагдана |
| Цэвэрлэгээний хавтас | `*_backup`, `*_log`, `Revit_temp`, нуугдсан хавтсууд | **Тусгаарласан** гэж жагсаагдана, уншигдахгүй |

Харах [Хавтасны тайлан: үүрэг, статус ба холбоосууд](topic:folder-roles).
