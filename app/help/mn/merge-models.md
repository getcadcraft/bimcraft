Хоёр хүн нэг барилгын хуулбарыг авдаг: нэг нь зүүн жигүүрийг, нөгөө нь баруун жигүүрийг зурдаг; дараа нь хуулбарууд нэг болох ёстой. Хэрэв тэд өөр өөр объектод хүрсэн бол хүний оронд программ үүнийг хийж чадна.

## Энэ юу хийдэг вэ

IFC файлын хана, хаалга, түвшин, өрөө, шинж чанарын багц бүр хэзээ ч өөрчлөгдөхгүй GlobalId-тай. Нэгтгэл объектыг файлын өгсөн дугаараар (`#123`) биш, тэр id-аар олдог, учир нь программ хадгалах үед дугаар нь өөрчлөгддөг. Объектод хамаарах, өөрийн id-гүй хэсгүүд (байрлал, хэлбэр, нэгж) нь агуулгаараа харьцуулагдана.

Хоёр хуулбар ижил IFC хувилбартай байх ёстой (2x3, 4 эсвэл 4.3). Нэгтгэл таны файлыг өөрчлөгдөөгүй, дараалал ба дугаартай нь хадгална, шинэ зүйлийг нэмнэ; тиймээс git diff нь зөвхөн нэгтгэлийн өөрчилсөн зүйлийг харуулна.

## Тохируулах

Git нь репозитор бүрт нэг удаа хоёр мөр шаардана:

```
# .gitattributes
*.ifc merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git-гүйгээр `cadcraft merge <base> <ours> <theirs>`-ыг ажиллуулна. Fossil ба Mercurial нь ижил гурван файлыг өөрсдийн нэгтгэх хэрэгслийн тохиргоонд авна. Юу ч илгээгдэхгүй; бүх зүйл таны компьютер дээр ажиллана.

## Дүрмүүд

- Нэг талд л өөрчлөгдсөн шинж чанарыг авна. Хоёр талд ижил өөрчлөлт нэг удаа авагдана.
- Ижил шинж чанар хоёр янзаар өөрчлөгдсөн бол (ижил түвшинг хоёр янзаар нэрлэсэн) **зөрчил** болно: таны тал үлдэж, тайланд хоёуланг нь жагсаана. Үр дүнг нээгээд гараар засна уу.
- Олон зүйлийн жагсаалт (түвшний хана, шинж чанарын багц) багцын адил нэгдэнэ: аль нэг тал нэмсэн зүйл хадгалагдаж, аль нэг тал устгасан зүйл устана. Хоёр хүн ижил түвшинд хана нэмбэл зөрчил гарахгүй.
- Аль нэг талд нэмэгдсэн объект хэлбэр ба шинж чанартайгаа хэвээр үлдэнэ. Нэг талд устгасан, нөгөө талд хөндөгдөөгүй бол устана. Нэг талд устгасан, нөгөө талд өөрчлөгдсөн бол устаж, тайланд бичигдэнэ.
- Файлын цагийн тэмдэг ба зохиогч, объект бүрийн эзэмшигчийн түүх танд үлдэнэ.

Геометрийг бүхэлд нь нэгтгэнэ: ханын хэлбэр нэг талаас авагдана, цэг цэгээр холилдохгүй. Зипэд хийсэн IFC ба IFCX файлуудыг нэгтгэхгүй. Нэгтгэлийн дараа үр дүнг BimCraft-д нээж, хадгалахаасаа өмнө Асуудлын самбарыг шалгана уу.
