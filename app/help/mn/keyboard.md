BimCraft-д цөөн товчлол бий. Ихэнх ажлыг хулгана болон самбараар хийнэ. {{key:Mod}}-ээр бичсэн товчлолууд Mac дээр Command, бусад дээр Ctrl ашиглана. Товчийг энэ тусламжид хэрхэн бичдэгийг [Товч, хулгана ба тачпад](common:keys)-аас харна уу.

## Бүх дээр

| Товч | Юу хийдэг |
|---|---|
| {{key:Ctrl+Shift+F}} | Дэлгэцийн горимуудыг эргүүлнэ: энгийн, бүтэн дэлгэц, самбаргүй бүтэн дэлгэц. Бүх платформд Ctrl, Mac дээр ч адил |
| {{key:Esc}} | Бүтэн дэлгэцээс гарна |
| {{key:Mod+,}} | {{ui:Тохиргоо}}-г нээнэ. Үзэх: [BimCraft-ийн тохиргоо](topic:settings) |
| {{key:Tab}} | Товч, сонгох нүд, утгуудын хооронд шилжинэ. Бүх удирдлагыг товчлуураар хүрч болно |

## 3D харагдац (IFC загварууд)

| Товч эсвэл үйлдэл | Юу хийдэг |
|---|---|
| {{key:F}} | Бүх загварыг гурван квартерын харагдлаар багтаана ({{ui:Багтаах}}-тай адил) |
| {{key:Esc}} | Сонголтыг цуцлах, эсвэл байрлуулах, буулгахыг зогсоох |
| Дарах | Заагчийн доорх элементийг сонгоно; хоосон дэвсгэрийг дарвал сонголт цэвэрлэгдэнэ |
| {{key:Mod}}+дарах эсвэл {{key:Shift}}+дарах | Элементийг сонголтод нэмэх эсвэл хасах |
| {{key:H}} | Сонгосон элементүүдийг нуух. Үзэх: [Элементийг нуух, тусгаарлах, нэвтрүүлэн харах](topic:hide-and-isolate) |
| {{key:I}} | Зөвхөн сонгосон элементүүдийг харуулах (тусгаарлах) |
| {{key:T}} | Сонгосон элементүүдийг харуулж, бусдыг нэвтрүүлэн харуулна |
| {{key:Shift+H}} | Бүх элементийг дахин харуулна |
| {{ui:Алхах}} | Дараа нь {{key:W}} {{key:A}} {{key:S}} {{key:D}} эсвэл сумнууд нь алхуулна, {{key:Shift}} гүйлгэнэ, чирэх нь эргүүлнэ, {{key:Esc}} зогсооно. Үзэх: [Загвараар алхах](topic:walk) |
| {{key:M}} | Зайн хэмжээ ба нүүрний талбайг хэмжинэ. Үзэх: [3D-д зай, нүүрний талбай, байрлалыг хэмжих](topic:measure) |
| Зүүн товчийг чирэх | Эргүүлэх |
| Баруун товчийг чирэх | Шилжүүлэх |
| {{key:Shift}} эсвэл {{key:Mod}} дарж зүүн товчоор чирэх | Шилжүүлэх (тачпад дээр тохиромжтой) |
| Гулсуурыг гүйлгэх, эсвэл дунд товчоор чирэх | Томруулах |
| Тачпад дээр хоёр хуруугаар гүйлгэх эсвэл нугалах | Томруулах |
| Нэг хуруу (мэдрэгч) | Эргүүлэх; товшвол сонгоно |
| Хоёр хуруу (мэдрэгч) | Нугалж томруулна, хамт зөөвөл шилжүүлнэ |

| {{key:X}} | Зүсэлтийн хавтгайг асаах/унтраах. Үзэх: [IFC загварыг зүсэлтийн хавтгайгаар таслах](topic:section-plane) |
| {{key:Shift+X}} | Сонгосон элементүүдийн эргэн тойронд зүсэлтийн хайрцаг, Тохиргоонд тохируулсан өрөөтэй |

{{ui:Дээд}}, {{ui:Урд}} ба {{ui:Талаас}}-д товч байхгүй; товчлууруудыг ашиглана уу.

## Засварлах

Ижил командууд хэрэгслийн мөрөнд байна: {{ui:Буцаах}}, {{ui:Дахин хийх}}, {{ui:Хуулах}}, {{ui:Буулгах}} ба {{ui:Бусад}} цэс, энэ нь товч бүрийг харуулна. Тэд IFC загварын 3D харагдацад ажиллана, талбарт бичиж байх үед биш. Үзэх: [Номын сангийн зүйлийг хуулах, буулгах, хуулбарлах](topic:copy-paste).

| Товч | Юу хийдэг |
|---|---|
| {{key:Mod+Z}} | Сүүлийн өөрчлөлтийг буцаана |
| {{key:Mod+Y}} эсвэл {{key:Mod+Shift+Z}} | Буцаах-аар буцаасныг дахин хийнэ |
| {{key:Mod+C}} | Сонгосон элементүүдийг хуулна (нэр, шинж чанар нь текстээр түр санах ойд орно) |
| {{key:Mod+X}} | Сонгосон элементүүдийг тайрна: хуулж, дараа нь устгана |
| {{key:Mod+V}} | Хуулсан зүйлээ буулгана: заагчийг дагана, очих газраа дарна |
| {{key:Mod+Shift+V}} | Яг байрлалд буулгана: тайрсан газраа эсвэл хуулсны дараа эх дээрээ зэрэгцүүлэн |
| {{key:Mod+D}} | Хуулбар үүсгэнэ: сонгосон элементүүдийг хуулж, буулгаж эхэлнэ |
| {{key:Delete}} | Сонгосон элементүүдийг эд анги, нээлттэйн хамт устгана. Үзэх: [Барилгын элементүүдийг устгах, тайрах, хуулах, буулгах](topic:edit-elements) |
| {{key:Mod+A}} | Харагдаж буй бүх элементийг сонгоно |
| {{key:Esc}} | Юуг ч сонгохгүй |

Хуудсан дээр текст сонгогдсон үед {{key:Mod+C}} тэр текстийг уламжлалт байдлаар хуулна.

## Төлөвлөгөөний харагдац (Зурах)

Эдгээр нь {{ui:Зурах}} асаалттай, талбарт бичээгүй байх үед ажиллана. Үзэх: [Ханыг зурах](topic:draw-walls) ба [Хаалга, цонх](topic:doors-and-windows).

| Товч эсвэл үйлдэл | Юу хийдэг |
|---|---|
| {{key:V}} | {{ui:Сонгох}} |
| {{key:W}} | {{ui:Хана}} |
| {{key:D}} | {{ui:Хаалга}} |
| {{key:N}} | {{ui:Цонх}} |
| {{key:H}} | {{ui:Хаалга}} эсвэл {{ui:Цонх}}-тай: нугасыг нөгөө үзүүрт |
| Хана зурж байхад {{key:Shift}} | 0°, 90°, 180° эсвэл 270°-д байлгана |
| Цифр ба футын, инчийн тэмдэг (`'` ба `"`) | {{ui:Урт}} талбарт урт бичиж эхэлнэ; {{key:Enter}} түүнийг ашиглана |
| {{key:Enter}}, {{key:Esc}}, баруун товч эсвэл давхар дарах | Зурж буй ханаа дуусгана; {{key:Esc}} дахин дарвал {{ui:Сонгох}} горимд буцна |
| {{key:Delete}} | Сонгосон хана, хаалга, цонхыг устгана; үлдсэн ханууд дахин залгагдана |
| Төлөвлөгөө дээр заагч байхад {{key:F}} | Төлөвлөгөөг багтаана |
| Гулсуурыг гүйлгэх | Заагчийн дэргэд томруулна |
| Дунд эсвэл баруун товчийг чирэх, эсвэл {{key:Space}} дарж чирэх | Шилжүүлнэ; {{ui:Сонгох}} асаалттай бол энгийн чирэлт ч шилжүүлнэ |
| {{ui:Сонгох}} асаалттай үед хаалга эсвэл цонхыг чирэх | Ханынхаа дагуу эсвэл өөр ханан дээр зөөнө |
| Хоёр хуруу (мэдрэгч) | Нугалж томруулна, хамт зөөвөл шилжүүлнэ |

## Номын сангийн зүйлийг байрлуулах ба буулгах

| Товч | Юу хийдэг |
|---|---|
| {{key:R}} | Зүйлийг 90° эргүүлнэ |
| {{key:Tab}} | Ханатай татах асаах/унтраах: зүйлийн ар тал хамгийн ойрын ханад тулна |
| {{key:Enter}} **X, Y (mm)** талбарт | Бичсэн байрлалд байрлуулна |
| {{key:Esc}} | Байрлуулах эсвэл буулгахыг зогсооно |

## IFC утгыг засах

| Товч | Юу хийдэг |
|---|---|
| {{key:Enter}} | Бичсэн утгыг хадгална |
| {{key:Esc}} | Цуцалж хуучин утгыг буцаана |
| Өөр газар дарах | Бичсэн утгыг хадгална |
| {{key:Mod+Z}} | Сүүлийн өөрчлөлтийг буцаана. Зөвхөн хадгалаагүй өөрчлөлт байгаа үед, талбарт бичээгүй байхад |
| {{key:Mod+Y}} | Буцаах-аар буцаасныг дахин хийнэ |
| {{key:Mod+S}} | IFC-ээр хадгална. Зөвхөн хадгалаагүй өөрчлөлт байгаа үед; эс бол хөтчийн өөрийн хадгалах команд нээгдэнэ |

Зөвхөн товчлуураар засах бол: утга тодрох хүртэл {{key:Tab}} дарж, дараа нь {{key:Enter}} дарж бичиж эхэлнэ.

## 2D зургууд (DWG ба DXF)

| Товч эсвэл үйлдэл | Юу хийдэг |
|---|---|
| {{key:F}} | Зураг эсвэл хуудсыг багтаана |
| {{key:P}} | Хэвлэх харагдацыг асаах/унтраах |
| Давхар дарах | Багтаана |
| Ямар ч товчоор чирэх | Шилжүүлнэ |
| Гулсуурыг гүйлгэх | Заагчийн дэргэд томруулна |
| Тачпад дээр хоёр хуруугаар гүйлгэх эсвэл нугалах | Заагчийн дэргэд томруулна. Хоёр хуруугаар гүйлгэх нь шилжүүлэхгүй |
| Нэг хуруу (мэдрэгч) | Шилжүүлнэ. Зургуудад нугалж томруулах одоогоор хийгдээгүй |

## 3D дэх зургууд

| Товч эсвэл үйлдэл | Юу хийдэг |
|---|---|
| {{key:3}} | 3D асаах/унтраах (2D харагдац дээр ч) |
| {{key:F}} | Хүрээ: бүх зураг |
| Дунд эсвэл зүүн товчийг чирэх | Эргүүлэх |
| Баруун товчийг чирэх, эсвэл {{key:Shift}} дарж чирэх | Шилжүүлэх |
| Гулсуурыг гүйлгэх | Заагч дээрх зүйл рүү томруулна |
| Тачпад дээр хоёр хуруугаар гулсуулах | Эргүүлэх; {{key:Shift}}-тэй бол шилжүүлэх |
| Тачпад дээр нугалах | Томруулах |
| Нэг хуруу (мэдрэгч) | Эргүүлэх |
| Хоёр хуруу (мэдрэгч) | Нугалж томруулна, хамт зөөвөл шилжүүлнэ |

{{key:F}}, {{key:P}} ба {{key:3}} нь талбарт бичиж байх, тоног төхөөрөмжийн хуваарь харагдаж байх, эсвэл {{key:Mod}} эсвэл {{key:Alt}} дарж байвал юу ч хийхгүй.
