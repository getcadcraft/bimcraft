BimCraft Chrome, Edge, Firefox ба Safari-н одоогийн хувилбарт, Mac, Windows ба Linux дээр ажилладаг. 3D харагдац WebGL шаарддаг бөгөөд одоогийн хөтөч бүрт байдаг. Аппуудад ерөнхийдөө юу хэрэгтэйг [Хөтөч ба компьютерууд](common:browsers)-ээс үзнэ үү.

## Фолдер нээх

| Хөтөч | {{ui:Open a folder}} юу хийдэг | Фолдер чирэх | {{ui:Recent folders}} |
|---|---|---|---|
| Chrome, Edge | Хөтчийн фолдер сонгогч, дараа нь "Сайтад файл харах уу?": **Файл харах** дарна уу | Ямар ч асуултгүй нээгдэнэ | Тийм, сонгосон эсвэл чирсэн фолдеруудад |
| Firefox | Системийн фолдер сонгогч | Ямар ч асуултгүй нээгдэнэ | Үгүй |
| Safari | Системийн фолдер сонгогч, **Upload** товчтой (юу ч илгээгдэхгүй) | Ямар ч асуултгүй нээгдэнэ | Үгүй |

Ард нь: Chrome ба Edge File System Access сонгогчийг ашиглаж, фолдерыг санаж чадна. Firefox ба Safari хуучин фолдер сонгогчийг ашигладаг бөгөөд тэр фолдерын файл бүрийг нэг дор өгч, санах боломжгүй. Чирсэн фолдерыг бүх хөтөч дээр оруулгаар нь уншина.

:::chromium
Brave болон бусад зарим Chromium хөтөч фолдер сонгогчийг унтраадаг. Тэгвэл BimCraft системийн фолдер сонгогчийг ашигладаг ба хөтөч "*n* файлыг энэ сайтад илгээх үү?" гэж асууж болно. Юу ч илгээгдэхгүй; файлууд зөвхөн табд очно. Фолдерыг чирвэл асуулт гарахгүй.
:::

## Mac, Windows ба Linux

- {{key:Mod+S}} ба {{key:Mod+Z}} гэж бичигдсэн товчлолууд Mac дээр Command, Windows ба Linux дээр Ctrl.
- {{key:Ctrl+Shift+F}} (дэлгэцийн горим) бүх платформ дээр Control, Mac дээр ч.
- Файлын харилцах цонх ба татагдсан файлуудын фолдер нь таны системийнх.

## Хулгана, трекпад ба хүрэлт

| Оролт | 3D харагдац | 2D зураг |
|---|---|---|
| Хулгана | Зүүн чирэлт эргүүлнэ, баруун чирэлт шилжүүлнэ, дугуй томруулна, дарах сонгоно | Аливаа чирэлт шилжүүлнэ, дугуй томруулна, давхар дарах багтаана |
| Трекпад | Дарж чирэх эргүүлнэ; {{key:Shift}} эсвэл {{key:Mod}}-ийн дараа чирэх шилжүүлнэ; хоёр хуруугаар гүйлгэх эсвэл нугалах томруулна | Дарж чирэх шилжүүлнэ; хоёр хуруугаар гүйлгэх эсвэл нугалах томруулна |
| Хүрэлт | Нэг хуруугаар эргүүлнэ, хоёр хуруугаар нугалах ба шилжүүлнэ, товшиж сонгоно | Нэг хуруугаар шилжүүлнэ; одоогоор нугалж томруулах байхгүй; {{ui:Fit}}-д товшино |

Mac-ийн трекпад дээр баруун товшилт нь хоёр хуруугаар дарах (эсвэл Control-дарах). [Товчлуур, хулгана ба трекпад](common:keys)-ийг үзнэ үү.

Таблет ба утас ганц файл нээж үзэх боломжтой, гэвч дэлгэц жижиг, олон мобайл хөтөч фолдер сонгож чаддаггүй, том загвар тэдний санах ойд багтахгүй байж болно. Компьютер хамгийн сайн ажиллана.

## Том файлууд ба санах ой

BimCraft-ийн уншдаг бүх зүйл хөтөчийн табын санах ойд байна. Таб хэдий хэмжээний санах ой ашиглаж чадах нь хөтөч ба таны компьютерээс хамаарна, BimCraft-аас илүү.

| Файл | Хэр их уншигдах | Юу хүлээх вэ |
|---|---|---|
| IFC | Бүх файл, түүнээс бүтээсэн 3D геометр | Хэр том байх нь таны компьютер ба хөтчөөс хамаарна; хэдэн зуун мегабайтын загвар зөөврийн компьютерт хэт их байж болно. 1.5 сая гурвалжнаас дээш бол ирмэгүүдийг унтраана |
| Төсөл ба гэр бүлийн файлууд | Хэдий ч том байсан ойролцоогоор 40 KB-аас 100 KB | Маш том төвийн загварууд ч нэг мөчид нээгдэнэ, сүлжээний драйвераас ч |
| DWG ба DXF | Бүх файл | Маш том зураг «Энэ зураг маш том; зөвхөн хэсэг нь харагдана.» гэж харуулна |
| Фолдерууд | Файлын жагсаалт, загвар бүрт хэдэн килобайт | 20,000 файл хүртэл |

Хөтчийн санах ой дуусвал хөтөч өөрийн алдааны хуудсыг харуулна (жишээ нь Chrome дээр "Aw, Snap!"). Бусад табыг хаах, BimCraft-аа дахин ачаалах, эсвэл илүү санах ойтой компьютер ашиглана уу.
