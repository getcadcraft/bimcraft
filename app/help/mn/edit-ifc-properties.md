## Юу хийх вэ

IFC загварын өгөгдлийг засна: элементийн нэрийг солих, тэмдгийг засах, шинж чанарын утгыг өөрчлөх. Дараа нь өөрчлөлттэйгээр шинэ IFC файл хадгална. Таны нээсэн файлд хэзээ ч хүрэхгүй.

## Юу өөрчилж болох вэ

| Талбар | Засах боломжтой эсэх |
|---|---|
| Нэр, Object type, Тэмдэг, Тайлбар | Тийм |
| Ганц шинж чанарын утгууд (текст, тоо, Yes/No) | Тийм |
| Төрлийн шинж чанарууд ("(type)" гэж тэмдэглэгдсэн багцууд) | Тийм, өөрчлөлт тэр төрлийн элемент бүрд хэрэгжинэ |
| Төрөл, GlobalId, Line | Үгүй |
| Хэмжээ (урт, талбай, эзэлхүүн, тоо) | Үгүй |
| Жагсаалт, тооллого ба бусад олон хэсэгт утгууд | Үгүй |
| Геометр, байрлал, элемент нэмэх эсвэл устгах | Үгүй |

## Алхмууд

1. IFC загвар нээж, өөрчлөх элементээ дарна уу.
2. {{ui:Properties}} самбарт өөрчлөх утгаа дарна уу. Энэ текстийн талбар болно. Хоосон утга нь *empty* гэж харагдана.
3. Шинэ утгыг бичнэ үү.
4. {{key:Enter}} дарах эсвэл өөр газар дарж хадгална уу. Цуцлахын тулд {{key:Esc}} дарна уу.
5. Утгыг шалгана уу: одоо тод үсгээр, хажууд цэнхэр зурвастай — энэ нь засварласан утга гэсэн үг.
6. Зүүн талд байгаа {{ui:Changes}} хэсгийг харна уу: өөрчлөлт нь *элемент*: *талбар*, хуучин утгаас шинэ утга хүртэл гэж жагсаагдана.
7. Бусад утга эсвэл элементүүдэд давтана уу.
8. {{ui:Save as IFC}} дарна уу (хүлээгдэж буй өөрчлөлтийн тоог харуулна, жишээ нь "Save as IFC (3)"), эсвэл {{key:Mod+S}} дарна уу.
9. Татаж авсан фолдерт "*original name* (edited).ifc" файлыг олно уу.

## Юу харагдах ёстой вэ

Статус мөрөнд "Saved *name* (edited).ifc with *n* changes (… bytes). Your original file is unchanged." гэж гарна. {{ui:Changes}} жагсаалт хоосорч, дараагийн удаад бэлэн болно.

## Утгын төрлүүд

- **Текст**: бичсэн бүх зүйл хэвээр хадгалагдана. Нэр, Object type, Тэмдэг эсвэл Тайлбарыг арилгавал утга устана.
- **Тоо**: файлын өөрийн нэгжээр энгийн тоо бичнэ үү, жишээ нь `2.4` эсвэл `1200`. Нэгжийн тэмдэг бичихгүй. Бусад бичлэгт "Use a number." гэж гарна.
- **Бүхэл тоо** (тоо, бүхэл): аравтын бичвэл "Use a whole number." гэж гарна.
- **Yes/No**: утга нь Тийм ба Үгүй гэсэн цэс болно.

Утга бүр өөрийн IFC төрлөө хадгалдаг тул тоо тоо хэвээр үлдэж, бусад программууд зөв уншина.

## Буцаах

1. {{ui:Changes}} хэсэгт {{ui:Undo}} дарна уу, эсвэл талбарт бичихгүй байхад {{key:Mod+Z}} дарна уу.
2. Илүү буцаахын тулд давтана уу. Буцаах бүр хамгийн шинэ өөрчлөлтийг арилгана.

Хадгалсны дараа буцааж болохгүй: хадгалсны дараа жагсаалт дахин эхэлнэ. Хадгалсан файл бүх зүйлийг хадгална.

## Яагаад таны засвар зөвхөн нэг элементэд нөлөөлдөг вэ

Экспортлогчид орон зайг хуваалцсан өгөгдлөөр хэмнэдэг. Нэг шинж чанарын багц хорин хаалгатай хуваалцагдаж болно, нэг утга ("Fire rating: 60 min") ерэн багцад жагсаагдаж болно. Хэрэв BimCraft хуваалцсан утгыг шууд өөрчилбөл, түүнийг хуваалцдаг элемент бүр өөрчлөгдөнө.

Тиймээс BimCraft бичихийн өмнө хуулбарлана:

- Таны засах шинж чанарын багц бусад элементүүдтэй хуваалцагдсан бол таны элемент өөрийн багцын хуулбарыг авна, зөвхөн хуулбар өөрчлөгдөнө.
- Утга бусад багцтай хуваалцагдсан бол таны багц өөрийн утгын хуулбарыг авна.

Хөрш элементүүд хуучин өгөгдлөө хадгална. Үүнийг *copy-on-write* гэдэг. Энэ нь файлд цөөн жижиг оруулга нэмдэг; IFC программ бүр үүнийг хэвийн уншина.

**Төрлийн шинж чанарууд бол зориуд үл хамаарах тохиолдол.** "(type)" гэж тэмдэглэгдсэн багц нь элементийн төрөлд хамаарна, IFC-д төрлийн элемент бүр түүнийг тэндээс уншина. Үүнийг өөрчлөх нь төрлийг өөрчилнө, тиймээс тухайн төрлийн элемент бүр шинэ утгыг харуулна. {{ui:Changes}} жагсаалт ийм засварыг "(type)"-оор тэмдэглэнэ. Харна уу: [Төрлийн шинж чанарыг төрлийн бүх элементэд өөрчлөх](topic:type-vs-instance).

## Анхааруулгууд: ажлаа алдахаас өмнө

- Хадгалаагүй өөрчлөлттэй байхад өөр файл нээвэл "You have *n* unsaved changes to *file*. Discard them?" гэж асууна. Cancel дарвал ажилдаа үргэлжлүүлж, дараа нь хадгална.
- Хадгалаагүй өөрчлөлттэй табыг хаах эсвэл дахин ачаалвал хөтөч гарахыг асууна.

## Түгээмэл алдаанууд

- **Нэгжээ бичих.** `2400 mm` татгалзагдана. `2400` гэж бичнэ үү.
- **Нэг элементэд хэрэгтэй гэж бодоод төрлийн шинж чанар өөрчлөх.** Бичихээсээ өмнө "(type)" тэмдэглэлийг хайна уу. Хэрэв нэг элемент өөр байх ёстой бол харин жишээ шинж чанар эсвэл Тэмдэг, Нэрийг өөрчилнө.
- **Анхны файл өөрчлөгдөнө гэж бодох.** Хадгалах үргэлж шинэ файл татна. Хэрэв хүсвэл анхны файлаа өөрөө солиорой, хуулбарыг хадгална уу.
- **Өөрчлөлтгүй үед {{key:Mod+S}} дарах.** BimCraft зөвхөн хадгалах зүйл байхад хадгална; эс бөгөөс хөтчийн "Save page" нээгдэж магадгүй. Хаана уу.
- **Хоёр удаа хадгалаад хоёр бага файл хүлээх.** Хадгалах бүр таны загварыг нээснээс хойшхи бүх засварыг агуулна.
- **Засваруудаа төслийн файлд буцаана гэж бодох.** BimCraft зөвхөн IFC бичдэг. Засварласан IFC-г зохиогч программдаа ямар ч IFC импортлох адил оруулна уу.
