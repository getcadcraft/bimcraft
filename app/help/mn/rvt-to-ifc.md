## Юу хийх вэ

Төслийн файлыг BimCraft-д эргүүлж, харах, шалгах, засах боломжтой IFC файл болгоно. BimCraft одоогоор `.rvt` файлын 3D загварыг уншдаггүй тул экспорт нь файлыг үүсгэсэн программд (Revit) хийгдэж, BimCraft үр дүнг нээнэ.

## Алхмууд

1. Төслөө үүсгэсэн программд нээнэ. BimCraft-ын карт нь хадгалсан хувилбарыг нэрлэнэ.
2. Экспортлох зүйлээ харуулсан 3D харагдац нээнэ.
3. **File > Export > IFC**-г сонгоно.
4. Экспортын харилцах цонхонд доорх тохиргоотой загварыг (эсвэл **Modify setup…**) сонгоно.
5. Хавтас, файлын нэрийг сонгоод экспортлоно.
6. BimCraft-д {{ui:Choose a file}}-г дарж шинэ `.ifc` файлыг сонгоно. Тусдаа файл болгон экспортолсон холбогдсон загварууд {{ui:Add a model}}-оор нэг гэрэлт зурагт нээгдэнэ.

## BimCraft-д хамгийн сайн нээгдэх тохиргоо

| Экспортлогчийн тохиргоо | Сонгох | Яагаад |
|---|---|---|
| IFC хувилбар | Харах, шалгах, тоо хэмжээ авахад **IFC4 Reference View**; бусад хүнд IFC2X3 хэрэгтэй үед **IFC2X3 Coordination View 2.0** | Хоёулаа бүрэн нээгдэнэ. **IFC4 Design Transfer View** ч нээгдэнэ, илүү нарийн хэлбэртэй боловч файл нь том, удаан. |
| Файлын төрөл | **IFC** (энгийн) | BimCraft `.ifczip` эсвэл `.ifcxml`-ийг нээдэггүй. |
| Үе шат / харагдах элементүүд | Таны хүссэн үе шат, мөн 3D харагдацаа тохируулсан бол **Export only elements visible in view** | Санаатайгаар нуусан зүйлсийг орхино. |
| Шинж чанарын багц | **Export Revit property sets** ба **Export IFC common property sets** | BimCraft-д {{ui:Properties}} дотор харуулах багцууд болж, {{ui:Find}}, {{ui:Color}} ба {{ui:Model checks}}-д ашиглагдана. |
| Суурь тоо хэмжээ | **Export base quantities** | {{ui:Quantity totals}} ба хүснэгтүүд тэдгээрийг (урт, талбай, эзэлхүүн) таамаглахын оронд ашиглана. |
| Өрөө ба талбай | **Export rooms in 3D views** (эсвэл Rooms / Spaces сонголт) | Өрөөнүүд орон зай болж ирнэ: харахын тулд {{ui:Spaces}}-г дарна. |
| Холбогдсон файлууд | **Export linked files as separate IFCs** | Холбоос бүр өөрийн файл болно; {{ui:Add a model}}-оор хамт нээвэл зэрэгцэнэ. |
| Координатын суурь | **Shared coordinates** (эсвэл судалгааны цэг) | Файлд газрын зургийн байрлал (IfcMapConversion) орно, тиймээс Хэмжилт › Байрлал, газар дээрх зургийн давхарга, газрын координатаар байрласан цэгийн үүл ажиллана. Төслийн суурь цэг загварыг эхлэлийн ойролцоо байлгах боловч газрын зургийн байрлалгүй. |
| Давхраар ханыг ба баганыг хуваах | Давхар бүрээр тоо хэмжээ авах үед асаана | Давхар бүрийн хэсэг тусдаа элемент болно. |

## Харах зүйл

Загварыг 3D-д харна: давхрууд төслийн түвшнээс авагдаж, төслийн мэдээлэл {{ui:File}} самбарт. **Exported from** нь экспортлогчийн нэрийг харуулна.

## Экспорт юуг хадгалах, юуг үгүй

- **Хадгалагдана**: геометр, давхар, элементийн төрөл, нэр, төрөл, ихэнх параметр (шинж чанарын багцаар), хүссэн үед суурь тоо хэмжээ, өрөөнүүд орон зай болж, хуваалцсан координат байвал газрын зургийн байрлал.
- **Хадгалагдахгүй**: харагдац, хуудас, тайлбар, засварлагдах гэр бүл болсон гэр бүл, ажлын багц, дизайн сонголт. IFC файл нь загварын элементүүдийн агшин зураг, төсөл биш. Хуудсуудын хувьд DWG экспортлоод 2D харагдацад нээнэ.

## Түгээмэл алдаа

- **BimCraft-д параметр алга.** Дээрх шинж чанарын багцын сонголтыг асааж дахин экспортлоно.
- **Өрөөнүүд алга.** Өрөөний сонголтыг асааж, дараа нь {{ui:Spaces}}-г дарна.
- **`.ifczip`-ээр хадгалсан.** Энгийн IFC сонгох, эсвэл `.ifczip`-ийг задлана.
- **Газрын зургийн байрлал алга.** Хуваалцсан координаттай экспортлоно; төслийн судалгааны цэг тохируулагдсан эсэхийг шалгана.
- **BimCraft-д хийсэн засвар төсөл рүү буцна гэж бодох.** BimCraft-д хадгалсан засвар нь шинэ IFC файлд орно, төслийн файлд биш.
