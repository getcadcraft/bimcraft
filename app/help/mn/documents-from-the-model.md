## Юу хийх вэ

Загвар нь хос хаалт `{{ }}` дотор талбартай Markdown текст. BimCraft талбаруудыг нээлттэй загвараас бөглөнө (тоо, төрлөөр тоо хэмжээ, шинж чанар, таны [тэмдэгүүд](topic:tags-and-schedules)) ба үр дүнг PDF, Word баримт (.docx) эсвэл Markdown болгон хадгална.

## Алхмууд

1. Нээлттэй IFC загвар нээнэ.
2. Зүүн самбарт, {{ui:Тоо хэмжээ}}-ний доор {{ui:Загвараас баримтууд}}-ыг нээнэ.
3. Загвар сонгоно: {{ui:Хаалга ба тоног төхөөрөмж}}, эсвэл {{ui:Хана, бүрээс ба гадаргуугийн чимэглэл}}, эсвэл өөрийнхөө {{ui:Загвар ачаалах (.md)…}}.
4. Хэрвээ загвар загварт тодорхойлоогүй тэмдгүүдийг уншвал {{ui:Энэ загварын тэмдгүүдийг нэмэх}}-ийг дарна, дараа нь {{ui:Тэмдэгүүд}} доор элементүүдэд тэмдэг тавина.
5. Текстийг хүссэнээрээ засаад {{ui:Баримтыг харуулах}} дарна.
6. {{ui:PDF}}-ийг дарна (эхлээд A4 эсвэл Letter сонгоно), эсвэл {{ui:Word (.docx)}}.

## Та юу харах ёстой вэ

- Товчнуудын доор бөглөгдсөн баримт, хүснэгтүүдтэй.
- Талбар уншигдахгүй үед анхааруулгын жагсаалт (тодорхойлоогүй тэмдэг, загварт байхгүй шинж чанар, хаагдаагүй блок); ийм талбар `[?…]` хэлбэрээр хэвлэгдэнэ.
- PDF хуудсууд баримтын гарчигтай, хуудас бүрийн доод хэсэгт «Хуудас 1 / 3»; урт хүснэгтүүд толгой мөрөө авч дараагийн хуудсанд үргэлжилнэ.

## Талбарууд

| Талбар | Үр дүн |
|---|---|
| `{{project}}`, `{{project description}}`, `{{file}}`, `{{date}}` | төслийн нэр ба тайлбар, файлын нэр, өнөөдөр |
| `{{count IfcDoor}}` | хаалганы тоо |
| `{{sum IfcWall NetSideArea}}` | нийлбэр, нэгжтэйгээр |
| `{{calc [sum IfcWall NetSideArea] * 1.1 round 1 unit m²}}` | арифметик (`+ - * /` ба хаалт) квадрат хаалтанд байгаа нэр томъёонд: `[sum …]`, `[count …]`, мөн each дотор `[qty Width]`. `round n` аравтын оронг тодорхойлно, `unit` нэгж нэмнэ. Уншиж чадахгүй зүйл эсвэл тэгээр хуваах нь `[?…]` хэлбэрээр хэвлэгдэж, анхааруулна |
| `{{qty IfcWall NetSideArea by Type}}` | хүснэгт: төрөл бүрт нэг мөр, тоо ба нийлбэртэй, мөн нийт мөр |
| `{{table IfcDoor cols Mark, Type, Width, tag:Fire rating}}` | хүснэгт, элемент бүрт нэг мөр |
| `{{tag Finish}}` | давталтанд элементийн утга; бусад газар ашигласан бүх утга (Oak, Paint) |
| `{{tags}}` | тэмдгийн тодорхойлолтууд хүснэгт хэлбэрээр |
| `{{#each IfcDoor}} … {{else}} … {{/each}}` | элемент бүрт текст нэг удаа; байхгүй үед `{{else}}`-ийн дараах хэсэг |
| `{{#group IfcWall by Type}} … {{/group}}` | төрөл бүрт текст нэг удаа, `{{value}}`, `{{count}}`, `{{sum Length}}` ба дотор нь энгийн `{{#each}}` |

`{{#each}}` дотор: `{{name}}`, `{{type}}`, `{{storey}}`, `{{class}}`, `{{material}}`, `{{mark}}` (IFC Tag), `{{guid}}`, `{{n}}` (1, 2, 3 …), `{{prop Pset_DoorCommon.FireRating}}`, `{{qty Width}}` (элементийн өөрийн, нэгжтэйгээр).

Анги хэд байж болно (`IfcDoor|IfcWindow`) эсвэл бүх элемент (`*`). Аль нэгийг нь `where`-ээр нарийсгана: `{{#each IfcDoor where Fire rating >= 60}}`, `{{count IfcWall where Wall finish hasnot}}`. Шалгалтууд нь `=`, `!=`, `~` (агуулна), `>`, `<`, `>=`, `<=`, `has` ба `hasnot`; хэд хэдийг `and`-ээр холбоно; хоосон зайтай утгыг "хашилт" дотор бичнэ. `sort Name` давталтыг эрэмбэлнэ.

## Хуваарь ба баримт дахь тодорхойлолт

`{{schedule doors}}` загварын хуваарийг таны оффисын зохион байгуулалтаар хүснэгт болгон хэвлэнэ: `doors`, `windows`, `walls`, `rooms`, `floors`, `roomfinishes`, `wallfinishes`, `zonefinishes`, `finishtotals`, `layers`, эсвэл Хуваарьт хадгалсан тохиргооны нэр. `{{specification}}` төслийн тодорхойлолтыг хэвлэнэ. **Ажлын зургийн хуваарь** ба **Тодорхойлолт** загварууд эдгээрийг ашигладаг. Урьдчилан харахад энэ хуваарийн тоон дээр дарвал тэр элементүүдийг сонгоно. Харна уу: [Хуваарийг зохион байгуулах, хадгалах, экспортлох](topic:schedule-layouts) ба [Тодорхойлолтыг загвараас бичих](topic:specification).

## Сайн мэдэх зүйлс

- Талбар нь бэлэн талбарыг (Name, Type, Storey, Class, Material, Mark), тэмдгийг (`tag:Fire rating`, эсвэл түүний нэр), шинж чанарыг (`Pset_WallCommon.FireRating`) эсвэл зөвхөн шинж чанарын нэрийг (`NetSideArea`, `Width`) нэрлэнэ. Энгийн нэр нь элемент бүрийн өөрийн багцыг уншина, тоон багцууд эхэнд; тиймээс хаалган дээрх `Width` нь хаалганы өргөн, ханын зузаан биш. `where`-ийн дотор энгийн нэр нь сонгосон элементүүдийн ихэнхийн багцыг уншина.
- Тоо хэмжээ нь файлын тоон багцууд юуг хэлснийг; BimCraft өөрийн зурсан зүйлдээ тэдгээрийг бичнэ. Нэгжүүд файлын нэгжийн тохиргооноос авагдана.
- Талбарын үгс (`count`, `sum`, `qty`, `by`, `cols`, `where`, `each`, `group` …) хэл бүрт англиар үлдэнэ. Жишээ загварууд англи хэлтэй.
- Загвараас ирсэн текст хэзээ ч форматлах тэмдэг болохгүй: `*` эсвэл `|` агуулсан нэр нь яг байгаагаараа хэвлэгдэнэ.
- Өөрчилсөн загвараа {{ui:Энэ хөтөчид хадгалах}} (зөвхөн энэ хөтөчид байна) эсвэл {{ui:Загварыг татах}}-аар хадгална.
- PDF текст нь стандарт PDF фонтыг ашиглана: Баруун Европын текстээс гадуурх тэмдэгт "?" гэж хэвлэгдэж, төлөвийн мөр хэдэн ширхэгийг хэлнэ.
- Мэргэжил бүрийн загварууд Номын санд байна (төрөл Баримтын загвар). Загвараас баримтууд дотор **Номын сангаас…**-ыг сонгоод, нэгийг нь сонговол түүний текст ба уншдаг тэмдгүүд орно; дураараа засаж болно. Өөрийн загварыг номын санд нийтлэх нь бусад зүйлтэй адил байршуулалт. Одоогоор бэлэн болоогүй: тоо ба нийлбэрээс илүү тооцоолол.
