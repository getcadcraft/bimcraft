IFC5 alpha (файлын өргөтгөл {{ui:.ifcx}}) бол buildingSMART-ийн одоо боловсруулж буй файлын формат юм. Энэ эцсийнх биш: файлууд болон тэдгээрийг уншсан бидний тайлбар өөрчлөгдөж болно. Тийм учраас энэ нь туршилтын сонголт бөгөөд эхлээд уншина уу.

## Асаах

1. {{ui:Тохиргоо}}-г сонгоод, BimCraft табын {{ui:IFC5 alpha (IFCX)}} хэсгийг нээнэ үү.
2. {{ui:IFC5 alpha (IFCX) - формат одоо ч өөрчлөгдөж байна; эхлээд уншина уу}}-г сонгоно уу.

Анхдагчаар унтраалттай. Унтарсан үед .ifcx файлыг энэ хуудсыг заасан өгүүлбэрээр татгалзана. {{ui:IFC5 alpha (.ifcx) нээх…}} болон {{ui:IFC5 alpha}} экспортын товч асаалттай үед харагдана.

## Нээх

- {{ui:Файл эсвэл хавтас нээх}}-ээр .ifcx файлыг сонгоно уу (энэ нь нээлттэй загварыг солино, засварын асуултын дараа), эсвэл
- {{ui:IFC5 alpha (.ifcx) нээх…}}-ийг сонгоод хэд хэдэн файлыг хамт сонгоно уу: файл, түүний давхаргууд, мөн импортлодог схемийн файлууд. Загвар аль хэдийн нээлттэй бол файл **хажууд нь нэмэгдэнэ**; загварын жагсаалтын x тэр файлыг дахин хасна, энэ нь буцаах үйлдэл юм.

IFCX файл нь зангилааг жагсаана (зам, түүний хүүхдүүд, өвлөх зүйл, шинж чанарууд). Олон файл нэг зангилааг дүрсэлж болно: сүүлийн файл (давхарга) өмнөхийнхийг давж бичих шинж чанаруудыг, null хүүхэд нь хүүхдийг хасна. BimCraft тэдгээрийг нэгтгээд үр дүнг жижиг IFC4 загвар болгон зурна: төсөл, талбай, барилга, давхрууд, элементүүд нэр, ангилал, шинж чанар, тоо хэмжээ, өнгө, сүлжээтэй.

Файлаас сүлжээгээр юу ч татахгүй. Файлын импортлодог схемийн файлууд (жишээ нь `ifc@v5a.ifcx`) зөвхөн файлтай хамт сонгосон бол ашиглагдана; эс бөгөөс тайланд тэр тухай хэлж, шинж чанаруудыг төрлийн шалгалтгүйгээр уншина.

### Тайлан

Нээсний дараа тайланд уншилтаас олдсон зүйлс жагсаагдана: схемтэй тохирохгүй өгөгдөл, өгөгдөөгүй схемийн файлууд, энд IFC утгагүй шинж чанарууд. Ямар ч зураглалгүй шинж чанар загварт **хадгалагдана**, хасагдахгүй, экспортлоход буцаж бичигдэнэ.

## Юу юунд болдог вэ

| IFCX файлд | BimCraft-д |
|---|---|
| IFC ангилалтай зангилаа (төсөл, талбай, барилга, давхар, хана …) | Тохирох IFC4 элемент; энэ уншилт мэддэггүй ангилал нь building element proxy болно |
| Эцэг дор нь тухайн зангилаанд байх нэр | Элементийн нэр |
| Хэмжээний төрөлтэй шинж чанарууд (Length, Area, Volume, Mass …) | `Qto_IFCX` нэртэй IFC4 хэмжээний багц (IFC4 хэмжээнүүд IFC4 `Qto_*` багц хэвээр үлдэнэ) |
| Бусад шинж чанарууд | `Pset_IFCX` нэртэй шинж чанарын багц |
| Mesh ба transform шинж чанарууд | Элементийн гурвалжнууд ба байрлал; үл харагдах mesh-үүдийг зурахгүй |
| Өнгө, opacity, материал, ангилал | Элементийн гадаргуугийн загвар, материал, ангилал |

Нэгжүүдийг метрээр авч, Z дээш гэж үзнэ: alpha нь нэгжүүдийг хожим баримтжуулна гэж заасан.

## Экспорт

Хэрэгслийн мөрөнд {{ui:IFC5 alpha}}-г сонгоод тэмдэглэлийг уншаад, дараа нь {{ui:Экспортлох .ifcx}}-ийг дарна уу. Файлд бидний толгой хэсэг (зохиогч CadCraft, хувилбар ifcx_alpha) байх ба өөрөө alpha формат гэж хэлнэ. Загвар бүрийг өөрийн файлын координатаар, метрээр бичнэ: нэр, ангилал, шинж чанарын багцууд, хэмжээ (төрлөө заасан шинж чанар хэлбэрээр), өнгө ба гурвалжнууд. Давхарга ба өвлөлтийг тэгшлэгдсэн байдлаар бичнэ. Хүлээн авах програмдаа файлаа шалгаарай.

## Хязгаарлалт

- Муруй геометр (муруй, гадаргуу) уншигдахгүй: зөвхөн гурвалжин mesh.
- Ханын дотор байрласан хаалга, цонхнууд давхарт байрлана; тэдгээрийн гаралтай хана холбогдохгүй.
- IFC4 `Qto_*` багцын нэрнүүд өөрсдийн шинж чанарын бүлгүүд болгон хадгалагдана (`cadcraft::qto::…`); стандарт alpha схемд хэдхэн хэмжээний нэр л байна.
- Формат бидний хяналтаас гадуур өөрчлөгдөж болно; өнөөдөр бичсэн файл маргааш уншигдахгүй байж магадгүй.
