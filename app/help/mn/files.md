BimCraft файлуудыг таны компьютер дээр, хөтчийн таб дотор уншина. **Ямар ч файл илгээгдэхгүй** CadCraft руу ч, өөр хэнд ч. Хадгалахад BimCraft хөтөчид татах шинэ файл өгнө; нээсэн файлаа хэзээ ч дарж бичихгүй.

## Юу нээдэг вэ

| Формат | Өргөтгөл | Таны авах зүйл |
|---|---|---|
| IFC | `.ifc` | Загвар 3D-д, давхрууд, элементийн тоо болон элемент бүрийн шинж чанарууд. Нэр, тэмдэг болон ганц шинж чанарын утгыг өөрчилж болно. |
| Төслийн ба гэр бүлийн файлууд | `.rvt` `.rfa` `.rte` `.rft` | Файлын карт: хувилбарын дугаар, хамтран ажиллах тохиргоо, төслийн мэдээлэл, гэр бүлийн параметрүүд, холбогдсон файлууд ба урьдчилан харах зураг. 3D байхгүй. |
| DWG | `.dwg` | Зураг 2D-д: загварын орон зай, бүх хуудас, давхаргууд, холбогдсон зургууд, дүрсүүд ба хэвлэх харагдац. Загварын орон зай 3D-д ч. AutoCAD 2000-аас 2018 хүртэлх форматуудыг шалгасан. |
| DXF | `.dxf` | DWG-тэй адил. |
| STEP | `.step` `.stp` | Эд анги, тоног төхөөрөмж эсвэл нийлүүлэгчийн загвар (AP203, AP214, AP242) 3D-д: solid бүр нэг элемент болдог (барилгын элементийн прокси) нэг давхарт байрлах жижиг IFC загварт. Гурвалжин хэлбэрээр жинхэнэ хэмжээгээрээ уншигдана; файл хаана байрлуулсан бол тэр газарт бүх эд анги угсарсан угсралт. Цаанаасаа IFC шиг ажиллана: шинж чанар, зүсэлт, хэмжилт, IFC-ээр хадгалах. Өнгө болон угсралтын модыг уншдаггүй. |
| Цэгийн үүл | `.las` `.laz` `.e57` `.ply` `.pcd` `.ptx` `.pts` `.xyz` | Скан нь 3D харагдацад, загварын хажууд эсвэл өөрөө харагдана. Харна уу: [Загварын хажууд цэгийн үүлийг харуулах](topic:point-clouds). |
| Төслийн багц | `.ccbundle.zip` | Загвар түүний харагдац, байрлал болон шинж чанарын бүлгүүдтэй. Харна уу: [Төслийн багцыг нээх](topic:open-project-bundle). |
| Хавтас | ямар ч | Дотор нь байгаа загвар, зураг, төслийн багц бүрийн тайлан. Тайланд байгаа аль ч IFC, загвар, зураг эсвэл багцыг нэг товшилтоор нээнэ. |

[Формат бүрээс BimCraft юуг уншдаг вэ](topic:file-formats) гэдэгт дэлгэрэнгүй орсон.

BimCraft файл юу болохыг нэрнээс гадна эхний байтуудаар нь тодорхойлдог тул ер бусын өргөтгөлтэй төслийн файл ч гэсэн файлын карт болж нээгдэнэ.

### Нээгдэхгүй

- `.ifczip` ба `.ifcxml`: BimCraft «.ifczip одоогоор дэмжигдээгүй байна. Загвараа энгийн .ifc файл болгож хадгална уу эсвэл экспортлоно уу.» гэж хэлнэ. `.ifczip`-ийг задлах (дотор нь энгийн `.ifc` байна) эсвэл энгийн IFC-ээр дахин экспортлох.
- DGN зургууд хавтасны тайланд жагсаагдах боловч нээгдэхгүй.
- PDF, зураг болон оффисын файлууд өөрөө нээгдэхгүй. Зургууд DWG-ийн дотор зураг болгон ашиглагдах бөгөөд {{ui:Бүтээлийн дугаар}} › {{ui:Зургаас…}} нь PDF эсвэл скан хуудсуудыг ханa болгон хөрвүүлнэ: харна уу: [Төлөвлөгөөний багцаас хана](topic:walls-from-plans).

## Юуг хадгалдаг вэ

| Таны дарах | Таны авах зүйл | Хаана |
|---|---|---|
| {{ui:IFC-ээр хадгалах}} | Засварласан шинэ IFC файл, нэрлэгдэх нь "*анхны нэр* (edited).ifc" | Хөтчийн татаж авсан файлуудын хавтас |
| Тоног төхөөрөмжийн хуваарьт {{ui:CSV татах}} | Жагсаалтын зүйлсийн CSV, нэрлэгдэх нь "*зургийн нэр* equipment.csv" | Хөтчийн татаж авсан файлуудын хавтас |

Бусад зүйлсийг үүсгэсэн газартаа, тус бүр өөрийн сэдэвт хадгална: {{ui:USD}} ([Загварыг USD-ээр экспортлох](topic:usd)), {{ui:Collada}} ([Загварыг Collada эсвэл Google Earth-д зориулж экспортлох](topic:collada)), {{ui:Рендерт зориулсан}} .glb, рендерлэсэн зургууд, хуудас ба төлөвлөгөө PDF-ээр, хуваарь ба жагсаалт CSV-ээр, BCF асуудлууд, COBie хүснэгт, гэр бүлийн файлууд, бүртгэгдсэн скан LAS эсвэл E57-оор. BimCraft DWG, DXF эсвэл төслийн файлуудыг хадгалдаггүй бөгөөд нээсэн файлуудаа хэзээ ч өөрчилдөггүй.

:::chromium
Chrome ба Edge татсан файлуудаа тохиргоонд тавьсан хавтаст хадгална, ихэвчлэн Downloads. Хадгалах газрыг хадгалах бүрд асуулгахын тулд хөтчийн татаж авалтын тохиргоонд «Татахаас өмнө файл бүрийг хаана хадгалахыг асуух» сонголтыг асаана уу.
:::

:::firefox
Firefox Downloads хавтаст хадгална, гэвч тохиргоондоо «Файлыг хаана хадгалахыг үргэлж асуух» гэж тавьсан бол биш.
:::

:::safari
Safari Downloads-д хадгална, гэхдээ **Safari > Тохиргоо > Ерөнхий > Файл татах байршил** дор өөр хавтас сонгоогүй бол.
:::

## Дахин хадгалах

Хадгалах бүр загварыг **нээснээс хойшхи бүх засварын хамт** бүхэлд нь татна, зөвхөн сүүлийн хадгалалтаас хойших засварыг биш. {{ui:Өөрчлөлтүүд}} жагсаалт хадгалах бүрийн дараа дахин хоосон эхэлдэг тул хадгалалтаас цааш буцааж болохгүй. Эхнээс нь дахин эхлэхийн тулд анхны файлыг дахин нээнэ үү.

## Том файлууд ба санах ой

- **IFC** файлуудыг бүтнээр нь табын санах ойд уншина, мөн 3D геометр дээрээ илүү санах ой авна. Хэдэн зуун мегабайттай загвар зөөврийн компьютерт хэт их байж болно. 1.5 сая гурвалжингаас дээш бол санах ойг хэмнэхийн тулд ирмэгүүдийг унтраана («Маш том загваруудад ирмэгүүд унтраастай»).
- **Төслийн файлуудыг** бүтнээр нь уншдаггүй. BimCraft зөвхөн хэрэгтэй жижиг хэсгээ уншина, файл ямар ч том байсан 40 KB-аас 100 KB орчим; тиймээс сүлжээний диск дээрх 500 MB-ын төв загвар хэдхэн агшинд нээгдэнэ.
- **DWG ба DXF** файлуудыг бүтнээр нь уншина. Маш том зураг «Энэ зураг маш том; зөвхөн түүний хэсгийг харуулж байна.» гэж харуулна.
- **Хавтсууд** 20,000 файл хүртэл нээгдэнэ. Загвар бүрийн картад хэрэгтэй хэдхэн килобайтыг л уншина.

Дэлгэрэнгүйг [Хөтөч, төхөөрөмж ба санах ой](topic:platforms) хэсгээс харна уу.

## Онлайн ба офлайн

Файл нээхэд интернэт хэрэггүй. Нэг уншигч хэрэгтэй үедээ анх сайтаас ачаалагдана: IFC хөдөлгүүр, IFC загварыг анх нээхдээ («IFC хөдөлгүүрийг эхлүүлж байна…»). DWG ба DXF уншигчид аппын бүрдэл хэсэг юм.

:::offline
Та офлайн байна. Аппын самбарын товч {{ui:Офлайнд бэлэн}} гэж харуулж байвал бүх формат ердийнхөөрөө нээгдэнэ. Үгүй бол IFC загвар энэ табд аль хэдийн нээгдсэн байхаас бусад тохиолдолд нээгдэхгүй: эхлээд дахин холбогдоно уу. Харна уу: [Онлайн ба офлайн](topic:online-offline).
:::

BimCraft-ыг холболтгүйгээр ашиглахын тулд интернэттэй байхад аппын самбар дээрээс {{ui:Офлайнд хадгалах}} товчийг дарж, {{ui:Офлайнд бэлэн}} гарах хүртэл хүлээнэ үү. Хадгалсан хуулбар ойролцоогоор 33 MB; түүнд IFC хөдөлгүүр багтдаг тул IFC загварууд офлайнд ч нээгдэнэ. [Офлайнаар ажиллах](common:offline) нь хадгалсан хуулбарын талаар ерөнхийд нь тайлбарлана.

## Үүлэн хадгалалт

Үүлэн хадгалалт одоогоор боломжгүй. Засварласан хуулбараа өөрийн компьютер эсвэл байгууллагын файлын серверт, бусад файл шиг хадгална уу. Харна уу: [Таны файлууд](common:your-files).
