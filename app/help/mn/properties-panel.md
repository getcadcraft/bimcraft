## IFC элемент

{{ui:Шинж чанар}} самбарын дээд хэсэг нь элементийн төрлийг "Ifc" угтваргүйгээр (жишээ нь "Door", "WallStandardCase", "FurnishingElement") болон нэрийг, эсвэл "Нэргүй"-г харуулна.

| Талбар | Утга | Засах боломжтой |
|---|---|---|
| Нэр | Элементийн нэр, ихэвчлэн экспортлогчийн гэр бүл ба төрлийн нэр | Тийм |
| Төрөл | Элементийн төрлийн нэр, байвал | Үгүй |
| Объектын төрөл | Зарим экспортлогчид бөглөдөг чөлөөт текст төрлийн тайлбар | Тийм |
| Тэмдэг | Элементийн тэмдэг эсвэл марк; олон экспортлогч энд элементийн ID бичдэг | Тийм |
| Тайлбар | Чөлөөт текст | Тийм |
| GlobalId | Элементийн байнгын 22 тэмдэгтийн IFC таних дугаар; ижил элементийн экспорт бүрт ижил | Үгүй |
| Мөр | Энэ IFC файл дахь элементийн мөрийн дугаар (`#1234`). Экспорт бүрт өөрчлөгддөг | Үгүй |

Доор **шинж чанарын олонлогууд** нэрээр нь эрэмбэлэгдэн харагдана:

- Олонлог бүр нэр дээр нь дарахад нээгдэж хаагдана. Эхний гурав нь нээлттэй байна.
- "(type)" гэж тэмдэглэсэн олонлог нь элементийн төрөлд хамаарна: "Төрлийн шинж чанар: энд хийсэн өөрчлөлт энэ төрлийн бүх элементэд хамаарна."
- Хэмжээний олонлогууд (урт, талбай, эзэлхүүн, тоо, жин) зөвхөн унших боломжтой.
- Жагсаалт ба тоологдсон утгууд харуулагдана, зөвхөн унших боломжтой.
- Тийм/Үгүй утгууд **Тийм** эсвэл **Үгүй** гэж харагдана.
- Тоонууд дэлгэцэд дөрвөн аравтын орон хүртэл бөөрөнхийлөгдсөн. Урт (уртын шинж чанар эсвэл хэмжээний урт) нь {{ui:Нэгж}}-ээр харагдах ба хажууд нь нэгжийн тэмдэг байна; та тэр нэгжээр эсвэл өөр нэгжийн тэмдгээр (2.4 m, 8'-0") шинэ утга бичиж болно: BimCraft файлын өөрийн тоог буцааж бичнэ. Бусад тоо нь файлд байгаагаараа харагдана.
- Хоосон утга *empty* гэж харагдана. Засагдсан утга тод байх ба хажууд цэнхэр зурвастай байна.

## Утга хуулах

{{ui:Шинж чанар}} дээрх утга бүр хажууд жижиг хуулах товчтой: дар, ингэснээр тэр утга харагдсанаар нь санах ойд орно, жишээ нь GlobalId, серийн дугаар эсвэл аливаа шинж чанарын олонлогийн утга. Хуулах нь хэзээ ч засварлалт эхлүүлдэггүй.

Дээд хэсэгт {{ui:Бүгдийг хуулах}} элементийн бүх утгыг олонлог тус бүрээр текст болгон хуулна; {{ui:CSV-ээр хуулах}} нь бүлэг, шинж чанар, утгын мөр болгон хуулж, хүснэгт программд наахад бэлэн болгоно. Хоосон утгыг мөр болгон хадгална. Энэ нь нээлттэй өөр загварын элементэд ч адилхан ажиллана; хэд хэдэн загвар нээлттэй үед CSV нь файлынхаа нэрийг заасан Загвар баганатай эхэлнэ.

## IFC файлын самбар

| Талбар | Утга |
|---|---|
| Файл, Хэмжээ | Таны нээсэн файл |
| Схем | IFC хувилбар, жишээ нь IFC2X3 эсвэл IFC4 |
| Төсөл | Төслийн нэр ба урт нэр |
| Үе шат | Төслийн үе шат, экспортлогч бичсэн бол |
| Экспортолсон программ | Файлын толгойгоос экспортлосон программ |
| Зохиогч | Файлын толгойн зохиогч |
| Экспортолсон | Файлын толгойн огноо ба цаг |
| Элементүүд | Хэдэн хэлбэртэй элемент зурагдсан |
| Гурвалжин | Тэдгээрийн хэлбэрүүдийн гурвалжны тоо; загварын жингийн хэмжүүр |

## Файлын самбар (төсөл ба гэр бүлийн файлууд)

| Талбар | Утга |
|---|---|
| Төрөл | Төсөл, Төслийн загвар, Гэр бүл эсвэл Гэр бүлийн загвар |
| Хадгалсан хувилбар | Файлыг сүүлд хадгалсан хувилбар |
| Бүтээц | Тэр хувилбарын яг бүтээц |
| Уншсан | BimCraft файлаас хэдийг нь уншсан, нийт хэмжээнээсээ |

## Зургийн самбар (DWG ба DXF)

| Талбар | Утга |
|---|---|
| Формат | Зургийг хадгалсан хувилбар, формат код (жишээ нь AC1032) |
| Нэгж | Зургийн оруулах нэгж, тохируулсан бол |
| Объектууд | Хэдэн объект уншигдсан |
| Давхарга | Хэдэн давхарга |
| Хуудас | Хэдэн хуудас (зохиомж), эсвэл Байхгүй |
| Холбогдсон зургууд | Холбогдсон зургуудын хэд нь олдож ачаалагдсан |
| Тоног төхөөрөмж | Хуудсан дээрх тэмдэглэгдсэн тоног төхөөрөмжийн тоо |

## Хавтасны самбар

| Талбар | Утга |
|---|---|
| Хавтас, Файлууд, Хэмжээ | Таны нээсэн хавтас, түүнд байгаа файлын тоо ба нийт хэмжээ |
| Загварууд | Төсөл ба гэр бүлийн файлууд, нөөц хуулбар бүр нэг удаа тоологдоно |
| CAD зурагнууд, IFC загварууд | Тус бүрийн тоо |
| Асуудлууд | Хэдэн загварын хуулбар дутуу эсвэл уншигдахгүй, эсвэл Байхгүй |
