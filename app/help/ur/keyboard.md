BimCraft میں شارٹ کٹس بہت کم ہیں۔ زیادہ تر کام ماؤس اور پینلز سے ہوتا ہے۔ جن شارٹ کٹس میں {{key:Mod}} لکھا ہو وہ Mac پر Command اور باقی جگہوں پر Ctrl استعمال کرتے ہیں۔ اس مدد میں کیز کیسے لکھی جاتی ہیں، یہ جاننے کے لیے [کیز، ماؤس اور ٹریک پیڈ](common:keys) دیکھیں۔

## ہر جگہ

| کی | کیا کرتی ہے |
|---|---|
| {{key:Ctrl+Shift+F}} | اسکرین موڈز کے درمیان گھومیں: عام، فل اسکرین، اور بارز چھپی ہوئی فل اسکرین۔ ہر پلیٹ فارم پر Ctrl، Mac پر بھی |
| {{key:Esc}} | فل اسکرین سے باہر نکلیں |
| {{key:Mod+,}} | {{ui:ترتیبات}} کھولیں۔ دیکھیں [BimCraft کی ترتیبات](topic:settings) |
| {{key:Tab}} | بٹنز، چیک باکسز اور ویلیوز کے درمیان حرکت کریں۔ ہر کنٹرول کی بورڈ سے پہنچا جا سکتا ہے |

## 3D ویو (IFC ماڈلز)

| کی یا عمل | کیا کرتا ہے |
|---|---|
| {{key:F}} | پورے ماڈل کو تین چوتھائی ویو میں فٹ کریں (وہی جو {{ui:فٹ}}) |
| {{key:Esc}} | انتخاب صاف کریں، یا رکھنا یا چسپاں کرنا بند کریں |
| کلک | پوائنٹر کے نیچے کا عنصر چنیں؛ خالی پس منظر پر کلک انتخاب صاف کرتا ہے |
| {{key:Mod}}+کلک یا {{key:Shift}}+کلک | ایک عنصر کو انتخاب میں شامل کریں، یا اسے نکال دیں |
| {{key:H}} | منتخب عناصر چھپائیں۔ دیکھیں [elements کو چھپانا، الگ کرنا اور شفاف بنانا](topic:hide-and-isolate) |
| {{key:I}} | صرف منتخب عناصر دکھائیں (الگ کرنا) |
| {{key:T}} | منتخب عناصر دکھائیں، باقی سب شفاف |
| {{key:Shift+H}} | ہر عنصر دوبارہ دکھائیں |
| {{ui:چہل قدمی}} | پھر {{key:W}} {{key:A}} {{key:S}} {{key:D}} یا تیر دبا کر چلیں، {{key:Shift}} سے دوڑیں، ڈریگ سے ادھر ادھر دیکھیں، {{key:Esc}} سے رکیں۔ دیکھیں [ماڈل میں چہل قدمی](topic:walk) |
| {{key:M}} | فاصلے اور چہرے کے رقبے ناپیں۔ دیکھیں [3D میں فاصلے، چہروں کے رقبے اور مقامات ناپنا](topic:measure) |
| بائیں بٹن سے ڈریگ | گھمائیں |
| دائیں بٹن سے ڈریگ | پین |
| {{key:Shift}} یا {{key:Mod}} دباکر بائیں بٹن سے ڈریگ | پین (ٹریک پیڈ پر آسان) |
| ماؤس کا پہیہ گھمائیں، یا درمیانی بٹن سے ڈریگ | زوم |
| ٹریک پیڈ پر دو انگلیوں سے اسکرول یا پنچ | زوم |
| ایک انگلی (ٹچ) | گھمائیں؛ ٹیپ سے چنیں |
| دو انگلیاں (ٹچ) | پنچ سے زوم، ایک ساتھ حرکت سے پین |

| {{key:X}} | سیکشن پلین آن اور آف۔ دیکھیں [IFC ماڈل کو سیکشن پلین سے کاٹنا](topic:section-plane) |
| {{key:Shift+X}} | منتخب عناصر کے گرد سیکشن باکس، کمرے کی ترتیب ترتیبات میں ہے |

{{ui:Top}}، {{ui:Front}} اور {{ui:Side}} کے لیے کوئی کی نہیں ہے؛ بٹن استعمال کریں۔

## ترمیم

یہی کمانڈز ٹول بار میں ہیں: {{ui:کالعدم کریں}}، {{ui:دوبارہ کریں}}، {{ui:نقل کریں}}، {{ui:چسپاں کریں}} اور {{ui:مزید}} مینو، جو ہر کی دکھاتا ہے۔ یہ IFC ماڈل کے 3D ویو میں کام کرتی ہیں، فیلڈ میں ٹائپ کرتے وقت نہیں۔ دیکھیں [لائبریری آئٹمز کی نقل، چسپاں اور ڈپلیکیٹ](topic:copy-paste)۔

| کی | کیا کرتی ہے |
|---|---|
| {{key:Mod+Z}} | آخری تبدیلی کالعدم کریں |
| {{key:Mod+Y}} یا {{key:Mod+Shift+Z}} | وہ دوبارہ کریں جو کالعدم کرنے سے واپس ہوا |
| {{key:Mod+C}} | منتخب عناصر کی نقل کریں (ان کے نام اور پراپرٹیز متن کے طور پر کلپ بورڈ پر بھی جاتے ہیں) |
| {{key:Mod+X}} | منتخب عناصر کاٹیں: پہلے نقل کریں، پھر حذف کریں |
| {{key:Mod+V}} | جو نقل کیا وہ چسپاں کریں: یہ پوائنٹر کے ساتھ چلتا ہے، جہاں جانا ہو وہاں کلک کریں |
| {{key:Mod+Shift+V}} | اسی جگہ چسپاں کریں: جہاں سے کاٹا گیا تھا، یا نقل کے بعد اصل کے ساتھ |
| {{key:Mod+D}} | ڈپلیکیٹ بنائیں: منتخب عناصر کی نقل کریں اور انہیں چسپاں کرنا شروع کریں |
| {{key:Delete}} | منتخب عناصر ان کے حصوں اور کھلے حصوں سمیت حذف کریں۔ دیکھیں [عمارتی عناصر حذف کریں، کاٹیں، نقل کریں اور چسپاں کریں](topic:edit-elements) |
| {{key:Mod+A}} | دکھائی دینے والے ہر عنصر کو منتخب کریں |
| {{key:Esc}} | کچھ بھی منتخب نہ کریں |

جب صفحے پر متن منتخب ہو، تو {{key:Mod+C}} حسبِ معمول وہ متن نقل کرتا ہے۔

## پلان ویو (ڈرا)

یہ اس وقت کام کرتے ہیں جب {{ui:ڈرا}} آن ہو اور آپ کسی فیلڈ میں ٹائپ نہ کر رہے ہوں۔ دیکھیں [دیواریں بنانا](topic:draw-walls) اور [دروازے اور کھڑکیاں](topic:doors-and-windows)۔

| کی یا عمل | کیا کرتا ہے |
|---|---|
| {{key:V}} | {{ui:منتخب کریں}} |
| {{key:W}} | {{ui:دیوار}} |
| {{key:D}} | {{ui:دروازہ}} |
| {{key:N}} | {{ui:کھڑکی}} |
| {{key:H}} | {{ui:دروازہ}} یا {{ui:کھڑکی}} کے ساتھ: کنڈے دوسرے سرے پر |
| دیوار بناتے وقت {{key:Shift}} | اسے 0°، 90°، 180° یا 270° پر رکھیں |
| ہندسے اور فٹ اور انچ کے نشان (`'` اور `"`) | {{ui:لمبائی}} باکس میں لمبائی ٹائپ کرنا شروع کریں؛ {{key:Enter}} اسے استعمال کرتا ہے |
| {{key:Enter}}، {{key:Esc}}، دائیں کلک یا ڈبل کلک | وہ دیوار ختم کریں جو آپ بنا رہے ہیں؛ {{key:Esc}} دوبارہ دبانے پر {{ui:منتخب کریں}} پر واپس جاتا ہے |
| {{key:Delete}} | منتخب دیواریں، دروازے اور کھڑکیاں حذف کریں؛ باقی دیواریں دوبارہ جڑ جاتی ہیں |
| پلان پر پوائنٹر کے ساتھ {{key:F}} | پلان کو فٹ کریں |
| ماؤس کا پہیہ گھمائیں | پوائنٹر کے گرد زوم |
| درمیانی یا دائیں بٹن سے ڈریگ، یا {{key:Space}} دباکر ڈریگ | پین؛ {{ui:منتخب کریں}} آن ہو تو سادہ ڈریگ بھی پین کرتا ہے |
| {{ui:منتخب کریں}} کے ساتھ دروازہ یا کھڑکی ڈریگ کریں | اسے اس کی دیوار کے ساتھ یا کسی اور دیوار پر منتقل کریں |
| دو انگلیاں (ٹچ) | پنچ سے زوم، ایک ساتھ حرکت سے پین |

## لائبریری آئٹمز رکھنا اور چسپاں کرنا

| کی | کیا کرتی ہے |
|---|---|
| {{key:R}} | آئٹم کو 90° گھمائیں |
| {{key:Tab}} | دیوار سے جوڑ آن اور آف: آئٹم کی پشت قریب ترین دیوار سے لگتی ہے |
| **X, Y (mm)** میں {{key:Enter}} | لکھی ہوئی پوزیشن پر رکھیں |
| {{key:Esc}} | رکھنا یا چسپاں کرنا بند کریں |

## IFC ویلیوز میں ترمیم

| کی | کیا کرتی ہے |
|---|---|
| {{key:Enter}} | جو ویلیو لکھی ہے وہ رکھیں |
| {{key:Esc}} | منسوخ کریں اور پرانی ویلیو واپس رکھیں |
| کہیں اور کلک | جو ویلیو لکھی ہے وہ رکھیں |
| {{key:Mod+Z}} | آخری تبدیلی کالعدم کریں۔ صرف اس وقت جب غیر محفوظ تبدیلیاں ہوں اور آپ کسی فیلڈ میں ٹائپ نہ کر رہے ہوں |
| {{key:Mod+Y}} | وہ دوبارہ کریں جو کالعدم کرنے سے واپس ہوا |
| {{key:Mod+S}} | IFC کے طور پر محفوظ کریں۔ صرف اس وقت جب غیر محفوظ تبدیلیاں ہوں؛ ورنہ براؤزر کی اپنی محفوظ کرنے کی کمانڈ کھلتی ہے |

صرف کی بورڈ سے ترمیم کرنے کے لیے: کوئی ویلیو نمایاں ہونے تک {{key:Tab}} دبائیں، پھر ٹائپ شروع کرنے کے لیے {{key:Enter}} دبائیں۔

## 2D ڈرائنگز (DWG اور DXF)

| کی یا عمل | کیا کرتا ہے |
|---|---|
| {{key:F}} | ڈرائنگ یا شیٹ کو فٹ کریں |
| {{key:P}} | پرنٹ ویو آن اور آف |
| ڈبل کلک | فٹ |
| کسی بھی بٹن سے ڈریگ | پین |
| ماؤس کا پہیہ گھمائیں | پوائنٹر پر زوم |
| ٹریک پیڈ پر دو انگلیوں سے اسکرول یا پنچ | پوائنٹر پر زوم۔ دو انگلیوں کا اسکرول پین نہیں کرتا |
| ایک انگلی (ٹچ) | پین۔ ڈرائنگز کے لیے پنچ زوم ابھی تیار نہیں |

## 3D میں ڈرائنگز

| کی یا عمل | کیا کرتا ہے |
|---|---|
| {{key:3}} | 3D آن اور آف (2D ویو پر بھی) |
| {{key:F}} | حدود: پوری ڈرائنگ |
| درمیانی یا بائیں بٹن سے ڈریگ | گھمائیں |
| دائیں بٹن سے ڈریگ، یا {{key:Shift}} دباکر ڈریگ | پین |
| ماؤس کا پہیہ گھمائیں | پوائنٹر کے نیچے کی طرف زوم |
| ٹریک پیڈ پر دو انگلیوں سے سوائپ | گھمائیں؛ {{key:Shift}} کے ساتھ پین |
| ٹریک پیڈ پر پنچ | زوم |
| ایک انگلی (ٹچ) | گھمائیں |
| دو انگلیاں (ٹچ) | پنچ سے زوم، ایک ساتھ حرکت سے پین |

{{key:F}}، {{key:P}} اور {{key:3}} اس وقت کچھ نہیں کرتے جب آپ کسی فیلڈ میں ٹائپ کر رہے ہوں، جب سامان کا شیڈول دکھایا جا رہا ہو، یا جب آپ {{key:Mod}} یا {{key:Alt}} دبائے ہوئے ہوں۔
