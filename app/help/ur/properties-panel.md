## IFC عنصر

{{ui:پراپرٹیز}} پینل کے اوپر عنصر کی قسم دکھائی جاتی ہے، "Ifc" کے سابقے کے بغیر (مثلاً "Door"، "WallStandardCase"، "FurnishingElement")، اور اس کا نام، یا اگر نام نہ ہو تو "بے نام"۔

| فیلڈ | مطلب | قابلِ ترمیم |
|---|---|---|
| Name | عنصر کا نام، اکثر ایکسپورٹر کا دیا ہوا فیملی اور ٹائپ کا نام | ہاں |
| Type | عنصر کی ٹائپ کا نام، جب اس کی ٹائپ ہو | نہیں |
| Object type | آزاد متن میں ٹائپ کی تفصیل، جو کچھ ایکسپورٹرز بھرتے ہیں | ہاں |
| Tag | عنصر کا ٹیگ یا نشان؛ کئی ایکسپورٹرز یہاں عنصر کا ID لکھتے ہیں | ہاں |
| Description | آزاد متن | ہاں |
| GlobalId | عنصر کا مستقل 22 حروف کا IFC شناخت کنندہ، ایک ہی عنصر کی ہر ایکسپورٹ میں یکساں | نہیں |
| Line | اس IFC فائل میں عنصر کا لائن نمبر (`#1234`)۔ یہ ایکسپورٹ کے درمیان بدلتا ہے | نہیں |

اس کے نیچے **پراپرٹی سیٹس** آتے ہیں، نام کے لحاظ سے ترتیب شدہ:

- ہر سیٹ اپنے نام پر کلک کرنے سے کھلتا اور بند ہوتا ہے۔ پہلے تین کھلے ہوتے ہیں۔
- "(type)" نشان والا سیٹ عنصر کی ٹائپ سے تعلق رکھتا ہے: "ٹائپ پراپرٹی: یہاں کی تبدیلی اس ٹائپ کے ہر عنصر پر لاگو ہوتی ہے۔"
- مقداری سیٹس (لمبائیاں، رقبے، حجم، گنتیاں، وزن) صرف پڑھنے کے لیے ہیں۔
- فہرستیں اور enumerated قدریں دکھائی جاتی ہیں، صرف پڑھنے کے لیے۔
- ہاں/نہیں والی قدریں **ہاں** یا **نہیں** کے طور پر دکھتی ہیں۔
- اعداد چار اعشاری ہندسوں تک گول کیے جاتے ہیں۔ لمبائیاں (لمبائی کی پراپرٹی یا مقدار کی لمبائی) ٹول بار پر منتخب {{ui:اکائیاں}} میں دکھائی جاتی ہیں، ساتھ اکائی کے نشان کے، اور آپ اسی اکائی میں یا کسی اور اکائی کے نشان کے ساتھ نیا نمبر لکھ سکتے ہیں (2.4 m، 8'-0")؛ BimCraft فائل کا اپنا نمبر واپس لکھتا ہے۔ دوسرے اعداد فائل میں جیسے ہیں ویسے دکھائے جاتے ہیں۔
- خالی قدر *خالی* دکھائی جاتی ہے۔ ترمیم شدہ قدر بولڈ ہوتی ہے اور اس کے ساتھ نیلی پٹی ہوتی ہے۔

## قدر نقل کریں

{{ui:پراپرٹیز}} میں ہر قدر کے ساتھ ایک چھوٹا نقل کا بٹن ہوتا ہے: اس پر کلک کریں تو وہ قدر بالکل ویسی ہی کلپ بورڈ پر چلی جاتی ہے جیسی دکھتی ہے، مثلاً GlobalId، سیریل نمبر یا کسی بھی پراپرٹی سیٹ کی قدر۔ نقل کرنے سے کبھی ترمیم شروع نہیں ہوتی۔

اوپر، {{ui:سب نقل کریں}} عنصر کی ہر قدر کو سیٹ بہ سیٹ متن کے طور پر نقل کرتا ہے، اور {{ui:CSV کے طور پر نقل کریں}} انہیں گروپ، پراپرٹی اور قدر کی قطاروں کے طور پر نقل کرتا ہے تاکہ اسپریڈشیٹ میں چسپاں کیا جا سکے؛ خالی قدریں رکھی جاتی ہیں تاکہ ہر فیلڈ کی ایک قطار ہو۔ یہ کسی دوسرے کھلے ماڈل کے عنصر کے لیے بھی یکساں کام کرتا ہے؛ جب ایک سے زیادہ ماڈل کھلے ہوں تو CSV کا آغاز ایک Model کالم سے ہوتا ہے جو اس کی فائل کا نام دیتا ہے۔

## File پینل (IFC)

| فیلڈ | مطلب |
|---|---|
| File، Size | وہ فائل جو آپ نے کھولی اور اس کا سائز |
| Schema | IFC ورژن، جیسے IFC2X3 یا IFC4 |
| Project | پروجیکٹ کا نام اور لمبا نام |
| Phase | پروجیکٹ کا مرحلہ، اگر ایکسپورٹر نے لکھا ہو |
| Exported from | ایکسپورٹ کرنے والا پروگرام، فائل ہیڈر سے |
| Author | فائل ہیڈر میں مصنف |
| Exported | فائل ہیڈر میں تاریخ اور وقت |
| Elements | کتنے شکل والے عناصر بنائے گئے |
| Triangles | ان کی شکلوں سے بننے والے ٹرائی اینگلز؛ ماڈل کتنا بھاری ہے، اس کا پیمانہ |

## File پینل (پروجیکٹ اور فیملی فائلیں)

| فیلڈ | مطلب |
|---|---|
| Kind | پروجیکٹ، پروجیکٹ ٹیمپلیٹ، فیملی یا فیملی ٹیمپلیٹ |
| Saved in | وہ ریلیز جس نے فائل آخری بار محفوظ کی |
| Build | اس ریلیز کا عین build |
| Read | فائل کا کتنا حصہ BimCraft نے پڑھا، اس کے سائز میں سے |

## Drawing پینل (DWG اور DXF)

| فیلڈ | مطلب |
|---|---|
| Format | وہ ریلیز جس میں ڈرائنگ محفوظ ہوئی، اس کے فارمیٹ کوڈ کے ساتھ، جیسے AC1032 |
| Units | ڈرائنگ کی insertion units، جب سیٹ ہوں |
| Entities | کتنے آبجیکٹس پڑھے گئے |
| Layers | کتنی لیئرز |
| Sheets | کتنی شیٹس (لے آؤٹس)، یا کوئی نہیں |
| Linked drawings | اس کی کتنی منسلک ڈرائنگز ملیں اور لوڈ ہوئیں |
| Equipment | شیٹس پر کتنے ٹیگ شدہ آلات ہیں |

## Folder پینل

| فیلڈ | مطلب |
|---|---|
| Folder، Files، Size | وہ فولڈر جو آپ نے کھولا، اس میں کتنی فائلیں ہیں اور ان کا کل سائز |
| Models | پروجیکٹ اور فیملی فائلیں، ہر ایک اپنے بیک اپس کے ساتھ ایک بار گنی گئی |
| CAD drawings، IFC models | ہر ایک کتنی ہیں |
| Problems | کتنی ماڈل کاپیاں نامکمل یا ناقابلِ پڑھائی ہیں، یا کوئی نہیں |
