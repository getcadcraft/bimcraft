اگر آپ Revit جانتے ہیں تو BimCraft کا زیادہ تر حصہ الفاظ میں مانوس اور دائرہ کار میں نامانوس لگے گا۔ سب سے اہم فرق یہ ہے: **یہ ورژن ماڈلز پڑھتا اور جانچتا ہے اور IFC ڈیٹا میں ترمیم کرتا ہے۔ یہ ابھی Revit کی طرح تخلیق نہیں کرتا۔** آپ دیواریں نہیں بنا سکتے، فیملیز نہیں رکھ سکتے، ویوز یا شیٹس نہیں بنا سکتے، یا پروجیکٹ فائل محفوظ نہیں کر سکتے۔ آپ جو کر سکتے ہیں وہ یہ ہے کہ کسی بھی کمپیوٹر پر براؤزر کے ساتھ تقریباً کوئی بھی عمارتی فائل کھولیں، اس میں موجود چیزیں دیکھیں، پورے پروجیکٹ فولڈر کی جانچ کریں، اور IFC ماڈل کا ڈیٹا درست کریں۔

## عادات کا نقشہ

| اگر آپ عادی ہیں | BimCraft میں |
|---|---|
| ماڈل دیکھنے کے لیے Revit میں `.rvt` کھولنا | BimCraft `.rvt` کو ایک فائل کارڈ کے طور پر کھولتا ہے: ریلیز، پروجیکٹ کی معلومات، لنکس، پیش منظر۔ 3D ماڈل کے لیے IFC برآمد کریں اور وہ کھولیں۔ [پروجیکٹ یا فیملی فائل پڑھیں](topic:read-rvt-file) |
| کھولنے سے پہلے دیکھنا کہ فائل کس ریلیز میں محفوظ ہوئی تھی | کارڈ کے اوپر "Revit میں محفوظ …" لکھا ہوتا ہے، فائل کو اپ گریڈ کیے یا چھوئے بغیر |
| پروجیکٹ براؤزر | ویوز اور شیٹس کا کوئی براؤزر نہیں۔ IFC ماڈل میں {{ui:منزلیں}} اور {{ui:عناصر}} کی فہرستیں ہوتی ہیں؛ ڈرائنگ میں شیٹ ٹیبز ہوتے ہیں |
| پراپرٹیز پیلیٹ | دائیں طرف {{ui:پراپرٹیز}} پینل، اس عنصر کے لیے جس پر آپ نے کلک کیا۔ پیرامیٹر گروپس کی جگہ IFC پراپرٹی سیٹس |
| انسٹینس اور قسم کے پیرامیٹرز | انسٹینس پراپرٹی سیٹس، اور وہ سیٹس جن پر "(type)" لکھا ہو۔ قسم کی تبدیلی اس قسم کے ہر عنصر پر لاگو ہوتی ہے، جیسے Revit میں۔ [ایک قسم کی پراپرٹی کو اس قسم کے ہر عنصر کے لیے بدلیں](topic:type-vs-instance) |
| Edit Type | کوئی ڈائیلاگ نہیں: کسی "(type)" سیٹ میں قدر پر کلک کریں اور ٹائپ کریں |
| کئی عناصر منتخب کرنا، فلٹرز، Select All Instances | ایک وقت میں ایک عنصر۔ ابھی تیار نہیں |
| ویو کیوب اور نیویگیشن وہیل | نیچے دائیں کونے میں ایک ویو کیوب، چار بٹن ({{ui:فٹ}}، {{ui:اوپر}}، {{ui:سامنے}}، {{ui:سائیڈ}}) اور آزاد گھماؤ۔ کوئی نیویگیشن وہیل نہیں |
| Shift اور درمیانی بٹن گھسیٹ کر گھمانا، درمیانی بٹن گھسیٹ کر پین کرنا | بائیں گھسیٹیں تو گھماتا ہے، دائیں گھسیٹیں (یا {{key:Shift}} اور گھسیٹیں) تو پین کرتا ہے، وہیل زوم کرتا ہے۔ {{ui:BIM ربن}} مینو انداز درمیانی بٹن سے گھسیٹ کر پین کرنے پر جاتا ہے، اور گھمانے کے لیے {{key:Shift}} اور درمیانی بٹن۔ [مینو، کیز اور ماؤس](topic:menus-keys-and-mouse) |
| فلور پلان، سیکشنز، سیکشن باکس | ایک وقت میں ایک {{ui:سیکشن}} پلین ({{key:X}})؛ کوئی سیکشن باکس یا 2D پلان نہیں۔ [سیکشن پلین سے IFC ماڈل کاٹیں](topic:section-plane) |
| ویو میں چھپانا، الگ کرنا، مرئیت / گرافکس | {{ui:منزلیں}} آن اور آف، {{ui:جگہیں}} اور {{ui:کنارے}}۔ ابھی ہر عنصر کو الگ سے چھپانا نہیں ہے |
| کمرے | IFC جگہیں، شروع میں چھپی ہوئی۔ {{ui:جگہیں}} پر کلک کریں |
| محفوظ کریں، بطور محفوظ کریں، سینٹرل کے ساتھ ہم آہنگ کریں | {{ui:IFC کے طور پر محفوظ کریں}} ایک نئی IFC فائل ڈاؤن لوڈ کرتا ہے۔ اصل فائل کبھی نہیں بدلتی۔ کوئی سینٹرل نہیں، کوئی ورک شیئرنگ نہیں |
| {{key:Mod+Z}} سے کالعدم کریں | IFC ترمیمات پر کام کرتا ہے جب تک آپ محفوظ نہ کریں۔ [IFC پراپرٹیز بدلیں اور ترمیم شدہ نقل محفوظ کریں](topic:edit-ifc-properties) |
| لنکس کا انتظام | پروجیکٹ فولڈر کھولیں: ہر لنک جانچا جاتا ہے اور **اس فولڈر میں**، **ہم نام ملا**، **لائبریری فائل** یا **اس فولڈر میں نہیں** نشان زد ہوتا ہے۔ [پورا پروجیکٹ فولڈر کھولیں](topic:open-project-folder) |
| آڈٹ، یا یہ دیکھنے کے لیے فائل کھولنا کہ کہیں خراب تو نہیں | فولڈر رپورٹ ہر نقل اور بیک اپ کو سیکنڈوں میں جانچتی ہے کہ کہیں کٹا ہوا تو نہیں۔ [فولڈر میں خراب نقلیں جانچیں](topic:check-folder-health) |
| بکھرے ہوئے فولڈر سے درست فائل چننا | {{ui:یہاں سے شروع کریں}} باکس وجوہات کے ساتھ ایک فائل تجویز کرتا ہے |

اگر آپ زیادہ تر ماڈلز کو جانچنے کے لیے کھولتے ہیں، جیسے ماڈل جانچنے یا IFC دیکھنے والے پروگرام میں، تو {{ui:ویور}} مینو انداز چنیں: دیکھنے اور جانچنے کے ٹولز پہلے آتے ہیں اور عمارتی ٹولز ایک مینو میں انتظار کرتے ہیں۔ دیکھیں [مینو، کیز اور ماؤس](topic:menus-keys-and-mouse)۔

## DWG فائلیں دیکھنے سے

اگر آپ DWG فائلیں AutoCAD یا DWG ویور میں کھولتے ہیں:

| اگر آپ عادی ہیں | BimCraft میں |
|---|---|
| نیچے ماڈل اور لے آؤٹ ٹیبز | ڈرائنگ کے اوپر ٹیبز: {{ui:ماڈل}} اور ہر شیٹ کے لیے ایک |
| ZOOM Extents، وہیل پر ڈبل کلک | ڈبل کلک، {{key:F}} یا {{ui:فٹ}} |
| درمیانی بٹن سے پین | کسی بھی بٹن سے گھسیٹیں |
| لیئر مینیجر | {{ui:لیئرز}} کی فہرست: دکھانے کے لیے ٹِک کریں، چھپانے کے لیے ٹِک ہٹائیں، {{ui:سب آن}} اور {{ui:سب آف}} |
| Xref مینیجر | دائیں طرف **منسلک ڈرائنگز**، جن پر **دکھایا گیا** یا **نہیں ملا** لکھا ہو، اور {{ui:منسلک ڈرائنگز شامل کریں…}} |
| پلاٹ پیش منظر | {{ui:پرنٹ ویو}} یا {{key:P}}: سفید پر سیاہ، لائن کی موٹائی کے ساتھ۔ یہ پرنٹ نہیں کرتا |
| بلاک اٹریبیوٹس کا ڈیٹا نکالنا | ٹیگ شدہ فوڈ سروس ڈرائنگز کے لیے {{ui:سامان}} ٹیب، {{ui:CSV ڈاؤن لوڈ کریں}} کے ساتھ |
| ناپنا، ڈرا کرنا، ترمیم، بطور محفوظ کریں | BimCraft میں نہیں۔ CadCraft ڈرافٹنگ ایپ ڈرا کرتی ہے اور ترمیم کرتی ہے |

## وہ فرق جو لوگوں کو الجھاتے ہیں

- **یہ براؤزر میں چلتا ہے، اور براؤزر آپ کی فائلوں کے معاملے میں محتاط ہے۔** BimCraft صرف وہ فائلیں اور فولڈرز پڑھ سکتا ہے جو آپ اسے دیتے ہیں، انہیں منتخب کر کے یا گھسیٹ کر۔ یہ خود کوئی فائل نہیں کھول سکتا، اور نہ کسی فائل پر محفوظ کر سکتا ہے۔ ہر محفوظ کرنا ایک ڈاؤن لوڈ ہے۔
- **کچھ اپ لوڈ نہیں ہوتا۔** بعض براؤزرز کے فولڈر ڈائیلاگ میں "اپ لوڈ" کا لفظ براؤزر کا اپنا ہے۔ فائلیں آپ کے کمپیوٹر پر ہی رہتی ہیں۔
- **IFC ماڈل کا فارمیٹ ہے۔** پروجیکٹ فائل کارڈ کے طور پر کھلتی ہے کیونکہ اس کا 3D مواد غیر دستاویزی ہے۔ IFC کو اس طرح سمجھیں جس سے ماڈلز BimCraft تک پہنچتے ہیں۔
- **ترامیم کاپی آن رائٹ ہوتی ہیں۔** کسی ایک عنصر کی قدر بدلنے سے اس کے پڑوسی کبھی نہیں بدلتے، چاہے برآمد کنندہ نے وہ قدر ان کے درمیان مشترک رکھی ہو۔ قسم کی پراپرٹیاں جان بوجھ کر استثنا ہیں۔
- **کوئی پروجیکٹ نہیں، کوئی ویوز نہیں۔** BimCraft ایک وقت میں ایک فائل دکھاتا ہے اور ٹیب بند کرنے کے بعد اس کے بارے میں کچھ یاد نہیں رکھتا، سوائے Chrome اور Edge میں حالیہ فولڈرز کے ناموں کے۔
- **Mac کی کیز۔** جہاں Revit کے ونڈوز شارٹ کٹس Ctrl استعمال کرتے ہیں، وہاں BimCraft کے شارٹ کٹس {{key:Mod}} استعمال کرتے ہیں، جو Mac پر Command کی کلید ہے۔
- **آپ کی ماؤس کی عادات۔** گھمانا بائیں بٹن سے ہوتا ہے، Shift اور درمیانی بٹن سے نہیں، جب تک آپ {{ui:BIM ربن}} مینو انداز نہ چنیں، یا [مینو، کیز اور ماؤس](topic:menus-keys-and-mouse) میں بٹن خود مقرر نہ کریں۔

آج کے لیے متبادل دیکھنے کے لیے [ابھی کیا تیار نہیں ہے](topic:not-built-yet) دیکھیں۔
