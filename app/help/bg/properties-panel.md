## Елемент IFC

Горната част на панела {{ui:Свойства}} показва вида на елемента без префикса „Ifc“ (например „Door“, „WallStandardCase“, „FurnishingElement“) и името му или „Unnamed“.

| Поле | Значение | Редактируемо |
|---|---|---|
| Name | Името на елемента, често името на семейството и типа от експортера | Да |
| Type | Името на типа на елемента, когато има такъв | Не |
| Object type | Описание на типа като свободен текст, което някои експортери попълват | Да |
| Tag | Маркировката или означението на елемента; много експортери записват тук идентификатора на елемента | Да |
| Description | Свободен текст | Да |
| GlobalId | Постоянният 22-символен IFC идентификатор на елемента, същият при всеки експорт на същия елемент | Не |
| Line | Номерът на реда (`#1234`) на елемента в този IFC файл. Той се променя между експортите | Не |

Отдолу идват **наборите от свойства**, подредени по име:

- Всеки набор се отваря и затваря, когато щракнете върху името му. Първите три са отворени.
- Набор, отбелязан с „(type)“, принадлежи на типа на елемента: „Свойство на тип: промяната тук се прилага за всеки елемент от този тип.“
- Наборите с количества (дължини, площи, обеми, броеве, тегла) са само за четене.
- Списъците и изброимите стойности се показват, само за четене.
- Стойностите да/не се показват като **Да** или **Не**.
- Числата се закръгляват до четири десетични знака при показване. Дължините (свойство за дължина или дължина на количество) се показват в {{ui:Мерни единици}}, избрани в лентата с инструменти, с мерната единица до тях. Можете да въведете нова стойност в същата единица или с друга мерна единица (2.4 m, 8'-0"): BimCraft записва обратно собственото число на файла. Други числа се показват такива, каквито са във файла.
- Празна стойност се показва като *празна*. Редактираната стойност е с получер шрифт и синя черта отстрани.

## Копиране на стойност

Всяка стойност в {{ui:Свойства}} има малък бутон за копиране до нея: щракнете върху него, за да поставите стойността в клипборда точно както е показана, например GlobalId, сериен номер или всяка стойност на набор от свойства. Копирането никога не започва редакция.

В горната част {{ui:Копиране на всичко}} копира всяка стойност на елемента като текст, набор по набор, а {{ui:Копиране като CSV}} копира редове с група, свойство и стойност за поставяне в електронна таблица; празните стойности се запазват, така че всяко поле има ред. Това важи и за елемент от друг отворен модел; когато са отворени повече модели, CSV файлът започва с колона „Модел“, която назовава файла му.

## Панелът Файл (IFC)

| Поле | Значение |
|---|---|
| File, Size | Файлът, който сте отворили |
| Schema | Версията на IFC, например IFC2X3 или IFC4 |
| Project | Името и дългото име на проекта |
| Phase | Фазата на проекта, ако експортерът я е записал |
| Exported from | Програмата за експорт, от заглавната част на файла |
| Author | Авторът от заглавната част на файла |
| Exported | Датата и часът от заглавната част на файла |
| Elements | Колко елемента с форма са нарисувани |
| Triangles | Колко триъгълника образуват формите им; мярка за тежестта на модела |

## Панелът Файл (проектни и семейни файлове)

| Поле | Значение |
|---|---|
| Kind | Проект, Шаблон на проект, Семейство или Шаблон на семейство |
| Saved in | Версията, която последно е запазила файла |
| Build | Точната компилация на тази версия |
| Read | Колко от файла е прочел BimCraft, спрямо размера му |

## Панелът Чертеж (DWG и DXF)

| Поле | Значение |
|---|---|
| Format | Версията, в която е запазен чертежът, с кода на формата, например AC1032 |
| Units | Мерните единици на вмъкване на чертежа, когато са зададени |
| Entities | Колко обекта са прочетени |
| Layers | Колко слоя има |
| Sheets | Колко листа (layouts) или Няма |
| Linked drawings | Колко от свързаните му чертежи са намерени и заредени |
| Equipment | Колко маркирани елемента от оборудване има на листове |

## Панелът Папка

| Поле | Значение |
|---|---|
| Folder, Files, Size | Папката, която сте отворили, колко файла съдържа и общият им размер |
| Models | Проектни и семейни файлове, като резервните копия се броят по веднъж |
| CAD drawings, IFC models | Колко има от всеки вид |
| Problems | Колко копия на модели са непълни или нечетими, или Няма |
