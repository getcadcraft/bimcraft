BimCraft чытае вашы файлы ўнутры ўкладкі браўзера. Адкрыццё, праглядванне, рэдагаванне і захаванне ніколі не адпраўляюць вашы файлы нікуды — ні ў сетцы, ні па-за ёю. [Праца па-за сеткай](common:offline) тлумачыць, як працуюць копіі для працы па-за сеткай ва ўсіх праграмах; гэтая старонка апісвае тое, што ўласціва BimCraft.

## Што BimCraft загружае з сайта

| Частка | Калі загружаецца без копіі для працы па-за сеткай | Памер |
|---|---|---|
| Сама праграма, з 3D-прагляднікам і кодам рухавіка IFC | Пры адкрыцці BimCraft | Некалькі мегабайтаў |
| WebAssembly-частка рухавіка IFC | Першы файл IFC, які вы адкрываеце ў ўкладцы: «Запуск рухавіка IFC…» | Каля 1.6 MB |

Чарцяжы DWG і DXF, файлы праектаў і сямействаў і папкі нічога дадатковага не патрабуюць: іх чытачы з'яўляюцца часткай праграмы.

## Захаваць BimCraft для працы па-за сеткай

1. Адкрыйце BimCraft, калі вы ў сетцы.
2. Націсніце {{ui:Захаваць для працы па-за сеткай}} у верхняй панэлі праграмы.
3. Сачыце, як кнопка лічыць: «Захаванне 40 з 212», напрыклад. Копія BimCraft важыць каля 11 MB, бо ўключае рухавік IFC.
4. Пачакайце, пакуль з'явіцца {{ui:Гатова для працы па-за сеткай}}.

Калі з'явіцца {{ui:Гатова для працы па-за сеткай}}, мадэлі IFC, чарцяжы DWG і DXF, файлы праектаў, папкі і гэтая даведка адчыняюцца без злучэння. Не трэба спачатку адкрываць IFC або DWG, каб «разагрэць» чытачы.

Каб абнавіць або выдаліць копію, націсніце {{ui:Гатова для працы па-за сеткай}} і абярыце {{ui:Захаваць зноў (атрымаць апошнюю версію)}} або {{ui:Выдаліць копію для працы па-за сеткай}}.

## Што азначае кнопка

| Кнопка | Азначае |
|---|---|
| {{ui:Захаваць для працы па-за сеткай}} | Копіі ў гэтым браўзеры пакуль няма. Націсніце, каб захаваць |
| «Захаванне *n* з *m*» | Захаванне; трымайце ўкладку адкрытай, пакуль яно не скончыцца |
| {{ui:Гатова для працы па-за сеткай}} | Захавана. Навядзіце, каб убачыць, калі; націсніце для меню |
| {{ui:Не ўдалося захаваць}} | Частка файлаў не загрузілася. Праверце злучэнне і націсніце, каб паўтарыць. Апошняя добрая копія, калі яна ёсць, захоўваецца |
| {{ui:Праца па-за сеткай недаступна}} | Гэта акно не можа захоўваць копію для працы па-за сеткай (прыватнае акно або кіраваны кампутар). Гл. [Праца па-за сеткай](common:offline) |

:::offline
Вы па-за сеткай.

- Калі кнопка кажа {{ui:Гатова для працы па-за сеткай}}, кожны від файла адкрываецца як звычайна.
- Калі не кажа, працуе толькі тое, што ўкладка ўжо загрузіла: чытач, які ніколі не загружаўся ў гэтай ўкладцы, не запусціцца, і адкрыццё такога файла паказвае памылку браўзера ў радку стану. Не перазагружайце ўкладку, пакуль не будзеце ў сетцы.
:::

## Што ніколі не патрабуе злучэння

Калі BimCraft ужо адкрыты ў ўкладцы, гэтыя дзеянні працуюць па-за сеткай нават без захаванай копіі:

- Чытанне файлаў праектаў і сямействаў і праверка папак.
- Выбар элементаў, чытанне ўласцівасцяў і рэдагаванне значэнняў IFC ў адкрытай мадэлі.
- {{ui:Захаваць як IFC}} і {{ui:Спампаваць CSV}}: абодва — спампоўкі, зробленыя ў ўкладцы.

## Што пакуль недаступна

- **Захаванне ў воблаку.** Файлы захоўваюцца толькі на вашым кампутары.

Гл. [Куды ідуць вашы файлы](common:your-files).
