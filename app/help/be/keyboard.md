У BimCraft мала спалучэнняў клавіш. Большую частку работы выконваеце мышшу і панэлямі. Спалучэнні, пазначаныя з {{key:Mod}}, выкарыстоўваюць Command на Mac і Ctrl у астатніх асяроддзях. Гл. [Клавішы, мышы і трэкпады](common:keys), як клавішы запісаны ў гэтай даведцы.

## Усюды

| Клавіша | Што робіць |
|---|---|
| {{key:Ctrl+Shift+F}} | Пераключае рэжымы экрана: звычайны, поўнаэкранны, поўнаэкранны са схаванымі панэлямі. Ctrl на любой платформе, у тым ліку на Mac |
| {{key:Esc}} | Выйсці з поўнаэкраннага рэжыму |
| {{key:Mod+,}} | Адкрыць {{ui:Налады}}. Гл. [Налады BimCraft](topic:settings) |
| {{key:Tab}} | Пераход паміж кнопкамі, сцяжкамі і значэннямі. Да кожнага элемента кіравання можна дайсці з клавіятуры |

## 3D-выгляд (мадэлі IFC)

| Клавіша або дзеянне | Што робіць |
|---|---|
| {{key:F}} | Умясціць усю мадэль, тры чвэрці выгляду (тое самае, што {{ui:Умясціць}}) |
| {{key:Esc}} | Зняць выбар або спыніць размяшчэнне ці ўстаўку |
| Клік | Выбраць элемент пад покажчыкам; клік па пустым фоне зымае выбар |
| {{key:Mod}}+клік або {{key:Shift}}+клік | Дадаць элемент у выбар або выняць яго |
| {{key:H}} | Схаваць выбраныя элементы. Гл. [Схаванне, ізаляцыя і прасвечванне элементаў](topic:hide-and-isolate) |
| {{key:I}} | Паказаць толькі выбраныя элементы (ізаляцыя) |
| {{key:T}} | Паказаць выбраныя элементы, усё астатняе — прасвечанае |
| {{key:Shift+H}} | Паказаць усе элементы зноў |
| {{ui:Прайсці}} | Потым {{key:W}} {{key:A}} {{key:S}} {{key:D}} або стрэлкі — ход; {{key:Shift}} — бег, перацягванне паварочвае погляд, {{key:Esc}} спыняе. Гл. [Ход па мадэлі](topic:walk) |
| {{key:M}} | Вымярэнне адлегласцей і плошчаў граняў. Гл. [Вымярэнне адлегласцей, плошчаў граняў і месцазнаходжанняў у 3D](topic:measure) |
| Перацягванне левай кнопкай | Арбіта |
| Перацягванне правай кнопкай | Панарамаванне |
| {{key:Shift}} або {{key:Mod}} і перацягванне левай кнопкай | Панарамаванне (зручна на трэкпадзе) |
| Прагортка колца або перацягванне сярэдняй кнопкай | Маштаб |
| Двухпальцавая прагортка або сціск на трэкпадзе | Маштаб |
| Адзін палец (сэнсар) | Арбіта; націсканне выбірае |
| Два пальцы (сэнсар) | Сціск для маштабу, рух разам — панарамаванне |

| {{key:X}} | Плоскасць разрэзу ўключаецца і выключаецца. Гл. [Разрэз мадэлі IFC плоскасцю разрэзу](topic:section-plane) |
| {{key:Shift+X}} | Скрынка разрэзу вакол выбраных элементаў з памяшканнем, наладжаным у Наладах |

Для {{ui:Верх}}, {{ui:Спераду}} і {{ui:Збоку}} клавіш няма; выкарыстоўвайце кнопкі.

## Рэдагаванне

Тыя ж каманды ёсць на панэлі інструментаў: {{ui:Адрабіць}}, {{ui:Паўтарыць}}, {{ui:Скапіяваць}}, {{ui:Уставіць}} і меню {{ui:Больш}}, якое паказвае кожную клавішу. Яны працуюць у 3D-выглядзе мадэлі IFC, а не калі вы набіраеце ў полі. Гл. [Капіяванне, уставка і дубліраванне элементаў бібліятэкі](topic:copy-paste).

| Клавіша | Што робіць |
|---|---|
| {{key:Mod+Z}} | Адрабіць апошнюю змену |
| {{key:Mod+Y}} або {{key:Mod+Shift+Z}} | Паўтарыць тое, што адмяніла Адрабіць |
| {{key:Mod+C}} | Скапіяваць выбраныя элементы (іх назвы і ўласцівасці таксама трапляюць у буфер абмену як тэкст) |
| {{key:Mod+X}} | Выразаць выбраныя элементы: скапіяваць іх, потым выдаліць |
| {{key:Mod+V}} | Уставіць тое, што вы скапіявалі: яно рухаецца за покажчыкам, націсніце, дзе яно павінна быць |
| {{key:Mod+Shift+V}} | Уставіць на месца: туды, адкуль выразалі, або побач з арыгіналамі пасля капіявання |
| {{key:Mod+D}} | Дубляваць: скапіяваць выбраныя элементы і пачаць іх уставаць |
| {{key:Delete}} | Выдаліць выбраныя элементы разам з іх часткамі і праёмамі. Гл. [Выдаленне, выразанне, капіраванне і ўстаўка будаўнічых элементаў](topic:edit-elements) |
| {{key:Mod+A}} | Выбраць усе паказаныя элементы |
| {{key:Esc}} | Не выбраць нічога |

Калі на старонцы выбраны тэкст, {{key:Mod+C}} капіюе гэты тэкст, як звычайна.

## Выгляд плана (Малаванне)

Гэтыя дзеянні працуюць, калі ўключана {{ui:Малаванне}} і вы не набіраеце ў полі. Гл. [Малаванне сцен](topic:draw-walls) і [Дзверы і вокны](topic:doors-and-windows).

| Клавіша або дзеянне | Што робіць |
|---|---|
| {{key:V}} | {{ui:Выбраць}} |
| {{key:W}} | {{ui:Сцяна}} |
| {{key:D}} | {{ui:Дзверы}} |
| {{key:N}} | {{ui:Акно}} |
| {{key:H}} | З {{ui:Дзверы}} або {{ui:Акно}}: завесы з другога боку |
| {{key:Shift}} падчас малявання сцяны | Трымае яе пад вуглом 0°, 90°, 180° або 270° |
| Лічбы і знакі футаў і цаляў (`'` і `"`) | Пачынаеце набіраць даўжыню ў полі {{ui:Даўжыня}}; {{key:Enter}} яе прымяняе |
| {{key:Enter}}, {{key:Esc}}, правая кнопка або двайны клік | Завяршае сцяну, якую малюеце; {{key:Esc}} яшчэ раз вяртае да {{ui:Выбраць}} |
| {{key:Delete}} | Выдаляе выбраныя сцены, дзверы і вокны; астатнія сцены зноў злучаюцца |
| {{key:F}} з покажчыкам над планам | Умясціць план |
| Прагортка колца | Маштаб вакол покажчыка |
| Перацягванне сярэдняй або правай кнопкай, або {{key:Space}} і перацягванне | Панарамаванне; з уключаным {{ui:Выбраць}} звычайнае перацягванне таксама панарамуе |
| Перацягванне дзвярэй або вокна з {{ui:Выбраць}} | Перамяшчае іх уздоўж сцяны або на іншую сцяну |
| Два пальцы (сэнсар) | Сціск для маштабу, рух разам — панарамаванне |

## Размяшчэнне і ўстаўка элементаў бібліятэкі

| Клавіша | Што робіць |
|---|---|
| {{key:R}} | Павярнуць элемент на 90° |
| {{key:Tab}} | Прывязка да сцен уключана і выключана: тыльны бок элемента прылягае да бліжэйшай сцяны |
| {{key:Enter}} у **X, Y (mm)** | Размясціць у набраным становішчы |
| {{key:Esc}} | Спыніць размяшчэнне або ўстаўку |

## Рэдагаванне значэнняў IFC

| Клавіша | Што робіць |
|---|---|
| {{key:Enter}} | Захаваць набранае значэнне |
| {{key:Esc}} | Адмяніць і вярнуць старое значэнне |
| Клік у іншым месцы | Захаваць набранае значэнне |
| {{key:Mod+Z}} | Адрабіць апошнюю змену. Толькі пакуль ёсць незахаваныя змены і вы не набіраеце ў полі |
| {{key:Mod+Y}} | Паўтарыць тое, што адмяніла {{ui:Адрабіць}} |
| {{key:Mod+S}} | Захаваць як IFC. Толькі пры незахаваных змянях; інакш адкрываецца звычайная каманда захавання браўзера |

Каб рэдагаваць толькі з клавіятуры: націскайце {{key:Tab}}, пакуль значэнне не будзе вылучана, потым націсніце {{key:Enter}}, каб пачаць набіраць.

## 2D-чарцяжы (DWG і DXF)

| Клавіша або дзеянне | Што робіць |
|---|---|
| {{key:F}} | Умясціць чарцёж або аркуш |
| {{key:P}} | Выгляд для друку ўключаны і выключаны |
| Двайны клік | Умясціць |
| Перацягванне любой кнопкай | Панарамаванне |
| Прагортка колца | Маштаб па покажчыку |
| Двухпальцавая прагортка або сціск на трэкпадзе | Маштаб па покажчыку. Двухпальцавая прагортка не панарамуе |
| Адзін палец (сэнсар) | Панарамаванне. Сціск для маштабу для чарцяжоў яшчэ не зроблены |

## Чарцяжы ў 3D

| Клавіша або дзеянне | Што робіць |
|---|---|
| {{key:3}} | 3D уключана і выключана (таксама на 2D-выглядзе) |
| {{key:F}} | Ахоп: увесь чарцёж |
| Перацягванне сярэдняй або левай кнопкай | Арбіта |
| Перацягванне правай кнопкай або {{key:Shift}} і перацягванне | Панарамаванне |
| Прагортка колца | Маштаб да таго, што пад покажчыкам |
| Двухпальцавае перацягванне на трэкпадзе | Арбіта; з {{key:Shift}} — панарамаванне |
| Сціск на трэкпадзе | Маштаб |
| Адзін палец (сэнсар) | Арбіта |
| Два пальцы (сэнсар) | Сціск для маштабу, рух разам — панарамаванне |

{{key:F}}, {{key:P}} і {{key:3}} не працуюць, пакуль вы набіраеце ў полі, пакуль паказана спецыфікацыя абсталявання, або калі ўтрымліваеце {{key:Mod}} ці {{key:Alt}}.
