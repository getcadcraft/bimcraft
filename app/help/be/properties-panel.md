## Элемент IFC

У верхняй частцы панэлі {{ui:Properties}} паказаны від элемента без прыстаўкі «Ifc» (напрыклад, «Door», «WallStandardCase», «FurnishingElement») і яго назва або «Без назвы».

| Поле | Значэнне | Можна рэдагаваць |
|---|---|---|
| Name | Назва элемента, часта назва сямейства і тыпу з экспарту | Так |
| Type | Назва тыпу элемента, калі ён ёсць | Не |
| Object type | Вольнае апісанне тыпу, якое запаўняюць некаторыя экспарты | Так |
| Tag | Тэг або пазнака элемента; многія экспарты пішуць сюды ID элемента | Так |
| Description | Вольны тэкст | Так |
| GlobalId | Пастаянны 22-знакавы ідэнтыфікатар IFC элемента, аднолькавы ў кожным экспарце таго самага элемента | Не |
| Line | Нумар радка элемента (`#1234`) у гэтым файле IFC. Ён мяняецца паміж экспартамі | Не |

Ніжэй ідуць **наборы ўласцівасцей**, сартаваныя па назве:

- Кожны набор разгортваецца і згортваецца пры націску на яго назву. Першыя тры адкрытыя.
- Набор з пазнакай «(type)» належыць тыпу элемента: «Уласцівасць тыпу: змена тут ужываецца да кожнага элемента гэтага тыпу».
- Наборы колькасцей (даўжыні, плошчы, аб’ёмы, падлікі, вагі) толькі для чытання.
- Спісы і пералічэнні паказваюцца толькі для чытання.
- Значэнні «Yes/No» паказваюцца як **Так** або **Не**.
- Лікі акругляюцца да чатырох знакаў пасля коскі для паказу. Даўжыні (уласцівасць даўжыні або даўжыня колькасці) паказваюцца ў {{ui:Units}}, выбраных на панэлі інструментаў, з адзінкай побач. Вы можаце ўвесці новае значэнне ў гэтай адзінцы або з іншым абазначэннем адзінкі (2.4 m, 8'-0"): BimCraft запісвае лік файла назад. Іншыя лікі паказваюцца так, як іх мае файл.
- Пустое значэнне паказваецца як *пуста*. Змененае значэнне выдзелена тлустым шрыфтам і мае сіняю паласу побач.

## Скапіяваць значэнне

Кожнае значэнне ў {{ui:Properties}} мае малую кнопку капіявання побач: націсніце яе, каб змясціць гэта значэнне ў буфер абмену дакладна ў тым выглядзе, у якім яно паказана, напрыклад GlobalId, серыйны нумар або любое значэнне набору ўласцівасцей. Капіяванне ніколі не пачынае рэдагаванне.

Уверсе {{ui:Copy all}} капіюе ўсе значэнні элемента як тэкст, набор за наборам, а {{ui:Copy as CSV}} капіюе іх як радкі «група, уласцівасць, значэнне» для ўстаўкі ў электронную табліцу. Пустыя значэнні захоўваюцца, каб кожнае поле мела радок. Тое самае працуе для элемента іншай адкрытай мадэлі. Калі адкрыта некалькі мадэляў, CSV пачынаецца са слупка {{ui:Model}} з назвай файла.

## Панэль File (IFC)

| Поле | Значэнне |
|---|---|
| File, Size | Файл, які вы адкрылі, і яго памер |
| Schema | Версія IFC, напрыклад IFC2X3 або IFC4 |
| Project | Назва праекта і яго поўная назва |
| Phase | Стадыя праекта, калі экспарт яе запісаў |
| Exported from | Праграма экспарту з загалоўка файла |
| Author | Аўтар у загалоўку файла |
| Exported | Дата і час у загалоўку файла |
| Elements | Колькі элементаў з формай было намалявана |
| Triangles | На колькі трохвугольнікаў раскладаюцца іх формы; мера таго, наколькі мадэль цяжкая |

## Панэль File (файлы праекта і сямейства)

| Поле | Значэнне |
|---|---|
| Kind | Праект, Шаблон праекта, Сямейства або Шаблон сямейства |
| Saved in | Выпуск, які захаваў файл апошнім |
| Build | Дакладная зборка гэтага выпуску |
| Read | Колькі файла BimCraft прачытаў з яго агульнага памеру |

## Панэль Drawing (DWG і DXF)

| Поле | Значэнне |
|---|---|
| Format | Выпуск, у якім захаваны чарцёж, з кодам фармату, напрыклад AC1032 |
| Units | Адзінкі ўстаўкі чарцяжа, калі яны зададзены |
| Entities | Колькі аб’ектаў было прачытана |
| Layers | Колькі пластоў |
| Sheets | Колькі аркушаў (макетаў) або None |
| Linked drawings | Колькі звязаных чарцяжоў было знойдзена і загружана |
| Equipment | Колькі пазначаных адзінак абсталявання ёсць на аркушах |

## Панэль Folder

| Поле | Значэнне |
|---|---|
| Folder, Files, Size | Папка, якую вы адкрылі, колькі файлаў у ёй і іх агульны памер |
| Models | Файлы праекта і сямейства, кожны з рэзервовымі копіямі, палічанымі адзін раз |
| CAD drawings, IFC models | Колькі кожнага |
| Problems | Колькі копій мадэляў няпоўныя або не чытаюцца, або None |
