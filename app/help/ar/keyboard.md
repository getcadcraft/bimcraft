BimCraft فيه اختصارات قليلة. معظم العمل يُنجَز بالفأرة واللوحات. تعني الاختصارات المكتوبة بـ {{key:Mod}} استخدام Command على Mac، وCtrl في غيره. انظر [المفاتيح والفأرات ولوحات اللمس](common:keys) لمعرفة كيفية كتابة المفاتيح في هذه المساعدة.

## في كل مكان

| المفتاح | ما يفعله |
|---|---|
| {{key:Ctrl+Shift+F}} | التنقل بين أوضاع الشاشة: عادي، ملء الشاشة، ملء الشاشة مع إخفاء الأشرطة. Ctrl على كل المنصات، بما فيها Mac |
| {{key:Esc}} | الخروج من ملء الشاشة |
| {{key:Mod+,}} | فتح {{ui:الإعدادات}}. انظر [إعدادات BimCraft](topic:settings) |
| {{key:Tab}} | الانتقال بين الأزرار ومربعات الاختيار والقيم. يمكن الوصول إلى كل عنصر تحكّم من لوحة المفاتيح |

## عرض ثلاثي الأبعاد (نماذج IFC)

| المفتاح أو الإجراء | ما يفعله |
|---|---|
| {{key:F}} | ملاءمة النموذج كله، بمنظر ثلاثة أرباع (كالزر {{ui:ملاءمة}}) |
| {{key:Esc}} | إلغاء التحديد، أو إيقاف الإدراج أو اللصق |
| نقرة | تحديد العنصر تحت المؤشر؛ انقر الخلفية الفارغة لإلغاء التحديد |
| {{key:Mod}}+نقرة أو {{key:Shift}}+نقرة | إضافة عنصر إلى التحديد أو إخراجه منه |
| {{key:H}} | إخفاء العناصر المحددة. انظر [إخفاء العناصر وعزلها وجعلها شفافة](topic:hide-and-isolate) |
| {{key:I}} | إظهار العناصر المحددة فقط (العزل) |
| {{key:T}} | إظهار العناصر المحددة، وجعل كل ما عداها شفافًا |
| {{key:Shift+H}} | إظهار كل العناصر من جديد |
| {{ui:مشي}} | ثم {{key:W}} {{key:A}} {{key:S}} {{key:D}} أو الأسهم للمشي، و{{key:Shift}} للجري، والسحب للنظر حولك، و{{key:Esc}} للتوقف. انظر [المشي داخل النموذج](topic:walk) |
| {{key:M}} | قياس المسافات ومساحات الأوجه. انظر [قياس المسافات ومساحات الأوجه والمواقع في ثلاثي الأبعاد](topic:measure) |
| السحب بالزر الأيسر | المدار |
| السحب بالزر الأيمن | التحريك |
| {{key:Shift}} أو {{key:Mod}} مع السحب بالزر الأيسر | التحريك (مفيد على لوحة اللمس) |
| تمرير عجلة الفأرة، أو السحب بالزر الأوسط | التكبير |
| تمرير بإصبعين أو قرص على لوحة اللمس | التكبير |
| إصبع واحد (لمس) | المدار؛ النقرة تحدد |
| إصبعان (لمس) | قرص للتكبير، وتحريك الإصبعين معًا للتحريك |

| {{key:X}} | تشغيل مستوى المقطع وإيقافه. انظر [قطع نموذج IFC بمستوى مقطع](topic:section-plane) |
| {{key:Shift+X}} | صندوق المقطع حول العناصر المحددة، مع الغرفة المضبوطة في الإعدادات |

لا توجد اختصارات للمناظر {{ui:علوي}} و{{ui:أمامي}} و{{ui:جانبي}}؛ استخدم الأزرار.

## التحرير

الأوامر نفسها موجودة في شريط الأدوات: {{ui:تراجع}}، و{{ui:إعادة}}، و{{ui:نسخ}}، و{{ui:لصق}}، وقائمة {{ui:المزيد}} التي تعرض كل مفتاح. وتعمل في العرض ثلاثي الأبعاد لنموذج IFC، لا أثناء كتابتك في حقل. انظر [نسخ عناصر المكتبة ولصقها وتكرارها](topic:copy-paste).

| المفتاح | ما يفعله |
|---|---|
| {{key:Mod+Z}} | التراجع عن آخر تغيير |
| {{key:Mod+Y}} أو {{key:Mod+Shift+Z}} | إعادة ما سحبه التراجع |
| {{key:Mod+C}} | نسخ العناصر المحددة (وتُرسل أسماؤها وخصائصها كنص إلى الحافظة أيضًا) |
| {{key:Mod+X}} | قص العناصر المحددة: نسخها ثم حذفها |
| {{key:Mod+V}} | لصق ما نسخته: يتبع المؤشر، فانقر حيث تريده |
| {{key:Mod+Shift+V}} | اللصق في المكان نفسه: حيث جاء القص، أو بجانب الأصول بعد النسخ |
| {{key:Mod+D}} | تكرار: نسخ العناصر المحددة وبدء لصقها |
| {{key:Delete}} | حذف العناصر المحددة مع أجزائها وفتحاتها. انظر [حذف عناصر البناء وقصها ونسخها ولصقها](topic:edit-elements) |
| {{key:Mod+A}} | تحديد كل العناصر المعروضة |
| {{key:Esc}} | إلغاء كل التحديد |

عندما يكون النص محددًا في الصفحة، ينسخ {{key:Mod+C}} ذلك النص كالمعتاد.

## المسقط (رسم)

تعمل هذه الاختصارات عندما يكون {{ui:رسم}} مفعّلًا، وأنت لا تكتب في حقل. انظر [رسم الجدران](topic:draw-walls) و[الأبواب والنوافذ](topic:doors-and-windows).

| المفتاح أو الإجراء | ما يفعله |
|---|---|
| {{key:V}} | {{ui:تحديد}} |
| {{key:W}} | {{ui:جدار}} |
| {{key:D}} | {{ui:باب}} |
| {{key:N}} | {{ui:نافذة}} |
| {{key:H}} | مع {{ui:باب}} أو {{ui:نافذة}}: المفصلات في الطرف الآخر |
| {{key:Shift}} أثناء رسم جدار | إبقاؤه عند 0° أو 90° أو 180° أو 270° |
| الأرقام وعلامتا القدم والبوصة (`'` و`"`) | البدء بكتابة طول في مربع {{ui:الطول}}؛ ويستخدمه {{key:Enter}} |
| {{key:Enter}} أو {{key:Esc}} أو النقر بالزر الأيمن أو النقر المزدوج | إنهاء الجدار الذي ترسمه؛ و{{key:Esc}} مرة أخرى يعود إلى {{ui:تحديد}} |
| {{key:Delete}} | حذف الجدران والأبواب والنوافذ المحددة؛ وتتصل الجدران المتبقية من جديد |
| {{key:F}} والمؤشر فوق المسقط | ملاءمة المسقط |
| تمرير عجلة الفأرة | التكبير حول المؤشر |
| السحب بالزر الأوسط أو الأيمن، أو {{key:Space}} مع السحب | التحريك؛ ومع تفعيل {{ui:تحديد}} يحرّك السحب العادي أيضًا |
| سحب باب أو نافذة مع {{ui:تحديد}} | تحريكها على طول جدارها، أو إلى جدار آخر |
| إصبعان (لمس) | قرص للتكبير، وتحريك الإصبعين معًا للتحريك |

## وضع عناصر المكتبة ولصقها

| المفتاح | ما يفعله |
|---|---|
| {{key:R}} | تدوير العنصر 90° |
| {{key:Tab}} | تفعيل الالتصاق بالجدار وإلغاؤه: يلتصق ظهر العنصر بأقرب جدار |
| {{key:Enter}} في **X, Y (mm)** | الوضع عند الموضع المكتوب |
| {{key:Esc}} | إيقاف الوضع أو اللصق |

## تحرير قيم IFC

| المفتاح | ما يفعله |
|---|---|
| {{key:Enter}} | الاحتفاظ بالقيمة التي كتبتها |
| {{key:Esc}} | الإلغاء وإعادة القيمة القديمة |
| النقر في مكان آخر | الاحتفاظ بالقيمة التي كتبتها |
| {{key:Mod+Z}} | التراجع عن آخر تغيير. فقط عندما تكون لديك تغييرات غير محفوظة ولا تكتب في حقل |
| {{key:Mod+Y}} | إعادة ما سحبه التراجع |
| {{key:Mod+S}} | الحفظ بصيغة IFC. فقط عندما تكون لديك تغييرات غير محفوظة؛ وإلا يفتح أمر الحفظ الخاص بالمتصفح |

للتحرير بلوحة المفاتيح وحدها: اضغط {{key:Tab}} حتى تُبرز قيمة، ثم اضغط {{key:Enter}} لبدء الكتابة.

## الرسومات ثنائية الأبعاد (DWG وDXF)

| المفتاح أو الإجراء | ما يفعله |
|---|---|
| {{key:F}} | ملاءمة الرسم أو الورقة |
| {{key:P}} | تشغيل منظر الطباعة وإيقافه |
| النقر المزدوج | ملاءمة |
| السحب بأي زر | التحريك |
| تمرير عجلة الفأرة | التكبير عند المؤشر |
| تمرير بإصبعين أو قرص على لوحة اللمس | التكبير عند المؤشر. التمرير بإصبعين لا يحرّك |
| إصبع واحد (لمس) | التحريك. التكبير بالقرص للرسومات لم يُبنَ بعد |

## الرسومات في ثلاثي الأبعاد

| المفتاح أو الإجراء | ما يفعله |
|---|---|
| {{key:3}} | تشغيل العرض ثلاثي الأبعاد وإيقافه (وأيضًا في المنظر ثنائي الأبعاد) |
| {{key:F}} | الامتدادات: الرسم كله |
| السحب بالزر الأوسط أو الأيسر | المدار |
| السحب بالزر الأيمن، أو {{key:Shift}} مع السحب | التحريك |
| تمرير عجلة الفأرة | التكبير نحو ما تحت المؤشر |
| تمرير بإصبعين على لوحة اللمس | المدار؛ ومع {{key:Shift}} التحريك |
| قرص على لوحة اللمس | التكبير |
| إصبع واحد (لمس) | المدار |
| إصبعان (لمس) | قرص للتكبير، وتحريك الإصبعين معًا للتحريك |

لا تعمل {{key:F}} و{{key:P}} و{{key:3}} أثناء كتابتك في حقل، أو عند عرض جدول المعدات، أو عند الضغط على {{key:Mod}} أو {{key:Alt}}.
