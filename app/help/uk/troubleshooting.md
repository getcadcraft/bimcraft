Повідомлення з'являються в рядку стану внизу сцени, червоним, коли щось не вдалося. Знайдіть повідомлення нижче.

## Відкриття файлів

**"*name* is not an IFC, RVT, RFA, DWG or DXF file."**
«*name* не є файлом IFC, RVT, RFA, DWG або DXF.»
BimCraft не розпізнав файл. Перевірте розширення і те, що файл не порожній. PDF, зображення і файли офісних програм не відкриваються.

**".ifczip is not supported yet. Save or export the model as a plain .ifc file."** (also for `.ifcxml`)
«.ifczip ще не підтримується. Збережіть або експортуйте модель як звичайний файл .ifc.» (також для `.ifcxml`)
Розпакуйте `.ifczip` (це звичайний архів zip, що містить `.ifc`) або експортуйте звичайний IFC.

**"… is a project file BimCraft does not read yet."**
«… є файлом проєкту, який BimCraft ще не читає.»
Файл `.pln`, `.pla`, `.tpl` або `.bpn`. Експортуйте з нього IFC або DWG і відкрийте його: див. [Відкриття файлів проєктів .pln і .pla](topic:pln-project-files).

**"This IFC file could not be read."**
«Цей файл IFC не вдалося прочитати.»
Файл IFC пошкоджено або це насправді не IFC. Відкрийте його в текстовому редакторі: справжній файл IFC починається з `ISO-10303-21;`. Експортуйте його знову.

**"This file is incomplete: it is … MB, but its own index points to data at least … MB in. …"**
«Файл неповний: його розмір … MB, але його власний індекс вказує на дані щонайменше до … MB. …»
Файл проєкту або сімейства обрізано під час копіювання, завантаження або синхронізації. Файл у хмарному диску, що є «лише онлайн», виглядає так само. Файл, відкритий окремо, все одно відкривається, з цим повідомленням угорі картки і «Показано відновлене; скопіюйте оригінал знову для повної моделі.»: картка показує лише частини, кожен байт яких є у файлі, а решту перелічує в розділі **Немає у файлі**. Зробіть файл доступним офлайн у вашому хмарному диску або скопіюйте оригінал знову і відкрийте його. У папці BimCraft натомість показує найновішу повну резервну копію.

**"… The file's own list of contents is in the missing part too, so nothing in it can be opened."**
«… Список вмісту файлу теж у втраченій частині, тож нічого в ньому не можна відкрити.»
Файл обрізано так рано, що навіть його списку вмісту немає. З цієї копії нічого не можна відновити. Скопіюйте оригінал знову і відкрийте його.

**"This compound file has no BasicFileInfo stream, so it is not a Revit file."**
«Цей складений файл не має потоку BasicFileInfo, тож це не файл Revit.»
Це складений файл іншого типу (старі офісні документи використовують той самий контейнер). Перевірте, чи ви вибрали правильний файл.

**"Still working on the last one…"**
«Ще обробляється попередній…»
BimCraft ще зайнятий попереднім файлом або папкою. Дочекайтеся, поки рядок стану закінчиться, і спробуйте знову.

**The file chooser greys out my file.**
Вибирач файлів не дає вибрати мій файл.
Вибирач пропонує лише `.ifc`, `.rvt`, `.rfa`, `.rte`, `.rft`, `.dwg` і `.dxf`. Перетягніть інші файли на сторінку, і BimCraft скаже, чи може він їх прочитати.

## Відкриття папок

**"This folder has more than 20,000 files. Pick a smaller folder, such as one project."**
«У цій папці більше 20,000 файлів. Виберіть меншу папку, наприклад одного проєкту.»
Ви вибрали занадто високу папку, наприклад цілий диск. Виберіть папку одного проєкту.

**"The browser did not give access to *name*. Choose it again with Open a folder."**
«Браузер не надав доступу до *name*. Виберіть її знову через «Відкрити папку».»
Ви натиснули {{ui:Відкрити знову}} для нещодавньої папки, а дозвіл браузера відмовлено або він втратив чинність. Виберіть папку знову або перетягніть її.

**The browser says it will "upload" files.**
Браузер пише, що «вивантажить» файли.
Так браузер називає передачу файлів сторінці. BimCraft їх нікуди не надсилає. Щоб не виникало питання, перетягніть папку.

**Nothing happens on a phone or tablet.**
На телефоні або планшеті нічого не відбувається.
Багато мобільних браузерів не можуть вибирати папки. Відкривайте окремі файли або використовуйте компʼютер.

## Рушій IFC завантажується вперше

**The status line stays on "Starting the IFC engine…", or shows an error such as "Failed to fetch".**
Рядок стану лишається на «Запуск рушія IFC…» або показує помилку на кшталт «Failed to fetch».
Рушій IFC не вдалося завантажити. Можливо, немає зʼєднання, або брандмауер чи блокувальник вмісту його зупиняє.

:::offline
Немає зʼєднання. Якщо кнопка на панелі програми не показує {{ui:Готово для роботи без зʼєднання}}, рушій IFC ніколи не зберігався в цьому браузері. Відновіть зʼєднання, відкрийте файл знову, потім натисніть {{ui:Зберегти для роботи без зʼєднання}}, щоб він працював без зʼєднання наступного разу. Див. [Онлайн і офлайн](topic:online-offline).
:::

:::online
Перезавантажте сторінку і спробуйте знову. У робочій мережі попросіть вашу ІТ-службу дозволити файли `.wasm` сайту.
:::

## Збереження для роботи без зʼєднання

**The button says {{ui:Could not save}}.**
Кнопка показує {{ui:Не вдалося зберегти}}.
Деякі файли не завантажилися, зазвичай через обрив зʼєднання. Перевірте зʼєднання і натисніть кнопку знову. Попередня копія для роботи без зʼєднання зберігається, доки нову не буде завершено.

**The button says {{ui:Offline not available}}.**
Кнопка показує {{ui:Робота без зʼєднання недоступна}}.
Це вікно не може зберегти копію для роботи без зʼєднання, наприклад приватне вікно або керований робочий комп'ютер. Див. [Робота без зʼєднання](common:offline).

**The button stays on "Saving *n* of *m*" for a while.**
Кнопка довго лишається на «Збереження *n* з *m*».
Копія BimCraft важить близько 11 MB, більшість із них — рушій IFC. Тримайте вкладку відкритою, доки не з'явиться {{ui:Готово для роботи без зʼєднання}}.

**BimCraft opened offline but looks out of date.**
BimCraft відкрився без зʼєднання, але виглядає застарілим.
Збережена копія з попереднього візиту. Коли є зʼєднання, натисніть {{ui:Готово для роботи без зʼєднання}} і виберіть {{ui:Зберегти знову (отримати найновішу версію)}}.

## Вигляд 3D

**The model is not where I expected, or it is tiny.**
Модель не там, де я очікував, або вона крихітна.
Натисніть {{key:F}} або {{ui:Вмістити}}. «Вмістити» завжди охоплює все в моделі, зокрема вимкнені поверхи і випадкові елементи далеко від будівлі, тож будівля може виглядати малою. Далі наблизьте масштаб.

**Clicking does not pick anything.**
Клацання нічого не вибирає.
Тримайте мишу нерухомо, коли клацаєте: невелике перетягування обертає вигляд. Елементи на вимкнених поверхах не можна вибрати. Коли {{ui:Простори}} увімкнено, прозорі простори вибираються раніше за те, що в них всередині.

**The {{ui:Edges}} button is greyed out: "Edges are off for very large models".**
Кнопка {{ui:Ребра}} неактивна: «Ребра вимкнено для дуже великих моделей».
У моделі понад 1.5 мільйона трикутників. Ребра вимкнено, щоб заощадити пам'ять.

**The tab turns slow, white, or shows the browser's crash page.**
Вкладка сповільнюється, стає білою або показує сторінку збою браузера.
Модель занадто велика для пам'яті, яку браузер виділяє вкладці. Закрийте інші вкладки і перезавантажте. Експортуйте менший IFC: одну будівлю, одну дисципліну або менше поверхів. Див. [Браузери, пристрої та пам'ять](topic:platforms).

**The 3D view stays blank.**
Вигляд 3D лишається порожнім.
WebGL може бути вимкнено або заблоковано. У налаштуваннях браузера увімкніть апаратне прискорення (або прискорення графіки) і перезапустіть браузер.

## Редагування IFC

**"Use a number."** Значення числове. Введіть просте число без одиниць, наприклад `2.4`.

**"Use a whole number."** Значення є кількістю або цілим числом. Приберіть десяткові знаки.

**"Only single-value properties can be edited."** Редагувати можна лише властивості з одним значенням. Списки, переліки і величини доступні лише для читання.

**{{key:Mod+S}} opens the browser's "Save page" window.**
{{key:Mod+S}} відкриває вікно браузера «Зберегти сторінку».
Незбережених змін немає, тож BimCraft залишив клавішу браузеру. Закрийте вікно.

**{{key:Mod+Z}} does nothing.**
{{key:Mod+Z}} нічого не робить.
Вона працює лише тоді, коли є незбережені зміни і ви не вводите текст у полі. Після збереження скасовувати вже нічого.

**The {{ui:Changes}} list still shows edits after I discarded them and opened a drawing or a folder.**
Список {{ui:Зміни}} і далі показує правки після того, як я їх відкинув і відкрив креслення або папку.
Коли на питання «Відкинути їх?» ви відповідаєте OK, а потім відкриваєте щось, окрім моделі IFC, старі правки зберігаються в пам'яті, і {{ui:Зберегти як IFC}} усе одно їх збереже. Щоб почати справді з чистого аркуша, відкрийте початковий IFC знову або перезавантажте сторінку.

**My edit changed more elements than I picked.**
Моя правка змінила більше елементів, ніж я вибрав.
Ви змінили властивість у наборі з позначкою «(тип)». Властивості типу застосовуються до кожного елемента цього типу. Натисніть {{ui:Скасувати}}. Див. [Змінити властивість типу для кожного елемента типу](topic:type-vs-instance).

## Креслення

**"*name* could not be read. It may be damaged, or saved in a format the reader does not handle yet (…)."**
«*name* не вдалося прочитати. Можливо, його пошкоджено або збережено у форматі, який читач ще не обробляє (…).»
Збережіть креслення з програми, у якій його створено, як старіший DWG (2018 або раніший) чи як DXF, і спробуйте знову.

**"This drawing has nothing to show."** or **"*name* is an empty drawing: it holds no lines, text or blocks."**
«Це креслення нічого не показує.» або «*name* — порожнє креслення: в ньому немає ліній, тексту чи блоків.»
Креслення порожнє або містить лише те, що BimCraft ще не малює (див. праворуч **Ще не намальовано**).

**"This drawing is very large; only part of it is shown."**
«Креслення дуже велике; показано лише його частину.»
BimCraft припинив малювання, щоб лишатися чуйним. Вимкніть непотрібні шари або відкрийте потрібні аркуші з меншого креслення.

**Parts of a sheet are missing.**
Частини аркуша відсутні.
Можуть бути відсутні зовнішні посилання: дивіться праворуч у розділі **Зовнішні посилання**. Див. [Знайти зовнішні посилання і зображення](topic:dwg-linked-files). Шари також можуть бути вимкнені: натисніть {{ui:Увімкнути всі}}.

**A picture shows as an empty frame.**
Зображення показується порожньою рамкою.
Його файл не знайдено, або це TIFF («TIFF не можна показати в браузері»). Додайте копію у PNG або JPEG за допомогою {{ui:Додати малюнки…}}.

**Scrolling on my trackpad zooms instead of moving the drawing.**
Прокручування на тачпаді масштабує, а не переміщує креслення.
Так працюють креслення в BimCraft. Щоб перемістити, клацніть і перетягніть.
