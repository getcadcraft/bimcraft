BimCraft має небагато комбінацій клавіш. Більшість роботи виконується мишею та панелями. Комбінації, записані з {{key:Mod}}, використовують Command на Mac і Ctrl в інших системах. Див. [Клавіші, миші та трекпади](common:keys), щоб дізнатися, як клавіші записано в цій довідці.

## Загальні

| Клавіша | Що робить |
|---|---|
| {{key:Ctrl+Shift+F}} | Перемикає режими екрана: звичайний, повноекранний, повноекранний з прихованими панелями. Ctrl на всіх платформах, включно з Mac |
| {{key:Esc}} | Вихід із повноекранного режиму |
| {{key:Mod+,}} | Відкрити {{ui:Settings}}. Див. [Налаштування BimCraft](topic:settings) |
| {{key:Tab}} | Перехід між кнопками, прапорцями та значеннями. До кожного елемента керування можна дістатися з клавіатури |

## 3D-вид (моделі IFC)

| Клавіша або дія | Що робить |
|---|---|
| {{key:F}} | Вмістити всю модель, вигляд три чверті (те саме, що {{ui:Fit}}) |
| {{key:Esc}} | Скасувати вибір або припинити розміщення чи вставлення |
| Клік | Вибрати елемент під вказівником; клік на порожньому фоні скасовує вибір |
| {{key:Mod}}+клік або {{key:Shift}}+клік | Додати елемент до вибору або вилучити його |
| {{key:H}} | Сховати вибрані елементи. Див. [Приховування, ізоляція та перегляд крізь елементи](topic:hide-and-isolate) |
| {{key:I}} | Показати лише вибрані елементи (ізолювати) |
| {{key:T}} | Показати вибрані елементи, а все інше зробити прозорим |
| {{key:Shift+H}} | Знову показати всі елементи |
| {{ui:Walk}} | Далі {{key:W}} {{key:A}} {{key:S}} {{key:D}} або стрілки для руху, {{key:Shift}} — біг, перетягування — огляд навколо, {{key:Esc}} — зупинка. Див. [Прогулянка моделлю](topic:walk) |
| {{key:M}} | Вимірювати відстані та площі граней. Див. [Вимірювання відстаней, площ граней і положень у 3D](topic:measure) |
| Перетягування лівою кнопкою | Обертання |
| Перетягування правою кнопкою | Зсув |
| {{key:Shift}} або {{key:Mod}} і перетягування лівою кнопкою | Зсув (зручно на трекпаді) |
| Прокрутка колеса або перетягування середньою кнопкою | Масштаб |
| Прокрутка двома пальцями або масштабування щипком на трекпаді | Масштаб |
| Один палець (сенсор) | Обертання; дотик вибирає |
| Два пальці (сенсор) | Масштабування щипком, спільне переміщення для зсуву |

| {{key:X}} | Площина перерізу увімкнено і вимкнено. Див. [Розрізання моделі IFC площиною перерізу](topic:section-plane) |
| {{key:Shift+X}} | Коробка перерізу навколо вибраних елементів, з кімнатою, заданою в Налаштуваннях |

Клавіш для {{ui:Top}}, {{ui:Front}} і {{ui:Side}} немає; користуйтеся кнопками.

## Редагування

Ті самі команди є на панелі інструментів: {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}} і меню {{ui:More}}, яке показує кожну клавішу. Вони працюють у 3D-виді моделі IFC, але не тоді, коли ви вводите текст у полі. Див. [Копіювання, вставлення та дублювання елементів бібліотеки](topic:copy-paste).

| Клавіша | Що робить |
|---|---|
| {{key:Mod+Z}} | Скасувати останню зміну |
| {{key:Mod+Y}} або {{key:Mod+Shift+Z}} | Повторити те, що скасувала дія Скасувати |
| {{key:Mod+C}} | Копіювати вибрані елементи (їхні назви й властивості також потрапляють у буфер обміну як текст) |
| {{key:Mod+X}} | Вирізати вибрані елементи: скопіювати їх, а потім видалити |
| {{key:Mod+V}} | Вставити скопійоване: воно йде за вказівником, клікніть, куди його помістити |
| {{key:Mod+Shift+V}} | Вставити на місце: туди, звідки вирізано, або поруч з оригіналами після копіювання |
| {{key:Mod+D}} | Дублювати: скопіювати вибрані елементи й почати їх вставляти |
| {{key:Delete}} | Видалити вибрані елементи разом з їхніми частинами та отворами. Див. [Видалення, вирізання, копіювання та вставлення будівельних елементів](topic:edit-elements) |
| {{key:Mod+A}} | Вибрати всі показані елементи |
| {{key:Esc}} | Скасувати весь вибір |

Коли на сторінці виділено текст, {{key:Mod+C}} копіює цей текст, як зазвичай.

## Вид плану (Креслення)

Ці дії працюють, коли {{ui:Draw}} увімкнено і ви не вводите текст у полі. Див. [Креслення стін](topic:draw-walls) і [Двері та вікна](topic:doors-and-windows).

| Клавіша або дія | Що робить |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | З {{ui:Door}} або {{ui:Window}}: петлі з іншого кінця |
| {{key:Shift}} під час креслення стіни | Тримати під кутом 0°, 90°, 180° або 270° |
| Цифри та знаки футів і дюймів (`'` і `"`) | Почати вводити довжину в поле {{ui:Length}}; {{key:Enter}} застосовує її |
| {{key:Enter}}, {{key:Esc}}, права кнопка або подвійний клік | Завершити стіну, яку креслите; ще один {{key:Esc}} повертає до {{ui:Select}} |
| {{key:Delete}} | Видалити вибрані стіни, двері та вікна; стіни, що лишилися, знову з'єднуються |
| {{key:F}} з вказівником над планом | Вмістити план |
| Прокрутка колеса | Масштаб навколо вказівника |
| Перетягування середньою або правою кнопкою, або {{key:Space}} і перетягування | Зсув; коли {{ui:Select}} увімкнено, звичайне перетягування теж зсуває |
| Перетягування дверей або вікна з {{ui:Select}} | Пересунути їх уздовж стіни або на іншу стіну |
| Два пальці (сенсор) | Масштабування щипком, спільне переміщення для зсуву |

## Розміщення й вставлення елементів бібліотеки

| Клавіша | Що робить |
|---|---|
| {{key:R}} | Повернути елемент на 90° |
| {{key:Tab}} | Прилипання до стіни увімкнено і вимкнено: задня частина елемента притискається до найближчої стіни |
| {{key:Enter}} у полі **X, Y (mm)** | Розмістити за введеним положенням |
| {{key:Esc}} | Припинити розміщення або вставлення |

## Редагування значень IFC

| Клавіша | Що робить |
|---|---|
| {{key:Enter}} | Зберегти введене значення |
| {{key:Esc}} | Скасувати й повернути старе значення |
| Клік в іншому місці | Зберегти введене значення |
| {{key:Mod+Z}} | Скасувати останню зміну. Лише поки є незбережені зміни і ви не вводите текст у полі |
| {{key:Mod+Y}} | Повторити те, що скасувала дія Скасувати |
| {{key:Mod+S}} | Зберегти як IFC. Лише коли є незбережені зміни; інакше відкривається власна команда збереження браузера |

Щоб редагувати лише з клавіатури: натискайте {{key:Tab}}, доки значення не буде виділено, а потім натисніть {{key:Enter}}, щоб почати вводити.

## 2D-креслення (DWG і DXF)

| Клавіша або дія | Що робить |
|---|---|
| {{key:F}} | Вмістити креслення або аркуш |
| {{key:P}} | Вигляд для друку увімкнено і вимкнено |
| Подвійний клік | Вмістити |
| Перетягування будь-якою кнопкою | Зсув |
| Прокрутка колеса | Масштаб під вказівником |
| Прокрутка двома пальцями або масштабування щипком на трекпаді | Масштаб під вказівником. Прокрутка двома пальцями не зсуває |
| Один палець (сенсор) | Зсув. Масштабування щипком для креслень ще не зроблено |

## Креслення у 3D

| Клавіша або дія | Що робить |
|---|---|
| {{key:3}} | 3D увімкнено і вимкнено (також у 2D-виді) |
| {{key:F}} | Межі: усе креслення |
| Перетягування середньою або лівою кнопкою | Обертання |
| Перетягування правою кнопкою або {{key:Shift}} і перетягування | Зсув |
| Прокрутка колеса | Масштаб до того, що під вказівником |
| Проведення двома пальцями на трекпаді | Обертання; з {{key:Shift}} — зсув |
| Щипок на трекпаді | Масштаб |
| Один палець (сенсор) | Обертання |
| Два пальці (сенсор) | Масштабування щипком, спільне переміщення для зсуву |

{{key:F}}, {{key:P}} і {{key:3}} нічого не роблять, поки ви вводите текст у полі, поки показано відомість обладнання або коли затиснуто {{key:Mod}} чи {{key:Alt}}.
