Двоє людей беруть копію однієї будівлі: один креслить східне крило, інший — західне, а пізніше копії треба звести в одне. Якщо вони торкалися різних об’єктів, це може зробити програма замість людини.

## Як це працює

Кожна стіна, двері, рівень, кімната і набір властивостей у файлі IFC має GlobalId, який ніколи не змінюється. Обʼєднання шукає об’єкти за цим ідентифікатором, а не за номером, який файл їм присвоює (`#123`), бо номери змінюються, коли програма зберігає файл. Частини, що належать об’єкту і не мають власного ідентифікатора (розміщення, форми, одиниці), порівнюються за своїм вмістом.

Обидві копії мають бути однієї версії IFC (2x3, 4 або 4.3). Обʼєднання залишає ваш файл таким, яким він є, — з його порядком і номерами, — і додає те, що нове, тож git diff обʼєднання показує лише те, що змінило обʼєднання.

## Налаштування

Git потребує двох рядків один раз для кожного репозиторію:

```
# .gitattributes
*.ifc merge=cadcraft

# один раз, на кожному комп’ютері
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Без git запустіть `cadcraft merge <base> <ours> <theirs>`. Fossil і Mercurial беруть ті самі три файли в налаштуванні власного засобу обʼєднання. Нічого не вивантажується; усе працює на вашому комп’ютері.

## Правила

- Атрибут, змінений лише з одного боку, береться. Однакова зміна з обох боків береться один раз.
- Той самий атрибут, змінений двома способами (той самий рівень перейменовано по-різному), — це **конфлікт**: залишається ваш варіант, а звіт перелічує обидва. Відкрийте результат і виправте вручну.
- Список речей (стіни рівня, властивості набору) обʼєднується як набір: додане будь-якою стороною зберігається, а видалене будь-якою стороною вилучається. Двоє людей, кожен із яких додає стіни на той самий рівень, не створюють конфлікту.
- Об’єкт, доданий з будь-якого боку, зберігається разом зі своєю формою і властивостями. Видалений з одного боку і не змінений з іншого: видаляється. Видалений з одного боку, а змінений з іншого: видаляється і зазначається у звіті.
- Позначка часу та автор файлу, а також історія власника кожного об’єкта залишаються вашими.

Геометрія обʼєднується цілком: форма стіни береться з однієї сторони і ніколи не змішується точка за точкою. Заархівовані файли IFC та IFCX не обʼєднуються. Після обʼєднання відкрийте результат у BimCraft і перегляньте панель «Проблеми» перед збереженням.
