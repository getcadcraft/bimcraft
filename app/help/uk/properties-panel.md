## Елемент IFC

Угорі панелі {{ui:Властивості}} показано тип елемента без префікса «Ifc» (наприклад, «Door», «WallStandardCase», «FurnishingElement») і його назву або «Без назви».

| Поле | Зміст | Можна змінювати |
|---|---|---|
| Назва | Назва елемента, часто назва сімейства та типу від експортера | Так |
| Тип | Назва типу елемента, якщо він має тип | Ні |
| Тип об'єкта | Вільний текстовий опис типу, який заповнюють деякі експортери | Так |
| Мітка | Позначка або марка елемента; багато експортерів записують сюди ідентифікатор елемента | Так |
| Опис | Вільний текст | Так |
| GlobalId | Постійний 22-символьний ідентифікатор IFC елемента, однаковий у кожному експорті того самого елемента | Ні |
| Рядок | Номер рядка елемента (`#1234`) у цьому файлі IFC. Змінюється між експортами | Ні |

Далі йдуть **набори властивостей**, відсортовані за назвою:

- Кожен набір відкривається і закривається, коли ви натискаєте його назву. Перші три відкриті.
- Набір із позначкою «(type)» належить типу елемента: «Властивість типу: зміна тут застосовується до кожного елемента цього типу».
- Набори кількостей (довжини, площі, об'єми, кількості, маса) доступні лише для читання.
- Списки та переліки показуються лише для читання.
- Значення так/ні показуються як **Так** або **Ні**.
- Числа округлюються до чотирьох знаків після коми для показу. Довжини (властивість довжини або довжина з кількостей) показуються в {{ui:Одиниці}}, обраних на панелі інструментів, з позначкою одиниці поруч. Ви можете ввести нове значення в цій одиниці або з іншою позначкою одиниці (2.4 m, 8'-0"): BimCraft записує назад власне число файлу. Інші числа показуються так, як їх має файл.
- Порожнє значення показується як *порожньо*. Змінене значення жирне, із синьою смужкою збоку.

## Копіювання значення

Біля кожного значення в {{ui:Властивості}} є маленька кнопка копіювання: натисніть її, щоб помістити це значення в буфер обміну точно так, як показано, наприклад GlobalId, серійний номер або будь-яке значення набору властивостей. Копіювання ніколи не починає редагування.

Угорі {{ui:Копіювати все}} копіює кожне значення елемента як текст, набір за набором, а {{ui:Копіювати як CSV}} копіює їх рядками групи, властивості та значення для вставлення в електронну таблицю. Порожні значення зберігаються, тож кожне поле має рядок. Це працює так само для елемента іншої відкритої моделі; коли відкрито кілька моделей, CSV починається зі стовпця «Модель» з назвою файлу.

## Панель файлу (IFC)

| Поле | Зміст |
|---|---|
| Файл, Розмір | Файл, який ви відкрили |
| Схема | Версія IFC, наприклад IFC2X3 або IFC4 |
| Проєкт | Назва проєкту та її повна назва |
| Фаза | Фаза проєкту, якщо експортер її записав |
| Експортовано з | Програма, яка експортувала, з заголовка файлу |
| Автор | Автор із заголовка файлу |
| Експортовано | Дата і час із заголовка файлу |
| Елементи | Скільки елементів з формою було намальовано |
| Трикутники | Скільки трикутників складають їхні форми; міра того, наскільки важка модель |

## Панель файлу (проєкт і сімейство)

| Поле | Зміст |
|---|---|
| Вид | Проєкт, Шаблон проєкту, Сімейство або Шаблон сімейства |
| Збережено в | Випуск, який востаннє зберіг файл |
| Збірка | Точна збірка цього випуску |
| Прочитано | Яка частина файлу прочитана BimCraft порівняно з його розміром |

## Панель креслення (DWG і DXF)

| Поле | Зміст |
|---|---|
| Формат | Випуск, у якому креслення збережено, з його кодом формату, наприклад AC1032 |
| Одиниці | Одиниці вставки креслення, якщо вони задані |
| Об'єкти | Скільки об'єктів прочитано |
| Шари | Скільки шарів |
| Аркуші | Скільки аркушів (макетів) або Немає |
| Пов'язані креслення | Скільки з його пов'язаних креслень знайдено і завантажено |
| Обладнання | Скільки позначених одиниць обладнання є на аркушах |

## Панель теки

| Поле | Зміст |
|---|---|
| Тека, Файли, Розмір | Тека, яку ви відкрили, скільки файлів вона містить і їхній загальний розмір |
| Моделі | Файли проєкту і сімейств, кожен із його резервними копіями, що враховуються один раз |
| Креслення CAD, моделі IFC | Скільки кожного |
| Проблеми | Скільки копій моделей неповні або не читаються, або Немає |
