BimCraft читає ваші файли всередині вкладки браузера. Відкриття, перегляд, редагування та збереження ніколи нічого не надсилають нікуди, онлайн чи офлайн. [Робота без зʼєднання](common:offline) пояснює, як працюють офлайн-копії в усіх застосунках; ця сторінка розповідає про те, що особливе для BimCraft.

## Що BimCraft завантажує з сайту

| Частина | Коли завантажується без офлайн-копії | Розмір |
|---|---|---|
| Сам застосунок, з 3D-переглядачем і кодом рушія IFC | Коли ви відкриваєте BimCraft | Кілька MB |
| Частина WebAssembly рушія IFC | Перший файл IFC, який ви відкриваєте у вкладці: «Запуск рушія IFC…» | Близько 1.6 MB |

Файли DWG і DXF, файли проєктів і сімейств та папки не потребують нічого зайвого: їхні читачі є частиною застосунку.

## Збережіть BimCraft для роботи без зʼєднання

1. Відкрийте BimCraft, маючи зʼєднання.
2. Натисніть {{ui:Зберегти для роботи без зʼєднання}} на панелі застосунку вгорі.
3. Спостерігайте, як лічильник на кнопці зростає: наприклад, «Збереження 40 з 212». Копія BimCraft важить близько 11 MB, бо включає рушій IFC.
4. Дочекайтеся {{ui:Готово для роботи без зʼєднання}}.

Щойно з'явиться {{ui:Готово для роботи без зʼєднання}}, моделі IFC, креслення DWG і DXF, файли проєктів, папки та ця довідка відкриватимуться без підключення. Не потрібно спершу відкривати IFC або DWG, щоб «прогріти» читачі.

Щоб оновити або видалити копію, натисніть {{ui:Готово для роботи без зʼєднання}} і оберіть {{ui:Зберегти знову (отримати найновішу версію)}} або {{ui:Прибрати копію для роботи без зʼєднання}}.

## Що означає кнопка

| Кнопка | Означає |
|---|---|
| {{ui:Зберегти для роботи без зʼєднання}} | Офлайн-копії в цьому браузері ще немає. Натисніть, щоб зберегти |
| «Збереження *n* з *m*» | Збереження; тримайте вкладку відкритою, поки воно не завершиться |
| {{ui:Готово для роботи без зʼєднання}} | Збережено. Наведіть, щоб побачити, коли; натисніть для меню |
| {{ui:Не вдалося зберегти}} | Деякі файли не завантажилися. Перевірте зʼєднання та натисніть, щоб спробувати знову. Остання правильна копія, якщо така є, зберігається |
| {{ui:Робота без зʼєднання недоступна}} | Це вікно не може зберігати офлайн-копію (приватне вікно або керований комп'ютер). Див. [Робота без зʼєднання](common:offline) |

:::offline
Ви без зʼєднання.

- Якщо кнопка каже {{ui:Готово для роботи без зʼєднання}}, кожен тип файлів відкривається, як звичайно.
- Якщо ні, працює лише те, що ця вкладка вже завантажила: читач, який ніколи не завантажувався у вкладці, не може запуститися, і відкриття такого файлу показує помилку від браузера в рядку стану. Не перезавантажуйте вкладку, поки не буде зʼєднання.
:::

## Що ніколи не потребує зʼєднання

Щойно BimCraft відкрито у вкладці, це працює без зʼєднання навіть без збереженої копії:

- Читання файлів проєктів і сімейств та перевірка папок.
- Вибір елементів, читання властивостей і редагування значень IFC в уже відкритій моделі.
- {{ui:Зберегти як IFC}} і {{ui:Завантажити CSV}}: обидва — завантаження, зроблені у вкладці.

## Що ще не доступно

- **Хмарне збереження.** Файли зберігаються лише на вашому комп'ютері.

Див. [Де зберігаються ваші файли](common:your-files).
