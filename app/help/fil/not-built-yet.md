Sa ngayon, ang BimCraft ay isang reader, checker at IFC data editor na nagsimula nang gumuhit ng mga gusali: mga pader, pinto at bintana, kuwarto, sahig, kisame at bubong (tingnan ang [Gumuhit ng mga pader](topic:draw-walls), [Mga pinto at bintana](topic:doors-and-windows) at [Mga kuwarto, sahig, kisame at bubong](topic:floors-and-roofs)). Ito ang tapat na listahan ng mga hindi pa nito nagagawa, kasama ang dapat gawin sa halip.

## Pagmomodelo at authoring

| Hindi pa | Sa halip, sa ngayon |
|---|---|
| Pagguhit ng beam; column na steel section | Gamitin ang iyong authoring program, pagkatapos buksan dito ang IFC export nito. Dito nailalagay ang rectangular at round na column (tingnan ang [Grid at column](topic:grids-and-columns)); dito iginuguhit ang straight, L, U, winder at spiral na hagdan at railing (tingnan ang [Hagdan at railing](topic:stairs-and-railings)) |
| Bintana sa harap ng dormer; dormer sa roof plane na iginuhit nang kamay; kurbadong bubong; texture ng bubong na naka-render | Mga roof plane na iginuhit sa pamamagitan ng mga sulok nito, at pitch para sa bawat pader: tingnan ang [Bubong: pitch para sa bawat pader, gable, shed at roof plane](topic:roofs) |
| Pagbago ng mga pader, pinto o bintana na ginawa ng ibang program | Ang iyong authoring program; binabago lang ng mga drawing tool ang mga iginuhit nila |
| Profile ng pader na may overhang o butas; wall opening na hindi parihaba; pagdagdag o pag-alis ng profile point ng pader sa 3D view | Gumagana sa {{ui:Properties}}, sa elevation at section, sa face view ng pader, at sa mga grip sa 3D ang profile, attach, slant at opening, para sa tuwid at kurbadong pader: tingnan ang [Hubugin ang pader: attach, profile, slant at opening](topic:wall-shape) |
| Sa kurbadong pader: {{ui:Trim / extend}} at {{ui:Sulok}}, framing, awtomatikong dimension sa plano, pag-snap sa kahabaan ng arko (sumasalo ito sa mga dulo at sa gitna ng arko nito) | Iguhit nang tuwid ang pader para sa mga iyon, o gumamit ng tuwid na segment. Nasa [Gumuhit ng mga pader](topic:draw-walls) ang mga kurbadong pader |
| Pag-drag ng nailagay na library item sa 3D view | I-drag ito sa plano, o i-type ang X, Y at Rotation sa {{ui:Properties}}: tingnan ang [Maglagay ng kagamitan at muwebles mula sa library](topic:place-from-library) |
| Paglalagay ng halaman mula sa plant library ng Landscape workspace ng CivilCraft | Itanim ang mga ito sa CivilCraft, o maglagay ng puno at palumpong mula sa entourage ng library: tingnan ang [Maglagay ng kagamitan at muwebles mula sa library](topic:place-from-library) |
| Sa Plant add-on (naka-patay hanggang i-on mo): pagguhit ng routed run sa model, spool number sa isometric nito, layout check ng kagamitang nailagay mula sa library | Iguhit ang run gamit ang {{ui:Tubo}} (tingnan ang [Mga tubo at duct](topic:pipes-and-ducts)); binabasa ng layout check ang sariling equipment table ng add-on |
| Pag-ikot, pag-mirror o pag-array ng iisang iginuhit na pader, pinto at bintana (gumagalaw at kumokopya ang mga pader gamit ang Ilipat, Offset at Box stretch: tingnan ang [Hugis ng pader, split, offset, stretch at lock](topic:wall-tools)); istilo ng join (butt, square off) sa mga sulok na may kurbadong pader o tatlo o higit pang pader (tingnan ang [Hugis ng pader, split, offset, stretch at lock](topic:wall-tools)); Text tool; curtain wall | Kopyahin ang lahat sa isang level gamit ang {{ui:Kopyahin ang level na ito…}} (tingnan ang [Gumuhit ng mga pader](topic:draw-walls#levels)); kung hindi, iguhit muli ang mga ito |
| Mga layer ng wall assembly na iginuhit sa plano at section; dimension sa section at elevation; reference dimension sa pinto, bintana at iba pang component; assembly at membrane sa schedule at quantity; material library na ibinabahagi sa mga project; layer priority sa section, elevation at 3D at sa mga node ng tatlo o higit pang pader (sa plano, nililinis ng layer priority ang mga sulok, T join at tawiran ng dalawang pader: tingnan ang [Hugis ng pader, split, offset, stretch at lock](topic:wall-tools)); wrapped o variable na layer; pag-edit sa assembly ng pader na ginawa ng ibang program | Nasa type ng pader at sa preview nito ang mga layer ({{ui:Mga wall assembly…}}); sinusukat ang mga pader bilang iisang envelope: tingnan ang [Wall assembly at reference dimension](topic:wall-assemblies) |
| Pagbago ng hugis o laki ng element (maliban sa mga pader, pinto at bintanang iginuhit dito, at mga element na inilagay mula sa family) | Ang iyong authoring program. Gumagana rito ang Burahin, cut, kopyahin at i-paste: tingnan ang [Burahin, i-cut, kopyahin at i-paste ang mga building element](topic:edit-elements) |
| Pagbura ng mga palapag, space, building o site | Burahin ang mga element sa loob ng mga ito |
| Pag-paste ng building element sa ibang model | Kopyahin at i-paste sa loob ng iisang model; ang nailagay na library item ay maaaring i-paste sa anumang model |
| Pagdagdag ng bagong property o property set | Punan dito ang umiiral na value, o idagdag ang parameter sa iyong authoring program at i-export muli |
| Pag-edit ng quantity, listahan, enumeration | Ang iyong authoring program |
| Pag-save ng project file ng ibang program | Nagsa-save ang BimCraft ng IFC (at sarili nitong family file: tingnan ang [Mga family at ang kanilang laki](topic:families)) |
| Mga family: library ng mga family na inilagay mula sa plano at ibinabahagi sa mga project (Library), hotspot na dina-drag sa 3D view ng nailagay na element (sa preview ng family editor at sa plano sila nada-drag), detail level na pinipili kada view (isang level para sa project; pinipili ng mga sheet ayon sa scale), revolve sa upright plane sa loob ng ibang family na pinaikot ng isang quarter turn, sariling plan symbol ng pinto at bintana (ginuguhit nila ang sa starter nila) | Ang mga family na may typed parameter, formula, sariling plan symbol, hotspot, repeat, detail level, family sa loob ng family, laki mula sa table, at parameter kada element ay ginagawa dito: tingnan ang [I-edit ang family](topic:family-editor) at [Mga family at ang kanilang laki](topic:families). Mag-duplicate ng family para magsimula sa isa |
| Pag-edit ng type ng ibang program bilang family; pag-convert ng library item sa family | Nakalista ang type ng ibang program, pinagsama-sama ayon sa hula, at pinipili ang mga element nito. Inilalagay ang mga library item kung ano sila |
| Fitting, balbula at kagamitan ng mga maker (kapasidad, timbang, laki ng koneksyon ng maker); haba ng tee at reducer na ASME B16.9 sa steel spool; pressure loss sa mga fitting, daloy at balancing; sprinkler; cable tray; pag-size ng stack at vent ayon sa fixture unit; pag-drag sa sulok ng run; pagbubukas ng butas sa mga pader at slab; pagbitaw sa dulo ng run na nakakabit sa port (maliban sa pagbura ng kagamitan); port ng mga library item na inilagay mula sa Library panel; timbang ng fitting; duct seam, gauge at connector | Ang generic na standard fitting na tubo at duct run, system, plano, schedule at takeoff ay iginuguhit dito: tingnan ang [Mga tubo at duct](topic:pipes-and-ducts). Generic na kagamitang may port, mga konektadong run, at Connections check: [MEP equipment na may port](topic:mep-equipment), [Ikonekta ang tubo at duct sa kagamitan](topic:mep-connections). Clash set, clearance at listahan ng opening: [Suriin ang tubo at duct laban sa istruktura](topic:mep-against-structure). Steel spool at spool sheet, cut list ng duct: [Steel pipe spool at spool sheet](topic:pipe-spools). Ilagay ang mga item ng maker mula sa iyong MEP program bilang IFC |
| Design code check ng welded I-shape, ng I-shape na ang IFC profile ay hindi nakapangalan bilang rolled na W, S, IPE, HEA o HEB size, at ng tube, angle at channel (ibinabalik silang hindi sinusuri); buckling o dynamic response (nasa Finite elements block ang natural frequency) (second order ay P-Delta lang: elastic, flexural, walang stiffness reduction); pader at slab sa analysis; load na ginawa mula sa area (maliban sa isang pressure sa bawat concrete slab) | Ang tab na {{ui:Analysis}} ay nagbibigay ng puwersa, reaction at deflection ng beam, column at brace sa pamamagitan ng first-order analysis at tinitingnan ang rolled na I-shape, bilang tulong hanggang masuri ito ng isang engineer: tingnan ang [Suriin ang structural frame](topic:frame-analysis#design-checks) |

## Pagtingin sa mga model

| Hindi pa | Sa halip, sa ngayon |
|---|---|
| 3D mula sa project file | I-export ang IFC at buksan ito. Tingnan ang [Ilagay sa 3D ang project file sa pamamagitan ng IFC](topic:rvt-to-ifc) |
| Mga interior elevation sa nabuong drawing set (mula sa Properties ng kuwarto at sa sarili mong sheet ang mga ito binubuo); sarili mong dimension sa elevation at section (level mark, taas, lapad at door / window tag ang iginuguhit; ang mga note ay isinusulat sa view: tingnan ang [I-edit sa elevation at section](topic:edit-in-elevations)); pagguhit ng pader sa elevation (iginuguhit sila sa eroplano ng section); team template sa pamamagitan ng Studio | Ang drawing set na ginawa mula sa model: tingnan ang [Elevation, section at sheet](topic:sheets). Para sa anumang IFC model: isang {{ui:Section}} plane, o section box; tingnan ang [Gupitin ang IFC model gamit ang section plane](topic:section-plane) |
| Callout view, detail view, drafting view at legend; drafting line at hatch na iginuguhit sa view; pag-crop ng elevation o section; view template para sa elevation, section, ceiling plan at 3D view; ceiling plan sa nabuong drawing set; buong set ng sarili mong sheet sa isang PDF | Ang mga plano at ceiling plan ay may view range, crop region, scale at underlay (may template din ang mga plano), at ang sarili mong sheet ay tumatanggap ng plano, ceiling plan, elevation, section at schedule, bawat isa ay naka-save bilang PDF: tingnan ang [Mga view, view range at sarili mong sheet](topic:views-and-sheets) |
| Paglipat ng nailagay na ilaw paakyat sa kisame pagkatapos; kisameng nakahilig o may baitang; pattern ng kisame maliban sa limang grid; sariling simbolo ng ilaw sa ceiling plan | Ilagay ito gamit ang **Mount: At the ceiling**; gumuguhit ang ceiling plan ng fixture mula sa sarili nitong hugis: tingnan ang [Maglagay ng kagamitan at muwebles mula sa library](topic:place-from-library) |
| Pagbabahagi ng search set sa iba, mga set sa loob ng IFC file | Nananatili ang mga set sa browser na ito; tingnan ang [Hanapin ang mga element ayon sa class, pangalan o property](topic:find) |
| Pagsukat ng anggulo, o kasama ang landas ng ilang punto | Sukatin ang bawat bahagi gamit ang {{ui:Measure}}: tingnan ang [Sukatin ang distansya, face area at lokasyon sa 3D](topic:measure) |
| Mga texture sa live 3D view | Ipinapakita ng mga pininturahang materyal ang kulay nila sa view at ang texture nila sa mga naka-render na larawan: tingnan ang [I-render ang larawan ng model](topic:render) |
| Clearance (soft) clash sa pagitan ng alinmang dalawang set, clash group, pag-save ng clash result | Patakbuhin ang {{ui:Clash check}} at gawing issue ang mga mahalaga: tingnan ang [Suriin ang clash](topic:clash-check). Ang tubo at duct laban sa istruktura ay may {{ui:Suriin ang clearance}}: tingnan ang [Suriin ang tubo at duct laban sa istruktura](topic:mep-against-structure) |
| Pag-save ng ilang model bilang iisang set, o pag-edit ng dalawang model nang sabay | I-edit ang isang model sa bawat pagkakataon; bawat isa ay nagsa-save ng sarili nitong file |
| Pag-assign ng issue, due date, label, ilang viewpoint kada issue, pag-edit ng issue | Isang view kada issue; tingnan ang [Mga issue at BCF file](topic:issues-bcf) |
| `.ifczip` at `.ifcxml` | I-unzip o i-export ang simpleng `.ifc` |
| Map layer para sa model na walang map conversion, o sa mga view ng drawing | I-export ang model kasama ang mga coordinate nito: tingnan ang [Mapa sa lupa sa ilalim ng model](topic:map-layers) |
| E57 scan na lampas 6 milyong punto o 512 MB; sariling file ng mga maker ng scanner (RCP, RCS, FLS, LGS, TZF, ZFS); point cloud sa 3D view ng drawing; pag-save ng posisyon ng cloud kasama ang model | I-export ang scan bilang LAS o LAZ at buksan ito sa tabi ng IFC model: tingnan ang [Mga format ng point cloud](topic:point-cloud-formats) at [Ipakita ang point cloud sa tabi ng model](topic:point-clouds) |
| Pagre-rehistro ng scan: paghahanap ng target (sphere, checkerboard) sa scan nang mag-isa, paglutas sa lahat ng scan nang sabay (bundle adjustment), scale, pagre-rehistro laban sa model | Pumili ng magkatugmang punto o i-type ang coordinate ng target, pagkatapos pinuhin ang isang scan sa bawat pagkakataon gamit ang ICP: tingnan ang [Pagsamahin ang ilang scan sa iisa](topic:register-scans) |
| Pagbubukas ng `.pln`, `.pla`, `.tpl` at `.bpn` na project file | I-export ang IFC at DWG mula sa mga ito, o project bundle: tingnan ang [Buksan ang .pln at .pla na project file](topic:pln-project-files) at [Buksan ang project bundle](topic:open-project-bundle) |
| Pagbubukas ng listahan ng {{ui:Mga element}} para pumili ayon sa uri | I-click ang group ng isang uri sa {{ui:Model tree}}: tingnan ang [Maghanap ng daan gamit ang model tree](topic:model-tree) |
| Pag-type ng komento o pamagat sa issue sa VR, voice note, paglipat ng section plane gamit ang kamay sa VR, section box sa VR | Ilagay ang issue sa VR, pagkatapos idagdag ang mga salita nito sa tab na Issues; itakda ang section plane o box sa 3D view bago pumasok: tingnan ang [Suriin ang model sa VR headset](topic:vr-review) |
| Pagkita sa mga tao sa desk sa VR (tanging ang nasa VR ang lumalabas), pag-record ng VR walk | Hilingin silang sumali sa VR, o sumunod sa 3D view |
| Daylight simulation (climate-based daylight, glare, sun hours), roof window sa daylight factor, tseke laban sa BS EN 17037 o green building scheme; ang ISO 52016-1 energy method, hourly energy simulation, thermal mass at bridge, climate file | Mga kagamitang pang-disenyo: karaniwang daylight factor, vertical sky component ng bawat bintana, ang araw sa mga bintana sa isang petsa at ang daylight factor sa grid ([Tantyahin ang liwanag ng araw sa bawat kuwarto](topic:daylight-factor)); heat loss, taon ng degree-day at cooling peak kada kuwarto ([Tantyahin ang heating at cooling load](topic:heating-and-cooling-loads)). Gumamit ng simulation program para sa compliance |
| Naka-host na building twin: nakatagong reading at email na alerto habang sarado ang BimCraft, mga email para sa due na maintenance; MQTT 5; pagbasa ng COBie job pabalik | Mga reading mula sa CSV o direkta mula sa sarili mong broker o address habang bukas ang model, limitasyong nagmamarka ng asset, dokumento, COBie palabas at papasok: tingnan ang [Panatilihin ang asset data at maintenance record sa model](topic:assets-and-maintenance) |
| Plug-in o live link para sa Enscape, Twinmotion o iba pang visualization program; FBX o Datasmith file; isang object kada element, mga naka-save na view at walk sa .glb | I-save ang .glb para sa mga rendering program na bumabasa ng glTF, USD file (isang object kada element, kasama ang IFC data nito: tingnan ang [I-export ang model bilang USD](topic:usd)), o ang IFC para sa mga tumatakbo sa loob ng ibang design program: tingnan ang [Ipadala ang model sa rendering program](topic:model-for-rendering) at [Buksan ang eksena sa ibang program](topic:render-open-in) |
| Ibang program ang gumuguhit ng Render picture nang walang render-engine add-on (hindi kailanman nagpapatakbo ang CadCraft ng program sa ilalim ng GNU GPL licence); panorama o stereo camera at sky picture sa pamamagitan ng ibang program; Unreal Engine plug-in (nasusulat ang mga file, pero hindi pa nirirelease ang plug-in na magbubukas sa mga ito) | Ang sarili naming Fast at Path tracer engine; engine ng add-on ([gumuhit ng larawan gamit ang ibang program](topic:render-other-program)); USD, glTF o Unreal folder file mula sa listahan ng Engine na dadalhin sa anumang program |
| Sa live view: pagkalat ng halaman at bato, pagbabahagi ng panorama, tour, offline viewer o video | Mayroon nito ang live view ng ModelCraft; dito, render na larawan at 360° panorama: tingnan ang [Ang live view](topic:live-view) at [I-render ang larawan ng model](topic:render) |

## Mga drawing

| Hindi pa | Sa halip, sa ngayon |
|---|---|
| Pag-edit, pagsukat o pag-save ng DWG at DXF | Ang CadCraft drafting app ({{ui:I-edit sa CadCraft}} sa 2D view) |
| Pag-print o pag-export ng PDF | I-print mula sa program na gumawa ng drawing; suriin muna ito gamit ang {{ui:Print view}} |
| Plot style at pen table | Ipinapakita ng {{ui:Print view}} ang simpleng itim na may line weight |
| Mga DWG file na mas luma sa R13, at binary na DXF (sinasabi ito ng BimCraft kapag may binuksan ka) | I-save muli ang drawing bilang mas bagong DWG, o bilang ASCII DXF |
| Mga drawing na naka-link sa loob ng naka-link na drawing | Buksan sila nang direkta |
| Mga TIFF na larawan | I-save ang kopya bilang PNG o JPEG na may parehong pangalan at idagdag ito |
| Mga DGN drawing | Nakalista lang sa mga folder report |
| Mga object na nakalista sa ilalim ng **Not drawn yet** | Tingnan ang drawing sa program na gumawa nito |
| ACIS solid, body, region at surface, at subdivision mesh sa 3D | I-export ang IFC o 3D face mula sa program na gumawa ng drawing |
| Mga larawan, multileader at sheet sa 3D view ng drawing | Tingnan ang mga ito sa tab na {{ui:Model}} at sa mga sheet |
| Pagpili ng object sa 2D view ng drawing | Lumipat sa {{ui:3D}} at i-click doon ang object: tingnan ang [Tingnan ang DWG o DXF drawing sa 3D](topic:dwg-in-3d) |
| Equipment schedule mula sa mga drawing na walang `KCL-ITEM` tag | Hindi available |
| Equipment schedule bilang XLSX o PDF | {{ui:I-download ang CSV}} at buksan ito sa spreadsheet |

## Mga file at platform

| Hindi pa | Sa halip, sa ngayon |
|---|---|
| Pag-save sa cloud | I-save ang mga kopya sa iyong computer o office server. Hindi pa available ang pag-save sa cloud |
| Pag-alala sa mga folder sa Firefox at Safari | Piliin muli ang folder, o i-drag ito |
| I-undo pagkatapos mag-save | Buksan muli ang orihinal na file para magsimula muli |
| Pagpupuno sa nawawalang bahagi ng putol na project file | Kopyahin muli ang orihinal; sa folder, binabasa ng BimCraft ang pinakabagong kumpletong backup |
| Muling pagbubukas ng mga file na nakabukas dati | Ang mga hindi na-save na pagbabago ay ibinabalik bilang "Recover your work?" pagbalik mo; buksan muli ang mga file mula sa recent list |
