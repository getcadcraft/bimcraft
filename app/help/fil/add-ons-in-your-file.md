## Ano ang ginagawa nito

Kapag sumulat ang isang add-on sa model (isang truss, isang linya ng pipe), itinatala ng BimCraft ang add-on at ang bersyon nito sa IFC project, sa property set na CadCraft_AddOns. Isinusulat ang tala sa parehong undo step ng sariling pagbabago ng add-on, kaya kapag na-undo ang pagbabago, mababawi rin ang tala. Hindi pinapansin ng ibang program ang property set; nananatili sa file ang iginuhit ng add-on, anuman ang mangyari.

## Mga hakbang

1. Magbukas ng IFC file na nakatulong sa paggawa ng isang add-on.
2. Kung may add-on na ginamit nito na hindi naka-on, may tala sa itaas ng model na nagsasabi kung alin, kasama ang button para idagdag ang mga ito mula sa iyong Library account.
3. Idagdag sila, o isara ang tala. Bubukas ang model sa alinmang paraan.

## Mga karaniwang pagkakamali

- **Walang lumalabas na tala.** Hindi ka naka-sign in sa iyong account sa tab na ito, o walang tala ang file (ginawa ito bago magkaroon ng mga tala, o ng ibang program).
- **Nakasulat na "undefined" ang change list.** Naayos na: ipinapakita na ngayon ng mga label ang pangalan ng add-on.
