## Ang gagawin mo

Ipagpatuloy ang trabaho sa file sa app na ginawa para sa susunod na gawain, nang hindi sini-save at binubuksan ulit.

## Mga hakbang

1. Buksan ang DWG o DXF drawing para i-edit sa drafting app, o ang IFC model para i-detail sa detailing app.
2. I-click ang {{ui:Edit in CadCraft}} sa 2D view ng drawing, o ang {{ui:Open in DetailCraft}} sa toolbar ng model.
3. Magbubukas ang kabilang app sa bagong tab na bukas na ang file.

## Ano ang dapat mong makita

- Ang file sa bagong tab. Bukas pa rin ito sa BimCraft.
- Ang model na may hindi pa na-save na pagbabago ay ililipat kasama ang mga pagbabagong iyon. Hindi sine-save ang sarili mong kopya.
- Ang drawing ay ililipat nang walang mga naka-link na drawing nito.

## Mabuting malaman

- Ang file ay dumadaan sa pagitan ng dalawang tab sa loob ng browser mo. Walang ina-upload.
- Lumalabas lang ang button kapag bukas ang kabilang app sa lugar mo at kaya nitong tumanggap ng file sa ganitong paraan.
- Kung walang bumukas, hinarang ng browser ang bagong tab: payagan ang pop-ups para sa site na ito at i-click ulit.
