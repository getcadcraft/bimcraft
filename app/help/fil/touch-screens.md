Gumagana ang BimCraft sa mga daliri gayundin sa mouse. Sa unang pagdampi mo sa screen, lumalaki ang mga button, tab at hilera ng listahan para sa laki ng daliri.

## Ang 3D model

| Upang | Gawin ito |
|---|---|
| Orbit | I-drag gamit ang isang daliri |
| Zoom | I-pinch gamit ang dalawang daliri palayo o palapit |
| Pan | I-drag gamit ang dalawang daliri nang magkasama |
| Pumili ng element | I-tap ito |
| Magdagdag ng element sa pinili, o alisin ito | Pindutin nang matagal dito nang kalahating segundo (kapareho ng {{key:Ctrl}}+click) |
| Walang piliin | I-tap ang bakanteng espasyo |

Hindi kailanman pumipili ng anuman ang pinch o two-finger drag, kahit kapag may daliring umangat sa ibabaw ng isang element.

## Mga drawing (DWG at DXF)

| Upang | Gawin ito |
|---|---|
| Pan | I-drag gamit ang isang daliri |
| Zoom | I-pinch; nananatili sa lugar ang punto sa pagitan ng iyong mga daliri |
| Ipakita ang buong sheet | I-double-tap, o i-tap ang {{ui:Fit}} |

Sa {{ui:3D}} view ng isang drawing, nalalapat ang mga gesture ng model: isang daliri ang nag-o-orbit, dalawa ang nag-pi-pinch at nagpa-pan, pumipili ang tap, at nagdadagdag sa pinili ang long press.

## Walk

I-tap ang {{ui:Walk}}, saka i-tap ang floor kung saan mo gustong tumayo. Lalabas ang isang hilera ng arrow button sa walk bar:

- Pindutin nang matagal ang isang arrow para maglakad pasulong, paatras, o humakbang sa gilid.
- Kapag naka-off ang {{ui:Gravity}}, umaakyat at bumababa ang double arrows.
- I-drag ang isang daliri sa model para tumingin sa paligid.
- I-tap ang {{ui:Done}} para tumigil.

## Paglalagay ng library item

I-tap kung saan pupunta ang item. Pinapaikot ito ng {{ui:Turn 90°}} sa placing bar (ang {{key:R}} key sa keyboard), ikinakabit ng {{ui:Wall snap}} ang likod nito sa pinakamalapit na pader, at tinatapos ito ng {{ui:Stop placing}}.

## Sukatin

I-tap ang unang punto, saka ang ikalawa. Dumidikit ang mga punto sa mga sulok at gilid na malapit sa iyong tap.

:::tip
Kapag may nakakabit na keyboard sa tablet, gumagana ang bawat shortcut tulad ng sa computer. Tingnan ang [Mga keyboard shortcut](topic:keyboard).
:::
