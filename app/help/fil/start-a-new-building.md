## Ano ang gagawin mo

Magsimula ng building model mula sa wala sa halip na magbukas ng isa. Gumagawa ang BimCraft ng blangkong IFC model na may project, site, ang building at ang mga level nito. Maaari kang maglagay ng kagamitan at muwebles sa mga level mula sa library at i-save ito bilang IFC file.

:::note
Maaari nang iguhit ang mga pader: tingnan ang [Gumuhit ng pader](topic:draw-walls). Ginagawa pa lang ang mga pinto, bintana, sahig at bubong.
:::

## Mga hakbang

1. I-click ang {{ui:Bagong building}} sa ilalim ng **Magbukas ng file o folder**, o sa start page.
2. I-type ang **Pangalan ng building**.
3. Piliin kung ilang **level** ang mayroon ito (1 hanggang 200).
4. I-type ang **Taas ng level**, mula sahig hanggang sahig: halimbawa `10'-0"`, `10'6"` o `3000 mm`. Ang simpleng numero ay feet sa US, millimeters saanman.
5. I-click ang {{ui:Gawin}}. Nakasalansan ang mga level mula 0, bawat isa ay isang taas ng level ang layo mula sa nauna, at pinangalanang Level 1, Level 2 at iba pa. Lumalabas ang mga ito sa model tree, at bumubukas sa tabi ng 3D view ang plano ng Level 1 na naka-on ang {{ui:Draw}}.
6. Iguhit ang mga pader: tingnan ang [Gumuhit ng pader](topic:draw-walls). Palitan ang pangalan ng mga level o baguhin ang taas nila sa **Mga level** panel.
7. Maglagay ng mga item: tingnan ang [Maglagay ng kagamitan at muwebles mula sa library](topic:place-from-library). Nakalista sa placing bar ang bawat level.
8. I-click ang {{ui:I-save bilang IFC}}. Pinangalanan ang file ayon sa building, halimbawa `Smith's house.ifc`.

## Dapat tandaan

- Ise-save ang model sa millimeters, bilang IFC4. Mabubuksan ito ng ibang BIM program.
- **Mga palapag** sa kaliwang panel ay naglilista lamang ng mga level na may laman; nakalista silang lahat sa model tree.
- Hanggang sa i-save mo, ituturing na hindi pa nase-save na trabaho ang bagong building. Nagtatanong ang BimCraft bago ka magbukas ng ibang file o umalis, at nagtatago ito ng kopya sa browser na ito kung sakaling magsara ang tab.
