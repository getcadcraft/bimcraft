## Ano ang gagawin mo

Magbigay ng credit kung saan hinihingi ito ng license, at maabot ang sarili mong mga library item ng team.

## Library credits

1. Buksan ang model.
2. I-click ang {{ui:Credits}} sa toolbar.
3. Basahin ang listahan: bawat item na ginamit, ang version nito, license, attribution at ang item number kung saan ito nakalagay.
4. I-click ang {{ui:Kopyahin ang credits}} para kopyahin ang mga linya ng attribution, o ang {{ui:CSV na may schedule}} para sa spreadsheet ng bawat placement kasama ang credit nito.

Makikita rin ang license at attribution sa {{ui:Properties}} kapag pumili ka ng nakalagay na item, at sine-save ang mga ito sa IFC (`CadCraft_LibraryItem`), kaya kasama ang mga ito ng file.

## Ang equipment schedule ng model

I-click ang {{ui:Equipment}} sa toolbar. Binubuo ang schedule mula sa mga nakalagay na library item: item number, quantity, pangalan, maker, model, electrical at plumbing data, pinagsama-sama ayon sa palapag. Dina-download ito bilang parehong CSV gaya ng schedule ng drawing.

## Mag-sign in sa library

1. Sa tab na {{ui:Library}}, piliin ang **Library**.
2. I-click ang {{ui:Mag-sign in sa library}}. Bubukas ang maliit na window sa site na ito.
3. Mag-sign in kung hinihingi, tapos i-click ang **Connect**. Ibibigay ng window sa BimCraft ang library key, at maaari mo na itong isara.

## Ano ang dapat mong makita

- "Naka-sign in sa library" sa itaas ng listahan ng Library. Lumalabas ang mga item ng team mo sa tabi ng mga pampubliko.
- Naitatala bilang ginamit ang mga item na ilalagay mo, para masabi ng library kapag nagbago ang mga ito.

## Mabuting malaman

- Nasa tab na ito lang ang key at nagtatapos ito kapag isinara mo ang tab. Mas maaga itong binubura ng {{ui:Kalimutan ang sign-in}}.
- Nakalista ang key sa security page ng account mo bilang "BimCraft library (browser)"; bawiin ito doon.
- Walang ipinapadalang impormasyon tungkol sa model mo: tanging kung aling library item ang nailagay mo.
