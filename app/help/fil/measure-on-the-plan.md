## Ano ang gagawin mo

Suriin ang haba sa plano ng isang level, gaya ng lapad ng kuwarto o distansya sa pagitan ng dalawang grid line, nang hindi nagdaragdag ng anuman sa model. Para sumukat sa 3D view, tingnan ang [Sukatin ang distansya, lawak ng face at lokasyon sa 3D](topic:measure).

## Mga hakbang

1. Ipakita ang plano ng level na gusto mo: {{ui:Plan}} para sa plano lamang, o {{ui:I-split}}.
2. Sa grupong {{ui:Draw}}, i-click ang {{ui:Measure}}. Kapag plano lamang ang nakikita, maaari mong pindutin ang {{key:M}} sa halip.
3. I-click ang unang punto. Nagsa-snap ang mga punto sa mga pader, grid line at column.
4. I-click ang pangalawang punto. Ipinapakita ng linya ng dimension ang distansya, at ibinibigay ng status line ang distansya kasama ang pagkakaiba sa X at Y.
5. Para magpatuloy sa pagsukat, i-click ang pangatlong punto. Sinusukat ang bawat bahagi at idinadagdag ang kabuuan.
6. Pindutin nang matagal ang {{key:Shift}} habang nag-click para panatilihing tuwid ang bahagi mula sa nauna rito.
7. Pindutin ang {{key:Esc}} para i-clear ang sukat, o pumili ng ibang tool.

## Mga tala

- Walang isinusulat sa model, at mawawala ang dimension kapag na-clear ito. Para sa mga dimension na nananatili, tingnan ang [Mga assembly ng pader at reference dimension](topic:wall-assemblies).
- Kapag nakikita ang 3D view, nananatiling 3D Measure ang {{key:M}}. Ang {{key:Shift+M}} ay Ilipat.
- Ang distansya ay gumagamit ng display unit na pinili mo sa {{ui:Mga setting}}.
