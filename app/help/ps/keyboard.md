BimCraft کې ډېر لږ شارټ کټونه شته. ډېره کار په ماوس او پینلونو کیږي. هغه شارټ کټونه چې د {{key:Mod}} سره لیکل شوي د Mac کې Command او نورو ځایونو کې Ctrl کاروي. د دې لارښود کې د کیلیو لیکلو لپاره [کیلي، ماوس او ټچ پیډونه](common:keys) وګورئ.

## هرچیرې

| کیلي | کار یې څه دی |
|---|---|
| {{key:Ctrl+Shift+F}} | د سکرین حالتونه بدل کړئ: عادي، بشپړ سکرین، بشپړ سکرین له پټو بارونو سره. Ctrl په هر سیسټم کې، د Mac په شمول |
| {{key:Esc}} | له بشپړ سکرین څخه وتل |
| {{key:Mod+,}} | {{ui:Settings}} پرانیزي. [BimCraft امستنې](topic:settings) وګورئ |
| {{key:Tab}} | د تڼیو، چیک بکسونو او ارزښتونو ترمنځ حرکت. هر کنټرول له کیلي تختې څخه رسېدلی شي |

## 3D لید (IFC ماډلونه)

| کیلي یا عمل | کار یې څه دی |
|---|---|
| {{key:F}} | ټول ماډل برابر کړئ، درې-څلورمه لید (لکه {{ui:Fit}}) |
| {{key:Esc}} | ټاکنه پاکه کړئ، یا ایښودل یا سرېښول ودروئ |
| کلیک | عنصر چې د اشاره کوونکي لاندې دی وټاکئ؛ د تش شاتني ځای کلیک وکړئ ترڅو پاک شي |
| {{key:Mod}}+کلیک یا {{key:Shift}}+کلیک | یو عنصر په ټاکنه کې اضافه کړئ یا له هغې لرې یې کړئ |
| {{key:H}} | ټاکل شوي عناصر پټ کړئ. [عناصر پټول، جلا کول او له بې ډکولو ګورل](topic:hide-and-isolate) وګورئ |
| {{key:I}} | یوازې ټاکل شوي عناصر وښایاست (جلا کول) |
| {{key:T}} | ټاکل شوي عناصر وښایاست، نور ټول شفاف |
| {{key:Shift+H}} | هر عنصر بیا وښایاست |
| {{ui:Walk}} | بیا {{key:W}} {{key:A}} {{key:S}} {{key:D}} یا غشي ګرځي، {{key:Shift}} منډه کوي، ډریګ کول ګرځي او شاوخوا ته ګوري، {{key:Esc}} ودروي. [په ماډل کې ګرځیدل](topic:walk) وګورئ |
| {{key:M}} | واټنونه او د مخونو ساحې اندازه کړئ. [په 3D کې واټنونه، د مخونو ساحې او ځایونه اندازه کړئ](topic:measure) وګورئ |
| ډریګ کول په کیڼ تڼۍ | دوران |
| ډریګ کول په ښۍ تڼۍ | لید خوځول |
| {{key:Shift}} یا {{key:Mod}} او ډریګ کول په کیڼ تڼۍ | لید خوځول (د ټچ پیډ لپاره ګټور) |
| سکرول د ټایر، یا ډریګ کول په منځنۍ تڼۍ | زوم |
| د ټچ پیډ دوه-ګوټي سکرول یا پینچ | زوم |
| یوه ګوته (ټچ) | دوران؛ یوه ټکولې ټاکل |
| دوه ګوټي (ټچ) | پینچ کول زوم دی، یوځای خوځول لید خوځوي |

| {{key:X}} | د پرې شوې الوتکې چالو او بند. [IFC ماډل د پرې شوې الوتکې سره پرې کړئ](topic:section-plane) وګورئ |
| {{key:Shift+X}} | د ټاکل شوي عناصرو شاوخوا پرې شوی بکس، د کوټې امستنې سره په Settings کې |

د {{ui:Top}}، {{ui:Front}} او {{ui:Side}} لپاره کیلي نشته؛ تڼۍ وکاروئ.

## سمون

ورته فرمانونه په وسیلو کرښه کې دي: {{ui:Undo}}، {{ui:Redo}}، {{ui:Copy}}، {{ui:Paste}} او د {{ui:More}} مینو، چې هره کیلي ښیي. دوی د IFC ماډل په 3D لید کې کار کوي، نه کله چې په ساحه کې لیکئ. [د کتابتون توکي کاپي، سرېښول او نقل کول](topic:copy-paste) وګورئ.

| کیلي | کار یې څه دی |
|---|---|
| {{key:Mod+Z}} | وروستی بدلون بېرته واخلئ |
| {{key:Mod+Y}} یا {{key:Mod+Shift+Z}} | هغه بیا کړئ چې Undo یې واخیست |
| {{key:Mod+C}} | ټاکل شوي عناصر کاپي کړئ (نومونه او ملکیتونه هم د کلیپ بورډ ته د متن په توګه ځي) |
| {{key:Mod+X}} | ټاکل شوي عناصر پرې کړئ: لومړی کاپي، بیا ړنګ کړئ |
| {{key:Mod+V}} | هغه څه سرېښئ چې کاپي کړي دي: د اشاره کوونکي تعقیبوي، هغه ځای کلیک کړئ چېرې چې ځي |
| {{key:Mod+Shift+V}} | ځای پر ځای سرېښول: چېرې چې پرې شوي و، یا د کاپي وروسته د اصلي څنګ ته |
| {{key:Mod+D}} | نقل: ټاکل شوي عناصر کاپي کړئ او د سرېښولو پیل وکړئ |
| {{key:Delete}} | ټاکل شوي عناصر ړنګ کړئ، د دوی برخو او خلاصونو سره. [د ودانۍ عناصر ړنګ کړئ، پرې کړئ، کاپي او سرېښول](topic:edit-elements) وګورئ |
| {{key:Mod+A}} | هر ښکاره عنصر وټاکئ |
| {{key:Esc}} | هیڅ ونه ټاکئ |

کله چې په پاڼه کې متن ټاکل شوی وي، {{key:Mod+C}} په عادي ډول هغه متن کاپي کوي.

## د پلان لید (Draw)

دا هغه وخت کار کوي چې {{ui:Draw}} فعال وي او تاسو په ساحه کې نه لیکئ. [دېوالونه رسم کړئ](topic:draw-walls) او [دروازې او کړکۍ](topic:doors-and-windows) وګورئ.

| کیلي یا عمل | کار یې څه دی |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | د {{ui:Door}} یا {{ui:Window}} سره: لولې د بل پای ته |
| {{key:Shift}} کله چې دېوال رسموئ | دېوال په 0°، 90°، 180° یا 270° وساتئ |
| عددونه او د فوټ او انچ نښې (`'` او `"`) | د {{ui:Length}} بکس کې د اوږدوالي لیکل پیل کړئ؛ {{key:Enter}} هغه کاروي |
| {{key:Enter}}، {{key:Esc}}، ښۍ تڼۍ یا دوه ځله کلیک | هغه دېوال چې رسمېږي پای ته ورسوئ؛ {{key:Esc}} بیا {{ui:Select}} ته ځي |
| {{key:Delete}} | ټاکل شوي دېوالونه، دروازې او کړکۍ ړنګ کړئ؛ پاتې دېوالونه بیا سره نښلېږي |
| {{key:F}} کله چې اشاره کوونکی پلان کې وي | پلان برابر کړئ |
| د ټایر سکرول | زوم د اشاره کوونکي شاوخوا |
| ډریګ کول په منځنۍ یا ښۍ تڼۍ، یا {{key:Space}} او ډریګ | لید خوځول؛ کله چې {{ui:Select}} فعال وي، ساده ډریګ هم لید خوځوي |
| ډریګ کول د دروازې یا کړکۍ په {{ui:Select}} | د خپل دېوال په اوږدو یا بل دېوال ته یې حرکت کړئ |
| دوه ګوټي (ټچ) | پینچ کول زوم دی، یوځای خوځول لید خوځوي |

## د کتابتون توکي ایښودل او سرېښول

| کیلي | کار یې څه دی |
|---|---|
| {{key:R}} | توکی 90° وګرځوئ |
| {{key:Tab}} | د دېوال نیول چالو او بند: د توکي شاته د نږدې دېوال سره لګي |
| {{key:Enter}} په **X, Y (mm)** کې | په لیکل شوي ځای کې کېږدئ |
| {{key:Esc}} | ایښودل یا سرېښول ودروئ |

## د IFC ارزښتونو سمول

| کیلي | کار یې څه دی |
|---|---|
| {{key:Enter}} | هغه ارزښت وساتئ چې لیکلی یې |
| {{key:Esc}} | ولغوه کړئ او زوړ ارزښت بیرته کېږدئ |
| کلیک په بل ځای | هغه ارزښت وساتئ چې لیکلی یې |
| {{key:Mod+Z}} | وروستی بدلون بېرته واخلئ. یوازې هغه وخت چې نه ساتل شوي بدلونونه لرئ او په ساحه کې نه لیکئ |
| {{key:Mod+Y}} | هغه بیا کړئ چې Undo یې واخیست |
| {{key:Mod+S}} | د IFC په توګه خوندي کړئ. یوازې هغه وخت چې نه ساتل شوي بدلونونه لرئ؛ که نه، د براوزر خپل خوندي کولو فرمان پرانیستل کیږي |

یوازې د کیلۍ تختې سره د سمولو لپاره: {{key:Tab}} وفشارئ تر هغه چې یو ارزښت ښکاره شي، بیا {{key:Enter}} وفشارئ ترڅو لیکل پیل کړئ.

## 2D نقشې (DWG او DXF)

| کیلي یا عمل | کار یې څه دی |
|---|---|
| {{key:F}} | نقشه یا پاڼه برابره کړئ |
| {{key:P}} | د چاپ لید چالو او بند |
| دوه ځله کلیک | برابرول |
| ډریګ کول په هر تڼۍ | لید خوځول |
| د ټایر سکرول | زوم د اشاره کوونکي ځای کې |
| د ټچ پیډ دوه-ګوټي سکرول یا پینچ | زوم د اشاره کوونکي ځای کې. دوه-ګوټي سکرول لید نه خوځوي |
| یوه ګوته (ټچ) | لید خوځول. د نقشو لپاره پینچ زوم لا جوړ شوی نه دی |

## نقشې په 3D کې

| کیلي یا عمل | کار یې څه دی |
|---|---|
| {{key:3}} | 3D چالو او بند (په 2D لید کې هم) |
| {{key:F}} | ابعاد: ټوله نقشه |
| ډریګ کول په منځنۍ یا کیڼ تڼۍ | دوران |
| ډریګ کول په ښۍ تڼۍ، یا {{key:Shift}} او ډریګ | لید خوځول |
| د ټایر سکرول | زوم د هغه څه په لوري چې د اشاره کوونکي لاندې دي |
| د ټچ پیډ دوه-ګوټي سوایپ | دوران؛ له {{key:Shift}} سره، لید خوځول |
| د ټچ پیډ پینچ | زوم |
| یوه ګوته (ټچ) | دوران |
