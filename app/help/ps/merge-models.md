دوه کسان د ورته ودانۍ یوه کاپي اخلي، یو ختیځ وزره رسموي او بل لوېديځ، او وروسته باید کاپيانې یو شي شي. که دوی مختلف شیان سمون کړي، یو پروګرام کولای شي دا کار پرځای د یو انسان وکړي.

## څه کار جوړوي

هر دیوال، دروازه، پوړ، کوټه او ملکیت سیټ په IFC فایل کې یو GlobalId لري چې هېڅکله نه بدلېږي. یوځای کول شیان د هغه id له لارې پیدا کوي، نه د هغه شمېرې له لارې چې فایل ورکوي (`#123`)، ځکه شمېرې بدلېږي کله چې پروګرام خوندي کوي. هغه برخې چې له شي څخه ځړېږي او خپل id نه لري (ځایونه، شکلونه، واحدونه) د منځپانګې له مخې پرتله کېږي.

د دواړو کاپيو باید ورته IFC نسخه وي (2x3، 4 یا 4.3). یوځای کول ستاسو فایل لکه خپل شوی ساتي، ترتیب او شمېرې، او هغه څه اضافه کوي چې نوي دي، نو د یوځای کولو git diff یوازې هغه ښیي چې یوځای کول یې بدل کړي.

## یې تنظیم کړئ

Git ته یوځل په هر ریپوزیټوري کې دوه کرښې اړینې دي:

```
# .gitattributes
*.ifc merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

د Git پرته، `cadcraft merge <base> <ours> <theirs>` وچلوئ. Fossil او Mercurial همدې درې فایلونه د خپل merge-tool تنظیم کې اخلي. هېڅ نه پورته کېږي؛ ټول ستاسو په کمپیوټر کې ځي.

## قواعد

- یوه ځانګړتیا چې یوازې په یو اړخ بدله شي اخیستل کېږي. ورته بدلون په دواړو اړخونو یو ځل اخیستل کېږي.
- ورته ځانګړتیا په دوو لارو بدله شوې (ورته پوړ په دوو لارو بېرته نومول) یوه **شخړه** ده: ستاسو اړخ پاتې کېږي او راپور دواړه لیست کوي. پایله خلاصه کړئ او په لاس یې سم کړئ.
- د شیانو لیست (د پوړ دیوالونه، د سیټ ملکیتونه) د سیټ په توګه یوځای کېږي: هغه څه چې کوم اړخ اضافه کړي ساتل کېږي او هغه څه چې کوم اړخ لرې کړي لرې کېږي. دوه کسان چې هر یو دیوالونه په ورته پوړ کې اضافه کوي شخړه نه لري.
- یو شی چې په کوم اړخ اضافه شي د خپل شکل او ملکیتونو سره ساتل کېږي. په یو اړخ لرې او بل اړخ نه بدل شوی: لرې. په یو اړخ لرې او بل اړخ بدل شوی: لرې، او راپور ورکول کېږي.
- د فایل وخت مهر او لیکوال، او د هر شي د مالک تاریخ، ستاسو پاتې کېږي.

هندسه بشپړه یوځای کېږي: د دیوال شکل له یو اړخ راځي، هېڅکله ټکي په ټکي نه ګډېږي. ZIP شوي IFC او IFCX فایلونه نه یوځای کېږي. وروسته له یوځای کولو، BimCraft کې یې پرانیزئ او مخکې له خوندي کولو د ستونزو پینل وګورئ.
