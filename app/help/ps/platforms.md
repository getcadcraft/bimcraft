BimCraft د Chrome، Edge، Firefox او Safari په اوسنیو نسخو کې، په Mac، Windows او Linux کې چلېږي. د 3D لید WebGL ته اړتیا لري، کوم چې هر اوسنی براوزر لري. وګورئ [براوزرونه او کمپیوټرونه](common:browsers) د هغه څه لپاره چې اپلیکیشنونه عموماً ورته اړتیا لري.

## فولډر پرانیستل

| براوزر | {{ui:Open a folder}} دا کوي | فولډر کش کول | {{ui:Recent folders}} |
|---|---|---|---|
| Chrome، Edge | د براوزر د فولډر ټاکونکی، بیا "سایټ ته اجازه ورکړو چې فایلونه وګوري؟": **فایلونه وګورئ** کلیک کړئ | پرته له پوښتنې پرانیستل کېږي | هو، هغه فولډرونه چې ټاکل یا کش شوي |
| Firefox | د سیستم فولډر ټاکونکی | پرته له پوښتنې پرانیستل کېږي | نه |
| Safari | د سیستم فولډر ټاکونکی، د **پورته کول** تڼۍ سره (هېڅ نه پورته کېږي) | پرته له پوښتنې پرانیستل کېږي | نه |

پټ کار: Chrome او Edge د File System Access ټاکونکی کاروي او فولډر یاد ساتلای شي. Firefox او Safari زوړ فولډر ټاکونکی کاروي، کوم چې ټول فایلونه په یوځل ورکوي او یاد نه ساتل کېږي. کش شوی فولډر په هر براوزر کې د هرې ننوتنې په ډول لوستل کېږي.

:::chromium
Brave او ځینې نور Chromium براوزرونه د فولډر ټاکونکی بندوي. BimCraft بیا د سیستم فولډر ټاکونکی کاروي، او براوزر ممکن وپوښتي "*n* فایلونه دې سایټ ته پورته کړم؟". هېڅ نه پورته کېږي؛ فایلونه یوازې ټب ته ځي. فولډر کش کول پوښتنه له منځه وړي.
:::

## Mac، Windows او Linux

- چټکې لارې {{key:Mod+S}} او {{key:Mod+Z}} په Mac کې Command دي، او په Windows او Linux کې Ctrl.
- {{key:Ctrl+Shift+F}} (د سکرین حالتونه) د هرې پلیټفارم کې Control دی، په Mac کې هم.
- د فایل ډیالوګونه او د ډاونلوډ فولډر ستاسو د سیستم خپل دي.

## ماوس، ټچ پیډ او لمس

| ان پوټ | 3D لید | 2D رسم |
|---|---|---|
| ماوس | کیڼ کش مدار، ښي کش لېږدول، ټایر زوم، کلیک ټاکي | هر کش لېږدوي، ټایر زوم، دوه ځله کلیک برابروي |
| ټچ پیډ | کلیک-کش مدار؛ {{key:Shift}} یا {{key:Mod}} او کش لېږدول؛ دوه-ګوتو سکرول یا فشار زوم | کلیک-کش لېږدوي؛ دوه-ګوتو سکرول یا فشار زوم |
| لمس | یوه ګوته مدار، دوه ګوتې فشار او لېږدول، ټپ ټاکي | یوه ګوته لېږدوي؛ تر اوسه فشار زوم نشته؛ {{ui:Fit}} ټپ کړئ |

په Mac ټچ پیډ کې، ښي کلیک دوه-ګوتو کلیک دی (یا Control-کلیک). وګورئ [کیبورډ، ماوس او ټچ پیډونه](common:keys).

ټابلیټ او تلیفونونه کولای شي یوازې فایلونه پرانیزي او وګوري، خو سکرین کوچنی دی، ډېری موبایل براوزرونه فولډرونه نشي ټاکلای، او لوی ماډلونه ممکن په حافظه کې ونه ځي. کمپیوټر ښه کار کوي.

## لوی فایلونه او حافظه

هر هغه څه چې BimCraft یې لولي د براوزر ټب په حافظه کې ژوند کوي. یو ټب څومره کارولای شي د براوزر او ستاسو کمپیوټر پورې اړه لري، د BimCraft څخه ډېر.

| فایل | څومره لوستل کېږي | څه تمه وکړئ |
|---|---|---|
| IFC | ټول فایل، د هغه له مخې جوړ شوی 3D جیومیټري | لوی والی ستاسو کمپیوټر او براوزر پورې اړه لري؛ څو سوه مېګابایټه ماډل ممکن لپټاپ ته ډېر وي. د 1.5 میلیونو مثلثونو څخه پورته، کنارې بندې کېږي |
| د پروژې او کورنۍ فایلونه | شاوخوا 40 KB تر 100 KB، هر اندازه | حتی ډېر لوی مرکزي ماډلونه په یوه شیبه کې پرانیستل کېږي، د شبکې ډرایو څخه هم |
| DWG او DXF | ټول فایل | ډېرې لوی نقشې ښيي "دا نقشه ډېره لویه ده؛ یوازې یوه برخه ښودل کېږي." |
| فولډرونه | د فایلونو لیست، پلس په هر ماډل څو کیلوبایټه | تر 20,000 فایلونو پورې |

که ټب له حافظې څخه ووځي، براوزر خپله تېروتنې پاڼه ښيي (د مثال په توګه په Chrome کې "Aw, Snap!"). نور ټبونه وتړئ، BimCraft بیا وپورته کړئ او بیا هڅه وکړئ، یا یو کمپیوټر وکاروئ چې ډېره حافظه ولري.
