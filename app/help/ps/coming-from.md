که Revit پیژنئ، د BimCraft ډېره برخه به په ټکو کې آشنا وي، او په لړۍ کې نا آشنا. تر ټولو مهم توپیر: **دا نسخه ماډلونه لولي او ازموي او د IFC معلوماتو سمون کوي. دا لا Revit په څېر ډیزاین نه کوي.** تاسو نشئ کولی دیوالونه انځور کړئ، کورنۍ کېږدئ، لیدونه یا شیټونه جوړ کړئ، یا پروژه فایل خوندي کړئ. هغه څه چې کولی شئ دا دي: تقریباً هر ودانۍ فایل په هر کمپیوټر کې د براوزر سره پرانیزئ، څه پکې دي وګورئ، د پروژې ټول فولډر وڅیړئ، او د IFC ماډل کې معلومات سم کړئ.

## نقشه شوي عادتونه

| که عادت لرئ | په BimCraft کې |
|---|---|
| `.rvt` په Revit کې پرانیستل ترڅو ماډل وګورئ | BimCraft `.rvt` د فایل کارت په توګه پرانیزي: نسخه، د پروژې معلومات، اړیکې، مخکتنه. د 3D ماډل لپاره IFC صادر کړئ او هغه پرانیزئ. [یوه پروژه یا کورنۍ فایل ولولئ](topic:read-rvt-file) |
| د فایل د خوندي کېدو نسخه وګورئ مخکې له پرانیستلو | کارت پورته کې وایي "saved in Revit …"، پرته له دې چې فایل وده کړي یا بدل کړي |
| د پروژې کتونکی | د لیدونو او شیټونو کوم کتونکی نشته. IFC ماډل {{ui:پوړونه}} او {{ui:عناصر}} لیستونه لري؛ نقشه د شیټ ټبونه لري |
| د ملکیتونو پینل | د ښي خوا {{ui:ملکیتونه}} پینل، د هغه توکي لپاره چې کلیک مو کړی. د پیرامیټر ډلو پر ځای IFC د ملکیت سیټونه |
| د مثال او ډول پیرامیټرونه | د مثال ملکیت سیټونه، او هغه چې "(type)" نښه لري. د ډول بدلون د هغه ډول ټولو توکو باندې تطبیقېږي، لکه Revit کې. [د یوه ډول ملکیت د هغه ډول ټولو توکو لپاره بدل کړئ](topic:type-vs-instance) |
| Edit Type | خبري کړکۍ نشته: په "(type)" سیټ کې یو ارزښت کلیک کړئ او ولیکئ |
| ډېر توکي ټاکل، فلټرونه، Select All Instances | یو په یو توکی. لا نه دی جوړ شوی |
| د لید مکعب او د ګرځېدو څرخ | د لید مکعب ښکته ښي کونج کې، څلور تڼۍ ({{ui:برابرول}}، {{ui:پورته}}، {{ui:مخکنی}}، {{ui:اړخ}}) او وړیا ګرځېدنه. د ګرځېدو څرخ نشته |
| Shift او منځنۍ تڼۍ کش کول، منځنۍ تڼۍ کش کول ترڅو حرکت وکړي | کیڼ کش ګرځوي، ښی کش (یا {{key:Shift}} او کش) حرکت کوي، څرخ زوم کوي. د {{ui:BIM ribbon}} مینو ډول منځنۍ تڼۍ کش ته حرکت او {{key:Shift}} سره منځنۍ تڼۍ ته ګرځېدنه ورکوي. [مینوګانې، کیلي او موږک](topic:menus-keys-and-mouse) |
| د فرش پلانونه، مقطعونه، د مقطع بکسونه | یو {{ui:مقطع}} الوتکه یوځل ({{key:X}})؛ د مقطع بکس یا 2D پلانونه نشته. [IFC ماډل د مقطع الوتکې سره پرې کړئ](topic:section-plane) |
| د لیدونو کې پټول، جلا کول، لید/ګرافیک | {{ui:پوړونه}} بند او پرانیستل، {{ui:ځایونه}} او {{ui:کنارې}}. د هر توکي پټول لا نشته |
| کوټې | IFC ځایونه، په پیل کې پټ. {{ui:ځایونه}} کلیک کړئ |
| خوندي کول، په بل نوم خوندي کول، مرکزي سره همغړي کول | {{ui:IFC په توګه خوندي کول}} نوی IFC فایل ډاونلوډ کوي. اصلي هېڅکله نه بدلېږي. مرکزي او شریکه کار نشته |
| {{key:Mod+Z}} سره بېرته کول | د IFC بدلونونو باندې کار کوي تر هغې چې خوندي شي. [د IFC ملکیتونه بدل کړئ او بدل شوې کاپي خوندي کړئ](topic:edit-ifc-properties) |
| اړیکې مدیریت | د پروژې فولډر خلاص کړئ: هره اړیکه وڅیړل کېږي او په **په دې فولډر کې**، **ورته نوم وموندل شو**، **کتابتون فایل** یا **په دې فولډر کې نه دی** نښه کېږي. [یو ټول پروژه فولډر خلاص کړئ](topic:open-project-folder) |
| کتنه، یا فایل پرانیستل ترڅو وګورئ خراب دی که نه | د فولډر راپور هر کاپي او بیک اپ د پرې کېدو لپاره وڅیړي، په ثانیو کې. [د فولډر خرابې کاپي وڅیړئ](topic:check-folder-health) |
| په ګډوډ فولډر کې سم فایل ټاکل | د {{ui:دلته پیل کړئ}} بکس یو وړاندیز کوي، دلیلونو سره |

که تاسو ډېری وخت ماډلونه د ازموینې لپاره پرانیزئ، لکه د ماډل ازموینې یا IFC کتلو پروګرام، {{ui:لیدونکی}} مینو ډول وټاکئ: د لید او ازموینې اوزارونه لومړی راځي، او د جوړونې اوزارونه په یوه مینو کې انتظار کوي. وګورئ [مینوګانې، کیلي او موږک](topic:menus-keys-and-mouse).

## د DWG فایلونو کتلو څخه

که DWG فایلونه په AutoCAD یا DWG کتونکي کې پرانیزئ:

| که عادت لرئ | په BimCraft کې |
|---|---|
| ښکته د ماډل او ترتیب ټبونه | نقشې پورته ټبونه: {{ui:ماډل}} او هر شیټ لپاره یو |
| ZOOM Extents، د څرخ دوه ځله کلیک | دوه ځله کلیک، {{key:F}} یا {{ui:برابرول}} |
| منځنۍ تڼۍ سره حرکت | هر تڼۍ سره کش کړئ |
| د لایو مدیر | {{ui:لایې}} لیست: ټیک یې کړئ ترڅو وښایئ، ټیک یې لرې کړئ ترڅو پټ کړئ، {{ui:ټول فعال}} او {{ui:ټول غیر فعال}} |
| د xref مدیر | ښي خوا کې **تړلې نقشې**، د **ښکاره** یا **ونه موندل شو** سره، او {{ui:تړلې نقشې اضافه کول…}} |
| د چاپ مخکتنه | {{ui:د چاپ لید}} یا {{key:P}}: تور په سپین کې د کرښو پراخوالي سره. چاپ نه کوي |
| د بلاک ځانګړتیاوو استخراج | {{ui:تجهیزات}} ټب د نښه شوو خوړو خدماتو نقشو لپاره، {{ui:CSV ډاونلوډ کول}} سره |
| اندازه کول، کښل، سمول، په بل نوم خوندي کول | په BimCraft کې نشته. د CadCraft د کښلو اپلیکیشن دا کار کوي |

## هغه توپیرونه چې خلک ورته ستړي کیږي

- **دا په براوزر کې چلېږي، او براوزر ستاسو فایلونو سره محتاط دی.** BimCraft یوازې هغه فایلونه او فولډرونه لوستلی شي چې تاسو یې ورکوئ، په ټاکلو یا ډراګ کولو سره. دا پخپله فایل نشي پرانیستی، او نشي کولی پر یو فایل خوندي کړي. هر خوندي کول یو ډاونلوډ دی.
- **هېڅ نه پورته کېږي.** د براوزر فولډر کړکیو کې "پورته کول" ټکی د براوزر خپل ټکی دی. فایلونه ستاسو په کمپیوټر کې پاتې کېږي.
- **IFC د ماډل بڼه ده.** پروژه فایل د کارت په توګه پرانیستل کېږي ځکه چې د هغې 3D مینځپانګه نه ده تشریح شوې. IFC د ماډلونو لپاره وکاروئ.
- **بدلونونه د کاپي-پر-لیکلو دي.** د یو توکي ارزښت بدلول د هغه ګاونډیانو نه بدلوي، حتی کله چې صادر کوونکي دا ارزښت شریک کړی وي. د ډول ملکیتونه ځانګړی استثنا دي.
- **پروژه نشته، لیدونه نشته.** BimCraft یو وخت یو فایل ښیي او د تړلو وروسته یې هېڅ نه ساتي، پرته له هغو وروستیو فولډرونو له نومونو چې په Chrome او Edge کې دي.
- **Mac کیلي.** چیرې چې Revit د Windows کیلي Ctrl کاروي، BimCraft کیلي {{key:Mod}} کاروي: په Mac کې Command.
- **ستاسو د موږک عادتونه.** ګرځېدنه کیڼه تڼۍ ده، نه Shift او منځنۍ تڼۍ، مګر تر هغې چې {{ui:BIM ribbon}} مینو ډول وټاکئ یا تڼۍ په [مینوګانې، کیلي او موږک](topic:menus-keys-and-mouse) کې ځانته وټاکئ.

د نن ورځې بدیلونو لپاره [لا نه دي جوړ شوي](topic:not-built-yet) وګورئ.
