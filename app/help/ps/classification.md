## تاسو به څه وکړئ

یو طبقه بندي کوډ دیوالونو، فرشونو، چتونو، دروازو، کړکیو او هر بل شي ته ورکړئ چې ماډل کې دی، تر درې سیستمونو پورې یوځای: Uniclass، OmniClass او UniFormat. نور ډیسپلینونه او نور سافټویرونه په کوډ تکیه کوي، نه په نوم، نو کوډونه د IFC فایل کې د طبقه بندۍ حوالو په توګه ساتل کېږي چې هر BIM پروګرام یې لولي.

## عنصر ته کوډ ورکول

1. یو عنصر (یا ډېر) وټاکئ او **Properties** پرانیزئ. د {{ui:Classification}} برخه پرانیزئ.
2. د خپل سیستم په بکس کې کوډ ولیکئ او Enter کېکاږئ. کله چې د کوډ لیست بار شوی وي، د کوډ یوه برخه یا څو ټکي ولیکئ ("curtain wall") او له پرتلې څخه غوره کړئ: د کوډ سرلیک ستاسو لپاره ډکېږي.
3. {{ui:Applies to}} وایي کوډ چېرې ځي: **This element** یا **Its type (every element of the type)**. په دیوال ټایپ کې کوډ هر دیوال لولي چې په دې ټایپ وي، هغه هم چې وروسته ډیزاین کوئ.
4. {{ui:Clear}} کوډ لرې کوي.

د هرې سیستم لاندې برخه وایي چې کوډ له کومه دی: په دې عنصر ټاکل شوی، د خپل ټایپ څخه، یا د خپل ټولګي د پروژې ډیفالټ څخه. د عنصر خپل کوډ تل د ټایپ له کوډ څخه غالب دی، او د ټایپ کوډ د ډیفالټ څخه. کله چې ډېر عناصر وټاکل شي، بکس چې "varies" لیکي پدې مانا دی چې دوی یو کوډ نه شریکوي؛ یو ولیکل شي نو ټولو ته ورکول کېږي. هر بدلون یو بېرته کولو ګام دی.

کوډ تل لیکل کېږي، لیست پورته وي یا نه. که د دې سیستم کوډ ونه بریښي یا په بار شوي لیست کې نه وي، یوه اشاره دا وایي او کوډ لکه څنګه چې ولیکل شو ساتل کېږي.

## د پروژې سیستمونه وټاکئ

**Data** په ماډل بار کې پرانیزئ او {{ui:Classification}} وټاکئ (یا په Properties برخه کې {{ui:Project classification…}}).

- هغه سیستمونه ټیک کړئ چې پروژه یې کاروي. Properties بیا یوازې هغه ښيي.
- **Uniclass**: د Elements/ functions (EF)، Systems (Ss) او Products (Pr) جدولونه د اپلیکیشن سره راځي. دا د NBS لخوا دي، د Creative Commons Attribution-NoDerivatives 4.0 لاندې جواز لري، او بې بدلونه لېږدول کېږي. ډیالوګ د هرې جدول نسخه او هغه ورځ ښيي چې لوستل شوی. دا نوي جدولونه نه دي: خپرونکی هر ربع کال نوي جدولونه په خپل سایټ خپروي.
- **OmniClass** او **UniFormat**: د اپلیکیشن سره کوډ لیست نه راځي، ځکه خپرونکی جدولونه بې جوازه لېږدول نه غواړي. هر کوډ وليکئ، یا د خپل دفتر جوازلرونکی جدول پورته کړئ.
- {{ui:Load a table (CSV)…}} د دفتر خپل جدول د CSV فایل څخه لولي چې یو کوډ کالم او یو سرلیک کالم لري (د Code، Number یا Identifier او Title، Name یا Description سرلیک قطار خپلې موندل کېږي؛ که نه وي، لومړۍ دوه کالمونه کارول کېږي). جدول په همدې براوزر کې پاتې کېږي او هېڅکله په پروژې فایل کې نه اچول کېږي. یوازې هغه کوډونه چې تاسو ورکوئ په فایل کې ساتل کېږي. تاسو کولی شئ په همدې ډول نوی Uniclass جدول هم پورته کړئ.
- {{ui:Give elements a default code by their class}} هر دیوال، فرش، چت، دروازه، کړکۍ، زینه، ریمپ، ستون، تیر او فرنیچر ټوټه د Elements/ functions جدول څخه لومړنی Uniclass کوډ ورکوي کله چې خپل کوډ نه لري. هغه عناصر چې وروسته ډیزاین کوئ هم ترلاسه کوي.
- {{ui:Show the codes as columns in the schedules}} د هر سیستم لپاره یو کالم د Doors، Windows، Walls by type او Rooms جدولونو او د دوی CSV کې اضافه کوي. د ډېرو عناصرو قطار "varies" ښيي کله چې کوډونه توپیر ولري.

## ښه پوهېدل

- د ډیفالټ کوډونه د CadCraft خپل لومړنی انتخاب دي، نه د خپرونکي، او د یوه متخصص لخوا نه دي ازمول شوي. د خپل پروژې معیار سره یې وڅیړئ.
- په فایل کې ډیفالټ یوه ریښتینې طبقه بندي ده، د "CadCraft default" اړیکې نوم سره نښه شوې، او ورک کېږي کله چې عنصر یا ټایپ خپل کوډ ترلاسه کړي.
- هغه کوډونه چې یو مخکې راوړل شوی فایل لري لوستل او ښودل کېږي، په هر املا چې بل پروګرام د سیستم نوم لیکلی. د نورو سیستمونو کوډونه (د دفتر خپل) لیست کېږي او نه بدلېږي.
- کوډونه بیا لوستل کېږي کله چې فایل بیا پرانیستل شي، دلته یا په بل پروګرام کې. دوی د IFC5 alpha (IFCX) صادرولو کې هم وړل کېږي کله چې دا د لابراتوار اختیار فعال وي، پرته له هغه کوډ څخه چې په چت ټاکل شوی.
- جوړ شوي نه دي: د جدول د کچو په اساس د لټولو ونه، په پوړونو او خونو کې کوډونه د پروژې ډیفالټ په توګه، او د فایل ښکاره شوی نسخه د کوډ سره چک کول.
