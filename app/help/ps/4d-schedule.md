## هغه څه چې به ترسره کړئ

هغه ودانۍ وګورئ چې جوړېږي: ستاسو په مهالویش کې هره دنده د هغو عناصرو سره تړل شوې چې جوړوي، ورځ په ورځ ښودل شوي.

## ګامونه

1. یو IFC ماډل پرانیزئ او د کیڼ پینل کې {{ui:4D schedule}} پرانیزئ.
2. د دندو لیست لپاره چې د هر پوړ لپاره یوه اونۍ لري، {{ui:Download a template}} کلیک کړئ او په سپریډشیټ کې یې بدل کړئ. یا خپل لیست ولیکئ.
3. {{ui:Open a task list…}} کلیک کړئ او CSV وټاکئ.
4. د نیټې سلایډر کش کړئ، یا {{ui:Play}} کلیک کړئ.

## د دندو لیست

یو CSV چې د سرلیک قطار او ستونونه **Task**، **Start**، **Finish**، **Field** او **Value** لري. کاما یا سیمي کولون دواړه کار کوي.

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| Level 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| Roof | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| Roof | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- نیټې د YYYY-MM-DD په بڼه ولیکئ.
- یو قطار دندې ته هر هغه عنصر تړي چې **Field** یې د دې **Value** سره په سم ډول سمون ولري. ساحه یو ملکیت دی لکه Storey، Class، Name، Type، Material، Tag یا GlobalId، یا هر ملکیت چې د خپل set او نوم په بڼه ولیکل شي: `Pset_WallCommon.FireRating`.
- یوه دنده په ډېرو قطارونو کې تکرار کړئ، د ورته نیټو سره، ترڅو ډېر عناصر ورسره وتړل شي.

## پړاوونه او د کار بستې

یو **Stage** ستون، یو **Package** ستون، یا دواړه ورزیات کړئ، ترڅو دندې په پړاوونو او د کار بستو کې راټولې شي. Phase او WBS هم د ستون نومونو په توګه کار کوي.

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| Level 1 slab | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| Level 1 walls | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| Doors | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- یوه دنده یو پړاو او یوه بسته لري. که د ورته دندې وروستی قطار بل نوم وښيي، هغه قطار د خپل کرښې شمېرې سره لیست کېږي او پرېښودل کېږي.
- د یوې بستې ورته نوم په دوو پړاوونو کې دوه بستې دي.

کله چې لیست ډلې ولري، د نیټې پورته یو {{ui:Show}} لیست ښکاري. یو پړاو یا بسته وټاکئ او دا د یوه واحد په توګه چلېږي:

- سلایډر او {{ui:Play}} د ډلې له لومړني پیل څخه تر وروستي پای پورې چلېږي،
- یوازې د ډلې دندې لیستل کېږي او رنګ کېږي، او د ډلې بهر هر څه شفاف وي،
- د لیست لاندې کرښه ښيي چې په هغه نیټه کې د دې دندو کوم شمېر بشپړ دي، روان دي او راتلونکي دي،
- {{ui:Select its elements}} د ډلې ټول عناصر ټاکي، د {{ui:Show}}، {{ui:Section}} یا جدول لپاره.

د ټول مهالویش د بیا لیدلو لپاره **هره دنده** وټاکئ.

## څه باید وویني

- **جوړ شوی**: هغه عناصر چې ټولې دندې یې بشپړې شوې، په خپلو رنګونو کې.
- **پرمختګ کې**: هغه عناصر چې په هغه ورځ کې روانه دندې ولري، په ژېړ-نارنجي رنګ. یوه دنده د خپلې پیل نیټې څخه تر خپلې پای نیټې پورې روانه ده.
- **لا پیل شوي نه دي**: شفاف.
- هغه عناصر چې په هېڅ دنده کې نه دي، خپل حال ساتي. لیست ښيي چې هره دنده څو عنصر موندلي. هغه قطارونه چې نه شي لوستل کېدای یا هېڅ نه وي موندلي، د خپلو کرښو شمېرو سره لیست کېږي.

## اړیکې، د ګانټ چارټ او MS Project

- یو Microsoft Project XML فایل (`.xml`) یا CSV پرانیزئ چې `Predecessors` ستون ولري. اړیکې کېدای شي پای تر پیل، پیل تر پیل، پای تر پای یا پیل تر پای وي، هر یو د ورځو په ځنډ یا مخکې والي سره.
- د دندو لیست لاندې، ګانټ چارټ هره دنده د بار په توګه انځوروي، د اړیکو لپاره د تیرو سره. په اصلي لاره کې دندې سرې دي. د اړیکو حلقه یا یو شتون نلرونکی مخکښ په پینل کې لیست کېږي.
- {{ui:Save as MS Project XML}} او {{ui:Save CSV with links}} مهالویش د خپلو اړیکو سره بیرته لیکي.
