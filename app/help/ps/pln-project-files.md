## تاسو به څه وکړئ

یوه پروژه چې `.pln` (پروژه)، `.pla` (آرشیف د خپل کتابتون سره)، `.tpl` (کينډۍ) یا `.bpn` (بیک اپ) په توګه خوندي شوې وي، BimCraft ته راولئ. دا د Archicad خپل فایلونه دي.

## اوس څه پرانیستل کیږي

- **د پروژې فایلونه اوس پخپله نه پرانیستل کیږي.** د دوی بڼه نه ده خپره شوې، او BimCraft تر اوسه نه لولي. کله چې یو فایل پرانیزئ، BimCraft دا ویلی او دلته اشاره کوي.
- **BimCraft د فایل لومړني بایټونه چک کوي.** له نسخې 17 راهیسې Archicad پروژې په ورته لنډ نښان پیلیږي، نو BimCraft کولی شي په ډاډ سره ووایي چې فایل د Archicad پروژه ده. هغه فایل چې د Archicad نوم لري خو په دې ډول نه پیلیږي، احتمال لري نوم یې بدل شوی وي، خراب وي یا له زاړه نسخې راغلی وي. نښان د پروژې، آرشیف او کينډۍ ترمنځ توپیر نه شي کولی.
- **IFC صادرول په بشپړه توګه پرانیستل کیږي**: ماډل په 3D کې، پوړونه، سیمې د ځایونو په توګه، د عنصر معلومات، د ملکیت سیټونه او طبقه بندۍ، د ټولو BimCraft وسیلو سره.
- **DWG صادرول په 2D لید کې پرانیستل کیږي**، د خپلو لایو او پاڼو سره، او په {{ui:3D}} کې. د سمون لپاره، {{ui:CadCraft کې سمول}} وکاروئ.

یا ټول پروژه د یوه zip فایل په توګه راولئ، د خپلو لیدونو، پاڼو او ملکیت ډلو سره: وګورئ [یوه د پروژې بنډل پرانیستل](topic:open-project-bundle).

## IFC صادرول (ماډل)

1. پروژه په Archicad کې پرانیزئ.
2. **File > Save As** وټاکئ، او د فایل ډول په توګه **IFC** وټاکئ.
3. IFC ژباړونکی وټاکئ (د Archicad نوم د IFC صادراتو امستنو د یوې ټولګې لپاره). د BimCraft لپاره **IFC4 Reference View** یا **IFC2X3 Coordination View 2.0** مناسب دي. IFC4X3 هم پرانیستل کیږي.
4. وټاکئ څه صادر شي: ټوله پروژه، یا یوازې هغه عناصر چې په هغو پوړونو کې دي چې تاسو یې ګورئ.
5. وژغورئ، بیا BimCraft کې {{ui:فایل وټاکئ}} کلیک وکړئ او `.ifc` فایل وټاکئ.

صادرولو دمخه د ژباړونکي په امستنو کې دا وګورئ:

- **سیمې**: صادري یې کړئ، ترڅو خونې د ځایونو په توګه راشي. BimCraft کې {{ui:ځایونه}} کلیک وکړئ چې وینئ.
- **ملکیتونه او طبقه بندۍ**: صادري یې کړئ، ترڅو په {{ui:ملکیتونه}} کې ښکاره شي او په {{ui:پلټنه}}، {{ui:رنګ}} او {{ui:د مقدارونو مجموعې}} کې وکارول شي.
- **ساده `.ifc`**، نه `.ifczip` یا `.ifcxml`. BimCraft یوازې ساده `.ifc` پرانیزي.

## DWG صادرول (نقشې)

1. هغه پلان، برخه یا لایوت پرانیزئ چې غواړئ.
2. **File > Save As** وټاکئ، او **DWG** د فایل ډول په توګه وټاکئ.
3. DXF-DWG ژباړونکی وټاکئ، او وژغورئ.
4. د پاڼو ټولې ټولګې لپاره، لایوتونه د Layout Book څخه وژغورئ، یا یې د DWG په توګه خپاره کړئ.
5. `.dwg` په BimCraft کې پرانیزئ. هغه نقشې چې صادرات یې تړلي دي، که په ورته فولډر کې وي، ورسره پرانیستل کیږي؛ وګورئ [تړل شوي نقشې او انځورونه](topic:dwg-linked-files).

## ستونزې حل کول

- **"… is an Archicad project: its first bytes say so."** … د Archicad پروژه ده: لومړني بایټونه دا وايي. پورته ډول IFC یا DWG صادر کړئ، او هغه فایل پرانیزئ.
- **"… is named like an Archicad file but does not start like one."** … د Archicad فایل په څېر نوم لري، خو داسې نه پیلیږي. وګورئ فایل له کوم ځای راغلی: شاید بل ډول فایل وي چې نوی نوم لري (هڅه وکړئ د خپل اصلي توسیع لاندې یې پرانیزئ)، نابشپړ کاپي، یا د نسخې 17 دمخه پروژه. که کولی شئ، په Archicad کې یې پرانیزئ، بیا IFC یا DWG صادر کړئ.
- **ماډل پرته له خونو پرانیستل کیږي.** سیمې نه دي صادرې شوي. په IFC ژباړونکي کې یې فعال کړئ او بیا صادر کړئ.
- **پرانستې نه دي پرې شوي.** BimCraft دا په {{ui:فایل}} پاینل کې د **Not drawn yet** لاندې ښيي. بیا صادر کړئ؛ که پاتې شي، ماډل په هغه برنامه کې پرانیزئ چې جوړ یې کړی، او پرانستې هلته وګورئ.
- **په DWG کې متن بل ډول ښکاري.** صادرات ممکن هغه فونټونه وساتي چې BimCraft یې نه لري؛ BimCraft متن په ساده sans-serif فونټ انځوروي.

وګورئ هم [د IFC له لارې پروژه فایل په 3D کې ترلاسه کول](topic:rvt-to-ifc) او [BimCraft له هر بڼې څه لولي](topic:file-formats).
