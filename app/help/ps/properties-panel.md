## IFC عنصر

د {{ui:ملکیتونه}} پاینل پورته د عنصر ډول د "Ifc" مختاړي پرته ښيي (د مثال په توګه "Door"، "WallStandardCase"، "FurnishingElement") او نوم یې، یا "نوم نلري".

| ساحه | معنا | بدلېدای شي |
|---|---|---|
| نوم | د عنصر نوم، ډیرځله د کورنۍ او ډول نوم له صادرونکي څخه | هو |
| ډول | د عنصر د ډول نوم، کله چې یې ولري | نه |
| د شيء ډول | د متن ډول تشریح چې ځینې صادرونکي ډکوي | هو |
| ټګ | د عنصر ټګ یا نښه؛ ډیری صادرونکي دلته د عنصر ID ليکي | هو |
| تشریح | ازاد متن | هو |
| GlobalId | د عنصر دایمي 22-توری IFC پیژندنه، په هر صادرات کې ورته | نه |
| کرښه | د عنصر کرښې شمېره (`#1234`) په دې IFC فایل کې. د صادراتو تر منځ بدلېږي | نه |

لاندې د **ملکیت سیټونه** دي، د نوم له مخې ترتیب شوي:

- هر سیټ کلیک په نوم خلاصېږي او تړل کیږي. لومړني درې خلاص وي.
- هغه سیټ چې "(type)" نښه لري د عنصر د ډول پورې اړه لري: "د ډول ملکیت: دلته بدلون د دې ډول ټولو عنصرونو ته پلی کیږي."
- د مقدار سیټونه (اوږدوالی، سطحې، حجمونه، شمېرې، وزنونه) یوازې لوستل کیږي.
- لیستونه او شمارل شوي ارزښتونه ښودل کیږي، یوازې لوستل کیږي.
- هو/نه ارزښتونه د **هو** یا **نه** په توګه ښکاره کیږي.
- شمېرې د ښودلو لپاره تر څلورو لسیزو پورې ګردېږي. اوږدوالي (د اوږدوالي ملکیت یا د مقدار اوږدوالی) د {{ui:واحدونه}} له مخې ښکاره کیږي چې په بار کې ټاکل شوي، د واحد نښې سره، او تاسو کولی شئ نوی ارزښت په همغه واحد یا په بل واحد نښه سره ولیکئ (2.4 m، 8'-0"): BimCraft د فایل خپله شمېره بېرته لیکي. نورې شمېرې لکه څنګه چې فایل یې لري ښکاره کیږي.
- خالي ارزښت د *خالي* په توګه ښکاره کیږي. بدل شوی ارزښت تور دی او د نیلي کرښې سره یې څنګ کې.

## ارزښت کاپي کول

په {{ui:ملکیتونه}} کې هر ارزښت د یوې کوچنۍ کاپي تڼۍ سره دی: کلیک یې وکړئ ترڅو هغه ارزښت لکه څنګه چې ښودل شوی په کلپ بورډ کې واچوي، د مثال په توګه GlobalId، سریال شمېره یا د ملکیت سیټ هر ارزښت. کاپي کول هېڅکله بدلون نه پیلوي.

په پورته برخه کې، {{ui:ټول کاپي کول}} د عنصر ټول ارزښتونه د متن په توګه کاپي کوي، سیټ په سیټ، او {{ui:د CSV په توګه کاپي کول}} یې د ډلې، ملکیت او ارزښت د قطارونو په توګه کاپي کوي چې په سپریډشیټ کې واچول شي؛ خالي ارزښتونه ساتل کیږي ترڅو هر ساحه قطار ولري. دا د بل پرانیستل شوي ماډل عنصر لپاره هم همدغسې کار کوي؛ کله چې له یو څخه ډیر ماډلونه پرانیستل شوي وي، CSV د Model کالم سره پیلیږي چې د فایل نوم یې ورکوي.

## د IFC فایل پاینل

| ساحه | معنا |
|---|---|
| فایل، اندازه | هغه فایل چې پرانیستی یې |
| Schema | د IFC نسخه، لکه IFC2X3 یا IFC4 |
| پروژه | د پروژې نوم او اوږد نوم |
| پړاو | د پروژې پړاو، که صادرونکي لیکلی وي |
| له چا صادر شوی | صادرونکې برنامه، د فایل له سرلیک |
| لیکوال | لیکوال د فایل په سرلیک کې |
| صادر شوی | نېټه او وخت د فایل په سرلیک کې |
| عناصر | څو عناصر چې شکل لري انځور شوي |
| مثلثونه | څو مثلثونه شکلونه جوړوي؛ د ماډل د درنوالي اندازه |
