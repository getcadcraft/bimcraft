یوه ضمیمه (امستنې › ضمیمه) کولی شي د {{ui:رنډر}} د انجن لیست ته یو انجن اضافه کړي. د ضمیمې د لیکوالانو لپاره بشپړ متن د ضمیمې مشخصاتو 16 برخه ده؛ په لنډ ډول:

- ضمیمه یو انجن د یو ID سره ثبتوي چې د خپل نوم سره پیل کېږي، یو نوم، اختیاري امستنې، **یا** یو برنامه چې باید وچلول شي **یا** یو فنکشن په JavaScript کې چې انځور جوړوي.
- هغه انجن چې برنامه چلوي د **`engine.run`** اجازې ته اړتیا لري، چې نصب کولو دمخه او په امستنو کې ښودل کېږي. دا یوازې په Studio کې چلېږي؛ په براوزر کې دا د ساتلو فایل په توګه ښکاري.
- ضمیمه برنامه نوملي (یو ساده فایل نوم، هېڅکله shell نه)، یو سکریپت چې **د لاسلیک شوې ضمیمې دننه** دی، او دلیلونه چې د ځای‌ نیونکو او ساده کلمو څخه جوړ دي. Studio برنامه پیدا کوي یا یو ځل تاسو ته وايي چې ورته اشاره وکړئ.
- لومړی ځل چې یوه ضمیمه برنامه چلوي، **Studio په خپل ډیالوګ کې له تاسو پوښتنه کوي**: کومه ضمیمه، کومه برنامه، او دا چې سکریپت کولی شي هرڅه وکړي چې برنامه یې کولی شي. یوازې هغه ضمیمه اجازه ورکړئ چې باور ورباندې لرئ. ستاسو ځواب د دې ضمیمې او برنامې لپاره ساتل کېږي.
- بسته (صحنه د USD په توګه او یوه امستنې فایل، د glTF فایل سره کله چې ضمیمه یې وغواړي) او د ضمیمې سکریپت یو نوي موقت فولډر ته ځي، برنامه هلته چلېږي، او انځور د ضمیمې د انجن په نوم نښه شوی بېرته راځي.

:::note
ضمیمې یوازې د ضمیمې API 1.4 څخه رنډر انجنونه اضافه کولی شي. یو کار شوی مثال د یو خلاص‌سرچینې کمانډ-لاین رنډر لپاره په خپل ریپازیټوري کې دی؛ دا لا په دې رنډر کې نه دی چلول شوی.
:::
