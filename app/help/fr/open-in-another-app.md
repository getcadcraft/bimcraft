## Ce que vous allez faire

Poursuivre le travail sur un fichier dans l'application prévue pour la tâche suivante, sans l'enregistrer puis le rouvrir.

## Étapes

1. Ouvrez un dessin DWG ou DXF pour le modifier dans l'application de dessin, ou un modèle IFC pour le détailler dans l'application de détaillage.
2. Cliquez sur {{ui:Modifier dans CadCraft}} sur la vue 2D d'un dessin, ou sur {{ui:Ouvrir dans DetailCraft}} dans la barre d'outils d'un modèle.
3. L'autre application s'ouvre dans un nouvel onglet, avec le fichier déjà ouvert.

## Ce que vous devez voir

- Le fichier dans le nouvel onglet. BimCraft le garde ouvert également.
- Un modèle avec des modifications non enregistrées est transmis avec ces modifications. Votre propre copie n'est pas enregistrée.
- Un dessin est transmis sans ses dessins liés.

## Bon à savoir

- Le fichier passe d'un onglet à l'autre dans votre navigateur. Rien n'est téléversé.
- Un bouton n'apparaît que si l'autre application est ouverte là où vous êtes et peut recevoir un fichier de cette façon.
- Si rien ne s'ouvre, le navigateur a bloqué le nouvel onglet : autorisez les fenêtres surgissantes pour ce site, puis cliquez à nouveau.
