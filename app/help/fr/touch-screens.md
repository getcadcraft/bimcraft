BimCraft fonctionne avec les doigts comme avec une souris. La première fois que vous touchez l'écran, les boutons, les onglets et les lignes de liste s'agrandissent à la taille d'un doigt.

## Le modèle 3D

| Pour | Action |
|---|---|
| Orbiter | Faites glisser un doigt |
| Zoomer | Pincez avec deux doigts en les écartant ou en les rapprochant |
| Faire un panoramique | Faites glisser deux doigts ensemble |
| Sélectionner un élément | Touchez-le |
| Ajouter un élément à la sélection, ou le retirer | Appuyez de façon prolongée dessus pendant une demi-seconde (identique à {{key:Ctrl}}+clic) |
| Ne rien sélectionner | Touchez un espace vide |

Un pincement ou un glissement à deux doigts ne sélectionne jamais rien, même lorsqu'un doigt se lève au-dessus d'un élément.

## Dessins (DWG et DXF)

| Pour | Action |
|---|---|
| Faire un panoramique | Faites glisser un doigt |
| Zoomer | Pincez ; le point situé entre vos doigts reste en place |
| Afficher la feuille entière | Touchez deux fois, ou touchez {{ui:Fit}} |

Dans la vue {{ui:3D}} d'un dessin, les gestes du modèle s'appliquent : un doigt fait orbiter, deux doigts pincent et font un panoramique, un toucher sélectionne, et un appui prolongé ajoute à la sélection.

## Marche

Touchez {{ui:Walk}}, puis touchez le sol où vous voulez vous tenir. Une rangée de boutons fléchés apparaît dans la barre de marche :

- Maintenez une flèche pour avancer, reculer ou faire un pas latéral.
- Lorsque {{ui:Gravity}} est désactivé, les doubles flèches montent et descendent.
- Faites glisser un doigt sur le modèle pour regarder autour de vous.
- Touchez {{ui:Done}} pour arrêter.

## Placer des éléments de bibliothèque

Touchez l'endroit où l'élément doit être placé. {{ui:Turn 90°}} sur la barre de placement le fait pivoter (la touche {{key:R}} d'un clavier), {{ui:Wall snap}} le cale par l'arrière sur le mur le plus proche, et {{ui:Stop placing}} termine l'opération.

## Mesurer

Touchez le premier point, puis le second. Les points s'alignent sur les angles et les arêtes proches de votre toucher.

:::tip
Avec un clavier connecté à une tablette, tous les raccourcis fonctionnent comme sur un ordinateur. Voir [Raccourcis clavier](topic:keyboard).
:::
