## ဘာလုပ်မလဲ

နံရံ၊ ကော်လံ၊ ကြမ်းပြင် သို့မဟုတ် ထားထားသော စာကြည့်တိုက် ပစ္စည်းတစ်ခုကို နေရာအသစ်သို့ ရွှေ့ပါ၊ မိတ္တူများ ပြုလုပ်ပါ၊ သို့မဟုတ် အများအပြားကို တန်းစီပါ၊ ပြန်ဆွဲစရာ မလိုပါ။

## အမည်များနှင့် ခလုတ်များ

Command များကို {{ui:Move}}၊ {{ui:Align}} နှင့် {{ui:Distribute}} ဟု ခေါ်ပြီး command line တွင် `MOVE`၊ `ALIGN` နှင့် `DISTRIBUTE` ကို ရိုက်နိုင်သည်၊ CadCraft drafting app ကဲ့သို့ပင်။ ကွာခြားချက်တစ်ခု: BimCraft တွင် {{key:M}} သည် Measure ဖြစ်သောကြောင့် Move တွင် ၎င်း၏ကိုယ်ပိုင် ခလုတ် {{key:Shift+M}} ရှိသည်။ ကိရိယာများသည် {{ui:Build}} မီနူးတွင် ရှိသည်။

## ရွှေ့ရန် (Move)

1. ရွှေ့မည့်အရာကို ပလန်ပေါ် သို့မဟုတ် 3D view တွင် ရွေးပါ။ နံရံများ၊ ကြမ်းပြင်များ၊ ကော်လံများနှင့် ထားထားသော စာကြည့်တိုက် ပစ္စည်းများကို ရွေးချက်တစ်ခုတည်းတွင် ထည့်နိုင်သည်။
2. {{key:Shift+M}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:Move}} ကို ရွေးပါ။
3. Base point ကို နှိပ်ပြီး ဒုတိယအမှတ်ကို နှိပ်ပါ။ သို့မဟုတ် base point ပြီးနောက် အကွာအဝေးကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ- base point မှ ညွှန်ပြသော ဘက်သို့ သွားသည်။ `dx,dy` (သို့မဟုတ် `@dx,dy`) သို့မဟုတ် `length<angle` ကိုလည်း ရိုက်နိုင်သည်။
4. {{ui:Copy}} ကို ဖွင့်ရန် {{key:C}} ကို နှိပ်ပါ- ထို့နောက် ရွှေ့ခြင်းတိုင်းသည် မိတ္တူများ ပြုလုပ်ပြီး နောက်တစ်ခုအတွက် အသင့်ရှိနေသည်။ ရပ်ရန် {{key:Esc}} ကို နှိပ်ပါ။

အမှတ်နှစ်ခုစလုံးကို 3D view တွင်လည်း နှိပ်နိုင်သည်- Move ဖွင့်ထားစဉ် ညွှန်ပြချက်သည် အထပ်၏ ကြမ်းပြင်အမြင့်ကို တွေ့သဖြင့် ထိုနေရာကို နှိပ်လျှင် ပလန်၏ အမှတ်တစ်ခု ဖြစ်သည်။ အခြားအစိတ်အပိုင်းကို ရွေးလိုပါက နှိပ်စဉ် {{key:Shift}} ကို ဖိထားပါ။ ပလန်၊ အပေါ် (Top)၊ ရှေ့ (Front) သို့မဟုတ် ဘေးမြင် (Side) view ကို သင်နှစ်သက်သလို သုံးပါ- အမှတ်များသည် အမြဲ ထိုအထပ်ပေါ်တွင် ရှိနေသည်။

နံရံတစ်ခုသည် ၎င်း၏ တံခါးနှင့် ပြတင်းပေါက်များကို ယူသွားသည်။ ဆွဲထားသော ကြမ်းပြင်တစ်ခုသည် ၎င်း၏ အပေါက်များကို ယူသွားသည်။ နံရံများကို လိုက်သော အခန်းများ၊ ကြမ်းပြင်များနှင့် မျက်နှာကြက်များကို အသစ်ပြုပြင်သည်။ ရွှေ့သော နံရံနှင့် ဆက်ထားသော နံရံများသည် ၎င်းတို့၏ နေရာတွင် ရှိနေသည်။

ရွှေ့ခြင်းတစ်ခုစီသည် ပြောင်းလဲမှု တစ်ခုဖြစ်သည်: {{key:Mod+Z}} တစ်ကြိမ်ဖြင့် ပြန်ဖျက်နိုင်ပြီး Live TeamWork session တွင် လူတိုင်းသို့ ရောက်သွားသည်။ ထားထားသော စာကြည့်တိုက် ပစ္စည်းကို ဤနည်းဖြင့် မကူးနိုင်ပါ; {{ui:Edit}} › {{ui:Copy}} နှင့် {{ui:Paste}} ကို သုံးပါ။

## ညှိရန် (Align)

အစိတ်အပိုင်း နှစ်ခု သို့မဟုတ် ထို့ထက်ပိုကို ရွေးပါ၊ {{ui:Align}} ကို ရွေးပါ၊ ထို့နောက် ဘက် (ဘယ်၊ ဗဟို၊ ညာ၊ အပေါ်၊ အလယ် သို့မဟုတ် အောက်) နှင့် ညှိရမည့်အရာ: ရွေးထားသော အစုအဝေး၊ ပထမ ရွေးထားသည်၊ နောက်ဆုံး ရွေးထားသည်၊ သို့မဟုတ် သင်နှိပ်သော အမှတ်။ ဘားရှိ {{ui:Align}} ကို နှိပ်ပါ။

## ခွဲဝေရန် (Distribute)

အစိတ်အပိုင်း သုံးခု သို့မဟုတ် ထို့ထက်ပိုကို ရွေးပါ၊ {{ui:Distribute}} ကို ရွေးပါ၊ ထို့နောက် ဦးတည်ရာ (ဘေးတလျှောက် သို့မဟုတ် အောက်သို့) နှင့် အကွာအဝေး: ၎င်းတို့ကြား ခြားနားချက် ညီမျှခြင်း သို့မဟုတ် ဗဟို ညီမျှခြင်း။ အဆုံးရှိ နှစ်ခုသည် ၎င်းတို့၏ နေရာတွင် ရှိနေသည်။

ညှိခြင်း သို့မဟုတ် ခွဲဝေခြင်းဖြင့် ရွှေ့သော နံရံများသည် Move ကဲ့သို့ ၎င်းတို့၏ ဆက်စပ်မှုကို ထိန်းထားသည်: ရွှေ့သော နံရံနှင့် ဆက်ထားသော နံရံသည် ၎င်း၏ ကိုယ်ပိုင်မျဉ်းပေါ်တွင် အဆုံးကို ဆွဲရွှေ့ပြီး ဆက်နေစေသည်၊ ထိုနံရံကို ထိုးဝင်နေသော ကန့်လန့်နံရံများသည် လိုက်ပါသည်၊ ရွှေ့နေသော ဆက်ထားသော နံရံနှစ်ခုစလုံး၏ ထောင့်သည် ၎င်းတို့၏ လိုင်းအသစ်များ ဆုံသော နေရာတွင် ရှိနေသည်။ အခန်းများ ပိတ်နေဆဲ ဖြစ်သည်။ ၎င်းသည် **ပြောင်းလဲမှုများ** တွင် အဆင့်တစ်ခု ဖြစ်သည်။
