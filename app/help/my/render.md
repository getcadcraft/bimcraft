toolbar ပေါ်ရှိ {{ui:Render}} က 3D view ၏ နေ့ရောင်ပုံဆင်တူသော ရုပ်ပုံကို ထုတ်သည်: ကောင်းကင်၊ site ၏ latitude က နေကို ထားသည့်နေရာ၊ နူးညံ့သော အရိပ်၊ ကောင်းကင်တစ်ခုလုံးမှ အလင်းကြောင့် မှောင်သော ထောင့်များ၊ နှင့် ဖန်သို့မဟုတ် သတ္တုကဲ့သို့ မြင်ရသော အရောင်များ။ မော်ဒယ်နှင့် ဖိုင်ကို ပြောင်းလဲမည် မဟုတ်ပါ။

## view ကို render လုပ်ရန်

1. ရုပ်ပုံအတွက် လိုချင်သည့်အတိုင်း 3D view ကို သတ်မှတ်ပါ: orbit နှင့် zoom၊ မလိုသော storey သို့မဟုတ် element များကို ဖျောက်ပါ၊ ပုံက ဖြတ်ထားသည်ကို ပြလိုလျှင် [section](topic:section-plane) ကို သတ်မှတ်ပါ။
2. toolbar ပေါ်ရှိ {{ui:Render}} ကို နှိပ်ပါ။
3. နှိပ်ထားသည်မှာ မလိုချင်ပါက {{ui:Scene}} ကို ရွေးပါ ([Scene presets](topic:render#scene-presets-a-good-picture-in-one-click) ကို ကြည့်ပါ)၊ {{ui:Size}} ကို ရွေးပါ၊ ထို့နောက် dialog ရှိ {{ui:Render}} ကို နှိပ်ပါ။

   ရုပ်ပုံသည် render လုပ်နေစဉ် ဖြည့်ဝင်လာပြီး pass တိုင်းတွင် ပိုချောမွေ့လာသည်။ {{ui:Stop}} (သို့မဟုတ် {{key:Esc}}) က စောစောရပ်စေပြီး ထိုအချိန်အထိ ရုပ်ပုံကို ထိန်းထားသည်။

4. {{ui:Save}} ကို နှိပ်၍ PNG အဖြစ် download လုပ်ပါ၊ သို့မဟုတ် အခြားဖော်မတ်အတွက် {{ui:Save as}} ([ရုပ်ပုံ သိမ်းခြင်း](topic:render#save-the-picture) ကို ကြည့်ပါ)။ မော်ဒယ်ဖိုင်အမည်ဖြင့် အမည်ပေးသည်။

:::tip
ပထမ {{ui:Draft}} ကို {{ui:The view's size}} ဖြင့် စတင်ပြီး ကင်မရာကို စစ်ဆေးပါ၊ ထို့နောက် နောက်ဆုံးရုပ်ပုံအတွက် {{ui:Good}} သို့မဟုတ် {{ui:Best}} ကို ပိုကြီးသော size ဖြင့် render လုပ်ပါ။
:::

## Scene presets: တစ်ချက်နှိပ်ဖြင့် ကောင်းသော ရုပ်ပုံ

dialog ၏ အထက်ပိုင်းတွင် {{ui:Scene}} ခလုတ် လေးခု ရှိသည်။ နှိပ်တိုင်း ကောင်းကင်၊ လင်းအား၊ မြေပြင်၊ အနားသတ်မျဉ်းများ၊ အရည်အသွေးနှင့် နေကို တစ်ချက်နှိပ်ဖြင့် သတ်မှတ်သည်၊ ထို့ကြောင့် ပထမရုပ်ပုံမတိုင်မီ ဘာမျှ သင်ယူစရာ မလို။ တစ်ခုကို နှိပ်ပြီး {{ui:Render}} ကို နှိပ်ပါ။

| {{ui:Scene}} | ဘာကို သတ်မှတ်သလဲ | ဘာအတွက် သုံးသလဲ |
|---|---|---|
| {{ui:Exterior}} | ကြည်လင်သော ကောင်းကင်၊ မော်ဒယ်၏ ကိုယ်ပိုင် နေ၊ မြေပြင် ဖွင့် | အဆောက်အအုံ အပြင်မှ |
| {{ui:Interior}} | တိမ်ဖုံးသော ကောင်းကင် (အလင်း ညီညာ၊ နေ၏ အစင်းအကွက် မရှိ)၊ အဆင့်တဝက် ပိုလင်း | အခန်းအတွင်းမှ မြင်ကွင်း |
| {{ui:Section view}} | အဖြူရောင် စတူဒီယို၊ မြေပြင် မရှိ၊ မြန်ဆန်သော render တွင် အနားသတ်မျဉ်းများ | section ဖြင့် ဖြတ်ထားသော မော်ဒယ် |
| {{ui:Night}} | နေ ဝင်ထားသည် (site ၏ ဘက်ခြမ်းအတွက် ဆောင်းရာသီ သန်းခေါင်)၊ အဆင့်တစ်ခု ပိုလင်း | မော်ဒယ်ကို မီးလုံးများက ထိုးထွန်းခြင်း။ မီးလုံးမရှိလျှင် ပုံမှောင်သည် |

- {{ui:Pick for this view}} က သင့်အတွက် ရွေးပေးသည်: section ဖြတ်ချက် ဖွင့်ထားလျှင် {{ui:Section view}}၊ ကင်မရာ မော်ဒယ်အတွင်း ရှိလျှင် {{ui:Interior}}၊ အခြား အခါတွင် {{ui:Exterior}}။ dialog ကို ပထမဆုံး ဖွင့်သည့်အခါ ဤနည်းဖြင့် ကိုယ်တိုင် စတင်သည်။
- ဆက်တင် အားလုံးသည် အောက်တွင် ရှိနေပြီး ပြောင်းနိုင်သည်။ မြင်ကွင်း သတ်မှတ်ထားသော တန်ဖိုးတစ်ခုကို ပြောင်းလိုက်သည်နှင့် ခလုတ် မနှိပ်ထားတော့ဘဲ ခလုတ်အောက် မျဉ်းက ဆက်တင်များ သင့်ကိုယ်ပိုင်ဖြစ်ကြောင်း ပြောသည်။ မြင်ကွင်းကို ထပ်နှိပ်၍ ၎င်း၏ တန်ဖိုးများ ပြန်ထားပါ။
- မြင်ကွင်းသည် engine၊ မုဒ်၊ အရွယ်အစား၊ ပစ္စည်းများ၊ ကင်မရာ သို့မဟုတ် မီးလုံးများကို မထိပါ။

:::note
မြင်ကွင်းများသည် ModelCraft နှင့် BimCraft တွင် တန်ဖိုးတူညီသည်။ ပြီးစီးသော ရုပ်ပုံ ပုံစံသည် သင့်မော်ဒယ်နှင့် graphics card ပေါ် မူတည်သည်။
:::

## ရုပ်ပုံတွင် ပေါ်သည့်အရာ

3D view တွင် အစိုင်အခဲအဖြစ် ပြသသည့်အရာ: ဖျောက်ထားသော နှင့် ဖောက်ထွင်းမြင်ရသော element များ၊ ဖျောက်ထားသော storey များနှင့် ဖျောက်ထားသော မော်ဒယ်များကို ချန်ထားသည်၊ နှင့် {{ui:Spaces}} ဖွင့်ထားမှသာ အခန်းများ ပေါ်သည်။ section plane သို့မဟုတ် section box သည် view ကို ဖြတ်သကဲ့သို့ ရုပ်ပုံကိုလည်း ဖြတ်သည်။ Element များသည် ကိုယ်ပိုင်အရောင်ဖြင့် ပြသည်: property ဖြင့် အရောင်ခြယ်ခြင်း ({{ui:Color}} tab) ကို မသုံးပါ။

## ဆက်တင်များ

| ဆက်တင် | ဘာလုပ်သလဲ |
|---|---|
| {{ui:Size}} | view ၏ အရွယ်အစား၊ view ၏ နှစ်ဆ၊ Full HD၊ 4K သို့မဟုတ် စတုရန်း |
| {{ui:Mode}} | {{ui:Fast}}၊ သို့မဟုတ် အောက်ရှိ {{ui:High quality (path traced)}} နှင့် ၎င်း၏ {{ui:Time limit}} |
| {{ui:Quality}} | pass အရေအတွက် (သို့မဟုတ် အရည်အသွေးမြင့်တွင် sample များ) ပျမ်းမျှယူသည်: {{ui:Draft}} 16၊ {{ui:Good}} 64၊ {{ui:Best}} 256။ pass ပိုများလျှင် အရိပ်နှင့် အနားသတ်များ ပိုချောမွေ့ပြီး ပိုကြာသည် |
| {{ui:Sky}} | {{ui:Clear sky}}၊ {{ui:Overcast}}၊ {{ui:Dusk}} သို့မဟုတ် {{ui:White studio}} (ရိုးရိုး အဖြူရောင် နောက်ခံ) |
| {{ui:Sun}} | ဖိုင်က site (IfcSite) အတွက် ပေးသော latitude တွင် ဇွန် 21 ရက် 15:00၊ မော်ဒယ်၏ မှန်ကန်သော မြောက်ဘက်သို့ လှည့်ထားသည်။ အခြားအချိန်အတွက် {{ui:Use another date and time for this picture}} ကို အမှန်ခြစ်ပါ |
| {{ui:Brightness}} | ပိုလင်း သို့မဟုတ် ပိုမှောင်၊ အဆင့်များဖြင့် (stop) |
| {{ui:Ground under the model}} | မော်ဒယ်၏ အနိမ့်ဆုံးအချက်တွင် မြေပြင်၊ အရိပ်ကို လက်ခံပြီး horizon သို့ ပျော့ပျောင်းသွားသည် |
| {{ui:Draw edges}} | element များ၏ အနားသတ်များကို ရုပ်ပုံပေါ်တွင် ပါးပါးဆွဲသည် |

ရွေးထားသော အချိန်တွင် နေသည် horizon အောက်တွင် ရှိလျှင် ညဖြစ်သည်: ကောင်းကင် မှောင်ပြီး မော်ဒယ်၏ မီးလုံးများက ထိုးထွန်းသည်။

## မီးလုံးများ

မော်ဒယ်ရှိ မီးပုံစံတိုင်းသည် ရုပ်ပုံရှိ မီးလုံးတစ်လုံးဖြစ်သည်: IFC ဖိုင်ရှိ fixture များ (IfcLightFixture၊ သို့မဟုတ် light fixture အဖြစ် ရိုက်ထားသော element)၊ library မှ ထည့်ထားသည်များအပါအဝင်။ နှစ်ခုစီသည် fixture အောက်ပိုင်းမှ အောက်ဘက်သို့ ထိုးသည်။ ဖိုင်က fixture ၏ watt ကိုပေးလျှင် ၎င်း၏ လင်းအားသည် ထိုမှ လိုက်သည်; မဟုတ်လျှင် 800 lumens၊ နွေးသော အဖြူရောင် ဖြစ်သည်။

dialog က {{ui:Lamps}} အောက်တွင် မီးလုံးများကို စာရင်းပြသည်: တစ်လုံးကို ပိတ်ရန် အမှန်ခြစ်ဖြုတ်ပါ၊ သို့မဟုတ် lumens ဖြင့် လင်းအားကို ရိုက်ထည့်ပါ။ ဤပြောင်းလဲမှုများကို IFC တွင် သိမ်းသည် (fixture ၏ `CadCraft_Light` property set၊ Properties တွင်လည်း ပြောင်းနိုင်သည်)၊ နှင့် {{key:Ctrl+Z}} က ပြန်ဖျက်သည်။

ဖိုင်က site တည်နေရာကို မပြောပါက နေကို မြောက်ဘက် 40° တွင် ထားပြီး dialog က ထိုသို့ ပြောသည်။ အချိန်သည် site ၏ နာရီအချိန်ဖြစ်ပြီး ၎င်း၏ longitude မှ တွက်သည်၊ ထို့ကြောင့် နာရီများ ကွဲပြားစွာ သတ်မှတ်ထားသည့် နေရာတွင် တစ်နာရီ လွဲနိုင်သည်။

ဤဆက်တင်များကို နောက်ရုပ်ပုံအတွက် ဤ browser တွင် ထားသည်။ IFC ဖိုင်တွင် မသိမ်းပါ။

## ဖန်နှင့် အခြား ပစ္စည်းများ

{{ui:Materials}} အောက်တွင် မျက်နှာပြင် အရောင်တိုင်းတွင် look တစ်ခုရှိသည်: {{ui:Matte}}၊ {{ui:Satin}}၊ {{ui:Glossy}}၊ {{ui:Metal}}၊ {{ui:Polished metal}}၊ {{ui:Glass}} သို့မဟုတ် {{ui:Frosted glass}}။ IFC ဖိုင်က ဖောက်ထွင်းမြင်ရအောင် ပြုလုပ်ထားသော အရောင်များ (ဥပမာ ပြတင်းမှန်) သည် {{ui:Glass}} ဖြင့် စတင်သည်။

:::note
{{ui:Fast}} မုဒ်တွင် ဖန်နှင့် သတ္တုသည် ကောင်းကင်ကို ထင်ဟပ်သည်၊ မော်ဒယ်ကျန်ရှိသည်ကို မဟုတ်ပါ၊ အလင်းသည် ဖန်ထဲ မကွေ့ပါ။ အောက်ရှိ {{ui:High quality (path traced)}} မုဒ်က နှစ်ခုလုံးကို လုပ်သည်။
:::

## အရည်အသွေးမြင့်

ကင်မရာက မြင်သည့်ပုံစံအတိုင်း အလင်းကို လိုက်သော ရုပ်ပုံအတွက် {{ui:Mode}} › {{ui:High quality (path traced)}} ကို ရွေးပါ:

- အလင်းသည် မျက်နှာပြင်များကြား ပြန်ထွက်သည်၊ ထို့ကြောင့် ပြတင်းမှတစ်ဆင့် သို့မဟုတ် မီးလုံးဖြင့် လင်းသော အခန်းသည် ပတ်လည်လုံး လင်းပြီး အရောင်များသည် အနီးရှိ အရာများဆီ ပျံ့သည်;
- ဖန်သည် အစစ်အမှန် ဖန်ဖြစ်သည်: အလင်းသည် ထိုမှတဆင့် ကွေ့ပြီး မော်ဒယ်ကို ထင်ဟပ်သည်;
- သတ္တုနှင့် ပွတ်ထားသော မျက်နှာပြင်များသည် မော်ဒယ်ကျန်ရှိသည်ကို ထင်ဟပ်သည်;
- မီးပြားများသည် ပြားအဖြစ် လင်းပြီး နူးညံ့သော အရိပ်ရှိသည်။

{{ui:Fast}} ထက် သိသိသာသာ နှေးသည်: pass တိုင်းသည် pixel တိုင်း၏ အလင်းကို ထပ်လိုက်ရှာသည်။ ရုပ်ပုံသည် grain ရှိစွာ စတင်ပြီး sample များ ပေါင်းလာသည်နှင့်အမျှ ရှင်းလာသည်၊ ထို့ကြောင့် သေးငယ်စွာ စတင်ပါ ({{ui:The view's size}}၊ {{ui:Draft}}) နှင့် {{ui:Time limit}} ကို ရွေးပါ: အချိန်ကုန်သောအခါ ရှိသည့် ရုပ်ပုံကို ထိန်းထားသည်။ {{ui:Stop}} ကလည်း ထိန်းထားသည်။ ပထမ pass သည် browser က path tracer ကို ပြင်ဆင်နေစဉ် စောင့်သည်။

browser တွင် WebGPU ရှိလျှင် path tracer သည် ကျွန်ုပ်တို့၏ကိုယ်ပိုင်ဖြစ်ပြီး graphics card ပေါ်တွင် run သည်; ရုပ်ပုံအောက်မျဉ်းက ထိုသို့ ပြောသည်။ {{ui:Stop}} သို့မဟုတ် အချိန်ကန့်သတ်ချက် ပြီးနောက် {{ui:Resume}} က ပုံတူဖြင့် sample အားလုံးပြည့်သည်အထိ ဆက်လုပ်သည်; ဆက်တင် ပြောင်းခြင်း သို့မဟုတ် {{ui:Render}} ကို ထပ်နှိပ်ခြင်းက အစကနေ စတင်သည်။ WebGPU မရှိလျှင် ရုပ်ပုံကို WebGL ဖြင့် path trace လုပ်သည် (စာကြောင်းက ထိုသို့ ပြောသည်) နှင့် {{ui:Resume}} ကို မပေးပါ။

:::linux
Linux ပေါ်ရှိ Firefox နှင့် Chrome အများစုတွင် WebGPU မရှိသေးသဖြင့် အရည်အသွေးမြင့်က WebGL ကို အသုံးပြုသည်။
:::

ဤမုဒ်တွင် အနားသတ်များကို မဆွဲပါ၊ texture များက အရောင်နှင့် roughness ကို ပြသည် သို့မဟုတ် bump မပြပါ၊ ရုပ်ပုံမစမီ section ဖြတ်ချက်ကို မော်ဒယ်ပေါ်တွင် ပြုလုပ်သည်။

{{ui:Denoise (clears the grain left after the samples)}} ကို မူလအားဖြင့် ဖွင့်ထားသည်: ရုပ်ပုံ ပြီးပါက သို့မဟုတ် ရပ်ပါက၊ ကျန်သော grain ကို ဤအတွက် ပြုလုပ်ထားသော neural network (Intel Open Image Denoise ၏ ထုတ်ပြန်ထားသော network၊ သင့်ကွန်ပျူတာပေါ်တွင် run သည်: graphics card ပေါ်တွင်၊ မဟုတ်လျှင် processor ပေါ်တွင်) ဖြင့် ရှင်းသည်။ {{ui:Show}} › {{ui:The picture before denoising}} က render ထားသည့်အတိုင်း ပြသည်။

## graphics card ပေါ်ရှိ ကောင်းကင်များနှင့် light profile များ

WebGPU ဖြင့် အရည်အသွေးမြင့်တွင် ကောင်းကင် နှစ်ခု ပိုရှိသည်:

- {{ui:Physical sky}} က နေရောင်ကို နေ၏ အမြင့်မှ တွက်သည်: အပေါ်တွင် အပြာရင့်၊ horizon တွင် ဖျော့သော ဘောင်၊ နေသည် နိမ့်လာသည်နှင့် ပိုနွေးပြီး ပိုမှိန်သည်။ {{ui:Haze}} က ရှင်းလင်းဆုံးနေ့ (2) မှ မှုန်သော နေ့ (10) အထိ။
- {{ui:Sky picture (HDRI)}} က မော်ဒယ်ကို အမှန်တကယ် နေရာ၏ panorama ပုံဖြင့် လင်းစေသည်။ {{ui:Choose a picture…}} က equirectangular `.hdr` သို့မဟုတ် `.exr` ဖိုင်ကို ယူသည်; {{ui:Turn}} က မော်ဒယ်ပတ်လည် လှည့်ပြီး {{ui:Picture brightness}} က ပိုလင်း သို့မဟုတ် ပိုမှောင်စေသည်။ ပုံတွင် ကိုယ်ပိုင် နေ ပါသည်၊ ထို့ကြောင့် မော်ဒယ်၏ နေကို ထပ်မထည့်ပါ။ စာမျက်နှာ ဖွင့်နေချိန်တွင်သာ ထိန်းထားသည်: ပြန်ဖွင့်လျှင် ထပ်ရွေးပါ။

{{ui:Lamps}} စာရင်းရှိ မီးလုံးတိုင်းသည် ထုတ်လုပ်သူ၏ light profile ယူနိုင်သည်: {{ui:IES profile…}} က IES (LM-63) ဖိုင်ကို ဖတ်ပြီး မီးလုံးသည် ထို fitting ကဲ့သို့ အလင်းကို ထိုးသည် (ကျဉ်းသော downlight၊ နံရံ wash)။ ထို အမည်ရှိ မီးလုံးတိုင်းသည် ထို profile ကို သုံးပြီး မီးလုံးသည် ကိုယ်ပိုင် လင်းအားကို ထိန်းသည်။ profile ၏ အမည်ကို နှိပ်လျှင် အသုံးပြုခြင်း ရပ်သည်။

ရှင်းလင်းသော ဖန်ပြတင်းများက ကောင်းကင်၏ အလင်းကို အခန်းထဲ ရောက်အောင် ကူသည်။

{{ui:Fast}} မုဒ်နှင့် WebGL path tracer သည် {{ui:Physical sky}} နှင့် {{ui:Sky picture (HDRI)}} ကို ရှင်းသော ကောင်းကင်အဖြစ် ပြပြီး light profile များကို လျစ်လျူရှုသည်။

## ကင်မရာ

{{ui:Camera}} သည် ရုပ်ပုံကို ဓာတ်ပုံကဲ့သို့ သတ်မှတ်သည်:

- {{ui:Exposure}}: {{ui:Brightness slider}} ကို ထားပါ၊ သို့မဟုတ် {{ui:Camera settings}} ကို ရွေးပြီး ကင်မရာပေါ်ကဲ့သို့ {{ui:Aperture (f-stop)}}၊ {{ui:Shutter speed}} နှင့် {{ui:ISO}} ကို သတ်မှတ်ပါ; ၎င်းတို့ဘေးရှိ EV သည် ပုံမှန် exposure value ဖြစ်သည်။ f/16၊ 1/100 s နှင့် ISO 100 သည် နေသာသော နေ့နှင့် ကိုက်ညီသည်; ပိုမှောင်သော ဇာတ်ကွင်းသည် ပိုကျယ်သော aperture၊ ပိုနှေးသော shutter သို့မဟုတ် ပိုမြင့်သော ISO ကို လိုသည်။ ဤအရာသည် မုဒ်အားလုံးတွင် အလုပ်လုပ်သည်။
- {{ui:Depth of field}} သည် {{ui:Focus distance (m)}} ထက် နီးသော သို့မဟုတ် ဝေးသော အရာများကို ထို f-stop ရှိ မှန်ဘီလူးကဲ့သို့ ဝါးစေသည် (ကြည့်ရှုမှု၏ အလယ်တွင်ရှိသည်ကို အာရုံစိုက်ရန် ဗလာထားပါ); {{ui:Aperture shape}} က အာရုံမထားသော highlight များကို စက်ဝိုင်း သို့မဟုတ် ဓားစာကွက်ပုံ ပေးသည်။
- {{ui:Two-point perspective (vertical lines stay vertical)}} သည် ကင်မရာကို ညီညာစေပြီး architectural tilt-shift lens ကဲ့သို့ ပုံကို ရွှေ့သည်၊ ထို့ကြောင့် အဆောက်အအုံကို အထက် သို့မဟုတ် အောက် ကြည့်သောအခါ နံရံများ စောင်းမနေပါ။
- {{ui:White balance}} က မည်သည့် အလင်းအရောင်ကို အဖြူအဖြစ် ပြမည်ကို သတ်မှတ်သည်: နွေးသော မီးလုံးအလင်းအတွက် နိမ့်ခြင်း (ဥပမာ 3000 K)၊ အရိပ်နှင့် တိမ်ဖုံးသော နေ့အတွက် မြင့်ခြင်း။
- {{ui:Projection}}: {{ui:360° panorama}} က panorama ကြည့်ရှုသူများအတွက် ကင်မရာ ပတ်လည် အရာအားလုံး၏ 2:1 ရုပ်ပုံ ပြုလုပ်သည်; {{ui:360° stereo panorama}} က headset များအတွက် ဘယ်မျက်လုံးနှင့် ညာမျက်လုံး panorama ကို ဆင့်ထားသည်; {{ui:Cube map (6 faces)}} က 3 × 2 grid တွင် လေးထောင့် မြင်ကွင်း ခြောက်ခုကို ပြုလုပ်သည်။ အကျယ်ကို {{ui:Size}} မှ ယူသည်။

Projection၊ depth of field၊ two-point perspective နှင့် white balance သည် graphics card ပေါ်ရှိ path tracer (WebGPU) လိုအပ်သဖြင့် {{ui:High quality (path traced)}} တွင်သာ ပေါ်သည်။

## ရုပ်ပုံ အပြီးသတ်ခြင်း

{{ui:Picture}} က အရည်အသွေးမြင့် ရုပ်ပုံကို ဓာတ်ပုံကဲ့သို့ grade လုပ်သည်၊ ထိန်းချုပ်မှုတိုင်းက ပြီးစီးသော ရုပ်ပုံကို ထပ် render မလုပ်ဘဲ တစ်ပြိုင်နက် ပြောင်းသည်:

- {{ui:Look (view transform)}}: {{ui:ACES filmic}} (ယခင်ကဲ့သို့ ရုပ်ပုံ)၊ {{ui:AgX}} (ပျော့ပြော့၊ အလွန်လင်းသော အလင်းတွင် အရောင်ကို ထိန်းသည်)၊ {{ui:Filmic}} (နူးညံ့သော ဖလင်ကွေး) သို့မဟုတ် {{ui:Standard}} (ရိုးရိုး၊ အလွန်လင်းသော အလင်းသည် အဖြူသို့ ဖြတ်သည်)။
- {{ui:Contrast}} နှင့် {{ui:Highlight compression}} (အလွန်လင်းသော အပိုင်းများတွင် အသေးစိတ်ကို ပြန်ပေါ်စေသည်)။
- {{ui:Bloom}} (လင်းသော အလင်းပတ်လည် ပျော့ပျောင်းသော တောက်ပမှု)၊ {{ui:Glare}} နှင့် {{ui:Glare streaks}} (အလင်းဆုံးအချက်များမှ ကြယ်ရောင်ကြိုးများ) နှင့် {{ui:Vignette}} (မှောင်သော ထောင့်များ)။
- {{ui:Colour table (.cube)…}} က `.cube` ဖိုင်မှ အရောင် grade ကို {{ui:Colour table strength}} ဖြင့် သက်ရောက်စေသည်; ကောင်းကင်ပုံကဲ့သို့ စာမျက်နှာ ဖွင့်နေချိန်တွင်သာ ထိန်းထားသည်။

## ရုပ်ပုံ သိမ်းခြင်း

{{ui:Save}} ဘေးရှိ {{ui:Save as}} က ဖိုင်ကို ရွေးသည်: မျှဝေရန် {{ui:PNG}}၊ {{ui:JPEG}} သို့မဟုတ် {{ui:WebP}} (JPEG နှင့် WebP သည် browser ရေးနိုင်သော နေရာတွင်သာ)၊ နှင့် graphics card ပေါ်ရှိ အရည်အသွေးမြင့် render ပြီးနောက် အောက်ပါလည်း-

- {{ui:PNG, 16 bits}}: grade ပြီးသော ရုပ်ပုံ၊ အရောင်အဆင့်များ ပိုနုသော၊ ပုံနှိပ်ရန် သို့မဟုတ် ဆက်လက်ပြင်ရန်။
- {{ui:EXR, every layer (32-bit float)}}: render ထားသည့်အတိုင်း ရုပ်ပုံ (linear အလင်း၊ grade မပါ)၊ render element နှင့် light group တိုင်းကို ကိုယ်ပိုင် layer အဖြစ်၊ compositing program များအတွက်။
- {{ui:Render file (.ccrender, to grade again later)}}: dialog က ရုပ်ပုံကို နောက်တစ်ကြိမ် ရောနှောရန်နှင့် grade ပြန်လုပ်ရန် လိုအပ်သည့် အရာအားလုံး။ {{ui:Open a render file…}} က mix နှင့် grade နှင့်အတူ render မလုပ်ဘဲ ပြန်ယူသည်။

## render ပြီးနောက် အလင်းများကို ရောနှောခြင်း

{{ui:Render}} ကို မနှိပ်မီ {{ui:Light mixing (change each light's colour and brightness after the render)}} ကို ဖွင့်ပါ။ ရုပ်ပုံ ပြီးပါက (သို့မဟုတ် ရပ်ပါက) {{ui:Mix the picture}} က အလင်းများကို အုပ်စုလိုက် ဖော်ပြသည်: ကောင်းကင်၊ နေ၊ နှင့် မီးလုံးများ အမည်အလိုက် (အမည်တူ မီးလုံးတိုင်းသည် အုပ်စုတစ်စု)။ အုပ်စုတစ်ခုကို ပိတ်ပါ၊ အရောင်ပေးပါ၊ သို့မဟုတ် ပိုလင်း/ပိုမှောင်စေပါ၊ ရုပ်ပုံသည် ချက်ချင်း ပြောင်းသည်၊ ထပ် render မလုပ်ပါ။ {{ui:Save mix}} က ရောနှောမှုကို အမည်ဖြင့် နောက်မှ ရွေးနိုင်ရန် ထိန်းသည်; {{ui:As rendered}} က ရုပ်ပုံကို ပထမ ပြုလုပ်ထားသည့်အတိုင်း ပြန်ပေးသည်။ {{ui:Save}} က ရောနှောပြီး ရုပ်ပုံကို သိမ်းသည်။

{{ui:Render elements (albedo, normals, depth, diffuse, specular, transmission, emission, IDs)}} သည် ရုပ်ပုံ၏ အစိတ်အပိုင်းများကိုလည်း ထိန်းသည်။ {{ui:Show}} က view ကို ၎င်းတို့ထဲမှ တစ်ခုသို့ ပြောင်းသည်: မျက်နှာပြင်အရောင် (albedo)၊ normals၊ depth၊ diffuse၊ specular နှင့် ထိုးဖောက်သော အလင်း (တိုက်ရိုက်နှင့် သွယ်ဝိုက် တစ်ခုစီ)၊ လင်းနေသည်များနှင့် ကောင်းကင်၊ နှင့် object တစ်ခု သို့မဟုတ် material တစ်ခုစီအတွက် အရောင် mask ပြုလုပ်ရန်။

နှစ်ခုလုံးက graphics card ပေါ်တွင် အပိုအလွှာများ ထိန်းထားသည်။ အရွယ်ကြီးသောအခါ graphics card တွင် နေရာ မရှိနိုင်; dialog က ထိုသို့ ပြော၍ အရွယ်သေးသော size က အလုပ်လုပ်သည်။

## မြူ၊ မီးခိုး၊ noise နှင့် caustics

ဤအရာများသည် {{ui:Fog, smoke and noise}} တွင်ရှိပြီး graphics card ပေါ်ရှိ {{ui:High quality (path traced)}} တွင် အလုပ်လုပ်သည်; အခြား engine များက ဤအရာများကို ချန်ထားသည်။

- {{ui:Fog and haze}} က လေကို အမြင့်တစ်ခုအထိ နေ၊ ကောင်းကင်နှင့် မီးလုံးများက လင်းသော မြူဖြင့် ဖြည့်သည်။ {{ui:How far you can see, in meters}} က ထူမှုကို သတ်မှတ်သည် (100 m ခန့်သည် ပေါ့ပါးသော မှုန်မှု၊ 20 m သည် ထူသော မြူ)၊ {{ui:Fog height above the ground, in meters}} က ဘယ်မှာ ဆုံးသလဲ၊ နှင့် {{ui:Light shafts}} က မြူက အလင်းဘက်သို့ ဘယ်လောက် တောက်ပလာသလဲ။ နေရောင်သည် မြူ၏ထိပ်မှ ထွက်သဖြင့် ပြတင်းပေါက် သို့မဟုတ် အဆောက်အအုံများကြား နေ ဝင်လာသည့်နေရာတွင် အလင်းတန်းများအဖြစ် မြင်ရသည်။
- {{ui:Smoke or cloud}} က မီးခိုး သို့မဟုတ် တိမ် ထုထည် တစ်ခုကို မြူကဲ့သို့ လင်းစေသည်ထည့်သည်။ {{ui:Kind}} သည် {{ui:Cloud}}၊ {{ui:Smoke column}} သို့မဟုတ် {{ui:From a volume file (.ccvol)}} (CadCraft ၏ ကိုယ်ပိုင် grid ဖော်မတ်) တစ်ခု ဖြစ်သည်။ {{ui:Detail}} နှင့် {{ui:Variation}} က ပြုလုပ်ပြီးသော တိမ် သို့မဟုတ် တိုင်ကို ပြောင်းသည်၊ {{ui:Size of its longest side, in meters (0 = the size of the model)}}၊ {{ui:Move X (m)}}၊ {{ui:Move Y (m)}}၊ {{ui:Move Z (m)}} နှင့် {{ui:Turn}} က နေရာချသည် (မော်ဒယ်အလယ်တွင် စတင်သည်)၊ {{ui:Thickness}} က ပိုသိပ်စေသည်၊ {{ui:Forward glow}} က အလင်းဘက်သို့ ပိုတောက်စေသည်၊ နှင့် {{ui:Color}} က အရောင်ခြယ်သည်။ volume ဖိုင်ကို စာမျက်နှာ ဖွင့်နေချိန်တွင်သာ ထိန်းထားသည်၊ ရုပ်ပုံ ကောင်းကင်ကဲ့သို့ပင်။
- {{ui:Stop early where the picture is clean (adaptive sampling)}} က ငြိမ်သွားသော pixel များကို sample ထပ်မပေးပါ။ {{ui:Noise to accept}} က pixel ရပ်သောအခါ ကျန်သော grain ပမာဏ ဖြစ်သည်။ ရုပ်ပုံအောက်မျဉ်းက pixel တစ်ခုစီ ပျမ်းမျှ sample ဘယ်လောက်ရသည် ပြောသည်။
- {{ui:Caustics (light bent by glass or bounced by mirrors)}} က မီးလုံးနှင့် နေမှ အလင်းကို ခြေရာခံသည်၊ ထို့ကြောင့် ဖန်ဘောလုံး အောက်ရှိ တောက်ပသော အစိတ်အပိုင်း သို့မဟုတ် မှန်ရောင် နံရံပေါ်ရှိ အလင်း ပြတ်ကွက်သည် grain မပါဘဲ သန့်ရှင်းစွာ ထွက်သည်။ မြူ၊ မီးခိုး၊ light mixing သို့မဟုတ် render elements ဖွင့်ထားစဉ် ပိတ်ထားပြီး ရုပ်ပုံအတွက် ဖြစ်သည်၊ 360° ရုပ်ပုံအတွက် မဟုတ်ပါ။

## Render တန်းစီစာရင်း

dialog ရှိ {{ui:Render queue}}: {{ui:Add this picture to the queue}} က ရုပ်ပုံ၏ ဆက်တင်နှင့် view ကို ထိန်းသည်၊ {{ui:Start the queue}} က စောင့်နေသော ရုပ်ပုံများကို ဤကွန်ပျူတာပေါ်တွင် တစ်ခုပြီးတစ်ခု render လုပ်သည်။ စာမျက်နှာ ပိတ်လျှင် တန်းစီစာရင်း ကျန်နေသည်; ဆက်ရန် မော်ဒယ်တူကို ဖွင့်ပါ။ {{ui:Save}} က ပြီးသော တစ်ခုကို download လုပ်သည်; {{ui:Remove}} နှင့် {{ui:Clear finished}} က စာရင်းကို သပ်ရပ်စေသည်။ တန်းစီစာရင်းသည် အရည်အသွေးမြင့်ဖြင့် render လုပ်သဖြင့် WebGPU လိုအပ်သည်။

## ဘယ်လောက်ကြာသလဲ

ရုပ်ပုံကို သင့်ကွန်ပျူတာပေါ်တွင် graphics card က ပြုလုပ်သည်; ဘာမျှ အပ်လုဒ် မလုပ်ပါ။ အချိန်သည် pass နှင့် pixel များနှင့်အတူ တိုးသည်: {{ui:Best}} သည် {{ui:Draft}} ထက် pass 16 ဆ ရှိသည်၊ 4K ရုပ်ပုံသည် Full HD ထက် pixel ~4 ဆ ရှိသည်။ မော်ဒယ်ကြီးများသည် pass တစ်ခုစီ ပိုကြာသည်။
