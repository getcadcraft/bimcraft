## ဘာလုပ်မလဲ

အဆောက်အအုံ တက်လာပုံကို ကြည့်ပါ: အချိန်ဇယားရှိ လုပ်ငန်းတစ်ခုစီကို ၎င်းတည်ဆောက်သော ဒြပ်စင်များနှင့် ချိတ်ဆက်ပြီး နေ့စဉ် ပြသပါမည်။

## အဆင့်များ

1. IFC မော်ဒယ်ကို ဖွင့်ပြီး ဘယ်ဘောင်ရှိ {{ui:4D အချိန်ဇယား}} ကို ဖွင့်ပါ။
2. အထပ်တစ်ခုလျှင် အပတ်တစ်ပတ်ပါသော လုပ်ငန်းစာရင်း နမူနာအတွက် {{ui:နမူနာ ဒေါင်းလုဒ်ဆွဲရန်}} ကို နှိပ်ပြီး စာရွက်ပေါ်တွင် ပြင်ပါ။ သို့မဟုတ် ကိုယ်ပိုင် ရေးပါ။
3. {{ui:လုပ်ငန်းစာရင်း ဖွင့်ရန်…}} ကို နှိပ်ပြီး CSV ကို ရွေးပါ။
4. ရက်စွဲ ဆလိုက်ဒါကို ဆွဲရွှေ့ပါ၊ သို့မဟုတ် {{ui:ပြေးရန်}} ကို နှိပ်ပါ။

## လုပ်ငန်းစာရင်း

ခေါင်းစီးအတန်းနှင့် **Task**၊ **Start**၊ **Finish**၊ **Field** နှင့် **Value** ကော်လံများပါသော CSV။ ကော်မာ သို့မဟုတ် semicolon နှစ်မျိုးလုံး အလုပ်လုပ်သည်။

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| အဆင့် 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| ခေါင်မိုး | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| ခေါင်မိုး | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- ရက်စွဲများကို YYYY-MM-DD ဖြင့် ရေးပါ။
- အတန်းတစ်ခုသည် လုပ်ငန်းကို **Field** တန်ဖိုး **Value** နှင့် တိတိကျကျ ကိုက်ညီသော ဒြပ်စင်အားလုံးနှင့် ချိတ်ဆက်သည်။ Field သည် Storey၊ Class၊ Name၊ Type၊ Material၊ Tag သို့မဟုတ် GlobalId ကဲ့သို့ ဂုဏ်သတ္တိတစ်ခု ဖြစ်နိုင်သည်၊ သို့မဟုတ် `Pset_WallCommon.FireRating` ကဲ့သို့ pset နှင့် အမည်ဖြင့် ရေးထားသော ဂုဏ်သတ္တိ ဖြစ်နိုင်သည်။
- ရက်စွဲတူသော အတန်းများစွာဖြင့် လုပ်ငန်းတစ်ခုကို ထပ်ရေးခြင်းဖြင့် ဒြပ်စင်ပိုမိုချိတ်ဆက်နိုင်သည်။

## အဆင့်များနှင့် အလုပ်ပက်ကေ့ချ်များ

**Stage** ကော်လံ၊ **Package** ကော်လံ သို့မဟုတ် နှစ်ခုလုံး ထည့်ပြီး လုပ်ငန်းများကို အဆင့်များနှင့် အလုပ်ပက်ကေ့ချ်များအဖြစ် စုပါ။ Phase နှင့် WBS ကိုလည်း ကော်လံအမည်အဖြစ် သုံးနိုင်သည်။

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| အဆင့် 1 ကြမ်းပြင် | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| အဆင့် 1 နံရံများ | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| တံခါးများ | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- လုပ်ငန်းတစ်ခုသည် အဆင့်တစ်ခုနှင့် ပက်ကေ့ချ်တစ်ခုတွင်သာ ပါဝင်သည်။ တူညီသော လုပ်ငန်း၏ နောက်အတန်းတစ်ခုက အခြားအမည် ပေးထားလျှင် ထိုအတန်းကို လိုင်းနံပါတ်ဖြင့် စာရင်းပြုပြီး ချန်လှပ်သည်။
- အဆင့်နှစ်ခုတွင် ပက်ကေ့ချ်အမည်တူ ရှိလျှင် ပက်ကေ့ချ်နှစ်ခု ဖြစ်သည်။

စာရင်းတွင် အုပ်စုများ ရှိသောအခါ ရက်စွဲအပေါ်တွင် {{ui:ပြရန်}} စာရင်း ပေါ်လာသည်။ အဆင့် သို့မဟုတ် ပက်ကေ့ချ်တစ်ခု ရွေးလျှင် တစ်ခုတည်းအဖြစ် ပြေးသည်:

- ဆလိုက်ဒါနှင့် {{ui:ပြေးရန်}} သည် အုပ်စု၏ ပထမ စတင်ရက်မှ နောက်ဆုံး ပြီးဆုံးရက်အထိ လည်ပတ်သည်၊
- အုပ်စု၏ လုပ်ငန်းများကိုသာ စာရင်းပြပြီး ဆေးသုတ်ပြသည်၊ အုပ်စုပြင်ပရှိ အရာအားလုံးကို မြင်ရမပေါက်အောင် ပြသည်၊
- စာရင်းအောက်ရှိ စာကြောင်းက ထိုရက်တွင် ၎င်း၏ လုပ်ငန်းများ မည်မျှ ပြီးပြီ၊ ဆောင်ရွက်နေဆဲ၊ နောက်မှ ရှိမည်ကို ပြောပြသည်၊
- {{ui:ဒြပ်စင်များကို ရွေးရန်}} သည် အုပ်စု၏ ဒြပ်စင်အားလုံးကို ရွေးပေးပြီး {{ui:ပြရန်}}၊ {{ui:ဖြတ်ပိုင်း}} သို့မဟုတ် ဇယားအတွက် သုံးနိုင်သည်။

အချိန်ဇယားတစ်ခုလုံးကို ပြန်ကြည့်ရန် **လုပ်ငန်းအားလုံး** ကို ရွေးပါ။

## ဘာတွေ မြင်ရမလဲ

- **Built**: လုပ်ငန်းအားလုံး ပြီးဆုံးသော ဒြပ်စင်များ၊ ၎င်းတို့၏ ကိုယ်ပိုင်အရောင်များဖြင့်။
- **In progress**: ထိုနေ့တွင် လုပ်ငန်းတစ်ခု ဆောင်ရွက်နေသော ဒြပ်စင်များ၊ ရွှေဝါရောင်ဖြင့်။ လုပ်ငန်းသည် စတင်ရက်မှ ပြီးဆုံးရက်အထိ ဆောင်ရွက်နေဆဲ ဖြစ်သည်။
- **Not started**: ဆေးသုတ်ပြသည်။
- မည်သည့်လုပ်ငန်းမှ မပါသော ဒြပ်စင်များသည် ယခင်အတိုင်း ရှိနေသည်။ စာရင်းက လုပ်ငန်းတစ်ခုစီ တွေ့ရှိသော ဒြပ်စင် အရေအတွက်ကို ပြသည်။ ဖတ်၍ မရသော သို့မဟုတ် ဘာမျှ မတွေ့သော အတန်းများကို လိုင်းနံပါတ်ဖြင့် စာရင်းပြုသည်။

## ချိတ်ဆက်မှုများ၊ Gantt ဇယားနှင့် MS Project

- Predecessors ကော်လံပါသော Microsoft Project XML ဖိုင် (`.xml`) သို့မဟုတ် CSV ကို ဖွင့်ပါ။ ချိတ်ဆက်မှုများသည် finish to start၊ start to start၊ finish to finish သို့မဟုတ် start to finish ဖြစ်နိုင်ပြီး၊ ရက်ပေါင်းဖြင့် lead သို့မဟုတ် lag ပါနိုင်သည်။
- လုပ်ငန်းစာရင်းအောက်တွင် Gantt ဇယားက လုပ်ငန်းတစ်ခုစီကို ချိတ်ဆက်မှုများအတွက် မြားပါသော bar အဖြစ် ဆွဲသည်။ critical path ပေါ်ရှိ လုပ်ငန်းများကို အနီရောင်ဖြင့် ပြသည်။ ချိတ်ဆက်မှု loop သို့မဟုတ် မရှိသော predecessor ကို panel တွင် စာရင်းပြုသည်။
- {{ui:MS Project XML အဖြစ် သိမ်းရန်}} နှင့် {{ui:လင့်ခ်များပါသော CSV သိမ်းရန်}} တို့သည် အချိန်ဇယားကို ချိတ်ဆက်မှုများနှင့်အတူ ပြန်ရေးသည်။
