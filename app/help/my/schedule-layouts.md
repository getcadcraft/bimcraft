## ဘာလုပ်ရမလဲ

ရိုးရိုး ဇယားကို သင်၏ ရုံးထုတ်ပေးသော ဇယားအဖြစ် ပြောင်းပါ- အဆင့်၊ အမျိုးအစား သို့မဟုတ် အခန်းအလိုက် အုပ်စုဖွဲ့ထား၊ subtotal နှင့် total ပါ၊ လိုအပ်သော ကော်လံများပါ၊ ၎င်း၏ ကိုယ်ပိုင်အမည်ဖြင့်။ ထို့နောက် spreadsheet သို့ ပို့ပါ။ အတန်းတိုင်းနှင့် ဂဏန်းတိုင်းက ၎င်းမှ လာသော element များကို ဆက်လက် သိနေသည်။

## အဆင့်များ

1. {{ui:Draw}} ကို ဖွင့်ပြီး ဘယ်ဘက်အကန့်ရှိ **ဇယားများ** ကို ဖွင့်ပါ။ ဇယားတစ်ခုကို ရွေးပါ၊ ဥပမာ **တံခါးများ**။
2. ဇယားအပေါ်တွင် **အုပ်စုဖွဲ့ရန်** (ဇယား၏ ကော်လံတစ်ခု၊ ဥပမာ အဆင့် သို့မဟုတ် အမျိုးအစား၊ သို့မဟုတ် **အုပ်စုမဖွဲ့**) နှင့် **စုစုပေါင်းများ** (**စုစုပေါင်းမရှိ**၊ **စုစုပေါင်း တစ်ခု**၊ သို့မဟုတ် **ခွဲစုစုပေါင်းများနှင့် စုစုပေါင်း**) ကို ရွေးပါ။ **သတ်မှတ်ထားသည့်အတိုင်း** က ရွေးချယ်မှုကို သိမ်းထားသော setup သို့မဟုတ် ရုံးစံနှုန်းထံ ထားသည်။
3. element များမှ ဖတ်ထားသော ကော်လံ ထည့်ရန် ဇယားအောက်တွင် property သို့မဟုတ် tag အမည်ကို ရိုက်ထည့်ပါ (ဥပမာ `FireRating`၊ `Pset_DoorCommon.FireRating` သို့မဟုတ် `Ironmongery` ကဲ့သို့ tag အမည်) ပြီး **ကော်လံ ထည့်ရန်** ကို နှိပ်ပါ။ BimCraft သည် element ၏ ကိုယ်ပိုင် property sets ကို အရင်ဖတ်ပြီး ထို့နောက် ၎င်း၏ အမျိုးအစား၏ property sets ကို ဖတ်သည်။ element တစ်ခုမှ တန်ဖိုးမရှိသေးလျှင် ထိုသို့ ပြောပြသည်။ တန်ဖိုး သတ်မှတ်ပြီးသည်နှင့် ကော်လံသည် ကိုယ်တိုင် ဖြည့်သွားသည်။
4. အမည် (ဥပမာ "အထပ်အလိုက် တံခါးဇယား") ရိုက်ပြီး **setup အဖြစ် သိမ်းရန်** ကို နှိပ်ပါ။ setup ကို အဆောက်အအုံဖိုင်တွင် သိမ်းထားပြီး ဇယား စာရင်းသို့ ၎င်း၏ အမည်ဖြင့် ပေါင်းဝင်သည်။ မော်ဒယ်၏ အပြောင်းအလဲတိုင်းကို လိုက်သည်။ **ဤ setup ကို ဖယ်ရန်** က ၎င်းကို ပြန်ဖယ်ပေးသည်။ နှစ်ခုလုံးသည် ပြန်ဖျက်ရန် အဆင့်တစ်ခု ဖြစ်သည်။

## ပမာဏတစ်ခုကို နှိပ်၍ ၎င်းမှ လာသည်ကို ရွေးပါ

အတန်း မည်သည့်အရာ သို့မဟုတ် ပမာဏတစ်ခုတည်းကိုမဆို နှိပ်လျှင် ပလန်နှင့် 3D တွင် ၎င်းနောက်ကွယ်ရှိ element များကို ရွေးမည်-

- အတန်းတစ်ခုက ထိုအတန်း၏ element များကို ရွေးသည်;
- ခွဲစုစုပေါင်း သို့မဟုတ် စုစုပေါင်းက ၎င်း ပေါင်းထားသည်အားလုံးကို ရွေးသည်၊ အုပ်စုခေါင်းစဉ်က ၎င်း၏ အုပ်စုကို ရွေးသည်;
- ကိုယ်ပိုင် element များပါသော ပမာဏက ထိုများကို ရွေးသည်- နံရံအမျိုးအစား၏ **Deductions** က ၎င်း၏ တံခါးနှင့် ပြတင်းပေါက်များကို၊ အခန်းတစ်ခု၏ နံရံဧရိယာက ၎င်း၏ နံရံများကို ရွေးသည်။

မော်ဒယ်မှ ပြုလုပ်ထားသော စာရွက်စာတမ်းတွင်လည်း အလားတူ အလုပ်လုပ်သည်- နှိုက်ကြည့်ရှုမှုတွင် ဇယား၏ ပမာဏတစ်ခုကို နှိပ်ပါ။

## ပို့ထုတ်ခြင်း

- **Download Excel** က .xlsx workbook ကို သိမ်းသည်။ အလျား၊ ဧရိယာ၊ ထုထည်နှင့် အရေအတွက်များသည် ကော်လံ ပြသသော ယူနစ်ဖြင့် အစစ်အမှန် ဂဏန်းများ ဖြစ်သည် (feet and inches ကတော့ စာသားအဖြစ် ကျန်သည်)။ ဒုတိယ sheet **Elements** တွင် အတန်းတစ်ခုစီအတွက် ၎င်းနောက်ကွယ်ရှိ element များ၏ GlobalId များကို စာရင်းပြုသည်။
- **Copy for Google Sheets** က ဇယားကို tab ခြားထားသော စာသားအဖြစ် clipboard သို့ ထည့်သည်။ Google Sheet တွင် cell A1 ကို နှိပ်ပြီး ကူးထည့်ပါ။ **Open a new Google Sheet** က `sheets.new` ကို ဖွင့်သည်၊ ၎င်းသည် Google ၏ ဗလာ sheet လိပ်စာ ဖြစ်ပြီး သင်၏ ကိုယ်ပိုင် Google အကောင့်တွင် ဖွင့်သည်။ BimCraft သည် Google သို့ ဝင်ရောက်ခြင်း မပြုပါ၊ ဘာမျှ ပို့ခြင်း မပြုပါ- ကူးထည့်ခြင်းသည် သင့်ထံမှ ဖြစ်သည်။
- **Download CSV** က ဇယားကို screen ပေါ်တွင် ဖြန့်ကျက်ထားသည့်အတိုင်း သိမ်းသည်။

## ရုံးစံနှုန်း

ရုံးတစ်ခုက ၎င်း၏ ဇယားများကို မည်သို့ အပြင်အဆင်ချသည်ကို တစ်ကြိမ် ပြောနိုင်သည်။ **Default Policies** add-on ([Default Policies](topic:default-policies)) ကို ဖွင့်ပြီး **ဆက်တင်များ › ကမ္ဘာလုံးဆိုင်ရာ › Default Policies › Schedule layout (ရုံးစံနှုန်း)** တွင် သတ်မှတ်ပါ:

| မူဝါဒ | ဘာလုပ်သလဲ |
|---|---|
| **ဇယားများကို အုပ်စုဖွဲ့ရန်** | အဆင့်၊ အမျိုးအစား၊ အခန်း သို့မဟုတ် အုပ်စုမဖွဲ့ရန်၊ ထိုကော်လံရှိသော ဇယားတိုင်းအတွက် |
| **ဇယားများရှိ စုစုပေါင်းများ** | စုစုပေါင်းမရှိ၊ အဆုံးတွင် စုစုပေါင်း တစ်ခု၊ သို့မဟုတ် အုပ်စုတစ်ခုစီအောက် ခွဲစုစုပေါင်းနှင့် စုစုပေါင်း |
| **ဇယား ခေါင်းစဉ်** | ပုံစံတစ်ခု၊ ဥပမာ `{project}: {schedule}` |
| **ကော်လံ ခေါင်းစဉ်များ** | ရေးထားသည့်အတိုင်း၊ IN CAPITALS (အကြီးစာလုံးအားလုံး) သို့မဟုတ် With Capitals (ပထမစာလုံးကြီး) |

စံနှုန်းက ဇယားအားလုံးကို သက်ရောက်သည်၊ မည်သူ setup လုပ်သည်ဖြစ်စေ- panel ရှိ ရိုးရိုး ဇယားများ၊ သိမ်းထားသော setup၊ AI လက်ထောက်က setup လုပ်သော ဇယား၊ export များနှင့် စာရွက်စာတမ်းရှိ ဇယားများ။ ကိုယ်ပိုင် အုပ်စုဖွဲ့ခြင်း၊ စုစုပေါင်းနှင့် ခေါင်းစဉ် ဖော်ပြသော setup က ၎င်းတို့ကို ထိန်းထားသည်; ရုံးစံနှုန်းက ကျန်သည်ကို ဖြည့်ပေးသည်။ panel က ရုံးစံနှုန်းက သတ်မှတ်ထားသော အပိုင်းများကို ပြောသည်။ မူဝါဒများသည် Default Policies ဖိုင်တွင် အခြားများနှင့်အတူ ပါလာသည်။

## သိထားသင့်သည်များ

- setup သည် ၎င်း၏ ရင်းမြစ်ဇယားနှင့် ကော်လံများကို အမည်ပေးသည်; ဂဏန်းများ မပါဝင်ပါ။ ဂဏန်းများကို မော်ဒယ်မှ အကြိမ်တိုင်း ဖတ်သည်။
- element အတန်းများ မဟုတ်သော စာရင်းများ (နံရံ အစုအဝေးများနှင့် ပစ္စည်း legend) တွင် ဤနေရာတွင် အပြင်အဆင်နှင့် export မရှိပါ။
- AI လက်ထောက်က ဤအရာအားလုံးကို သင့်အတွက် လုပ်ပေးနိုင်သည်: [AI လက်ထောက်ဖြင့် သင်၏ မော်ဒယ်ပေါ်တွင် အလုပ်လုပ်ခြင်း](topic:assistants)။
