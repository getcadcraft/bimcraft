## လုပ်မည့်အရာ

CAD ပုံဆွဲတစ်ခုကို ဖွင့်ပြီး 3D သို့မဟုတ် 2D တွင် ကြည့်ခြင်း၊ ၎င်းပတ်ပတ်လည် လှည့်ခြင်း၊ model space နှင့် ၎င်း၏ sheet များအကြား ပြောင်းခြင်းနှင့် ကိုအော်ဒီနိတ်များ ဖတ်ခြင်း။ BimCraft သည် DWG နှင့် DXF ပုံဆွဲများကို ပြသသည်; ၎င်းတို့ကို တည်းဖြတ်ခြင်း သို့မဟုတ် သိမ်းခြင်း မပြုပါ။ ပြင်လိုလျှင် {{ui:Edit in CadCraft}} ကို နှိပ်ပါ၊ ပုံဆွဲသည် tab အသစ်တွင် CadCraft drafting app ဖြင့် ဖွင့်မည်။

## အဆင့်များ

1. {{ui:Choose a file}} ကို နှိပ်ပါ၊ သို့မဟုတ် ပုံဆွဲကို စာမျက်နှာပေါ် ဆွဲချပါ။
2. `.dwg` သို့မဟုတ် `.dxf` ဖိုင်ကို ရွေးပါ။
3. အခြေအနေလိုင်းက "ပုံဆွဲကို ဖတ်နေသည်…" ဟု ပြသနေစဉ် စောင့်ပါ။ ပုံဆွဲကြီးများသည် စက္ကန့်အနည်းငယ် ကြာသည်။ ထို့နောက် ဖတ်ချိန်ကို ပြောပြပြီး ပထမဆုံးပုံ ဆွဲနေစဉ် "ရုပ်ပုံဖန်တီးနေသည်…" ဟု ပြသကာ ထိုကြာချိန်ကိုလည်း ပြောပြသည်။
4. ပုံဆွဲသည် 3D တွင် ဖွင့်သည်၊ ကြီးမားသော ပုံဆွဲကို ပြရာတွင် အမြန်ဆုံးနည်းလမ်းဖြစ်သည် (See [DWG သို့မဟုတ် DXF ပုံဆွဲကို 3D တွင် ကြည့်ရန်](topic:dwg-in-3d))။ ပြားသော 2D view အတွက် {{ui:Model}} ကို နှိပ်ပါ။ အမြဲ 2D တွင် ဖွင့်လိုလျှင် {{ui:Settings}} › {{ui:BimCraft}} › **ပုံဆွဲများ ဖွင့်မည့်နေရာ** ကို {{ui:Model (2D)}} သို့ သတ်မှတ်ပါ။ model space တွင် ဘာမျှမရှိသော ပုံဆွဲ သို့မဟုတ် 3D ကို မပြနိုင်သော browser သည် 2D တွင် ဖွင့်သည်။
5. ပုံဆွဲအပေါ်ရှိ tab များကို ကြည့်ပါ: {{ui:Model}} ဦးစွာ၊ ထို့နောက် sheet တစ်ခုလျှင် tab တစ်ခု၊ ပုံဆွဲ၏ ကိုယ်ပိုင်အစီအစဉ်အတိုင်း။
6. sheet tab ကို နှိပ်ပြီး ထို sheet ကို ကြည့်ပါ: စက္ကူ၊ viewport များမှတစ်ဆင့် ပြထားသော မော်ဒယ်။
7. model space သို့ ပြန်ရန် {{ui:Model}} ကို နှိပ်ပါ။
8. pointer ကို ပုံဆွဲပေါ် ရွှေ့ပြီး ထောင့်ရှိ X နှင့် Y ကိုအော်ဒီနိတ်များကို ဖတ်ပါ။

## မြင်ရမည့်အရာများ

- ပုံဆွဲ၊ ဝင်းဒိုးတွင် ကိုက်ညီအောင် ချိန်ထားသည်။ အရောင်များသည် ပုံဆွဲကို လိုက်သည်; အဖြူမျဉ်း (အရောင် 7) သည် theme ၏ မင်ဖြင့် ဆွဲသည်၊ ပါးသော အရောင်များကို light theme တွင် မှောင်စေ၍ ဖတ်ရလွယ်အောင် ထားသည်။
- ဘယ်ဘက်ရှိ {{ui:Drawing}} panel: ဖိုင်၊ အရွယ်အစား၊ ဖော်မတ် (ဥပမာ "AutoCAD 2018 (AC1032)")၊ unit များ၊ entity နှင့် layer အရေအတွက်၊ sheet အရေအတွက်၊ ရှိလျှင် ချိတ်ဆက်ထားသော ပုံဆွဲနှင့် equipment များ။
- ဘယ်ဘက်ရှိ {{ui:Layers}} စာရင်း။
- ညာဘက်တွင်: လှည့်ပတ်ပုံ၊ ချိတ်ဆက်ထားသော ပုံဆွဲနှင့် ပုံများ၊ နှင့် **ဆွဲမထားသေး**။

## ဒိုင်နမစ် block များ

ဒိုင်နမစ် block ကို ပုံဆွဲက ပြထားသည့်အတိုင်း ဆွဲသည်: placed block တိုင်းကို ပုံဆွဲသိမ်းစဉ်က မြင်နိုင်မှု အခြေအနေ (ဥပမာ "Plan" သို့မဟုတ် "Front"၊ "Single bowl" သို့မဟုတ် "Double bowl") ဖြင့် ဆွဲသည်။ ညာဘက်ရှိ **ဒိုင်နမစ် block များ** က model space တွင် placed ဖြစ်သော block တိုင်းကို စာရင်းပြသည်: ဘယ်နှစ်ခု placed ဖြစ်သည်၊ ပြနေသော အခြေအနေများနှင့် block တွင်ရှိသော အခြေအနေအားလုံး။ {{ui:3D}} တွင် placed block ကို နှိပ်လျှင် ဂုဏ်သတ္တိများတွင် **ဒိုင်နမစ် block**၊ **ပြနေသော အခြေအနေ** နှင့် **အခြား အခြေအနေများ** ကို မြင်ရမည်။ BimCraft သည် အခြေအနေများကို မပြောင်းပါ။

## ဆွဲမထားသေးသော အရာများ

အမျိုးအစား အရာဝတ်ထု အချို့ကို ဤ build တွင် မဆွဲရသေးပါ။ ၎င်းတို့ကို ညာဘက်ရှိ **ဆွဲမထားသေး** အောက်တွင် ရေတွက်ပြသည် ("ပုံဆွဲ၏ ဤအပိုင်းများကို ခန့်မှန်းခြင်းမပြုဘဲ ယခုအတွက် ကျော်သွားသည်။")၊ ထို့ကြောင့် တစ်ခုခု ပျောက်နေကြောင်း သိနိုင်သည်။ မျဉ်းများ၊ polyline များ၊ arc များ၊ စက်ဝိုင်းများ၊ ellipse များ၊ spline များ၊ hatch နှင့် solid fill များ၊ စာသားနှင့် multiline စာသား၊ attribute ပါသော block များ၊ dimension များ၊ leader နှင့် multileader များ၊ ဇယားများ၊ ပုံများနှင့် viewport များကို ဆွဲသည်။ 3D face များ၊ polyface mesh များနှင့် polygon mesh များကို အပေါ်မှ မြင်ရသော edge များအဖြစ် ဆွဲသည်; မျက်နှာပြင်အဖြစ် မြင်ရန် {{ui:3D}} သို့ ပြောင်းပါ။

binary DXF ဖွင့်မရပါ: BimCraft က ထိုသို့ ပြောသည်။ ဖန်တီးထားသော program မှ ASCII DXF သို့မဟုတ် DWG အဖြစ် ပြန်သိမ်းပါ။

## အမှားများ

- **ပုံဆွဲသည် ဗလာဖြစ်နေသယောင်။** Layer အချို့ကို ပုံဆွဲကိုယ်တွင် ပိတ်ထား သို့မဟုတ် ခဲထားနိုင်သည်; ၎င်းတို့သည် {{ui:Layers}} တွင် အမှန်အမှတ် မပါဘဲ စတင်သည်။ {{ui:All on}} ကို နှိပ်ပါ။ အခြေအနေက "*name* သည် ဗလာပုံဆွဲဖြစ်သည်: မျဉ်း၊ စာသား သို့မဟုတ် block မရှိပါ။" ဟု ပြောလျှင် ထဲတွင် ဘာမျှ မရှိပါ။
- **sheet တွင် ဗလာဘောင်သာ ပြသည်။** sheet သည် ချိတ်ဆက်ထားသော ပုံဆွဲများကို အားထားနိုင်သည်။ See [ချိတ်ဆက်ထားသော ပုံဆွဲနှင့် ပုံများ ရှာခြင်း](topic:dwg-linked-files)။
- **စာသား အနည်းငယ် ကွဲပြားနေသည်။** BimCraft သည် စာသားကို ပုံဆွဲ၏ ကိုယ်ပိုင်ဖောင့်မဟုတ်ဘဲ ကျဉ်းသော sans-serif ဖောင့်ဖြင့် ဆွဲသည်၊ ထို့ကြောင့် ဖန်တီးထားသော program ထက် စာသား အနည်းငယ် ပိုကျယ် သို့မဟုတ် ပိုကျဉ်းနိုင်သည်။
- **"*name* ကို ဖတ်၍ မရပါ။ ပျက်စီးနေနိုင်သည် သို့မဟုတ် ဖတ်သူက မကိုင်တွယ်နိုင်သေးသော ဖော်မတ်ဖြင့် သိမ်းထားနိုင်သည်။"** အဆုံးရှိ ကွင်းစကွင်းပိတ်သည် ဖိုင်၏ ဖော်မတ်ကုဒ်ကို ဖော်ပြသည်။ ဖန်တီးထားသော program မှ ပိုဟောင်းသော DWG သို့မဟုတ် DXF အဖြစ် သိမ်းပြီး ထပ်ကြိုးစားပါ။
- **တိုင်းတာ၊ ဆွဲ သို့မဟုတ် တည်းဖြတ်ရန် မျှော်လင့်ခြင်း။** BimCraft သည် ပုံဆွဲများကို ကြည့်ရုံသာ ကြည့်သည်။ တည်းဖြတ်ရန် {{ui:Edit in CadCraft}} ကို နှိပ်ပါ၊ ထိုဖိုင်ကို CadCraft drafting app တွင် ဖွင့်ပြီး တည်းဖြတ်ကာ မိတ္တူကို DWG သို့မဟုတ် DXF အဖြစ် သိမ်းမည်။ မူရင်းဖိုင် မပြောင်းပါ၊ ချိတ်ဆက်ထားသော ပုံဆွဲများမှာ BimCraft တွင် ကျန်သည်။ ခလုတ်သည် CadCraft ဖွင့်ထားသော နေရာတွင်သာ ပေါ်သည်။
