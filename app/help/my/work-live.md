## သင်လေ့လာရမည့်အရာ

IFC မော်ဒယ်တစ်ခုကို လူများစွာက တစ်ပြိုင်နက် တည်းဖြတ်သောအခါ ဘာဖြစ်သလဲ။ CadCraft Studio က Live TeamWork စက်ရှင်ကို စတင်ပြီး ဝင်ရောက်သည် (မျှဝေရန်၊ ဝင်ရန်); ဤစာမျက်နှာသည် မော်ဒယ်ကိုယ်တိုင်အကြောင်း ဖြစ်သည်။

## လူအားလုံး တစ်ပြိုင်နက် တည်းဖြတ်ခြင်း

ဝင်ရောက်သူအားလုံးထံ ဖိတ်ကြားသူ၏ မော်ဒယ် ရောက်ရှိသည်။ အစိတ်အပိုင်းများကို အမည်ပြောင်းခြင်း၊ ၎င်းတို့၏ ဂုဏ်သတ္တိတန်ဖိုးများ ပြောင်းခြင်း၊ library ပစ္စည်းများနှင့် အစိတ်အပိုင်းများ နေရာချခြင်း၊ လဲလှယ်ခြင်း သို့မဟုတ် ဖယ်ရှားခြင်းတို့ကို ပုံမှန်အတိုင်း ပြုလုပ်ပါ။ သင့်ကိုယ်ပိုင် တည်းဖြတ်မှုများ ချက်ချင်း ပေါ်လာသည်၊ အခြားသူများ၏ တည်းဖြတ်မှုများမှာ ၎င်းတို့ ပြုလုပ်ပြီး ခဏအကြာတွင် ပေါ်လာသည်။ သင်မြင်ရသည်ကို ပြောင်းစေသော တည်းဖြတ်မှု (အစိတ်အပိုင်း နေရာချခြင်း သို့မဟုတ် ဖယ်ရှားခြင်း) ဖြစ်သောအခါ BimCraft က မော်ဒယ်ကို ပြန်ဆွဲပြီး သင့်မြင်ကွင်းကို ထိန်းသိမ်းထားသည်။

- **လူနှစ်ဦးက အစိတ်အပိုင်းတစ်ခုကို ပြောင်းသောအခါ:** မော်ဒယ်၏ တူညီသော လိုင်းအတွက် နောက်ဆုံးပြောင်းလဲမှု အနိုင်ရသည်။ အစိတ်အပိုင်းများစွာ မျှဝေသော property set ကို သင်တည်းဖြတ်သော အစိတ်အပိုင်းအတွက် ပုံမှန်အတိုင်း ကူးယူသည်၊ ထို့ကြောင့် အခြားအစိတ်အပိုင်းများက ၎င်းတို့တန်ဖိုးများကို ထိန်းသိမ်းထားသည်။
- **လူတစ်ဦးက ယခုဖယ်ရှားလိုက်သော အစိတ်အပိုင်း** ကို ထပ်မံ တည်းဖြတ်၍ မရတော့ပါ: သင့်တည်းဖြတ်မှုကို ပြန်ရုပ်သိမ်းပြီး status bar က အကြောင်းပြချက်ကို ပြသည်။
- လူတစ်ဦးချင်းစီ၏ မော်ဒယ်ထဲရှိ လိုင်းအသစ်များသည် ၎င်းတို့ကိုယ်ပိုင် နံပါတ်များ ရရှိသည်၊ ထို့ကြောင့် လူနှစ်ဦးက တူညီသော နံပါတ်ကို တစ်ပြိုင်နက် ထုတ်မပေးမိပါ။

## တစ်ဦးချင်းကို မြင်ခြင်း

စက်ရှင်ရှိ လူတိုင်းတွင် ကိုယ်ပိုင်အရောင် ရှိသည်။ 3D view တွင် လူတစ်ဦးစီ၏ pointer ကို ၎င်းတို့အရောင်ဖြင့် မြားအဖြစ်၊ ၎င်းဘေးတွင် အမည်နှင့်အတူ၊ ၎င်းတို့ ညွှန်ပြနေသော အစိတ်အပိုင်းပေါ်တွင် မြင်ရသည်၊ ၎င်းတို့ ရွေးထားသော အစိတ်အပိုင်းတစ်ခုစီ ပတ်လည်တွင် ၎င်းတို့အရောင်ဖြင့် အစက်အပြတ်ဘောင် မြင်ရသည်။

Pointer၊ အမည်နှင့် ရွေးချယ်မှုများသည် စက်ရှင်အတွက်သာ ဖြစ်သည်: ဖိုင်တွင် ဘယ်တော့မှ မသိမ်းဆည်းပါ၊ မည်သူ့ရဲ့ ပြန်ဖျက်မှုထဲကိုမျ ဝင်မည်မဟုတ်ပါ။ ၎င်းတို့သည် လူတစ်ဦးစီ ရှိနေသည့်နေရာသို့ ချောမွေ့စွာ ရွေ့သွားသည်၊ ထို့ကြောင့် နှေးကွေးသော ချိတ်ဆက်မှုတွင်လည်း ချောမွေ့နေသည်။

## ပြန်ဖျက်ရန်က သင့်ကိုယ်ပိုင်အလုပ်ကိုသာ ဖျက်သည်

{{ui:ပြန်ဖျက်ရန်}} သည် သင့်ကိုယ်ပိုင် နောက်ဆုံး တည်းဖြတ်မှုကို ပြန်ဖျက်ပြီး အခြားသူများ၏ တည်းဖြတ်မှုများကို မထိပါ။ တူညီသောအရာကို တစ်စုံတစ်ဦးက ထို့နောက် ပြောင်းလဲခဲ့လျှင် ဘာမျှ ပြန်မဖျက်ရဘဲ status bar က ဘယ်သူဖြစ်သည်ကို ပြသည်။

## browser မှ ဝင်ရောက်ခြင်း

Studio မရှိသော အဖွဲ့ဝင်တစ်ဦးသည် တူညီသောကွန်ရက်ပေါ်ရှိ ဖုန်း၊ tablet သို့မဟုတ် ကွန်ပျူတာဖြင့် ဖိတ်ကြားသူ၏ session code အောက်ရှိ ပုံကို စကင်ဖတ်နိုင်သည်။ BimCraft သည် browser တွင် ဖွင့်ပြီး ဖိတ်ကြားသူက ခွင့်ပြုသည်နှင့် ဖိတ်ကြားသူ၏ မော်ဒယ်ကို ဖွင့်ပေးသည်။ Invite link က အခြားကွန်ရက်မှ တစ်စုံတစ်ဦးကို ဝင်ရောက်စေသည်: ဖိတ်ကြားသူသည် ဤအက်ပ်အတွက် Team Cloud Plan seat လိုအပ်သည်၊ အခြားသူအားလုံး အခမဲ့ ဝင်ရောက်နိုင်သည်၊ link သည် ဖိတ်ကြားသူ၏ စက်ရှင် ဖွင့်ထားချိန်တွင်သာ အလုပ်လုပ်သည်။

## စက်ရှင် ပြီးဆုံးသောအခါ

ဖိတ်ကြားသူတစ်ဦးတည်းသာ မော်ဒယ်ကို သိမ်းဆည်းသည်။ အခြားသူအားလုံးသည် မသိမ်းရသေးသော မိတ္တူကို ထားသည်; ထိန်းသိမ်းလိုလျှင် IFC အဖြစ် သိမ်းပါ။

:::note
ဇာတ်ကွင်းထဲရှိ ပထမမော်ဒယ်တစ်ခုသာ မျှဝေသည်။ စက်ရှင်အတွင်း အခြားဖိုင်ကို ဖွင့်ခြင်းသည် ထို window တွင် စက်ရှင်ကို ထားခဲ့သည်။
:::
