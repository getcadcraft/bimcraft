## သင်လုပ်ရမည့်အရာ

BimCraft ကို သင့်လုပ်ငန်းပုံစံအတိုင်း သတ်မှတ်ပါ၊ မြင်ကွင်းများကို ပွားပါ၊ မျှော်လင့်သလို ပုံနှိပ်ပါ၊ ဒြပ်စင်များကို အမှန်အတိုင်း ရေတွက်ပါ၊ သင့်ရုံး၏ template မှ စီမံကိန်းတိုင်းကို စတင်ပါ။

## လုပ်ငန်းစဉ်ပုံစံ ရွေးချယ်ခြင်း

1. {{ui:ဆက်တင်များ}} ကို ဖွင့်ပြီး **BimCraft** tab ကို ဖွင့်ပါ။ {{ui:လုပ်ငန်းစဉ်ပုံစံ}} ကို ရှာပါ။
2. တစ်ခုကို ရွေးပါ:
   - {{ui:မြင်ကွင်းတစ်ခုစီ ကိုယ်ပိုင်}} (ပထမရွေးချယ်မှု): ပွားထားသော မြင်ကွင်းသည် ၎င်း၏ မှတ်ချက်များကို ကူးယူပြီး ထိုမြင်ကွင်း၏ ကိုယ်ပိုင်အဖြစ် ဆက်နေသည်; စာရွက်များသည် ဖန်သားပြင်ပေါ် ပြသသည့်အတိုင်း ပုံနှိပ်သည်။
   - {{ui:မျှဝေသော မှတ်ချက်များနှင့် ဘောပင်ဇယားများ}}: ပွားထားသော မြင်ကွင်းများသည် မှတ်ချက်များကို မျှဝေသည်; ပုံနှိပ်ခြင်းသည် ဘောပင်ဇယားမှတစ်ဆင့် ဖြစ်သည်။
3. ရွေးချယ်မှုအောက်တွင် ၎င်းသတ်မှတ်သော အချက်လေးခု ရှိသည်။ တစ်ခုချင်းစီကို ပြောင်းနိုင်သည်; ထို့နောက် ပုံစံသည် {{ui:ကိုယ်ပိုင်}} ဟု ဖတ်ရသည်။

လုပ်ငန်းစဉ်ပုံစံကို ဤ browser တွင် သိမ်းထားသည်၊ workspace layout ကဲ့သို့ပင်။ template က မော်ဒယ်အသစ်များသို့ ၎င်းကို သယ်ဆောင်သည်။

## မြင်ကွင်းတစ်ခု ပွားခြင်း

1. {{ui:Project browser}} တွင် floor plan၊ ceiling plan၊ callout၊ elevation နှင့် section တိုင်းတွင် {{ui:Duplicate}} ခလုတ် ရှိသည် (စာရွက်နှစ်ရွက်)။
2. မိတ္တူကို အမည်ပေးပြီး ၎င်း၏ အပြုအမူကို ရွေးပါ:
   - {{ui:Own copy}}: ၎င်း၏ drafting၊ dimensions၊ crop၊ ဝှက်ထားသော ဒြပ်စင်များနှင့် pens များကို ကူးယူပြီး ကိုယ်ပိုင်အဖြစ် ထားသည်။ မြင်ကွင်းတစ်ခုကို တည်းဖြတ်ခြင်းက အခြားမြင်ကွင်းကို ဘယ်တော့မှ မပြောင်းပါ၊ ထို့ကြောင့် ထုတ်ပြီးသား စာရွက်ပေါ်ရှိ မြင်ကွင်းသည် ထုတ်ချိန်အတိုင်း ရှိနေသည်။
   - {{ui:Linked}}: မှတ်ချက်နှင့် settings တစ်ခုတည်းဖြင့် တူညီသော မြင်ကွင်းကို ပြသသည်။
3. မိတ္တူကို {{ui:Duplicated views}} အောက်တွင် စာရင်းပြုသည်။ ဖွင့်ရန် နှိပ်ပါ; plan အထက်ရှိ bar က ၎င်းသည် မိတ္တူဖြစ်ကြောင်း ပြပြီး မူရင်းမြင်ကွင်းသို့ ပြန်ရန် {{ui:Up}} ရှိသည်။
4. ၎င်း၏ slider ခလုတ်က settings ကို ဖွင့်သည်: အမည်၊ {{ui:View range}} (ကိုယ်ပိုင်မိတ္တူတွင် ကိုယ်ပိုင် range ရှိသည်)၊ linked အတွက် {{ui:Make own copy}}၊ နှင့် {{ui:Delete}}။

elevation နှင့် section ၏ မိတ္တူများကို ၎င်းတို့ ထွက်လာသော မြင်ကွင်းများကဲ့သို့ သင့်ကိုယ်ပိုင်စာရွက်များပေါ်တွင် ထားသည်။ ပွားခြင်းသည် undo တစ်ဆင့် ဖြစ်ပြီး မိတ္တူများကို IFC ထဲတွင် callouts ဘေးတွင် သိမ်းထားသည်။

## မြင်ကွင်းနှင့်အတူ ထားသော ဘောပင်များ၊ ပြသထားသည့်အတိုင်း ပုံနှိပ်ခြင်း

1. {{ui:Draw}} ကို ဖွင့်ပြီး {{ui:Pens}} ကို ရွေးပါ။
2. {{ui:For}} တွင် category အားလုံး ပေါ်လာသည်: နံရံများ၊ တံခါးနှင့် ပြတင်းပေါက်များ၊ slabs၊ roofs၊ columns၊ stairs၊ furniture နှင့် အခြား၊ drafting နှင့် dimensions။
3. {{ui:Apply}} က pen ကို ပြသထားသော မြင်ကွင်းနှင့်အတူ IFC တွင် ထားသည်: plan၊ ceiling plan၊ callout သို့မဟုတ် ပွားထားသော မြင်ကွင်း။ 0.9 မတိုင်မီ ပြုလုပ်ထားသော pens များကို browser တွင် ထားခဲ့ပြီး {{ui:Keep these in the file}} က ၎င်းတို့ကို ဖိုင်ထဲသို့ ရွှေ့သည်။
4. စာရွက်များနှင့် PDF သည် pen တိုင်းကို ဖန်သားပြင်ပေါ် ပြသသည့်အတိုင်း ဆွဲသည်။

ဘောပင်ဇယားမှတစ်ဆင့် ပုံနှိပ်ရန်၊ Pens row ရှိ {{ui:Print}} ကို {{ui:Through a pen table}} သို့ သတ်မှတ်ပြီး ဇယားတစ်ခု (colour၊ monochrome၊ grayscale) သို့မဟုတ် {{ui:Edit pen table…}} ကို ရွေးပါ: အရောင်တစ်ခုစီသည် ပုံနှိပ်သည့် အရောင်၊ အထူနှင့် screening ကို ရရှိသည်။ ဇယားသည် CadCraft ၏ plot style ဖိုင်ဖြစ်သောကြောင့် {{ui:Import…}} က CadCraft app တွင် ပြုလုပ်ထားသော ဇယားကို ယူသည်၊ {{ui:Export}} က ဇယားတစ်ခု ပြန်ပေးသည်။ မော်ဒယ်က ၎င်း၏ရွေးချယ်မှုကို ထိန်းသည်; မရှိလျှင် လုပ်ငန်းစဉ်ပုံစံက ဆုံးဖြတ်သည်။

## ဒြပ်စင်တစ်ခုကို အခြား class အဖြစ် အစီရင်ခံခြင်း

road အဖြစ် ဆွဲထားသော slab၊ panel အဖြစ် သုံးထားသော နံရံ၊ ramp ပုံသဏ္ဍာန်ရှိသော roof: ဆွဲခဲ့သော tool ကို ဆက်သုံးပြီး ၎င်းဖြစ်သည့်အတိုင်း အစီရင်ခံပါ။

1. ဒြပ်စင်ကို ရွေးပြီး {{ui:Properties}} ကို ဖွင့်ပါ။ {{ui:Report as}} ကို ဖွင့်ပါ။
2. ရှာဖွေရေးအကွက်တွင် ပုံသဏ္ဍာန်နှင့်ကိုက်ညီသော class ကို ရိုက်ရှာပြီး ရွေးပါ၊ ၎င်း၏ predefined type ကိုလည်း ရွေးပါ။ ကိုယ်ပိုင် type အတွက် USERDEFINED ကို ရွေးပြီး အမည်ပေးပါ။
3. {{ui:Apply}} (undo တစ်ဆင့်)။ {{ui:Clear}} က ဆွဲထားသည့်အတိုင်း ပြန်အစီရင်ခံသည်။

ဆွဲခဲ့သော tool ဖြင့် ဆက်တည်းဖြတ်ရမည်။ သိမ်းထားသော IFC က အစီရင်ခံထားသော class အဖြစ် ရေးသည်၊ ထို့ကြောင့် အခြား program များ၊ {{ui:Quantities}} takeoff၊ ရှာရန်၊ အရောင်ဖြင့်၊ model checks နှင့် {{ui:Problems}} တို့က ထို class အဖြစ် ရေတွက်သည်။ schedules များသည် panel အဖြစ် အစီရင်ခံထားသော နံရံကို walls schedule မှ ဖယ်ထုတ်သည်၊ {{ui:Elements by reported class}} က အားလုံးကို စာရင်းပြုသည်။ ၎င်းသည် IFC4 နှင့် IFC2X3 ဖိုင်များတွင် အလုပ်လုပ်သည်; စာရင်းတွင် ဖိုင်၏ IFC ဗားရှင်းအတွက် class များသာ ပါသည်။ Doors၊ windows၊ stairs၊ rooms နှင့် levels တို့သည် ၎င်းတို့ကိုယ်ပိုင် class ကို ထားသည်။

## စီမံကိန်းကို template အဖြစ် သိမ်းပြီး ၎င်းမှ စတင်ခြင်း

1. စီမံကိန်းဖွင့်ထားစဉ် {{ui:Save}} ဘေးရှိ {{ui:Save as template}} ကို နှိပ်ပါ။
2. အမည်ပေးပါ။ template ကို IFC ဖိုင်အဖြစ် မျှဝေရန် template ဖိုင်ကိုလည်း ဒေါင်းလုဒ်လုပ်ရန် ကို အမှန်ခြစ်ပြီး၊ မော်ဒယ်အသစ်များကို ၎င်းမှ စတင်ရန် {{ui:Start new models from it}} ကို အမှန်ခြစ်ပါ။
3. Template က အထပ်များ၊ view templates နှင့် view settings၊ ပွားထားသော မြင်ကွင်းများနှင့် callouts၊ drafting၊ pens နှင့် ဘောပင်ဇယား၊ tags၊ families နှင့် types၊ sheets၊ sheet sizes၊ title blocks နှင့် လုပ်ငန်းစဉ်ပုံစံကို ထိန်းသည်။ Walls၊ floors၊ doors နှင့် အခြား မော်ဒယ်ဒြပ်စင်အားလုံးကို ထားခဲ့သည်။
4. {{ui:New building}} ကို နှိပ်ပြီး {{ui:Start from}} အောက်တွင် ရွေးပါ၊ သို့မဟုတ် ပို့ပေးထားသော template အတွက် {{ui:A template file…}} ကို ရွေးပါ။ စီမံကိန်းအသစ်သည် ၎င်း၏ကိုယ်ပိုင်အမည်နှင့် ကိုယ်ပိုင် project identity ရရှိသည်; အခြားအရာများသည် template တွင် ရှိသည့်အတိုင်း ဖြစ်သည်။

:::note
Templates များကို ဤ browser တွင် သိမ်းထားသည်။ CadCraft Studio မှတစ်ဆင့် မျှဝေသော အဖွဲ့ templates များ မပြီးသေးပါ: ယခု template ဖိုင်ကို ပို့ပါ။
:::
