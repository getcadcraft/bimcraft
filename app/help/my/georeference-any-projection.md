မြေပုံပေါ် ဆွဲထားသော plan အချို့သည် တိုတောင်းသော စာရင်းတွင် မပါသော မြေပုံစနစ်တစ်ခုပေါ်တွင် ရှိသည်။ ဥပမာ UTM zone၊ အမျိုးသား grid၊ သို့မဟုတ် တစ်စုံတစ်ဦးက စာသား သတ်မှတ်ချက်အဖြစ် ရေးထားသော projection။ {{ui:Measure}} › {{ui:Coordinate system…}} က မော်ဒယ်သုံးထားသော စနစ်ကို သင် ပြောနိုင်စေသည်။

## မော်ဒယ်အတွက် စနစ် ရွေးရန်

1. မော်ဒယ်ကို ဖွင့်ပါ၊ {{ui:Measure}} ကို ရွေးပြီး {{ui:Coordinate system…}} ကို ရွေးပါ။
2. ရှာဖွေရေး အကွက်တွင် ရိုက်ပါ။ အောက်ပါတို့ အလုပ်ဖြစ်သည်:
   - EPSG နံပါတ်: `32633` သို့မဟုတ် `EPSG:2277`;
   - UTM zone: `UTM 33N`၊ `UTM 20 S`၊ `NAD83 UTM 15N`၊ `ETRS89 UTM 32N`;
   - အမည်မှ စကားလုံးများ: `lambert 93`၊ `mga zone 56`၊ `texas central`;
   - projection သတ်မှတ်ချက်: `+proj=tmerc +lat_0=0 +lon_0=9 +k=0.9996 +x_0=500000 +y_0=0 +ellps=WGS84 +units=m` ကဲ့သို့ ရှေ့တွင် အမည်တစ်ခု ထည့်နိုင်သည် (`My grid = +proj=…`);
   - `.prj` ဖိုင်၏ စာသား၊ သို့မဟုတ် {{ui:Load a .prj file…}} ကို သုံးပါ။
3. ရလဒ်တစ်ခု ရွေးပြီး {{ui:Use this system}} ကို နှိပ်ပါ။

ရွေးချယ်မှုကို မော်ဒယ်တွင် သိမ်းသည် (ပရောဂျက်ပေါ်ရှိ `CadCraft_CRS` property set)၊ ထို့ကြောင့် မော်ဒယ် ပြန်ဖွင့်သည့်အခါ ပြန်ပေါ်သည်။ ထိန်းသိမ်းရန် မော်ဒယ်ကို သိမ်းပါ။ {{ui:Take it off the model}} သည် ဖိုင်က ပြောသည့်အတိုင်း ပြန်သွားသည်။

သင့်သတ်မှတ်ချက်က စာရင်းပါ EPSG စနစ်တစ်ခုနှင့် တူညီသော coordinate ပေးလျှင် BimCraft က ထိုသို့ ပြောပြပြီး ထို code ကို သုံးသည်။ စာရင်းပါ စနစ်များ တူညီသော maths ရှိလျှင် အခြားများကိုလည်း နာမည် ပေးသည်။

## ကျွန်ုပ်၏ projections

သင် ကူးထည့်သော သတ်မှတ်ချက် သို့မဟုတ် သင် တင်သော `.prj` ကို {{ui:Keep in My projections}} ဖြင့် ထိန်းနိုင်သည်။ စာရင်းသည် ဤစက် (ဤဘရောက်ဇာ) ပေါ်တွင် ရှိပြီး မော်ဒယ် ရွေးချယ်ကိရိယာကို နောက်တစ်ကြိမ် ဖွင့်သည့်အခါ ပေးသည်။

## အသုံးပြုသည့်အရာများ

- {{ui:Measure}} › {{ui:Location}} သည် ရွေးထားသော အမှတ်ကို မော်ဒယ်၏ စနစ်မှတစ်ဆင့် latitude နှင့် longitude သို့ ပြောင်းသည်။ ဖိုင်က EPSG code မပါဘဲ မြေပုံစနစ်ကို အမည်ပေးထားသည့်အခါ မှတ်ချက်ဖြင့် ရပ်တတ်ခဲ့သည်။ ရွေးချယ်မှု သိမ်းထားသည့်အခါ အဖြေ ပေးသည်။
- မော်ဒယ်အောက်ရှိ မြေပုံအလွှာများသည် တူညီသော စနစ်ကို သုံးသည်။ အခြားစနစ်ရှိ point cloud သို့မဟုတ် terrain ဖိုင်ကို မော်ဒယ်၏ စနစ်ဖြင့် ပေးသည် (အောက်တွင် ကြည့်ပါ)။
- {{ui:Settings}} › {{ui:BimCraft}} › {{ui:Location}} › {{ui:Choose another system…}} သည် {{ui:Location}} က ပို၍ ပြသမည့်အရာကို သတ်မှတ်သည်: မော်ဒယ်၏ ကိုယ်ပိုင်အပြင် ဖော်ပြထားသော geographic စနစ်မည်သည့်တစ်ခုတွင်မဆို latitude နှင့် longitude၊ သို့မဟုတ် projected စနစ်မည်သည့်တစ်ခုတွင်မဆို easting နှင့် northing။

## မြေပုံပေါ် မရှိသေးသော မော်ဒယ်

ဖိုင်တွင် map conversion မရှိလျှင် စနစ်ရွေးချယ်သည့်အခါ {{ui:Place this model on the map}} ဖွင့်သည်။ {{ui:Measure}} › {{ui:Map origin…}} မှလည်း ဖွင့်နိုင်သည်။

1. မော်ဒယ်၏ မူလအမှတ်ကို စနစ်တွင် eastings နှင့် northings အဖြစ် ပေးပါ၊ သို့မဟုတ် latitude နှင့် longitude ရိုက်ပြီး {{ui:Convert to eastings and northings}} ကို ရွေးပါ။
2. Grid north သို့ လည်ပတ်မှု (ဒီဂရီ၊ နာရီလက်တံနှင့် ဆန့်ကျင်ဘက်၊ 0 ဆိုသည်မှာ မော်ဒယ်၏ Y ဝင်ရိုးက grid north ကို ညွှန်သည်) နှင့် မူလအမှတ်၏ အမြင့်ကို ပေးပါ။
3. Scale သည် မော်ဒယ်နှင့် မြေပုံအကြား ယူနစ်ကွာခြားချက် (မီလီမီတာ မော်ဒယ်ကို မီတာ grid ပေါ်တွင် 0.001) မှ စတင်သည်။ ground-to-grid combined factor အတွက်သာ ပြောင်းပါ။
4. {{ui:Place on the map}} ကို ရွေးပါ။ Undo တစ်ကြိမ်ဖြင့် IfcProjectedCRS နှင့် IfcMapConversion (IFC4) ကို ရေးသည်။ မော်ဒယ်ကိုယ်တိုင် မရွှေ့ပါ။

IFC2X3 ဖိုင်တွင် ထို entity နှစ်မျိုး မရှိပါ။ BimCraft သည် ထိုစံက ခွင့်ပြုသော နည်းဖြင့် ဂဏန်းများကို ရေးသည်: buildingSMART property set များ `ePSet_MapConversion` နှင့် `ePSet_ProjectedCRS` ကို ပရောဂျက်ပေါ်တွင်၊ ဆိုက်၏ latitude နှင့် longitude၊ နှင့် true north။ Dialog က ထိုသို့ ပြောသည်။ ထိန်းသိမ်းရန် မော်ဒယ်ကို သိမ်းပါ။

## မြေပုံပေါ် ရှိပြီးသား မော်ဒယ်

ဖိုင်က ကိုယ်တိုင် မြေပုံပေါ် နေရာယူထားပြီး သင် အခြားစနစ် ရွေးသည့်အခါ BimCraft က မေးသည်:

- {{ui:Only change what Location reports}} သည် ဖိုင်၏ ကိုယ်ပိုင် georeference ကို ထိန်းထားပြီး သင့်ရွေးချယ်မှုကို {{ui:Location}}၊ မြေပုံအလွှာနှင့် point cloud များအတွက် သုံးသည်။ (မော်ဒယ်၏ ဂဏန်းများကို ထိုအခါ စနစ်အသစ်ထဲရှိ အဖြစ် ဖတ်သည်။)
- {{ui:Move the model to this system}} သည် georeference ကို ပြန်ရေးသည်။ မူလအမှတ်သည် projection မှတစ်ဆင့် ဖြတ်သွားသည် (eastings၊ northings၊ အမြင့်၊ လည်ပတ်မှုနှင့် scale) ပြီး IfcProjectedCRS (အမည်၊ datum၊ projection၊ zone၊ unit) ကို ပြန်ရေးသည်။ ထို့ကြောင့် သိမ်းထားသော IFC က စနစ်အသစ်ကို ပြောသည်။ ကမ္ဘာပေါ် နေရာသည် အတူတူ ဖြစ်နေသည်: မူလအမှတ်က latitude နှင့် longitude တူညီသည်။ မော်ဒယ်အတွင်း element များ ဘယ်တော့မှ မပြောင်းပါ၊ georeference သာ ပြောင်းသည်။

Dialog က ရွေးချယ်ခြင်းမတိုင်မီ အဟောင်းနှင့် အသစ် မူလအမှတ်ကို ပြသည်။ ထိုသို့ သွားပြီး ပြန်လာခြင်းသည် မူလအမှတ်ကို မီလီမီတာတစ်ခုအတွင်း ပြန်ပေးသည်။

## အခြားစနစ်ရှိ point cloud နှင့် terrain

Cloud သို့မဟုတ် survey ဖိုင်သည် ကိုယ်ပိုင် စနစ် (LAS၊ LAZ၊ E57၊ GeoTIFF) သို့မဟုတ် မည်သည့် စနစ်မှ မပါဘဲ ရှိနိုင်သည်။ မော်ဒယ်နှင့် မတူလျှင် BimCraft က {{ui:Reproject into the model's system}} ကို ပေးသည်။ အမှတ်များကို အစုလိုက် ရွှေ့သည် (များသောအားဖြင့် worker တွင်၊ စာမျက်နှာ အသုံးပြုနိုင်ရန်)။ သင့်ကွန်ပျူတာရှိ ဖိုင်ကို မထိပါ၊ status line က ဘာပြီးသွားသည်ကို ပြောသည်။ ဖိုင်ကို ပြန်ဖွင့်လျှင် ကိုယ်ပိုင် စနစ်သို့ ပြန်ရသည်။ ဖွင့်ပြီးသား cloud အတွက် cloud bar ရှိ {{ui:Reproject to the model…}} က တူညီသည်ကို လုပ်သည်။

ဖိုင်က စနစ်မပြောလျှင် BimCraft က {{ui:Which system is this file in?}} ဟု မေးသည်။ {{ui:Choose the system…}} ဖြင့် ရွေးပါ၊ ထိုဖိုင်အတွက် ဤစက်ပေါ်တွင် မှတ်ထားသည်။ {{ui:Keep the file's own system}} သည် အမှတ်များကို ရှိသည့်အတိုင်း ထားသည်။

## ခန့်မှန်းချက်ဖြစ်သည့်အခါ

ပြဿနာများကို dialog နှင့် Problems panel တွင် စာရင်းပြုသည်၊ တိတ်တဆိတ် မလုပ်ပါ:

- စနစ်ကို ရည်ရွယ်သော ဧရိယာ အပြင်ရှိ နေရာ: ဂဏန်းများ အလုပ်လုပ်သော်လည်း ပုံပျက်မှု ကြီးလာသည်။
- Grid ဖိုင် (NADCON၊ NTv2 နှင့် တူသော) လိုအပ်သော datum shift များ မရနိုင်ပါ။ မတူသော datum ရှိ စနစ်များကို EPSG registry က စာရင်းပြုသော grid-free shift ဖြင့် ရွှေ့ပြီး ရလဒ်သည် ဖော်ပြထားသော တိကျမှုအထိ ခန့်မှန်းချက် ဖြစ်သည်၊ message က မီတာဖြင့် ပြောသည်။
- Projection မလုပ်နိုင်သော အမှတ်ကို ချန်ထားပြီး ရေတွက်သည်။ အရွယ်အစား ကန့်သတ်ချက် ကျော်သော ဖိုင်ကို ကန့်သတ်ချက် ဖော်ပြပြီး ငြင်းသည်။

:::tip
မြေပုံ coordinate များသည် map conversion လိုအပ်သည်။ မရှိသော ဖိုင်ကို {{ui:Map origin…}} ဖြင့် မြေပုံပေါ် နေရာချပါ။
:::

:::note
Grid ဖိုင်မရှိဘဲ datum များကြား ရွှေ့ခြင်းသည် မီတာအနည်းငယ်အတွင်း ကောင်းသည်။ Location ရလဒ်က catalog သိသောအခါ ဘယ်လောက် ကွာသည်ကို ပြောသည်။
:::
