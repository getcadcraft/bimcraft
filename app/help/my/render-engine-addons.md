ထပ်ဆောင်း (ဆက်တင်များ › ထပ်ဆောင်းများ) က {{ui:Render}} ၏ Engine စာရင်းသို့ engine တစ်ခု ထည့်နိုင်သည်။ ထပ်ဆောင်းရေးသူများအတွက် အပြည့်အစုံကို add-on specification ၏ အပိုင်း 16 တွင် ဖော်ပြထားသည်၊ အတိုချုပ်မှာ -

- ထပ်ဆောင်းသည် ကိုယ်ပိုင် ရှေ့ဆက် (prefix) ဖြင့် စသော id၊ အမည်၊ ရွေးချယ်နိုင်သော ဆက်တင်များနှင့် **program တစ်ခုကို run ရန်** သို့မဟုတ် ရုပ်ပုံ ဆွဲသော JavaScript **function တစ်ခု** ထဲမှ **တစ်ခုခု**ကို မှတ်ပုံတင်သည်။
- program ကို run သော engine သည် **`engine.run`** ခွင့်ပြုချက် လိုအပ်ပြီး install မပြုမီနှင့် ဆက်တင်များတွင် ပြသည်။ Studio တွင်သာ run နိုင်သည်; ဝဘ်တွင် သိမ်းရန် ဖိုင်အဖြစ် ပြသည်။
- ထပ်ဆောင်းက program အမည် (ရိုးရိုး ဖိုင်အမည်သာ၊ shell ဘယ်တော့မှ မဟုတ်)၊ **signed ထပ်ဆောင်းအတွင်းရှိ** script နှင့် placeholder နှင့် ရိုးရိုး စကားလုံးများ ပါသော arguments တို့ကို သတ်မှတ်သည်။ Studio က program ကို ရှာတွေ့ရင် သို့မဟုတ် တစ်ကြိမ် ညွှန်ပြရန် မေးသည်။
- ထပ်ဆောင်းက program ကို ပထမဆုံး run သောအခါ **Studio က ကိုယ်ပိုင် dialog ဖြင့် မေးသည်**: မည်သည့် ထပ်ဆောင်း၊ မည်သည့် program၊ နှင့် script သည် program ကဲ့သို့ ဘာမဆို လုပ်နိုင်ကြောင်း။ ယုံကြည်ရသော ထပ်ဆောင်းအတွက်သာ ခွင့်ပြုပါ။ သင့်ဖြေဆိုချက်ကို ထိုထပ်ဆောင်းနှင့် program အတွက် မှတ်ထားသည်။
- Package (ဇာတ်ကွင်းကို USD နှင့် ဆက်တင်ဖိုင်၊ ထပ်ဆောင်းက တောင်းဆိုသည့်အခါ glTF ဖိုင်ပါ) နှင့် ထပ်ဆောင်း၏ script တို့ကို temporary folder အသစ်သို့ ထည့်သည်၊ program ကို ထို နေရာတွင် run ပြီး ရုပ်ပုံကို ထပ်ဆောင်း၏ engine အမည်ဖြင့် အမှတ်အသားပြုကာ ပြန်ပေးသည်။

:::note
ထပ်ဆောင်းများသည် add-on API 1.4 မှစ၍သာ render engine ထည့်နိုင်သည်။ open-source command-line renderer အတွက် ဥပမာကို ၎င်း၏ ကိုယ်ပိုင် repository တွင် ရှိသည်၊ ထို renderer တွင် ဘယ်တော့မှ မ run ရသေးပါ။
:::
