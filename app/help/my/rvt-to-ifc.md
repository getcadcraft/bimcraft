## ဘာလုပ်ရမလဲ

ပရောဂျက်ဖိုင်ကို BimCraft တွင် လှည့်ကြည့်၊ စစ်ဆေး၊ ပမာဏထုတ်နှင့် ပြင်ဆင်နိုင်သော IFC ဖိုင်အဖြစ် ပြောင်းပါ။ BimCraft သည် `.rvt` ဖိုင်ထဲရှိ 3D မော်ဒယ်ကို မဖတ်နိုင်သေးသဖြင့် export သည် ဖိုင်ကို ဖန်တီးခဲ့သော ပရိုဂရမ် (Revit) တွင် ပြုလုပ်ပြီး BimCraft က ရလဒ်ကို ဖွင့်သည်။

## အဆင့်များ

1. ပရောဂျက်ကို ၎င်းကို ဖန်တီးခဲ့သော ပရိုဂရမ်တွင် ဖွင့်ပါ။ BimCraft ၏ ကဒ်က ၎င်းသိမ်းခဲ့သော release ကို အမည်ပေးသည်။
2. export လုပ်လိုသည်ကို ပြသသော 3D view ကို ဖွင့်ပါ။
3. **File > Export > IFC** ကို ရွေးပါ။
4. export dialog တွင် အောက်ပါ ဆက်တင်များဖြင့် setup တစ်ခုကို ရွေးပါ (သို့မဟုတ် **Modify setup…**)။
5. folder နှင့် ဖိုင်အမည်ကို ရွေးပြီး export လုပ်ပါ။
6. BimCraft တွင် {{ui:Choose a file}} ကို နှိပ်ပြီး အသစ် `.ifc` ဖိုင်ကို ရွေးပါ။ သီးခြားဖိုင်များအဖြစ် export လုပ်ထားသော ချိတ်ဆက်ထားသည့် မော်ဒယ်များကို {{ui:Add a model}} ဖြင့် တူညီသော ဇာတ်ခင်းတွင် ဖွင့်နိုင်သည်။

## ဤနေရာတွင် အကောင်းဆုံး ဖွင့်နိုင်သော ဆက်တင်များ

| exporter ရှိ ဆက်တင် | ရွေးရန် | အကြောင်းရင်း |
|---|---|---|
| IFC version | ကြည့်ရန်၊ စစ်ဆေးရန်နှင့် ပမာဏထုတ်ရန်အတွက် **IFC4 Reference View**၊ အခြားသူများက IFC2X3 လိုအပ်သောအခါ **IFC2X3 Coordination View 2.0** | နှစ်ခုလုံး အပြည့်အဝ ဖွင့်သည်။ **IFC4 Design Transfer View** ကလည်း ဖွင့်သည်၊ ပိုတိကျသော ပုံသဏ္ဍာန်များပါသော်လည်း ဖိုင်က ပိုကြီးပြီး ပိုနှေးသည်။ |
| ဖိုင်အမျိုးအစား | **IFC** (ရိုးရိုး) | BimCraft သည် `.ifczip` သို့မဟုတ် `.ifcxml` ကို မဖွင့်ပါ။ |
| အဆင့် / မြင်ရသော အစိတ်အပိုင်းများ | သင်ဆိုလိုသော အဆင့်နှင့် 3D view ကို ထိုအတွက် ပြင်ဆင်သည့်အခါ **Export only elements visible in view** | ရည်ရွယ်ချက်ရှိရှိ ဝှက်ထားသည်များကို ချန်ထားသည်။ |
| Property sets | **Export Revit property sets** နှင့် **Export IFC common property sets** | ၎င်းတို့သည် BimCraft က {{ui:Properties}} တွင် ပြသသော property sets ဖြစ်လာပြီး {{ui:Find}}၊ {{ui:Color}} နှင့် {{ui:Model checks}} တို့က သုံးသည်။ |
| Base quantities | **Export base quantities** | {{ui:Quantity totals}} နှင့် ဇယားများက ခန့်မှန်းမည့်အစား (အလျား၊ ဧရိယာ၊ ထုထည်) ကို သုံးသည်။ |
| အခန်းများနှင့် ဧရိယာများ | **Export rooms in 3D views** (သို့မဟုတ် Rooms / Spaces ရွေးချယ်မှု) | အခန်းများသည် spaces အဖြစ် ရောက်လာသည်- ၎င်းတို့ကို ကြည့်ရန် {{ui:Spaces}} ကို နှိပ်ပါ။ |
| ချိတ်ဆက်ထားသော ဖိုင်များ | **Export linked files as separate IFCs** | ချိတ်ဆက်မှုတစ်ခုစီသည် ကိုယ်ပိုင်ဖိုင် ဖြစ်လာသည်; {{ui:Add a model}} ဖြင့် အတူ ဖွင့်ပါက ၎င်းတို့ လိုက်ဖက်သည်။ |
| Coordinate base | **Shared coordinates** (သို့မဟုတ် survey point) | ထို့နောက် ဖိုင်က မြေပုံပေါ်ရှိ နေရာကို (IfcMapConversion) သယ်ဆောင်သဖြင့် တိုင်း › တည်နေရာ၊ မြေပြင်ပေါ်ရှိ မြေပုံအလွှာများနှင့် မြေပုံ coordinates ဖြင့် နေရာချထားသော point cloud များ အလုပ်လုပ်သည်။ project base point က မော်ဒယ်ကို မူလအမှတ်အနီးတွင် ထားသော်လည်း ၎င်း၏ မြေပုံနေရာ မရှိပါ။ |
| နံရံနှင့် ကော်လံများကို အဆင့်အလိုက် ခွဲခြင်း | ဖွင့်ပါ၊ အထပ်တစ်ခုစီအလိုက် ပမာဏထုတ်သည့်အခါ | အထပ်တစ်ခုစီ၏ အပိုင်းသည် ၎င်း၏ ကိုယ်ပိုင် element ဖြစ်သည်။ |

## မြင်ရမည့်အရာများ

3D ရှိ မော်ဒယ်၊ ပရောဂျက် အဆင့်များမှ အထပ်များ၊ နှင့် {{ui:File}} panel ရှိ ပရောဂျက် အချက်အလက်။ **Exported from** က exporter ကို အမည်ပေးသည်။

## export က ထိန်းထားသည်များနှင့် မထိန်းထားသည်များ

- **ထိန်းထားသည်**: geometry၊ အထပ်များ၊ element အမျိုးအစားများ၊ အမည်များ၊ အမျိုးအစားများ၊ parameter အများစု (property sets အဖြစ်)၊ တောင်းဆိုသည့်အခါ base quantities၊ spaces အဖြစ် အခန်းများနှင့် shared coordinates ဖြင့် မြေပုံနေရာ။
- **မထိန်းထားသည်**: views၊ sheets၊ annotation၊ ပြင်ဆင်နိုင်သော family အဖြစ် families၊ worksets နှင့် design options။ IFC ဖိုင်သည် မော်ဒယ် element များ၏ လျှပ်တပြက်ဖြစ်ပြီး ပရောဂျက် မဟုတ်ပါ။ sheets အတွက် DWG ကို export လုပ်ပြီး 2D view တွင် ဖွင့်ပါ။

## အများဆုံး မှားတတ်သည်များ

- **BimCraft တွင် parameters မရှိခြင်း။** အထက်ပါ property set ရွေးချယ်စရာများကို ဖွင့်ပြီး ထပ်မံ export လုပ်ပါ။
- **အခန်းများ မရှိခြင်း။** အခန်းရွေးချယ်စရာကို ဖွင့်ပြီး {{ui:Spaces}} ကို နှိပ်ပါ။
- **`.ifczip` အဖြစ် သိမ်းခြင်း။** ရိုးရိုး IFC ကို ရွေးပါ၊ သို့မဟုတ် `.ifczip` ကို ဖြည်ပါ။
- **မြေပုံနေရာ မရှိခြင်း။** shared coordinates ဖြင့် export လုပ်ပါ၊ ပရောဂျက်၏ survey point ကို သတ်မှတ်ထားကြောင်း စစ်ပါ။
- **ပြင်ဆင်ချက်များ ပြန်ရောက်မည်ဟု မျှော်လင့်ခြင်း။** BimCraft တွင် သိမ်းသော ပြင်ဆင်ချက်များသည် ပရောဂျက်ဖိုင်ထဲသို့ မဟုတ်ဘဲ IFC ဖိုင်အသစ်ထဲသို့ ဝင်သည်။
