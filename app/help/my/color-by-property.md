## သင်လုပ်မည့်အရာ

ဂုဏ်သတ္တိတစ်ခုသည် မော်ဒယ်တစ်ခုလုံးတွင် ဘယ်လို ပျံ့နှံ့နေသည်ကို တစ်ချက်ကြည့်ဖြင့် မြင်ပါ။ ဥပမာ ဘယ်နံရံများသည် ပြင်ပဖြစ်သလဲ၊ ဘယ်နေရာတွင် ဘယ်ပစ္စည်းများ သုံးထားသလဲ၊ ဘယ်ဒြပ်စင်တွင် fire rating မရှိသလဲ။ ဒြပ်စင်တိုင်းသည် မိမိတန်ဖိုး၏ အရောင်ကို ယူသည်၊ legend က အရောင်တစ်ခုစီ၏ အဓိပ္ပာယ်နှင့် ဒြပ်စင်မည်မျှ ရှိသည်ကို ပြသည်။

## အဆင့်များ

1. IFC မော်ဒယ်တစ်ခုကို ဖွင့်ပါ။
2. ညာဘက်ရှိ {{ui:Color}} tab ကို နှိပ်ပါ။
3. စာရင်းမှ ဂုဏ်သတ္တိတစ်ခုကို ရွေးပါ။ ပထမဆုံးများသည် ဒြပ်စင်အားလုံးတွင် ရှိသည် ({{ui:Class}}၊ {{ui:Type}}၊ {{ui:Storey}}၊ {{ui:Material}}၊ {{ui:Name}}…)၊ ကျန်တာများကို မော်ဒယ်၏ property sets နှင့် quantity sets မှ ယူထားပြီး set ၏ အမည်အောက်တွင် ပါသည်။ အမည်တစ်ခုစီနောက်ရှိ နံပါတ်သည် ထိုဂုဏ်သတ္တိရှိသော ဒြပ်စင် အရေအတွက် ဖြစ်သည်။
4. Legend ကို ဖတ်ပါ။ အရောင်၊ တန်ဖိုးနှင့် ဒြပ်စင် အရေအတွက်ကို ကြည့်ပါ။
5. တန်ဖိုးတစ်ခုကို နှိပ်ပြီး ထိုဒြပ်စင်များသာ ပြပါ။ တန်ဖိုးများ ထပ်ထည့်ရန် {{key:Mod}} ကို ဖိထားပြီး နှိပ်ပါ။ အားလုံးကို ပြန်ပြရန် {{key:Shift+H}} ကို နှိပ်ပါ။
6. မော်ဒယ်၏ မူလအရောင်များသို့ ပြန်သွားရန် {{ui:Off}} ကို နှိပ်ပါ။

## သင်မြင်ရမည့်အရာ

- အများဆုံးဖြစ်သော တန်ဖိုးကို အရင်ဆုံး ယူပြီး တန်ဖိုး ခုနစ်ခုအထိ အရောင်တစ်ခုစီ ရသည်။ ထိုထက်ပိုသော တန်ဖိုးများသည် မီးခိုးရောင်တစ်ခုတည်းကို မျှဝေပြီး **other values** ဟု စာရင်းပြုသည်။
- ဂဏန်းတန်ဖိုး အမျိုးမျိုးရှိသော ဂုဏ်သတ္တိကို အပိုင်းတန်းညီ ခြောက်ပိုင်းခွဲသည်၊ နိမ့်ရာမှ (light) မြင့်ရာသို့ (dark)။
- ဂုဏ်သတ္တိမရှိသော ဒြပ်စင်များသည် မှိန်သော မီးခိုးရောင် ဖြစ်ပြီး **No value** ဟု စာရင်းပြုသည်၊ အရောင်ရှိသော ဒြပ်စင်များ ထင်ရှားစေရန်။
- အရောင်များသည် Paper နှင့် Model အလိုက် ပြောင်းလဲပြီး မော်ဒယ်ကို တည်းဖြတ်နေချိန်တွင်လည်း ဆက်ရှိနေသည်။
- Type တစ်ခု၏ ဂုဏ်သတ္တိသည် ထို type ၏ ဒြပ်စင်အားလုံးအတွက် သက်ရောက်သည်။ ဒြပ်စင်တစ်ခုတွင် တူညီသော ဂုဏ်သတ္တိအတွက် မိမိတန်ဖိုး ရှိလျှင် မိမိတန်ဖိုးက ဦးစားပေးသည်။

## အရောင်ပြောင်းပြီး scheme အဖြစ် ထားရှိခြင်း

- Legend ရှိ တန်ဖိုး၏ swatch ကို နှိပ်ပြီး အခြားအရောင် ရွေးပါ။ မော်ဒယ်ကို ချက်ချင်း ပြန်ဆိုးသည်။
- {{ui:Save scheme}} သည် အရောင်များကို ဂုဏ်သတ္တိအမည်ဖြင့် အမည်ပေးထားသော `.json` ငယ်ငယ်ဖိုင်အဖြစ် ဒေါင်းလုဒ်ဆွဲသည်၊ ဥပမာ `Class colors.json`။
- အခြားမော်ဒယ်တစ်ခု သို့မဟုတ် အဖွဲ့ဝင်တစ်ဦး၏ ကွန်ပျူတာတွင် {{ui:Open scheme…}} ကို နှိပ်ပြီး ထိုဖိုင်ကို ရွေးပါ။ Scheme ရှိ တန်ဖိုးတိုင်းသည် အရောင်ရမည်၊ ထို့ကြောင့် fire rating သို့မဟုတ် စနစ်တစ်ခုသည် မော်ဒယ်တိုင်းတွင် အရောင်တူသည်။
- Scheme တွင် မရှိသော တန်ဖိုးကို မီးခိုးရောင်ဖြင့် ဆိုးပြီး "not in the scheme" ဟု စာရင်းပြုသည်။ Scheme တွင်ရှိသော်လည်း ဤမော်ဒယ်တွင် မရှိသော တန်ဖိုးများကို 0 ဖြင့် ဆက်ပြသည်၊ scheme တစ်ခုလုံးကို မြင်နိုင်စေရန်။
- Scheme သည် အရောင်များကို theme နှစ်ခုစလုံးတွင် သိမ်းထားသည်။ စာရင်းမှ ဂုဏ်သတ္တိတစ်ခုကို ရွေးချယ်လျှင် အလိုအလျောက် အရောင်များမှ ပြန်စသည်။

## အများဆုံး အမှားများ

- **"This model has no … values".** Scheme ကို ဤမော်ဒယ်တွင် မရှိသော ဂုဏ်သတ္တိအတွက် သိမ်းထားသည် (ဥပမာ property set အမည် မတူ)။ ဤအမျိုးအစား မော်ဒယ်အတွက် ပြုလုပ်ထားသော scheme ကို ဖွင့်ပါ၊ သို့မဟုတ် စာရင်းမှ ဂုဏ်သတ္တိကို ရွေးပါ။

- **ဂုဏ်သတ္တိတစ်ခု စာရင်းတွင် မပါခြင်း။** မော်ဒယ်ထဲတွင် ပုံသဏ္ဍာန်ရှိသော ဒြပ်စင်တစ်ခုမှ မရှိပါ။ Storey နှင့် space များ၏ ဂုဏ်သတ္တိများကို စာရင်းတွင် မပြပါ။
- **အားလုံး အရောင်တူခြင်း။** ဒြပ်စင်အားလုံးတွင် တန်ဖိုးတူ သို့မဟုတ် တစ်ခုမှ မရှိပါ၊ legend ရှိ အရေအတွက်များကို ကြည့်ပါ။
