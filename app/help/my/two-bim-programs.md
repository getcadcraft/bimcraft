## ဘာလုပ်မလဲ

မော်ဒယ်ကို BIM ပရိုဂရမ်တစ်ခုမှ တစ်ခုသို့ ရွှေ့ပါ၊ ဥပမာ Revit မှ Archicad သို့ သွားပြီး ပြန်လာခြင်း၊ IFC မှတစ်ဆင့်၊ BimCraft ကို အလယ်တွင်ထား၍ စစ်ဆေးပြီး ထည့်ပြီး ဘာများ ကျန်ခဲ့သည်ကို အစီရင်ခံပါ။ ပရိုဂရမ်တစ်ခုစီ၏ ကိုယ်ပိုင်ဖိုင်ဖော်မတ်ကို မဖတ်ပါ: အရာအားလုံးသည် IFC အဖြစ် သွားသည်။

## BimCraft ထိန်းထားသည်များ

BimCraft တွင် မော်ဒယ်ကို ပြောင်းပြီး **{{ui:IFC အဖြစ် သိမ်းရန်}}** ကို နှိပ်သောအခါ သင်မပြင်ခဲ့သော လိုင်းတိုင်း အတိအကျ ပြန်ရေးသည်။ ထို့ကြောင့်:

- **GlobalId** များ အတူတူ ကျန်သည်၊ အခြားပရိုဂရမ်က ပို့ထားသော ဒြပ်စင်တိုင်းနှင့် ကိုက်ညီနိုင်သည်။
- **Property set** များနှင့် တန်ဖိုးများ ကျန်သည်၊ သင်ပြောင်းလဲထားသော တန်ဖိုးများမှလွဲ၍။
- **Classification** များသည် ၎င်းတို့၏ ဒြပ်စင်များတွင် ချိတ်ထားဆဲ ဖြစ်သည်။

## ပရိုဂရမ်နှစ်ခုလုံးကို တူညီသော ဂုဏ်သတ္တိများအတွက် ပြင်ဆင်ခြင်း

1. BimCraft တွင် မော်ဒယ်ကို ဖွင့်ပါ (ပရောဂျက် bundle ရှိလျှင် ထိုကိုလည်း ဖွင့်ပါ: ၎င်း၏ property group များ ထည့်သည်)။
2. ဘယ်ဘက်ပြားတွင် {{ui:BIM ပရိုဂရမ်နှစ်ခုကြား}} ကို ဖွင့်ပါ။
3. **Property mapping** အောက်တွင် ပရိုဂရမ်တစ်ခုစီ လိုအပ်သည်များကို ဒေါင်းလုဒ်လုပ်ပါ:
   - {{ui:မျှဝေ parameter များ}}: မျှဝေ parameter ဖိုင်။ Revit တွင် Manage › Shared Parameters ဖြင့် တင်ပြီး လိုအပ်သော အမျိုးအစားများသို့ parameter များ ထည့်ပါ။
   - {{ui:IFC ထုတ်ယူမှု ဂုဏ်သတ္တိအစုများ}}: အသုံးပြုသူသတ်မှတ် property set ဖိုင်။ Revit ၏ IFC ထုတ်ယူမှု ဆက်တင်တွင် user-defined property set များအောက်တွင် ရွေးပါ၊ ထို့ကြောင့် ထုတ်ထားသော IFC သည် တူညီသော set နှင့် property အမည်များကို ဆောင်သည်။
   - {{ui:မြေပုံဇယား (CSV)}}: property တိုင်းအတွက် ၎င်း၏ IFC set နှင့် အမည်၊ အမျိုးအစား၊ နှင့် ပရိုဂရမ်တစ်ခုစီရှိ ကိုက်ညီသော အမည်များ။ Archicad ၏ mapping ဖိုင်များသည် ထုတ်ပြန်ထားသော ဖော်မတ် မဟုတ်ပါ၊ ထို့ကြောင့် ၎င်း၏ IFC translator နှင့် property manager ကို ဤဇယားမှ လက်ဖြင့် သတ်မှတ်ပါ။
   - {{ui:မြေပုံဖိုင်}}: mapping အပြည့်အစုံကို ဖိုင်တစ်ခုအဖြစ်၊ ပရောဂျက်နှင့်အတူ ထားရန်။

Standard set (Pset_ နှင့် Qto_) များကို မျှဝေ parameter ဖိုင်မှ ချန်ထားသည်: ပရိုဂရမ်နှစ်ခုစလုံးက ၎င်းတို့၏ ကိုယ်ပိုင်ဒေတာမှ ထိုကို ရေးသည်။

## မော်ဒယ်ပို့ပြီး ပြန်ယူခြင်း

1. ပထမပရိုဂရမ်မှ GlobalId များ ထိန်းပြီး IFC ထုတ်ပါ (Revit: "Store the IFC GUID in an element parameter after export" ကို ဖွင့်ပါ)။
2. BimCraft တွင် ဖွင့်ပြီး စစ်ဆေးပါ ({{ui:မော်ဒယ် စစ်ဆေးချက်များ}}၊ {{ui:ထိခိုက်မှု စစ်ဆေးခြင်း}})၊ ပြဿနာများ ထည့်ပါ ({{ui:ပြဿနာများ}}၊ BCF)၊ လိုအပ်လျှင် တန်ဖိုးများ ပြောင်းပြီး {{ui:IFC အဖြစ် သိမ်းရန်}}။
3. သိမ်းထားသော IFC ကို ဒုတိယပရိုဂရမ်တွင် ဖွင့်ပြီး အလုပ်လုပ်ကာ GlobalId များ ထိန်းပြီး IFC ထုတ်ပါ (Archicad translator: "Global Unique Identifiers: Keep existing")။
4. BimCraft သို့ ပြန်ရောက်ပြီး ထွက်သွားသော မော်ဒယ်ကို ဖွင့်ပါ၊ ထို့နောက် ပြန်လာသော မော်ဒယ်ကို ထည့်ပါ (မော်ဒယ်များ အောက်ရှိ {{ui:မော်ဒယ် ထည့်ရန်}})။
5. {{ui:BIM ပရိုဂရမ်နှစ်ခုကြား}} တွင် **ထွက်သွားသည်** နှင့် **ပြန်လာသည်** ကို ရွေးပြီး {{ui:အစီရင်ခံစာ ပြုလုပ်ရန်}} ကို နှိပ်ပါ။

## အစီရင်ခံစာ ဖတ်ခြင်း

- **ဒြပ်စင်များ**: GlobalId တူညီစွာ ပြန်ရောက်လာသော အရေအတွက်၊ ပျောက်နေသော အရေအတွက်နှင့် အသစ် အရေအတွက်။ GlobalId အသစ်ရှိ ဒြပ်စင်များသည် ပျောက်တစ်ခုနှင့် အသစ်တစ်ခုအဖြစ် ပြသည်: အခြားပရိုဂရမ်က မထိန်းထားခဲ့ပါ။
- **IFC class ပြောင်းသွားသည်**: အခြားအမျိုးအစား ဒြပ်စင်အဖြစ် ပြန်ရောက်လာသော ဒြပ်စင်များ။
- **ထိန်းထားသော property တန်ဖိုးများ**: မပြောင်းဘဲ ပြန်ရောက်သော တန်ဖိုး၏ ရာခိုင်နှုန်း။ အောက်ပါစာရင်းက ပြောင်းသွား သို့မဟုတ် ပျောက်သော တန်ဖိုးအများဆုံး property များကို ပြသည်။
- **Classification များ**: ထိန်းထားသည်၊ ပြောင်းသွားသည် (စနစ်တူ၊ ကုဒ်အခြား) သို့မဟုတ် ပျောက်သည်။

{{ui:အစီရင်ခံစာ ဒေါင်းလုဒ် (CSV)}} က property တိုင်းကို ၎င်း၏ အရေအတွက်များဖြင့် ပေးသည်။ ဒြပ်စင်များ ရွှေ့သွားခြင်း သို့မဟုတ် ပုံသဏ္ဍာန် ပြောင်းသွားခြင်းကို ကြည့်လိုလျှင် မော်ဒယ်နှစ်ခုတူညီပေါ်တွင် {{ui:ဗားရှင်းများ နှိုင်းယှဉ်ရန်}} ကို သုံးပါ။

:::note
BimCraft သည် ပရိုဂရမ်နှစ်ခုလုံးကို မလည်ပတ်ပါ။ တန်ဖိုးကို မည်သည့် ဆက်တင်က သယ်သည်ဆိုသည်မှာ ပရိုဂရမ်တစ်ခုစီ၏ IFC ဆက်တင်အပေါ် မူတည်သည်: အစီရင်ခံစာက တကယ်ပြန်ရောက်လာသည်ကို ပြသသောကြောင့် ဆက်တင်တစ်ခုကို စမ်းကြည့်ပြီး ပြန်ထုတ်ကာ နှိုင်းယှဉ်ပါ။
:::

## ပြဿနာများကို BCF အဖြစ် သယ်ခြင်း

BimCraft တွင် သင်တင်သော ပြဿနာများသည် BCF ({{ui:ပြဿနာများ}}) အဖြစ် ထုတ်သည်၊ ပရိုဂရမ်နှစ်ခုလုံးက ၎င်းတို့၏ BCF ကိရိယာများဖြင့် ဖတ်နိုင်သည်၊ ထို့ကြောင့် ဒြပ်စင်အကြောင်း မေးခွန်းသည် ၎င်း၏ viewpoint နှင့်အတူ အခြားပရိုဂရမ်တွင် လုပ်နေသူထံ ရောက်သည်။

ကြည့်ရန်လည်း [ပရောဂျက် bundle ဖွင့်ခြင်း](topic:open-project-bundle)၊ [ပရောဂျက်ဖိုင်မှ BimCraft သို့ IFC မှတစ်ဆင့်](topic:rvt-to-ifc) နှင့် [မော်ဒယ်ဗားရှင်းနှစ်ခု နှိုင်းယှဉ်ခြင်း](topic:compare-versions)။
