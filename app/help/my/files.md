BimCraft သည် သင့်ကွန်ပျူတာပေါ်ရှိ ဖိုင်များကို browser tab အတွင်းတွင် ဖတ်သည်။ **ဘာမျှ မတင်ပါ** CadCraft သို့မဟုတ် အခြား မည်သူ့ဆီသို့မျှ။ သိမ်းသောအခါ BimCraft သည် browser သို့ ဒေါင်းလုဒ်လုပ်ရန် ဖိုင်အသစ်တစ်ခု ပေးသည်; သင်ဖွင့်ထားသော ဖိုင်ကို ဘယ်တော့မျှ အစားထိုး မရေးပါ။

## ဖွင့်နိုင်သည့်အရာ

| ဖော်မတ် | တိုးချဲ့ခြင်းများ | ရရှိမည့်အရာ |
|---|---|---|
| IFC | `.ifc` | 3D ဖြင့် မော်ဒယ်၊ အထပ်များ၊ element အရေအတွက်နှင့် element တိုင်း၏ ဂုဏ်သတ္တိများ။ အမည်များ၊ tag များနှင့် property တန်ဖိုး တစ်ခုချင်းစီကို ပြောင်းလဲနိုင်သည်။ |
| Project and family files | `.rvt` `.rfa` `.rte` `.rft` | ဖိုင်ကတ်: release၊ build၊ worksharing၊ ပရောဂျက် အချက်အလက်၊ family parameter များ၊ ချိတ်ဆက်ထားသော ဖိုင်များနှင့် preview ပုံ။ 3D မပါ။ |
| DWG | `.dwg` | 2D ဖြင့် ပုံဆွဲ- model space၊ sheet တိုင်း၊ layer များ၊ ချိတ်ဆက်ထားသော ပုံဆွဲများ၊ ပုံများနှင့် print view။ Model space ကို 3D ဖြင့်လည်း ပြသည်။ AutoCAD 2000 မှ 2018 အထိ ဖော်မတ်များကို စစ်ဆေးပြီးဖြစ်သည်။ |
| DXF | `.dxf` | DWG နှင့် တူညီသည်။ |
| STEP | `.step` `.stp` | 3D ဖြင့် အပိုင်းတစ်ခု၊ စက်ပစ္စည်းတစ်ခု သို့မဟုတ် supplier ၏ မော်ဒယ် (AP203, AP214, AP242): solid တစ်ခုစီသည် အထပ်တစ်ခုတည်းပေါ်ရှိ IFC မော်ဒယ်အသေးတစ်ခု၏ element တစ်ခု (building element proxy) ဖြစ်လာပြီး၊ triangle များအဖြစ် ၎င်း၏ အမှန်အရွယ်အတိုင်း ဖတ်သည်၊ ဖိုင်က ထားရှိသည့်နေရာတွင် အစိတ်အပိုင်းအားလုံးပါသော assembly။ ထိုနေရာမှစ၍ မည်သည့် IFC နှင့်မဆို အလားတူ အလုပ်လုပ်သည်- ဂုဏ်သတ္တိများ၊ ဖြတ်ပိုင်းများ၊ တိုင်းတာခြင်း၊ {{ui:IFC အဖြစ် သိမ်းရန်}}။ အရောင်များနှင့် assembly tree ကို မဖတ်ပါ။ |
| Point clouds | `.las` `.laz` `.e57` `.ply` `.pcd` `.ptx` `.pts` `.xyz` | 3D view ရှိ scan၊ မော်ဒယ်ဘေးတွင် သို့မဟုတ် တစ်ကိုယ်တည်း- [မော်ဒယ်ဘေးတွင် point cloud ပြခြင်း](topic:point-clouds) ကို ကြည့်ပါ။ |
| Project bundle | `.ccbundle.zip` | မော်ဒယ်နှင့် ၎င်း၏ views၊ layouts နှင့် property groups- [ပရောဂျက် bundle ဖွင့်ခြင်း](topic:open-project-bundle) ကို ကြည့်ပါ။ |
| ဖိုဒါ | မည်သည်ဖြစ်စေ | ဖိုဒါထဲရှိ မော်ဒယ်၊ ပုံဆွဲနှင့် bundle တိုင်း၏ အစီရင်ခံစာ။ အစီရင်ခံစာရှိ IFC၊ မော်ဒယ်၊ ပုံဆွဲ သို့မဟုတ် bundle တစ်ခုကို နှိပ်လိုက်လျှင် ဖွင့်သည်။ |

[ဖော်မတ်တစ်ခုစီမှ BimCraft ဖတ်သည့်အရာ](topic:file-formats) တွင် အသေးစိတ် ဖော်ပြထားသည်။

BimCraft သည် ဖိုင်တစ်ခု ဘာလဲဆိုသည်ကို ၎င်း၏ ပထမ bytes များကိုလည်း ကြည့်ပြီး ဆုံးဖြတ်သည်၊ ထို့ကြောင့် သာမန်မဟုတ်သော extension ရှိသော ပရောဂျက်ဖိုင်သည်လည်း ဖိုင်ကတ်အဖြစ် ဖွင့်သည်။

### မဖွင့်နိုင်သောဖိုင်များ

- `.ifczip` နှင့် `.ifcxml`: BimCraft က "`.ifczip is not supported yet. Save or export the model as a plain .ifc file.`" ဟု ပြောသည်။ `.ifczip` ကို unzip လုပ်ပါ (ထိုဖိုင်တွင် ရိုးရိုး `.ifc` ပါသည်) သို့မဟုတ် ရိုးရိုး IFC အဖြစ် ထပ်မံ export လုပ်ပါ။
- DGN ပုံဆွဲများကို ဖိုဒါအစီရင်ခံစာတွင် ဖော်ပြသော်လည်း ဖွင့်မရပါ။
- PDF၊ ပုံများနှင့် office ဖိုင်များကို သီးခြား မဖွင့်နိုင်ပါ။ ပုံများကို DWG အတွင်း ပုံအဖြစ် သုံးသည်၊ နှင့် {{ui:Build}} › {{ui:ပုံဆွဲမှ…}} သည် PDF သို့မဟုတ် scan ၏ စာမျက်နှာများကို နံရံများအဖြစ် ပြောင်းပေးသည်- [ပလန်အစုမှ နံရံများ](topic:walls-from-plans) ကို ကြည့်ပါ။

## ဘာသိမ်းသလဲ

| သင်နှိပ်သည် | သင်ရရှိသည် | နေရာ |
|---|---|---|
| {{ui:IFC အဖြစ် သိမ်းရန်}} | သင့်တည်းဖြတ်မှုများပါသော IFC ဖိုင်အသစ်၊ "*original name* (edited).ifc" ဟု အမည်ပေးထားသည် | သင့် browser ၏ downloads ဖိုဒါ |
| စက်ပစ္စည်းဇယားရှိ {{ui:CSV ဒေါင်းလုဒ်လုပ်ရန်}} | စာရင်းရှိ ပစ္စည်းများ၏ CSV၊ "*drawing name* equipment.csv" ဟု အမည်ပေးထားသည် | သင့် browser ၏ downloads ဖိုဒါ |

အခြားအရာများကို ၎င်းတို့ ပြုလုပ်သည့်နေရာတွင် သိမ်းပြီး၊ အကြောင်းအရာတစ်ခုစီ၏ ကိုယ်ပိုင် topic တွင် ဖော်ပြသည်- {{ui:USD}} ([USD အဖြစ် မော်ဒယ်ကို export လုပ်ခြင်း](topic:usd))၊ {{ui:Collada}} (.dae နှင့် Google Earth .kmz: [Collada သို့မဟုတ် Google Earth အတွက် export လုပ်ခြင်း](topic:collada))၊ {{ui:အရောင်ဖော်ရန်အတွက်}} .glb၊ render ပုံများ၊ sheet နှင့် ပလန်များကို PDF အဖြစ်၊ ဇယားနှင့် စာရင်းများကို CSV အဖြစ်၊ BCF issue များ၊ COBie spreadsheet၊ family ဖိုင်များနှင့် မှတ်ပုံတင်ထားသော scan များကို LAS သို့မဟုတ် E57 အဖြစ်။ BimCraft သည် DWG၊ DXF သို့မဟုတ် ပရောဂျက်ဖိုင်များကို မသိမ်းပါ၊ ဖွင့်ထားသော ဖိုင်များကိုလည်း ဘယ်တော့မျှ မပြောင်းပါ။

## ဒုတိယအကြိမ် သိမ်းခြင်း

သိမ်းတိုင်း မော်ဒယ်တစ်ခုလုံးကို **ဖွင့်ကတည်းက လုပ်ထားသော တည်းဖြတ်မှုအားလုံး** နှင့်အတူ ဒေါင်းလုဒ်လုပ်သည်၊ နောက်ဆုံးသိမ်းပြီးနောက် လုပ်ထားသော တည်းဖြတ်မှုများသာ မဟုတ်ပါ။ {{ui:ပြောင်းလဲမှုများ}} စာရင်းသည် သိမ်းတိုင်း ပြန်လည် ဗလာဖြစ်သွားသောကြောင့် သိမ်းပြီးနောက် ပြန်ဖျက်၍ မရပါ။ မူလမှ ပြန်စရန် မူလဖိုင်ကို ထပ်မံ ဖွင့်ပါ။

## ဖိုင်ကြီးများနှင့် memory

- **IFC** ဖိုင်များကို tab ၏ memory ထဲသို့ အပြည့်အစုံ ဖတ်သည်၊ 3D geometry က memory ပိုသုံးသည်။ ရာချီ မီဂါဘိုက် အရွယ်ရှိသော မော်ဒယ်သည် laptop အတွက် များလွန်းနိုင်သည်။ Triangle 1.5 သန်းကျော်သောအခါ memory သက်သာစေရန် edges ကို ပိတ်သည် ("Edges are off for very large models")။
- **ပရောဂျက်ဖိုင်** များကို အပြည့်အစုံ မဖတ်ပါ။ BimCraft သည် လိုအပ်သော အသေးစား အပိုင်းများကိုသာ ဖတ်သည်၊ ဖိုင်ကြီးသည်ဖြစ်စေ 40 KB မှ 100 KB ခန့်သာ ဖြစ်ပြီး network drive ပေါ်ရှိ 500 MB central model သည် ခဏအတွင်း ဖွင့်သည်။
- **DWG နှင့် DXF** ဖိုင်များကို အပြည့်အစုံ ဖတ်သည်။ အလွန်ကြီးသော ပုံဆွဲသည် "This drawing is very large; only part of it is shown." ဟု ပြသသည်။
- **ဖိုဒါများ** ဖိုင် 20,000 အထိ ဖွင့်နိုင်သည်။ မော်ဒယ်ကတ်တစ်ခုစီ လိုအပ်သော kilobyte အနည်းငယ်သာ ဖတ်သည်။

နောက်ထပ်အချက်အလက်အတွက် [ဘရောက်ဆာများ၊ စက်ပစ္စည်းများနှင့် memory](topic:platforms) ကို ကြည့်ပါ။

## အွန်လိုင်းနှင့် အော့ဖ်လိုင်း

ဖိုင်ဖွင့်ရာတွင် အင်တာနက် မလိုအပ်ပါ။ ဖတ်ရှုကိရိယာတစ်ခုသာ လိုအပ်သည့်အခါ ပထမဆုံးအကြိမ် ဆိုက်မှ တင်သည်- IFC engine ကို IFC မော်ဒယ် ပထမဆုံး ဖွင့်သည့်အခါ ("Starting the IFC engine…")။ DWG နှင့် DXF ဖတ်ရှုကိရိယာများသည် အက်ပ်၏ အစိတ်အပိုင်း ဖြစ်သည်။

:::offline
သင် အော့ဖ်လိုင်းဖြစ်နေသည်။ app bar ၏ ခလုတ်က {{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ဟု ပြပါက ဖော်မတ်အားလုံး ပုံမှန်အတိုင်း ဖွင့်သည်။ မဟုတ်ပါက၊ ဤ tab တွင် ဖွင့်ပြီးသား IFC မော်ဒယ် မရှိလျှင် IFC မော်ဒယ်များ မဖွင့်နိုင်ပါ- ပထမဆုံး ပြန်ချိတ်ဆက်ပါ။ [အွန်လိုင်းနှင့် အော့ဖ်လိုင်း](topic:online-offline) ကို ကြည့်ပါ။
:::

အင်တာနက်မရှိဘဲ BimCraft ကို သုံးလိုပါက အွန်လိုင်းရှိစဉ် app bar ရှိ {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ကို နှိပ်ပြီး {{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ကို စောင့်ပါ။ သိမ်းထားသော မိတ္တူသည် 33 MB ခန့်ရှိပြီး IFC engine ပါဝင်သောကြောင့် IFC မော်ဒယ်များကိုလည်း အော့ဖ်လိုင်းတွင် ဖွင့်နိုင်သည်။ [အော့ဖ်လိုင်း လုပ်ဆောင်ခြင်း](common:offline) တွင် သိမ်းထားသော မိတ္တူများကို အထွေထွေ ရှင်းပြသည်။

## Cloud သိမ်းခြင်း

Cloud သိမ်းခြင်း မရရှိသေးပါ။ ပြင်ဆင်ထားသော မိတ္တူများကို သင့်ကွန်ပျူတာ သို့မဟုတ် ရုံး၏ ဖိုင်ဆာဗာတွင် ဖိုင်အခြားတစ်ခုကဲ့သို့ သိမ်းပါ။ [သင့်ဖိုင်များ](common:your-files) ကို ကြည့်ပါ။
