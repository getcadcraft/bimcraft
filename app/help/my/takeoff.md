## သင်လုပ်မည့်အရာ

မော်ဒယ်ကို TakeoffCraft ရှိ ပစ္စည်းစာရင်းနှင့် ခန့်မှန်းတန်ဖိုး အဖြစ် ပြောင်းပါ။ BimCraft သည် အထပ်တစ်ခုစီ၏ plan ကို စံ scale ဖြင့် ဆွဲပြီး ပမာဏတိုင်းကို ၎င်းပေါ်တွင် မှတ်သည်။ ထို့နောက် takeoff ကို PDF ထဲတွင် ထည့်သည်။ TakeoffCraft သည် မှတ်ချက်များကို ကိုယ်တိုင် တိုင်းသဖြင့် ဂဏန်းတိုင်းကို စာရွက်ပေါ်တွင် စစ်ဆေးနိုင်သည်။

## ပို့ရန်

1. မော်ဒယ်ဘား (စာရွက်များ၏ ဘေးတွင်) ရှိ {{ui:ပမာဏထုတ်ယူခြင်း}} ကို နှိပ်ပါ။
2. TakeoffCraft သည် plan များနှင့်အတူ tab အသစ်တစ်ခုတွင် ဖွင့်သည်။ မေးလျှင် PDF ထဲတွင် တွေ့သော takeoff ကို ဖွင့်ရန် ရွေးပါ။
3. TakeoffCraft ၏ quantities table တွင် သင့်စျေးနှုန်းများ ထည့်ပါ။ assembly များက ပစ္စည်းများကို ရှိပြီးသား ဖော်ပြထားသည်။

:::note
ဤနေရာတွင် TakeoffCraft မရရှိနိုင်လျှင် ခလုတ်က PDF ကို အစားထိုး ဒေါင်းလုဒ်လုပ်သည်။ နောက်မှ TakeoffCraft တွင် ဖွင့်ပါ။ ၎င်းက takeoff ကို ရှာတွေ့မည်။
:::

## ဘာတိုင်းသလဲ

- **နံရံများ** အမျိုးအစားနှင့် အမြင့်အလိုက်။ ၎င်းတို့၏ ဗဟိုမျဉ်းများကို run များအဖြစ် ယူပြီး item ပေါ်တွင် နံရံအမြင့် ပါဝင်သဖြင့် TakeoffCraft က အလျားနှင့် နံရံဧရိယာကို ပေးသည်။ run တစ်ခုစီတွင် နံရံ၏ တံခါးနှင့် ပြတင်းပေါက်များ ပါဝင်သည်။ ထို့ကြောင့် TakeoffCraft က BimCraft ၏ ဇယားများနည်းတူ စည်းမျဉ်းဖြင့် ၎င်းတို့ကို နံရံဧရိယာမှ တစ်ကြိမ်နှုတ်သည်။ နှစ်ခုက gross၊ နှုတ်ချက်များနှင့် net တွင် သဘောတူသည်။ နံရံအမျိုးအစား၏ takeoff ဒေတာ (ယူနစ်၊ ပြာ၊ နှုန်း၊ [နံရံ assembly](topic:wall-assemblies) ကို ကြည့်ပါ) သည် ထိုအမျိုးအစား item ပေါ်တွင် စျေးနှုန်းတပ်သော လိုင်းတစ်ခုအဖြစ် လာသည်။ မူလနည်းလမ်းမဟုတ်သော တိုင်းတာနည်း ([တိုင်းတာနည်း ရွေးခြင်း](topic:plan-schedules-and-pdf#choose-a-measurement-method) ကို ကြည့်ပါ) အောက်တွင် takeoff က နည်းလမ်းကို ပါစေသည်။ run တစ်ခုစီက junction များက နံရံမျက်နှာမှ နုတ်သည့်အရာကို ပါစေသည်။ TakeoffCraft က ထိုနည်းဖြင့် တိုင်းပြီး အမည်ပေးသည်။ ယူနစ်တွင် အလျားနှင့် အမြင့်ရှိသော အမျိုးအစားများသည် ပမာဏပါသော အစိတ်အပိုင်းနှစ်ခု ပေးသည်။ မှာရန် ယူနစ်များနှင့် ပြာ ထုထည်။ အမျိုးအစား၏ နှုန်းသည် ယူနစ်တစ်ခုလျှင်၊ ယူနစ် 1000 လျှင် သို့မဟုတ် ပြာ m³ လျှင် ဖြစ်သည့်အခါ စျေးနှုန်းတပ်သည်။ အရေအတွက်တစ်ခုသည် ကိန်းပြည့်အတိအကျ ဖြစ်သည့်အခါ TakeoffCraft တွင် ယူနစ်တစ်ခု ပိုနိုင်သည်။ အကြောင်းမှာ လွှဲပြောင်းမှုက စာရွက်ပေါ်ရှိ နေရာများကို ပတ်ပြီး ပြုလုပ်သည်။
- **ခေါင်မိုးများ** ခေါင်မိုးအလွှာတစ်ခုစီကို ၎င်း၏ စောက်ချိုင်းနှင့်အတူ ဧရိယာအဖြစ် (TakeoffCraft က စောက်ချိုင်းဧရိယာ ပေးသည်)၊ ridge၊ hip နှင့် valley များ (hip နှင့် valley များကို ၎င်းတို့၏ စောက်ချိုင်းတလျှောက်)၊ eave နှင့် rake။
- **အုတ်မြစ်များ** footing နှင့် stem wall များကို ၎င်းတို့၏ အလယ်ဗဟိုအဖြစ် run များအဖြစ်၊ slab များကို ၎င်းတို့၏ အထူဖြင့် ဧရိယာများအဖြစ်၊ ထို့ကြောင့် ကွန်ကရစ်ကို ထုထည်အလိုက် ရရှိသည်။
- **တံခါးနှင့် ပြတင်းပေါက်များ** အမျိုးအစားအလိုက် ရေတွက်ထားသည်။ ပြတင်းပေါက် trim ပါဝင်သည်။
- **အောက်ခြေ cabinet များ** ၎င်းတို့၏ ရှေ့မျက်နှာ အလျားအလိုက်။
- **လျှပ်စစ် device များ** အမျိုးအလိုက် ရေတွက်ထားသည်။
- **အထပ်တစ်ခု၏ ကြမ်းပြင်ဧရိယာ** ၎င်း၏ အခန်းများမှ။
- **သစ်ထုတ် ဖြတ်စာရင်း** framing မှ၊ ကိုယ်ပိုင် စာရွက်တစ်ခုပေါ်တွင် ရေတွက်သည် (ပစ္စည်းတစ်ခုစီအတွက် အစက်တစ်ခု)။

trade pack တစ်ခုတွင် ကိုက်ညီသော assembly ရှိသည့်နေရာ (အပြင်နှင့် အတွင်းနံရံများ၊ slab များ၊ အုတ်မြစ်များ၊ stem wall များ၊ shingle များ၊ ridge နှင့် hip cap၊ valley များ၊ eave များ၊ အတွင်းတံခါးများ၊ ပြတင်းပေါက် trim၊ အောက်ခြေ cabinet များ၊ outlet များ၊ switch များ၊ မီးများ၊ junction box များနှင့် panel) item သည် ၎င်း၏ ပစ္စည်းများနှင့် ပုံသေနည်းများ ပါလာသည်။ pack များတွင် စျေးနှုန်း မပါဝင်ပြီး ခန့်မှန်းသူက မသုံးသပ်ရသေးပါ။

:::tip
plan များကို နှိပ်တိုင်း မော်ဒယ်မှ ပြန်ဆောက်သည်။ ပြောင်းလဲမှုတစ်ခုပြီးလျှင် {{ui:ပမာဏထုတ်ယူခြင်း}} ကို ထပ်နှိပ်ပါ။
:::
