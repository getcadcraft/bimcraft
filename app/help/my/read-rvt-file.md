## လုပ်ဆောင်မည့်အရာ

Revit တွင် မဖွင့်ဘဲ project သို့မဟုတ် family ဖိုင်တစ်ခုတွင် ဘာပါသည်ကို ရှာပါ: ဘယ် release က သိမ်းခဲ့သည်၊ workshared ဟုတ်မဟုတ်၊ ပရောဂျက် အချက်အလက်နှင့် ၎င်း ချိတ်ဆက်ထားသော အရာများ။ အခြားသူထံမှ ဖိုင်ရောက်လာပြီး မည်သည့် release တွင် ဖွင့်ရမည်ကို သိလိုသောအခါ အသုံးဝင်သည်။

## အဆင့်များ

1. {{ui:Choose a file}} ကို နှိပ်ပါ။
2. `.rvt`၊ `.rfa`၊ `.rte` သို့မဟုတ် `.rft` ဖိုင်ကို ရွေးပါ။
3. ခဏစောင့်ပါ။ Status line က "Reading the file…" ဟု ပြပြီးနောက် "Opened *file name*" ဟု ပြသည်။
4. Card ၏ထိပ်ကို ကြည့်ပါ: ဖိုင်တွင် သိမ်းထားသော preview ပုံ၊ ဖိုင်အမျိုးအစားနှင့် သိမ်းခဲ့သော release၊ နှင့် ပရောဂျက်အမည်။
5. Card ၏ အပိုင်းများကို ဆင်းဖတ်ပါ။

## သင်မြင်ရမည်များ

အလယ်ရှိ card တွင် ဖိုင်တွင် ရှိသည့်အခါ အောက်ပါအပိုင်းများ ပါဝင်သည်:

| အပိုင်း | ပြောပြသည့်အရာ |
|---|---|
| ဖိုင် | ဖိုင်အမည်၊ အရွယ်အစား၊ အမျိုးအစား (project, project template, family သို့မဟုတ် family template)၊ သိမ်းခဲ့သော release နှင့် build၊ worksharing၊ central model ၏ path၊ နောက်ဆုံး သိမ်းခဲ့သော နေရာ၊ သိမ်းသူ၊ locale နှင့် document GUID |
| ပရောဂျက် အချက်အလက် | ပရောဂျက်၏ ကိုယ်ပိုင် field များ၊ ဥပမာ အမည်၊ နံပါတ်၊ client၊ လိပ်စာနှင့် status။ ပရောဂျက်အသစ်၏ မူရင်း တန်ဖိုးတွင် ကျန်ခဲ့သော field များကို ထားခဲ့သည်။ |
| Family၊ Family: … | Family အတွက်: ၎င်း၏ အမည်၊ category၊ release၊ နောက်ဆုံး update နှင့် parameter များ၊ group တစ်ခုချင်းစီအလိုက် |
| ချိတ်ဆက်ထားသော နှင့် ရည်ညွှန်းထားသော ဖိုင်များ | ဖိုင်က ညွှန်ပြသော link မော်ဒယ်၊ CAD link၊ ပုံနှင့် keynote table အားလုံး၊ သိမ်းထားသော path နှင့်အတူ |

ဘယ်ဘက်ရှိ {{ui:File}} panel သည် အဓိက အချက်အလက်များကို ထပ်ပြပြီး **ဖတ်ထားမှု** ကို ထည့်သည်: BimCraft က ဖိုင်မှ တကယ် ဖတ်ခဲ့သော ပမာဏ၊ များသောအားဖြင့် မဂ်ဂါဘိုက်များစွာရှိသော ဖိုင်မှ 40 KB ခန့်။ ညာဘက်ရှိ {{ui:Properties}} panel က element property များ 3D မော်ဒယ် လိုအပ်သည်ဟု ပြောသည်။

## 3D မရှိသည့် အကြောင်းရင်း

3D မော်ဒယ်နှင့် project ဖိုင်ထဲရှိ element များကို မှတ်တမ်းမတင်ထားသော format ဖြင့် သိမ်းထားသည်။ BimCraft သည် မှတ်တမ်းတင်ထားသော သို့မဟုတ် ရိုးရှင်းစွာ ဖတ်နိုင်သော အပိုင်းများကိုသာ ဖတ်သည်: ဖိုင်အချက်အလက်၊ ပရောဂျက် အချက်အလက်၊ family data၊ link စာရင်းနှင့် preview ပုံ။ ကျန်တာကို ခန့်မှန်းခြင်း မလုပ်ပါ။ 3D မော်ဒယ်နှင့် element property များ ကြည့်ရန် ဖိုင်ကို ထုတ်လုပ်ခဲ့သော program မှ IFC ထုတ်ပါ။ [IFC ဖြင့် project ဖိုင်ကို 3D သို့ ရယူခြင်း](topic:rvt-to-ifc) ကို ကြည့်ပါ။

## အမှားများ

- **3D ရမည်ဟု မျှော်လင့်ခြင်း။** အထက်ကို ကြည့်ပါ။
- **Link များက သိမ်းထားသော path သာ ပြသည်။** ဖိုင်ကို တစ်ကိုယ်တည်း ဖွင့်လျှင် link များ ရှိမရှိ စစ်၍ မရပါ။ ၎င်း နေထိုင်သော ဖိုလ်ဒါကို ဖွင့်ပါ၊ ထိုအခါ BimCraft က link တစ်ခုစီကို တွေ့သည် သို့မဟုတ် မတွေ့ဟု အမှတ်အသားပြုသည်: [project ဖိုလ်ဒါတစ်ခုလုံး ဖွင့်ခြင်း](topic:open-project-folder)။
- **"This file is incomplete…"** ဖိုင်ကို ကူးယူခြင်း၊ upload လုပ်ခြင်း သို့မဟုတ် sync လုပ်စဉ် ဖြတ်တောက်ခံရသည်။ "online only" ဖြစ်နေသော cloud-drive ဖိုင်လည်း ဤအတိုင်း ဖြစ်နိုင်သည်။ BimCraft သည် ထိုဖိုင်ကို ဆက်ဖွင့်ပြီး ပြန်ရရှိသော အပိုင်းများကိုသာ ပြသည်: card ထိပ်တွင် အ၀ါရောင် အသိပေးချက်၊ ဖိုင်ထဲတွင် ပြည့်စုံစွာ ရှိသော အစိတ်အပိုင်းများကို စာရင်းပြုသည့် **ဤဖိုင်မှ ပြန်ရရှိထားသည်** အပိုင်း၊ နှင့် ကျန်သော အရာများအတွက် **ဖိုင်တွင် မရှိ** အပိုင်း။ ပျောက်နေသော အပိုင်းအတွက် ဘာမျှ မဖြည့်ပါ၊ ထို့ကြောင့် ဖြတ်ထားသော နောက်ပိုင်းတွင် သိမ်းထားသော release၊ preview ပုံ သို့မဟုတ် ပရောဂျက် အချက်အလက် ပျောက်နိုင်သည်။ ဖိုင်၏ အကြောင်းအရာစာရင်းပင် ဖြတ်ခံရလျှင် ဘာမျှ ဖွင့်၍ မရပါ။ မူရင်းကို ထပ်ကူးပြီး ပြည့်စုံသော ဖိုင်အဖြစ် ပြန်ဖွင့်ပါ။
- **"No preview picture in this file".** အချို့ဖိုင်များကို preview မပါဘဲ သိမ်းထားသည်။ ၎င်းသည် ပုံမှန် ဖြစ်သည်။
- **Backup ကို အမှားဖွင့်ခြင်း။** `Tower.0004.rvt` ကဲ့သို့ အမည်ရှိ ဖိုင်များသည် နံပါတ်တပ်ထားသော backup များ ဖြစ်သည်။ ဖိုလ်ဒါကို ဖွင့်လျှင် ၎င်းတို့ကို မော်ဒယ်နှင့် အုပ်စုဖွဲ့သည်။
