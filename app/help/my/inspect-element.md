## သင်လုပ်မည့်အရာ

IFC မော်ဒယ်ထဲရှိ ဒြပ်စိတ်များကို ရွေးပြီး ဖိုင်က ၎င်းတို့အကြောင်း ပြောသမျှကို ဖတ်ပါ: attributes၊ property sets၊ type properties နှင့် ပမာဏများ။

## အဆင့်များ

1. IFC မော်ဒယ်တစ်ခု ဖွင့်ပါ။
2. ဒြပ်စိတ်တစ်ခုကို နှိပ်ပါ၊ ဥပမာ တံခါး။ ဆွဲမလှုပ်ဘဲ နှိပ်ပါ: ပစ်ဇယ်အနည်းငယ်ထက် ပိုဆွဲလျှင် ရွေးမည့်အစား လည်ပတ်သည်။
3. ဒြပ်စိတ်ကို ကြည့်ပါ: အပြာရောင်ဖြင့် မီးမောင်းထိုးထားသည်။
4. ညာဘက်ရှိ {{ui:Properties}} ပြားကို ကြည့်ပါ။ အပေါ်ဆုံးတွင် ဒြပ်စိတ်၏ အမျိုးအစား (ဥပမာ "Door" သို့မဟုတ် "WallStandardCase") နှင့် ၎င်း၏ အမည် ရှိသည်။
5. ပထမ ပိတ်ကွက်ကို ဖတ်ပါ: **Name**၊ **Type**၊ **Object type**၊ **Tag**၊ **Description**၊ **GlobalId** နှင့် **Line**။
6. property sets အထိ အောက်ဆင်းပါ။ ပထမ သုံးခုကို ဖွင့်ထားသည်; အခြားတစ်ခုကို ဖွင့်ရန် ၎င်း၏ အမည်ကို နှိပ်ပါ။
7. အခြားဒြပ်စိတ်ကို နှိပ်၍ ၎င်းသို့ ပြောင်းပါ။
8. {{key:Esc}} ကို နှိပ်ပါ၊ သို့မဟုတ် နောက်ခံ အလွတ်နေရာကို နှိပ်ပါ၊ ရွေးချယ်မှု ဖယ်ရန်။

## မြင်ရမည့်အရာများ

- မီးမောင်းထိုးထားသော ဒြပ်စိတ်နှင့် ညာဘက်ရှိ ၎င်း၏ ဒေတာ။
- Property sets များကို အက္ခရာအစဉ်လိုက် စီထားသည်။ ဒြပ်စိတ်၏ **type** မှ လာသော sets များ၏ အမည်နောက်တွင် " (type)" ပါဝင်ပြီး မှတ်ချက် "Type property: ဤနေရာတွင် ပြောင်းလဲမှုသည် ဤအမျိုးအစား၏ ဒြပ်စိတ်အားလုံးကို သက်ရောက်သည်။" ပါသည်။
- Quantity sets (ဥပမာ အရှည်၊ ဧရိယာနှင့် ထုထည်များ) ကို အခြား sets များနှင့်အတူ ပြသည်။ ပမာဏများကို ဖတ်ရုံသာ ဖတ်နိုင်သည်။
- ပြောင်းလဲနိုင်သော တန်ဖိုးများသည် ခလုတ်များနှင့် တူသည်။ [IFC ဂုဏ်သတ္တိများ ပြောင်းပြီး တည်းဖြတ်ထားသော မိတ္တူ သိမ်းရန်](topic:edit-ifc-properties) က နည်းလမ်းကို ပြသည်။

[ဂုဏ်သတ္တိများ ပြား အကွက်များ](topic:properties-panel) တွင် အကွက်တိုင်းကို ရှင်းပြသည်။

## ဖျောက်ထားသော ဒြပ်စိတ်များသို့ ရောက်ရန်

1. အဆောက်အအုံအတွင်းရှိ တစ်ခုခုသို့ ရောက်ရန်၊ {{ui:Storeys}} စာရင်းတွင် ၎င်းအထက်ရှိ အထပ်များကို အမှန်ဖြုတ်ပါ။
2. ခန်းမ volume နောက်ရှိ နံရံသို့ ရောက်ရန်၊ {{ui:Spaces}} ကို ပိတ်ပါ။
3. ဒြပ်စိတ်ကို နှိပ်ပါ။

## အများဆုံး အမှားများ

- **နှိပ်နေစဉ် အနည်းငယ် ဆွဲမိခြင်း။** BimCraft က ထိုသို့ orbit အဖြစ် သတ်မှတ်ပြီး ရွေးမည်မဟုတ်ပါ။ မောက်စ်ကို ငြိမ်ငြိမ်ထားပါ။
- **ကိန်းဂဏန်းများ နောက်တွင် ယူနစ်ကို မျှော်လင့်ခြင်း။** တန်ဖိုးများကို ဖိုင်ထဲ သိမ်းထားသည့်အတိုင်း၊ ဒဿမ လေးနေရာအထိ ပြတ်ပြီး ယူနစ်သင်္ကေတ မပါဘဲ ပြသည်။ မက်ထရစ် တင်ပို့မှုတွင် အရှည်များသည် များသောအားဖြင့် မီလီမီတာ သို့မဟုတ် မီတာဖြစ်သည်; တင်ပို့သူ၏ ဆက်တင်များကို စစ်ပါ။
- **ရင်းနှီးသော အမည်ဖြင့် ပါရာမီတာ ရှာခြင်း။** တင်ပို့သူများက ပါရာမီတာများကို အမည်ပြောင်း၍ `Pset_WallCommon` ကဲ့သို့ IFC property sets များအဖြစ် စုစည်းကြသည်။ set တစ်ခုစီကို ကြည့်ပါ; စိတ်ကြိုက် ပါရာမီတာများသည် တင်ပို့သော ပရိုဂရမ် သို့မဟုတ် သင့်ကုမ္ပဏီအမည်ဖြင့် set တွင် မကြာခဏ ရှိသည်။
- **ရှာဖွေရေး အကွက် မျှော်လင့်ခြင်း။** ဒြပ်စိတ်ကို ရွေးရန် နှိပ်ပါ; {{key:Mod}}+နှိပ်ခြင်း သို့မဟုတ် {{key:Shift}}+နှိပ်ခြင်းဖြင့် ပိုရွေးနိုင်ပြီး {{key:Mod+A}} က ပြထားသော ဒြပ်စိတ်အားလုံး ရွေးသည်။ ဘယ်ဘက်ရှိ {{ui:Elements}} စာရင်းက အမျိုးအစားအလိုက် ရေတွက်သည်သာ; နှိပ်၍ မရပါ။
- **ပရောဂျက်ဖိုင် ကတ်ပေါ်တွင် ရွေးခြင်း။** ဖိုင်ကတ်တွင် ရွေးစရာ ဒြပ်စိတ်မရှိပါ: "ဒြပ်စိတ် ဂုဏ်သတ္တိများ 3D မော်ဒယ် လိုအပ်သည်။ ၎င်းတို့ကို ကြည့်ရန် ဤဖိုင်၏ IFC တင်ပို့မှုကို ဖွင့်ပါ။"
