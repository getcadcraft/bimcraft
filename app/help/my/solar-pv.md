## လုပ်ဆောင်မည့်အရာ

**Solar PV** pane ကို ဖွင့်ပါ။ ခေါင်မိုးမျက်နှာတစ်ခုကို ရွေးပါ (ထောင်စောက်နှင့် မျက်နှာမူပုံကို မော်ဒယ်မှ ဖတ်သည်) သို့မဟုတ် ထောင်စောက်နှင့် မျက်နှာမူပုံဖြင့် မြေပြင်အခင်းကို ချပါ; module များကို setback များဖြင့် အတွင်းတွင် ထည့်ပြီး ရေတွက်ကာ DC ပါဝါကို kWp ဖြင့် ပေးသည်။ အခင်းကို ထားလျှင် မော်ဒယ်ထဲသို့ solar device အဖြစ် တစ်ဆင့်တည်း undo ဖြင့် ရေးသည်။

## အရိပ်၊ ထုတ်လုပ်မှုနှင့် string များ

- **အရိပ်** က module တစ်ခုစီမှ ရာသီလတိုင်း ပုံမှန်နေ့များအတွက် နေဘက်သို့ ရောင်ခြည်ပေါက်တစ်ခု ထုတ်ပြီး မော်ဒယ်၏ ကိုယ်ပိုင်ဂျီသြမေတြီကို ဆန့်ကျင်၍ စစ်သည်၊ ထို့ကြောင့် အိမ်နီးချင်း အဆောက်အအုံများ၊ parapet နှင့် ရှေ့ရှိ တန်းများ ရေတွက်သည်။ တိုက်ရိုက်နေရောင်ခြည်သာ လျော့သည်၊ တစ်စိတ်တစ်ပိုင်း အရိပ်ကျသော အခင်းသည် အချိုးအစားအလိုက် ပါဝါဆုံးရှုံးသည်။
- **ထုတ်လုပ်မှု** က လနှင့် နှစ်အလိုက် kWh၊ kWp တစ်ခုလျှင် kWh နှင့် performance ratio ပေးသည်။ နေရောင်ခြည်သည် သင်ရိုက်ထည့်ပါက သင်၏ကိုယ်ပိုင် လစဉ်စုစုပေါင်းများ ဒေါင်မဟုတ်သော မျက်နှာပြင်ပေါ်မှ ဖြစ်သည်။ မရှိလျှင် pane သည် clear-sky အထက်ကန့်သတ်ချက်ကို သုံးပြီး ထိုအကြောင်း ပြောသည်။ Yield tab ရှိ ခလုတ်ဖြင့် **NASA POWER မှ ရာသီဥတု ရယူရန်**: ၎င်းသည် ဆိုက်၏ latitude နှင့် longitude ကိုသာ တစ်ကြိမ် ပို့ပြီး အဖြေကို ဤကွန်ပျူတာတွင် ထားသည် (browser မှ 2026-10-30 တွင် စစ်ဆေးသည်)။ PVGIS က web page က အဖြေကို ဖတ်ခွင့်မပေးသောကြောင့် tab က ဆိုက်အတွက် PVGIS ၏ လစဉ်ဒေတာကို အသစ် tab တွင် ဖွင့်သော လင့်ခ်ကို ပေးသည်; ၎င်းပြသသည့်အရာကို ဘောက်စ်ထဲ ကူးထည့်လျှင် လ ၁၂ လုံး ဖြည့်ပေးသည်။
- **String** က module များကို string တစ်ခုချင်းစီအတွက် အေးဆုံးနှင့် ပူဆုံးနေ့တွင် အင်ဗာတာ၏ voltage window နှင့် စစ်ပြီး ဆက်တန်း string များကို current နှင့် စစ်သည်။
- **One-line** က ဒိုင်ယာဂရမ် ဒေတာ (အခင်း၊ combiner၊ disconnect၊ inverter၊ panel၊ utility) ကို ဆွဲသည်၊ သင်ရိုက်ထည့်သော factor များမှ ဝါယာနှင့် ဖျူးစ် အရွယ်အစားများဖြင့်။ ၎င်းသည် ဒေတာနှင့် SVG ဖြစ်ပြီး CadCraft ရှိ လျှပ်စစ် ထပ်ဆောင်းက ၎င်းကို သင်္ကေတများအဖြစ် ထားနိုင်သည်။

BimCraft နှင့်အတူ ပါလာသော module၊ inverter၊ ဆုံးရှုံးမှုနှင့် ဝါယာ factor များသည် ယေဘုယျ နမူနာများ ဖြစ်ပြီး ရလဒ်တိုင်းတွင် အညွှန်းပြသည်။ ထုတ်လုပ်သူ၏ ဒေတာနှင့် သင်ဒီဇိုင်းဆွဲသော code တန်ဖိုးများကို ရိုက်ထည့်ပြီး ဒီဇိုင်းကို ၎င်းအတွက် တာဝန်ရှိသူက ပြန်လည် စစ်ဆေးစေပါ။
