## ဘာလုပ်ရမလဲ

tool တစ်ခု၏ shortcut ကို ညွှန်ပြခြင်းဖြင့် သင်ယူပါ၊ plan ပေါ်ရှိ အရာတစ်ခုကို မရွေးဘဲ ဘာဖြစ်သလဲ ဖတ်ပါ။

## အဆင့်များ

1. tool တစ်ခုကို ညွှန်ပြပါ၊ ဥပမာ Draw ဘားရှိ {{ui:Wall}}။ ချက်ချင်းနီးပါး tooltip က ၎င်း၏ အမည်နှင့် shortcut (**Wall**၊ **W**) ကို ပြသည်။
2. pointer ကို ထိုနေရာတွင် ဆက်ထားပါ။ ခဏအကြာတွင် အောက်ရှိ စာကြောင်းတစ်ကြောင်းက tool ဘာလုပ်သည်ကို ပြောသည်။
3. {{ui:Select}} tool ဖွင့်ထားပြီး plan ကို ဖွင့်ပါ။ နံရံတစ်ခုပေါ်တွင် pointer ထားပါ။ pointer ဘေးရှိ tooltip က ၎င်း၏ အမျိုးအစား၊ level၊ အရှည်နှင့် အထူ၊ နှင့် straight သို့မဟုတ် skew ဖြစ်မဖြစ် ပြသည်။
4. တံခါး၊ ပြတင်းပေါက်၊ အခန်း သို့မဟုတ် အတိုင်းအတာသို့ ရွှေ့ပြီး ထိုတစ်ခုကို ဖတ်ပါ။ ဘာမျှ ရွေးထားခြင်း မရှိပါ။

## tool ၏ tooltip ပြသသည်များ

- **Stage 1**: command ၏ အမည်ကို သင်သုံးသော menu ပုံစံဖြင့်၊ နှင့် ထိုပုံစံ၏ key များ။ command line ကို မျက်နှာပြင်တွင် ဖွင့်ထားလျှင် key မရှိသော command အတွက် ရိုက်ရမည့် စကားလုံးကိုလည်း ပြသည်။
- **Stage 2**: ဖော်ပြချက် တစ်ကြောင်း။ ၎င်းသည် command ၏ ကိုယ်ပိုင် ခလုတ်၏ စာသားဖြစ်သဖြင့် command ပေါ်ရှိနေရာတိုင်း (Draw ဘား၊ ribbon၊ menu ပုံစံ၊ layout ရှိ tool အတန်းများ) တွင် တူညီစွာ ပြောသည်။
- ပိတ်ထားသော tool သည် ဘာကြောင့်ဖြစ်သည်ကို အစား ပြသည်။

## rollover ပြသသည်များ

- **နံရံ**: အမျိုးအစား၊ level၊ အရှည်နှင့် အထူ၊ နှင့် **Straight**၊ **Skew** (ထောင့်ပါ) သို့မဟုတ် **Curved**။ Straight ဆိုသည်မှာ ချိတ်ဆက်ထားသော နံရံများ၏ အဓိက ဦးတည်ချက်နှင့် ထောင့်မှန်ခြင်း ဖြစ်သည်: စာမျက်နှာပေါ်တွင် လှည့်ထားသော အဆောက်အအုံသည်လည်း straight ဖြစ်သည်။ နံရံတစ်ခုတည်းသည် straight ဖြစ်သည်။
- **တံခါး သို့မဟုတ် ပြတင်းပေါက်**: အမျိုးအစား၊ level၊ အကျယ်နှင့် အမြင့်၊ ပြတင်းပေါက်၏ sill အမြင့်၊ နှင့် ၎င်းရှိသော နံရံ။
- **အခန်း**: အမည်နှင့် နံပါတ်၊ level၊ နှင့် plan က ညွှန်းသော ဧရိယာ။
- **အတိုင်းအတာ**: ၎င်း၏ အရှည်၊ နံရံတစ်ခုလုံး သို့မဟုတ် ပွင့်ပေါက်များကြား အပိုင်းလား၊ မည်သည့်မျက်နှာမှ တိုင်းသလဲ၊ နှင့် ၎င်းပိုင်သော နံရံ။

## သိထားရန် အချက်များ

- Rollover သည် Select tool ဖြင့် အလုပ်လုပ်သည်။ Draw tool တစ်ခု run နေစဉ် tool က ၎င်း၏ကိုယ်ပိုင် အမှတ်အသားကို ပြသည်။
- အရာမှ ရွေ့သွားလျှင်၊ မောက်စ်ခလုတ် နှိပ်လျှင်၊ ဘီးလ် လှည့်လျှင် သို့မဟုတ် ခလုတ် နှိပ်လျှင် ပျောက်သွားသည်။
- Tooltip များသည် touch ပေါ်တွင် ဘယ်တော့မှ မပေါ်ပါ။
