## ဘာလုပ်ရမလဲ

မီးဖိုချောင် သို့မဟုတ် foodservice ပုံဆွဲမှ စက်ပစ္စည်းစာရင်းကို ဖတ်ပါ၊ စစ်ဆေးပါ၊ ပလန်ပေါ်တွင် item တစ်ခုစီကို ရှာပါ၊ ပြီးလျှင် spreadsheet ဖိုင်အဖြစ် ဒေါင်းလုဒ်လုပ်ပါ။

ဤသည် KCL ကဲ့သို့ မီးဖိုချောင်-ဒီဇိုင်း စာကြည့်တိုက်များ သုံးသည့် ပုံဆွဲများတွင် အလုပ်လုပ်သည်၊ tag တစ်ခုစီက ၎င်း၏ ဒေတာကို block attribute အဖြစ် သယ်ဆောင်ထားသည်: tag တွင် item နံပါတ် (`KCL-ITEM`)၊ quantity၊ category၊ manufacturer၊ model၊ လျှပ်စစ်နှင့် ရေပိုက်ဒေတာ၊ နှင့် remarks ပါဝင်သည်။ အခြား ပုံဆွဲများတွင် {{ui:Equipment}} tab မရှိပါ။

## အဆင့်များ

1. ပုံဆွဲကို ဖွင့်ပါ၊ ဖြစ်နိုင်လျှင် ၎င်း၏ ပရောဂျက်ဖိုင်တွဲမှ ဖွင့်ပါ၊ ထို့ကြောင့် ချိတ်ဆက်ထားသော ပုံဆွဲများလည်း ဝင်လာမည်။
2. ပုံဆွဲအပေါ်ရှိ {{ui:Equipment}} tab ကို နှိပ်ပါ။ ၎င်း၏ label သည် sheet များပေါ်ရှိ item အရေအတွက်ကို ပြသည်၊ ဥပမာ "Equipment (88)"။
3. ဇယားကို ဖတ်ပါ: **Item**, **Qty**, **Equipment**, **Manufacturer**, **Model**, **Electrical**, **Plumbing** နှင့် **Where**။
4. ဇယားအပေါ်ရှိ menu တွင် ဘာကို စာရင်းပြုမည်ကို ရွေးပါ: **Every sheet**၊ sheet တစ်ခု၊ **Not on any sheet** သို့မဟုတ် **Everything tagged in the drawing**။ ရွေးချယ်မှုတစ်ခုစီက ၎င်း၏ အရေအတွက်ကို ပြသည်။
5. စာရင်းကို ကျဉ်းရန် filter box ("Filter: category, maker, model…") တွင် ရိုက်ပါ၊ ဥပမာ `refrigerator` သို့မဟုတ် `208`။
6. **Where** ကော်လံရှိ item ၏ sheet အမည်ကို နှိပ်ပါ။
7. ပုံဆွဲကို ကြည့်ပါ: BimCraft သည် ထို sheet သို့ ပြောင်းပြီး item ကို zoom ဆွဲကာ ၎င်းပတ်လည် ring ဆွဲပြသည်။ Status line က "Item *n*၊ *category* ကို *sheet* တွင် ring ဖြင့် ပတ်ထားသည်။" ဟု ပြောသည်။
8. ဇယားသို့ ပြန်သွားရန် {{ui:Equipment}} ကို နှိပ်ပါ။
9. {{ui:Download CSV}} ကို နှိပ်ပါ။

## မြင်ရမည့်အရာ

- ဒေါင်းလုဒ်ဖိုင်တွဲတွင် "*drawing name* equipment.csv" ဟု အမည်ပေးထားသော ဖိုင် (sheet တစ်ခုကို စာရင်းပြုသောအခါ sheet အမည်ကို ကွင်းအတွင်း ထည့်သည်)။ Excel, Numbers, LibreOffice သို့မဟုတ် Google Sheets တွင် ဖွင့်နိုင်သည်။
- Status line: "ဒေါင်းလုဒ်ပြီး *file name* (*n* items)။"

CSV တွင် Item, Qty, Category, Manufacturer, Model, Electrical, Plumbing, Remarks, Electrical remarks, Plumbing remarks, Sheets, Placed (tag အရေအတွက်) ကော်လံများ ပါသည်။ menu နှင့် filter နောက်တွင် ဇယားက ပြသသော အတန်းများအတိအကျကို ဒေါင်းလုဒ်လုပ်သည်။

## ဇယားကို မည်သို့ တည်ဆောက်သနည်း

- ပုံဆွဲပေါ်ရှိ ဇယားမှ မဟုတ်ဘဲ **tag များကိုယ်တိုင်** မှ ဖတ်သည်။ ဇယားအပေါ်ရှိ မှတ်ချက်က ဖတ်ခဲ့သော tag အရေအတွက်ကို ပြောသည်။
- အတန်းတစ်ခုသည် item နံပါတ်တစ်ခုနှင့် ဒေတာအစုတစ်ခု ဖြစ်သည်။ ၎င်း၏ quantity သည် tag များ၏ **ပေါင်းလဒ်** ဖြစ်သည်၊ ပုံနှိပ်ဇယားက ရေတွက်သည့်နည်းအတိုင်း: တစ်နေရာတွင် "5" နှင့် အခြားနေရာတွင် "3" ဟု tag ထားသော shelving သည် 8 ဖြစ်ပြီး "5 + 3" ဟု ပြသည်။
- **Where** သည် item တစ်ခုစီကို ပြသော sheet များကို စာရင်းပြုသည်၊ sheet တစ်ခုစီ၏ viewport များ ပြသသည်မှ တွက်ချက်သည်၊ ၎င်းသည် ပရင့်ထုတ်သည်နှင့် တူသည်။ "Model only" ဆိုသည်မှာ sheet တစ်ခုမှ မပြသဟု ဆိုလိုသည်။
- **Number used twice** သည် စက်ပစ္စည်းနှစ်ခုပေါ်ရှိ item နံပါတ်တစ်ခုတည်းကို အမှတ်အသားပြုသည်။ အတန်းတွင် အဝါရောင် အမှတ်အသား ရှိသည်။
- sheet မပြသော tag များကို **Not on any sheet** အောက်တွင် သီးခြား ထားသည်။ ၎င်းတို့သည် အကြိမ်များစွာ အရင် ပလန်များ သို့မဟုတ် အခြား အလုပ်များမှ ကျန်ခဲ့ခြင်း ဖြစ်ပြီး **Every sheet** ထဲသို့ ဘယ်တော့မှ မရော။
- **Electrical** သည် tag တွင် ထားသည့်အတိုင်း amps, kW, HP, volts, phase, connection နှင့် plug ကို ပြသည်။ **Plumbing** သည် connection အရွယ်အစားများကို ပြသည်: CW ရေအေး, HW ရေနွေး, DD တိုက်ရိုက်ရေစွန့်, ID သွယ်ဝိုက်ရေစွန့်, နှင့် gas။ အခြား tag field များကို ယခု မပြသေးပါ။

## အများဆုံး အမှားများ

- **{{ui:Equipment}} tab မရှိခြင်း။** ပုံဆွဲတွင် `KCL-ITEM` tag မရှိခြင်း သို့မဟုတ် ဒေတာမပါဘဲ ဆွဲထားခြင်း ဖြစ်သည်။ ဖတ်စရာ ဘာမျှ မရှိပါ။
- **ပုံနှိပ်ဇယားနှင့် အရေအတွက် မတူခြင်း။** ပုံနှိပ်ဇယားတွင် အပို နံပါတ်များ ပါနိုင်သည် သို့မဟုတ် tag များထက် တိုသော အမည်များ သုံးနိုင်သည်။ ထားရှိထားသည်ကို tag များအတိုင်း ယုံပါ၊ ကွာခြားချက်များကို ဒီဇိုင်နာနှင့် စစ်ဆေးပါ။
- **CSV ဖွင့်သောအခါ ထူးခြားသော စာလုံးများ ပေါ်ခြင်း။** ဖိုင်သည် UTF-8 ဖြစ်သည်။ spreadsheet ၏ import command ဖြင့် ဖွင့်ပြီး program က မေးလျှင် UTF-8 ကို ရွေးပါ။
- **cell တစ်ခု အစတွင် apostrophe ပေါ်ခြင်း။** `=`, `+`, `-` သို့မဟုတ် `@` ဖြင့် စတင်သော တန်ဖိုးများသည် spreadsheet က formula အဖြစ် မ run အောင် ရှေ့တွင် `'` ထည့်ထားသည်။
- **{{key:F}} နှင့် {{key:P}} အလုပ်မလုပ်ခြင်း။** ၎င်းတို့သည် ပုံဆွဲပေါ်တွင် အလုပ်လုပ်သည်၊ ဇယားပေါ်တွင် မဟုတ်ပါ။ ပထမ sheet tab ကို ဦးစွာ နှိပ်ပါ။
