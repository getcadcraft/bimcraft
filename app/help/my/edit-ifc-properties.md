## လုပ်ဆောင်မည့်အရာ

IFC မော်ဒယ်ရှိ ဒေတာကို ပြင်ပါ: အစိတ်အပိုင်းကို အမည်ပြောင်းပါ၊ ၎င်း၏ tag ကို ပြင်ပါ၊ property တန်ဖိုးကို ပြောင်းပါ။ ထို့နောက် ပြောင်းလဲမှုများပါသော IFC ဖိုင်အသစ်ကို သိမ်းပါ။ သင်ဖွင့်ခဲ့သော ဖိုင်ကို ဘယ်တော့မှ မထိပါ။

## ပြောင်းလဲနိုင်သည်များ

| အကွက် | ပြင်နိုင်ခြင်း |
|---|---|
| အမည်၊ Object type၊ Tag၊ ဖော်ပြချက် | ရ |
| တစ်ခုတည်းသော property တန်ဖိုးများ (စာသား၊ နံပါတ်၊ Yes/No) | ရ |
| အမျိုးအစား property များ ("(type)" ဟု မှတ်ထားသော set များ) | ရ၊ ပြောင်းလဲမှုသည် ထိုအမျိုးအစား အစိတ်အပိုင်းအားလုံးတွင် သက်ရောက်ပါသည် |
| Type၊ GlobalId၊ Line | မရ |
| ပမာဏများ (အလျား၊ ဧရိယာ၊ ထုထည်၊ အရေအတွက်) | မရ |
| စာရင်းများ၊ enumeration များနှင့် အပိုင်းများစွာ တန်ဖိုးများ | မရ |
| ဂျီသြမေတြီ၊ နေရာ၊ အစိတ်အပိုင်း ထည့်ခြင်း သို့မဟုတ် ဖျက်ခြင်း | မရ |

## အဆင့်များ

1. IFC မော်ဒယ်ကို ဖွင့်ပြီး ပြင်လိုသော အစိတ်အပိုင်းကို နှိပ်ပါ။
2. {{ui:Properties}} အကန့်တွင် ပြောင်းလိုသော တန်ဖိုးကို နှိပ်ပါ။ ၎င်းသည် စာသားအကွက် ဖြစ်လာပါသည်။ ဗလာတန်ဖိုးကို *ဗလာ* ဟု ပြပါသည်။
3. တန်ဖိုးအသစ်ကို ရိုက်ထည့်ပါ။
4. ထားရန် {{key:Enter}} ကို နှိပ်ပါ၊ သို့မဟုတ် အခြားနေရာကို နှိပ်ပါ။ ပယ်ဖျက်ရန် {{key:Esc}} ကို နှိပ်ပါ။
5. တန်ဖိုးကို ကြည့်ပါ: ၎င်းသည် ယခု မည်းထူပြီး ဘေးတွင် အပြာရောင်ဘားရှိသည်၊ ၎င်းက တည်းဖြတ်ထားသော တန်ဖိုးကို မှတ်သားပါသည်။
6. ဘယ်ဘက်ရှိ {{ui:Changes}} အပိုင်းကို ကြည့်ပါ: ပြောင်းလဲမှုကို *အစိတ်အပိုင်း*: *အကွက်*၊ အဟောင်းတန်ဖိုးမှ အသစ်တန်ဖိုးသို့ ဟု စာရင်းပြုပါသည်။
7. အခြားတန်ဖိုး သို့မဟုတ် အခြားအစိတ်အပိုင်းများအတွက် ထပ်လုပ်ပါ။
8. {{ui:Save as IFC}} ကို နှိပ်ပါ (စောင့်နေသော ပြောင်းလဲမှုအရေအတွက်ကို ပြပါသည်၊ ဥပမာ "Save as IFC (3)")၊ သို့မဟုတ် {{key:Mod+S}} ကို နှိပ်ပါ။
9. သင့်ဒေါင်းလုဒ်ဖိုဒါတွင် "*မူလအမည်* (edited).ifc" ကို ရှာပါ။

## မြင်ရမည့်အရာ

အခြေအနေစာကြောင်းက "*name* (edited).ifc ကို ပြောင်းလဲမှု *n* ခုဖြင့် သိမ်းပြီးပါပြီ (… bytes)။ မူလဖိုင်ကို မပြောင်းလဲပါ။" ဟု ပြပါသည်။ {{ui:Changes}} စာရင်းသည် ဗလာဖြစ်ပြီး နောက်အကြိမ်အတွက် အဆင်သင့်ဖြစ်ပါသည်။

## တန်ဖိုးအမျိုးအစားများ

- **စာသား**: ရိုက်ထည့်သမျှကို ဘယ်လိုရှိသည့်အတိုင်း ထားပါသည်။ အမည်၊ Object type၊ Tag သို့မဟုတ် ဖော်ပြချက်ကို ရှင်းလင်းလျှင် တန်ဖိုးကို ဖယ်ပါသည်။
- **နံပါတ်များ**: `2.4` သို့မဟုတ် `1200` ကဲ့သို့ ရိုးရိုးနံပါတ်ကို ဖိုင်၏ ကိုယ်ပိုင်ယူနစ်ဖြင့် ရိုက်ထည့်ပါ။ ယူနစ်သင်္ကေတ မပါပါ။ အခြားအရာမဆို "နံပါတ်ရိုက်ပါ။" ဟု ပြပါသည်။
- **ကိန်းပြည့်များ** (အရေအတွက်၊ integers): ဒဿမရိုက်ထည့်လျှင် "ကိန်းပြည့်ရိုက်ပါ။" ဟု ပြပါသည်။
- **Yes/No**: တန်ဖိုးသည် Yes နှင့် No ပါသော မီနူးဖြစ်လာပါသည်။

တန်ဖိုးတိုင်းသည် ၎င်း၏ IFC အမျိုးအစားကို ထိန်းထားပါသည်၊ ထို့ကြောင့် နံပါတ်သည် နံပါတ်အဖြစ်ဆက်ရှိပြီး အခြားပရိုဂရမ်များက မှန်ကန်စွာ ဖတ်ပါသည်။

## ပြန်ဖျက်ခြင်း

1. {{ui:Changes}} အပိုင်းရှိ {{ui:Undo}} ကို နှိပ်ပါ၊ သို့မဟုတ် အကွက်တစ်ခုတွင် မရိုက်နေချိန် {{key:Mod+Z}} ကို နှိပ်ပါ။
2. ပိုပြန်ဖျက်ရန် ထပ်လုပ်ပါ။ ပြန်ဖျက်တိုင်း နောက်ဆုံးပြောင်းလဲမှုကို ဖယ်ပါသည်။

သိမ်းချက်ကို ကျော်၍ ပြန်ဖျက်၍ မရပါ: သိမ်းပြီးနောက် စာရင်းသည် ပြန်စပါသည်။ သိမ်းထားသော ဖိုင်က အားလုံးကို ထိန်းထားပါသည်။

## သင်၏ တည်းဖြတ်မှုသည် အစိတ်အပိုင်းတစ်ခုတည်းကိုသာ ပြောင်းလဲရခြင်းအကြောင်း

ထုတ်ယူသူများက ဒေတာကို မျှဝေခြင်းဖြင့် နေရာချွေတာပါသည်။ property set တစ်ခုကို တံခါးနှစ်ဆယ်က မျှဝေနိုင်ပြီး၊ တန်ဖိုးတစ်ခု ("Fire rating: 60 min") ကို set ကိုးဆယ်တွင် စာရင်းပြုနိုင်ပါသည်။ BimCraft က မျှဝေထားသော တန်ဖိုးကို ရိုးရိုးပြောင်းလျှင် ၎င်းကို မျှဝေသော အစိတ်အပိုင်းအားလုံး ပြောင်းသွားပါမည်။

ထို့ကြောင့် BimCraft က ရေးမီ ကော်ပီလုပ်ပါသည်:

- သင်တည်းဖြတ်သော property set ကို အခြားအစိတ်အပိုင်းများက မျှဝေထားလျှင် သင့်အစိတ်အပိုင်းသည် set ၏ ကိုယ်ပိုင်ကော်ပီကို ရရှိပြီး ကော်ပီသာ ပြောင်းပါသည်။
- တန်ဖိုးကို အခြား set များက မျှဝေထားလျှင် သင့် set သည် တန်ဖိုး၏ ကိုယ်ပိုင်ကော်ပီကို ရရှိပါသည်။

အိမ်နီးချင်းများသည် ၎င်းတို့၏ ဟောင်းဒေတာကို ထိန်းထားပါသည်။ ၎င်းကို *copy-on-write* ဟု ခေါ်ပါသည်။ ၎င်းသည် ဖိုင်သို့ အသေးစားထည့်သွင်းမှု အနည်းငယ် ထည့်ပေးပြီး၊ IFC ပရိုဂရမ်တိုင်း ပုံမှန်ဖတ်ပါသည်။

**အမျိုးအစား property များသည် ရည်ရွယ်ချက်ဖြင့် ခြွင်းချက်ဖြစ်သည်။** "(type)" ဟု မှတ်ထားသော set သည် အစိတ်အပိုင်း၏ အမျိုးအစားနှင့် သက်ဆိုင်ပြီး၊ IFC တွင် ထိုအမျိုးအစား အစိတ်အပိုင်းတိုင်းက ထိုနေရာမှ ဖတ်ပါသည်။ ၎င်းကို ပြောင်းလျှင် အမျိုးအစားကို ပြောင်းသည်၊ ထို့ကြောင့် အမျိုးအစားရှိ အစိတ်အပိုင်းတိုင်းသည် တန်ဖိုးအသစ်ကို ပြပါသည်။ {{ui:Changes}} စာရင်းက ထိုသို့သော တည်းဖြတ်မှုများကို "(type)" ဖြင့် မှတ်ပါသည်။ [အမျိုးအစားတစ်ခု၏ အစိတ်အပိုင်းတိုင်းအတွက် အမျိုးအစား property ကို ပြောင်းခြင်း](topic:type-vs-instance) ကို ကြည့်ပါ။

## အလုပ်မဆုံးရှုံးမီ သတိပေးချက်များ

- မသိမ်းရသေးသော ပြောင်းလဲမှုများရှိနေစဉ် အခြားဖိုင်ဖွင့်လျှင် "*file* တွင် မသိမ်းရသေးသော ပြောင်းလဲမှု *n* ခုရှိသည်။ ၎င်းတို့ကို ဖယ်ရှားမလား?" ဟု မေးပါသည်။ အလုပ်ဆက်လုပ်ရန် ပယ်ဖျက်ရန် ကို နှိပ်ပြီး၊ ထို့နောက် သိမ်းပါ။
- မသိမ်းရသေးသော ပြောင်းလဲမှုများဖြင့် တက်ဘ်ကို ပိတ်ခြင်း သို့မဟုတ် ပြန်တင်ခြင်းသည် browser က ထွက်မလား မေးစေပါသည်။

## အများဆုံးဖြစ်တတ်သော အမှားများ

- **ယူနစ်ရိုက်ခြင်း။** `2400 mm` ကို ငြင်းပယ်ပါသည်။ `2400` ဟု ရိုက်ပါ။
- **အစိတ်အပိုင်းတစ်ခုကို ရည်ရွယ်ပြီး အမျိုးအစား property ကို ပြောင်းခြင်း။** ရိုက်မီ "(type)" မှတ်ချက်ကို ရှာပါ။ အစိတ်အပိုင်းတစ်ခုသာ ကွဲပြားစေလိုလျှင် instance property သို့မဟုတ် ၎င်း၏ Tag သို့မဟုတ် အမည်ကို ပြောင်းပါ။
- **မူလဖိုင် ပြောင်းမည်ဟု မျှော်လင့်ခြင်း။** သိမ်းခြင်းသည် အမြဲ ဖိုင်အသစ်ကို ဒေါင်းလုဒ်ဆွဲပါသည်။ လိုချင်လျှင် မူလကို သင်ကိုယ်တိုင် အစားထိုးပြီး မိတ္တူထားပါ။
