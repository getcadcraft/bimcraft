## လုပ်ဆောင်မည့်အရာ

မော်ဒယ်မှ စုစုပေါင်းများ ထုတ်ယူပါ: storey တစ်ခုလျှင် နံရံအရှည်များ၊ type တစ်ခုလျှင် တံခါး အရေအတွက်များ၊ material တစ်ခုလျှင် slab ထုထည်၊ zone တစ်ခုစီ၏ ကုန်ကျစရိတ်။

## အဆင့်များ

1. IFC မော်ဒယ်ကို ဖွင့်ပါ။
2. ဘယ်ဘက် panel ရှိ {{ui:Quantity totals}} ကို ဖွင့်ပါ။
3. {{ui:Count}} တွင် {{ui:Every element}} သို့မဟုတ် ရွေးထားသော အရာများကိုသာ ရွေးပါ။
4. {{ui:Group by}} အောက်တွင် {{ui:Class}} ကဲ့သို့ property တစ်ခုကို ရွေးပါ။ ထပ်ခွဲလိုလျှင် {{ui:Add a group}} ကို နှိပ်ပါ (အများဆုံး သုံးခု)၊ ဥပမာ {{ui:Storey}} အလိုက်။
5. {{ui:Add up}} အောက်တွင် စုစုပေါင်းလိုသော နံပါတ်များကို အမှတ်ခြစ်ပါ။ မော်ဒယ်၏ quantity set များကို အစတွင် အမှတ်ခြစ်ထားသည်။
6. Table ကို spreadsheet တွင် ဖွင့်ရန် {{ui:Download CSV}} ကို နှိပ်ပါ။

## သင်မြင်ရမည်များ

- အုပ်စုတစ်ခုစီအတွက် row တစ်ခု၊ ၎င်းတွင် element အရေအတွက်နှင့် စုစုပေါင်းတစ်ခုစီ၊ နှင့် စုစုပေါင်း row တစ်ခု။
- တန်ဖိုးမရှိသော element များကို ရေတွက်သော်လည်း ဘာမျှ မပေါင်းပါ။ ထိုသို့ဖြစ်လျှင် CSV သည် စုစုပေါင်းဘေးတွင် "left out" column ထည့်သည်၊ ထို့ကြောင့် အရေအတွက် မည်မျှရှိသည်ကို မြင်နိုင်သည်။
- နံပါတ်များသည် ဖိုင်၏ ကိုယ်ပိုင် ယူနစ်ဖြင့် ဖြစ်ပြီး ဖိုင်က သိမ်းထားသည့်အတိုင်း၊ အရှည်များအတွက် မကြာခဏ မီလီမီတာ။

## Element တစ်ခုလျှင် row တစ်ခု၊ သို့မဟုတ် space များ

{{ui:Show}} ကို ပြောင်းပါ:

- **Element တစ်ခုလျှင် row တစ်ခု**: element တစ်ခုစီ သီးခြား row တွင်၊ property များကို {{ui:Columns}} အောက်တွင်၊ နံပါတ်များကို {{ui:Add up}} အောက်တွင်။ CSV သည် element တစ်ခုစီ၏ GlobalId ဖြင့် စတင်သည်။ Row ရှိ ပထမ တန်ဖိုးကို နှိပ်၍ ထို element ကို ရွေးပါ။
- **Spaces**: အခန်းတစ်ခုစီ၏ နံပါတ်၊ အမည်၊ storey၊ ဧရိယာနှင့် ထုထည်၊ နှင့် ၎င်းတို့၏ စုစုပေါင်းများ။ ဧရိယာနှင့် ထုထည်များသည် space ၏ quantity များမှ ဖိုင်က ဖော်ပြသည့်အတိုင်း ရယူသည်။ ဖိုင်တွင် မရှိလျှင် space ၏ ပုံသဏ္ဍာန်မှ m² နှင့် m³ ဖြင့် တိုင်းတာပြီး စာလုံးစောင်းဖြင့် ပြသည်; CSV က မည်သည်က မည်သည်ဖြစ်သည်ကို ပြောသည်။
