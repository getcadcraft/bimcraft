## လုပ်ဆောင်မည့်အရာ

ပုံဆွဲ၏ model space ကို 3D ဖြင့် ကြည့်ပါ။ မျဉ်းများနှင့် polyline များသည် ၎င်းတို့၏ အမှန်အမြင့်တွင် ရှိပြီး၊ အထူရှိသော အရာများသည် နံရံများအဖြစ် ထမ်းရပ်ပါသည်၊ 3D မျက်နှာများ၊ mesh များနှင့် 3D ဘလော့များကို လှည့်ပတ်ကြည့်နိုင်သော မျက်နှာပြင်များအဖြစ် ပြပါသည်။ စာရွက်များသည် 2D အတိုင်း နေပါသည်။

## အဆင့်များ

1. DWG သို့မဟုတ် DXF ကို ဖွင့်ပါ။ [DWG သို့မဟုတ် DXF ပုံဆွဲကို ကြည့်ခြင်း](topic:view-dwg) ကို ကြည့်ပါ။ {{ui:Settings}} › {{ui:BimCraft}} › **ပုံဆွဲများ ဖွင့်ရာ** က {{ui:Model (2D)}} ဟု မပြောသည့်အတိုင်း 3D ဖြင့် ဖွင့်ပါသည်။
2. 2D မှ ပုံဆွဲအပေါ်ရှိ ဘားတွင် {{ui:3D}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{key:3}} ကို နှိပ်ပါ။
3. ပထမဆုံးအကြိမ်တွင် ခဏစောင့်ပါ: အခြေအနေစာကြောင်းက "ပုံဆွဲကို 3D တွင် တည်ဆောက်နေသည်…" ဟု ပြပြီး၊ ထို့နောက် မျဉ်းနှင့် မျက်နှာ အရေအတွက်ကို ပြပါသည်။
4. လှည့်ပတ်၊ ရွှေ့နှင့် ဇူးမ်လုပ်ပါ (အောက်ရှိ ဇယားကို ကြည့်ပါ)။
5. ဒုတိယဘားရှိ မြင်ကွင်းတစ်ခုကို နှိပ်ပါ: {{ui:Iso}}၊ {{ui:Top}}၊ {{ui:Bottom}}၊ {{ui:Front}}၊ {{ui:Back}}၊ {{ui:Left}} သို့မဟုတ် {{ui:Right}}။
6. perspective နှင့် ပြိုင်မြင်ကွင်းကြား ပြောင်းရန် {{ui:Perspective}} ကို နှိပ်ပါ။
7. ပုံဆွဲတစ်ခုလုံးကို ထပ်မံကြည့်ရန် {{ui:Extents}} ကို နှိပ်ပါ သို့မဟုတ် {{key:F}} ကို နှိပ်ပါ။
8. 2D သို့ ပြန်ရန် {{ui:3D}} ကို ထပ်နှိပ်ပါ၊ {{key:3}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:Model}} သို့မဟုတ် စာရွက်တက်ဘ်ကို နှိပ်ပါ။

## မြင်ရမည့်အရာ

- 3D ရှိ model space၊ Z အပေါ်သို့၊ ပုံဆွဲ၏ မူလအရောင်များဖြင့်။ မျက်နှာများသည် ၎င်းတို့၏ အစွန်းများထက် အရောင်ပိုဖျော့သည်။
- {{ui:Layers}} တွင် ပိတ်ထားသော လေယာများသည် 3D မြင်ကွင်းမှလည်း ပျောက်ပါသည်။
- ညာဘက်တွင်: မျဉ်းနှင့် မျက်နှာအရေအတွက်၊ ပုံဆွဲ၏ X၊ Y နှင့် Z အရွယ်အစား၊ **2D မြင်ကွင်းတွင်သာ** နှင့် **ယခုထိ မဆွဲရသေးသည်**။

## ဖြတ်ပိုင်းပလိန်ဖြင့် ဖြတ်ခြင်း

3D ဘားပေါ်ရှိ {{ui:Section}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{key:X}} ကို နှိပ်ပါ။ ၎င်းအောက်ရှိ ဘားသည် IFC မော်ဒယ်များအတွက် အလုပ်လုပ်သည့်အတိုင်း အလုပ်လုပ်ပါသည် ([IFC မော်ဒယ်ကို ဖြတ်ပိုင်းပလိန်ဖြင့် ဖြတ်ခြင်း](topic:section-plane) ကို ကြည့်ပါ): {{ui:Top}}၊ {{ui:Front}} သို့မဟုတ် {{ui:Side}} မှ ဖြတ်ပါ၊ offset ကို ဆွဲ သို့မဟုတ် ရိုက်ထည့်ပါ — ဤနေရာတွင် ပုံဆွဲ၏ ကိုယ်ပိုင်ယူနစ်များဖြင့် — နှင့် တခြားဘက်ကို ထိန်းရန် {{ui:Flip}}။ ပလိန်က ဖြတ်ထုတ်လိုက်သော အရာများကို ရွေး၍ မရပါ။ 2D သို့ ပြန်သွားလျှင် ဖြတ်ချက်ကို ဖယ်ပါသည်။

## အရာဝတ္ထု၏ ဂုဏ်သတ္တိများကို ကြည့်ရန်

3D မြင်ကွင်းရှိ အရာဝတ္ထုကို နှိပ်ပါ။ ၎င်းသည် ရွေးချယ်အရောင်သို့ ပြောင်းပြီး {{ui:Properties}} က ဖိုင်က ၎င်းအကြောင်း ဘာပြောသည်ကို ပြပါသည်: အမျိုးအစား၊ လေယာ၊ အရောင်၊ linetype နှင့် handle၊ ထို့နောက် မျဉ်း၏ အစ၊ အဆုံးနှင့် အလျား၊ စက်ဝိုင်း၏ ဗဟိုနှင့် အချင်းဝက်၊ 3D မျက်နှာ၏ ထောင့်များ၊ သို့မဟုတ် ဘလော့ကိုးကားချက်၏ ဘလော့၊ ထည့်သွင်းမှတ်၊ စကေး၊ လှည့်ပတ်မှုနှင့် အရည်အချင်းတန်ဖိုးများကဲ့သို့သော ကိုယ်ပိုင်ဒေတာ။

- ဘလော့ကိုးကားချက်ကို တစ်ခုလုံးအဖြစ် ရွေးပါသည်၊ ၎င်းအတွင်းရှိ ဘလော့များလည်း ပါဝင်သည်။
- မျဉ်းနှင့် ပစ်ဆယ်အနည်းငယ် အကွာတွင် နှိပ်လျှင် မျဉ်းကို ရွေးပါသည်။
- အရာဝတ္ထုများကို ပိုရွေးရန် သို့မဟုတ် တစ်ခုကို ဖယ်ရန် {{key:Mod}} ကို ဖိထားပြီး နှိပ်ပါ; {{ui:Properties}} က ၎င်းတို့ကို အမျိုးအစားအလိုက် ရေတွက်ပြပါသည်။
- {{key:Esc}}၊ သို့မဟုတ် အလွတ်နေရာတွင် နှိပ်လျှင် ရွေးချယ်မှုကို ရှင်းပါသည်။
- ပိတ်ထားသော လေယာပေါ်ရှိ အရာဝတ္ထုများကို ရွေး၍ မရပါ။

## 3D တွင် ဆွဲပေးသည့်အရာများ

| ပုံဆွဲတွင် | 3D တွင် |
|---|---|
| မျဉ်းများ၊ 3D polyline များ | အမှန်အမြင့်တွင် |
| Polyline များ၊ စက်ဝိုင်းများ၊ အဆို့များ၊ ellipse များ | ၎င်းတို့၏ ကိုယ်ပိုင်ပလိန်တွင်၊ အမြင့်ညွှန်းတွင်၊ ပုံဆွဲ စောင်းသောအခါ စောင်းပါသည် |
| မျဉ်း၊ polyline၊ စက်ဝိုင်းနှင့် အဆို့များပေါ်ရှိ အထူ | ထိုအမြင့်ရှိ နံရံများ; စက်ဝိုင်းများသည် အပေါ်နှင့် အောက်တွင် ပိတ်ထားသည် |
| 3D မျက်နှာများ၊ polyface mesh များ၊ polygon mesh များ | မြင်ရသော အစွန်းများပါသော အရိပ်ထိုးထားသော မျက်နှာပြင်များ |
| ဘလော့များ | 3D တွင် နေရာချ၊ လှည့်၊ စကေးပြောင်း၊ အတွင်းဘလော့များလည်း ပါ |
| Hatch များ | ၎င်းတို့၏ အပြင်ပန်းကြိုးများ |
| ရိုးရိုး 2D မျဉ်းများ | ဆွဲခဲ့သည့်နေရာတွင် ပြားချပ်စွာ |

## 2D မြင်ကွင်းတွင်သာ

စာသား၊ multiline စာသားနှင့် ဘလော့များ၏ မြင်ရသော အရည်အချင်းများကို 3D တွင် ၎င်းတို့၏ ကိုယ်ပိုင်ပလိန်နှင့် ကိုယ်ပိုင်အမြင့်တွင် ဆွဲပါသည်၊ ၎င်းတို့ကို နှိပ်လျှင် ရွေးပါသည်။ ကျယ်သော polyline များသည် ၎င်းတို့၏ အကျယ်ကို ပြားချပ်သော band တစ်ခုအဖြစ် ပြပါသည်။ Multileader များ၊ ပုံများနှင့် hatch ပုံစံများကို **2D မြင်ကွင်းတွင်သာ** အောက်တွင် ရေတွက်ပါသည်: ၎င်းတို့ကို {{ui:Model}} တက်ဘ် သို့မဟုတ် စာရွက်များပေါ်တွင် ကြည့်ပါ။

## ယခုထိ မဆွဲရသေးသည်များ

ACIS ခန္ဓာကိုယ်များ (3D solids၊ bodies၊ regions နှင့် surfaces) အဖြစ် သိမ်းထားသော solid များနှင့် မျက်နှာပြင်များ၊ နှင့် subdivision mesh များကို **ယခုထိ မဆွဲရသေးသည်** အောက်တွင် အရေအတွက်နှင့်အတူ စာရင်းပြုပါသည်။ ၎င်းတို့ကို ကျော်သွားပြီး ခန့်မှန်း၍ မဆွဲပါ။

## အများဆုံးဖြစ်တတ်သော အမှားများ

- **အားလုံး ပြားနေသည်ဟု ပေါ်သည်။** ပုံဆွဲသည် 2D ဖြစ်ပြီး ၎င်း၏ မျဉ်းများတွင် အမြင့် မရှိပါ။ စစ်ဆေးရန် {{ui:Front}} ကို နှိပ်ပါ; ပြားသော ပုံဆွဲသည် မျဉ်းတစ်ကြောင်းအဖြစ် ပေါ်ပါသည်။
- **solid မော်ဒယ်တစ်ခု ဘာမှမပြပါ။** solid modeler ဖြင့် ဖန်တီးထားသော solid များသည် ACIS ခန္ဓာကိုယ်များဖြစ်ပြီး **ယခုထိ မဆွဲရသေးသည်** အောက်တွင် စာရင်းပါသည်။ မော်ဒယ်ကို ဖန်တီးခဲ့သော ပရိုဂရမ်မှ IFC သို့မဟုတ် 3D faces အဖြစ် ထုတ်ယူပါ။
- **ပုံဆွဲသည် အလယ်တွင် အသေးစား အစုတစ်ခုဖြစ်နေသည်။** model space ၏ အဝေးမှ အရာတစ်ခု၊ ဥပမာ ပလန်ဟောင်းကော်ပီ၊ က extents ကို ကြီးစေပါသည်။ ကြည့်လိုသော နေရာတွင် ဘီးဖြင့် ဇူးမ်ချဲ့ပါ။
