{{ui:Render}} ရှိ ရုပ်ပုံကို **ကိုယ်ပိုင် engine များ** က ဆွဲသည်: မြန်ဆန် နှင့် Path tracer၊ ဝဘ်နှင့် CadCraft Studio နှစ်ခုလုံးတွင်။ အခြား program က **render-engine ထပ်ဆောင်း** တစ်ခုက ယူဆောင်လာမှသာ ရုပ်ပုံကို ဆွဲနိုင်သည်: [render-engine ထပ်ဆောင်းဖြင့် engine ထည့်ခြင်း](topic:render-engine-addons) ကို ကြည့်ပါ။ ဇာတ်ကွင်းကို အခြား program သို့ ယူသွားပြီး ထိုနေရာတွင် ဆက်လုပ်လိုလျှင် [ဇာတ်ကွင်းကို အခြား program တွင် ဖွင့်ခြင်း](topic:render-open-in) သို့မဟုတ် [ဇာတ်ကွင်းကို game engine သို့ ပို့ခြင်း](topic:render-unreal) ကို သုံးပါ။

## ထပ်ဆောင်း၏ engine ဖြင့် ရုပ်ပုံဆွဲခြင်း

1. ဆက်တင်များ › ထပ်ဆောင်းများတွင် ထပ်ဆောင်းကို ဖွင့်ပါ။ ၎င်း၏ engine သည် {{ui:Render}} ၏ Engine စာရင်းတွင် ပေါ်လာသည်။
2. ရွေးပါ။ ၎င်း၏ ကိုယ်ပိုင် ဆက်တင်များသည် Engine စာရင်းအောက်တွင် ပြသည်။
3. {{ui:Render}} ကို နှိပ်ပါ။ Studio တွင် ထပ်ဆောင်းက program ကို ပထမဆုံး run သောအခါ Studio က ကိုယ်ပိုင် dialog ဖြင့် မေးသည်။ ဆွဲနေစဉ် တိုးတက်မှု ပြသည်; {{ui:Stop}} က ရပ်စေသည်။ ရုပ်ပုံသည် ဆွဲခဲ့သော engine အမှတ်အသားဖြင့် ပေါ်လာသည်။

JavaScript ဖြင့် ရေးထားသော engine သည် ဝဘ်တွင်လည်း run သည်။ ဤကွန်ပျူတာပေါ်တွင် program run သော engine သည် Studio တွင်သာ run သည်; ဝဘ်တွင် သိမ်းရန် ဖိုင်အဖြစ် ပြသည်။

## ယူဆောင်သွားသော အရာများ

engine သည် **package** ကို ရရှိသည်: မော်ဒယ်ကို USD ဖိုင် (နှင့် တောင်းဆိုပါက glTF ဖိုင်) အဖြစ်၊ နှင့် material တန်ဖိုးအတိအကျ၊ နေနှင့် ကောင်းကင်၊ ဖွင့်ထားသော မီးလုံးတိုင်း၏ power နှင့် light profile၊ ကင်မရာနှင့် exposure ပါသော ဆက်တင်ဖိုင်။ program တစ်ခုစီက အလင်း၊ အရောင်နှင့် နမူနာကို ကိုယ်ပိုင်နည်းဖြင့် လုပ်သဖြင့် ရုပ်ပုံများသည် ကင်မရာ၊ နေ၊ မီးလုံးနှင့် exposure တွင် ဆင်တူသော်လည်း pixel အတိအကျ မတူပါ။

## CadCraft ဘယ်တော့မှ မ run သော program များ

CadCraft သည် GNU GPL လိုင်စင်အောက်ရှိ program ကို ဘယ်တော့မှ မစတင်ပါ၊ engine စာရင်း သို့မဟုတ် Open in ပစ်မှတ်အဖြစ်လည်း ဘယ်တော့မှ မစာရင်းသွင်းပါ။ Blender သည် ၎င်းတို့ထဲမှ တစ်ခုဖြစ်သဖြင့် Engine စာရင်းတွင် မပါပါ။ {{ui:Render}} မှ သိမ်းသော USD သို့မဟုတ် glTF ဖိုင်သည် အခြား program ဖတ်နိုင်သည့်အတိုင်း ထို program တွင် ဖွင့်နိုင်သေးသည်။

:::note
Panorama နှင့် stereo ကင်မရာများ နှင့် ကောင်းကင်ပုံ (ကောင်းကင်၏ အရောင်များကို အစားထိုး သုံးသည်) တို့သည် အခြား program သို့ မယူဆောင်ပါ။ အခြား program တွင် လုပ်သမျှ မော်ဒယ်သို့ ပြန်မလာပါ။
:::
