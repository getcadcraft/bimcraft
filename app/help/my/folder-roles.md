## မိတ္တူ အခြေအနေ

မော်ဒယ်တိုင်း၏ မိတ္တူ၊ main file နှင့် နံပါတ်ပါ backup များ အားလုံးသည် header စစ်ဆေးမှု ရရှိသည်။

| အညွှန်း | အဓိပ္ပာယ် |
|---|---|
| **Complete** | ဖိုင်၏ header နှင့် index သည် ဖိုင်အတွင်း အံဝင်သည် |
| **Incomplete** | ဖိုင်သည် ၎င်း၏ index ပြသထားသည်ထက် တိုသည်: ကူးယူနေစဉ်၊ upload လုပ်စဉ် သို့မဟုတ် sync လုပ်စဉ် ဖြတ်တောက်ခံရသည်၊ သို့မဟုတ် "online only" ဟု ရှိနေသေးသော cloud ဖိုင် ဖြစ်သည် |
| **Unreadable** | ဖိုင်သည် valid compound file မဟုတ်ပါ၊ သို့မဟုတ် ဖတ်၍ မရပါ |

**Status** ကော်လံတွင် မော်ဒယ်သည် **Complete** ပြသည်။ မိတ္တူတစ်ခုမျှ ပျက်နေသော်လည်း နောက်တစ်ခု ကောင်းနေသည့်အခါ အဝါရောင် "*n* incomplete" ပြသည်။ ကောင်းသော မိတ္တူ တစ်ခုမျှ မရှိသည့်အခါ အနီရောင် **Incomplete** ပြသည်။

## Backup များ

`Name.0001.rvt`၊ `Name.0002.rvt` စသည့် ဖိုင်များသည် `Name.rvt` ၏ နံပါတ်ပါ backup များဖြစ်သည်။ ၎င်းတို့ကို မော်ဒယ်အောက်တွင် အသစ်ဆုံးကို ထိပ်ဆုံးထား၍ **All … copies** တွင် အုပ်စုဖွဲ့ထားသည်။ ကတ်ကို main file မှ ဖတ်သည် ပြည့်စုံလျှင်၊ မဟုတ်လျှင် နောက်ဆုံး ပြည့်စုံသော backup မှ ("newest complete") ဖတ်သည်။

## အခန်းတာဝန်များ

မော်ဒယ်အမည်အောက်တွင် စာလုံးစောင်းဖြင့် ပြသည်။

| အခန်းတာဝန် | အဓိပ္ပာယ် |
|---|---|
| *အခြားမော်ဒယ်* မှ ချိတ်ဆက်: နောက်ခံ | ဖိုင်တွဲရှိ အခြားမော်ဒယ်တစ်ခုက ဤမော်ဒယ်ကို ချိတ်ဆက်ထားသည်၊ ထို့ကြောင့် အခြားသူ၏ နောက်ခံ ဖြစ်နိုင်သည် (ဥပမာ အကြံပေးသူ၏ မော်ဒယ်) |
| Starter သို့မဟုတ် အမည်မပေးရသေးသော ဖိုင် | Blank၊ Template၊ Default၊ Untitled သို့မဟုတ် Project1 ကဲ့သို့ အမည်: စတင်ရန် အစမှတ်၊ သို့မဟုတ် မှန်ကန်စွာ အမည်မပေးရသေးသော ဖိုင် |
| Central model | Workshared central model။ အလုပ်လုပ်ခြင်းသည် ဤနေရာတွင် မဟုတ်ပါ၊ local copy တွင် ဖြစ်သည် |
| Family (အပိုင်းတစ်ခု) | `.rfa` သို့မဟုတ် `.rft` ဖိုင်: ပရောဂျက် မဟုတ်ဘဲ အစိတ်အပိုင်း တစ်ခု |
| Backup များသာ | Main file ပျောက်သွားပြီး နံပါတ်ပါ backup များသာ ကျန်သည် |

## ဤနေရာမှ စတင်ပါကို ဘယ်လို ရွေးသလဲ

BimCraft သည် အတွေ့အကြုံရှိ အသုံးပြုသူ၏ ကျိုးကြောင်းဆင်ခြင်ပုံကို အသုံးပြုသည်:

1. ရွေးချယ်ခံများမှာ အခြားမော်ဒယ်က ချိတ်ဆက်မထားပြီး starter မဟုတ်သော၊ ဖတ်နိုင်သော ပရောဂျက်ဖိုင်များ (`.rvt`၊ `.rte`) ဖြစ်သည်။
2. Central နှင့် backup-only မော်ဒယ်များကို အခြား ပိုကောင်းသော ရွေးချယ်ခံ မရှိမှသာ ထည့်စဉ်းစားသည်။
3. ရွေးချယ်ခံများထဲမှ နောက်ဆုံး သိမ်းထားသော ဖိုင်က အနိုင်ရသည်။

အကွက်တွင် ၎င်း၏ အကြောင်းရင်းများကို စာရင်းပြုသည်။ ထင်ရှားသော ရွေးချယ်မှုဖြစ်ပုံရသော ဖိုင်သည် ပျက်စီးနေသည့်အခါ၊ အခြား မော်ဒယ်များ နောက်ခံ ဖြစ်သည့်အခါနှင့် ရွေးချယ်မှုသည် central မော်ဒယ် ဖြစ်သည့်အခါတွင် သတိပေးသည်။ ၎င်းသည် အကောင်းဆုံး ခန့်မှန်းချက်သာ ဖြစ်သည်၊ ပရောဂျက်ကို နောက်ဆုံး လုပ်ခဲ့သူနှင့် စစ်ဆေးပါ။

## လင့်ခ် အခြေအနေ

| အညွှန်း | အဓိပ္ပာယ် |
|---|---|
| **In this folder** | သိမ်းထားသော ဆွေမျိုး လမ်းကြောင်းတွင် သို့မဟုတ် ဖိုင်တွဲအတွင်း သိမ်းထားသော full path ၏ အဆုံးတွင် တွေ့သည် |
| **Same name found** | ၎င်း၏ လမ်းကြောင်းတွင် မဟုတ်သော်လည်း ဖိုင်တွဲတွင် အမည်တူဖိုင် ရှိသည်။ မှန်ကန်သည်ကို စစ်ပါ |
| **Library file** | Keynote သို့မဟုတ် assembly code ဇယား။ ၎င်းတို့သည် ကွန်ပျူတာတိုင်းတွင် ပရိုဂရမ်နှင့်အတူ ပါလာသည် |
| **Not in this folder** | ဖိုင်တွဲတွင် ဘယ်နေရာမှ မတွေ့ပါ |

**Models** ရှိ **Links found** ကော်လံသည် မော်ဒယ်၏ လင့်ခ်များအနက် ဖိုင်တွဲတွင် မျှော်လင့်ထားသော လင့်ခ်များထဲမှ မည်မျှ တွေ့သည်ကို ပြသည် (library ဖိုင်များကို မရေတွက်ပါ)။
