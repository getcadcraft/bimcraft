## ဘာလုပ်မလဲ

IFC မော်ဒယ်ကို ဖွင့်ပြီး 3D တွင် ပတ်ပတ်လည် လှည့်ပါ၊ ရွှေ့ပါနှင့် စံ view များသို့ ခုန်ပါ။ ခန့်မှန်း ငါးမိနစ်။

`.ifc` ဖိုင် လိုအပ်သည်။ BIM program အများစုက ထုတ်ပေးသည်; Revit တွင် **File > Export > IFC** ဖြစ်သည်။ [IFC မှတစ်ဆင့် ပရောဂျက်ဖိုင်ကို 3D သို့ ရယူခြင်း](topic:rvt-to-ifc) ကို ကြည့်ပါ။

## အဆင့်များ

1. {{ui:Choose a file}} (သို့မဟုတ် ဘယ်အပေါ်ထောင့်ရှိ ဖိုင်ချရန်နေရာ) ကို နှိပ်ပါ။
2. သင့် `.ifc` ဖိုင်ကို ရွေးပြီး အတည်ပြုပါ။
3. Status line ပြီးသည်အထိ စောင့်ပါ။ ပထမဆုံးအကြိမ် "IFC engine စတင်နေသည်…" ကို ပြသပြီး၊ ထို့နောက် "မော်ဒယ်ကို ဖတ်နေသည်…" နှင့် "ဂျီသြမေတြီ တည်ဆောက်နေသည်: … / … အစိတ်အပိုင်း" ကို ပြသည်။
4. မော်ဒယ်ကို ကြည့်ပါ: သုံးပုံလေးပုံ view ဖြင့် ဖွင့်ပြီး မျက်နှာပြင်နှင့် ကိုက်ညီသည်။
5. မော်ဒယ်အပေါ်ရှိ toolbar ရှိ {{ui:Top}} ကို နှိပ်ပြီး တိုက်ရိုက် အောက်သို့ ကြည့်ပါ။
6. ရှေ့ကို ကြည့်ရန် {{ui:Front}} ကို နှိပ်ပါ၊ ထို့နောက် ဘေးမှ ကြည့်ရန် {{ui:Side}} ကို နှိပ်ပါ။
7. မော်ဒယ်တစ်ခုလုံး၏ သုံးပုံလေးပုံ view သို့ ပြန်သွားရန် {{ui:Fit}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{key:F}} ကို ဖိပါ။

## မြင်ရမည့်အရာ

- မော်ဒယ်ကို အလယ်တွင်၊ ပုံဆွဲကဲ့သို့ ပုံစံအတွက် အနက်ရောင် ပါးလွှာသော အစွန်းများဖြင့်။
- ဘယ်ဘက်ရှိ {{ui:File}} panel: ဖိုင်အမည်၊ အရွယ်အစား၊ IFC schema (ဥပမာ IFC2X3 သို့မဟုတ် IFC4)၊ ပရောဂျက်အမည်၊ phase၊ ထုတ်ပေးခဲ့သော program၊ ရေးသူ၊ export ရက်စွဲ၊ နှင့် အစိတ်အပိုင်းနှင့် triangle အရေအတွက်။
- ၎င်းအောက်ရှိ {{ui:Storeys}} နှင့် {{ui:Elements}} စာရင်းများ။
- Status line: "ဖွင့်ပြီး *file name*: အစိတ်အပိုင်း *n*၊ *s* စက္ကန့်အတွင်း"။

## ရွေ့လျားခြင်း

:::mouse
| ရည်ရွယ်ချက် | ဤအရာကို လုပ်ပါ |
|---|---|
| လှည့်ခြင်း | ဘယ်ခလုတ်ဖြင့် ဆွဲပါ |
| ရွှေ့ခြင်း | ညာခလုတ်ဖြင့် ဆွဲပါ၊ သို့မဟုတ် {{key:Shift}} (သို့မဟုတ် {{key:Mod}}) ကို ဖိထားပြီး ဘယ်ခလုတ်ဖြင့် ဆွဲပါ |
| ဇူးမ် | ဘီးကို လှိမ့်ပါ၊ သို့မဟုတ် အလယ်ခလုတ်ဖြင့် ဆွဲပါ |
| အားလုံးကို ကြည့်ခြင်း | {{key:F}} ကို ဖိပါ သို့မဟုတ် {{ui:Fit}} ကို နှိပ်ပါ |
:::

:::mac mouse
Trackpad တွင်: လက်ညိုးတစ်ချောင်းဖြင့် ဖိ၍ ဆွဲလျှင် လှည့်သည်; {{key:Shift}} သို့မဟုတ် {{key:Mod}} ကိုဖိထားပြီး ဆွဲလျှင် ရွှေ့သည်; လက်ချောင်းနှစ်ချောင်းဖြင့် လှိမ့်ပါ သို့မဟုတ် ဆွဲညှစ်ပါ ဇူးမ်အတွက်။ လက်ချောင်းနှစ်ချောင်း နှိပ်ခြင်းသည် ညာကလစ် ဖြစ်ပြီး ၎င်းဖြင့် ဆွဲ၍ ရွှေ့နိုင်သည်၊ သို့သော် {{key:Shift}} နှင့် ဆွဲခြင်းက ပိုလွယ်သည်။
:::

:::touch
| ရည်ရွယ်ချက် | ဤအရာကို လုပ်ပါ |
|---|---|
| လှည့်ခြင်း | လက်ချောင်းတစ်ချောင်းဖြင့် ဆွဲပါ |
| ဇူးမ် | လက်ချောင်းနှစ်ချောင်းဖြင့် ဆွဲညှစ်ပါ |
| ရွှေ့ခြင်း | လက်ချောင်းနှစ်ချောင်းကို အတူရွှေ့ပါ |
| အားလုံးကို ကြည့်ခြင်း | {{ui:Fit}} ကို တို့ပါ |
:::

လှည့်ခြင်းသည် အမြဲ မော်ဒယ်အလယ်ရှိ အမှတ်တစ်ခုပတ်လည် လှည့်သည်။ ရွှေ့ခြင်းသည် ထိုအမှတ်ကို ရွှေ့သဖြင့် ရှည်ရှည် ရွှေ့ပြီးနောက် လှည့်ခြင်းသည် ဗဟိုမှ လွဲနေသလို ခံစားရနိုင်သည်- ပြန်စရန် {{ui:Fit}} ကို နှိပ်ပါ။

## အရိပ်ထည့်၊ အစွန်းများ သို့မဟုတ် wireframe

View cube ၏ အပေါ်ရှိ ခလုတ်သေးငယ် သုံးခုက မော်ဒယ်ကို မည်သို့ ဆွဲမည်ကို ရွေးသည်- {{ui:Shaded}}၊ {{ui:Shaded with edges}} (မူရင်း) နှင့် {{ui:Wireframe}}။ ၎င်းတို့သည် command များလည်း ဖြစ်သည် (မီနူးများရှိ View နှင့် Customize စာရင်း)၊ ထို့ကြောင့် ကိုယ်ပိုင် ခလုတ်များ ရှိနိုင်သည်။ {{ui:Plan}}၊ {{ui:Split}} နှင့် {{ui:3D}} သည် toolbar ၏ {{ui:View}} အတန်းတွင် ရှိသည်။

## အမှားများ

- **အမည်ပေးထားသော view များကို မျှော်လင့်ခြင်း။** BimCraft တွင် သတ်မှတ်ထားသော view လေးခု ({{ui:Fit}}၊ {{ui:Top}}၊ {{ui:Front}}၊ {{ui:Side}})၊ ညာအောက်ထောင့်ရှိ view cube နှင့် လွတ်လပ်စွာ လှည့်ခြင်း ရှိသည်။ View များကို သိမ်းခြင်း မရှိပါ။
- **ပလန်နှင့် section များကို ရှာခြင်း။** ဤ build တွင် 2D ပလန် သို့မဟုတ် section box မရှိပါ။ {{ui:Section}} plane တစ်ခုဖြင့် မော်ဒယ်ကို ဖြတ်ပါ ([IFC မော်ဒယ်ကို section plane ဖြင့် ဖြတ်ခြင်း](topic:section-plane)) သို့မဟုတ် အထပ်များကို ပိတ်ပါ: [အထပ်များ၊ နေရာများနှင့် အစွန်းများကို ပြခြင်းနှင့် ဝှက်ခြင်း](topic:storeys-and-spaces)။
- **ပရောဂျက်ဖိုင်ကို ဖွင့်ပြီး 3D ကို မျှော်လင့်ခြင်း။** ပရောဂျက်ဖိုင်သည် file card အဖြစ် ဖွင့်သည်။ ဦးစွာ IFC export လုပ်ပါ။
- **`.ifczip` ဖွင့်ခြင်း။** Unzip လုပ်ပါ၊ သို့မဟုတ် ရိုးရိုး `.ifc` export လုပ်ပါ။
- **အလွန်ကြီးသော မော်ဒယ်က tab ကို နှေးစေခြင်း သို့မဟုတ် crash ဖြစ်စေခြင်း။** [ဘရောက်ဆာများ၊ စက်ပစ္စည်းများနှင့် memory](topic:platforms) ကို ကြည့်ပါ။
