## Embodied carbon

**Carbon** pane ကို ဖွင့်ပါ။ element တစ်ခုစီ၏ ပမာဏ (ထု၊ ဧရိယာ သို့မဟုတ် အလျား) ကို table မှ factor တစ်ခုဖြင့် မြှောက်သည်၊ life-cycle module အလိုက်: product stage လိုအပ်သည်၊ transport နှင့် waste ကို ရွေးချယ်နိုင်သည်။ စုစုပေါင်းကို ပစ္စည်း၊ အမျိုးအစားနှင့် ထပ်အလိုက်၊ နှင့် ကြမ်းပြင် စတုရန်းမီတာတစ်ခုစီအလိုက် ထုတ်ပေးသည်။

**factor table သည် သင့်ပိုင်ဆိုင်ပါသည်။** BimCraft နှင့်အတူ ပါလာသော အတန်းများသည် အရေအတွက်အမျိုးအစား မှန်ကန်သော ယေဘုယျ စတင်တန်ဖိုးများ ဖြစ်သည်။ ၎င်းတို့သည် database မှ မဟုတ်ပါ၊ unchecked ဟု အမှတ်အသားပြုထားပြီး သင်အသုံးပြုသော ရင်းမြစ် (EPD၊ နိုင်ငံ့ database သို့မဟုတ် သင့်ကုမ္ပဏီ၏ ကိန်းဂဏန်း) ဖြင့် အစားထိုးရန် လိုသည်။ Pane တွင် အတန်းများကို တည်းဖြတ်ပါ၊ သို့မဟုတ် table ကို CSV သို့မဟုတ် JSON အဖြစ် တင်သွင်း/ထုတ်ပါ။ သင်ထည့်သော အတန်းသည် တူညီသော id ရှိ စတင်အတန်းကို အစားထိုးသည်။ table ကို model ထဲတွင် သိမ်းသည်။

ကိုက်ညီသော factor မရှိ သို့မဟုတ် ပမာဏမရှိသော element များကို သုညအဖြစ် မရေတွက်ဘဲ **Problems** အဖြစ် စာရင်းပြုသည်။

## ဇယားပေါ်ရှိ ကုန်ကျစရိတ်

4D ဇယားဘေးရှိ **Cost** pane ကို ဖွင့်ပါ။ စျေးနှုန်းများ ပေးပါ (ရိုက်ထည့်၊ CSV သို့မဟုတ် JSON တင်သွင်း၊ သို့မဟုတ် TakeoffCraft ၏ လိုင်းများ ယူလာပါ)၊ စျေးနှုန်းတစ်ခုစီကို keyword များဖြင့် မော်ဒယ်ပစ္စည်းများနှင့် ချိတ်ပါ၊ ထို့နောက် task တစ်ခုစီ၏ element များကို စျေးနှုန်းသတ်မှတ်သည်။ task တစ်ခု၏ ကုန်ကျစရိတ်ကို ၎င်း၏ စတင်ရက်မှ ပြီးဆုံးရက်အထိ ဝေသည် (အညီအမျှ၊ ရှေ့ဆုံး သို့မဟုတ် နောက်ဆုံး အများဆုံး); pane သည် နေ့၊ ရက်သတ္တပတ် သို့မဟုတ် လအလိုက် စုစည်းငွေစီးဆင်းမှုကွေးကို ဆွဲပြသည်၊ stage နှင့် package အလိုက် ကုန်ကျစရိတ်၊ နှင့် ရက်တစ်ရက်တွင် စီစဉ်ထားသည်နှင့် တည်ဆောက်ပြီးသည်ကို နှိုင်းယှဉ်ပြသည်။ CSV ထုတ်ယူသည်။ စျေးနှုန်းမပေးမချင်း ဘာမျှ စျေးနှုန်း မသတ်မှတ်ပါ: ပါလာသော စျေးနှုန်း မရှိပါ။

## ငွေကြေး

စျေးနှုန်းဇယားတစ်ခုသည် ၎င်း၏ စျေးနှုန်းများ၏ ငွေကြေးကို ပြောနိုင်သည် (အက္ခရာ သုံးလုံး၊ ဥပမာ USD သို့မဟုတ် EUR)။ 5D pane တွင် ၎င်းအတွက် အကွက်ရှိပြီး စျေးနှုန်းများနှင့်အတူ ဖိုင်ထဲတွင် သိမ်းသည်၊ JSON ထုတ်ယူမှုများတွင်လည်း ပါဝင်သည်။ ဤမတိုင်မီ ပြုလုပ်ထားသော သို့မဟုတ် ဗလာထားခဲ့သော ဇယားတွင် ငွေကြေးမရှိ: ၎င်း၏ ကုန်ကျစရိတ်များကို shell ၏ မူလ USD အဖြစ် ပြသပြီး pane နှင့် စုစုပေါင်းများက ထိုသို့ ပြောသည်။ ငွေကြေးများအကြား ဘာမျှ ပြောင်းလဲမပြုပါ။
