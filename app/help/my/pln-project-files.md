## လုပ်ဆောင်မည့်အရာ

`.pln` (ပရောဂျက်), `.pla` (စာကြည့်တိုက်နှင့်အတူ archive), `.tpl` (template) သို့မဟုတ် `.bpn` (backup) အဖြစ် သိမ်းထားသော ပရောဂျက်ကို BimCraft သို့ ရယူပါ။ ဤဖိုင်များသည် Archicad ၏ ကိုယ်ပိုင်ဖိုင်များ ဖြစ်သည်။

## ယနေ့ ဖွင့်နိုင်သည်များ

- **ပရောဂျက်ဖိုင်များကိုယ်တိုင် ယခုထိ မဖွင့်နိုင်သေးပါ။** ၎င်းတို့၏ ဖော်မတ်ကို မထုတ်ပြန်ရသေးသဖြင့် BimCraft သည် ယခုထိ မဖတ်နိုင်သေးပါ။ ဖိုင်တစ်ခုကို ဖွင့်သောအခါ BimCraft က ထိုအကြောင်း ပြပြီး ဤစာမျက်နှာကို ညွှန်ပြမည်။
- **BimCraft သည် ဖိုင်၏ ပထမ bytes များကို စစ်ဆေးသည်။** Archicad ပရောဂျက်များ (version 17 မှစ၍) သည် တူညီသော တိုတောင်းသော signature ဖြင့် စတင်သဖြင့် ဖိုင်တစ်ခုသည် Archicad ပရောဂျက် ဖြစ်ကြောင်း BimCraft က သေချာစွာ ပြနိုင်သည်။ Archicad အမည်ရှိသော်လည်း ထိုသို့ မစသော ဖိုင်သည် အမည်ပြောင်းထားခြင်း၊ ပျက်စီးခြင်း သို့မဟုတ် ဗားရှင်းဟောင်းမှ ဖြစ်ခြင်း ဖြစ်နိုင်သည်။ Signature သည် ပရောဂျက်၊ archive နှင့် template ကို ခွဲခြားပေးမည် မဟုတ်ပါ။
- **IFC export** ဖိုင်သည် အပြည့်အဝ ဖွင့်နိုင်သည်: 3D မော်ဒယ်၊ storey များ၊ zone များကို space အဖြစ်၊ element data၊ property set များနှင့် classification များ၊ BimCraft ကိရိယာအားလုံးနှင့်အတူ။
- **DWG export** ကို 2D view တွင် ဖွင့်နိုင်သည်၊ layer များနှင့် layout များပါဝင်ပြီး {{ui:3D}} တွင်လည်း ဖွင့်နိုင်သည်။ တည်းဖြတ်ရန် {{ui:CadCraft တွင် တည်းဖြတ်ရန်}} ကို အသုံးပြုပါ။

သို့မဟုတ် view များ၊ layout များနှင့် property group များပါသော ပရောဂျက် တစ်ခုလုံးကို zip တစ်ခုအဖြစ် ယူဆောင်နိုင်သည်: [ပရောဂျက် bundle ဖွင့်ခြင်း](topic:open-project-bundle) ကို ကြည့်ပါ။

## IFC ထုတ်ခြင်း (မော်ဒယ်)

1. Archicad တွင် ပရောဂျက်ကို ဖွင့်ပါ။
2. **File > Save As** ကို ရွေးပြီး ဖိုင်အမျိုးအစားအဖြစ် **IFC** ကို ရွေးပါ။
3. IFC translator ကို ရွေးပါ (IFC ထုတ်ရန် ဆက်တင်အစုတစ်ခုအတွက် Archicad ၏ အမည်ဖြစ်သည်)။ **IFC4 Reference View** သို့မဟုတ် **IFC2X3 Coordination View 2.0** တစ်ခုသည် BimCraft နှင့် ကိုက်ညီသည်။ IFC4X3 ကိုလည်း ဖွင့်နိုင်သည်။
4. ထုတ်ရန် အရာများကို ရွေးပါ: ပရောဂျက်တစ်ခုလုံး၊ သို့မဟုတ် သင်ကြည့်နေသော storey များပေါ်တွင် မြင်ရသော element များသာ။
5. သိမ်းပြီး BimCraft တွင် {{ui:Choose a file}} ကို နှိပ်ကာ `.ifc` ဖိုင်ကို ရွေးပါ။

ထုတ်ခင် translator ၏ ဆက်တင်များတွင် ဤအရာများကို စစ်ဆေးပါ:

- **Zone များ**: ၎င်းတို့ကို ထုတ်ပါ၊ ထို့ကြောင့် အခန်းများသည် space အဖြစ် ရောက်ရှိမည်။ BimCraft တွင် ၎င်းတို့ကို ကြည့်ရန် {{ui:Spaces}} ကို နှိပ်ပါ။
- **Property များနှင့် classification များ**: ၎င်းတို့ကို ထုတ်ပါ၊ ထို့ကြောင့် {{ui:Properties}} တွင် ပေါ်ပြီး {{ui:Find}}၊ {{ui:Color}} နှင့် {{ui:Quantity totals}} တွင် အသုံးပြုနိုင်မည်။
- **ရိုးရိုး `.ifc`** ဖြစ်ရမည်၊ `.ifczip` သို့မဟုတ် `.ifcxml` မဟုတ်ပါ။ BimCraft သည် ရိုးရိုး `.ifc` ကိုသာ ဖွင့်သည်။

## DWG ထုတ်ခြင်း (ပုံဆွဲများ)

1. သင်လိုချင်သော plan၊ section သို့မဟုတ် layout ကို ဖွင့်ပါ။
2. **File > Save As** ကို ရွေးပြီး ဖိုင်အမျိုးအစားအဖြစ် **DWG** ကို ရွေးပါ။
3. DXF-DWG translator ကို ရွေးပြီး သိမ်းပါ။
4. စာရွက်အစုလိုက်အတွက် Layout Book မှ layout များကို သိမ်းပါ၊ သို့မဟုတ် DWG အဖြစ် publish လုပ်ပါ။
5. `.dwg` ကို BimCraft တွင် ဖွင့်ပါ။ ထုတ်ချိန်က ချိတ်ဆက်ထားသော ပုံဆွဲများသည် တူညီသော ဖိုင်တွဲတွင် ရှိလျှင် ၎င်းနှင့်အတူ ဖွင့်မည်; [ချိတ်ဆက်ထားသော ပုံဆွဲများနှင့် ပုံများ](topic:dwg-linked-files) ကို ကြည့်ပါ။

## ပြဿနာ ဖြေရှင်းခြင်း

- **"… is an Archicad project: its first bytes say so."** အထက်ပါအတိုင်း IFC သို့မဟုတ် DWG ထုတ်ပြီး ထိုဖိုင်ကို ဖွင့်ပါ။
- **"… is named like an Archicad file but does not start like one."** ဖိုင်သည် ဘယ်မှ လာသည်ကို စစ်ဆေးပါ: အခြားအမျိုးအစား ဖိုင်ကို အမည်အသစ်ဖြင့် ပြောင်းထားခြင်း (မူလ extension ဖြင့် ဖွင့်ကြည့်ပါ)၊ မပြီးသေးသော မိတ္တူ၊ သို့မဟုတ် version 17 မတိုင်မီ ပရောဂျက် ဖြစ်နိုင်သည်။ ဖြစ်နိုင်လျှင် Archicad တွင် ဖွင့်ပြီး IFC သို့မဟုတ် DWG ထုတ်ပါ။
- **မော်ဒယ်ဖွင့်သော်လည်း အခန်းများ မပါပါ။** Zone များ မထုတ်ခဲ့ပါ။ IFC translator တွင် ၎င်းတို့ကို ဖွင့်ပြီး ထပ်မံ ထုတ်ပါ။
- **အဖွင့်များ မဖြတ်ရသေးပါ။** BimCraft က ၎င်းကို {{ui:File}} panel ရှိ **မဆွဲရသေးပါ** အောက်တွင် ပြသည်။ ထပ်မံ ထုတ်ပါ; ဆက်ရှိနေလျှင် မော်ဒယ်ကို ဖန်တီးခဲ့သော program တွင် ဖွင့်ပြီး အဖွင့်များကို ထိုနေရာတွင် စစ်ဆေးပါ။
- **DWG ပေါ်ရှိ စာသား ကွဲပြားနေသည်။** ထုတ်ချိန်က BimCraft တွင် မရှိသော font များကို ထိန်းထားနိုင်သည်; BimCraft သည် စာသားကို ရိုးရှင်းသော sans-serif font ဖြင့် ဆွဲသည်။
