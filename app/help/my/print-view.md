## လုပ်ဆောင်မည့်အရာ

ပရင့်ထုတ်ခင် စာရွက်ပေါ်တွင် ဘယ်လို ပေါ်မည်ကို ကြည့်ပါ၊ ၎င်းကို ဖန်တီးခဲ့သော program မှ ထုတ်ရန် မလိုပါ: အဖြူပေါ် အနက်ရောင်၊ မျဉ်းအထူများ၏ အမှန်အထူဖြင့်၊ နှင့် ပရင့်မထုတ်ရန် သတ်မှတ်ထားသော layer များမပါဘဲ။

## အဆင့်များ

1. DWG သို့မဟုတ် DXF ပုံဆွဲကို ဖွင့်ပါ။
2. ပုံဆွဲအပေါ်ရှိ စာရွက် tab တစ်ခုကို နှိပ်ပါ။
3. Tab များ၏ အဆုံးရှိ {{ui:Print view}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{key:P}} ကို နှိပ်ပါ။
4. အသေးစိတ်ကို zoom ဝင်ကြည့်ပြီး လေးသော နှင့် ပေါ့သော မျဉ်းများကို နှိုင်းယှဉ်ပါ။
5. သာမန်အရောင်များသို့ ပြန်ရန် {{ui:Print view}} ကို ထပ်နှိပ်ပါ၊ သို့မဟုတ် {{key:P}} ကို ထပ်နှိပ်ပါ။

## သင်မြင်ရမည်များ

- အဖူးရောင် စာရွက်ကို ဖိုးမီးရောင်ခုံ (gray desk) ပေါ်တွင်၊ မျဉ်းနှင့် စာသားအားလုံး အနက်ရောင်၊ theme မည်သို့ပင် ဖြစ်စေ။
- မျဉ်းအထူများ: စာရွက်ပေါ်တွင် အထူတစ်ခုစီကို ၎င်း၏ အမှန်အထူဖြင့် ဆွဲသည်၊ ထို့ကြောင့် 0.5 mm မျဉ်းသည် 0.25 mm မျဉ်းထက် နှစ်ဆထူသည်၊ zoom မည်သို့ပင် ဖြစ်စေ။ မျဉ်းကို ၎င်း၏ screen အထူထက် ဘယ်တော့မှ ပိုပါးအောင် မဆွဲပါ။
- ပရင့်မထုတ်ရန် သတ်မှတ်ထားသော layer များနှင့် DEFPOINTS layer ကို ဖျောက်ထားသည်။
- {{ui:Print view}} ခလုတ်သည် နှိပ်ထားသည့် အခြေအနေတွင် ရှိနေသည်။ Print view သည် စာရွက်များ ပြောင်းသည့်အခါ သို့မဟုတ် အခြားပုံဆွဲ ဖွင့်သည့်အခါတွင်လည်း ဖွင့်ထားဆဲ ဖြစ်ပြီး ပိတ်မချင်း ဆက်ရှိနေမည်။

{{ui:Model}} တွင် print view သည် screen အထူများသာ သုံးသည် (ပါးလွှာသော မျဉ်းများ 1 pixel၊ ထူသောမျဉ်းများ အနည်းငယ် ထူသည်)၊ မော်ဒယ်နေရာတွင် စာရွက်အရွယ် မရှိသောကြောင့် ဖြစ်သည်။

## အမှားများ

- **ပရင့်ထုတ်မည်ဟု မျှော်လင့်ခြင်း။** Print view သည် အကြို ကြည့်ခြင်း ဖြစ်သည်။ ပရင့်ထုတ်ခြင်းနှင့် PDF export ကို BimCraft တွင် မတည်ဆောက်ရသေးပါ; ပုံဆွဲကို ဖန်တီးခဲ့သော program မှ ပရင့်ထုတ်ပါ။
- **Plot style များ ရမည်ဟု မျှော်လင့်ခြင်း။** Pen table များနှင့် plot style အရောင်များကို မဖတ်ပါ။ အားလုံးသည် ရိုးရိုး အနက်ရောင် ဖြစ်သည်။
- **စာရိုက်နေစဉ် P နှိပ်ခြင်း။** Field တစ်ခုတွင် စာရိုက်နေချိန်၊ သို့မဟုတ် equipment ဇယား ပြနေချိန်တွင် {{key:F}} နှင့် {{key:P}} သည် ဘာမျှ မလုပ်ပါ။
