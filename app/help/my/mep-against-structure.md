## သင်လုပ်ဆောင်မည့်အရာ

ဝန်ဆောင်မှုများ ဆောက်အအုံနှင့် ကိုက်ညီကြောင်း သေချာစေပါ၊ ဖွဲ့စည်းပုံထဲ ဝင်ရောက်နေသည့်အရာ၊ နီးကပ်လွန်းသည့်အရာ၊ နှင့် နံရံနှင့် slab များတွင် အပေါက်လိုအပ်သည့်နေရာများကို ကြည့်ပါ။ ဘယ်ဘက် panel ရှိ {{ui:ထိခိုက်မှု စစ်ဆေးခြင်း}} ကို ဖွင့်ပါ; **ဖွဲ့စည်းပုံနှင့် ဆန့်ကျင်သော ပိုက်နှင့် လေပိုက်များ** အပိုင်းသည် ပုံမှန် စစ်ဆေးချက်အောက်တွင် ရှိသည်။

## ပြင်းထန်သော ထိခိုက်မှုများ

set စာရင်း နှစ်ခုတွင် ယခု **ပိုက်နှင့် လေပိုက်များ**၊ **နံရံများ**၊ **Slab နှင့် ခေါင်မိုးများ**၊ **Beam များ**၊ **Column များ** နှင့် **ဖွဲ့စည်းပုံ** (လေးခုလုံး) ကိုပါ ပေးသည်၊ တစ်ခုစီတွင် element အရေအတွက် ပါသည်။ ပထမနှင့် နောက်ဆုံးကို ရွေးပြီး စစ်ဆေးချက် run ရန် {{ui:ပိုက်နှင့် duct များ × ဖွဲ့စည်းပုံ}} ကို နှိပ်ပါ; သို့မဟုတ် တွဲ မည်သည့်တစ်တွဲကိုမဆို ကိုယ်တိုင်ရွေးပြီး {{ui:လုပ်ဆောင်ရန်}} ကို နှိပ်ပါ။ [ထိခိုက်မှု စစ်ဆေးခြင်း](topic:clash-check) ကို ကြည့်ပါ။

## ခွာချိန်များ

ဝန်ဆောင်မှု အချို့သည် ၎င်းတို့ ပတ်လည်တွင် နေရာလိုအပ်သည်: ၎င်းတို့၏ insulation နှင့် အလုပ်လုပ်ရန် သို့မဟုတ် sleeve အတွက် နေရာ။

1. ဂုဏ်သတ္တိများ တွင် ပိုက် သို့မဟုတ် လေပိုက် run တစ်ခု၏ **Insulation** အထူကို ပေးပါ (ထိုအတွက် ဘာမျှ မဆွဲပါ)။
2. ထိခိုက်မှု စစ်ဆေးခြင်း တွင် **ပိုက်နှင့် လေပိုက် ပတ်လည် gap** (mm) ကို ရိုက်ပါ။
3. {{ui:ခွာချိန်များ စစ်ဆေးရန်}} ကို နှိပ်ပါ: နံရံ၊ slab၊ beam သို့မဟုတ် column နှင့် ၎င်း၏ insulation ပေါင်း gap ထက် နီးကပ်သော အပိုင်းတိုင်းကို ရှိသော အကွာအဝေးနှင့် လိုချင်သော အကွာအဝေးနှင့်အတူ စာရင်းပြုသည်။ မျဉ်းကြောင်းတစ်ခုကို နှိပ်ပြီး နှစ်ခုကို ကြည့်ပါ။

နံရံ သို့မဟုတ် slab ကို ဖြတ်သွားသော အပိုင်းသည် ခွာချိန် မဟုတ်ဘဲ အပေါက်ဖြစ်ပြီး ထိုနေရာတွင် အစား စာရင်းပြုသည်။

## လိုအပ်သော အပေါက်များ

{{ui:လိုအပ်သော အပေါက်များ}} ကို နှိပ်ပါ။ run ၏ အလယ်မျဉ်းသည် နံရံ သို့မဟုတ် slab ကို ဖြတ်သွားသည့်နေရာတွင် BimCraft က ၎င်းလိုအပ်သော အပေါက်ကို စာရင်းပြုသည်: ပိုက် သို့မဟုတ် လေပိုက် စက်ဝိုင်းဖြစ်လျှင် စက်ဝိုင်း၊ သို့မဟုတ် ထောင့်မှန်ဖြစ်ပြီး run ၏ ပြင်ပအရွယ်အစား ပေါင်း insulation နှစ်ဆ ပေါင်း gap နှစ်ဆ၊ run ဖြတ်သည့်နေရာတွင် အလယ်ဗဟိုရှိသည်။ မျဉ်းကြောင်းတစ်ခုကို နှိပ်ပြီး run နှင့် နံရံ သို့မဟုတ် slab ကို ကြည့်ပါ။

- {{ui:အပေါက်များ CSV အဖြစ်}}: အပေါက်တစ်ခုစီအတွက် မျဉ်းတစ်ကြောင်း၊ run၊ ၎င်း၏အရွယ်အစားနှင့် insulation၊ အပေါက်၏ အရွယ်အစား၊ ဖြတ်သွားသော element နှင့် ၎င်း၏ GlobalId၊ level၊ အလယ်ဗဟို၏ X၊ Y နှင့် Z၊ နှင့် run က ဘယ်လောက် ဖောက်ထွင်းသွားသည်။
- {{ui:အပေါက်များ BCF issue များအဖြစ်}}: အပေါက်တစ်ခုစီအတွက် issue တစ်ခု၊ ၎င်းကို ကြည့်သော camera၊ ရွေးထားသော run နှင့် element ပါဝင်သည်၊ ဖွဲ့စည်းပုံ engineer ၏ program အတွက်။

:::note
ဘာမျှ မဖြတ်ပါ: အပေါက်များသည် ၎င်းတို့ အရွယ်အစား သတ်မှတ်သူများအတွက် စာရင်းသာ ဖြစ်သည်။ gap ကို သင်ရိုက်ရမည်; အပေါက်ဘယ်လောက်ကြီးရမည်ကို ဘယ်ကုဒ်မှ မပြောပါ။ Beam နှင့် column များသည် အပေါက်မဟုတ်ဘဲ ထိခိုက်မှုများ ဖြစ်သည်; ပိုက်တစ်ခု ၎င်းကို ဖြတ်ခွင့်ရှိ/မရှိသည် ဖွဲ့စည်းပုံ engineer ၏ ဆုံးဖြတ်ချက် ဖြစ်သည်။
:::
