## သင်လုပ်မည့်အရာ

ဖွင့်ခြင်းအစား အဆောက်အအုံ မော်ဒယ်ကို အစမှ စတင်ပါ။ BimCraft သည် ပရောဂျက်၊ site၊ အဆောက်အအုံနှင့် ၎င်း၏ အထပ်များပါဝင်သော အလွတ် IFC မော်ဒယ်တစ်ခု ပြုလုပ်သည်။ စာကြည့်တိုက်မှ ပစ္စည်းများနှင့် ပရိဘောဂများကို အထပ်များပေါ်တွင် ထားနိုင်ပြီး IFC ဖိုင်အဖြစ် သိမ်းနိုင်သည်။

:::note
နံရံများကို ယခု ဆွဲနိုင်သည်။ [နံရံများ ဆွဲခြင်း](topic:draw-walls) ကို ကြည့်ပါ။ တံခါး၊ ပြတင်းပေါက်၊ ကြမ်းပြင်နှင့် ခေါင်မိုးများကို နောက်တွင် တည်ဆောက်နေဆဲ ဖြစ်သည်။
:::

## အဆင့်များ

1. **Open a file or folder** အောက်တွင် သို့မဟုတ် start page ပေါ်တွင် {{ui:အဆောက်အအုံအသစ်}} ကို နှိပ်ပါ။
2. **Building name** ကို ရိုက်ထည့်ပါ။
3. **Levels** အရေအတွက် (1 မှ 200) ကို ရွေးပါ။
4. **Level height** ကို ကြမ်းပြင်မှ ကြမ်းပြင်အထိ ရိုက်ထည့်ပါ။ ဥပမာ `10'-0"`၊ `10'6"` သို့မဟုတ် `3000 mm`။ ဂဏန်းတစ်ခုတည်းသည် US တွင် ပေ ဖြစ်ပြီး အခြားနေရာများတွင် မီလီမီတာ ဖြစ်သည်။
5. အကွက်အားလုံး ဖြည့်ပြီးသားဖြစ်သဖြင့် အားလုံးကို ထားခဲ့နိုင်သည်။ ၎င်းတို့အောက်ရှိ အကွန်အကန်က သင်စတင်မည့်အရာများကို ပြသည်။ ယူနစ်များ၊ နံရံ ကိရိယာက ပထမဆုံး ဆွဲမည့် **Wall type** (စာရင်းမှ အခြားတစ်ခု ရွေးနိုင်သည်) နှင့် ပထမ စာရွက်။
6. {{ui:ဖန်တီးရန်}} ကို နှိပ်ပါ။ အထပ်များကို 0 မှ စတင်ပြီး အထပ်တစ်ခုစီသည် ယခင်အထပ်အပေါ် အထပ်အမြင့်တစ်ခုစီဖြင့် ပေါ်တင်ထားသည်။ Level 1၊ Level 2 စသဖြင့် အမည်ပေးထားသည်။ ၎င်းတို့သည် မော်ဒယ် သစ်ပင်တွင် ပြသည်။ Level 1 ၏ plan သည် {{ui:ဆွဲရန်}} ဖွင့်ထားသည့် 3D view ဘေးတွင် ဖွင့်သည်။
7. နံရံများ ဆွဲပါ။ {{ui:နံရံ}} ကို နှိပ်ပြီး အမှတ်နှစ်ခု နှိပ်ပါ။ [နံရံများ ဆွဲခြင်း](topic:draw-walls) ကို ကြည့်ပါ။ **Levels** panel တွင် အထပ်များကို အမည်ပြောင်းခြင်း သို့မဟုတ် အမြင့်ပြောင်းခြင်း ပြုလုပ်နိုင်သည်။
8. ပစ္စည်းများ ထားပါ။ [စာကြည့်တိုက်မှ စက်ပစ္စည်းနှင့် ပရိဘောဂများ ထားခြင်း](topic:place-from-library) ကို ကြည့်ပါ။ placing bar တွင် အထပ်အားလုံး ပါဝင်သည်။
9. {{ui:IFC အဖြစ် သိမ်းရန်}} ကို နှိပ်ပါ။ ဖိုင်ကို အဆောက်အအုံ၏ အမည်ဖြင့် အမည်ပေးသည်။ ဥပမာ `Smith's house.ifc`။

## သိထားသင့်သည်များ

- မော်ဒယ်ကို မီလီမီတာဖြင့် IFC4 အဖြစ် သိမ်းသည်။ အခြား BIM ပရိုဂရမ်များက ဖွင့်နိုင်သည်။
- အဆောက်အအုံအသစ်တွင် စာရွက်တစ်ခု **A-101** ပါဝင်ပြီး အနိမ့်ဆုံးအထပ်၏ plan ကို ထားသည်။ မက်ထရစ်ယူနစ်ဖြင့် အလုပ်လုပ်လျှင် A3 ကို 1:100 ဖြင့်၊ မဟုတ်လျှင် Tabloid ကို 1/8" = 1'-0" ဖြင့်။ ပထမနံရံ မဆွဲမချင်း ဗလာဖြစ်ပြီး ဆွဲသည်နှင့်အမျှ plan ကို ပြသည်။ စာရွက်၏ ကော်ဇောကဒ်၊ scale သို့မဟုတ် ခေါင်းစဉ် ပြောင်းရန်၊ view ထည့်ရန် သို့မဟုတ် ဖျက်ရန် project browser ရှိ **Sheets** အောက်တွင် ဖွင့်ပါ။ template မှ စတင်သော အဆောက်အအုံသည် template ၏ စာရွက်များကို ယူလာသည်။
- အဆောက်အအုံအသစ်တိုင်း စတင်သည့်အရာ (မက်ထရစ်ပရောဂျက်အတွက် နံရံအမျိုးအစား၊ အထပ်များ၊ ပထမ စာရွက်၊ Create ပြီးနောက် တက်ကြွသော ကိရိယာ) ကို ပြောင်းလိုပါက [Default Policies](topic:default-policies) ကို ကြည့်ပါ။
- ပထမနံရံမတိုင်မီ ဘာမှ သတ်မှတ်စရာ မလိုပါ။ နံရံအမျိုးအစား၊ အထပ်အမြင့်များ၊ ယူနစ်များနှင့် စာရွက်တို့ကို နောက်မှ ပြောင်းနိုင်သည်။
- ဘယ်ဘက်ပြား၏ **Storeys** တွင် တစ်ခုခု ရှိသော အထပ်များကိုသာ ပြသည်။ မော်ဒယ်သစ်ပင်တွင် အားလုံး ပြသည်။
- သိမ်းမချင်း အဆောက်အအုံအသစ်ကို မသိမ်းရသေးသော အလုပ်အဖြစ် ရေတွက်သည်။ အခြားဖိုင် ဖွင့်ခြင်း သို့မဟုတ် ထွက်ခြင်းမတိုင်မီ BimCraft က မေးပြီး tab ပိတ်သွားလျှင် ဤ browser တွင် မိတ္တူတစ်ခု သိမ်းထားသည်။
