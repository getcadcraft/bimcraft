## လုပ်မည့်အရာ

BIM ပရောဂျက်များကို စီစဉ်သည့်နည်းအတိုင်း လုပ်ပါ: view အားလုံးကို စာရင်းတစ်ခုတည်းတွင်၊ plan တစ်ခုစီကို သင်ချင်သည့်နေရာတွင် ဖြတ်ထား၊ template မှတစ်ဆင့် plan များစွာအတွက် ဆက်တင် တူညီစွာ၊ နှင့် ကိုယ်တိုင် စီစဉ်သော sheet များ။

## project browser

1. {{ui:Draw}} ကို ဖွင့်ပါ။ ဘယ်ဘက် panel တွင် မော်ဒယ်များအောက်၌ {{ui:Project browser}} ရှိသည်။
2. ၎င်းတွင် အောက်ပါတို့ ပါဝင်သည်:
   - **Floor plans** (ကြမ်းပြင် plan များ): level တစ်ခုစီ။ တစ်ခုကို နှိပ်လျှင် ၎င်း၏ plan ကို ပြသည်။ ၎င်းဘေးရှိ slider ခလုတ်က view range ကို သတ်မှတ်သည် (အောက်တွင်)။ template ကို လိုက်သော plan က template ၏ အမည်ကို ပြသည်။
   - **Ceiling plans** (မျက်နှာကျင်ပုံများ): level တစ်ခုစီ၏ reflected ceiling plan (အောက်တွင်)။
   - **Callouts** (ချဲ့ပြချက်များ): ချဲ့ပြချက်တစ်ခုစီနှင့် ၎င်းရေးဆွဲထားသော view၊ နှင့် {{ui:New callout}}။ **Missing** (ပျောက်နေသည်) က view ပျောက်နေသော callout များကို စာရင်းပြသည်။
   - **Elevations** နှင့် **Sections**: မျက်နှာစည်းလေးဘက်နှင့် section line တိုင်း။ တစ်ခုကို နှိပ်လျှင် ၎င်းတို့ ဆွဲထားသော ပုံဆွဲအစုကို ဖွင့်သည်။
   - **3D views**: {{ui:Views}} ဖြင့် သိမ်းထားသော view များ။
   - **Schedules**: တစ်ခုကို နှိပ်လျှင် plan အောက်တွင် ပြသည်။
   - **Sheets**: သင်ပြုလုပ်ထားသော sheet များ၊ {{ui:New sheet}}၊ နှင့် မော်ဒယ်မှ ပြုလုပ်ထားသော အစုတစ်ခုလုံးအတွက် {{ui:Drawing set…}}။
   - **View templates** ({{ui:New template}} ဖြင့်) နှင့် **Links** (ချိတ်ဆက်ထားသော မော်ဒယ်များ)။

## plan ၏ view range ကို သတ်မှတ်ရန်

1. **Floor plans** အတွင်း level ဘေးရှိ slider ခလုတ်ကို နှိပ်ပါ။
2. ထို level အထက်ရှိ အမြင့်များကို သတ်မှတ်ပါ:
   - **Cut at** (ဖြတ်မည့်အမြင့်): plan က နံရံ၊ တံခါးနှင့် ပြတင်းပေါက်များကို ဖြတ်သည့်နေရာ (ပြောင်းမထားလျှင် 1200 mm၊ ခန့်မှန်း 4 ft)။
   - **Top** (အထက်ဆုံး): ဖြတ်ချက်အထက်နှင့် အထက်ဆုံးအောက်ရှိ အရာများကို မျဉ်းထိုးဖြင့် ဆွဲသည် (ဥပမာ အမြင့်ဗီရို၊ beam)။ level ၏ အမြင့်အတွက် ဗလာထားပါ။
   - **Bottom** နှင့် **Depth below the bottom** (အောက်ဆုံး နှင့် အောက်ဆုံးအောက် နက်နဲမှု): ဖြတ်ချက်ထက် နိမ့်သော အရာများကို အောက်ဆုံးအထိ နှင့် ထိုအောက်အထိ ပါးသော မျဉ်းများဖြင့် ဆွဲသည်။
3. **Shown in this plan** (ဤ plan တွင် ပြသည်များ) အောက်တွင် ဤ plan က ချန်ထားမည့်အရာများ (ပရိဘောဂ၊ အခန်းများ၊ ကော်လံများ စသည်) ကို ရှင်းပါ။
4. element တစ်ခုချင်းစီကို ဖျောက်ရန် plan သို့မဟုတ် 3D view တွင် ရွေး၍ dialog ကိုဖွင့်ပြီး {{ui:Hide the selected here}} ကို နှိပ်ပါ။ {{ui:Show them all}} က ပြန်ပြသည်။
5. {{ui:Use these settings}} ကို နှိပ်ပါ။

plan ကို ချက်ချင်း ထပ်ဖြတ်သည်၊ ပုံဆွဲအစုနှင့် သင့် sheet များလည်း လိုက်ပြောင်းသည်။ point cloud ၏ slice သည်လည်း ဖြတ်အမြင့်ကို လိုက်သည်။

## plan ကို crop လုပ်ခြင်း၊ စကေးပေးခြင်းနှင့် အောက်တွင် level နောက်တစ်ခု ပြခြင်း

သုံးခုလုံးသည် တူညီသော dialog တွင် ရှိသည် (level ဘေးရှိ slider ခလုတ်):

- **Scale** (စကေး): plan ပရင့်ထုတ်သည့် စကေး ({{ui:Print}} ကို plan ၏ bar တွင်) နှင့် sheet ပေါ်တွင် ကိုက်သော စကေး။ **Fit** (ကိုက်ညီအောင်) က အကြီးဆုံး စံစကေးကို ရွေးသည်။
- **Crop region** (crop ဒေသ): {{ui:Draw on the plan…}} ကို နှိပ်ပြီး plan ပေါ်တွင် ထောင့်တစ်ခုနှင့် ဆန့်ကျင်ဘက်ထောင့်ကို နှိပ်ပါ ({{key:Esc}} က ရပ်သည်)။ ဒေသအပြင် plan ကို screen တွင် ဖုံးထားပြီး ထိုနေရာတွင်လည်း လုပ်ဆောင်နိုင်သည်; ပရင့်ထုတ်သည့်အခါ၊ sheet များနှင့် ပုံဆွဲအစုတွင် ဒေသအတွင်းရှိသာ ပြသည်။ {{ui:Clear}} က crop ကို ဖယ်သည်။ {{ui:Fit}} က crop ကို ကိုက်ညီစေသည်။
- **Underlay** (အောက်ခံ): level နောက်တစ်ခု ရွေးပါ။ ၎င်း၏ နံရံများ၊ ဖြတ်ထားသော element များ၊ တံခါးနှင့် ပြတင်းပေါက်များကို ဤ plan အောက်တွင် ပါးပါးဖြင့် ဆွဲသည်၊ အောက်/အထက် level နှင့် ညီအောင်။ ဤနေရာတွင် ရွေး၍ မရပါ၊ ပရင့်ထုတ်သည့်အခါ မီးခိုးရောင်ပါးပါးဖြင့် ထွက်သည်။

view template တွင် စကေးကို အမြင့်နှင့် အမျိုးအစားများနှင့်အတူ သယ်သည်။ crop ဒေသနှင့် underlay သည် plan တစ်ခုတည်းအတွက်သာ ဖြစ်သည်။

## level ၏ မျက်နှာကျင်ပုံ

level တိုင်းတွင် ကြမ်းပြင် plan ဘေးတွင် reflected ceiling plan ရှိသည်: အောက်မှ ကြည့်သော plan၊ ခုံးမများနှင့် ၎င်းတို့မှ ကြိုးတွဲသော အရာများကို ပြင်ဆင်ရန်။

1. browser ရှိ **Ceiling plans** အောက်တွင် level ကို နှိပ်ပါ၊ သို့မဟုတ် plan ၏ bar တွင် level ဘေးရှိ {{ui:Ceiling plan}} ကို ရွေးပါ။
2. နံရံများကို 2300 mm (ခန့်မှန်း 7'-6") တွင် ဖြတ်သည်။ ထိုဖြတ်ချက်အထက်နှင့် level ၏ အမြင့်အောက်ရှိ အရာများ ဆွဲသည်: grid နှင့် အမြင့် tag (`CLG 2438`) ပါသော ခုံးမများ၊ မီးများ၊ beam များ။ တံခါး၊ ပြတင်းပေါက်နှင့် ဖြတ်ချက်အောက်ရှိ အရာများကို ချန်ထားသည်။
3. ခုံးမ ပြုလုပ်ရန် ကြမ်းပြင် plan ကဲ့သို့ {{ui:Ceiling}} ကို သုံးပြီး၊ ရွေးကာ Properties တွင် **Pattern** ကို ရွေးပါ။ See [အခန်းများ၊ ကြမ်းပြင်များ၊ ခုံးမများနှင့် အမိုးများ](topic:floors-and-roofs)။
4. ထိုမှ မီးကို ကြိုးတွဲရန် ခုံးမ plan ပြနေစဉ် library မှ ပစ္စည်းကို ထည့်ပါ: ၎င်းသည် **At the ceiling** ထဲ ရောက်သည်။ See [library မှ equipment နှင့် ပရိဘောဂများ ထားခြင်း](topic:place-from-library)။
5. ceiling plan ဘေးရှိ slider ခလုတ်က ၎င်း၏ ဖြတ်ချက်နှင့် အထက်ဆုံး၊ စကေး၊ အမျိုးအစားများ၊ crop ဒေသနှင့် underlay ကို ကြမ်းပြင် plan ကဲ့သို့ သတ်မှတ်သည်။ ceiling plan များသည် view template မယူပါ။

၎င်းကို ကြမ်းပြင် plan နှင့် တူသော ပုံစံဖြင့် ဆွဲသည် (reflected plan ဖြစ်ပြီး mirror image မဟုတ်ပါ)။ ဖြတ်ချက်ထက် နိမ့်သော ခုံးမကို မဆွဲပါ: ထို level ၏ ceiling plan အတွက် ဖြတ်ချက်ကို နိမ့်ချပါ။ Ceiling plan များသည် plan ကဲ့သို့ ကိုယ်ပိုင် sheet များပေါ် သွားသည်; ပုံဆွဲအစုက ၎င်းတို့ကို ကိုယ်တိုင် မထည့်ပါ။

## ချဲ့ပြချက် ပြုလုပ်ခြင်း

ချဲ့ပြချက်သည် plan ၏ အစိတ်အပိုင်းတစ်ခုကို ကိုယ်ပိုင်စကေးဖြင့် ပိုကြီးစွာ၊ ကိုယ်ပိုင် view အဖြစ် ပြသည်: မီးဖိုချောင်၊ လှေကား၊ နံရံထောင့်။

1. ၎င်းပိုင်သော plan၊ ceiling plan သို့မဟုတ် callout ကို ပြပါ။
2. plan ၏ bar တွင် {{ui:Annotate}} › {{ui:Callout}} ကို ရွေးပါ (သို့မဟုတ် browser ရှိ {{ui:New callout}}) ပြီးလျှင် နေရာ၏ ထောင့်တစ်ခုနှင့် ဆန့်ကျင်ဘက်ထောင့်ကို နှိပ်ပါ။ {{key:Esc}} က ရပ်သည်။
3. ချဲ့ပြချက်ကို 1:20 (feet နှင့် လက်မဖြင့် 1/2" = 1'-0") ဖြင့် ပြုလုပ်သည်။ ၎င်း၏ လေးထောင့်နှင့် စက်ဝိုင်း tag ကို plan ပေါ်တွင် ဆွဲသည်။
4. {{ui:Select}} ဖြင့် tag ကို နှိပ်ပါ၊ သို့မဟုတ် browser ရှိ callout ကို နှိပ်ပါ၊ ဖွင့်ရန်: plan က ထိုနေရာကိုသာ callout ၏ စကေးဖြင့် ပြသည်။ bar က {{ui:Callout:}} နှင့် ၎င်း၏ အမည်ကို ပြသည်; {{ui:Up}} က ၎င်းရေးဆွဲထားသော view သို့ ပြန်သည်။
5. callout ဘေးရှိ slider ခလုတ် (browser သို့မဟုတ် bar တွင်) က ၎င်းကို အမည်ပြောင်း၊ စကေးပြောင်း၊ လေးထောင့်ကို ပြန်ဆွဲ သို့မဟုတ် ဖျက်သည်။

callout သည် ၎င်း၏ view ပြသသည့်အရာကို ပြသည်: တူညီသော ဖြတ်ချက်၊ တူညီသော အမျိုးအစားများ၊ ceiling plan ၏ ခုံးမများ။ callout ၏ callout လည်း အလားတူ လုပ်သည်။ callout ကို sheet တွင် plan ကဲ့သို့ ထားပါ; ၎င်း၏ tag က ၎င်းနေရာကို ပြသသည် (`1 / A-501`: sheet A-501 ပေါ်ရှိ ပထမ view)။ callout တွင် {{ui:Print}} က ထိုနေရာကိုသာ ၎င်း၏ စကေးဖြင့် ပရင့်ထုတ်သည်။

callout ကို ဖျက်လျှင် ၎င်းအတွင်း ဆွဲထားသော callout များနှင့် ထိုအတွင်း ဆွဲထားသော မျဉ်းနှင့် hatch များလည်း ဖျက်သည် (အရင်မေးသည်)။ callout ရေးဆွဲထားသော level ကို ဖျက်လျှင် callout သည် ဖျက်သည်အထိ **Missing** အောက်တွင် ရှိနေပြီး ၎င်းပေါ်ရှိ sheet များက ပျောက်နေကြောင်း အစီရင်ခံသည်။

## view တစ်ခုတွင် မျဉ်းနှင့် hatch ဆွဲခြင်း

Drafting သည် view တစ်ခုတည်းနှင့်သာ သက်ဆိုင်သော 2D လုပ်ငန်းဖြစ်သည်: မျဉ်းဖြင့် မှတ်ချက်များ၊ ကွန်ကရစ် သို့မဟုတ် မြေဆီ၏ hatch ထားသော နေရာ၊ ဖြည့်ထားသော ဒေသ။ ၎င်းသည် 3D view တွင် ဘယ်တော့မှ မရှိ၊ တခြား plan တွင်လည်း ဘယ်တော့မှ မရှိပါ။

1. ဆွဲမည့် ကြမ်းပြင် plan၊ ceiling plan သို့မဟုတ် callout ကို ပြပါ။
2. plan ၏ bar ရှိ {{ui:Annotate}} မှ ရွေးပါ:
   - {{ui:Line}}: စသည့်နေရာနှင့် ဆုံးသည့်နေရာကို နှိပ်ပါ။ နောက်မျဉ်းသည် နောက်ဆုံးမျဉ်း ဆုံးသည့်နေရာမှ စတင်သည်; {{key:Enter}} က အစမှ ပြန်စတင်သည်။
   - {{ui:Polyline}}: ၎င်း၏ အမှတ်များကို နှိပ်ပါ; {{key:Enter}} သို့မဟုတ် နှစ်ကြိမ်နှိပ်ခြင်းက အဆုံးသတ်သည်၊ ပထမအမှတ်ကို နှိပ်လျှင် ပိတ်သည်။
   - {{ui:Rectangle}}: ဆန့်ကျင်ဘက် ထောင့်နှစ်ခု။
   - {{ui:Hatch region}}: bar တွင် **Pattern** (Solid၊ Diagonal၊ Cross-hatch၊ Concrete၊ Insulation၊ Earth) နှင့် ၎င်း၏ စကေးကို ရွေးပြီး ထောင့်များကို နှိပ်ပါ; {{key:Enter}}၊ နှစ်ကြိမ်နှိပ်ခြင်း သို့မဟုတ် ပထမထောင့်ကို နှိပ်ခြင်းက ပိတ်သည်။ {{ui:Fill a room}} ကို အမှန်ခြစ်ထားလျှင် အခန်းတစ်ခုတွင် နှိပ်တစ်ကြိမ်ဖြင့် ၎င်း၏ အစွန်းကို hatch ထားသည်။
3. နေရာချိန်ခြင်းသည် နံရံကဲ့သို့ ဖြစ်သည်; {{key:Shift}} က မျဉ်းကို ထောင့်မှန်ထားသည်၊ နံရံကဲ့သို့ အရှည်ကို ရိုက်ထည့်နိုင်သည်။ {{key:Backspace}} က နောက်ဆုံးအမှတ်ကို ပြန်ဖျက်သည်။

plan ပေါ်တွင် {{ui:Select}} ဖြင့် မျဉ်း သို့မဟုတ် hatch ကို ရွေးပါ။ Properties က hatch ၏ pattern နှင့် စကေးကို ပြောင်းပြီး {{ui:Move…}} ရှိသည် (ရွှေ့မည့် အမှတ်ကို နှိပ်ပြီး ဘယ်သို့ရွှေ့မည်)။ {{key:Delete}} က ဖျက်သည်။ မျဉ်း၊ hatch နှင့် ပြောင်းလဲမှု တိုင်းသည် အဆင့်တစ်ခုစီ ဖြစ်သည်။

မျဉ်းနှင့် hatch များကို plan နှင့်အတူ ပရင့်ထုတ်သည်၊ sheet များပေါ်သို့ လိုက်သွားပြီး ပုံဆွဲအစုတွင် ပါသည်။ view range တွင် **Annotations** ကို ရှင်းလိုက်လျှင် ထို view မှ ချန်ထားသည်။

## view template တွင် ဆက်တင်များ သိမ်းခြင်း

1. browser ရှိ {{ui:New template}} သို့မဟုတ် plan ၏ view range ရှိ {{ui:Save as a template…}} ကို နှိပ်ပါ (ထို plan က ထို template ကို သုံးသည်)။
2. အမည် ပေးပါ၊ အမြင့်နှင့် အမျိုးအစားများ သတ်မှတ်ပြီး {{ui:Save the template}} ကို နှိပ်ပါ။
3. plan မည်သည့် view range တွင်မဆို template ကို ရွေးပါ။ plan က ၎င်း၏ အမြင့်နှင့် အမျိုးအစားများကို ယူသည်; template ကို ပြောင်းလျှင် ၎င်းကို သုံးသော plan အားလုံး ပြောင်းသည်။ တစ်ခုချင်း ဖျောက်ထားသော element များက ၎င်း၏ကိုယ်ပိုင် plan တွင် ဖျောက်ထားဆဲ ဖြစ်သည်။
4. ပြောင်းရန်၊ အမည်ပြောင်းရန် သို့မဟုတ် ဖျက်ရန် browser ရှိ template ကို နှိပ်ပါ။ ဖျက်လျှင် ၎င်းနှင့်ချိတ်ထားသော plan များသည် ၎င်းတို့၏ ကိုယ်ပိုင် ဆက်တင်များကို ဆက်ထားသည်။

## ကိုယ်ပိုင် sheet တစ်ခု စီစဉ်ခြင်း

1. {{ui:New sheet}} ကို နှိပ်ပါ။ နံပါတ်နှင့် ခေါင်းစဉ် ရိုက်ပြီး စက္ကူကို ရွေးပါ။
2. plan၊ ceiling plan၊ callout၊ elevation၊ section သို့မဟုတ် schedule ဘေးရှိ {{ui:Add}} ကို နှိပ်ပါ။ sheet ၏ အလယ်တွင် ရောက်သည်။
3. ဆွဲ၍ နေရာချပါ။ ရွေးထားစဉ် **Scale** ကို ရွေးပါ၊ သို့မဟုတ် plan ၏ ကိုယ်ပိုင် စကေး (ရှိလျှင်) ၊ သို့မဟုတ် sheet ၏ သုံးပုံတစ်ပုံအတွက် ကိုက်ညီသော စကေးကို ထားပါ။ {{ui:Take off the sheet}} က ဖယ်ရှားသည်။
4. {{ui:Save the sheet}} ကို နှိပ်ပါ။ **Sheets** အောက်တွင် စာရင်းပါသည်; နောက်ပိုင်း ပြောင်းလိုလျှင် နှိပ်ပါ။
5. {{ui:Download as PDF}} က ထို sheet ကို စာမျက်နှာတစ်ခုအဖြစ် သိမ်းသည်။

## မြင်ရမည့်အရာများ

- သင့်အမြင့်တွင် ဖြတ်ထားသော plan များ၊ ဖြတ်ချက်အထက်ရှိ အရာများ dashed ဖြစ်ပြီး ရှင်းထားသည်များ ပျောက်နေ။
- crop ထားသော plan သည် screen တွင် ဒေသအပြင်ဘက် ဖုံးထားပြီး စက္ကူပေါ်တွင် ဒေသအတိုင်း ဖြတ်ထား၊ ပေးထားသော စကေးဖြင့်။
- ceiling grid နှင့် အမြင့် tag ပါသော ceiling plan၊ နှင့် ceiling တွင် မီးများ။
- plan ပေါ်တွင် ၎င်း၏ လေးထောင့်နှင့် tag ပါသော callout များ၊ ကိုယ်ပိုင်စကေးဖြင့် ဖွင့်သည်။
- မျဉ်းနှင့် hatch များကို ဆွဲခဲ့သော view တွင်သာ။
- သင့် sheet များကို ဖွင့်တိုင်း မော်ဒယ်မှ ပြန်ဆွဲသဖြင့် အမြဲ ကိုက်ညီသည်။ level သို့မဟုတ် section line ကို ဖျက်ထားသော view ကို မဆွဲဘဲ အစီရင်ခံသည်။
- ဤနေရာရှိ ပြောင်းလဲမှုတိုင်း တစ်ဆင့်ဖြစ်သည်: {{key:Mod+Z}} က ပြန်ဖျက်သည်။

:::note
ဤအရာအားလုံးကို IFC ဖိုင်တွင် အခြား programs က မထိသော ဂုဏ်သတ္တိအစုများအဖြစ် သိမ်းထားသည်: level တစ်ခုစီ၏ view range နှင့် ceiling plan ကို level ပေါ်တွင်၊ template များ၊ callout များနှင့် သင့် sheet များကို ပရောဂျက်ပေါ်တွင်။ မျဉ်းနှင့် hatch များသည် level ထဲရှိ IFC annotation များဖြစ်သဖြင့် အခြား programs က 2D curve နှင့် hatch ထားသော ဒေသများအဖြစ် မြင်သည် (pattern တစ်ခုစီ၏ ကိုယ်ပိုင် ပုံဖော်ပုံ)၊ သို့သော် မည်သည့် view နှင့် သက်ဆိုင်သည်ကို မသိပါ။
:::

:::tip
အခြား BIM programs များက ဖြတ်ချက်ကို view range သို့မဟုတ် cut plane ဟု ခေါ်၊ template များကို view template ဟု၊ drafting မျဉ်းများကို detail lines ဟု၊ hatch region ကို filled region ဟု ခေါ်သည်။ အယူအဆများ တူညီသည်; view ဆက်တင်များမှာ ၎င်းတို့ဆီ မသွားပါ။
:::
