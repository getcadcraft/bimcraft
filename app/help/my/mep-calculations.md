## သင်လုပ်ဆောင်မည့်အရာ

ပုံမှန်အတိုင်း ပိုက်များ၊ လေပိုက်များ၊ cable tray များနှင့် conduit များကို ဆွဲပါ၊ ထို့နောက် **တွက်ချက်မှု** pane ကို ဖွင့်ပါ။ tab တစ်ခုစီက မော်ဒယ်ကို ဖတ်ပြီး ဇယားတစ်ခု ပြကာ မှားနေသည့်အရာများကို ⚠ panel တွင် ပြဿနာများအဖြစ် စာရင်းပြုသည်။ အရွယ်အစားတစ်ခုက ပြဿနာတစ်ခုကို ပြင်နိုင်သည့်အခါ **အရွယ်အစားများ ကျင့်သုံးရန်** က run များကို undo အဆင့်တစ်ခုတည်းဖြင့် ပြောင်းပေးသည်။

ဤအရာများသည် ဒီဇိုင်းဆွဲခြင်း အကူအညီများသာ ဖြစ်ပါသည်။ ပုံသေတန်ဖိုး တိုင်းကို မျက်နှာပြင်ပေါ်တွင် အမှတ်အသားပြုထားပြီး တစ်ခုမျှ ကုဒ်ဇယား မဟုတ်ပါ: သင် ဒီဇိုင်းဆွဲသော စံနှုန်းမှ ဂဏန်းများကို ရိုက်ထည့်ပြီး ရလဒ်ကို ၎င်းအတွက် တာဝန်ရှိသော engineer က သုံးသပ်စေပါ။

## ပိုက်များ

1. **စနစ်** key ကို ရွေးပါ (အအေးရေက `cw`၊ အပူရေက `hw`)။
2. အမြင့်ဆုံး အမြန်နှုန်းကို သတ်မှတ်ပါ၊ ဖိအားကို စစ်လိုလျှင် အရင်းအမြစ်ရှိ ဖိအားနှင့် fixture တစ်ခုလိုအပ်သော အနည်းဆုံး ဖိအားကို သတ်မှတ်ပါ။
3. {{ui:စစ်ဆေးရန်}} ကို နှိပ်ပါ။

ပိုက်တိုင်းသည် ၎င်းအောက်ရှိ fixture units များ၏ ဝန်ကို သယ်ဆောင်သည်။ ဝန်သည် Hunter ဖော်ပြခဲ့သည့်နည်းအတိုင်း fixture units နှင့် စီးဆင်းမှု ကွေးကောက်မျဉ်းမှ လာသည်။ **တည်ဆောက်ပြီးသား ကွေးကောက်မျဉ်းသည် ဥပမာသာ ဖြစ်ပြီး ကုဒ်ဇယား မဟုတ်ပါ**; သင့်ကိုယ်ပိုင် ရိုက်ထည့်သည်အထိ ပြဿနာများက ထိုအတိုင်း ပြောပါလိမ့်မည်။ ပွတ်တိုက်မှုသည် Hazen–Williams ဖြစ်ပြီး fittings များသည် loss coefficient များ ဖြစ်သည်၊ အတက်အမြင့်တစ်မီတာလျှင် 9.8 kPa ကုန်သည်။ fixture တစ်ခု၏ units များသည် ၎င်း၏အမျိုးအစားမှ သို့မဟုတ် assistant tool `loads_set` ဖြင့် သင်သတ်မှတ်သော ဂဏန်းမှ လာသည်။

## လေပိုက်များ

စနစ်၊ ပွတ်တိုက်နှုန်း (equal friction) သို့မဟုတ် အမြန်နှုန်း၊ နှင့် coil၊ filter သို့မဟုတ် silencer ဆုံးရှုံးမှုကို သတ်မှတ်ပါ။ Terminal များသည် diffuser ပေါ်ရှိ `loads_set` မှ ၎င်းတို့၏ လေစီးဆင်းမှုကို ယူသည်။ ဇယားက အစိတ်အပိုင်းတစ်ခုစီအတွက် အမြန်နှုန်းနှင့် ပွတ်တိုက်မှုကို ပြသည်၊ အရေးကြီးသော လမ်းကြောင်းရှိ **fan ဖိအား** နှင့် အခြား terminal တစ်ခုစီ၏ damper က ယူရမည့် ဖိအားကို ပြသည်။ fitting ဆုံးရှုံးမှုများသည် အဝိုင်းပြုထားသော ပုံသေ coefficient များကို သုံးသည်၊ fitting database မဟုတ်ပါ။

## Cable tray နှင့် conduit များ

လေပိုက် tool ဖြင့် ဆွဲပါ: **Cable tray** နှင့် **Conduit** စနစ်များကို cable carrier အဖြစ် သိမ်းထားသဖြင့် အခြား program များက tray နှင့် conduit အဖြစ် ဖတ်သည်။ Cables tab တွင် ကေဘယ်စာရင်း (tag၊ ပြင်ပ အချင်း mm၊ အရေအတွက်၊ from၊ to) ကို paste လုပ်ပါ။ `from` နှင့် `to` သည် စက်ပစ္စည်းတစ်ခု၏ tag သို့မဟုတ် မီလီမီတာဖြင့် အမှတ် `x,y,z` ဖြစ်သည်။ ကေဘယ်များသည် tray နှင့် conduit များမှတစ်ဆင့် အတိုဆုံး ဆက်တိုက် လမ်းကြောင်းကို လိုက်သည်; run တစ်ခုစီက သင်ရိုက်ထည့်သော ကန့်သတ်ချက်များနှင့် နှိုင်းယှဉ်ပြီး ၎င်း၏ ဖြည့်မှုကို ပြသည်၊ ဇယားကို slack ရာခိုင်နှုန်းနှင့် အဆုံးများ ပါဝင်သော အရှည်ဖြင့် CSV အဖြစ် သိမ်းသည်။

## မီးရောင်

luminaire တစ်ခုစီကို `photometry_set` assistant tool ဖြင့် ၎င်း၏ IES (LM-63) သို့မဟုတ် EULUMDAT ဖိုင် ပေးပါ။ ပစ်မှတ်များ၊ grid အကွာအဝေးနှင့် workplane အမြင့်ကို ရိုက်ထည့်ပါ။ ရလဒ်သည် **တိုက်ရိုက်** illuminance သာ ဖြစ်သည်: ပြန်လည်ရောင်ပြန်ဟပ်မှု မပါ၊ အရိပ် မပါ၊ ထို့ကြောင့် အခန်းတစ်ခုတွင် အနိမ့်ဆုံး ခန့်မှန်းချက် ဖြစ်သည်။

## မီးသတ် sprinkler များ

**မီးသတ် sprinkler** ထပ်ဆောင်း၌ ကိုယ်ပိုင် tab ရှိသည်; ၎င်း၏ အကူအညီကို ကြည့်ပါ။
