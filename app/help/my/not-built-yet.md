ယနေ့ BimCraft သည် ဖတ်ကိရိယာ၊ စစ်ဆေးကိရိယာနှင့် IFC ဒေတာ တည်းဖြတ်ကိရိယာ ဖြစ်ပြီး အဆောက်အအုံများကို ဆွဲရန် စတင်ထားသည်: နံရံများ၊ တံခါးနှင့် ပြတင်းပေါက်များ၊ အခန်းများ၊ ကြမ်းပြင်များ၊ မျက်နှာကြက်များနှင့် ခေါင်မိုးများ ([နံရံဆွဲခြင်း](topic:draw-walls)၊ [တံခါးနှင့် ပြတင်းပေါက်များ](topic:doors-and-windows) နှင့် [အခန်းများ၊ ကြမ်းပြင်များ၊ မျက်နှာကြက်များနှင့် ခေါင်မိုးများ](topic:floors-and-roofs) ကို ကြည့်ပါ)။ ဤသည်မှာ ယခုထိ မလုပ်နိုင်သေးသည်များ၏ ရိုးသား စာရင်းဖြစ်ပြီး အစားထိုး ဘာလုပ်ရမည်ကို ဖော်ပြထားသည်။

## မော်ဒယ်ဆွဲခြင်းနှင့် ဖန်တီးခြင်း

| မရသေးသည် | ယနေ့ အစားထိုး |
|---|---|
| beam ဆွဲခြင်း; သံမဏိ အပိုင်းအစ ကော်လံများ | သင့် authoring program ဖြင့် လုပ်ပြီး ၎င်း၏ IFC export ကို ဤနေရာတွင် ဖွင့်ပါ။ ထောင့်စတုဂံနှင့် စက်ဝိုင်း ကော်လံများကို ဤနေရာတွင် ထားနိုင်သည် ([Grids and columns](topic:grids-and-columns) ကို ကြည့်ပါ); ဖြောင့်၊ L၊ U၊ winder နှင့် spiral လှေကားနှင့် လက်ရန်းများကို ဤနေရာတွင် ဆွဲနိုင်သည် ([Stairs and railings](topic:stairs-and-railings) ကို ကြည့်ပါ) |
| ဒောက်ဆာ (dormer) ရှေ့ရှိ ပြတင်းပေါက်; လက်ဖြင့် ဆွဲထားသော ခေါင်မိုးမျက်နှာပြင်ပေါ်ရှိ dormer များ; မွေ့ကွေးသော ခေါင်မိုးများ; render ပြုလုပ်ထားသော ခေါင်မိုး ကာထားသည့် texture | ထောင့်များဖြင့် ဆွဲထားသော ခေါင်မိုးမျက်နှာပြင်များနှင့် နံရံတစ်ခုစီအတွက် စောင်း: [Roofs: a pitch for each wall, gables, sheds and roof planes](topic:roofs) ကို ကြည့်ပါ |
| အခြားပရိုဂရမ်က ပြုလုပ်ထားသော နံရံ၊ တံခါး သို့မဟုတ် ပြတင်းပေါက်များကို ပြောင်းခြင်း | သင့် authoring program; ဆွဲကိရိယာများသည် ၎င်းတို့ ဆွဲထားသည့်အရာကိုသာ ပြောင်းသည် |
| အပြင်ထွက်နေသော သို့မဟုတ် အပေါက်ပါသော နံရံ ပုံသဏ္ဍာန်များ; စတုဂံ မဟုတ်သော နံရံအပေါက်များ; 3D view တွင် နံရံ၏ ပုံသဏ္ဍာန် အမှတ်များ ထည့်ခြင်း သို့မဟုတ် ဖယ်ခြင်း | Properties၊ elevation နှင့် section များတွင်၊ ၎င်း၏ မျက်နှာ view တွင်နှင့် 3D တွင် grip ဖြင့် ပုံသဏ္ဍာန်၊ ချိတ်ဆက်မှု၊ စောင်းနှင့် အပေါက်များ အလုပ်လုပ်သည်၊ ဖြောင့်နှင့် မွေ့ကွေးသော နံရံများအတွက်: [နံရံပုံသဏ္ဍာန် ပြင်ခြင်း: ချိတ်ဆက်၊ ပုံသဏ္ဍာန်၊ စောင်းနှင့် အပေါက်များ](topic:wall-shape) ကို ကြည့်ပါ |
| မွေ့ကွေးသော နံရံများတွင်: {{ui:Trim / extend}} နှင့် {{ui:Corner}}၊ framing၊ အလိုအလျောက် ပလန် အတိုင်းအတာများ၊ arc တလျှောက် ကပ်ခြင်း (၎င်း၏ အဆုံးနှင့် arc အလယ်သို့သာ ကပ်သည်) | ထိုအတွက် နံရံကို ဖြောင့်ဆွဲပါ၊ သို့မဟုတ် ဖြောင့်အပိုင်းများ သုံးပါ။ မွေ့ကွေးသော နံရံများကို [နံရံများ ဆွဲခြင်း](topic:draw-walls) တွင် ကြည့်ပါ |
| 3D view တွင် ထားထားသော စာကြည့်တိုက် ပစ္စည်းကို ဆွဲခြင်း | ပလန်တွင် ဆွဲပါ၊ သို့မဟုတ် {{ui:Properties}} တွင် X၊ Y နှင့် လှည့်ခြင်း (Rotation) ကို ရိုက်ပါ: [စာကြည့်တိုက်မှ စက်ကိရိယာနှင့် ပရိဘောဂ ထားခြင်း](topic:place-from-library) ကို ကြည့်ပါ |
| CivilCraft ၏ Landscape workspace ၏ အပင်စာကြည့်တိုက်မှ အပင်များ ထားခြင်း | CivilCraft တွင် ထားပါ၊ သို့မဟုတ် စာကြည့်တိုက်၏ ပတ်ဝန်းကျင်ပစ္စည်း (entourage) မှ သစ်ပင်နှင့် ချုံပင်များကို ထားပါ: [စာကြည့်တိုက်မှ စက်ကိရိယာနှင့် ပရိဘောဂ ထားခြင်း](topic:place-from-library) ကို ကြည့်ပါ |
| Plant ထပ်ဆောင်းတွင် (ဖွင့်မှသာ ဖွင့်မည်): ပိုက်ကြောင်းကို မော်ဒယ်ထဲသို့ ဆွဲခြင်း၊ isometrics ပေါ်ရှိ spool နံပါတ်များ၊ စာကြည့်တိုက်မှ ထားသော စက်ကိရိယာများ၏ layout စစ်ဆေးခြင်း | {{ui:Pipe}} ဖြင့် ပိုက်ကြောင်းကို ဆွဲပါ ([Pipes and ducts](topic:pipes-and-ducts) ကို ကြည့်ပါ); layout စစ်ဆေးခြင်းသည် ထပ်ဆောင်း၏ ကိုယ်ပိုင် စက်ကိရိယာ ဇယားကို ဖတ်သည် |
| ဆွဲထားသော နံရံ၊ တံခါး၊ ပြတင်းပေါက် တစ်ခုချင်းစီကို လှည့်ခြင်း၊ ထင်ဟပ်ပြောင်းခြင်း သို့မဟုတ် array ပြုခြင်း (နံရံများ Move၊ Offset နှင့် Box stretch ဖြင့် ရွှေ့နှင့် ကူးနိုင်သည်: [Wall shapes, split, offset, stretch and lock](topic:wall-tools) ကို ကြည့်ပါ); မွေ့ကွေးသော နံရံ သို့မဟုတ် နံရံသုံးခု သို့မဟုတ် ထို့ထက်ပိုသော ထောင့်များတွင် ချိတ်ဆက်ပုံစံ (butt၊ square off) (ကို [Wall shapes, split, offset, stretch and lock](topic:wall-tools) တွင် ကြည့်ပါ); Text ကိရိယာ; curtain walls | {{ui:Copy this level…}} ဖြင့် အထပ်တစ်ခုလုံးကို ကူးပါ ([Draw walls](topic:draw-walls#levels) ကို ကြည့်ပါ); မဟုတ်လျှင် ထပ်ဆွဲပါ |
| ပလန်နှင့် section တွင် ဆွဲထားသော နံရံ assembly အလွှာများ; section နှင့် elevation များတွင် အတိုင်းအတာများ; တံခါး၊ ပြတင်းပေါက်နှင့် အခြား အစိတ်အပိုင်းများသို့ အတိုင်းအတာ ရည်ညွှန်းချက်များ; assembly နှင့် membrane များကို schedule နှင့် quantities တွင်; ပရောဂျက်များကြား မျှဝေသော ပစ္စည်း စာကြည့်တိုက်; section၊ elevation နှင့် 3D တွင် အလွှာ ဦးစားပေးမှု နှင့် နံရံသုံးခု သို့မဟုတ် ထို့ထက်ပိုသော node များ (ပလန်တွင် ထောင့်၊ T ချိတ်ဆက်မှုနှင့် နံရံနှစ်ခု ဖြတ်ကျော်မှုများကို အလွှာ ဦးစားပေးမှုဖြင့် သန့်ရှင်းသည်: [Wall shapes, split, offset, stretch and lock](topic:wall-tools) ကို ကြည့်ပါ); ပတ်ထားသော သို့မဟုတ် ပြောင်းလဲနိုင်သော အလွှာများ; အခြားပရိုဂရမ်က ပြုလုပ်ထားသော နံရံ၏ assembly ကို တည်းဖြတ်ခြင်း | အလွှာများသည် နံရံအမျိုးအစားနှင့် ၎င်း၏ preview ({{ui:Wall assemblies…}}) တွင် ရှိသည်; နံရံများကို စုစုပေါင်း envelope တစ်ခုအဖြစ် တိုင်းသည်: [Wall assemblies and reference dimensions](topic:wall-assemblies) ကို ကြည့်ပါ |
| အစိတ်အပိုင်း၏ ပုံသဏ္ဍာန် သို့မဟုတ် အရွယ်အစား ပြောင်းခြင်း (ဤနေရာတွင် ဆွဲထားသော နံရံ၊ တံခါး၊ ပြတင်းပေါက်နှင့် family မှ ထားသော အစိတ်အပိုင်းများမှလွဲ၍) | သင့် authoring program။ ဖျက်ခြင်း၊ ဖြတ်ခြင်း၊ ကူးခြင်းနှင့် ကူးထည့်ခြင်းတို့သည် ဤနေရာတွင် အလုပ်လုပ်သည်: [အဆောက်အအုံ အစိတ်အပိုင်းများကို ဖျက်ခြင်း၊ ဖြတ်ခြင်း၊ ကူးခြင်းနှင့် ကူးထည့်ခြင်း](topic:edit-elements) ကို ကြည့်ပါ |
| အထပ်များ၊ နေရာများ၊ အဆောက်အအုံများ သို့မဟုတ် ဆိုဒ်ကို ဖျက်ခြင်း | ၎င်းတွင်ရှိသော အစိတ်အပိုင်းများကို ဖျက်ပါ |
| အဆောက်အအုံ အစိတ်အပိုင်းများကို အခြားမော်ဒယ်သို့ ကူးထည့်ခြင်း | မော်ဒယ်တစ်ခုတည်းအတွင်း ကူးပြီး ကူးထည့်ပါ; ထားထားသော စာကြည့်တိုက် ပစ္စည်းများသည် မော်ဒယ်မည်သည့်တစ်ခုသို့မဆို ကူးထည့်နိုင်သည် |
| ဂုဏ်သတ္တိအသစ်များ သို့မဟုတ် property set အသစ်များ ထည့်ခြင်း | ရှိပြီးသား တန်ဖိုးများကို ဤနေရာတွင် ဖြည့်ပါ၊ သို့မဟုတ် သင့် authoring program တွင် parameter ထည့်ပြီး ပြန် export လုပ်ပါ |
