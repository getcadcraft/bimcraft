## ဘာလုပ်မလဲ

သင် တည်ဆောက်မည့် နံရံနှင့် ကိုက်ညီသော နံရံအမျိုးအစားကို ပြုလုပ်ပါ: siding၊ sheathing၊ ၅½ လက်မ stud core နှင့် drywall၊ သို့မဟုတ် အုတ်၊ လေကွာဟချက်နှင့် သစ်ဘောင် နံရံ။ ဘယ်အလွှာများက core ဖြစ်သည်ကို အမှတ်အသားပြုပါ၊ ထို့ကြောင့် ၎င်းကို ဝန်းရံထားသော ပြီးစီးမှုအလွှာများ ပြောင်းသည့်အခါ အတိုင်းအတာ သို့မဟုတ် တည်နေရာမျဉ်းက core ကို ဆက်ထိန်းထားနိုင်မည်။ ထို့နောက် သင်ရည်ရွယ်သော မျက်နှာနှင့် အလယ်မျဉ်းများထံ နံရံများကို အတိုင်းအတာ ပေးပါ။

## နံရံအမျိုးအစား ဖန်တီးရန်

1. အဆောက်အအုံ စတင်ပါ သို့မဟုတ် IFC မော်ဒယ် ဖွင့်ပြီး {{ui:Draw}} ကို ဖွင့်ကာ {{ui:Wall}} tool ကို ရွေးပါ။
2. {{ui:Wall type}} တွင် starter တစ်ခု ရွေးပြီး {{ui:Wall assemblies…}} ကို ဖွင့်ပါ။ Starter သည် မိတ္တူအဖြစ် ဖွင့်မည်; အမျိုးအစား အသစ်အား အမည် ပေးပါ။
3. အလွှာများသည် စာရင်း၏ထိပ်ရှိ ပြင်ပမှ အောက်ခြေရှိ အတွင်းသို့ သွားသည်။ အလွှာတစ်ခုစီအတွက် ပစ္စည်းကို ရွေးပါ၊ အထူကို ရိုက်ထည့်ပါ (ပရောဂျက်ယူနစ်၊ သို့မဟုတ် `12.7 mm` သို့မဟုတ် `1/2"` ကဲ့သို့ သတ်မှတ်ထားသော တိကျသည့် အတိုင်းအတာ)၊ လုပ်ဆောင်ချက် (finish၊ substrate၊ structure၊ insulation၊ membrane) ကို ရွေးပြီး **Core** အလွှာများကို အမှန်ခြစ်ပါ။ Core သည် ဆက်တိုက်အုပ်စု တစ်ခုတည်း ဖြစ်ရမည်။
4. {{ui:Add layer}} က အလွှာ ထည့်သည်၊ {{ui:Add cavity}} က လေဝင်ပေါက် အခြေအနေ (မသတ်မှတ်ထား၊ လေမဝင်၊ လေဝင်သော) ပါသည့် လေကွာဟချက် ထည့်သည်၊ {{ui:Add membrane}} က အမည်ခံ အထူမရှိသော အလွှာ (ဥပမာ house wrap) ထည့်သည်။ မြားများက အလွှာကို အပြင် သို့မဟုတ် အတွင်းသို့ ရွှေ့သည်။
5. Preview က အလွှာများကို အတိုင်းအတာအတိုင်း ဆွဲပြပြီး core ကို မျဉ်းသားဖြင့် ဖော်ပြကာ အတန်းနံပါတ်အတိုင်း နံပါတ်ပေးသည်၊ အလွှာတစ်ခုချင်းစီ၊ core နှင့် စုစုပေါင်းကို အတိုင်းအတာ ပေးသည်။ {{ui:Save type}} ကို နှိပ်ပါ။

အမျိုးအစား အသစ်သည် Wall tool ၏ စာရင်းနှင့် ရွေးထားသော နံရံ၏ **Properties** တွင် ပေါ်လာမည်။ သင် ပြင်ဆင်သော အမျိုးအစားကို သိမ်းခြင်းသည် ထိုအမျိုးအစားကို သုံးသော နံရံအားလုံးကို ပြောင်းမည်; {{ui:Duplicate type}} က သီးခြား တစ်ခု ပြုလုပ်ပြီး ရွေးထားသော နံရံများသို့သာ ပေးမည်။ သိမ်းတိုင်းသည် undo အဆင့် တစ်ခု ဖြစ်ပြီး ၎င်းမှ ရွှေ့သော နံရံများ၊ ၎င်းတို့ထဲရှိ တံခါးနှင့် ပြတင်းပေါက်များ၊ ၎င်းပေါ် မူတည်သော အတိုင်းအတာများ ပါဝင်သည်။

လေအတွင်းခန်းသည် အကျယ်ကို တိုးစေသည်။ Membrane က ဘာမျှ မတိုးစေပါ: schedule က နောက်ပိုင်း ရှာနိုင်စေရန် အမျိုးအစားထဲတွင်သာ ရှိနေပြီး နံရံ သို့မဟုတ် core ၏ အထူတွင် မပါဝင်ပါ။ လေအတွင်းခန်း သို့မဟုတ် membrane ကို အစိုင်အခဲပစ္စည်းအဖြစ် ဘယ်တော့မှ မရေတွက်ပါ။ IFC2X3 အဖြစ် သိမ်းထားသော ဖိုင်တွင် membrane သည် အမျိုးအစား၏ မှတ်တမ်းတွင် ရှိနေသော်လည်း ၎င်း၏ physical material အလွှာများထဲမှ ချန်ထားသည်။

## အမျိုးအစားကို ဖွံ့ဖြိုးမှုအဆင့် (LOD) ဖြင့် အမှတ်အသားပြုရန်

အမျိုးအစားတစ်ခုက ၎င်း၏ ဖွံ့ဖြိုးမှု အဆင့်ကို ပြောနိုင်သည်။ Editor တွင် **Level of development (LOD)** က စကေး 100၊ 200၊ 300၊ 350၊ 400 နှင့် 500 ကို ပေးသည်၊ သို့မဟုတ် **မသတ်မှတ်ရသေး** ဟု ရွေးနိုင်သည်။ generic နံရံ ("Wall 230 generic") သည် LOD 100 သို့မဟုတ် 200 ဖြစ်ပြီး၊ အလွှာအစစ်ပါသော သတ်မှတ်ထားသည့် တည်ဆောက်ပုံ ("230 clay brick, plastered both sides") သည် LOD 300 သို့မဟုတ် ထို့ထက်မြင့်သည်။ အမှတ်အသားကို သင်ကိုယ်တိုင် သတ်မှတ်ရမည်: BimCraft က တွက်ချက်ပေးခြင်း မရှိပြီး starter အမျိုးအစားများတွင် အမှတ်အသား မရှိပါ။

အမှတ်အသားသည် Wall tool ၏ အမျိုးအစားစာရင်း၊ နံရံ၏ Properties နှင့် [Swap type](topic:wall-tools) စာရင်းတွင် အမည်ဘေးတွင် ပေါ်မည်ဖြစ်ပြီး၊ ပြောင်းပြီးနောက် report က အဆင့် မြင့်သွားခြင်း သို့မဟုတ် နိမ့်သွားခြင်းကို ပြမည်။ **Walls by type** schedule နှင့် ၎င်း၏ CSV တွင် မြင်ရန် Settings › BimCraft › Walls တွင် **Show each wall type's LOD in the wall schedule** ကို အမှန်ခြစ်ပါ: နောက်ဆုံး column တစ်ခု LOD ထပ်ထည့်မည်။ ၎င်းကို အမျိုးအစားနှင့်အတူ IFC ဖိုင်တွင် သိမ်းသည် (အမျိုးအစား၏ `CadCraft_WallType` property set ထဲတွင် `LOD` property အဖြစ်နှင့် အမျိုးအစား မှတ်တမ်းအတွင်း) ထို့ကြောင့် ဖိုင်ကို နောက်တစ်ကြိမ် ဖွင့်သည့်အခါ ရှိနေမည်။ အမှတ်အသားသည် ယခုအချိန်တွင် နံရံအမျိုးအစားများအပေါ်သာ ရှိပြီး တစ်ခုချင်း element သို့မဟုတ် အခြား element အမျိုးအစားများပေါ်တွင် မရှိသေးပါ။

## Sketch အဆင့်အတွက် generic နံရံများ

Wall tool ၏ Type စာရင်းသည် **generic** နံရံ နှစ်ခုဖြင့် စတင်သည်: **Generic wall 200 mm (exterior)** နှင့် **Generic wall 100 mm (interior)**။ ၎င်းတို့ တစ်ခုစီသည် generic ပစ္စည်း၏ အလွှာတစ်ခုဖြစ်ပြီး LOD 200 ဟု အမှတ်အသားပြုထားသည်။ နံရံများ ဘယ်နေရာရှိမည်ကို သိပြီး ဘာနဲ့ ဆောက်မည်ကို မသိသေးသောအခါ ၎င်းတို့ကို သုံးပါ။

LOD 100 သို့မဟုတ် LOD 200 ဟု အမှတ်အသားပြုထားသော အမျိုးအစားရှိ နံရံကို plan တိုင်းတွင် အကွက်ကျ hatched band **တစ်ခု** အဖြစ်၊ ဖော်ပြမှု အဆင့်မည်သည်ဖြစ်စေ ဆွဲမည်: အလွှာ မရှိ၊ အလွှာမျဉ်း မရှိ။ ၎င်းသည် generic နံရံများနှင့် သင် LOD 100 သို့မဟုတ် 200 ဟု အမှတ်အသားပြုသော ကိုယ်ပိုင်အမျိုးအစား မည်သည့်အရာမဆို အတွက် မှန်သည်။ နံရံသည် ပြည့်စုံပြီးသား ဖြစ်သည်: အထူ၊ တံခါးနှင့် ပြတင်းပေါက်များ၊ အခန်းများနှင့် ပမာဏများ ရှိသည်။

ဖွံ့ဖြိုးစေရန် ၎င်း၏ အမျိုးအစားကို ပြောင်းပါ (Edit › Walls › **Swap type**၊ သို့မဟုတ် Properties တွင် Type)။ နံရံကို နောက်တစ်ကြိမ် မဆွဲတော့ပါ: နံရံတူတူကပင် အမျိုးအစား အသစ်ကို ယူမည်ဖြစ်ပြီး report က ဘာရွှေ့သွားသလဲ ပြမည်။ LOD 300 သို့မဟုတ် ထို့ထက်မြင့်ဟု အမှတ်အသားပြုထားသော အမျိုးအစားကို အလွှာများနှင့်အတူ ယခင်အတိုင်း ဆွဲမည်။

အမှတ်အသားမည်သို့ပင် ဖြစ်စေ အလွှာအလိုက် နံရံအားလုံးကို ဆွဲလိုပါက: Settings › BimCraft › Walls တွင် **Draw walls of an LOD 100 or LOD 200 type as one hatched band** ကို အမှန်ဖြုတ်ပါ။

Starter တံခါးနှင့် ပြတင်းပေါက်များသည်လည်း generic အမျိုးအစားများ ဖြစ်သည် (ပမာဏနှင့် ဖွင့်ပုံ၊ ထုတ်ကုန် မဟုတ်ပါ)။ **Show each wall type's LOD in the wall schedule** ဖွင့်ထားလျှင် Doors နှင့် Windows schedule များက ၎င်းတို့အတွက် LOD 200 ပြမည်။

## အမျိုးအစားအတွက် takeoff ဒေတာ ထည့်ရန်

နံရံအမျိုးအစား တည်းဖြတ်သူတွင် **Takeoff data** က ခန့်မှန်းသူအတွက် လိုအပ်သော နံရံအကြောင်း အချက်အလက်ကို အမျိုးအစားတစ်ခုလျှင် တစ်ကြိမ် ယူသည်: တည်ဆောက်ထားသော **ယူနစ်** (အုတ် သို့မဟုတ် ဘလောက်၏ အမည်၊ အလျား၊ အမြင့်နှင့် အကျယ်)၊ **mortar** (အမည်နှင့် အဆစ် အထူ) နှင့် **rate** ကို ငွေကြေးကုဒ် (အက္ခရာသုံးလုံး၊ ဥပမာ USD၊ EUR သို့မဟုတ် ZAR) နှင့်အတူ၊ ၎င်း၏ အချိုးကို အခြေခံသည်: နံရံ net ဧရိယာ၏ စတုရန်းမီတာ သို့မဟုတ် စတုရန်းပေ၊ နံရံအလျား၏ မီတာ သို့မဟုတ် ပေ၊ သို့မဟုတ် နံရံတစ်ခုစီ။ အားလုံးက ရွေးချယ်စရာ ဖြစ်သည်။

ဤအချက်အလက်ကို ဖိုင်တွင် အမျိုးအစားနှင့်အတူ သိမ်းသည်။ အမျိုးအစား၏ နံရံတိုင်းက ၎င်းကို ပြန်ပြသည်: {{ui:Schedules}} › **Wall types: takeoff data** က ယူနစ်၊ mortar၊ rate နှင့် rate ကို တိုင်းတာထားသော ပမာဏဖြင့် မြှောက်ထားသည့် တန်ဖိုးကို ဖော်ပြပြီး TakeoffCraft သို့ ပေးသော takeoff သည် ထိုနံရံအမျိုးအစား၏ item တွင် ပါဝင်သည်။ အမျိုးအစားပေါ်တွင် ပြောင်းပါက နံရံအားလုံး လိုက်ပြောင်းမည်။

အုတ် သို့မဟုတ် ဘလောက်များနှင့် mortar ကို ရေတွက်ရန် အကွက်သုံးခု ထပ်ရှိသည်:

- **Waste on units, %** ကို ယူနစ် အရေအတွက်တွင် ပေါင်းထည့်သည်။ ပရောဂျက်၏ တိုင်းတာမှုနည်းလမ်း၏ ဂဏန်းကို သုံးရန် ဗလာထားပါ၊ နည်းလမ်းတွင် မရှိလျှင် ဘာမျှ မထည့်ပါ။ နည်းလမ်းက ဘာပြောပြောပင် စွန့်စားမှု မရှိစေလိုလျှင် 0 ရိုက်ထည့်ပါ။
- **Extra mortar, %** က mortar ဝင်သော frog သို့မဟုတ် အပေါက်များအတွက် ဖြစ်ပြီး mortar ထုထည်တွင် ပေါင်းထည့်သည်။ မရှိလျှင် ဗလာထားပါ။
- **Layers built of this unit**: ဤအုတ် သို့မဟုတ် ဘလောက်ဖြင့် ဆောက်ထားသော အလွှာတိုင်းကို အမှန်ခြစ်ပါ။ Cavity နံရံတွင် နှစ်ခုရှိသည်။ တစ်ခုမှ အမှန်မခြစ်ထားလျှင် core အလွှာများကို ရေတွက်သည်။

Rate ကို အမှာစာ ယူနစ်တစ်ခုလျှင်၊ အမှာစာ ယူနစ် 1000 လျှင် သို့မဟုတ် mortar m³ လျှင်လည်း ထားနိုင်သည်။ ယူနစ်တွင် အလျားနှင့် အမြင့် ရှိသည့်အခါ **Wall types: takeoff data** က leaf တစ်ခု၏ m² (သို့မဟုတ် ft²) လျှင် ယူနစ်များ၊ အမှာစာ ယူနစ်များနှင့် mortar ထုထည်ကို ပြသည်; ဖော်မြူလာများကို [Bricks, blocks and mortar](topic:plan-schedules-and-pdf#bricks-blocks-and-mortar) တွင် ရှာနိုင်သည်။ အမျိုးအစားတစ်ခုတွင် ယူနစ်တစ်မျိုးသာ ရှိသည်: leaf နှစ်ခု ကွဲပြားသော ယူနစ် (အပြင် leaf အုတ်နှင့် အတွင်း leaf ဘလောက်) ကို အမျိုးအစားတစ်ခုတည်းတွင် ယခုအချိန် မရေတွက်နိုင်သေးပါ။

## Core ကို မလှုပ်ရန် ထိန်းထားခြင်း

**Properties** တွင် နံရံ၏ **Location line** ကို core မျက်နှာ သို့မဟုတ် core အလယ်မျဉ်းသို့ သတ်မှတ်ပါ။ နောက်ပိုင်း ပြီးစီးမှုကို ထည့်သည် သို့မဟုတ် ထူစေသည့်အခါ ထိုမျဉ်းက နေရာတူ ရှိနေပြီး နံရံက ၎င်းပတ်လည် ကြီးထွားသည်; ထောင့်တွင် ထိုမျဉ်းနှင့် တွေ့သော နံရံများက လိုက်ပြောင်းသဖြင့် ဖြောင့်သော ထောင့်များ ပိတ်နေမည်။

## ပရောဂျက် ပစ္စည်းများ

{{ui:Material library…}} က ပရောဂျက်၏ ပစ္စည်းများကို ဖော်ပြသည်: အမည်၊ အမျိုးအစား၊ အလွှာ စတင်သော အထူ၊ ပြသရာ အရောင်၊ ဖြတ်ပိုင်း ဖြည့်ပုံစံ နှင့် မှတ်ချက်များ။ စာကြည့်တိုက်ကို ပရောဂျက်နှင့်အတူ IFC တွင် သိမ်းသည်။ အလွှာတစ်ခုအတွက် ပစ္စည်း ရွေးလျှင် ထိုအလွှာသည် ပစ္စည်း၏ မူလအထူကို ရယူပြီး ထို့နောက် ပြောင်းနိုင်သည်; နောက်ပိုင်း စာကြည့်တိုက်ကို တည်းဖြတ်ခြင်းက ရှိပြီးသား ဆွဲထားသော နံရံများကို ဘယ်တော့မှ အရွယ်မပြောင်းပါ။ Layer ၏ ပစ္စည်းစာရင်းမှ {{ui:+ New material…}} ဖြင့်လည်း ပစ္စည်း အသစ် ပြုလုပ်နိုင်သည်။

## ကိုးကားအတိုင်းအတာများ

{{ui:Annotate}} › {{ui:Reference dimension}}: horizontal၊ vertical သို့မဟုတ် aligned ကို ရွေးပြီး ကိုးကားချက် တစ်ခု ရွေးပါ: ပြင်ပ သို့မဟုတ် အတွင်း ပြီးစီးမှု မျက်နှာ၊ ပြင်ပ သို့မဟုတ် အတွင်း core မျက်နှာ၊ နံရံ အလယ်မျဉ်း သို့မဟုတ် core အလယ်မျဉ်း။ ပထမနံရံကို ရွေးပါ၊ လိုလျှင် ကိုးကားချက်ကို ပြောင်းပါ၊ ဒုတိယကို ရွေးပြီး အတိုင်းအတာမျဉ်း သွားရမည့်နေရာကို နှိပ်ပါ။ နံရံတစ်ခုတွင် ကိုးကားချက် နှစ်ခုက ၎င်း၏ စုစုပေါင်း သို့မဟုတ် core အထူကို တိုင်းသည်။ {{ui:Reference dimensions…}} က view ၏ အတိုင်းအတာများကို ပြသည်၊ နံရံ ဆုံးရှုံးသွားသော အတိုင်းအတာများ အပါအဝင်၊ Properties၊ Rebind references နှင့် Delete ဖြင့်။

### စည်းမျဉ်းဖြင့် plan တစ်ခုလုံး အတိုင်းအတာ ပေးရန်

{{ui:Annotate}} › {{ui:Dimension the plan…}} က သင်ကြည့်နေသော ကြမ်းပြင် plan ၏ ပြင်ပကို အတိုင်းအတာ ပေးသည်: အလျား တစ်ဖက်စီ၏ စုစုပေါင်း အရွယ်အစား၊ ပြင်ပ အစွန်းတစ်ခုစီတလျှောက် အတိုင်းအတာ တန်းတစ်တန်း (နံရံ အဆုံးများ၊ အစွန်းနှင့် တွေ့သော နံရံများနှင့် ၎င်းထဲရှိ တံခါးနှင့် ပြတင်းပေါက်များ)၊ အတန်းများကို အဆောက်အအုံနှင့် ရှင်းရှင်းလင်းလင်း ခွာထားသည်။ လိုချင်သည်များကို အမှန်ခြစ်၊ အရေအတွက် ဖတ်ပြီး၊ ထို့နောက် {{ui:Add the dimensions}} ကို နှိပ်ပါ။ ၎င်းတို့သည် ပုံမှန် ကိုးကားအတိုင်းအတာများ ဖြစ်သည်၊ ထို့ကြောင့် နံရံများ ရွှေ့သည့်အခါ လိုက်ပြောင်းပြီး ၎င်းတို့ထဲမှ မည်သည့်တစ်ခုကိုမဆို ရွေး၊ ရွှေ့ သို့မဟုတ် ဖျက်နိုင်သည်; အစုလိုက် တစ်ခုလုံးသည် undo အဆင့် တစ်ခုဖြစ်ပြီး ပြန်လုပ်ခြင်းက ထပ်တူ တစ်ခုမှ မထပ်ပေါင်းပါ။

ပြင်ပကိုသာ အတိုင်းအတာ ပေးသည်: အဆောက်အအုံ အတွင်းရှိ အခန်းများ၊ မျဉ်းကွေးနံရံများနှင့် plan နှင့် ထောင့်မှန်မဟုတ်သော နံရံများကို လက်ကိရိယာများအတွက် ထားခဲ့သည်၊ grid လိုင်းများသည် နံရံ မဟုတ်သဖြင့် grid များကြား အတိုင်းအတာကို ဤနေရာတွင် မပြုလုပ်ပါ။ ချိတ်ဆက်ထားသော assistant က `plan_dimension` ဖြင့် အလားတူ လုပ်နိုင်သည်။

အတိုင်းအတာသည် မျက်နှာပြင်ပေါ်ရှိ နေရာတစ်ခုကို မဟုတ်ဘဲ နံရံများကို ချိတ်ထားသည်: နံရံ ရွှေ့သည် သို့မဟုတ် ၎င်း၏ အမျိုးအစား ပြောင်းသည့်အခါ တန်ဖိုးသည် လိုက်ပြောင်းသည်။ နံရံ ဖျက်လိုက်ပါက အတိုင်းအတာသည် ဖြေရှင်းမရသေးကြောင်း ပြပြီး ဂဏန်းမပြရပါ၊ ပြန်ချိတ်သည် သို့မဟုတ် undo လုပ်သည်အထိ ဖြစ်သည်။ အလျား အကွက်သည် တိကျသော နေရာ အတွက် `10',12'` ကဲ့သို့ plan coordinates ကိုလည်း လက်ခံသည်။

အတိုင်းအတာများသည် BimCraft ဆွဲထားသော နံရံများအတွက် ဖြစ်ပြီး plan view များတွင်သာ။ ယခုမဆောက်ရသေးသည်: section နှင့် elevation များတွင် အတိုင်းအတာ၊ တံခါး၊ ပြတင်းပေါက်နှင့် အခြား အစိတ်အပိုင်းများသို့ အတိုင်းအတာ၊ plan နှင့် section တွင် ဆွဲသော assembly အလွှာများ; [ဘာကို မပြုလုပ်ရသေးသလဲ](topic:not-built-yet) ကို ကြည့်ပါ။
