ပုံစံသည် နှစ်ဆဆွဲကွင်း အကွက်များပါသော Markdown စာသားတစ်ခု ဖြစ်သည်။ BimCraft သည် အကွက်များကို ဖွင့်ထားသော မော်ဒယ်မှ (အရေအတွက်၊ အမျိုးအစားအလိုက် ပမာဏများ၊ ဂုဏ်သတ္တိများ၊ သင်၏ [တဂ်များ](topic:tags-and-schedules)) ဖြည့်ပြီး ရလဒ်ကို PDF၊ Word စာရွက်စာတမ်း (.docx) သို့မဟုတ် Markdown အဖြစ် သိမ်းသည်။

## အဆင့်များ

1. IFC မော်ဒယ်ကို ဖွင့်ပါ။
2. ဘယ်ဘက်အကန့်တွင်၊ {{ui:Quantities}} အောက်တွင် {{ui:Documents from the model}} ကို ဖွင့်ပါ။
3. ပုံစံတစ်ခု ရွေးပါ: {{ui:Doors and hardware}} သို့မဟုတ် {{ui:Walls, linings and finishes}}၊ သို့မဟုတ် သင့်ကိုယ်ပိုင်အတွက် {{ui:Load a template (.md)…}}။
4. ပုံစံက မော်ဒယ်မှ မသတ်မှတ်ရသေးသော တဂ်များကို ဖတ်လျှင် {{ui:Add this template’s tags}} ကို နှိပ်ပါ၊ ထို့နောက် {{ui:Tags}} အောက်တွင် ဒြပ်စင်များကို တဂ်ပါ။
5. စာသားကို နှစ်သက်ရာ ပြောင်းပြီး {{ui:Show the document}} ကို နှိပ်ပါ။
6. {{ui:PDF}} ကို နှိပ်ပါ (ရှေ့ဦးစွာ A4 သို့မဟုတ် Letter ကို ရွေးပါ) သို့မဟုတ် {{ui:Word (.docx)}}။

## သင်တွေ့ရမည့်အရာ

- ခလုတ်များအောက်တွင် ဖြည့်ပြီးသော စာရွက်စာတမ်း၊ ၎င်း၏ ဇယားများနှင့်အတူ။
- အကွက်ကို ဖတ်၍မရသောအခါ သတိပေးချက်စာရင်း (သတ်မှတ်မထားသော တဂ်၊ မော်ဒယ်တွင် မရှိသော ဂုဏ်သတ္တိ၊ ဘယ်တော့မှ မပိတ်သော block); ထိုအကွက်သည် `[?…]` ဟု ပုံနှိပ်သည်။
- PDF စာမျက်နှာများတွင် စာရွက်စာတမ်း၏ ခေါင်းစဉ်နှင့် စာမျက်နှာတိုင်း အောက်ခြေတွင် "Page 1 of 3"; ရှည်လျားသော ဇယားများသည် ၎င်းတို့၏ ခေါင်းစီးအတန်းဖြင့် ဆက်သွားသည်။

## အကွက်များ

| အကွက် | ပေးသည် |
|---|---|
| `{{project}}`, `{{project description}}`, `{{file}}`, `{{date}}` | ပရောဂျက်၏ အမည်နှင့် ဖော်ပြချက်၊ ဖိုင်အမည်၊ ယနေ့ |
| `{{count IfcDoor}}` | တံခါး အရေအတွက် |
| `{{sum IfcWall NetSideArea}}` | စုစုပေါင်း၊ ၎င်း၏ယူနစ်ဖြင့် |
| `{{calc [sum IfcWall NetSideArea] * 1.1 round 1 unit m²}}` | သင်္ချာ (`+ - * /` နှင့် ကွင်းများ) စတုရန်းကွင်းထဲရှိ အသုံးအနှုန်းများအပေါ်: `[sum …]`၊ `[count …]`၊ နှင့် each အတွင်း `[qty Width]`။ `round n` က ဒဿမနေရာများ သတ်မှတ်; `unit` က ယူနစ်ထည့်သည်။ ဖတ်၍မရသော အရာ သို့မဟုတ် သုညဖြင့် စားခြင်းက `[?…]` ပုံနှိပ်ပြီး သတိပေးသည် |
| `{{qty IfcWall NetSideArea by Type}}` | ဇယား: အမျိုးအစားတစ်ခုစီအတွက် အတန်းတစ်ခု၊ ၎င်း၏ အရေအတွက်နှင့် စုစုပေါင်း၊ နှင့် စုစုပေါင်းအတန်း |
| `{{table IfcDoor cols Mark, Type, Width, tag:Fire rating}}` | ဇယား၊ ဒြပ်စင်တစ်ခုစီအတွက် အတန်းတစ်ခု |
| `{{tag Finish}}` | loop အတွင်း၊ ဒြပ်စင်၏ တန်ဖိုး; အခြားနေရာတွင် သုံးထားသော တန်ဖိုးအားလုံး (Oak, Paint) |
| `{{tags}}` | တဂ်အဓိပ္ပာယ်ဖွင့်ဆိုချက်များကို ဇယားအဖြစ် |
| `{{#each IfcDoor}} … {{else}} … {{/each}}` | ဒြပ်စင်တစ်ခုစီအတွက် စာသား တစ်ကြိမ်; ဘာမှမရှိလျှင် `{{else}}` နောက်ပိုင်း |
| `{{#group IfcWall by Type}} … {{/group}}` | အမျိုးအစားတစ်ခုစီအတွက် စာသား တစ်ကြိမ်၊ `{{value}}`၊ `{{count}}`၊ `{{sum Length}}` နှင့် အတွင်း ရိုးရိုး `{{#each}}` ပါသည် |

`{{#each}}` အတွင်း: `{{name}}`၊ `{{type}}`၊ `{{storey}}`၊ `{{class}}`၊ `{{material}}`၊ `{{mark}}` (IFC Tag)၊ `{{guid}}`၊ `{{n}}` (1၊ 2၊ 3 …)၊ `{{prop Pset_DoorCommon.FireRating}}`၊ `{{qty Width}}` (ဒြပ်စင်ကိုယ်တိုင်၊ ယူနစ်ဖြင့်)။

class တစ်ခုတွင် အများအပြား ပါနိုင်သည် (`IfcDoor|IfcWindow`) သို့မဟုတ် ဒြပ်စင်အားလုံး (`*`)။ `where` ဖြင့် ကျဉ်းအောင် လုပ်နိုင်သည်: `{{#each IfcDoor where Fire rating >= 60}}`၊ `{{count IfcWall where Wall finish hasnot}}`။ စမ်းသပ်ချက်များမှာ `=`၊ `!=`၊ `~` (ပါဝင်သည်)၊ `>`၊ `<`၊ `>=`၊ `<=`၊ `has` နှင့် `hasnot`; အများအပြားကို `and` ဖြင့် ချိတ်ပါ; နေရာလွတ်ပါသော တန်ဖိုးကို "quotes" ထဲထည့်ပါ။ `sort Name` က loop ကို စီသည်။

## ဇယားများနှင့် စာရွက်စာတမ်းအတွင်းရှိ သတ်မှတ်ချက်

`{{schedule doors}}` သည် မော်ဒယ်ဇယားကို သင့်ရုံးပုံစံဖြင့် ဇယားအဖြစ် ပုံနှိပ်သည်: `doors`၊ `windows`၊ `walls`၊ `rooms`၊ `floors`၊ `roomfinishes`၊ `wallfinishes`၊ `zonefinishes`၊ `finishtotals`၊ `layers`၊ သို့မဟုတ် ဇယားများ တွင် သိမ်းထားသော ပုံစံအမည်။ `{{specification}}` က ပရောဂျက်၏ သတ်မှတ်ချက်ကို ပုံနှိပ်သည်။ **အလုပ်ပုံဆွဲဇယားများ** နှင့် **သတ်မှတ်ချက်** ပုံစံများက ၎င်းတို့ကို သုံးသည်။ ကြိုတင်ကြည့်ရှုမှုတွင် ထိုသို့ဇယား၏ ပုံကို နှိပ်လျှင် ၎င်းမှ ဆင်းသက်လာသော ဒြပ်စင်များကို ရွေးသည်။ [ဇယားကို ပုံစံချခြင်း၊ သိမ်းခြင်းနှင့် ထုတ်ခြင်း](topic:schedule-layouts) နှင့် [မော်ဒယ်မှ သတ်မှတ်ချက် ရေးခြင်း](topic:specification) ကို ကြည့်ပါ။

## သိထားသင့်သည်များ

- အကွက်တစ်ခုက built-in (Name၊ Type၊ Storey၊ Class၊ Material၊ Mark)၊ တဂ် (`tag:Fire rating`၊ သို့မဟုတ် ၎င်း၏အမည်)၊ ဂုဏ်သတ္တိ (`Pset_WallCommon.FireRating`) သို့မဟုတ် ဂုဏ်သတ္တိအမည်သာ (`NetSideArea`၊ `Width`) ကို အမည်ပေးသည်: အမည်သက်သက်သည် ဒြပ်စင်တစ်ခုစီ၏ကိုယ်ပိုင် set ကို ဖတ်သည်၊ ပမာဏ set များကို ဦးစွာ၊ ထို့ကြောင့် တံခါးပေါ်ရှိ `Width` သည် တံခါးအကျယ်ဖြစ်ပြီး နံရံထူ မဟုတ်ပါ။ `where` အတွင်း၊ အမည်သက်သက်သည် ရွေးထားသော ဒြပ်စင်အများစုရှိသော set ကို ဖတ်သည်။
- ပမာဏများသည် ဖိုင်၏ ပမာဏ set များ ပြောသည့်အရာဖြစ်သည် (BimCraft က ၎င်းဆွဲသည့်အတွက် ရေးသည်); ယူနစ်များသည် ဖိုင်၏ ယူနစ်ဆက်တင်များမှ လာသည်။
- အကွက်စကားလုံးများ (`count`၊ `sum`၊ `qty`၊ `by`၊ `cols`၊ `where`၊ `each`၊ `group` …) သည် ဘာသာတိုင်းတွင် အင်္ဂလိပ်အတိုင်း ဆက်ရှိသည်။ ဥပမာပုံစံများသည် အင်္ဂလိပ်ဖြစ်သည်။
- မော်ဒယ်မှ စာသားသည် ဖော်မတ် မဖြစ်ပါ: `*` သို့မဟုတ် `|` ပါသော အမည်ကို ဤအတိုင်း ပုံနှိပ်သည်။
- ပြောင်းလဲထားသော ပုံစံကို {{ui:Keep in this browser}} (ဤဘရောက်ဇာတွင်သာ ရှိသည်) သို့မဟုတ် {{ui:Download the template}} ဖြင့် သိမ်းပါ။
- PDF စာသားသည် စံ PDF ဖောင့်များကို သုံးသည်: ဥရောပအနောက်ပိုင်း စာသားပြင်ပ အက္ခရာသည် "?" ဟု ပုံနှိပ်ပြီး အခြေအနေလိုင်းက မည်မျှဖြစ်သည်ကို ပြောသည်။
- အလုပ်အမျိုးအစားအလိုက် ပုံစံများသည် Library တွင် ရှိသည် (အမျိုးအစား Document template)။ မော်ဒယ်မှ စာရွက်စာတမ်းများတွင်၊ From the Library… ကို ရွေး၊ တစ်ခု ရွေး၊ ၎င်း၏စာသားနှင့် ဖတ်သော တဂ်များ ဝင်လာသည်; နှစ်သက်ရာ တည်းဖြတ်ပါ။ သင့်ကိုယ်ပိုင် ပုံစံကို Library သို့ တင်ခြင်းသည် ပစ္စည်းအခြားတစ်ခုနှင့် တူညီသော အပ်လုဒ်ဖြစ်သည်။ မပြုလုပ်ရသေးသည်: အရေအတွက်နှင့် စုစုပေါင်းထက် ကျော်သော တွက်ချက်မှုများ။
