BimCraft သည် Chrome၊ Edge၊ Firefox နှင့် Safari ၏ လက်ရှိ ဗားရှင်းများတွင်၊ Mac၊ Windows နှင့် Linux ပေါ်တွင် အလုပ်လုပ်သည်။ 3D view သည် WebGL ကို လိုအပ်ပြီး လက်ရှိ ဘရောက်ဆာတိုင်းတွင် ရှိသည်။ အက်ပ်များ ယေဘုယျအားဖြင့် ဘာလိုအပ်သလဲ ကြည့်ရန် [ဘရောက်ဆာများနှင့် ကွန်ပျူတာများ](common:browsers) ကို ကြည့်ပါ။

## ဖိုဒါ ဖွင့်ခြင်း

| ဘရောက်ဆာ | {{ui:ဖိုဒါ ဖွင့်ရန်}} ၏ လုပ်ဆောင်ချက် | ဖိုဒါကို ဆွဲထည့်ခြင်း | {{ui:မကြာမီက ဖိုဒါများ}} |
|---|---|---|---|
| Chrome၊ Edge | ဘရောက်ဆာ၏ ဖိုဒါရွေးကိရိယာ၊ ထို့နောက် "Let site view files?": **View files** ကို နှိပ်ပါ | မေးခွန်းမရှိဘဲ ဖွင့်သည် | ရှိသည်၊ ရွေးထားသော သို့မဟုတ် ဆွဲထည့်ထားသော ဖိုဒါများအတွက် |
| Firefox | စနစ်၏ ဖိုဒါရွေးချယ်ကိရိယာ | မေးခွန်းမရှိဘဲ ဖွင့်သည် | မရှိပါ |
| Safari | စနစ်၏ ဖိုဒါရွေးချယ်ကိရိယာ၊ **Upload** ခလုတ်ပါသည် (တစ်စုံတစ်ရာ upload မလုပ်ပါ) | မေးခွန်းမရှိဘဲ ဖွင့်သည် | မရှိပါ |

နောက်ကွယ်တွင်: Chrome နှင့် Edge သည် File System Access ရွေးကိရိယာကို သုံးပြီး ဖိုဒါကို မှတ်သားနိုင်သည်။ Firefox နှင့် Safari သည် အဟောင်း ဖိုဒါရွေးကိရိယာကို သုံးပြီး ဖိုင်အားလုံးကို တစ်ကြိမ်တည်း ပေးသည်၊ ၎င်းကို မှတ်သား၍ မရပါ။ ဆွဲထည့်သော ဖိုဒါကို ဘရောက်ဆာတိုင်းတွင် entry တစ်ခုချင်းစီ ဖတ်သည်။

:::chromium
Brave နှင့် အခြား Chromium ဘရောက်ဆာအချို့သည် ဖိုဒါရွေးကိရိယာကို ပိတ်သည်။ ထိုအခါ BimCraft က စနစ်၏ ဖိုဒါရွေးကိရိယာကို သုံးပြီး ဘရောက်ဆာက "Upload *n* files to this site?" ဟု မေးနိုင်သည်။ တစ်စုံတစ်ရာ upload မလုပ်ပါ; ဖိုင်များသည် tab သို့သာ သွားသည်။ ဖိုဒါကို ဆွဲထည့်ခြင်းဖြင့် မေးခွန်းကို ရှောင်နိုင်သည်။
:::

## Mac၊ Windows နှင့် Linux

- {{key:Mod+S}} နှင့် {{key:Mod+Z}} ဟု ရေးထားသော ဖြတ်လမ်းများသည် Mac တွင် Command ဖြစ်ပြီး Windows နှင့် Linux တွင် Ctrl ဖြစ်သည်။
- {{key:Ctrl+Shift+F}} (screen modes) သည် Mac အပါအဝင် ပလက်ဖောင်းတိုင်းတွင် Control ဖြစ်သည်။
- ဖိုင်ဒိုင်ယာလော့ခ်နှင့် downloads ဖိုဒါသည် သင့်စနစ်၏ ကိုယ်ပိုင်ဖြစ်သည်။

## မောက်စ်၊ trackpad နှင့် touch

| ထည့်သွင်းမှု | 3D view | 2D ပုံဆွဲ |
|---|---|---|
| မောက်စ် | ဘယ်ဘက်ဆွဲခြင်းဖြင့် လှည့်၊ ညာဘက်ဆွဲခြင်းဖြင့် ရွှေ့၊ ဘီးဖြင့် zoom၊ နှိပ်ခြင်းဖြင့် ရွေး | မည်သည့် ဆွဲခြင်းမဆို ရွှေ့၊ ဘီးဖြင့် zoom၊ နှစ်ချက်နှိပ်ခြင်းဖြင့် {{ui:Fit}} |
| Trackpad | နှိပ်ဆွဲခြင်းဖြင့် လှည့်; {{key:Shift}} သို့မဟုတ် {{key:Mod}} နှင့် ဆွဲခြင်းဖြင့် ရွှေ့; လက်နှစ်ချောင်း scroll သို့မဟုတ် pinch ဖြင့် zoom | နှိပ်ဆွဲခြင်းဖြင့် ရွှေ့; လက်နှစ်ချောင်း scroll သို့မဟုတ် pinch ဖြင့် zoom |
| Touch | လက်တစ်ချောင်းဖြင့် လှည့်၊ လက်နှစ်ချောင်းဖြင့် pinch နှင့် ရွှေ့၊ ထိခြင်းဖြင့် ရွေး | လက်တစ်ချောင်းဖြင့် ရွှေ့; pinch zoom မရှိသေး; {{ui:Fit}} ကို ထိပါ |

Mac trackpad တွင် right-click သည် လက်နှစ်ချောင်း နှိပ်ခြင်း (သို့မဟုတ် Control-click) ဖြစ်သည်။ [ကီး၊ မောက်စ်နှင့် trackpad များ](common:keys) ကို ကြည့်ပါ။

တက်ဘလက်နှင့် ဖုန်းများသည် ဖိုင်တစ်ခုချင်းကို ဖွင့်ပြီး ကြည့်နိုင်သော်လည်း မျက်နှာပြင် သေးငယ်သည်၊ မိုဘိုင်းဘရောက်ဆာများစွာသည် ဖိုဒါ ရွေး၍မရပါ၊ နှင့် မော်ဒယ်ကြီးများသည် ၎င်းတို့၏ memory ထဲ မဝင်နိုင်ပါ။ ကွန်ပျူတာက အကောင်းဆုံး အလုပ်လုပ်သည်။

## ဖိုင်ကြီးများနှင့် memory

BimCraft ဖတ်သမျှ အရာအားလုံးသည် ဘရောက်ဆာ tab ၏ memory ထဲတွင် ရှိသည်။ tab က ဘယ်လောက် သုံးနိုင်သည်ဆိုတာသည် BimCraft ထက် ဘရောက်ဆာနှင့် ကွန်ပျူတာပေါ် မူတည်သည်။

| ဖိုင် | ဘယ်လောက် ဖတ်သလဲ | ဘာမျှော်ရမလဲ |
|---|---|---|
| IFC | ဖိုင်တစ်ခုလုံး၊ နှင့် ၎င်းမှ တည်ဆောက်ထားသော 3D ဂျီသြမေတြီ | ကွန်ပျူတာနှင့် ဘရောက်ဆာပေါ် မူတည်သည်; မေဂါဘိုက်ရာချီ မော်ဒယ်သည် လက်ပ်တော့အတွက် များလွန်းနိုင်သည်။ တြိဂံ ၁.၅ သန်းကျော်တွင် အစွန်းများ ပိတ်သည် |
| ပရောဂျက်နှင့် မိသားစု ဖိုင်များ | ခန့်မှန်း 40 KB မှ 100 KB၊ အရွယ်မရွေး | အလွန်ကြီးသော ဗဟို မော်ဒယ်များပင် ခဏတွင် ဖွင့်သည်၊ ကွန်ရက်ဒရိုက်မှလည်း |
| DWG နှင့် DXF | ဖိုင်တစ်ခုလုံး | အလွန်ကြီးသော ပုံဆွဲများတွင် "This drawing is very large; only part of it is shown." ဟု ပြသည် |
| ဖိုဒါများ | ဖိုင်စာရင်း၊ မော်ဒယ်တစ်ခုလျှင် ကီလိုဘိုက်အနည်းငယ် | ဖိုင် 20,000 အထိ |

ဘရောက်ဆာ tab က memory ကုန်သွားပါက ဘရောက်ဆာ၏ ကိုယ်ပိုင် error စာမျက်နှာ ပေါ်လာသည် (ဥပမာ Chrome တွင် "Aw, Snap!")။ အခြား tab များကို ပိတ်ပါ၊ BimCraft ကို ပြန်ဖွင့်ပြီး ထပ်ကြိုးစားပါ၊ သို့မဟုတ် memory ပိုရှိသော ကွန်ပျူတာကို သုံးပါ။
