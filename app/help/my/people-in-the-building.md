{{ui:အဆောက်အအုံထဲရှိ လူများ}} အပိုင်းသည် ဘယ်ဘက်ပြားတွင် ဖွင့်ထားသော IFC မော်ဒယ်၏ အခန်းများ၊ တံခါးများနှင့် လှေကားများမှတစ်ဆင့် လူများကို လျှောက်ပြသည်။ မော်ဒယ်ထဲရှိ မည်သည့်အရာမျှ မပြောင်းလဲပါ၊ မည်သည်ကိုမျှ upload မလုပ်ပါ။

:::warning
ဤသည်မှာ **ဒီဇိုင်း အကူအညီ တစ်ခုဖြစ်ပြီး မီးဘေးလုံခြုံရေး လက်မှတ် မဟုတ်ပါ**။ ၎င်းသည် မီး၊ မီးခိုး၊ ထိတ်လန့်မှု၊ လှုပ်ရှားနိုင်မှု ကွာခြားချက်များ သို့မဟုတ် ကုဒ်က သင့်အပေါ် ဘာတောင်းဆိုသည်ကို မသိပါ။ ကန့်သတ်ချက်များသည် သင့်ဆုံးဖြတ်ချက် ဖြစ်သည်: ထွက်ပေါက်သို့ အရှည်ဆုံး ခရီးနှင့် ရရှိနိုင်သော အချိန်များသည် သင်ရိုက်ထည့်သော ကိန်းဂဏန်းများ ဖြစ်ပြီး မည်သည်ကိုမျှ ယူဆချက် မပြုပါ။
:::

## လုပ်ဆောင်ရန်

1. အခန်းများနှင့် တံခါးများ ပိတ်ထားသော မော်ဒယ်တစ်ခုကို ဖွင့်ပါ။ တံခါးတစ်ဘက်တွင် အခန်းတစ်ခုသာ ရှိသော တံခါးသည် ထွက်ပေါက် ဖြစ်သည်; အခန်းနှစ်ခုကြား တံခါးသည် ၎င်းတို့ကို ချိတ်ဆက်သည်; လှေကားသည် ၎င်း၏ အဆုံးရှိ အခန်းများကို ချိတ်ဆက်သည်။
2. **Evacuation** (လူအားလုံး ထွက်ပေါက်သို့ လျှောက်သည်)၊ **Arrivals** (လူအားလုံး ဝင်ပြီး အခန်းသို့ လျှောက်သည်) သို့မဟုတ် **Exchange** (အခန်းရှိ လူများ ထွက်ခွာနေစဉ် အရေအတွက်အတိုင်း ဝင်လာသည်) ကို ရွေးပြီး လူတစ်ယောက်အတွက် ကြမ်းပြင်ဧရိယာကို ရိုက်ထည့်ပါ။ corridor၊ လှေကား၊ lobby သို့မဟုတ် အိမ်သာ ဟု အမည်ပေးထားသော အခန်းများတွင် မည်သူမျှ မရှိပါ။
3. {{ui:လုပ်ဆောင်ရန်}} ကို နှိပ်ပါ။ နောက်ဆုံးလူ ထွက်သွားသည့်အချိန် (တစ်ဝက်နှင့် ဆယ်ခုတွင် ကိုးခုအချိန်များလည်း) ကို ရမည်၊ တံခါးနှင့် လှေကားတိုင်းရှိ တန်းစီမှု၊ ခရီးအရှည်ဆုံးရှိသော အခန်းနှင့် run ကို ဖွင့်ပြသည့် ပလန်ကို ရမည်။

## what-if များ

ဇယားရှိ တံခါးပေါ်ရှိ {{ui:ပိတ်}} ကို အမှန်ခြစ်ပြီး ထပ် run ပါ: လူများက တခြားလမ်း ရှာသည်၊ သို့မဟုတ် ထွက်ပေါက်မရှိသော အခန်းများကို အမှားအဖြစ် စာရင်းပြုသည်။ နှစ်ဆ ကျယ်သော တံခါးသည် အခန်းကို ပိုမြန်စွာ ရှင်းသည်; ဇယားက တန်းစီမှုများ ရှိရာကို ပြသည်။

## အလုပ်လုပ်ပုံ

အခန်းတစ်ခုစီသည် grid တစ်ခုဖြစ်သည်၊ ထို့ကြောင့် လူများသည် နံရံများကို မဖြတ်ဘဲ ထောင့်များကို ကွေ့သွားသည်။ အခန်း ပြည့်လာသည်နှင့်အမျှ အမြန်နှုန်း ကျသည် (S = 1.4 (1 − 0.266 D) m/s, D သည် m² လျှင် လူ)။ တံခါး အကျယ် တစ်မီတာစီမှ စက္ကန့်လျှင် လူ 1.3 ဦး ဖြတ်သွားနိုင်ပြီး ဘက်တစ်ဘက်လျှင် 150 mm နုတ်သည်; လှေကားက 1.0 နှင့် ပိုနှေးသော လမ်းလျှောက်မှု ရှိသည်။ လူများက ဝင်လာသူ ဦးစားပေး တန်းစီသည်။ run နံပါတ်တစ်ခုက တူညီသော run ကို အတိအကျ ပြန်လုပ်သည်။

အကူအညီပေးသူ (assistant) သည် တူညီသော အရာကို run နိုင်သည်: အရေးပေါ်ထွက်ခွာခြင်း သို့မဟုတ် အခန်းတစ်ခုစီမှ ထွက်ပေါက်သို့ အရှည်ဆုံး ခရီးကို တောင်းဆိုပါ။

## အခန်းတစ်ခုစီရှိ လူများ

{{ui:အခန်းတစ်ခုစီရှိ လူများ}} ကို ဖွင့်ပြီး အခန်းတစ်ခုခုအတွက် နံပါတ် ရိုက်ထည့်ပါ။ အလွတ် အကွက်သည် ကြမ်းပြင်ဧရိယာ တန်ဖိုး (မီးခိုးရောင်ဖြင့် ပြသည်) ကို သုံးသည်; 0 သည် အခန်းကို ရှင်းသည်။ သင့်နံပါတ်များကို run အတွက် သုံးပြီး ဤ browser တွင် သိမ်းထားသည်။

## တံခါးများရှိ ဆန့်ကျင်ဘက် စီးဆင်းမှု

**Exchange** တွင် ထွက်သွားသူများနှင့် ဝင်လာသူများသည် တံခါးတူတူတွင် တွေ့သည်။ တံခါးက နောက်ဆုံးလူ၏ နောက်တွင် နီးကပ်စွာ တစ်ဖက်သို့ ဖြတ်သွားသူကို ကျော်သည့်အခါ ၎င်း၏ နှုန်း၏ အစိတ်အပိုင်းကို ထိန်းထားသည် (ဤနေရာတွင် 0.8; ယူဆချက် တစ်ခုဖြစ်သည်၊ ထုတ်ပြန်ထားသော တန်ဖိုးများ ကွဲပြားသောကြောင့်)၊ ဇယားက ဦးတည်ချက် ပြောင်းလဲမှုများကို ရေတွက်သည်။ မကြာခဏ ဦးတည်ချက် ပြောင်းသော တံခါးကို **Problems** တွင် မှတ်ချက်အဖြစ် စာရင်းပြုသည်။

## လှေကားများနှင့် ကြမ်းပြင်ခုံများ

လှေကား၏ ကြမ်းပြင်ခုံ (landing) တိုင်းသည် လမ်းလျှောက်သူအား လှည့်ရန် စက္ကန့်တစ်ခု ကုန်စေသည် (ယူဆချက်)။ ဖြောင့်သော လှေကားတွင် မရှိ; L သို့မဟုတ် U ပုံ လှေကားတွင် တစ်ခုရှိသည်။ လှေကား၏ နှုန်းသည် ၎င်း၏ လှေကားခုံ၏ အကျယ်မှ ဆက်ရရှိသည်။

## 3D view တွင်

{{ui:လူများကို 3D view တွင် ပြရန်}} ကို အမှန်ခြစ်လိုက်လျှင် လမ်းလျှောက်သူများသည် မော်ဒယ်တွင် ပုံများအဖြစ် ပေါ်လာပြီး ၎င်းတို့ လုပ်နေသည့်အရာအလိုက် အရောင်ခွဲကာ run ကို ဖွင့်ချိန်တွင် ရွေ့လျားသည်။ မော်ဒယ်ထဲသို့ ဘာမျှ မထည့်ပါ။
