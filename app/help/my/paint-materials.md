{{ui:ဆေးသုတ်ရန်}} ကို toolbar ပေါ်တွင် နှိပ်လျှင် 3D view ၏ အပေါ်တွင် ပစ္စည်း စာကြည့်တိုက် ဖွင့်သည်: အုတ်နှင့် ဘလော့ခ်၊ siding၊ အမိုး၊ သစ်၊ ကျောက်၊ ကြွေပြား၊ ကွန်ကရစ်၊ stucco၊ မြေ၊ ဖန်နှင့် သံ။

## element များကို ဆေးသုတ်ရန်

1. {{ui:ဆေးသုတ်ရန်}} ကို နှိပ်ပါ။
2. ပစ္စည်းတစ်ခုကို နှိပ်ပါ။
3. 3D view ရှိ element များကို နှိပ်ပါ။ နှိပ်သမျှ element ကို ဆေးသုတ်သည်။

များစွာကို တစ်ပြိုင်နက် ဆေးရန် ၎င်းတို့ကို အရင် ရွေးပါ (နှိပ်ခြင်း၊ {{key:Ctrl}}+နှိပ်ခြင်း၊ သို့မဟုတ် [ရှာဖွေခြင်း](topic:find))၊ ထို့နောက် ပစ္စည်းကို နှိပ်ပါ: ရွေးထားသော element အားလုံးက တစ်ဆင့်တည်း ရရှိသည်။

element သည် 3D view တွင် ပစ္စည်း၏ အရောင်ကို ချက်ချင်း ပြသည်။ ၎င်း၏ texture ကို [rendered ပုံ](topic:render) တွင် ပြသည်။ {{key:Esc}} သို့မဟုတ် {{ui:ပိတ်ရန်}} ဖြင့် ဆေးသုတ်ခြင်း ပြီးဆုံးသည်။

## တစ်ဘက်တည်း ဆေးသုတ်ရန်

{{ui:နှိပ်ထားသော ဘက်ခြမ်းသာ}} ကို ရွေးပြီး သင်လိုချင်သော ဘက်ကို နှိပ်ပါ: နံရံ၏ အပြင်ဘက်ကို siding ဖြင့်၊ အတွင်းဘက်ကို အခြား finish ဖြင့်၊ ကြမ်းပြင်၏ အပေါ်ဘက်ကို သစ်ဖြင့် နှင့် အောက်ခြမ်းကို မူလအတိုင်း ထားခြင်း။ element ၏ ကျန်အပိုင်းသည် ၎င်း၏ ပစ္စည်းကို ဆက်ထားသည်။

ဘက်ကို element ၏ ကိုယ်ပိုင် ဦးတည်ချက်များမှ ရှာသောကြောင့် element ကို ရွှေ့ သို့မဟုတ် လှည့်သည့်အခါလည်း တူညီသော ဘက်ဖြစ်နေသည်။

ကြမ်းပြင်များကို အခန်းတစ်ခန်းချင်းစီ ဆေးရန် အခန်းတစ်ခုစီကို ကိုယ်ပိုင် ကြမ်းပြင် ပေးပါ ({{ui:ဆွဲရန်}} › {{ui:ကြမ်းပြင်}} › **ဤအခန်း**၊ [အခန်းများ၊ ကြမ်းပြင်များ၊ မျက်နှာကြက်များနှင့် ခေါင်မိုးများ](topic:floors-and-roofs) ကို ကြည့်ပါ)၊ ထို့နောက် ကြမ်းပြင်တစ်ခုစီ၏ အပေါ်ဘက်ကို ဆေးပါ။

## ပစ္စည်းကို ဖယ်ရှားရန်

အစင်းကြောင်းပါသော အရောင်နမူနာ ({{ui:ပစ္စည်း မရှိ}}) ကို နှိပ်ပြီး element ကို နှိပ်ပါ။ ဘက်များအပါအဝင် ၎င်းပေါ်ရှိ ပစ္စည်းအားလုံး ဖယ်သွားသည်။

## ဖိုင်တွင်

ဆေးသုတ်ခြင်းသည် IFC ကို ပြောင်းလဲသည် (ခြေလှမ်းတစ်ခုစီ၊ {{key:Ctrl+Z}} ဖြင့် ပြန်ဖျက်နိုင်သည်) နှင့် plain IFC အဖြစ် ဆက်နေသည်:

- ဆေးထားသော element တစ်ခုစီသည် ၎င်း၏ ပစ္စည်းကို အမည်ပေးသော property set `CadCraft_Render` ရရှိပြီး ဆေးထားသော ဘက်တစ်ဘက်စီအတွက် property တစ်ခုစီ ရရှိသည်။
- ၎င်း၏ body သည် ပစ္စည်း၏ အရောင်ပါသော surface style ရရှိသဖြင့် အခြား BIM ပရိုဂရမ်များက အရောင်ကို ပြသည်။ IFC4 တွင် style က texture ကိုပါ အမည်ပေးသည်။

BimCraft က သင်ဆေးထားသော နံရံကို ပုံသဏ္ဍာန် ပြောင်းသည့်အခါ (ဥပမာ ၎င်း၏ အဆုံးကို ရွှေ့သည်ဆိုပါစို့) နံရံသည် ၎င်း၏ ပစ္စည်းနှင့် အရောင်ကို ထိန်းထားသည်၊ BimCraft၊ ပုံများနှင့် အခြားပရိုဂရမ်များတွင်။

:::note
texture များကို BimCraft ကိုယ်တိုင် ဆွဲသည်: ၎င်းတို့သည် အင်တာနက်မရှိဘဲ အလုပ်လုပ်ပြီး မည်သည့်အတွက်မဆို အခမဲ့ သုံးနိုင်သည် (CC0)။ သင့်ကိုယ်ပိုင် ပုံ texture များကို ယခုထိ မပြုလုပ်ရသေးပါ။
:::

## 3D view ရှိ texture များ

ဆေးထားသော အုတ်နံရံသည် ၎င်း၏ အုတ်ခဲများ၊ သစ်ကြမ်းပြင်သည် ၎င်း၏ သစ်ပြားများကို ပစ္စည်း ဆေးတင်ပြီးချက်ချင်း အမှန်အရွယ်အစားဖြင့် ပြသည်။ အရောင်ပြား ရိုးရိုးကို ပြရန် Paint palette ရှိ **3D view တွင် texture များ ပြရန်** ကို ဖြုတ်ပါ (အလွန်ကြီးသော မော်ဒယ်သည် ၎င်းကို ကိုယ်တိုင် ပိတ်ပြီး ထိုအကြောင်း ပြောသည်)။ property ဖြင့် အရောင်ခွဲခြင်းသည် ၎င်း၏ ကိုယ်ပိုင် အရောင်များကို အမြဲပြသည်။ texture များကို ပရိုဂရမ်က ဆွဲသည်ဖြစ်၍ ဘာမျှ ဒေါင်းလုဒ် မလုပ်ပါ၊ rendered ပုံများနှင့် glTF ဖိုင်သည် ၎င်းတို့ကို ယခုနည်းတူ ထည့်ပါဝင်သည်။
