တိုက်ရိုက်ကြည့်ရှုမှုသည် မော်ဒယ်ကို အချိန်နှင့်တစ်ပြေးညီ ပုံစံဖြင့် ပြသသည်: ဝါဒ်ဖြစ်ရာ နေရာနှင့် ရက်စွဲမှ ကောင်းကင်နှင့် နေ၊ နေ၏ အရိပ်များ၊ ဒြပ်စင်များအတွက် သင်ပေးထားသော အရောင်နှင့် ပစ္စည်းများ၊ မီးများနှင့် နံရံနှင့် ကြမ်းပြင်များမှ ပြန်ရောင်သော အလင်းတို့ ဖြစ်သည်။ သင်ပြုသည့်အရာကို လိုက်ပါသည်: 3D view ကို လှည့်လျှင် ၎င်းလည်း လှည့်သည်၊ မော်ဒယ်ကို ပြောင်းလျှင် ခဏအကြာတွင် ပြောင်းလဲမှုကို ပြသည်။ မည်သည့်အရာမျှ အပ်လုဒ်မလုပ်ပါ။

ဤသည်မှာ [ပုံ ရေးဆွဲခြင်း](topic:render) နှင့် တူညီသော မြင်ကွင်း၊ အရောင်၊ မီးနှင့် နေကို ရေးဆွဲသည်; ပြီးပြည့်စုံသော ပုံအတွက် ထိုကိရိယာကို သုံးပါ။

## ဖွင့်ခြင်း

1. မော်ဒယ်တစ်ခု ဖွင့်ပြီး ကိရိယာဘားတွင် {{ui:တိုက်ရိုက်ကြည့်ရှုမှု}} ကို ရွေးပါ။ ပြတင်းသည် အက်ပ်ပေါ်တွင် ညာဘက်အောက်ထောင့်တွင် ဖွင့်သည်။
2. ၎င်းကို ရွှေ့ရန် ခေါင်းစဉ်ဘားကို ဆွဲပါ၊ ပိုကြီးစေရန် ထောင့်ကို ဆွဲဆန့်ပါ။
3. {{ui:တိုက်ရိုက်ကြည့်ရှုမှုကို ဝင်းဒိုးအသစ်တွင်}} (ဘေးရှိခလုတ်) သို့မဟုတ် ပြတင်းရှိ {{ui:ဝင်းဒိုးအသစ်}} သည် ၎င်းကို ကိုယ်ပိုင်ဝင်းဒိုးသို့ ရွှေ့ပြီး ဒုတိယ မျက်နှာပြင်အတွက် သုံးနိုင်သည်။ ဘရောင်ဇာက ပေါ့ပ်အပ် ဝင်းဒိုးများကို ပိတ်ထားလျှင် ပြတင်းအဖြစ် ဖွင့်သည်။
4. {{ui:ပိတ်ရန်}} သည် ပိတ်သည်။

## ထိန်းချုပ်မှုများ

| ထိန်းချုပ်မှု | ဘာလုပ်သလဲ |
|---|---|
| {{ui:ကြည့်ရှုမှုကို လိုက်ရန်}} | ဖွင့်ထားလျှင် တိုက်ရိုက်ကြည့်ရှုမှုသည် 3D view ကြည့်သည့်နေရာကို ကြည့်သည်။ လျှောက်လျှင် ၎င်း ပိတ်သွားသည် |
| {{ui:လျှောက်ရန်}} | မော်ဒယ်ထဲတွင် လျှောက်ကြည့်ရန် (အောက်တွင်) |
| {{ui:ဆွဲငင်အား}} | လျှောက်နေစဉ်: ကြမ်းပြင်များပေါ် ရပ်ပြီး လှေကား တက်သည်။ ပိတ်ထားလျှင်: ပျံသန်းသည် |
| {{ui:အချိန်}} | နေ့၏ နာရီ။ ဆွဲသည်နှင့် နေ ရွေ့သည် |
| {{ui:လ}} | လ၊ ဆောင်းနှင့် နွေရာသီတွင် နေကို မြင်နိုင်ရန် |
| {{ui:အရည်အသွေး}} | {{ui:ဤကွန်ပျူတာအတွက်}}၊ သို့မဟုတ် {{ui:နိမ့်}}၊ {{ui:အလယ်အလတ်}} သို့မဟုတ် {{ui:မြင့်}} |

အောက်ဆုံးလိုင်းတွင် ကြည့်ရှုမှုကို မည်သည်က ရေးဆွဲသည် (WebGPU သို့မဟုတ် WebGL 2)၊ အရည်အသွေးနှင့် ပြန်ရောင်အလင်းကို ပြသသည်။

## မော်ဒယ်ထဲတွင် လျှောက်ကြည့်ခြင်း

1. 3D view ကို သင်ရပ်ချင်သော နေရာသို့ လှည့်ပြီး {{ui:လျှောက်ရန်}} ကို ရွေးပါ။ ကြည့်ရှုမှု၏ မျက်စိအမှတ်အောက်ရှိ ကြမ်းပြင်ပေါ် ၁.၆ မီတာ အမြင့်ဖြင့် ရပ်သည်။
2. တိုက်ရိုက်ကြည့်ရှုမှုကို နှိပ်ပြီး {{key:W}} {{key:A}} {{key:S}} {{key:D}} သို့မဟုတ် မြား ခလုတ်များကို သုံးပါ။ ပြေးရန် {{key:Shift}} ကို ဖိထားပါ။ ပတ်ကြည့်ရန် ဆွဲပါ။
3. ၄၀ စင်တီမီတာအထိ အဆင့်များကို တက်သည် (လှေကားများ); ထိုထက်မြင့်သော မည်သည့်အရာမဆို နံရံဖြစ်သည်။ နံရံများက သင့်ကို ရပ်စေပြီး ၎င်းတို့ဘေးတွင် ဆွဲလျှောသွားသည်။
4. {{ui:ဆွဲငင်အား}} ပိတ်ထားလျှင် သင် ပျံသန်းသည်: {{key:E}} သည် အပေါ်သို့၊ {{key:Q}} သည် အောက်သို့။
5. {{key:Esc}} သည် လျှောက်ခြင်းကို ရပ်စေသည်။

## ပြန်ရောင်အလင်း

နေလင်းထိသော နံရံမှ ပြန်ရောင်ပြီး ကြမ်းပြင်သို့ ကျသော အလင်းနှင့် အခန်း၏ အတွင်းပိုင်း အမှောင်ဘက်တို့ကို နောက်ခံတွင် ဗဟိုပရိုဆက်ဆာ အူတိုင်တိုင်းပေါ်တွင် တွက်ချက်သည်။ တွက်ချက်နေစဉ် အောက်ဆုံးလိုင်းက {{ui:အလင်း ပြန်ရောင်ခြင်း: 40 %}} ဟု ပြသသည်; အဆင်သင့်ဖြစ်လျှင် ကြည့်ရှုမှုက ၎င်းကို ထည့်သွင်းသည်။ ပြောင်းလဲမှုတစ်ခုပြီးနောက် ပြန်စတင်သည်။

:::note
ဤသည်မှာ တိုက်ရိုက်ကြည့်ရှုမှုအတွက် ခန့်မှန်းချက် ဖြစ်ပြီး ပြီးစီးသော ပုံမဟုတ်ပါ: အမှတ်များကြားရှိ သေးငယ်သော အသေးစိတ်များသည် အနီးရှိ အမှတ်များ၏ ပြန်ရောင်အလင်းကို ရယူသည်။
:::

:::note
ဘရောင်ဇာများ ကွဲပြားသည်။ ဘရောင်ဇာတွင် WebGPU ရှိလျှင် တိုက်ရိုက်ကြည့်ရှုမှုက ၎င်းကို သုံးသည်; မဟုတ်ပါက WebGL 2 ကို သုံးပြီး တူညီစွာ ပေါ်သည်။ နှစ်ခုလုံး မရှိလျှင် ပြတင်းက ထိုသို့ ပြောသည်။
:::
