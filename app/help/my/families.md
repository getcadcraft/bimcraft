## မိသားစုဆိုသည်မှာ

မိသားစုဆိုသည်မှာ အရွယ်အစား အများအပြားရှိသော အမျိုးအစား တစ်ခု ဖြစ်သည်: အကျယ် 32၊ 36 နှင့် 42 inches ရှိသော တံခါးတစ်ချပ်တည်း၊ သို့မဟုတ် ရှည်သည်နှင့် တိုသော စားပွဲ။ BimCraft တွင် မိသားစုကို တစ်ကြိမ်တည်း၊ ၎င်း၏ အရွယ်အစားများနှင့်အတူ တွေ့ရသည်၊ type ရှည်ရှည် စာရင်းအစား။

IFC တွင် မိသားစု မရှိပါ။ ဖိုင်တွင် အရွယ်အစားတစ်ခုစီသည် ရိုးရိုး type တစ်ခု ဖြစ်သည် (တံခါး type၊ ပြတင်းပေါက် type၊ ပရိဘောဂ type…)၊ မိသားစုသည် ၎င်း၏ အရွယ်အစားများကို စာရင်းပြုသော group တစ်ခု ဖြစ်သည်။ အခြား BIM ပရိုဂရမ်များက type နှင့် group ကို ၎င်းအတိုင်း ဖတ်သည်; BimCraft က ၎င်းတို့မှ မိသားစုကို ပြန်ဖတ်သည်။

## ဘယ်မှာ ရှာရမလဲ

- ပရောဂျက် browser ရှိ **Families** group တွင် ဤ model ရှိ မိသားစုများ၊ အရွယ်အစား မည်မျှ ရှိသည်နှင့် မည်မျှ ထားပြီးသည်ကို စာရင်းပြုသည်။ ၎င်းအောက်တွင် **Starter families** ရှိသည်: Door နှင့် Window ကိရိယာများ၏ တံခါးနှင့် ပြတင်းပေါက်များ၊ နှင့် စားပွဲ၊ စင်ယူနစ်နှင့် အောက်ခြေ ဗီရို။
- {{ui:Build}} › {{ui:Families…}} သည် တူညီသော စာရင်းကို window တစ်ခုတွင် ပြသည်။
- မိသားစုတစ်ခုကို နှိပ်၍ ဖွင့်ပါ: ၎င်း၏ အရွယ်အစားများ၊ အရွယ်အစားတစ်ခုစီ၏ တန်ဖိုးများနှင့် element မည်မျှ သုံးသည်ကို ကြည့်ပါ။

## တံခါးနှင့် ပြတင်းပေါက်

Door နှင့် Window ကိရိယာများသည် ထိုအမျိုးအစား၏ မိသားစုများကို စာရင်းပြုပြီး ဘေးတွင် **size list** ကို ပြသည်။ အရွယ်အစားတစ်ခုကို ရွေးပါ၊ သို့မဟုတ် **W** နှင့် **H** ရိုက်ပါ: မည်သည့် အရွယ်အစားမှ မရှိသေးသော အကျယ်နှင့် အမြင့်သည် တံခါးထားသောအခါ မိသားစု၏ အရွယ်အစားအသစ် ဖြစ်လာသည်။ အရွယ်အစားတူသော တံခါးများသည် type တစ်ခုကို မျှသည်။

{{ui:Properties}} တွင် ရွေးထားသော တံခါး သို့မဟုတ် ပြတင်းပေါက်သည် ၎င်း၏ **Family** နှင့် **Size** ကို ပြသည်။ စာရင်းမှ အခြား အရွယ်အစားကို ရွေးပါ၊ သို့မဟုတ် အကျယ် သို့မဟုတ် အမြင့်အသစ် ရိုက်ပါ။ {{ui:Open the family}} သည် ၎င်းပိုင်သော မိသားစုကို ဖွင့်သည်။

တံခါး သို့မဟုတ် ပြတင်းပေါက်၏ ဘောင်သည် ၎င်း၏ နံရံ၏ အထူကို လိုက်သည်၊ ရှေ့ကအတိုင်း။ အရွယ်အစား၏ type သည် 140 mm နံရံတွင် ဆွဲထားသော တံခါးကိုလည်း ထိန်းထားသည်၊ type ကို ဖတ်သော ပရိုဂရမ်များအတွက်။

## ဤမိသားစုမှ အရွယ်အစားအသစ်

1. မိသားစုကို ဖွင့်ပါ။
2. **New size from this family** အောက်တွင် တန်ဖိုးများ (Width, Height နှင့် မိသားစု၏ အခြား parameter များ) ကို ရိုက်ပြီး လိုလျှင် အမည်ပေးပါ။ အမည်မပေးလျှင် တန်ဖိုးများမှ အမည်ပေးသည်။
3. {{ui:Make the size}} ကို နှိပ်ပါ။

အရွယ်အစားနှစ်ခုသည် တန်ဖိုးတူ၍ မရပါ။ **Rename** သည် အရွယ်အစား၏ အမည်ကို ပြောင်းသည်; **Remove** သည် မည်သူမျှ မသုံးသော အရွယ်အစားကို ဖယ်သည်; **Select** သည် ထို အရွယ်အစား၏ element များကို ရွေးသည်။

## ပရိဘောဂ ထားရန်

1. {{ui:Build}} › {{ui:Place family}}၊ သို့မဟုတ် မိသားစု၏ window ရှိ {{ui:Place}}။
2. bar တွင် မိသားစုနှင့် ၎င်း၏ အရွယ်အစားကို ရွေးပါ။
3. ပလန်ပေါ်တွင် နှိပ်၍ အလွှာပေါ် ထားပါ။ နှိပ်ခြင်းမတိုင်မီ {{key:R}} ကို နှိပ်လျှင် 90° လှည့်သည်။ {{key:Esc}} က ရပ်စေသည်။

ထားပြီးသော အပိုင်း၏ {{ui:Properties}} တွင် အရွယ်အစား၊ နေရာနှင့် လှည့်ထားသော ထောင့်ကို ပြသည်; {{key:Delete}} က ဖယ်သည်။ အရွယ်အစား တစ်ခုတည်း၏ အပိုင်းတိုင်းသည် ထို အရွယ်အစား၏ ပုံသဏ္ဍာန်ကို မျှသည်၊ ထို့ကြောင့် မိသားစုကို ပြောင်းလျှင် ၎င်းတို့အားလုံး ပြောင်းသည်။

## ဇယားမှ အရွယ်အစားများ

မိသားစု၏ window ရှိ {{ui:Sizes from a table…}} သည် CSV ဖိုင် (comma၊ semicolon သို့မဟုတ် tab) ကို ဖတ်သည်။ ပထမ အတန်းက ကော်လံများကို အမည်ပေးသည်: parameter ၏ အမည် သို့မဟုတ် label၊ နှင့် ရွေးချယ်ပါက `Name`။ အရှည်များသည် မီလီမီတာ ဖြစ်သည်၊ unit မရေးထားလျှင် (`1.2 m`, `36 in`)၊ Yes / No ကော်လံများက yes, no, true, false, 1 သို့မဟုတ် 0 ယူသည်၊ ကော်လံမရှိသော parameter သည် မူလတန်ဖိုးကို ထိန်းသည်။ အတန်းတိုင်းသည် အရွယ်အစားတစ်ခု ဖြစ်လာသည်၊ undo လုပ်နိုင်သော အဆင့်တစ်ခုတည်းဖြင့်; ရှိပြီးသား အရွယ်အစားကို ကျော်သည်။ ဖတ်မရသော သို့မဟုတ် မိသားစုက ဆွဲ၍မရသော အတန်းတစ်ခုသည် ဇယားတစ်ခုလုံးကို ငြင်းပြီး ၎င်း၏ လိုင်းနံပါတ်ကို ပြောသည်။ အများဆုံး 200 အတန်းနှင့် 1 MB။ {{ui:Save the sizes as a table}} သည် တူညီသော ဇယားကို ပြန်ရေးသည်။

## element တစ်ခုစီတွင် သတ်မှတ်ခြင်း

editor တွင် **Per element** အဖြစ် အမှတ်အသားပြုထားသော parameter (transom, label, material ထည့်သော Yes / No) သည် အရွယ်အစား၏ အပိုင်း မဟုတ်: အရွယ်အစားတူသော တံခါးနှစ်ချပ်သည် ကွဲပြားနိုင်သည်။ element ကို ရွေးပါ၊ **Properties** တွင် ဤ parameter များကို ပြသည်; တစ်ခုကို ပြောင်းလျှင် ထို element သည် ၎င်း၏ ကိုယ်ပိုင် ပုံသဏ္ဍာန်ဖြင့် ပြန်ဆွဲသည် (ပရိဘောဂနှင့် တပ်ဆင်ပစ္စည်းများက ကိုယ်ပိုင် ပုံသဏ္ဍာန် ရသည်၊ တံခါးနှင့် ပြတင်းပေါက်များကို နံရံများတွင် ပြန်ဖန်တီးသည်)။ အားလုံးကို မူလတန်ဖိုးသို့ ပြန်ထားလျှင် ၎င်းသည် အရွယ်အစား၏ ပုံသဏ္ဍာန်သို့ ပြန်ရောက်သည်။

## အသေးစိတ် အဆင့်

{{ui:Build}} › {{ui:Families…}} › **Detail level** သည် model ရှိ မိသားစုတိုင်းအတွက် solid များတွင် သိမ်းမည့်အရာနှင့် plan symbol များတွင် ဆွဲမည့်အရာကို သတ်မှတ်သည်: **Fine** က အားလုံး ထားသည်၊ **Medium** နှင့် **Coarse** က editor က ပိုသေးဟု အမှတ်အသားပြုသော အပိုင်းများကို ချန်ထားသည် (ဖိုင်ငယ်ပြီး view မြန်သည်)။ **Automatic** က အားလုံး သိမ်းပြီး sheet ၏ view က scale ဖြင့် ရွေးစေသည်: 1:50 နှင့် ကြီးသည် fine၊ 1:100 medium၊ 1:200 နှင့် ငယ်သည် coarse။ undo လုပ်နိုင်သော အဆင့်တစ်ခု။

## မိသားစုကို ပွားခြင်း

အစမှ စရန် မလိုပါ။ {{ui:Duplicate}} သည် မိသားစုကို ၎င်း၏ parameter, solid နှင့် အရွယ်အစားများနှင့်အတူ အမည်အသစ်ဖြင့် ကူးသည်။ editor တွင် မိတ္တူကို ပြောင်းပါ; မူရင်းသည် မူလအတိုင်း ကျန်သည်။

## မိသားစုဖိုင်များ

- {{ui:Save the family file}} သည် `.ccfamily.json` ကို သိမ်းသည်: မိသားစု၏ parameter, solid နှင့် အရွယ်အစားများ။ အခြား model တွင် Families group ရှိ {{ui:Open a family file…}} ဖြင့် ဖွင့်ပါ။
- {{ui:Save as IFC}} သည် မိသားစုကို IFC ဖိုင်ငယ်အဖြစ် သိမ်းသည်: ၎င်း၏ အရွယ်အစားများ၏ type များနှင့် group၊ IFC ပရောဂျက် စာကြည့်တိုက်က ကြေညာထားသည်။ အခြား ပရိုဂရမ်များက type အစုအဖွဲ့အဖြစ် ဖွင့်သည်; BimCraft က မိသားစုအဖြစ် ပြန်ဖွင့်သည်။

ဤနေရာတွင် ဖွင့်သော မိသားစုဖိုင်ကို ဒေတာအဖြစ် ဖတ်ပြီး ဘာမျှ မရေးမီ စစ်ဆေးသည်။ model တွင် ရှိပြီးသား key ရှိသော မိသားစုသည် သီးခြား မိသားစုအဖြစ် ဝင်လာသည်။ အခြား မိသားစုများကို ထိန်းထားသော မိသားစု (editor help ရှိ **အတွင်းရှိ မိသားစုများ** ကို ကြည့်ပါ) က ၎င်းတို့ကို ယူလာသည်: ဖိုင်က စာရင်းပြုပြီး model က ရှိပြီးသားကို ထိန်းသည်။

## Library ရှိ မိသားစုများ

{{ui:Families…}} ကို ဖွင့်ပြီး {{ui:From the Library…}} ကို ရွေးပါ၊ Library တွင် မျှဝေထားသော မိသားစုများကို ကြည့်ရန်။ {{ui:Add to this project}} သည် ထိုတစ်ခုကို မိသားစုဖိုင်ကဲ့သို့ ဖတ်သည်: BimCraft က ဘာမျှ မဖန်တီးမီ field တိုင်းကို စစ်ဆေးသည်၊ မိသားစုသည် ကိုယ်ပိုင် မိသားစုအဖြစ် ဝင်လာပြီး editor တွင် ဖွင့်သည်။ ထည့်ခြင်းသည် undo အဆင့်တစ်ခု ဖြစ်သည်။ ကိုယ်ပိုင်ကို မျှဝေရန် {{ui:Save all as a library}} ကို သုံးပြီး ဖိုင်ကို Library သို့ ပို့ပါ (Library ၏ ဝန်ထမ်းများက မိသားစုဖိုင်ကို command ဖြင့် ထုတ်ဝေသည်၊ မိသားစုတစ်ခုစီသည် ၎င်း၏ အရွယ်အစားများနှင့်အတူ ကိုယ်ပိုင် item ဖြစ်သည်)။ Library ကို မရောက်နိုင်ပါက စာရင်းက ထိုသို့ ပြောပြီး ဘာမျှ မပြောင်းပါ။

## အခြား ပရိုဂရမ်များ၏ type များ

အခြား ပရိုဂရမ်များ ပြုလုပ်သော type များကိုလည်း Families group တွင် ပြသည်၊ ခန့်မှန်းချက်ဖြင့် အုပ်စုဖွဲ့ထားသည်: element အမည်များ၏ ပထမ colon မတိုင်မီ အပိုင်း၊ သို့မဟုတ် နံပါတ်တွင်သာ ကွဲသော type အမည်များ။ မိသားစု window က မည်သည့် ခန့်မှန်းချက်ကို သုံးသည်ကို ပြောသည်။ ၎င်းတို့ကို စာရင်းပြုပြီး element များကို ရွေးနိုင်သော်လည်း ဤနေရာတွင် မတည်းဖြတ်ပါ: မိသားစု recipe မရှိပါ။

:::note
starter တံခါးနှင့် ပြတင်းပေါက်များကို မိသားစုမတိုင်မီကလို အတိအကျ ဆွဲထားသည်။ မိသားစုမတိုင်မီ ဖန်တီးထားသော ဖိုင်များသည် ပြောင်းလဲမထားဘဲ ဖွင့်ပြီး၊ ၎င်းတို့၏ တံခါးနှင့် ပြတင်းပေါက်များသည် သုံးနေသော အရွယ်အစားများနှင့်အတူ ၎င်းတို့၏ မိသားစုအောက်တွင် ပေါ်ပြီး ပထမဆုံး ပြောင်းလဲသည့်အခါ ကိုယ်ပိုင် အရွယ်အစားသို့ ရွှေ့သည်။
:::
