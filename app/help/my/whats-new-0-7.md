ဤသည်မှာ BimCraft 0.6 နှင့် နှိုင်းယှဉ်လျှင် 0.7 တွင် ပြောင်းလဲသွားသည်များ ဖြစ်သည်။ စာရင်းကို နယ်ပယ်အလိုက် အုပ်စုဖွဲ့ထားပြီး အရေးအကြီးဆုံးကို ရှေ့ဆုံးတွင် ထားသည်။

## အသစ်များ

### အဆောက်အအုံ ဆွဲခြင်း

- **အဆင့်များစွာမှ နံရံများ။** Wall tool ၏ အမြင့် စာရင်းတွင် အပေါ်ရှိ အဆင့်မည်သည်ကိုမဆို **Up to** ဟု ပေးသည်၊ Properties က ရွေးထားသော နံရံကို ပေးသကဲ့သို့။ ကြားက အဆင့်များ၏ plan များတွင် နံရံကို ပိုပေါ့ပါးစွာ ပြပြီး အခန်းများသည် ထိုနံရံကို ကပ်ပိတ်ကြ၍ တံခါးနှင့် ပြတင်းပေါက်များကို ထို plan များမှ ထည့်နိုင်သည်; Properties ရှိ **Runs through** က ဖြတ်သန်းသော အဆင့်များကို အမည်ပေးသည်။ [နံရံ၊ တံခါး သို့မဟုတ် ပြတင်းပေါက် ပြောင်းရန်](topic:change-a-wall-or-door#change-a-wall) ကို ကြည့်ပါ။
- **ဤအဆင့်ကို ကူးရန်။** Levels panel ရှိ {{ui:Copy this level…}} က အဆင့်တစ်ခု၏ နံရံများကို၊ ၎င်းတို့၏ တံခါးနှင့် ပြတင်းပေါက်များဖြင့်၊ ၎င်း၏ ကြမ်းပြင်များနှင့် ခုံးများကို အခြားအဆင်တစ်ခု သို့မဟုတ် အပေါ်တွင် အသစ် တစ်ခုပေါ်သို့ ပြန်ဆွဲပေးသည်၊ undo အဆင့် တစ်ခုတည်းဖြင့်; အခန်းများကို အလိုအလျောက် ပေါ်လာသည်။ [နံရံများ ဆွဲရန်](topic:draw-walls#levels) ကို ကြည့်ပါ။
- **PDF သို့မဟုတ် scan မှ နံရံများ။** {{ui:Build}} › {{ui:From a drawing…}} သည် PDF (မျဉ်းများ သို့မဟုတ် အတွင်းရှိ scan) သို့မဟုတ် scan လုပ်ထားသော plan (PNG၊ JPEG၊ TIFF၊ စာမျက်နှာ အများအပြား) ကို ယခု လက်ခံသည်: စာမျက်နှာတစ်ခုစီသည် အဆင့်တစ်ခု၏ နံရံများ၊ တံခါးများ၊ ပြတင်းပေါက်များနှင့် အခန်းများ ဖြစ်လာပြီး စာမျက်နှာကို ၎င်း plan အောက်တွင် ထိန်းသည်။ Trace သည် network သို့မဟုတ် လေ့ကျင်ထားသော model ကို မသုံးပါ၊ ရလဒ်သည် မျဉ်းများက ပေးသည့်အတိုင်း ဖြစ်သည်: အဆင့်တစ်ခုစီကို ၎င်း စာမျက်နှာနှင့် စစ်ဆေးပါ။ [ပုံဆွဲအစုမှ နံရံများ](topic:walls-from-plans) ကို ကြည့်ပါ။
- **ကိုယ်ပိုင် နံရံ အစိတ်အပိုင်းများ။** {{ui:Wall assemblies…}} သည် နံရံအမျိုးအစားကို အလွှာတစ်ခုချင်းစီဖြင့် တည်ဆောက်ပေးသည်၊ core၊ လေကွာဟချက်နှင့် အမြှေးပါးများပါ၊ ပမာဏ ပါသော preview ဖြင့်; {{ui:Material library…}} သည် ပရောဂျက်၏ ပစ္စည်းများကို IFC တွင် ထိန်းသည်; {{ui:Annotate}} › {{ui:Reference dimension}} သည် မျက်နှာများနှင့် core မျဉ်းများထံ တိုင်းပြီး နံရံများ ပြောင်းသည့်အခါ လိုက်သည်။ ပါဝင်ကူညီသူ Doc (drsurfbum) မှ ဖြစ်သည်။ [နံရံ အစိတ်အပိုင်းများနှင့် ကိုးကားအတိုင်းအတာများ](topic:wall-assemblies) ကို ကြည့်ပါ။
- **ပြသမှု ယူနစ်များနှင့် view ထိန်းချုပ်မှုများ။** Toolbar ရှိ {{ui:Units}} က အရှည်များကို ပေနှင့် လက်မ၊ လက်မ၊ ဒဿမ ပေ၊ မီလီမီတာ၊ စင်တီမီတာ သို့မဟုတ် မီတာဖြင့် ပြသည်၊ အတိုင်းအတာများ၊ schedule များ၊ coordinates၊ တိုင်းတာမှုများနှင့် section များတွင်။ {{ui:Plan}}၊ {{ui:Split}} နှင့် {{ui:3D}} တို့သည် toolbar တွင် ရှိပြီး split ကို ဆွဲ၍ ရွှေ့နိုင်သည် (သို့မဟုတ် keyboard ဖြင့်)၊ {{ui:Shaded}}၊ {{ui:Edges}} နှင့် {{ui:Wireframe}} တို့ view cube ဘေးတွင် ရှိပြီး အမိုး စောင်း၊ fascia နှင့် soffit များက ရွေးထားသော အမိုးကို ချက်ချင်း ပြောင်းသည်။ ပါဝင်ကူညီသူ Joel (yisraelk) မှ ဖြစ်သည်။ [နံရံများ ဆွဲရန်](topic:draw-walls#levels) ကို ကြည့်ပါ။
- **Span အလိုက် ကြမ်းပြင် joist များ။** {{ui:Framing}} သည် engineered joist များ (ကြိုတင်) နှင့် sawn lumber နှစ်မျိုးလုံးကို ခင်းနိုင်သည်၊ span ကို ရောက်စေသော အငယ်ဆုံး စီးရီးနှင့် အနက်ကို ရွေးပြီး 16" သို့မဟုတ် 24" on center ဖြင့် ဘက်နှစ်ခုလုံးတွင်; IFC နှင့် cut list တွင် ထည့်သည်။ ထုတ်လုပ်သူ၏ ထုတ်ပြန်ထားသော ဇယားမှ အကြံပြုချက်ဖြစ်ပြီး engineering မဟုတ်ပါ။ Joel မှလည်း ဖြစ်သည်။ [နံရံများ၊ ကြမ်းပြင်များနှင့် အမိုးများ ဘောင်ခတ်ခြင်း](topic:framing) ကို ကြည့်ပါ။
- **လျှပ်စစ် စက်ပစ္စည်း ပိုများ။** {{ui:Electrical}} သည် data၊ ဖုန်းနှင့် audio-video outlet များ၊ selector switch၊ timer၊ thermostat၊ မီးခိုး နှင့် အပူ detector များ၊ pull station နှင့် siren၊ fan၊ energy meter နှင့် sub-panel တို့ကို ထည့်သည်၊ တစ်ခုချင်းစီ၏ IFC class ကိုယ်ပိုင်ဖြင့်။ [လျှပ်စစ်ပုံဆွဲ](topic:electrical-plan) ကို ကြည့်ပါ။

### Family များ

- **Family များ ပိုလုပ်နိုင်သည်။** Parameter များသည် ကိန်းပြည့်၊ စာသား၊ ပစ္စည်း၊ ဆေးတံ သို့မဟုတ် ဖြည့်စရာ ဖြစ်နိုင်သည်; family တစ်ခုက ၎င်း၏ plan သင်္ကေတကို ဆွဲနိုင်သည်၊ solid တစ်ခုကို ထပ်ခါတလဲလဲ ထုတ်နိုင်သည်၊ ပိုမှိုင်းသော detail level များအတွက် အစိတ်အပိုင်းများကို အမှတ်အသားပြုနိုင်သည်၊ အခြား family များကို ကိုင်ထားနိုင်သည် (ပွဲစားပွဲတွင် ခြေထောက်တစ်ခု)၊ နှင့် သင်ဆွဲနိုင်သော hotspot များ ရှိနိုင်သည်၊ plan ပေါ်တွင် ချထားသော element ပေါ်တွင်လည်း။ အရွယ်အစားများကို CSV ဇယားမှ ယူသည်၊ **Per element** ဟု အမှတ်အသားပြုထားသော parameter များက အရွယ်တူ တံခါးနှစ်ခု ကွဲပြားစေနိုင်သည်။ [family တည်းဖြတ်ရန်](topic:family-editor#plan-symbol) နှင့် [Family များနှင့် ၎င်းတို့၏ အရွယ်အစားများ](topic:families#sizes-from-a-table) ကို ကြည့်ပါ။

### ပိုက်များ၊ duct များနှင့် စက်ပစ္စည်းများ

- **Port ပါသော စက်ပစ္စည်း။** {{ui:Build}} › {{ui:Equipment}} သည် generic air handler၊ inline fan၊ pump၊ boiler၊ water heater၊ terminal unit၊ diffuser၊ grille သို့မဟုတ် tank တစ်ခုကို နေရာချပေးသည်၊ သင်ရိုက်ထည့်သော တန်ဖိုးဖြင့် အရွယ်ပြုပြီး ၎င်း၏ ပိုက်နှင့် duct ချိတ်ဆက်မှုများကို port အဖြစ် ထားသည်။ တစ်ခုချင်းစီကို IFC port ပါသော ၎င်း၏ IFC class အဖြစ် သိမ်းသည်။ [MEP စက်ပစ္စည်းများ port ဖြင့်](topic:mep-equipment) ကို ကြည့်ပါ။
- **ချိတ်ဆက်ထားသော လမ်းကြောင်းများ။** Port တစ်ခုပေါ်မှ စတင်သော ပိုက် သို့မဟုတ် duct သည် ၎င်း၏ အရွယ်နှင့် စနစ်ကို ယူပြီး ထို port တွင် ပြတ်မခွာ ကပ်နေသည်: ပန့်ကို ရွှေ့လျှင် ပိုက်လိုက်လာသည်။ **Check connections** က ဖွင့်ထားသော port များ၊ လွတ်နေသော အဆုံးများ၊ အရွယ်နှင့် စနစ် မကိုက်ညီမှုများနှင့် ဘာမျှ မထောက်ပံ့သော လမ်းကြောင်းများကို စာရင်းပြုသည်။ [ပိုက်နှင့် duct များကို စက်ပစ္စည်းသို့ ချိတ်ဆက်ရန်](topic:mep-connections) ကို ကြည့်ပါ။
- **ပိုက်နှင့် duct များ နှင့် အဆောက်အအုံ။** {{ui:Clash check}} တွင် အသင့်သုံး အစုများနှင့် {{ui:Pipes and ducts × structure}} တစ်ချက်နှိပ်ဖြင့် ရှိသည်; {{ui:Check clearances}} သည် လမ်းကြောင်းတစ်ခုချင်းစီ၏ insulation နှင့် သင်ရိုက်ထည့်သော gap ကို သုံးသည်; {{ui:Openings needed}} သည် လမ်းကြောင်းများ နံရံနှင့် slab များကို ဖြတ်သော နေရာများကို CSV နှင့် BCF ပြဿနာများအဖြစ် စာရင်းပြုသည်။ ဘာမျှ မဖြတ်ပါ။ [ပိုက်နှင့် duct များကို အဆောက်အအုံနှင့် စစ်ဆေးရန်](topic:mep-against-structure) ကို ကြည့်ပါ။
- **သံမဏိ ပိုက် spool များ။** သံမဏိ လမ်းကြောင်းကို အရှည်ဆုံး အရှည်နှင့် သင်နေရာချထားသော {{ui:Field weld}} များတွင် နံပါတ်တပ်ထားသော spool များအဖြစ် ဖြတ်သည်; {{ui:Spool sheets (PDF)}} သည် spool တစ်ခုလျှင် စာမျက်နှာတစ်ခုကို ၎င်း isometric view၊ ဖြတ်အရှည်များ၊ fitting များ၊ weld များနှင့် bill of materials ဖြင့် ပေးသည်၊ နှင့် {{ui:Duct cut list}} က duct တည့်တည့် အပိုင်းများကို စာရင်းပြုသည်။ [သံမဏိ ပိုက် spool များနှင့် spool sheet များ](topic:pipe-spools) ကို ကြည့်ပါ။

ဤတို့သည် ဒီဇိုင်းကူညီမှုနှင့် ညှိနှိုင်းမှု ကိရိယာများဖြစ်ပြီး အင်ဂျင်နီယာက အရွယ်ချထားသည်: စီးဆင်းမှု၊ ဖိအား သို့မဟုတ် ညီမျှချိန်ခွင် မပါဝင်ပါ။

### လည်ပတ်မှု

- **Asset တစ်ခုချင်းစီ၏ စာရွက်စာတမ်းများ။** {{ui:Assets}} tab သည် လက်စွဲစာအုပ်များ၊ အာမခံများ၊ ဓာတ်ပုံများနှင့် ပုံဆွဲများကို IFC ဘေးရှိ ဖိုင်အမည် သို့မဟုတ် ဝဘ်လိပ်စာဖြင့် asset တစ်ခုသို့ ချိတ်သည်; လင့်ခ်သာ IFC တွင် သိမ်းသည်။ [စာရွက်စာတမ်းများ](topic:assets-and-maintenance#documents) ကို ကြည့်ပါ။
- **COBie spreadsheet။** {{ui:Save as COBie (.xlsx)}} သည် COBie 2.4 handover workbook ကို ရေးသည်၊ နှင့် ပြန်ဖတ်ထားသော COBie workbook သည် ပြောင်းလဲမှု အားလုံးကို {{ui:Apply}} တစ်ကြိမ် မတိုင်မီ စာရင်းပြုသည်။ COBie validator ဖြင့် မစစ်ဆေးရသေးပါ။ [COBie spreadsheet](topic:assets-and-maintenance#cobie-spreadsheet) ကို ကြည့်ပါ။
- **အာရုံခံကိရိယာ ဖတ်ရှုချက်များနှင့် live feed များ။** ဖတ်ရှုချက် CSV တစ်ခုကို ဖွင့်ပါ၊ သို့မဟုတ် ဘရောက်ဇာမှ သင့်ကိုယ်ပိုင် MQTT broker သို့ သို့မဟုတ် သင့် အဆောက်အအုံ စနစ် ဖြေသော လိပ်စာသို့ {{ui:Connect}} လုပ်ပါ: asset တစ်ခုစီက နောက်ဆုံးဖတ်ရှုချက်နှင့် ဇယားကို ပြပြီး model ပေါ်တွင် အရောင်ပြောင်းသည်၊ IFC တွင် သိမ်းထားသော ကန့်သတ်ချက်များ အပြင်ဘက်ဖြစ်လျှင် အမှတ်အသားပြုသည်။ ဖတ်ရှုချက်များသည် tab ထဲတွင်သာ ရှိနေသည်; password များကို ဘယ်တော့မှ မသိမ်းပါ။ [အာရုံခံကိရိယာ ဖတ်ရှုချက်များ](topic:assets-and-maintenance#sensor-readings) နှင့် [တိုက်ရိုက် ဖတ်ရှုချက်များ](topic:assets-and-maintenance#live-readings) ကို ကြည့်ပါ။

### နေ့ရောင်နှင့် စွမ်းအင်

- **ပြတင်းပေါက်တိုင်း၏ ကောင်းကင်နှင့် နေ။** {{ui:Daylight}} tab သည် ပြတင်းပေါက်တိုင်းကို ၎င်း၏ vertical sky component နှင့် အဟန့်အတားထောင့်ကို ပေးသည်၊ {{ui:Sun through the windows on a date}} ဖြင့် ရက်တစ်ရက်ကို နေ လိုက်ကြည့်နိုင်သည်၊ နှင့် အခန်းတစ်ခုစီအပေါ် {{ui:Daylight factor on a grid}} ကို တွက်ပြီး ၎င်း plan ပေါ်တွင် ဆွဲသည်။ [ပြတင်းပေါက်တိုင်း၏ vertical sky component](topic:daylight-factor#vertical-sky-component-of-each-window) ကို ကြည့်ပါ။
- **အပူနှင့် အအေး ဝန်များ။** {{ui:Heating and cooling loads}} သည် အခန်းတစ်ခုစီ၏ အပူဆုံးရှုံးမှု၊ degree-day များမှ တစ်နှစ်တာ အပူလိုအပ်ချက်နှင့် အအေး အမြင့်ဆုံးကို မော်ဒယ်တွင် ၎င်းကိုဝန်းရံသော အရာများနှင့် element တစ်ခုစီ၏ U-value မှ တွက်သည်; ထိုနေရာတွင် ရိုက်ထည့်သော U-value ကို IFC တွင် ရေးသည်။ [အပူနှင့် အအေး ဝန်များ ခန့်မှန်းရန်](topic:heating-and-cooling-loads) ကို ကြည့်ပါ။

နှစ်ခုစလုံးသည် ထုတ်ပြန်ထားသော နည်းလမ်းများဖြင့် ဒီဇိုင်းကူညီသည့် ကိရိယာများဖြစ်ပြီး ဥပဒေနှင့် ကိုက်ညီမှု တွက်ချက်မှုများ မဟုတ်ပါ၊ panel တိုင်းက ထိုသို့ ပြောသည်။

### Scan များ

- **Scan များစွာ ပေါင်းရန်။** {{ui:Register scans…}} (စတင်ရာ panel တွင်၊ သို့မဟုတ် {{ui:Show}} တွင်) က scan များကို ရွေးထားသော အမှတ်အတွဲများ သို့မဟုတ် ရိုက်ထည့်သော target များဖြင့် frame တစ်ခုတည်းတွင် နေရာချပြီး point to point ထို့နောက် point to plane ဖြင့် ICP ဖြင့် ညှိသည်၊ ပြန်ညှိချက်ကို ဖိုင် ငယ်ငယ်တစ်ခုအဖြစ် သိမ်းပြီး ပေါင်းထားသော cloud ကို LAS သို့မဟုတ် E57 ဖိုင်တစ်ခုအဖြစ် ရေးသည်။ [Scan များစွာကို တစ်ခုအဖြစ် ပေါင်းရန်](topic:register-scans) ကို ကြည့်ပါ။

### ပုံများနှင့် live view

- **Live view။** Toolbar ရှိ {{ui:Live view}} သည် မော်ဒယ်ကို 3D view ဘေးတွင် real-time ပုံစံဖြင့် ပြပြီး ၎င်းနှင့် ပြောင်းလဲမှု အားလုံးကို လိုက်သည်၊ Walk၊ နေ့ရက်အချိန်နှင့် လနှင့်အတူ; {{ui:Live view in a new window}} က ဒုတိယ မျက်နှာပြင်တွင် ထားသည်။ [Live view](topic:live-view) ကို ကြည့်ပါ။
- **ဂရပ်ဖစ်ကတ်ပေါ်ရှိ path tracing။** WebGPU ဖြင့် {{ui:Render}} › {{ui:High quality (path traced)}} သည် CadCraft ၏ ကိုယ်ပိုင် path tracer ကို ဂရပ်ဖစ်ကတ်ပေါ်တွင် run သည်၊ ရပ်နိုင်ပြီး {{ui:Resume}} လုပ်နိုင်သည်၊ အဆုံးတွင် denoise လုပ်သည်; WebGPU မရှိလျှင် ယခင်အတိုင်း WebGL path tracer ကို သုံးသည်။ [High quality](topic:render#high-quality) ကို ကြည့်ပါ။
- **Render dialog တွင် ပိုများသည်များ** (ဂရပ်ဖစ်ကတ်ပေါ်တွင်ဖြစ်သဖြင့် WebGPU လိုသည်): physical sky နှင့် sky ပုံများ၊ IES light profile များ၊ f-stop၊ depth of field၊ two-point perspective၊ white balance နှင့် 360° panorama ပါသော ကင်မရာ၊ ပြီးစီးသော ပုံအတွက် grade၊ light mixing နှင့် render အစိတ်အပိုင်းများ render ပြီးနောက်၊ fog၊ smoke နှင့် caustics၊ 16-bit PNG၊ EXR သို့မဟုတ် render ဖိုင်အဖြစ် သိမ်းခြင်း၊ နှင့် render queue။ [ကောင်းကင်များနှင့် light profile များ ဂရပ်ဖစ်ကတ်ပေါ်တွင်](topic:render#skies-and-light-profiles-on-the-graphics-card) နှင့် [render queue](topic:render#the-render-queue) ကို ကြည့်ပါ။
- **သင့်စက်။** {{ui:Settings}} › {{ui:BimCraft}} › {{ui:Rendering}} › {{ui:Your machine}} သည် ဤဘရောက်ဇာက အက်ပ်ကို သုံးခွင့်ပြုသော ဂရပ်ဖစ်၊ processor core များနှင့် memory ကို ပြပြီး render စတင်သည့် အဆင့်ကို ပြသည်။ [သင့်စက် ဘာနဲ့ render လုပ်သလဲ](topic:your-machine) ကို ကြည့်ပါ။

### ဖိုင်များနှင့် အခြားအက်ပ်များ

- **STEP ဖိုင်များ ဖွင့်ခြင်း။** `.step` သို့မဟုတ် `.stp` ပစ္စည်း၊ စက်ပစ္စည်း သို့မဟုတ် ပေးသွင်းသူ၏ မော်ဒယ် (AP203၊ AP214၊ AP242) သည် IFC မော်ဒယ်ငယ်တစ်ခုအဖြစ် ဖွင့်သည်၊ solid တစ်ခုစီသည် စစ်ဆေး၊ section ဖြတ်၊ တိုင်း၊ IFC အဖြစ် သိမ်းနိုင်သော element တစ်ခု ဖြစ်သည်။ အရောင်များနှင့် assembly ၏ အစိတ်အပိုင်းအမည်များကို မဖတ်ရသေးပါ။ [BimCraft ဖွင့်နိုင်သော ဖိုင်များ](topic:files#what-it-opens) ကို ကြည့်ပါ။
- **USD export။** Toolbar ရှိ {{ui:USD}} သည် ဖွင့်ထားသော မော်ဒယ်များကို `.usda`၊ `.usdc` သို့မဟုတ် `.usdz` အဖြစ် ရေးသည်၊ site၊ building၊ storey နှင့် discipline အလိုက် စီထား၍ element တစ်ခုစီ၏ IFC class၊ GlobalId နှင့် properties ပါသည်။ [မော်ဒယ်ကို USD အဖြစ် ထုတ်ရန်](topic:usd) ကို ကြည့်ပါ။
- **CivilCraft မှ mass။** CivilCraft ၏ site view မှ ပို့ထားသော အဆောက်အအုံ mass သည် Properties တွင် ၎င်း၏ လေ့လာမှု နံပါတ်များကို ပြပြီး {{ui:Develop this mass}} သည် အဆင့်အားလုံးတွင် နံရံများနှင့် ၎င်းမှ ကြမ်းပြင်တစ်ခုကို undo အဆင့်တစ်ခုတည်းဖြင့် ဆောက်သည်။ [site လေ့လာမှု မှ အဆောက်အအုံ mass ကို ဖွံ့ဖြိုးစေခြင်း](topic:develop-a-mass) ကို ကြည့်ပါ။
- **Variant ပါသော စာကြည့်တိုက် ပစ္စည်းများ။** Variant အများအပြားဖြင့် ဝင်လာသော ပစ္စည်းတွင် {{ui:Library}} tab တွင် {{ui:Variant}} ရွေးချယ်မှု ရှိသည်; နေရာချထားသော element သည် ၎င်း၏ variant ကို IFC တွင် ထိန်းသည်၊ {{ui:Swap item…}} က အခြား variant များကို စာရင်းပြုပြီး မိတ္တူများနှင့် အဆင့်မြှင့်ခြင်းများက ထိန်းသည်။ [Variant ပါသော စာကြည့်တိုက် ပစ္စည်းကို နေရာချပြီး လဲလှယ်ရန်](topic:library-variants) ကို ကြည့်ပါ။
- **ဖိုဒါထဲရှိ project bundle များ။** {{ui:Open a folder}} သည် {{ui:Project bundles}} အောက်တွင် `.ccbundle.zip` ဖိုင်များကို စာရင်းပြုပြီး bundle တစ်ခုရှိ layout တိုင်းတွင် **Open in …** ရှိသည်: PDF ကို MarkupCraft သို့၊ DWG ကို CadCraft သို့၊ tab အသစ်တွင်။ [layout တစ်ခု ဖွင့်ရန်](topic:open-project-bundle#open-a-layout) ကို ကြည့်ပါ။

### AI assistant များနှင့် add-on များ

- **AI assistant များအတွက် ပိုများသည်။** Assistant သည် ယခု element အမည်များပြောင်းနိုင်ပြီး property တန်ဖိုးများ သတ်မှတ်နိုင်သည်၊ element များကို ရွှေ့နိုင်ပြီး ဖျက်နိုင်သည်၊ နံရံများ၊ တံခါးများနှင့် ပြတင်းပေါက်များကို ပြောင်းနိုင်သည်၊ USD ထုတ်နိုင်သည်၊ ပုံတစ်ပုံ render လုပ်နိုင်သည် သို့မဟုတ် render queue ကို run နိုင်သည်; ပြောင်းလဲမှုတိုင်းသည် undo အဆင့် တစ်ခု။ [AI assistant ဖြင့် မော်ဒယ်ကို လုပ်ဆောင်ခြင်း](topic:assistants) ကို ကြည့်ပါ။
- **Add-on များက model ထဲတွင် တည်ဆောက်နိုင်သည်။** Add-on API 1.1 သည် add-on ကို model တွင် ပြောင်းလဲမှု တစ်ခုကို undo အဆင့် တစ်ခုအဖြစ် ပြုလုပ်ခွင့်ပြုသည် (Live TeamWork တွင် သွားသည်)၊ model ကို ဖတ်ခွင့်ပြုသည်၊ ပိုက်နှင့် duct လမ်းကြောင်းများ၊ port များ၊ စက်ပစ္စည်းများနှင့် spool များကိုလည်း ဖတ်ခွင့်ပြုသည်။
- **Plant add-on** (ဆက်တင်များ › General › Add-ons တွင် ဖွင့်မှ ဖွင့်သည်): ပိုက် spec များကို လမ်းကြောင်းများနှင့် စစ်ဆေးခြင်း၊ လမ်းကြောင်း၏ isometric ပုံဆွဲများကို SVG နှင့် DXF အဖြစ် bill of materials ဖြင့်၊ nozzle များပါသော generic process စက်ပစ္စည်းများကို model တွင် နေရာချခြင်း၊ port နှစ်ခုကြား router၊ နှင့် စက်ရုံ layout စစ်ဆေးမှု။ ဒီဇိုင်းကူညီသည့် ကိရိယာ၊ engineering အတည်ပြုချက် မဟုတ်ပါ၊ စာသားများသည် အင်္ဂလိပ်ဘာသာသာ ဖြစ်သည်။

## ပြောင်းလဲထားသည်များ

- **လက်ပ်တော့ပေါ်ရှိ ပထမဆုံး အိမ်။** လက်ပ်တော့ အရွယ်ရှိ မျက်နှာပြင်တွင် BimCraft သည် plan တစ်ခုတည်းဖြင့် စတင်သည်၊ Draw bar သည် plan နှင့်အတူ ကျဉ်းသော panel ဖြစ်ပြီး၊ ပုံဆွဲက ထွက်သွားသည့်အခါ plan နှင့် 3D view များ ပြန်ပေါ်လာသည်၊ 3D view သည် အိမ်တစ်လုံးလုံးကို ကျဉ်းသော pane တွင် ဘောင်ခတ်ပြသည်၊ နှင့် တံခါးများနှင့် ပြတင်းပေါက်များကို dimension မျဉ်းများထက် အရင် ရွေးသည်။
- **ဓာတ်ပုံ သိမ်းခြင်း။** Render dialog ရှိ **Save PNG** သည် ယခု {{ui:Save}} ဖြစ်ပြီး {{ui:Save as}} သည် အခြား format များအတွက် ဘေးတွင် ရှိသည်။ [ပုံကို သိမ်းခြင်း](topic:render#save-the-picture) ကို ကြည့်ပါ။
- **Analysis tab** တွင် {{ui:Design checks}} block ရှိသည်: သင့်ကိစ္စများအတွက် ASCE 7 သို့မဟုတ် EN 1990 ၏ load combination များကို ပြုလုပ်ပြီး rolled steel I-shape တစ်ခုစီ (W၊ S၊ IPE၊ HEA သို့မဟုတ် HEB အရွယ်ကို ၎င်း profile အမည်နှင့် အရွယ်အစားဖြင့်) ကို AISC 360 သို့မဟုတ် EN 1993-1-1 ဖြင့် စစ်ဆေးပြီး ၎င်း capacity ၏ ဘယ်လောက် သုံးနေသလဲ ပြသည်။ Engineer တစ်ဦး သုံးသပ်သည်အထိ ကူညီသည့် ကိရိယာ; welded shape များနှင့် အခြား section များက "not checked" ဟု ပြသည်။ [Design checks](topic:frame-analysis#design-checks) ကို ကြည့်ပါ။

## ပြင်ဆင်ထားသည်များ

- Family အရွယ်အသစ် ဖန်တီးသော ခြေလှမ်းတစ်ခုပြီး redo လုပ်ခြင်း ("no size") ကျရှုံးခဲ့သည်။ ယခု ခြေလှမ်းတိုင်းသည် redo တွင် IFC GlobalId တူညီစွာ ပြန်ထုတ်ပြီး family နှင့် အခြား ပြောင်းလဲမှု အားလုံးအတွက် redo အလုပ်လုပ်သည်။
- လူနှစ်ဦးက family တစ်ခုကို တူညီစွာ သိမ်းသည့်အခါ (Live TeamWork session သို့မဟုတ် ဝင်းဒိုးနှစ်ခုတွင်) ဒုတိယ သိမ်းမှုက ပထမ၏ ပြောင်းလဲမှုကို အသံမထွက်ဘဲ ဖျက်ခဲ့သည်။ ယခု ငြင်းပယ်ပြီး သူတို့၏ ပြောင်းလဲမှုကို ကြည့်ရန်နှင့် သင့်ပြောင်းလဲမှုကို ပြန်ပြုလုပ်ရန် နည်းလမ်းကို ပြသည်။
- US survey feet ရှိ မော်ဒယ်ကို ပေတစ်ခုလျှင် 0.3048 m အဖြစ် ဖတ်ခဲ့သည် 0.3048006096 m အစား၊ ထို့ကြောင့် US feet ရှိ georeferenced IFC အားလုံး မြေပုံပေါ်တွင် ရွေ့သွားခဲ့သည်။
- Family editor: ပိတ်လိုက်သည့်အခါ keyboard focus ကို စာမျက်နှာသို့ မပြောင်းတော့ပါ၊ ဖုန်းပေါ်တွင် Save သည် မြင်ရဆဲ ဖြစ်သည်၊ နှင့် field များက ဖုန်းကို zoom မလုပ်စေတော့ပါ။

## အက်ပ်အားလုံးတွင်

- **ယူနစ်များ။** {{ui:Settings}} › {{ui:General}} › {{ui:Units}} တွင် အရှည်၊ ဧရိယာ၊ ထုထည်၊ ထောင့်နှင့် စောင်း အတွက် စာရင်း တစ်ခုစီ ရှိသည်၊ ယူနစ်များ၏ သတ်မှတ်ချက်များက ပေးသော တိကျသော အရွယ်အစားများဖြင့် (US survey foot သည် ကိုယ်ပိုင် ယူနစ်)။ သင်မသုံးသော ယူနစ်များကို ပိတ်ပါက ယူနစ်စာရင်းမှ ထွက်သွားသည်; ကြယ်ပွင့်တပ်ပါက အသစ် အလုပ်များ ထိုယူနစ်ဖြင့် စတင်သည်။ ဖိုင်တစ်ခုသည် ၎င်း၏ ကိုယ်ပိုင် ယူနစ်ကို အမြဲ ထိန်းသည်။ BimCraft တွင် toolbar ရှိ {{ui:Units}} စာရင်းသည် ခလုတ်များကို လိုက်သည်၊ ကြယ်ပွင့်က toolbar တွင် သင်ရွေးမချင်း ပြသမှု ယူနစ်များကို သတ်မှတ်သည် (ယခင် ရွေးချယ်မှု ထိန်းသိမ်းထား)၊ နှင့် ဆွဲကိရိယာများ၏ အရှည် အကွက်များက မည်သည့်ယူနစ် အမှတ်အသားမဆို လက်ခံသည်၊ ဥပမာ `3.5 m` သို့မဟုတ် `10 US ft`။ [ယူနစ်များ၊ ရိုက်ထည့်သော တန်ဖိုးများနှင့် ယူနစ် စာရင်းများ](common:unit-lists) ကို ကြည့်ပါ။
- **ပိုသိပ်သော အပြင်အဆင်နှင့် ပျောက်သွားသော panel များ။** {{ui:Settings}} › {{ui:General}} › {{ui:Layout density}} › {{ui:Compact}} သည် မျက်နှာပြင်ပေါ်တွင် ပိုထည့်နိုင်သည် (touch screen နှင့် ဖုန်းများက ခလုတ်ကြီးများကို ထိန်းသည်)။ Side panel တိုင်းတွင် ပါးသော ခေါင်းစဉ်ဘား ရှိပြီး ၎င်းကို ဆွဲ၍ ဆိုင်ခွဲ သို့မဟုတ် လွတ်ထားနိုင်သည်၊ အခြား panel ၏ ဘားပေါ်သို့ ချပြီး frame တစ်ခုတည်းကို tab များအဖြစ် မျှဝေနိုင်သည်၊ ဘေးသို့ ပြေးဝင်စေရန် pin လုပ်နိုင်သည်၊ သို့မဟုတ် ဖျောက်ပြီး ဘေးမှ ပြန်ခေါ်နိုင်သည်။ [panel များကို စီစဉ်ခြင်း](common:arrange-panels#make-the-layout-denser) ကို ကြည့်ပါ။
- **Dialog များ ရွှေ့နိုင်သည်။** Dialog ကို ခေါင်းစဉ်ဘားဖြင့် ဆွဲ၍ ပုံဆွဲနှင့် မထိစေရန် ရွှေ့ပါ; ထားခဲ့ရာသို့ ပြန်ရောက်သည်။ ခေါင်းစဉ်ဘားကို နှစ်ချက်နှိပ်၍ ပြန် ဗဟိုထားနိုင်သည်။ [dialog ရွှေ့ရန်](common:arrange-panels#move-a-dialog) ကို ကြည့်ပါ။
- **AI assistant အတွက် ချက်များ။** သင့်ကိုယ်ပိုင် assistant အတွက် လုပ်ဆောင်ချက် ဆယ်ခု (ပုံဆွဲ သပ်ရပ်အောင်၊ အစုကို ပုံဖော်၊ ပုံဆွဲများ စစ်ဆေး၊ မော်ဒယ်အကြောင်း မေးခွန်း၊ takeoff စုစုပေါင်း၊ part variant စမ်းသပ် …) တစ်ခုစီ၊ ခေါ်သော tools နှင့် လိုအပ်သော ခွင့်ပြုချက်များ၊ နှင့် ကျွန်ုပ်တို့၏ စမ်းသပ်မှုများက ပြန်လည်လုပ်ဆောင်ထားသည်။ အက်ပ်များတွင် AI မပါပါ။ [AI assistant အတွက် ချက်များ](common:assistants-recipes) ကို ကြည့်ပါ။
- **ဘာသာစကားများ။** **Português (Portugal)** သည် {{ui:Settings}} › {{ui:General}} › {{ui:Language}} တွင် အသစ်ဖြစ်သည်။ ၎င်းနှင့် **Português (Brasil)**၊ **Español (México)** နှင့် **Bahasa Indonesia** တို့တွင် ယခု အက်ပ်များ၏ စကားလုံးအားလုံး ရှိသည်၊ မူကြမ်းအဖြစ်၊ ဘာသာစကား ပိုင်ရှင်က မသုံးသပ်ရသေးပါ။ Help topic များသည် အင်္ဂလိပ်ဖြစ်ပြီး အချို့ကို စပိန်ဖြင့်။
- **CadCraft Studio** သည် update စစ်ဆေးမှု မအောင်မြင်သည့်အကြောင်းကို ပြသည် (သင့်စနစ်အတွက် ဖိုင် မရှိသေး၊ network မရှိ၊ signature မှား) "Done" ဟု ရိုးရိုးမပြဘဲ၊ သင်ပိတ်ထားသော What's new ကတ်ကို ပြန်ပေါ်စေခြင်းကို ရပ်ပြီး အသစ်ထွက်မှ ပြန်ပြသည်။

## ယခုဗားရှင်းတွင် မရှိသေးသည်များ

- **0.7 ကို code-sign မလုပ်ထားပါ။** Signing နှင့် Microsoft Store package သည် 0.8 သို့ ရွှေ့သွားသည်၊ အကြောင်းမှာ certificate validation မရောက်သေးသောကြောင့်။ getcadcraft.com/download တွင် ဖိုင်တိုင်းနှင့်အတူ SHA-256 ကို စစ်ဆေးပါ။ Windows တွင် SmartScreen က installer ကို ရပ်ပါက {{ui:More info}} ကို ရွေးပြီး ထို့နောက် {{ui:Run anyway}} ကို ရွေးပါ။ Mac တွင် ပထမဆုံးအကြိမ် CadCraft Studio ကို right-click လုပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ CadCraft Studio သည် app store တွင် မရှိသေးပါ၊ iPad သို့မဟုတ် iPhone build လည်း မရှိသေးပါ။
- {{ui:Units}} ရှိ ထောင့်နှင့် စောင်း စာရင်းများကို သိမ်းထားသော်လည်း ဘယ်အကွက်ကမျှ ဖတ်ခြင်း မရှိသေးပါ။
- Graphics card ပေါ်ရှိ path tracing၊ Render dialog ရှိ အပိုများနှင့် render queue တို့သည် WebGPU လိုအပ်သည် (မရှိလျှင် high quality သည် WebGL path tracer ကို သုံးသည်); live view သည် ဘရောက်ဇာတွင် ရှိလျှင် WebGPU ကို သုံးပြီး မဟုတ်လျှင် WebGL 2 ကို သုံးသည်။ ဤနေရာတွင် software graphics အစားထိုးတစ်ခုတွင်သာ စမ်းသပ်ထားပြီး ထိုအပြင် စစ်မှန်သော graphics card များပေါ်တွင် မစမ်းသပ်ရသေးပါ။ Live view တွင် BimCraft ၌ scatter သို့မဟုတ် sharing မပါပါ (ModelCraft တွင် ရှိသည်)။
- Recorded walkthrough ကို ဗီဒီယိုအဖြစ် render လုပ်ခြင်းကို BimCraft တွင် built-in မလုပ်ရသေးပါ။
- Design checks: IFC profile အမည်သည် W၊ S၊ IPE၊ HEA သို့မဟုတ် HEB အရွယ် မဟုတ်သော (သို့မဟုတ် အရွယ်သည် ကွဲပြားသော) I-shape ကို welded ဟု ယူပြီး "not checked" ပြန်ပေးသည်၊ tube၊ angle၊ channel၊ ပါးသော အစိတ်အပိုင်းနှင့် torsion ကဲ့သို့ပင်။ Engineer တစ်ဦးက စစ်ဆေးချက်များကို သုံးသပ်ခြင်း မရှိသေးပါ။
- ဆွဲထားသော element များကို တစ်ခုချင်း မိတ္တူကူး၊ လှည့်၊ ထင်ပြောင်း သို့မဟုတ် array မလုပ်နိုင်ပါ (အဆင့်တစ်ခုလုံးကို ကူးနိုင်သည်)၊ နှင့် split နံရံ၊ Text tool သို့မဟုတ် curtain wall မရှိပါ။ အထက်အဆင့်ပေါ်ရှိ နံရံသည် အောက်အဆင့်မှ နံရံတစ်ခုနှင့် တွေ့သောအခါ ထိုနံရံ၏ 3D ကိုယ်ထည်ထဲသို့ မဖြတ်ပါ၊ schedule များက အထက်အဆင့်ရှိ အပေါက်ကို ၎င်းနံရံ၏ ကိုယ်ပိုင် အဆင့်အောက်တွင် စာရင်းပြုသည်။
- Family စာကြည့်တိုက် (ပရောဂျက်များကြား မျှဝေသော) မဆောက်ရသေးပါ။ Family များနှင့် ကူးထားသော အဆင့်များကို အခြား BIM ပရိုဂရမ်များတွင် မဖွင့်ရသေးပါ။
- MEP: စက်ပစ္စည်းများသည် generic ဖြစ်ပြီး (ထုတ်လုပ်သူ data မပါ)၊ steel spool များပေါ်ရှိ tee နှင့် reducer များသည် generic ဖြစ်ပြီး ASME B16.9 ဇယားမှ မဟုတ်ပါ၊ {{ui:Library}} tab မှ နေရာချထားသော library ပစ္စည်းများ၏ port များကို IFC တွင် မရေးပါ၊ ဘာမျှ engineer တစ်ဦးက မသုံးသပ်ရသေးပါ။
- Plant add-on သည် ဆွဲထားသော လမ်းကြောင်းကို model ထဲသို့ မဆွဲနိုင်သေးပါ၊ isometric များပေါ်ရှိ spool များကို နံပါတ်မပေးနိုင်သေးပါ၊ သို့မဟုတ် library မှ နေရာချထားသော စက်ပစ္စည်း၏ layout ကို မစစ်ဆေးနိုင်သေးပါ။
- CivilCraft ၏ plant library မှ plant များကို BimCraft ၏ {{ui:Library}} tab မှ မနေရာချနိုင်သေးပါ။
- Energy: နာရီအလိုက် simulation မရှိ၊ ISO 52016-1 နည်းလမ်းမရှိ၊ climate ဖိုင်မရှိ။ Assets: BimCraft ပိတ်ထားစဉ် ဖတ်ရှုချက်များ ထိန်းသိမ်းခြင်း သို့မဟုတ် သတိပေးချက် ပို့ခြင်း လုပ်သော hosted twin မရှိပါ။
- Scan ပြန်ညှိခြင်းကို စမ်းသပ် scan များတွင် စမ်းသပ်ပြီးပြီ၊ စစ်မှန်သော scanner ၏ scan အစုတွင် မစမ်းသပ်ရသေးပါ; E57 ဖိုင်များသည် အမှတ် 6 သန်းနှင့် 512 MB အထိသာ ဖွင့်နိုင်သေးသည်။
- Project bundle များသည် BimCraft တွင်သာ ဖွင့်သည် (အခြား app များက **Open in …** ဖြင့် layout ကို လက်ခံသည်)၊ bundle နှင့် နှစ်ပရိုဂရမ် kit ကို stand-in များဖြင့်သာ စမ်းသပ်ပြီး Archicad သို့မဟုတ် Revit ကိုယ်တိုင်ဖြင့် မစမ်းသပ်ရသေးပါ။
