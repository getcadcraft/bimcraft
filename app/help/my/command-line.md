## သင်လုပ်မည့်အရာ

ကိရိယာများကို အမည်ရိုက်ထည့်ခြင်းဖြင့် အသုံးပြုပါ၊ ကွက်တစ်ခုအရင် နှိပ်စရာ မလိုပါ။

## အဆင့်များ

1. Command line ပါသော layout ကို ရွေးပါ- {{ui:Settings}} ကို ဖွင့်ပါ၊ {{ui:Global}} ကို ရွေးပါ၊ ထို့နောက် {{ui:Layout}} ကို ရွေးပြီး **Duncan** (သို့မဟုတ် **Rhino**) ကို ရွေးပါ။ Line သည် ပြတင်းပေါက်အောက်ခြေရှိ status strip တွင် ရှိသည်။
2. မောက်စ်ဘယ်နေရာမဆို ရှိပြီး ပွင့်နေသော ကွက်မရှိသောအခါ `wall` ဟု ရိုက်ပါ။ စာလုံးများသည် command line တွင် ပေါ်ပြီး အထက်ရှိ စာရင်းတွင် ကိုက်ညီသော command များ ပြသည်။
3. {{key:Enter}} ကို နှိပ်ပါ။ Wall ကိရိယာ စတင်သည်။
4. Command line ကို နှိပ်ပါ (သို့မဟုတ် ခလုတ်တစ်ခု ထပ်နှိပ်ပါ)။ Line ဗလာဖြစ်နေသောအခါ စာရင်းတွင် ယခင်က ရိုက်ခဲ့သော command များ ပြသည်။ {{key:Up}} နှင့် {{key:Down}} ဖြင့် လှည့်ကြည့်ပြီး {{key:Enter}} ဖြင့် ပြနေသည့်အရာကို run ပါ။

## ရိုက်နိုင်သည့်အရာများ

- သုံးနေသော menu ပုံစံ၏ command စကားလုံး၊ ထိုပုံစံတွင် ရှိလျှင် (Drafting ပုံစံတွင် `WALL`၊ `WA`၊ `DOOR`)။
- Command ၏ key ကို စကားလုံးအဖြစ်၊ ဥပမာ `W` ထို့နောက် {{key:Enter}} သို့မဟုတ် {{key:Space}} သည် Wall ဖြစ်သည်၊ `D` သည် Door ဖြစ်သည်။
- Command ၏ အမည်ကို နေရာခြားခြင်းဖြင့် သို့မဟုတ် မခြားဘဲ၊ ဥပမာ `split wall`၊ `wallrectangle`။
- စကားလုံး သို့မဟုတ် အမည်၏ အစ၊ command တစ်ခုတည်းသာ ထိုသို့ စသည့်အခါ။
- ကျန်တာအားလုံးသည် command finder ကို သင်ရိုက်ထားသည့်အရာဖြင့် ဖွင့်သည်။

## သိထားသင့်သည်များ

- {{key:Esc}} သည် line ကို ရှင်းပြီး ကီးများကို ပုံဆွဲထံ ပြန်ပေးသည်။
- ဤ layout များတွင် စာလုံးတစ်လုံးတည်းသည် ကိုယ်တိုင် ကိရိယာ မစတင်တော့ပါ၊ {{key:Enter}} သို့မဟုတ် {{key:Space}} ကို စောင့်ပြီး line တွင် စောင့်နေသည်။ {{key:Ctrl}} ပါသော ကီးများ၊ function keys၊ {{key:Delete}} နှင့် {{key:Esc}} တို့သည် ယခင်အတိုင်း အလုပ်လုပ်သည်။ အခြား layout များတွင် ဘာမျှ မပြောင်းပါ။
- Draw ကိရိယာ run နေစဉ် ဂဏန်းများသည် ကိရိယာထံ ကျန်နေသည် (ရိုက်ထည့်ထားသော အရှည်)။
- ကွက်၊ dialog သို့မဟုတ် Settings ထဲတွင် ရိုက်ခြင်းသည် ထိုနေရာတွင်သာ ရှိနေသည်။
- သမိုင်းကို ဤကွန်ပျူတာတွင် မှတ်ထားပြီး app တစ်ခုလျှင် command 50 ခု ရှိသည်။
