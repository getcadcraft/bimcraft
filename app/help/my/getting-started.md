BimCraft သည် CadCraft မိသားစု၏ အဆောက်အအုံ-မော်ဒယ် အက်ပ် ဖြစ်သည်။ ဤ build တွင် အဆောက်အအုံဖိုင်များကို **ဖွင့်၊ ဖတ်ပြီး စစ်ဆေးသည်**၊ နှင့် IFC မော်ဒယ်များ၏ ဒေတာကို **တည်းဖြတ်သည်**။ ၎င်းသည် element အသစ်များကို ဆွဲ သို့မဟုတ် မော်ဒယ်လုပ်ခြင်း မရှိသေးပါ။ မော်ဒယ် ကြည့်ရှုသူနှင့် စစ်ဆေးသူတစ်ခု အဖြစ် စဉ်းစားပါ၊ IFC ဖိုင်ရှိ အမည်များ၊ tag များနှင့် property တန်ဖိုးများကို ပြင်ဆင်ခွင့်လည်း ရှိသည်။

ဖွင့်နိုင်သောအရာများ-

| ဖိုင် | ရရှိမည့်အရာ |
|---|---|
| IFC (`.ifc`) | 3D ဖြင့် မော်ဒယ်အပြည့်အစုံ- orbit၊ အထပ်များ၊ element ဂုဏ်သတ္တိများနှင့် အမည်များနှင့် property တန်ဖိုးများ တည်းဖြတ်ခြင်း |
| Project and family files (`.rvt`, `.rfa`, `.rte`, `.rft`) | ဖိုင်ကတ်: သိမ်းထားသော release၊ ပရောဂျက် အချက်အလက်၊ preview ပုံနှင့် ချိတ်ဆက်ထားသော ဖိုင်များ။ 3D မပါ။ |
| DWG and DXF | 2D ဖြင့် ပုံဆွဲ- model space နှင့် sheet တိုင်း၊ layer များ၊ ချိတ်ဆက်ထားသော ပုံဆွဲများ၊ print view၊ tag ပါသော အစားအသောက်ဝန်ဆောင်မှု ပုံဆွဲများအတွက် equipment ဇယား |
| A project folder | ဖိုဒါရှိ မော်ဒယ်တိုင်း၏ အစီရင်ခံစာ- backup များ၊ link များ၊ ပျက်စီးသော မိတ္တူများနှင့် မည်သည့်ဖိုင်ဖြင့် စရမည်ကို အကြံပြုချက် |

အရာအားလုံးသည် သင့်ဘရောက်ဆာတွင်၊ သင့်ကွန်ပျူတာပေါ်တွင် ဖြစ်သည်။ **ဘာမျှ မတင်ပါ။** အသေးစိတ်အတွက် [BimCraft ဖွင့်ပြီး သိမ်းသော ဖိုင်များ](topic:files) ကို ကြည့်ပါ။

## BimCraft ကို ဖွင့်ခြင်း

1. ယခုအချိန်ရှိ ဘရောက်ဆာတစ်ခုတွင် BimCraft ကို ဖွင့်ပါ။ Chrome၊ Edge၊ Firefox နှင့် Safari အားလုံး အလုပ်လုပ်သည်; [ဘရောက်ဆာများ၊ စက်ပစ္စည်းများနှင့် memory](topic:platforms) တွင် ကွာခြားချက်များ ဖော်ပြထားသည်။
2. "Open a building model." ဟု ပြသော အလွတ် ဖန်သားပြင်ကို စောင့်ပါ။

:::note
BimCraft သည် ဘရောက်ဆာတွင် လည်ပတ်ပြီး၊ CadCraft Studio အတွင်း desktop ပေါ်တွင် အခြားအက်ပ်များနှင့်အတူ လည်ပတ်သည်။ Cloud သိမ်းခြင်း မရရှိသေးပါ- သင့်ကွန်ပျူတာမှ ဖိုင်ဖွင့်ပြီး မိတ္တူများကို ပြန်သိမ်းပါ။
:::

## ပထမဆုံး မော်ဒယ်ကို ဖွင့်ခြင်း

BimCraft ဘာလုပ်သည်ကို အမြန်ဆုံး မြင်ရန် နည်းလမ်းမှာ IFC ဖိုင် ဖြစ်သည်။

1. ဖန်သားပြင် အလယ်ရှိ {{ui:ဖိုင်ရွေးရန်}} ကို နှိပ်ပါ။
2. {{pick:mac=Finder|windows=File Explorer|linux=သင့် ဖိုင်မန်နေဂျာ}} တွင် `.ifc` ဖိုင်ကို ရွေးပြီး အတည်ပြုပါ။
3. ဖန်သားပြင် အောက်ခြေရှိ status line က "Starting the IFC engine…" ထို့နောက် "Building geometry" ဟု ပြသနေစဉ် စောင့်ပါ။

ဖန်သားပြင် အလယ်တွင် မော်ဒယ်ကို 3D ဖြင့် မြင်ရမည်၊ ဘယ်ဘက်တွင် {{ui:ဖိုင်}} panel နှင့် {{ui:အထပ်များ}} စာရင်း၊ ညာဘက်တွင် ဗလာ {{ui:ဂုဏ်သတ္တိများ}} panel ကို မြင်ရမည်။ Status line သည် "Opened" နှင့် element အရေအတွက်ဖြင့် အဆုံးသတ်သည်။

:::tip
ဖိုင်ကို {{pick:mac=Finder|windows=File Explorer|linux=သင့် ဖိုင်မန်နေဂျာ}} မှ စာမျက်နှာပေါ်သို့ တိုက်ရိုက် ဆွဲချနိုင်သည်။ ဆွဲနေစဉ် ဖန်သားပြင်က "Drop to open" ဟု ပြသည်။
:::

:::offline
BimCraft ကို အော့ဖ်လိုင်းသုံးရန် သိမ်းထားခြင်း မရှိပါက IFC engine သည် IFC မော်ဒယ် ပထမဆုံး ဖွင့်သည့်အခါ ဆိုက်မှ တင်သည်။ DWG နှင့် DXF ပုံဆွဲများ၊ ပရောဂျက်ဖိုင်များနှင့် ဖိုဒါများသည် အပိုမလိုပါ- ၎င်းတို့၏ ဖတ်ရှုကိရိယာများသည် အက်ပ်၏ အစိတ်အပိုင်း ဖြစ်သည်။ app bar ခလုတ်က {{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ဟု ပြပါက အရာအားလုံး အော့ဖ်လိုင်းတွင် ဖွင့်နိုင်သည်။ မဟုတ်ပါက ပြန်ချိတ်ဆက်သည်အထိ IFC မော်ဒယ်များ မဖွင့်နိုင်ပါ၊ ဤ tab တွင် ဖွင့်ပြီးသားဖြစ်ခဲ့လျှင် မှလွဲ၍။ [အွန်လိုင်းနှင့် အော့ဖ်လိုင်း](topic:online-offline) ကို ကြည့်ပါ။
:::

:::online
အင်တာနက် မရှိသော နေရာသို့ သွားမလား? app bar ရှိ {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ကို နှိပ်ပြီး {{ui:အော့ဖ်လိုင်း အဆင်သင့်}} ကို စောင့်ပါ။ သိမ်းထားသော မိတ္တူ (11 MB ခန့်) တွင် IFC engine ပါဝင်သည်။ [အော့ဖ်လိုင်း လုပ်ဆောင်ခြင်း](common:offline) ကို ကြည့်ပါ။
:::

## ပတ်ပတ်လည် ကြည့်ခြင်း

:::mouse
1. ဘယ် mouse ခလုတ်ဖြင့် ဆွဲ၍ မော်ဒယ် ပတ်ပတ်လည် orbit လုပ်ပါ။
2. ဘီးကို လှိမ့်၍ zoom လုပ်ပါ။
3. ညာ mouse ခလုတ်ဖြင့် ဆွဲ၍ pan လုပ်ပါ။ Mac trackpad တွင် {{key:Shift}} ကို ဖိထားပြီး ဆွဲပါ။
4. {{key:F}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:ကိုက်ညီအောင်}} ကို နှိပ်ပြီး မော်ဒယ်တစ်ခုလုံးကို ပြန်ကြည့်ပါ။
:::

:::touch
1. လက်ချောင်းတစ်ချောင်းဖြင့် ဆွဲ၍ orbit လုပ်ပါ။
2. လက်ချောင်းနှစ်ချောင်းဖြင့် pinch လုပ်၍ zoom လုပ်ပြီး လက်နှစ်ချောင်းကို အတူတကွ ရွှေ့၍ pan လုပ်ပါ။
3. {{ui:ကိုက်ညီအောင်}} ကို တို့ပြီး မော်ဒယ်တစ်ခုလုံးကို ပြန်ကြည့်ပါ။
:::

## အမှန်တကယ် တစ်ခု လုပ်ကြည့်ပါ- tag တစ်ခု ပြင်ခြင်း

1. မော်ဒယ်ရှိ နံရံ၊ တံခါး သို့မဟုတ် element မည်သည့်တစ်ခုကို နှိပ်ပါ။ အပြာရောင်ပြောင်းပြီး ၎င်း၏ ဂုဏ်သတ္တိများ ညာဘက်တွင် ပေါ်လာသည်။
2. {{ui:ဂုဏ်သတ္တိများ}} panel တွင် **Tag** ဘေးရှိ တန်ဖိုးကို နှိပ်ပါ။
3. Tag အသစ်ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
4. ဘယ်ဘက်တွင် ဖွင့်လာသော {{ui:ပြောင်းလဲမှုများ}} အပိုင်းကို ကြည့်ပါ: သင့်ပြောင်းလဲမှုကို ဟောင်းနှင့် အသစ် တန်ဖိုးဖြင့် စာရင်းပြသည်။

## မိတ္တူ သိမ်းခြင်း

1. {{ui:ပြောင်းလဲမှုများ}} အပိုင်းရှိ {{ui:IFC အဖြစ် သိမ်းရန်}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{key:Mod+S}} ကို နှိပ်ပါ။
2. ဒေါင်းလုဒ်ဖိုဒါတွင် ဖိုင်အသစ်ကို ရှာပါ။ မူလအမည်အနောက်တွင် " (edited)" ထည့်ထားသော အမည် ဖြစ်ပြီး ဥပမာ `Clinic (edited).ifc` ဖြစ်သည်။

မူလဖိုင်ကို ဘယ်တော့မျှ မပြောင်းပါ။ [IFC ဂုဏ်သတ္တိများ ပြင်ပြီး တည်းဖြတ်ထားသော မိတ္တူ သိမ်းခြင်း](topic:edit-ifc-properties) တွင် တည်းဖြတ်ခြင်းကို အပြည့်အစုံ ရှင်းပြသည်။

- [ပရောဂျက် ဖိုဒါတစ်ခုလုံး ဖွင့်ခြင်း](topic:open-project-folder)- ပရောဂျက်ဖိုဒါကို ညွှန်ပြပြီး ဖိုင်များကို စီစေပါ။
