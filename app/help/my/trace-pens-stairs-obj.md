## အဆင့်ကို ခြေရာခံခြင်း

{{ui:Build}} မီနူးမှ {{ui:ခြေရာခံ}} ကို ရွေးပြီး စာရင်းထဲမှ view တစ်ခုကို ရွေးပါ: အခြားအဆင့်၏ ပလန်၊ အဆင့်၏ ခုံမျက်နှာကြက်ပလန် သို့မဟုတ် callout (crop သို့ ဖြတ်ထားသော)။ ၎င်း၏ နံရံ၊ ကော်လံနှင့် ကြမ်းပြင်များသည် သင်ဆွဲနေသော ပလန်အောက်တွင် မျဉ်းစဉ်းဖြင့် ပေါ်သည်။ ရည်ညွှန်းပေါ်ရှိ base point ကို နှိပ်ပြီး ထို point သွားရမည့်နေရာကို နှိပ်ခြင်းဖြင့် ရွှေ့နိုင်သည်၊ သို့မဟုတ် X၊ Y နှင့် angle ကို ရိုက်ပါ (ကိုယ်ပိုင်အလယ်ဗဟိုကို ပတ်၍ လှည့်သည်)။ {{ui:ပြန်စရန်}} က ပြန်ထားသည်၊ {{ui:ဖျောက်ရန်}} က ဖယ်ရှားသည်။ ၎င်းသည် ရည်ညွှန်းသက်သာသာ သာဖြစ်ပြီး ဘယ်သူမှ မရွေးနိုင်၊ ပုံမထုတ်၊ IFC တွင်လည်း မသိမ်းပါ။ BimCraft သည် ဤဘရောက်ဆာတွင် အဆင့်တစ်ခုစီအတွက် မှတ်ထားသည်။

## view တစ်ခုစီအတွက် ဆေးတံများ

{{ui:ဆေးတံများ}} ကို ရွေးပါ။ ဆေးတံအတွက် ရည်ရွယ်ချက်ကို ပြောပါ: နံရံအားလုံး၊ တံခါးအားလုံး၊ ပြတင်းပေါက်အားလုံး၊ ရွေးထားသော ဒြပ်စင်၏ အမျိုးအစား၊ သို့မဟုတ် ရွေးထားသော ဒြပ်စင်များ။ အထူ၊ မျဉ်းပုံစံ (solid၊ dashed၊ dotted) နှင့် အရောင် ရွေးပြီး {{ui:အသုံးပြုရန်}} ကို နှိပ်ပါ။ ပြောင်းလဲမှုသည် ဤအဆင့်၏ ပလန်အတွက်သာ ဖြစ်သည်။ ရွေးချယ်မှုက အမျိုးအစားကို အနိုင်ရသည်၊ အမျိုးအစားက အမျိုးအစားတစ်ခုလုံးကို အနိုင်ရသည်။ {{ui:အားလုံး ဖျက်ရန်}} က အားလုံးဖယ်သည်။ ၎င်းတို့ကို ဤဘရောက်ဆာတွင် သိမ်းထားသည်။ 3D view တွင် အရောင်ဆေးတံများကို မော်ဒယ်ပေါ် ဆေးရန် **3D တွင် ဆေးတံအရောင်များ** ကို အမှတ်ခြစ်ပါ (အထူ သို့မဟုတ် dash သည် မျဉ်း၏ ဖြစ်သည်၊ ထို့ကြောင့် အရောင်သာ ပြသည်); ပြန်ဖျက်ရန် အမှတ်ခြစ်ဖြုတ်ပါ။ {{ui:ပရင့်ထုတ်ရန်}} က ပလန်၏ PDF ပေါ်တွင် ဆွဲပေးသည်: အထူသည် မျက်နှာပြင်မှ စကေးချသည် (ပုံသေ နံရံဆေးတံ 1.75 pixel သည် 0.5 mm)၊ dash များ dash အဖြစ် ကျန်ပြီး အရောင်သည် paper-theme တန်ဖိုးဖြင့် ပရင့်ထွက်သည်။

## ပုံဖော်မှုမှ လှေကား

{{ui:လှေကား ပုံဖော်ရန်}} ကို ရွေးပြီး လမ်းလျှောက်မျဉ်း၏ ထောင့်များကို အောက်ဆုံးခြေလှမ်းက အရင်ဖြစ်အောင် နှိပ်ပါ။ မျဉ်းတစ်ကြောင်းသည် ဖြောင့်လှေကား၊ ထောင့်ဉီးဖြင့် တွေ့သော မျဉ်းနှစ်ကြောင်းသည် L၊ မျဉ်းသုံးကြောင်း (အပေါ်၊ ဖြတ်၊ ပြန်) သည် U ဖြစ်သည်။ landing ဆွဲရန် {{key:L}} ကို နှိပ်ပါ: ထောင့်များ နှိပ်ပြီး {{key:Enter}} နှိပ်ပါ၊ တိုသော ဘက်က လှေကား၏ အကျယ်ကို သတ်မှတ်သည်။ လှေကားကို ချရန် {{key:Enter}} ကို နှိပ်ပါ။ တစ်ခုစီ tread ကို မျဉ်း၏ အရှည်နှင့် အမြင့်အတွက် လိုအပ်သော riser အရေအတွက်မှ တွက်ချက်သည်။ ထို့နောက် ၎င်းသည် ပုံမှန်လှေကား ဖြစ်သည်: ဂုဏ်သတ္တိများတွင် ပြောင်းနိုင်ပြီး stairwell နှင့် လက်ရန်းများ လိုက်သည်။

tool အတန်းတွင် **Family အဖြစ် ပြုလုပ်ရန်** ကို အမှတ်ခြစ်ပါ (သို့မဟုတ် {{key:F}} ကို နှိပ်ပါ) {{key:Enter}} မနှိပ်မီ၊ ထိုအခါ လှေကားကို family (ဖြောင့်၊ L သို့မဟုတ် U) အဖြစ် ချသည်။ ၎င်းသည် ဒြပ်စင်တစ်ခုအဖြစ် ဝင်လာပြီး family editor တွင် အကျယ်၊ tread၊ စုစုပေါင်းအမြင့်၊ လှေကားတစ်ထပ်စီ၏ tread များနှင့် U ၏ ကွာဟချက်ကို parameter များအဖြစ် ဖွင့်ပေးသည်၊ ထို့ကြောင့် အရွယ်အစား၊ ပလန်သင်္ကေတ သို့မဟုတ် hotspot များ ထည့်နိုင်သည်။ အဆင့်များနှင့် riser အမြင့်သည် ၎င်းတို့မှ လိုက်သည်။ လက်ရန်းနှင့် stairwell မပါပါ: ၎င်းတို့သည် ပုံမှန်လှေကားနှင့်သာ သက်ဆိုင်သည်။

## OBJ ဖွင့်ခြင်း

`.obj` ဖိုင်ကို အခြားဖိုင်တိုင်းကဲ့သို့ ဖွင့်ပါ။ OBJ တွင် ယူနစ် မရှိပါ၊ ထို့ကြောင့် BimCraft သည် Y အပေါ်သို့ရှိသော မီတာများအဖြစ် ဖတ်သည်၊ ပရိုဂရမ်အများစု ရေးသည့်အတိုင်း။ object သို့မဟုတ် group တိုင်းသည် အဆင့်တစ်ခုတည်းပေါ်တွင် mesh ဒြပ်စင်တစ်ခု ဖြစ်လာပြီး၊ ထို့နောက် ကြည့်ခြင်း၊ တိုင်းတာခြင်း၊ ပုံဖြတ်ခြင်း၊ မော်ဒယ်ထဲ ထည့်ခြင်းနှင့် IFC အဖြစ် သိမ်းနိုင်သည်။ မျဉ်း၊ ကွေးနှင့် မျက်နှာပြင်များကို ချန်လှပ်ထားပြီး status line က ထိုသို့ ပြောသည်။

object တစ်ခုသည် အတိအကျ ဖြောင့်ထောင့်ပုံ prism ဖြစ်လျှင် (အဆုံးမျက်နှာ နှစ်ခုသည် မျဉ်းပြိုင်နှင့် တူညီသော၊ ဘေးမျက်နှာများ ထောင့်မှန်ဖြစ်သော ပိတ်သည့် mesh: slab၊ post၊ wall block၊ အပေါက်ပါ plate) IFC တွင် IFC ၏ ကိုယ်ပိုင် extruded solid အဖြစ် ၎င်း၏ outline နှင့် အနက်ဖြင့် သိမ်းသည်၊ တြိဂံများ စာရင်းအဖြစ် မဟုတ်ပါ။ အခြားပရိုဂရမ်များက ထိုကို တကယ့် solid အဖြစ် ဖတ်ပြီး ၎င်းသည် သေးငယ်နေပြီး နောက်မှ အနက်နှင့် outline ကို ပြင်နိုင်သည်။ status line က ထိုနည်းဖြင့် မည်မျှ object ကို ထိန်းထားသည်ကို ပြောသည်။ prism အတိအကျ မဟုတ်သည်များ (စောင်းသော ပုံ၊ vertex တစ်ခုရွှေ့ထားသော mesh၊ ကွာဟချက်ပါ mesh) တြိဂံအဖြစ် ကျန်သည်။ STEP ဖိုင်ကိုလည်း တူညီစွာ ဖတ်သည်။
