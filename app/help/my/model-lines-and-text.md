## ဘာလုပ်မလဲ

မော်ဒယ်၏ အစိတ်အပိုင်းဖြစ်သော မျဉ်းများနှင့် စာလုံးများကို ဆွဲပါ၊ view တစ်ခု၏ အစိတ်အပိုင်း မဟုတ်ပါ။

## အဆင့်များ

1. ဦးစွာ work plane ကို သတ်မှတ်ပါ (**work plane** ကို ကြည့်ပါ)။ အထပ်ပေါ် plane ကို ပလန်တွင် ဆွဲသည်; ရပ်ထားသော plane ကို Work Plane Viewer တွင် ဆွဲသည်။
2. မျဉ်းအတွက် **Build** မီနူးတွင် **Model Line** ကို ရွေးပြီး **Line**၊ **Polyline** သို့မဟုတ် **Arc (three points)** ကို ရွေးပါ:
   - မျဉ်းတစ်ခုသည် နှိပ်ချက် နှစ်ချက် ဖြစ်သည်;
   - polyline သည် အမှတ်တစ်ခုစီအတွက် နှိပ်ချက်တစ်ခုစီ ဖြစ်ပြီး၊ ထို့နောက် Enter သို့မဟုတ် နှစ်ကြိမ်နှိပ်ပါ။ ပထမအမှတ်ကို နှိပ်လျှင် ပိတ်သည်;
   - arc သည် နှိပ်ချက်သုံးချက် ဖြစ်သည်: စတင်အမှတ်၊ ဖြတ်သွားသော အမှတ်၊ အဆုံးအမှတ်။
3. စာသားအတွက် **Model Text** ကို ရွေးပါ။ စာလုံးများကို ရိုက်ပါ၊ အကြီးစာလုံး အမြင့်နှင့် အနက်ကို သတ်မှတ်ပါ၊ ထို့နောက် စာသား စတင်ရမည့် နေရာကို နှိပ်ပါ (baseline ၏ ဘယ်ဘက်အဆုံး)။
4. မျဉ်း သို့မဟုတ် စာသားကို ရွေး၍ **Properties** တွင် ကြည့်ပါ။ စာသား၏ စာလုံး၊ အမြင့်နှင့် အနက်ကို ထိုနေရာတွင် ပြောင်းနိုင်သည်။ ဖျက်ရန် (Delete) ဖြင့် ဖယ်ရှားသည်။

## ပြသမည့်နေရာ

- မော်ဒယ်မျဉ်းကို ၎င်း၏ အထပ်၏ ပလန်၊ 3D view၊ elevation နှင့် section panel တွင် ပြသည်၊ အလားတူ work plane ပေါ်တွင် ရှိသောအခါ Work Plane Viewer တွင်လည်း ပြသည်။ drafting line (Annotate, Line) သည် view တစ်ခုတည်းနှင့်သာ သက်ဆိုင်သည်။
- မော်ဒယ်စာသားသည် အစိုင်အခဲ (solid) ပုံသဏ္ဍာန် ဖြစ်သည်- မော်ဒယ်ပြသသည့်နေရာတိုင်း၊ ပလန်၊ 3D၊ elevation နှင့် section များနှင့် စာရွက်များပေါ်တွင် ပြသည်။
- မော်ဒယ်မျဉ်းများကို ပုံနှိပ်စာရွက်များပေါ်တွင် ယခုထိ မဆွဲသေးပါ။ မော်ဒယ်စာသားကို ဆွဲသည်။

## Font

မော်ဒယ်စာသားသည် စာရွက်များနှင့် PDF များနှင့် တူညီသော font ကို သုံးသည်: Liberation Sans၊ SIL Open Font License အောက်တွင်။ Font တွင် မရှိသော စာလုံးကို မေးခွန်းအမှတ် (?) အဖြစ် ဆွဲပြီး မည်သည့်စာလုံးဖြစ်ကြောင်း အသိပေးသည်။ Font တစ်ခုနှင့် အလေးချိန်တစ်ခုသာ ရှိသည်။ စာလုံးများကို font ၏ ကိုယ်ပိုင် အကျယ်များဖြင့် ခြားသည်၊ kerning မပါပါ။

## IFC ဖိုင်တွင်

- မော်ဒယ်မျဉ်းသည် object type ModelLine ပါသော IfcAnnotation ဖြစ်သည်။ ၎င်း၏ ပုံသဏ္ဍာန်သည် 3D curve ဖြစ်သည်: polyline တစ်ခု၊ သို့မဟုတ် arc အတွက် trimmed circle။
- မော်ဒယ်စာသားသည် object type ModelText ပါသော IfcBuildingElementProxy ဖြစ်သည်။ ၎င်း၏ ပုံသဏ္ဍာန်သည် စာလုံးအစိတ်အပိုင်းတစ်ခုစီအတွက် extruded solid တစ်ခုဖြစ်ပြီး O နှင့် B ကဲ့သို့ စာလုံးများ၏ အပေါက်များ ပါသည်။ ၎င်း၏ ပမာဏများမှာ မျက်နှာ ဧရိယာနှင့် ထုထည် (မျက်နှာ ဧရိယာ × အနက်) ဖြစ်သည်။

## သိထားရန်

- မည်သည့်အရွယ်အစားမဆို တောင်းဆိုသည့်အတိုင်း ပြုလုပ်သည်။ အလျား မရှိသော မျဉ်း၊ အမှတ်သုံးချက် တစ်ကြောင်းတည်း ရှိသော arc၊ သို့မဟုတ် စာလုံးမပါသော စာသား ကိုသာ ငြင်းပယ်သည်၊ ပြုလုပ်စရာ မရှိသောကြောင့်။
- မျဉ်းတစ်ခုစီနှင့် စာသားတစ်ခု သို့မဟုတ် ၎င်းကို ပြောင်းလဲမှုတိုင်းသည် ပြန်ဖျက်ရန် (Undo) အဆင့်တစ်ခု ဖြစ်သည်။
