## ဘာလုပ်မလဲ

ပရောဂျက် ဖိုဒါတစ်ခုလုံးကို ဖွင့်ပါ၊ ဥပမာ အလုပ်တစ်ခုအတွက် ပေးထားသော ဖိုဒါ — BimCraft က ကျန်တာကို စီစဉ်ပေးသည်: ဘယ်မော်ဒယ်တွေ ရှိသလဲ၊ ဘယ်မိတ္တူတွေက backup ဖြစ်သလဲ၊ ဘာနဲ့ ဘာကို ချိတ်ထားသလဲ၊ ဘယ်ဖိုင်တွေ ပျက်စီးနေသလဲ၊ နဲ့ ဘယ်ဖိုင်ကို သင်ဖွင့်ချင်ဖွယ်ရှိသလဲ။

မော်ဒယ် card တစ်ခုစီအတွက် လိုအပ်သော ကီလိုဘိုက် အနည်းငယ်သာ ဖတ်သည်၊ ထို့ကြောင့် network drive သို့မဟုတ် sync လုပ်ထားသော cloud ဖိုဒါသည် ရပါသည်။

## အဆင့်များ

:::chromium
1. ဘယ်ဘက်ရှိ {{ui:ဖိုဒါ ဖွင့်ရန်}} ကို နှိပ်ပါ (သို့မဟုတ် အလွတ် screen အလယ်တွင်)။
2. ဖွင့်လာသော window တွင် ပရောဂျက် ဖိုဒါကို ရွေးပြီး **Select** ကို နှိပ်ပါ (သို့မဟုတ် သင့်စနစ်ပေါ်မူတည်၍ **Upload** သို့မဟုတ် **Open**)။
3. browser က "Let site view files?" ဟု မေးသောအခါ **View files** ကို နှိပ်ပါ။ ၎င်းသည် tab ကို ဖိုဒါ ဖတ်ခွင့်သာ ပေးပြီး ဘာမျှ upload မလုပ်ပါ။
4. status line က ရေတွက်နေချိန်ကို စောင့်ပါ: "ဖိုဒါကို စာရင်းပြုနေသည်: … ဖိုင်" ထို့နောက် "Revit ဖိုင်များကို စစ်နေသည်: … မှ …"။
:::

:::firefox
1. ဘယ်ဘက်ရှိ {{ui:ဖိုဒါ ဖွင့်ရန်}} ကို နှိပ်ပါ (သို့မဟုတ် အလွတ် screen အလယ်တွင်)။
2. ဖွင့်လာသော window တွင် ပရောဂျက် ဖိုဒါကို ရွေးပြီး အတည်ပြုပါ။ Firefox က စာမျက်နှာ ဖိုင်များကို ဖတ်ခွင့်ကို အတည်ပြုရန် မေးနိုင်သည်; ဖိုင်များသည် သင့်ကွန်ပျူတာတွင်သာ ရှိနေဆဲ ဖြစ်သည်။
3. status line က "ဖိုဒါကို ဖတ်နေသည်: … ဖိုင်" ထို့နောက် "Revit ဖိုင်များကို စစ်နေသည်: … မှ …" ဟု ပြောသည်အထိ စောင့်ပါ။
:::

:::safari
1. ဘယ်ဘက်ရှိ {{ui:ဖိုဒါ ဖွင့်ရန်}} ကို နှိပ်ပါ (သို့မဟုတ် အလွတ် screen အလယ်တွင်)။
2. ဖွင့်လာသော window တွင် ပရောဂျက် ဖိုဒါကို ရွေးပြီး **Upload** ကို နှိပ်ပါ။ စကားလုံးက ထိုသို့ ဖြစ်သော်လည်း Mac မှ ဘာမျှ မထွက်ပါ: ဖိုင်များကို tab သို့သာ ပေးသည်။
3. status line က "ဖိုဒါကို ဖတ်နေသည်: … ဖိုင်" ထို့နောက် "Revit ဖိုင်များကို စစ်နေသည်: … မှ …" ဟု ပြောသည်အထိ စောင့်ပါ။
:::

ဖိုဒါကို {{pick:mac=Finder|windows=File Explorer|linux=သင့် ဖိုင်မန်နေဂျာ}} မှ စာမျက်နှာပေါ် **ဆွဲချ** နိုင်သည်။ ဆွဲချထားသော ဖိုဒါသည် browser တိုင်းတွင် ခွင့်တောင်းမေးမှု မပါဘဲ ဖွင့်သည်။

## ဘာကို မြင်ရမလဲ

ဖိုဒါ အစီရင်ခံစာက အလယ်တွင် ဖြည့်သည်:

- ဖိုဒါအမည်၊ မော်ဒယ်၊ CAD ပုံဆွဲ၊ IFC မော်ဒယ်နှင့် ဖိုင်များ၏ အရေအတွက်နှင့် စုစုပေါင်း အရွယ်အစား။
- ဖိုင်အချို့ မပြည့်စုံလျှင် အနီ သို့မဟုတ် အဝါရောင် မှတ်စုများ၊ သို့မဟုတ် ဖိုဒါတွင် မရှိသော ချိတ်ဆက်ထားသည့် ဖိုင်များ။
- {{ui:ဤနေရာမှ စတင်ပါ}} အကွက်: BimCraft အကြံပြုသော ဖိုင်နှင့် အကြောင်းရင်းများ။
- **Models**: မော်ဒယ်တစ်ခုလျှင် အတန်းတစ်ခု၊ ၎င်း၏ backup များကို အောက်တွင် အုပ်စုဖွဲ့ထားသည်။
- **Linked and referenced files**၊ **IFC models**၊ **CAD drawings** နှင့် **Set aside** (ဖိုဒါတွင် ရှိသည့်အခါ)။

ဘယ်ဘက်ရှိ {{ui:ဖိုဒါ}} panel က အကျဉ်းချုပ် ပြသည်; **Problems** တွင် မိတ္တူအားလုံး ကောင်းမွန်သည့်အခါ "None" ဟု ပြသည်။

## ဤနေရာမှ စတင်ပါ အကွက်ကို သုံးရန်

အကွက်က ဖိုင်တစ်ခုကို အမည်ပေးပြီး အကြောင်းရင်းကို ပြောပြသည်၊ ဥပမာ:

- "ဤဖိုဒါတွင် အသစ်ဆုံး သိမ်းထားသော အလုပ် (Mar 3, 2025)။"
- "*Consultant.rvt* ကို အခြားမော်ဒယ်များတွင် ချိတ်ထားသဖြင့် ၎င်းသည် နောက်ခံဖြစ်ပြီး တည်းဖြတ်ရမည့် ဖိုင် မဟုတ်ပါ။"
- "*Tower.rvt* သည် ရွေးရန် သင့်တော်ဟု ထင်ရသော်လည်း ပျက်စီးနေသည်; ၎င်း၏ နောက်ဆုံး ကောင်းသော မိတ္တူမှာ … မှ ဖြစ်သည်။"
- "ဤသည်မှာ central model ဖြစ်သည်: Revit တွင် "Create New Local" ဖြင့် ဖွင့်ပြီး local မိတ္တူတွင် လုပ်ပါ။"

1. အကြောင်းရင်းများကို ဖတ်ပါ။
2. ထိုဖိုင်၏ card ကို ဖတ်ရန် {{ui:ကတ်ကို ဖွင့်ရန်}} ကို နှိပ်ပါ၊ သို့မဟုတ် **Models** တွင် ၎င်း၏ အတန်းကို ရှာရန် {{ui:စာရင်းတွင် ပြရန်}} ကို နှိပ်ပါ။
3. မှီခိုမီ နောက်ဆုံး လုပ်ခဲ့သူနှင့် အတည်ပြုပါ။ အကွက်ကလည်း ထိုသို့ ပြောသည်: ၎င်းသည် အမည်၊ ရက်စွဲနှင့် link များမှ ခန့်မှန်းချက်သာ ဖြစ်သည်။

## ဖိုဒါ အစီရင်ခံစာမှ ဖိုင်များ ဖွင့်ရန်

1. မော်ဒယ်အမည်ကို နှိပ်၍ ၎င်း၏ card ကို ဖွင့်ပါ။ card က link တစ်ခုစီကို ဖိုဒါနှင့် စစ်ဆေးသည်။
2. card ၏ ထိပ်ရှိ {{ui:ပြန်သွားရန်}} နှင့် ဖိုဒါအမည်ကို နှိပ်ပါ (သို့မဟုတ် ဘယ်ဘက်ရှိ {{ui:ဖိုဒါသို့ ပြန်ရန်}}) ပြန်သွားရန်။
3. **IFC models** အောက်ရှိ IFC ဖိုင်ကို နှိပ်၍ 3D တွင် ဖွင့်ပါ။
4. **CAD drawings** အောက်ရှိ DWG သို့မဟုတ် DXF ကို နှိပ်၍ 2D တွင် ဖွင့်ပါ။ ၎င်း၏ ချိတ်ဆက်ထားသော ပုံဆွဲများနှင့် ပုံများကို ဖိုဒါတွင် အလိုအလျောက် ရှာတွေ့သည်။

## နောက်မှ ဖိုဒါ ပြန်ဖွင့်ရန်

:::chromium
{{ui:ဖိုဒါ ဖွင့်ရန်}} သို့မဟုတ် ဆွဲချခြင်းဖြင့် ဖွင့်ထားသော ဖိုဒါများကို ဘယ်ဘက်ရှိ {{ui:မကြာမီက ဖိုဒါများ}} အောက်တွင် စာရင်းပြုသည်။ {{ui:ပြန်ဖွင့်ရန်}} နှင့် ဖိုဒါအမည်ကို နှိပ်ပါက ရွေးစရာ မလိုဘဲ ပြန်ဖွင့်သည်။ browser ပြန်စတင်ပြီးနောက် Chrome သို့မဟုတ် Edge က တစ်ကြိမ် ထပ်မေးသည်; မမေးတော့စေရန် "Allow on every visit" ကို ရွေးပါ။ စာရင်းကို ဤ browser တွင်သာ သိမ်းပြီး ဘယ်သို့မျှ မပို့ပါ။ ဖိုဒါကို မေ့ရန် × ကို နှိပ်ပါ။
:::

:::firefox safari
ဤ browser သည် ဖိုဒါများကို လည်ပတ်မှုများကြား မမှတ်ထားနိုင်ပါ။ {{ui:ဖိုဒါ ဖွင့်ရန်}} ဖြင့် ဖိုဒါကို ထပ်ရွေးပါ၊ သို့မဟုတ် ဆွဲချပါ။
:::

## အများဆုံး ဖြစ်တတ်သော အမှားများ

- **အရမ်းကြီးသော ဖိုဒါ ရွေးခြင်း။** ဖိုင် 20,000 ကျော်: "ဤဖိုဒါတွင် ဖိုင် 20,000 ကျော် ရှိသည်။ ပရောဂျက်တစ်ခုလို ပိုသေးသော ဖိုဒါ ရွေးပါ။" ဒရိုက်တစ်ခုလုံးမဟုတ်ဘဲ ပရောဂျက် ဖိုဒါကို ရွေးပါ။
- **ပရောဂျက်များစွာ၏ မိဘဖိုဒါကို ရွေးခြင်း။** ထိုအခါ ဤနေရာမှ စတင်ပါ အကွက်က ပရောဂျက်များကြား ရွေးမည်။ ပရောဂျက် တစ်ခုကို ရွေးပါ။
- **Revit ၏ ကိုယ်ပိုင် ဖိုဒါများကို လျစ်လျူရှုထားသည်ဟု ထင်ခြင်း။** `*_backup`၊ `*_log` နှင့် `Revit_temp` ဖိုဒါများသည် ထိန်းသိမ်းမှု ဖိုဒါများ ဖြစ်ပြီး **Set aside** အောက်တွင် စာရင်းပြုသည်၊ ဖတ်ခြင်း မရှိပါ။
- **card မှ မော်ဒယ်ကို 3D တွင် ဖွင့်မည်ဟု မျှော်လင့်ခြင်း။** ပရောဂျက်ဖိုင်သည် card သာ ဖြစ်သည်။ ၎င်း၏ IFC export ကို ဖွင့်ပါ။
- **ဖုန်းနှင့် tablet များ။** မိုဘိုင်း browser အများအပြားသည် ဖိုဒါများ ရွေးချယ်နိုင်ခြင်း မရှိပါ။ ကွန်ပျူတာ သုံးပါ။
