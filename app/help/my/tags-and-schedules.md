## သင်လုပ်မည့်အရာ

တဂ်သည် သင့်ကိုယ်ပိုင် ဂုဏ်သတ္တိတစ်ခုဖြစ်သည်။ ဥပမာ *Finish* သို့မဟုတ် *Fire rating*။ ပရောဂျက်အတွက် တစ်ကြိမ် သတ်မှတ်ပြီး element အများအပြားတွင် တစ်ပြိုင်နက် သတ်မှတ်နိုင်သည်။ BimCraft ရှိ ဇယားတိုင်းသည် ၎င်းကို ဖတ်နိုင်သည်။ ဤနေရာရှိ တဂ်ဇယား၊ {{ui:ပမာဏများ}}၊ ရှာဖွေခြင်း၊ ဂုဏ်သတ္တိအလိုက် အရောင်ပေးခြင်း နှင့် [မော်ဒယ်မှ စာရွက်စာတမ်းများ](topic:documents-from-the-model)။

## အဆင့်များ

1. IFC မော်ဒယ်တစ်ခု ဖွင့်ပါ၊ သို့မဟုတ် အဆောက်အအုံအသစ် စတင်ပါ။
2. ဘယ်ဘက် panel တွင် {{ui:ပမာဏများ}} အောက်ရှိ {{ui:တဂ်များ}} ကို ဖွင့်ပါ။
3. {{ui:တဂ်ထည့်ရန်}} ကို နှိပ်ပါ။ အမည် ပေးပါ၊ အမျိုးအစား ရွေးပါ၊ လိုအပ်လျှင် ခွင့်ပြုသော တန်ဖိုးများ (ကော်မာဖြင့်) နှင့် ၎င်းအတွက် class များ (`IfcDoor`၊ `IfcWall` …) ကို စာရင်းပြုစုပါ။ {{ui:တဂ်ကို ထည့်ရန်}} ကို နှိပ်ပါ။
4. မော်ဒယ်ထဲရှိ element များကို ရွေးပါ (ရှာဖွေရေးက တံခါးအားလုံးကို တစ်ပြိုင်နက် ရွေးနိုင်သည်)။
5. {{ui:တဂ်ကို တပ်ရန် ရွေးထားသည်များ}} အောက်တွင် သတ်မှတ်လိုသော တဂ်တစ်ခုစီအတွက် တန်ဖိုးကို ရွေးပါ သို့မဟုတ် ရိုက်ပါ၊ အခြားများကို ဆက်ထားပါ၊ ထို့နောက် {{ui:ရွေးထားသော … အစိတ်အပိုင်းများသို့ အသုံးပြုရန်}} ကို နှိပ်ပါ။
6. {{ui:တဂ်ဇယား}} အောက်တွင် ကော်လံများကို အမှန်ခြစ်ပါ၊ filter ထည့်ပါ၊ {{ui:အုပ်စုဖွဲ့ရန်}} ကို ရွေးပါ၊ ထို့နောက် {{ui:CSV ဒေါင်းလုဒ်လုပ်ရန်}}။

## သင်မြင်ရမည့်အရာ

- သိမ်းထားသော ဖွဲ့စည်းပုံတစ်ခုနှင့် တဂ်တပ်ထားသည့် တစ်ခုစီအတွက် ပြောင်းလဲမှုစာရင်းတွင် အဆင့်တစ်ခု။ {{ui:ပြန်ဖျက်ရန်}} က ပြန်ယူသည်။
- တဂ်တစ်ခု မသက်ဆိုင်သော class ရှိ element များကို ထိုတဂ်မှ ချန်ထားပြီး အခြေအနေစာကြောင်းက ဘယ်နှစ်ခုဖြစ်သည်ကို ပြောသည်။
- တဂ်ဇယားသည် element တစ်ခုလျှင် အတန်းတစ်ခု စာရင်းပြုပြီး သင်ရွေးသော အကွက်ဖြင့် အုပ်စုဖွဲ့သည်။ ထို element ကို ရွေးရန် အတန်း၏ ပထမဆဲလ်ကို နှိပ်ပါ။
- {{ui:ပမာဏများ}} သည် တဂ်များကို `CadCraft_Tags` အောက်တွင် စာရင်းပြုသည်။ ထို့ကြောင့် ဧရိယာများ သို့မဟုတ် အရေအတွက်များကို တဂ်အလိုက် ပေါင်းနိုင်သည်။

## အမျိုးအစားများ

အမျိုးအစားများသည် family parameter များနှင့် တူညီသော စာရင်းဖြစ်သည်။ အလျား (မီလီမီတာ)၊ ထောင့် (ဒီဂရီ)၊ နံပါတ်၊ ကိန်းပြည့်၊ ဟုတ်/မဟုတ်၊ Pen (1–16)၊ စာသား၊ ပစ္စည်း နှင့် ဖြည့်။ တန်ဖိုးသည် ၎င်း၏အမျိုးအစားနှင့် မကိုက်ညီခြင်း သို့မဟုတ် ခွင့်ပြုထားသော တန်ဖိုးများထဲမှ တစ်ခု မဟုတ်ခြင်းဆိုလျှင် မက်ဆေ့ချ်ဖြင့် ငြင်းပယ်သည်။ ဘာမှ မပြောင်းပါ။

## သိထားသင့်သည်များ

- အားလုံးသည် ရိုးရိုး IFC ဖြစ်သည်။ အခြားပရိုဂရမ်များက တန်ဖိုးများကို ဖတ်နိုင်သည်။ သတ်မှတ်ချက်များသည် ပရောဂျက်ပေါ်ရှိ `CadCraft_TagDefs` property set တွင်၊ တန်ဖိုးများသည် element တစ်ခုစီပေါ်ရှိ `CadCraft_Tags` property set တွင် ရှိသည် (တဂ်တစ်ခုလျှင် property တစ်ခု)။ အရှည်များကို ဖိုင်၏ အရှည်ယူနစ်ဖြင့် ရေးသည်။
- တဂ်တွင် class များအတွက် `IfcWall` က standard-case နှင့် elemented နံရံများကိုလည်း ပါဝင်စေသည်။
- တဂ်ကို အမည်ပြောင်းလျှင် ထိုတဂ်၏ တန်ဖိုးအားလုံးကို element တိုင်းတွင် တစ်ဆင့်တည်းဖြင့် ပြောင်းသည်။ တဂ်ကို ဖယ်လျှင် ၎င်း၏ သတ်မှတ်ချက်သာ ဖျက်သည်။ ထား ပြီးသား တန်ဖိုးများသည် element များပေါ်တွင် ရိုးရိုး ဂုဏ်သတ္တိများအဖြစ် ကျန်ခဲ့သည်။ ဖယ်ရန် ၎င်းတို့ကို ဦးစွာ ရှင်းပါ ({{ui:ရှင်းရန်}} ကို ရွေးပါ)။
- CadCraft drafting app (block attribute) ရှိ တဂ်များကို မတည်ဆောက်ရသေးပါ။
