## ဘာလုပ်သလဲ

ထပ်ဆောင်းတစ်ခုက မော်ဒယ်ထဲသို့ ရေးသွင်းသည့်အခါ (truss၊ ပိုက်လိုင်း) BimCraft က ထပ်ဆောင်းနှင့် ၎င်း၏ ဗားရှင်းကို IFC project ပေါ်ရှိ CadCraft_AddOns property set တွင် မှတ်တမ်းတင်သည်။ မှတ်တမ်းကို ထပ်ဆောင်း၏ ကိုယ်ပိုင်ပြောင်းလဲမှုနှင့် တူညီသော ပြန်ဖျက်ရန် အဆင့်တွင် ရေးသည်၊ ထို့ကြောင့် ပြောင်းလဲမှုကို ပြန်ဖျက်လျှင် မှတ်တမ်းလည်း ပြန်ဖျက်ပါသည်။ အခြားပရိုဂရမ်များက ထို property set ကို လျစ်လျူရှုသည်; ထပ်ဆောင်းဆွဲထားသော အရာသည် မည်သို့ပင်ဖြစ်စေ ဖိုင်ထဲတွင် ကျန်နေသည်။

## အဆင့်များ

1. ထပ်ဆောင်းတစ်ခု ကူညီဖန်တီးခဲ့သော IFC ဖိုင်ကို ဖွင့်ပါ။
2. အသုံးပြုထားသော ထပ်ဆောင်းတစ်ခု ပိတ်ထားလျှင် မော်ဒယ်အပေါ်ရှိ မှတ်ချက်တွင် မည်သည်တို့ ဖြစ်ကြောင်း ပြပြီး သင့် Library အကောင့်မှ ထည့်ရန် ခလုတ်ပါသည်။
3. ထည့်ပါ၊ သို့မဟုတ် မှတ်ချက်ကို ပိတ်ပါ။ မော်ဒယ်သည် နည်းလမ်းနှစ်ခုလုံးဖြင့် ဖွင့်သည်။

## အများဆုံး မှားတတ်သော အချက်များ

- **မှတ်ချက် မပေါ်ပါ။** ဤတက်ဘ်တွင် သင့်အကောင့်ဖြင့် ဝင်ရောက်မထားခြင်း၊ သို့မဟုတ် ဖိုင်တွင် မှတ်တမ်း မရှိခြင်း (မှတ်တမ်းမရှိမီ သို့မဟုတ် အခြားပရိုဂရမ်ဖြင့် ပြုလုပ်ထားခြင်း)။
- **ပြောင်းလဲမှုစာရင်းတွင် "undefined" ပြသည်။** ပြင်ဆင်ပြီးပါပြီ: တံဆိပ်များက ထပ်ဆောင်း၏ အမည်ကို ယခု ပြသသည်။
