## သင် လေ့လာရမည့်အရာများ

## ဖွင့်ရန်

အကူအညီပေးသူများသည် သင့်ကွန်ပြူတာရှိ CadCraft Studio မှတစ်ဆင့် BimCraft သို့ ရောက်သည်; ရိုးရိုး browser တွင် ဝင်ပေါက် မရှိပါ။

1. {{ui:ဆက်တင်များ}} ကို ဖွင့်ပြီး **BimCraft** tab ကို ရွေးပါ။
2. **အကူအညီပေးသူများ** အောက်တွင် **AI အကူအညီပေးသူများနှင့် script များကို BimCraft သုံးခွင့်ပေးရန်** ကို အမှန်ခြစ်ပါ။
3. **ဖတ်ခြင်း** ကို သင့်အတွက် အမှန်ခြစ်ပြီးသားဖြစ်သည်။ အကူအညီပေးသူက သီးသန့်ပြခြင်းနှင့် ဖျောက်ခြင်း၊ ဆွဲခြင်း ပြုလုပ်ရလျှင် **မြင်ကွင်း ပြောင်းခြင်းနှင့် ဆွဲခြင်း** ကိုလည်း အမှန်ခြစ်ပါ၊ မော်ဒယ်ကို ဖိုင်အသစ်အဖြစ် သိမ်းခွင့်ရှိလျှင် **သိမ်းခြင်း** ကို အမှန်ခြစ်ပါ။
4. Studio တွင် အကူအညီပေးသူကို ချိတ်ဆက်ပါ (Studio က လိပ်စာနှင့် ကူးထည့်ရန် ဆက်တင်များကို ပြသည်)။

## အကူအညီပေးသူ ချိတ်ဆက်နေစဉ်

ညာဘောင်၏ အပေါ်ဘက်ရှိ မှတ်ချက်က ချိတ်ဆက်ထားသော အကူအညီပေးသူနှင့် ၎င်း ဘာလုပ်နိုင်သည်ကို ပြောသည်။ ၎င်း၏ session ကို ချက်ချင်း အဆုံးသတ်ရန် {{ui:ချိတ်ဆက်ဖြတ်ရန်}} ကို နှိပ်ပါ; ဆက်လုပ်ရန် ထပ်မံ ချိတ်ဆက်ရမည်။

**လှုပ်ရှားမှု**၊ ဆက်တင်များရှိ **အကူအညီပေးသူများ** အောက်တွင်၊ အကူအညီပေးသူ ခေါ်ဆိုသော ခေါ်ဆိုမှု အားလုံးကို နောက်ဆုံးမှ အစောဆုံးအထိ စာရင်းပြုပြီး အလုပ်ဖြစ်သည်ဟု ပြသည်။

:::tip
ရိုးရိုးစကားဖြင့် မေးပါ၊ ဥပမာ "အဆင့် 1 ရှိ ပြင်ပနံရံများကို သီးသန့်ပြပါ" "မီးခံနှုန်း မရှိသော တံခါးများ ဘာတွေလဲ?" သို့မဟုတ် "အဆင့် 1 တွင် မီတာ 6 × 4 အခန်းတစ်ခုကို တောင်ဘက်နံရံတွင် တံခါးတစ်ခုနှင့်အတူ ဆွဲပါ"။ အကူအညီပေးသူက ဒြပ်စင်များကို ရှာပြီး သင့်မြင်ကွင်းတွင် ပြသသည် သို့မဟုတ် ဆွဲပေးသည်။
:::

## ဝင်းဒိုးမရှိဘဲ: script များနှင့် command line

တူညီသော ဆွဲရေးကိရိယာများသည် သင်အမည်ပေးသော ဖိုဒါများရှိ IFC ဖိုင်များပေါ်တွင်လည်း အလုပ်လုပ်သည်၊ ဝင်းဒိုးမဖွင့်ဘဲ: CadCraft ၏ MCP server နှင့် command line သည် အဆောက်အအုံအသစ် စတင်နိုင်သည် သို့မဟုတ် IFC ဖိုင်ကို ဖွင့်နိုင်သည်၊ ဖော်ပြနိုင်သည်၊ နံရံများ၊ တံခါးများ၊ ပြတင်းပေါက်များ၊ ကြမ်းပြင်များ၊ အဆင့်များနှင့် ဂရစ်များ ထည့်နိုင်သည်၊ ပြန်ဖျက်နိုင်သည်၊ နှင့် `.ifc` ဖိုင်အသစ်အဖြစ် သိမ်းနိုင်သည်။ သင်က မည်သည့်ဖိုဒါများကို သုံးခွင့်ရှိသလဲ၊ ပြောင်းခြင်း သို့မဟုတ် သိမ်းခြင်း လုပ်ခွင့်ရှိသလားကို ဆုံးဖြတ်သည်။

## ပိတ်ရန်

**AI အကူအညီပေးသူများနှင့် script များကို BimCraft သုံးခွင့်ပေးရန်** ကို ဖယ်ထုတ်ပါ။ အကူအညီပေးသူ အားလုံး ချက်ချင်း ချိတ်ဆက်ဖြတ်သည်၊ ဆက်တင်ကို နောက်တစ်ကြိမ်အတွက် ထိန်းထားသည်။
