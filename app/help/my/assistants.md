## သင်လေ့လာရမည့်အရာများ

MCP ကို နားလည်သော မည်သည့် AI အကူအညီပေးသူမဆို သင်ဖွင့်ထားသော IFC မော်ဒယ်ကို ကြည့်ရှုပြီး ထိုထဲတွင် ဆွဲနိုင်အောင် မည်သို့ပြုလုပ်ရမည်၊ ၎င်း ဘာလုပ်နိုင်/မနိုင်သည်နှင့် ရပ်တန့်ရန် မည်သို့လုပ်ရမည်ကို လေ့လာပါ။

| အမည် သို့မဟုတ် property တန်ဖိုး ပြောင်းရန် | element တစ်ခု၏ Name၊ Description၊ Object type သို့မဟုတ် Tag၊ သို့မဟုတ် property တန်ဖိုးတစ်ခု။ အခြား element များနှင့် မျှဝေထားသော တန်ဖိုးကို ၎င်းအတွက် ဦးစွာ ကူးယူသည်၊ type ၏ တန်ဖိုးကို အကူအညီပေးသူက ပြောမှသာ ပြောင်းသည်၊ အဘယ်ကြောင့်ဆိုသော် ထို type ၏ element အားလုံး လိုက်ပါသည် | view ပြောင်းရန်နှင့် ဆွဲရန် |

| ဇယားကို စီစဉ်ရန်၊ ဖွဲ့စည်းရန်နှင့် ဖတ်ရန် | "ထပ်အလိုက် တံခါးဇယား၊ မီးခံနှုန်းနှင့် သံပစ္စည်းများ ပါဝင်သည်" ဟူသော အကူအညီပေးသူက ဇယားအမည်၊ ၎င်း၏ ကော်လံများ (property သို့မဟုတ် tag တစ်ခုသည် ကော်လံဖြစ်လာသည်) နှင့် အုပ်စုဖွဲ့မှုကို သတ်မှတ်သည်။ BimCraft က မော်ဒယ်မှ ဖြည့်ပြီး ပုံစံချသည်၊ အကူအညီပေးသူ မဖော်ပြသော အရာများကို ရုံးစံချိန်မှ ယူသည်။ ဤ set-up သည် သင့် ဇယားများ စာရင်းတွင် ပေါင်းထည့်သည်။ ပြန်ရသော စာကြောင်းတိုင်းတွင် ၎င်း၏ element များ အမည်ဖော်ပြသည်၊ ထို့ကြောင့် ရွေးချယ်နိုင်သည် | ဖတ်ရန် ဖတ်ခွင့်; set-up သိမ်းရန် view ပြောင်းရန်နှင့် ဆွဲရန် |

| Element များ ရွေးရန်၊ ကိုယ်တိုင်၏ အဆင့်များ ပြန်ဖျက်ရန် | Element များကို view တွင် ရွေးသည်; ၎င်း၏ နောက်ဆုံးအဆင့်ကို ပြန်ဖျက်သည် | view ပြောင်းရန်နှင့် ဆွဲရန် |

အကူအညီပေးသူ ပြုလုပ်သော ပြောင်းလဲမှုတိုင်းသည် **ပြောင်းလဲမှုများ** တွင် အဆင့်တစ်ခုဖြစ်ပြီး "Assistant: …" ဟု အမည်ပေးသည် (ဥပမာ "Assistant: နံရံ 4 ခု ထည့်ရန်")။ ထို့ကြောင့် {{key:Mod+Z}} က ၎င်း၏ လုပ်ဆောင်ချက် တစ်ခုလုံးကို ပြန်ဖျက်သည်၊ နှင့် မည်သူ၏ အဆင့်ဖြစ်ကြောင်း သင်မြင်နိုင်သည်။ ဝင်းဒိုးအတွင်းတွင် ဖိုင်များ ဖွင့်၍ မရပါ- သင်က မော်ဒယ်ကို ဖွင့်ပါ၊ ဖွင့်ထားသော မော်ဒယ်ဖြင့် အလုပ်လုပ်သည်။

## ဖွင့်ရန်

အကူအညီပေးသူများသည် သင့်ကွန်ပျူတာရှိ CadCraft Studio မှတစ်ဆင့် BimCraft သို့ ရောက်ရှိသည်; ရိုးရိုး browser တွင် ဝင်ရောက်ရန် နည်းလမ်း မရှိပါ။

1. {{ui:ဆက်တင်များ}} ကိုဖွင့်ပြီး **BimCraft** tab ကို ရွေးပါ။
2. **အကူအညီပေးသူများ** အောက်တွင် **AI အကူအညီပေးသူများနှင့် script များကို BimCraft သုံးခွင့်ပေးရန်** ကို အမှန်ခြစ်ပါ။
3. **ဖတ်ရန်** ကို သင့်အတွက် အမှန်ခြစ်ထားပြီးဖြစ်သည်။ အကူအညီပေးသူက element များကို သီးခြားခွဲ၊ ဖျောက်ပြီး ဆွဲနိုင်လျှင် **view ပြောင်းရန်နှင့် ဆွဲရန်** ကိုလည်း အမှန်ခြစ်ပါ၊ မော်ဒယ်ကို ဖိုင်အသစ်အဖြစ် သိမ်းနိုင်လျှင် **သိမ်းရန်** ကို အမှန်ခြစ်ပါ။
4. Studio တွင် အကူအညီပေးသူကို ချိတ်ဆက်ပါ (Studio က လိပ်စာနှင့် ကူးထည့်ရမည့် ဆက်တင်များကို ပြသသည်)။

## အကူအညီပေးသူ ချိတ်ဆက်နေစဉ်

ညာဘက်ပန်နယ်၏ထိပ်ရှိ မှတ်ချက်က မည်သည့် အကူအညီပေးသူ ချိတ်ဆက်ထားကြောင်းနှင့် ၎င်း ဘာလုပ်နိုင်သည်ကို ပြသသည်။ session ကို ချက်ချင်း အဆုံးသတ်ရန် {{ui:ချိတ်ဆက်ဖြတ်ရန်}} ကို နှိပ်ပါ၊ ဆက်လုပ်ရန် ထပ်မံ ချိတ်ဆက်ရမည်။

ဆက်တင်များအတွင်း **အကူအညီပေးသူများ** အောက်ရှိ **Activity** သည် အကူအညီပေးသူ ခေါ်ဆိုသော အရာတိုင်းကို နောက်ဆုံးအရင်ဆုံး စာရင်းပြုပြီး အလုပ်ဖြစ်/မဖြစ်ကို ပြသသည်။

ရိုးရှင်းသော စကားဖြင့် မေးပါ၊ ဥပမာ "Level 1 ရှိ ပြင်ပနံရံများကို သီးခြားခွဲပါ"၊ "မီးခံနှုန်း မရှိသော တံခါးများ ဘာတွေလဲ?" သို့မဟုတ် "Level 1 တွင် 6 by 4 metre အခန်းတစ်ခုကို တောင်ဘက်နံရံတွင် တံခါးဖြင့် ဆွဲပါ"။ အကူအညီပေးသူက element များကို ရှာပြီး သင့် view တွင် ပြသသည် သို့မဟုတ် ဆွဲသည်။
:::

## ဝင်းဒိုးမရှိဘဲ: script များနှင့် command line

တူညီသော ဆွဲရေးကိရိယာများသည် သင်ဖွင့်ထားသော ဝင်းဒိုး မရှိဘဲ သင် အမည်ပေးထားသော ဖိုင်တွဲများရှိ IFC ဖိုင်များပေါ်တွင် အလုပ်လုပ်သည်။ CadCraft ၏ MCP server နှင့် command line က မော်ဒယ်အသစ်တစ်ခု စတင်နိုင်သည် သို့မဟုတ် IFC ဖိုင်တစ်ခုကို ဖွင့်နိုင်သည်၊ ၎င်းကို ဖော်ပြနိုင်သည်၊ နံရံ၊ တံခါး၊ ပြတင်းပေါက်၊ ကြမ်းပြင်၊ အထပ်နှင့် ဂရစ်များ ထည့်နိုင်သည်၊ ပြန်ဖျက်နိုင်ပြီး `.ifc` ဖိုင်အသစ်အဖြစ် သိမ်းနိုင်သည်။ script များအတွက် ကိရိယာ လေးခု ထပ်ရှိသည်- `ifc_batch` သည် တည်းဖြတ်ခြင်း အဆင့် 200 အထိကို တစ်ခုအဖြစ် လည်ပတ်သည် (အားလုံး သို့မဟုတ် ဘာမျှမဟုတ်; ပြန်ဖျက်တစ်ကြိမ်ဖြင့် batch တစ်ခုလုံး ပြန်ဖျက်သည်၊ ငြင်းဆိုသော အဆင့်တစ်ခုက ကျန်သည်များကို ပြန်ဖျက်ပြီး အဆင့်ကို အမည်ပေးသည်); `ifc_describe` သည် အထပ်များနှင့် တံခါး၊ ပြတင်းပေါက်များပါသော နံရံတိုင်းကို စာရင်းပြုသည်; `ifc_render_png` သည် ဝင်းဒိုးမရှိဘဲ မော်ဒယ်၏ အရောင်ချထားသော စစ်ဆေးရေးပုံ (material၊ texture သို့မဟုတ် အရိပ်မရှိ) ကို ရေးသည်; `usd_export` သည် `.usda`၊ `.usdc` သို့မဟုတ် `.usdz` ကို ရေးသည်။ command line တွင် `cadcraft bim script.json --from model.ifc -o out.ifc` သည် အဆင့်များ script ကို လည်ပတ်ပြီး `--usd`၊ `--png` နှင့် `--plan` က အတူတူ run မှ USD ဖိုင်၊ ပုံ သို့မဟုတ် ပလန်ကို ရေးသည်။ သင်က မည်သည့် ဖိုင်တွဲများကို သုံးခွင့်ရှိမည်နှင့် မည်သည်ကိုမဆို ပြောင်းခွင့် သို့မဟုတ် သိမ်းခွင့်ရှိမရှိကို ဆုံးဖြတ်သည်။

## ပိတ်ရန်

**AI အကူအညီပေးသူများနှင့် script များကို BimCraft သုံးခွင့်ပေးရန်** ကို အမှန်ခြစ်ဖြုတ်ပါ။ အကူအညီပေးသူ အားလုံး ချက်ချင်း ချိတ်ဆက်ဖြတ်တောက်ပြီး ဆက်တင်ကို နောက်တစ်ကြိမ်အတွက် သိမ်းထားသည်။
