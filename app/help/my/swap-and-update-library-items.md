## သင်လုပ်မည့်အရာ

ပစ္စည်းတစ်ခုအပေါ် စိတ်ပြောင်းလျှင် ထပ်မရွှေ့ဘဲ လဲပါ။ မော်ဒယ်ရှိ စာကြည့်တိုက်ပစ္စည်းများကိုလည်း ဆန်းသစ်အောင် ထားပါ။

## ပစ္စည်းတစ်ခု လဲရန်

1. မော်ဒယ်ထဲရှိ ထားထားသော စာကြည့်တိုက်ပစ္စည်းကို နှိပ်ပါ။
2. {{ui:Properties}} တွင် **စာကြည့်တိုက်ပစ္စည်း** အကွက်ရှိ {{ui:အရာဝတ္ထု လဲရန်…}} ကို နှိပ်ပါ။ {{ui:Library}} tab ဖွင့်သည်။
3. ပစ္စည်းအသစ်ကို ရှာပြီး ၎င်း၏ကဒ်ကို နှိပ်ပါ။
4. {{ui:… ကို ဤအရာသို့ လဲရန်}} ကို နှိပ်ပါ။

element သည် ၎င်း၏နေရာ၊ လှည့်ပုံ၊ အထပ်၊ ပစ္စည်းနံပါတ်၊ ပမာဏနှင့် မှတ်ချက်များကို ထိန်းသည်။ ၎င်း၏ အမျိုးအစား၊ ပုံသဏ္ဍာန်နှင့် ပစ္စည်းဒေတာတို့သည် ပစ္စည်းအသစ်သို့ ပြောင်းသွားသည်။ တူညီသောနည်းဖြင့် ထားသော ပစ္စည်းများသည် အမျိုးအစားတစ်ခုတည်း ဝေမျှသည်။

variant များရှိသော ပစ္စည်း (ကြည့်ရန် [variant ရှိသော စာကြည့်တိုက်ပစ္စည်းကို ထားပြီး လဲခြင်း](topic:library-variants)) ကို လဲသည့်အခါ ၎င်း၏ အခြား variant များကို {{ui:Library}} tab ထိပ်တွင် ပြသည်။ တစ်ခုစီကို တစ်ချက်နှိပ်ဖြင့် ရွေးနိုင်သည်။

ပစ္စည်းအသစ်သည် အမျိုးအစား မတူသည့်အရာ ဖြစ်လျှင် ဥပမာ ရေချိုးခန်းအစား စားပွဲ၊ element ၏ IFC class သည် ၎င်းနှင့်ကိုက်ညီအောင် ပြောင်းသည်။ ဥပမာ furnishing element မှ sanitary terminal သို့။ ထို့ကြောင့် အခြားဆော့ဖ်ဝဲများက ၎င်းကို မှန်ကန်စွာ စာရင်းပြုစုသည်။ element သည် တူညီသော GlobalId ဖြင့် တူညီသော element ဖြစ်နေဆဲဖြစ်သဖြင့် ၎င်းသို့ ညွှန်ထားသော link များ ဆက်အလုပ်လုပ်သည်။ {{key:Mod+Z}} က ဟောင်းသော class နှင့် ဟောင်းသော ပစ္စည်းကို ပြန်ယူသည်။

## ဗားရှင်းသစ်များ စစ်ဆေးရန်

1. toolbar ရှိ {{ui:Updates}} ကို နှိပ်ပါ (သို့မဟုတ် စာကြည့်တိုက်ပစ္စည်း၏ အကွက်ရှိ {{ui:အပ်ဒိတ်များ စစ်ဆေးရန်}})။
2. စာရင်းကို ဖတ်ပါ။ မော်ဒယ်ရှိ Library ပစ္စည်းတစ်ခုစီ၊ မော်ဒယ်ထဲရှိ ဗားရှင်း၊ နောက်ဆုံးဗားရှင်းနှင့် အခြေအနေ: **အပ်ဒိတ်လုပ်ပြီး**၊ **ပိုသစ်သောဗားရှင်း**၊ **ရုပ်သိမ်းပြီး** သို့မဟုတ် **မတွေ့ပါ**။ ဘာပြောင်းခဲ့သည်ကိုလည်း ပြသည် (geometry၊ data၊ လိုင်စင် သို့မဟုတ် ပြင်ဆင်ချက်)။
3. အတန်းတစ်ခုပေါ်ရှိ {{ui:အပ်ဒိတ်}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:အားလုံး အပ်ဒိတ်လုပ်ရန်}} ကို နှိပ်ပါ။

## သင်မြင်ရမည့်အရာ

- "*n* နေရာ အပ်ဒိတ်လုပ်ပြီးပါပြီ။ နေရာများ၊ ပစ္စည်းနံပါတ်များ၊ ပမာဏများနှင့် မှတ်ချက်များကို ထိန်းသိမ်းထားသည်။"
- ပြောင်းလဲမှုစာရင်းတွင် "အပ်ဒိတ်လုပ်ပြီး: *item*" လိုင်းများ။ {{key:Mod+Z}} က တစ်ခုစီကို ပြန်ဖျက်သည်။

## သိထားသင့်သည်များ

- Library မှ လာသော ပစ္စည်းများကိုသာ စစ်ဆေးနိုင်သည်။ ဖိုင်များမှ ပစ္စည်းများတွင် library id မပါ။
- လိုင်စင် ပြောင်းသွားလျှင် ထားပြီးသား မိတ္တူသည် ၎င်းနှင့်အတူ လာသော လိုင်စင်ကို အပ်ဒိတ်မလုပ်မချင်း ဆက်ထားသည်။
- **ရုပ်သိမ်းပြီး** ပစ္စည်းကို ထားရန်အတွက် ထပ်မပေးပါ။ မူပိုင်ခွင့် အကြောင်းကြောင့် ရုပ်သိမ်းထားသည့် ပစ္စည်းကို လုံးဝ ဒေါင်းလုဒ်မလုပ်နိုင်ပါ။ {{ui:အရာဝတ္ထု လဲရန်…}} ဖြင့် အစားထိုးပါ။
- ထားပြီးသား variant သည် ပစ္စည်းအသစ်တွင် ထို variant ရှိနေလျှင် ထို variant အဖြစ် ဆက်နေသည်။ မဟုတ်ပါက ပစ္စည်း၏ မူလ variant ကို ယူသည်။
- စစ်ဆေးခြင်းသည် ပစ္စည်း id များနှင့် ဗားရှင်းများကိုသာ ပို့သည်။ သင်၏ မော်ဒယ်ကို တစ်ခုမျှ မပို့ပါ။
