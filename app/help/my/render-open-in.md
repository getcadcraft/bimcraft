ဇာတ်ကွင်းကို အခြား program သို့ ယူသွားရန် {{ui:Render}} ၏ Engine စာရင်းမှ **Open in** အရာတစ်ခုကို ရွေးပါ။ မော်ဒယ်သို့ တစ်စုံတစ်ခုမျှ ပြန်မလာပါ။

## program မည်သည့်အတွက်မဆို ဖိုင်

- **USD file** က ဇာတ်ကွင်းကို `.usdc` (မော်ဒယ်တွင် ပုံများပါလျှင် `.usdz`) အဖြစ် သိမ်းသည်: [အမည်ပြောင်း၍ သိမ်းရန် USD](topic:usd) နှင့် တူညီသော ဖိုင်ဖြစ်ပြီး material၊ မီးလုံးနှင့် ကင်မရာများ ပါဝင်သည်။ instancing နှင့် material တန်ဖိုးအတိအကျကို ထိန်းသည်။ ရုပ်ပုံထုတ်ကိရိယာအများစု၊ game engine နှင့် viewer များက USD ကို ဖတ်သည်။
- **glTF ဖိုင် (.glb)** က material၊ texture နှင့် မီးလုံးများ ပါသော ပေါ့ပါးသော glTF 2.0 ဖိုင်ကို သိမ်းသည်; ၎င်းတွင် ပါဝင်သည်နှင့် ချန်ထားသည်များအတွက် [မော်ဒယ်ကို ရုပ်ပုံထုတ် program သို့ ပို့ခြင်း](topic:model-for-rendering) ကို ကြည့်ပါ။

- **Unreal project folder (.zip)** က [ဇာတ်ကွင်းကို game engine သို့ ပို့ခြင်း](topic:render-unreal) ရေးသော folder ကို သိမ်းသည်၊ ကွန်ပျူတာ မည်သည့်တစ်ခုပေါ်ရှိ project အတွက်မဆို။

သုံးမျိုးလုံး ဝဘ်နှင့် Studio တွင် အလုပ်လုပ်သည်။

## Studio တွင်: program တွင် ဖွင့်ရန်

Studio က ဤကွန်ပျူတာပေါ်တွင် ဇာတ်ကွင်းကို ဖွင့်နိုင်သော program များကို ဖော်ပြသည်: ရှာဖွေရာလမ်းကြောင်းတွင်ရှိလျှင် usdview နှင့် ဖိုင်အမျိုးအစားအတွက် ကွန်ပျူတာ၏ ကိုယ်ပိုင် program။ တစ်ခုရွေးပါ၊ နှစ်မျိုးလုံး ဖတ်နိုင်လျှင် USD သို့မဟုတ် glTF ရွေးပါ၊ ပြီးလျှင် {{ui:Render}} ကို နှိပ်ပါ။ Studio သည် package ကို Documents အောက်ရှိ folder အသစ် (`CadCraft hand-off`; ဘာမျှ မရေးထပ်ပါ၊ ပို့တိုင်း folder ကိုယ်ပိုင်ရှိသည်) တွင် ရေးပြီး ထို folder ပေါ်တွင် program ကို စတင်သည်၊ ထို့နောက် ဖိုင်များ ရှိရာနေရာကို ပြောသည်။

| Program | အကောင်းဆုံး ဖတ်နိုင်သည် |
|---|---|
| usdview | USD |
| ကွန်ပျူတာ၏ ကိုယ်ပိုင် program | ဖိုင်အမျိုးအစားအတွက် ကွန်ပျူတာတွင် ရှိသည့်အရာ |

Studio သည် ဤသတ်မှတ်ထားသော စာရင်းမှ program များကိုသာ စတင်သည်; စာမျက်နှာက အမည်ဖြင့် တောင်းဆိုသည့် မည်သည့်အရာကိုမျှ မ run ပါ၊ GNU GPL လိုင်စင်အောက်ရှိ program ကို ဘယ်တော့မှ မစတင်ပါ ([အခြား program ဖြင့် ရုပ်ပုံဆွဲခြင်း](topic:render-other-program#programs-cadcraft-never-runs) ကို ကြည့်ပါ)။ USD သို့မဟုတ် glTF ကို ဖတ်နိုင်သည့် မည်သည့် program မဆို အထက်ရှိ **program မည်သည့်အတွက်မဆို ဖိုင်** မှ ဖိုင်ကို ဖွင့်သည်။

:::note
Twinmotion၊ Enscape နှင့် အခြား visualization program များသည် စာရင်းတွင် မပါပါ: CadCraft ကို ၎င်းတို့နှင့် စစ်ဆေးထားခြင်း မရှိပါ၊ ၎င်းတို့အကြောင်း အာမခံချက် မပေးပါ။ ဤနေရာမှ glTF သို့မဟုတ် USD ဖိုင်သည် ဝင်ပေါက်ဖြစ်သည်; [plug-in renderer](topic:model-for-rendering#enscape-and-other-plug-in-renderers) များ၏ မှတ်ချက်များကို ကြည့်ပါ။
:::
