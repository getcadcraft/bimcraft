## သင်လုပ်ဆောင်မည့်အရာ

စက်ပစ္စည်းကို သင့်ပိုက်နှင့် လေပိုက်များ၏ အဆုံးတွင် ထားပါ။ အစိတ်အပိုင်းတစ်ခုစီသည် သင်ရိုက်ထည့်သော တန်ဖိုးများဖြင့် အရွယ်အစားသတ်မှတ်ထားသော generic ပုံသဏ္ဍာန် ဖြစ်ပြီး ၎င်း၏ ချိတ်ဆက်မှုများကို **port** များအဖြစ် ပါဝင်သည်: ပိုက် သို့မဟုတ် လေပိုက် ဝင်ရောက်ချိတ်ဆက်သော နေရာ၊ စနစ်၊ စီးဆင်းမှု လမ်းကြောင်းနှင့် အရွယ်အစား။ port မှ ဆွဲထားသော ပိုက်နှင့် လေပိုက်များသည် ၎င်း၏ အရွယ်အစားနှင့် စနစ်ကို ယူပြီး ၎င်းနှင့် တည်ငြိမ်စွာ ချိတ်ထားသည်: [ပိုက်နှင့် လေပိုက်များကို စက်ပစ္စည်းများသို့ ချိတ်ဆက်ခြင်း](topic:mep-connections) ကို ကြည့်ပါ။

:::note
ဤသည်မှာ ဒီဇိုင်းဆွဲခြင်းနှင့် ညှိနှိုင်းမှု အကူအညီဖြစ်ပြီး engineer က အရွယ်အစား သတ်မှတ်သည်။ စက်ပစ္စည်းသည် ထုတ်လုပ်သူ၏ ထုတ်ကုန် မဟုတ်ပါ: စွမ်းရည်၊ အလေးချိန် သို့မဟုတ် ထုတ်လုပ်သူ၏ ချိတ်ဆက်မှု အရွယ်အစား မပါပါ။ လိုအပ်သည့်အခါ သင်၏ MEP program မှ ထုတ်လုပ်သူ၏ မော်ဒယ်ကို IFC အဖြစ် ယူလာပါ။
:::

## အစိတ်အပိုင်း ထားခြင်း

1. {{ui:ဆွဲရန်}} ကို ဖွင့်ပါ၊ {{ui:Build}} ကို ဖွင့်ပြီး {{ui:စက်ပစ္စည်း}} ကို ရွေးပါ။
2. bar တွင် အမျိုးအစားကို ရွေးပြီး အရွယ်အစားများကို ရိုက်ပါ။ အမျိုးအစား တစ်ခုစီက ၎င်း၏ကိုယ်ပိုင် အရာများကို မေးသည်:

| အမျိုးအစား | သင်ရိုက်ထည့်သည် | ၎င်း၏ port များ |
|---|---|---|
| Air handler | အလျား၊ အကျယ်၊ အမြင့်; supply နှင့် return အဖွင့်များ; coil ပိုက် အရွယ်အစားနှင့် စနစ်; condensate အရွယ်အစား | supply duct ထွက်၊ return duct ဝင်၊ coil ဝင်နှင့် ထွက်၊ condensate ရေမြောင်း |
| Inline fan | အချင်း၊ အလျား၊ စနစ် | duct ဝင်နှင့် ထွက် |
| ပန့် | ပိုက် အရွယ်အစား၊ စနစ် | inlet နှင့် outlet |
| ဘွိုင်လာ | အလျား၊ အကျယ်၊ အမြင့်၊ ပိုက် အရွယ်အစား၊ gas အရွယ်အစား၊ flue အချင်း | heating supply ထွက်နှင့် return ဝင်၊ gas ဝင်၊ flue ထွက် |
| ရေနွေးထုတ်စက် | အချင်း၊ အမြင့်၊ ပိုက် အရွယ်အစား၊ gas သို့မဟုတ် electric | cold water ဝင်၊ hot water ထွက် (gas ဖြင့် လောင်ပါက gas ဝင်နှင့် flue ပါ) |
| Terminal unit | အလျား၊ အကျယ်၊ အမြင့်၊ စက်ဝိုင်း inlet၊ outlet အကျယ်နှင့် အမြင့် | supply air ဝင်နှင့် ထွက် |
| Diffuser | face၊ neck၊ စနစ် | ၎င်း၏ neck (လေ ဝင်) |
| Grille | face အကျယ်နှင့် အမြင့်၊ neck အကျယ်နှင့် အမြင့်၊ စနစ် | ၎င်း၏ neck (လေ ထွက်၊ return သို့မဟုတ် exhaust duct သို့) |
| Tank | အချင်း၊ အမြင့်၊ ပိုက် အရွယ်အစား၊ စနစ် | inlet ထိပ်ပေါ်၊ outlet အောက်ခြေအနီး |
| Radiator | အလျား၊ အမြင့်၊ အနက်၊ ပိုက် အရွယ်အစား၊ စနစ် | flow ဝင် တစ်ဘက်အဆုံး၏ ထိပ်၊ return ထွက် အခြားဘက်အဆုံး၏ အောက်ခြေ |
| Convector / panel heater | အလျား၊ အမြင့်၊ အနက်၊ ပိုက် အရွယ်အစား၊ စနစ် | flow ဝင် တစ်ဖက်အဆုံး၊ return ထွက် အခြားအဆုံး |
| ထုတ်လုပ်သူ၏ family | family ([ပိုက် specs၊ valve၊ damper နှင့် ထုတ်လုပ်သူ family များ](topic:pipe-specs) ကို ကြည့်ပါ) | family ကို ပေးထားသော port များ |

3. **At** ကို သတ်မှတ်ပါ၊ level ၏ အထက်ရှိ ၎င်း၏ အောက်ခြေ အမြင့်။ diffuser သို့မဟုတ် grille ၏ အမြင့်သည် ၎င်း၏ face ဖြစ်သည်: ခုံမျဉ်း အမြင့်ကို ရိုက်ပါ။
4. လိုချင်လျှင် **Tag** ကို ရိုက်ပါ (`AHU-1`); အမျိုးအစား တူသော နောက်အစိတ်အပိုင်းက နောက်နံပါတ် ရမည်။
5. pointer ကို plan ပေါ် ရွှေ့ပါ: footprint နှင့် ၎င်း၏ port များ လိုက်သည်။ {{key:R}} ကို နှိပ်ပြီး 90° လှည့်ပါ။ သွားလိုသော နေရာတွင် click လုပ်ပါ။

ပိုက် အရွယ်အစားများသည် သံမဏိ ပိုက် အရွယ်အစားများ (ASME B36.10M) ဖြစ်သည်။ အခြား ပစ္စည်းဖြင့် ပန့်မှ ဆွဲသော ပိုက်သည် ၎င်း၏ကိုယ်ပိုင် ပစ္စည်းတွင် တူညီသော nominal အရွယ်အစားကို ယူသည်။

## ပြောင်းခြင်း သို့မဟုတ် ဖယ်ရှားခြင်း

plan သို့မဟုတ် 3D view တွင် ရွေးပါ။ ဂုဏ်သတ္တိများ က သင်ရိုက်ထည့်ခဲ့သော အရွယ်အစားအားလုံး၊ ၎င်း၏ tag၊ X၊ Y၊ အမြင့်နှင့် လှည့်ပုံ၊ နှင့် port တစ်ခုစီ — ၎င်း၏ အရွယ်အစား၊ စနစ်၊ စီးဆင်းမှု လမ်းကြောင်းနှင့် တစ်ခုခု ချိတ်ဆက်ထားခြင်း ရှိ/မရှိ — ကို ပြသည်။ ပြောင်းလဲမှု တစ်ခုစီသည် {{ui:ပြန်ဖျက်ရန်}} ၏ အဆင့်တစ်ခု ဖြစ်သည်; ၎င်း၏ port များတွင် ပြင်ဆင်ထားသော run များသည် ၎င်းနှင့်အတူ ရွှေ့သွားသည်။ {{key:Delete}} က ဖယ်ရှားသည်; ၎င်းတွင် ပြင်ဆင်ထားသော run များ ကျန်ခဲ့ပြီး ချိတ်ဆက်မှု စစ်ဆေးချက်က ၎င်းတို့ကို စာရင်းပြုသည်။

## IFC ဖိုင်တွင်

အမျိုးအစား တစ်ခုစီကို ၎င်း၏ IFC class အဖြစ် သိမ်းသည်: IfcUnitaryEquipment (air handler)၊ IfcFan၊ IfcPump၊ IfcBoiler (ဘွိုင်လာ; ရေနွေးထုတ်စက်သည် type water နှင့် object type "Water heater" ပါသော IfcBoiler ဖြစ်သည်)၊ IfcAirTerminalBox (terminal unit)၊ IfcAirTerminal (diffuser၊ grille) နှင့် IfcTank၊ အမျိုးအစားနှင့် အရွယ်အစား တူသော အစိတ်အပိုင်းတိုင်းက type တစ်ခုကို မျှဝေသည်။ IFC2X3 ဖိုင်များသည် ကိုက်ညီသော type များဖြင့် IfcEnergyConversionDevice၊ IfcFlowMovingDevice၊ IfcFlowController၊ IfcFlowTerminal နှင့် IfcFlowStorageDevice ကို ရရှိသည်။ port တစ်ခုစီသည် ချိတ်ဆက်မှုရှိသည့်နေရာတွင် ထားသော IfcDistributionPort ဖြစ်ပြီး အပြင်သို့ မျက်နှာမူ၊ ၎င်း၏ စီးဆင်းမှု လမ်းကြောင်းနှင့် စနစ်ပါဝင်သည်; အခြား program များက မည်သည့် run မည်သည့် port သို့ ချိတ်ဆက်သည်ကို ဖတ်သည်။ အစိတ်အပိုင်းသည် port တစ်ခုစီ၏ စနစ်ကို ပေါင်းစပ်ပြီး ထားထားသော library item တိုင်းပါသော library item set များကို သယ်ဆောင်သည်။
