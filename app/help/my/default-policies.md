## ဘာလုပ်မလဲ

BimCraft ကို အဆောက်အအုံအသစ် မည်သည်ဖြင့် စတင်သင့်သည်ကို ပြောပြပါ၊ ရုံးတွင် မည်သူမျှ တူညီသော အရာများကို အချိန်တိုင်း ပြောင်းစရာမလိုပါ။ ဤသည်မှာ ထပ်ဆောင်းအစိတ်အပိုင်းတစ်ခု ဖြစ်သည်: ဖွင့်မချင်း ပိတ်ထားသည်၊ သင် သတ်မှတ်မထားသော မူဝါဒသည် BimCraft ၏ ကိုယ်ပိုင် မူလကို မပြောင်းလဲဘဲ ထားသည်။

:::note
ဤအရာများသည် **အသစ်** အဆောက်အအုံများနှင့် **အသစ်** အရာများအတွက် မူလများ ဖြစ်သည်။ သင်စတင်ပြီးသား ပရောဂျက်ကို မပြောင်းပါ။
:::

## အဆင့်များ

1. Settings ကို ဖွင့်ပါ၊ {{ui:Add-ons}} သို့ သွားပြီး {{ui:Default Policies}} ကို ဖွင့်ပါ။
2. Settings တွင် **BimCraft** တဘ်ကို ဖွင့်ပြီး ဘယ်ဘက်စာရင်းမှ {{ui:Default Policies}} ကို ရွေးပါ။
3. လိုချင်သော မူဝါဒများကို သတ်မှတ်ပါ။ တစ်ခုစီသည် **BimCraft ၏ ကိုယ်ပိုင်** ဖြင့် စတင်သည်၊ ကွင်းထဲရှိ အရာနှင့်အတူ။ **Metric** နှင့် **Imperial** အကွက်ပါသော မူဝါဒသည် ပရောဂျက်အမျိုးအစား တစ်မျိုးစီအတွက် တန်ဖိုးတစ်ခု ယူသည်; လိုအပ်သောအရာများကိုသာ ဖြည့်ပါ။
4. သိမ်းရန် ခလုတ် မရှိပါ: ပြောင်းလဲမှုတိုင်းကို သင်ပြုလုပ်သည်နှင့် သိမ်းသည်။ အသုံးမပြုနိုင်သော တန်ဖိုးကို စကားလုံးဖြင့် ငြင်းပယ်ပြီး ဟောင်းသည် ကျန်နေသည်။
5. {{ui:New building}} ကို နှိပ်ပါ။ ဒိုင်ယာလော့ခ်ကို သင့်မူဝါဒများမှ ဖြည့်ထားပြီး၊ မူဝါဒက သတ်မှတ်ထားသော တန်ဖိုးတိုင်း၏ ဘေးတွင် **သင့် Default Policies မှ** ဟု ပြသည်။ {{ui:Create}} မတိုင်မီ ၎င်းတို့အားလုံးကို ပြောင်းနိုင်သေးသည်။

## မူဝါဒများ

- **အဆောက်အအုံအသစ်၏ ယူနစ်များ**: Create တွင် ယူနစ်များ ဤသို့ ပြောင်းသည်။
- **အဆင့်အရေအတွက်**၊ **အဆင့်အမည်များ** နှင့် **အဆင့်အမြင့်**။ အမည်တွင်၊ `{n}` က 1၊ 2၊ 3 ကို ရေတွက်သည်; `{n0}` က 0၊ 1၊ 2 ကို ရေတွက်သည်; `{nn}` နှင့် `{nn0}` က ဂဏန်းနှစ်လုံးဖြင့် တူညီစွာ ပြုသည်။ ထို့ကြောင့် `Floor {nn0}` က Floor 00၊ Floor 01၊ Floor 02 ကို ပေးသည်။
- **ပထမနံရံအမျိုးအစား**: Wall ကိရိယာက ပထမဆွဲသည့်အရာ။ မက်ထရစ်ရုံးက Exterior masonry 300 mm ဖြင့် စတင်နိုင်ပြီး အင်ပီရီယယ် ပရောဂျက်များက Exterior 2×6 ကို ထားသည်။
- **စတင်နံရံအမျိုးအစားများပေါ်ရှိ LOD တဂ်**: အမျိုးအစား စာရင်းပြုသည့်နေရာတိုင်းတွင် ကိုးမျိုး စတင်အမျိုးအစားများက ပြသသော ဖွံ့ဖြိုးမှုအဆင့် (LOD 100 မှ 500)။ [နံရံအစုအဝေးများကို တည်ဆောက်ခြင်း](topic:wall-assemblies) ကို ကြည့်ပါ။
- **အသစ်ပြုလုပ်သော နံရံအမျိုးအစား၏ LOD**: အမျိုးအစား တည်းဖြတ်ကိရိယာတွင် အမျိုးအစားအသစ် စတင်သည့် တဂ်။ ထိုနေရာတွင် ပြောင်းနိုင်သည်။
- **ပထမစာရွက်**: ၎င်း၏ စက္ကူ၊ စကေး၊ စာရွက်နံပါတ်နှင့် အမည် (အနိမ့်ဆုံးအဆင့်၏ အမည်အတွက် `{level}` ကို သုံးပါ)၊ သို့မဟုတ် ပထမစာရွက် လုံးဝမရှိခြင်း။
- **စက္ကူပေါ်ရှိ မှတ်ချက်အရွယ်အစားများ** (Settings › Global › မူလမူဝါဒများ): ရုံး၏ အမြင့်များ၊ ပရင့်ထုတ်သော မီလီမီတာဖြင့်၊ မှတ်ချက်များ၊ အတိုင်းအတာစာသား၊ တဂ်များ၊ အခန်းအမည်များ၊ ဂရစ်ဘဘယ်လ် အက္ခရာများ၊ view ခေါင်းစဉ်များနှင့် ဇယားစာသား အတွက်။ အဆောက်အအုံအသစ်သည် Create တွင် ယူပြီး ၎င်း၏ဖိုင်တွင် သိမ်းထားသည်။ [အပြည့်အစုံအရွယ်ဖြင့် ဆွဲ၊ စကေးအလိုက် မှတ်ချက်ရေးခြင်း](topic:annotation-sizes) ကို ကြည့်ပါ။
- **Create ပြီးနောက် တက်ကြွသော ကိရိယာ**: Select (BimCraft ၏ ကိုယ်ပိုင်အတိုင်း) သို့မဟုတ် Wall၊ ထို့ကြောင့် ပလန်ပေါ်တွင် ပထမနှိပ်နှစ်ချက်က နံရံဆွဲပြီးသား ဖြစ်စေသည်။

## ဇယားပုံစံ- ရုံးစံ

**Settings › Global › မူလမူဝါဒများ** အောက်ရှိ **ဇယားပုံစံ (ရုံးစံ)** တွင်၊ ဇယားတိုင်း မည်သို့ အုပ်စုဖွဲ့သည်၊ subtotal နှင့် စုစုပေါင်း ရှိ/မရှိ၊ ၎င်း၏ခေါင်းစဉ်နှင့် ကော်လံခေါင်းစဉ်များ၏ စာလုံးပုံစံကို သတ်မှတ်ပါ။ ၎င်း၏ကိုယ်ပိုင်မသတ်မှတ်သော ဇယားတိုင်းသည် ၎င်းတို့ကို ယူသည်၊ ဘယ်သူ စီစဉ်ထားသည်ဖြစ်စေ။ [ဇယားကို ပုံစံချခြင်း၊ သိမ်းခြင်းနှင့် ထုတ်ခြင်း](topic:schedule-layouts) ကို ကြည့်ပါ။

## ရုံးတစ်ခုလုံးတွင် မျှဝေခြင်း

1. Settings တွင် **Global** တဘ်ကို ဖွင့်ပြီး {{ui:Default Policies}} ကို ရွေးပါ။
2. လိုလျှင် **Office name** ကို ရိုက်ပါ။ ၎င်းကို ဖိုင်ထဲ ရေးသည်။
3. {{ui:Save to a file}} ကို နှိပ်ပါ။ `.ccdefaults.json` ဖြင့်အဆုံးသတ်သော ဖိုင်ငယ်တစ်ခု ရရှိမည်။
4. အခြားကွန်ပျူတာတွင်၊ ထပ်ဆောင်းကို ဖွင့်ပြီး တူညီသော နေရာကို ဖွင့်ကာ {{ui:Load from a file}} ကို နှိပ်ပါ။ ဖိုင်၏ မူဝါဒများက ထိုကွန်ပျူတာ၏ မူဝါဒများကို အစားထိုးသည်။

Global တဘ်တွင် **ပရောဂျက်အသစ်၏ ယူနစ်စနစ်** နှင့် {{ui:Reset every policy}} လည်း ရှိသည်၊ ထိုအရာသည် ထပ်ဆောင်းပါရှိသည့် app တိုင်းအတွက် သက်ရောက်သည်။ BimCraft တဘ်ရှိ {{ui:Reset to BimCraft's own defaults}} က BimCraft ၏ မူဝါဒများကိုသာ ရှင်းသည်။

## သိထားသင့်သည်များ

- ဖိုင်သည် ရိုးရှင်း၊ ဖတ်ရလွယ်သော JSON ဖြစ်သည်: မူဝါဒအမည်နှင့် တန်ဖိုးများ၏ စာရင်း။ ဤဗားရှင်းမသိသော မူဝါဒကို ဖိုင်က အမည်ပေးထားလျှင် ချန်ထားပြီး မက်ဆေ့ချ်တွင် အမည်ဖြင့် ဖော်ပြသည်; ကျန်သည် ဆက်လက် တင်သည်။
- မူဝါဒများကို ဤကွန်ပျူတာရှိ CadCraft app တိုင်းအတွက် ဤဘရောက်ဇာတွင် သိမ်းထားသည်။ အဆောက်အအုံဖိုင်တွင် သိမ်းမထားပါ၊ ကွန်ပျူတာများကြား ထပ်တူမကျပါ: ဖိုင်ကို သုံးပါ။
- စတင်အမျိုးအစား၏ LOD တဂ်သည် ဤကွန်ပျူတာရှိ မူဝါဒမှ လာသည်။ စတင်အမျိုးအစား၏ မိတ္တူအဖြစ် ပြုလုပ်သော အမျိုးအစားသည် ၎င်း၏ တဂ်ကို အဆောက်အအုံဖိုင်တွင် ယူသည်။
- BimCraft တွင် တိကျမှု ဆက်တင် မရှိပါ၊ ထို့ကြောင့် ဤနေရာတွင် တိကျမှု မူဝါဒ မရှိပါ။
- ပုံစံမှ စတင်သော အဆောက်အအုံသည် ပုံစံ၏ ကိုယ်ပိုင်အဆင့်များနှင့် စာရွက်များကို ယူသည်။ နံရံအမျိုးအစားနှင့် ယူနစ် မူဝါဒသည် ဆက်လက် သက်ရောက်သည်။
- ထပ်ဆောင်းကို ပိတ်လိုက်လျှင် အရာအားလုံးသည် BimCraft ၏ ကိုယ်ပိုင်သို့ ပြန်ရောက်သည်။ ပြန်ဖွင့်သည့်အချိန်အတွက် သင့်မူဝါဒများကို သိမ်းထားသည်။
