IFC တစ်ခုကို ဖွင့်ပြီး ၎င်းနှင့်အတူ point cloud တစ်ခုကို ဖွင့်ပါ (see [Point clouds](topic:point-clouds)) ထို့နောက် မော်ဒယ်ပေါ်တွင် နေရာချပါ။ Cloud ဖွင့်ထားစဉ် ညာဘက် panel တွင် {{ui:Compare the scan with the model}} အပိုင်း ပေါ်လာသည်။

## ဘာလုပ်သလဲ

{{ui:Compare}} ကို နှိပ်ပါ။ မော်ဒယ်၏ ဒြပ်စင်တိုင်းကို မျက်နှာပြင်ဖြင့် စစ်ဆေးသည်၊ စကင်ဖတ်သူက မြင်သည်မှာ မျက်နှာပြင်ဖြစ်သောကြောင့်ဖြစ်သည်။ ဒြပ်စင်၏ သေတ္တာ၏ မျက်နှာ ၆ ခုကို ၂၀ စင်တီမီတာ ခန့် ဆဲလ်များအဖြစ် ဖြတ်သည်။ စကင် အမှတ်တစ်ခုသည် မျက်နှာ၏ သင်၏ {{ui:Tolerance}} (စတင်ရန် 50 mm) အတွင်း ရှိပါက ဆဲလ်တစ်ခု ရေတွက်သည်။ အကြီးဆုံး မျက်နှာကောင်းသည် ရေတွက်သည်၊ ထို့ကြောင့် တစ်ဘက်မှ စကင်ဖတ်ထားသော နံရံသည် အခြားဘက်အတွက် ပြစ်ဒဏ် မခံရပါ။

- **Built**: မျက်နှာ၏ အနည်းဆုံး 40 % ကို မြင်ရသည်။
- **Partly**: 10 % မှ 40 %။
- **Missing**: ထိုထက်နည်းသော်လည်း စကင်က ဒြပ်စင်သို့ ရောက်သည် (ဒြပ်စင်မှ 1.5 m အတွင်း အမှတ်များ ရှိသည်)။
- **Not reached**: စကင်က ထိုနေရာသို့ မသွားခဲ့ပါ၊ ထို့ကြောင့် ၎င်းအကြောင်း ဘာမျှ မပြောပါ။

Built နှင့် partly built ဒြပ်စင်များအတွက် စကင်အမှတ်များ၏ မော်ဒယ်မျက်နှာပြင်မှ ပျမ်းမျှ offset ကိုလည်း ပေးပြီး ဒြပ်စင်သည် နေရာတွင် (tolerance အတွင်း)၊ နီးစပ် (သုံးဆအတွင်း) သို့မဟုတ် off (ထို့ထက်ဝေး) ဟု ပြောသည်။ Tolerance ၏ ငါးဆအထိ offset များကိုသာ မြင်နိုင်သည်၊ ထိုထက် ဝေးသည့် နေရာတွင် တည်ဆောက်ထားသော ဒြပ်စင်သည် missing ဟု ဖတ်ရသည်။

ချုပ်ရလဒ်သည် စကင် ရောက်သော ဒြပ်စင်များအကြား built ရာခိုင်နှုန်းကို အရေအတွက်နှင့် ပမာဏအလိုက် ပေးသည်။ Partly built ဒြပ်စင်များကို သီးခြား ရေတွက်ပြီး built ထဲသို့ မပေါင်းပါ။

## 4D အချိန်ဇယားနှင့်

4D အချိန်ဇယား ဖွင့်ထားလျှင် (see [4D schedule](topic:4d-schedule))၊ ရလဒ်သည် 4D slider တွင် သင်သတ်မှတ်ထားသော နေ့ကိုလည်း အသုံးပြုသည်- ထိုနေ့တွင် ရောက်သင့်သော်လည်း စကင်က built ဟု မပြသော ဒြပ်စင်များသည် **behind the schedule** ဖြစ်သည်၊ မရောက်သေးသော်လည်း built ဖြစ်နေသော ဒြပ်စင်များသည် **ahead** ဖြစ်သည်။ နောက်ကျသော ဒြပ်စင်များကို {{ui:Problems}} တွင် စာရင်းပြုပြီး ဇယားကို ၎င်းတို့သို့ စစ်ထုတ်နိုင်သည်။ အချိန်ဇယား မရှိလျှင် နောက်ကျခြင်း သို့မဟုတ် စောခြင်းအကြောင်း ဘာမျှ မပြောပါ။

## ဇယားနှင့် မော်ဒယ်

ဒြပ်စင်ကို ရွေးရန် အတန်းတစ်ခုကို နှိပ်ပါ။ {{ui:Colour the model}} သည် ဒြပ်စင်များကို အစိမ်း (built)၊ အဝါ (partly)၊ အနီ (missing) သို့မဟုတ် မီးခိုး (not reached) ဖြင့် ဆိုးသည်၊ {{ui:Own colours}} ဖြင့် မူလသို့ ပြန်ရောက်သည်။ {{ui:Save CSV}} သည် ဇယားကို ရေးသည်။ {{ui:Mark the matching elements as field-verified}} သည် built နှင့် tolerance အတွင်း မြင်ရသော ဒြပ်စင်အားလုံးကို field-verified (LOD 500၊ method scan) ဟု တစ်ကြိမ်တည်းဖြင့် အမှတ်အသားပြုပြီး ပြန်ဖျက်နိုင်သည်။ [ဒြပ်စင်များကို စစ်ဆေးပြီး သို့မဟုတ် field-verified အဖြစ် အမှတ်အသားပြုခြင်း](topic:verification) ကို ကြည့်ပါ။

:::warning
ဤအရာသည် ဒြပ်စင်တစ်ခုစီ၏ သေတ္တာကို tolerance အတွင်း စကင်အမှတ်များနှင့် နှိုင်းယှဉ်သည်။ ၎င်းသည် **စစ်တမ်း၊ ပမာဏ တွက်ချက်ချက် သို့မဟုတ် ငွေပေးချေမှုအတွက် အခြေခံ မဟုတ်ပါ**။ စကင်ဖတ်ထားသော ဒြပ်စင်နောက်တွင် ဝှက်ထားသော ဒြပ်စင် (လိုင်နင်နောက်ရှိ နံရံ၊ ကြမ်းခင်းအောက်ရှိ ကြမ်းပြင်ပြား) သည် မျက်နှာပြင်ကို မျှဝေပြီး built ဟု ဖတ်ရနိုင်သည်၊ ကွေးသော သို့မဟုတ် စောက်စောက်ရှိ ဒြပ်စင်တွင် သေတ္တာသည် ကိုယ်ထည်ထက် ကြီးသဖြင့် partly သို့မဟုတ် missing ဟု ဖတ်ရနိုင်သည်။ အရာတစ်ခုခု မလုပ်မီ စာရင်းကို ကြည့်ပါ။ ခွင့်ပြုချက် မှတ်ချက်များနှင့် တိုးတက်မှု မှတ်စုများသည် ဤအရာ၏ အစိတ်အပိုင်း မဟုတ်ပါ၊ သင်ထားသော ကော်လံများတွင်သာ ရှိနေသည်။
:::
