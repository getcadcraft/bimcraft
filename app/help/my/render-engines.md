{{ui:Render}} တွင် {{ui:Mode}} အပေါ်၌ **Engine** ရွေးချယ်မှု ရှိသည်။ ကျွန်ုပ်တို့၏ engine နှစ်ခုသည် အမြဲရှိပြီး နေရာတိုင်းတွင် အလုပ်လုပ်သည်; ထပ်ဆောင်းများက ပိုထည့်နိုင်ပြီး CadCraft Studio တွင် စာရင်းတွင် ဇာတ်ကွင်းကို လက်ဝယ်ယူသော program များလည်း ပါသည်။

| Engine | ဘာလုပ်သလဲ | ဘယ်မှာ |
|---|---|---|
| အတွင်းပါ: မြန်ဆန် | အမြန် ငြိမ်ပုံ: နေ့ရောင်၊ နူးညံ့သော အရိပ်၊ ဖန်နှင့် သတ္တုပုံစံများ၊ စက္ကန့်ပိုင်းအတွင်း | ဝဘ်နှင့် Studio |
| အတွင်းပါ: Path tracer | မျက်နှာပြင်များကြား အလင်း ပြန်ထွက်ခြင်း၊ သင့်ဂရပ်ဖစ်ကတ် သို့မဟုတ် processor ပေါ်တွင်၊ render queue နှင့် ကွန်ရက်ပေါ်ရှိ အခြားကွန်ပျူတာများ | ဝဘ်နှင့် Studio |
| ထပ်ဆောင်း၏ engine | ရုပ်ပုံကို ဆွဲပြီး ပြန်ပေးသည်: [အခြား program ဖြင့် ရုပ်ပုံဆွဲခြင်း](topic:render-other-program) ကို ကြည့်ပါ | ဝဘ် (JavaScript ဖြင့် ရေးသော engine) သို့မဟုတ် Studio (program run သော engine) |
| ဇာတ်ကွင်းကို လက်ဝယ်ယူသော program | Studio က ဇာတ်ကွင်းကို ၎င်း၏ folder ထဲ ထည့်ပြီး ညီညွတ်အောင် ထိန်းထားသည် | Studio |
| ဖြင့်ဖွင့်ရန် … | ဇာတ်ကွင်းကို သိမ်းပြီး program တစ်ခုတွင် ဖွင့်သည်; ပြန်မလာပါ: [ဇာတ်ကွင်းကို အခြား program ဖြင့် ဖွင့်ခြင်း](topic:render-open-in) ကို ကြည့်ပါ | ဝဘ်က ဖိုင်ကို သိမ်းသည် |

## ရွေးချယ်မှု အလုပ်လုပ်ပုံ

- မြန်ဆန် သို့မဟုတ် Path tracer ကို ရွေးလျှင် မုဒ် ပါ အလိုက် ပြောင်းသည်၊ ပြောင်းပြန်လည်း ဖြစ်သည်။ အခြား engine ကို တစ်ခါမှ မသုံးသူများအတွက် dialog ၏ အခြားအရာများ မပြောင်းပါ။
- မရရှိနိုင်သော engine သည် အကြောင်းရင်းနှင့်အတူ စာရင်းတွင် ရှိနေသည် ("ရှာမတွေ့" "ဗားရှင်းသစ် လိုအပ်သည်"); ရွေး၍ မရပါ။ ဝဘ်တွင် Studio တွင်သာ run သော engine က "ဖိုင်သိမ်းသည်" ဟု ပြသည်; {{ui:Render}} က ဇာတ်ကွင်းနှင့် ဆက်တင်များကို ထို program သို့ သယ်ဆောင်ရန် ဖိုင်တစ်ခုအဖြစ် သိမ်းသည်။
- ရွေးချယ်မှုကို ဖိုင်၏ render ဆက်တင်များနှင့်အတူ သိမ်းသည်၊ နောက်ဆုံးရွေးထားသော engine သည် ကိုယ်ပိုင်ရွေးချယ်မှု မရှိသော ဖိုင်များအတွက် စတင်အသုံးပြုမည့် engine ဖြစ်သည်။
- အခြား program မှ ရုပ်ပုံသည် မည်သည့် program က ဆွဲသည်နှင့် ၎င်း၏ ဗားရှင်းကို dialog နှင့် render queue တွင် ပြသည်။ [Render](topic:render) စာမျက်နှာ၏ ကတိများသည် **ကျွန်ုပ်တို့၏ကိုယ်ပိုင်** engine များအတွက်သာ ဖြစ်သည်: အခြား program သည် အလင်း၊ အရောင်အသွေးနှင့် နမူနာများကို ကိုယ်ပိုင်နည်းဖြင့် လုပ်သဖြင့် ဇာတ်ကွင်းတစ်ခုတည်း၏ ရုပ်ပုံ နှစ်ပုံသည် ကင်မရာ၊ နေ၊ မီးလုံးနှင့် exposure တွင် ဆင်တူသော်လည်း pixel အတိအကျ မတူပါ။

## engine တိုင်းရရှိသော အရာ

ဇာတ်ကွင်းသည် အခြား program သို့ **package** အဖြစ် သွားသည်: မော်ဒယ်ကို USD ဖိုင် ([USD အဖြစ် အမည်ပြောင်း၍ သိမ်းရန်](topic:usd) ရေးသော ဖိုင်နှင့် တူညီသည်) အဖြစ်၊ နှင့် USD importer ကို အတိအကျ ယုံ၍ မရသော အရာများ - material တန်ဖိုးအတိအကျ၊ ဖွင့်ထားသော မီးလုံးများ၏ power နှင့် light profile၊ နေ၊ ကောင်းကင်၊ exposure နှင့် dialog ဆွဲမည့်အတိုင်း ကင်မရာ - ပါဝင်သော ဆက်တင်ဖိုင်။ ဘယ်နေရာသို့မဆို အပ်လုဒ် မလုပ်ပါ။

## Render တန်းစီစာရင်း

အခြား program အတွက် ရုပ်ပုံသည် ကိုယ်ပိုင် engine ကဲ့သို့ [render တန်းစီစာရင်း](topic:render#the-render-queue) တွင် စောင့်နိုင်သည်; ၎င်း၏ job သည် မည်သည့် engine အတွက်ဖြစ်သည်ကို မှတ်ထားသည်။
