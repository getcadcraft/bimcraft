BimCraft ၏ command များသည် သင် ဘယ်နည်းဖြင့် ရောက်ရှိသည်ဖြစ်စေ အတူတူ ဖြစ်ပါသည်။ **မီနူးပုံစံ** တစ်ခုသည် ၎င်းတို့ မျက်နှာပြင်ပေါ်တွင် ဘယ်နေရာ၌ ရှိမည်၊ ဘာနာမည်ဖြင့် ခေါ်မည်နှင့် ဘယ် key က ၎င်းတို့ကို လုပ်ဆောင်မည်ကိုသာ ဆုံးဖြတ်သောကြောင့် သင့်ရှိပြီးသား အလေ့အကျင့်များကို ဆက်လက်ထိန်းသိမ်းနိုင်ပါသည်။ {{ui:ဆက်တင်များ}} ({{key:Mod+,}}) › {{ui:BimCraft}} › {{ui:Menus, keys နှင့် mouse}} တွင် ရွေးချယ်ပါ၊ ပြောင်းလဲမှုသည် ချက်ချင်း ဖြစ်ပြီး ဤဘရောက်ဇာက ၎င်းကို မှတ်ထားပါသည်။

## စတိုင် ငါးခု

| စတိုင် | သင်ရရှိမည့်အရာ |
|---|---|
| {{ui:CadCraft}} | BimCraft ၏ ကိုယ်ပိုင် toolbar နှင့် keys ({{key:W}} နံရံ၊ {{key:D}} တံခါး၊ {{key:N}} ပြတင်းပေါက်၊ {{key:X}} section၊ {{key:F}} အံဝင်)။ စတင်ရန် ပုံစံ။ |
| {{ui:အိမ်ဒီဇိုင်း}} | မီနူးဘား (ဖိုင်၊ တည်းဖြတ်ရန်၊ Build၊ စာကြည့်တိုက်၊ 3D၊ CAD၊ ကိရိယာများ၊ ကြည့်ရန်) အပေါ်တွင် အဆောက်အအုံ ကိရိယာများ အတန်းတစ်တန်း၊ နေအိမ် home-design program များ ခင်ဒဲ့ ဖော်ပြသည့် ပုံစံအတိုင်း။ တူညီသော single keys အပြင် စာကြည့်တိုက်အတွက် {{key:Mod+L}}၊ 3D view အတွက် {{key:F9}}၊ plan အတွက် {{key:F10}} နှင့် နှစ်ခုလုံးအတွက် {{key:F11}}။ |
| {{ui:BIM ribbon}} | ခလုတ်ကြီးများ၏ tab များ (Architecture၊ Insert၊ Annotate၊ Modify၊ View၊ Output) ဖြင့် File မီနူးနှင့် ညာဘက်ရှိ အမြန်ခလုတ်များ။ အက္ခရာ နှစ်လုံး keys: wall အတွက် {{key:W}} ထို့နောက် {{key:A}}၊ door {{key:D}} {{key:R}}၊ window {{key:W}} {{key:N}}၊ section {{key:S}} {{key:C}}၊ fit {{key:Z}} {{key:F}}။ အလယ် ခလုတ်က pan လုပ်သည်; {{key:Shift}} နှင့် အလယ် ခလုတ်က orbit လုပ်သည်။ |
| {{ui:Drafting classic}} | command ရိုက်သူများအတွက် ribbon သေး တစ်ခုနှင့် command line: WALL၊ DOOR၊ WINDOW၊ ROOF၊ U (undo)၊ ZOOM၊ SECTION၊ PLOT၊ INSERT၊ HELP။ နေရာမရွေး ရိုက်စတင်လိုက်လျှင် အက္ခရာများသည် command line သို့ ရောက်သွားသည်; {{key:Enter}} က လုပ်ဆောင်သည်၊ ဘာမျှ မရှိစဉ် {{key:Enter}} က နောက်ဆုံး command ကို ပြန်လုပ်သည်၊ {{key:Esc}} က ရှင်းလင်းသည်။ |
| {{ui:ကြည့်ရှုရေး}} | မော်ဒယ်များကို ဆွဲခြင်းထက် ဖွင့်ခြင်းနှင့် စစ်ဆေးခြင်းအတွက်: {{ui:ဖိုင်}}၊ {{ui:ကြည့်ရန်}}၊ {{ui:ပြရန်}}၊ {{ui:စစ်ဆေးရန်}} နှင့် {{ui:တည်းဖြတ်ရန်}} မီနူးများ အပေါ်တွင် ကြည့်ရှုကိရိယာ အတန်း (fit၊ top၊ front၊ side၊ section၊ measure၊ hide၊ isolate၊ see-through၊ show all၊ walk)။ အဆောက်အအုံကိရိယာများက နောက်ဆုံးတွင် {{ui:မော်ဒယ်}} မီနူးထဲ စောင့်နေသည်။ BimCraft ၏ ကိုယ်ပိုင်ပုံစံနှင့် တူညီသော keys။ |

မော်ဒယ် တစ်ခု ဖွင့်ပြီး သို့မဟုတ် အဆောက်အအုံအသစ် စတင်ပြီးမှသာ မီနူးများနှင့် ribbon များ ပေါ်လာပါသည်။ ထိုမတိုင်မီ ဘယ်ဘက် panel က ဖိုင်များကို ဖွင့်ပြီး အဆောက်အအုံများကို စတင်ပေးပါသည်။

:::tip
BimCraft ၏ ကိုယ်ပိုင် layout နှင့် ပိုင်သော်လည်း သင်ရွေးထားသော စတိုင်နှင့် မပိုင်သည့် key သည် ဘာမျှ မလုပ်ပါ၊ status line က ၎င်း command ရောက်သွားသည့် နေရာကို ပြပါသည် ("In BIM ribbon, Section is SC")။ {{key:Delete}}၊ {{key:Esc}}၊ {{key:Enter}}၊ {{key:Tab}}၊ {{key:Space}} နှင့် မြားခလုတ်များသည် အမြဲ ၎င်းတို့ အဓိပ္ပာယ်ကို ထိန်းသိမ်းပြီး လည်ပတ်နေသော tool တစ်ခုသည် ၎င်း၏ကိုယ်ပိုင် keys ကို ထိန်းသိမ်းသည်: နေရာချနေစဉ် {{key:R}} နှင့် {{key:Tab}}၊ လမ်းလျှောက်နေစဉ် {{key:W}} {{key:A}} {{key:S}} {{key:D}}၊ တံခါးနှင့် ပြတင်းပေါက် tool များဖြင့် {{key:H}}၊ အရှည် ရိုက်နေစဉ် ဂဏန်းများ။
:::

## သင့်ကိုယ်ပိုင် ပြုလုပ်ရန်

1. သင်လိုချင်သည်နှင့် အနီးဆုံး ပုံစံကို ရွေးပြီး {{ui:စိတ်ကြိုက်ပြင်ရန်…}} ကို နှိပ်ပါ။
2. {{ui:Keys နှင့် menus}} တွင် command ကို ရှာပါ (search box က ကူညီသည်)။ {{ui:key ထည့်ရန်}} ကို နှိပ်ပြီး key ကို နှိပ်ပါ၊ အက္ခရာ နှစ်လုံး key အတွက် key နှစ်ခုကို တစ်ဆက်တည်း နှိပ်ပါ။ key ကို နှိပ်လျှင် ဖယ်ရှားသည်။
3. မီနူးဘား သို့မဟုတ် ribbon ဖြင့် {{ui:တည်နေရာ}} က command ကို အခြား မီနူး သို့မဟုတ် panel သို့၊ သို့မဟုတ် {{ui:Keys သာ}} သို့ ရွှေ့ပေးသည်။
4. {{ui:Mouse}} တွင် ဘီး၊ plan ကို pan လုပ်သည့် ခလုတ်များနှင့် 3D view များတွင် ခလုတ်တစ်ခုစီ လုပ်ဆောင်ချက်ကို သတ်မှတ်ပါ။
5. အမည်ပေးပြီး {{ui:သိမ်းရန်}} ကို နှိပ်ပါ။

ပါလာသော စတိုင်ကို သိမ်းခြင်းက သင့်ကိုယ်ပိုင် မိတ္တူ ("My Home design") ဖန်တီးပေးသည်၊ built-in တစ်ခုသည် တစ်ခါမှ မပြောင်းပါ။ command နှစ်ခုကို key တစ်ခုတည်း ပေးထားခြင်း၊ သို့မဟုတ် အက္ခရာ နှစ်လုံး ရိုက်နိုင်မီ လုပ်ဆောင်သွားမည့် key ဖြစ်ခြင်းတို့ကို အနီရောင်ဖြင့် ပြပြီး သိမ်းခင် ပြင်ရပါမည်။

## Mouse

- **Mouse ဘီး**: {{ui:အပေါ်သို့ scroll လုပ်လျှင် zoom in}} (မူလ) သို့မဟုတ် {{ui:အပေါ်သို့ scroll လုပ်လျှင် zoom out}}၊ နှင့် ၎င်း၏ အမြန်နှုန်း။ trackpad pinch က အမြဲ သင့်လက်ချောင်းများ ရွေ့သည့် ဘက်သို့ zoom လုပ်သည်။
- **Plan နှင့် ပုံများကို pan လုပ်ရန်**: ဘယ်၊ အလယ်နှင့် ညာ ခလုတ်များမှ မည်သည့်ခလုတ်ဖြင့်မဆို။ {{key:Space}} နှင့် drag လုပ်ခြင်းလည်း pan လုပ်သည်; ဘယ်ခလုတ် drag သည် click က ရွေး သို့မဟုတ် ဆွဲမည်မဟုတ်သော နေရာတွင်သာ pan လုပ်သည်။
- **3D view များတွင် drag**: {{ui:View တစ်ခုချင်းစီ၏ ကိုယ်ပိုင်}} က BimCraft ၏ ခလုတ်များကို ထိန်းထားသည် (ဘယ်က orbit၊ ညာက pan)။ သို့မဟုတ် ခလုတ်တစ်ခုစီကို orbit၊ pan၊ zoom သို့မဟုတ် ဘာမျှ မလုပ်ရန် သတ်မှတ်နိုင်သည်; {{key:Shift}} နှင့် ခလုတ်သည် orbit နှင့် pan ကို လဲလှယ်သည်။ drag မလုပ်ဘဲ click ကသာ ရွေးချယ်ပါသည်။

## သင်နှင့်အတူ ယူဆောင်ရန်

{{ui:ထုတ်ရန်}} သည် အသုံးပြုနေသော style ကို သေးငယ်သော `.ccinput.json` ဖိုင်အဖြစ် သိမ်းသည်; {{ui:သွင်းရန်…}} သည် အခြား ကွန်ပျူတာ သို့မဟုတ် လုပ်ဖော်ကိုင်ဖက်ထံမှ တစ်ခုကို ထည့်သည်။ သွင်းထားသော ဖိုင်သည် BimCraft ၏ ကိုယ်ပိုင် command များကိုသာ ညွှန်ပြနိုင်ပြီး အခြားအရာများ (ဤဗားရှင်းတွင် မရှိသော command၊ ဤနေရာတွင် မအလုပ်လုပ်သော key) ကို ချန်လှပ်ထားပြီး status line တွင် ရေတွက်ပြသည်။ {{ui:ဤ style ကို ဖျက်ရန်}} က သင့်ကိုယ်ပိုင် တစ်ခုကို ဖယ်ရှားသည်။

:::note
ဤဆက်တင်များသည် ဤဘရောက်ဇာတွင်သာ ရှိနေသည်။ style card များအောက်ရှိ {{ui:ဤ style ကို အက်ပ်အားလုံးတွင် အသုံးပြုရန်}} က app တိုင်းကို ၎င်းတို့နှင့် ကိုက်ညီသော style (ကိုယ်ပိုင် toolbar၊ မီနူးဘား၊ ribbon သို့မဟုတ် Drafting classic; {{ui:ကြည့်ရှုရေး}} သည် BimCraft ကိုယ်တိုင်သာ ဖြစ်ပြီး အခြားနေရာတွင် မကိုက်ညီပါ) ဖြင့် ဖွင့်စေသည်၊ app တစ်ခုစီတွင် သင်ပြုလုပ်ထားသော ပြောင်းလဲမှုများနှင့်အတူ။ ကိုက်ညီသော style မရှိသည့် app သည် ကိုယ်ပိုင်အတိုင်း ဆက်ရှိနေသည်။ app တစ်ခုတွင် အခြား style ရွေးချယ်ခြင်းသည် ထို app ကိုသာ ပြောင်းသည်။
:::
