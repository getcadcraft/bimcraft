## သင်လုပ်ဆောင်မည့်အရာ

run များကို စက်ပစ္စည်းများနှင့် ချိတ်ဆက်ပါ၊ မော်ဒယ်သည် ချိတ်ဆက်ထားသော စနစ်တစ်ခု ဖြစ်စေရန်: ပန့်၏ outlet ကို ထွက်သွားသော ပိုက်နှင့်၊ diffuser ၏ neck ကို ၎င်း၏ branch လေပိုက်နှင့်။ ထို့နောက် ချိတ်မထားရသေးသည်များကို BimCraft က စာရင်းပြုစေပါ။

## port မှ ဆွဲခြင်း

1. {{ui:ပိုက်}} သို့မဟုတ် {{ui:လေပိုက်}} ကို ရွေးပါ။
2. pointer ကို စက်ပစ္စည်းတစ်ခု၏ port ပေါ် ရွှေ့ပါ (သေးငယ်သော စက်ဝိုင်းများ; ဖွင့်ထားသော port ကို သတိပေးရောင်ဖြင့် ဆွဲသည်)။ pointer က ၎င်းနှင့် snap ဖြစ်ပြီး **on a port** ဟု ပြောသည်။
3. Click: run သည် port ၏ အမြင့်တွင် စတင်ပြီး **port ၏ အရွယ်အစားနှင့် စနစ်ကို ယူသည်** (ပိုက်သည် စနစ်၏ ပုံမှန် ပစ္စည်းကိုလည်း ယူသည်)။ status line က ယူသွားသည့်အရာကို ပြောသည်။
4. ပုံမှန်အတိုင်း ဆက်ဆွဲပါ။ run ကို အခြား port တစ်ခုတွင် အဆုံးသတ်ခြင်းက ထို အဆုံးကိုလည်း ပြင်ဆင်ပေးသည်။

port ပေါ်ရှိ run ၏ အဆုံးသည် ၎င်းနှင့် **ပြင်ဆင်ထား** သည်: စက်ပစ္စည်းကို ရွှေ့ သို့မဟုတ် လှည့် (ဂုဏ်သတ္တိများ တွင်) ပါက run ၏ အဆုံးက ၎င်းနှင့်အတူ လိုက်သည်; run ကို တည်းဖြတ်သော်လည်း ထို အဆုံးသည် port ပေါ်တွင် ကျန်နေသည်။ run ၏ အခြား ထောင့်များသည် မူလနေရာတွင် ကျန်နေသဖြင့် ကြီးမားသော ရွှေ့ပြီးနောက် ပထမ leg သည် port မှ ထောင့်တစ်ခုဖြင့် လွတ်သွားနိုင်သည်: နောက်ထောင့်ကိုလည်း ရွှေ့ပါ။

## ချိတ်ဆက်မှုများ စစ်ဆေးခြင်း

{{ui:Build}} ကို ဖွင့်ပြီး {{ui:ချိတ်ဆက်မှု စစ်ဆေးရန်}} ကို နှိပ်ပါ။ bar အောက်ရှိ စာရင်းက ပြသသည်:

| မျဉ်းကြောင်း | အဓိပ္ပာယ် |
|---|---|
| port တစ်ခု မချိတ်ဆက်ရသေးပါ | စက်ပစ္စည်းတစ်ခုတွင် ဘာမျဉ်းမှ မဆွဲထားသော ချိတ်ဆက်မှု တစ်ခု ရှိသည် |
| အဆုံးတွင် ဘာမျှ မရှိပါ | run တစ်ခု လေထဲတွင် အဆုံးသတ်သည် |
| ချိတ်ဆက်ထားသော port များ အရွယ်အစား မတူ | အရွယ်အစား တစ်မျိုးရှိ run တစ်ခုသည် reducer မပါဘဲ အခြား အရွယ်အစား port သို့မဟုတ် run နှင့် တွေ့သည် (ပိုက်၏ nominal အရွယ်အစား၊ လေပိုက်၏ ပုံသဏ္ဍာန်နှင့် ဘက်များ) |
| ချိတ်ဆက်ထားသော port များ စနစ် မတူ | ဥပမာ supply diffuser ပေါ်ရှိ return လေပိုက် |
| ပိုက်တစ်ခု လေပိုက်နှင့် ချိတ်ဆက်ထား | မတူသော အမျိုးအစား ချိတ်ဆက်မှု နှစ်ခု တွေ့သည် |
| ကွန်ရက်တွင် ၎င်းကို ထောက်ပံ့သော စက်ပစ္စည်း မရှိ | run ချိတ်ထားသည့် အရာများထဲမှ မည်မျှ ဝေးသည်ဖြစ်စေ outlet ရှိသည့် အရာ တစ်ခုမှ မရှိပါ။ ရေမြောင်း၊ storm နှင့် vent များကို ဤမေးခွန်း မမေးပါ: ၎င်းတို့၏ ရေသည် fixture များမှ ရောက်သည် |
| မော်ဒယ်တွင် မရှိတော့သော စက်ပစ္စည်း၏ port တစ်ခုသို့ ပြင်ဆင်ထား | စက်ပစ္စည်းကို ဖျက်ပြီးပြီ; အဆုံးကို ပြန်ဆွဲပါ သို့မဟုတ် run ကို ဖျက်ပါ |

အမှားများက ရှေ့ဆုံးတွင် ရှိသည်။ မျဉ်းကြောင်းတစ်ခုကို နှိပ်ပြီး ၎င်းနာမည်ပေးထားသည့်အရာကို ရွေးပါ။ {{ui:ပိတ်ရန်}} က စာရင်းကို ဝှက်သည်။ စစ်ဆေးချက်က ဆွဲထားသည့်အတိုင်း မော်ဒယ်ကို ဖတ်သည်: ချိတ်ဆက်မှုနှင့် အရွယ်အစားများကို စစ်ဆေးသည်၊ စီးဆင်းမှု၊ ဖိအား သို့မဟုတ် balancing ကို ဘယ်တော့မှ မစစ်ပါ။
