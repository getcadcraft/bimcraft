## ဘာလုပ်မလဲ

door type တစ်ခုတွင် ထုတ်လုပ်သူကို သတ်မှတ်ပါ ထို့ကြောင့် ထို type ၏ door တိုင်းက ပြသည်၊ ထို့နောက် door တစ်ခုတည်းကို ကိုယ်ပိုင် မီးဘေးကင်းမှုအဆင့် ပေးပါ၊ အခြားတစ်ခုကို မထိပါ။ ၎င်းသည် BimCraft တွင် type ဂုဏ်သတ္တိနှင့် instance ဂုဏ်သတ္တိကြား ခြားနားချက်ကို ပြသည်။

## Type သလား၊ Instance သလား?

- **instance** ဂုဏ်သတ္တိသည် ဒြပ်စင်တစ်ခုတည်းနှင့် ဆိုင်သည်: ၎င်း၏ tag၊ mark၊ အခန်း၊ ကိုယ်ပိုင် မီးဘေးကင်းမှုအဆင့်။
- **type** ဂုဏ်သတ္တိသည် ဒြပ်စင်များစွာ မျှဝေသော type နှင့် ဆိုင်သည်: ထုတ်လုပ်သူ၊ မော်ဒယ်၊ door type ၏ အကျယ်။

{{ui:ဂုဏ်သတ္တိများ}} panel တွင် type မှလာသော set များသည် အမည်နောက်တွင် " (type)" ရှိပြီး "Type ဂုဏ်သတ္တိ: ဤနေရာက ပြောင်းလဲမှုသည် ဤ type ၏ ဒြပ်စင်တိုင်းကို သက်ရောက်သည်။" ဟူသော စာကြောင်းရှိသည်။ အခြား set တိုင်းသည် ဒြပ်စင်ကိုယ်တိုင်နှင့် ဆိုင်သည်။ ပထမ block ရှိ **Type** သည် type ၏ အမည်ကို ပြသည်။

## အဆင့်များ: type ကို ပြောင်းခြင်း

1. IFC မော်ဒယ်ကို ဖွင့်ပြီး တံခါးတစ်ခုကို နှိပ်ပါ။
2. {{ui:ဂုဏ်သတ္တိများ}} panel ၏ ပထမ block တွင် **Type** ကို မှတ်ပါ၊ ဥပမာ "Single-Flush 900 x 2100"။
3. အမည်တွင် "(type)" ဖြင့် အဆုံးသတ်သော set ကို လှိမ့်ပါ။
4. ပြောင်းလိုသော တန်ဖိုးကို နှိပ်ပါ၊ ဥပမာ **Manufacturer**။
5. တန်ဖိုးအသစ်ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
6. {{ui:ပြောင်းလဲမှုများ}} စာရင်းကို ကြည့်ပါ: အတန်းသည် "(type)" ဖြင့် အဆုံးသတ်သည်။
7. တူညီသော type ၏ တံခါးတစ်ခုကို နှိပ်ပါ။
8. တန်ဖိုးကို စစ်ပါ: တန်ဖိုးအသစ်ကို ပြသည်။

## အဆင့်များ: ဒြပ်စင်တစ်ခုတည်းကိုသာ ပြောင်းခြင်း

1. တံခါးတစ်ခုကို နှိပ်ပါ။
2. အမည်တွင် "(type)" မပါသော set တစ်ခုကို ဖွင့်ပါ၊ ဥပမာ `Pset_DoorCommon`။
3. တန်ဖိုးတစ်ခုကို နှိပ်ပါ၊ ဥပမာ **FireRating**၊ တန်ဖိုးအသစ်ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
4. ၎င်းဘေးရှိ တူညီသော type ၏ တံခါးကို နှိပ်ပါ။
5. တန်ဖိုးကို စစ်ပါ: ဟောင်းတန်ဖိုးကို ဆက်ပြသည်။

exporter က property set ကို တံခါးနှစ်ခုလုံးအတွက် မျှဝေထားသော်လည်း BimCraft သည် ပထမတံခါးကို ပြောင်းမီ ကိုယ်ပိုင်မိတ္တူ ပေးခဲ့သည်။ ကြည့်ပါ: [ဂုဏ်သတ္တိကို ပြင်ရာတွင် တစ်ခုတည်းသာ ပြောင်းသည့်အကြောင်း](topic:edit-ifc-properties#why-your-edit-changes-only-one-element)။

## သိမ်းခြင်း

1. {{ui:IFC အဖြစ် သိမ်းရန်}} ကို နှိပ်ပါ သို့မဟုတ် {{key:Mod+S}} ကို နှိပ်ပါ။
2. သိမ်းထားသော မိတ္တူကို BimCraft တွင် သို့မဟုတ် မည်သည့် IFC viewer တွင်မဆို ပြန်ဖွင့်ပြီး ပြောင်းလဲမှု နှစ်ခုလုံးကို စစ်ပါ။

## အမှားများ

- **မော်ဒယ်အချို့တွင် type မရှိပါ။** exporter အချို့က type object မရေးပါ၊ သို့မဟုတ် အားလုံးကို instance တွင်သာ ထားသည်။ ထိုအခါ "(type)" set မရှိပြီး ဒြပ်စင်တစ်ခုစီကို သီးခြား ပြင်ရမည်။
- **တန်ဖိုးတူညီသည် type set နှင့် instance set နှစ်ခုလုံးတွင် ပေါ်သည်။** exporter အချို့က parameter တစ်ခုကို နေရာနှစ်ခုလုံးတွင် ရေးသည်။ အခြားပရိုဂရမ်များက တစ်ခုခုကို ဖတ်နိုင်သည်; သဘောတူရန် လိုလျှင် နှစ်ခုလုံးကို ပြောင်းပါ။
- **ဤ type ၏ "ဒြပ်စင်အားလုံးကို ရွေး၍ အတူတူ ပြင်ရန်" ကို မျှော်လင့်ခြင်း။** ဤဗားရှင်းတွင် multi-select မရှိပါ။ type ဂုဏ်သတ္တိသည် ဒြပ်စင်များစွာကို တစ်ကြိမ်တည်း ပြောင်းရန် နည်းလမ်းဖြစ်သည်။
