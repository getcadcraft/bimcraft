## လုပ်ဆောင်မည့်အရာ

အဆောက်အဦ၏ အခွံကို ပြီးအောင် လုပ်ပါ။ အခန်းများသည် နံရံများမှ အလိုအလျောက် ပေါ်လာသည်။ ကြမ်းပြင်၊ ခုံးမနှင့် ခေါင်မိုးတို့ကို ကလစ်တစ်ချက်စီဖြင့် ရနိုင်သည်။ နံရံများမှ ရှာတွေ့သောကြောင့် နံရံများ ရွေ့သည့်အခါ ၎င်းတို့လည်း လိုက်ပြောင်းသည်။

## အခန်းများ

နံရံများဖြင့် ပိတ်ထားသော နေရာတိုင်းသည် အခန်းဖြစ်သည်။ နောက်ဆုံးနံရံက ပိတ်လိုက်သည်နှင့် ပေါ်လာပြီး ဂဏန်း (ပထမထပ်တွင် 101၊ 102 …၊ နောက်ထပ်ထပ်တွင် 201 …) နှင့် အမည် (**Room 1**၊ **Room 2** …) ရှိသည်။ ၎င်း၏ ဧရိယာကို plan ပေါ်တွင် အလယ်တွင် ပြသသည်။

- {{ui:Select}} ဖွင့်ထားစဉ် အခန်းအတွင်းကို နှိပ်၍ ရွေးပါ။ **Properties** တွင် **Name** (ဥပမာ `Kitchen`) နှင့် **Number** ကို ပြောင်းနိုင်သည်။ ဧရိယာနှင့် ပတ်လည်အလျားကို ပြသသည်။
- အခန်းနှစ်ခုကြားရှိ နံရံကို ဖျက်လျှင် တစ်ခုဖြစ်သွားပြီး၊ အခန်းတစ်ခုကို ဖြတ်ဆွဲသော နံရံဖြင့် နှစ်ခု ဖြစ်သွားသည်။ အခန်းသည် ၎င်းကို ဝန်းရံထားသော နံရံများ ရွေ့သော်လည်း အမည်နှင့် နံပါတ်ကို ထိန်းထားသည်။
- အခန်းကို သီးခြား ဖျက်၍ မရပါ။ ၎င်းသည် နံရံများ ဖန်တီးထားသော နေရာဖြစ်သည်။

ဧရိယာကို နံရံမျက်နှာပြင်များ၏ အတွင်းဘက်မှ တိုင်းသည်။ အခန်းများကို ကြမ်းပြင်ဧရိယာ၊ ပတ်လည်အလျား၊ အမြင့်နှင့် ထုထည်တို့ပါသော IFC spaces အဖြစ် သိမ်းသောကြောင့် ဇယားများက ဖတ်နိုင်သည် ([ပမာဏများ ပေါင်းရန်၊ element များကို စာရင်းပြုရန်နှင့် spaces များကို ဇယားပြုရန်](topic:quantity-totals) ကို ကြည့်ပါ)။

## ကြမ်းပြင်များ

1. {{ui:Floor}} ကို နှိပ်ပါ။
2. **ဤအခန်း** သို့မဟုတ် **အဆောက်အဦတစ်ခုလုံး** ကို ရွေးပါ၊ **Kind** (သစ်ကြမ်းပြင် သို့မဟုတ် ကွန်ကရစ် slab) နှင့် အထူကို ရွေးပါ။
3. အခန်းတစ်ခုအတွင်း (သို့မဟုတ် အဆောက်အဦအတွင်း မည်သည့်နေရာမဆို) ကို ညွှန်ပါ။ ကြမ်းပြင်ဖုံးမည့် အရာကို ဧရိယာနှင့်အတူ အရောင်ခွဲပြသည်။
4. နှိပ်ပါ။ ကြမ်းပြင်၏ အပေါ်ဘက်သည် အဆင့်၏ ကြမ်းပြင် ဖြစ်ပြီး အထူအတိုင်း အောက်သို့ ဆင်းသည်။ အဆောက်အဦတစ်ခုလုံးအတွက် ကြမ်းပြင်သည် နံရံ၏ အပြင်ဘက်မျက်နှာပြင်များအထိ ရောက်သည်။

## ခုံးမများ

1. {{ui:Ceiling}} ကို နှိပ်ပါ။
2. **ဤအခန်း** သို့မဟုတ် **အဆောက်အဦတစ်ခုလုံး** ကို ရွေးပြီး ကြမ်းပြင်အထက် **Height** (အမြင့်) ကို ထည့်ပါ။
3. အတွင်းကို ညွှန်ပြီး နှိပ်ပါ။
4. အောက်ဘက်မှ ကြည့်ရန်၊ ၎င်း၏ grid နှင့် မီးများနှင့်အတူ plan ကို ခုံးမ plan သို့ ပြောင်းပါ: [View များ၊ view range များနှင့် ကိုယ်ပိုင် sheet များ](topic:views-and-sheets) ကို ကြည့်ပါ။

## ခေါင်မိုးတစ်ခု

1. ခေါင်မိုးကို ထမ်းရမည့် နံရံများရှိ အဆင့်ပေါ်တွင် {{ui:Roof}} ကို နှိပ်ပါ။
2. **Pitch** ကို 12 အပေါ် တက်မှု အချိုးအစား (`6/12`) သို့မဟုတ် ဒီဂရီ (`30`) ဖြင့် ရိုက်ပြီး **Overhang** ကို ရိုက်ပါ။
3. **Ends** ကို ရွေးပါ: **Hip roof** (ဘက်တိုင်း စောက်စောက်)၊ **Gables on the short sides** သို့မဟုတ် **Gables on the long sides** (မျက်နှာလေးဘက်ရှိ အဆောက်အဦ)၊ သို့မဟုတ် **Shed**။
4. အဆောက်အဦအတွင်းကို ညွှန်ပါ။ eave နှင့် ridge တို့ plan ပေါ်တွင် ပေါ်လာသည်။ နှိပ်ပါ။

ခေါင်မိုးသည် နံရံများ၏ အပေါ်တွင်၊ ၎င်းတို့အထက် အဆင့်တွင် ထိုင်သည်၊ အောက်မျက်နှာပြင်သည် နံရံ၏ အပြင်ဘက်မျက်နှာနှင့် ထိသည်။ Gable ထိပ်များကို အောက်ရှိ နံရံနှင့် အထူတူသော gable နံရံဖြင့် ဖြည့်သည်။ L-, T- သို့မဟုတ် U-ပုံသဏ္ဍာန် အဆောက်အဦသည် တောင်ပံများ ဆုံသော valley များပါသည့် hip ခေါင်မိုး ရသည်။

## ပြင်ဆင်ရန်

ကြမ်းပြင်၊ ခုံးမ သို့မဟုတ် ခေါင်မိုးတစ်ခုကို ရွေးပါ (3D view၊ model tree၊ သို့မဟုတ် အထက်အဆင့်ရှိ ခေါင်မိုး outline အတွင်း နှိပ်ခြင်းဖြင့်) ပြီး **Properties** တွင် ပြောင်းပါ။ ကြမ်းပြင်၏ အမျိုးအစား၊ အထူနှင့် အပေါ်ဘက်သည် အဆင့်အထက် အဘယ်မျှရှိသည်။ ခုံးမ၏ အမြင့်၊ အထူနှင့် **Pattern** (ခုံးမ plan တွင် ဆွဲမည့် grid၊ မရှိ၊ 600 × 600၊ 600 × 1200၊ 2' × 2' သို့မဟုတ် 2' × 4'). ခေါင်မိုး၏ pitch၊ overhang၊ ends နှင့် အထူ။ ပြောင်းလဲမှုတိုင်းသည် undo တစ်ခု ဖြစ်သည်။

## အလွှာများဖြင့် ကြမ်းပြင်၊ ခုံးမ သို့မဟုတ် ခေါင်မိုးတစ်ခုကို type ပေးခြင်း

ကြမ်းပြင်၊ ခုံးမနှင့် ခေါင်မိုးတို့သည် နံရံကဲ့သို့ **type** ယူနိုင်သည်။ ၎င်းမှာ အမည်ပေးထားသော အလွှာ တည်ဆောက်ပုံ ဖြစ်ပြီး အလွှာတစ်ခုစီတွင် ၎င်း၏ material နှင့် အမှန်အထူ ပါသည်။

- **နေရာချသည့်အခါ။** Floor၊ Ceiling၊ Roof နှင့် Draw floor ကိရိယာများ၏ အတန်းတွင် **Type** စာရင်း ရှိသည်။ **No type** ဖြင့် ယခင်ကဲ့သို့ ကိုယ်ပိုင်အထူဖြင့် နေရာချသည်။ Type တစ်ခုဖြင့် type ၏ အလွှာများ စုစုပေါင်းအထူအတိုင်း နေရာချသည်။
- **နောက်ပိုင်း။** ကြမ်းပြင်၊ ခုံးမ သို့မဟုတ် ခေါင်မိုးကို ရွေးပြီး Properties တွင် **Type** ကို ရွေးပါ။ Element သည် တူညီသော element အဖြစ် ကျန်ရှိသည်။ ၎င်း၏ နေရာ၊ အခန်းနှင့် ဒေတာ ထိန်းထားပြီး မည်သည်ကိုမျှ ပြန်မဆွဲရ။ အမျိုးအစား၊ အထူနှင့် material သာ ပြောင်းသည်။ ဤသည်မှာ sketch အဆင့် element တစ်ခုကို ပြည့်စုံသော element အဖြစ် ပြောင်းသည့်နည်း ဖြစ်သည်: ယေဘုယျ type ကို အမှန်တကယ် type ဖြင့် လဲပါ။
- **Edit the type…** က ထို type ၏ type editor ကို ဖွင့်သည်: အလွှာများကို **top** မှ အောက်သို့၊ core၊ အလွှာတစ်ခုစီ၏ function နှင့် type ၏ LOD tag။ သိမ်းလိုက်လျှင် ထို type ၏ element အားလုံး တစ်ကြိမ်တည်း ပြောင်းသည်၊ Undo တစ်ကြိမ်ဖြင့် ပြန်ရသည်။ Starter type ကို ပြောင်းလျှင် ကိုယ်ပိုင် type အဖြစ် မိတ္တူ သိမ်းသည်။
- Type ရှိသော element ၏ **Thickness** သည် type ၏ အထူ ဖြစ်ပြီး ရိုက်ထည့်၍ မရပါ။ အထူ ပြောင်းရန် type အခြားတစ်ခု သို့မဟုတ် **No type** ကို ရွေးပါ။

Starter type များမှာ အမျိုးအစားတစ်ခုစီအတွက် **generic** type တစ်ခု (generic material အလွှာတစ်ခု၊ LOD 200 tag) နှင့် အလွှာပါသော type နှစ်ခု (LOD 300 tag) ဖြစ်သည်: သစ် joist ကြမ်းပြင်နှင့် screed ပါသော ကွန်ကရစ်ကြမ်းပြင်; သစ်ခေါင်မိုးနှင့် ကွန်ကရစ် ပြားခေါင်မိုး; gypsum board ခုံးမနှင့် ဆိုင်းထားသော ကြွေပြား ခုံးမ။ ၎င်းတို့သည် စတင်တန်ဖိုးများသာ ဖြစ်ပြီး စမ်းသပ်ပြီးသော တည်ဆောက်ပုံများ မဟုတ်ပါ: အားကိုးမီ အလွှာများကို စစ်ဆေးပါ။

**Layers: area and volume** ဇယားသည် သုံးနေသော type တိုင်း၏ အလွှာတိုင်းကို စာရင်းပြုသည်၊ [ဇယားများ၊ ဖြတ်ကျော်အတိုင်းအတာနှင့် PDF](topic:plan-schedules-and-pdf) ကို ကြည့်ပါ။ ကြမ်းပြင်၊ ခေါင်မိုးနှင့် ခုံးမ type များသည် type pack သို့မဟုတ် စာကြည့်တိုက် ပစ္စည်းအဖြစ် ပရောဂျက်များကြား သွားနိုင်သည်၊ [Type pack များ](topic:type-packs) ကို ကြည့်ပါ။

## သိထားသင့်သည်များ

- နံရံများ ရွေ့ခြင်း၊ ထည့်ခြင်း သို့မဟုတ် ဖျက်ခြင်းသည် အခန်းများ၊ ကြမ်းပြင်များ၊ ခုံးမများနှင့် ၎င်းတို့အပေါ် ခေါင်မိုးကို ထပ်မံ ပြုလုပ်သည်။
- ခေါင်မိုးသည် မည်သည့် outline ကိုမဆို ထိုင်နိုင်သည်။ နံရံတစ်ခုစီကို ကိုယ်ပိုင် pitch၊ gable သို့မဟုတ် shed ထိပ်၊ raised plate၊ fascia နှင့် soffit ပေးရန်၊ သို့မဟုတ် ခေါင်မိုး plane တစ်ခုတည်း ဆွဲရန် [ခေါင်မိုးများ- နံရံတစ်ခုစီအတွက် pitch၊ gable၊ shed နှင့် ခေါင်မိုး plane များ](topic:roofs) ကို ကြည့်ပါ။
- {{key:Delete}} သည် ရွေးထားသော ကြမ်းပြင်၊ ခုံးမ သို့မဟုတ် ခေါင်မိုးကို ဖျက်သည်။
