## ဘာလုပ်မလဲ

သင်ရွေးချယ်သော အမှတ်မှ၊ သင်ရွေးချယ်သော ဦးတည်ချက်ဖြင့် ကြည့်ထားသော အဆောက်အအုံ၏ ပုံဆွဲချက်ကို ကိုယ်တိုင် ဖန်တီးပါ။ အစီအစဉ်ပုံပေါ်တွင် နှိပ်ရန် နှစ်ကြိမ်သာ လိုပါသည်။ ထို့နောက် ပုံဆွဲချက်ကို အဆောက်အအုံ၏ အခြား elevation များနှင့်အတူ စာရင်းထဲတွင် ပြပါမည်။

:::note
မျက်နှာစာ လေးဘက်ကို ရှိပြီးသားဖြစ်သည်။ အဆောက်အအုံတိုင်းတွင် North၊ East၊ South နှင့် West elevation များ ရှိပြီး၊ ၎င်းတို့ကို တစ်ခုမှ မထားဘဲ {{ui:Project browser}} အောက်ရှိ {{ui:Elevations}} တွင် တွေ့နိုင်သည်။ အခြားနေရာမှ မြင်ကွင်းလိုသည့်အခါ ကိုယ်တိုင် ထည့်ပါ၊ ဥပမာ ထောင့်ငန်းသို့ ထောင့်မှန်ဖြင့်၊ ခြံဝင်းအတွင်းမှ၊ သို့မဟုတ် အခန်းတစ်ခန်းအတွင်းရှိ နံရံတစ်ခုကို ကြည့်လိုသည့်အခါ။
:::

## ကိရိယာ ရှိရာနေရာ

- Ribbon အပြင်အဆင်များ: {{ui:View}} › **Create** › {{ui:Elevation}}။
- Classic အပြင်အဆင်: {{ui:Draw}} ကို ဖွင့်ပြီး၊ ထို့နောက် {{ui:Build}} › {{ui:Elevation}}။
- မီနူးပုံစံမည်သည့်အရာမဆို: command အမည်မှာ Elevation ဖြစ်ပြီး command palette တွင် ရှာနိုင်သည်၊ command line တွင် ELEVATION ဟု ရိုက်ပါ။

## အဆင့်များ

1. {{ui:Elevation}} ကို ရွေးပါ။ Elevation ကို အစီအစဉ်ပုံပေါ်တွင် ထားသည်၊ ထို့ကြောင့် 3D မြင်ကွင်းတွင် ရှိနေပါက BimCraft က သင်ရှိနေသော အလွှာ၏ အစီအစဉ်ပုံကို ပြပါမည်။ ပွိုင်တာက **Click where the elevation stands** ဟု ပြပါမည်။
2. မြင်ကွင်းကို ယူမည့်နေရာကို နှိပ်ပါ။ အပြင်ဘက် elevation အတွက်၊ မြင်လိုသော နံရံနှင့် အနည်းငယ် ဝေးသော အဆောက်အအုံ အပြင်ဘက်ကို နှိပ်ပါ။
3. ပွိုင်တာက ယခု **Click the way it looks** ဟု ပြပါမည်။ အဆောက်အအုံဘက်သို့ ရွှေ့ပါ၊ မြှားက ဦးတည်ချက်ကို ပြပြီး၊ ပထမ နှိပ်ချက်ကို ဖြတ်သော တိုတောင်းသည့် မျဉ်းက မြင်ကွင်း ကြည့်သည့် ဘေးဖြစ်သည်။ နှိပ်ပါ။
4. အစီအစဉ်ပုံပေါ်တွင် နံပါတ်နှင့် ပွိုင်တာပါသော စက်ဝိုင်း ပေါ်လာပါမည်။ ၎င်းက elevation marker ဖြစ်သည်။ ပထမတစ်ခုသည် 1၊ နောက်တစ်ခုသည် 2 ဖြစ်သည်။
5. အပြီးသတ်ရန် Esc ကို နှိပ်ပါ၊ သို့မဟုတ် ဆက်လုပ်ပြီး နောက်တစ်ခု ထည့်ပါ။

Marker ထည့်ခြင်းသည် တစ်ဆင့်တည်းဖြစ်သည်။ ပြန်ဖျက်ရန် {{key:Mod+Z}} ကို နှိပ်ပါ။

## ပုံဆွဲချက်ကို ဖွင့်ရန်

ဒုတိယနှိပ်ချက်ပြီးနောက် အစီအစဉ်ပုံသည် သင့်ရှေ့တွင် ရှိနေဆဲဖြစ်သည်။ ပုံဆွဲချက်ကို {{ui:Project browser}} တွင် တွေ့နိုင်သည်–

1. {{ui:Elevations}} ကို ဖွင့်ပါ။ သင့်အမှတ်ကို မျက်နှာစာ လေးခုအပြီးတွင် **Elevation 1** ဟု စာရင်းပြုထားသည်။
2. ပုံဆွဲချက်ကို မြင်ရန်နှင့် အတွင်းတွင် အလုပ်လုပ်ရန် ၎င်း၏ အတန်းပေါ်ရှိ ခဲတံခလုတ် {{ui:Edit in this view}} ကို နှိပ်ပါ- နံရံများ၊ တံခါးများ၊ ပြတင်းပေါက်များနှင့် အလွှာများကို ရွှေ့ရန်၊ မှတ်ချက်နှင့် အတိုင်းအတာများ ထည့်ရန်။ [Edit in elevations and sections](topic:edit-in-elevations) ကို ကြည့်ပါ။
3. ပုံဆွဲချက်ကို ဖွင့်ရန် အတန်းကို ကိုယ်တိုင် နှိပ်ပါ၊ သို့မဟုတ် မြင်ကွင်းကို ကိုယ်ပိုင် စာရွက်သို့ ထည့်ပါ။ [Views and sheets](topic:views-and-sheets) ကို ကြည့်ပါ။

Classic အပြင်အဆင်တွင် {{ui:Draw}} ဖွင့်ထားစဉ် project browser သည် ဘယ်ဘက်ပြားတွင် ရှိသည်။ Ribbon အပြင်အဆင်များတွင် Properties အောက်ရှိ {{ui:Project Browser}} tab ဖြစ်သည်။

## မြင်ကွင်းတွင် ပြသသည့်အရာများ

- Marker ရှေ့ရှိ အရာအားလုံး၊ အဆောက်အအုံ ရောက်သည့်အထိ။ နောက်ဘက်ရှိ အရာမပါ။
- အလွှာများ၊ ၎င်းတို့၏ နာမည်နှင့် အမြင့်များနှင့်အတူ။
- Marker က အဆောက်အအုံအတွင်းတွင် ရပ်နေပါက၊ ၎င်း ရပ်နေသည့် အရာကို ထိုနေရာတွင် section ဖြတ်သကဲ့သို့ ဖြတ်ထားမည်။ သန့်ရှင်းသော အပြင်ဘက် elevation အတွက် အပြင်ဘက်တွင် ရပ်ပါ။

## ပြင်ဆင်ရန်

Marker ကို အစီအစဉ်ပုံပေါ်တွင် ရွေးပါ ({{ui:Select}} ဖြင့် ၎င်း၏ စက်ဝိုင်းကို နှိပ်ပါ)။ Properties တွင် အောက်ပါများ ရှိသည်–

- {{ui:Label}}: ၎င်း၏ နံပါတ် သို့မဟုတ် ကိုယ်ပိုင်အမည်၊ စာလုံး 8 လုံးအထိ။
- {{ui:Flip the view}}: တူညီသော နေရာမှ ဆန့်ကျင်ဘက် ဦးတည်ချက်ကို ကြည့်ပါ။
- {{ui:Look as far as}}: marker ရှေ့မှ မြင်ကွင်း ဘယ်လောက်ဝေးအထိ ရောက်မည်နည်း။ 0 သည် အရာအားလုံးကို ပြသည်။

Marker နှင့် ၎င်း၏ ပုံဆွဲချက်ကို ဖယ်ရှားရန် Delete ကို နှိပ်ပါ။ Undo က နှစ်ခုလုံးကို ပြန်ထားပေးသည်။

:::tip
အလုပ်လုပ်စဉ် အစီအစဉ်နှင့် 3D မြင်ကွင်းကို တစ်ပြိုင်နက် ကြည့်ရန်၊ ribbon အပြင်အဆင်များတွင် {{ui:View}} › **Windows** › {{ui:Tile Views}} ကို သုံးပါ၊ သို့မဟုတ် classic အပြင်အဆင်တွင် {{ui:Split}} ကို သုံးပါ။ မြင်ကွင်း tab ကို နှိပ်လိုက်ပါက တစ်ခုတည်းသော မြင်ကွင်းသို့ ပြန်သွားမည်။
:::

## ကန့်သတ်ချက်များ

- Marker ကို အစီအစဉ်ပုံပေါ်တွင် ဆွဲရွှေ့ခြင်း သို့မဟုတ် လှည့်ခြင်း မရှိသေးပါ။ ဖျက်ပြီး ပြန်ထည့်ပါ၊ သို့မဟုတ် {{ui:Flip the view}} ကို သုံးပါ။
- စာရွက်သို့ ထည့်နိုင်သော မြင်ကွင်းများ စာရင်းတွင်၊ သင်ထည့်ထားသော elevation ကို section များနှင့်အတူ စာရင်းပြုသည်။
- တံခါးနှင့် ပြတင်းပေါက် tag များကို မျက်နှာစာ လေးခုပေါ်တွင် ဆွဲသည်၊ သင်ထည့်ထားသည့် တစ်ခုပေါ်တွင် မဆွဲပါ။

## IFC ထဲတွင်

Marker ကို ဖိုင်ထဲတွင် IfcAnnotation အဖြစ် "Elevation 1" အမည်နှင့် "Elevation marker" object type ဖြင့် သိမ်းသည်၊ ထည့်ခဲ့သော အလွှာတွင် ရှိသည်။ အခြားပရိုဂရမ်တစ်ခုက ၎င်းကို annotation အဖြစ် ပြသည်၊ ပုံဆွဲချက်ကိုမူ BimCraft က မော်ဒယ်မှ အမြဲ ပြန်ဖန်တီးပေးသည်။
