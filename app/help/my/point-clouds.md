## လုပ်ဆောင်မည့်အရာ

မော်ဒယ်ဘေးတွင် အဆောက်အအုံ၏ laser scan ကို ကြည့်ပါ: တည်ဆောက်ထားသည်နှင့် ဒီဇိုင်း ကိုက်ညီမှု စစ်ဆေးပါ၊ scan အမှတ်များကြား တိုင်းတာပါ၊ နံရံ၊ တံခါးနှင့် ကော်လံများကို ဖတ်ရန် ပါးလွှာသော slice တစ်ခုဖြတ်ပါ။

## အဆင့်များ

1. Cloud ကို ဖွင့်ပါ: `.las`, `.laz`, `.e57`, `.ply`, `.pcd`, `.ptx`, `.pts` သို့မဟုတ် `.xyz` ဖိုင်ကို {{ui:Open}} ဖြင့် ဖွင့်ပါ သို့မဟုတ် စာမျက်နှာပေါ် ချပါ (ဖိုင်တစ်ခုချင်းစီက ဘာယူလာသည်နှင့် scanner ၏ ကိုယ်ပိုင် software မှ ဘာထုတ်ရမည်ကို point cloud format များ အကြောင်းအရာတွင် ကြည့်ပါ)။ မော်ဒယ် ဖွင့်ထားလျှင် cloud သည် 3D view တွင် မော်ဒယ်နှင့် ပူးပေါင်းမည်; cloud ဖွင့်ခြင်းသည် မော်ဒယ် သို့မဟုတ် ၎င်း၏ မသိမ်းရသေးသော ပြောင်းလဲမှုများကို ဘယ်တော့မှ မပိတ်ပါ။ မော်ဒယ် မရှိလျှင် cloud သည် သီးခြား ဖွင့်မည်။
2. Cloud bar သည် toolbar အောက်တွင် ပေါ်လာသည်။ ပြသနေသော အမှတ်အရေအတွက်နှင့် ဖိုင်တွင် ရှိသော စုစုပေါင်းကို ပြောသည်။
3. {{ui:Color by}} ကို ရွေးပါ: ဖိုင်၏ ကိုယ်ပိုင်အရောင်များ (scanner က သိမ်းထားလျှင်), {{ui:Height}}, {{ui:Intensity}}, {{ui:Class}} (LiDAR class များ၊ ဥပမာ ground၊ vegetation နှင့် building) သို့မဟုတ် {{ui:One color}}။ {{ui:Size}} သည် အမှတ်များကို ပိုကြီး သို့မဟုတ် ပိုသေးစေသည်။
4. {{ui:Slice}} အောက်ရှိ {{ui:Plan}} ကို နှိပ်၍ အနိမ့်ဆုံးအမှတ်အထက် 1.2 m ရှိ ပါးလွှာသော band တစ်ခုကိုသာ ထားပါ၊ အပေါ်မှ ကြည့်သည်: နံရံများ၊ တံခါးအဖွင့်များနှင့် ကော်လံများသည် floor plan ကဲ့သို့ ဖတ်ရသည်။ {{ui:Front}} နှင့် {{ui:Side}} သည် elevation နှင့် section များအတွက် ဒေါင်လိုက် band များကို ဖြတ်သည်။ Band ကို {{ui:At}} ဖြင့်ရွှေ့ပြီး {{ui:Thickness}} (မီတာ) ကို ပြောင်းပါ။ {{ui:Off}} သည် cloud တစ်ခုလုံးကို ပြန်ပြသည်။
5. Toolbar ရှိ {{ui:Measure}} ကို နှိပ်ပါ။ Pointer သည် cloud ၏ အမှတ်များသို့ snap လုပ်သည် (label က "point cloud" ဟု ပြသည်)၊ ထို့ကြောင့် slice အတွင်း နံရံမှ နံရံသို့ သို့မဟုတ် မော်ဒယ် element မှ scan သို့ တိုင်းတာနိုင်သည်။ အနီးရှိ မော်ဒယ်၏ corner သို့မဟုတ် edge က ပိုဦးစားပေးသည်။
6. {{ui:Measure}} › {{ui:Location}} ဖြင့်၊ cloud အမှတ်တစ်ခုသည် ဖိုင်က coordinate system ကို အမည်ပေးထားလျှင် ထို cloud ၏ ကိုယ်ပိုင် coordinate system မှ latitude နှင့် longitude ကို ပေးသည်။
7. {{ui:Hide}} သည် cloud ကို ယာယီ ဖျောက်သည်; {{ui:Remove}} သည် ဖယ်ရှားသည်။ {{ui:Show}} › {{ui:Point cloud}} သည် bar ကို ဖျောက်ခြင်း သို့မဟုတ် ပြခြင်း ပြုသည်။

## Cloud ကို ဘယ်မှာ ထားမလဲ

Bar ရှိ {{ui:Place}} သည် cloud သည် မော်ဒယ်နှင့် ဘယ်လို ညီသည်ကို ပြောသည်:

- **Model coordinates**: cloud ၏ နံပါတ်များသည် မော်ဒယ်၏ ကိုယ်ပိုင် ဖြစ်သည် (ဒီဇိုင်း coordinate များသို့ registered လုပ်ထားသော scan)။
- **Map coordinates**: မော်ဒယ်တွင် map conversion (IfcMapConversion) ရှိပြီး cloud သည် တူညီသော projected system တွင် ရှိသည်: cloud ကို ထိုတစ်ဆင့် နေရာချသည်။ နှစ်ခုက မတူသော system များကို အမည်ပေးထားလျှင် status line က ထိုသို့ ပြောသည်။
- **Centered on the model**: နှစ်ခုစလုံးက cloud ကို မော်ဒယ်အနီး မထားနိုင်လျှင်၊ ၎င်း၏ အလယ်ကို မော်ဒယ်၏ အလယ်တွင်၊ အနိမ့်ဆုံး အမှတ်ကို မော်ဒယ်၏ floor တွင် ထားသည်။ အစားထိုး ရွေးချယ်ရန် အခြားရွေးချယ်မှု တစ်ခုကို ရွေးပါ။

ဖိုင်က ယူနစ်များကို မပြောသောအခါ BimCraft သည် မီတာများဟု ဖတ်ပြီး bar တွင် {{ui:Units}} ကို ပေးသည်။

## as-built မျဉ်းများကို ခြေရာခံခြင်း

Cloud ကို drafting app သို့ tab အသစ်တစ်ခုတွင် ပို့ရန် {{ui:CadCraft တွင် ခြေရာခံရန်}} ကို နှိပ်ပါ။ ၎င်းသည် drawing အောက်တွင် ဖွင့်မည်; ထိုနေရာတွင် plan slice နှင့် object snap ဖြင့် scan အပေါ်မှ နံရံများကို ဆွဲနိုင်သည်။ CadCraft ၏ point cloud အကြောင်းအရာကို ကြည့်ပါ။

## အမှတ် မည်မျှ

Scan တစ်ခုတွင် အမှတ် ရာသန်းချီ ရှိနိုင်သည်။ BimCraft သည် အမှတ်တိုင်းကို တစ်ကြိမ် ဖတ်ပြီး ဆွဲရန် ညီမျှသော အစိတ်အပိုင်းကို ထိန်းထားသည်: bar ရှိ {{ui:Show}} သည် အရေအတွက် (1၊ 2၊ 5 သို့မဟုတ် 10 သန်း) ကို သတ်မှတ်သည်။ အမှတ်ပိုများလျှင် memory နှင့် ပိုမြန်သော graphics card လိုအပ်သည်။ LiDAR class တစ်ခုချင်းစီ၏ အရေအတွက်များသည် ဖိုင်ရှိ အမှတ်အားလုံးအတွက် ဖြစ်သည်။

:::note
ဖိုင်များကို ဤကွန်ပျူတာပေါ်တွင် ဖတ်သည်; ဘာမျှ upload မလုပ်ပါ။ LAS 1.0–1.4 နှင့် LAZ ကို ဖတ်သည် (LAZ 1 GB အထိ၊ ဖတ်နေစဉ် memory တွင် ထားသည်); E57 ဖိုင်များ ယခုအချိန်တွင် အမှတ် 6 သန်းနှင့် 512 MB အထိ (ပိုကြီးသော scan များ: LAS သို့မဟုတ် LAZ ထုတ်ပါ); PLY၊ PCD နှင့် PTX အပြည့်အစုံ; text cloud များသည် `x y z` ဖြစ်ပြီး ရှိနေလျှင် အရောင် (`r g b`) နှင့် intensity column များ ပါသည်။
:::

## Scan အများအပြား

နေရာအမျိုးမျိုးမှ ယူထားသော scan များကို frame တစ်ခုတည်းသို့ registered လုပ်နိုင်ပြီး ICP ဖြင့် ညှိကာ LAS သို့မဟုတ် E57 တစ်ခုအဖြစ် ထုတ်နိုင်သည်: [Scan အများအပြားကို တစ်ခုတည်းသို့ register လုပ်ခြင်း](topic:register-scans) ကို ကြည့်ပါ။
