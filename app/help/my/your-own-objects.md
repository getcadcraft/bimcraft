## သင်လုပ်မည့်အရာ

သင်ရှိပြီးသား အရာဝတ္ထုများကို BimCraft သို့ ယူလာပါ: Revit မှ family library၊ ထုတ်လုပ်သူ၏ IFC သို့မဟုတ် DWG ဒေါင်းလုဒ်၊ အခြား modeler မှ mesh တစ်ခု။ {{ui:Library}} tab တွင် ဖိုင်ကို ဖတ်ပြီး အရာဝတ္ထုကို သင့်မော်ဒယ်တွင် မှန်ကန်သော IFC element အဖြစ် ထားပါ၊ နောက်မှ ပြန်သုံးလိုလျှင် {{ui:ကိုယ်ပိုင်အရာဝတ္ထုများ}} တွင် သိမ်းပါ။

## အဆင့်များ

1. IFC မော်ဒယ်ကို ဖွင့်ပါ၊ သို့မဟုတ် အဆောက်အအုံအသစ် စတင်ပါ။
2. {{ui:Properties}} ဘေးရှိ {{ui:စာကြည့်တိုက်}} tab ကို နှိပ်ပါ။
3. {{ui:ဖိုင်များ…}} ကို နှိပ်ပြီး {{ui:ဖိုင်ရွေးရန်…}} ကို နှိပ်ပါ။ ဖိုင်တစ်ခု သို့မဟုတ် အများအပြားကို တစ်ပြိုင်နက် ရွေးပါ: `.rfa`၊ `.ifc`၊ `.dwg`၊ `.dxf`၊ `.glb`၊ `.gltf`၊ `.obj` သို့မဟုတ် `.csv`။ သို့မဟုတ် ဖိုင်တွဲတစ်ခုလုံးနှင့် အတွင်းရှိ ဖိုင်တွဲများကို ဖတ်ရန် {{ui:ဖိုင်တွဲ ရွေးရန်…}} ကို နှိပ်ပါ (တစ်ကြိမ်လျှင် ဖိုင် 200 အထိ)။
4. ဖတ်ထားသည်ကို ကြည့်ရန် ကတ်တစ်ခုကို နှိပ်ပါ: ပလန် အကြို၊ အမည်၊ ထုတ်လုပ်သူနှင့် မော်ဒယ်၊ အရွယ်အစားများနှင့် မှတ်စုများ။
5. နေရာချရန် {{ui:ပုံဆွဲတွင် နေရာချရန်}} သို့မဟုတ် {{ui:မော်ဒယ်တွင် နေရာချရန်}} ကို နှိပ်ပါ။
6. အခြားပရောဂျက်များတွင် ထပ်သုံးလိုလျှင် {{ui:ကျွန်ုပ်၏ အရာဝတ္ထုများတွင် သိမ်းရန်}} ကို နှိပ်ပါ။ ဖိုင်များစွာ ဖတ်ထားသောအခါ {{ui:ကျွန်ုပ်၏ အရာဝတ္ထုများတွင် အားလုံး သိမ်းရန်}} က တစ်ကြိမ်တည်း သိမ်းသည်။
7. နောက်ပိုင်း Library tab တွင် {{ui:ကိုယ်ပိုင်အရာဝတ္ထုများ}} ကို နှိပ်ပြီး ရှာပါ။ ၎င်းတို့ကို Library ပစ္စည်းအခြားတစ်ခုကဲ့သို့ နေရာချ၊ လဲ၊ အပ်ဒိတ်လုပ်သည်။

ဖိုင်များကို ဤ tab တွင် ဖတ်သည်။ {{ui:ကျွန်ုပ်၏ အရာဝတ္ထုများတွင် သိမ်းရန်}} ကို မရွေးမချင်း ဘာမျှ မတင်ပါ။

## ဖိုင်အမျိုးအစားတစ်ခုစီမှ ဖတ်ရသည်များ

| ဖိုင် | ရရှိသည်များ |
|---|---|
| IFC | element အမျိုးအစားတစ်ခုစီ၊ သူ၏ အမှန် 3D ပုံသဏ္ဍာန်၊ IFC class နှင့် property set များပါသော အရာဝတ္ထုတစ်ခု |
| glTF၊ GLB၊ OBJ | အမှန် 3D ပုံသဏ္ဍာန်ပါသော mesh အဖြစ် အရာဝတ္ထုတစ်ခု။ ယူနစ်နှင့် အထက်ဝင်ရိုးကို ပထမဆုံး သတ်မှတ်ပါ။ |
| DWG၊ DXF | block တစ်ခုစီ၊ ၎င်း၏ ပလန်ပုံဆွဲနှင့် attribute များပါသော အရာဝတ္ထုတစ်ခု |
| Family ဖိုင် (`.rfa`) | family ၏ အမည်၊ category၊ ထုတ်လုပ်သူ၊ မော်ဒယ်၊ parameter များနှင့် ၎င်း၏ type များ။ **3D ပုံသဏ္ဍာန် မဟုတ်ပါ:** family ၏ Width၊ Depth နှင့် Height ဖြင့် ဘောက်စ်တစ်ခုက နေရာယူသည်။ |
| CSV | အတန်းတစ်ခုလျှင် အရာဝတ္ထုတစ်ခု: အမည်၊ အရွယ်အစားနှင့် ဒေတာ၊ ဘောက်စ်အဖြစ် ဆွဲထား |

## Family ဖိုင်များနှင့် ၎င်းတို့၏ 3D ပုံသဏ္ဍာန်

`.rfa` ဖိုင်အတွင်းရှိ 3D ပုံသဏ္ဍာန်ကို မှတ်တမ်းမတင်ထားသော ပုံစံဖြင့် သိမ်းထားသောကြောင့် BimCraft သည် family ၏ ဒေတာကို ဖတ်ပြီး ၎င်း၏ ဂျီသြမေတြီကို ခန့်မှန်းမည်မဟုတ်ပါ။ ကတ်က ဤအရာကို ပြောသည်: "ဤ family မှ ဂျီသြမေတြီ မဖတ်ရပါ; ဘောက်စ်တစ်ခု နေရာယူသည်။"

ပုံသဏ္ဍာန်မှန်ဖြင့် family ကို ယူလာရန် ၎င်းကို ဖန်တီးခဲ့သော ပရိုဂရမ် (Revit) မှ ထုတ်ပါ:

1. Family ကို ဖွင့်ပါ၊ သို့မဟုတ် ၎င်းထည့်ထားသော ပရောဂျက်ကို ဖွင့်ပါ။
2. **File > Export > IFC** ကို ရွေးပါ။ [ဤနေရာတွင် အကောင်းဆုံးဖွင့်သော ထုတ်ယူမှု ဆက်တင်များ](topic:rvt-to-ifc) ကို ကြည့်ပါ။
3. BimCraft တွင် `.ifc` ဖိုင်ကို {{ui:ဖိုင်များ…}} ဖြင့် ဖတ်ပါ။ Family type တစ်ခုစီသည် ၎င်း၏ပုံသဏ္ဍာန်နှင့် property set များပါသော အရာဝတ္ထုတစ်ခုအဖြစ် ရောက်လာသည်။

ထုတ်လုပ်သူများစွာသည် family ဖိုင်ဘေးတွင် IFC သို့မဟုတ် DWG ဒေါင်းလုဒ်ကို ပေးသည်။ ၎င်းတို့ကို တိုက်ရိုက် ဖတ်ပါသည်။

## Family type များ

Type အများအပြားရှိသော family တစ်ခုသည် {{ui:Variant}} ရွေးချယ်မှုဖြင့် ပစ္စည်းတစ်ခုအဖြစ် ရောက်လာပြီး type တစ်ခုစီအတွက် variant တစ်ခု ရှိသည်။ Variant တစ်ခုစီတွင် type များကြား ကွဲပြားသော တန်ဖိုးများ ပါပြီး type တွင် Width နှင့် Depth ရှိလျှင် ၎င်း၏ကိုယ်ပိုင် ဘောက်စ် ရှိသည်။ Type တစ်ခုတည်းရှိသော family သည် ထို type ၏ တန်ဖိုးများဖြင့် ဖြည့်ထားသော ရိုးရိုးပစ္စည်း ဖြစ်သည်။

Family အချို့သည် ၎င်းတို့၏ type များကို type catalog တွင် ထားသည်: family ဖိုင်ဘေးရှိ အမည်တူ `.txt` ဖိုင်။ နှစ်ခုလုံးကို တစ်ပြိုင်နက် ရွေးပါ၊ သို့မဟုတ် ဖိုင်တွဲကို ရွေးပါ၊ ထို့နောက် catalog ၏ အတန်းများသည် variant များ ဖြစ်လာသည်။

## အမှန်ပုံသဏ္ဍာန်ပေါ်ရှိ family ဒေတာ

Family ဖိုင်နှင့် အမည်တူ IFC၊ glTF သို့မဟုတ် OBJ ဖိုင်တစ်ခု ဖိုင်တွဲတစ်ခုတွင် ရှိလျှင် (`Chair.rfa` နှင့် `Chair.ifc`) နှစ်ခုလုံးကို တစ်ပြိုင်နက် ရွေးပါ သို့မဟုတ် ဖိုင်တွဲကို ရွေးပါ။ BimCraft သည် ပစ္စည်းတစ်ခု ပြုလုပ်သည်: family ဖိုင်က အမည်၊ ထုတ်လုပ်သူ၊ မော်ဒယ်၊ parameter နှင့် type များကို ပေးပြီး အခြားဖိုင်က အမှန် 3D ပုံသဏ္ဍာန်ကို ပေးသည်။ မှတ်စုများက ပုံသဏ္ဍာန်ကို ဘယ်ဖိုင်မှ ယူသည်ကို ပြောသည်။ ပုံသဏ္ဍာန် တစ်ခုကို type အားလုံးအတွက် သုံးသည်။

Family ဖိုင်တွင် သိမ်းထားသော ပုံရှိလျှင် ပစ္စည်း၏ အသေးစိတ်တွင် ပလန်ပုံဆွဲအောက်တွင် ထိုပုံကို ပြသည်။ ပုံကို ထိုနေရာတွင်သာ ပြသပြီး ပစ္စည်းနှင့်အတူ မသိမ်းပါ။

## ကိုယ်ပိုင်အရာဝတ္ထုများ

{{ui:ကိုယ်ပိုင်အရာဝတ္ထုများ}} သည် Library တွင် သင်၏ ကိုယ်ပိုင် ကိုယ်တိုင် စာရင်းဖြစ်သည်။ ၎င်းထဲမှာ ဘာရှိသည်ကို သင်တစ်ဦးတည်းသာ မြင်နိုင်သည်: ၎င်းသည် အများပြည်သူ Library တွင် မရှိ၊ ရှာဖွေမှုတွင် မရှိ၊ သင့်အဖွဲ့သို့ မပြပါ။ ၎င်းသည် သင့်အကောင့်ကို လိုက်သည်၊ ထို့ကြောင့် Library သို့ ဝင်ရောက်ပြီးနောက် အခြားကွန်ပျူတာတွင် အရာဝတ္ထုများ တူတူ ရှိသည်။

- အရာဝတ္ထု သိမ်းရန် Library သို့ ဝင်ထားရမည်။ [Library သို့ ဝင်ရောက်ခြင်း](topic:library-credits) ကို ကြည့်ပါ။
- အရာဝတ္ထုကို သိမ်းခြင်းသည် ထိုအရာဝတ္ထုတစ်ခုတည်းကို သင့်အကောင့်သို့ ပို့သည်။ ထိုအချိန်အထိ ၎င်းသည် သင့်ကွန်ပျူတာတွင် ရှိနေသည်။
- {{ui:ကိုယ်ပိုင်အရာဝတ္ထုများမှ ဖယ်ရန်}} သည် အရာဝတ္ထုကို စာရင်းမှ ထုတ်သည်။ ပုံဆွဲများတွင် ထားပြီးသား မိတ္တူများ ကျန်ခဲ့သည်။
- အရာဝတ္ထုကို လူအားလုံးနှင့် မျှဝေလိုလျှင် ၎င်းကို သင်ရွေးသော လိုင်စင်အောက်တွင် အများပြည်သူ Library သို့ အစား upload လုပ်ပါ။

:::note
ကိုယ်ပိုင်အရာဝတ္ထုများကို စမ်းသပ်နေဆဲဖြစ်ပြီး သင့်အကောင့်အတွက် မဖွင့်ရသေးနိုင်ပါ။ အရင်းအမြစ် မရှိလျှင် သို့မဟုတ် "ကိုယ်ပိုင်အရာဝတ္ထုများကို ဤအကောင့်အတွက် မဖွင့်ရသေးပါ" ဟု ပြောလျှင် သင့်ဖိုင်များကို {{ui:ဖိုင်များ…}} ဖြင့် ဖတ်ပြီး နေရာချနိုင်ဆဲ ဖြစ်သည်; ၎င်းတို့ကို သင့်မော်ဒယ်အတွင်း သိမ်းထားသည်။
:::

## အမှား အများဆုံး

- **`.rfa` မှ family ၏ အမှန်ပုံသဏ္ဍာန်ကို မျှော်လင့်ခြင်း။** ဒေတာသာ ဖတ်သည်။ ပုံသဏ္ဍာန်အတွက် IFC ထုတ်ပါ။
- **မျှော်ထားသည်ထက် အရာဝတ္ထု နှစ်ခု ရောက်လာခြင်း။** Family နှင့် ၎င်း၏ ပုံသဏ္ဍာန်ဖိုင်ကို အမည် အစ နောက်ဆက်မှလွဲ၍ တူညီစွာ ကိုက်ညီပြီး ဖိုင်တွဲတစ်ခုတည်းတွင် ရှိမှသာ ပေါင်းသည်။
- **ဖိုင်တစ်ခု ပေးရာတွင် မျှော်ထားသည်ထက် ထောင်ဆတစ်ဆ ကြီးခြင်း သို့မဟုတ် ဘေးတိုက် လဲနေခြင်း။** ဖိုင်ကို မရွေးမီ {{ui:ဖိုင်များ…}} အောက်တွင် {{ui:ဖိုင်၏ ယူနစ်များ}} နှင့် {{ui:mesh ၏ အထက်ဝင်ရိုး}} ကို သတ်မှတ်ပါ။
- **ဖိုင်ပေါ်တွင် "No family data"။** ၎င်းသည် ပရောဂျက် (အခြား ending ဖြင့် သိမ်းထားသော `.rvt`) သို့မဟုတ် family template ဖြစ်ပြီး family မဟုတ်ပါ။ [ပရောဂျက် သို့မဟုတ် family ဖိုင်ကို ဖတ်ခြင်း](topic:read-rvt-file) ကို ကြည့်ပါ။
- **ကိုယ်တိုင်မဖန်တီးထားသော အကြောင်းအရာကို သိမ်းခြင်း။** အချို့ ပေးဆောင်ရသော library များသည် ၎င်းတို့၏ ဝန်ဆောင်မှုအပြင် မိတ္တူကူးခွင့် မပြုပါ။ သင် မဖန်တီးထားသော အကြောင်းအရာ၏ စည်းကမ်းများကို စစ်ဆေးပါ။
