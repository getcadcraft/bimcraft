## လုပ်ဆောင်မည့်အရာ

တစ်ကြိမ်တည်းဖြင့် တစ်မျိုးတည်း သို့မဟုတ် တန်ဖိုးတစ်ခုတည်းပါသော အစိတ်အပိုင်းအားလုံးကို ရွေးချယ်ပါ။ ဥပမာ တံခါးအားလုံး၊ Level 2 ပေါ်ရှိ နံရံအားလုံး၊ မီးခံနှုန်း EI60 ရှိသော အစိတ်အပိုင်းအားလုံး၊ သတ်မှတ်ထားသော ပမာဏထက် ပိုကုန်ကျသော နံရံအားလုံး။

## အဆင့်များ

1. IFC မော်ဒယ်တစ်ခု ဖွင့်ပါ။
2. ဘယ်ဘက်ပြားတွင် {{ui:Find}} ကို ဖွင့်ပါ။
3. ပထမစည်းမျဉ်းတွင် ဂုဏ်သတ္တိတစ်ခုကို ရွေးပါ (အစိတ်အပိုင်း၏ ကိုယ်ပိုင်ဂုဏ်သတ္တိများကို ဦးစွာ၊ ဥပမာ {{ui:Class}} နှင့် {{ui:Storey}}၊ ထို့နောက် မော်ဒယ်၏ property set များ)၊ နှိုင်းယှဉ်ပုံနှင့် တန်ဖိုးတစ်ခုကို ရွေးပါ။ တန်ဖိုးအကွက်က မော်ဒယ်တွင်ရှိသော တန်ဖိုးများကို အကြံပြုသည်။
4. ပိုတိကျအောင် ကန့်သတ်ရန် {{ui:Add a rule}} ကို နှိပ်ပါ။ အားလုံး လိုအပ်စေရန် {{ui:Every rule}} ကို ရွေးပါ၊ သို့မဟုတ် တစ်ခုခုသာ လိုအပ်စေရန် {{ui:Any rule}} ကို ရွေးပါ။
5. {{ui:Find}} ကို နှိပ်ပါ၊ သို့မဟုတ် တန်ဖိုးအကွက်တွင် {{key:Enter}} ကို နှိပ်ပါ။ ကိုက်ညီသော အရာများကို ရွေးချယ်ပြီးဖြစ်သည်။
6. စည်းမျဉ်းများကို သိမ်းလိုပါက {{ui:Save as a set}} ကို နှိပ်ပါ၊ အမည်ရိုက်ထည့်ပြီး ထပ်နှိပ်ပါ။ နောက်ပိုင်း အစု၏ အမည်ကို နှိပ်ပြီး ထိုအစုဖြင့် ရှာနိုင်သည်။

## ရလဒ်အနေဖြင့် မြင်ရမည့်အရာ

- ကိုက်ညီသော အရာများကို 3D view နှင့် model tree တွင် ရွေးချယ်ပြသပြီး {{ui:Properties}} တွင် class အလိုက် အရေအတွက်ကို ပြသည်။ {{key:I}} ကို နှိပ်လျှင် ၎င်းတို့ကိုသာ ပြ၍၊ {{key:H}} ကို နှိပ်လျှင် ဝှက်သည်။
- စာလုံးအကြီးအသေး ခွဲခြားခြင်းမရှိဘဲ စာသားများ ကိုက်ညီသည်။ ဂဏန်းများကို ဂဏန်းအဖြစ် နှိုင်းယှဉ်သည်။ "1000 ထက်ကြီးသည်" ဆိုသည်မှာ စာသားမဟုတ်ဘဲ တန်ဖိုးကို ဆိုလိုသည်။
- {{ui:has a value}} နှင့် {{ui:has no value}} တွင် တန်ဖိုး မလိုပါ။ တန်ဖိုး ဖြည့်ထားသည်ကို သို့မဟုတ် ပျောက်နေသည်ကို ရှာပေးသည်။
- သိမ်းထားသော အစုများသည် ဖွင့်သည့် မော်ဒယ်အားလုံးအတွက် ဤဘရောက်ဇာတွင် ကျန်ရှိနေသည်။

## အများဆုံး ဖြစ်တတ်သော အမှားများ

- **ဘာမျှ မတွေ့ပါ။** စည်းမျဉ်းတွင် ကိုက်ညီနိုင်သော တန်ဖိုး လိုအပ်သည်။ တန်ဖိုးအကွက်ရှိ အကြံပြုချက်များကို ကြည့်ပါ။
- **ဂုဏ်သတ္တိ စာရင်းတွင် မပါပါ။** ဤမော်ဒယ်ရှိ ပုံသဏ္ဍာန်ပါသော အစိတ်အပိုင်း တစ်ခုမျှ ထိုဂုဏ်သတ္တိ မရှိပါ။
