## သင်လုပ်မည့်အရာ

ပြီးသား မော်ဒယ်တွင် ရှိနေသော connector များကြား run ကွန်ရက်တစ်ခုကို BimCraft က ပြုလုပ်ပေးစေပြီး နံရံနှင့် beam များပတ်လည်တွင်၊ ထို့နောက် သင်မြင်နိုင်သော ကိန်းဂဏန်းများဖြင့် စစ်ဆေးပါ။

## အဆင့်များ

1. မော်ဒယ်နှင့် clash check ကို ဖွင့်ပါ။ **လေပိုက်များကို အလိုအလျောက် လမ်းကြောင်းဖြတ်ရန်** အောက်တွင် air handler နှင့် terminal များကို ရွေးပါ၊ သို့မဟုတ် **အခြားစနစ်များကို အလိုအလျောက် လမ်းကြောင်းဖြတ်ရန်** အောက်တွင် စနစ်တစ်ခုကို ရွေးပါ။
2. **ဆွဲငင်အားဖြင့် စွန့်ထုတ်ခြင်း။** အထွက်နေရာကို ရိုက်ထည့်ပါ၊ သင်တွင်ရှိလျှင် stack နေရာများကိုလည်း ရိုက်ထည့်ပါ။ ပစ္စည်းများရှိသော အထပ်တိုင်းကို တစ်ကြိမ်တည်း ယူရန် **အထပ်တိုင်းကို တစ်ကြိမ်တည်း လမ်းကြောင်းဖြတ်ရန်** ကို အမှန်ခြစ်ပါ: အထပ်တစ်ခုစီ၏ စွန့်ထုတ်ပိုက်များသည် ၎င်းတို့၏ အဆင့်တွင် stack နှင့် ဆုံသည်၊ stack သည် အမြင့်ဆုံး ရေခုံအထက်မှ ၎င်း၏ အောက်ခြေအထိ ရောက်သည်။ {{ui:လမ်းကြောင်းဖြတ်ရန်}} ကို နှိပ်ပါ။
3. **Trap မှ vent သို့။** ပြန်ပြသော ပန်နယ်သည် trap တစ်ခုစီမှ ၎င်း၏ vent အထိ အကွာအဝေးကို စာရင်းပြုသည်။ သင့်ကုဒ်က ခွင့်ပြုသည့် အများဆုံးကို **Trap မှ vent အထိ အများဆုံး** တွင် ရိုက်ထည့်ပါ; ထို့အထက် ပစ္စည်းတစ်ခုကို မပြီးသေးဟု စာရင်းပြုပြီး မီလီမီတာ ပိုသည်ကို ပြသည်။ ပစ္စည်းများတွင် ကိုယ်ပိုင် vent stub မရှိသည့်အခါ **Stack ဖြင့် vent** ကို အမှန်ခြစ်ပါ: ထို့နောက် အကွာအဝေးကို stack အထိ တိုင်းသည်။ BimCraft တွင် ဤအတွက် ကုဒ်ဇယား မပါပါ: နံပါတ်ကို သင်ရိုက်ထည့်ပါ။
4. **အေးသောနှင့် ပူသောရေ။** ရင်းမြစ်ကို ရွေးပါ၊ ရင်းမြစ်ရှိ ဖိအားနှင့် ပစ္စည်းတစ်ခုတွင် လိုအပ်သော ဖိအားကို ရိုက်ထည့်ပါ။ **ပူသောရေ** ကို အမှန်ခြစ်ပြီး heater ၏ ပူသော connection ကို ရွေးပါ၊ **Return loop** ကို အမှန်ခြစ်ပြီး return လိုင်းကို heater ၏ **hot-return** connection သို့မဟုတ် သင်ရွေးသော အခြား connection သို့ အဆုံးသတ်ပါ (ထို connection သည် 150 mm တိုသော၊ ဖွင့်ထားသော၊ သင်ဆက်ရန် အတွက် ဖြစ်သည်)။
5. **Split၊ multi-split နှင့် VRF။** အပြင်ယူနစ်ကို ရွေးပါ၊ အတွင်းယူနစ်များကို အမှန်ခြစ်ပြီး တစ်ခုစီ၏ capacity ကို ရိုက်ထည့်ပါ။ သင့်ထုတ်လုပ်သူ၏ ဒေတာမှ ကန့်သတ်ချက်များကို ရိုက်ထည့်ပါ။ ကွေးတစ်ခုနှင့် branch kit တစ်ခု၏ **equivalent length** (ထုတ်လုပ်သူ၏ တန်ဖိုးများ) ကို ရိုက်ထည့်ပါ၊ ထို့နောက် အရှည်ဆုံးနှင့် စုစုပေါင်း အရှည်များကို equivalent length များပေါ်တွင် စစ်ဆေးသည်။
6. {{ui:လမ်းကြောင်းဖြတ်ရန်}} ကို နှိပ်ပါ။ ပန်နယ်က ဆွဲခဲ့သော run အရေအတွက်နှင့် မလုပ်နိုင်ခဲ့သော အရာများနှင့် အကြောင်းရင်းကို ပြောသည်။ {{ui:ပြန်ဖျက်ရန်}} က အားလုံးကို အဆင့်တစ်ခုဖြင့် ပြန်ယူသည်။

## သင်မြင်သင့်သည်များ

Elbow၊ tee နှင့် reducer ပါသော ပိုက်များ; အရွယ်အစားအလိုက် အသေးဆုံး စောင်းနိုးမှုအနည်းဆုံးကို ကျသော စွန့်ထုတ်ပိုက်များ; ပစ္စည်းတစ်ခုစီတွင် vent stub များ; refrigerant လိုင်းများသည် ထောင့်တိုင်းတွင် တူညီစွာ လှည့်သော liquid နှင့် gas အတွဲ၊ branch ခွဲထွက်သည့်နေရာတွင် branch kit အမှတ်အသားပါသည်။

## သိထားသင့်သည်များ

- စွန့်ထုတ်ပိုက်တစ်ခုသည် အခြားစွန့်ထုတ်ပိုက်နှင့် ဆုံသည့်နေရာတွင် မော်ဒယ်က tee ကို ဆွဲသည်။ ပလန်က ထိုနေရာများကို 45-degree wye junction အဖြစ် အမည်ပေးထားပြီး fitting ကို ပြောင်းနိုင်သည်။
- ပူသောရေသည် ပစ္စည်း၏ family တွင် ရှိလျှင် ၎င်း၏ ကိုယ်ပိုင် ပူသော connection ကို သုံးပြီး မရှိလျှင် အေးသော connection ၏ ဘေးတွင် 100 mm connection ကို သုံးသည်။
- Refrigerant လိုင်းများသည် ယူနစ်တစ်ခုစီ၏ port နှစ်ခုကြားမှ စတင်သည်။ ယူနစ်၏ port နှစ်ခုသည် ကွေးရန် အလွန်နီးလွန်းလျှင် တွဲသည် ၎င်းတို့ကြားတွင် ဗဟိုချထားသည်။
- ရေကွန်ရက်သည် calculations တွင် ပြသထားသော demand curve နှင့် friction ကိန်းဂဏန်းများကို သုံးသည်; ဖိအားများကို မယုံမီ သင့်ကုဒ်ဖြင့် အစားထိုးပါ။
- အိမ်ကြီးများသည် မိနစ်နှစ်ဆယ်ခန့် သို့မဟုတ် ပို၍ ကြာနိုင်သည်၊ အများစုမှာ ပူသောရေကွန်ရက်ကြောင့်ဖြစ်သည်။
- ဤသည်မှာ ဒရာဖ်တင် ကူညီမှုဖြစ်သည်။ အရည်အချင်းပြည့်မီသူတစ်ဦးက သက်ဆိုင်သော ကုဒ်နှင့် အရွယ်အစား၊ စောင်းနိုးမှု၊ vent နှင့် ဖိအားများကို စစ်ဆေးပါ။
