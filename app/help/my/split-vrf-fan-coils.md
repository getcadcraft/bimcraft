## သင်လုပ်မည့်အရာ

Split၊ multi-split သို့မဟုတ် VRF စနစ်၏ ယူနစ်များနှင့် ၎င်း၏ fan coil များကို မော်ဒယ်ထဲ ထည့်ပါ။ ထို့နောက် line set များဖြင့် ချိတ်ဆက်ပါ။ ACR ကြေးနီဖြင့် ပြုလုပ်ထားသော အရည်လိုင်းနှင့် ဓာတ်ငွေ့လိုင်းတစ်ခုစီကို ယူနစ်များ၏ port များသို့ ချိတ်ပါ။ ဤယူနစ်များသည် [port ပါဝင်သော MEP equipment](topic:mep-equipment) ထဲရှိ အခြားအစိတ်အပိုင်းတိုင်းနှင့် တူညီစွာ အလုပ်လုပ်သည်။ ဘားတူ၊ {{ui:Properties}} (ဂုဏ်သတ္တိများ)၊ port များနှင့် [ချိတ်ဆက်မှုများ](topic:mep-connections) ကို အသုံးပြုနိုင်သည်။

:::note
ဤသည်မှာ ပုံဆွဲခြင်းနှင့် ညှိနှိုင်းဆောင်ရွက်ရန် အထောက်အကူပြုသော ကိရိယာတစ်ခု ဖြစ်သည်။ ယူနစ်များသည် သင်ရိုက်ထည့်သော တန်ဖိုးများဖြင့် အရွယ်အစားသတ်မှတ်ထားသော အထွေထွေပုံသဏ္ဍာန်များ ဖြစ်ပြီး ထုတ်လုပ်သူ၏ ထုတ်ကုန်များ မဟုတ်ပါ။ ၎င်းတို့၏ ပိုက်အရွယ်အစားများသည် R410A နှင့် R32 စက်ပစ္စည်းများအတွက် **ပုံမှန်ဥပမာတန်ဖိုးများ** ဇယားမှ လာသည်။ ထုတ်လုပ်သူ၏ တပ်ဆင်လမ်းညွှန်ကသာ အမှန်တကယ် အရွယ်အစားကို ဆုံးဖြတ်သည်။ ရှည်လျားသော လမ်းကြောင်းများ သို့မဟုတ် အမြင့်ကွာဟချက်ကြီးများက ၎င်းတို့ကို ပြောင်းစေသည်။ သင်အသုံးပြုသော ယူနစ်များနှင့် ကိုက်ညီစေရန် ဇယားကို ပြောင်းပါ သို့မဟုတ် အရွယ်အစားများကို ရိုက်ထည့်ပါ။
:::

## ယူနစ်တစ်ခု ထားရန်

1. {{ui:Draw}} ကို ဖွင့်ပါ၊ {{ui:Build}} ကို ဖွင့်ပြီး {{ui:Equipment}} ကို ရွေးပါ။
2. အမျိုးအစားကို ရွေးပြီး တန်ဖိုးများ သတ်မှတ်ပါ။

| အမျိုးအစား | သတ်မှတ်ရမည့်အရာ | ၎င်း၏ port များ |
|---|---|---|
| Split အတွင်းပိုင်းယူနစ်၊ နံရံ | စွမ်းရည်၊ အရည်နှင့် ဓာတ်ငွေ့လိုင်း၊ အလျား၊ အနက်၊ အမြင့်၊ ရေငွေ့ရည်ပိုက်အရွယ် | refrigerant အရည်နှင့် ဓာတ်ငွေ့၊ ရေငွေ့ရည်ထွက်ပေါက် (ညာဘက်အဆုံး၊ နံရံအနီး) |
| Split အတွင်းပိုင်းယူနစ်၊ cassette | စွမ်းရည်၊ အရည်နှင့် ဓာတ်ငွေ့လိုင်း၊ panel၊ body၊ အမြင့်၊ ရေငွေ့ရည်ပိုက်အရွယ် | refrigerant အရည်နှင့် ဓာတ်ငွေ့၊ ရေငွေ့ရည်ထွက်ပေါက် (တစ်ဖက်၊ အပေါ်အနီး) |
| Split အတွင်းပိုင်းယူနစ်၊ ducted | စွမ်းရည်၊ အရည်နှင့် ဓာတ်ငွေ့လိုင်း၊ အလျား၊ အကျယ်၊ အမြင့်၊ supply နှင့် return အဖွင့်များ၊ ရေငွေ့ရည်ပိုက်အရွယ် | supply လေပိုက်ထွက်၊ return လေပိုက်ဝင်၊ refrigerant အရည်နှင့် ဓာတ်ငွေ့၊ ရေငွေ့ရည်ထွက်ပေါက် |
| Split အပြင်ပိုင်းယူနစ် | စွမ်းရည်၊ အရည်နှင့် ဓာတ်ငွေ့လိုင်း၊ အကျယ်၊ အနက်၊ အမြင့် | refrigerant အရည်နှင့် ဓာတ်ငွေ့ (ညာဘက်တွင်) |
| VRF အပြင်ပိုင်းယူနစ် | စွမ်းရည်၊ အရည်နှင့် ဓာတ်ငွေ့လိုင်း၊ အကျယ်၊ အနက်၊ အမြင့် | refrigerant အရည်နှင့် ဓာတ်ငွေ့ (ရှေ့၊ နိမ့်ဘက်တွင်) |
| Refnet ဆက်စပ်ချိတ် | အရည် သို့မဟုတ် ဓာတ်ငွေ့လိုင်း၊ branch တစ်ခုစီ၏ load၊ အဆုံးတစ်ခုစီရှိ ပိုက် | ဝင်ပေါက်၊ branch A၊ branch B |
| Fan coil ယူနစ် | 2-pipe သို့မဟုတ် 4-pipe၊ အလျား၊ အကျယ်၊ အမြင့်၊ supply နှင့် return အဖွင့်များ၊ coil ပိုက်နှင့် စနစ်၊ အပူပေးပိုက်၊ ရေငွေ့ရည်ပိုက်အရွယ် | supply လေပိုက်ထွက်၊ return လေပိုက်ဝင်၊ coil ဝင်နှင့်ထွက်၊ အပူပေးဝင်နှင့်ထွက် (4-pipe)၊ ရေငွေ့ရည်ထွက်ပေါက် |

3. **At** ကို သတ်မှတ်ပါ။ ၎င်းသည် ယူနစ်အောက်ခြေ၏ အမြင့်ဖြစ်သည်။ နံရံယူနစ်၏ အောက်ခြေမှာ ၎င်း၏ အောက်ဘက်မျက်နှာ ဖြစ်သည် (မကြာခဏ 2100 mm)။ cassette ၏အမြင့်မှာ မျက်နှာပြင်ဖြစ်ပြီး ၎င်း၏ ခုံးမျက်နှာ ဖြစ်သည်။ refnet ၏အမြင့်မှာ ၎င်း၏ ပိုက်၏ ဗဟိုဖြတ်မျဉ်းအမြင့် ဖြစ်သည်။
4. ထားလိုသည့်နေရာကို နှိပ်ပါ ({{key:R}} က ၎င်းကို 90° လှည့်ပေးသည်)။

**စွမ်းရည်** သည် ယူနစ်၏ အမည်ခံ အအေးပေးစွမ်းရည်ဖြစ်ပြီး kW ဖြင့် ဖော်ပြသည်။ Btu/h ကို ဘေးတွင် ပြသည်။ **{{ui:Liquid line}}** နှင့် **{{ui:Gas line}}** ကို "From the table" တွင် ထားခဲ့လျှင် ယူနစ်၏ ချိတ်ဆက်မှုများသည် ထိုစွမ်းရည်အတွက် ဇယား၏ အရွယ်အစားများကို ယူသည်။ သင့်ယူနစ်၏ ကိုယ်ပိုင်အရွယ်ကို သုံးလိုပါက ပိုက်အရွယ်တစ်ခု ရွေးပါ။ refnet ၏ ဝင်ပေါက်ကို branch နှစ်ခုလုံးအတွက် ပေါင်းပြီး အရွယ်သတ်မှတ်ထားပြီး branch တစ်ခုစီကို ၎င်း၏ load အတွက် သတ်မှတ်သည်။

Refrigerant port များသည် နှစ်ဘက်လုံး အလုပ်လုပ်သည် (heat pump သည် နှစ်ဖက်လုံး လည်ပတ်နိုင်သည်)။ ရေငွေ့ရည်ထွက်ပေါက်သည် မည်သည့် drain ကဲ့သို့မဆို ပိုက်အရွယ်တစ်ခု ဖြစ်သည်။

## Line set တစ်ခု ဆွဲရန်

1. ပိုင်းနှစ်ခု ရွေးပါ ({{key:Shift}}+နှိပ်ပြီး ဒုတိယတစ်ခုကို ရွေးပါ)။ အပြင်ပိုင်းယူနစ်နှင့် အတွင်းပိုင်းယူနစ် (single split) သို့မဟုတ် အပြင်ပိုင်းယူနစ်နှင့် refnet၊ refnet နှင့် အတွင်းပိုင်းယူနစ်၊ သို့မဟုတ် refnet နှစ်ခု (VRF) ဖြစ်နိုင်သည်။
2. {{ui:Build}} ကို ဖွင့်ပြီး {{ui:Line set}} ကို ရွေးပါ။

BimCraft သည် အရည်နှင့် ဓာတ်ငွေ့ လမ်းကြောင်းများကို ၎င်းတို့၏ လွတ်နေသော port များကြားတွင် ဆွဲသည်။ port တစ်ခုစီမှ အပေါ်သို့ ဘုံအမြင့်အထိ ထွက်ပြီး ACR ကြေးနီ (1-5/8 in အထိ annealed coil၊ အထက်တွင် drawn tube) ဖြင့် ပြုလုပ်သည်။ ၎င်းအားလုံးသည် {{ui:Undo}} တစ်ဆင့်ပဲ ဖြစ်သည်။ refnet သည် ၎င်း၏ကိုယ်ပိုင်လိုင်းကိုသာ ယူသည်။ အပြင်ဘက်မှ ဝင်ပေါက်သို့ ဝင်ပြီး အတွင်းပိုင်းယူနစ်များဆီသို့ branch တစ်ခုမှ ထွက်သည်။ လမ်းကြောင်းတစ်ခုစီသည် ၎င်း၏ အောက်ဘက်အဆုံး (အတွင်းပိုင်းယူနစ် သို့မဟုတ် refnet ၏ ဝင်ပေါက်) ၏ အရွယ်ကို ယူသည်။ အခြားအဆုံး၏ port က မတူညီသော အရွယ်ဖြစ်ပါက {{ui:Check connections}} က ၎င်းကို စာရင်းပြုစုသည်။ ထိုနေရာတွင် reducer ထည့်ရမည်။ အတွင်းပိုင်းယူနစ် နှစ်ခုကြားတွင် refnet တစ်ခု လိုအပ်သည်။

နောက်ပိုင်းတွင် လမ်းကြောင်းများကို ပိုက်လမ်းကြောင်းအတိုင်း ရွှေ့နိုင်သည်။ ၎င်းတို့၏ အဆုံးများသည် port များပေါ်တွင် ဆက်နေသည်။ အဆင့်များကြား လမ်းကြောင်းများကို {{ui:Pipe}} ဖြင့် ဆွဲသည်။ refrigerant port မှ စတင်သော ပိုက်သည် ၎င်း၏ စနစ်၊ ACR ကြေးနီနှင့် အရွယ်အစားကို ယူသည်။

ဤတန်ဖိုးများသည် စတင်သော ပုံမှန်တန်ဖိုးများ ဖြစ်သည်။ အတန်းတစ်ခုကို ပြောင်းပါ၊ အတန်းများ ထည့်ပါ သို့မဟုတ် ဖျက်ပါ၊ ထို့နောက် {{ui:Save}} ကို နှိပ်ပါ။ ဇယားကို မော်ဒယ်ထဲတွင် သိမ်းထားသဖြင့် ဖိုင်ကို အလုပ်လုပ်သူအားလုံး အသုံးပြုသည်။ {{ui:Undo}} ဖြင့် ပြန်ယူနိုင်သည်။ {{ui:Use the typical values}} က စတင်ဇယားကို ပြန်ထားပေးသည်။ ယခင်ထားပြီးသား အရာများသည် သင်ပြောင်းသည် အထိ ၎င်းတို့၏ port များကို ဆက်ထားသည်။

## IFC ဖိုင်ထဲတွင်

Split နှင့် VRF စနစ်များ၏ အတွင်းပိုင်းနှင့် အပြင်ပိုင်းယူနစ်များသည် SPLITSYSTEM အမျိုးအစား IfcUnitaryEquipment ဖြစ်ပြီး object type က မည်သည့်အရာဖြစ်သည်ကို ဖော်ပြသည် ("Split indoor unit, wall-mounted"၊ "Split indoor unit, ceiling cassette"၊ "Split indoor unit, ducted"၊ "Split outdoor unit"၊ "VRF outdoor unit")။ fan coil သည် AIRHANDLER အမျိုးအစား IfcUnitaryEquipment ဖြစ်ပြီး object type က "Fan coil unit" ဖြစ်သည်။ IFC4 တွင် fan coil အမျိုးအစား မရှိပါ။ အခန်းတစ်ခုအတွက် fan၊ coil နှင့် filter တို့ကို AIRHANDLER က ဖော်ပြသည်။ refnet ဆက်စပ်ချိတ်သည် JUNCTION အမျိုးအစား IfcPipeFitting ("Refnet joint") ဖြစ်သည်။ IFC2X3 ဖိုင်များသည် ကိုက်ညီသော အမျိုးအစားများဖြင့် IfcEnergyConversionDevice နှင့် IfcFlowFitting ရရှိသည်။

Refrigerant port များနှင့် လမ်းကြောင်းများသည် REFRIGERATION စနစ်များထဲတွင် ရှိသည် (အရည်လိုင်းများအတွက် တစ်ခု၊ ဓာတ်ငွေ့လိုင်းများအတွက် တစ်ခု)။ ရေငွေ့ရည်သည် DRAINAGE စနစ်ထဲတွင် ရှိသည်။ ACR လမ်းကြောင်းများကို အပြင်ဘက် အချင်းဖြင့် အမည်ပေးသည်။ line set ဇယားသည် ပရောဂျက်ပေါ်ရှိ CadCraft_HvacLineSets property set ဖြစ်သည်။
