## ဘာလုပ်မလဲ

လေဆာစကင်မှ ရှိပြီးသား အဆောက်အအုံကို ဆွဲပါ: စကင်ပြသည့် နေရာများတွင် နံရံများ၊ မှန်ကန်သော အထပ်ပေါ်တွင်၊ တစ်ခုနှင့်တစ်ခု ထောင့်မှန်အောင်။

## အဆင့်များ

1. **ဆွဲရမည့် အဆောက်အအုံ။** {{ui:File}} › {{ui:New building}} ကို အဆောက်အအုံတွင် ရှိသလောက် အထပ်အရေအတွက်ဖြင့် ရွေးပါ (အထပ်များကို နောက်မှ ထပ်ထည့်နိုင်သည်၊ [ဆိုက်၊ ၎င်းပေါ်ရှိ အဆောက်အအုံနှင့် ၎င်း၏ အထပ်များ](topic:site-building-and-levels) ကို ကြည့်ပါ)။ {{ui:Draw}} ဖွင့်သွားမည်။
2. **စကင်။** {{ui:Show}} › {{ui:Point cloud}} ကိုနှိပ်ပြီး ဖိုင်ကို ရွေးပါ (LAS, LAZ, E57, PLY, PCD, PTX သို့မဟုတ် XYZ: [မော်ဒယ်ဘေးတွင် point cloud ပြရန်](topic:point-clouds) ကို ကြည့်ပါ)။ Cloud သည် 3D view တွင် ပေါ်လာပြီး ပလန်တွင် ၎င်း၏ **အလွှာ** ကို ပြသည်: စကင်ဖတ်ထားသော အမှတ်များကို အထပ်အပေါ် 1200 mm (4 feet) အမြင့်တွင် အစက်များအဖြစ်။ ထိုအမြင့်သည် နံရံ၊ တံခါးနှင့် ပြတင်းပေါက်များကို အကောင်းဆုံး ဖတ်ရသော အမြင့် ဖြစ်သည်။
3. **အထပ်နှင့် ညှိပါ။** မော်ဒယ်ဘား၏ {{ui:Scan}} မီနူးကိုဖွင့်ပြီး {{ui:Align its floor to this level}} ကို နှိပ်ပါ: စကင်ဖတ်ထားသော ကြမ်းပြင်သည် ပြထားသော အထပ်ပေါ်တွင် ရောက်သည်အထိ cloud သည် အပေါ် သို့မဟုတ် အောက်သို့ ရွေ့သည်။ အလွှာသည် ယခု နံရံများကို ဖြတ်နေသည်ကို စစ်ဆေးပါ။
4. **အဆောက်အအုံနှင့် ထောင့်မှန်အောင်။** {{ui:Scan}} › {{ui:Turn it square to the building}} သည် cloud ကို လှည့်ပေးသဖြင့် အလွှာရှိ နံရံများသည် ပလန်၏ ဝင်ရိုးများနှင့် တပြိုင်တည်း ကျသွားပြီး {{key:Shift}} ကိုဖိထားကာ ဆွဲသော နံရံများသည် စကင်နှင့် တန်းညီသည်။ ၎င်းသည် တွေ့ရှိသော နံရံများ၏ အလယ်ဗဟိုအနီးတွင် လှည့်သဖြင့် အလွှာထဲ ပါလာသော သစ်ပင် သို့မဟုတ် အိမ်နီးချင်း၏ နံရံက စကင်ကို မလွဲစေပါ။ ဦးစွာ ကြမ်းပြင်ကို ညှိပါ- ထိုအခါ အလွှာသည် နံရံများကို ဖြတ်မည်။
5. **နံရံများကို ခြေရာခံပါ။** {{ui:Wall}} ကို ရွေး၍ အစက်များတလျှောက် နှိပ်ပါ: ကိရိယာသည် စကင်အမှတ်များနှင့် သင်ဆွဲထားသော နံရံများသို့ ကပ်ပေးသည် (snap အမှတ်သည် အသေးစား ဒိုင်းမွန်း)။ နံရံတစ်ခုကို ၎င်း၏ အလယ်မျဉ်းပေါ်တွင် ဆွဲသဖြင့် နံရံတစ်ခုက ထားခဲ့သော အစက်တန်းနှစ်တန်း၏ အလယ်ကို တလျှောက် နှိပ်ပါ; နံရံ၏ အထူကို နံရံအမျိုးအစားကို ဦးစွာ ရွေးပြီးမှ ရိုက်ထည့်ပါ။ ထို့နောက် အလွှာက အပေါက်များ ပြသသော နေရာများတွင် တံခါးနှင့် ပြတင်းပေါက်များ ထည့်ပါ။
6. **နောက်အထပ်။** ပလန်၏ အထပ်စာရင်းတွင် အထက်အထပ်ကို ရွေးပါ: အလွှာသည် အထပ်၏ ဖြတ်အမြင့်ကို လိုက်သည်။ စကင်၏ ကြမ်းပြင်များသည် သင့်အထပ်များနှင့် မတူသောအခါမှသာ ထိုအထပ်သို့ ကြမ်းပြင်ကို နောက်တစ်ကြိမ် ညှိပါ။

## မြင်ရမည့်အရာ

- အထပ်ပြောင်းသည်နှင့် အလွှာ ပြောင်းသည်၊ အလွှာ ထူ ({{ui:Scan}} › {{ui:Slice thickness}}) ကို ပိုထူပါက စကင် ပါးသည့် နေရာများတွင် အမှတ်ပိုပြသည်။
- {{ui:Scan}} › {{ui:Undo the alignment}} သည် cloud ကို ဖွင့်စဉ်က ထားခဲ့သော နေရာသို့ ပြန်ထားပေးသည်။ ညှိခြင်းသည် view တွင်သာ cloud ကို ရွှေ့သည်- IFC ဖိုင်တွင် မသိမ်းပါ၊ ဆွဲထားသော နံရံများမူ နေရာတွင် ရှိနေသည်။ {{ui:Place}} သို့မဟုတ် {{ui:Units}} ကို ပြောင်းသည့်အခါ၊ သို့မဟုတ် အခြားမော်ဒယ်ကို ဖွင့်သည့်အခါ ညှိမှုသည် cloud နှင့်အတူ ပျောက်သွားသည်။
- {{ui:Scan}} › {{ui:Show the slice on the plan}} သည် အစက်များကို ဝှက်သည် သို့မဟုတ် ပြသည်။

:::tip
ကြီးမားသော စကင်များ: ပလန်သည် အလွှာမှ အမှတ် 60,000 အထိ ဆွဲပြပြီး 3D view သည် cloud တစ်ခုလုံးမှ သန်းချို့သော အမှတ်များကို ဆွဲပြသည်၊ နှစ်ခုစလုံးသည် စကင်တလျှောက် ညီညီမျှမျှ ရွေးထားသဖြင့် ဖိုင်ကြီးသော်လည်း မြန်ဆန်နေသည်။ ဒရာဖ်တင် အက်ပ်တွင် ခြေရာခံလိုပါက cloud bar ၏ {{ui:Trace in CadCraft}} (CadCraft တွင် ခြေရာခံ) ကို သုံးပါ။
:::
