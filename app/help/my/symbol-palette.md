## သင်လုပ်မည့်အရာ

လျှပ်စစ်သင်္ကေတများနှင့် ရေပိုက် plan သင်္ကေတများကို ပုံနှင့် အမည်များဖြင့် စာရင်းပြုသည့် panel တစ်ခုကို ဖွင့်ပါ။ သင်လိုချင်သည့်ကို ရှာပြီး plan ပေါ်တွင် ထားပါ။ ဤနေရာတွင် အင်တာနက် မလိုအပ်ပါ။ သင်္ကေတများသည် အက်ပ်နှင့်အတူ ပါလာသည်။

## ဖွင့်ပြီး သင်္ကေတတစ်ခု ထားရန်

1. မော်ဒယ်တစ်ခု ဖွင့်ပြီး {{ui:Build}} › {{ui:သင်္ကေတပြား}} ကို ဖွင့်ပါ (ရိုက်ထည့်သော command: SYMBOLS)။ ခလုတ်တူသည် Draw bar ၏ Tools menu တွင်နှင့် toolbar ၏ Library အုပ်စုတွင် **သင်္ကေတများ** အဖြစ်လည်း ရှိသည်။
2. အစုံတစ်ခု ရွေးပါ: **Electrical** သို့မဟုတ် **Plumbing**၊ သို့မဟုတ် **All sets**။ ရှာဖွေရေးအကွက်တွင် ရိုက်ပြီး စာရင်းကို ကျဉ်းအောင် လုပ်နိုင်သည်။ အမည် သို့မဟုတ် အတိုကောက် (WC၊ CW၊ HB) ဖြင့် ရှာနိုင်သည်။
3. သင်္ကေတတစ်ခုကို နှိပ်ပါ။ plan သည် ၎င်းကို ထားရန် အဆင်သင့်ဖြစ်သည်။
   - **လျှပ်စစ်** သင်္ကေတသည် ထို device ရွေးထားသော Electrical ကိရိယာကို စတင်သည်။ ထို့ကြောင့် [လျှပ်စစ် plan](topic:electrical-plan) ပေါ်ရှိ အရာအားလုံး သက်ဆိုင်သည်။ plan ကို နှိပ်ပါ၊ undo တစ်ဆင့်။
   - **ရေပိုက်** သင်္ကေတသည် plan သင်္ကေတကိရိယာကို စတင်သည်။ plan ကို နှိပ်ပါ။ နံရံပေါ် ထိုင်သော fixture (ရေအိမ်၊ lavatory၊ ရေချိုးကန်၊ sink၊ hose bib) သည် အနီးဆုံး နံရံမျက်နှာသို့ နောက်ကျောကို နံရံဘက်ထားပြီး ကပ်သည်။ drain၊ valve၊ ရေနွေးထိုင်၊ line style များသည် နှိပ်သည့်နေရာသို့ သွားသည်။
4. {{key:R}} ကို နှိပ်ပြီး သင်္ကေတကို 90 ဒီဂရီ လှည့်ပါ ({{key:Shift}}+{{key:R}} က ဘက်တစ်ဖက်သို့ လှည့်သည်)။ သို့မဟုတ် options bar ရှိ **လည်ပတ်မှု** တွင် ထောင့်တစ်ခုကို ရိုက်ထည့်ပါ။ ရပ်ရန် {{key:Esc}} ကို နှိပ်ပါ။

နံရံမျက်နှာသို့ ကပ်သော fixture သို့မဟုတ် hose bib သည် ထို နံရံကို မှတ်ထားသည်။ နံရံ ရွေ့သည့်အခါ သင်္ကေတသည် ၎င်းနှင့်အတူ ရွေ့သည် (တူညီသော မျက်နှာ၊ နံရံတလျှောက် အကွာအဝေးတူ) ပြောင်းလဲမှု တစ်ဆင့်တည်းတွင်။ နံရံကို ဖျက်လျှင် သင်္ကေတသည် မူလနေရာတွင် ကျန်ခဲ့ပြီး **ပြဿနာများ** က "lost its wall" ဟု စာရင်းပြုသည်။ ရွှေ့ပါ သို့မဟုတ် ဖျက်ပါ။ နံရံနှင့် မကပ်သော သင်္ကေတများသည် တစ်ခုခုနှင့်မှ ချိတ်ဆက်မထားပါ။

သင်ထားသော သင်္ကေတတစ်ခုစီသည် undo တစ်ဆင့် ဖြစ်သည်။ ထားပြီးသော သင်္ကေတသည် IFC ဖိုင်တွင် tag (WC1၊ WC2၊ ...) ပါဝင်သော plan annotation တစ်ခု ဖြစ်သည်။ tag သို့မဟုတ် လှည့်ပုံပြောင်းရန် ၎င်းကို ရွေးပြီး **Properties** တွင် ပြောင်းပါ၊ ဒါမှမဟုတ် {{key:Delete}} ကို နှိပ်ပါ။

## ရေပိုက်အစုံတွင် ပါဝင်သည်များ

Fixture များ (water closet၊ urinal၊ lavatory၊ ရေချိုးကန်၊ ရေချိုးခန်း shower၊ မီးဖိုချောင် sink၊ sink တစ်ခု)၊ floor drain၊ ကြမ်းပြင်နှင့် နံရံ cleanout များ၊ hose bib၊ နံရံ hydrant၊ ရေနွေးထိုင်၊ valve များ (gate၊ globe၊ ball၊ check၊ butterfly၊ pressure reducing) နှင့် ၎င်းတို့၏ အတိုကောက်များပါသော line style များ: cold water (CW)၊ hot water (HW)၊ hot water return (HWR)၊ waste (W)၊ vent (V)၊ storm drain (SD) နှင့် gas (G)။ ပုံများသည် plan နှင့်အတူ scale ကျသဖြင့် ပရင့်ထုတ်သော စာရွက်ပေါ်တွင် အရွယ်အစား မပြောင်းပါ။ line style သည် plan ပေါ်တွင် style ကို ပြရန် တိုတောင်းသော အပိုင်းတစ်ခုသာ ဖြစ်သည်။ အမှန်တကယ် ပိုက်လမ်းကြောင်းများကို ပိုက်ကိရိယာများဖြင့် ဆွဲပါ။

:::note
ဤသည်မှာ ဘုံ ရေပိုက် plan စည်းမျဉ်းများ ဖြစ်ပြီး ကျွန်ုပ်တို့ ဆွဲထားသည်။ ISO 4067-1 သို့မဟုတ် ASME Y32.4 အတွက် လက်မှတ်မထိုးထားပါ။ ၎င်းတို့ကို အများပြည်သူ ပုံဆွဲ အကျဉ်းချုပ်များ နှင့် သင်တန်းစာအုပ်များနှင့် နှိုင်းယှဉ်ထားသည် (အစုံ၏ sources မှတ်ချက်တွင် ကိုက်ညီသည့်နေရာနှင့် ကွဲပြားသည့်နေရာကို ဖော်ပြထားသည်)။ ထုတ်ကုန်တစ်ခုမှ ကူးယူထားခြင်း မဟုတ်ပါ။ အခမဲ့ အသုံးပြုနိုင်သည် (Apache-2.0)။ ပုံဆွဲ အစုံများ ကွဲပြားသဖြင့် သင့်ပရောဂျက်၏ legend ကို စစ်ဆေးပါ။ ၎င်းတို့သည် plan သင်္ကေတများဖြစ်ပြီး ရေပိုက် ဒီဇိုင်း မဟုတ်ပါ။ ပိုက်အရွယ်များကို မသတ်မှတ်ပါ သို့မဟုတ် ကုဒ်များကို စစ်မဆေးပါ။
:::

## အကြိုက်ဆုံးများနှင့် keyboard

- သင်္ကေတတစ်ခုပေါ်ရှိ ကြယ်ပွင့်ကို နှိပ်ပါ (သို့မဟုတ် ၎င်းပေါ်တွင် {{key:F}} ကို နှိပ်ပါ) အကြိုက်ဆုံးအဖြစ် ထားရန်။ အကြိုက်ဆုံးများကို အရင်ဆုံး ပြပြီး ဤ browser တွင် ဆက်ရှိနေသည်။ **အကြိုက်ဆုံးများသာ** က ၎င်းတို့ကိုသာ ပြသည်။
- ရှာဖွေရေးအကွက်မှ {{key:Down}} က သင်္ကေတများထဲ ဝင်သည်။ ညွှန်မြားခလုတ်များ၊ {{key:Home}} နှင့် {{key:End}} က ၎င်းတို့ကြားတွင် ရွှေ့သည်။ {{key:Enter}} က အာရုံရှိသည့်တစ်ခုကို ရွေးသည်။ {{key:Esc}} က palette ကို ပိတ်သည်။
- ဖုန်းတွင် palette သည် မျက်နှာပြင်အောက်ခြေရှိ စာရွက်ဖြစ်သည်။ သင်္ကေတတစ်ခု ရွေးသည့်အခါ plan ကို မြင်နိုင်ရန် ဘေးဖယ်ပေးသည်။ Build menu မှ သို့မဟုတ် options bar ရှိ **ပြား** ခလုတ်မှ ပြန်ဖွင့်ပါ။

:::tip
ဖိုင်တစ်ခုက ဤဗားရှင်းတွင် မပါသော သင်္ကေတအစုံကို သုံးလျှင် သင်္ကေတနေရာတွင် plan က ဘောက်စ်တစ်ခု ပြသည်။ ပြဿနာများက ၎င်းကို စာရင်းပြုစုသည်။
:::

## ထားပြီးသော element ကို သင်္ကေတနှင့် ချိတ်ဆက်ရန်

စာကြည့်တိုက်မှ မီးချိတ် တစ်ခုသည် 3D element ဖြစ်သော်လည်း လျှပ်စစ် အပြင်အဆင်တွင် ၎င်း၏ သင်္ကေတအဖြစ် ပြသည်။ ၎င်းကို **တစ်ကြိမ်** ထားပြီး ချိတ်ဆက်ပါ:

1. Build › **Symbol link** ကို ရွေးပါ (သို့မဟုတ် SYMBOLLINK ကို ရိုက်ပါ)။ ဘယ်ဘက် panel တွင် Symbol link အပိုင်း ဖွင့်သည်။
2. plan သို့မဟုတ် 3D ထဲတွင် ထားပြီး element များကို ရွေးပါ။ အပိုင်းက ရွေးထားသည့်အရေအတွက်နှင့် ၎င်းတို့ ချိတ်ဆက်ထားသည့်အရာများကို ပြောသည်။
3. **Symbol** ကို ရွေးပါ (သင်္ကေတအစုံမှ မည်သည့်တစ်ခုမဆို: Electrical၊ Plumbing) ထို့နောက် **Link** ကို ရွေးပါ။

element သည် element တစ်ခုအတိုင်း ဆက်ရှိပြီး ဇယားတိုင်းက တစ်ကြိမ်သာ ရေတွက်သည်:

- **3D** တွင် အမြဲ ၎င်း၏ ကိုယ်ထည်ကို ပြသည်။
- **plan** တွင် ယခင်အတိုင်း ၎င်း၏ plan ပုံစံကို ပြသည်။
- **ဤ view သည် ချိတ်ဆက်ထားသော element များကို ... အဖြစ် ပြသည်** ကို **ကိုယ်စားပြုသော သင်္ကေတ (ဝန်ဆောင်မှု အပြင်အဆင်)** သို့ သတ်မှတ်ထားသော plan သည် သင်္ကေတကို နေရာတွင် ပြသည်။ သင်္ကေတကို နှိပ်လျှင် element ကို ရွေးသည်။ ရွေးချယ်မှုကို ဖိုင်ထဲရှိ ထို view (အထပ်၏ floor plan၊ ceiling plan သို့မဟုတ် callout) အတွက် သိမ်းထားသည်။

**သင်္ကေတကို 90° လှည့်ပါ** သည် သင်္ကေတကို ၎င်း၏ element နှင့် ဆန့်ကျင်ဘက် လှည့်သည်။ **Remove the link** က ချိတ်ဆက်မှုကို ဖယ်သည်။ element သည် ကျန်နေသည်။ **Linked symbols** ဇယားသည် ချိတ်ဆက်ထားသော element တစ်ခုစီကို အထပ်နှင့် ရှိနေသည့် အခန်းနှင့်အတူ တစ်ကြိမ်စာရင်းပြုသည်။

မပါသေးသည်: စာရွက်ပေါ်ရှိ view ၏ ရွေးချယ်မှုသည် ပြသသော အထပ် plan ၏ ရွေးချယ်မှုဖြစ်သည်။ Electrical ကိရိယာဖြင့် ထားသော စက်ပစ္စည်းများသည် plan တိုင်းတွင် သင်္ကေတများ ဖြစ်ဆဲ ဖြစ်သည်။
