IFC5 alpha (ဖိုင်အဆုံး {{ui:.ifcx}}) သည် buildingSMART က ဒီဇိုင်းလုပ်နေဆဲဖြစ်သော ဖိုင်ဖော်မတ် ဖြစ်သည်။ ၎င်းသည် နောက်ဆုံးမဟုတ်သေးပါ: ဖိုင်များနှင့် ၎င်းကို ဖတ်ပုံကို ပြောင်းနိုင်သည်။ ထို့ကြောင့် ဤသည်မှာ လက်တွေ့ရွေးချယ်မှု ဖြစ်ပြီး ဦးစွာ ဖတ်ရန် လိုအပ်သည်။

## ဖွင့်ရန်

1. {{ui:Settings}} ကို ရွေးပြီး BimCraft tab ရှိ {{ui:IFC5 alpha (IFCX)}} အပိုင်းကို ရွေးပါ။
2. {{ui:IFC5 alpha (IFCX) - the format is still changing; read first}} ကို အမှန်ခြစ်ပါ။

မူလအားဖြင့် ပိတ်ထားသည်။ ပိတ်ထားစဉ် .ifcx ဖိုင်ကို ဤစာမျက်နှာကို ညွှန်သော စာကြောင်းဖြင့် ငြင်းပယ်သည်။ ဖွင့်ထားစဉ် {{ui:Open IFC5 alpha (.ifcx)…}} နှင့် {{ui:IFC5 alpha}} ထုတ်ယူခလုတ် ပေါ်လာသည်။

## ဖွင့်ရန်

- {{ui:Open a file or folder}} ဖြင့် .ifcx ဖိုင်တစ်ခု ရွေးပါ (ဖွင့်ထားသော မော်ဒယ်ကို အစားထိုးသည်၊ ပုံမှန် တည်းဖြတ်မှု မေးခွန်းပြီးနောက်)၊ သို့မဟုတ်
- {{ui:Open IFC5 alpha (.ifcx)…}} ကို ရွေးပြီး ဖိုင်အများအပြား တစ်ပြိုင်တည်း ရွေးပါ: ဖိုင်၊ ၎င်း၏ အလွှာများနှင့် ၎င်း တင်သွင်းသော schema ဖိုင်များ။ မော်ဒယ် ဖွင့်ထားပြီးဖြစ်လျှင် ဖိုင်ကို **ဘေးတွင် ထည့်သည်**; မော်ဒယ်စာရင်းရှိ x သည် ၎င်းကို ပြန်ဖယ်သည်၊ ၎င်းသည် undo ဖြစ်သည်။

IFCX ဖိုင်သည် node များ (လမ်းကြောင်း၊ ၎င်း၏ ကလေးများ၊ အမွေဆက်ခံသည်များ၊ attributes) ကို စာရင်းပြုသည်။ ဖိုင်များစွာက node တစ်ခုတည်းကို ဖော်ပြနိုင်သည်: နောက်ဖိုင် (အလွှာ) သည် ယခင်ဖိုင်၏ attributes ကို အစားထိုးသည်၊ null ကလေးက ကလေးကို ဖယ်သည်။ BimCraft က ၎င်းတို့ကို ပေါင်းပြီး ရလဒ်ကို ငယ်သော IFC4 မော်ဒယ်အဖြစ် ဆွဲသည်: ပရောဂျက်၊ ဆိုက်၊ အဆောက်အအုံ၊ အထပ်များနှင့် အမည်၊ အမျိုးအစား၊ ဂုဏ်သတ္တိများ၊ ပမာဏများ၊ အရောင်များနှင့် mesh များပါသော ဒြပ်စိတ်များ။

ကွန်ယက်မှ ဘာမျှ မရယူပါ။ ဖိုင်က တင်သွင်းသော schema ဖိုင်များ (ဥပမာ `ifc@v5a.ifcx`) ကို သင်ဖိုင်နှင့်အတူ ရွေးထားမှသာ သုံးသည်; မဟုတ်ပါက အစီရင်ခံစာက ထိုသို့ ပြောပြပြီး attributes ကို အမျိုးအစား စစ်ဆေးခြင်းမရှိဘဲ ဖတ်သည်။

### အစီရင်ခံစာ

ဖွင့်ပြီးနောက် အစီရင်ခံစာက ဖတ်ခြင်းက တွေ့သည်များကို စာရင်းပြုသည်: schema နှင့် မကိုက်ညီသော ဒေတာ၊ မပေးထားသော schema ဖိုင်များ၊ ဤနေရာတွင် IFC အဓိပ္ပာယ် မရှိသော attributes။ မြေပုံဆွဲရန် မရှိသော attributes များကို မော်ဒယ်တွင် **ထိန်းထားသည်**၊ မဖျက်ပါ၊ ထုတ်ယူစဉ် ပြန်ရေးသည်။

## ဘာဖြစ်သွားသလဲ

| IFCX ဖိုင်တွင် | BimCraft တွင် |
|---|---|
| IFC class ပါသော node (project, site, building, storey, wall …) | ကိုက်ညီသော IFC4 ဒြပ်စိတ်; ဤဖတ်ခြင်းက မသိသော class သည် building element proxy ဖြစ်လာသည် |
| Parent အောက်တွင် node ရှိ အမည် | ဒြပ်စိတ်အမည် |
| Quantity kind ပါသော attributes (Length, Area, Volume, Mass …) | `Qto_IFCX` ဟု အမည်ပေးထားသော IFC4 quantity set (IFC4 quantities သည် IFC4 `Qto_*` sets အဖြစ် ဆက်ရှိ) |
| အခြား property attributes | `Pset_IFCX` ဟု အမည်ပေးထားသော property set |
| Mesh နှင့် transform attributes | ဒြပ်စိတ်၏ triangles နှင့် နေရာချထားမှု; မမြင်ရသော mesh များကို မဆွဲပါ |
| Colour, opacity, material, classification | ဒြပ်စိတ်၏ surface style၊ material နှင့် classification |

ယူနစ်များကို မီတာ၊ Z အပေါ်ဘက်ဟု ယူသည်: alpha က ယူနစ်များကို နောက်မှ မှတ်တမ်းတင်မည်ဟု ဆိုသည်။

## ထုတ်ယူခြင်း

Toolbar ပေါ်ရှိ {{ui:IFC5 alpha}} ကို ရွေး၊ မှတ်ချက်ကို ဖတ်ပြီး {{ui:Export .ifcx}} ကို နှိပ်ပါ။ ဖိုင်တွင် ကျွန်ုပ်တို့၏ header (author CadCraft၊ version ifcx_alpha) ပါဝင်ပြီး ၎င်းသည် alpha ဖော်မတ်ဖြစ်ကြောင်း ကိုယ်တိုင် ပြောသည်။ မော်ဒယ်တစ်ခုစီကို ၎င်း၏ ကိုယ်ပိုင် ဖိုင်ကိုဩဒီနိတ်ဖြင့်၊ မီတာဖြင့် ရေးသည်၊ အမည်များ၊ class များ၊ property sets များ၊ ပမာဏများ (kind ပါသော attributes အဖြစ်)၊ အရောင်များနှင့် triangles ဖြင့်။ အလွှာများနှင့် အမွေဆက်ခံမှုကို ပြားချထားသည်။ ပို့သော ပရိုဂရမ်တွင် ဖိုင်ကို စစ်ဆေးပါ။

## ကန့်သတ်ချက်များ

- ကွေးသော ဂျီသြမေတြီ (curves, surfaces) ကို မဖတ်ပါ: triangle mesh များသာ။
- နံရံအတွင်း ထည့်ထားသော တံခါးနှင့် ပြတင်းပေါက်များကို အထပ်ပေါ်တွင် နေရာချသည်; ၎င်းတို့ ထွက်လာသော နံရံကို မချိတ်ဆက်ပါ။
- IFC4 `Qto_*` set အမည်များကို ကျွန်ုပ်တို့ကိုယ်ပိုင် attribute group များ (`cadcraft::qto::…`) အဖြစ် ထိန်းထားသည်; စံ alpha schema တွင် quantity အမည် အနည်းငယ်သာ ရှိသည်။
- ဖော်မတ်သည် ပြောင်းလဲနိုင်သည်; ယနေ့ ပြုလုပ်သော ဖိုင်သည် မနက်ဖြန် မဖတ်နိုင်ပါ။
