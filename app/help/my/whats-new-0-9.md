ဤသည်မှာ 0.8.1 နှင့် နှိုင်းယှဉ်လျှင် BimCraft 0.9 တွင် ပြောင်းလဲသွားသည်များ ဖြစ်သည်။ အဓိက အကြောင်းအရာ နှစ်ခုမှာ အမှန်တကယ် နံရံကိရိယာနှင့် ကြီးမားသော BIM ပရိုဂရမ်များမှ လာသူများ မျှော်လင့်သော ပုံစံဖြင့် ကြည့်ရှုသည့် view များ ဖြစ်သည်။ ၎င်းတို့ပတ်ဝန်းကျင်တွင် Collada ထုတ်ခြင်း၊ လျှပ်စစ်စက်ပစ္စည်း ထည့်နိုင်သော အကူအညီပေးသူများ၊ Scan to BIM နှင့် {{ui:ခွဲခြမ်းစိတ်ဖြာမှု}} tab ရှိ လေ၊ ငလျင်နှင့် finite-element အလုပ်များ ပါဝင်သည်။

## အသစ်

### နံရံများ

- **အပိုင်းလုံး ပုံသဏ္ဍာန်များ ဆွဲရန်။** {{ui:ဆွဲရန်}} တွင် {{ui:ပုံသဏ္ဍာန်များ}} ကို ဖွင့်ပါ (သို့မဟုတ် နံရံ အတန်း၏ Shape စာရင်းတွင် ပုံသဏ္ဍာန် ရွေးပါ) - ထောင့်မှန်ကွက်၊ လှည့်ထားသော ထောင့်မှန်ကွက်၊ ဘက်ပေါင်း 3 မှ 64 အထိ ပိုလီဂွန်၊ ဗဟိုဖြင့် arc၊ tangent arc၊ ရွေးထားသော မျဉ်းများပေါ်ရှိ နံရံများ၊ သို့မဟုတ် သင်နှိပ်ထားသော ပိတ်ထားသော နယ်ပယ်ပတ်လည်ရှိ နံရံများ။ ထောင့်မှန်ကွက်တစ်ခုသည် ထောင့်ဆက်ထားသော နံရံလေးခုနှင့် ပြန်ဖျက်ရန် အဆင့်တစ်ခုဖြစ်သည်။ [နံရံပုံသဏ္ဍာန်၊ split၊ offset၊ stretch နှင့် lock](topic:wall-tools) ကို ကြည့်ပါ။
- **ဆွဲမီ သတ်မှတ်ပါ၊ ဆွဲပြီးနောက် ပြောင်းပါ။** နံရံ အတန်းတွင် {{ui:Offset}} နှင့် {{ui:Join}} ရှိသည် (လွတ်ရှိနေသော နံရံများ ဆွဲရန် ဖြုတ်ပါ)။ ဆွဲပြီးနောက် ဆွဲထားသော နံရံများပေါ်တွင် {{ui:Offset}}၊ {{ui:Box stretch}} နှင့် {{ui:Align and lock}} ကို သုံးပါ။ ရွှေ့ထားသော သို့မဟုတ် ဆန့်ထားသော နံရံသည် ၎င်း၏ တံခါး၊ ပြတင်းပေါက်နှင့် အတိုင်းအတာများကို ထိန်းထားသည်။ အချက်တိုင်း ပြန်ဖျက်ရန် အဆင့်တစ်ခု ဖြစ်သည်။
- **နံရံများ ဖြတ်ရန်။** {{ui:Split}}၊ {{ui:Gap}}၊ {{ui:Free ends}}၊ {{ui:Delete segment}} နှင့် {{ui:Rejoin}} သည် နှိပ်သည့်နေရာ သို့မဟုတ် အခြားနံရံ ဖြတ်ကျော်သည့်နေရာတွင် နံရံကို ဖြတ်သည်။ တံခါးမှ ဖြတ်ခြင်းကို ငြင်းဆိုသည်။ [နံရံပုံသဏ္ဍာန်၊ split၊ offset၊ stretch နှင့် lock](topic:wall-tools) ကို ကြည့်ပါ။
- **နံရံများကို ဂရစ်မျဉ်းများသို့ လော့ခ်ချရန်။** ဂရစ်မျဉ်းတစ်လျှောက်ရှိ နံရံကို ရွေးပြီး {{ui:ဂုဏ်သတ္တိများ}} တွင် {{ui:Lock to grid}} ကို အမှန်ခြစ်ပါ။ Grid ကိရိယာ ဖွင့်ထားစဉ် ရွေးထားသော မျဉ်းအတွက် {{ui:Move by}} တွင် အကွာအဝေး ရိုက်ထည့်ပါ၊ လော့ခ်ချထားသော နံရံများသည် ပြန်ဖျက်ရန် အဆင့်တစ်ခုဖြင့် လိုက်ပါသည်။
- **နံရံတစ်ခု ပုံသဏ္ဍာန်ပေးရန်။** နံရံတစ်ခု၏ {{ui:ဂုဏ်သတ္တိများ}} တွင် ၎င်း၏ အပေါ် သို့မဟုတ် အောက်ခြေကို ခေါင်မိုး၊ ကြမ်းပြင် သို့မဟုတ် ခုံမိုးနှင့် ချိတ်နိုင်သည်၊ elevation outline ကို တည်းဖြတ်နိုင်သည်၊ စောင်းနိုင်သည်၊ သို့မဟုတ် တံခါး သို့မဟုတ် ပြတင်းပေါက် မပါဘဲ နံရံဖွင့်ပေါက် ဖြတ်နိုင်သည်။ [နံရံပုံသဏ္ဍာန်](topic:wall-shape) ကို ကြည့်ပါ။
- **အရှည်က မည်သည့်အဖျား ရပ်နေသည်ကို ပြသသည်။** {{ui:Grow from}} သည် အရှည် ပြောင်းသောအခါ အစ၊ အဆုံး သို့မဟုတ် ဗဟို ရပ်နေမည်ကို သတ်မှတ်သည်။
- **အရှည်နှင့် ပလန်အတိုင်းအတာ သဘောတူသည်။** {{ui:Measure from}} (ဗဟိုမျဉ်း၊ အတွင်းမျက်နှာ သို့မဟုတ် အပြင်မျက်နှာ) သည် Length အကွက်နှင့် ပလန်ပေါ်ရှိ နံရံအတိုင်းအတာ နှစ်ခုလုံးကို ထိန်းသည်။ ဗဟိုမျဉ်းဖြင့် စတင်ထားသောကြောင့် ပလန်၏ နံရံအတိုင်းအတာများသည် ယခင် အပြင်မျက်နှာကို ဖတ်ခဲ့သည်နေရာတွင် ယခု ဗဟိုမျဉ်းကို ဖတ်သည်။ နံရံ အတန်း၊ {{ui:ဂုဏ်သတ္တိများ}} သို့မဟုတ် {{ui:ဆက်တင်များ}} › {{ui:BimCraft}} › {{ui:နံရံများ}} တွင် ပြောင်းပါ။

### အထပ်များ၊ ဂရစ်များနှင့် တိုင်းတာခြင်း

- **အောက်တွင် အထပ် ထည့်ရန်။** {{ui:အထပ်များ}} ပန်နယ်ရှိ {{ui:Add a level below}} သည် အနိမ့်ဆုံးအထပ်အောက်တွင် အမြင့်တူသော အထပ်တစ်ခုကို အနှုတ် elevation ဖြင့် ထည့်သည် (Level -1၊ Level -2)။ အခြားအရာ မရွေ့ပါ။ {{ui:Add levels…}} က ယခု အနှုတ် အမြင့်များကို လက်ခံသည်။ Command line တွင် LEVEL၊ LEVELS၊ STOREY သို့မဟုတ် STOREYS ရိုက်ပါက {{ui:Add levels…}} ကို ဖွင့်သည်၊ menu နှင့် ribbon tab များတွင် {{ui:အထပ်များ}} ခလုတ် ရှိသည်။ [ဆိုက်၊ အဆောက်အအုံနှင့် အထပ်များ](topic:site-building-and-levels) ကို ကြည့်ပါ။
- **ပလန်ပေါ်ရှိ ဂရစ် အတိုင်းအတာများ။** {{ui:Grid}} ကိရိယာ ဖွင့်ထားစဉ် {{ui:Dimensions}} ကို အမှန်ခြစ်လျှင် ကပ်လျက် မျဉ်းများကြား အကွာအဝေးနှင့် ပတ်လည်ရှိ စုစုပေါင်း အရွယ်အစားကို အထပ်တိုင်း၏ ပလန်ပေါ်တွင် bubble များအပြင်ဘက် ဆွဲသည်။ [ဂရစ်ကို အတိုင်းအတာချရန်](topic:grid-dimensions) ကို ကြည့်ပါ။
- **ပလန်ပေါ်တွင် တိုင်းတာရန်။** {{ui:Draw}} အုပ်စုရှိ {{ui:Measure}} သည် နှိပ်ချက်နှစ်ခုကြား အကွာအဝေးနှင့် X နှင့် Y ကွာခြားချက်များကို ပေးသည်။ မော်ဒယ်တွင် ဘာမျှ မသိမ်းပါ။ [ပလန်ပေါ်တွင် တိုင်းတာခြင်း](topic:measure-on-the-plan) ကို ကြည့်ပါ။
- **ကော်လံများစွာ တစ်ပြိုင်နက် ပြောင်းရန်။** နံရံနှင့်အတူ ကော်လံများ ရွေးပါက စာရင်းတွင် အမျိုးအစား တစ်ခုစီကို {{ui:Keep only these}} ဖြင့် ပြသသည်။ တစ်ချက်နှိပ်ခြင်းဖြင့် ကော်လံများ ကျန်ခဲ့ပြီး ၎င်းတို့၏ မျှဝေသော အကွက်များ ပြသသည်။
- **ဖော်ပြသည့် ယူနစ်တစ်ခုတည်း နေရာတိုင်း။** ညှိနှိုင်းချက်များ၊ တိုင်းတာချက်များ၊ section များ၊ စာရွက် အတိုင်းအတာများ၊ frame tab ၏ load နှင့် ရလဒ်များနှင့် Problems စာသားများသည် သင်ရွေးသော ယူနစ်ကို လိုက်သည်။ ထုတ်ယူမှုများသည် SI အတိုင်း ရှိနေသည်။

### View များ၊ စာရွက်များနှင့် print

- **လုပ်ငန်းစဉ်ပုံစံ။** {{ui:ဆက်တင်များ}} › {{ui:BimCraft}} › {{ui:လုပ်ငန်းစဉ်ပုံစံ}} သည် view တစ်ခုစီ၏ ကိုယ်ပိုင် မှတ်စုများနှင့် ဆေးတံဇယားများ ရှိခြင်း၊ သို့မဟုတ် မျှဝေခြင်းကို ရွေးသည်။ [လုပ်ငန်းစဉ်ပုံစံ၊ ပွားထားသော view များ၊ စာရွက်ပေါ် ဆေးတံများ၊ Report as နှင့် template များ](topic:working-style) ကို ကြည့်ပါ။
- **View ပွားရန်။** Plan၊ ceiling plan၊ callout၊ elevation နှင့် section များကို {{ui:Own copy}} သို့မဟုတ် {{ui:Linked}} အဖြစ် ပွားနိုင်သည်; {{ui:Make own copy}} က linked တစ်ခုကို လွတ်လပ်စေသည်။ [လုပ်ငန်းစဉ်ပုံစံ၊ ပွားထားသော view များ၊ စာရွက်ပေါ် ဆေးတံများ၊ Report as နှင့် template များ](topic:working-style) ကို ကြည့်ပါ။
- **ပုံအတိုင်း print၊ သို့မဟုတ် ဆေးတံဇယားဖြင့်။** Pen overrides များကို view နှင့်အတူ IFC တွင် သိမ်းထားပြီး စာရွက်များနှင့် PDF များက စခရင်အတိုင်း ဆွဲသည်။ အတူတူ အခန်းတွင် pen table များကိုလည်း ဖုံးလွှမ်းသည်။
- **Report as။** {{ui:ဂုဏ်သတ္တိများ}} ရှိ {{ui:Report as}} သည် လမ်းအဖြစ် ဆွဲထားသော slab၊ panel အဖြစ် ဆွဲထားသော နံရံ သို့မဟုတ် ramp အဖြစ် ဆွဲထားသော ခေါင်မိုးကို သင်ရွေးသော class အဖြစ် IFC သို့ ရေးပြီး ဇယားများ၊ Quantities၊ Find၊ Color by နှင့် Problems တွင် ထိုနည်းဖြင့် ရေတွက်သည်။
- **Elevation နှင့် section များတွင် တည်းဖြတ်ရန်။** နံရံများ၊ အပေါက်များ၊ အထပ်များ၊ အတိုင်းအတာများနှင့် မှတ်စုများကို elevation သို့မဟုတ် section တွင် တိုက်ရိုက် ဆွဲ၊ ရွှေ့နိုင်သည်၊ သင့်ကိုယ်ပိုင် စာရွက်အရွယ်အစားနှင့် title block များဖြင့်။ [Elevation နှင့် section များတွင် တည်းဖြတ်ရန်](topic:edit-in-elevations) ကို ကြည့်ပါ။
- **စာရွက်များ။** စာရွက်တိုင်း landscape သို့မဟုတ် portrait ဖြစ်နိုင်သည်။ {{ui:Type a scale}} အကွက်သည် ထားသော view တိုင်း၏ အတိုင်းအတာစာရင်းဘေးတွင် ရှိသည် (1:64၊ 2:1၊ 1/4" = 1')။ ထားထားသော ပုံဆွဲကို ဆွဲရွှေ့နိုင်သည် သို့မဟုတ် မြား key များဖြင့် အနည်းငယ် ရွှေ့နိုင်သည်၊ နှင့် {{ui:Formats…}} › {{ui:Import SVG…}} က သင်၏ ကိုယ်ပိုင် စာရွက်ဒီဇိုင်းကို စာရွက်တစ်ခုချင်းစီအလိုက် ရိုက်ထည့်သော အကွက်များပါသည့် title block အဖြစ် ပြောင်းသည်။
- **စာရွက်ပေါ်ရှိ Library ဂုဏ်ပြုချက်များ။** Library ပစ္စည်းများပါသော ပုံဆွဲအစုအဝေးတွင် Library credits ဇယား ရရှိပြီး မည်သည့် စာရွက်ပေါ်တွင်မဆို ထားနိုင်သည်။ [Library credits](topic:library-credits) ကို ကြည့်ပါ။

### Library- ထားခြင်း

- **Place သည် view ကို လိုက်သည်။** Plan view တွင် Library သည် {{ui:Place in plan}} ကို ပြသည်; 3D တွင် {{ui:Place in model}} ကို ပြသည်; Split တွင် {{ui:Place in plan}} ကို အဓိကလုပ်ဆောင်ချက်အဖြစ် ခလုတ်ခွဲ ပြသည်။ နည်းလမ်း နှစ်ခုစလုံးက IFC element တူတူကို ရေးသည်။ Library ကဒ်တစ်ခုကို plan သို့မဟုတ် 3D view သို့ ဆွဲချနိုင်သည်; ဘောပင် သို့မဟုတ် လက်ဖြင့်ဆိုလျှင် ဖိထားပြီး ဆွဲပါ။ [Library မှ ထားခြင်း](topic:place-from-library) ကို ကြည့်ပါ။

### ဖိုင်များနှင့် အကူအညီပေးသူများ

- **Collada နှင့် Google Earth။** Toolbar ရှိ {{ui:Collada}} (menu style များတွင် File menu) က .dae၊ သို့မဟုတ် မြေပုံပေါ်တွင် မော်ဒယ် ရှိသည့်နေရာတွင် ချထားသော .kmz ကို ရေးသည်။ [Collada သို့မဟုတ် Google Earth အတွက် မော်ဒယ်ထုတ်ခြင်း](topic:collada) ကို ကြည့်ပါ။
- **အကူအညီပေးသူများက လျှပ်စစ်စက်ပစ္စည်း ထားနိုင်သည်။** သင်ချိတ်ဆက်ထားသော အကူအညီပေးသူတွင် စက်ပစ္စည်းများ ထည့်၊ စာရင်းပြု၊ ပြောင်းနှင့် ဖျက်ရန်၊ မီးများ သတ်မှတ်ရန် ကိရိယာအသစ်များ ရှိသည်။ အကူအညီပေးသူများသည် {{ui:ဆက်တင်များ}} တွင် သင်ဖွင့်မချင်း ပိတ်ထားသည်။ [AI အကူအညီပေးသူနှင့် သင့်မော်ဒယ်ပေါ် အလုပ်လုပ်ခွင့်ပေးရန်](topic:assistants) ကို ကြည့်ပါ။
- **Scan to BIM (add-on)။** မူလအားဖြင့် ပိတ်ထားပြီး Point clouds add-on လိုအပ်သည်။ Scan မှ အထပ်များ၊ နံရံများ၊ တံခါးများနှင့် ပြတင်းပေါက်များကို အဆိုပြုပြီး တိုင်းတာထားသော သွေဖည်မှုကို တစ်ခုချင်းစီအတွက် ပြသသည်; လက်ခံခြင်းသည် ပြန်ဖျက်ရန် အဆင့်တစ်ခု ဖြစ်သည်။

### ခွဲခြမ်းစိတ်ဖြာမှု

- **လေနှင့် ငလျင် ဆိုက်ဒေတာ။** {{ui:ခွဲခြမ်းစိတ်ဖြာမှု}} tab တွင်- လေဝင်ရိုက်မှုများကို ASCE 7-10 သို့မဟုတ် 7-16 ဖြင့် တင်းကျပ်ပိတ်ထားသော အဆောက်အအုံအတွက်၊ အထပ်တိုင်းပေါ် အင်အားကို load cases အဖြစ်; ငလျင် ဆိုက်ဒေတာကို USGS ရှာဖွေမှုနှင့် design spectrum ဖြင့်။
- **ဖော်ပြသော ဖွဲ့စည်းပုံ နောက်ဆက်တွဲနှင့် finite element။** ACI 318-19 အတွက် ကွန်ကရစ်စစ်ဆေးချက်များ၊ ASCE 7-22 အတွက် ညီမျှသော ဘေးဘက်အား၊ အထပ် drift၊ ပြားများအဖြစ် slab နှင့် နံရံများ၊ ASCE 7 နှင့် EN 1990 မှ load combination များ။ ကျွန်ုပ်တို့၏ ကိုယ်ပိုင် finite-element engine က shell၊ tetrahedra နှင့် modal analysis ကို လုပ်သည်။ [ကွန်ကရစ် အဖွဲ့ဝင်များကို စစ်ဆေးပြီး ငလျင် load များ ပြုလုပ်ခြင်း](topic:concrete-and-seismic) နှင့် [Frame analysis](topic:frame-analysis) ကို ကြည့်ပါ။

## ပြင်ဆင်ပြီး

- **Stair များပေါ်တွင် ရွှေ့ခြင်း အလုပ်လုပ်သည်၊** ramp၊ ရေလက်ရုံး၊ ခေါင်မိုး အပြင်ပြား၊ ကိရိယာ ရပ်တည်သော စက်ပစ္စည်းများ၊ ပုံများနှင့် လမ်းကြောင်းများပေါ်တွင်လည်း။
- **နံရံ ဆွဲခြင်းသည် အခန်းကို မပုံပျက်စေတော့ပါ။** ဗဟိုကိုင်တွယ်ချက်သည် နံရံကို ကိုယ်ကိုယ်တိုင် အပြိုင်ရွှေ့ပြီး ထောင့်များသည် ဆက်ထားသော နံရံများအတိုင်း ပွတ်ဆွဲသည်။ ဟောင်းသော လွတ်လပ်စွာ ရွှေ့ရန် {{key:Mod}} ကို ဖိထားပါ; {{ui:Square up}} က 90 ဒီဂရီကို ပြန်ယူသည်။
- **ဆက်ထားသော node တွင် အထူ သို့မဟုတ် အမျိုးအစား ပြောင်းခြင်း** ယခု L၊ T၊ နံရံသုံးခု node နှင့် ကွေးသော နံရံဘေးတွင် ထောင့်ကို ပိတ်ထားသည်။
- **အခန်းအုပ်စုကို ရွှေ့ခြင်း သို့မဟုတ် ကူးခြင်း** အုပ်စုအပြင်ရှိ ဆက်ထားသော နံရံများကို ဆက်ထားဆဲ ဖြစ်စေသည်။
- **နံရံအတိုင်းအတာ၏ identity ကို Redo ထိန်းသည်။**
- **Draw ပိတ်ထားစဉ် နံရံကို ရွေးခြင်း** Properties တွင် အမှားမပေးတော့ပါ။
- **GPU မစတင်နိုင်သောအခါ Render သည် WebGL သို့ ပြန်သွားသည်**၊ ရပ်တန့်ခြင်း အစား။
- **EnergyPlus စစ်ဆေးချက်** ကို ပြန်ဖွင့်နိုင်သည်။
- **Documents သည် ဗဟိုချထားသော ဒိုင်ယာလော့ဂ်အဖြစ် ဖွင့်သည်။** {{key:Esc}}၊ X သို့မဟုတ် မှိန်ထားသော စာမျက်နှာပေါ် နှိပ်ခြင်းဖြင့် ပိတ်သည်။
- **{{ui:Plan}}၊ {{ui:Split}} နှင့် {{ui:3D}} ခလုတ်များ** မော်ဒယ် ဖွင့်သည်နှင့် ပြသည်၊ Draw ကို တစ်ကြိမ် ဖွင့်ပြီးမှသာ မဟုတ်ပါ။

## ရိုးသားသော ကန့်သတ်ချက်များ

- ရုပ်ပိုင်း ဟာ့ဒ်ဝဲပေါ်တွင် မည်သည်ကိုမျှ မပုံနှိပ်ခဲ့ပါ။ resin ထောက်ပံ့မှုများသည် အသစ်ဖြစ်ပြီး မစမ်းသပ်ရသေးပါ။
- လေ၊ ငလျင်၊ ကွန်ကရစ်နှင့် finite-element ရလဒ်များသည် အင်ဂျင်နီယာအတွက် စစ်ဆေးရေး အကူအညီများဖြစ်သည်၊ closed form များနှင့် စစ်ဆေးထားပြီး အမှန်တကယ် အဆောက်အအုံနှင့် မဟုတ်ပါ။
- Scan to BIM ကို synthetic အဆောက်အအုံဖြင့် စမ်းသပ်ထားပြီး အမှန် scan မဟုတ်ပါ၊ ထောင့်မှန်ခန်းများကိုသာ ရှာသည်။
- Collada ကို ဤနေရာတွင် Blender သို့မဟုတ် Google Earth တွင် မဖွင့်ခဲ့ပါ။
- အလင်းရောင် ခန့်မှန်းချက်ကို ကျွန်ုပ်တို့၏ကိုယ်ပိုင် trace နှင့် စစ်ဆေးထားပြီး အခြား အလင်းရောင် ပရိုဂရမ်များနှင့် မဟုတ်ပါ။
- တောင်အာဖရိကန် နံပါတ်များ အတည်မပြုရသေးပါ။
- ဘက်ပေါင်းချိတ်ဆက်ပုံစံများ (butt၊ mitre၊ square off) နှင့် အလွှာ ဦးစားပေးမှု မတည်ဆောက်ရသေးပါ; ထောင့်များကို mitre ဖြင့် ပြုလုပ်သည်။
- အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် စက်ဖြင့်ရေးထားသော မူကြမ်းများဖြစ်သည်။

ကျန်အရာအားလုံးကို [မတည်ဆောက်ရသေးသောအရာများ](topic:not-built-yet) တွင် တွေ့ရသည်။ ယခင် ပြောင်းလဲမှုများကို ဤစာမျက်နှာအောက်ရှိ 0.8 နှင့် 0.8.1 မှတ်စုများတွင် တွေ့ရသည်။

## ယခင်: 0.8 နှင့် 0.8.1

ဤသည်မှာ 0.7 နှင့် နှိုင်းယှဉ်လျှင် BimCraft 0.8 (2026-11-01) နှင့် 0.8.1 (2026-11-02) တွင် ပြောင်းလဲသွားသည်များ ဖြစ်သည်။ BimCraft သည် ယခု အဆောက်အအုံအကြောင်း မေးခွန်းများ ဖြေနိုင်ပြီး လူများ၊ အသံ၊ ရေ၊ လေနှင့် ငလျင်များဖြင့် စမ်းသပ်နိုင်သည်၊ ကိရိယာ ပိုများဖြင့်လည်း ဆွဲနိုင်သည်; 0.8.1 သည် ပြင်ဆင်ချက် ထုတ်လွှင့်မှု ဖြစ်သည်။

### အသစ်

**အဆောက်အအုံကို စမ်းသပ်ခြင်း**

- **အဆောက်အအုံထဲရှိ လူများ။** ဘယ်ဘက်ပန်နယ်ရှိ {{ui:အဆောက်အအုံထဲရှိ လူများ}} အပိုင်းသည် ထွက်ပြေးခြင်း သို့မဟုတ် ပုံမှန်နေ့ရက် ရောက်ရှိမှုကို သင်၏ အခန်းများ၊ တံခါးများနှင့် လှေကားများအတွင်း လျှောက်သည်။ အဆောက်အအုံ ကျဉ်းလာသည့်နေရာတွင် တန်းစီမှုများ၊ အခန်းတစ်ခုစီမှ ထွက်ပေါက်သို့ အရှည်ဆုံး လမ်းလျှောက်ချိန်နှင့် နောက်ဆုံးလူ မည်မျှကြာသည်ကို တွေ့ရသည်။ တံခါးတစ်ခုပေါ်တွင် {{ui:Shut}} ကို အမှန်ခြစ်ပြီး ဘာပြောင်းလဲသည်ကို ကြည့်ပါ၊ လျှောက်သူများကို ကြည့်ရန် {{ui:3D view တွင် လူများကို ပြရန်}} ကို အမှန်ခြစ်ပါ။ တွေ့ရှိချက်များသည် Problems သို့ သွားသည်။ ဒီဇိုင်းဆုံးဖြတ်ချက်အတွက် ကြမ်းတမ်းသော လူအုပ်မော်ဒယ်ဖြစ်ပြီး မီးဘေးကင်းရေး လက်မှတ် မဟုတ်ပါ။ [အဆောက်အအုံတစ်လျှောက် လူများကို လျှောက်စေခြင်း](topic:people-in-the-building) ကို ကြည့်ပါ။
- **အခန်း အသံ၊ နှင့် နားထောင်ခြင်း။** {{ui:အခန်း အသံစနစ်}} အပိုင်းက အခန်းတစ်ခုစီ၏ reverberation အချိန်ကို octave band အလိုက် (Sabine နှင့် Eyring) ပေးသည်၊ အရွယ်အစားနှင့် သင်ရွေးသော အလှဆင်မှုများမှ၊ သင့်ကိုယ်ပိုင် ပစ်မှတ်ဖြင့် အသံစုပ်ယူမှု မည်မျှ လိုအပ်သည်ကို ပြသည်။ {{ui:ဤအခန်းတွင် ဖွင့်ရန်}} သည် အသံ၊ လက်ခုပ်တီး၊ ဆွဲထားသော အသံ သို့မဟုတ် သင့်ကိုယ်ပိုင် အသံဖိုင်ကို အခန်းအတွက် တွက်ချက်ထားသော impulse response မှတစ်ဆင့် ဖွင့်သည်။ အသံစုပ်ယူမှု ကိန်းဂဏန်းများသည် သင် အစားထိုးရန် ပုံမှန် ထုတ်ပြန်ထားသော တန်ဖိုးများ ဖြစ်သည်။ [အခန်း အသံစနစ်](topic:room-acoustics) ကို ကြည့်ပါ။
- **ရေလွှမ်းမှု၊ လေနှင့် ငလျင် ပြန်ဖွင့်ခြင်း။** {{ui:အန္တရာယ် ပြန်ဖွင့်ခြင်း}} သည် အခန်းများထဲသို့ ရေတက်လာခြင်း၊ အထပ်တစ်ခုစီပေါ် လေဖိအား နှင့် အထပ်များကို လှုပ်ခတ်သော ငလျင်ကို ပလန် သို့မဟုတ် elevation ပေါ်တွင် အချိန်ဘားဖြင့် ပြသည်။ ရိုးရှင်းသော မော်ဒယ်များကို ၎င်းတို့၏ ယူဆချက်များနှင့်အတူ ပန်နယ်တွင် ပြသည်; စည်းမျဉ်း စစ်ဆေးချက် မဟုတ်ပါ။ [ရေလွှမ်းမှု၊ လေ သို့မဟုတ် ငလျင်ကို ပြန်ဖွင့်ခြင်း](topic:hazard-playback) ကို ကြည့်ပါ။
- **ဆယ်စုနှစ်ငါးခုအတွင်း ဘာပျက်စီးမလဲ။** {{ui:သက်တမ်းတစ်လျှောက် အမြင်}} သည် ပြတင်းပေါက်၊ တံခါး၊ အလှဆင်မှုနှင့် ခေါင်မိုး တစ်ခုစီ၏ ဝန်ဆောင်ခ သက်တမ်းကို၊ အစားထိုးရမည့် နှစ်များကို၊ နှင့် ယူနစ်တစ်ခုအတွက် ကုန်ကျစရိတ် ရိုက်ထည့်သောအခါ နှစ်အလိုက် ကုန်ကျစရိတ်နှင့် ၎င်း၏ ယခုတန်ဖိုးကို စာရင်းပြုသည်။ {{ui:ဇယားကို သိမ်းရန် (CSV)}} က ရေးထုတ်သည်။ ဝန်ဆောင်ခ သက်တမ်းများသည် စီစဉ်ရေး ကိန်းဂဏန်းများ ဖြစ်သည်။ [ဆယ်စုနှစ်ငါးခုအတွင်း ဘာပျက်စီးမလဲ ကြည့်ရန်](topic:life-cycle-view) ကို ကြည့်ပါ။
- **ကွန်ကရစ်နှင့် ငလျင် စစ်ဆေးချက်များ။** {{ui:Analysis}} tab ရှိ {{ui:Concrete members}} နှင့် {{ui:Seismic loads}} block များသည် ကွန်ကရစ် beam နှင့် ကော်လံများကို ACI 318-19 ဖြင့် စစ်ဆေးပြီး ထပ်ကြိမ် ကြမ်းပြင်များပေါ် ASCE 7-22 ဖြင့် ညီမျှသော ဘေးဘက်အားကို ပြုလုပ်ကာ အထပ် drift ပါဝင်သည်။ အင်ဂျင်နီယာ စစ်ဆေးရန်အတွက်။ [ကွန်ကရစ် အဖွဲ့ဝင်များကို စစ်ဆေးပြီး ငလျင် load များ ပြုလုပ်ခြင်း](topic:concrete-and-seismic) ကို ကြည့်ပါ။

**စစ်ဆေးခြင်းနှင့် အစီရင်ခံခြင်း**

- **IDS ဖြင့် စစ်ဆေးခြင်း။** ဖောက်သည်က ပေးသော `.ids` ဖိုင်ကို တင်ပြီး IFC မပို့မီ ၎င်းနှင့် မကိုက်ညီသော element အားလုံးကို Problems တွင် ကြည့်ပါ။ {{ui:မော်ဒယ် စစ်ဆေးချက်များ}} အောက်ရှိ {{ui:IDS ဖြင့် စစ်ဆေးရန်}} ကို ဖွင့်ပါ။ [ဖောက်သည်၏ IDS ဖြင့် မော်ဒယ်ကို စစ်ဆေးခြင်း](topic:check-against-ids) ကို ကြည့်ပါ။
- **Tag များနှင့် ဇယားများ။** သင့်ကိုယ်ပိုင် tag များကို သတ်မှတ်ပြီး element အများအပြားကို တစ်ပြိုင်နက် သတ်မှတ်ကာ ၎င်းတို့ကို ဖတ်သော ကော်လံများ၊ filter များနှင့် အုပ်စုများပါသည့် ဇယားများ ပြုလုပ်ပါ; tag များကို IFC တွင် သိမ်းသည်။ [Tag များနှင့် ဇယားများ](topic:tags-and-schedules) ကို ကြည့်ပါ။
- **မော်ဒယ်မှ စာရွက်စာတမ်းများ။** {{ui:မော်ဒယ်မှ စာရွက်စာတမ်းများ}} သည် ဖွင့်ထားသော IFC မှ specification template ကို ဖြည့်ပြီး PDF၊ Word စာရွက်စာတမ်း သို့မဟုတ် Markdown အဖြစ် သိမ်းသည်။ [မော်ဒယ်မှ စာရွက်စာတမ်းများ](topic:documents-from-the-model) ကို ကြည့်ပါ။
- **Scan ကို မော်ဒယ်နှင့် နှိုင်းယှဉ်ခြင်း။** Point cloud ဖွင့်ထားစဉ် {{ui:Compare}} က element တစ်ခုစီကို ပြီးစီး၊ တစ်စိတ်တစ်ပိုင်း ပြီးစီး၊ ပျောက်နေ သို့မဟုတ် မရောက်ရှိသေးဟု ဆုံးဖြတ်ပြီး ပြီးစီးမှု ရာခိုင်နှုန်းကို ပြသည်။ [Scan ကို မော်ဒယ်နှင့် နှိုင်းယှဉ်ခြင်း](topic:compare-scan-with-model) ကို ကြည့်ပါ။
- **ကာဗွန်နှင့် ကုန်ကျစရိတ်။** Carbon pane သည် တည်းဖြတ်နိုင်သော factor ဇယားမှ embodied carbon ကို ပေါင်းထည့်သည်၊ Cost pane သည် စျေးနှုန်းများကို 4D အချိန်ဇယားတစ်လျှောက် ခွဲဝေသည်။ BimCraft နှင့်အတူ ပါလာသော factor များသည် အထွေထွေ ဖြစ်ပြီး စစ်မဆေးရသေးဟု မှတ်သားထားသည်။ [Embodied carbon နှင့် ကုန်ကျစရိတ်](topic:embodied-carbon-and-5d-cost) ကို ကြည့်ပါ။
- **မည်သည့် မြေပုံ projection မဆို။** {{ui:Measure}} › {{ui:Coordinate system…}} သည် EPSG နံပါတ်၊ UTM zone၊ အမည် သို့မဟုတ် သင့်ကိုယ်ပိုင် projection အဓိပ္ပာယ်ဖွင့်ဆိုချက်ကို လက်ခံသည်။ [မည်သည့် projection ဖြင့် georeference လုပ်ခြင်း](topic:georeference-any-projection) ကို ကြည့်ပါ။

**ဆွဲခြင်းနှင့် တည်းဖြတ်ခြင်း**

- **ရွှေ့ခြင်း၊ ညှိခြင်းနှင့် ဖြန့်ခြင်း။** {{ui:Build}} အောက်တွင်; {{key:Shift+M}} က Move ကို စတင်သည် (ရိုးရိုး {{key:M}} သည် Measure ဖြစ်ဆဲ)။ Move သည် သွားနေစဉ် {{key:C}} ဖြင့် ကူးသည်၊ အဆင့်တစ်ခုစီသည် ပြန်ဖျက်ရန် တစ်ခုဖြစ်ပြီး Live TeamWork session တွင် သွားသည်။ [ရွှေ့ခြင်း၊ ကူးခြင်း၊ ညှိခြင်းနှင့် ဖြန့်ခြင်း](topic:move-align-distribute) ကို ကြည့်ပါ။
- **ပလန်အောက်ရှိ ပုံများ။** {{ui:Build}} › {{ui:Picture}} သည် PNG၊ JPEG သို့မဟုတ် WebP ကို အထပ်၏ ပလန်အောက် သို့မဟုတ် ဒေါင်လိုက်ပြားပေါ် ထားသည်။ အတိုင်းအတာကို အမှတ်နှစ်ခုဖြင့် သတ်မှတ်ပြီး ရွှေ့၊ လှည့်၊ မှိန်၊ လော့ခ်ချပါ။ MarkupCraft တွင် ကူးထားသော နေရာသည် ၎င်း၏ စာရွက် အတိုင်းအတာဖြင့် ကပ်ထည့်သည်။ [ပလန်အောက်တွင် ပုံထားခြင်း](topic:pictures-as-backgrounds) ကို ကြည့်ပါ။
- **Scan မှ နံရံများ။** Scan ဖွင့်ထားစဉ် နံရံများ၊ တံခါးများနှင့် အခန်းများသည် အဆိုပြုချက်များအဖြစ် ရောက်လာပြီး တစ်ခုချင်းစီ ထားရန် သို့မဟုတ် ငြင်းဆိုရန်၊ ပြန်ဖျက်ရန် အဆင့်တစ်ခုတွင်။ တစ်ဖက်တစ်ချက် ထောင့်မတ်သော နှစ်ဘက်ရှိ နံရံများကိုသာ ရှာသည်။ [Scan ကို နံရံများအဖြစ် ပြောင်းခြင်း](topic:scan-to-walls) ကို ကြည့်ပါ။
- **Trace၊ ဆေးတံများနှင့် sketch stair။** {{ui:Trace}} သည် အခြားအထပ်ကို ပလန်အောက်တွင် မျဉ်းကြောင်းဖြင့် ပြသည်၊ {{ui:Pens}} သည် နံရံ၊ တံခါးနှင့် ပြတင်းပေါက်တိုင်းကို view တစ်ခုတည်းတွင် ကိုယ်ပိုင် မျဉ်းအထူ ပေးသည်၊ {{ui:Sketch stair}} က လမ်းလျှောက်မျဉ်းကို လှေကားအဖြစ် ပြောင်းသည်။ Wavefront OBJ mesh ကို ဖွင့်သည်။ [Trace အထပ်၊ ဆေးတံများနှင့် ပုံဖော်ထားသော လှေကား](topic:trace-pens-stairs-obj) ကို ကြည့်ပါ။
- **လိပ်စာပတ်ဝန်းကျင်ရှိ အဆောက်အအုံများ။** CivilCraft ၏ Address to site က ရှာတွေ့သော အဆောက်အအုံများနှင့် မြေကွက်များသည် အကြံပြုချက်များအဖြစ် ရောက်လာပြီး ထည့်လိုသည်များကို သင်အမှန်ခြစ်ပါ။ [CivilCraft ၏ ဆိုက်မှ စတင်ခြင်း](topic:site-from-civilcraft) ကို ကြည့်ပါ။
- **ပန်နယ် ပုံဆွဲများ။** {{ui:Build}} › {{ui:ပန်နယ် ပုံဆွဲများ}} သည် သစ်သား သို့မဟုတ် ပေါ့ပါးသော ပြား သံမဏိဖြင့် နံရံ၊ ကြမ်းပြင်နှင့် ခေါင်မိုးများကို ဘောင်ခတ်ပြီး ဖြတ်စာရင်းကို CSV နှင့် shop ပုံဆွဲများကို PDF အဖြစ် သိမ်းသည်။ စတင်တန်ဖိုးများဖြစ်ပြီး ဖွဲ့စည်းပုံ ဒီဇိုင်း မဟုတ်ပါ။ [ပန်နယ် ပုံဆွဲများ](topic:panel-drawings) ကို ကြည့်ပါ။
- **သင်္ကေတပြားနှင့် အပင်များ။** {{ui:Build}} › {{ui:သင်္ကေတပြား}} သည် လျှပ်စစ်နှင့် ပိုက်ပြင် သင်္ကေတများကို အမည်ဖြင့် ရှာသည်; {{ui:Library}} ၏ {{ui:အပင်များ}} အရင်းအမြစ်သည် ပလန်သင်္ကေတ ပါသော အပင်ပေါင်း 400 ခန့်ကို စာရင်းပြုသည်။ [သင်္ကေတပြား](topic:symbol-palette) နှင့် [အပင် ထားခြင်း](topic:plant-list) ကို ကြည့်ပါ။

**ပိုက်၊ လေပိုက်နှင့် စွမ်းအင်**

- **Split၊ VRF နှင့် fan coil များ။** အတွင်းနှင့် အပြင်ယူနစ်များ၊ ၎င်းတို့၏ ချိတ်ဆက်မှုများနှင့်အတူ၊ line set များကို သင်ပြောင်းနိုင်သော ပုံမှန် ဥပမာတန်ဖိုး ဇယားမှ အရွယ်အစားချထားသည်။ [Split၊ VRF နှင့် fan coil များ](topic:split-vrf-fan-coils) ကို ကြည့်ပါ။
- **တွက်ချက်မှုများ။** Calculations ပန်နယ်သည် ရေပိုက်နှင့် လေပိုက် အရွယ်အစားများကို ဖိအားကျဆင်းမှုဖြင့် စစ်ဆေးပြီး ကေဘယ်များကို tray နှင့် conduit မှတစ်ဆင့် လမ်းကြောင်းဖြတ်ကာ ၎င်းတို့ ပြည့်နေမှုကို ပြသည်၊ IES သို့မဟုတ် EULUMDAT ဖိုင်များမှ illuminance ကို တွက်သည်။ မူလတန်ဖိုးများကို အညွှန်းထားသည်; သင့်ကုဒ်၏ တန်ဖိုးများကို ရိုက်ထည့်ပါ။ [ပိုက်၊ လေပိုက်၊ ကေဘယ်နှင့် အလင်းရောင် တွက်ချက်မှုများ](topic:mep-calculations) ကို ကြည့်ပါ။
- **PCF ဖိုင်များ။** Pipe ကိရိယာ၏ **Export PCF** သည် pipe-stress နှင့် isometric ပရိုဂရမ်များအတွက် run များကို ရေးသည်၊ နှင့် ပြန်ဖတ်သော PCF ဖိုင်သည် ၎င်း၏ ပိုက်ကို ဆွဲသည်။ [ပိုက် အစိတ်အပိုင်း ဖိုင်များ](topic:piping-pcf) ကို ကြည့်ပါ။
- **Solar PV။** အရောင်းလိုင်းများကို ခေါင်မိုး သို့မဟုတ် မြေပြင်ပေါ် တပ်ဆင်ပြီး မော်ဒယ်မှ အရိပ်ကျစေကာ နှစ်စဉ် စွမ်းအင်ကို ခန့်မှန်းပြီး strings စစ်ဆေးကာ one-line diagram ဒေတာ ပြုလုပ်သည်။ စတင်ရေးမှူးမော်ဂျူးနှင့် ဆုံးရှုံးမှုများသည် အထွေထွေ ဖြစ်သည်။ [Solar PV](topic:solar-pv) ကို ကြည့်ပါ။
- **EnergyPlus ဖိုင်။** Check with EnergyPlus ပန်နယ်သည် မော်ဒယ်ကို သင့်ကိုယ်ပိုင် EnergyPlus တွင် လည်ပတ်ရန် IDF အဖြစ် ရေးသည်။ browser တွင် လည်ပတ်ရန် သင် host လုပ်သော build နှင့် သင် ရိုက်ထည့်သော လိပ်စာ လိုအပ်သည်; BimCraft က ၎င်းကို မပါဝင်ပါ။ [EnergyPlus ဖြင့် အပူနှင့် အေးမှု စစ်ဆေးခြင်း](topic:check-with-energyplus) ကို ကြည့်ပါ။

**ပုံများနှင့် ဖိုင်များ**

- **Render engine ရွေးခြင်း။** {{ui:Render}} တွင် {{ui:Engine}} ရွေးချယ်မှု ရှိသည်။ ကျွန်ုပ်တို့၏ built-in engine နှစ်ခု (Fast နှင့် Path tracer) သည် မူလအတိုင်း ရှိနေဆဲ ဖြစ်သည်။ **Open in** သည် scene ကို USD သို့မဟုတ် glTF ဖိုင်အဖြစ် သိမ်းသည်၊ Unreal project folder ကို .zip အဖြစ် သိမ်းသည်; CadCraft Studio တွင် add-on တစ်ခုက engine ထည့်နိုင်သည်။ project ဖွင့်သော Unreal plug-in ကို မထုတ်ပြန်ရသေးပါ။ [ပုံကို မည်သည့် ပရိုဂရမ်က ဆွဲသလဲ ရွေးခြင်း](topic:render-engines) ကို ကြည့်ပါ။
- **Studio ပြန်ဖျက်ခြင်း။** CadCraft Studio အတွင်း BimCraft သည် ပြီးသော အဆင့်တိုင်းကို Studio သို့ ပြောပြသဖြင့် Studio က နောက်ဆုံး အသုံးပြုခဲ့သော ဝင်းဒိုးတွင် သင့်နောက်ဆုံး အဆင့်ကို ပြန်ဖျက်နိုင်သည်။ [Apps များကြား ပြန်ဖျက်ခြင်း](topic:undo-across-apps) ကို ကြည့်ပါ။
- **ဖိုင်ထဲရှိ add-on များ။** IFC သည် ဘယ် add-on များက ရေးခဲ့သည်ကို မှတ်ထားပြီး ဖွင့်သောအခါ သင်မရှိသော add-on များကို ကမ်းလှမ်းသည်။ [ဖိုင်ထဲရှိ add-on များ](topic:add-ons-in-your-file) ကို ကြည့်ပါ။

### 0.8.1 တွင် ပြင်ဆင်ပြီး

- **Ribbon + Project browser အပြင်အဆင်။** Insert › Import CAD၊ Insert › Image နှင့် Manage › Project Units တို့က "BimCraft တွင် မတည်ဆောက်ရသေးပါ" ဟု ပြခဲ့သည်။ Image သည် Picture ကိရိယာကို ဖွင့်သည်၊ Import CAD သည် {{ui:Build}} › {{ui:ဆွဲထားသော ပုံမှ…}} ကို ဖွင့်သည် (DWG၊ DXF၊ PDF သို့မဟုတ် scan)၊ Project Units သည် {{ui:ဆက်တင်များ}} › {{ui:Global}} › {{ui:ယူနစ်များ}} ကို ဖွင့်သည်။ Move နှင့် Align သည် Move နှင့် Align ကိရိယာများကို လည်ပတ်သည်၊ Level သည် {{ui:Add levels…}} ကို ဖွင့်သည်၊ Phases သည် Renovation phases အပိုင်းကို ဖွင့်ပြီး Materials သည် material စာကြည့်တိုက်ကို ဖွင့်သည်။
- **DWG class အပိုင်း။** အမျိုးအစား မှားစွာ ဖတ်ခံခဲ့ရသည်; BimCraft နှင့် DWG ကို ဖတ်သော အခြား app များတွင် ပြင်ဆင်ပြီးပြီ။

- **Archicad bundle script။** `archicad_bundle.py`၊ သီးခြား ဒေါင်းလုဒ်ဖြစ်သည်၊ ယခု Archicad ၏ လမ်းကြောင်းကို ရှာပြီး ဖိုင်တွဲကို စက္ကန့် 20 အထိ စောင့်ကြည့်ကာ bundle ဘေးတွင် ပြန်ကြိုးစားသည်။

### ဤဗားရှင်းတွင် မရှိသေးသော အရာများ

- **ဘေးကင်းရေးနှင့် ဒီဇိုင်း အကူအညီများ။** အဆောက်အအုံ ကုဒ်မှ ခရီးအကွာအဝေး ကန့်သတ်ချက် မရှိ (သင်က ကန့်သတ်ချက် ရိုက်ထည့်သည်) ပါ၊ အဆောက်အအုံထဲရှိ လူများသည် အမှန်ပလန်ပေါ်တွင် လက်ဖြင့် မစစ်ဆေးရသေးပါ။ အသံ၊ ဝန်ဆောင်ခ သက်တမ်းနှင့် အန္တရာယ် ကိန်းဂဏန်းများသည် စည်းမျဉ်း စစ်ဆေးချက် မဟုတ်ဘဲ စီစဉ်ရေး တန်ဖိုးများ ဖြစ်သည်။
- **ရာသီဥတု အနာဂတ်နှင့် EnergyPlus။** ရာသီဥတု အနာဂတ် built-in မရှိ: ရေလွှမ်းမှု run အတွက် scenario ဖိုင် တင်နိုင်သည်။ browser ရှိ EnergyPlus run သည် ဤထုတ်ဝေမှုတွင် မပါဝင်ပါ။
- **Ribbon အပြင်အဆင်။** Material Takeoff သည် "Not built" ဖြစ်ဆဲ ဖြစ်သည်၊ BimCraft တွင် material ပမာဏ စာရင်း မရှိသောကြောင့်၊ နောက်ထပ် ribbon ကိရိယာ 54 ခု မီးခိုးရောင် ဖြစ်ပြီး BimCraft ကိရိယာ နောက်ကွယ်တွင် မရှိသေးပါ။
- **လက်မှတ်ထိုးခြင်းနှင့် ပလက်ဖောင်းများ။** Windows installer များနှင့် macOS .dmg သည် လက်မှတ်မထိုးထားသောကြောင့် SmartScreen က {{ui:More info}} ကို ပြပြီးနောက် {{ui:Run anyway}} ကို ပြသည်၊ macOS တွင် right-click ပြီး {{ui:Open}} လိုအပ်သည်။ iPad နှင့် iPhone build ကို 0.8.1 အတွက် ပြန်မတည်ဆောက်ရသေးပါ။
- **Real-page စမ်းသပ်မှုများ။** BimCraft browser စမ်းသပ်မှု အချို့ဟောင်းများသည် ကျွန်ုပ်တို့၏ စမ်းသပ်စာမျက်နှာတွင် 0.8.1 မတိုင်မီကကဲ့သို့ ယခုလည်း ကျရှုံးဆဲ ဖြစ်သည်။

ကျန်အရာအားလုံးကို [မတည်ဆောက်ရသေးသောအရာများ](topic:not-built-yet) တွင် တွေ့ရသည်။ ယခင် ပြောင်းလဲမှုများကို [0.7 တွင် အသစ်ရှိသည်](topic:whats-new-0-7) တွင် တွေ့ရသည်။
