## ဘာလုပ်ရမလဲ

မော်ဒယ်ထဲတွင် အိမ်၏ လျှပ်စစ်ပလန်ကို ဆွဲပါ: နံရံပေါ်ရှိ အထွက်ပေါက်၊ ခလုတ်နှင့် ပြားများ၊ ခေါင်မိုးပေါ်ရှိ မီးများနှင့် အာရုံခံကိရိယာများ။ စက်ပစ္စည်းတိုင်းသည် IFC ဖိုင်ထဲရှိ လျှပ်စစ် element အစစ်ဖြစ်ပြီး ၎င်း၏ tag၊ circuit နှင့် load ပါဝင်သည်၊ ခလုတ်များသည် ၎င်းတို့ဖွင့်သော မီးများကို မှတ်ထားသည်။

## စက်ပစ္စည်းများ ထားရှိခြင်း

1. အလွှာတစ်ခုပေါ်တွင် {{ui:Build}} ကို ဖွင့်ပြီး {{ui:Electrical}} ကို ရွေးပါ။
2. စက်ပစ္စည်းကို ရွေးပါ: အထွက်ပေါက်များ (power, data, phone, audio-video), ခလုတ်နှင့် အာရုံခံကိရိယာများ (thermostat နှင့် timer အပါအဝင်), မီးများ၊ detector နှင့် alarm များ၊ junction box၊ panel သို့မဟုတ် sub-panel။
3. သိလျှင် **Circuit** ထဲတွင် ရိုက်ပါ (အမည်မည်သည့်ပုံစံမဆို၊ ဥပမာ 1, 2, A-3)။ **Mounting height** ကို ကွက်လပ်ထားလျှင် ထို စက်ပစ္စည်း၏ ပုံမှန်အမြင့်ကို သုံးမည်။
4. ပလန်ပေါ်တွင် နှိပ်ပါ။ အထွက်ပေါက်၊ ခလုတ်နှင့် ပြားများသည် အနီးဆုံးနံရံ၏ မျက်နှာပြင်ပေါ်တွင် အခန်းဘက်သို့ မျက်နှာမူ၍ ထားသည်။ မီး၊ အာရုံခံကိရိယာနှင့် junction box များသည် နှိပ်လိုက်သော နေရာ၏ ခေါင်မိုးပေါ်တွင် ထားသည်။

စက်ပစ္စည်းများကို ထားသည့်အခါ tag ပေးသည်: အထွက်ပေါက်များ **R**၊ ခလုတ်များ **S**၊ မီးများ **L**၊ လှုပ်ရှားမှု အာရုံခံကိရိယာများ **M**၊ junction box များ **J**၊ ပြားများ **P**။ နံရံပေါ်ရှိ စက်ပစ္စည်းများသည် နံရံကို ရွှေ့သောအခါ အတူရွှေ့သည်။

ပုံဖြင့် ကြည့်ရှုလိုပါက {{ui:Build}} မှ **Symbol palette** ကို ဖွင့်ပြီး အမည်ဖြင့် စက်ပစ္စည်းကို ရှာပါ၊ အသုံးများသည်များကို ကြယ်အမှတ်ပြုပြီး တစ်ချက်နှိပ်ဖြင့် ထားပါ: [The symbol palette](topic:symbol-palette) ကို ကြည့်ပါ။

## ခလုတ်များကို မီးများနှင့် ချိတ်ဆက်ခြင်း

1. ခလုတ် (သို့မဟုတ် လှုပ်ရှားမှု အာရုံခံကိရိယာ) ကို ရွေးပြီး **Properties** တွင် **Link lights** ကို နှိပ်ပါ။
2. ၎င်းဖွင့်သော မီးတစ်ခုစီကို နှိပ်ပါ။ ချိတ်ဆက်ပြီးသား မီးကို ထပ်နှိပ်လျှင် ချိတ်ဆက်မှု ပြတ်သည်။
3. {{key:Enter}} ကို နှိပ်ပါ သို့မဟုတ် **Done** ကို နှိပ်ပါ။

ပလန်သည် ခလုတ်မှ ၎င်း၏ မီးတစ်ခုစီသို့ အစက်ကွေးမျဉ်းကို ဆွဲပြသည်။ မီး၏ **Properties** တွင် ၎င်းကို ဖွင့်သော ခလုတ်များကို ပြသည်။

## စက်ပစ္စည်း ရှိနေသော အခန်း

စက်ပစ္စည်းတိုင်းသည် ၎င်း ရှိနေသော အခန်းကို သိသည်။ နံရံပေါ်ရှိ စက်ပစ္စည်းသည် မျက်နှာမူသော အခန်းတွင်၊ ခေါင်မိုးပေါ်ရှိ စက်ပစ္စည်းသည် အောက်ရှိ အခန်းတွင် ရှိသည်။ Properties တွင် **Room** ကို ပြပြီး **Electrical devices** ဇယားတွင် **Room** ကော်လံ (နံပါတ်နှင့် အမည်၊ ဥပမာ 101 မီးဖိုချောင်) ရှိသည်။

၎င်းကို အမြဲ update လုပ်သည်: အခန်းကို အမည်ပြောင်း သို့မဟုတ် နံပါတ်ပြောင်းလျှင်၊ စက်ပစ္စည်း သို့မဟုတ် နံရံကို ရွှေ့လျှင် အခန်းသည် တစ်ဆင့်တည်းဖြင့် လိုက်ပြောင်းသည်။ အဆောက်အအုံ၏ အပြင်ဘက် မျက်နှာပြင် သို့မဟုတ် အခန်းမဟုတ်သော နေရာရှိ စက်ပစ္စည်းသည် အခန်းတွင် မရှိဟု ပြသည်။

ထို့အပြင် အခန်းကို ဖိုင်ထဲ၌ စက်ပစ္စည်း၏ property set `CadCraft_Location` (Room, RoomNumber, RoomName) တွင်လည်း ရေးသည်၊ ထို့ကြောင့် Find, Color by property နှင့် tag ဇယားတို့က အသုံးပြုနိုင်ပြီး အခြား ပရိုဂရမ်များကလည်း အသုံးပြုနိုင်သည်။ ပလန် သင်္ကေတများနှင့် သင်္ကေတသို့ ချိတ်ထားသော element များသည် တူညီသော set ကို ရရှိသည်; [Symbol palette](topic:symbol-palette) ကို ကြည့်ပါ။

## အကူအညီပေးသူက ထားစေခြင်း

Settings › Assistants တွင် အကူအညီပေးသူကို ချိတ်ဆက်ထားလျှင် (ပြင်ဆင်ခွင့် ဖွင့်ထားရမည်)၊ စက်ပစ္စည်းများကို စကားဖြင့် တောင်းနိုင်သည်: "ဧည့်ခန်းနံရံများတလျှောက် 2 m တစ်ခုစီတွင် နှစ်ပေါက်ဆော့ကက်ထားပါ၊ 300 mm အမြင့်၊ circuit 3 ပေါ်တွင်" သို့မဟုတ် "တံခါးနားတွင် ခလုတ်နှင့်အတူ ခေါင်မိုးမီးတစ်ခု ထည့်ပါ"။ အကူအညီပေးသူသည် ကိရိယာ ငါးခုကို သုံးသည်: `devices_add`, `device_change`, `lights_set`, `devices_delete` နှင့် `devices_list`။ ၎င်းတို့သည် Electrical ကိရိယာ ဖန်တီးသော စက်ပစ္စည်းများကို တူညီသော နံရံများပေါ်တွင်၊ တူညီသော tag, circuit, load နှင့် အမြင့်များဖြင့် ဖန်တီးသည်၊ ခေါ်ဆိုမှု တစ်ခုစီသည် undo အဆင့်တစ်ခု ဖြစ်သည်။

စက်ပစ္စည်းသည် Electrical ကိရိယာတွင် မရှိသော အမျိုးအစားကို ဘယ်တော့မှ မရယူပါ: အမျိုးအစား မသိသည်ကို ပယ်ချပြီး အကူအညီပေးသူသို့ စာရင်းကို ပေးသည်။ အထွက်ပေါက် သို့မဟုတ် ခလုတ်သည် နံရံမျက်နှာမှ 600 mm အတွင်း ရှိရမည်၊ နှိပ်ခြင်းကဲ့သို့ပင်၊ မဟုတ်ပါက ခေါ်ဆိုမှုကို ပယ်ချပြီး ဘာမျှ မထားပါ။ မူလအမြင့်များသည် မီလီမီတာဖြစ်သည်: အထွက်ပေါက် 300၊ ခလုတ် 1100; ခေါင်မိုးပေါ်ရှိ စက်ပစ္စည်းသည် ခေါင်မိုးမှ ချိတ်ဆွဲထားသည်။

## ပြင်ဆင်ခြင်းနှင့် စာရင်းပြုခြင်း

စက်ပစ္စည်းကို ရွေး၍ tag, circuit, load (watts) နှင့် mounting height ကို ပြောင်းပါ။ အများအပြားကို ရွေးလျှင် circuit တစ်ခုတည်းတွင် တစ်ပြိုင်နက် ထားနိုင်သည်။ ဖယ်ရှားရန် {{key:Delete}} ကို နှိပ်ပါ; ဖျက်လိုက်သော မီးကို ၎င်း၏ ခလုတ်များမှ ဖယ်သည်။

{{ui:Schedules}} တွင် ပြည့်စုံသော စက်ပစ္စည်းတိုင်း၊ ၎င်း၏ အဆင့်၊ circuit၊ load၊ အမြင့်နှင့် ခလုတ်တစ်ခုစီ ဖွင့်သော မီးများကို ပြသော **Electrical devices** ကို ရွေးပါ၊ သို့မဟုတ် circuit တစ်ခုစီ၏ စက်ပစ္စည်း၊ load စုစုပေါင်းနှင့် current ကို ပြသော **Circuits** ကို ရွေးပါ။ နှစ်ခုစလုံးသည် ပုံဆွဲအစုံ၏ schedule sheet တွင်လည်း ရှိသည်: [Elevations, sections and sheets](topic:sheets) ကို ကြည့်ပါ။

:::note
အမြင့်များနှင့် load များသည် စီစဉ်မှု မူလတန်ဖိုးများ ဖြစ်သည် (အထွက်ပေါက် 16" အမြင့်နှင့် 200 W၊ ခလုတ် 48" တွင်၊ ခေါင်မိုးမီး 60 W)၊ ဒီဇိုင်း မဟုတ်ပါ: လျှပ်စစ်ဆရာ သို့မဟုတ် အင်ဂျင်နီယာက circuit များကို အရွယ်ချပြီး စည်းမျဉ်းကို စစ်ဆေးသည်။
:::

:::tip
သင်္ကေတများသည် CadCraft ၏ Electrical ထပ်ဆောင်းက တပ်ဆင်ပလန်များပေါ်တွင် ဆွဲသော သင်္ကေတများ ဖြစ်သောကြောင့် ထိုအက်ပ်နှစ်ခုမှ ပလန်တစ်ခုသည် တူညီစွာ ဖတ်ရသည်။
:::
