## လုပ်မည့်အရာ

ဖိုင်တစ်ခုကို ထည့်သွင်းပြီး မှန်ကန်သော အရွယ်အစားဖြင့် ဝင်လာကြောင်း သေချာစေပါ။

## အဆင့်များ

1. ပုံမှန်အတိုင်း ဖိုင်ကို ဖွင့်ပါ သို့မဟုတ် ထည့်ပါ: {{ui:Open}}၊ Library ၏ {{ui:Files}}၊ {{ui:Point clouds}}၊ သို့မဟုတ် Build › ပုံဆွဲမှ။
2. ဖိုင်က unit ကို ဖော်ပြထားလျှင် ဘာမျှ မမေးပါ။ အခြေအနေလိုင်းက ဖိုင်ဖော်ပြသော unit ကို ပြောပြသည်။
3. မဖော်ပြလျှင် ဒိုင်ယာလော့ဂ် တစ်ခုက ဖိုင်၏ **ဖိုင်၏ unit များ** ကို မေးသည်။ ဖိုင်ထဲရှိ unit တစ်ခုသည် ဘာဖြစ်သည်ကို ရွေးပြီး {{ui:Use these units}} ကို နှိပ်ပါ။ သင်မဖြေမီ ဘာမျှ မထားပါ။
4. {{ui:Cancel}} (သို့မဟုတ် {{key:Esc}}) က ဘာမျှ မထည့်ပါ။

## ဖိုင်အမျိုးအစားအလိုက် unit ဖော်ပြမှု

- **IFC**: length unit ကို ဖော်ပြပြီး "ဖွင့်ပြီး" တွင် မည်သည်ကို ဖော်ပြသည်ကို ပြသည်။ unit မဖော်ပြသော IFC ကို ဖွင့်မီ မေးမြန်းသည်; သင့်အဖြေကို မော်ဒယ်ထဲ ရေးထားပြီး သိမ်းသည့်အခါ ဖိုင်က တစ်ကြိမ်ဖော်ပြသည်။
- **DWG နှင့် DXF**: ပုံဆွဲ၏ insertion unit များ။ မပါသော ပုံဆွဲကို မေးမြန်းသည် (Library ဖိုင်များ၊ Build › ပုံဆွဲမှ၊ contour မှ မြေပြင်)။
- **မြေပြင်အတွက် အမှတ်စာရင်းများ**: unit မဖော်ပြပါ။ သင့်ကို မေးသည်။
- **အမှတ်တိမ်များ**: coordinate system ပါသော LAS နှင့် LAZ၊ E57၊ PTX နှင့် PLY တို့သည် ၎င်းတို့၏ unit ကို ဖော်ပြသည်။ အခြားများကို မေးသည်။
- **OBJ နှင့် STL**: unit ဘယ်တော့မှ မဖော်ပြပါ။ သင့်ကို မေးသည်။
- **glTF နှင့် GLB**: ဖော်မတ်၏ ကိုယ်ပိုင်စည်းမျဉ်းအရ မီတာ။
- **ပုံများ**: ကိုယ်ပိုင်အရွယ်အစား မရှိပါ။ ပုံကို view နှင့် ကိုက်ညီအောင် ချိန်ညှိသည်၊ သင်သည် **အမှတ်နှစ်ခုဖြင့် စကေးချိန်ညှိ** ဖြင့် အရွယ်အစားကို သတ်မှတ်ပါ။ ပေးသော အရွယ်အစားကို ထိုဖိုင်အတွက် မှတ်ထားသည်: ထပ်မံ ထည့်လျှင် ထိုအရွယ်အစားဖြင့် ဝင်လာပြီး အခြေအနေလိုင်းက ထိုသို့ ပြောပြသည်။
- **အမှတ်တိမ်များ ထပ်ဆောင်း**: coordinate မပါသော unit မပါသည့် ဖိုင်ဖြင့် cloud တည်ဆောက်သည့်အခါ မေးသည်၊ cloud ၏ ကိန်းဂဏန်းများကို ၎င်းသယ်ဆောင်သော unit ဖြင့် အညွှန်းတပ်သည်။

## သိထားသင့်သည်များ

- အဖြေကို ထိုဖိုင်အတွက် (အမည်၊ အရွယ်အစားနှင့် ရက်စွဲ) ဤကွန်ပျူတာပေါ်တွင်၊ CadCraft app အားလုံးတွင် မှတ်ထားသည်။ နောက်တစ်ကြိမ် တူညီသော ဖိုင် ဝင်လာသည့်အခါ သင့်ကို မမေးတော့ပါ၊ အခြေအနေလိုင်းက မှတ်ထားသော unit များကို သုံးကြောင်း ပြောပြသည်။
- ထပ်မံ မေးလိုလျှင်: command palette ({{key:Mod+K}}) › **ထည့်သွင်းထားသော ဖိုင်များ၏ unit ကို ထပ်မံမေးရန်**။
- import တွင် ရှိပြီးသား unit စာရင်း (Library ၏ Units၊ cloud bar ၏ Units၊ Build › ပုံဆွဲမှ တွင် ပုံဆွဲ unit) က ထည့်သွင်းပြီးနောက်တွင်လည်း unit ကို ပြောင်းသေးသည်။ မြေပြင် tool ၏ Units စာရင်းသည် ယခု မေးမြန်းမှု စတင်သော အချက်သာ ဖြစ်သည်။
