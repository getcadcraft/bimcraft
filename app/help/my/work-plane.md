## သင်လုပ်ရမည့်အရာ

သင်ဆွဲမည့် plane ကို ရွေးပါ၊ ၎င်းရှိနေရာကို ကြည့်ပါ၊ ထောင်ရပ်သော plane ပေါ်တွင် ဆွဲပါ။

## အဆင့်များ

1. **Draw** ကို ဖွင့်ပြီး **တည်ဆောက်ခြင်း** menu ကို ဖွင့်ပါ (ribbon layout တွင်: **ဗိသုကာ** tab၊ work plane)။
2. **work plane သတ်မှတ်ရန်** ကို ရွေးပါ။ ထို့နောက် အောက်ပါတို့ထဲမှ တစ်ခုကို လုပ်ပါ:
   - **သတ်မှတ်ရန်** တွင် အထပ်တစ်ခုကို ရွေးပါ;
   - ၎င်းဘေးရှိစာရင်းမှ အမည်ပေးထားသော reference plane တစ်ခုကို ရွေးပါ;
   - plan တွင် လိုင်းတစ်ခုကို နှိပ်ပါ: နံရံ၊ grid line၊ reference plane၊ model line သို့မဟုတ် curtain system။ work plane သည် ထိုလိုင်းမှတဆင့် ထောင်ရပ်သော plane ဖြစ်လာသည်;
   - 3D view ရှိ ပြားချပ်သော face တစ်ခုကို နှိပ်ပါ။ work plane သည် ထို face ပေါ်တွင် တည်ရှိသည်။
3. **work plane ပြရန်** ကို ရွေး၍ ကြည့်ပါ: 3D view တွင် မီတာ grid ပါသော အရောင်ခပ်ဖျော့ဖျော့ စာရွက်၊ plan တွင် အစက်အပြတ် outline သို့မဟုတ် လိုင်း၊ elevation နှင့် section panel တွင် အစက်အပြတ် outline။ ဖျောက်ရန် ထပ်ရွေးပါ။
4. **Work Plane Viewer** ကို ရွေး၍ plane ကို တည့်တည့် ကြည့်ပါ။ အနက်ရောင်လိုင်းများသည် plane က ဖြတ်ထားသော model ဖြစ်သည်။ ၎င်း၏ tools များဖြင့် plane ပေါ်တွင် model line၊ model text သို့မဟုတ် reference plane ဆွဲပါ။ **3D ဖြင့် ကြည့်ရန်** က 3D view ကို plane ဘက် မျက်နှာမူစေသည်။

## Reference planes

reference plane သည် လိုင်းအဖြစ် ဆွဲသော အမည်ပေးထားသော plane ဖြစ်သည်။

1. **Reference Plane** ကို ရွေးပါ။ လိုလျှင် ၎င်း၏ row တွင် အမည်ရိုက်ပါ (မဟုတ်လျှင် အမည်ကို သင့်အတွက် ပေးသည်) နှင့် အမြင့်။
2. စတင်သည့်နေရာနှင့် အဆုံးသတ်သည့်နေရာကို နှိပ်ပါ။ plan တွင် ၎င်းသည် ထောင်ရပ် plane ဖြစ်လာသည်။ Work Plane Viewer တွင် work plane နှင့် ထောင့်မှန်ရပ်သော plane ဖြစ်လာသည်။
3. plan တွင် အမည်ပါသော အစိမ်းရောင် အစက်အပြတ်လိုင်းအဖြစ်၊ 3D view နှင့် elevation နှင့် section panel တွင် အစက်အပြတ် outline အဖြစ် ပေါ်သည်။
4. ရွေး၍ အမည်ပြောင်းနိုင်သည်၊ အရှည်၊ အမြင့်နှင့် အောက်ခြေကို ပြောင်းနိုင်သည်၊ သို့မဟုတ် **work plane အဖြစ် အသုံးပြုရန်** ကို နှိပ်ပါ။

reference plane နှစ်ခုသည် တူညီသောအမည် မရှိနိုင်ပါ၊ အမည်ဖြင့်သာ ရွေးချယ်ရသောကြောင့် ဖြစ်သည်။

## သိထားသင့်သည်များ

- work plane မသတ်မှတ်ထားသော မော်ဒယ်သည် အနိမ့်ဆုံးအထပ်တွင် အလုပ်လုပ်သည်။
- work plane ကို ဖိုင်တွင် သိမ်းထားသည်။ ပြခြင်း သို့မဟုတ် ဖျောက်ခြင်းကို ဤ browser တွင် မှတ်ထားသည်၊ ဖိုင်ထဲတွင် မဟုတ်ပါ။
- work plane က reference plane ကို လိုက်နေပြီး ၎င်း plane ကို ရွှေ့လျှင် work plane လည်း အတူရွှေ့သည်။
- ထောင်ရပ် work plane ပေါ်တွင် Model Line နှင့် Model Text tools များသည် viewer ကို ဖွင့်သည်၊ အကြောင်းမှာ plan က အမြင့်ကို ညွှန်ပြနိုင်ခြင်း မရှိသောကြောင့်။
- drawing tools များသည် plan တွင် ဆွဲထားသော reference plane များ၏ ဆုံးနေရာများကို viewer တွင် အခြားလိုင်းများ၏ ဆုံးနေရာများကဲ့သို့ ဖမ်းယူသည်။

## IFC ဖိုင်တွင်

- work plane သည် project ပေါ်ရှိ property set (CadCraft_WorkPlane) ဖြစ်သည်။
- reference plane သည် object type ReferencePlane နှင့် အမည်ပါ IfcAnnotation ဖြစ်သည်။ ၎င်း၏ shape သည် plane ၏ ပိတ်ထားသော outline ဖြစ်သောကြောင့် အခြား program များက ၎င်းရှိနေရာကို ပြနိုင်သည်။ ၎င်း၏ set CadCraft_ReferencePlane တွင် origin၊ direction၊ normal နှင့် extent ရှိသည်။ IFC တွင် reference plane အတွက် class မရှိပါ; annotation ကို building element အဖြစ် မရေတွက်ပါ၊ rooms ကိုလည်း မကန့်သတ်ပါ။
