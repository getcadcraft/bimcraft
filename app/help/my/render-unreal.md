Studio တွင် Engine စာရင်းတွင် Unreal Engine project သို့ **ချိတ်ဆက်မှု** တစ်ခု ပါနိုင်သည်။ တစ်လမ်းသွားသာ: CadCraft မှ Unreal သို့သာ။

## ဇာတ်ကွင်းကို ပို့ရန်

1. Engine စာရင်းတွင် Unreal အရာကို ရွေးပါ။ ပထမအကြိမ်တွင် Studio က project ၏ folder (`.uproject` ဖိုင်ပါသော) ကို ရွေးရန် တောင်းဆိုသည်; ၎င်းက မှတ်ထားသည်။
2. {{ui:Send}} ကို နှိပ်ပါ။ Studio က project အတွင်း `CadCraft/<file name>/` ကို ရေးသည်: ဇာတ်ကွင်းကို USD ဖိုင်၊ ဆက်တင်ဖိုင်၊ light profile များနှင့် layer ဖိုင်ငယ် နှစ်ခု အဖြစ်။
3. မော်ဒယ်ကို ပြင်ပြီး သိမ်း၍ ပြန်ပို့ပါ။ ဇာတ်ကွင်းနှင့် ဆက်တင်ဖိုင်သာ အစားထိုးသည်။

## သင့်ကိုယ်ပိုင် ပြင်ဆင်မှုများ ဘေးကင်းသည်

Unreal ဖွင့်သော stage သည် တစ်ကြိမ်ဖန်တီးထားသော အမြစ် layer အသေးတစ်ခုဖြစ်ပြီး အောက်တွင် layer နှစ်ခုရှိသည်: အပေါ်ရှိ **သင့်ကိုယ်ပိုင်** (`<name>.user.usda`၊ အစတွင် ဗလာ၊ CadCraft က ဘယ်တော့မှ ပြန်မရေး) နှင့် အောက်ရှိ CadCraft ၏ ဇာတ်ကွင်း။ သင့် layer တွင် သိမ်းသော ပြင်ဆင်မှုများသည် ဇာတ်ကွင်းကို ပြန်ပို့သည့်အခါတွင်လည်း ကျန်နေသည်။ Unreal level တွင် သင်ထားသော မီးနှင့် အခြား actor များသည် stage အပြင်ဖြစ်ပြီး ၎င်းတို့ကိုလည်း မထိပါ။

## Studio မရှိဘဲ

ဝဘ်တွင်၊ သို့မဟုတ် Studio က Unreal ကို မတွေ့သော ကွန်ပျူတာတွင် Engine စာရင်းမှ **Unreal project folder (.zip)** ကို ရွေးပြီး {{ui:Render}} ကို နှိပ်ပါ။ ၎င်းသည် တူညီသော folder ကို zip အဖြစ် သိမ်းသည်: project ၏ `CadCraft` folder ထဲ unzip လုပ်ပါ။ ပထမအကြိမ်တွင် **stage ဖိုင်များ ပါဝင်စေရန်** ကို ဖွင့်ထားပါ; နောက်ပိုင်း သိမ်းတိုင်း ပိတ်ပါ၊ ထို့ကြောင့် zip တွင် ဇာတ်ကွင်းနှင့် ဆက်တင်ဖိုင်သာ ပါပြီး သင့် layer ကို ဘယ်တော့မှ အစားမထိုးပါ။

:::note
stage ကို ဖွင့်ပြီး နေ၊ မီးလုံး၊ ကင်မရာနှင့် exposure ကို အသုံးပြုကာ ပို့တိုင်းကို လိုက်ပြီး ကင်မရာကို render ပြုလုပ်သော Unreal plug-in ကို **၎င်း မထုတ်ပြန်သေးပါ** နှင့် Unreal တွင် မ run ရသေးပါ။ ထိုအချိန်အထိ Send သည် ဖိုင်များကို project ထဲ ထည့်ပေးပြီး Unreal ၏ ကိုယ်ပိုင် USD ကိရိယာများက ဖွင့်နိုင်သည်။ Windows က ပထမဆုံး စနစ်ဖြစ်ပြီး macOS က နောက်မှ လိုက်မည်။
:::
