## editor ဖွင့်ခြင်း

မိသားစုကို ဖွင့်ပါ (ပရောဂျက် browser ရှိ **Families** သို့မဟုတ် {{ui:Build}} › {{ui:Families…}}) ပြီး {{ui:Edit the family}} ကို နှိပ်ပါ။ အစမှ စရန် {{ui:New family}} ကို နှိပ်ပါ: အမည်ပေးပါ၊ ၎င်းက ဘာလဲ (တံခါး၊ ပြတင်းပေါက်၊ ပရိဘောဂ၊ တပ်ဆင်ပစ္စည်း သို့မဟုတ် အခြားတစ်ခု) ပြောပါ၊ တံခါး သို့မဟုတ် ပြတင်းပေါက်ဖြစ်လျှင် ၎င်း၏ ပလန် သင်္ကေတနှင့် လက်ကိုင်သည် မည်သည့် starter မှ လာမည်ကို ပြောပါ။ editor သည် parameter အနည်းငယ်နှင့် solid တစ်ခု ပါသော မိသားစုတစ်ခုဖြင့် ဖွင့်သည်။

starter မိသားစုကို တည်းဖြတ်လျှင် ပြောင်းလဲမှုကို ဤ model တွင်သာ ထားသည်။ အခြား model များသည် starter ကို မူလအတိုင်း ထားသည်။

{{ui:Save the family}} ကို နှိပ်မချင်း model တွင် ဘာမျှ မပြောင်းပါ။ editor တွင် ကိုယ်ပိုင် undo နှင့် redo ရှိသည် (အမည်ဘေးရှိ ခလုတ်များ၊ သို့မဟုတ် {{key:Mod+Z}} နှင့် {{key:Mod+Y}}); သိမ်းခြင်းသည် model ၏ undo တွင် အဆင့်တစ်ခု ဖြစ်သည်။

## ပါရာမီတာများ

{{ui:Parameters}} tab သည် မိသားစု၏ parameter များကို စာရင်းပြုသည်: အမည်၊ အမျိုးအစား နှင့် မူလတန်ဖိုး။ အမျိုးအစားများ: **Length** (မီလီမီတာ), **Angle** (ဒီဂရီ), **Number**, **Whole number**, **Yes / No**, **Pen** (1–16), နှင့် စကားလုံးများကို ကိုင်သော သုံးမျိုး: **Text**, **Material** (ပရောဂျက် material တစ်ခု) နှင့် **Fill** (plan fill)။ စကားလုံးများကို formula တွင် မသုံးပါ; ၎င်းတို့က solid တစ်ခု၏ အရောင် (၎င်း၏ **Material**) ပေးသည်၊ symbol အပိုင်းကို fill ဖြည့်သည်၊ သို့မဟုတ် symbol စာသားထဲတွင် `{Name}` အဖြစ် ပုံနှိပ်သည်။ **Per element** အကွက်က ထားသော element တစ်ခုစီက ကိုယ်ပိုင် သတ်မှတ်သော parameter ဖြစ်စေသည်၊ အရွယ်အစားမဟုတ်။

- **formula** သည် parameter တစ်ခုကို အခြားတစ်ခုအတိုင်း လိုက်စေသည်၊ ဥပမာ `Width / 30` သို့မဟုတ် `if(Width > 1200, 2, 1)`။ formula ထဲ အရှည်များသည် မီလီမီတာ ဖြစ်သည်၊ သို့မဟုတ် unit ရေးပါ: `3'`, `6in`, `50cm`။
- parameter ကို အမည်ပြောင်းလျှင် formula နှင့် field တိုင်းတွင် ထို့အတိုင်း ပြောင်းသည်။ အသုံးပြုနေဆဲ parameter ကို ဖယ်၍ မရပါ။
- solid ၏ **Material** သည် ပရောဂျက် material ၏ အရောင် (သို့မဟုတ် Material parameter ၏) ကို ယူသည်၊ **Shown at** သည် ပိုကြမ်းသော အသေးစိတ်အဆင့်များတွင် ဝှက်သည်၊ **Repeat** က မိတ္တူများ ပြုလုပ်သည်: အရေအတွက် (နံပါတ် သို့မဟုတ် whole-number parameter, 1 မှ 200) နှင့် x, y, z တွင် ၎င်းတို့ကြား အဆင့်။ ထပ်ခါတလဲ solid သည် ဘုတ်၊ ဘား သို့မဟုတ် အပေါက်များ အတန်းတစ်ခု ဖြစ်သည်; cut တွင် သုံးလျှင် မိတ္တူများ အတူ ဖြတ်သည်။
- တံခါး သို့မဟုတ် ပြတင်းပေါက် မိသားစုသည် ၎င်း၏ နံရံမှ အမည် နှစ်ခု ထပ်ရသည်: `WallThickness` နှင့် `Face` (1 သို့မဟုတ် −1, တံခါး ပွင့်သော ဘက်)။

## Solid များ

{{ui:Solids}} tab က solid များကို စာရင်းပြုသည်။ box, extrusion, revolve သို့မဟုတ် sweep ထည့်ပါ:

| Solid | သတ်မှတ်သည့်အရာ |
|---|---|
| Box | ထောင့်နှစ်ခု: x0 မှ x1, y0 မှ y1, z0 မှ z1 |
| Extrusion | work plane (plan, front သို့မဟုတ် side) ပေါ်ရှိ profile၊ plane ၏ နေရာနှင့် depth |
| Revolve | profile၊ plane ပေါ်ရှိ axis နှင့် 360° အထိ angle |
| Sweep | point များ၏ path နှင့် radius (တုတ် သို့မဟုတ် ရေလား) |

ဂဏန်းတိုင်းသည် ရိုက်ထားသော နံပါတ် သို့မဟုတ် parameter များ၏ expression ဖြစ်နိုင်သည်။ solid တိုင်းတွင် အရောင်နှင့် **Shown when** ရှိသည်: အလွတ်ထားလျှင် အမြဲပြသည်၊ သို့မဟုတ် Yes / No parameter တစ်ခု (သို့မဟုတ် `Shelves >= 3` ကဲ့သို့ နှိုင်းယှဉ်ချက်) ကို အမည်ပေးလျှင် ထိုအချိန်တွင်သာ ပြသည်။ ၎င်းသည် visibility parameter ဖြစ်သည်။

### Profile ဆွဲခြင်း

extrusion သို့မဟုတ် revolve ၏ profile ကို preview အောက်ရှိ work plane ပေါ်တွင် ဆွဲသည်:

- စက္ကူပေါ်တွင် နှိပ်၍ ရွေးထားသော point ၏ နောက်တွင် point ထည့်ပါ။
- point ကို ဆွဲ၍ ရွှေ့ပါ။ point များသည် grid သို့ ကပ်သည်; {{key:Shift}} ကိုင်ထားလျှင် လွတ်လပ်စွာ နေရာချသည်။
- segment ပေါ်ရှိ အကွက်ငယ်လေးကို နှိပ်ပြီး ထိုနေရာတွင် point ထည့်ပါ။ {{key:Shift}}+နှိပ်ခြင်းဖြင့် ထို segment ကို arc ဖြစ်စေသည် (ထပ်နှိပ်လျှင် တခြားဘက်၊ ထို့နောက် straight)။
- point ကို နှစ်ချက်နှိပ်ပါက ဖယ်သည်။

အပေါက်ဖြစ်သော point များကို parameter များဖြင့် သတ်မှတ်ထားသည်: ၎င်းတို့ကို ဆွဲ၍ မဟုတ်ဘဲ table တွင် ပြောင်းပါ။

## Boolean များ

{{ui:Booleans}} tab က ဒုတိယ solid ကို ပထမ၏ အတွင်းမှ ဖြတ်ထုတ်သည်၊ သို့မဟုတ် ပေါင်းသည်။ Boolean ၏ ရလဒ်ကို ထပ်မံ ဖြတ်နိုင်သည် သို့မဟုတ် ပေါင်းနိုင်သည်။ Boolean တွင် သုံးသော solid သည် ၎င်း၏ အစိတ်အပိုင်းအဖြစ်သာ ဆွဲသည်။

ဒုတိယ solid ကို ၎င်း၏ Yes / No parameter က ဝှက်ထားလျှင် ပထမကို ထိန်းထားသည်; ပထမ ဝှက်ထားလျှင် ရလဒ် ဝှက်သည်။

## ပလန် သင်္ကေတ

{{ui:Plan symbol}} tab သည် solid များ၏ ဖြတ်ပိုင်းအစား ပလန်တွင် ဤမိသားစုအတွက် ပြသမည့်အရာကို ဆွဲသည်: မျဉ်း၊ ထောင့်မှန်၊ စက်ဝိုင်း၊ arc၊ polygon နှင့် စာသား၊ မိသားစု၏ ကိုယ်ပိုင် axes တွင်။ အပိုင်းတစ်ခုစီတွင် **pen** (1–16၊ expression သို့မဟုတ် Pen parameter), **fill** (none, solid, diagonal, crossed, concrete, insulation, earth သို့မဟုတ် Fill parameter), **shown by** expression, base အထက် မီလီမီတာဖြင့် **cut range** (ပလန်၏ ဖြတ်ချက် ၎င်းအတွင်း ရှိလျှင် အပြည့်အလေးဖြင့်၊ အောက်တွင် ပါးလျား၊ အထက်တွင် dashed: ဖြတ်ချက်အထက်ရှိ ဗီရို dashed ပြသည်), detail level နှင့် repeat ရှိသည်။ စာသားက parameter များကို `{Name}` ဖြင့် ညွှန်းနိုင်သည်။ **The plan shows: The cut of the solids** က symbol ကို မိသားစုတွင် ထားစဉ် ပလန်က solid များ ဖြတ်ပြသည်ကို ထိန်းသည်။ အခြား ပရိုဂရမ်များက symbol ကို မိသားစု၏ footprint (မျဉ်းနှင့် ပုံသဏ္ဍာန်များ; စာသားသည် BimCraft တွင်သာ) အဖြစ် ဖတ်သည်။

## အတွင်းရှိ မိသားစုများ

{{ui:Families inside}} tab သည် အခြားမိသားစုကို ဤမိသားစု၏ အတွင်းသို့ ထည့်သည်: စားပွဲတွင် ခြေထောက်၊ တံခါးတွင် လက်ကိုင်။ မိသားစုကို ရွေးပါ၊ ထို့နောက် နေရာ (x, y, z)၊ ဘယ်လောက် လှည့်မည် (လေးပုံတစ်ပုံ လှည့်ချက်သာ: 0, 90, 180, 270)၊ ဘယ်အချိန် ပြမည်နှင့် ရရှိမည့် တန်ဖိုးများ (တစ်ကြောင်း တစ်ခု `Height = Height - 40`)။ အတွင်းမိသားစုကို သိမ်းလျှင် ဤမိသားစုကို ထပ်ဆွဲသည်; အခြားက ထိန်းထားသော မိသားစုကို ဖျက်၍ မရပါ; မိသားစုသည် ကိုယ်ကိုယ်တိုင် မထိန်းနိုင်ပါ၊ အခြားတစ်ခုမှ တစ်ဆင့်လည်း မရပါ၊ အဆင့် လေးဆင့်အထိသာ ထိန်းသည်။

## Hotspot များ

hotspot သည် parameter ပြောင်းရန် ဆွဲသော point သို့မဟုတ် edge ဖြစ်သည်။ {{ui:Hotspots}} tab တွင် တစ်ခု ထည့်ပြီး ဆွဲသော axis နှင့် ပြောင်းသော နံပါတ် parameter ကို ရွေးပါ၊ ၎င်း၏ နေရာကို solid များနှင့် တူသော expression ဖြင့် ရေးပါ။ preview တွင် handle များအောက်ရှိ **Hotspots** ကို ရွေး၍ ဆွဲပါ။ ပလန်ပေါ်ရှိ ထားပြီး element တစ်ခု (ရွေးရန် {{ui:Select}}) ၌ x နှင့် y hotspot များသည် grip အဖြစ် ပြသည်: တစ်ခုကို ဆွဲလျှင် element သည် hotspot ကို ထိုနေရာသို့ ရောက်စေသော အရွယ်အစားကို ယူသည်၊ ၎င်းတို့ကြား formula များ မှတစ်ဆင့်; Undo တစ်ကြိမ်ဖြင့် ပြန်ထားသည်။ hotspot သည် driven parameter, Yes / No သို့မဟုတ် စကားလုံးကို ပြောင်းနိုင်မည် မဟုတ်ပါ။

3D view တွင် တူညီသော hotspot များသည် ရွေးထားသော element ပေါ်တွင် grip အဖြစ် ပြသည်၊ ထို့အပြင် အပေါ်-အောက် (axis z) များလည်း ပြသည်၊ ပလန်က ဆွဲ၍ မရသောကြောင့်။ element ကို ရွေး၊ grip ကို axis တလျှောက် ဆွဲ၍ လွှတ်ပါ: element သည် hotspot ကို ထိုနေရာသို့ ရောက်စေသော အရွယ်အစားကို ယူသည်၊ undo တစ်ဆင့်တည်း။ section box ဖွင့်နေချိန်တွင် grip များကို ဝှက်သည်၊ ၎င်းက တူညီသော grip ကို သုံးသောကြောင့်။

## ချိတ်ဆက်ကိရိယာများ

ကြမ်းပြင်ပေါ် ထားသော မိသားစုများ (ပရိဘောဂ၊ တပ်ဆင်ပစ္စည်းနှင့် အခြား) တွင် {{ui:Connectors}} tab ရှိသည်: ပိုက် သို့မဟုတ် duct ချိတ်ဆက်သော အမှတ်များ၊ ရေဆေးဝန်၏ ရေကြောင်းနှင့် ရေထုတ်ကဲ့သို့။ {{ui:Add a connector}} ကို နှိပ်ပြီး သတ်မှတ်ပါ:

- **Kind**: pipe သို့မဟုတ် duct နှင့် ၎င်း၏ **System** (cold water, sanitary drain, supply air…)။
- **x**, **y** နှင့် **z**: နေရာ၊ မိသားစု၏ ကိုယ်ပိုင် axes တွင်။ solid ၏ နံပါတ်များကဲ့သို့ တစ်ခုစီသည် နံပါတ် သို့မဟုတ် parameter formula ဖြစ်နိုင်သည်၊ ထို့ကြောင့် connector သည် အရွယ်အစားနှင့်အတူ ရွှေ့သည်။
- **Way out**: ပိုက် သို့မဟုတ် duct ထွက်သော ဦးတည်ချက်၊ မိသားစု၏ axis တစ်ခုတလျှောက် (ရေဆေးဝန်အောက်ရှိ ရေထုတ်သည် **Down** ဖြစ်သည်)။
- **Size (mm)**: ပိုက်၏ nominal အရွယ် (DN) သို့မဟုတ် စက်ဝိုင်း duct ၏ အချင်း။
- **Flow**: **In** သည် ထည့်ပေးသော connector (ရေကြောင်း), **Out** သည် ရေစွန့်သော connector။

Preview က connector တစ်ခုစီကို ring နှင့် ထွက်သည့်ဘက်ကို မြားဖြင့် ဆွဲပြသည်။ တံခါးနှင့် ပြတင်းပေါက်တွင် connector မရှိပါ။

ရေပိုက်ပစ္စည်းအတွက် **Plumbing fixture** အောက်တွင် ၎င်းသည် ဘာလဲ ရွေးပါ (water closet, lavatory, kitchen sink, shower, laundry tub)။ starter ပစ္စည်းများက ထိုသို့ ပြောပြီးသား ဖြစ်သည်။

မိသားစုမှ ထားသော element တိုင်းသည် ၎င်း၏ connector များကို IFC ဖိုင်တွင် port များအဖြစ် ရရှိပြီး element အရွယ် ပြောင်းလျှင် သို့မဟုတ် မိသားစုကို သိမ်းလျှင် ပြန်ဖန်တီးသည်။ IFC system ကို ဖတ်သော ပရိုဂရမ်များက ပိုက် သို့မဟုတ် duct တစ်ခုစီ ဘယ်နေရာ သက်ဆိုင်သည်ကို မြင်သည်။

## Preview နှင့် ၎င်း၏ handle များ

preview သည် မိသားစုကို IFC အဖြစ် ရေးထားသော ပုံဖြစ်ပြီး model ထဲ သိမ်းသည့် ကုဒ်တူဖြင့် ပြန်ဆွဲသည်။ သင်မြင်သည်မှာ အခြား ပရိုဂရမ်များ ရသည်နှင့် တူသည်။ ၎င်းအောက်တွင် **Size shown** က preview သုံးသော parameter တန်ဖိုးများကို သတ်မှတ်သည်။

**Handles** သည် preview ပေါ်ရှိ အစက်များ: **The size** သည် Width, Depth နှင့် Height အတွက် handle ပြသည်; **The solid picked** သည် ရွေးထားသော solid ၏ မျက်နှာတစ်ခုစီအတွက် တစ်ခု ပြသည်။ handle ကို ဆွဲပါ:

- parameter က သတ်မှတ်သော မျက်နှာပေါ်တွင်၊ ပြသော အရွယ်အစား ပြောင်းသည် (မိသားစု၏ formula များ ထိန်းသည်)။
- ရိုက်ထားသော နံပါတ်က သတ်မှတ်သော မျက်နှာပေါ်တွင်၊ နံပါတ် ပြောင်းသည်။

## သိမ်းခြင်း

{{ui:Save the family}} သည် မိသားစုကို စစ်ဆေးပြီး အရွယ်အစားတိုင်းကို ပြန်ဆွဲကာ element တိုင်းကို ပြန်ဖန်တီးသည်၊ undo လုပ်နိုင်သော အဆင့်တစ်ခုအဖြစ်။ အရွယ်အစားတစ်ခုကို ပြောင်းလဲမှုဖြင့် ဆွဲ၍ မရလျှင် (ဥပမာ solid တစ်ခု၏ width သုညဖြစ်သွားလျှင်) ဘာမျှ မသိမ်းဘဲ editor က အရွယ်အစားကို ပြောသည်။

editor ဖွင့်နေစဉ် တစ်ယောက်ယောက်က တူညီသော မိသားစုကို သိမ်းလျှင် (Live TeamWork session တွင် သို့မဟုတ် အခြား window တွင်)၊ {{ui:Save the family}} သည် ငြင်းပြီး ထိုသို့ ပြောသည်၊ သင့်ပြောင်းလဲမှုဖြင့် ၎င်းတို့၏ ပြောင်းလဲမှုကို အစားမထိုးပါ။ editor ကို ပိတ်ပြီး မိသားစုကို ထပ်ဖွင့်၍ ၎င်းတို့၏ ပြောင်းလဲမှုကို ကြည့်ပြီး သင့်ပြောင်းလဲမှုကို ပြန်လုပ်ပါ။

:::note
ပုံသဏ္ဍာန်ကို IFC ၏ ကိုယ်ပိုင် solid များအဖြစ် သိမ်းသည်: extrusion, revolve, swept disk နှင့် Boolean ရလဒ်များ။ triangle စာရင်းအဖြစ် ဘာမျှ မပြောင်းပါ၊ ထို့ကြောင့် ဖိုင်များ ငယ်ပြီး အခြား ပရိုဂရမ်များက ပုံသဏ္ဍာန်များကို ပုံသဏ္ဍာန်အဖြစ် ဖတ်နိုင်သည်။ arc ပါသော profile များကို IFC4 တွင် arc ဖြင့် သိမ်းသည်; IFC2X3 တွင် profile တွင် arc အပိုင်း မရှိသောကြောင့် ထိုနေရာတွင် arc များကို တိုတိုသော မျဉ်းပိုင်းများအဖြစ် သိမ်းသည်။
:::
