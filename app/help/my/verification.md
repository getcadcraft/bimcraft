## လုပ်မည့်အရာ

မော်ဒယ်တွင် တစ်စုံတစ်ဦးက တကယ်ကြည့်ခဲ့သည့်အရာကို ခြေရာခံပါ။ element တစ်ခုတွင် အမှတ်အသား သုံးမျိုးထဲမှ တစ်ခု သို့မဟုတ် မရှိပါ:

- **အတည်မပြုရသေး**: program က PDF၊ စကင်ဖတ်ထားသော ပုံဆွဲ၊ ခြေရာခံထားသော ပုံဆွဲ သို့မဟုတ် အမှတ်တိမ် စကင်မှ အသိအမှတ်ပြုခဲ့သည်။ ဘယ်သူမျှ မစစ်ဆေးရသေးပါ။
- **စစ်ဆေးပြီး**: တစ်ဦးက ၎င်း ထွက်လာသော ပုံဆွဲနှင့် နှိုင်းယှဉ်ခဲ့သည်။
- **ဆိုဒ်တွင် အတည်ပြုပြီး (LOD 500)**: တစ်ဦးက ဆိုဒ်တွင် တိုင်းတာခဲ့သည်။ ဘယ်သူ၊ ဘယ်အချိန်နှင့် ဘယ်နည်းဖြင့် ၎င်းနှင့်အတူ သိမ်းထားသည်။
- **အမှတ်အသားမရှိ**: လူတစ်ဦးက ဆွဲထားသည်။ မော်ဒယ်က ၎င်းအပေါ် ဘာမျှ အခိုင်အမာ မပြောပါ။

## အဆင့်များ

1. element တစ်ခု သို့မဟုတ် အများအပြား ရွေးပါ (နံရံများ၊ တံခါးများ၊ ပြတင်းပေါက်များ၊ အခန်းများ၊ မည်သည့် element မဆို)။
2. {{ui:Properties}} တွင် {{ui:Verification}} ကို ဖွင့်ပါ။
3. စစ်ဆေးသူ သို့မဟုတ် တိုင်းတာသူ၏ အမည်ကို ရိုက်ထည့်ပါ။ ရက်စွဲကို သင်ပြောင်းသည်အထိ ယနေ့ဖြစ်သည်။
4. {{ui:Mark as checked}} ကို နှိပ်ပါ။ ဆိုဒ်တိုင်းတာမှုအတွက် တိုင်းတာပုံကို ရွေးပါ (တိပ်တိုင်း၊ လေဆာအကွာအဝေးတိုင်းကိရိယာ၊ စကင်၊ စရင်းကောက်ယူမှု) ပြီးလျှင် {{ui:Mark as field-verified (LOD 500)}} ကို နှိပ်ပါ။
5. {{ui:Mark as unverified}} နှင့် {{ui:Take the mark off}} က နောက်သို့ ပြန်ထားသည်။ နှိပ်သည့်အကြိမ်တိုင်းသည် ရွေးထားသော အစုတစ်ခုလုံးအတွက် ပြန်ဖျက်နိုင်သော အဆင့်တစ်ခု ဖြစ်သည်။

ရွေးချယ်မှုကို အမြန်အမှတ်အသားပြုရန်: {{ui:Tools}} › {{ui:Mark as checked}} (ရိုက်ထည့်ပါက `MARKCHECKED`) သည် ယနေ့ သင်က စစ်ဆေးပြီးအဖြစ် အမှတ်အသားပြုသည်။

## မြင်ရမည့်အရာများ

- plan တွင် အတည်မပြုရသေးသော element တွင် မျဉ်းထိုးဘောက်စ်နှင့် "?" ရှိသည်; ဆိုဒ်အတည်ပြုပြီးသော element တွင် အမှန်အမှတ် ရှိသည်။ {{ui:Audit}} အပိုင်းရှိ {{ui:Show verification marks in the plan}} ကို ဖြုတ်လိုက်လျှင် ၎င်းတို့ကို ဖျောက်နိုင်သည်။
- {{ui:Schedules}} › {{ui:Verification}} သည် အမှတ်အသားပြုထားသော element အားလုံးကို level၊ state၊ ဘယ်သူ၊ ဘယ်အချိန်၊ ဘယ်နည်း နှင့် မည်သည့်နေရာမှ ရလာသည်ဖြင့် စာရင်းပြုသည်။
- audit သည် အတည်မပြုရသေးသော element များကို စာရင်းပြုပြီး ဆိုဒ်အတည်ပြုပြီး element ကို LOD 500 အဖြစ် ရေတွက်သည်။ See [မော်ဒယ်ကို စစ်ဆေးခြင်း](topic:audit-the-model)။

## စကင်မှ

စကင်နှင့် မော်ဒယ်ကို နှိုင်းယှဉ်သောအခါ၊ {{ui:Mark the matching elements as field-verified}} သည် စကင်က တည်ဆောက်ပြီးအဖြစ် မြင်ခဲ့သော element တိုင်းကို အကျွန်းအတွင်း၊ နည်းလမ်း "scan" နှင့် မှတ်ချက်တွင် အကျွန်းကို ထည့်၍ အမှတ်အသားပြုသည်။ See [စကင်ကို မော်ဒယ်နှင့် နှိုင်းယှဉ်ခြင်း](topic:compare-scan-with-model)။

:::warning
ထိုနှိုင်းယှဉ်မှုသည် element တစ်ခုစီ၏ ဘောက်စ်ကို စကင်အမှတ်များနှင့် ကိုက်ညီစေသည်။ ၎င်းသည် စရင်းကောက်ယူမှု မဟုတ်ပါ။ သင်ကိုယ်တိုင်လည်း ကြည့်ခဲ့သော element များအတွက်သာ အသုံးပြုပါ။
:::

## တည်ဆောက်ပြီးနောက် မော်ဒယ်နှင့် လွှဲပြောင်းရေး ပက်ကေ့ချ်

{{ui:Assets}} tab ရှိ {{ui:Build the handover package}} သည် တည်ဆောက်ပြီးနောက် မော်ဒယ်ကို zip ထဲတွင် အောက်ပါအတိုင်း ထည့်သည်:

- ပရောဂျက်ပေါ်တွင် ဆိုဒ်အတည်ပြုပြီး၊ စစ်ဆေးပြီး၊ အတည်မပြုရသေးသော နှင့် အမှတ်အသားမရှိသော element မည်မျှရှိကြောင်း ထုတ်ပြန်ချက်;
- `as-built/verified-elements.csv`: element နှင့် အခန်းတိုင်း ၎င်း၏ state၊ ဘယ်သူ၊ ဘယ်အချိန်၊ ဘယ်နည်း;
- `as-built/as-built-drawings.pdf`: ယခုအခြေအနေအတိုင်း ပုံဆွဲအစု;
- မော်ဒယ်တွင် ထုတ်ပြန်ထားသော အစုများ ရှိသောအခါ ပုံဆွဲ changelog။

See [ပိုင်ဆိုင်မှုများနှင့် ပြုပြင်ထိန်းသိမ်းမှု](topic:assets-and-maintenance)။

## IFC တွင် မည်သို့ သိမ်းထားသနည်း

အမှတ်အသားပြုထားသော element တိုင်းတွင် ဂုဏ်သတ္တိအစု `CadCraft_Verification` ပါသည်: State၊ By၊ On၊ Method၊ Source၊ Note နှင့် LevelOfDevelopment (ဆိုဒ်အတည်ပြုစဉ် `LOD 500`)။ ၎င်းတို့သည် ရိုးရိုးစာသား ဂုဏ်သတ္တိများ ဖြစ်သဖြင့် အခြား programs များက စာရင်းပြုနိုင်ပြီး ရှာရန်၊ ဂုဏ်သတ္တိအလိုက် အရောင်ခြယ်ခြင်းနှင့် tag ဇယားများက သုံးနိုင်သည်။ တည်ဆောက်ပြီးနောက် ထုတ်ပြန်ချက်သည် ပရောဂျက်ပေါ်ရှိ ဂုဏ်သတ္တိအစု `CadCraft_AsBuilt` ဖြစ်သည်။ အစုမပါသော element ကို ဆိုဒ်တွင် မတိုင်းတာခဲ့ပါ။
