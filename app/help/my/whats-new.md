ဤသည်မှာ BimCraft 0.8.1 နှင့် နှိုင်းယှဉ်လျှင် 0.9 တွင် ပြောင်းလဲသွားသည်များ ဖြစ်သည်။ အဓိက အကြောင်းအရာ နှစ်ခုမှာ အစစ်အမှန် နံရံ tool တစ်ခုနှင့် ကြီးမားသော BIM ပရိုဂရမ်များမှ လူများ မျှော်လင့်သော ပုံစံဖြင့် အလုပ်လုပ်သော view များ ဖြစ်သည်။ ၎င်းတို့အပြင် Collada ထုတ်ခြင်း၊ လျှပ်စစ် ပစ္စည်းများ နေရာချနိုင်သော assistant များ၊ Scan to BIM နှင့် {{ui:Analysis}} tab ရှိ လေ၊ ငလျင်နှင့် finite-element လုပ်ဆောင်ချက်များ ပါဝင်သည်။

## အသစ်များ

### နံရံများ

- **တစ်ခုလုံးသော ပုံသဏ္ဍာန်များ ဆွဲရန်။** {{ui:Draw}} တွင် {{ui:Shapes}} ကို ဖွင့်ပါ (သို့မဟုတ် Wall အတန်း၏ Shape စာရင်းတွင် ပုံသဏ္ဍာန် တစ်ခု ရွေးပါ): စတုဂ္ဂံ၊ လှည့်ထားသော စတုဂ္ဂံ၊ ဘေး 3 မှ 64 ရှိ ပိုလီဂွန်၊ ဗဟိုဖြင့် arc၊ tangent arc၊ ရွေးထားသော မျဉ်းများပေါ်ရှိ နံရံများ၊ သို့မဟုတ် သင်နှိပ်သော ပိတ်ထားသော နယ်ပယ်တစ်ခုပတ်လည် နံရံများ။ စတုဂ္ဂံသည် ထောင့်ဆက် လေးခုပါသော နံရံ လေးခုဖြစ်ပြီး undo အဆင့် တစ်ခုဖြစ်သည်။ [နံရံ ပုံသဏ္ဍာန်များ၊ ခွဲခြင်း၊ offset၊ stretch နှင့် lock](topic:wall-tools) ကို ကြည့်ပါ။
- **ဆွဲမီ သတ်မှတ်ပြီး ဆွဲပြီးနောက် ပြောင်းပါ။** Wall အတန်းတွင် {{ui:Offset}} နှင့် {{ui:Join}} ရှိသည် (ချိတ်ဆက်မှု မရှိသော နံရံများ ဆွဲရန် ဖြုတ်ပါ)။ နောက်ပိုင်း ဆွဲထားသော နံရံများပေါ်တွင် {{ui:Offset}}၊ {{ui:Box stretch}} နှင့် {{ui:Align and lock}} ကို သုံးပါ။ ရွှေ့ထားသော သို့မဟုတ် stretch လုပ်ထားသော နံရံသည် ၎င်း၏ တံခါး၊ ပြတင်းပေါက်နှင့် အတိုင်းအတာများကို ထိန်းသည်။ ချက်တိုင်းသည် undo အဆင့် တစ်ခု။
- **နံရံ ဖြတ်ခြင်း။** {{ui:Split}}၊ {{ui:Gap}}၊ {{ui:Free ends}}၊ {{ui:Delete segment}} နှင့် {{ui:Rejoin}} တို့သည် နှိပ်ချက် သို့မဟုတ် အခြားနံရံ ဖြတ်ကျော်သော နေရာတွင် နံရံကို ဖြတ်သည်။ တံခါးကို ဖြတ်ခြင်းကို ငြင်းပယ်သည်။ [နံရံ ပုံသဏ္ဍာန်များ၊ ခွဲခြင်း၊ offset၊ stretch နှင့် lock](topic:wall-tools) ကို ကြည့်ပါ။
- **နံရံများကို grid မျဉ်းများသို့ lock ချခြင်း။** Grid မျဉ်းတစ်လျှောက် နံရံကို ရွေးပြီး {{ui:Properties}} တွင် {{ui:Lock to grid}} ကို အမှန်ခြစ်ပါ။ Grid tool ဖွင့်ထားစဉ် ရွေးထားသော မျဉ်းအတွက် {{ui:Move by}} တွင် အကွာအဝေး ရိုက်ထည့်ပါ၊ lock ချထားသော နံရံများ လိုက်လာမည်၊ undo အဆင့် တစ်ခုတည်းဖြင့်။
- **နံရံ တစ်ခု၏ ပုံသဏ္ဍာန်။** နံရံ တစ်ခု၏ {{ui:Properties}} တွင် ၎င်း၏ထိပ် သို့မဟုတ် အောက်ခြေကို အမိုး၊ ကြမ်းပြင် သို့မဟုတ် ခုံးသို့ ချိတ်နိုင်သည်၊ ၎င်း၏ elevation outline ကို တည်းဖြတ်နိုင်သည်၊ စောင်းနိုင်သည်၊ သို့မဟုတ် တံခါး သို့မဟုတ် ပြတင်းပေါက် မပါဘဲ နံရံအပေါက် ဖောက်နိုင်သည်။ [နံရံ ပုံသဏ္ဍာန်](topic:wall-shape) ကို ကြည့်ပါ။
- **အရှည်က မည်သည့် အဆုံး ကိုင်ထားသည်ကို ပြသည်။** {{ui:Grow from}} သည် အရှည် ပြောင်းသည့်အခါ အစ၊ အဆုံး သို့မဟုတ် အလယ် ဘယ်ဟာ နေရာတွင် ရှိနေမည်ကို သတ်မှတ်သည်။
- **အရှည်နှင့် plan အတိုင်းအတာ တူညီသည်။** {{ui:Measure from}} (အလယ်မျဉ်း၊ အတွင်းမျက်နှာ သို့မဟုတ် ပြင်ပမျက်နှာ) သည် Length အကွက်နှင့် plan ၏ နံရံအတိုင်းအတာများ နှစ်ခုလုံးကို မောင်းသည်။ အလယ်မျဉ်းတွင် စတင်သည်၊ ထို့ကြောင့် plan ၏ နံရံ အတိုင်းအတာများသည် ယခင် ပြင်ပမျက်နှာ အစား အလယ်မျဉ်းကို ယခု ဖတ်သည်။ Wall အတန်း၊ {{ui:Properties}} သို့မဟုတ် {{ui:Settings}} › {{ui:BimCraft}} › {{ui:Walls}} တွင် ပြောင်းပါ။

### အဆင့်များ၊ grid များနှင့် တိုင်းတာခြင်း

- **အောက်ပိုင်းအဆင့် ထည့်ရန်။** {{ui:Levels}} panel ရှိ {{ui:Add a level below}} သည် အနိမ့်ဆုံးအဆင့်အောက်တွင် အဆင့်တစ်ခုကို ထည့်သည်၊ အမြင့်တူ၊ အနုတ် elevation ဖြင့် (Level -1၊ Level -2)။ အခြား ဘာမျှ မရွှေ့ပါ။ {{ui:Add levels…}} သည် ယခု အနုတ်အမြင့်ကို လက်ခံသည်။ Command line တွင် LEVEL၊ LEVELS၊ STOREY သို့မဟုတ် STOREYS ရိုက်လျှင် {{ui:Add levels…}} ဖွင့်သည်၊ နှင့် menu နှင့် ribbon tab များတွင် {{ui:Levels}} ခလုတ် ရှိသည်။ [ဆိုက်၊ အဆောက်အအုံနှင့် အဆင့်များ](topic:site-building-and-levels) ကို ကြည့်ပါ။
- **Grid အတိုင်းအတာများ plan ပေါ်တွင်။** {{ui:Grid}} tool ဖွင့်ထားစဉ် {{ui:Dimensions}} ကို အမှန်ခြစ်ပါက အနီးဆုံး မျဉ်းများအကြား အကွာအဝေးနှင့် bubble များ၏ အပြင်ဘက် စုစုပေါင်း အရွယ်အစားကို အဆင့်တိုင်း၏ plan တွင် ဆွဲသည်။ [Grid ကို အတိုင်းအတာ ပေးခြင်း](topic:grid-dimensions) ကို ကြည့်ပါ။
- **Plan ပေါ်တွင် တိုင်းတာခြင်း။** Draw group ရှိ {{ui:Measure}} သည် ကလစ် နှစ်ချက်ကြား အကွာအဝေးကို X နှင့် Y ကွာခြားချက်များဖြင့် ပေးသည်။ မော်ဒယ်တွင် ဘာမျှ မသိမ်းပါ။ [Plan ပေါ်တွင် တိုင်းခြင်း](topic:measure-on-the-plan) ကို ကြည့်ပါ။
- **ကော်လံများစွာ တစ်ပြိုင်နက် ပြောင်းခြင်း။** နံရံနှင့်အတူ ကော်လံများကို အတူ ရွေးပါ၊ ရွေးချယ်မှုက ကော်လံအမျိုးအစား တစ်ခုစီကို {{ui:Keep only these}} ဖြင့် ပြသည်။ တစ်ချက်နှိပ်ဖြင့် ကော်လံများကို ထားပြီး ၎င်းတို့၏ မျှဝေ အကွက်များကို ပြသည်။
- **ယူနစ် တစ်ခုတည်း နေရာတိုင်း။** Coordinates၊ တိုင်းတာမှုများ၊ section များ၊ sheet စကေးများ၊ frame tab ရှိ load နှင့် ရလဒ်များနှင့် Problems စာသားများသည် သင်ရွေးသော ယူနစ်ကို လိုက်သည်။ Export များသည် SI အတိုင်း ရှိနေသည်။

### View များ၊ sheet များနှင့် print

- **Working style။** {{ui:Settings}} › {{ui:BimCraft}} › {{ui:Working style}} သည် view တစ်ခုစီ၏ ကိုယ်ပိုင် annotation နှင့် pen table ရှိခြင်း သို့မဟုတ် မျှဝေခြင်း ကို ရွေးသည်။ [Working style၊ ပွားထားသော view များ၊ စက္ကူပေါ်ရှိ pen များ၊ Report as နှင့် template များ](topic:working-style) ကို ကြည့်ပါ။
- **View ပွားရန်။** Plan၊ ceiling plan၊ callout၊ elevation နှင့် section များကို {{ui:Own copy}} သို့မဟုတ် {{ui:Linked}} အဖြစ် ပွားနိုင်သည်; {{ui:Make own copy}} က linked တစ်ခုကို လွတ်လပ်စေသည်။ [Working style၊ ပွားထားသော view များ၊ စက္ကူပေါ်ရှိ pen များ၊ Report as နှင့် template များ](topic:working-style) ကို ကြည့်ပါ။
- **မြင်သည့်အတိုင်း print သို့မဟုတ် pen table ဖြင့် print။** Pen overrides များကို view နှင့်အတူ IFC တွင် ထိန်းပြီး sheet နှင့် PDF များက ၎င်းတို့ကို မျက်နှာပြင်အတိုင်း ဆွဲသည်။ Topic တူညီသည်တွင် pen table များလည်း ပါသည်။
- **Report as။** Properties ရှိ {{ui:Report as}} သည် လမ်းအဖြစ် ဆွဲထားသော slab၊ panel အဖြစ် နံရံ၊ သို့မဟုတ် ramp အဖြစ် အမိုးကို သင်ရွေးသော class ဖြင့် IFC တွင် ရေးပြီး schedule များ၊ Quantities၊ Find၊ Color by နှင့် Problems တွင် ထိုသို့ ရေတွက်သည်။
- **Elevation နှင့် section တွင် တည်းဖြတ်ခြင်း။** နံရံများ၊ အပေါက်များ၊ အဆင့်များ၊ အတိုင်းအတာများနှင့် မှတ်ချက်များကို elevation သို့မဟုတ် section ထဲတွင် တိုက်ရိုက် ဆွဲ၍ ရွှေ့နိုင်သည်၊ သင်၏ ကိုယ်ပိုင် sheet အရွယ်အစားနှင့် title block များဖြင့်။ [Elevation နှင့် section တွင် တည်းဖြတ်ခြင်း](topic:edit-in-elevations) ကို ကြည့်ပါ။

## ရိုးရိုးသားသား ကန့်သတ်ချက်များ

- ပေါက်ကွဲ ရုပ်ပုံများ သို့မဟုတ် hardware အမှန်တကယ်တွင် ဘာမျှ မပရင့်ထုတ်ရသေးပါ။ Resin supports များသည် အသစ်ဖြစ်ပြီး မစမ်းသပ်ရသေးပါ။
- Wind၊ seismic၊ concrete နှင့် finite-element ရလဒ်များသည် engineer အတွက် စစ်ဆေးကူညီသည့် ကိရိယာများဖြစ်ပြီး closed form များနှင့် စစ်ဆေးထားသည်၊ အမှန်တကယ် အဆောက်အအုံနှင့် မဟုတ်ပါ။
- Scan to BIM ကို ပေါင်းစပ် အဆောက်အအုံ (synthetic) တွင် စမ်းသပ်ထားသည်၊ အမှန်တကယ် scan တွင် မဟုတ်ပါ၊ နှင့် ထောင့်မှန် အခန်းများကိုသာ ရှာသည်။
- Collada ကို Blender သို့မဟုတ် Google Earth တွင် ဤနေရာတွင် မဖွင့်ရသေးပါ။
- အလင်း ခန့်မှန်းချက်ကို ကျွန်ုပ်တို့၏ ကိုယ်ပိုင် trace နှင့် စစ်ဆေးထားသည်၊ အခြား အလင်းပရိုဂရမ်များနှင့် မဟုတ်ပါ။
- တောင်အာဖရိကန် ကိန်းဂဏန်းများကို မစစ်ဆေးရသေးပါ။
- Wall join style များ (butt၊ mitre၊ square off) နှင့် layer priority တို့ကို မဆောက်ရသေးပါ; ထောင့်များကို mitre ဖြင့် ပြုလုပ်သည်။
- အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် စက်ဖြင့် ရေးထားသော မူကြမ်းများ ဖြစ်သည်။

ကျန်အရာအားလုံးကို [မပြုလုပ်ရသေးသော အရာများ](topic:not-built-yet) တွင် ရှာနိုင်သည်။ ယခင် ပြောင်းလဲမှုများသည် ဤစာမျက်နှာ၏ အောက်ပိုင်းရှိ 0.8 နှင့် 0.8.1 မှတ်စုများတွင် ရှိသည်။

## ယခင်: 0.8 နှင့် 0.8.1

ဤသည်မှာ BimCraft 0.7 နှင့် နှိုင်းယှဉ်လျှင် 0.8 (2026-11-01) နှင့် 0.8.1 (2026-11-02) တွင် ပြောင်းလဲသွားသည်များ ဖြစ်သည်။ BimCraft သည် ယခု လူများ၊ အသံ၊ ရေ၊ လေနှင့် ငလျင်တို့ဖြင့် အဆောက်အအုံအကြောင်း မေးခွန်းများကို ဖြေနိုင်ပြီး စမ်းသပ်နိုင်သည်၊ နှင့် ကိရိယာ ပိုများဖြင့် ဆွဲနိုင်သည်; 0.8.1 သည် ပြင်ဆင်ချက် ထုတ်ဝေမှု ဖြစ်သည်။

### အသစ်များ

**အဆောက်အအုံကို စမ်းသပ်ခြင်း**

- **အဆောက်အအုံထဲရှိ လူများ။** ဘယ်ဘက် panel ၏ {{ui:People in the building}} အပိုင်းက evacuation သို့မဟုတ် ပုံမှန်နေ့ရက် ရောက်ရှိမှုကို သင့်အခန်းများ၊ တံခါးများနှင့် လှေကားများတလျှောက် လျှောက်စေသည်။ အဆောက်အအုံ ကျဉ်းသွားသည့်နေရာတွင် တန်းစီမှုများ၊ အခန်းတိုင်းမှ ထွက်ပေါက်သို့ အရှည်ဆုံး လမ်းလျှောက်ချိန်နှင့် နောက်ဆုံးလူ ဘယ်လောက် ကြာသည်ကို မြင်ရသည်။ တံခါးတစ်ခုပေါ်တွင် {{ui:Shut}} ကို အမှန်ခြစ်၍ ဘာပြောင်းသည်ကို ကြည့်ပါ၊ နှင့် လျှောက်သူများကို ကြည့်ရန် {{ui:Show the people in the 3D view}} ကို အမှန်ခြစ်ပါ။ တွေ့ရှိချက်များကို Problems သို့ ပို့သည်။ ဒီဇိုင်းဆုံးဖြတ်ချက်များအတွက် ကြမ်းတမ်းသော လူအုပ် မော်ဒယ်ဖြစ်ပြီး မီးဘေးကင်းရေး လက်မှတ် မဟုတ်ပါ။ [အဆောက်အအုံအတွင်း လူများကို လျှောက်စေခြင်း](topic:people-in-the-building) ကို ကြည့်ပါ။
- **အခန်း acoustics နှင့် နားထောင်ခြင်း။** {{ui:Room acoustics}} အပိုင်းက အခန်းတစ်ခုစီ၏ reverberation အချိန်ကို octave band အလိုက် (Sabine နှင့် Eyring) အရွယ်အစားနှင့် သင်ရွေးသော အပြီးသတ်များမှ ပေးသည်၊ နှင့် သင့်ကိုယ်ပိုင် ပစ်မှတ်ဖြင့် ထိုအရာကို ဖြည့်ဆည်းရန် စုပ်ယူမှု မည်မျှ လိုသလဲ ပြောသည်။ {{ui:Play it in this room}} သည် အသံ၊ လက်ခုပ်၊ ဆွဲထားသော ဂီတ သို့မဟုတ် သင့်ကိုယ်ပိုင် အသံဖိုင်ကို အခန်းအတွက် တွက်ထားသော impulse response မှ ဖွင့်သည်။ စုပ်ယူမှု ဂဏန်းများသည် သင် အစားထိုးရန် ထုတ်ပြန်ထားသော typical တန်ဖိုးများ ဖြစ်သည်။ [အခန်း acoustics](topic:room-acoustics) ကို ကြည့်ပါ။
- **ရေလွှမ်းမိုးမှု၊ လေနှင့် ငလျင် ပြန်ဖွင့်ခြင်း။** {{ui:Hazard playback}} သည် အခန်းများထဲ ရေတက်လာခြင်း၊ storey တစ်ခုစီပေါ် လေဖိအား နှင့် storey များကို တုန်ခါစေသည့် ငလျင်ကို plan သို့မဟုတ် elevation ပေါ်တွင် အချိန်ဆလိုက်ဒါ ဖြင့် ဖွင့်သည်။ Panel ပေါ်တွင် ရိုးရှင်းသော မော်ဒယ်များနှင့် ၎င်းတို့၏ ယူဆချက်များ; ဥပဒေ စစ်ဆေးမှု မဟုတ်ပါ။ [ရေလွှမ်းမိုးမှု၊ လေ သို့မဟုတ် ငလျင် ဖွင့်ခြင်း](topic:hazard-playback) ကို ကြည့်ပါ။
- **ပွင့်ဆိုင်း ၅၀ နှစ်တွင် ပျက်စီးမည့်အရာ။** {{ui:Life-cycle view}} က ပြတင်းပေါက်များ၊ တံခါးများ၊ အပြီးသတ်များနှင့် အမိုးကို service life တစ်ခုစီဖြင့် စာရင်းပြုပြီး၊ အစားထိုးရမည့် နှစ်များ၊ ယူနစ်တစ်ခုလျှင် ကုန်ကျစရိတ်ကို ရိုက်ထည့်လျှင် နှစ်အလိုက် ကုန်ကျစရိတ်နှင့် ယခုတန်ဖိုး။ {{ui:Save the schedule (CSV)}} က ထုတ်ရေးသည်။ Service life များသည် စီမံကိန်းဆိုင်ရာ ဂဏန်းများ ဖြစ်သည်။ [ငါးဆယ်နှစ်အတွင်း ဘာပျက်စီးမလဲ ကြည့်ခြင်း](topic:life-cycle-view) ကို ကြည့်ပါ။
- **Concrete နှင့် seismic စစ်ဆေးမှုများ။** {{ui:Analysis}} tab ၏ {{ui:Concrete members}} နှင့် {{ui:Seismic loads}} block များသည် concrete beam နှင့် column များကို ACI 318-19 ဖြင့် စစ်ဆေးပြီး rigid ကြမ်းပြင်များပေါ် ASCE 7-22 ဖြင့် ညီမျှသော ဘေးဖိအားများကို ပြုလုပ်ပြီး storey drift ပါသည်။ Engineer တစ်ဦးက စစ်ဆေးရန်။ [Concrete member များ စစ်ဆေးပြီး ငလျင် load များ ပြုလုပ်ခြင်း](topic:concrete-and-seismic) ကို ကြည့်ပါ။

**စစ်ဆေးခြင်းနှင့် အစီရင်ခံခြင်း**

- **IDS ဖြင့် စစ်ဆေးခြင်း။** Client က ပေးသော `.ids` ဖိုင်ကို တင်ပြီး IFC မပို့မီ ၎င်းနှင့် မကိုက်ညီသော element တိုင်းကို Problems တွင် ကြည့်ပါ။ {{ui:Model checks}} အောက်ရှိ {{ui:Check against an IDS}} ကို ဖွင့်ပါ။ [Client ၏ IDS ဖြင့် မော်ဒယ်ကို စစ်ဆေးခြင်း](topic:check-against-ids) ကို ကြည့်ပါ။
- **Tag များနှင့် schedule များ။** သင့်ကိုယ်ပိုင် tag များ သတ်မှတ်ပါ၊ element များစွာပေါ်တွင် တစ်ပြိုင်နက် သတ်မှတ်ပါ၊ ၎င်းတို့ကို ဖတ်သော ကော်လံများ၊ filter များနှင့် အုပ်စုများပါသော schedule များ ပြုလုပ်ပါ; tag များကို IFC တွင် သိမ်းသည်။ [Tag များနှင့် schedule များ](topic:tags-and-schedules) ကို ကြည့်ပါ။
- **မော်ဒယ်မှ စာရွက်စာတမ်းများ။** {{ui:Documents from the model}} သည် ဖွင့်ထားသော IFC မှ specification template ကို ဖြည့်ပြီး PDF၊ Word စာရွက်စာတမ်း သို့မဟုတ် Markdown အဖြစ် သိမ်းသည်။ [မော်ဒယ်မှ စာရွက်စာတမ်းများ](topic:documents-from-the-model) ကို ကြည့်ပါ။
- **Scan ကို မော်ဒယ်နှင့် နှိုင်းယှဉ်ခြင်း။** Point cloud ဖွင့်ထားစဉ် {{ui:Compare}} သည် element တစ်ခုစီကို တည်ဆောက်ပြီး၊ တစ်စိတ်တစ်ပိုင်း တည်ဆောက်ပြီး၊ ပျောက်နေသော သို့မဟုတ် မရောက်သေးသော အဖြစ် ဆုံးဖြတ်ပြီး ရာခိုင်နှုန်း တည်ဆောက်ပြီးမှု ပြသည်။ [Scan ကို မော်ဒယ်နှင့် နှိုင်းယှဉ်ခြင်း](topic:compare-scan-with-model) ကို ကြည့်ပါ။
- **Carbon နှင့် cost။** Carbon pane သည် ပြင်ဆင်နိုင်သော factor ဇယားမှ embodied carbon ကို ပေါင်းသည်၊ နှင့် Cost pane သည် ဈေးနှုန်းများကို 4D schedule အပေါ် ခွဲဝေသည်။ BimCraft နှင့်အတူလာသော factor များသည် generic ဖြစ်ပြီး မစစ်ဆေးရသေးဟု အမှတ်အသားပြုထားသည်။ [Embodied carbon နှင့် cost](topic:embodied-carbon-and-5d-cost) ကို ကြည့်ပါ။
- **မြေပုံပေါ်မဆို projection။** {{ui:Measure}} › {{ui:Coordinate system…}} သည် EPSG နံပါတ်၊ UTM zone၊ အမည် သို့မဟုတ် သင့်ကိုယ်ပိုင် projection အဓိပ္ပါယ်ကို လက်ခံသည်။ [မည်သည့် projection ဖြင့်မဆို georeference](topic:georeference-any-projection) ကို ကြည့်ပါ။

**ဆွဲခြင်းနှင့် တည်းဖြတ်ခြင်း**

- **ရွှေ့ခြင်း၊ ညှိခြင်းနှင့် ဖြန့်ခြင်း။** {{ui:Build}} အောက်တွင်; {{key:Shift+M}} က Move စတင်သည် (ရိုးရိုး {{key:M}} က Measure ဖြစ်ဆဲ)။ Move သည် {{key:C}} ဖြင့် ကူးရင်း သွားသည်၊ အဆင့်တိုင်း undo တစ်ခု၊ နှင့် Live TeamWork session တွင် သွားသည်။ [ရွှေ့ခြင်း၊ ကူးခြင်း၊ ညှိခြင်းနှင့် ဖြန့်ခြင်း](topic:move-align-distribute) ကို ကြည့်ပါ။
- **ပုံများ plan အောက်တွင်။** {{ui:Build}} › {{ui:Picture}} သည် PNG၊ JPEG သို့မဟုတ် WebP ကို အဆင့်တစ်ခု၏ plan အောက် သို့မဟုတ် ဒေါင်လိုက် အပြင်ပြင်တွင် ချသည်။ စကေးကို အမှတ်နှစ်ခုဖြင့် သတ်မှတ်ပြီး ရွှေ့၊ လှည့်၊ မှိန်စေ၊ နှင့် လော့ခ်ချနိုင်သည်။ MarkupCraft တွင် ကူးထားသော နေရာသည် ၎င်း၏ sheet စကေးဖြင့် ကပ်ထည့်သည်။ [ပုံကို plan အောက်တွင် ထားခြင်း](topic:pictures-as-backgrounds) ကို ကြည့်ပါ။
- **Scan မှ နံရံများ။** Scan ဖွင့်ထားစဉ် နံရံများ၊ တံခါးများနှင့် အခန်းများသည် အဆိုပြုချက်များအဖြစ် ရောက်လာပြီး တစ်ခုချင်း ထိန်းထား သို့မဟုတ် ပယ်ချနိုင်သည်၊ undo အဆင့် တစ်ခုတည်းဖြင့်။ ထောင့်မတိုင်း နှစ်ခုတွင်သာ နံရံများကို တွေ့သည်။ [Scan ကို နံရံများအဖြစ် ပြောင်းခြင်း](topic:scan-to-walls) ကို ကြည့်ပါ။
- **ခြေရာခံ၊ ဆေးတံနှင့် sketch stair။** {{ui:Trace}} သည် အခြားအဆင့်ကို plan အောက်တွင် အစက်ကြောင်းဖြင့် ပြသည်၊ {{ui:Pens}} သည် နံရံ၊ တံခါးနှင့် ပြတင်းပေါက်များကို view တစ်ခုတည်းတွင် ကိုယ်ပိုင် မျဉ်းအထူ ပေးသည်၊ နှင့် {{ui:Sketch stair}} သည် လမ်းလျှောက်မျဉ်းကို လှေကားအဖြစ် ပြောင်းသည်။ Wavefront OBJ mesh ဖွင့်သည်။ [Trace၊ pen များနှင့် sketch မှ လှေကား](topic:trace-pens-stairs-obj) ကို ကြည့်ပါ။
- **လိပ်စာပတ်လည် အဆောက်အအုံများ။** CivilCraft ၏ Address to site က ရှာတွေ့သော အဆောက်အအုံများနှင့် ပိုင်ဆိုင်မြေကွက်သည် အကြံပြုချက်များအဖြစ် ရောက်လာပြီး ထည့်လိုသည်များကို အမှန်ခြစ်ပါ။ [CivilCraft ၏ site မှ စတင်ခြင်း](topic:site-from-civilcraft) ကို ကြည့်ပါ။
- **ပြား ပုံဆွဲများ။** {{ui:Build}} › {{ui:Panel drawings}} သည် သစ် သို့မဟုတ် ပေါ့ပါးသော ဂဟေထားသော သံမဏိဖြင့် နံရံ၊ ကြမ်းပြင်နှင့် အမိုးများကို ဘောင်ခတ်ပြီး cut list ကို CSV အဖြစ်၊ shop ပုံဆွဲများကို PDF အဖြစ် သိမ်းသည်။ စတင်တန်ဖိုးများဖြစ်ပြီး ဖွဲ့စည်းပုံ ဒီဇိုင်း မဟုတ်ပါ။ [ပြား ပုံဆွဲများ](topic:panel-drawings) ကို ကြည့်ပါ။
- **သင်္ကေတ palette နှင့် အပင်များ။** {{ui:Build}} › {{ui:Symbol palette}} သည် လျှပ်စစ်နှင့် ပိုက်ကွန်ရက် သင်္ကေတများကို အမည်ဖြင့် ရှာသည်; {{ui:Library}} ၏ {{ui:Plants}} source သည် plan သင်္ကေတပါသော အပင် ၄၀၀ ခန့် စာရင်းပြုသည်။ [Symbol palette](topic:symbol-palette) နှင့် [အပင် နေရာချခြင်း](topic:plant-list) ကို ကြည့်ပါ။

**ပိုက်၊ duct နှင့် energy**

- **Split၊ VRF နှင့် fan coil။** အတွင်းနှင့် အပြင် ယူနစ်များ ချိတ်ဆက်မှုများနှင့်အတူ၊ နှင့် line set များကို ပြောင်းလဲနိုင်သော typical ဥပမာတန်ဖိုး ဇယားမှ အရွယ်ချသည်။ [Split၊ VRF နှင့် fan coil များ](topic:split-vrf-fan-coils) ကို ကြည့်ပါ။
- **တွက်ချက်မှုများ။** Calculations pane သည် supply ပိုက်နှင့် duct အရွယ်များကို ဖိအားကျဆင်းမှုဖြင့် စစ်ဆေးသည်၊ ကေဘယ်များကို tray နှင့် conduit များမှ ဖြတ်ပြီး ၎င်းတို့၏ ဖြည့်မှုကို ပြသည်၊ နှင့် IES သို့မဟုတ် EULUMDAT ဖိုင်များမှ illuminance ကို တွက်သည်။ မူရင်းတန်ဖိုးများကို အမှတ်အသားပြုထားသည်; သင့်ကုဒ်၏ တန်ဖိုးများကို ရိုက်ထည့်ပါ။ [ပိုက်၊ duct၊ cable နှင့် မီးအလင်း တွက်ချက်မှုများ](topic:mep-calculations) ကို ကြည့်ပါ။
- **PCF ဖိုင်များ။** Pipe tool ၏ **Export PCF** သည် ပိုက်-ဖိအားနှင့် isometric ပရိုဂရမ်များအတွက် လမ်းကြောင်းများကို ရေးသည်၊ နှင့် ပြန်ဖတ်သော PCF ဖိုင်သည် ၎င်း၏ ပိုက်ကို ဆွဲသည်။ [ပိုက်ပစ္စည်း ဖိုင်များ](topic:piping-pcf) ကို ကြည့်ပါ။
- **Solar PV။** အမိုး သို့မဟုတ် မြေပေါ်တွင် array များ တပ်ဆင်ပါ၊ မော်ဒယ်မှ အရိပ်ထည့်ပါ၊ နှစ်စဉ် စွမ်းအင် ခန့်မှန်းပါ၊ string များကို စစ်ဆေးပြီး တစ်လိုင်း diagram data ပြုလုပ်ပါ။ Starter module နှင့် ဆုံးရှုံးမှုများသည် generic ဖြစ်သည်။ [Solar PV](topic:solar-pv) ကို ကြည့်ပါ။
- **EnergyPlus ဖိုင်။** Check with EnergyPlus pane သည် မော်ဒယ်ကို သင့်ကိုယ်ပိုင် EnergyPlus တွင် run ရန် IDF အဖြစ် ရေးသည်။ ဘရောက်ဇာတွင် run ရန် သင်ကိုယ်တိုင် host လုပ်သော build နှင့် သင်ရိုက်ထည့်သော လိပ်စာ လိုအပ်သည်; BimCraft က ၎င်းကို မပါဝင်ပါ။ [EnergyPlus ဖြင့် အပူနှင့် အအေး စစ်ဆေးခြင်း](topic:check-with-energyplus) ကို ကြည့်ပါ။

**ပုံများနှင့် ဖိုင်များ**

- **Render engine ရွေးချယ်ခြင်း။** {{ui:Render}} တွင် {{ui:Engine}} ရွေးချယ်မှု ရှိသည်။ ကျွန်ုပ်တို့၏ built-in engine နှစ်ခု (Fast နှင့် Path tracer) သည် default ဖြစ်ဆဲ။ **Open in** က scene ကို USD သို့မဟုတ် glTF ဖိုင်အဖြစ်၊ Unreal project ဖိုင်တွဲကို .zip အဖြစ် သိမ်းသည်; CadCraft Studio တွင် add-on တစ်ခုက engine ထည့်နိုင်သည်။ Project ကို ဖွင့်သော Unreal plug-in ကို မထုတ်ပြန်ရသေးပါ။ [ပုံကို မည်သည့်ပရိုဂရမ်ဖြင့် ဆွဲမလဲ ရွေးခြင်း](topic:render-engines) ကို ကြည့်ပါ။
- **Studio undo။** CadCraft Studio အတွင်း BimCraft သည် Studio သို့ ပြီးစီးသော အဆင့်တိုင်းကို ပြောသည်၊ ထို့ကြောင့် Studio က သင်နောက်ဆုံး အသုံးပြုသော ဝင်းဒိုးတွင် နောက်ဆုံး အဆင့်ကို ပြန်ဖျက်နိုင်သည်။ [အက်ပ်များကြား undo](topic:undo-across-apps) ကို ကြည့်ပါ။
- **Add-on များ သင့်ဖိုင်ထဲတွင်။** IFC တစ်ခုက ၎င်းထဲ ရေးခဲ့သော add-on များကို မှတ်တမ်းတင်ပြီး ဖွင့်သည့်အခါ သင်မရှိသော add-on များကို ကမ်းလှမ်းသည်။ [သင့်ဖိုင်ထဲရှိ add-on များ](topic:add-ons-in-your-file) ကို ကြည့်ပါ။

**အက်ပ်အားလုံးတွင်**

- **AI ကို ချိတ်ဆက်ခြင်း။** သင့်ကိုယ်ပိုင် assistant သည် Studio ၏ ချိတ်ဆက်မှုမှတစ်ဆင့် BimCraft ကို မောင်းပြီး မော်ဒယ်အကြောင်း မေးခွန်းများ ဖြေနိုင်သည်၊ ဥပမာ ဧရိယာတစ်ခုအောက်ရှိ အခန်းများ။ Studio တွင် ကိုယ်ပိုင် AI မရှိပါ။ [AI assistant ဖြင့် မော်ဒယ်ကို လုပ်ဆောင်ခြင်း](topic:assistants) ကို ကြည့်ပါ။
- **Toolbar အတန်းများ။** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} သည် Wrap၊ 2 rows သို့မဟုတ် 1 row ကို ပေးသည်; Wrap သည် default ဖြစ်ဆဲ။

- **ဘာသာစကားများ။** ဘာသာစကား ၅၄ ခု၊ ၎င်းတို့ထဲမှ ၁၀ ခု အသစ်။ အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် စက်ဖြင့် ရေးထားသော မူကြမ်းများ ဖြစ်ပြီး ဘာသာစကား ပိုင်ရှင်က မဖတ်ရသေးပါ; help topic များမှာ အများအားဖြင့် အင်္ဂလိပ်ဖြစ်သည်။

### 0.8.1 တွင် ပြင်ဆင်ထားသည်များ

- **Ribbon + Project browser အပြင်အဆင်။** Insert › Import CAD၊ Insert › Image နှင့် Manage › Project Units တို့က "Not built in BimCraft yet" ဟု ပြခဲ့သည်။ ယခု Image သည် Picture tool ကို ဖွင့်သည်၊ Import CAD သည် {{ui:Build}} › {{ui:From a drawing…}} (DWG၊ DXF၊ PDF သို့မဟုတ် scan) ကို ဖွင့်သည်၊ နှင့် Project Units သည် {{ui:Settings}} › {{ui:Global}} › {{ui:Units}} ကို ဖွင့်သည်။ Move နှင့် Align သည် Move နှင့် Align tools များကို run သည်၊ Level သည် {{ui:Add levels…}} ကို ဖွင့်သည်၊ Phases သည် Renovation phases အပိုင်းကို ဖွင့်ပြီး Materials သည် ပစ္စည်းစာကြည့်တိုက်ကို ဖွင့်သည်။

### ဤဗားရှင်းတွင် မရှိသေးသည်များ

- **Safety နှင့် design aid များ။** အဆောက်အအုံ စည်းမျဉ်းမှ ခရီးအကွာအဝေး ကန့်သတ်ချက် မရှိသော People in the building (သင်က ကန့်သတ်ချက်ကို ရိုက်ထည့်ရမည်) နှင့် အမှန်တကယ် plan တွင် လက်ဖြင့် မစစ်ဆေးရသေးပါ။ acoustics၊ life-cycle နှင့် hazard ဂဏန်းများသည် စီမံကိန်းတန်ဖိုးများဖြစ်ပြီး ဥပဒေစစ်ဆေးမှု မဟုတ်ပါ။
- **Climate futures နှင့် EnergyPlus။** Built-in climate futures မရှိပါ: ရေလွှမ်းမိုးမှု run အတွက် scenario ဖိုင် တင်နိုင်သည်။ ဘရောက်ဇာတွင် EnergyPlus run သည် ဤထုတ်ဝေမှုတွင် မပါဝင်ပါ။
- **Ribbon အပြင်အဆင်။** Material Takeoff သည် "Not built" ဖြစ်ဆဲ ဖြစ်သည်၊ ဘာကြောင့်ဆိုသော် BimCraft တွင် ပစ္စည်း ပမာဏ စာရင်း မရှိသောကြောင့်၊ နှင့် တခြား ribbon tool ၅၄ ခု မှိန်ထားသည် နောက်ကွယ်တွင် BimCraft tool မရှိသေးသောကြောင့်။
- **Signing နှင့် platform များ။** Windows installer နှင့် macOS .dmg များကို မ code-sign၊ ထို့ကြောင့် SmartScreen က {{ui:More info}}၊ ထို့နောက် {{ui:Run anyway}} ကို ပြသည်၊ နှင့် macOS တွင် right-click ပြီး {{ui:Open}} လိုသည်။ iPad နှင့် iPhone build ကို 0.8.1 အတွက် ပြန်မတည်ဆောက်ရသေးပါ။
- **အမှန်တကယ် စာမျက်နှာ စမ်းသပ်မှုများ။** BimCraft ဘရောက်ဇာ စမ်းသပ်မှု အချို့သည် ကျွန်ုပ်တို့၏ စမ်းသပ်စာမျက်နှာတွင် ကျရှုံးသည်၊ 0.8.1 မတိုင်မီကကဲ့သို့ပင်။
