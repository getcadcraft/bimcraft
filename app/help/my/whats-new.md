ဤသည်မှာ BimCraft 0.8 (2026-11-01) နှင့် 0.8.1 (2026-11-02) တွင် 0.7 နှင့် နှိုင်းယှဉ်လျှင် ပြောင်းလဲသွားသည်များ ဖြစ်သည်။ BimCraft သည် ယခု အဆောက်အအုံအကြောင်း မေးခွန်းများကို ဖြေနိုင်ပြီး လူများ၊ အသံ၊ ရေ၊ လေနှင့် ငလျင်များဖြင့် စမ်းသပ်နိုင်ကာ ကိရိယာ အများအပြားဖြင့် ဆွဲနိုင်ပြီ; 0.8.1 သည် ပြင်ဆင်ချက် ထုတ်ပြန်မှု ဖြစ်သည်။

## အသစ်

### အဆောက်အအုံကို စမ်းသပ်ခြင်း

- **အဆောက်အအုံထဲရှိ လူများ။** {{ui:အဆောက်အအုံထဲရှိ လူများ}} panel ၏ အပိုင်းသည် ထွက်ပေါက်ဆိုင်ရာ ဖယ်ထုတ်ခြင်း သို့မဟုတ် နေ့စဉ် ရောက်ရှိမှုများကို သင့်အခန်းများ၊ တံခါးများနှင့် လှေကားများမှ ဖြတ်သန်းစေသည်။ အဆောက်အအုံ ကျဉ်းသွားသော နေရာတွင် တန်းစီမှုများကို၊ အခန်းတိုင်းမှ ထွက်ပေါက်သို့ အရှည်ဆုံး လမ်းလျှောက်ချိန်နှင့် နောက်ဆုံး လူ၏ ကြာချိန်ကို မြင်ရသည်။ တံခါးတွင် {{ui:ပိတ်}} ကို အမှန်ခြစ်ပြီး ပြောင်းလဲမှုကို ကြည့်ပါ၊ {{ui:လူများကို 3D view တွင် ပြရန်}} ကို အမှန်ခြစ်ပြီး လမ်းလျှောက်သူများကို ကြည့်ပါ။ တွေ့ရှိချက်များကို ပြဿနာများသို့ ပို့သည်။ ဒီဇိုင်း ဆုံးဖြတ်ချက်အတွက် ကြမ်းတမ်းသော လူစုလူဝေး မော်ဒယ် ဖြစ်ပြီး မီးဘေးကာကွယ်ရေး လက်မှတ် မဟုတ်ပါ။ [အဆောက်အအုံထဲတွင် လူများ လျှောက်ခြင်း](topic:people-in-the-building) ကို ကြည့်ပါ။
- **အခန်း အသံစနစ်၊ နားထောင်နိုင်သည်။** {{ui:အခန်း အသံစနစ်}} အပိုင်းက အခန်းတစ်ခုစီ၏ reverberation အချိန်ကို octave band အလိုက် (Sabine နှင့် Eyring) ၎င်း၏ အရွယ်အစားနှင့် သင်ရွေးသော မျက်နှာပြင် အပြီးသတ်များမှ ပေးသည်၊ နှင့် ကိုယ်ပိုင် ပစ်မှတ်ဖြင့် ထိုအပေါ် ဂုဏ်ပြုရန် အသံစုပ်ယူမှု ဘယ်မျှလိုသလဲဆိုသည်ကို ပြသသည်။ {{ui:ဤအခန်းတွင် ဖွင့်ရန်}} သည် အသံ၊ လက်ခုပ်တီး၊ ဆွဲထားသော အသံ သို့မဟုတ် သင့်ကိုယ်ပိုင် အသံဖိုင်ကို အခန်းအတွက် တွက်ချက်ထားသော impulse response မှတစ်ဆင့် ဖွင့်သည်။ စုပ်ယူမှု ကိန်းဂဏန်းများသည် သင် အစားထိုးရန် ထုတ်ပြန်ထားသော ပုံမှန် တန်ဖိုးများ ဖြစ်သည်။ [အခန်း အသံစနစ်](topic:room-acoustics) ကို ကြည့်ပါ။
- **ရေလွှမ်းမှု၊ လေနှင့် ငလျင် ပြန်ဖွင့်ခြင်း။** {{ui:အန္တရာယ် ပြန်ဖွင့်ခြင်း}} သည် အခန်းများထဲ တက်လာသော ရေ၊ အထပ်တစ်ခုစီပေါ်ရှိ လေဖိအား နှင့် အထပ်များကို လှုပ်စေသော ငလျင်ကို အချိန်ဘားဖြင့် ပလန် သို့မဟုတ် elevation ပေါ်တွင် ပြန်ဖွင့်သည်။ ရိုးရှင်းသော မော်ဒယ်များကို ၎င်းတို့၏ ယူဆချက်များနှင့်အတူ panel ပေါ်တွင် ပြသည်; ကုဒ် စစ်ဆေးမှု မဟုတ်ပါ။ [ရေလွှမ်းမှု၊ လေ သို့မဟုတ် ငလျင် ပြန်ဖွင့်ခြင်း](topic:hazard-playback) ကို ကြည့်ပါ။
- **နှစ်ပေါင်း ငါးဆယ်အတွင်း ဘာပျက်စီးမလဲ။** {{ui:သက်တမ်းတစ်လျှောက် အမြင်}} သည် ပြတင်းပေါက်၊ တံခါး၊ အနှီးများနှင့် ခေါင်မိုးတို့ကို service life တစ်ခုစီ၊ အစားထိုးရမည့် နှစ်များနှင့် ယူနစ်တစ်ခုအတွက် ကုန်ကျစရိတ်ကို ရိုက်ထည့်သောအခါ နှစ်အလိုက် ကုန်ကျစရိတ်နှင့် ယခုတန်ဖိုး (present value) ကို စာရင်းပြုသည်။ {{ui:အချိန်ဇယားကို သိမ်းရန် (CSV)}} က ထုတ်ပေးသည်။ Service life များသည် စီမံကိန်း တွက်ချက်ရန် ခန့်မှန်းတန်ဖိုးများ ဖြစ်သည်။ [နှစ်ပေါင်း ငါးဆယ်အတွင်း ဘာပျက်စီးမလဲ ကြည့်ခြင်း](topic:life-cycle-view) ကို ကြည့်ပါ။
- **ကွန်ကရစ်နှင့် ငလျင် စစ်ဆေးမှုများ။** {{ui:ကွန်ကရစ် အဖွဲ့ဝင်များ}} နှင့် {{ui:ငလျင်အင်အားများ}} block များသည် {{ui:ခွဲခြမ်းစိတ်ဖြာမှု}} tab မှ ကွန်ကရစ် beam နှင့် column များကို ACI 318-19 အတိုင်း စစ်ဆေးပြီး rigid floor များပေါ် ASCE 7-22 အတိုင်း ညီမျှသော ဘေးဖိအား အင်အားများကို ဖန်တီးပြီး အထပ် drift ကို ပြသသည်။ အင်ဂျင်နီယာ စစ်ဆေးရန်အတွက်။ [ကွန်ကရစ် အဖွဲ့ဝင်များ စစ်ဆေးခြင်းနှင့် ငလျင် အင်အားများ ဖန်တီးခြင်း](topic:concrete-and-seismic) ကို ကြည့်ပါ။

### စစ်ဆေးခြင်းနှင့် အစီရင်ခံခြင်း

- **IDS ဖြင့် စစ်ဆေးခြင်း။** ဖောက်သည်ပေးသော `.ids` ဖိုင်ကို တင်ပြီး IFC ကို ပေးပို့မည့်အရှေ့တွင် မကိုက်ညီသော element တိုင်းကို ပြဿနာများတွင် ကြည့်ပါ။ {{ui:မော်ဒယ် စစ်ဆေးချက်များ}} အောက်ရှိ {{ui:IDS ဖြင့် စစ်ဆေးရန်}} ကို ဖွင့်ပါ။ [ဖောက်သည်၏ IDS ဖြင့် မော်ဒယ် စစ်ဆေးခြင်း](topic:check-against-ids) ကို ကြည့်ပါ။
- **Tag များနှင့် ဇယားများ။** ကိုယ်ပိုင် tag များ သတ်မှတ်ပြီး element အများအပြားတွင် တစ်ပြိုင်နက် သတ်မှတ်ကာ tag ကို ဖတ်သော column၊ filter နှင့် group ပါသော ဇယားများ ပြုလုပ်နိုင်သည်; tag များကို IFC တွင် သိမ်းသည်။ [Tag များနှင့် ဇယားများ](topic:tags-and-schedules) ကို ကြည့်ပါ။
- **မော်ဒယ်မှ စာရွက်စာတမ်းများ။** {{ui:မော်ဒယ်မှ စာရွက်စာတမ်းများ}} သည် ဖွင့်ထားသော IFC မှ specification template ကို ဖြည့်ပြီး PDF၊ Word စာရွက်စာတမ်း သို့မဟုတ် Markdown အဖြစ် သိမ်းသည်။ [မော်ဒယ်မှ စာရွက်စာတမ်းများ](topic:documents-from-the-model) ကို ကြည့်ပါ။
- **Scan ကို မော်ဒယ်နှင့် နှိုင်းယှဉ်ခြင်း။** Point cloud ဖွင့်ထားစဉ် {{ui:နှိုင်းယှဉ်ရန်}} သည် element တစ်ခုစီကို ဆောက်ပြီး၊ တစ်စိတ်တစ်ပိုင်း ဆောက်ပြီး၊ ပျောက်နေသည်၊ သို့မဟုတ် မရောက်သေးသည်ဟု ဆုံးဖြတ်ပြီး ဆောက်ပြီးမှု ရာခိုင်နှုန်းကို ပြသသည်။ [Scan ကို မော်ဒယ်နှင့် နှိုင်းယှဉ်ခြင်း](topic:compare-scan-with-model) ကို ကြည့်ပါ။
- **ကာဗွန်နှင့် ကုန်ကျစရိတ်။** Carbon panel သည် တည်းဖြတ်နိုင်သော factor ဇယားမှ embodied carbon ကို ပေါင်းပြီး Cost panel သည် 4D အချိန်ဇယားပေါ်တွင် စျေးနှုန်းများကို ခွဲဝေသည်။ BimCraft နှင့်အတူ ပါလာသော factor များသည် generic ဖြစ်ပြီး unchecked ဟု အမှတ်အသားပြုထားသည်။ [Embodied carbon နှင့် ကုန်ကျစရိတ်](topic:embodied-carbon-and-5d-cost) ကို ကြည့်ပါ။
- **မည်သည့် မြေပုံ projection မဆို။** {{ui:တိုင်းတာရန်}} › {{ui:ကိုအော်ဒီနိတ်စနစ်…}} သည် EPSG နံပါတ်၊ UTM zone၊ အမည် သို့မဟုတ် သင်၏ကိုယ်ပိုင် projection သတ်မှတ်ချက်ကို လက်ခံသည်။ [မည်သည့် projection ဖြင့်မဆို georeference ပြုလုပ်ခြင်း](topic:georeference-any-projection) ကို ကြည့်ပါ။

### ဆွဲခြင်းနှင့် တည်းဖြတ်ခြင်း

- **Move၊ Align နှင့် Distribute။** {{ui:Build}} အောက်တွင်; {{key:Shift+M}} သည် Move ကို စတင်သည် (ရိုးရိုး {{key:M}} သည် ဆက်လက် {{ui:တိုင်းတာရန်}} ဖြစ်သည်)။ Move သည် {{key:C}} ဖြင့် ကူးရင်း ကူးသည်၊ အဆင့်တိုင်း တစ်ခုစီသည် undo တစ်ခု ဖြစ်ပြီး Live TeamWork session တွင် ပါ သွားသည်။ [ရွှေ့ခြင်း၊ ကူးခြင်း၊ ညှိခြင်းနှင့် ဖြန့်ခြင်း](topic:move-align-distribute) ကို ကြည့်ပါ။
- **ပလန်အောက်ရှိ ပုံများ။** {{ui:Build}} › {{ui:ပုံ}} သည် PNG၊ JPEG သို့မဟုတ် WebP ကို level ၏ ပလန်အောက် သို့မဟုတ် ဒေါင်လိုက် ပလိန်ပေါ်တွင် ထားသည်။ အမှတ်နှစ်ခုဖြင့် scale သတ်မှတ်ပြီး ရွှေ့၊ လှည့်၊ မှိန်စေ၊ သော့ခတ်နိုင်သည်။ MarkupCraft တွင် ကူးထားသော နယ်ပယ်သည် ၎င်း၏ sheet scale ဖြင့် ထည့်သည်။ [ပလန်အောက်တွင် ပုံထားခြင်း](topic:pictures-as-backgrounds) ကို ကြည့်ပါ။
- **Scan မှ နံရံများ။** Scan ဖွင့်ထားစဉ် နံရံများ၊ တံခါးများနှင့် အခန်းများသည် အကြံပြုချက်များအဖြစ် ရောက်လာပြီး တစ်ခုချင်းစီ ထားရန် သို့မဟုတ် ပယ်ရန် ရွေးနိုင်သည်၊ undo အဆင့်တစ်ခုတည်းဖြင့်။ ထောင့်မတ်သော ဦးတည်ချက် နှစ်ခုတွင်သော နံရံများကိုသာ တွေ့သည်။ [Scan ကို နံရံများအဖြစ် ပြောင်းခြင်း](topic:scan-to-walls) ကို ကြည့်ပါ။
- **ခြေရာခံ၊ ဆေးတံများနှင့် ပုံဖော်ထားသော လှေကား။** {{ui:ခြေရာခံ}} သည် အခြား level ကို ပလန်အောက်တွင် မျဉ်းကြောင်းဖြင့် ပြသည်၊ {{ui:ဆေးတံများ}} သည် နံရံ၊ တံခါးနှင့် ပြတင်းပေါက်များကို ၎င်းတို့၏ ကိုယ်ပိုင် မျဉ်းအထူဖြင့် view တစ်ခုတည်းတွင် ပေးသည်၊ နှင့် {{ui:လှေကား ပုံဖော်ရန်}} သည် လမ်းလျှောက်မျဉ်းကို လှေကားအဖြစ် ပြောင်းသည်။ Wavefront OBJ mesh ဖွင့်သည်။ [Level ကို ခြေရာခံခြင်း၊ ဆေးတံများနှင့် ပုံဖော်ထားသော လှေကား](topic:trace-pens-stairs-obj) ကို ကြည့်ပါ။
- **လိပ်စာတစ်ခုပတ်လည် အဆောက်အအုံများ။** CivilCraft ၏ Address to site က ရှာတွေ့သော အဆောက်အအုံများနှင့် parcel သည် အကြံပြုချက်များအဖြစ် ရောက်လာသည်; ထည့်လိုသည်များကို အမှန်ခြစ်ပါ။ [CivilCraft မှ site ဖြင့် စတင်ခြင်း](topic:site-from-civilcraft) ကို ကြည့်ပါ။
- **ပြားပုံဆွဲများ။** {{ui:Build}} › {{ui:ပြားပုံဆွဲများ}} သည် နံရံ၊ ကြမ်းပြင်နှင့် ခေါင်မိုးများကို သစ် သို့မဟုတ် ပါးသော သံမဏိဖြင့် ဘောင်ခတ်ပြီး cut list ကို CSV အဖြစ်နှင့် shop drawing များကို PDF အဖြစ် သိမ်းသည်။ စတင်တန်ဖိုးများဖြစ်ပြီး ဖွဲ့စည်းပုံ ဒီဇိုင်း မဟုတ်ပါ။ [ပြားပုံဆွဲများ](topic:panel-drawings) ကို ကြည့်ပါ။
- **သင်္ကေတပြားနှင့် အပင်များ။** {{ui:Build}} › {{ui:သင်္ကေတပြား}} သည် လျှပ်စစ်နှင့် ပိုက်ပြင် သင်္ကေတများကို အမည်ဖြင့် ရှာသည်; {{ui:စာကြည့်တိုက်}} ၏ {{ui:အပင်များ}} source သည် ပလန်သင်္ကေတပါသော အပင် 400 ခန့်ကို စာရင်းပြုသည်။ [သင်္ကေတပြား](topic:symbol-palette) နှင့် [အပင် ထားခြင်း](topic:plant-list) ကို ကြည့်ပါ။

### ပိုက်၊ လေပိုက်နှင့် စွမ်းအင်

- **Split၊ VRF နှင့် fan coil များ။** အတွင်းပိုင်းနှင့် အပြင်ပိုင်း ယူနစ်များ ၎င်းတို့၏ ချိတ်ဆက်မှုများဖြင့်၊ line set များကို သင်ပြောင်းလဲနိုင်သော ဥပမာ တန်ဖိုးများ၏ ဇယားမှ အရွယ်ချိန်သည်။ [Split၊ VRF နှင့် fan coil များ](topic:split-vrf-fan-coils) ကို ကြည့်ပါ။
- **တွက်ချက်မှုများ။** Calculations panel သည် supply ပိုက်နှင့် လေပိုက် အရွယ်များကို pressure drop ဖြင့် စစ်ဆေး၊ ကေဘယ်များကို tray နှင့် conduit မှ ဖြတ်ပြီး ၎င်းတို့၏ ဖြည့်မှုကို ပြ၊ နှင့် IES သို့မဟုတ် EULUMDAT ဖိုင်များမှ illuminance ကို တွက်သည်။ ပုံမှန် တန်ဖိုးများကို အမှတ်အသားပြုထားသည်; သင့်ကုဒ်၏ တန်ဖိုးများကို ရိုက်ထည့်ပါ။ [ပိုက်၊ လေပိုက်၊ ကေဘယ်နှင့် မီးရောင် တွက်ချက်မှုများ](topic:mep-calculations) ကို ကြည့်ပါ။
- **PCF ဖိုင်များ။** ပိုက် ကိရိယာ၏ **Export PCF** သည် pipe-stress နှင့် isometric ပရိုဂရမ်များအတွက် run များကို ရေးသည်၊ ပြန်ဖတ်သော PCF ဖိုင်သည် ၎င်း၏ ပိုက်ကို ဆွဲသည်။ [ပိုက် ပစ္စည်းဖိုင်များ](topic:piping-pcf) ကို ကြည့်ပါ။
- **Solar PV။** ခေါင်မိုး သို့မဟုတ် မြေပေါ်တွင် array များ ထည့်၊ မော်ဒယ်မှ ရိပ်ကွက်ချ၊ နှစ်စဉ် စွမ်းအင် ခန့်မှန်း၊ string များ စစ်ဆေး၊ one-line diagram ဒေတာ ပြုလုပ်သည်။ စတင်မော်ဂျူးနှင့် ဆုံးရှုံးမှုများသည် generic ဖြစ်သည်။ [Solar PV](topic:solar-pv) ကို ကြည့်ပါ။
- **EnergyPlus ဖိုင်။** EnergyPlus ဖြင့် စစ်ဆေးခြင်း panel သည် မော်ဒယ်ကို သင့် EnergyPlus တွင် run ရန် IDF အဖြစ် ရေးသည်။ Browser တွင် run ရန် သင် host လုပ်သော build လိုအပ်ပြီး ၎င်း၏ လိပ်စာကို ရိုက်ရမည်; BimCraft တွင် မပါဝင်ပါ။ [EnergyPlus ဖြင့် အပူနှင့် အေးမှု စစ်ဆေးခြင်း](topic:check-with-energyplus) ကို ကြည့်ပါ။

### ပုံများနှင့် ဖိုင်များ

- **Render engine ရွေးခြင်း။** {{ui:ရုပ်ပုံထုတ်ရန်}} တွင် {{ui:အင်ဂျင်}} ရွေးချယ်မှု ရှိသည်။ built-in engine နှစ်ခု (Fast နှင့် Path tracer) သည် မူလအတိုင်း ဆက်ရှိသည်။ **ဤတွင်ဖွင့်ရန်** သည် scene ကို USD သို့မဟုတ် glTF ဖိုင်အဖြစ် သိမ်းသည်၊ Unreal ပရောဂျက်ဖိုဒါကို .zip အဖြစ်; CadCraft Studio တွင် add-on တစ်ခုက engine ထည့်နိုင်သည်။ ပရောဂျက်ကို ဖွင့်သော Unreal plug-in ကို မထုတ်ပြန်သေးပါ။ [ပုံကို မည်သည့်ပရိုဂရမ်က ဆွဲမည်ကို ရွေးခြင်း](topic:render-engines) ကို ကြည့်ပါ။
- **Studio undo။** CadCraft Studio အတွင်း BimCraft သည် ပြီးစီးသော အဆင့်တိုင်းကို Studio သို့ ပြောပြသောကြောင့် Studio သည် နောက်ဆုံးသုံးခဲ့သော ဝင်းဒိုးတွင် နောက်ဆုံးအဆင့်ကို ပြန်ဖျက်နိုင်သည်။ [အက်ပ်များကြား undo](topic:undo-across-apps) ကို ကြည့်ပါ။
- **ဖိုင်ထဲရှိ add-on များ။** IFC တွင် မည်သည့် add-on များက ရေးသားခဲ့သည်ကို မှတ်ထားပြီး ဖွင့်သည့်အခါ သင်မရှိသော add-on များကို ပေးသည်။ [ဖိုင်ထဲရှိ add-on များ](topic:add-ons-in-your-file) ကို ကြည့်ပါ။

### အက်ပ်တိုင်းတွင်

- **AI ကို ချိတ်ဆက်ခြင်း။** သင့်ကိုယ်ပိုင် assistant သည် Studio ၏ ချိတ်ဆက်မှုမှတစ်ဆင့် BimCraft ကို ထိန်းချုပ်နိုင်ပြီး မော်ဒယ်အကြောင်း မေးခွန်းများကို ဖြေနိုင်သည်၊ ဥပမာ ဧရိယာတစ်ခုအောက်ရှိ အခန်းများ။ Studio တွင် ကိုယ်ပိုင် AI မရှိပါ။ [AI assistant ဖြင့် မော်ဒယ်ကို လုပ်ဆောင်ခြင်း](topic:assistants) ကို ကြည့်ပါ။
- **ကိရိယာဘား အတန်းများ။** {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:ကိရိယာဘား အတန်းများ}} တွင် Wrap၊ 2 rows သို့မဟုတ် 1 row ရွေးနိုင်သည်; Wrap သည် မူလအတိုင်း ဖြစ်သည်။

- **DWG classes အပိုင်း။** မှားသော အမျိုးအစားအဖြစ် ဖတ်ခဲ့သည်; BimCraft နှင့် DWG ကို ဖတ်သော အခြား အက်ပ်များတွင် ပြင်ထားပြီး။
- **Run ချိန်ရှိ ဘာသာစကား။** Studio နှင့် packed edition များသည် ယခု restart မလုပ်ဘဲ ဘာသာစကား ပြောင်းနိုင်သည်။ ပလက်ဖောင်းအားလုံးတွင် မစမ်းသပ်ရသေးပါ; ဘာသာစကား မပြောင်းလျှင် ကျွန်ုပ်တို့အား အကြောင်းကြားပါ။
- **Archicad bundle script။** `archicad_bundle.py` (သီးခြား ဒေါင်းလုဒ်) သည် Archicad ၏ path ကို ယခု ရှာပြီး ဖိုဒါကို စက္ကန့် 20 အထိ စောင့်ကြည့်ကာ bundle ဘေးတွင် ပြန်ကြိုးစားသည်။

## ဤဗားရှင်းတွင် မပါသေးသော အရာများ

- **ဘေးကင်းရေးနှင့် ဒီဇိုင်း အကူများ။** အဆောက်အအုံထဲ လူများ ဖြတ်သန်းမှုတွင် ဆောက်လုပ်ရေးကုဒ်မှ ခရီးအကွာအဝေး ကန့်သတ်ချက် မပါဝင်ပါ (သင်က ကန့်သတ်ချက်ကို ရိုက်ထည့်ရမည်) နှင့် အမှန်တကယ် ပလန်တစ်ခုပေါ်တွင် လက်ဖြင့် စစ်ဆေးပြီးမှု မရှိသေးပါ။ အသံ၊ သက်တမ်းနှင့် အန္တရာယ် တန်ဖိုးများသည် စီမံကိန်း တန်ဖိုးများဖြစ်ပြီး ကုဒ် စစ်ဆေးမှု မဟုတ်ပါ။
- **ရာသီဥတု အနာဂတ်နှင့် EnergyPlus။** Built-in ရာသီဥတု အနာဂတ် ခန့်မှန်းချက် မရှိ: ရေလွှမ်းမှု run အတွက် scenario ဖိုင်ကို တင်နိုင်သည်။ Browser တွင် EnergyPlus run သည် ဤထုတ်ပြန်မှုတွင် မပါဝင်ပါ။
- **Ribbon layout။** Material Takeoff သည် BimCraft တွင် material quantity list မရှိသောကြောင့် "Not built" ဖြစ်နေပြီး ကျန် ribbon ကိရိယာ 54 ခု ဝါးနေသည်မှာ နောက်ကွယ်တွင် BimCraft ကိရိယာ မရှိသေးသောကြောင့် ဖြစ်သည်။
- **လက်မှတ်ထိုးခြင်းနှင့် ပလက်ဖောင်းများ။** Windows installer များနှင့် macOS .dmg သည် လက်မှတ်မထိုးထားသောကြောင့် SmartScreen က {{ui:နောက်ထပ် အချက်အလက်}} ၊ ထို့နောက် {{ui:ဘယ်လိုပဲဖြစ်စေ run ရန်}} ကို ပြသသည်၊ macOS တွင် right-click ပြီး {{ui:ဖွင့်ထား}} လုပ်ရမည်။ iPad နှင့် iPhone build ကို 0.8.1 အတွက် ပြန်မတည်ဆောက်ရသေးပါ။
- **စမ်းသပ်ချက် စာမျက်နှာများ။** BimCraft browser test အဟောင်းအချို့သည် ကျွန်ုပ်တို့၏ test page တွင် ကျရှုံးဆဲ ဖြစ်သည်၊ 0.8.1 မတိုင်မီကဲ့သို့ပင်။

ကျန်အရာအားလုံးသည် [မတည်ဆောက်ရသေးသော အရာများ](topic:not-built-yet) တွင် ရှိသည်။ အစောပိုင်း ပြောင်းလဲမှုများသည် [0.7 ၏ အသစ်များ](topic:whats-new-0-7) တွင် ရှိသည်။
