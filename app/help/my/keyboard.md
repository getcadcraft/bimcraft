BimCraft တွင် ဖြတ်လမ်းများ အနည်းငယ်သာ ရှိသည်။ အလုပ်အများစုကို မောက်စ်နှင့် ဘားများဖြင့် လုပ်ဆောင်ပါ။ {{key:Mod}} ဖြင့် ရေးထားသော ဖြတ်လမ်းများသည် Mac တွင် Command ကို၊ အခြားနေရာများတွင် Ctrl ကို သုံးသည်။ ဤအကူအညီတွင် ကီးများကို မည်သို့ ရေးသားသည်ကို [ကီးများ၊ မောက်စ်များနှင့် trackpad များ](common:keys) တွင် ကြည့်ပါ။

## နေရာတိုင်း

| ကီး | ဘာလုပ်ပေးသလဲ |
|---|---|
| {{key:Ctrl+Shift+F}} | မျက်နှာပြင်မုဒ်များကို လှည့်ပါ: ပုံမှန်၊ မျက်နှာပြင်အပြည့်၊ ဘားများဝှက်ထားသော မျက်နှာပြင်အပြည့်။ Mac အပါအဝင် ပလက်ဖောင်းတိုင်းတွင် Ctrl |
| {{key:Esc}} | မျက်နှာပြင်အပြည့်မှ ထွက်ပါ |
| {{key:Mod+,}} | {{ui:Settings}} ကို ဖွင့်ပါ။ [BimCraft ဆက်တင်များ](topic:settings) ကို ကြည့်ပါ |
| {{key:Tab}} | ခလုတ်များ၊ checkbox များနှင့် တန်ဖိုးများကြား ရွှေ့ပါ။ ထိန်းချုပ်မှုအားလုံးကို ကီးဘုတ်ဖြင့် ရောက်နိုင်သည် |

## 3D မြင်ကွင်း (IFC မော်ဒယ်များ)

| ကီး သို့မဟုတ် လုပ်ဆောင်ချက် | ဘာလုပ်ပေးသလဲ |
|---|---|
| {{key:F}} | မော်ဒယ်တစ်ခုလုံးကို သုံးပုံလေးပုံ မြင်ကွင်းဖြင့် ကိုက်ညီအောင် ပြပါ (အလားတူ {{ui:Fit}}) |
| {{key:Esc}} | ရွေးထားမှုကို ရှင်းပါ၊ သို့မဟုတ် နေရာချခြင်း သို့မဟုတ် ကူးထည့်ခြင်းကို ရပ်ပါ |
| နှိပ်ခြင်း | ညွှန်ပြချက်အောက်ရှိ ဒြပ်စင်ကို ရွေးပါ; နောက်ခံအလွတ်ကို နှိပ်လျှင် ရှင်းပါ |
| {{key:Mod}}+နှိပ်ခြင်း သို့မဟုတ် {{key:Shift}}+နှိပ်ခြင်း | ဒြပ်စင်ကို ရွေးမှုထဲ ထည့်ပါ သို့မဟုတ် ထုတ်ပါ |
| {{key:H}} | ရွေးထားသော ဒြပ်စင်များကို ဝှက်ပါ။ [ဒြပ်စင်များကို ဝှက်ခြင်း၊ သီးသန့်ပြခြင်းနှင့် ဖောက်ထွင်းမြင်ခြင်း](topic:hide-and-isolate) ကို ကြည့်ပါ |
| {{key:I}} | ရွေးထားသော ဒြပ်စင်များကိုသာ ပြပါ (သီးသန့်ပြ) |
| {{key:T}} | ရွေးထားသော ဒြပ်စင်များကို ပြပြီး အခြားအရာအားလုံးကို ဖောက်ထွင်းမြင်ရအောင် ထားပါ |
| {{key:Shift+H}} | ဒြပ်စင်အားလုံးကို ပြန်ပြပါ |
| {{ui:Walk}} | ထို့နောက် {{key:W}} {{key:A}} {{key:S}} {{key:D}} သို့မဟုတ် မြားများဖြင့် လျှောက်ပါ၊ {{key:Shift}} ဖြင့် ပြေးပါ၊ ဆွဲလျှင် ကြည့်ပတ်ပါ၊ {{key:Esc}} ဖြင့် ရပ်ပါ။ [မော်ဒယ်ထဲ လျှောက်ခြင်း](topic:walk) ကို ကြည့်ပါ |
| {{key:M}} | အကွာအဝေးနှင့် မျက်နှာပြင်ဧရိယာ တိုင်းတာပါ။ [3D ရှိ အကွာအဝေး၊ မျက်နှာပြင်ဧရိယာနှင့် နေရာများကို တိုင်းတာခြင်း](topic:measure) ကို ကြည့်ပါ |
| ဘယ်ဘက်ခလုတ်ဖြင့် ဆွဲခြင်း | Orbit |
| ညာဘက်ခလုတ်ဖြင့် ဆွဲခြင်း | Pan |
| {{key:Shift}} သို့မဟုတ် {{key:Mod}} ကို ဖိ၍ ဘယ်ဘက်ခလုတ်ဖြင့် ဆွဲခြင်း | Pan (trackpad တွင် အထောက်အကူ) |
| ဘီးကို လှိမ့်ခြင်း၊ သို့မဟုတ် အလယ်ခလုတ်ဖြင့် ဆွဲခြင်း | Zoom |
| trackpad တွင် လက်ညှိုးနှစ်ချောင်းဖြင့် ဆွဲခြင်း သို့မဟုတ် ညှစ်ခြင်း | Zoom |
| လက်ညှိုးတစ်ချောင်း (touch) | Orbit; တစ်ချက်နှိပ်ခြင်းက ရွေးသည် |
| လက်ညှိုးနှစ်ချောင်း (touch) | ညှစ်၍ zoom လုပ်ပါ၊ အတူရွှေ့ခြင်းဖြင့် pan လုပ်ပါ |

| {{key:X}} | ဖြတ်ပိုင်းပြားကို ဖွင့်/ပိတ်ပါ။ [section plane ဖြင့် IFC မော်ဒယ်ကို ဖြတ်ခြင်း](topic:section-plane) ကို ကြည့်ပါ |
| {{key:Shift+X}} | ရွေးထားသော ဒြပ်စင်များပတ်လည်တွင် section box၊ Settings တွင် သတ်မှတ်ထားသော အခန်းနှင့်အတူ |

{{ui:Top}}၊ {{ui:Front}} နှင့် {{ui:Side}} အတွက် ကီးမရှိပါ၊ ခလုတ်များကို သုံးပါ။

## တည်းဖြတ်ရန်

တူညီသော အမိန့်များကို toolbar တွင်လည်း ရှိသည်: {{ui:Undo}}၊ {{ui:Redo}}၊ {{ui:Copy}}၊ {{ui:Paste}} နှင့် {{ui:More}} မီနူး ဖြစ်ပြီး ၎င်းတွင် ကီးတစ်ခုစီကို ပြသသည်။ ၎င်းတို့သည် IFC မော်ဒယ်၏ 3D မြင်ကွင်းတွင် အလုပ်လုပ်ပြီး အကွက်တစ်ခုတွင် စာရိုက်နေချိန်တွင် မလုပ်ပါ။ [စာကြည့်တိုက် ပစ္စည်းများကို ကူးခြင်း၊ ကူးထည့်ခြင်းနှင့် ပွားခြင်း](topic:copy-paste) ကို ကြည့်ပါ။

| ကီး | ဘာလုပ်ပေးသလဲ |
|---|---|
| {{key:Mod+Z}} | နောက်ဆုံးပြောင်းလဲမှုကို ပြန်ဖျက်ပါ |
| {{key:Mod+Y}} သို့မဟုတ် {{key:Mod+Shift+Z}} | Undo ဖြုတ်ထားသည့်အရာကို ပြန်လုပ်ပါ |
| {{key:Mod+C}} | ရွေးထားသော ဒြပ်စင်များကို ကူးပါ (၎င်းတို့၏ အမည်နှင့် ဂုဏ်သတ္တိများကို စာသားအဖြစ် clipboard သို့လည်း ပို့သည်) |
| {{key:Mod+X}} | ရွေးထားသော ဒြပ်စင်များကို ဖြတ်ပါ: ကူးပြီးနောက် ဖျက်ပါ |
| {{key:Mod+V}} | ကူးထားသည်ကို ကူးထည့်ပါ: ညွှန်ပြချက်ကို လိုက်သည်၊ သွားလိုသော နေရာတွင် နှိပ်ပါ |
| {{key:Mod+Shift+V}} | မူလနေရာတွင် ကူးထည့်ပါ: ဖြတ်ထားခဲ့သည့်နေရာ သို့မဟုတ် ကူးပြီးနောက် မူလအရာဘေးတွင် |
| {{key:Mod+D}} | ပွားပါ: ရွေးထားသော ဒြပ်စင်များကို ကူးပြီး ကူးထည့်ခြင်းကို စတင်ပါ |
| {{key:Delete}} | ရွေးထားသော ဒြပ်စင်များကို ၎င်းတို့၏ အစိတ်အပိုင်းများနှင့် အပေါက်များအပါအဝင် ဖျက်ပါ။ [အဆောက်အအုံ ဒြပ်စင်များကို ဖျက်ခြင်း၊ ဖြတ်ခြင်း၊ ကူးခြင်းနှင့် ကူးထည့်ခြင်း](topic:edit-elements) ကို ကြည့်ပါ |
| {{key:Mod+A}} | ပြထားသော ဒြပ်စင်အားလုံးကို ရွေးပါ |
| {{key:Esc}} | ဘာမှမရွေးပါ |

စာမျက်နှာပေါ်တွင် စာသားကို ရွေးထားသည့်အခါ {{key:Mod+C}} သည် စာသားကို ပုံမှန်အတိုင်း ကူးပေးသည်။

## ပုံဆွဲ မြင်ကွင်း (Draw)

ဤလုပ်ဆောင်ချက်များသည် {{ui:Draw}} ဖွင့်ထားပြီး အကွက်တစ်ခုတွင် စာမရိုက်နေချိန်တွင် အလုပ်လုပ်သည်။ [နံရံများ ဆွဲခြင်း](topic:draw-walls) နှင့် [တံခါးများနှင့် ပြတင်းပေါက်များ](topic:doors-and-windows) ကို ကြည့်ပါ။

| ကီး သို့မဟုတ် လုပ်ဆောင်ချက် | ဘာလုပ်ပေးသလဲ |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | {{ui:Door}} သို့မဟုတ် {{ui:Window}} နှင့်အတူ: ခုံကို အခြားဘက်အဆုံးတွင် ထားပါ |
| နံရံဆွဲနေစဉ် {{key:Shift}} | 0°၊ 90°၊ 180° သို့မဟုတ် 270° တွင် ထားပါ |
| ဂဏန်းများနှင့် ပေ နှင့် လက်မ အမှတ်များ (`'` နှင့် `"`) | {{ui:Length}} အကွက်ထဲသို့ အလျားကို ရိုက်စတင်ပါ; {{key:Enter}} ဖြင့် အသုံးပြုပါ |
| {{key:Enter}}၊ {{key:Esc}}၊ ညာခလုတ်နှိပ်ခြင်း သို့မဟုတ် နှစ်ချက်နှိပ်ခြင်း | ဆွဲနေသော နံရံကို အဆုံးသတ်ပါ; {{key:Esc}} ထပ်နှိပ်ပါက {{ui:Select}} သို့ ပြန်သွားသည် |
| {{key:Delete}} | ရွေးထားသော နံရံများ၊ တံခါးများနှင့် ပြတင်းပေါက်များကို ဖျက်ပါ; ကျန်နံရံများ ပြန်ဆက်သွားသည် |
| ညွှန်ပြချက် ပုံဆွဲပေါ်ရှိ နေစဉ် {{key:F}} | ပုံဆွဲကို ကိုက်ညီအောင် ပြပါ |
| ဘီးကို လှိမ့်ခြင်း | ညွှန်ပြချက်ဘက်သို့ zoom လုပ်ပါ |
| အလယ် သို့မဟုတ် ညာခလုတ်ဖြင့် ဆွဲခြင်း၊ သို့မဟုတ် {{key:Space}} ကို ဖိ၍ ဆွဲခြင်း | Pan; {{ui:Select}} ဖွင့်ထားလျှင် ရိုးရိုးဆွဲခြင်းလည်း pan လုပ်သည် |
| {{ui:Select}} ဖြင့် တံခါး သို့မဟုတ် ပြတင်းပေါက်ကို ဆွဲခြင်း | ၎င်း၏ နံရံတစ်လျှောက် သို့မဟုတ် အခြားနံရံပေါ်သို့ ရွှေ့ပါ |
| လက်ညှိုးနှစ်ချောင်း (touch) | ညှစ်၍ zoom လုပ်ပါ၊ အတူရွှေ့ခြင်းဖြင့် pan လုပ်ပါ |

## စာကြည့်တိုက် ပစ္စည်းများ နေရာချခြင်းနှင့် ကူးထည့်ခြင်း

| ကီး | ဘာလုပ်ပေးသလဲ |

| {{key:Esc}} | ပယ်ဖျက်ပြီး မူလတန်ဖိုးကို ပြန်ထားပါ |
| အခြားနေရာကို နှိပ်ခြင်း | ရိုက်ထားသော တန်ဖိုးကို ထိန်းပါ |
| {{key:Mod+Z}} | နောက်ဆုံးပြောင်းလဲမှုကို ပြန်ဖျက်ပါ။ သိမ်းမထားသော ပြောင်းလဲမှု ရှိနေစဉ်နှင့် အကွက်တစ်ခုတွင် စာမရိုက်နေချိန်တွင်သာ |
| {{key:Mod+Y}} | Undo ဖြုတ်ထားသည့်အရာကို ပြန်လုပ်ပါ |
| {{key:Mod+S}} | IFC အဖြစ် သိမ်းပါ။ သိမ်းမထားသော ပြောင်းလဲမှု ရှိနေစဉ်သာ; မဟုတ်လျှင် ဘရောက်ဇာ၏ သိမ်းသည့်အမိန့် ပွင့်သည် |

ကီးဘုတ်ဖြင့်သာ တည်းဖြတ်ရန်: တန်ဖိုးတစ်ခု မီးမောင်းသည်အထိ {{key:Tab}} ကို နှိပ်ပြီး၊ ထို့နောက် ရိုက်စတင်ရန် {{key:Enter}} ကို နှိပ်ပါ။
