## လုပ်ဆောင်မည့်အရာ

တူညီသော နေရာတစ်ခု၏ scan အများအပြား (scanner နေရာစီမှ) သည် ၎င်းတို့၏ ကိုယ်ပိုင် coordinate များဖြင့် စတင်သည်။ ၎င်းတို့ကို register လုပ်ပါ: scan တစ်ခုစီကို နေရာချထားမှု တစ်ခုပေးပါ၊ ထို့ကြောင့် အားလုံးသည် frame တစ်ခုတည်းတွင် ရှိနေမည်၊ ထို့နောက် ပရောဂျက်အဖြစ် သိမ်းပြီး registered cloud ကို LAS သို့မဟုတ် E57 ဖိုင်တစ်ခုအဖြစ် ရေးပါ။

## Scan များကို နေရာချထားခြင်း

1. ဒိုင်ယာလော့ဂ် ကို ဖွင့်ပါ ({{ui:Register scans…}} ကို စတင် panel တွင်၊ သို့မဟုတ် မော်ဒယ် ဖွင့်ပြီးနောက် {{ui:Show}} › {{ui:Register scans…}})။ {{ui:Add scans…}} သည် LAS, LAZ, E57, PLY, PCD, PTX, PTS သို့မဟုတ် XYZ ဖိုင်များကို လက်ခံသည်၊ သို့မဟုတ် ဒိုင်ယာလော့ဂ်ပေါ် ချပါ။ မတူညီသော ယူနစ်သုံးထားသော scan များကို မှတ်ချက်ဖြင့် ငြင်းပယ်သည်: အရင် တစ်ခုကို ပြောင်းပါ။
2. {{ui:Scan to move}} နှင့် {{ui:Place against}} ကို ရွေးပါ။ ပုံသည် ယခုအခြေအနေရှိ scan တိုင်းကို frame တွင် အရောင်တစ်ခုစီဖြင့် ပြသည်: {{ui:Plan}}၊ {{ui:Front}} သို့မဟုတ် {{ui:Side}}; ရွှေ့ရန် ဆွဲပါ၊ zoom ဝင်/ထွက် ဖို့ wheel ကို သုံးပါ။
3. **Point အတွဲများဖြင့်။** {{ui:Pick a pair}} ကို နှိပ်ပြီး ရွှေ့ရမည့် scan ပေါ်ရှိ point တစ်ခု၊ ထို့နောက် အခြား scan ပေါ်ရှိ တူညီသော နေရာ (corner၊ target၊ ကော်လံ၏ အောက်ခြေ) ကို နှိပ်ပါ။ အနည်းဆုံး သုံးကြိမ် လုပ်ပါ၊ မျဉ်းတစ်ကြောင်းတည်းတွင် မရှိသော၊ ဝေးဝေးကွဲနေသော point များဖြင့်။ {{ui:Place by pairs}} ကို နှိပ်ပါ: scan ကို least-squares fit ဖြင့် နေရာချသည်၊ နှင့် **ကျန်နေသည်** က အတွဲတစ်ခုစီ မည်မျှ မကိုက်ညီသေးကို ပြသည်။ နံပါတ်ကြီးသော အတွဲသည် မှားသော ရွေးချယ်မှု ဖြစ်သည်: လက်ကွပ်ဖြင့် ဖယ်ရှားပြီး ထပ်နေရာချပါ။
4. **Target များဖြင့်။** Point တစ်ခု၏ မှန်ကန်သော coordinate များ သိပါက (စစ်တမ်း target များ)၊ {{ui:Pick, then type target}} ကို နှိပ်ပါ၊ ၎င်း scan ပေါ်ရှိ point ကို နှိပ်ပြီး row တွင် target ၏ X၊ Y နှင့် Z ကို ရိုက်ပါ။ အတွဲများနှင့် ရိုက်ထားသော target များကို လွတ်လပ်စွာ ရောနိုင်သည်။

## ICP ဖြင့် ညှိခြင်း

အတွဲများက ကြမ်းကြမ်းသော နေရာချထားမှုကို ပေးသည်။ {{ui:Refine}} သည် scan ကို အခြား scan ၏ မျက်နှာပြင်များပေါ် ရောက်အောင် ရွှေ့သည်: ပထမ **point မှ point သို့**၊ ထို့နောက် **point မှ plane သို့**။ ဇယားက အဆင့်တစ်ခုစီကို error နှင့် ကိုက်ညီခဲ့သော အမှတ် အရေအတွက်ဖြင့် ဖော်ပြသည်; ၎င်းအထက်ရှိ မျဉ်းက error ကျဆင်းလာပုံကို ဆွဲပြသည်။ {{ui:Stop}} သည် လက်ရှိ အဆင့်ပြီးသည်နှင့် run ကို ရပ်ပြီး ရောက်ခဲ့သည့်အရာကို ထိန်းထားသည်။ {{ui:Undo}} သည် run တစ်ခုလုံး (သို့မဟုတ် နောက်ဆုံး နေရာချထားမှု) ကို ပြန်ဖျက်သည်; {{ui:Reset}} သည် scan ကို ၎င်း၏ ဖိုင် coordinate များသို့ ပြန်ထားသည်။

Laptop တွင် မြန်စေရန် ICP သည် ပေါ့ပါးသွားသော အမှတ်ခွဲ (decimated) အစိတ်အပိုင်းပေါ် အလုပ်လုပ်သည် ({{ui:Points used}}, 5,000 မှ 60,000) နှင့် {{ui:Largest match distance}} ထက် ဝေးသော ကိုက်ညီမှုများကို လျစ်လျူရှုသည် (မူရင်း scan အရွယ်အစား၏ 5% ဖြစ်ပြီး ငြိမ်လာသည်နှင့်အမျှ ပိုသေးလာသည်)။ ၎င်းသည် ပထမဦးဆုံး ကြမ်းကြမ်း နေရာချထားမှု လိုအပ်သည်: သိသိသာသာ မထပ်နေသော scan များသည် ကိုက်ညီ၍ မရကြောင်း ပြသည်။ မျက်နှာပြင်များသည် ပြန့်ပြား သို့မဟုတ် မျဉ်းဖြောင့် တစ်ခုတည်းသာ ဖြစ်လျှင် ၎င်းတို့၏ ကိုယ်ပိုင် အတိုင်းအတာအတွင်း နေရာကို ပြင်၍ မရပါ; ထိုအခါ အတွဲများ ထည့်ပါ။

## သိမ်းခြင်းနှင့် ထုတ်ခြင်း

- {{ui:Save project}} သည် `.ccscans.json` ဖိုင်သေးငယ်တစ်ခုကို ရေးသည်: scan တစ်ခုစီ၏ အမည်၊ အရွယ်အစားနှင့် ပထမ 64 KB ၏ fingerprint၊ ၎င်း၏ transform နှင့်အတူ။ Point မပါပါ။ {{ui:Open project…}} သည် scan ဖိုင်များကို ထို ရည်ညွှန်းချက်များဖြင့် ရှာသည် (ဖိုင်များကို အရင် ထည့်ထားရမည်) နှင့် transform အားလုံးကို ပြန်ထည့်သည်။
- {{ui:Export LAS}} နှင့် {{ui:Export E57}} သည် ဖိုင်တစ်ခုတည်းတွင် scan အားလုံးကို ၎င်းတို့၏ registered နေရာဖြင့် ရေးသည်။ မူရင်း ဖိုင်များ၏ အမှတ်များကို ဘယ်တော့မှ ပြန်မရေးပါ; transform ကို ထုတ်သည့်အချိန်တွင် အသုံးချသည်။ {{ui:Read every point from the files}} ဖွင့်ထားလျှင် ဖိုင်တစ်ခုစီကို အမှတ်တိုင်းအတွက် ထပ်ဖတ်သည် (scan တစ်ခုလျှင် 20 သန်းအထိ); ပိတ်ထားလျှင် viewer တွင် ပြနေသော အမှတ်များသာ ရေးသည်။
- {{ui:Show registered cloud}} (BimCraft) သည် LAS ကို ရေးပြီး ၎င်းကို မည်သည့် cloud ကဲ့သို့မဆို 3D view တွင် မော်ဒယ်ဘေးတွင် ဖွင့်သည်။

:::note
ဘာမျှ upload မလုပ်ပါ။ Registration သည် ဖိုင်များ၏ ကိုယ်ပိုင် ယူနစ်ဖြင့် လုပ်ဆောင်ပြီး မီလီမီတာကို ထိန်းထားသည်: LAS ကို ကိုက်ညီသော scale ဖြင့် ရေးသည် (0.1 mm အထိ)၊ E57 ကို double ဖြင့် ရေးသည်။ Coordinate system ကို LAS ထဲသို့ scan အားလုံးက EPSG code တူညီစွာ ပြောသည့်အခါမှသာ ထည့်သည်။ E57 writer သည် ကိုယ်ပိုင် ဖြစ်ပြီး ၎င်းဖိုင်များကို ဤ reader နှင့် libE57Format ဖြင့် ပြန်ဖတ်၍ စစ်ဆေးထားသည်။
:::
