BimCraft ma niewiele skrótów. Większość pracy wykonujesz myszą i panelami. Skróty zapisane z {{key:Mod}} używają Command na Macu, a Ctrl w pozostałych systemach. Zobacz [Klawisze, myszy i gładziki](common:keys), aby dowiedzieć się, jak klawisze są zapisane w tej pomocy.

## Wszędzie

| Klawisz | Co robi |
|---|---|
| {{key:Ctrl+Shift+F}} | Przełącza tryby ekranu: normalny, pełny ekran, pełny ekran z ukrytymi paskami. Zawsze Ctrl, także na Macu |
| {{key:Esc}} | Wyjście z pełnego ekranu |
| {{key:Mod+,}} | Otwiera {{ui:Ustawienia}}. Zobacz [Ustawienia BimCraft](topic:settings) |
| {{key:Tab}} | Przechodzi między przyciskami, polami wyboru i wartościami. Do każdej kontrolki można dotrzeć z klawiatury |

## Widok 3D (modele IFC)

| Klawisz lub akcja | Co robi |
|---|---|
| {{key:F}} | Dopasowuje cały model, widok z trzech czwartych (tak samo jak {{ui:Dopasuj}}) |
| {{key:Esc}} | Czyści zaznaczenie albo przerywa umieszczanie lub wklejanie |
| Kliknięcie | Wybiera element pod wskaźnikiem; kliknięcie pustego tła czyści zaznaczenie |
| {{key:Mod}}+kliknięcie lub {{key:Shift}}+kliknięcie | Dodaje element do wyboru albo go z niego usuwa |
| {{key:H}} | Ukrywa wybrane elementy. Zobacz [Ukrywanie, izolowanie i przezroczystość elementów](topic:hide-and-isolate) |
| {{key:I}} | Pokazuje tylko wybrane elementy (izolacja) |
| {{key:T}} | Pokazuje wybrane elementy, a reszta jest przezroczysta |
| {{key:Shift+H}} | Ponownie pokazuje wszystkie elementy |
| {{ui:Spacer}} | Następnie {{key:W}} {{key:A}} {{key:S}} {{key:D}} lub strzałki poruszają po modelu, {{key:Shift}} przyspiesza, przeciągnięcie rozgląda się, {{key:Esc}} zatrzymuje. Zobacz [Spacer po modelu](topic:walk) |
| {{key:M}} | Mierzy odległości i pola powierzchni ścian. Zobacz [Pomiar odległości, pól powierzchni i położeń w 3D](topic:measure) |
| Przeciągnięcie lewym przyciskiem | Obrót |
| Przeciągnięcie prawym przyciskiem | Przesunięcie |
| {{key:Shift}} lub {{key:Mod}} i przeciągnięcie lewym przyciskiem | Przesunięcie (wygodne na gładziku) |
| Przewinięcie kółkiem lub przeciągnięcie środkowym przyciskiem | Powiększenie |
| Przewinięcie dwoma palcami lub uszczypnięcie na gładziku | Powiększenie |
| Jeden palec (dotyk) | Obrót; stuknięcie wybiera |
| Dwa palce (dotyk) | Uszczypnięcie powiększa, przesunięcie razem przesuwa |

| {{key:X}} | Włącza i wyłącza płaszczyznę przekroju. Zobacz [Przecięcie modelu IFC płaszczyzną przekroju](topic:section-plane) |
| {{key:Shift+X}} | Pudełko przekroju wokół wybranych elementów, z pomieszczeniem ustawionym w Ustawieniach |

Nie ma klawiszy dla {{ui:Góra}}, {{ui:Przód}} i {{ui:Z boku}}; użyj przycisków.

## Edycja

Te same polecenia są na pasku narzędzi: {{ui:Cofnij}}, {{ui:Ponów}}, {{ui:Kopiuj}}, {{ui:Wklej}} oraz menu {{ui:Więcej}}, które pokazuje każdy klawisz. Działają w widoku 3D modelu IFC, nie wtedy, gdy wpisujesz w polu. Zobacz [Kopiowanie, wklejanie i duplikowanie elementów biblioteki](topic:copy-paste).

| Klawisz | Co robi |
|---|---|
| {{key:Mod+Z}} | Cofa ostatnią zmianę |
| {{key:Mod+Y}} lub {{key:Mod+Shift+Z}} | Ponawia to, co Cofnij cofnęło |
| {{key:Mod+C}} | Kopiuje wybrane elementy (ich nazwy i właściwości trafiają też do schowka jako tekst) |
| {{key:Mod+X}} | Wycina wybrane elementy: kopiuje je, a potem usuwa |
| {{key:Mod+V}} | Wkleja to, co skopiowano: podąża za wskaźnikiem, kliknij, gdzie ma trafić |
| {{key:Mod+Shift+V}} | Wkleja w miejscu: tam, skąd pochodzi wycięcie, albo obok oryginałów po kopiowaniu |
| {{key:Mod+D}} | Duplikuje: kopiuje wybrane elementy i zaczyna je wklejać |
| {{key:Delete}} | Usuwa wybrane elementy wraz z ich częściami i otworami. Zobacz [Usuwanie, wycinanie, kopiowanie i wklejanie elementów budynku](topic:edit-elements) |
| {{key:Mod+A}} | Wybiera wszystkie widoczne elementy |
| {{key:Esc}} | Nie zaznacza niczego |

Gdy na stronie zaznaczono tekst, {{key:Mod+C}} kopiuje ten tekst jak zwykle.

## Widok planu (Rysuj)

Działają, gdy {{ui:Rysuj}} jest włączone i nie wpisujesz w polu. Zobacz [Rysowanie ścian](topic:draw-walls) i [Drzwi i okna](topic:doors-and-windows).

| Klawisz lub akcja | Co robi |
|---|---|
| {{key:V}} | {{ui:Zaznacz}} |
| {{key:W}} | {{ui:Ściana}} |
| {{key:D}} | {{ui:Drzwi}} |
| {{key:N}} | {{ui:Okno}} |
| {{key:H}} | Przy {{ui:Drzwi}} lub {{ui:Okno}}: zawiasy na drugim końcu |
| {{key:Shift}} podczas rysowania ściany | Utrzymuje ją pod kątem 0°, 90°, 180° lub 270° |
| Cyfry oraz znaki stopy i cala (`'` i `"`) | Zaczynają wpisywanie długości w polu {{ui:Długość}}; {{key:Enter}} go używa |
| {{key:Enter}}, {{key:Esc}}, prawy przycisk lub dwuklik | Kończy rysowaną ścianę; kolejne {{key:Esc}} wraca do {{ui:Zaznacz}} |
| {{key:Delete}} | Usuwa wybrane ściany, drzwi i okna; pozostałe ściany łączą się ponownie |
| {{key:F}} z wskaźnikiem nad planem | Dopasowuje plan |
| Przewinięcie kółkiem | Powiększa względem wskaźnika |
| Przeciągnięcie środkowym lub prawym przyciskiem albo {{key:Space}} i przeciągnięcie | Przesunięcie; przy włączonym {{ui:Zaznacz}} zwykłe przeciągnięcie też przesuwa |
| Przeciągnięcie drzwi lub okna przy {{ui:Zaznacz}} | Przesuwa je wzdłuż ściany lub na inną ścianę |
| Dwa palce (dotyk) | Uszczypnięcie powiększa, przesunięcie razem przesuwa |

## Umieszczanie i wklejanie elementów biblioteki

| Klawisz | Co robi |
|---|---|
| {{key:R}} | Obraca element o 90° |
| {{key:Tab}} | Przyciąganie do ściany włączone i wyłączone: tył elementu przylega do najbliższej ściany |
| {{key:Enter}} w polu **X, Y (mm)** | Umieszcza element w wpisanym położeniu |
| {{key:Esc}} | Przerywa umieszczanie lub wklejanie |

## Edycja wartości IFC

| Klawisz | Co robi |
|---|---|
| {{key:Enter}} | Zachowuje wpisaną wartość |
| {{key:Esc}} | Anuluje i przywraca starą wartość |
| Kliknięcie gdziekolwiek indziej | Zachowuje wpisaną wartość |
| {{key:Mod+Z}} | Cofa ostatnią zmianę. Tylko gdy masz niezapisane zmiany i nie wpisujesz w polu |
| {{key:Mod+Y}} | Ponawia to, co Cofnij cofnęło |
| {{key:Mod+S}} | Zapisuje jako IFC. Tylko gdy masz niezapisane zmiany; w przeciwnym razie otwiera się własne polecenie zapisu przeglądarki |

Aby edytować samą klawiaturą: naciskaj {{key:Tab}}, aż wartość zostanie podświetlona, a potem naciśnij {{key:Enter}}, aby zacząć wpisywać.

## Rysunki 2D (DWG i DXF)

| Klawisz lub akcja | Co robi |
|---|---|
| {{key:F}} | Dopasowuje rysunek lub arkusz |
| {{key:P}} | Włącza i wyłącza widok wydruku |
| Dwuklik | Dopasowuje |
| Przeciągnięcie dowolnym przyciskiem | Przesunięcie |
| Przewinięcie kółkiem | Powiększa przy wskaźniku |
| Przewinięcie dwoma palcami lub uszczypnięcie na gładziku | Powiększa przy wskaźniku. Przewinięcie dwoma palcami nie przesuwa |
| Jeden palec (dotyk) | Przesunięcie. Powiększanie uszczypnięciem dla rysunków nie jest jeszcze zbudowane |

## Rysunki w 3D

| Klawisz lub akcja | Co robi |
|---|---|
| {{key:3}} | Włącza i wyłącza 3D (także w widoku 2D) |
| {{key:F}} | Zasięg: cały rysunek |
| Przeciągnięcie środkowym lub lewym przyciskiem | Obrót |
| Przeciągnięcie prawym przyciskiem lub {{key:Shift}} i przeciągnięcie | Przesunięcie |
| Przewinięcie kółkiem | Powiększa w stronę tego, co jest pod wskaźnikiem |
| Przewinięcie dwoma palcami na gładziku | Obrót; z {{key:Shift}} przesunięcie |
| Uszczypnięcie na gładziku | Powiększenie |
| Jeden palec (dotyk) | Obrót |
| Dwa palce (dotyk) | Uszczypnięcie powiększa, przesunięcie razem przesuwa |

{{key:F}}, {{key:P}} i {{key:3}} nic nie robią, gdy wpisujesz w polu, gdy widoczne jest zestawienie wyposażenia lub gdy trzymasz {{key:Mod}} albo {{key:Alt}}.
