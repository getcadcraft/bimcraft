BimCraft میانبر کمی دارد. بیشتر کارها با ماوس و پنل‌ها انجام می‌شود. میانبرهایی که با {{key:Mod}} نوشته شده‌اند روی مک از Command و در بقیه جاها از Ctrl استفاده می‌کنند. برای دیدن اینکه کلیدها در این راهنما چطور نوشته می‌شوند، [کلیدها، ماوس و تاچ‌پد](common:keys) را ببینید.

## همه‌جا

| کلید | کاری که انجام می‌دهد |
|---|---|
| {{key:Ctrl+Shift+F}} | جابه‌جایی بین حالت‌های صفحه: عادی، تمام‌صفحه، تمام‌صفحه با پنهان بودن نوارها. Ctrl در همه سکوها، از جمله مک |
| {{key:Esc}} | خروج از تمام‌صفحه |
| {{key:Mod+,}} | باز کردن {{ui:Settings}}. [تنظیمات BimCraft](topic:settings) را ببینید |
| {{key:Tab}} | حرکت بین دکمه‌ها، کادرهای انتخاب و مقادیر. هر کنترل با صفحه‌کلید در دسترس است |

## نمای سه‌بعدی (مدل‌های IFC)

| کلید یا عمل | کاری که انجام می‌دهد |
|---|---|
| {{key:F}} | جا دادن کل مدل، نمای سه‌چهارم (همان {{ui:Fit}}) |
| {{key:Esc}} | پاک کردن انتخاب، یا توقف قرار دادن یا چسباندن |
| کلیک | عنصر زیر نشانگر را انتخاب می‌کند؛ کلیک روی زمینه خالی انتخاب را پاک می‌کند |
| کلیک همراه با {{key:Mod}} یا {{key:Shift}} | یک عنصر را به انتخاب اضافه یا از آن خارج می‌کند |
| {{key:H}} | پنهان کردن عناصر انتخاب‌شده. [پنهان کردن، جداسازی و شفاف کردن عناصر](topic:hide-and-isolate) |
| {{key:I}} | فقط نشان دادن عناصر انتخاب‌شده (جداسازی) |
| {{key:T}} | نشان دادن عناصر انتخاب‌شده، و شفاف بودن بقیه |
| {{key:Shift+H}} | نشان دادن دوباره همه عناصر |
| {{ui:Walk}} | سپس {{key:W}} {{key:A}} {{key:S}} {{key:D}} یا کلیدهای جهت‌نما برای قدم زدن؛ {{key:Shift}} می‌دود، کشیدن برای نگاه به اطراف، {{key:Esc}} توقف. [قدم زدن در مدل](topic:walk) |
| {{key:M}} | اندازه‌گیری فاصله‌ها و مساحت وجوه. [اندازه‌گیری فاصله‌ها، مساحت وجوه و مکان‌ها در سه‌بعدی](topic:measure) |
| کشیدن با دکمه چپ | چرخش |
| کشیدن با دکمه راست | پن |
| {{key:Shift}} یا {{key:Mod}} و کشیدن با دکمه چپ | پن (مناسب تاچ‌پد) |
| چرخ ماوس یا کشیدن با دکمه وسط | زوم |
| اسکرول دو انگشتی یا پینچ روی تاچ‌پد | زوم |
| یک انگشت (لمس) | چرخش؛ ضربه انتخاب می‌کند |
| دو انگشت (لمس) | پینچ برای زوم، حرکت همزمان برای پن |

| {{key:X}} | صفحه برش روشن و خاموش. [برش یک مدل IFC با صفحه برش](topic:section-plane) |
| {{key:Shift+X}} | جعبه برش دور عناصر انتخاب‌شده، با اتاقی که در تنظیمات تعیین شده است |

برای {{ui:Top}}، {{ui:Front}} و {{ui:Side}} کلیدی وجود ندارد؛ از دکمه‌ها استفاده کنید.

## ویرایش

همین دستورها در نوار ابزار هم هستند: {{ui:Undo}}، {{ui:Redo}}، {{ui:Copy}}، {{ui:Paste}} و منوی {{ui:More}} که کلید هر کدام را نشان می‌دهد. این‌ها در نمای سه‌بعدی مدل IFC کار می‌کنند، نه وقتی در یک کادر متن تایپ می‌کنید. [کپی، چسباندن و تکثیر موارد کتابخانه](topic:copy-paste) را ببینید.

| کلید | کاری که انجام می‌دهد |
|---|---|
| {{key:Mod+Z}} | واگرد آخرین تغییر |
| {{key:Mod+Y}} یا {{key:Mod+Shift+Z}} | ازنو برای آنچه واگرد برداشت |
| {{key:Mod+C}} | کپی عناصر انتخاب‌شده (نام و ویژگی‌هایشان هم به‌صورت متن در کلیپ‌بورد می‌رود) |
| {{key:Mod+X}} | برش عناصر انتخاب‌شده: کپی و سپس حذف آن‌ها |
| {{key:Mod+V}} | چسباندن آنچه کپی شده: دنبال نشانگر حرکت می‌کند، با کلیک جایی که باید برود قرار می‌گیرد |
| {{key:Mod+Shift+V}} | چسباندن در همان مکان: جایی که برش از آن آمده، یا کنار اصل‌ها بعد از کپی |
| {{key:Mod+D}} | تکثیر: کپی عناصر انتخاب‌شده و شروع چسباندن آن‌ها |
| {{key:Delete}} | حذف عناصر انتخاب‌شده، همراه با بخش‌ها و بازشدگی‌هایشان. [حذف، برش، کپی و چسباندن عناصر ساختمانی](topic:edit-elements) |
| {{key:Mod+A}} | انتخاب همه عناصر نشان‌داده‌شده |
| {{key:Esc}} | لغو انتخاب همه |

وقتی متنی در صفحه انتخاب شده باشد، {{key:Mod+C}} مثل همیشه آن متن را کپی می‌کند.

## نمای پلان (ترسیم)

این‌ها وقتی کار می‌کنند که {{ui:Draw}} روشن است و در یک کادر متن تایپ نمی‌کنید. [ترسیم دیوار](topic:draw-walls) و [در و پنجره](topic:doors-and-windows) را ببینید.

| کلید یا عمل | کاری که انجام می‌دهد |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | با {{ui:Door}} یا {{ui:Window}}: لولاها در انتهای دیگر |
| {{key:Shift}} هنگام ترسیم دیوار | نگه داشتن آن روی 0، 90، 180 یا 270 درجه |
| ارقام و علامت‌های فوت و اینچ (`'` و `"`) | شروع تایپ طول در کادر {{ui:Length}}؛ {{key:Enter}} آن را به کار می‌برد |
| {{key:Enter}}، {{key:Esc}}، کلیک راست یا دوبار کلیک | پایان دیواری که ترسیم می‌کنید؛ {{key:Esc}} دوباره به {{ui:Select}} برمی‌گردد |
| {{key:Delete}} | حذف دیوارها، درها و پنجره‌های انتخاب‌شده؛ دیوارهای باقی‌مانده دوباره به هم وصل می‌شوند |
| {{key:F}} با نشانگر روی پلان | جا دادن پلان |
| چرخ ماوس | زوم حول نشانگر |
| کشیدن با دکمه وسط یا راست، یا {{key:Space}} و کشیدن | پن؛ با {{ui:Select}} روشن، کشیدن ساده هم پن می‌کند |
| کشیدن در یا پنجره با {{ui:Select}} | جابه‌جایی در امتداد دیوارش، یا روی دیوار دیگر |
| دو انگشت (لمس) | پینچ برای زوم، حرکت همزمان برای پن |

## قرار دادن و چسباندن موارد کتابخانه

| کلید | کاری که انجام می‌دهد |
|---|---|
| {{key:R}} | چرخاندن مورد 90 درجه |
| {{key:Tab}} | روشن و خاموش کردن اسنپ به دیوار: پشت مورد به نزدیک‌ترین دیوار می‌چسبد |
| {{key:Enter}} در **X, Y (mm)** | قرار دادن در موقعیت تایپ‌شده |
| {{key:Esc}} | توقف قرار دادن یا چسباندن |

## ویرایش مقادیر IFC

| کلید | کاری که انجام می‌دهد |
|---|---|
| {{key:Enter}} | نگه داشتن مقدار تایپ‌شده |
| {{key:Esc}} | لغو و برگرداندن مقدار قبلی |
| کلیک جای دیگر | نگه داشتن مقدار تایپ‌شده |
| {{key:Mod+Z}} | واگرد آخرین تغییر. فقط وقتی تغییرات ذخیره‌نشده دارید و در کادر متن تایپ نمی‌کنید |
| {{key:Mod+Y}} | ازنو برای آنچه واگرد برداشت |
| {{key:Mod+S}} | ذخیره به‌عنوان IFC. فقط وقتی تغییرات ذخیره‌نشده دارید؛ در غیر این صورت فرمان ذخیره خود مرورگر باز می‌شود |

برای ویرایش فقط با صفحه‌کلید: {{key:Tab}} را بزنید تا یک مقدار انتخاب شود، سپس {{key:Enter}} را بزنید تا تایپ شروع شود.

## نقشه‌های دو‌بعدی (DWG و DXF)

| کلید یا عمل | کاری که انجام می‌دهد |
|---|---|
| {{key:F}} | جا دادن نقشه یا برگه |
| {{key:P}} | روشن و خاموش کردن نمای چاپ |
| دوبار کلیک | جا دادن |
| کشیدن با هر دکمه | پن |
| چرخ ماوس | زوم در نشانگر |
| اسکرول دو انگشتی یا پینچ روی تاچ‌پد | زوم در نشانگر. اسکرول دو انگشتی پن نمی‌کند |
| یک انگشت (لمس) | پن. پینچ برای زوم نقشه‌ها هنوز ساخته نشده است |

## نقشه‌ها در سه‌بعدی

| کلید یا عمل | کاری که انجام می‌دهد |
|---|---|
| {{key:3}} | روشن و خاموش کردن سه‌بعدی (همچنین در نمای دو‌بعدی) |
| {{key:F}} | حدود: کل نقشه |
| کشیدن با دکمه وسط یا چپ | چرخش |
| کشیدن با دکمه راست، یا {{key:Shift}} و کشیدن | پن |
| چرخ ماوس | زوم به سمت آنچه زیر نشانگر است |
| کشیدن دو انگشتی روی تاچ‌پد | چرخش؛ با {{key:Shift}}، پن |
| پینچ روی تاچ‌پد | زوم |
| یک انگشت (لمس) | چرخش |
| دو انگشت (لمس) | پینچ برای زوم، حرکت همزمان برای پن |

کلیدهای {{key:F}}، {{key:P}} و {{key:3}} هنگامی که در کادر متن تایپ می‌کنید، وقتی جدول تجهیزات نشان داده می‌شود، یا وقتی {{key:Mod}} یا {{key:Alt}} را نگه داشته‌اید، کاری انجام نمی‌دهند.

## فایل‌ها

| عمل | کاری که انجام می‌دهد |
|---|---|
| فایل را روی صفحه بکشید | باز کردن آن |
| پوشه را روی صفحه بکشید | باز کردن آن به‌عنوان پوشه پروژه، بدون درخواست مجوز |
