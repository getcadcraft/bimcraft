## What you'll do

Find what you need in the Library by what it is, add a Type to the project you are drawing, start a new project from a template someone shared, and share your own templates, types and kits.

## The three kinds of Library item

- **Symbols** are drawing conventions: 2D only, drawn at the annotation size, grouped by discipline.
- **Types** say what an element is made of: its layers with their real thickness, its level of development (LOD) and its classification code. A Type is added to the project, not drawn.
- **Assets** are physical objects such as doors, windows, furniture, fixtures and equipment, with a plan view and a 3D body at real size.

In the {{ui:Library}} tab, choose {{ui:Library}} and use **Kind of item** to show Everything, Symbols, Types or Assets.

## Add a Type to your project

1. Choose **Types** under Kind of item and open one.
2. Check its build-up, LOD and classification under the picture, then choose {{ui:Add to this project}}.
3. It is added as a wall, floor, roof or ceiling type you can draw with. If a type with that name is already there, the new one is added as a copy and yours stays as it was. One undo takes it out.

## Project templates and Quick Kits

Choose {{ui:Kits}} to see what people shared.

- **A project template** is an IFC file with levels, grids, types and settings. {{ui:Save to my templates}} puts it in New building under Start from.
- **A Quick Kit** is a list of Library items. {{ui:Show the kit's items}} lists them as cards you can place.
- Every kit has a version and a changelog, newest first. A version that starts with 0 is for discussion; 1.0.0 is only for what the owner of the line has adopted.

## Share your own

- **A project template:** {{ui:Save as template}}, tick {{ui:Also make a file to share in the Library}}, add what it holds and a version. You get a `.json` file.
- **A Quick Kit:** in {{ui:Kits}}, choose {{ui:Make a Quick Kit from this project}}. It lists the Library items the project uses.
- **A Type:** in {{ui:Type packs}}, tick one type and choose {{ui:Save as a Library item…}}.

Upload the file on the Library's upload page. It goes through the same review as any item, and you choose the licence there: every item states its licence. Items are asked for their LOD, an IFC class and a classification code (a code, not just a name).

## Notes from practice

On any Library item's page, signed-in members can add a note: used on a real project, tried on a sample project, or found a problem. Say what kind of project in a few words and leave out client names. A note is public and is not a review: it does not change the item.

## Good to know

- Nothing is sent from the app. The files are made on your computer and you upload them yourself.
- A kit made from a template carries the IFC text exactly as saved. Check it for anything private before you upload.
- CadCraft shows Symbols and Assets in its Library tab; Types and templates are for BimCraft projects.
