BimCraftissa on vain muutama pikanäppäin. Useimmat työt tehdään hiirellä ja paneeleilla. Pikanäppäimet, joissa on {{key:Mod}}, käyttävät Commandia Macissa ja Ctrl-näppäintä muualla. Katso [Näppäimet, hiiri ja kosketuslevy](common:keys), miten näppäimet kirjoitetaan tässä ohjeessa.

## Kaikkialla

| Näppäin | Mitä tekee |
|---|---|
| {{key:Ctrl+Shift+F}} | Vaihtaa näyttötilat: normaali, koko näyttö ja koko näyttö piilotetuilla palkeilla. Ctrl kaikilla alustoilla, myös Macilla |
| {{key:Esc}} | Poistuu koko näytöstä |
| {{key:Mod+,}} | Avaa {{ui:Asetukset}}. Katso [BimCraftin asetukset](topic:settings) |
| {{key:Tab}} | Siirtyy painikkeiden, valintaruutujen ja arvojen välillä. Jokaiseen säätimeen pääsee näppäimistöllä |

## 3D-näkymä (IFC-mallit)

| Näppäin tai toiminto | Mitä tekee |
|---|---|
| {{key:F}} | Sovittaa koko mallin, kolmen neljäsosan näkymä (sama kuin {{ui:Sovita}}) |
| {{key:Esc}} | Tyhjentää valinnan tai lopettaa sijoittamisen tai liittämisen |
| Napsauta | Valitsee osoittimen alla olevan elementin; napsauta tyhjää taustaa tyhjentääksesi |
| {{key:Mod}}+napsautus tai {{key:Shift}}+napsautus | Lisää elementin valintaan tai poistaa sen |
| {{key:H}} | Piilottaa valitut elementit. Katso [Piilota, eristä ja tee läpinäkyviksi elementit](topic:hide-and-isolate) |
| {{key:I}} | Näyttää vain valitut elementit (eristäminen) |
| {{key:T}} | Näyttää valitut elementit, kaikki muu läpinäkyvänä |
| {{key:Shift+H}} | Näyttää jokaisen elementin uudelleen |
| {{ui:Kävely}} | Sen jälkeen {{key:W}} {{key:A}} {{key:S}} {{key:D}} tai nuolet kävelevät, {{key:Shift}} juoksee, vetäminen katsoo ympärille, {{key:Esc}} pysäyttää. Katso [Kävely mallissa](topic:walk) |
| {{key:M}} | Mittaa etäisyyksiä ja pintojen aloja. Katso [Mittaa etäisyyksiä, pinta-aloja ja sijainteja 3D:ssä](topic:measure) |
| Vetäminen vasemmalla painikkeella | Kiertäminen |
| Vetäminen oikealla painikkeella | Panorointi |
| {{key:Shift}} tai {{key:Mod}} ja vetäminen vasemmalla painikkeella | Panorointi (kätevä kosketuslevyllä) |
| Rullan vieritys tai vetäminen keskipainikkeella | Zoomaus |
| Kahden sormen vieritys tai nipistys kosketuslevyllä | Zoomaus |
| Yksi sormi (kosketus) | Kiertäminen; napautus valitsee |
| Kaksi sormea (kosketus) | Nipistys zoomaa, yhdessä liikuttaminen panoroi |

| {{key:X}} | Leikkaustaso päälle ja pois. Katso [Leikkaa IFC-malli leikkaustasolla](topic:section-plane) |
| {{key:Shift+X}} | Leikkauslaatikko valittujen elementtien ympärille, huoneen asetus Asetuksista |

{{ui:Ylhäältä}}-, {{ui:Edestä}}- ja {{ui:Sivu}}-näkymille ei ole näppäimiä; käytä painikkeita.

## Muokkaus

Samat komennot ovat työkalurivillä: {{ui:Kumoa}}, {{ui:Tee uudelleen}}, {{ui:Kopioi}}, {{ui:Liitä}} ja {{ui:Lisää}}-valikko, joka näyttää jokaisen näppäimen. Ne toimivat IFC-mallin 3D-näkymässä, eivät kun kirjoitat kenttään. Katso [Kopioi, liitä ja monista kirjastokohteet](topic:copy-paste).

| Näppäin | Mitä tekee |
|---|---|
| {{key:Mod+Z}} | Kumoaa viimeisimmän muutoksen |
| {{key:Mod+Y}} tai {{key:Mod+Shift+Z}} | Tekee uudelleen sen, minkä Kumoa otti pois |
| {{key:Mod+C}} | Kopioi valitut elementit (niiden nimet ja ominaisuudet menevät myös leikepöydälle tekstinä) |
| {{key:Mod+X}} | Leikkaa valitut elementit: kopioi ne ja poistaa sitten |
| {{key:Mod+V}} | Liittää kopioidut: ne seuraavat osoitinta, napsauta kohtaa, johon ne menevät |
| {{key:Mod+Shift+V}} | Liittää samaan paikkaan: leikkauksen lähtöpaikkaan tai kopioinnin jälkeen alkuperäisten viereen |
| {{key:Mod+D}} | Monistaa: kopioi valitut elementit ja aloittaa niiden liittämisen |
| {{key:Delete}} | Poistaa valitut elementit osineen ja aukkoineen. Katso [Poista, leikkaa, kopioi ja liitä rakennuselementtejä](topic:edit-elements) |
| {{key:Mod+A}} | Valitsee kaikki näkyvät elementit |
| {{key:Esc}} | Poistaa valinnan |

Kun sivulla on tekstiä valittuna, {{key:Mod+C}} kopioi tekstin tavalliseen tapaan.

## Pohjakuvanäkymä (Piirrä)

Nämä toimivat, kun {{ui:Piirrä}} on päällä eikä kirjoita kenttään. Katso [Piirrä seinät](topic:draw-walls) ja [Ovet ja ikkunat](topic:doors-and-windows).

| Näppäin tai toiminto | Mitä tekee |
|---|---|
| {{key:V}} | {{ui:Valitse}} |
| {{key:W}} | {{ui:Seinä}} |
| {{key:D}} | {{ui:Ovi}} |
| {{key:N}} | {{ui:Ikkuna}} |
| {{key:H}} | Kun {{ui:Ovi}} tai {{ui:Ikkuna}} on valittuna: saranat toiseen päähän |
| {{key:Shift}} piirrettäessä seinää | Pitää sen kulmassa 0°, 90°, 180° tai 270° |
| Numerot sekä jalka- ja tuumamerkit (`'` ja `"`) | Aloittaa pituuden kirjoittamisen {{ui:Pituus}}-kenttään; {{key:Enter}} käyttää sitä |
| {{key:Enter}}, {{key:Esc}}, oikea napsautus tai kaksoisnapsautus | Lopettaa piirrettävän seinän; {{key:Esc}} uudelleen palaa {{ui:Valitse}}-tilaan |
| {{key:Delete}} | Poistaa valitut seinät, ovet ja ikkunat; jäljelle jääneet seinät liittyvät uudelleen |
| {{key:F}}, osoitin pohjakuvan päällä | Sovittaa pohjakuvan |
| Rullan vieritys | Zoomaus osoittimen kohdalle |
| Vetäminen keskipainikkeella tai oikealla, tai {{key:Space}} ja vetäminen | Panorointi; kun {{ui:Valitse}} on päällä, pelkkä vetäminen panoroi myös |
| Oven tai ikkunan vetäminen {{ui:Valitse}}-tilassa | Siirtää sitä seinää pitkin tai toiselle seinälle |
| Kaksi sormea (kosketus) | Nipistys zoomaa, yhdessä liikuttaminen panoroi |

## Kirjastokohteiden sijoittaminen ja liittäminen

| Näppäin | Mitä tekee |
|---|---|
| {{key:R}} | Kääntää kohdetta 90° |
| {{key:Tab}} | Seinäkiinnitys päälle ja pois: kohteen takaosa menee lähimpää seinää vasten |
| {{key:Enter}} kentässä **X, Y (mm)** | Sijoittaa kirjoitettuun paikkaan |
| {{key:Esc}} | Lopettaa sijoittamisen tai liittämisen |

## IFC-arvojen muokkaus

| Näppäin | Mitä tekee |
|---|---|
| {{key:Enter}} | Säilyttää kirjoittamasi arvon |
| {{key:Esc}} | Peruuttaa ja palauttaa vanhan arvon |
| Napsautus muualle | Säilyttää kirjoittamasi arvon |
| {{key:Mod+Z}} | Kumoaa viimeisimmän muutoksen. Vain kun sinulla on tallentamattomia muutoksia eikä kirjoita kenttään |
| {{key:Mod+Y}} | Tekee uudelleen sen, minkä Kumoa otti pois |
| {{key:Mod+S}} | Tallentaa IFC:nä. Vain kun sinulla on tallentamattomia muutoksia; muuten avautuu selaimen oma tallennuskomento |

Muokataksesi pelkällä näppäimistöllä: paina {{key:Tab}}, kunnes arvo on korostettu, ja paina sitten {{key:Enter}} aloittaaksesi kirjoittamisen.

## 2D-piirustukset (DWG ja DXF)

| Näppäin tai toiminto | Mitä tekee |
|---|---|
| {{key:F}} | Sovittaa piirustuksen tai arkin |
| {{key:P}} | Tulostusnäkymä päälle ja pois |
| Kaksoisnapsautus | Sovittaa |
| Vetäminen millä tahansa painikkeella | Panorointi |
| Rullan vieritys | Zoomaus osoittimen kohdalle |
| Kahden sormen vieritys tai nipistys kosketuslevyllä | Zoomaus osoittimen kohdalle. Kahden sormen vieritys ei panoroi |
| Yksi sormi (kosketus) | Panorointi. Nipistyszoomaus ei ole vielä toteutettu piirustuksille |

## Piirustukset 3D:nä

| Näppäin tai toiminto | Mitä tekee |
|---|---|
| {{key:3}} | 3D päälle ja pois (myös 2D-näkymässä) |
| {{key:F}} | Laajuus: koko piirustus |
| Vetäminen keskipainikkeella tai vasemmalla | Kiertäminen |
| Vetäminen oikealla, tai {{key:Shift}} ja vetäminen | Panorointi |
| Rullan vieritys | Zoomaus kohti sitä, mikä on osoittimen alla |
| Kahden sormen pyyhkäisy kosketuslevyllä | Kiertäminen; {{key:Shift}}-näppäimen kanssa panorointi |
| Nipistys kosketuslevyllä | Zoomaus |
| Yksi sormi (kosketus) | Kiertäminen |
| Kaksi sormea (kosketus) | Nipistys zoomaa, yhdessä liikuttaminen panoroi |

{{key:F}}, {{key:P}} ja {{key:3}} eivät tee mitään, kun kirjoitat kenttään, kun laiteluettelo näkyy tai kun pidät {{key:Mod}}- tai {{key:Alt}}-näppäintä painettuna.
