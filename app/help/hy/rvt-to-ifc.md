## Ինչ եք անելու

Նախագծային ֆայլը վերածեք IFC ֆայլի, որ BimCraft-ում կարող եք պտտել, զննել, ստուգել և խմբագրել։ BimCraft-ը դեռ չի կարդում `.rvt` ֆայլի ներսի 3D մոդելը, ուստի արտահանումը կատարվում է այն ծրագրում, որ ստեղծել է ֆայլը (Revit)․ BimCraft-ը բացում է արդյունքը։

## Քայլեր

1. Բացեք նախագիծը այն ծրագրում, որում ստեղծվել է։ BimCraft-ի քարտը անվանում է թողարկումը, որով այն պահվել է։
2. Բացեք 3D տեսք, որ ցույց է տալիս այն, ինչ ուզում եք արտահանել։
3. Ընտրեք **File > Export > IFC**։
4. Արտահանման երկխոսության մեջ ընտրեք կարգավորում (կամ **Modify setup…**) ստորև նշված կարգավորումներով։
5. Ընտրեք թղթապանակ և ֆայլի անուն, և արտահանեք։
6. BimCraft-ում սեղմեք {{ui:Ընտրել ֆայլ}} և ընտրեք նոր `.ifc` ֆայլը։ Առանձին ֆայլերով արտահանված կապված մոդելները բացվում են նույն տեսարանում՝ {{ui:Ավելացնել մոդել}}-ով։

## Կարգավորումները, որոնք լավագույնս բացվում են այստեղ

| Կարգավորում արտահանիչում | Ընտրեք | Ինչու |
|---|---|---|
| IFC տարբերակ | **IFC4 Reference View** դիտելու, ստուգելու և քանակները հանելու համար; **IFC2X3 Coordination View 2.0**, երբ ուրիշներին պետք է IFC2X3 | Երկուսն էլ լրիվ բացվում են։ **IFC4 Design Transfer View**-ը նույնպես բացվում է, ավելի ճշգրիտ ձևերով, բայց ֆայլը մեծ է և դանդաղ։ |
| Ֆայլի տեսակ | **IFC** (սովորական) | BimCraft-ը չի բացում `.ifczip` կամ `.ifcxml`։ |
| Փուլ / տեսանելի տարրեր | Փուլը, որ նկատի ունեք, և **Export only elements visible in view**, երբ 3D տեսքը կարգավորում եք դրա համար | Թողնում է դուրս այն, ինչ միտումնավոր թաքցրել եք։ |
| Հատկությունների հավաքածուներ | **Export Revit property sets** և **Export IFC common property sets** | Դրանք դառնում են այն հատկությունների հավաքածուները, որ BimCraft-ը ցույց է տալիս {{ui:Հատկություններ}}-ում, և որոնք օգտագործում են {{ui:Փնտրել}}-ը, {{ui:Գույն}}-ը և {{ui:Մոդելի ստուգումներ}}-ը։ |
| Հիմնական քանակներ | **Export base quantities** | {{ui:Քանակների գումարներ}}-ը և ցանկերը օգտագործում են դրանք (երկարություններ, մակերեսներ, ծավալներ)՝ ենթադրությունների փոխարեն։ |
| Սենյակներ և մակերեսներ | **Export rooms in 3D views** (կամ Rooms / Spaces տարբերակը) | Սենյակները գալիս են որպես տարածություններ․ սեղմեք {{ui:Տարածքներ}}-ը՝ դրանք տեսնելու համար։ |
| Կապված ֆայլեր | **Export linked files as separate IFCs** | Յուրաքանչյուր կապ դառնում է իր ֆայլը․ բացեք դրանք միասին {{ui:Ավելացնել մոդել}}-ով, և նրանք համընկնում են։ |
| Կոորդինատների հիմք | **Shared coordinates** (կամ հետազոտական կետը) | Ֆայլը այդ դեպքում կրում է իր տեղը քարտեզի վրա (IfcMapConversion), ուստի Չափում › Տեղադրություն-ը, գետնի վրա քարտեզի շերտերը և քարտեզի կոորդինատներով տեղադրված ամպային կետերը աշխատում են։ Նախագծի հիմնական կետը մոդելը պահում է ծագման մոտ, բայց առանց իր քարտեզի տեղի։ |
| Պատերի և սյուների բաժանում ըստ մակարդակի | Միացված, երբ քանակները հաշվում եք յուրաքանչյուր հարկով | Յուրաքանչյուր հարկի մասը առանձին տարր է։ |

## Ինչ պետք է տեսնեք

Մոդելը 3D-ում, հարկերը վերցված նախագծի մակարդակներից, և նախագծի տեղեկությունը {{ui:Ֆայլ}} վահանակում։ **Exported from** դաշտը անվանում է արտահանիչը։

## Ինչ է պահում արտահանումը, և ինչ ոչ

- **Պահվում է**. երկրաչափությունը, հարկերը, տարրերի տեսակները, անունները, տիպերը, հիմնական պարամետրերի մեծ մասը (որպես հատկությունների հավաքածուներ), հիմնական քանակները, եթե խնդրել եք, սենյակները՝ որպես տարածություններ, և քարտեզի տեղը՝ ընդհանուր կոորդինատներով։
- **Չի պահվում**. տեսքերը, թերթերը, նշումները, ընտանիքները՝ որպես խմբագրվող ընտանիքներ, աշխատանքային բազմությունները և նախագծային տարբերակները։ IFC ֆայլը մոդելի տարրերի պատկեր է, ոչ թե նախագիծ։ Թերթերի համար արտահանեք DWG և բացեք այն 2D տեսքում։

## Սովորական սխալներ

- **Պարամետրերը բացակայում են BimCraft-ում.** միացրեք վերևի հատկությունների հավաքածուների տարբերակները և արտահանեք նորից։
- **Սենյակները բացակայում են.** միացրեք սենյակների տարբերակը, ապա սեղմեք {{ui:Տարածքներ}}-ը։
- **Պահում եք որպես `.ifczip`.** Ընտրեք սովորական IFC, կամ բացեք `.ifczip`-ը։
- **Քարտեզի տեղ չկա.** արտահանեք ընդհանուր կոորդինատներով և ստուգեք, որ նախագծի հետազոտական կետը սահմանված է։
- **Սպասել, որ փոփոխությունները կվերադառնան նախագծին.** BimCraft-ում պահած փոփոխությունները մտնում են նոր IFC ֆայլ, ոչ թե նախագծի ֆայլ։
