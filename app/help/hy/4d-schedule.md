## Ինչ կանեք

Դիտեք, թե ինչպես է շենքը բարձրանում․ ձեր ժամանակացույցի յուրաքանչյուր առաջադրանք կապված է այն տարրերի հետ, որոնք այն կառուցում է, ցույց է տրվում օր առ օր։

## Քայլեր

1. Բացեք IFC մոդել և բացեք {{ui:4D ժամանակացույց}} ձախ վահանակում։
2. Սեղմեք {{ui:Ներբեռնել ձևանմուշ}}՝ յուրաքանչյուր հարկի համար մեկ շաբաթով առաջադրանքների ցանկի համար և փոփոխեք այն աղյուսակային ծրագրում։ Կամ գրեք ձերը։
3. Սեղմեք {{ui:Բացել առաջադրանքների ցանկը…}} և ընտրեք CSV-ն։
4. Քաշեք ամսաթվի սլայդերը կամ սեղմեք {{ui:Նվագարկել}}։

## Առաջադրանքների ցանկը

CSV՝ վերնագրի տողով և սյուներով **Task**, **Start**, **Finish**, **Field** և **Value**։ Ստորակետները կամ կետ-ստորակետները երկուսն էլ աշխատում են։

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| Level 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| Roof | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| Roof | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- Գրեք ամսաթվերը YYYY-MM-DD ձևով։
- Տողը կապում է առաջադրանքը յուրաքանչյուր տարրի հետ, որի **Field**-ն ունի հենց այդ **Value**-ն։ Դաշտը հատկություն է, ինչպիսիք են Storey, Class, Name, Type, Material, Tag կամ GlobalId, կամ ցանկացած հատկություն՝ գրված իր հավաքածուի և անվան տեսքով․ `Pset_WallCommon.FireRating`։
- Նույն առաջադրանքը կրկնեք մի քանի տողում, նույն ամսաթվերով, որպեսզի ավելի շատ տարրեր կապվեն դրան։

## Փուլեր և աշխատանքային փաթեթներ

Ավելացրեք **Stage** սյուն, **Package** սյուն կամ երկուսը, որպեսզի առաջադրանքները խմբավորվեն փուլերի և աշխատանքային փաթեթների մեջ։ Phase և WBS նույնպես աշխատում են որպես սյան անուններ։

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| Level 1 slab | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| Level 1 walls | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| Doors | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- Առաջադրանքը պատկանում է մեկ փուլին և մեկ փաթեթին։ Եթե նույն առաջադրանքի հետագա տողը մեկ այլ անուն է նշում, այդ տողը ցուցակվում է իր տողի համարով և բաց է թողնվում։
- Նույն փաթեթի անունը երկու փուլում երկու փաթեթ է։

Երբ ցանկում կան խմբեր, ամսաթվից վերև հայտնվում է {{ui:Ցույց տալ}} ցանկը։ Ընտրեք փուլ կամ փաթեթ, և այն նվագարկվում է որպես մեկ ամբողջություն՝

- սլայդերը և {{ui:Նվագարկել}}-ը աշխատում են խմբի առաջին սկզբից մինչև վերջին ավարտը,
- ցուցակվում և նկարվում են միայն խմբի առաջադրանքները, իսկ խմբից դուրս ամեն ինչ թափանցիկ է,
- ցուցակի տակ գտնվող տողը ասում է, թե խմբի քանի առաջադրանք է կատարված, քանիսը՝ ընթացքի մեջ և քանիսը՝ դեռ առջևում, տվյալ օրվա դրությամբ,
- {{ui:Ընտրել դրա տարրերը}}-ը ընտրում է խմբի յուրաքանչյուր տարր՝ {{ui:Ցույց տալ}}-ի, {{ui:Կտրվածք}}-ի կամ ցանկի համար։

Ընտրեք **Բոլոր առաջադրանքները**՝ ամբողջ ժամանակացույցը նորից տեսնելու համար։

## Ինչ պետք է տեսնեք

- **Կառուցված**․ տարրեր, որոնց բոլոր առաջադրանքներն ավարտված են, իրենց սեփական գույներով։
- **Ընթացքի մեջ**․ տարրեր, որոնց վրա այդ օրը ընթացքի մեջ գտնվող առաջադրանք կա, օխրա գույնով։ Առաջադրանքը ընթացքի մեջ է իր սկզբի ամսաթվից մինչև ավարտի ամսաթիվը։
- **Դեռ չսկսված**․ թափանցիկ։
- Ոչ մի առաջադրանքում չգտնվող տարրերը մնում են ինչպես են։ Ցուցակը ցույց է տալիս, թե յուրաքանչյուր առաջադրանք քանի տարր է գտել։ Չընթերցված կամ ոչինչ չգտած տողերը ցուցակվում են իրենց տողերի համարներով։

## Կապեր, Գանտի դիագրամը և MS Project

- Բացեք Microsoft Project XML ֆայլ (`.xml`) կամ CSV, որն ունի `Predecessors` սյուն։ Կապերը կարող են լինել ավարտից մինչև սկիզբ, սկզբից մինչև սկիզբ, ավարտից մինչև ավարտ կամ սկզբից մինչև ավարտ, յուրաքանչյուրը՝ օրերով լիդ կամ լագով։
- Առաջադրանքների ցանկի տակ Գանտի դիագրամը յուրաքանչյուր առաջադրանք նկարում է որպես գիծ, իսկ կապերը՝ սլաքներով։ Կրիտիկական ուղու առաջադրանքները կարմիր են։ Կապի օղակը կամ գոյություն չունեցող նախորդ առաջադրանքը ցուցակված է վահանակում։
- {{ui:Պահել որպես MS Project XML}}-ը և {{ui:Պահել CSV՝ կապերով}}-ը ժամանակացույցը գրում են հետ՝ իր կապերով։
