## IFC տարր

{{ui:Properties}} վահանակի վերևում ցուցադրվում է տարրի տեսակը՝ առանց «Ifc» նախածանցի (օրինակ՝ «Door», «WallStandardCase», «FurnishingElement») և նրա անունը, կամ «Անանուն»։

| Դաշտ | Իմաստը | Խմբագրելի |
|---|---|---|
| Անուն | Տարրի անունը, հաճախ՝ ընտանիքի և տեսակի անունը արտահանողից | Այո |
| Տեսակ | Տարրի տեսակի անունը, երբ այն ունի | Ոչ |
| Օբյեկտի տեսակ | Ազատ տեքստով տեսակի նկարագրություն, որը որոշ արտահանողներ լրացնում են | Այո |
| Պիտակ | Տարրի պիտակը կամ նշանը։ Շատ արտահանողներ այստեղ են գրում տարրի ID-ն | Այո |
| Նկարագրություն | Ազատ տեքստ | Այո |
| GlobalId | Տարրի մշտական 22-նիշ IFC նույնացուցիչը, նույնը տարրի յուրաքանչյուր արտահանման մեջ | Ոչ |
| Գիծ | Տարրի տողի համարը (`#1234`) այս IFC ֆայլում։ Այն փոխվում է արտահանումների միջև | Ոչ |

Ներքևում են **հատկությունների հավաքածուները**, դասավորված ըստ անվան։

- Յուրաքանչյուր հավաքածու բացվում և փակվում է իր անվան վրա սեղմելով։ Առաջին երեքը բաց են։
- «(type)» նշումով հավաքածուն պատկանում է տարրի տեսակին։ «Տեսակի հատկություն․ այստեղ կատարված փոփոխությունը կիրառվում է այս տեսակի յուրաքանչյուր տարրի վրա»։
- Քանակների հավաքածուները (երկարություններ, մակերեսներ, ծավալներ, քանակներ, կշիռներ) միայն կարդալու են։
- Ցուցակները և թվարկված արժեքները ցուցադրվում են միայն կարդալու համար։
- Այո/Ոչ արժեքները ցուցադրվում են **Այո** կամ **Ոչ**։
- Թվերը ցուցադրվելիս կլորացվում են մինչև չորս տասնորդական նիշ։ Երկարությունները (երկարության հատկությունը կամ քանակի երկարությունը) ցուցադրվում են գործիքագոտում ընտրված {{ui:Units}}-ով՝ կողքին միավորի նշանով։ Կարող եք նոր արժեք մուտքագրել այդ միավորով կամ մեկ այլ միավորի նշանով (2.4 m, 8'-0"). BimCraft-ը գրում է ֆայլի սեփական թիվը։ Մյուս թվերը ցուցադրվում են այնպես, ինչպես ֆայլն ունի։
- Դատարկ արժեքը ցուցադրվում է որպես *դատարկ*։ Խմբագրված արժեքը թավ է և կողքին ունի կապույտ գիծ։

## Արժեքի պատճենում

Յուրաքանչյուր արժեք {{ui:Properties}}-ում ունի փոքր պատճենման կոճակ։ Սեղմեք այն՝ արժեքը սեղմատախտակին տեղադրելու համար՝ ճիշտ այնպես, ինչպես ցուցադրվում է։ Օրինակ՝ GlobalId, սերիական համար կամ հատկությունների հավաքածուի ցանկացած արժեք։ Պատճենելը երբեք չի սկսում խմբագրում։

Վերևում {{ui:Copy all}}-ը պատճենում է տարրի բոլոր արժեքները որպես տեքստ՝ հավաքածու առ հավաքածու։ {{ui:Copy as CSV}}-ը պատճենում է դրանք որպես խմբի, հատկության և արժեքի տողեր՝ աղյուսակում տեղադրելու համար։ Դատարկ արժեքները պահվում են, որպեսզի յուրաքանչյուր դաշտ ունենա տող։ Սա նույն կերպ է աշխատում բաց այլ մոդելի տարրի համար։ Երբ բաց են մի քանի մոդել, CSV-ն սկսվում է Մոդել սյունակով, որտեղ նշված է ֆայլի անունը։

## Ֆայլ վահանակ (IFC)

| Դաշտ | Իմաստը |
|---|---|
| Ֆայլ, Մեծություն | Ձեր բացած ֆայլը |
| Schema | IFC տարբերակը, օրինակ՝ IFC2X3 կամ IFC4 |
| Project | Նախագծի անունը և երկար անունը |
| Phase | Նախագծի փուլը, եթե արտահանողը այն գրել է |
| Exported from | Արտահանող ծրագիրը՝ ֆայլի վերնագրից |
| Author | Հեղինակը ֆայլի վերնագրից |
| Exported | Ամսաթիվը և ժամը ֆայլի վերնագրից |
| Elements | Քանի տարր է նկարվել ձևով |
| Triangles | Քանի եռանկյուն են կազմում իրենց ձևերը։ Մոդելի ծանրության չափ |

## Ֆայլ վահանակ (նախագծի և ընտանիքի ֆայլեր)

| Դաշտ | Իմաստը |
|---|---|
| Տեսակ | Նախագիծ, Նախագծի ձևանմուշ, Ընտանիք կամ Ընտանիքի ձևանմուշ |
| Պահված է | Թողարկումը, որը վերջին անգամ պահել է ֆայլը |
| Build | Այդ թողարկման ճշգրիտ build-ը |
| Կարդացված | Ֆայլի ինչ մասն է BimCraft-ը կարդացել, չափով |

## Գծագրի վահանակ (DWG և DXF)

| Դաշտ | Իմաստը |
|---|---|
| Ձևաչափ | Թողարկումը, որով գծագիրը պահված է, իր ձևաչափի կոդով, օրինակ՝ AC1032 |
| Միավորներ | Գծագրի տեղադրման միավորները, երբ սահմանված են |
| Օբյեկտներ | Քանի օբյեկտ է կարդացվել |
| Շերտեր | Քանի շերտ կա |
| Թերթեր | Քանի թերթ (մակետ) կա, կամ Չկա |
| Կապված գծագրեր | Քանի կապված գծագիր է գտնվել և բեռնվել |
| Սարքավորումներ | Քանի պիտակավորված սարքավորում կա թերթերի վրա |

## Թղթապանակի վահանակ

| Դաշտ | Իմաստը |
|---|---|
| Թղթապանակ, Ֆայլեր, Մեծություն | Ձեր բացած թղթապանակը, քանի ֆայլ է այն պարունակում և դրանց ընդհանուր չափը |
| Մոդելներ | Նախագծի և ընտանիքի ֆայլեր, յուրաքանչյուրը՝ իր պահուստները մեկ անգամ հաշվելով |
| CAD գծագրեր, IFC մոդելներ | Քանի-քանի է յուրաքանչյուրից |
| Խնդիրներ | Քանի մոդելի պատճեն է թերի կամ չկարդացվող, կամ Չկա |
