BimCraft-ում դյուրանցումները քիչ են։ Աշխատանքի մեծ մասը կատարվում է մկնիկով և վահանակներով։ {{key:Mod}}-ով գրված դյուրանցումները օգտագործում են Command Mac-ում և Ctrl մյուս համակարգերում։ Տե՛ս [Ստեղներ, մկնիկներ և թաչփեդներ](common:keys), թե ինչպես են այս օգնությունում գրված ստեղները։

## Ամենուր

| Ստեղն | Ինչ է անում |
|---|---|
| {{key:Ctrl+Shift+F}} | Անցնել էկրանի ռեժիմների միջև՝ սովորական, լիաէկրան, լիաէկրան՝ թաքցված բարերով։ Ctrl բոլոր պլատֆորմներում, ներառյալ Mac-ը |
| {{key:Esc}} | Դուրս գալ լիաէկրան ռեժիմից |
| {{key:Mod+,}} | Բացել {{ui:Settings}}։ Տե՛ս [BimCraft-ի կարգավորումներ](topic:settings) |
| {{key:Tab}} | Տեղաշարժվել կոճակների, վանդակների և արժեքների միջև։ Ամեն կառավարիչ հասանելի է ստեղնաշարից |

## 3D տեսք (IFC մոդելներ)

| Ստեղն կամ գործողություն | Ինչ է անում |
|---|---|
| {{key:F}} | Տեղավորել ամբողջ մոդելը, եռամասնյա տեսքով (նույնն, ինչ {{ui:Fit}}) |
| {{key:Esc}} | Չեղարկել ընտրությունը, կամ դադարեցնել տեղադրումը կամ տեղադրելը |
| Սեղմել | Ընտրել կուրսորի տակ գտնվող տարրը․ դատարկ ֆոնի վրա սեղմելը մաքրում է |
| {{key:Mod}}+սեղմել կամ {{key:Shift}}+սեղմել | Ավելացնել տարր ընտրությանը կամ հանել այն |
| {{key:H}} | Թաքցնել ընտրված տարրերը։ Տե՛ս [Թաքցնել, առանձնացնել և տեսնել թափանցիկ տարրերը](topic:hide-and-isolate) |
| {{key:I}} | Ցուցադրել միայն ընտրված տարրերը (առանձնացնել) |
| {{key:T}} | Ցուցադրել ընտրված տարրերը, մնացածը՝ թափանցիկ |
| {{key:Shift+H}} | Նորից ցուցադրել բոլոր տարրերը |
| {{ui:Walk}} | Ապա {{key:W}} {{key:A}} {{key:S}} {{key:D}} կամ սլաքները՝ քայլում են, {{key:Shift}}-ը վազում է, քաշելով նայում եք շուրջը, {{key:Esc}}-ը կանգնեցնում է։ Տե՛ս [Քայլել մոդելով](topic:walk) |
| {{key:M}} | Չափել հեռավորությունները և երեսների մակերեսները։ Տե՛ս [Չափել հեռավորություններ, երեսների մակերեսներ և դիրքեր 3D-ում](topic:measure) |
| Քաշել ձախ կոճակով | Պտտել |
| Քաշել աջ կոճակով | Տեղաշարժել |
| {{key:Shift}} կամ {{key:Mod}} և քաշել ձախ կոճակով | Տեղաշարժել (հարմար է թաչփեդի վրա) |
| Ոլորել անիվը, կամ քաշել միջին կոճակով | Մասշտաբ |
| Երկու մատով ոլորում կամ պինչ թաչփեդի վրա | Մասշտաբ |
| Մեկ մատ (հպում) | Պտտել; թակելը ընտրում է |
| Երկու մատ (հպում) | Պինչով մասշտաբ, միասին շարժելով՝ տեղաշարժ |

| {{key:X}} | Կտրվածքի հարթություն միացված և անջատված։ Տե՛ս [Կտրել IFC մոդելը կտրվածքի հարթությամբ](topic:section-plane) |
| {{key:Shift+X}} | Կտրվածքի արկղ ընտրված տարրերի շուրջը, սենյակը՝ Կարգավորումներում սահմանված |

Չկան ստեղներ {{ui:Top}}, {{ui:Front}} և {{ui:Side}}-ի համար․ օգտագործեք կոճակները։

## Խմբագրում

Նույն հրամանները կան գործիքագոտում՝ {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}} և {{ui:More}} ցանկը, որը ցույց է տալիս յուրաքանչյուր ստեղն։ Դրանք աշխատում են IFC մոդելի 3D տեսքում, ոչ թե երբ դաշտում տեքստ եք գրում։ Տե՛ս [Պատճենել, տեղադրել և կրկնօրինակել գրադարանի տարրերը](topic:copy-paste)։

| Ստեղն | Ինչ է անում |
|---|---|
| {{key:Mod+Z}} | Հետարկել վերջին փոփոխությունը |
| {{key:Mod+Y}} կամ {{key:Mod+Shift+Z}} | Կրկնել այն, ինչ Հետարկելը վերցրեց |
| {{key:Mod+C}} | Պատճենել ընտրված տարրերը (դրանց անունները և հատկությունները նաև տեքստով են գնում սեղմատախտակ) |
| {{key:Mod+X}} | Կտրել ընտրված տարրերը՝ նախ պատճենելով, ապա ջնջելով |
| {{key:Mod+V}} | Տեղադրել այն, ինչ պատճենել եք․ այն հետևում է կուրսորին, սեղմեք, թե որտեղ գնա |
| {{key:Mod+Shift+V}} | Տեղադրել նույն տեղում․ որտեղից կտրվել է, կամ պատճենից հետո՝ բնօրինակների կողքին |
| {{key:Mod+D}} | Կրկնօրինակել՝ պատճենել ընտրված տարրերը և սկսել դրանք տեղադրել |
| {{key:Delete}} | Ջնջել ընտրված տարրերը՝ իրենց մասերով և բացվածքներով։ Տե՛ս [Ջնջել, կտրել, պատճենել և տեղադրել շինարարական տարրերը](topic:edit-elements) |
| {{key:Mod+A}} | Ընտրել յուրաքանչյուր երևացող տարր |
| {{key:Esc}} | Ոչինչ չընտրել |

Երբ էջի վրա տեքստ է ընտրված, {{key:Mod+C}}-ն պատճենում է այդ տեքստը, ինչպես սովորաբար։

## Հատակագծի տեսք (Գծում)

Սրանք աշխատում են, երբ {{ui:Draw}} միացված է և դուք դաշտում տեքստ չեք գրում։ Տե՛ս [Գծել պատեր](topic:draw-walls) և [Դռներ և պատուհաններ](topic:doors-and-windows)։

| Ստեղն կամ գործողություն | Ինչ է անում |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | Երբ {{ui:Door}} կամ {{ui:Window}} է ընտրված՝ ծխնիները մյուս ծայրում |
| {{key:Shift}} պատ գծելիս | Պահել այն 0°, 90°, 180° կամ 270°-ի վրա |
| Թվանշաններ և ֆուտի ու դյույմի նշաններ (`'` և `"`) | Սկսեք գրել երկարություն {{ui:Length}} վանդակում․ {{key:Enter}}-ը օգտագործում է այն |
| {{key:Enter}}, {{key:Esc}}, աջ սեղմում կամ կրկնակի սեղմում | Ավարտել պատը, որ գծում եք․ {{key:Esc}}-ը դարձյալ վերադարձնում է {{ui:Select}}-ին |
| {{key:Delete}} | Ջնջել ընտրված պատերը, դռներն ու պատուհանները․ մնացած պատերը նորից միանում են |
| {{key:F}}, երբ կուրսորը հատակագծի վրա է | Տեղավորել հատակագիծը |
| Ոլորել անիվը | Մասշտաբ՝ կուրսորի շուրջ |
| Քաշել միջին կամ աջ կոճակով, կամ {{key:Space}} և քաշել | Տեղաշարժ; {{ui:Select}}-ը միացված՝ պարզ քաշելը նույնպես տեղաշարժում է |
| {{ui:Select}}-ով քաշել դուռը կամ պատուհանը | Տեղափոխել այն պատի երկայնքով կամ մեկ այլ պատի վրա |
| Երկու մատ (հպում) | Պինչով մասշտաբ, միասին շարժելով՝ տեղաշարժ |

## Գրադարանի տարրերի տեղադրում և տեղադրելը

| Ստեղն | Ինչ է անում |
|---|---|
| {{key:R}} | Պտտել տարրը 90°-ով |

## IFC արժեքների խմբագրում

| Ստեղն | Ինչ է անում |
|---|---|
| {{key:Enter}} | Պահել մուտքագրված արժեքը |
| {{key:Esc}} | Չեղարկել և վերադարձնել հին արժեքը |
| Սեղմել այլ տեղ | Պահել մուտքագրված արժեքը |
| {{key:Mod+Z}} | Հետարկել վերջին փոփոխությունը։ Միայն երբ ունեք չպահված փոփոխություններ և դաշտում տեքստ չեք գրում |
| {{key:Mod+Y}} | Կրկնել այն, ինչ Հետարկելը վերցրեց |
| {{key:Mod+S}} | Պահել որպես IFC։ Միայն երբ ունեք չպահված փոփոխություններ․ հակառակ դեպքում բացվում է դիտարկիչի սեփական պահելու հրամանը |

Միայն ստեղնաշարով խմբագրելու համար՝ սեղմեք {{key:Tab}}, մինչև արժեքը նշվի, ապա սեղմեք {{key:Enter}}՝ մուտքագրելը սկսելու համար։
