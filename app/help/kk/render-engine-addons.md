Қосымша (Баптаулар › Қосымша) {{ui:Рендер}} диалогының Қозғалтқыш тізіміне қозғалтқыш қоса алады. Қосымша авторларына арналған толық мәтін қосымша сипаттамасының 16-бөлімінде; қысқаша:

- Қосымша қозғалтқышты тіркейді: өз префиксінен басталатын id, атауы, міндетті емес баптаулары және **немесе** іске қосатын программасы, **немесе** суретті салатын JavaScript функциясы.
- Программаны іске қосатын қозғалтқышқа **`engine.run`** рұқсаты қажет, ол орнатар алдында және Баптауларда көрсетіледі. Ол тек Studio-да іске қосылады; браузерде сақтауға арналған файл ретінде көрсетіледі.
- Қосымша программаны (тек қарапайым файл атауы, ешқашан қабық емес), **қолтаңбаланған қосымшаның ішінде** орналасқан скриптті және орын толтырғыштар мен қарапайым сөздерден тұратын аргументтерді көрсетеді. Studio программаны өзі табады немесе оны бір рет көрсетуіңізді сұрайды.
- Қосымша программаны алғаш рет іске қосқанда, **Studio өз диалогында сұрайды**: қай қосымша, қай программа және скрипт программаның қолынан келетін кез келген әрекетті орындай алатыны. Оған тек сенімді қосымшаға ғана рұқсат беріңіз. Сіздің жауабыңыз сол қосымша мен программа үшін сақталады.
- Пакет (USD ретіндегі сахна және баптау файлы, қосымша сұраса glTF файлымен бірге) мен қосымшаның скрипті жаңа уақытша қалтаға салынады, программа сол жерде іске қосылады, ал сурет қосымшаның қозғалтқыш атауымен белгіленіп қайтарылады.

:::note
Қосымшалар тек қосымша API 1.4 нұсқасынан бастап рендер қозғалтқыштарын қоса алады. Ашық бастапқы кодты командалық жол рендерері үшін толық мысал оның өз репозиторийінде берілген; ол әлі сол рендерерде іске қосылмаған.
:::
