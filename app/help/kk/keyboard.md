BimCraft-та жылдам пернелер аз. Жұмыстың көбі тінтуірмен және панельдермен орындалады. {{key:Mod}} арқылы жазылған пернелер тіркесімі Mac-та Command, басқа жерде Ctrl қолданады. Осы анықтамада пернелердің қалай жазылатыны үшін қараңыз: [Пернелер, тінтуірлер және сенсорлық тақтайшалар](common:keys).

## Барлық жерде

| Кілт | Не істейді |
|---|---|
| {{key:Ctrl+Shift+F}} | Экран режимдерін айналдырады: қалыпты, толық экран, панельдері жасырылған толық экран. Ctrl барлық платформада, Mac-та да |
| {{key:Esc}} | Толық экраннан шығу |
| {{key:Mod+,}} | {{ui:Баптаулар}} ашу. Қараңыз: [BimCraft баптаулары](topic:settings) |
| {{key:Tab}} | Түймелер, құсбелгілер және мәндер арасында жылжу. Әр басқару элементіне пернетақтамен жетуге болады |

| Кілт немесе әрекет | Не істейді |
|---|---|

| {{key:Esc}} | Таңдауды тазалау, немесе орналастыруды немесе қоюды тоқтату |

| {{key:M}} | Қашықтықтарды және беттердің ауданын өлшеу. Қараңыз: [3D-де қашықтықтарды, беттердің аудандарын және орындарды өлшеу](topic:measure) |

| Дөңгелекті айналдыру немесе орта түймемен сүйреу | Масштабтау |

| {{key:X}} | Қима жазықтығын қосу және өшіру. Қараңыз: [IFC моделін қима жазықтығымен кесу](topic:section-plane) |
| {{key:Shift+X}} | Таңдалған элементтердің айналасында қима қорабы, бөлме Баптауларда орнатылған |

{{ui:Үстіңгі}}, {{ui:Алдыңғы}} және {{ui:Бүйірден}} үшін пернелер жоқ; түймелерді пайдаланыңыз.

## Өңдеу

Құралдар жолағында дәл осы командалар бар: {{ui:Болдырмау}}, {{ui:Қайтару}}, {{ui:Көшіру}}, {{ui:Қою}} және әр пернені көрсететін {{ui:Тағы}} мәзірі. Олар IFC модельдің 3D көрінісінде жұмыс істейді, өріске мәтін теріп жатқанда емес. Қараңыз: [Кітапхана элементтерін көшіру, қою және көбейту](topic:copy-paste).

| Кілт | Не істейді |
|---|---|
| {{key:Mod+Z}} | Соңғы өзгерісті болдырмау |
| {{key:Mod+Y}} немесе {{key:Mod+Shift+Z}} | Болдырмау алып тастаған нәрсені қайтару |
| {{key:Mod+C}} | Таңдалған элементтерді көшіру (олардың атаулары мен қасиеттері мәтін ретінде буферге де жіберіледі) |
| {{key:Mod+X}} | Таңдалған элементтерді кесу: көшіріп, содан кейін жою |
| {{key:Mod+V}} | Көшірілгенді қою: ол көрсеткіні ілестіреді, қайда қоятынын басыңыз |
| {{key:Mod+Shift+V}} | Орнында қою: кесілген жерге, немесе көшірілгеннен кейін түпнұсқалардың жанына |
| {{key:Mod+D}} | Көбейту: таңдалған элементтерді көшіру және оларды қоюды бастау |
| {{key:Delete}} | Таңдалған элементтерді, олардың бөліктері мен ойықтарымен бірге жою. Қараңыз: [Ғимарат элементтерін жою, кесу, көшіру және қою](topic:edit-elements) |
| {{key:Mod+A}} | Көрсетілген әр элементті таңдау |
| {{key:Esc}} | Ештеңені таңдамау |

Бетте мәтін таңдалған кезде, {{key:Mod+C}} мәтінді әдеттегідей көшіреді.

## Жоспар көрінісі (Сызу)

Бұлар {{ui:Draw}} қосулы тұрғанда және өрісте мәтін теріп жатпасаңыз жұмыс істейді. Қараңыз: [Қабырғаларды сызу](topic:draw-walls) және [Есіктер мен терезелер](topic:doors-and-windows).

| Кілт немесе әрекет | Не істейді |
|---|---|
| {{key:V}} | {{ui:Таңдау}} |
| {{key:W}} | {{ui:Қабырға}} |
| {{key:D}} | {{ui:Есік}} |
| {{key:N}} | {{ui:Терезе}} |
| {{key:H}} | {{ui:Есік}} немесе {{ui:Терезе}} кезінде: ілгектер арғы жағында |
| Қабырға сызғанда {{key:Shift}} | Оны 0°, 90°, 180° немесе 270° күйінде ұстау |
| Сандар және фут пен дюйм белгілері (`'` және `"`) | {{ui:Ұзындық}} өрісіне ұзындықты теруді бастау; {{key:Enter}} оны қолданады |
| {{key:Enter}}, {{key:Esc}}, оң жақ басу немесе екі рет басу | Сызып жатқан қабырғаны аяқтау; {{key:Esc}} тағы басса {{ui:Таңдау}} режиміне қайтады |
| {{key:Delete}} | Таңдалған қабырғаларды, есіктер мен терезелерді жою; қалған қабырғалар қайта қосылады |
| Көрсеткі жоспар үстінде тұрғанда {{key:F}} | Жоспарды сыйғызу |
| Дөңгелекті айналдыру | Көрсеткі тұрған жерге қарай масштабтау |
| Орта немесе оң түймемен сүйреу, немесе {{key:Space}} және сүйреу | Жылжыту; {{ui:Таңдау}} қосулы болса, қарапайым сүйреу де жылжытады |
| Есікті немесе терезені {{ui:Таңдау}} арқылы сүйреу | Қабырға бойымен немесе басқа қабырғаға жылжыту |
| Екі саусақ (жанасу) | Қысып масштабтау, бірге жылжытса жылжыту |

## Кітапхана элементтерін орналастыру және қою

| Кілт | Не істейді |
|---|---|
| {{key:R}} | Элементті 90° бұру |
| {{key:Tab}} | Қабырғаға ілінуді қосу және өшіру: элементтің арқасы ең жақын қабырғаға тіреледі |
| {{key:Enter}} **X, Y (mm)** өрісінде | Терілген позицияға орналастыру |
| {{key:Esc}} | Орналастыруды немесе қоюды тоқтату |

## IFC мәндерін өңдеу

| Кілт | Не істейді |
|---|---|
| {{key:Enter}} | Терген мәнді сақтау |
| {{key:Esc}} | Болдырмау және ескі мәнді қайтару |
| Басқа жерді басу | Терген мәнді сақтау |
| {{key:Mod+Z}} | Соңғы өзгерісті болдырмау. Тек сақталмаған өзгерістер болғанда және өрісте мәтін теріп жатпағанда |
| {{key:Mod+Y}} | Болдырмау алып тастаған нәрсені қайтару |
| {{key:Mod+S}} | IFC ретінде сақтау. Тек сақталмаған өзгерістер болғанда; әйтпесе браузердің өз сақтау командасы ашылады |

Пернетақтамен ғана өңдеу үшін: мән бөлектелгенше {{key:Tab}} басыңыз, содан кейін теруді бастау үшін {{key:Enter}} басыңыз.

## 2D сызбалар (DWG және DXF)

| Кілт немесе әрекет | Не істейді |
|---|---|
| {{key:F}} | Сызбаны немесе парақты сыйғызу |
| {{key:P}} | Басып шығару көрінісін қосу және өшіру |
| Екі рет басу | Сыйғызу |
| Кез келген түймемен сүйреу | Жылжыту |

## 3D-дегі сызбалар

| Кілт немесе әрекет | Не істейді |
|---|---|
| {{key:3}} | 3D қосу және өшіру (2D көрініс үстінде де) |
| {{key:F}} | Өлшем: бүкіл сызба |
| Орта немесе сол түймемен сүйреу | Орбита |
| Оң түймемен сүйреу немесе {{key:Shift}} және сүйреу | Жылжыту |
| Дөңгелекті айналдыру | Көрсеткінің астындағыға қарай масштабтау |

| Сенсорлық тақтайшада қысу | Масштабтау |
| Бір саусақ (жанасу) | Орбита |
| Екі саусақ (жанасу) | Қысып масштабтау, бірге жылжытса жылжыту |
