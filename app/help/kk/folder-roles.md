## Көшірме күйі

Модельдің әр көшірмесі — негізгі файл және нөмірленген резервтік көшірмелер — тақырып тексерісінен өтеді.

| Белгі | Мағынасы |
|---|---|
| **Толық** | Файлдың тақырыбы мен индексі файлдың ішіне сыяды |
| **Толық емес** | Файл өзінің индексі көрсеткеннен қысқа: көшіру, жүктеу немесе синхрондау кезінде кесілген, немесе тек «тек онлайн» күйіндегі бұлттық файл |
| **Оқылмайды** | Файл жарамды compound file емес немесе оны оқу мүмкін болмады |

**Күй** бағанында модель **Толық** көрсетеді; кем дегенде бір көшірме жарамсыз, ал басқасы сау болса — сары «*n* толық емес»; ешбір көшірме сау болмаса — қызыл **Толық емес**.

## Резервтік көшірмелер

`Name.0001.rvt`, `Name.0002.rvt` және т.б. файлдар `Name.rvt` үшін нөмірленген резервтік көшірмелер болып саналады. Олар модель атауының астында **Барлық … көшірме** ішінде, жаңасы бірінші болып топтастырылады. Карточка негізгі файл толық болған кезде соған, әйтпесе ең жаңа толық резервтік көшірмеден оқылады («ең жаңа толық»).

## Рөлдер

Модель атының астында итальмен көрсетіледі.

| Рөл | Мағынасы |
|---|---|
| *Басқа модельмен* сілтемеленген: фон | Қалтадағы басқа модель осыған сілтеме жасайды, сондықтан бұл, көбіне, біреудің фондық моделі, мысалы кеңесшінің моделі |
| Бастапқы немесе атаусыз файл | Blank, Template, Default, Untitled немесе Project1 сияқты атау: бастапқы нүкте немесе дұрыс аталмаған файл |
| Орталық модель | Жұмыс бөлісілген орталық модель. Жұмыс осында емес, жергілікті көшірмеде жүреді |
| Отбасы (бөлшек) | `.rfa` немесе `.rft` файлы: жобаның емес, компонент |
| Тек резервтік көшірмелер | Негізгі файл жоқ, тек нөмірленген резервтік көшірмелер қалды |

## Осы жерден бастау қалай таңдалады

BimCraft тәжірибелі пайдаланушы қолданатын пайымдауды қолданады:

1. Үміткерлер — басқа модель сілтеме етпеген және бастапқы емес, оқылатын жоба файлдары (`.rvt`, `.rte`).
2. Орталық және тек резервтік көшірмелі модельдер тек жақсырақ ештеңе болмаған кезде ғана есептеледі.
3. Үміткерлердің ішінде ең соңғы сақталған жеңеді.

Тізімде себептер көрсетіледі, және ең айқын таңдау болып көрінетін файл зақымданған, басқа модельдер фон болған немесе таңдау орталық модель болған кезде ескертеді. Бұл шамамен болжам ғана; жобаны соңғы өңдеген адаммен тексеріңіз.

## Сілтеме күйі

| Белгі | Мағынасы |
|---|---|
| **Осы қалтада** | Сақталған салыстырмалы жолда немесе қалтаның ішіндегі сақталған толық жолдың соңында табылды |
| **Бірдей атау табылды** | Өз жолында емес, бірақ қалтада бірдей атаумен файл бар. Дұрыс екеніне көз жеткізіңіз |
| **Кітапхана файлы** | Кілттік жазбалар немесе жинақ кодтары кестесі. Олар әр компьютерде бағдарламамен бірге келеді |
| **Осы қалтада жоқ** | Қалтаның ешқайсысынан табылмады |

**Models** бөлімінің **Links found** бағанында қалтада күтілетін сілтемелердің қанша табылғаны көрсетіледі (кітапхана файлдары санға кірмейді).
