## IFC элементі

{{ui:Properties}} панелінің жоғарғы жағында элементтің түрі «Ifc» префиксінсіз (мысалы, «Door», «WallStandardCase», «FurnishingElement») және оның аты немесе «Атаусыз» көрсетіледі.

| Өріс | Мағынасы | Өзгертуге болады ма |
|---|---|---|
| Аты | Элементтің аты, көбіне экспорттаушыдан алынған отбасы және түр аты | Иә |
| Түрі | Элемент түрінің аты, бар болса | Жоқ |
| Нысан түрі | Кейбір экспорттаушылар толтыратын еркін мәтіндік түр сипаттамасы | Иә |
| Белгі | Элементтің белгісі немесе маркасы; көптеген экспорттаушылар мұнда элемент ID-ін жазады | Иә |
| Сипаттама | Еркін мәтін | Иә |
| GlobalId | Элементтің тұрақты 22 таңбалы IFC идентификаторы, элементтің әр экспортында бірдей | Жоқ |
| Жол | Элементтің осы IFC файлындағы жол нөмірі (`#1234`). Экспорттар арасында өзгереді | Жоқ |

Төменде **қасиеттер жиынтықтары** аты бойынша сұрыпталып көрсетіледі:

- Әр жиынтық атын басқанда ашылады және жабылады. Алғашқы үшеуі ашық.
- «(түр)» деп белгіленген жиынтық элемент түріне тиесілі: «Түр қасиеті: мұндағы өзгеріс осы түрдегі әр элементке қолданылады.»
- Саны жиынтықтары (ұзындықтар, аудандар, көлемдер, санақтар, салмақтар) тек оқуға арналған.
- Тізімдер мен санау мәндері көрсетіледі, тек оқуға арналған.
- Иә/Жоқ мәндері **Иә** немесе **Жоқ** ретінде көрсетіледі.
- Сандар көрсету үшін төрт ондық таңбаға дейін дөңгелектенеді. Ұзындықтар (ұзындық қасиеті немесе саны ұзындығы) құралдар тақтасындағы {{ui:Units}} бірлігімен көрсетіледі, жанында өлшем белгісі бар; жаңа мәнді сол бірлікпен немесе басқа өлшем белгісімен (2.4 m, 8'-0") теруге болады: BimCraft файлдың өз санын қайта жазады. Басқа сандар файлда қандай болса, солай көрсетіледі.
- Бос мән *бос* ретінде көрсетіледі. Өзгертілген мән қалың болып, жанында көк жолағы бар.

## Мәнді көшіру

{{ui:Properties}} ішіндегі әр мәннің жанында кішкентай көшіру түймесі бар: оны басса, мән көрсетілгендей дәл көшіру буферіне көшіріледі, мысалы GlobalId, сериялық нөмір немесе кез келген қасиеттер жиынтығының мәні. Көшіру ешқашан өңдеуді бастамайды.

Жоғарыда {{ui:Copy all}} элементтің барлық мәндерін жиынтық бойынша мәтін ретінде көшіреді, ал {{ui:Copy as CSV}} оларды электрондық кестеге қоюға арналған топ, қасиет және мән жолдары ретінде көшіреді; бос мәндер сақталады, сондықтан әр өрісте жол болады. Бұл ашық басқа модель элементі үшін де осылай жұмыс істейді; бірнеше модель ашық болса, CSV Model бағанынан басталады, онда файл аты жазылады.

## Файл панелі (IFC)

| Өріс | Мағынасы |
|---|---|
| Файл, Өлшемі | Сіз ашқан файл |
| Схема | IFC нұсқасы, мысалы IFC2X3 немесе IFC4 |
| Жоба | Жобаның аты және толық аты |
| Кезең | Жоба кезеңі, экспорттаушы жазса |
| Экспортталған бағдарлама | Экспорттаушы бағдарлама, файл тақырыбынан |
| Автор | Файл тақырыбындағы автор |
| Экспортталған | Файл тақырыбындағы күн мен уақыт |
| Элементтер | Пішіні бар элементтердің саны салынғаны |
| Үшбұрыштар | Олардың пішіндері неше үшбұрыш құрайды; модельдің қаншалықты ауыр екенінің өлшемі |

## Файл панелі (жоба және отбасы файлдары)

| Өріс | Мағынасы |
|---|---|
| Түрі | Жоба, Жоба үлгісі, Отбасы немесе Отбасы үлгісі |
| Сақталған нұсқа | Файлды соңғы рет сақтаған шығарылым |
| Құрастыру | Сол шығарылымның дәл құрастыру нөмірі |
| Оқылды | BimCraft файлдың өлшемінен қанша бөлігін оқығаны |

## Сызба панелі (DWG және DXF)

| Өріс | Мағынасы |
|---|---|
| Пішім | Сызба сақталған шығарылым, форматтың коды бар, мысалы AC1032 |
| Бірліктер | Сызбаның енгізу бірліктері, бар болса |
| Объектілер | Неше нысан оқылды |
| Қабаттар | Неше қабат бар |
| Парақтар | Неше парақ (макет), немесе Жоқ |
| Байланған сызбалар | Оның байланған сызбаларының қанша табылып жүктелгені |
| Жабдық | Парақтарда белгіленген жабдықтар саны |

## Қалта панелі

| Өріс | Мағынасы |
|---|---|
| Қалта, Файлдар, Өлшемі | Ашқан қалтаңыз, онда неше файл бар және олардың жалпы өлшемі |
| Модельдер | Жоба және отбасы файлдары, әрқайсысының резервтік көшірмелері бір рет есептеледі |
| CAD сызбалары, IFC модельдері | Әрқайсысынан неше |
| Мәселелер | Неше модель көшірмесі толық емес немесе оқылмайды, немесе Жоқ |
