## IFC

| Оқылады | Мәліметтер |
|---|---|
| Геометрия | Пішіні бар әр элемент, файл айтқандай боялған. Бөлмелер мен кеңістіктер мөлдір салынады және алғаш рет жасырылады |
| Қабаттар | Ғимарат қабаттары биіктік ретімен, және әр қабатта қандай элементтер тұрғаны. Ешбір қабатта жоқ элементтер «Қабатта емес» деп топталады |
| Элемент саны | Әр түрдегі элементтер саны (қабырғалар, есіктер, плиталар…), {{ui:Элементтер}} ішінде көрсетіледі |
| Жоба мәліметтері | Жоба атауы, толық атауы және кезеңі; схема; файл тақырыбынан экспорттаушы бағдарлама, автор және экспорт күні |
| Элемент деректері | Атауы, түрі, объект түрі, белгі, сипаттама, GlobalId; элементте де, оның түрінде де бар әр қасиет жиыны мен саны жиыны |

Өңделетіндер: атауы, объект түрі, белгі, сипаттама және жалғыз қасиет мәндері. Жаңа IFC файлы ретінде сақталады. IFC2X3, IFC4 және IFC4X3 схемалары ашылады, BimCraft-тың өз IFC қозғалтқышымен оқылады; әлі сала алмайтын нәрсе {{ui:Файл}} панелінде **Әлі салынбаған** астында тізіледі. Модель ашылғанда басына жылжытылады, сондықтан одан алыс орналасқан модель экранның ортасында көрінеді. `.ifczip` және `.ifcxml` ашылмайды.

## Жоба және отбасы файлдары

`.rvt` жобалары, `.rte` жоба үлгілері, `.rfa` отбасылары және `.rft` отбасы үлгілері.

| Оқылады | Мәліметтер |
|---|---|
| Файл туралы ақпарат | Шығарылым және құрастыру, бірлескен жұмыс, орталық модель жолы, соңғы сақталған жол, пайдаланушы аты, тіл-аймақ, құжат GUID |
| Жоба туралы ақпарат | Жобаның өз өрістері (атауы, нөмірі, клиент, мекенжай, мәртебе…), жаңа жобаның әдепкілерінсіз |
| Отбасы туралы ақпарат | Отбасы атауы, санаты, шығарылымы, соңғы жаңартуы, және оның параметрлері топтар бойынша |
| Сілтемелер | Файл көрсететін байланысқан модельдер, CAD сілтемелері, суреттер және кілт сөздер кестелерінің тізімі |
| Алдын ала көрсету суреті | Файлда сақталған кішкентай сурет |

Оқылмайды: 3D модель, элементтер, көріністер, парақтар және спецификациялар. Олар құжатталмаған форматта сақталған. BimCraft әр файлдан бірнеше ондаған килобайт ғана оқиды, сондықтан файл өлшемі аз маңызды.

## .pln, .pla, .tpl және .bpn жоба файлдары

Әлі оқылмайды: BimCraft оны ашқанда осыны айтады. Модель үшін IFC, сызбалар үшін DWG экспорттаңыз; қараңыз [.pln және .pla жоба файлдарын ашу](topic:pln-project-files).

## DWG және DXF

| Оқылады | Мәліметтер |
|---|---|
| Кеңістіктер | Модель кеңістігі және әр парақ (орналасу), қойынды ретімен |
| Көрініс терезелері | Әр парақтың көрініс терезелері, масштабы, бұрылысы және қатқан қабаттары бар |
| Қабаттар | Аты, түсі, қосулы/өшірулі күйі, қатқан күйі, басып шығару жалауы және сызық салмағы |
| Нысандар | Сызықтар, полисызықтар, доғалар, шеңберлер, эллипстер, сплайндар, штрихтаулар және қатты денелер, мәтін және көпжолды мәтін, блоктар және атрибуттар, өлшемдер, көсеткілер және көпкөсеткілер, кестелер, нүктелер, суреттер |
| Байланысқан сызбалар | Енгізілген жерінде салынады, олардың файлдары табылғанда |
| Суреттер | Сурет файлдарынан салынады, табылғанда (PNG, JPEG, GIF, BMP, WebP; TIFF жоқ) |
| Жабдық белгілері | Тағамдық қызмет көрсету элементі белгілері (`KCL-ITEM` атрибуттары), жабдықтар спецификациясы үшін |

Басқа нәрсе **Әлі салынбаған** ішінде санала береді, ешқашан болжанбайды. DWG форматтары AutoCAD 2000-нан 2018-ге дейінгі нұсқаларда тексерілген (R13 және R14 файлдары да қабылданады, бірақ сынақ жиынында болған жоқ; ескі DWG-лар ашылмайды); {{ui:Сызба}} панелі форматтың кодын көрсетеді (мысалы AC1032). DXF файлдарының барлық нұсқасы ашылады, R12 қоса. Екеуі де BimCraft-тың өз оқырмандарымен, осы қойындыда оқылады. DWG немесе DXF-ке ешнәрсе қайтарылып сақталмайды.

## Қалтада

| Түрі | Кеңейтімдер | Есепте |
|---|---|---|
| Модельдер | `.rvt` `.rfa` `.rte` `.rft` | Нөмірленген резервтік көшірмелермен топталған, тексерілген, карта оқылған, сілтемелері тексерілген |
| IFC | `.ifc` | Тізімделген; 3D-де ашылады |
| CAD | `.dwg` `.dxf` `.dgn` | Оларды сілтеме жасайтын модельдермен тізімделген; DWG және DXF 2D-да ашылады, DGN ашылмайды |
| Қалдықтар | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | **Бөлек қойылған** астында тізімделген |
| Қызметтік қалталар | `*_backup`, `*_log`, `Revit_temp`, жасырын қалталар | **Бөлек қойылған** астында тізімделген, оқылмайды |
