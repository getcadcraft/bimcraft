IFC5 alpha (кеңейтімі {{ui:.ifcx}} файл) — buildingSMART әлі жобалап жатқан файл форматы. Ол соңғы емес: файлдар мен оларды біздің оқуымыз өзгеруі мүмкін. Сондықтан бұл зертханалық опция және алдымен оқу керек.

## Қосу

1. {{ui:Settings}} таңдаңыз, содан кейін BimCraft қойындысындағы {{ui:IFC5 alpha (IFCX)}} бөлімін таңдаңыз.
2. {{ui:IFC5 alpha (IFCX) — формат әлі өзгеруде; алдымен оқыңыз}} құсбелгісін қойыңыз.

Ол әдепкі бойынша өшірулі. Өшірулі кезде .ifcx файлы осы бетке сілтейтін хабармен қабылданбайды. {{ui:Open IFC5 alpha (.ifcx)…}} және {{ui:IFC5 alpha}} экспорт түймесі ол қосылғанда пайда болады.

## Ашу

- {{ui:Open a file or folder}} көмегімен .ifcx файлын таңдаңыз (ол ашық модельді ауыстырады, өңдеу туралы әдеттегі сұрақтан кейін), немесе
- {{ui:Open IFC5 alpha (.ifcx)…}} түймесін таңдап, бірнеше файлды бірге таңдаңыз: файлды, оның қабаттарын және ол импорттайтын схема файлдарын. Модель бұрыннан ашық болса, файл **соның қасына қосылады**; модель тізіміндегі x белгісі оны қайта алып тастайды — бұл болдырмау.

IFCX файлы түйіндерді тізеді (жол, оның балалары, мұрагерлік алатын нәрселер, атрибуттар). Бірнеше файл бірдей түйінді сипаттай алады: кейінгі файл (қабат) алдыңғысының атрибуттарын қайта жазады, ал null балалық элемент баланы жояды. BimCraft оларды біріктіреді, содан кейін нәтижені атаулары, класстары, қасиеттері, санау мәндері, түстері және үшбұрышты мешлері бар шағын IFC4 моделі ретінде салады: жоба, учаске, ғимарат, қабаттар және элементтер.

Желіден ештеңе алынбайды. Файл импорттайтын схема файлдары (мысалы, `ifc@v5a.ifcx`) тек файлмен бірге таңдалса ғана пайдаланылады; әйтпесе есеп мұны айтады және атрибуттар типті тексеруісіз оқылады.

### Есеп

Ашқаннан кейін есеп оқудың не тапқанын тізеді: схемасына сәйкес келмейтін деректер, берілмеген схема файлдары, мұнда IFC мағынасы жоқ атрибуттар. Картаға түсірілмеген атрибуттар модельде **сақталады**, жойылмайды және экспорт кезінде қайта жазылады.

## Не нәрсеге айналады

| IFCX файлында | BimCraft-та |
|---|---|
| IFC класы бар түйін (жоба, учаске, ғимарат, қабат, қабырға …) | Сәйкес IFC4 элементі; осы оқу білмейтін класс building element proxy болады |
| Түйіннің ата-анасы астындағы аты | Элемент аты |
| Санау түрі бар атрибуттар (Length, Area, Volume, Mass …) | `Qto_IFCX` деп аталатын IFC4 санау жинағы (IFC4 санаулары IFC4 `Qto_*` жинақтары ретінде қалады) |
| Басқа қасиет атрибуттары | `Pset_IFCX` деп аталатын қасиет жинағы |
| Меш және түрлендіру атрибуттары | Элементтің үшбұрыштары және орны; көрінбейтін мештер салынбайды |
| Түс, мөлдірлік, материал, жіктеу | Элементтің беттік стилі, материалы және жіктеуі |

Бірліктер метр ретінде алынады, Z жоғары қарай: alpha нұсқасы бірліктер кейінірек құжатталады деп айтады.

## Экспорт

Құрал жолағындағы {{ui:IFC5 alpha}} таңдаңыз, ескертпені оқыңыз, содан кейін {{ui:Export .ifcx}} таңдаңыз. Файлда біздің тақырыбымыз бар (автор CadCraft, нұсқа ifcx_alpha) және өзінде бұл alpha форматы екенін айтады. Әр модель өзінің файл координаттарында, метрмен жазылады, аттарымен, класстарымен, қасиет жинақтарымен, санауларымен (түрімен атрибуттар ретінде), түстерімен және үшбұрыштарымен. Қабаттар мен мұрагерлік тегістеп жазылады. Оны жіберетін бағдарламада файлды тексеріңіз.

## Шектеулер

- Қисық геометрия (қисықтар, беттер) оқылмайды: тек үшбұрышты мешпен.
- Қабырғаның ішіне орналасқан есіктер мен терезелер қабатқа қойылады; олар шыққан қабырға байланыстырылмайды.
- IFC4 `Qto_*` жинақ аттары біздің атрибут топтары ретінде сақталады (`cadcraft::qto::…`); стандартты alpha схемасында санау аттары тек бірнешеу ғана.
- Формат бізден тыс өзгеруі мүмкін; бүгін жасалған файл ертең оқылмауы мүмкін.
