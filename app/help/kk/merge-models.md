Екі адам бір ғимараттың көшірмесін алады: біреуі шығыс қанатын, екіншісі батыс қанатын сызады, кейін көшірмелер бір болуы керек. Егер олар әр түрлі объектілерге тиген болса, адамның орнына бағдарлама жасай алады.

## Не жұмыс істейтінін қамтамасыз етеді

IFC файлындағы әр қабырға, есік, деңгей, бөлме және қасиеттер жиыны ешқашан өзгермейтін GlobalId-ге ие. Біріктіру объектілерді файл берген нөмір бойынша (`#123`) емес, осы id бойынша іздейді, өйткені бағдарлама сақтағанда нөмірлер өзгереді. Өзінің id-і жоқ, объектіге ілінген бөліктер (орналасулар, пішіндер, өлшем бірліктері) ішіндегісі бойынша салыстырылады.

Екі көшірме бірдей IFC нұсқасында болуы керек (2x3, 4 немесе 4.3). Біріктіру сіздің файлыңызды өз ретімен және нөмірлерімен сақтайды, жаңасын қосады, сондықтан біріктірудің git diff-і тек біріктіру өзгерткенін көрсетеді.

## Орнату

Git репозиторийіне бір рет екі жол керек:

```
# .gitattributes
*.ifc merge=cadcraft

# бір рет, әр компьютерде
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git-сыз `cadcraft merge <base> <ours> <theirs>` іске қосыңыз. Fossil және Mercurial сол үш файлды өз біріктіру құралының баптауында алады. Ешнәрсе жүктелмейді; бәрі сіздің компьютеріңізде жұмыс істейді.

## Ережелер

- Атрибут тек бір жақта өзгерсе, ол алынады. Екі жақта бірдей өзгеріс бір рет алынады.
- Бір атрибут екі түрлі жолмен өзгерсе (бір деңгей екі жақта екі түрлі атаумен аталса), бұл **қайшылық**: сіздің жағыңыз қалады, және есеп екеуін де тізеді. Нәтижені ашып, қолмен түзетіңіз.
- Нәрселер тізімі (деңгейдегі қабырғалар, жиынның қасиеттері) жиын ретінде біріктіріледі: екі жақтың қосқанының бәрі сақталады, екі жақтың өшіргені өшіріледі. Бір деңгейге қабырға қосқан екі адам қайшылыққа түспейді.
- Бір жақта қосылған объект өз пішінімен және қасиеттерімен сақталады. Бір жақта өшірілген, екінші жақта өзгермеген: өшіріледі. Бір жақта өшірілген, екінші жақта өзгерген: өшіріледі және хабарланады.
- Файлдың уақыт белгісі мен авторы, және әр объектінің иесі тарихы сізде қалады.

Геометрия толық біріктіріледі: қабырғаның пішіні бір жақтан келеді, нүкте-нүкте араластырылмайды. Zip-телген IFC және IFCX файлдары біріктірілмейді. Біріктіруден кейін нәтижені BimCraft-та ашып, сақтамас бұрын {{ui:Мәселелер}} панеліне қараңыз.
