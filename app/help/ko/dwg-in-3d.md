## 작업 내용

도면의 모델 공간을 3D로 봅니다. 선과 폴리선은 실제 높이에 놓이고, 두께가 있는 객체는 벽처럼 세워지며, 3D 면, 메시, 3D 블록은 주위를 회전할 수 있는 면으로 표시됩니다. 시트는 2D로 남습니다.

## 단계

1. DWG 또는 DXF를 엽니다. [DWG 또는 DXF 도면 보기](topic:view-dwg) 참조. {{ui:설정}} › {{ui:BimCraft}} › **도면 열기 방식**이 {{ui:모델 (2D)}}로 되어 있지 않으면 3D로 열립니다.
2. 2D에서 도면 위 막대의 {{ui:3D}}를 클릭하거나 {{key:3}}을 누릅니다.
3. 처음에는 잠시 기다리십시오. 상태 표시줄에 "3D로 도면을 작성하는 중…"이 나타난 뒤 표시되는 선과 면의 개수가 나옵니다.
4. 궤도 회전, 초점 이동, 확대/축소를 합니다(아래 표 참조).
5. 두 번째 막대에서 보기를 클릭합니다: {{ui:등각}}, {{ui:위}}, {{ui:아래}}, {{ui:앞}}, {{ui:뒤}}, {{ui:왼쪽}} 또는 {{ui:오른쪽}}.
6. {{ui:원근}}을 클릭해 원근 보기와 평행 보기를 전환합니다.
7. {{ui:범위}}를 클릭하거나 {{key:F}}를 눌러 도면 전체를 다시 봅니다.
8. {{ui:3D}}를 다시 클릭하거나 {{key:3}}을 누르거나, {{ui:모델}} 또는 시트 탭을 클릭하면 2D로 돌아갑니다.

## 보이는 것

- Z축이 위를 향하는 3D 모델 공간이며, 도면 고유의 색을 씁니다. 면은 모서리보다 조금 밝습니다.
- {{ui:도면층}}에서 끈 도면층은 3D 보기에서도 사라집니다.
- 오른쪽에는 선과 면의 개수, X, Y, Z 방향의 도면 크기, **2D 보기에서만**, **아직 그리지 않음**이 표시됩니다.

## 단면 평면으로 자르기

3D 막대의 {{ui:단면}}을 클릭하거나 {{key:X}}를 누릅니다. 그 아래 막대는 IFC 모델에서와 같이 작동합니다([단면 평면으로 IFC 모델 자르기](topic:section-plane) 참조). {{ui:위}}, {{ui:앞}} 또는 {{ui:측면}}에서 자르고, 간격을 끌거나 입력하며(여기서는 도면 고유의 단위로), 다른 쪽을 남기려면 {{ui:뒤집기}}를 누릅니다. 평면이 잘라 낸 부분은 고를 수 없습니다. 2D로 돌아가면 자른 것이 원래대로 돌아갑니다.

## 객체의 특성 보기

3D 보기에서 객체를 클릭합니다. 고른 색으로 바뀌고 {{ui:특성}}에 파일이 그 객체에 대해 말하는 내용이 표시됩니다. 유형, 도면층, 색, 선 종류, 핸들이 나오고, 그다음 자체 데이터가 나옵니다. 예를 들어 선의 시작점, 끝점, 길이, 원의 중심과 반지름, 3D 면의 모서리, 블록 참조의 블록, 삽입점, 축척, 회전, 속성 값 등입니다.

- 블록 참조는 전체가 한 번에 고르며, 그 안에 중첩된 블록도 함께 고릅니다.
- 선에서 몇 픽셀 떨어진 곳을 클릭하면 그 선을 고릅니다.
- {{key:Mod}}를 누른 채 클릭하면 객체를 더 고르거나 하나를 뺍니다. 그러면 {{ui:특성}}이 유형별 개수를 셉니다.
- {{key:Esc}}를 누르거나 빈 공간을 클릭하면 선택이 해제됩니다.
- 끈 도면층의 객체는 고를 수 없습니다.

## 이동

:::mouse
| 목적 | 할 일 |
|---|---|
| 궤도 회전 | 가운데 버튼으로 끌거나, 왼쪽 버튼으로 끕니다 |
| 초점 이동 | 오른쪽 버튼으로 끌거나, {{key:Shift}}를 누른 채 끕니다 |
| 확대/축소 | 휠을 굴립니다. 포인터 아래 쪽으로 확대/축소됩니다 |
| 전체 보기 | {{ui:범위}} 또는 {{key:F}} |
| 측면에서 보기 | 오른쪽 아래 뷰 큐브의 면, 모서리 또는 꼭짓점을 클릭합니다 |
:::

뷰 큐브는 {{ui:설정}}에서 축 아이콘으로 바꾸거나 숨길 수 있습니다. [BimCraft 설정](topic:settings) 참조.

:::mac mouse
트랙패드에서는 두 손가락으로 쓸어 궤도 회전하고, {{key:Shift}}를 누른 채 쓸어 초점을 이동하며, 핀치로 확대/축소합니다.
:::

:::touch
한 손가락으로 끌어 궤도 회전합니다. 두 손가락으로 벌리거나 모아 확대/축소하고, 두 손가락을 함께 움직여 초점을 이동합니다.
:::

## 3D로 그려지는 것

| 도면에서 | 3D에서 |
|---|---|
| 선, 3D 폴리선 | 실제 높이에 |
| 폴리선, 원, 호, 타원 | 자체 평면에, 표고에 놓이며, 도면이 기울면 함께 기울어짐 |
| 선, 폴리선, 원, 호의 두께 | 그 높이의 벽. 원은 위아래가 닫힘 |
| 3D 면, 폴리페이스 메시, 폴리곤 메시 | 보이는 모서리가 있는 음영 면 |
| 블록 | 3D에서 배치, 회전, 축척 적용, 중첩 블록도 포함 |
| 해치 | 외곽선 |
| 일반 2D 선 작업 | 그린 자리에 평평하게 |

## 2D 보기에서만

문자, 여러 줄 문자, 블록의 보이는 속성은 3D에서 자체 평면과 자체 높이로 그려지며, 그 위를 클릭하면 고를 수 있습니다. 넓은 폴리선은 너비를 평평한 띠로 보여 줍니다. 여러 줄 지시선, 그림, 해치 패턴은 **2D 보기에서만**에 집계됩니다. 이들은 {{ui:모델}} 탭이나 시트에서 보십시오.

## 아직 그리지 않음

ACIS 본체로 저장된 솔리드와 곡면(3D 솔리드, 본체, 영역, 곡면)과 세분화 메시는 **아직 그리지 않음** 아래에 개수와 함께 나열됩니다. 추측해서 그리지 않고 건너뜁니다.

## 자주 하는 실수

- **모든 것이 평평해 보임.** 도면이 2D이므로 선에는 높이가 없습니다. {{ui:앞}}을 클릭해 확인하십시오. 평평한 도면은 선으로 보입니다.
- **솔리드 모델이 아무것도 보이지 않음.** 솔리드 모델러로 만든 솔리드는 ACIS 본체이므로 **아직 그리지 않음**에 나열됩니다. 그 모델을 만든 프로그램에서 IFC나 3D 면으로 내보내십시오.
- **도면이 가운데에 작은 덩어리로 보임.** 모델 공간의 먼 곳에 있는 것(예: 오래된 평면의 복사본)이 범위를 크게 만듭니다. 보고 싶은 곳에서 휠로 확대하십시오.
