## 작업 개요

라이브러리에서 무엇인지 기준으로 필요한 항목을 찾고, 그리고 있는 프로젝트에 유형을 추가하며, 누군가 공유한 템플릿으로 새 프로젝트를 시작하고, 자신의 템플릿, 유형, 키트를 공유합니다.

## 라이브러리 항목의 세 가지 종류

- **심볼**은 도면 관례입니다. 2D 전용이며 주석 크기로 그려지고, 분야별로 묶입니다.
- **유형**은 요소가 무엇으로 이루어졌는지를 나타냅니다: 실제 두께를 가진 레이어, LOD(개발 수준), 분류 코드. 유형은 그리는 것이 아니라 프로젝트에 추가됩니다.
- **에셋**은 문, 창, 가구, 설비, 장비 같은 실물 객체입니다. 평면 보기와 실제 크기의 3D 본체를 가집니다.

{{ui:라이브러리}} 탭에서 {{ui:라이브러리}}를 고르고 **항목 종류**를 사용해 전체, 심볼, 유형, 에셋 중에서 보기를 바꿉니다.

## 프로젝트에 유형 추가

1. **항목 종류**에서 **유형**을 고르고 하나를 엽니다.
2. 그림 아래에서 구성, LOD, 분류를 확인한 다음 {{ui:이 프로젝트에 추가}}를 클릭합니다.
3. 벽, 바닥, 지붕, 천장 유형으로 추가되어 바로 그릴 수 있습니다. 같은 이름의 유형이 이미 있으면 새 유형은 사본으로 추가되고 기존 유형은 그대로 남습니다. 실행 취소 한 번으로 제거됩니다.

## 프로젝트 템플릿과 빠른 키트

{{ui:키트}}를 선택하면 사람들이 공유한 항목을 볼 수 있습니다.

- **프로젝트 템플릿**은 층, 그리드, 유형, 설정이 담긴 IFC 파일입니다. {{ui:내 템플릿에 저장}}을 누르면 새 건물의 시작 항목에 나타납니다.
- **빠른 키트**는 라이브러리 항목 목록입니다. {{ui:키트 항목 보기}}를 누르면 배치할 수 있는 카드로 나열됩니다.
- 모든 키트에는 버전과 변경 이력이 있으며 최신순입니다. 0으로 시작하는 버전은 논의용이고, 1.0.0은 라인의 소유자가 채택한 것에만 씁니다.

## 자신의 것 공유하기

- **프로젝트 템플릿:** {{ui:템플릿으로 저장}} 버튼을 누르고 {{ui:라이브러리에서 공유할 파일도 만들기}}를 선택한 뒤, 담긴 내용과 버전을 입력합니다. `.json` 파일을 받게 됩니다.
- **빠른 키트:** {{ui:키트}}에서 {{ui:이 프로젝트로 빠른 키트 만들기}}를 선택합니다. 프로젝트가 사용하는 라이브러리 항목이 나열됩니다.
- **유형:** {{ui:유형 팩}}에서 유형 하나를 선택하고 {{ui:라이브러리 항목으로 저장…}}을 누릅니다.

파일은 라이브러리의 업로드 페이지에서 올립니다. 다른 항목과 같은 검토를 거치며, 그곳에서 라이선스를 고릅니다. 모든 항목은 라이선스를 명시해야 합니다. 항목에는 LOD, IFC 클래스, 분류 코드(이름만이 아닌 코드)가 필요합니다.

## 실무 메모

라이브러리 항목 페이지에서 로그인한 회원은 메모를 남길 수 있습니다: 실제 프로젝트에 사용함, 샘플 프로젝트에서 시험함, 또는 문제를 발견함. 프로젝트 종류를 몇 단어로 적고 고객 이름은 빼십시오. 메모는 공개되지만 평가가 아니며 항목을 바꾸지 않습니다.

## 알아 두면 좋은 점

- 앱에서는 아무것도 전송되지 않습니다. 파일은 컴퓨터에서 만들어지며 직접 업로드합니다.
- 템플릿으로 만든 키트는 저장된 IFC 텍스트를 그대로 담습니다. 업로드하기 전에 비공개 내용이 없는지 확인하십시오.
- CadCraft는 라이브러리 탭에 심볼과 에셋을 표시합니다. 유형과 템플릿은 BimCraft 프로젝트용입니다.
