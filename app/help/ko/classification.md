## 할 일

벽, 바닥, 지붕, 문, 창문 등 모델의 모든 요소에 분류 코드를 붙입니다. Uniclass, OmniClass, UniFormat의 세 체계까지 나란히 지정할 수 있습니다. 다른 분야와 다른 소프트웨어는 이름이 아니라 코드를 기준으로 하므로, 코드는 모든 BIM 프로그램이 읽는 분류 참조로 IFC 파일에 저장됩니다.

## 요소에 코드 지정

1. 요소(또는 여러 요소)를 선택하고 **속성**을 엽니다. {{ui:분류}} 섹션을 펼칩니다.
2. 해당 체계의 칸에 코드를 입력하고 Enter를 누릅니다. 코드 목록을 불러온 상태라면 코드 일부나 몇 개의 단어("커튼월")를 입력한 뒤 일치 항목에서 고릅니다. 그러면 코드의 제목이 자동으로 채워집니다.
3. {{ui:적용 대상}}에서 코드가 적용될 범위를 정합니다. **이 요소** 또는 **유형(같은 유형의 모든 요소)**. 벽 유형에 지정한 코드는 그 유형의 모든 벽에 적용되며, 나중에 그리는 벽에도 적용됩니다.
4. {{ui:지우기}}를 누르면 코드가 삭제됩니다.

각 코드 아래의 섹션에는 출처가 표시됩니다. 이 요소에 직접 지정됨, 유형에서 가져옴, 또는 클래스별 프로젝트 기본값입니다. 요소 자체의 코드가 유형의 코드보다 우선하고, 유형의 코드가 기본값보다 우선합니다. 여러 요소를 선택했을 때 "다양함"이라고 표시된 칸은 요소들이 같은 코드를 공유하지 않는다는 뜻입니다. 코드를 하나 입력하면 모두에게 적용됩니다. 각 변경은 실행 취소 한 단계입니다.

코드 목록을 불러왔는지와 관계없이 언제든 코드를 입력할 수 있습니다. 해당 체계의 코드 형식이 아니거나 불러온 목록에 없으면 안내가 표시되며, 입력한 코드는 그대로 유지됩니다.

## 프로젝트의 체계 선택

모델 막대의 **데이터**를 열고 {{ui:분류}}(또는 속성 섹션의 {{ui:프로젝트 분류…}})를 선택합니다.

- 이 프로젝트가 사용하는 체계를 체크합니다. 그러면 속성에는 선택한 체계만 나타납니다.
- **Uniclass**: 요소/기능(EF), 시스템(Ss), 제품(Pr) 표가 앱과 함께 제공됩니다. 이 표들은 © NBS의 저작물이며 Creative Commons Attribution-NoDerivatives 4.0 라이선스로 배포되고, 변경 없이 그대로 전달됩니다. 대화상자에는 각 표의 판과 읽은 날짜가 표시됩니다. 이 표들은 최신 표가 아닙니다. 발행처는 분기마다 자체 사이트에서 새 표를 발행합니다.
- **OmniClass**와 **UniFormat**: 발행처가 라이선스 없이 표를 전달하는 것을 허용하지 않으므로, 코드 목록은 앱과 함께 제공되지 않습니다. 코드를 직접 입력하거나 사무실이 보유한 라이선스 표를 불러오십시오.
- {{ui:표 불러오기(CSV)…}}는 코드 열과 제목 열이 있는 CSV 파일에서 사무실의 표를 읽습니다. Code, Number 또는 Identifier 열과 Title, Name 또는 Description 열이 있는 머리글 행은 자동으로 인식되며, 머리글이 없으면 처음 두 열을 사용합니다. 표는 이 브라우저에만 보관되며 프로젝트 파일에는 저장되지 않습니다. 지정한 코드만 파일에 저장됩니다. 같은 방식으로 더 새로운 Uniclass 표를 불러올 수도 있습니다.
- {{ui:클래스별 기본 코드를 요소에 지정}}은 코드가 없는 모든 벽, 바닥, 지붕, 문, 창문, 계단, 경사로, 기둥, 보, 가구에 요소/기능 표에서 가져온 Uniclass 시작 코드를 지정합니다. 이후에 그리는 요소에도 적용됩니다.
- {{ui:일람표에 코드를 열로 표시}}는 문, 창문, 유형별 벽, 실 일람표와 그 CSV에 체계마다 열을 하나씩 추가합니다. 여러 요소를 묶은 행은 코드가 다르면 "다양함"으로 표시됩니다.

## 알아두면 좋은 점

- 기본 코드는 CadCraft가 정한 시작값이며 발행처의 공식 코드가 아닙니다. 실무자가 검토하지 않았습니다. 프로젝트의 표준과 비교하여 확인하십시오.
- 파일에서 기본값은 "CadCraft default"라는 관계 이름이 붙은 실제 분류로 기록되며, 요소나 유형에 고유한 코드가 지정되면 사라집니다.
- 가져온 파일에 이미 있는 코드는 다른 프로그램이 해당 체계의 이름을 어떻게 적었든 읽어서 표시합니다. 다른 체계(사무실 고유의 체계)의 코드는 목록에 표시되며 그대로 둡니다.
- 파일을 다시 열면 여기에서든 다른 프로그램에서든 코드를 다시 읽습니다. 실험 옵션이 켜져 있으면 IFC5 알파(IFCX) 내보내기에도 포함되며, 지붕에 지정한 코드는 제외됩니다.
- 아직 만들지 않은 기능: 표를 단계별로 탐색하는 트리, 층과 실에 대한 프로젝트 기본 코드, 파일에 적힌 판과 코드를 대조하는 기능.
