## 할 작업

주방 또는 급식 도면에서 설비 목록을 읽고, 확인하고, 평면에서 각 항목을 찾은 뒤 스프레드시트 파일로 다운로드합니다.

이 기능은 KCL과 같은 주방 설계 라이브러리처럼 설비 태그가 블록 속성으로 데이터를 가지고 있는 도면에서 작동합니다. 각 태그에는 항목 번호(`KCL-ITEM`), 수량, 분류, 제조사, 모델, 전기 및 배관 데이터, 비고가 들어 있습니다. 다른 도면에는 {{ui:Equipment}} 탭이 없습니다.

## 단계

1. 도면을 엽니다. 연결된 도면도 불러오려면 가능하면 프로젝트 폴더에서 엽니다.
2. 도면 위의 {{ui:Equipment}} 탭을 클릭합니다. 탭 이름에는 시트에 있는 항목 수가 표시됩니다(예: "설비 (88)").
3. 일람표를 확인합니다: **항목**, **수량**, **설비**, **제조사**, **모델**, **전기**, **배관**, **위치**.
4. 표 위의 메뉴에서 나열할 대상을 선택합니다: **모든 시트**, 한 시트, **어떤 시트에도 없음**, 또는 **도면에서 태그된 모든 항목**. 각 선택 항목에는 개수가 표시됩니다.
5. 필터 상자에 입력하여 목록을 좁힙니다("필터: 분류, 제조사, 모델…"). 예: `refrigerator` 또는 `208`. 한국어로는 `냉장고`처럼 입력할 수도 있습니다.
6. **위치** 열에서 항목의 시트 이름을 클릭합니다.
7. 도면을 확인합니다. BimCraft가 해당 시트로 전환하고, 항목을 확대하여 주위에 원을 그립니다. 상태 표시줄에는 "항목 *n*, *분류*: *시트*에서 원으로 표시됨"이 나타납니다.
8. {{ui:Equipment}}을 클릭하여 일람표로 돌아갑니다.
9. {{ui:Download CSV}}를 클릭합니다.

## 결과 확인

- 다운로드 폴더에 "*도면 이름* equipment.csv"라는 파일이 생성됩니다. 시트 하나만 나열했다면 파일 이름에 시트 이름이 괄호로 추가됩니다. 이 파일은 Excel, Numbers, LibreOffice 또는 Google 스프레드시트에서 열 수 있습니다.
- 상태 표시줄에 "다운로드됨: *파일 이름* (*n*개 항목)."이 표시됩니다.

CSV에는 항목, 수량, 분류, 제조사, 모델, 전기, 배관, 비고, 전기 비고, 배관 비고, 시트, 배치 수(태그 개수) 열이 있습니다. 메뉴와 필터를 적용한 후 표에 보이는 행만 다운로드됩니다.

## 일람표 작성 방식

- 일람표는 도면에 그려진 일람표가 아니라 **태그 자체**에서 읽습니다. 표 위의 메모에 읽은 태그 수가 표시됩니다.
- 한 행은 하나의 항목 번호와 하나의 데이터 집합에 해당합니다. 수량은 해당 태그들의 **합계**이며, 인쇄된 일람표와 같은 방식으로 계산합니다. 한 곳에 "5", 다른 곳에 "3"으로 태그된 선반은 8이며 "5 + 3"으로 표시됩니다.
- **위치**에는 각 시트의 뷰포트에 표시되는 내용을 기준으로, 항목이 나타나는 시트가 나열됩니다. 인쇄되는 내용을 기준으로 합니다. "모델에만"은 어떤 시트에도 표시되지 않았음을 뜻합니다.
- **번호 중복**은 서로 다른 두 설비에 같은 항목 번호가 사용된 경우를 표시합니다. 해당 행에 주황색 표시가 나타납니다.
- 어떤 시트에도 표시되지 않은 태그는 **어떤 시트에도 없음**에 따로 보관되며, **모든 시트**에는 절대 포함되지 않습니다. 이전 계획이나 다른 프로젝트에서 남은 태그인 경우가 많습니다.
- **전기**에는 태그된 대로 암페어, kW, HP, 볼트, 상, 연결 방식, 플러그가 표시됩니다. **배관**에는 연결 크기가 표시됩니다: CW 냉수, HW 온수, DD 직접 배수, ID 간접 배수, 가스. 다른 태그 필드는 아직 표시되지 않습니다.

## 자주 하는 실수

- **{{ui:Equipment}} 탭이 없습니다.** 도면에 `KCL-ITEM` 태그가 없거나, 설비가 데이터 없이 그려져 있습니다. 읽을 내용이 없습니다.
- **개수가 인쇄된 일람표와 다릅니다.** 인쇄된 일람표에는 여분 번호가 있거나 태그보다 짧은 이름이 쓰였을 수 있습니다. 실제 배치는 태그를 기준으로 확인하고, 차이는 설계자와 확인하십시오.
- **CSV를 열면 글자가 깨져 보입니다.** 파일은 UTF-8입니다. 스프레드시트의 가져오기 명령으로 열고, 프로그램이 묻는 경우 UTF-8을 선택하십시오.
- **셀 앞에 아포스트로피가 있습니다.** `=`, `+`, `-` 또는 `@`로 시작하는 값은 스프레드시트가 수식으로 실행하지 않도록 앞에 `'`가 붙습니다.
- **{{key:F}}와 {{key:P}}가 작동하지 않습니다.** 이 키는 일람표가 아니라 도면에서 작동합니다. 먼저 시트 탭을 클릭하십시오.
