애드온(설정 › 애드온)은 {{ui:Render}}의 엔진 목록에 엔진을 추가할 수 있습니다. 애드온 작성자를 위한 전체 내용은 애드온 사양의 16절에 있습니다. 요약하면 다음과 같습니다:

- 애드온은 자신의 접두사로 시작하는 ID, 이름, 선택 설정, 그리고 실행할 **프로그램** 또는 그림을 그리는 JavaScript **함수** 중 **하나**로 엔진을 등록합니다.
- 프로그램을 실행하는 엔진에는 **`engine.run`** 권한이 필요하며, 설치 전과 설정에 표시됩니다. 이 엔진은 Studio에서만 실행되며, 브라우저에서는 저장할 파일로 표시됩니다.
- 애드온은 프로그램 이름(셸이 아닌 일반 파일 이름), **서명된 애드온 안에 있는** 스크립트, 그리고 자리표시자와 일반 단어로 이루어진 인수를 지정합니다. Studio는 프로그램을 찾거나, 한 번만 위치를 지정하도록 요청합니다.
- 애드온이 처음 프로그램을 실행하면 **Studio가 자체 대화상자에서 묻습니다**: 어떤 애드온인지, 어떤 프로그램인지, 그리고 스크립트가 프로그램이 할 수 있는 모든 작업을 할 수 있다는 점. 신뢰하는 애드온에만 허용하십시오. 응답은 해당 애드온과 프로그램에 대해 기억됩니다.
- 패키지(USD 형식의 장면과 설정 파일, 애드온이 요청하면 glTF 파일 포함)와 애드온의 스크립트는 새로운 임시 폴더에 들어갑니다. 프로그램은 그 폴더에서 실행되고, 그림은 애드온의 엔진 이름이 표시된 채로 돌아옵니다.

:::note
애드온은 애드온 API 1.4 이상에서만 렌더 엔진을 추가할 수 있습니다. 오픈 소스 명령줄 렌더러의 작업 예제는 별도 저장소에 있으며, 아직 그 렌더러에서 실행해 보지는 않았습니다.
:::
