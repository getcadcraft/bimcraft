BimCraft는 브라우저 탭 안에서 내 컴퓨터의 파일을 읽습니다. CadCraft나 다른 곳으로 **아무것도 업로드되지 않습니다**. 저장할 때 BimCraft는 브라우저에 다운로드할 새 파일을 넘기며, 연 파일을 덮어쓰지 않습니다.

## 여는 파일

| 형식 | 확장자 | 얻는 것 |
|---|---|---|
| IFC | `.ifc` | 3D 모델, 층, 요소 개수, 모든 요소의 속성. 이름, 태그, 개별 속성 값을 바꿀 수 있습니다. |
| 프로젝트 및 패밀리 파일 | `.rvt` `.rfa` `.rte` `.rft` | 파일 카드: 릴리스, 빌드, 작업 공유, 프로젝트 정보, 패밀리 파라미터, 연결된 파일, 미리 보기 그림. 3D는 없습니다. |
| DWG | `.dwg` | 2D 도면: 모델 공간, 모든 시트, 도면층, 연결된 도면, 이미지, 인쇄 보기. 모델 공간은 3D로도 볼 수 있습니다. AutoCAD 2000부터 2018까지의 형식을 확인했습니다. |
| DXF | `.dxf` | DWG와 같습니다. |
| STEP | `.step` `.stp` | 3D로 보는 파트, 설비 또는 공급업체 모델(AP203, AP214, AP242): 각 솔리드는 한 층으로 된 작은 IFC 모델의 요소 하나(건축 요소 프록시)가 되며, 삼각형으로 실제 크기대로 읽습니다. 어셈블리는 파일에서 배치한 위치에 모든 파트가 놓입니다. 이후에는 다른 IFC와 같이 작동합니다: 속성, 단면, 측정, IFC로 저장. 색상과 어셈블리 트리는 읽지 않습니다. |
| 포인트 클라우드 | `.las` `.laz` `.e57` `.ply` `.pcd` `.ptx` `.pts` `.xyz` | 3D 보기의 스캔: 모델 옆에 또는 단독으로 표시합니다. [모델 옆에 포인트 클라우드 표시](topic:point-clouds)를 참조하십시오. |
| 프로젝트 번들 | `.ccbundle.zip` | 뷰, 배치, 속성 그룹이 포함된 모델: [프로젝트 번들 열기](topic:open-project-bundle)를 참조하십시오. |
| 폴더 | 모두 | 폴더 안의 모든 모델, 도면, 프로젝트 번들에 대한 보고서. 보고서의 IFC, 모델, 도면, 번들은 클릭하면 열립니다. |

[BimCraft가 각 형식에서 읽는 내용](topic:file-formats)에서 자세히 설명합니다.

BimCraft는 이름뿐 아니라 파일의 처음 바이트를 보고 파일 종류를 판단하므로, 확장자가 특이한 프로젝트 파일도 파일 카드로 열립니다.

### 열 수 없는 파일

- `.ifczip` 및 `.ifcxml`: BimCraft는 ".ifczip is not supported yet. Save or export the model as a plain .ifc file."이라는 메시지를 표시합니다. `.ifczip`의 압축을 풀거나(안에 일반 `.ifc`가 들어 있습니다) 일반 IFC로 다시 내보내십시오.
- DGN 도면은 폴더 보고서에 나열되지만 열리지 않습니다.
- PDF, 이미지, 오피스 파일은 단독으로 열리지 않습니다. 이미지는 DWG 안의 그림으로 사용되며, {{ui:빌드}} › {{ui:도면에서…}}는 PDF나 스캔의 페이지를 벽으로 바꿉니다. [도면 세트에서 벽 만들기](topic:walls-from-plans)를 참조하십시오.

## 저장하는 파일

| 클릭 | 얻는 것 | 위치 |
|---|---|---|
| {{ui:IFC 저장}} | 수정 내용이 담긴 새 IFC 파일, 이름은 "*원래 이름* (edited).ifc" | 브라우저의 다운로드 폴더 |
| 설비 일람표의 {{ui:CSV 다운로드}} | 목록 항목의 CSV, 이름은 "*도면 이름* equipment.csv" | 브라우저의 다운로드 폴더 |

그 밖의 것은 만든 위치에 저장되며, 각각 자기 항목에서 설명합니다: {{ui:USD}}([모델을 USD로 내보내기](topic:usd)), .glb {{ui:렌더링용}}, 렌더한 그림, PDF로 된 시트와 평면, CSV로 된 일람표와 목록, BCF 이슈, COBie 스프레드시트, 패밀리 파일, LAS 또는 E57로 된 정합된 스캔. BimCraft는 DWG, DXF, 프로젝트 파일을 저장하지 않으며, 연 파일을 절대 바꾸지 않습니다.

:::chromium
Chrome과 Edge는 설정에 지정한 폴더(보통 다운로드)에 저장합니다. 매번 저장 위치를 묻게 하려면 브라우저 다운로드 설정에서 "다운로드 전에 각 파일의 저장 위치 확인"을 켜십시오.
:::

:::firefox
Firefox는 설정에서 "항상 파일을 저장할 위치 선택"으로 지정하지 않는 한 다운로드 폴더에 저장합니다.
:::

:::safari
Safari는 **Safari > 설정 > 일반 > 파일 다운로드 위치**에서 다른 폴더를 선택하지 않는 한 다운로드 폴더에 저장합니다.
:::

## 다시 저장하기

저장할 때마다 마지막 저장 이후의 수정뿐 아니라 **연 이후의 모든 수정**이 담긴 전체 모델을 다운로드합니다. 저장할 때마다 {{ui:변경 사항}} 목록이 다시 비워지므로, 저장 이전으로는 실행 취소할 수 없습니다. 처음부터 다시 시작하려면 원본 파일을 다시 여십시오.

## 큰 파일과 메모리

- **IFC** 파일은 탭의 메모리로 완전히 읽히며, 3D 형상은 그 위에 메모리를 더 사용합니다. 수백 메가바이트의 모델은 노트북에 너무 클 수 있습니다. 삼각형이 150만 개를 넘으면 메모리를 아끼려고 모서리가 꺼집니다("매우 큰 모델에서는 모서리가 꺼져 있습니다").
- **프로젝트 파일**은 전부 읽지 않습니다. BimCraft는 파일 크기와 관계없이 필요한 작은 부분, 약 40 KB에서 100 KB만 읽으므로 네트워크 드라이브의 500 MB 중앙 모델도 순식간에 열립니다.
- **DWG와 DXF** 파일은 완전히 읽습니다. 매우 큰 도면에는 "이 도면은 매우 커서 일부만 표시합니다."가 표시됩니다.
- **폴더**는 파일 20,000개까지 열립니다. 각 모델 카드에 필요한 몇 킬로바이트만 읽습니다.

자세한 내용은 [브라우저, 기기, 메모리](topic:platforms)를 참조하십시오.

## 온라인과 오프라인

파일을 열 때 인터넷은 필요하지 않습니다. 필요할 때 처음 한 번 사이트에서 불러오는 리더가 하나 있습니다. IFC 모델을 처음 열 때의 IFC 엔진입니다("IFC 엔진을 시작하는 중…"). DWG와 DXF 리더는 앱에 포함되어 있습니다.

:::offline
오프라인 상태입니다. 앱 바의 버튼이 {{ui:오프라인 사용 준비됨}}이면 모든 형식이 평소처럼 열립니다. 아니면 이 탭에서 이미 연 IFC 모델이 없는 한 IFC 모델을 열 수 없으니 먼저 다시 연결하십시오. [온라인과 오프라인](topic:online-offline)을 참조하십시오.
:::

연결 없이 BimCraft를 사용하려면 온라인일 때 앱 바에서 {{ui:오프라인용 저장}}을 클릭하고 {{ui:오프라인 사용 준비됨}}이 표시될 때까지 기다리십시오. 저장된 사본은 약 33 MB이며 IFC 엔진이 포함되어 있어 IFC 모델도 오프라인에서 열립니다. 저장된 사본에 대한 일반적인 설명은 [오프라인으로 작업하기](common:offline)에 있습니다.

## 클라우드 저장

클라우드 저장은 아직 사용할 수 없습니다. 수정한 사본은 다른 파일과 마찬가지로 내 컴퓨터나 사무실 파일 서버에 저장하십시오. [내 파일](common:your-files)을 참조하십시오.
