BimCraft는 컴퓨터의 파일을 브라우저 탭에서 읽습니다. CadCraft나 다른 어떤 곳으로도 **아무것도 업로드되지 않습니다**. 저장할 때 BimCraft는 브라우저에 다운로드할 새 파일을 넘겨주며, 연 파일을 덮어쓰는 일은 없습니다.

## 여는 형식

| 형식 | 확장자 | 얻는 것 |
|---|---|---|
| IFC | `.ifc` | 3D 모델, 층, 요소 수, 모든 요소의 속성. 이름, 태그, 단일 속성 값은 바꿀 수 있습니다. |
| 프로젝트 및 패밀리 파일 | `.rvt` `.rfa` `.rte` `.rft` | 파일 카드: 릴리스, 빌드, 작업 공유, 프로젝트 정보, 패밀리 매개변수, 연결된 파일, 미리 보기 그림. 3D는 없습니다. |
| DWG | `.dwg` | 2D 도면: 모델 공간, 모든 시트, 도면층, 연결된 도면, 이미지, 인쇄 보기. 모델 공간은 3D로도 볼 수 있습니다. 확인된 형식은 AutoCAD 2000에서 2018까지의 형식입니다. |
| DXF | `.dxf` | DWG와 같음. |
| STEP | `.step` `.stp` | 3D 부품, 장비 또는 공급업체 모델(AP203, AP214, AP242). 각 솔리드가 한 층에 있는 작은 IFC 모델의 요소 하나(건물 요소 프록시)가 되며, 실제 크기의 삼각형으로 읽힙니다. 파일이 배치한 위치에 모든 파트가 들어 있는 어셈블리가 됩니다. 그 뒤로는 어떤 IFC와 같이 작동합니다: 속성, 단면, 측정, IFC로 저장. 색상과 어셈블리 트리는 읽지 않습니다. |
| 포인트 클라우드 | `.las` `.laz` `.e57` `.ply` `.pcd` `.ptx` `.pts` `.xyz` | 3D 보기에 나타나는 스캔. 모델 옆에 또는 단독으로 표시됩니다. 자세한 내용은 [모델 옆에 포인트 클라우드 표시하기](topic:point-clouds)를 참고하십시오. |
| 프로젝트 번들 | `.ccbundle.zip` | 뷰, 배치, 속성 그룹이 포함된 모델. 자세한 내용은 [프로젝트 번들 열기](topic:open-project-bundle)를 참고하십시오. |
| 폴더 | 모든 형식 | 폴더 안의 모든 모델, 도면, 프로젝트 번들을 나열한 보고서. 보고서의 IFC, 모델, 도면 또는 번들은 클릭 한 번으로 열립니다. |

[BimCraft가 각 형식에서 읽는 내용](topic:file-formats)은 자세히 설명되어 있습니다.

BimCraft는 파일 이름뿐 아니라 첫 바이트를 보고 파일이 무엇인지 판단하므로, 특이한 확장자를 가진 프로젝트 파일도 파일 카드로 열립니다.

### 열리지 않는 형식

- `.ifczip` 및 `.ifcxml`: BimCraft는 ".ifczip is not supported yet. Save or export the model as a plain .ifc file."라고 표시합니다. `.ifczip` 파일의 압축을 풀거나(안에 일반 `.ifc` 파일이 들어 있음) 일반 IFC로 다시 내보내십시오.
- DGN 도면은 폴더 보고서에 나열되지만 열리지 않습니다.
- PDF, 이미지, 오피스 파일은 단독으로 열리지 않습니다. 이미지는 DWG 안의 그림으로 사용되며, {{ui:빌드}} › {{ui:도면에서…}}: PDF나 스캔의 페이지를 벽으로 바꿉니다. 자세한 내용은 [여러 도면 세트에서 벽 만들기](topic:walls-from-plans)를 참고하십시오.

## 저장하는 항목

| 누르는 것 | 결과 | 위치 |
|---|---|---|
| {{ui:IFC 저장}} | 편집 내용이 포함된 새 IFC 파일. 이름은 "*원래 이름* (edited).ifc" | 브라우저의 다운로드 폴더 |
| 설비 일정표에서 {{ui:CSV 다운로드}} | 목록 항목의 CSV. 이름은 "*도면 이름* equipment.csv" | 브라우저의 다운로드 폴더 |

그 밖의 항목은 만들어진 곳에 저장되며, 각각 자체 항목에서 설명합니다: {{ui:USD}} ([모델을 USD로 내보내기](topic:usd)), {{ui:Collada}} ([모델을 Collada 또는 Google Earth용으로 내보내기](topic:collada) — .dae와 Google Earth .kmz), .glb {{ui:렌더링용}}, 렌더링한 그림, PDF로 된 시트와 평면도, CSV로 된 일정표와 목록, BCF 이슈, COBie 스프레드시트, 패밀리 파일, LAS 또는 E57로 등록된 스캔. BimCraft는 DWG, DXF 또는 프로젝트 파일을 저장하지 않으며, 연 파일은 절대 변경하지 않습니다.

:::chromium
Chrome 및 Edge는 설정에서 지정한 폴더에 다운로드를 저장하며, 보통은 다운로드 폴더입니다. 저장할 때마다 위치를 묻게 하려면 브라우저의 다운로드 설정에서 "다운로드 전에 각 파일의 저장 위치 묻기"를 켜십시오.
:::

:::firefox
Firefox는 설정에서 "파일을 저장할 위치를 항상 묻기"로 바꾸지 않는 한 다운로드 폴더에 저장합니다.
:::

:::safari
Safari는 **Safari > 설정 > 일반 > 파일 다운로드 위치**에서 다른 폴더를 고르지 않으면 다운로드 폴더에 저장합니다.
:::

## 다시 저장하는 경우

저장할 때마다 모델 전체를 **연 뒤의 모든 편집 내용**과 함께 다운로드합니다. 마지막 저장 이후의 편집만 저장되는 것은 아닙니다. 저장할 때마다 {{ui:변경 사항}} 목록이 다시 비워지므로, 저장 이전 상태로는 실행 취소할 수 없습니다. 원본부터 다시 시작하려면 원본 파일을 다시 여십시오.

## 큰 파일과 메모리

- **IFC** 파일은 탭의 메모리에 전부 읽히며, 3D 형상이 그 위에 메모리를 더 차지합니다. 수백 메가바이트짜리 모델은 노트북에는 너무 클 수 있습니다. 삼각형이 1,500,000개를 넘으면 메모리를 아끼려고 모서리가 꺼집니다("Edges are off for very large models").
- **프로젝트 파일**은 전부 읽지 않습니다. BimCraft는 필요한 작은 부분만 읽으며, 파일이 얼마나 크든 약 40 KB에서 100 KB 정도입니다. 그래서 네트워크 드라이브에 있는 500 MB 중앙 모델도 순식간에 열립니다.
- **DWG**와 **DXF** 파일은 전부 읽힙니다. 매우 큰 도면에는 "This drawing is very large; only part of it is shown."라고 표시됩니다.
- **폴더**는 파일 20,000개까지 열 수 있습니다. 각 모델 카드에 필요한 몇 킬로바이트만 읽습니다.

자세한 내용은 [브라우저, 기기 및 메모리](topic:platforms) 항목을 참고하십시오.

## 온라인 및 오프라인

파일을 여는 데 인터넷이 필요한 적은 없습니다. 읽기 도구 하나는 처음 필요할 때 사이트에서 불러옵니다. 바로 IFC 엔진이며, 처음 IFC 모델을 열 때 불러옵니다("Starting the IFC engine…"). DWG와 DXF 읽기 도구는 앱에 포함되어 있습니다.

:::offline
오프라인 상태입니다. 앱 막대의 버튼에 {{ui:오프라인 사용 준비됨}}이라고 표시되면 모든 형식이 평소처럼 열립니다. 그렇지 않으면 이 탭에서 이미 열었던 모델이 아닌 IFC 모델은 열 수 없습니다. 먼저 다시 연결하십시오. 자세한 내용은 [온라인 및 오프라인](topic:online-offline) 항목을 참고하십시오.
:::

연결 없이 BimCraft를 사용하려면 온라인 상태에서 앱 막대의 {{ui:오프라인용 저장}}을 누르고 {{ui:오프라인 사용 준비됨}}이 표시될 때까지 기다리십시오. 저장된 사본은 약 33 MB이며 IFC 엔진을 포함하므로 IFC 모델도 오프라인에서 열 수 있습니다. 저장된 사본에 대한 일반적인 설명은 [오프라인으로 작업하기](common:offline)에 있습니다.

## 클라우드 저장

클라우드 저장은 아직 사용할 수 없습니다. 편집한 사본은 다른 파일과 마찬가지로 본인의 컴퓨터나 사무실 파일 서버에 저장하십시오. 자세한 내용은 [내 파일](common:your-files) 항목을 참고하십시오.
