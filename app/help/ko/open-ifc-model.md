## 할 일

IFC 모델을 열고, 3D에서 이동하며, 표준 뷰로 바로 가 봅니다. 약 5분이 걸립니다.

`.ifc` 파일이 필요합니다. 대부분의 BIM 프로그램이 이 파일을 내보낼 수 있습니다. Revit에서는 **File > Export > IFC**입니다. 참조: [IFC로 프로젝트 파일을 3D로 가져오기](topic:rvt-to-ifc).

## 단계

1. {{ui:Choose a file}} 버튼(또는 왼쪽 위의 끌어 놓기 영역)을 클릭합니다.
2. `.ifc` 파일을 고르고 확인합니다.
3. 상태 표시줄이 끝날 때까지 기다립니다. 처음에는 "IFC 엔진 시작 중…"을, 그다음 "모델 읽는 중…"과 "지오메트리 생성 중: … / … 요소"를 표시합니다.
4. 모델을 봅니다: 3/4 뷰로 열리며 화면에 맞춰집니다.
5. 모델 위 도구 모음에서 {{ui:Top}} 버튼을 클릭해 아래를 똑바로 내려다봅니다.
6. {{ui:Front}} 버튼을 클릭해 앞을 보고, 그다음 {{ui:Side}} 버튼으로 옆에서 봅니다.
7. {{ui:Fit}} 버튼을 클릭하거나 {{key:F}} 키를 눌러 모델 전체의 3/4 뷰로 돌아갑니다.

## 보이는 것

- 가운데의 모델과, 도면 같은 느낌을 위한 얇은 어두운 모서리.
- 왼쪽의 {{ui:File}} 패널: 파일 이름, 크기, IFC 스키마(예: IFC2X3 또는 IFC4), 프로젝트 이름, 단계, 내보낸 프로그램, 작성자, 내보낸 날짜, 요소 수와 삼각형 수.
- 그 아래의 {{ui:Storeys}} 및 {{ui:Elements}} 목록.
- 상태 표시줄: "열림 *파일 이름*: 요소 *n*개, *s* 초".

## 이동

:::mouse
| 목적 | 방법 |
|---|---|
| 궤도 회전 | 왼쪽 버튼으로 드래그 |
| 초점 이동 | 오른쪽 버튼으로 드래그하거나, {{key:Shift}}(또는 {{key:Mod}})를 누른 채 왼쪽 버튼으로 드래그 |
| 확대/축소 | 휠을 굴리거나, 가운데 버튼으로 드래그 |
| 전체 보기 | {{key:F}}를 누르거나 {{ui:Fit}} 클릭 |
:::

:::mac mouse
트랙패드에서: 한 손가락을 누른 채 드래그하면 궤도 회전합니다. {{key:Shift}} 또는 {{key:Mod}}를 누른 채 드래그하면 초점 이동합니다. 두 손가락으로 스크롤하거나 꼬집으면 확대/축소합니다. 두 손가락 클릭은 오른쪽 클릭이며, 그것으로 드래그해 초점 이동할 수도 있지만, {{key:Shift}}를 누른 채 드래그하는 편이 더 쉽습니다.
:::

:::touch
| 목적 | 방법 |
|---|---|
| 궤도 회전 | 한 손가락으로 드래그 |
| 확대/축소 | 두 손가락으로 꼬집기 |
| 초점 이동 | 두 손가락을 함께 움직이기 |
| 전체 보기 | {{ui:Fit}} 탭 |
:::

궤도 회전은 항상 모델 가운데의 한 점을 중심으로 합니다. 초점 이동은 그 점을 옮기므로, 긴 초점 이동 후에는 궤도 회전이 중심에서 벗어난 것처럼 느껴질 수 있습니다. 그럴 때는 {{ui:Fit}} 버튼을 클릭해 재설정하십시오.

## 음영, 모서리, 와이어프레임

뷰큐브 바로 위의 세 작은 버튼이 모델을 그리는 방식을 고릅니다: {{ui:Shaded}}, {{ui:Shaded with edges}}(기본값), {{ui:Wireframe}}. 이들은 명령이기도 합니다(메뉴의 {{ui:View}} 및 사용자 지정 목록). 그래서 자체 키를 가질 수 있습니다. {{ui:Plan}}, {{ui:Split}}, {{ui:3D}}는 도구 모음의 {{ui:View}} 행에 있습니다.

## 흔한 실수

- **이름 있는 뷰를 기대하는 경우.** BimCraft에는 고정된 뷰 네 개({{ui:Fit}}, {{ui:Top}}, {{ui:Front}}, {{ui:Side}}), 오른쪽 아래 모서리의 뷰큐브, 자유 궤도 회전이 있습니다. 뷰는 저장하지 않습니다.
- **평면과 단면을 찾는 경우.** 이 빌드에는 2D 평면이나 단면 상자가 없습니다. 단면 평면 하나로 모델을 자르거나([IFC 모델을 단면 평면으로 자르기](topic:section-plane) 참조), 층을 끄십시오([층, 공간, 모서리 표시 및 숨기기](topic:storeys-and-spaces) 참조).
- **프로젝트 파일을 열고 3D를 기대하는 경우.** 프로젝트 파일은 파일 카드로 열립니다. 먼저 IFC로 내보내십시오.
- **`.ifczip`을 여는 경우.** 압축을 풀거나 일반 `.ifc`로 내보내십시오.
- **매우 큰 모델이 탭을 느리게 하거나 멈추게 하는 경우.** 참조: [브라우저, 기기 및 메모리](topic:platforms).
