## 하는 일

**프로젝트 번들**(`.ccbundle.zip`)을 열어, 프로젝트가 구성된 방식 그대로 작업합니다. 즉 모델 위에서 뷰, 배치, 속성 그룹을 함께 사용합니다.

번들에는 다음이 들어 있습니다:

- IFC 형식의 모델,
- PDF와 DWG 형식의 배치,
- IFC가 제외하는 항목의 목록: 뷰(각 뷰의 층, 도면층 조합, 축척 포함), 배치와 그 위에 놓인 도면, 그룹에 속한 속성 정의, 분류, 그리고 도면층, 펜 세트, 선 종류, 채우기, 곡면, 복합 구성 같은 표준.

번들은 Archicad 안에서 실행되는 오픈 소스 스크립트가 작성하며, 이 목록을 Archicad 자체에 요청합니다. BimCraft는 `.pln` 또는 `.tpl` 파일을 직접 읽지 않습니다. [`.pln` 및 `.pla` 프로젝트 파일 열기](topic:pln-project-files) 항목을 참고합니다.

## 번들 만들기

이 스크립트는 미리 보기 단계입니다. 아직 모든 Archicad 버전에서 시험하지 않았습니다. 스크립트는 [github.com/getcadcraft/bim-project-bundle](https://github.com/getcadcraft/bim-project-bundle)에서 받습니다. Archicad 24 이상과 Python 3.8 이상이 필요하며, 다른 설치는 필요 없습니다.

1. `archicad_bundle.py`를 폴더에 저장합니다. 예: `C:\cc-bundle`.
2. Archicad에서 프로젝트를 열고, 정확히 **CadCraft bundle**이라는 이름의 발행 세트를 만듭니다. 3D 뷰는 IFC로, 모든 배치는 PDF로, 그리고 모든 배치를 다시 DWG로 발행합니다. 모두 하위 폴더 없이 한 폴더에 있는 디스크 파일로 발행합니다.
3. 프로젝트를 연 상태에서 `python archicad_bundle.py --probe --out .`을 한 번 실행합니다. 이 명령은 읽기만 하며 `probe.json`을 씁니다.
4. `python archicad_bundle.py --out . --translator "IFC4 Reference View"`를 실행합니다(선택한 IFC 번역기를 사용합니다). Archicad가 세트를 발행하고, 스크립트가 `<project>.ccbundle.zip`을 씁니다.

스크립트로 발행하지 못하면 세트를 직접 발행한 뒤 `python archicad_bundle.py --out . --no-publish --files <folder>\*.ifc <folder>\*.pdf <folder>\*.dwg`를 실행합니다. 모든 옵션은 저장소의 README에 있습니다. 가져오지 못한 항목이 있으면 그 저장소에 이슈를 열고 `probe.json`을 첨부하십시오.

## 번들 열기

1. {{ui:파일 선택}} 버튼을 클릭하거나 `.ccbundle.zip`을 BimCraft에 끌어다 놓습니다. {{ui:폴더 열기}}로 연 폴더에서는 번들이 **프로젝트 번들** 아래에 나열되며, 이름을 클릭합니다.
2. 모델이 IFC처럼 열리며, 파일 정보 아래 왼쪽에 **프로젝트 번들** 섹션이 나타납니다.

아무것도 업로드되지 않습니다. 번들은 컴퓨터에서 파일 하나씩 읽으므로, 큰 모델이 두 번 복사되지 않습니다.

## 뷰 표시

**뷰** 아래에서 뷰는 프로젝트에서 가졌던 폴더별로 묶입니다. 뷰 이름을 클릭합니다.

- **평면도**는 해당 층만 위에서 본 모습으로 보여 줍니다.
- **도면층 조합**은 그 조합이 숨기는 도면층의 요소를 숨깁니다. 상태 표시줄에 숨겨진 요소 수가 나타납니다.
- **축척**은 이름 옆과 상태 표시줄에 표시됩니다.
- **3D 뷰**는 모든 층을 보여 줍니다.

모두 다시 표시하려면 {{ui:표시}} 아래의 {{ui:모두 표시}} 버튼을 사용하고 모든 층을 선택합니다.

:::note
BimCraft는 IFC 파일의 도면층 지정을 통해 도면층을 찾습니다. 지정 없이 IFC를 내보냈다면 도면층 조합은 아무것도 숨기지 않으며, 상태 표시줄에 숨겨진 요소 0개라고 표시됩니다.
:::

## 배치 열기

**배치** 아래에서 각 배치는 번호, 이름, 용지 크기, 그 위에 놓인 뷰를 보여 줍니다.

- **PDF**는 번들에서 배치의 PDF를 저장합니다.
- **DWG**는 배치의 도면을 2D 뷰에서 엽니다. 아무 뷰를 클릭하면 모델로 돌아갑니다.
- **…에서 열기**는 배치 파일을 편집하는 앱으로 새 탭에서 보냅니다. PDF는 MarkupCraft 앱으로, DWG는 CadCraft 앱으로 보냅니다. 해당 앱이 BimCraft 옆에 열려 있는 경우에만 표시됩니다. 탭이 열릴 때 번들에서 파일을 읽으며, 아무것도 업로드되지 않습니다.

PDF나 DWG가 모두 없는 배치에는 **번들에 파일 없음**이라고 표시됩니다.

## 프로젝트 그룹에서 속성 보기

요소를 하나 선택합니다. **속성 그룹**은 프로젝트가 정의한 그룹 아래에 요소의 속성을 보여 줍니다. 이는 정의가 IFC에 대해 지정한 속성 세트와 이름으로 맞춰지며, 그렇지 않으면 이름으로 맞춥니다. 나머지 속성은 평소처럼 {{ui:특성}}에 남습니다. **속성 정의**는 모든 정의를 그룹, 유형, IFC 이름과 함께 나열합니다.

## 표준과 참고

- **표준**은 번들의 도면층, 도면층 조합, 펜 세트, 선 종류, 채우기, 곡면, 복합 구성, 재료 수를 셉니다.
- **참고**는 해당 Archicad 버전에서 스크립트가 가져오지 못한 항목, BimCraft가 읽지 못한 필드, 번들이 이름은 대지만 담고 있지 않은 파일을 나열합니다.

## 문제 해결

- **zip이지만 프로젝트 번들이 아닙니다: "…"** zip에 `manifest.json`이 없습니다. 압축을 풀고 안의 `.ifc` 파일을 엽니다.
- **이 BimCraft가 읽을 수 있는 버전보다 최신 프로젝트 번들입니다: "…"** BimCraft를 업데이트합니다.
- **매니페스트가 지정한 모델을 담고 있지 않습니다: "…"** zip이 잘렸거나 편집되었습니다. 번들을 다시 만듭니다.
- **뷰에 모든 층이 표시됩니다.** 뷰의 층이 모델의 IFC에 없습니다(상태 표시줄에 그렇게 표시됩니다). 해당 층이 IFC 내보내기에 포함되었는지 확인합니다.
