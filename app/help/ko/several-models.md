## 할 일

여러 공종의 모델을 한곳에서 봅니다. 예를 들어 건축가의 모델에 구조 및 설비 모델을 함께 놓는 식입니다. 각 모델은 독립된 파일로 남고, BimCraft는 이들을 함께 보여 줄 뿐입니다.

## 단계

1. 첫 번째 IFC 모델을 평소처럼 엽니다.
2. 왼쪽의 {{ui:모델}} 패널에서 {{ui:모델 추가…}}를 클릭하고 IFC 파일을 하나 이상 선택합니다. 각 모델이 목록과 3D 뷰에 나타납니다.
3. 모델의 체크를 해제하면 숨겨지고, 다시 체크하면 표시됩니다.
4. 모델이 잘못된 위치에 들어왔다면(측량점이 다른 경우), 그 아래의 {{ui:이동}}을 클릭하고 X, Y, Z 방향으로 이동할 거리를 미터 단위로 입력한 뒤 {{ui:적용}}을 클릭합니다.
5. 점이 찍힌 모델이 편집 대상입니다. 다른 모델의 점을 클릭하면 그 모델을 편집합니다.
6. 모델 옆의 ×를 클릭하면 장면에서 제거됩니다.

## 팀의 모델 열기

열린 모델이 팀 프로젝트의 클라우드 파일이면 목록 아래에 {{ui:팀의 모델 열기}}가 나타납니다. 이 버튼은 프로젝트의 다른 IFC 모델을 현재 모델 옆에 열며, 각 모델은 프로젝트에서 설정한 간격 띄우기만큼 이동합니다. 나에게 숨겨진 모델은 제외되고 개수에 포함되며, 프로젝트에서 회전된 모델은 회전 없이 열리고 역시 개수에 포함됩니다. IFC가 아닌 파일(예: DWG)은 건너뛰고 상태 표시줄에 이름이 표시됩니다. 이미 열린 모델은 두 번 열리지 않습니다. 이 버튼은 팀 프로젝트에 속하지 않은 파일에서는 숨겨집니다.

## 보이는 결과

- 모든 모델은 첫 번째 모델의 좌표계에서, 각 파일이 놓은 그대로 표시됩니다. 같은 프로젝트에서 내보낸 모델은 아무것도 옮기지 않아도 정렬됩니다.
- 편집 중이 아닌 모델의 요소를 선택하면 속성이 읽기 전용으로 표시되며, 전환하려면 {{ui:해당 모델 편집}}을 사용합니다.
- {{ui:모델 트리}}, {{ui:층}}, {{ui:색상}}, {{ui:변경 사항}} 목록, 라이브러리 항목 배치, {{ui:IFC 저장}}은 모두 편집 중인 모델에 적용됩니다. 숨기기, 분리, 투시, {{ui:모두 선택}}은 모든 모델에 걸쳐 작동합니다.
- {{ui:IFC 저장}}은 편집 중인 모델을 변경 사항만 담아 다운로드합니다.

## 자주 하는 실수

- **모델이 멀리 있거나 보이지 않습니다.** 파일이 다른 좌표를 사용하고 있습니다. {{ui:맞춤}}으로 찾은 뒤 {{ui:이동}}으로 제자리에 맞추십시오.
- **선택한 요소에서 삭제나 복사가 비활성화되어 있습니다.** 그 요소는 다른 모델에 속합니다. 먼저 해당 모델로 전환하십시오.
- **'파일 선택'을 사용해 파일을 열면 모든 것이 바뀝니다.** 새 장면이 시작되기 때문입니다. 현재 모델에 파일을 추가하려면 {{ui:모델 추가…}}를 사용하십시오.
