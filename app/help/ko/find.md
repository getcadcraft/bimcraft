## 작업 내용

한 번에 같은 종류이거나 같은 값을 가진 요소를 모두 고릅니다. 예를 들어 모든 문, 2층의 모든 벽, 내화 등급이 EI60인 모든 요소, 정해진 금액보다 비싼 모든 벽을 고를 수 있습니다.

## 단계

1. IFC 모델을 엽니다.
2. 왼쪽 패널에서 {{ui:찾기}}를 엽니다.
3. 첫 번째 규칙에서 속성(먼저 요소 자체의 속성, 예: {{ui:클래스}} 및 {{ui:층}}, 그다음 모델의 속성 세트), 비교 방식, 값을 고릅니다. 값 입력란에는 모델이 가진 값이 제안됩니다.
4. 조건을 좁히려면 {{ui:규칙 추가}}를 클릭합니다. {{ui:모든 규칙}}을 선택하면 모든 규칙이 맞아야 하고, {{ui:하나 이상의 규칙}}을 선택하면 그중 하나만 맞으면 됩니다.
5. {{ui:찾기}}를 클릭하거나 값 입력란에서 {{key:Enter}}를 누릅니다. 조건에 맞는 요소가 선택됩니다.
6. 규칙을 보관하려면 {{ui:세트로 저장}}을 클릭하고 이름을 입력한 뒤 다시 클릭합니다. 나중에 세트의 이름을 클릭하면 그 세트로 찾습니다.

## 결과 확인

- 조건에 맞는 요소가 3D 뷰와 모델 트리에서 선택되고, {{ui:특성}}에 클래스별 개수가 표시됩니다. {{key:I}}를 누르면 선택된 요소만 보이고, {{key:H}}를 누르면 선택된 요소가 숨겨집니다.
- 대소문자를 구분하지 않고 단어를 비교합니다. 숫자는 숫자로 비교합니다. 예를 들어 "1000보다 큼"은 텍스트가 아니라 값을 기준으로 합니다.
- {{ui:값 있음}}과 {{ui:값 없음}}은 값을 입력할 필요가 없습니다. 값이 채워진 요소 또는 비어 있는 요소를 찾습니다.
- 저장된 세트는 여는 모든 모델에 대해 이 브라우저에 남아 있습니다.

## 자주 하는 실수

- **아무것도 찾지 못합니다.** 규칙에는 맞출 수 있는 값이 있어야 합니다. 값 입력란의 제안 목록을 확인합니다.
- **목록에 속성이 없습니다.** 이 모델에서 형상이 있는 요소 중에는 이 속성을 가진 요소가 없습니다.
