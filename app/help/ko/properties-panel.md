## IFC 요소

{{ui:Properties}} 패널의 맨 위에는 요소의 종류가 "Ifc" 접두사 없이 표시되고(예: "Door", "WallStandardCase", "FurnishingElement"), 그 다음에 이름 또는 "이름 없음"이 표시됩니다.

| 필드 | 의미 | 편집 가능 |
|---|---|---|
| 이름 | 요소의 이름. 보통 내보내기 도구의 패밀리 및 유형 이름 | 예 |
| 유형 | 요소에 유형이 있을 때 그 유형의 이름 | 아니요 |
| 객체 유형 | 일부 내보내기 도구가 채우는 자유 입력 유형 설명 | 예 |
| 태그 | 요소의 태그 또는 표시. 많은 내보내기 도구가 여기에 요소 ID를 씁니다 | 예 |
| 설명 | 자유 텍스트 | 예 |
| GlobalId | 요소의 영구 22자 IFC 식별자. 같은 요소의 모든 내보내기에서 동일합니다 | 아니요 |
| 줄 | 이 IFC 파일에서 요소의 줄 번호(`#1234`). 내보낼 때마다 바뀝니다 | 아니요 |

그 아래에는 이름순으로 정렬된 **속성 세트**가 표시됩니다:

- 각 세트는 이름을 클릭하면 열리고 닫힙니다. 처음 세 개는 열려 있습니다.
- "(type)"으로 표시된 세트는 요소의 유형에 속합니다: "유형 속성: 여기서 바꾸면 이 유형의 모든 요소에 적용됩니다."
- 수량 세트(길이, 면적, 부피, 개수, 무게)는 읽기 전용입니다.
- 목록과 열거형 값은 읽기 전용으로 표시됩니다.
- 예/아니요 값은 **예** 또는 **아니요**로 표시됩니다.
- 숫자는 표시용으로 소수점 넷째 자리까지 반올림됩니다. 길이(길이 속성 또는 수량의 길이)는 도구 모음에서 고른 {{ui:Units}}로 단위와 함께 표시되며, 그 단위 또는 다른 단위 표기(2.4 m, 8'-0")로 새 값을 입력할 수 있습니다. BimCraft는 파일 자체의 숫자로 다시 씁니다. 그 밖의 숫자는 파일에 있는 그대로 표시됩니다.
- 빈 값은 *빈 값*으로 표시됩니다. 편집된 값은 굵게 표시되고 옆에 파란 막대가 붙습니다.

## 값 복사

{{ui:Properties}}의 모든 값 옆에는 작은 복사 버튼이 있습니다. 클릭하면 그 값을 표시된 그대로 클립보드에 넣습니다. 예를 들어 GlobalId, 일련 번호 또는 속성 세트의 어떤 값이든 가능합니다. 복사는 편집을 시작하지 않습니다.

맨 위의 {{ui:Copy all}}은 요소의 모든 값을 세트별로 텍스트로 복사합니다. {{ui:Copy as CSV}}는 그룹, 속성, 값을 행으로 복사하여 스프레드시트에 붙여넣을 수 있게 합니다. 빈 값도 유지되므로 모든 필드에 행이 생깁니다. 열려 있는 다른 모델의 요소도 같은 방식으로 동작하며, 모델이 여러 개 열려 있으면 CSV는 파일 이름이 적힌 Model 열로 시작합니다.

## 파일 패널(IFC)

| 필드 | 의미 |
|---|---|
| 파일, 크기 | 연 파일 |
| 스키마 | IFC 버전(예: IFC2X3 또는 IFC4) |
| 프로젝트 | 프로젝트의 이름과 긴 이름 |
| 단계 | 내보내기 도구가 기록한 경우의 프로젝트 단계 |
| 내보낸 프로그램 | 파일 헤더에서 읽은 내보내는 프로그램 |
| 작성자 | 파일 헤더의 작성자 |
| 내보낸 날짜 | 파일 헤더의 날짜와 시간 |
| 요소 | 형상이 있어 그려진 요소의 수 |
| 삼각형 | 형상이 만드는 삼각형의 수. 모델이 얼마나 무거운지 나타내는 지표 |

## 파일 패널(프로젝트 및 패밀리 파일)

| 필드 | 의미 |
|---|---|
| 종류 | 프로젝트, 프로젝트 템플릿, 패밀리 또는 패밀리 템플릿 |
| 저장 버전 | 파일을 마지막으로 저장한 릴리스 |
| 빌드 | 그 릴리스의 정확한 빌드 |
| 읽은 양 | 파일 크기 중 BimCraft가 읽은 양 |

## 도면 패널(DWG 및 DXF)

| 필드 | 의미 |
|---|---|
| 형식 | 도면이 저장된 릴리스와 형식 코드(예: AC1032) |
| 단위 | 설정된 경우 도면의 삽입 단위 |
| 객체 | 읽은 객체의 수 |
| 도면층 | 도면층의 수 |
| 시트 | 시트(배치)의 수, 또는 없음 |
| 연결된 도면 | 찾아서 불러온 연결된 도면의 수 |
| 장비 | 시트에 있는 태그가 붙은 장비 항목의 수 |

## 폴더 패널

| 필드 | 의미 |
|---|---|
| 폴더, 파일, 크기 | 연 폴더, 그 안의 파일 수, 전체 크기 |
| 모델 | 프로젝트 및 패밀리 파일. 각 백업은 한 번만 계산합니다 |
| CAD 도면, IFC 모델 | 각각의 개수 |
| 문제 | 불완전하거나 읽을 수 없는 모델 사본의 수, 또는 없음 |
