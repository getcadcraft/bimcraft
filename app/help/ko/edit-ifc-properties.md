## 작업 내용

IFC 모델의 데이터를 바로잡습니다. 요소의 이름을 바꾸고, 태그를 고치고, 속성 값을 바꿉니다. 그다음 변경 사항을 담은 새 IFC 파일을 저장합니다. 열었던 파일은 절대 건드리지 않습니다.

## 변경할 수 있는 것

| 필드 | 편집 가능 |
|---|---|
| 이름, 객체 유형, 태그, 설명 | 예 |
| 단일 속성 값(텍스트, 숫자, 예/아니요) | 예 |
| 유형 속성("(type)"으로 표시된 세트) | 예, 변경은 그 유형의 모든 요소에 적용됩니다 |
| 유형, GlobalId, 줄 | 아니요 |
| 수량(길이, 면적, 부피, 개수) | 아니요 |
| 목록, 열거형 및 기타 다중 부분 값 | 아니요 |
| 형상, 위치, 요소 추가 또는 삭제 | 아니요 |

## 단계

1. IFC 모델을 열고 바꿀 요소를 클릭합니다.
2. {{ui:특성}} 패널에서 바꿀 값을 클릭합니다. 텍스트 상자로 바뀝니다. 빈 값은 *비어 있음*으로 표시됩니다.
3. 새 값을 입력합니다.
4. {{key:Enter}}를 누르거나 다른 곳을 클릭해 확정합니다. 취소하려면 {{key:Esc}}를 누르십시오.
5. 값을 확인합니다. 굵게 표시되고 옆에 파란 막대가 붙으며, 이것이 편집된 값을 나타냅니다.
6. 왼쪽의 {{ui:변경 사항}} 구역을 봅니다. 변경은 *요소*: *필드*, 이전 값에서 새 값으로 형식으로 나열됩니다.
7. 다른 값이나 다른 요소에 대해 반복합니다.
8. {{ui:IFC 저장}}을 클릭합니다(대기 중인 변경 개수를 표시합니다, 예: "IFC 저장 (3)"). 또는 {{key:Mod+S}}를 누릅니다.
9. 다운로드 폴더에서 "*original name* (edited).ifc"를 찾습니다.

## 보이는 것

상태 표시줄에 "*name* (edited).ifc 저장됨, 변경 *n*건(… bytes). 원본 파일은 변경되지 않았습니다."가 표시됩니다. {{ui:변경 사항}} 목록이 비워져 다음 작업을 준비합니다.

## 값의 종류

- **텍스트**: 입력한 것은 그대로 유지됩니다. 이름, 객체 유형, 태그 또는 설명을 지우면 값이 제거됩니다.
- **숫자**: 파일 고유의 단위로 `2.4` 또는 `1200`처럼 단순한 숫자를 입력합니다. 단위 기호는 쓰지 않습니다. 그 밖의 입력은 "숫자를 입력하십시오."라고 표시됩니다.
- **정수**(개수, 정수): 소수를 입력하면 "정수를 입력하십시오."가 표시됩니다.
- **예/아니요**: 값이 예와 아니요가 있는 메뉴가 됩니다.

각 값은 IFC 유형을 유지하므로, 숫자는 숫자로 남고 다른 프로그램도 올바르게 읽습니다.

## 실행 취소

1. {{ui:변경 사항}} 구역의 {{ui:실행 취소}}를 클릭하거나, 필드에 입력 중이 아닐 때 {{key:Mod+Z}}를 누릅니다.
2. 더 되돌리려면 반복합니다. 실행 취소할 때마다 가장 최근 변경이 제거됩니다.

저장 이전으로는 되돌릴 수 없습니다. 저장한 뒤에는 목록이 다시 시작됩니다. 저장된 파일에는 모든 것이 남아 있습니다.

## 왜 편집이 한 요소만 바꾸는가

내보내기 프로그램은 데이터를 공유해 공간을 절약합니다. 하나의 속성 세트를 문 스무 개가 공유할 수 있으며, 하나의 값("화재 등급: 60분")이 아흔 개의 세트에 나열될 수도 있습니다. BimCraft가 공유 값을 그냥 바꾼다면, 그것을 공유하는 모든 요소가 함께 바뀝니다.

그래서 BimCraft는 쓰기 전에 복사합니다.

- 편집하는 속성 세트를 다른 요소가 공유하면, 요소는 그 세트의 자체 복사본을 받고 복사본만 바뀝니다.
- 값이 다른 세트와 공유되면, 세트는 값의 자체 복사본을 받습니다.

이웃 요소는 이전 데이터를 유지합니다. 이것을 *copy-on-write*(쓰기 시 복사)라고 합니다. 파일에 작은 항목이 몇 개 추가되며, 모든 IFC 프로그램이 정상적으로 읽습니다.

**유형 속성은 의도적인 예외입니다.** "(type)"으로 표시된 세트는 요소의 유형에 속하며, IFC에서는 그 유형의 모든 요소가 거기서 읽습니다. 이를 바꾸면 유형이 바뀌므로, 그 유형의 모든 요소가 새 값을 보입니다. {{ui:변경 사항}} 목록은 그런 편집에 "(type)"을 표시합니다. [유형의 모든 요소에 대해 유형 속성 바꾸기](topic:type-vs-instance) 참조.

## 작업을 잃기 전 경고

- 저장하지 않은 변경이 있는 상태에서 다른 파일을 열면 "*file*에 저장되지 않은 변경 *n*건이 있습니다. 버리시겠습니까?"라고 묻습니다. 취소를 클릭해 계속 작업한 뒤 저장하십시오.
- 저장하지 않은 변경이 있는 상태에서 탭을 닫거나 새로 고치면, 브라우저가 떠날지 묻습니다.

## 자주 하는 실수

- **단위를 입력함.** `2400 mm`는 거부됩니다. `2400`을 입력하십시오.
- **한 요소를 의도했는데 유형 속성을 바꿈.** 입력하기 전에 "(type)" 표시를 확인하십시오. 한 요소만 다르게 하려면 인스턴스 속성이나 태그 또는 이름을 바꾸십시오.
- **원본 파일이 바뀌기를 기대.** 저장하면 항상 새 파일이 다운로드됩니다. 원본을 바꾸고 싶다면 직접 교체하고, 사본은 보관하십시오.
- **변경 없이 {{key:Mod+S}}를 누름.** BimCraft는 저장할 것이 있을 때만 저장합니다. 그렇지 않으면 브라우저의 "페이지 저장"이 열릴 수 있습니다. 닫으십시오.
- **두 번 저장하고 작은 파일 두 개를 기대.** 저장할 때마다 모델을 연 뒤의 모든 편집이 들어 있습니다.
- **편집이 프로젝트 파일로 돌아가기를 기대.** BimCraft는 IFC만 씁니다. 편집된 IFC는 일반 IFC를 가져오듯 저작 프로그램으로 가져오십시오.
