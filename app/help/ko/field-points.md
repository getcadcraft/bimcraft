{{ui:Points}} 탭(오른쪽)은 열린 모델에서 시공팀이 현장에서 위치를 잡을 점을 만들고, 이후 시공팀이 측정한 점을 확인합니다.

## 점 만들기

1. IFC 모델을 열고 {{ui:Points}} 탭을 엽니다.
2. 위치를 잡을 대상을 선택합니다: **기둥 중심**(각 기둥 중심선의 바닥), **벽 끝**(각 벽 축의 양 끝, 바닥 기준), **앵커 볼트**, **슬리브**(이름이나 유형에 sleeve가 포함된 요소), 그리고 **선택한 요소**(각 요소의 배치점. 보기에서 먼저 선택하십시오).
3. 첫 번호와 접두사, 좌표, 단위, 열, 파일 형식을 선택합니다.
   - **모델**: 파일 자체의 좌표. **측량 격자**: 모델 지리 참조의 지도 격자(IFC에 지도 변환이 있을 때만 표시), 미터 또는 선택한 단위.
   - 열은 **PNEZD**(점, 북, 동, 높이, 설명), **PENZD** 또는 **XYZ**. 파일은 **CSV**(쉼표) 또는 **TXT**(탭).
4. {{ui:Make points}}를 누르면 목록에 점이 표시되고, 보기에서 파란색으로 표시됩니다. {{ui:Download the points}}는 파일을 저장합니다.

점은 고정된 순서로 나옵니다. 종류별로 나열되고, 그 안에서 평면 위의 행 순서대로 정렬됩니다. 따라서 같은 모델에서 다시 만들어도 같은 번호가 나옵니다. 파일은 CivilCraft가 열고 CadCraft의 EXPORTPOINTS가 쓰는 형식입니다. 한 줄에 한 점이며, 소수점 셋째 자리까지 쓰고, 설명에 쉼표가 있으면 따옴표로 묶습니다.

## 준공 점 검사

시공팀이 측정한 결과를 보내오면, 허용 오차를 밀리미터 단위로 선택하고 점을 짝짓는 방식을 정합니다. **점 번호**(시공팀이 번호를 유지한 경우) 또는 **가장 가까운 측정점**으로 짝짓습니다. 그 다음 {{ui:Read as-built points…}}를 누릅니다. 파일은 작성할 때와 같은 단위와 좌표로 읽습니다.

각 설계 점은 허용 오차 **이내**, **이외**, **측정되지 않음** 중 하나로 표시되고, 요청하지 않은 측정값은 **추가**로 표시됩니다. 표에는 도구 모음에서 선택한 단위로 차이가 표시됩니다(피트 값은 십진 인치로 표시되며, 계산은 준공 값에서 설계 값을 뺀 값입니다: 동, 북, 높이, 평면상 거리). 보기에서는 각 점이 측정값까지 선으로 연결되어 초록색 또는 빨간색으로 표시되고, 측정되지 않은 점은 회색으로 표시됩니다. {{ui:Report (CSV)}}는 전체 비교 결과를 씁니다.

여기서 하는 작업은 모델을 변경하지 않습니다. 아직 만들지 않은 기능은 다음과 같습니다: 슬래브 가장자리, 격자 교차점, 개구부에서 자동으로 위치 잡기, 그리고 측량 장비로 점을 직접 보내기. 파일을 사용하십시오.
