## 수행할 작업

보고 있는 대상만 남기도록 화면을 정리합니다. 방해되는 요소는 숨기고, 선택한 요소만 표시하거나, 나머지는 희미한 윤곽선으로 남겨 현재 위치를 알 수 있게 합니다.

## 단계

1. IFC 모델을 엽니다. [3D에서 IFC 모델 열고 둘러보기](topic:open-ifc-model)를 참조하십시오.
2. 요소를 클릭하여 선택합니다. 더 선택하려면 {{key:Mod}} 또는 {{key:Shift}}를 누른 채 각 요소를 클릭합니다. 이미 선택된 요소를 이 방식으로 클릭하면 선택에서 빠집니다.
3. 도구 모음에서 {{ui:표시}}를 열고 작업을 선택하거나, 해당 단축키를 누릅니다.
   - {{ui:숨기기}}({{key:H}})는 선택한 요소를 숨깁니다.
   - {{ui:분리}}({{key:I}})는 선택한 요소만 표시합니다.
   - {{ui:투명 표시}}({{key:T}})는 선택한 요소를 원래대로 표시하고 나머지는 투명하게 표시합니다.
4. 같은 메뉴의 {{ui:모두 표시}}를 클릭하거나 {{key:Shift+H}}를 눌러 모든 요소를 다시 표시합니다.
5. 선택한 요소 주변의 모든 것을 대신 잘라내려면, 같은 메뉴에서 {{ui:선택 요소 둘러싼 단면 상자}}를 클릭하거나 {{key:Shift+X}}를 누릅니다. [단면 평면으로 IFC 모델 자르기](topic:section-plane)를 참조하십시오.

## 보게 되는 결과

- 여러 요소를 선택하면 {{ui:특성}}에 개수가 표시되고 클래스별로 목록이 나타납니다. 하나만 클릭하면 그 요소의 속성을 볼 수 있습니다.
- 숨겨진 요소는 선택할 수 없습니다. 클릭하면 그 뒤에 있는 요소가 선택됩니다.
- 투명 표시된 요소도 선택할 수 없으므로, 분리한 대상까지 벽을 통과하여 클릭할 수 있습니다.
- 모서리(edge)는 해당 요소와 함께 숨겨지고, 함께 희미해집니다.
- 숨기기, 분리, 투명 표시는 편집, 라이브러리 항목 배치, 단면 평면으로 모델을 자를 때에도 그대로 유지됩니다. 다른 모델을 열면 모든 요소가 다시 표시됩니다.

## 자주 하는 실수

- **메뉴 항목이 비활성화되어 있습니다.** 선택된 요소가 없습니다. 먼저 요소를 클릭하십시오. 항목 위에 포인터를 올리면 동작하지 않는 이유가 표시됩니다.
- **분리했는데 숨긴 벽이 보입니다.** 분리는 숨겨져 있든 아니든 선택한 요소만 정확히 표시합니다.
- **층 전체가 보이지 않습니다.** 원인은 {{ui:모두 표시}}가 아니라 {{ui:층}} 목록입니다. 해당 층을 다시 체크하십시오.
