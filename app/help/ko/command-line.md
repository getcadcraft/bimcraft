## 할 일

먼저 상자를 클릭하지 않고 도구 이름을 입력해 도구를 실행합니다.

## 단계

1. 명령줄이 있는 레이아웃을 선택합니다. {{ui:Settings}} 창을 열고, {{ui:Global}} 항목 아래의 {{ui:Layout}}에서 **Duncan** 또는 **Rhino** 중 하나를 고릅니다. 명령줄은 창 아래쪽 상태 표시줄에 놓입니다.
2. 포인터를 아무 곳에 두고 사용 중인 상자가 없을 때 입력합니다: `wall`. 글자가 명령줄에 나타나고, 그 위의 목록에 일치하는 명령이 표시됩니다.
3. {{key:Enter}} 키를 누릅니다. 벽 도구가 시작됩니다.
4. 명령줄을 클릭하거나(또는 키를 다시 누릅니다). 줄이 비어 있으면 목록에 이전에 입력한 명령이 표시됩니다. {{key:Up}} 키와 {{key:Down}} 키로 목록을 이동하고, {{key:Enter}} 키로 표시된 명령을 실행합니다.

## 입력할 수 있는 것

- 사용 중인 메뉴 스타일의 명령어(해당 스타일에 있는 경우, 예: 도면 스타일의 `WALL`, `WA`, `DOOR`).
- 단어 형태의 명령 단축키: `W` 입력 후 {{key:Enter}} 키 또는 {{key:Space}} 키를 누르면 벽, `D`는 문입니다.
- 띄어쓰기 유무와 관계없이 명령 이름: `split wall`, `wallrectangle`.
- 단어나 이름의 앞부분. 그렇게 시작하는 명령이 하나뿐일 때 사용합니다.
- 그 밖의 입력은 입력한 내용으로 명령 찾기를 엽니다.

## 알아두면 좋은 점

- {{key:Esc}} 키는 줄을 비우고 키 입력을 다시 도면에 돌려줍니다.
- 이 레이아웃에서는 글자 하나만으로 도구가 바로 시작되지 않습니다. 줄에서 {{key:Enter}} 키 또는 {{key:Space}} 키를 기다립니다. {{key:Ctrl}} 키 조합, 기능 키, {{key:Delete}} 키, {{key:Esc}} 키는 이전과 같이 작동합니다. 다른 레이아웃에서는 아무것도 바뀌지 않습니다.
- 그리기 도구가 실행되는 동안에는 숫자가 도구에 남습니다(입력한 길이).
- 상자, 대화상자 또는 설정에서 입력하면 그 안에 머뭅니다.
- 기록은 이 컴퓨터에 보관되며, 앱마다 명령 50개입니다.
