## 작업 내용

여러분은 Ana이며, 동료 Ben과 함께 Riverside Clinic 작업을 합니다. 프로젝트의 IFC 모델은 두 사람이 모두 접근할 수 있는 한 폴더(공유 드라이브, 동기화된 폴더 또는 클라우드 폴더)에 있습니다. 마지막에는 파일 하나가 첫 복사본에서 공개된 개정 **A**가 되고, 다시 **B.1**로 변경됩니다. 또 누가 무엇을 했는지 확인하고, 여러분이 파일을 보유할 때 Ben이 보는 화면도 확인합니다.

모든 것은 파일 옆의 숨겨진 `.ccvault` 폴더에 보관됩니다. 서버도 없고 업로드도 없습니다(클라우드 폴더는 예외이며 마지막 단계를 참조하십시오). 모든 버튼과 규칙을 한곳에서 보려면, 앱에 있는 경우 *문서: 체크아웃, 개정 및 공개* 항목을 참조하십시오.

## 1. 프로젝트 폴더 설정

1. 시작 화면에서 {{ui:폴더 열기}} 옆의 {{ui:문서}}를 선택하거나, **파일** 메뉴의 {{ui:문서…}}를 선택합니다.
2. {{ui:프로젝트 폴더 선택}} 버튼을 클릭하고, 프로젝트의 IFC 모델이 든 폴더를 고릅니다. (프로젝트 폴더는 Studio와 Chrome, Edge처럼 폴더를 열 수 있는 브라우저에서 작동합니다. 다른 브라우저에서는 패널이 이를 알려 줍니다.)
3. **사용자:** 옆의 {{ui:변경}} 버튼을 클릭하고 이름 `Ana`를 입력합니다. 요청하면 이 컴퓨터의 이름도 입력합니다. 패널에 여러분의 이름과 컴퓨터가 표시됩니다(*사용자: Ana*). 이름은 여러분이 하는 모든 작업에 붙습니다.
4. {{ui:이 폴더에서 보관함 시작}} 버튼을 클릭하고 프로젝트 이름에 `Riverside clinic`을 입력합니다. 패널에 *Riverside clinic 보관함이 시작되었습니다.*가 표시됩니다.

## 2. 파일을 관리 하에 두기

1. **보관함에 없는 파일** 영역을 열고 `models/House.ifc` 옆의 {{ui:추가}} 버튼을 클릭합니다.
2. 파일은 **보관함의 파일** 아래에 개정 **A.1**, 상태 **작업 중**으로 나타납니다. A.1은 첫 복사본입니다. 보관함은 모든 개정의 복사본을 보관합니다.

## 3. 체크아웃, 변경, 체크인

1. `models/House.ifc` 옆의 {{ui:열림}} 버튼을 클릭합니다. 모델이 BimCraft에서 열리고 패널이 닫히므로 모델을 볼 수 있습니다. {{ui:문서}}에서 패널을 다시 여십시오.
2. 패널을 다시 열고 {{ui:체크아웃}} 버튼을 클릭합니다. 행에는 **나에게 체크아웃됨**이 표시됩니다. `.ccvault/locks`에 잠금 파일이 만들어졌으며, 여러분이 체크인하기 전까지는 누구도 이 파일을 체크아웃할 수 없습니다.
3. 모델을 바꿉니다. 예: 벽을 옮기고 문을 추가합니다. 모델이 여러분에게 체크아웃되어 있지 않으면 저장이 거부되며 이유가 표시됩니다. 다른 이름으로 저장은 여러분 자신의 복사본에 대해서는 언제나 작동합니다.
4. 패널을 열고 {{ui:체크인}} 버튼을 클릭한 다음 바뀐 내용을 입력합니다(예: `문 이동`). 패널에 *A.2로 체크인됨*이 표시됩니다. 이제 프로젝트 폴더의 파일은 여러분이 열어 둔 모델이며, 잠금은 사라집니다. 변경 없이 체크인하면 개정은 그대로 유지됩니다.

마음이 바뀌면 {{ui:체크아웃 취소}} 버튼으로 새 개정 없이 파일을 돌려줄 수 있습니다.

## 4. 검토와 공개

1. {{ui:검토 요청}} 버튼을 클릭합니다. 상태는 **검토 중**이 되고 파일은 읽기 전용이 됩니다.
2. 승인하기 전에 {{ui:프로젝트 설정}} 항목에서 승인할 수 있는 사람을 한 줄에 한 명씩 적습니다(예: `Ben`, `Carla`). 작성자가 아닌 사람이 승인해야 한다는 규칙에도 체크합니다. {{ui:설정 저장}} 버튼을 클릭합니다. 이제 보관함 자체가 다른 사람의 승인을 거부합니다.
3. Ben(또는 Carla)이 {{ui:승인}} 버튼을 클릭하고 승인자의 이름을 입력합니다. 상태는 **공개됨**이 되고, 개정은 **A**가 되며, *승인자*와 이름이 기록됩니다. 공개된 파일은 읽기 전용입니다. {{ui:반려}} 기능은 이유와 함께 파일을 작업 중 상태로 되돌렸을 것입니다.

승인자의 이름은 패널에 입력한 이름이며, 누가 서명했는지에 대한 기록이지 신원 증명이 아닙니다.

## 5. 새 개정

1. 공개된 파일에서 {{ui:새 개정}} 버튼을 클릭합니다. 다음 글자 개정을 보유하게 됩니다.
2. 파일을 바꾼 다음 {{ui:체크인}} 버튼을 클릭합니다. 개정은 **B.1**이며 작업 중입니다. 같은 방식으로 공개하면 **B**가 됩니다. 첫 체크인 전에 {{ui:체크아웃 취소}} 버튼을 누르면 **A**에 그대로 남습니다.

개정 글자는 A, B … Z, AA, AB 순서입니다. 표준에 따라 일부 글자를 건너뛰어야 한다면, 프로젝트 설정 *ASME Y14.35 순서 사용*은 다음 개정에서 I, O, Q, S, X, Z를 건너뜁니다.

## 6. 무슨 일이 있었는지 보기

파일 이름을 선택하면 세부 정보가 열립니다:

- **{{ui:이력}}**: 모든 이벤트를 최신순으로 보여 주며, 누가, 어느 컴퓨터에서, 언제 했는지 표시합니다. 예: Ana의 *A.2 체크인*, Ben의 *공개*.
- **{{ui:개정}}**: 개정 표. 보관된 모든 개정과 날짜, 체크인한 사람, 메모, 승인자를 보여 줍니다. 보관함은 각 개정의 복사본을 `.ccvault/revs`에 보관합니다.
- **{{ui:사용하는 파일}}**: IFC 모델이 가리키는 문서.
- **{{ui:사용처}}**: 이 파일을 가리키는 보관함 안의 모든 모델을 나열합니다.

## 다른 문서를 가리키는 모델

프로젝트 폴더의 다른 문서(도면, 일람표)를 가리키는 IFC 모델은 **사용하는 파일**에 그 문서들을 표시하며, 각 문서는 **사용처**에 모델을 표시합니다. 문서를 체크인하면 어떤 모델이 그것을 참조하는지 볼 수 있습니다.

## 7. 여러분이 파일을 보유하는 동안 Ben이 보는 것

이제 파일을 다시 체크아웃하고, Ben에게 자신의 컴퓨터에서 같은 프로젝트 폴더를 열고 패널을 열어 보라고 하십시오. 파일의 행에는 **Ana가 체크아웃함**과 여러분의 컴퓨터 이름, 시작 시각이 표시되며, {{ui:체크아웃}} 버튼은 없습니다. 그래도 시도하면 보관함이 거부합니다. 잠금은 시스템이 두 번 만들 수 없는 파일이므로, Studio에서 폴더가 디스크에 있으면 같은 순간이라도 두 사람이 동시에 파일을 보유할 수 없습니다. (브라우저에서는 폴더가 최선의 노력만 허용하며, 패널의 **폴더** 항목에 이를 밝힙니다.)

Ana가 자리를 비우고 Ben에게 파일이 필요하면 {{ui:체크아웃 해제}} 버튼이 파일을 풀어 줍니다. Ben은 이유를 입력해야 하며, 이유는 누구의 체크아웃이었는지와 함께 기록에 남습니다. 프로젝트에 관리자가 나열되어 있으면 관리자만 할 수 있습니다. 오래됨 기준(기본 14일)을 넘긴 체크아웃에는 *오래 전*이 표시됩니다. 해제한 뒤 Ana가 늦게 체크인하면 거부되므로, 두 사람이 서로의 내용을 덮어쓸 수 없습니다.

## 8. 클라우드 폴더

클라우드 폴더는 팀의 클라우드 저장소에 보관되는 프로젝트 폴더이므로, 팀에 공유 드라이브가 필요하지 않습니다. CadCraft 계정에 로그인한 Studio에서 패널은 {{ui:프로젝트 폴더 선택}} 옆에 {{ui:클라우드 폴더 열기}}를 표시합니다. 이를 선택하고 폴더를 고릅니다. 목록에는 *워크스페이스 / 폴더* 형식으로 표시됩니다. 워크스페이스 소유자가 폴더를 먼저 만들어야 하며, 팀의 클라우드 저장소가 활성화되어 있어야 합니다. 위의 모든 것은 같은 방식으로 작동합니다. 서버가 잠금을 만들며, 사람 사이에서 엄격하게 적용됩니다. 로그인하지 않았다면 패널이 로그인하라고 알려 줍니다. 일반 브라우저 탭에서는 클라우드 버튼이 제공되지 않으므로 Studio를 사용하십시오.

## 직접 해 보기

위의 여덟 단계를 실제 파일의 복사본으로 해 보십시오. 두 사람이 필요한 단계에는 다른 사람이나 이름이 다른 창 두 개가 필요합니다. 실제 공유 폴더로 해 본다면, 커뮤니티 테스트 페이지에 바로 이것을 묻는 점검 항목이 있으며, 결과를 받습니다.
