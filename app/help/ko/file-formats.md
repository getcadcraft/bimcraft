## IFC

| 읽는 내용 | 세부 사항 |
|---|---|
| 형상 | 형상이 있는 모든 요소. 파일에 지정된 색으로 표시됩니다. 실과 공간은 투명하게 그려지며 처음에는 숨겨집니다 |
| 층 | 고도 순서의 건물 층과, 각 층에 있는 요소. 어떤 층에도 속하지 않는 요소는 "층 없음"으로 묶입니다 |
| 요소 수 | 종류별 요소 수(벽, 문, 슬래브 등), {{ui:Elements}}에 표시됩니다 |
| 프로젝트 정보 | 프로젝트 이름, 긴 이름, 단계. 스키마. 파일 헤더의 내보내기 프로그램, 작성자, 내보내기 날짜 |
| 요소 데이터 | 이름, 유형, 객체 유형, 태그, 설명, GlobalId. 요소와 그 유형의 모든 속성 세트와 수량 세트 |

편집 가능: 이름, 객체 유형, 태그, 설명, 단일 속성 값. 새 IFC 파일로 저장됩니다. IFC2X3, IFC4, IFC4X3 스키마를 열 수 있으며, BimCraft의 자체 IFC 엔진이 읽습니다. 아직 그릴 수 없는 항목은 {{ui:File}} 패널의 **아직 그리지 않음**에 나열됩니다. 모델은 열릴 때 원점으로 이동하므로, 원점에서 멀리 놓인 모델도 화면 가운데에 표시됩니다. `.ifczip`과 `.ifcxml`은 열리지 않습니다.

## 프로젝트 및 패밀리 파일

`.rvt` 프로젝트, `.rte` 프로젝트 템플릿, `.rfa` 패밀리, `.rft` 패밀리 템플릿.

| 읽는 내용 | 세부 사항 |
|---|---|
| 파일 정보 | 릴리스 및 빌드, 작업 공유, 중앙 모델 경로, 마지막 저장 경로, 사용자 이름, 로캘, 문서 GUID |
| 프로젝트 정보 | 프로젝트 고유 필드(이름, 번호, 발주처, 주소, 상태 등). 새 프로젝트의 기본값은 제외 |
| 패밀리 정보 | 패밀리 이름, 분류, 릴리스, 마지막 업데이트, 그룹별 매개변수 |
| 링크 | 파일이 가리키는 연결 모델, CAD 링크, 이미지, 키노트 표 목록 |
| 미리 보기 그림 | 파일에 저장된 썸네일 |

읽지 않는 항목: 3D 모델, 요소, 뷰, 시트, 일람표. 이들은 문서화되지 않은 형식으로 저장됩니다. BimCraft는 각 파일에서 수십 킬로바이트만 읽으므로, 파일 크기는 거의 영향을 주지 않습니다.

## .pln, .pla, .tpl 및 .bpn 프로젝트 파일

아직 읽지 않습니다. 열면 BimCraft가 이를 알려 줍니다. 모델은 IFC로, 도면은 DWG로 내보내십시오. 자세한 내용은 [.pln 및 .pla 프로젝트 파일 열기](topic:pln-project-files)를 참조하십시오.

## DWG 및 DXF

| 읽는 내용 | 세부 사항 |
|---|---|
| 공간 | 모델 공간과 모든 시트(배치), 탭 순서대로 |
| 뷰포트 | 각 시트의 뷰포트, 축척, 회전, 동결된 도면층 |
| 도면층 | 이름, 색, 켜기/끄기, 동결, 플롯 여부, 선 가중치 |
| 객체 | 선, 폴리선, 호, 원, 타원, 스플라인, 해치와 솔리드, 문자와 여러 줄 문자, 블록과 속성, 치수, 지시선과 다중 지시선, 표, 점, 이미지 |
| 연결된 도면 | 파일을 찾으면 삽입된 위치에 그려집니다 |
| 이미지 | 그림 파일을 찾으면 그려집니다(PNG, JPEG, GIF, BMP, WebP. TIFF는 제외) |
| 설비 태그 | 급식 설비 항목 태그(`KCL-ITEM` 속성), 설비 일람표용 |

그 밖의 항목은 **아직 그리지 않음**에 집계되며 추측하지 않습니다. 확인된 DWG 형식은 AutoCAD 2000에서 2018까지입니다(R13 및 R14 파일도 허용되지만 테스트 세트에는 없었습니다. 더 오래된 DWG는 열리지 않습니다). {{ui:Drawing}} 패널에는 AC1032 같은 형식 코드가 표시됩니다. 모든 버전의 DXF 파일을 열 수 있으며, R12도 포함됩니다. 둘 다 이 탭에 있는 BimCraft 자체 리더로 읽습니다. DWG나 DXF로 다시 저장되지 않습니다.

## 폴더에서

| 종류 | 확장자 | 보고서 표시 |
|---|---|---|
| 모델 | `.rvt` `.rfa` `.rte` `.rft` | 번호가 붙은 백업과 함께 묶음, 상태 검사, 요약 카드 읽기, 링크 확인 |
| IFC | `.ifc` | 목록에 표시됨. 3D로 열림 |
| CAD | `.dwg` `.dxf` `.dgn` | 이를 연결한 모델과 함께 목록에 표시됨. DWG와 DXF는 2D로 열리고, DGN은 열리지 않음 |
| 남은 파일 | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | **따로 보관**에 나열됨 |
| 정리용 폴더 | `*_backup`, `*_log`, `Revit_temp`, 숨김 폴더 | **따로 보관**에 나열됨. 읽지 않음 |
