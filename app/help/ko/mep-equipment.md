## 할 일

배관과 덕트의 끝에 설비를 놓으십시오. 각 항목은 입력한 값으로 크기가 정해지는 일반 형상이며, 연결부는 **포트**로 나타납니다. 포트는 배관이나 덕트가 연결되는 위치, 시스템, 흐름 방향, 크기를 정합니다. 포트에서 그린 배관과 덕트는 그 포트의 크기와 시스템을 따르며 그 포트에 고정됩니다. [배관과 덕트를 설비에 연결](topic:mep-connections)을 참조하십시오.

:::note
이것은 도면 작성과 조정을 돕는 도구이며, 크기는 엔지니어가 정합니다. 설비는 특정 제조사의 제품이 아닙니다. 용량, 중량, 제조사의 연결 크기는 포함하지 않습니다. 제조사 모델이 필요하면 MEP 프로그램에서 IFC로 가져오십시오.
:::

## 설비 배치

1. {{ui:Draw}}를 켜고 {{ui:Build}}를 연 뒤 {{ui:Equipment}}를 고르십시오.
2. 표시줄에서 종류를 고르고 크기를 입력하십시오. 종류마다 입력할 항목이 다릅니다.

| 종류 | 입력 항목 | 포트 |
|---|---|---|
| 공조기 | 길이, 너비, 높이; 급기 및 환기 개구부; 코일 배관 크기와 시스템; 응축수 배관 크기 | 급기 덕트 출구, 환기 덕트 입구, 코일 입구와 출구, 응축수 배수 |
| 인라인 팬 | 지름, 길이, 시스템 | 덕트 입구와 출구 |
| 펌프 | 배관 크기, 시스템 | 입구와 출구 |
| 보일러 | 길이, 너비, 높이, 배관 크기, 가스 배관 크기, 연도 지름 | 난방 공급 출구와 환수 입구, 가스 입구, 연도 출구 |
| 온수기 | 지름, 높이, 배관 크기, 가스 또는 전기 | 냉수 입구, 온수 출구(가스로 가열할 때는 가스 입구와 연도 포함) |
| 터미널 유닛 | 길이, 너비, 높이, 원형 입구, 출구의 너비와 높이 | 급기 입구와 출구 |
| 디퓨저 | 면, 목, 시스템 | 목(공기 입구) |
| 그릴 | 면의 너비와 높이, 목의 너비와 높이, 시스템 | 목(환기 또는 배기 덕트로 공기 출구) |
| 탱크 | 지름, 높이, 배관 크기, 시스템 | 위쪽의 입구, 아래쪽 가까이의 출구 |
| 라디에이터 | 길이, 높이, 깊이, 배관 크기, 시스템 | 한쪽 끝 위쪽에 송수 입구, 다른 쪽 끝 아래쪽에 환수 출구 |
| 대류 / 패널 히터 | 길이, 높이, 깊이, 배관 크기, 시스템 | 한쪽 끝에 송수 입구, 다른 쪽 끝에 환수 출구 |
| 제조사 패밀리 | 패밀리([배관 사양, 밸브, 댐퍼와 제조사 패밀리](topic:pipe-specs) 참조) | 그 패밀리에 지정된 포트 |

3. **위치**를 설정하십시오. 층에서 설비 밑면까지의 높이입니다. 디퓨저와 그릴의 높이는 면 기준이므로 천장 높이를 입력하십시오.
4. 원하면 **태그**를 입력하십시오(`AHU-1`). 같은 종류의 다음 설비는 다음 번호를 받습니다.
5. 평면 위로 포인터를 옮기면 바닥 면적과 포트가 따라옵니다. {{key:R}}을 누르면 90도 회전합니다. 놓을 위치를 클릭하십시오.

배관 크기는 강관 크기(ASME B36.10M)입니다. 펌프에서 다른 재질로 그린 배관은 같은 호칭 크기를 자체 재질로 따릅니다.

## 변경 및 삭제

평면이나 3D 보기에서 설비를 고르십시오. 속성에 입력한 모든 크기, 태그, X, Y, 높이, 회전, 그리고 각 포트의 크기, 시스템, 흐름 방향, 연결 여부가 나타납니다. 각 변경은 {{ui:Undo}} 한 단계이며, 포트에 고정된 구간은 함께 움직입니다. {{key:Delete}}로 삭제합니다. 그 설비에 고정되어 있던 구간은 남으며, 연결 검사에 목록으로 나타납니다.

## IFC 파일에서

각 종류는 해당 IFC 클래스로 저장됩니다. IfcUnitaryEquipment(공조기), IfcFan, IfcPump, IfcBoiler(보일러; 온수기는 유형이 water이고 객체 유형이 "Water heater"인 IfcBoiler), IfcAirTerminalBox(터미널 유닛), IfcAirTerminal(디퓨저, 그릴), IfcTank입니다. 같은 종류이며 크기가 같은 설비는 하나의 유형을 공유합니다. IFC2X3 파일에는 해당 유형과 함께 IfcEnergyConversionDevice, IfcFlowMovingDevice, IfcFlowController, IfcFlowTerminal, IfcFlowStorageDevice가 저장됩니다. 각 포트는 연결 위치에 놓인 IfcDistributionPort이며, 바깥쪽을 향하고 흐름 방향과 시스템을 가집니다. 다른 프로그램은 어느 구간이 어느 포트에 연결되는지 읽을 수 있습니다. 설비는 각 포트의 시스템에 속하며, 배치된 모든 라이브러리 항목의 라이브러리 항목 집합을 포함합니다.
