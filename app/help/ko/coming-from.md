Revit을 알고 계시다면 BimCraft의 대부분은 용어 면에서는 익숙하게, 범위 면에서는 낯설게 느껴질 것입니다. 가장 중요한 차이점은 다음과 같습니다: **이 빌드는 모델을 읽고 검사하며 IFC 데이터를 편집합니다. 아직 Revit처럼 작성하지는 않습니다.** 벽을 그리거나, 패밀리를 배치하거나, 뷰나 시트를 만들거나, 프로젝트 파일을 저장할 수 없습니다. 대신 브라우저가 있는 어느 컴퓨터에서든 거의 모든 건물 파일을 열고, 무엇이 들어 있는지 확인하고, 프로젝트 폴더 전체를 검사하며, IFC 모델의 데이터를 수정할 수 있습니다.

## 습관 대응표

| 익숙한 방식 | BimCraft에서 |
|---|---|
| 모델을 보려고 Revit에서 `.rvt`를 여는 것 | BimCraft는 `.rvt`를 파일 카드로 엽니다: 릴리스, 프로젝트 정보, 링크, 미리 보기. 3D 모델이 필요하면 IFC로 내보낸 뒤 그 파일을 엽니다. [프로젝트 또는 패밀리 파일 읽기](topic:read-rvt-file) |
| 열기 전에 파일이 어느 릴리스에서 저장되었는지 확인하는 것 | 카드 상단에 "Revit에서 저장됨 …"이 표시되며, 파일을 업그레이드하거나 건드리지 않습니다 |
| 프로젝트 브라우저 | 뷰와 시트를 나열하는 브라우저는 없습니다. IFC 모델에는 {{ui:Storeys}} 및 {{ui:Elements}} 목록이 있으며, 도면에는 시트 탭이 있습니다 |
| 속성 팔레트 | 오른쪽의 {{ui:Properties}} 패널에 클릭한 요소의 정보가 표시됩니다. 매개변수 그룹 대신 IFC 속성 세트를 사용합니다 |
| 인스턴스 및 유형 매개변수 | 인스턴스 속성 세트와 "(type)"으로 표시된 세트. 유형 변경은 Revit에서와 마찬가지로 그 유형의 모든 요소에 적용됩니다. [유형 속성을 같은 유형의 모든 요소에 대해 변경](topic:type-vs-instance) |
| 유형 편집 | 대화상자가 없습니다. "(type)" 세트의 값을 클릭하고 입력합니다 |
| 여러 요소 선택, 필터, Select All Instances | 한 번에 요소 하나씩 선택합니다. 아직 만들지 않았습니다 |
| 뷰큐브와 탐색 휠 | 오른쪽 아래 모서리의 뷰큐브, 네 개의 버튼({{ui:Fit}}, {{ui:Top}}, {{ui:Front}}, {{ui:Side}}), 자유 궤도 회전. 탐색 휠은 없습니다 |
| Shift 키와 가운데 버튼 드래그로 궤도 회전, 가운데 버튼 드래그로 초점 이동 | 왼쪽 드래그는 궤도 회전, 오른쪽 드래그({{key:Shift}} 키와 드래그)는 초점 이동, 휠은 줌입니다. {{ui:BIM ribbon}} 메뉴 스타일은 가운데 버튼 드래그로 초점 이동하고, 가운데 버튼과 {{key:Shift}} 키 조합으로 궤도 회전하도록 바뀝니다. [메뉴, 키, 마우스](topic:menus-keys-and-mouse) |
| 평면도, 단면, 단면 상자 | 한 번에 하나의 {{ui:Section}} 평면({{key:X}})만 사용할 수 있으며, 단면 상자나 2D 평면은 없습니다. [단면 평면으로 IFC 모델 자르기](topic:section-plane) |
| 뷰에서 숨기기, 분리, 가시성/그래픽 | {{ui:Storeys}}의 켜기 및 끄기, {{ui:Spaces}} 및 {{ui:Edges}}. 요소별 숨기기는 아직 없습니다 |
| 실 | IFC 공간이며 처음에는 숨겨져 있습니다. {{ui:Spaces}} 항목을 클릭합니다 |
| 저장, 다른 이름으로 저장, 중앙 파일과 동기화 | {{ui:Save as IFC}} 명령은 새 IFC 파일을 다운로드합니다. 원본은 변경되지 않습니다. 중앙 파일과 작업 공유는 없습니다 |
| {{key:Mod+Z}} 키로 실행 취소 | 저장할 때까지 IFC 편집에 대해 작동합니다. [IFC 속성 변경 및 편집된 복사본 저장](topic:edit-ifc-properties) |
| 링크 관리 | 프로젝트 폴더를 엽니다. 모든 링크를 검사하고 **이 폴더에 있음**, **같은 이름 찾음**, **라이브러리 파일** 또는 **이 폴더에 없음**으로 표시합니다. [프로젝트 폴더 전체 열기](topic:open-project-folder) |
| 감사, 또는 파일이 손상되었는지 보려고 파일 열기 | 폴더 보고서가 모든 복사본과 백업이 잘렸는지 몇 초 안에 검사합니다. [폴더에서 손상된 복사본 검사](topic:check-folder-health) |
| 어수선한 폴더에서 맞는 파일 고르기 | {{ui:Start here}} 상자가 이유와 함께 하나를 추천합니다 |

모델을 주로 검사하거나, 모델 검사 또는 IFC 뷰어 프로그램처럼 열어 보는 용도라면 {{ui:Viewer}} 메뉴 스타일을 선택합니다. 보기 및 검사 도구가 먼저 오고, 건물 도구는 하나의 메뉴에 모여 있습니다. [메뉴, 키, 마우스](topic:menus-keys-and-mouse)를 참고합니다.

## DWG 파일 보기에서 옮겨 올 때

AutoCAD나 DWG 뷰어에서 DWG를 연다면:

| 익숙한 방식 | BimCraft에서 |
|---|---|
| 아래쪽의 모델 및 배치 탭 | 도면 위의 탭: {{ui:Model}} 탭 하나와 시트마다 탭 하나 |
| ZOOM Extents, 휠 더블클릭 | 더블클릭, {{key:F}} 키 또는 {{ui:Fit}} |
| 가운데 버튼으로 초점 이동 | 아무 버튼으로 드래그합니다 |
| 도면층 관리자 | {{ui:Layers}} 목록: 체크하면 표시, 체크를 해제하면 숨김, {{ui:All on}} 및 {{ui:All off}} |
| xref 관리자 | 오른쪽의 **연결된 도면**에는 **표시됨** 또는 **찾을 수 없음** 상태가 나타나며, {{ui:Add linked drawings…}} 명령도 있습니다 |
| 플롯 미리 보기 | {{ui:Print view}} 또는 {{key:P}} 키: 흰 바탕에 선가중치를 적용한 검은색으로 표시됩니다. 인쇄되지는 않습니다 |
| 블록 속성 데이터 추출 | 태그가 붙은 주방 설비 도면용 {{ui:Equipment}} 탭과 {{ui:Download CSV}} 명령 |
| 측정, 그리기, 편집, 다른 이름으로 저장 | BimCraft에는 없습니다. CadCraft 도면 앱이 그리고 편집합니다 |

## 혼동하기 쉬운 차이점

- **브라우저에서 실행되며, 브라우저는 파일을 신중하게 다룹니다.** BimCraft는 직접 선택하거나 끌어다 놓은 파일과 폴더만 읽을 수 있습니다. 스스로 파일을 열 수 없으며, 기존 파일을 덮어쓸 수도 없습니다. 모든 저장은 다운로드입니다.
- **아무것도 업로드되지 않습니다.** 일부 브라우저의 폴더 대화상자에 있는 "업로드"라는 말은 브라우저 자체의 용어입니다. 파일은 컴퓨터에 그대로 남습니다.
- **IFC가 모델 형식입니다.** 프로젝트 파일은 3D 내용이 문서화되어 있지 않으므로 카드로 열립니다. IFC를 모델을 BimCraft로 가져오는 통로로 봅니다.
- **편집은 쓰기 시 복사 방식입니다.** 요소 하나의 값을 바꿔도, 내보낸 프로그램이 값을 서로 공유했더라도 이웃 요소는 바뀌지 않습니다. 유형 속성은 의도적인 예외입니다.
- **프로젝트도 뷰도 없습니다.** BimCraft는 한 번에 파일 하나만 보여 주며, 탭을 닫은 뒤에는 Chrome과 Edge에서 최근 폴더 이름을 제외하고 그 파일에 대해 아무것도 기억하지 않습니다.
- **Mac 키.** Revit의 Windows 단축키에서 Ctrl 키를 쓰는 곳은 BimCraft에서 {{key:Mod}} 키를 사용하며, Mac에서는 Command 키입니다.
- **마우스 습관.** 궤도 회전은 Shift 키와 가운데 버튼이 아니라 왼쪽 버튼입니다. 다만 {{ui:BIM ribbon}} 메뉴 스타일을 선택하거나 [메뉴, 키, 마우스](topic:menus-keys-and-mouse)에서 버튼을 직접 설정한 경우에는 예외입니다.

오늘 대신 사용할 수 있는 것은 [아직 만들지 않은 기능](topic:not-built-yet)을 참고합니다.
