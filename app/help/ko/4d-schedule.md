## 할 일

건물이 올라가는 과정을 지켜봅니다. 공정표의 각 작업을 그 작업이 시공하는 요소에 연결하고, 일 단위로 표시합니다.

## 진행 순서

1. IFC 모델을 열고 왼쪽 패널에서 {{ui:4D schedule}} 항목을 엽니다.
2. {{ui:Download a template}} 버튼을 클릭하면 층마다 일주일씩 배정된 작업 목록을 받을 수 있습니다. 스프레드시트에서 바꾸거나 직접 작성하십시오.
3. {{ui:Open a task list…}} 버튼을 클릭하고 CSV 파일을 선택합니다.
4. 날짜 슬라이더를 끌거나 {{ui:Play}} 버튼을 클릭합니다.

## 작업 목록

헤더 행과 **Task**, **Start**, **Finish**, **Field**, **Value** 열이 있는 CSV입니다. 쉼표와 세미콜론 모두 사용할 수 있습니다.

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| Level 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| Roof | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| Roof | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- 날짜는 YYYY-MM-DD 형식으로 씁니다.
- 한 행은 작업을 **Field** 값이 **Value** 값과 정확히 일치하는 모든 요소에 연결합니다. Field는 Storey, Class, Name, Type, Material, Tag, GlobalId 같은 속성이거나, `Pset_WallCommon.FireRating`처럼 속성 세트와 이름을 함께 쓴 속성입니다.
- 같은 작업을 같은 날짜로 여러 행에 반복하면 더 많은 요소를 연결할 수 있습니다.

## 단계와 작업 패키지

**Stage** 열, **Package** 열, 또는 둘 다 추가하면 작업을 단계와 작업 패키지로 묶을 수 있습니다. Phase와 WBS도 열 이름으로 사용할 수 있습니다.

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| Level 1 slab | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| Level 1 walls | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| Doors | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- 작업 하나는 단계 하나와 작업 패키지 하나에 속합니다. 같은 작업의 뒤쪽 행이 다른 단계나 패키지를 지정하면, 그 행은 줄 번호와 함께 나열되고 제외됩니다.
- 두 단계에 같은 이름의 작업 패키지가 있으면 서로 다른 두 작업 패키지로 취급합니다.

목록에 그룹이 있으면 날짜 위에 {{ui:Show}} 목록이 나타납니다. 단계나 작업 패키지를 고르면 하나의 단위로 재생됩니다.

- 슬라이더와 {{ui:Play}} 버튼은 그룹의 첫 시작일부터 마지막 완료일까지 실행됩니다.
- 그룹의 작업만 목록에 표시되고 칠해지며, 그룹 밖의 요소는 투명하게 보입니다.
- 목록 아래 줄에는 그 날짜에 완성, 진행 중, 예정인 작업이 각각 몇 개인지 표시됩니다.
- {{ui:Select its elements}} 버튼은 그룹의 모든 요소를 선택하며, 이를 {{ui:Show}}, {{ui:Section}} 또는 일람표에 사용할 수 있습니다.

**Every task**를 선택하면 전체 공정표가 다시 표시됩니다.

## 보이는 결과

- **완성**: 모든 작업이 끝난 요소이며, 고유한 색으로 표시됩니다.
- **진행 중**: 그날 진행 중인 작업이 있는 요소이며, 황토색으로 표시됩니다. 작업은 시작일부터 완료일까지 진행 중입니다.
- **시작 전**: 투명하게 표시됩니다.
- 어떤 작업에도 속하지 않은 요소는 그대로 둡니다. 목록에는 각 작업이 찾은 요소 수가 표시됩니다. 읽을 수 없거나 아무것도 찾지 못한 행은 줄 번호와 함께 나열됩니다.

## 연결, 간트 차트, MS Project

- Microsoft Project XML 파일(`.xml`) 또는 `Predecessors` 열이 있는 CSV를 엽니다. 연결은 종료에서 시작, 시작에서 시작, 종료에서 종료, 시작에서 종료 유형일 수 있으며, 각각 일 단위의 선행(lead) 또는 지연(lag)을 가질 수 있습니다.
- 작업 목록 아래의 간트 차트는 각 작업을 막대로, 연결을 화살표로 그립니다. 주공정 경로의 작업은 빨간색입니다. 연결 순환이나 존재하지 않는 선행 작업은 패널에 나열됩니다.
- {{ui:Save as MS Project XML}} 및 {{ui:Save CSV with links}} 버튼은 연결 정보와 함께 공정표를 다시 저장합니다.
