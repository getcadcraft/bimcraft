## 작업 내용

분리형, 멀티 분리형 또는 VRF 시스템의 유닛과 팬코일을 모델에 배치하고, ACR 구리관으로 된 액관과 가스관을 유닛의 포트에 고정하여 연결합니다. 유닛은 [포트가 있는 MEP 장비](topic:mep-equipment)의 다른 부품과 같이 동작합니다. 즉 같은 옵션 막대, 특성, 포트, [연결](topic:mep-connections)을 사용합니다.

:::note
이 기능은 도면 작성과 조정을 돕는 도구입니다. 유닛은 일반적인 형상이며 입력한 값에 따라 크기가 정해지고, 특정 제조사의 제품이 아닙니다. 배관 규격은 R410A 및 R32 장비의 **일반적인 예시 값** 표에서 가져오며, 특정 제조사의 값이 아닙니다. 실제 규격은 유닛 제조사의 설치 설명서가 정하며, 긴 배관이나 큰 높이 차이에 따라 달라집니다. 사용하는 유닛에 맞게 표를 바꾸거나 규격을 직접 입력하십시오.
:::

## 유닛 배치

1. {{ui:Draw}}를 켜고, {{ui:Build}}를 열고, {{ui:Equipment}}를 선택합니다.
2. 종류를 고르고 값을 설정합니다.

| 종류 | 설정 항목 | 포트 |
|---|---|---|
| 분리형 실내기, 벽걸이형 | 용량, 액관과 가스관, 길이, 깊이, 높이, 응축수 규격 | 냉매 액관과 가스관, 응축수 배수구 (오른쪽 끝, 벽 쪽) |
| 분리형 실내기, 카세트형 | 용량, 액관과 가스관, 패널, 본체, 높이, 응축수 규격 | 냉매 액관과 가스관, 응축수 배수구 (한쪽 옆, 위쪽 가까이) |
| 분리형 실내기, 덕트형 | 용량, 액관과 가스관, 길이, 너비, 높이, 급기와 환기 개구부, 응축수 규격 | 급기 덕트 출구, 환기 덕트 입구, 냉매 액관과 가스관, 응축수 배수구 |
| 분리형 실외기 | 용량, 액관과 가스관, 너비, 깊이, 높이 | 냉매 액관과 가스관 (오른쪽 면) |
| VRF 실외기 | 용량, 액관과 가스관, 너비, 깊이, 높이 | 냉매 액관과 가스관 (앞면, 낮은 위치) |
| 리넷 조인트 | 액관 또는 가스관, 각 분기의 부하, 각 끝의 배관 | 입구, 분기 A, 분기 B |
| 팬코일 유닛 | 2관 또는 4관, 길이, 너비, 높이, 급기와 환기 개구부, 코일 배관과 계통, 난방 배관, 응축수 규격 | 급기 덕트 출구, 환기 덕트 입구, 코일 입구와 출구, 난방 입구와 출구 (4관), 응축수 배수구 |

3. **높이**: 층 기준에서 유닛 바닥까지의 높이입니다. 벽걸이 유닛은 바닥면 기준(보통 2100 mm), 카세트는 천장 면 기준, 리넷은 배관 중심선의 높이입니다.
4. 배치할 위치를 클릭합니다 ({{key:R}}은 90° 회전).

**용량**은 kW 단위의 정격 냉방 용량이며 옆에 Btu/h 값이 표시됩니다. **액관**과 **가스관**을 **표에서 가져오기**로 두면 유닛의 연결부가 해당 용량에 맞는 표의 규격을 사용합니다. 유닛 고유의 배관 규격을 쓰려면 관 규격을 직접 고르십시오. 리넷 조인트의 입구는 두 분기를 합친 부하로, 각 분기는 자기 부하에 맞게 규격이 정해집니다.

냉매 포트는 양방향으로 동작합니다(히트펌프는 어느 방향으로도 운전됩니다). 응축수 배수구는 다른 배수관과 같은 배관 규격입니다.

## 배관 세트 그리기

1. 두 부품을 고릅니다({{key:Shift}}를 누른 채 두 번째 부품을 클릭): 실외기와 실내기(단일 분리형), 또는 실외기와 리넷, 리넷과 실내기, 또는 두 개의 리넷(VRF).
2. {{ui:Build}}를 열고 {{ui:Line set}}을 선택합니다.

BimCraft는 두 부품의 빈 포트 사이에 액관과 가스관을 그립니다. 각 포트에서 나와 공통 높이까지 올라가며, ACR 구리관(1-5/8 in 이하는 풀림 코일, 그 이상은 인발관)으로 그리고, 한 번의 {{ui:Undo}} 단계로 기록됩니다. 리넷은 자기 배관만 받아들입니다. 입구는 실외 쪽에서, 분기는 실내기 쪽으로 연결됩니다. 각 배관은 하류 끝(실내기 또는 리넷 입구)의 규격을 따릅니다. 다른 쪽 포트의 규격이 다르면 {{ui:Check connections}}에 표시되며, 이곳에 리듀서를 넣어야 합니다. 실내기 두 대는 사이에 리넷이 있어야 합니다.

이후 배관은 다른 배관처럼 이동할 수 있으며, 끝부분은 포트에 붙어 있습니다. 층 사이의 배관은 {{ui:Pipe}}로 그립니다. 냉매 포트에서 시작한 배관은 해당 계통, ACR 구리관, 규격을 그대로 가져갑니다.

## 배관 세트 표 바꾸기

{{ui:Build}}를 열고 {{ui:Line set sizes}}를 선택합니다. 각 행은 이 용량(kW) 이하에 대해 이 액관 규격과 이 가스관 규격을 뜻합니다.

| 이하 | 액관 | 가스관 |
|---|---|---|
| 2.8 kW | Ø6.35 (1/4") | Ø9.52 (3/8") |
| 5.6 kW | Ø6.35 (1/4") | Ø12.7 (1/2") |
| 16 kW | Ø9.52 (3/8") | Ø15.88 (5/8") |
| 22.4 kW | Ø9.52 (3/8") | Ø19.05 (3/4") |
| 33 kW | Ø9.52 (3/8") | Ø22.22 (7/8") |
| 47 kW | Ø12.7 (1/2") | Ø28.58 (1-1/8") |
| 71 kW | Ø15.88 (5/8") | Ø28.58 (1-1/8") |
| 104 kW | Ø19.05 (3/4") | Ø34.92 (1-3/8") |
| 180 kW | Ø19.05 (3/4") | Ø41.28 (1-5/8") |

이 값들은 시작점이 되는 일반적인 값입니다. 행을 바꾸거나 추가 또는 삭제한 뒤 {{ui:Save}}를 선택하십시오. 표는 모델에 저장되므로 파일을 작업하는 모든 사람이 같은 표를 사용하며, {{ui:Undo}}로 되돌릴 수 있습니다. {{ui:Use the typical values}}를 선택하면 시작 표로 돌아갑니다. 이미 배치된 부품은 바꾸기 전까지 기존 포트를 유지합니다.

## IFC 파일에서

분리형 및 VRF 시스템의 실내기와 실외기는 IfcUnitaryEquipment이며 유형은 SPLITSYSTEM입니다. 객체 유형으로 구분하며("벽걸이형 분리형 실내기", "천장 카세트형 분리형 실내기", "덕트형 분리형 실내기", "분리형 실외기", "VRF 실외기"), 팬코일은 IfcUnitaryEquipment이며 유형은 AIRHANDLER이고 객체 유형은 "팬코일 유닛"입니다. IFC4에는 팬코일 유형이 없으며, 한 실의 팬, 코일, 필터를 함께 나타내는 것이 AIRHANDLER입니다. 리넷 조인트는 유형 JUNCTION의 IfcPipeFitting("리넷 조인트")입니다. IFC2X3 파일에는 대응하는 유형의 IfcEnergyConversionDevice 및 IfcFlowFitting이 기록됩니다.

냉매 포트와 배관은 REFRIGERATION 계통(액관용, 가스관용 각각)에, 응축수는 DRAINAGE 계통에 들어갑니다. ACR 배관은 외경으로 이름이 붙습니다. 배관 세트 표는 프로젝트의 속성 세트 CadCraft_HvacLineSets입니다.
