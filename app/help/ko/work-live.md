## 배울 내용

여러 사람이 같은 IFC 모델을 동시에 편집할 때 모델에 무슨 일이 일어나는지 설명합니다. CadCraft Studio에서 Live TeamWork 세션을 시작하고 참여합니다(Share, Join). 이 페이지는 모델 자체를 다룹니다.

## 모두 동시에 편집

호스트의 모델이 참여하는 모든 사람에게 전달됩니다. 요소의 이름을 바꾸고, 속성 값을 변경하고, 라이브러리 항목과 요소를 배치, 교체, 삭제하는 작업은 평소와 같습니다. 나의 편집은 바로 표시되고, 다른 사람의 편집은 그 사람이 편집한 직후 잠시 뒤에 나타납니다. 편집으로 보이는 내용이 바뀌면(요소가 배치되거나 삭제되면) BimCraft가 모델을 다시 그리고 나의 보기를 유지합니다.

- **두 사람이 같은 요소를 변경한 경우:** 모델의 같은 항목에 대해서는 나중의 변경이 적용됩니다. 여러 요소가 공유하는 속성 세트는 편집하는 요소에 대해 복사되므로, 다른 요소들은 값을 그대로 유지합니다.
- **다른 사람이 방금 삭제한 요소**는 더 이상 편집할 수 없습니다. 나의 편집은 되돌려지고, 상태 표시줄에 그 이유가 표시됩니다.
- 각 사람이 모델에 추가하는 새 IFC 항목은 각자의 번호를 받으므로, 두 사람이 같은 번호를 쓰는 일은 없습니다.

## 서로 보기

세션에 참여한 모든 사람은 각자의 색을 가집니다. 3D 보기에서는 각 사람의 포인터가 그 사람의 색으로 된 화살표로 보이며, 옆에 이름이 함께 표시되고, 가리키고 있는 요소 위에 놓입니다. 각 사람이 선택한 요소 둘레에는 그 사람의 색으로 된 점선 상자가 표시됩니다.

포인터, 이름, 선택 표시는 세션 동안에만 유효합니다. 파일에 저장되지 않으며 누구의 실행 취소에도 들어가지 않습니다. 각 사람의 위치로 미끄러지듯 이동하므로 느린 연결에서도 매끄럽게 보입니다.

## 나의 작업만 실행 취소

{{ui:Undo}}는 나의 마지막 편집만 되돌리고 다른 사람의 편집은 그대로 둡니다. 그 이후에 누군가 같은 대상을 변경했다면 아무것도 되돌려지지 않으며, 상태 표시줄에 그 사람이 표시됩니다.

## 브라우저에서 참여하기

Studio가 없는 팀원은 같은 네트워크의 휴대폰, 태블릿 또는 컴퓨터로 호스트 화면에 표시된 코드 그림을 스캔할 수 있습니다. 브라우저에서 BimCraft가 열리고, 호스트가 허용하면 호스트의 모델이 열립니다. 초대 링크를 쓰면 다른 네트워크에서도 참여할 수 있습니다. 호스트에게는 이 앱의 Team Cloud Plan 좌석이 필요하며, 나머지 사람은 무료로 참여합니다. 링크는 호스트의 세션이 열려 있는 동안에만 작동합니다.

## 세션이 끝날 때

모델은 호스트만 저장합니다. 나머지 사람은 저장되지 않은 사본을 유지합니다. 보관하려면 IFC 형식으로 다른 이름으로 저장합니다.

:::note
장면의 첫 번째 모델만 공유됩니다. 세션 중 다른 파일을 열면 그 창에서 세션을 떠나게 됩니다.
:::
