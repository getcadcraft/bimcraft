## 수행할 작업

Revit에서 열지 않고 프로젝트 또는 패밀리 파일에 무엇이 들어 있는지 확인합니다: 어떤 릴리스로 저장되었는지, 작업 공유가 되어 있는지, 프로젝트 정보, 그리고 무엇을 링크하는지. 다른 사람이 보낸 파일을 받아 어떤 릴리스로 열어야 하는지 알아야 할 때 유용합니다.

## 단계

1. {{ui:Choose a file}}을 클릭합니다.
2. `.rvt`, `.rfa`, `.rte` 또는 `.rft` 파일을 고릅니다.
3. 잠시 기다립니다. 상태 줄에 "파일을 읽는 중…"이 나온 다음 "열림: *파일 이름*"이 표시됩니다.
4. 카드 맨 위를 봅니다: 파일에 저장된 미리 보기 그림, 파일 종류와 저장된 릴리스, 프로젝트 이름.
5. 카드의 섹션을 아래로 스크롤하며 읽습니다.

## 보이는 결과

파일에 해당 내용이 있으면, 가운데 카드에 다음 섹션이 표시됩니다:

| 섹션 | 알려 주는 내용 |
|---|---|
| 파일 | 파일 이름, 크기, 종류(프로젝트, 프로젝트 템플릿, 패밀리 또는 패밀리 템플릿), 저장된 릴리스와 빌드, 작업 공유 여부, 중앙 모델의 경로, 마지막 저장 위치, 저장한 사람, 로케일과 문서 GUID |
| 프로젝트 정보 | 이름, 번호, 발주처, 주소, 상태 같은 프로젝트 고유 필드. 새 프로젝트의 기본값에 머무른 필드는 제외됩니다. |
| 패밀리, 패밀리: … | 패밀리인 경우: 이름, 카테고리, 릴리스, 마지막 업데이트, 그리고 그룹별 매개변수 |
| 링크 및 참조 파일 | 파일이 가리키는 모든 링크 모델, CAD 링크, 이미지, 키노트 표와 저장된 경로 |

왼쪽의 {{ui:File}} 패널은 핵심 사실을 반복하고 **읽은 양**을 추가합니다. 이는 BimCraft가 실제로 읽은 파일의 양으로, 수 메가바이트짜리 파일 중 보통 약 40 KB입니다. 오른쪽의 {{ui:Properties}} 패널은 요소 속성에는 3D 모델이 필요하다고 알려 줍니다.

## 3D가 없는 이유

프로젝트 파일 안의 3D 모델과 요소는 문서화되지 않은 형식으로 저장됩니다. BimCraft는 문서화되었거나 분명히 읽을 수 있는 부분, 즉 파일 정보, 프로젝트 정보, 패밀리 데이터, 링크 목록, 미리 보기 그림만 읽습니다. 나머지는 추측하지 않습니다. 3D 모델을 보고 요소 속성을 읽으려면, 파일을 만든 프로그램에서 IFC로 내보내십시오. [IFC로 프로젝트 파일을 3D로 가져오기](topic:rvt-to-ifc)를 참조하십시오.

## 흔한 실수

- **3D를 기대하기.** 위를 참조하십시오.
- **링크가 저장된 경로만 표시됩니다.** 파일을 단독으로 열면 링크가 있는지 확인할 수 없습니다. 대신 파일이 있는 폴더를 열면 BimCraft가 각 링크를 찾음 또는 찾지 못함으로 표시합니다: [프로젝트 폴더 전체 열기](topic:open-project-folder).
- **"이 파일이 불완전합니다…"** 파일이 복사, 업로드 또는 동기화되는 동안 잘렸습니다. 아직 "온라인 전용"인 클라우드 드라이브 파일도 이렇게 됩니다. BimCraft는 그래도 파일을 열고 복구된 부분만 보여 줍니다. 카드 맨 위에 노란색 알림이 나오고, **이 파일에서 복구됨** 섹션에 파일 안에 모든 바이트가 있는 부분이 나열되며, 나머지는 **파일에 없음**으로 표시됩니다. 빠진 부분은 아무것도 채워 넣지 않으므로, 잘린 지점 뒤에 저장되었다면 릴리스, 미리 보기 그림 또는 프로젝트 정보가 없을 수 있습니다. 파일의 내용 목록 자체가 잘렸다면 아무것도 열 수 없습니다. 원본을 다시 복사한 다음 전체 파일을 다시 여십시오.
- **"이 파일에 미리 보기 그림이 없습니다."** 일부 파일은 미리 보기 그림 없이 저장됩니다. 정상입니다.
- **백업을 실수로 열기.** `Tower.0004.rvt`처럼 이름이 붙은 파일은 번호가 매겨진 백업입니다. 폴더를 열면 백업이 모델과 함께 묶여 표시됩니다.
