BimCraft의 명령은 어떤 방법으로 실행하든 같습니다. **메뉴 스타일**은 명령이 화면의 어디에 놓이고 어떤 이름으로 표시되며 어떤 키로 실행되는지만 정하므로, 평소의 작업 습관을 그대로 유지할 수 있습니다. {{ui:Settings}} ({{key:Mod+,}}) › BimCraft › {{ui:Menus, keys and mouse}}에서 고르십시오. 변경 사항은 즉시 적용되며, 이 브라우저에 기억됩니다.

## 다섯 가지 스타일

| 스타일 | 제공되는 기능 |
|---|---|
| {{ui:CadCraft}} | BimCraft 고유의 도구 모음과 키({{key:W}} 벽, {{key:D}} 문, {{key:N}} 창, {{key:X}} 단면, {{key:F}} 맞춤). 기본 시작 상태입니다. |
| {{ui:Home design}} | 건물 도구 줄 위에 메뉴 모음(파일, 편집, 빌드, 라이브러리, 3D, CAD, 도구, 보기)이 놓입니다. 주거용 홈 디자인 프로그램의 배치 방식과 같습니다. 같은 한 글자 키에 더해 라이브러리는 {{key:Mod+L}}, 3D 보기는 {{key:F9}}, 평면은 {{key:F10}}, 둘 다는 {{key:F11}}을 사용합니다. |
| {{ui:BIM ribbon}} | 큰 버튼이 있는 탭(건축, 삽입, 주석, 수정, 보기, 출력), 파일 메뉴, 오른쪽의 빠른 버튼. 두 글자 키: {{key:W}} 다음 {{key:A}}는 벽, {{key:D}} {{key:R}}은 문, {{key:W}} {{key:N}}은 창, {{key:S}} {{key:C}}는 단면, {{key:Z}} {{key:F}}는 맞춤. 가운데 버튼은 초점 이동, {{key:Shift}}와 가운데 버튼은 궤도 회전입니다. |
| {{ui:Drafting classic}} | 명령을 입력하는 사용자를 위한 작은 리본과 명령행: WALL, DOOR, WINDOW, ROOF, U(실행 취소), ZOOM, SECTION, PLOT, INSERT, HELP. 아무 곳에서나 입력을 시작하면 글자가 명령행으로 들어갑니다. {{key:Enter}}는 실행, 입력이 없을 때 {{key:Enter}}는 마지막 명령 반복, {{key:Esc}}는 입력 지우기입니다. |
| {{ui:Viewer}} | 그리기보다 모델을 열고 확인하기 위한 스타일: {{ui:File}}, {{ui:View}}, {{ui:Show}}, {{ui:Check}}, {{ui:Edit}} 메뉴와 보기 도구 줄(맞춤, 위, 앞, 옆, 단면, 측정, 숨기기, 단독 보기, 투시, 모두 표시, 걷기). 건물 도구는 끝의 {{ui:Model}} 메뉴에 있습니다. BimCraft 고유 스타일과 같은 키를 사용합니다. |

메뉴와 리본은 모델을 열거나 새 건물을 시작한 뒤에 나타납니다. 그 전에는 왼쪽 패널에서 파일을 열고 건물을 시작하십시오.

:::tip
BimCraft 고유 배치의 키이지만 선택한 스타일에는 속하지 않는 키는 아무 작업도 하지 않으며, 상태 표시줄에 그 명령이 어디에 있는지 표시됩니다("BIM 리본에서 단면은 SC입니다"). {{key:Delete}}, {{key:Esc}}, {{key:Enter}}, {{key:Tab}}, {{key:Space}}와 화살표 키는 항상 본래 기능을 유지합니다. 실행 중인 도구는 자체 키를 유지합니다. 배치 중에는 {{key:R}}과 {{key:Tab}}, 걷기 중에는 {{key:W}} {{key:A}} {{key:S}} {{key:D}}, 문과 창 도구에서는 {{key:H}}, 길이를 입력하는 동안에는 숫자 키가 그렇습니다.
:::

## 나만의 스타일 만들기

1. 원하는 것에 가장 가까운 스타일을 고른 뒤 {{ui:Customize…}}를 누르십시오.
2. {{ui:Keys and menus}}에서 명령을 찾으십시오(검색 상자가 도움이 됩니다). {{ui:Add a key}}를 누른 뒤 키를 누르거나, 두 글자 키라면 두 키를 연달아 누르십시오. 키를 누르면 그 키가 제거됩니다.
3. 메뉴 모음이나 리본을 쓰는 경우 {{ui:Where it sits}}에서 명령을 다른 메뉴나 패널로 옮기거나 {{ui:Keys only}}로 설정하십시오.
4. {{ui:Mouse}}에서 휠, 평면 초점 이동에 쓸 버튼, 3D 보기에서 각 버튼의 동작을 설정하십시오.
5. 이름을 입력하고 {{ui:Save}}를 누르십시오.

기본 제공 스타일을 저장하면 자신만의 사본("내 홈 디자인")이 만들어지며, 기본 스타일은 바뀌지 않습니다. 키 하나를 두 명령에 지정했거나 두 글자 키를 입력하기 전에 먼저 실행되는 키는 빨간색으로 표시되며, 저장하기 전에 고쳐야 합니다.

## 마우스

- **마우스 휠**: {{ui:Scroll up zooms in}}(기본값) 또는 {{ui:Scroll up zooms out}}, 그리고 줌 속도. 트랙패드 핀치는 항상 손가락이 움직이는 방향으로 줌합니다.
- **평면과 도면 초점 이동**: 왼쪽, 가운데, 오른쪽 버튼 중 어느 것이든. {{key:Space}}를 누른 채 드래그해도 초점이 이동합니다. 왼쪽 버튼 드래그는 클릭이 선택하거나 그리지 않는 곳에서만 초점을 이동합니다.
- **3D 보기에서 드래그**: {{ui:Each view's own}}는 BimCraft 고유 버튼(왼쪽은 궤도 회전, 오른쪽은 초점 이동)을 유지합니다. 또는 각 버튼을 궤도 회전, 초점 이동, 줌 또는 없음으로 설정할 수 있습니다. {{key:Shift}}와 버튼을 함께 누르면 궤도 회전과 초점 이동이 바뀝니다. 드래그 없이 클릭하면 여전히 선택됩니다.

## 다른 곳으로 가져가기

{{ui:Export}}는 사용 중인 스타일을 작은 `.ccinput.json` 파일로 저장합니다. {{ui:Import…}}는 다른 컴퓨터나 동료에게서 받은 파일을 추가합니다. 가져온 파일은 BimCraft 고유 명령만 가리킬 수 있습니다. 그 밖의 항목(이 버전에 없는 명령, 여기서 작동하지 않는 키)은 빠지며 상태 표시줄에 개수로 표시됩니다. {{ui:Delete this style}}는 직접 만든 스타일 중 하나를 삭제합니다.

:::note
이 설정은 이 브라우저에만 남습니다. 스타일 카드 아래의 {{ui:Use this style in every app}}을 켜면 모든 앱이 대응하는 스타일로 열립니다(각 앱 고유의 도구 모음, 메뉴 모음, 리본, 제도 클래식). 각 앱에서 바꾼 내용은 그대로 유지됩니다. 대응하는 스타일이 없는 앱은 자체 설정을 유지합니다. {{ui:Viewer}}는 BimCraft 전용이며 다른 앱에는 대응하는 스타일이 없습니다. 한 앱에서 다른 스타일을 고르면 그 앱만 바뀝니다.
:::
