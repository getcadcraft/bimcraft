## 하는 일

작업을 위해 받은 프로젝트 폴더처럼 프로젝트 폴더 전체를 열어 BimCraft가 정리하게 합니다. 어떤 모델이 있는지, 어떤 사본이 백업인지, 무엇이 무엇과 연결되는지, 어떤 파일이 손상되었는지, 그리고 여러분이 열고 싶어 할 가능성이 가장 높은 파일이 무엇인지 파악합니다.

각 모델 카드에 필요한 몇 킬로바이트만 읽으므로, 네트워크 드라이브나 동기화된 클라우드 폴더도 괜찮습니다.

## 단계

:::chromium
1. 왼쪽의 {{ui:폴더 열기}} 버튼을 클릭합니다(또는 빈 화면의 가운데를 클릭합니다).
2. 열리는 창에서 프로젝트 폴더를 선택하고 **선택**(또는 시스템에 따라 **업로드** 또는 **열기**) 버튼을 클릭합니다.
3. 브라우저가 "사이트에서 파일을 보도록 허용하시겠습니까?"라고 물으면 **파일 보기**를 클릭합니다. 이는 탭이 폴더를 읽을 수 있게만 하며, 아무것도 업로드되지 않습니다.
4. 상태 표시줄에 "폴더 목록 작성: … 파일"과 "Revit 파일 확인: … / …"이 표시되는 동안 기다립니다.
:::

:::firefox
1. 왼쪽의 {{ui:폴더 열기}} 버튼을 클릭합니다(또는 빈 화면의 가운데를 클릭합니다).
2. 열리는 창에서 프로젝트 폴더를 선택하고 확인합니다. Firefox가 페이지에 폴더의 파일을 읽을 권한을 줄지 물을 수 있습니다. 파일은 여전히 컴퓨터에 남아 있습니다.
3. 상태 표시줄에 "폴더 읽는 중: … 파일", 그다음 "Revit 파일 확인: … / …"이 표시되는 동안 기다립니다.
:::

:::safari
1. 왼쪽의 {{ui:폴더 열기}} 버튼을 클릭합니다(또는 빈 화면의 가운데를 클릭합니다).
2. 열리는 창에서 프로젝트 폴더를 선택하고 **업로드**를 클릭합니다. 이름과 달리 아무것도 Mac 밖으로 나가지 않습니다. 파일은 탭에 전달될 뿐입니다.
3. 상태 표시줄에 "폴더 읽는 중: … 파일", 그다음 "Revit 파일 확인: … / …"이 표시되는 동안 기다립니다.
:::

폴더를 {{pick:mac=Finder|windows=파일 탐색기|linux=파일 관리자}}에서 페이지로 **끌어 놓을** 수도 있습니다. 끌어 놓은 폴더는 모든 브라우저에서 권한 요청 없이 열립니다.

## 결과 확인

가운데에는 폴더 보고서가 나타납니다.

- 폴더 이름, 모델, CAD 도면, IFC 모델, 파일 수, 전체 크기.
- 일부 파일이 불완전하거나 연결된 파일이 폴더에 없으면 빨간색 또는 노란색 메모.
- {{ui:여기서 시작}} 상자: BimCraft가 열기를 제안하는 파일과 그 이유.
- **모델**: 모델마다 한 행이며, 그 백업은 그 아래에 묶입니다.
- 폴더에 있을 때 **연결 및 참조 파일**, **IFC 모델**, **CAD 도면**, **따로 보관됨**.

왼쪽의 {{ui:폴더}} 패널이 이를 요약합니다. 모든 사본이 정상이면 **문제**에 "없음"이라고 표시됩니다.

## 시작 상자 사용하기

상자는 파일 하나를 이름으로 지정하고 그 이유를 말합니다. 예를 들면 다음과 같습니다.

- "이 폴더에서 가장 최근에 저장된 작업(2025년 3월 3일)."
- "*Consultant.rvt*: 다른 모델에 연결되어 있으므로 편집할 파일이 아니라 배경 파일입니다."
- "*Tower.rvt*: 가장 적합해 보이지만 손상되었습니다. 마지막 정상 사본은 …입니다."
- "이것은 중앙 모델입니다. Revit에서 "Create New Local"로 열고 로컬 사본에서 작업합니다."

1. 이유를 읽습니다.
2. 그 파일의 카드를 읽으려면 {{ui:카드 열기}} 버튼을, **모델**에서 해당 행을 찾으려면 {{ui:목록에서 보기}} 버튼을 클릭합니다.
3. 사용하기 전에 프로젝트를 마지막으로 작업한 사람에게 확인합니다. 상자도 그렇게 말합니다. 이는 이름, 날짜, 연결을 바탕으로 한 최선의 추측입니다.

## 보고서에서 파일 열기

1. 모델 이름을 클릭하면 그 카드가 열립니다. 카드는 각 연결을 폴더와 대조해 확인합니다.
2. 카드 맨 위의 {{ui:뒤로}} 링크와 폴더 이름(또는 왼쪽의 {{ui:폴더로 돌아가기}} 버튼)을 클릭해 돌아갑니다.
3. **IFC 모델** 아래의 IFC 파일을 클릭하면 3D로 엽니다.
4. **CAD 도면** 아래의 DWG나 DXF를 클릭하면 2D로 엽니다. 연결된 도면과 그림은 폴더에서 자동으로 찾습니다.

## 나중에 폴더 다시 열기

:::chromium
{{ui:폴더 열기}}를 사용해 열었거나 끌어 놓아 연 폴더는 왼쪽의 {{ui:최근 폴더}} 아래에 나열됩니다. {{ui:다시 열기}} 버튼과 폴더 이름을 클릭하면 다시 고르지 않고 엽니다. 브라우저를 다시 시작한 뒤에는 Chrome 또는 Edge가 한 번 더 묻습니다. 묻지 않게 하려면 "방문할 때마다 허용"을 선택합니다. 목록은 이 브라우저에만 저장되며 어디로도 전송되지 않습니다. 폴더를 지우려면 ×를 클릭합니다.
:::

:::firefox safari
이 브라우저는 방문 사이에 폴더를 기억하지 못합니다. {{ui:폴더 열기}} 버튼으로 폴더를 다시 선택하거나 끌어 놓으십시오.
:::

## 자주 하는 실수

- **폴더가 너무 클 때.** 파일이 20,000개를 넘으면 "이 폴더에는 파일이 20,000개보다 많습니다. 프로젝트 하나처럼 더 작은 폴더를 고르십시오."라고 표시됩니다. 전체 드라이브가 아니라 프로젝트 폴더를 고릅니다.
- **여러 프로젝트를 담은 상위 폴더를 고를 때.** 그러면 {{ui:여기서 시작}} 상자가 여러 프로젝트 사이에서 고릅니다. 한 프로젝트를 고르십시오.
- **Revit 자체 폴더가 무시된 것처럼 보일 때.** `*_backup`, `*_log`, `Revit_temp` 폴더는 정리용이며 **따로 보관됨**에 나열되고 읽히지 않습니다.
- **카드에서 모델이 3D로 열릴 것으로 기대할 때.** 프로젝트 파일은 카드로만 표시됩니다. 해당 IFC 내보내기를 여십시오.
- **휴대폰과 태블릿.** 많은 모바일 브라우저는 폴더를 아예 고를 수 없습니다. 컴퓨터를 사용하십시오.
