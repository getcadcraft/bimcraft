BimCraft는 오늘 건물을 읽고, 점검하고, IFC 데이터를 편집하는 도구이며, 벽, 문과 창, 실, 바닥, 천장, 지붕을 그리기 시작했습니다(참조: [벽 그리기](topic:draw-walls), [문과 창](topic:doors-and-windows), [실, 바닥, 천장, 지붕](topic:floors-and-roofs)). 아래는 아직 하지 않는 기능의 정직한 목록과 그 대신 할 방법입니다.

## 모델링과 저작

| 아직 아님 | 대신 오늘 할 수 있는 것 |
|---|---|
| 보 그리기; 강재 단면의 기둥 | 저작 프로그램에서 작업한 뒤 여기서 그 IFC 내보내기를 여십시오. 직사각형 및 원형 기둥은 여기서 놓을 수 있습니다([기둥과 격자](topic:grids-and-columns) 참조). 직선, L자, U자, 와인더, 나선형 계단과 난간은 여기서 그릴 수 있습니다([계단과 난간](topic:stairs-and-railings) 참조) |
| 도머 앞면의 창; 지붕면에 손으로 그린 도머; 곡면 지붕; 텍스처가 있는 렌더링 지붕 마감 | 모서리로 그린 지붕면과 벽마다의 경사: [지붕: 벽마다의 경사, 박공, 차양 및 지붕면](topic:roofs) 참조 |
| 다른 프로그램이 만든 벽, 문, 창 변경 | 저작 프로그램. 그리기 도구는 자기가 그린 것만 바꿉니다 |
| 개구부가 있는 벽 프로필, 사각형이 아닌 벽 개구부; 3D 보기에서 벽 프로필 점 추가 또는 제거 | 프로필, 연결, 경사, 개구부는 특성, 입면과 단면, 벽의 면 뷰, 3D에서 그립으로 작업할 수 있습니다. 직선과 곡선 벽 모두 해당합니다: [벽 모양 잡기: 연결, 프로필, 경사, 개구부](topic:wall-shape) 참조 |
| 곡선 벽에서 {{ui:Trim / extend}} 및 {{ui:Corner}}, 프레이밍, 자동 평면 치수, 호를 따라 스냅(끝과 호의 가운데에 스냅) | 그 기능에는 벽을 직선으로 그리거나 직선 구간을 사용하십시오. 곡선 벽은 [벽 그리기](topic:draw-walls)에 있습니다 |
| 3D 보기에서 놓은 라이브러리 항목 끌기 | 평면에서 끌거나, {{ui:Properties}}에서 X, Y, 회전을 입력하십시오: [라이브러리에서 장비와 가구 놓기](topic:place-from-library) 참조 |
| CivilCraft의 Landscape 작업 공간 식물 라이브러리에서 식물 놓기 | CivilCraft에서 식물을 심거나, 라이브러리의 주변 요소(entourage)에서 나무와 관목을 놓으십시오: [라이브러리에서 장비와 가구 놓기](topic:place-from-library) 참조 |
| Plant 애드온(켜기 전까지 꺼져 있음): 경로가 있는 배관 구간을 모델에 그리기, 등각도의 스풀 번호, 라이브러리에서 놓은 장비의 배치 검사 | {{ui:Pipe}} 명령으로 배관 구간을 그리십시오([배관과 덕트](topic:pipes-and-ducts) 참조). 배치 검사는 애드온 자체의 장비 표를 읽습니다 |
| 단일 그린 벽, 문, 창의 회전, 대칭, 배열(벽은 이동, 간격 띄우기, 상자 신축으로 옮기고 복사합니다: [벽 모양, 분할, 간격 띄우기, 신축 및 잠금](topic:wall-tools) 참조); 곡선 벽의 모서리나 세 벽 이상의 교차점에서 이음 방식(맞대기, 직각 정리)([벽 모양, 분할, 간격 띄우기, 신축 및 잠금](topic:wall-tools) 참조); 문자 도구; 커튼월 | 한 레벨의 모든 것은 {{ui:Copy this level…}} 명령으로 복사하십시오([벽 그리기](topic:draw-walls#levels) 참조). 그 밖에는 다시 그리십시오 |
| 평면에 그린 벽 마감 레이어; 단면과 입면의 치수; 문, 창, 기타 구성 요소까지의 기준 치수; 일람표와 수량의 벽 구성 및 막; 프로젝트 사이에 공유하는 재료 라이브러리; 단면, 입면, 3D의 레이어 우선순위와 세 벽 이상이 만나는 노드(평면에서 모서리, T 이음, 두 벽의 교차는 레이어 우선순위로 정리됩니다: [벽 모양, 분할, 간격 띄우기, 신축 및 잠금](topic:wall-tools) 참조); 감싸인 레이어 또는 가변 레이어; 다른 프로그램이 만든 벽의 구성 편집 | 레이어는 벽의 유형과 미리보기({{ui:Wall assemblies…}})에 있습니다. 벽은 하나의 외피로 측정됩니다: [벽 구성과 기준 치수](topic:wall-assemblies) 참조 |
| 요소의 모양이나 크기 변경(여기서 그린 벽, 문, 창과 패밀리에서 놓은 요소는 제외) | 저작 프로그램. 삭제, 복사, 잘라내기, 붙여넣기는 여기서 작동합니다: [건물 요소 삭제, 잘라내기, 복사, 붙여넣기](topic:edit-elements) 참조 |
| 층, 공간, 건물 또는 부지 삭제 | 그 안의 요소를 삭제하십시오 |
| 다른 모델에 건물 요소 붙여넣기 | 한 모델 안에서 복사하고 붙여넣으십시오. 놓은 라이브러리 항목은 어느 모델에나 붙여넣을 수 있습니다 |
| 새 속성이나 속성 세트 추가 | 기존 값은 여기서 입력하거나, 저작 프로그램에 매개변수를 추가한 뒤 다시 내보내십시오 |
| 수량, 목록, 열거형 편집 | 저작 프로그램 |
| 다른 프로그램의 프로젝트 파일 저장 | BimCraft는 IFC(및 자체 패밀리 파일: [패밀리와 크기](topic:families) 참조)를 저장합니다 |
| 패밀리: 라이브러리에서 평면에 놓고 프로젝트 사이에 공유하는 패밀리(라이브러리), 놓은 요소의 3D 보기에서 끌어 놓는 핫스팟(패밀리 편집기의 미리보기와 평면에서는 끌 수 있음), 보기마다 고르는 상세 수준(프로젝트 하나의 수준; 시트는 축척으로 고름), 다른 패밀리 안의 세워진 평면에서 4분의 1 돌려 만든 회전, 자체 문과 창 평면 기호(시작 패밀리의 기호를 그림) | 타입 매개변수, 수식, 자체 평면 기호, 핫스팟, 반복, 상세 수준, 패밀리 안의 패밀리, 표에서 얻는 크기, 요소별 매개변수가 있는 패밀리는 여기서 만듭니다: [패밀리 편집](topic:family-editor)과 [패밀리와 크기](topic:families) 참조. 시작하려면 패밀리를 복제하십시오 |
| 다른 프로그램의 타입을 패밀리로 편집; 라이브러리 항목을 패밀리로 바꾸기 | 다른 프로그램의 타입은 추정에 따라 묶여 목록에 나타나며, 그 요소를 고를 수 있습니다. 라이브러리 항목은 있는 그대로 놓습니다 |
| 제조사의 피팅, 밸브, 장비(용량, 무게, 제조사 연결 크기); 강재 스풀의 ASME B16.9 티와 리듀서 길이; 피팅을 지나는 압력 손실, 유량, 균형 조정; 스프링클러; 케이블 트레이; 기구 단위로 스택과 통기관 크기 산정; 구간 모서리 끌기; 벽과 슬래브에 개구부 뚫기; 포트에 고정된 구간 끝 놓기(장비를 지우는 경우 제외); 라이브러리 패널에서 놓은 항목의 포트; 피팅 무게; 덕트 이음, 게이지 및 커넥터 | 표준 일반 피팅, 시스템, 평면, 일람표, 물량 산출이 있는 배관 및 덕트 구간은 여기서 그릴 수 있습니다: [배관과 덕트](topic:pipes-and-ducts) 참조. 포트가 있는 일반 장비, 연결된 구간, 연결 검사: [포트가 있는 MEP 장비](topic:mep-equipment), [배관과 덕트를 장비에 연결하기](topic:mep-connections). 간섭 세트, 이격, 개구부 목록: [구조에 대해 배관과 덕트 점검하기](topic:mep-against-structure). 강재 스풀과 시트, 덕트 절단 목록: [강관 스풀과 스풀 시트](topic:pipe-spools). 제조사 항목은 MEP 프로그램에서 IFC로 가져오십시오 |
| 용접 I형, IFC 프로파일이 W, S, IPE, HEA, HEB 규격으로 명명되지 않은 I형, 튜브, 앵글, 채널의 설계 기준 검사(확인되지 않음으로 나옴); 좌굴 또는 동적 응답(고유 진동수는 Finite elements 블록에 있음)(2차 해석은 P-Delta뿐: 탄성, 굽힘, 강성 감소 없음); 해석에서 벽과 슬래브; 면적으로 만든 하중(콘크리트 슬래브 전체에 가한 압력 하나는 예외) | {{ui:Analysis}} 탭은 보, 기둥, 가새의 힘, 반력, 처짐을 1차 해석으로 보여 주고, 압연 I형을 검사합니다. 기술자가 검토할 때까지의 보조 수단입니다: [구조 골조 해석](topic:frame-analysis#design-checks) 참조 |
