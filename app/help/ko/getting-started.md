BimCraft는 CadCraft 제품군에서 건물 모델을 다루는 앱입니다. 이 빌드에서는 건물 파일을 **열고, 읽고, 검사하며**, **IFC 모델의 데이터를 편집**합니다. 새 요소를 그리거나 모델링하는 기능은 아직 없습니다. 모델 뷰어이자 검사 도구로 생각하십시오. IFC 파일의 이름, 태그, 속성 값도 고칠 수 있습니다.

여는 파일:

| 파일 | 얻는 것 |
|---|---|
| IFC (`.ifc`) | 3D 전체 모델: 궤도 회전, 층, 요소 속성, 이름과 속성 값 편집 |
| 프로젝트 및 패밀리 파일 (`.rvt`, `.rfa`, `.rte`, `.rft`) | 파일 카드: 저장된 릴리스, 프로젝트 정보, 미리 보기 그림, 연결된 파일. 3D는 없습니다. |
| DWG 및 DXF | 2D 도면: 모델 공간과 모든 시트, 도면층, 연결된 도면, 인쇄 보기, 태그가 붙은 식당 설비 도면의 설비 일람표 |
| 프로젝트 폴더 | 폴더 안 모든 모델의 보고서: 백업, 링크, 손상된 사본, 어느 파일로 시작할지에 대한 제안 |

모든 작업은 내 컴퓨터의 브라우저 안에서 이루어집니다. **아무것도 업로드되지 않습니다.** 자세한 내용은 [BimCraft가 열고 저장하는 파일](topic:files)을 참조하십시오.

## BimCraft 열기

1. 최신 브라우저에서 BimCraft를 엽니다. Chrome, Edge, Firefox, Safari 모두 작동하며, 차이점은 [브라우저, 기기, 메모리](topic:platforms)에 나와 있습니다.
2. "건물 모델을 여십시오."라고 표시된 빈 화면이 나올 때까지 기다립니다.

:::note
BimCraft는 브라우저에서 실행되며, 데스크톱에서는 다른 앱들과 함께 CadCraft Studio 안에서 실행됩니다. 클라우드 저장은 아직 사용할 수 없습니다. 파일은 내 컴퓨터에서 열고 사본도 내 컴퓨터에 저장합니다.
:::

## 첫 모델 열기

BimCraft가 하는 일을 가장 빠르게 보려면 IFC 파일을 여십시오.

1. 화면 가운데의 {{ui:파일 선택}}을 클릭합니다.
2. {{pick:mac=Finder|windows=파일 탐색기|linux=파일 관리자}}에서 `.ifc` 파일을 선택하고 확인합니다.
3. 화면 아래의 상태 표시줄에 "IFC 엔진을 시작하는 중…"이 표시되고 이어서 형상 생성이 표시되는 동안 기다립니다.

가운데에 3D 모델이 보이고, 왼쪽에 {{ui:파일}} 패널과 {{ui:층}} 목록이, 오른쪽에 비어 있는 {{ui:특성}} 패널이 보여야 합니다. 상태 표시줄은 "열림"과 요소 개수로 끝납니다.

:::tip
{{pick:mac=Finder|windows=파일 탐색기|linux=파일 관리자}}에서 파일을 페이지 위로 바로 끌어다 놓을 수도 있습니다. 끄는 동안 화면에 "놓아서 열기"가 표시됩니다.
:::

:::offline
IFC 엔진은 BimCraft를 오프라인용으로 저장하지 않았다면 IFC 모델을 처음 열 때 사이트에서 불러옵니다. DWG와 DXF 도면, 프로젝트 파일, 폴더는 추가로 필요한 것이 없습니다. 이들의 리더는 앱에 포함되어 있습니다. 앱 바의 버튼이 {{ui:오프라인 사용 준비됨}}이면 모두 오프라인에서 열립니다. 아니면 이 탭에서 이미 연 IFC 모델이 없는 한 다시 연결할 때까지 IFC 모델이 열리지 않습니다. [온라인과 오프라인](topic:online-offline)을 참조하십시오.
:::

:::online
연결이 없는 곳으로 가십니까? 앱 바에서 {{ui:오프라인용 저장}}을 클릭하고 {{ui:오프라인 사용 준비됨}}이 표시될 때까지 기다리십시오. 저장된 사본(약 11 MB)에는 IFC 엔진이 포함됩니다. [오프라인으로 작업하기](common:offline)를 참조하십시오.
:::

## 둘러보기

:::mouse
1. 마우스 왼쪽 버튼으로 끌어 모델 주위를 궤도 회전합니다.
2. 휠을 굴려 줌합니다.
3. 마우스 오른쪽 버튼으로 끌어 초점 이동합니다. Mac 트랙패드에서는 대신 {{key:Shift}}를 누른 채 끕니다.
4. {{key:F}}를 누르거나 {{ui:맞춤}}을 클릭하면 모델 전체가 다시 보입니다.
:::

:::touch
1. 손가락 하나로 끌어 궤도 회전합니다.
2. 손가락 두 개를 모아 줌하고, 두 손가락을 함께 움직여 초점 이동합니다.
3. {{ui:맞춤}}을 탭하면 모델 전체가 다시 보입니다.
:::

## 실제로 해 보기: 태그 고치기

1. 모델에서 벽, 문 또는 아무 요소나 클릭합니다. 파랗게 바뀌고 속성이 오른쪽에 나타납니다.
2. {{ui:특성}} 패널에서 **Tag** 옆의 값을 클릭합니다.
3. 새 태그를 입력하고 {{key:Enter}}를 누릅니다.
4. 왼쪽에 열린 {{ui:변경 사항}} 섹션을 보십시오. 이전 값과 새 값과 함께 변경 내용이 나열됩니다.

## 사본 저장하기

1. {{ui:변경 사항}} 섹션에서 {{ui:IFC 저장}}을 클릭하거나 {{key:Mod+S}}를 누릅니다.
2. 다운로드 폴더에서 새 파일을 찾습니다. 이름은 원래 이름에 " (edited)"가 붙은 형태이며, 예를 들어 `Clinic (edited).ifc`입니다.

원본 파일은 절대 바뀌지 않습니다. 편집에 대한 전체 설명은 [IFC 속성 변경 및 수정된 사본 저장](topic:edit-ifc-properties)에 있습니다.
