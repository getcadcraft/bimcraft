BimCraft에는 단축키가 적습니다. 대부분의 작업은 마우스와 패널로 합니다. {{key:Mod}}로 표시된 단축키는 Mac에서는 Command, 그 밖의 환경에서는 Ctrl을 씁니다. 이 도움말에서 키를 표기하는 방식은 [키, 마우스, 트랙패드](common:keys)를 참고하십시오.

## 어디서나

| 키 | 기능 |
|---|---|
| {{key:Ctrl+Shift+F}} | 화면 모드를 순환합니다: 일반, 전체 화면, 막대를 숨긴 전체 화면. 모든 플랫폼에서 Ctrl을 사용합니다(Mac 포함) |
| {{key:Esc}} | 전체 화면 해제 |
| {{key:Mod+,}} | {{ui:설정}}을 엽니다. [BimCraft 설정](topic:settings) 참고 |
| {{key:Tab}} | 버튼, 체크박스, 값 사이를 이동합니다. 모든 컨트롤을 키보드로 쓸 수 있습니다 |

## 3D 보기 (IFC 모델)

| 키 또는 동작 | 기능 |
|---|---|
| {{key:F}} | 전체 모델을 3/4 시점으로 맞춥니다({{ui:맞춤}}과 같음) |
| {{key:Esc}} | 선택을 해제하거나 배치, 붙여넣기를 중지합니다 |
| 클릭 | 포인터 아래 요소를 고릅니다. 빈 배경을 클릭하면 선택을 해제합니다 |
| {{key:Mod}}+클릭 또는 {{key:Shift}}+클릭 | 선택에 요소를 추가하거나 뺍니다 |
| {{key:H}} | 선택한 요소를 숨깁니다. [요소 숨기기, 분리, 투시](topic:hide-and-isolate) 참고 |
| {{key:I}} | 선택한 요소만 표시합니다(분리) |
| {{key:T}} | 선택한 요소를 표시하고 나머지는 투시합니다 |
| {{key:Shift+H}} | 모든 요소를 다시 표시합니다 |
| {{ui:보행}} | 그다음 {{key:W}} {{key:A}} {{key:S}} {{key:D}} 또는 화살표로 걸어갑니다. {{key:Shift}}는 달리기, 드래그는 둘러보기, {{key:Esc}}는 중지입니다. [모델 속 걷기](topic:walk) 참고 |
| {{key:M}} | 거리와 면의 면적, 위치를 측정합니다. [3D에서 거리, 면적, 위치 측정](topic:measure) 참고 |
| 왼쪽 버튼 드래그 | 궤도 회전 |
| 오른쪽 버튼 드래그 | 초점 이동 |
| {{key:Shift}} 또는 {{key:Mod}}를 누르고 왼쪽 버튼 드래그 | 초점 이동(트랙패드에서 편리) |
| 휠 스크롤 또는 가운데 버튼 드래그 | 줌 |
| 트랙패드에서 두 손가락 스크롤 또는 핀치 | 줌 |
| 한 손가락(터치) | 궤도 회전. 탭하면 고릅니다 |
| 두 손가락(터치) | 핀치로 줌, 함께 움직이면 초점 이동 |

| {{key:X}} | 단면 평면 켜기 및 끄기. [IFC 모델을 단면 평면으로 자르기](topic:section-plane) 참고 |
| {{key:Shift+X}} | 선택한 요소 주변에 단면 상자를 만듭니다. 여유 공간은 설정에서 정합니다 |

{{ui:위}}, {{ui:앞}}, {{ui:측면}}에 대한 키는 없습니다. 버튼을 사용합니다.

## 편집

같은 명령이 도구 모음에도 있습니다: {{ui:실행 취소}}, {{ui:다시 실행}}, {{ui:복사}}, {{ui:붙여넣기}}, 그리고 각 단축키를 보여 주는 {{ui:더보기}} 메뉴입니다. IFC 모델의 3D 보기에서 작동하며, 입력란에 글을 입력하는 동안에는 작동하지 않습니다. [라이브러리 항목 복사, 붙여넣기, 복제](topic:copy-paste) 참고.

| 키 | 기능 |
|---|---|
| {{key:Mod+Z}} | 마지막 변경을 실행 취소합니다 |
| {{key:Mod+Y}} 또는 {{key:Mod+Shift+Z}} | 실행 취소한 내용을 다시 실행합니다 |
| {{key:Mod+C}} | 선택한 요소를 복사합니다(이름과 특성은 텍스트로도 클립보드에 들어갑니다) |
| {{key:Mod+X}} | 선택한 요소를 잘라냅니다: 복사한 뒤 삭제합니다 |
| {{key:Mod+V}} | 복사한 내용을 붙여넣습니다: 포인터를 따라다니며, 클릭한 곳에 놓입니다 |
| {{key:Mod+Shift+V}} | 제자리에 붙여넣기: 잘라낸 위치, 또는 복사 후에는 원본 옆에 놓입니다 |
| {{key:Mod+D}} | 복제: 선택한 요소를 복사하고 바로 붙여넣기를 시작합니다 |
| {{key:Delete}} | 선택한 요소를 부품과 개구부까지 포함해 삭제합니다. [건물 요소 삭제, 잘라내기, 복사, 붙여넣기](topic:edit-elements) 참고 |
| {{key:Mod+A}} | 보이는 모든 요소를 선택합니다 |
| {{key:Esc}} | 선택을 모두 해제합니다 |

페이지에서 텍스트를 선택한 경우 {{key:Mod+C}}는 평소처럼 그 텍스트를 복사합니다.

## 평면 보기 (그리기)

이 단축키는 {{ui:그리기}}가 켜져 있고 입력란에 입력 중이 아닐 때 작동합니다. [벽 그리기](topic:draw-walls)와 [문과 창](topic:doors-and-windows)을 참고하십시오.

| 키 또는 동작 | 기능 |
|---|---|
| {{key:V}} | {{ui:선택}} |
| {{key:W}} | {{ui:벽}} |
| {{key:D}} | {{ui:문}} |
| {{key:N}} | {{ui:창}} |
| {{key:H}} | {{ui:문}} 또는 {{ui:창}}을 고른 상태: 경첩을 반대쪽 끝에 둡니다 |
| 벽을 그리는 동안 {{key:Shift}} | 벽을 0°, 90°, 180°, 270°로 유지합니다 |
| 숫자와 피트, 인치 표시(`'` 및 `"`) | {{ui:길이}} 입력란에 길이 입력을 시작합니다. {{key:Enter}}로 적용합니다 |
| {{key:Enter}}, {{key:Esc}}, 오른쪽 클릭 또는 더블클릭 | 그리는 벽을 끝냅니다. {{key:Esc}}를 한 번 더 누르면 {{ui:선택}}으로 돌아갑니다 |
| {{key:Delete}} | 고른 벽, 문, 창을 삭제합니다. 남은 벽은 다시 연결됩니다 |
| 평면 위에서 포인터를 두고 {{key:F}} | 평면을 맞춥니다 |
| 휠 스크롤 | 포인터 위치를 기준으로 줌 |
| 가운데 또는 오른쪽 버튼 드래그, 또는 {{key:Space}}를 누르고 드래그 | 초점 이동. {{ui:선택}}이 켜져 있으면 일반 드래그도 초점을 이동합니다 |
| {{ui:선택}}을 켠 상태에서 문이나 창을 드래그 | 벽을 따라 이동하거나 다른 벽으로 옮깁니다 |
| 두 손가락(터치) | 핀치로 줌, 함께 움직이면 초점 이동 |

## 라이브러리 항목 배치와 붙여넣기

| 키 | 기능 |
|---|---|
| {{key:R}} | 항목을 90° 돌립니다 |
| {{key:Tab}} | 벽 스냅을 켜거나 끕니다: 항목의 뒷면이 가장 가까운 벽에 붙습니다 |
| **X, Y (mm)**에서 {{key:Enter}} | 입력한 위치에 배치합니다 |
| {{key:Esc}} | 배치 또는 붙여넣기를 중지합니다 |

## IFC 값 편집

| 키 | 기능 |
|---|---|
| {{key:Enter}} | 입력한 값을 유지합니다 |
| {{key:Esc}} | 취소하고 이전 값으로 되돌립니다 |
| 다른 곳 클릭 | 입력한 값을 유지합니다 |
| {{key:Mod+Z}} | 마지막 변경을 실행 취소합니다. 저장되지 않은 변경이 있고 입력란에 입력 중이 아닐 때만 작동합니다 |
| {{key:Mod+Y}} | 실행 취소한 내용을 다시 실행합니다 |
| {{key:Mod+S}} | IFC로 저장합니다. 저장되지 않은 변경이 있을 때만 작동합니다. 그 밖의 경우에는 브라우저의 저장 명령이 열립니다 |

키보드만으로 편집하려면 값이 강조될 때까지 {{key:Tab}}을 누른 다음 {{key:Enter}}를 눌러 입력을 시작합니다.

## 2D 도면 (DWG 및 DXF)

| 키 또는 동작 | 기능 |
|---|---|
| {{key:F}} | 도면 또는 시트를 맞춥니다 |
| {{key:P}} | 인쇄 보기를 켜거나 끕니다 |
| 더블클릭 | 맞춤 |
| 아무 버튼이나 드래그 | 초점 이동 |
| 휠 스크롤 | 포인터 위치에서 줌 |
| 트랙패드에서 두 손가락 스크롤 또는 핀치 | 포인터 위치에서 줌. 두 손가락 스크롤은 초점을 이동하지 않습니다 |
| 한 손가락(터치) | 초점 이동. 도면용 핀치 줌은 아직 만들지 않았습니다 |

## 3D에서 도면 보기

| 키 또는 동작 | 기능 |
|---|---|
| {{key:3}} | 3D를 켜거나 끕니다(2D 보기에서도 동작) |
| {{key:F}} | 범위: 도면 전체 |
| 가운데 또는 왼쪽 버튼 드래그 | 궤도 회전 |
| 오른쪽 버튼 드래그, 또는 {{key:Shift}}를 누르고 드래그 | 초점 이동 |
| 휠 스크롤 | 포인터 아래 대상 쪽으로 줌 |
| 트랙패드에서 두 손가락 스와이프 | 궤도 회전. {{key:Shift}}와 함께하면 초점 이동 |
| 트랙패드 핀치 | 줌 |
| 한 손가락(터치) | 궤도 회전 |
| 두 손가락(터치) | 핀치로 줌, 함께 움직이면 초점 이동 |

입력란에 입력 중이거나, 장비 일람표가 표시 중이거나, {{key:Mod}} 또는 {{key:Alt}}를 누르고 있으면 {{key:F}}, {{key:P}}, {{key:3}}은 작동하지 않습니다.

## 파일
