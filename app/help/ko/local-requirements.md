## 할 작업

해당 지역이 요구하는 사항을 확인하고 BimCraft가 이를 사용하도록 설정합니다. 허가를 받는 단계, 제출할 항목과 형식, 도면의 모양, 도면에 넣을 표준 노트가 포함됩니다. 하나의 팩이 이 내용을 담으며, 건축 법규 팩 옆에 놓이고 한 번만 선택하면 됩니다.

팩은 안내서입니다. 무엇이 필요한지는 관할 기관과 등록 전문가가 결정합니다. 모든 팩은 신뢰 수준을 표시합니다: **미검토**(아무도 확인하지 않음), **초안**(공개된 문서로 작성했으며 전문가 검토 전), 또는 **검토됨**. 교육용 가상 팩은 어디에서든 MADE-UP으로 표시됩니다.

## 단계

1. 건축 법규 애드온을 추가하고 {{ui:설정}} › {{ui:건축 법규}}를 엽니다.
2. 해당 지역의 팩을 선택합니다. 팩을 열면 {{ui:추가 포함 항목}}에 팩이 담은 내용이 나열됩니다.
3. 허가 패키지에서 목록을 선택하면 단계, 형식, 제출할 도면이 나타납니다. 자세한 내용은 [허가 패키지](topic:permit-package)를 참고하십시오.
4. 시트에서 {{ui:표준 노트}}는 팩의 노트를 배치합니다. 자세한 내용은 [시트](topic:sheets)를 참고하십시오.
5. {{ui:주석 크기}}에서 {{ui:규정 팩의 크기 사용}} 명령을 선택하면 팩의 문자 높이를 적용합니다. 자세한 내용은 [실척으로 그리고 축척으로 주석 달기](topic:annotation-sizes)를 참고하십시오.

## 팩이 담을 수 있는 내용

- **승인 절차:** 순서대로 단계, 각 단계의 담당자, 제출 항목, 문서. 수수료나 기간은 확인한 페이지와 확인한 날짜가 함께 있을 때만 표시됩니다.
- **제출 형식:** 시트 크기, 방향, 파일 형식, 부수, 파일 이름, 표제란 항목, 제출에 필요한 도면(축척 포함)과 서류. 누락된 항목은 {{ui:문제}} 목록에 참고로 표시되며, 작업을 중단시키지 않습니다.
- **도면 작성 관례:** 종이에서의 문자 높이, 선가중치, 펜 테이블, 북쪽 표시나 축척 막대 같은 표시. 일부는 규칙으로 검사됩니다.
- **표준 노트:** 분야별 노트이며, 팩의 고유 문구로 작성되고, 각 노트에는 해당 조항이 붙어 있습니다.

## 알아 두면 좋은 점

- 지자체 팩은 국가 팩을 기반으로 합니다. 지자체 팩의 고유 단계, 도면, 노트가 우선하며 국가 팩의 항목은 그대로 남습니다.
- 공식 페이지에서 확인하지 않은 내용은 팩과 표시 위치에서 샘플 또는 미검증으로 표시됩니다.
- 해당 지역용 팩을 직접 작성해 {{ui:규정 파일 업로드}}에서 추가할 수 있습니다. 이 팩은 항상 사용자의 팩으로 표시되며, 검토됨으로 표시되지 않습니다.
