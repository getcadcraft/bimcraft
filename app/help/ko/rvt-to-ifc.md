## 할 작업

프로젝트 파일을 BimCraft에서 돌려 보고, 검사하고, 확인하고, 편집할 수 있는 IFC 파일로 바꿉니다. BimCraft는 아직 `.rvt` 파일 안의 3D 모델을 읽지 못하므로, 내보내기는 파일을 만든 프로그램(Revit)에서 하고, BimCraft는 그 결과를 엽니다.

## 단계

1. 프로젝트를 만든 프로그램에서 프로젝트를 엽니다. BimCraft 카드에는 프로젝트가 저장된 릴리스 이름이 표시됩니다.
2. 내보내려는 내용이 보이는 3D 뷰를 엽니다.
3. **파일 > 내보내기 > IFC**를 선택하십시오.
4. 내보내기 대화상자에서 아래 설정을 갖춘 설정을 고르거나(또는 **설정 수정…**), 설정을 직접 맞추십시오.
5. 폴더와 파일 이름을 고른 뒤 내보내십시오.
6. BimCraft에서 {{ui:Choose a file}} 버튼을 클릭하고 새 `.ifc` 파일을 선택하십시오. 별도 파일로 내보낸 연결 모델은 {{ui:Add a model}} 기능으로 같은 장면에 열리며 위치가 맞춰집니다.

## 여기서 가장 잘 열리는 설정

| 내보내기 설정 | 선택 | 이유 |
|---|---|---|
| IFC 버전 | 보기, 검사, 물량 산출에는 **IFC4 Reference View**; 다른 사람이 IFC2X3를 필요로 하면 **IFC2X3 Coordination View 2.0** | 두 가지 모두 완전히 열립니다. **IFC4 Design Transfer View**도 열리지만, 형상이 더 정확한 대신 파일이 크고 느립니다. |
| 파일 형식 | **IFC**(일반) | BimCraft는 `.ifczip` 또는 `.ifcxml` 파일을 열지 않습니다. |
| 단계 / 보이는 요소 | 원하는 단계, 그리고 그 목적으로 3D 뷰를 설정했다면 **뷰에서 보이는 요소만 내보내기** | 의도적으로 숨긴 항목을 제외합니다. |
| 속성 세트 | **Revit 속성 세트 내보내기** 및 **IFC 공통 속성 세트 내보내기** | BimCraft의 {{ui:Properties}}에 표시되며, {{ui:Find}}, {{ui:Color}}, {{ui:Model checks}}가 사용하는 속성 세트가 됩니다. |
| 기본 물량 | **기본 물량 내보내기** | {{ui:Quantity totals}}와 일람표는 추측하는 대신 이를 사용합니다(길이, 면적, 부피). |
| 실과 면적 | **3D 뷰에서 실 내보내기**(또는 실/공간 옵션) | 실은 공간으로 들어옵니다. {{ui:Spaces}}를 클릭하면 확인할 수 있습니다. |
| 연결 파일 | **연결 파일을 별도 IFC로 내보내기** | 각 링크는 자체 파일이 됩니다. {{ui:Add a model}} 기능으로 함께 열면 위치가 맞춰집니다. |
| 좌표 기준 | **공유 좌표**(또는 측량점) | 파일이 지도 위의 위치(IfcMapConversion)를 가지므로, 측정 › 위치, 지면의 지도 레이어, 지도 좌표로 배치된 포인트 클라우드가 작동합니다. 프로젝트 기준점은 모델을 원점 근처에 두지만 지도 위치는 없습니다. |
| 레벨별 벽과 기둥 분할 | 층별로 물량을 산출할 때 켜기 | 각 층의 부분이 독립 요소가 됩니다. |

## 보게 되는 결과

3D 모델이 표시되며, 층은 프로젝트의 레벨에서 가져오고, 프로젝트 정보는 {{ui:File}} 패널에 있습니다. **내보낸 프로그램** 항목에 내보낸 프로그램의 이름이 표시됩니다.

## 내보내기가 유지하는 것과 유지하지 않는 것

- **유지**: 형상, 층, 요소 종류, 이름, 유형, 대부분의 매개변수(속성 세트로), 요청 시 기본 물량, 공간으로서의 실, 공유 좌표를 사용할 때의 지도 위치.
- **유지되지 않음**: 뷰, 시트, 주석, 편집 가능한 패밀리 형태의 패밀리, 작업 세트, 디자인 옵션. IFC 파일은 프로젝트가 아니라 모델 요소의 스냅샷입니다. 시트는 DWG로 내보낸 뒤 2D 뷰에서 여십시오.

## 흔한 실수

- **BimCraft에 매개변수가 없음.** 위의 속성 세트 옵션을 켜고 다시 내보내십시오.
- **실이 없음.** 실 옵션을 켠 다음 {{ui:Spaces}}를 클릭하십시오.
- **`.ifczip` 파일로 저장함.** 일반 IFC를 선택하거나, `.ifczip`의 압축을 푸십시오.
- **지도 위치가 없음.** 공유 좌표로 내보내고, 프로젝트의 측량점이 설정되어 있는지 확인하십시오.
- **편집 내용이 프로젝트로 돌아오리라 기대함.** BimCraft에서 저장한 편집은 프로젝트 파일이 아니라 새 IFC 파일에 저장됩니다.
