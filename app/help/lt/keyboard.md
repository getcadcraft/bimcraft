BimCraft turi nedaug spartiųjų klavišų. Didžiąją darbo dalį atliekate pele ir skydeliais. Spartieji klavišai, parašyti su {{key:Mod}}, Mac kompiuteryje naudoja Command, kitur – Ctrl. Žr. [Klavišai, pelės ir jutikliniai kilimėliai](common:keys), kaip šioje pagalboje rašomi klavišai.

## Visur

| Klavišas | Ką daro |
|---|---|
| {{key:Ctrl+Shift+F}} | Perjungia ekrano režimus: įprastą, visą ekraną, visą ekraną su paslėptomis juostomis. Ctrl visose platformose, įskaitant Mac |
| {{key:Esc}} | Išeina iš viso ekrano |
| {{key:Mod+,}} | Atidaro {{ui:Parametrai}}. Žr. [BimCraft nustatymai](topic:settings) |
| {{key:Tab}} | Pereina tarp mygtukų, žymimųjų langelių ir reikšmių. Visi valdikliai pasiekiami klaviatūra |

## 3D vaizdas (IFC modeliai)

| Klavišas ar veiksmas | Ką daro |
|---|---|
| {{key:F}} | Tilpti visą modelį, trijų ketvirtadalių vaizdas (kaip {{ui:Tilpti}}) |
| {{key:Esc}} | Panaikina pasirinkimą arba nustoja įterpti ar įklijuoti |
| Spustelėjimas | Pasirenka elementą po žymekliu; spustelėjus tuščią foną pasirinkimas panaikinamas |
| {{key:Mod}}+spustelėjimas arba {{key:Shift}}+spustelėjimas | Prideda elementą prie pasirinkimo arba jį pašalina |
| {{key:H}} | Paslepia pasirinktus elementus. Žr. [Slėpti, izoliuoti ir matyti per elementus](topic:hide-and-isolate) |
| {{key:I}} | Rodo tik pasirinktus elementus (izoliuoja) |
| {{key:T}} | Rodo pasirinktus elementus, o visa kita – permatoma |
| {{key:Shift+H}} | Vėl rodo visus elementus |
| {{ui:Vaikščioti}} | Tada {{key:W}} {{key:A}} {{key:S}} {{key:D}} arba rodyklės – eiti, {{key:Shift}} – bėgti, vilkimas – žiūrėti aplink, {{key:Esc}} – sustoti. Žr. [Vaikščioti po modelį](topic:walk) |
| {{key:M}} | Matuoja atstumus ir paviršių plotus. Žr. [Matuoti atstumus, paviršių plotus ir padėtis 3D](topic:measure) |
| Vilkti kairiuoju mygtuku | Sukti orbita |
| Vilkti dešiniuoju mygtuku | Slinkti |
| {{key:Shift}} arba {{key:Mod}} ir vilkti kairiuoju mygtuku | Slinkti (patogu su jutikliniu kilimėliu) |
| Slinkti ratuku arba vilkti vidurio mygtuku | Keisti mastelį |
| Dviejų pirštų slinkimas arba suspaudimas jutikliniu kilimėliu | Keisti mastelį |
| Vienas pirštas (palietimas) | Sukti orbita; bakstelėjimas pasirenka |
| Du pirštai (palietimas) | Suspausti – keisti mastelį; judinti kartu – slinkti |

| {{key:X}} | Pjūvio plokštuma įjungta ir išjungta. Žr. [Pjaustyti IFC modelį pjūvio plokštuma](topic:section-plane) |
| {{key:Shift+X}} | Pjūvio dėžutė aplink pasirinktus elementus, su tarpu, nustatytu Parametruose |

{{ui:Viršus}}, {{ui:Priekis}} ir {{ui:Iš šono}} klavišų nėra; naudokite mygtukus.

## Redagavimas

Tos pačios komandos yra įrankių juostoje: {{ui:Anuliuoti}}, {{ui:Perdaryti}}, {{ui:Kopijuoti}}, {{ui:Įklijuoti}} ir meniu {{ui:Daugiau}}, kuriame rodomas kiekvienas klavišas. Jos veikia IFC modelio 3D vaizde, o ne tada, kai rašote lauke. Žr. [Kopijuoti, įklijuoti ir dubliuoti bibliotekos elementus](topic:copy-paste).

| Klavišas | Ką daro |
|---|---|
| {{key:Mod+Z}} | Anuliuoja paskutinį pakeitimą |
| {{key:Mod+Y}} arba {{key:Mod+Shift+Z}} | Perdaro tai, ką Anuliuoti atšaukė |
| {{key:Mod+C}} | Kopijuoja pasirinktus elementus (jų pavadinimai ir savybės taip pat patenka į iškarpinę kaip tekstas) |
| {{key:Mod+X}} | Iškerpa pasirinktus elementus: nukopijuoja ir ištrina |
| {{key:Mod+V}} | Įklijuoja nukopijuotus elementus: jie seka žymeklį, spustelėkite, kur juos dėti |
| {{key:Mod+Shift+V}} | Įklijuoja į tą pačią vietą: kur buvo iškirpta, arba šalia originalų po kopijavimo |
| {{key:Mod+D}} | Dubliuoja: nukopijuoja pasirinktus elementus ir pradeda juos įklijuoti |
| {{key:Delete}} | Ištrina pasirinktus elementus kartu su jų dalimis ir angomis. Žr. [Ištrinti, iškirpti, kopijuoti ir įklijuoti statybinius elementus](topic:edit-elements) |
| {{key:Mod+A}} | Pasirenka visus rodomus elementus |
| {{key:Esc}} | Nepasirenka nieko |

Kai puslapyje pažymėtas tekstas, {{key:Mod+C}} nukopijuoja tekstą įprastai.

## Planas (Braižymas)

Šie veikia, kai įjungtas {{ui:Braižymas}} ir kai nerašote lauke. Žr. [Braižyti sienas](topic:draw-walls) ir [Durys ir langai](topic:doors-and-windows).

| Klavišas ar veiksmas | Ką daro |
|---|---|
| {{key:V}} | {{ui:Pasirinkti}} |
| {{key:W}} | {{ui:Siena}} |
| {{key:D}} | {{ui:Durys}} |
| {{key:N}} | {{ui:Langas}} |
| {{key:H}} | Su {{ui:Durys}} arba {{ui:Langas}}: vyriai kitame gale |
| {{key:Shift}} braižant sieną | Laiko ją ties 0°, 90°, 180° arba 270° |
| Skaitmenys ir pėdų bei colių ženklai (`'` ir `"`) | Pradeda rašyti ilgį į laukelį {{ui:Ilgis}}; {{key:Enter}} jį panaudoja |
| {{key:Enter}}, {{key:Esc}}, dešinysis spustelėjimas arba dvigubas spustelėjimas | Baigia braižomą sieną; {{key:Esc}} dar kartą grąžina į {{ui:Pasirinkti}} |
| {{key:Delete}} | Ištrina pasirinktas sienas, duris ir langus; likusios sienos vėl susijungia |
| {{key:F}}, kai žymeklis virš plano | Tilpti planui |
| Ratukas | Keisti mastelį apie žymeklį |
| Vilkti vidurio arba dešiniuoju mygtuku, arba {{key:Space}} ir vilkti | Slinkti; kai įjungtas {{ui:Pasirinkti}}, paprastas vilkimas taip pat slenka |
| Vilkti duris arba langą su {{ui:Pasirinkti}} | Perkelti jį palei sieną arba į kitą sieną |
| Du pirštai (palietimas) | Suspausti – keisti mastelį; judinti kartu – slinkti |

## Bibliotekos elementų įterpimas ir įklijavimas

| Klavišas | Ką daro |
|---|---|
| {{key:R}} | Pasuka elementą 90° |
| {{key:Tab}} | Prilipimas prie sienos įjungtas ir išjungtas: elemento nugarėlė prisiglaudžia prie artimiausios sienos |
| {{key:Enter}} lauke **X, Y (mm)** | Įterpia įvestoje padėtyje |
| {{key:Esc}} | Nustoja įterpti ar įklijuoti |

## IFC reikšmių redagavimas

| Klavišas | Ką daro |
|---|---|
| {{key:Enter}} | Palieka įvestą reikšmę |
| {{key:Esc}} | Atšaukia ir grąžina seną reikšmę |
| Spustelėjimas kitur | Palieka įvestą reikšmę |
| {{key:Mod+Z}} | Anuliuoja paskutinį pakeitimą. Tik tada, kai turite neįrašytų pakeitimų ir nerašote lauke |
| {{key:Mod+Y}} | Perdaro tai, ką Anuliuoti atšaukė |
| {{key:Mod+S}} | Įrašo kaip IFC. Tik kai turite neįrašytų pakeitimų; kitu atveju atsidaro naršyklės įrašymo komanda |

Kad redaguotumėte tik klaviatūra: spauskite {{key:Tab}}, kol paryškinama reikšmė, tada spauskite {{key:Enter}}, kad pradėtumėte rašyti.

## 2D brėžiniai (DWG ir DXF)

| Klavišas ar veiksmas | Ką daro |
|---|---|
| {{key:F}} | Tilpti brėžiniui arba lapui |
| {{key:P}} | Spausdinimo vaizdas įjungtas ir išjungtas |
| Dvigubas spustelėjimas | Tilpti |
| Vilkti bet kuriuo mygtuku | Slinkti |
| Ratukas | Keisti mastelį prie žymeklio |
| Dviejų pirštų slinkimas arba suspaudimas jutikliniu kilimėliu | Keisti mastelį prie žymeklio. Dviejų pirštų slinkimas neslenka |
| Vienas pirštas (palietimas) | Slinkti. Brėžiniams suspaudimo keitimas mastelį dar neįgyvendintas |

## Brėžiniai 3D

| Klavišas ar veiksmas | Ką daro |
|---|---|
| {{key:3}} | 3D įjungtas ir išjungtas (taip pat 2D vaizde) |
| {{key:F}} | Apimtis: visas brėžinys |
| Vilkti vidurio arba kairiuoju mygtuku | Sukti orbita |
| Vilkti dešiniuoju mygtuku arba {{key:Shift}} ir vilkti | Slinkti |
| Ratukas | Keisti mastelį link to, kas po žymekliu |
| Dviejų pirštų braukimas jutikliniu kilimėliu | Sukti orbita; su {{key:Shift}} – slinkti |
| Suspaudimas jutikliniu kilimėliu | Keisti mastelį |
| Vienas pirštas (palietimas) | Sukti orbita |
| Du pirštai (palietimas) | Suspausti – keisti mastelį; judinti kartu – slinkti |

{{key:F}}, {{key:P}} ir {{key:3}} neveikia, kol rašote lauke, kai rodomas įrangos žiniaraštis arba kai laikote {{key:Mod}} ar {{key:Alt}}.
