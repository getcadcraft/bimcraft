BimCraft hefur fáar flýtileiðir. Mest af vinnunni er unnin með músinni og spjöldunum. Flýtileiðir skrifaðar með {{key:Mod}} nota Command á Mac og Ctrl annars staðar. Sjá [Lyklar, mýs og snertiborð](common:keys) um hvernig lyklar eru skrifaðir í þessari hjálp.

## Alls staðar

| Lykill | Hvað hann gerir |
|---|---|
| {{key:Ctrl+Shift+F}} | Skiptir á milli skjástillinga: venjulegur, fullur skjár og fullur skjár með stikum faldar. Ctrl á öllum kerfum, líka á Mac |
| {{key:Esc}} | Hætta í fullum skjá |
| {{key:Mod+,}} | Opna {{ui:Stillingar}}. Sjá [Stillingar BimCraft](topic:settings) |
| {{key:Tab}} | Færa á milli hnappa, gátreita og gilda. Hægt er að ná í hvern stjórnhnapp með lyklaborðinu |

## 3D-sýn (IFC-líkön)

| Lykill eða aðgerð | Hvað hún gerir |
|---|---|
| {{key:F}} | Passar allt líkanið, þriggja fjórðu sýn (sama og {{ui:Passa}}) |
| {{key:Esc}} | Hreinsar valið, eða hættir að staðsetja eða líma |
| Smella | Velur hlutinn undir bendlinum; smelltu á autt bakgrunn til að hreinsa |
| {{key:Mod}}+smella eða {{key:Shift}}+smella | Bætir hlut við valið, eða tekur hann úr því |
| {{key:H}} | Felur valda hluti. Sjá [Fela, einangra og sjá í gegnum hluti](topic:hide-and-isolate) |
| {{key:I}} | Sýnir aðeins valda hluti (einangrun) |
| {{key:T}} | Sýnir valda hluti, allt annað gegnsætt |
| {{key:Shift+H}} | Sýnir alla hluti aftur |
| {{ui:Ganga}} | Síðan {{key:W}} {{key:A}} {{key:S}} {{key:D}} eða örvar til að ganga, {{key:Shift}} hleypur, draga til að líta í kring, {{key:Esc}} stöðvar. Sjá [Ganga í gegnum líkan](topic:walk) |
| {{key:M}} | Mælir vegalengdir og flatarmál fleta. Sjá [Mæla vegalengdir, flatarmál fleta og staðsetningar í þrívídd](topic:measure) |
| Draga með vinstri hnappi | Snúa |
| Draga með hægri hnappi | Hliðra |
| {{key:Shift}} eða {{key:Mod}} og draga með vinstri hnappi | Hliðra (hentugt á snertiborði) |
| Skrolla hjólinu, eða draga með miðhnappi | Aðdráttur |
| Skrun með tveimur fingrum eða klípa á snertiborði | Aðdráttur |
| Einn fingur (snerting) | Snúa; smella velur |
| Tveir fingur (snerting) | Klípa til aðdráttar, færa saman til að hliðra |

| {{key:X}} | Sniðplan á og af. Sjá [Skera IFC-líkan með sniðplani](topic:section-plane) |
| {{key:Shift+X}} | Sniðkassi utan um valda hluti, með herberginu stillt í Stillingum |

Það eru engir lyklar fyrir {{ui:Ofan}}, {{ui:Framan}} og {{ui:Hlið}}; notaðu hnappana.

## Breyta

Sömu skipanir eru á tækjastikunni: {{ui:Afturkalla}}, {{ui:Endurgera}}, {{ui:Afrita}}, {{ui:Líma}} og {{ui:Meira}}-valmyndin, sem sýnir hvern lykil. Þær virka í 3D-sýn IFC-líkans, ekki meðan þú skrifar í reit. Sjá [Afrita, líma og tvöfalda safnhluti](topic:copy-paste).

| Lykill | Hvað hann gerir |
|---|---|
| {{key:Mod+Z}} | Afturkallar síðustu breytingu |
| {{key:Mod+Y}} eða {{key:Mod+Shift+Z}} | Endurgerir það sem Afturkalla tók til baka |
| {{key:Mod+C}} | Afritar valda hluti (heiti þeirra og eiginleikar fara líka á klippiborðið sem texti) |
| {{key:Mod+X}} | Klippir valda hluti: afritar þá og eyðir síðan |
| {{key:Mod+V}} | Límir það sem þú afritaðir: það fylgir bendlinum, smelltu þar sem það á að fara |
| {{key:Mod+Shift+V}} | Límir á sama stað: þar sem klipping kom frá, eða við hlið upprunalegu eftir afritun |
| {{key:Mod+D}} | Tvöfaldar: afritar valda hluti og byrjar að líma þá |
| {{key:Delete}} | Eyðir völdum hlutum, með hlutum sínum og opum. Sjá [Eyða, klippa, afrita og líma byggingarhluti](topic:edit-elements) |
| {{key:Mod+A}} | Velur alla sýnilega hluti |
| {{key:Esc}} | Velur engan |

Þegar texti er valinn á síðunni afritar {{key:Mod+C}} textann eins og venjulega.

## Grunnmyndarsýn (Teikna)

Þetta virkar meðan {{ui:Teikna}} er á og þú ert ekki að skrifa í reit. Sjá [Teikna veggi](topic:draw-walls) og [Hurðir og gluggar](topic:doors-and-windows).

| Lykill eða aðgerð | Hvað hann gerir |
|---|---|
| {{key:V}} | {{ui:Velja}} |
| {{key:W}} | {{ui:Veggur}} |
| {{key:D}} | {{ui:Hurð}} |
| {{key:N}} | {{ui:Gluggi}} |
| {{key:H}} | Með {{ui:Hurð}} eða {{ui:Gluggi}}: lamir á hinum endanum |
| {{key:Shift}} meðan þú teiknar vegg | Heldur honum í 0°, 90°, 180° eða 270° |
| Tölustafir og fet- og tommumerki (`'` og `"`) | Byrjar að skrifa lengd í reitinn {{ui:Lengd}}; {{key:Enter}} notar hana |
| {{key:Enter}}, {{key:Esc}}, hægri smellur eða tvísmellur | Lýkur veggnum sem þú teiknar; {{key:Esc}} aftur fer til {{ui:Velja}} |
| {{key:Delete}} | Eyðir völdum veggjum, hurðum og gluggum; veggirnir sem eftir eru tengjast aftur |
| {{key:F}} með bendilinn yfir grunnmyndinni | Passar grunnmyndina |
| Skrolla hjólinu | Aðdráttur um bendilinn |
| Draga með miðhnappi eða hægri hnappi, eða {{key:Space}} og draga | Hliðra; með {{ui:Velja}} á hliðrar venjulegt drag líka |
| Draga hurð eða glugga með {{ui:Velja}} | Færir hann eftir veggnum sínum, eða yfir á annan vegg |
| Tveir fingur (snerting) | Klípa til aðdráttar, færa saman til að hliðra |

## Staðsetning og líming safnhluta

| Lykill | Hvað hann gerir |
|---|---|
| {{key:R}} | Snýr hlutnum um 90° |
| {{key:Tab}} | Veggsmell á og af: bakhlið hlutarins fer að næsta vegg |
| {{key:Enter}} í **X, Y (mm)** | Staðsetur á skrifaða staðnum |
| {{key:Esc}} | Hættir að staðsetja eða líma |

## Breyta IFC-gildum

| Lykill | Hvað hann gerir |
|---|---|
| {{key:Enter}} | Heldur gildinu sem þú skrifaðir |
| {{key:Esc}} | Hættir við og setur gamla gildið aftur |
| Smella annars staðar | Heldur gildinu sem þú skrifaðir |
| {{key:Mod+Z}} | Afturkallar síðustu breytingu. Aðeins meðan þú hefur óvistaðar breytingar og ert ekki að skrifa í reit |
| {{key:Mod+Y}} | Endurgerir það sem Afturkalla tók til baka |
| {{key:Mod+S}} | Vistar sem IFC. Aðeins meðan þú hefur óvistaðar breytingar; annars opnast vistunarskipun vafrans |

Til að breyta eingöngu með lyklaborðinu: ýttu á {{key:Tab}} þar til gildi er auðkennt, ýttu síðan á {{key:Enter}} til að byrja að skrifa.

## 2D-teikningar (DWG og DXF)

| Lykill eða aðgerð | Hvað hann gerir |
|---|---|
| {{key:F}} | Passar teikninguna eða blaðið |
| {{key:P}} | Prentsýn á og af |
| Tvísmella | Passa |
| Draga með hvaða hnappi sem er | Hliðra |
| Skrolla hjólinu | Aðdráttur við bendilinn |
| Skrun með tveimur fingrum eða klípa á snertiborði | Aðdráttur við bendilinn. Skrun með tveimur fingrum hliðrar ekki |
| Einn fingur (snerting) | Hliðra. Klípuaðdráttur er ekki kominn fyrir teikningar enn |

## Teikningar í þrívídd

| Lykill eða aðgerð | Hvað hann gerir |
|---|---|
| {{key:3}} | 3D á og af (líka á 2D-sýninni) |
| {{key:F}} | Útmörk: öll teikningin |
| Draga með miðhnappi eða vinstri hnappi | Snúa |
| Draga með hægri hnappi, eða {{key:Shift}} og draga | Hliðra |
| Skrolla hjólinu | Aðdráttur að því sem er undir bendlinum |
| Strjúka með tveimur fingrum á snertiborði | Snúa; með {{key:Shift}}, hliðra |
| Klípa á snertiborði | Aðdráttur |
| Einn fingur (snerting) | Snúa |
| Tveir fingur (snerting) | Klípa til aðdráttar, færa saman til að hliðra |

{{key:F}}, {{key:P}} og {{key:3}} gera ekkert meðan þú skrifar í reit, meðan búnaðarlistinn er sýndur, eða þegar þú heldur inni {{key:Mod}} eða {{key:Alt}}.
