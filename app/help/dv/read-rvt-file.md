## ކުރާނެ ކަންތައް

Revit ގައި ހުޅުވާ ނުލާ ޕްރޮޖެކްޓް ނުވަތަ ފެމިލީ ފައިލެއްގައި ކޮންކަން ހުންނަ ކަން ހޯދާ: އެ ކޮން ރިލީސްއިން ރައްކާކުރެވުނު، ވޯކް ޝެއަރިންގ ހުރި ނޫން، ޕްރޮޖެކްޓް މައުލޫމާތު، އަދި ކޮންތަކެއް ލިންކްވެއެވެ. ފައިލެއް އެހެން މީހަކުން ލިބިގެން އެ ކޮން ރިލީސްގައި ހުޅުވަންޖެހޭކަން ދެނެގަތުމަށް ބޭނުންވާއިރު ވެސް ފައިދާވެއެވެ.

## ފިޔަވަޅުތައް

1. {{ui:ފައިލެއް އިޚްތިޔާރުކުރޭ}} ކްލިކްކުރޭ.
2. `.rvt`، `.rfa`، `.rte` ނުވަތަ `.rft` ފައިލެއް ހޮވާ.
3. ވަގުތަކަށް ހިތާ. ސްޓޭޓަސް ލައިން "ފައިލް ކިޔަވަނީ…" ކިޔާ، ދެން "*ފައިލުގެ ނަން* ހުޅުވިއްޖެ" ކިޔާނެ.
4. ކާޑުގެ މަތީ ބަލާ: ފައިލުގައި ރައްކާ ކުރެވުނު ޕްރިވިއު ސޫރަތް، ފައިލުގެ ބާވަތް އަދި ރައްކާ ކުރެވުނު ރިލީސް، އަދި ޕްރޮޖެކްޓުގެ ނަން.
5. ކާޑުގެ ބައިތައް ކިޔުމަށް ތިރިކޮށް ސްކްރޯލް ކުރޭ.

## ކޮބައި ފެންނާނެ

މެދުގައިވާ ކާޑު، ފައިލުގައި ހުންނަ ކަމަށް ފެންނަ ބައިތަކާއެކު:

| ބައި | ކީއްކޮށް ދައްކާ |
|---|---|
| ފައިލް | ފައިލުގެ ނަން، ސައިޒް، ބާވަތް (ޕްރޮޖެކްޓް، ޕްރޮޖެކްޓް ޓެމްޕްލޭޓް، ފެމިލީ ނުވަތަ ފެމިލީ ޓެމްޕްލޭޓް)، ރައްކާކުރެވުނު ރިލީސް އަދި ބިލްޑް، ވޯކް ޝެއަރިންގ، ސެންޓްރަލް މޮޑެލްގެ މަގު، މުސާރަ ފަހުން ރައްކާ ކުރެވުނު ތަން، ރައްކާ ކުރި މީހާ، ލޮކޭލް އަދި ޑޮކިއުމަންޓް GUID |
| ޕްރޮޖެކްޓް މައުލޫމާތު | ޕްރޮޖެކްޓުގެ އަމިއްލަ ފީލްޑްތައް، މިސާލަކަށް ނަން، ނަންބަރު، ކްލަޔަންޓް، އެޑްރެސް އަދި ސްޓޭޓަސް. އައު ޕްރޮޖެކްޓުގެ ޑިފޮލްޓުގައި އަދިވެސް ހުންނަ ފީލްޑްތައް ހިމެނުން ނެތް. |
| ފެމިލީ، ފެމިލީ: … | ފެމިލީއަކަށް: އޭގެ ނަން، ކެޓަގަރީ، ރިލީސް، ފަހުގެ އަޕްޑޭޓް އަދި އޭގެ ޕެރާމީޓަރުތައް، ގްރޫޕް ގްރޫޕް ސީދާ |
| ލިންކްކުރެވުނު އަދި ރެފަރެންސް ކުރެވުނު ފައިލްތައް | ފައިލް ދައްކާ ކޮންމެ ލިންކްކުރެވުނު މޮޑެލް، CAD ލިންކް، ތަސްވީރު އަދި ކީނޮޓް ޓޭބަލް، އެ ރައްކާކުރެވުނު މަގާއެކު |

ގަނޑުގައި {{ui:ފައިލް}} ޕެނަލް މުހިންމު ފަރާތްތައް އަލުން ދައްކައި **ކިޔެވުނު** އެއް އިތުރު ކުރޭ: BimCraft ފައިލުން ކިތައް ކިޔެވުނު، އެ ފައިލް މެގާބައިޓު ގިނަ ސައިޒެއްގެ ތެރޭގައި ޢާމް ގޮތެއްގައި 40 KB ހަމައަށް. ނަގައިގައި {{ui:ޚާސިއްޔަތުތައް}} ޕެނަލް ދައްކާ އެއްޗެހީގެ ޚާސިއްޔަތުތަކަށް 3D މޮޑެލް ބޭނުންވާކަން.

## 3D ނެތް ސަބަބު

3D މޮޑެލް އަދި ޕްރޮޖެކްޓް ފައިލުގެ ތެރޭގައި އެއްޗެހި ލިޔެވިފައިވަނީ ލިޔުން ނެތް ފޯމެޓެއްގައި. BimCraft ކިޔަވަނީ ފައިލުގެ ލިޔުން ކުރެވިފައިވާ ނުވަތަ ސާދާ ކިޔެވޭ ބައި އެކަނި: ފައިލް މައުލޫމާތު، ޕްރޮޖެކްޓް މައުލޫމާތު، ފެމިލީ ޑޭޓާ، ލިންކް ލިސްޓް އަދި ޕްރިވިއު ސޫރަތް. ބާކީ ބައި އަނދާޒާ ނުކުރޭ. 3D ގައި މޮޑެލް ފެނުމަށް އަދި އެއްޗެހީގެ ޚާސިއްޔަތު ކިޔުމަށް، ފައިލް ހަދާ ޕްރޮގްރާމުން IFC އެކްސްޕޯޓްކުރޭ. ބައްލަވާ [ޕްރޮޖެކްޓް ފައިލެއް IFC އިން 3D ކުރުން](topic:rvt-to-ifc).

## ގިނައިން ދިމާވާ މައްސަލަތައް

- **3D ކަމުގައި އުއްމީދުވުން.** މަތީގައި ބަލާ.
- **ލިންކްތައް ރައްކާ ކުރެވުނު މަގު އެކަނި ދައްކާ.** ފައިލެއް އެކަނި ހުޅުވުމުން ލިންކްތައް މިހާރު ހުންނަނިކަން ބެލި ނުލެވޭ. އޭގެ ބަދަލުގައި އެ ހުންނަ ފޯލްޑަރ ހުޅުވާ، އަދި BimCraft ކޮންމެ ލިންކެއް ފެނިފައި ނުވަތަ ނުފެނި ކަން މާކް ކުރޭ: [މުޅި ޕްރޮޖެކްޓް ފޯލްޑަރ ހުޅުވާ](topic:open-project-folder).
- **"This file is incomplete…" (ފައިލް ފުރިހަމަ ނޫން…)** ފައިލް ކޮޕީކުރުމުގައި، އަޕްލޯޑުކުރުމުގައި ނުވަތަ ސިންކް ކުރުމުގައި ކެނޑިފައިވާ. "online only" ކިޔާ ކްލައުޑް ޑްރައިވް ފައިލް ވެސް މިގޮތަށް. BimCraft އެ ފައިލް އަދިވެސް ހުޅުވާ، އަދި ރައްކާވި ބައި އެކަނި ދައްކާ: ކާޑުގެ މަތީގައި އެމްބަރ ނޮޓިސެއް، **Recovered from this file** ބައި އެ ފައިލުގައި ކޮންމެ ބައިޓެއްގެ ކުންފުޓާ ހުރި ބައިތައް ލިސްޓް ކުރާ، އަދި **Not in the file** ބާކީ ބައި އަށް. ނެތް ބައިގެ ބަދަލުގައި އެއްވެސް އެއްޗެއް ފުރުވުމެއް ނުކުރެވޭ، ފަހެ ރިލީސް، ޕްރިވިއު ސޫރަތް ނުވަތަ ޕްރޮޖެކްޓް މައުލޫމާތު ނެތިދާނެ، ކެނޑުމުގެ ފަހުން ރައްކާވެފައި ހުރި ނަމަ. ފައިލުގެ ކޮންޓެންޓް ލިސްޓް ވެސް ކެނޑިފައި ނަމަ، އެއްވެސް ކަމެއް ހުޅުވޭނެ ނޫން. އަސްލު ފައިލް އަލުން ކޮޕީކޮށް ފުރިހަމަ ފައިލް ހުޅުވާ.
- **"No preview picture in this file" (ފައިލްގައި ޕްރިވިއު ސޫރަތެއް ނެތް).** ކޮޅެއް ފައިލްތައް އެއް ނެތި ރައްކާ ކުރެވެ. އެ ނޯމަލް.
- **ބެކްއަޕެއް މިސްވެ ހުޅުވުން.** `Tower.0004.rvt` ފަދަ ނަމުގެ ފައިލްތައް ނަންބަރުވެފައިވާ ބެކްއަޕްތަކެކެވެ. ފޯލްޑަރ ހުޅުވުމުން އެ ޖަމާކޮށް އެ މޮޑެލާ ގުޅޭ.
