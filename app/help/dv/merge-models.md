ދެ މީހުން އެއް ބިލްޑިންގގެ ކޮޕީއެއް ނަގައެވެ؛ އެކެއް އިރުކޮޅު ވިންގ ދަނީ އަދި އެކެއް އިރުއުތުރު، އަދި ފަހުން ކޮޕީތައް އެއްކޮށް ހަދަން ޖެހެއެވެ. އެމީހުން ވަނީ ވަކި އޮބްޖެކްޓްތައް ކަމުން ފަސްކުރެވުނަކަމުން، ޕްރޮގްރާމެއް ފަރުދެއްގެ ބަދަލުގައި ކުރެވޭ.

## އެއީ ކިހިނެއް ވާ ގޮތް

IFC ފައިލަކުގެ ކޮންމެ ފާރެއް، ދޮރެއް، ލެވެލެއް، ކޮޓަރިއެއް އަދި ޕްރޮޕަޓީ ސެޓެއްގައި GlobalId ހުންނާތީ އެއް ފަހަރު ބަދަލު ނުވާ. ޓަކާ ޖާގަ ގެ އައިޑީ މާ ފަހަރު ކުރާ ބޭނުމުގައި ޓަކާ ޖާގަ ފާޅަށް ޖަހާ، ނަމަވެސް ނަމްބަރ (`#123`) ނުވާ، އެކަން ޕްރޮގްރާމް ރައްކާ ކުރާ ވަގުތު ބަދަލުވާތީއެވެ. އޮބްޖެކްޓް ތެރޭގައި ނެތް އަމިއްލަ އައިޑީ ހުރި ބައިތައް (ޕްލޭސްމަންޓްތައް، ޝޭޕްތައް، ޔުނިޓްތައް) އެތަކެއްގެ ތެރެއިން ހިމެނެމެއް ކުރެވޭ.

ދެ ކޮޕީވެސް އެއް IFC ވާރޝަނެއް (2x3، 4 ނުވަތަ 4.3) ވާންޖެހޭ. މަރޖް ކުރުން ތިޔަ ފައިލް އޭގެ ގޮތުން، އޭގެ ޢިންތަޒީމް އަދި ނަމްބަރުތައް ރައްކާ ކޮށް، އައު ކަންތައް އިތުރު ކުރޭ؛ އެހެންކަމުން git diff ގައި މަރޖުން ބަދަލުވި ކަންތައް އެކަނި ފެންނާނެއެވެ.

## ސެޓަޕް ކުރޭ

Git އަށް ކޮންމެ ރިޕޯޒިޓަރީއަކަށް ފަހަރެއް ދެ ލައިން ބޭނުންވޭ:

```
# .gitattributes
*.ifc merge=cadcraft

# ފަހަރަކު، ކޮންމެ ކޮމްޕިއުޓަރެއްގައި
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git ނެތްނަމަ، `cadcraft merge <base> <ours> <theirs>` ރަން ކުރޭ. Fossil އަދި Mercurial އަށް ތިން ފައިލް އެއް ގޮތުގައި އެމީހުންގެ އަމިއްލަ merge-tool ސެޓިންގްސްގައި. އެއްވެސް ކަމެއް އަޕްލޯޑް ނުވޭ؛ ހުރިހާ ކަމެއް ތިޔަ ކޮމްޕިއުޓަރުގައި ހިނގާ.

## ގަވާއިދު

- ޗޭންޖްތަކެއްގެ ކުށެއް ބާރުގައި އެއް ފަރާތެއްގައި ބަދަލުވި ޚާސިއްޔަތެއް ނަގައެވެ. ދެ ފަރާތުގައި އެއް ބަދަލު ހުރިނަމަ އެއް ފަހަރު ނަގައެވެ.
- އެއް ޚާސިއްޔަތެއް ދެ ގޮތެއްގައި ބަދަލުވި (އެއް ލެވެލަކަށް ދެ ގޮތެއްގައި ނަން ބަދަލުކޮށްފައި) **ކޮންފްލިކްޓެއް** ކަމުގައި. ތިޔަ ފަރާތް ހުންނާނެ، ރިޕޯޓް ދެ ފަރާތް ލިސްޓް ކުރާނެ. ރިޒަލްޓް ހުޅުވާ އަތުން ރަނގަޅު ކުރޭ.
- އެއް ލިސްޓެއް (ލެވެލެއް ފާރުތައް، ސެޓެއް ޕްރޮޕަޓީތައް) ސެޓެއްގެ ގޮތުގައި މަރޖް ވެއެވެ: ދެ ފަރާތުން އިތުރު ކުރި ކަންތައް ހިފާ، ދެ ފަރާތުން ފޮހެލި ކަންތައް ފޮހެލާ. ލެވެލަކަށް ފާރު އިތުރު ކުރި ދެ މީހުން ކޮންފްލިކްޓެއް ނުހެދޭ.
- ދެ ފަރާތުގެ އެއް ފަރާތުން އިތުރު ކުރާ އޮބްޖެކްޓަކަށް އޭގެ ޝޭޕާއި ޕްރޮޕަޓީތައް ހިފާ. އެއް ފަރާތުން ފޮހެލި ހިނދު އަނެއް ފަރާތުގައި ބަދަލެއް ނެތުނަސް: ފޮހެލާ. އެއް ފަރާތުން ފޮހެލި އަދި އަނެއް ފަރާތުގައި ބަދަލުވި: ފޮހެލާ، އަދި ރިޕޯޓުން ދައްކާ.
- ފައިލުގެ ޓައިމް ސްޓެމްޕް އަދި ބޭނުންކުރާ މީހާ، އަދި ކޮންމެ އޮބްޖެކްޓުގެ އޮނަރ ހިސްޓްރީ، ތިޔަ އަމިއްލަ ވާހަކަ.

ޖިޔޮމެޓްރީ ފުރިހަމައަށް މަރޖް ވެއެވެ: ފާރެއްގެ ޝޭޕް އެއް ފަރާތުން ނަގައެވެ، ނުކުތާ ނުކުތާއަށް އެއްކޮށް ނޫން. ޒިޕްކުރެވިފައި ހުރި IFC އަދި IFCX ފައިލްތައް މަރޖް ނުވޭ. މަރޖުގެ ފަހުން، ސޭވް ކުރުމުގެ ކުރިން BimCraft ގައި ހުޅުވާ Problems ޕެނަލް ބަލާށެވެ.
