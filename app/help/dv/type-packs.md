## ކުރާނެ ކަންތައް

ފާރު ޓައިޕްތައް ޕްރޮޖެކްޓަކުން އެހެން ޕްރޮޖެކްޓަކަށް ގެންދޭ، ނުވަތަ އެހެން ޕްރޮގްރާމެއްގައި މަސައްކަތް ކުރާ މީހަކަށް ދޭ. ޓައިޕް ޕެކެއްގައި ކޮންމެ ފާރު ޓައިޕެއް އޭގެ ލޭޔަރތައް، ތިކުތާތައް، މެޓީރިއަލްތައް، ކޯ، ކެވިޓީތައް، ލޭޔަރ ޕްރައިއޮރިޓީ، ލެވަލް އޮފް ޑެވެލޮޕްމަންޓް، ޓޭކްއޮފް ޑޭޓާ އަދި ކްލާސިފިކޭޝަން ކޯޑްތައް ހިމެނޭ، އަދި ތިބާ އިތުރުކުރާ ކޮންމެ ފެމިލީއެއް. އޭ އޯޕަން ފައިލެއް: ކޮންމެ މީހަކަށް ކިޔެވޭ ސާދާ JSON ޓެކްސްޓެއް، ނުވަތަ IFC ފައިލެއް. އޭގައި އެއްވެސް ފަރުމާއަކަށް، ޤައުމަކަށް ނުވަތަ އެކައުންޓަކަށް ލޮކްވެފައެއް ނޫން.

## ޕްރޮޖެކްޓުން ޓައިޕްތައް ރައްކާކުރުން

1. މޮޑެލް ބާރުގެ **ޑޭޓާ** ހުޅުވާ، ދެން {{ui:Type packs}} ޚިޔާރުކުރޭ.
2. {{ui:Save types from this project}} ދަށުން، ހިމެނޭ ފާރު ޓައިޕްތައް ޓިކްކުރޭ. ޕްރޮޖެކްޓުގެ އަމިއްލަ ޓައިޕްތައް ޓިކްކޮށް ހުރެއެވެ؛ ސްޓާޓަރ ޓައިޕެއް އިތުރުކުރެވޭ އަދި ކޮޕީއެއްގެ ގޮތުން ދާނެ. ފެމިލީތައް ހިމެނުމަށް ބޭނުންނަމަ ޓިކްކުރޭ.
3. **Pack name** ޓައިޕްކުރޭ.
4. {{ui:Save as a pack (.json)}} ޑައުންލޯޑުކުރާ `.cctypes.json` ފައިލެއް. {{ui:Save as IFC (.ifc)}} ޑައުންލޯޑުކުރާ ޓައިޕް ބަހައްޓާ IFC ފައިލެއް: ކޮންމެ ފާރު ޓައިޕެއް IfcWallType ގެ ގޮތުން، އޭގެ މެޓީރިއަލް ލޭޔަރ ސެޓާއި މެޓީރިއަލްތަކާއި ކްލާސިފިކޭޝަންއާއެކު، ކޮންމެ BIM ޕްރޮގްރާމަކަށް.

## ޓައިޕްތައް ޕްރޮޖެކްޓަށް އިތުރުކުރުން

1. އެ ޑައިލޮގްގައި {{ui:Open a pack or an IFC file…}} ޚިޔާރުކުރޭ، `.json` ޕެކެއް ނުވަތަ `.ifc` ފައިލެއް ޚިޔާރުކުރޭ.
2. ޑައިލޮގް ފައިލުގައި ހުރި ކަންތައް ދައްކާ: ކޮންމެ ފާރު ޓައިޕެއް އޭގެ ތިކުތާ، ލޭޔަރ ގިނަކަން، ކޯޑްތައް، މެޓީރިއަލްތަކާއި ފެމިލީތައް.
3. {{ui:A type this project already has}} އަށް ކުރާކަން ޚިޔާރުކުރޭ: **Keep the project's**، **Add the pack's as a copy** (އާ ނަމެއް "(2)" ން ނިމޭ)، ނުވަތަ **Replace it (only when no wall uses it)**.
4. {{ui:Add to the project}}. ޑައިލޮގް ދައްކާ ކޮންތައް އިތުރުވި، ކޮޕީވި، ބަދަލުވި ނުވަތަ ހިފެހެއްޓި. އޭ އެއް އަންޑޫ ސްޓެޕެކެވެ.

އާ ޓައިޕްތައް Wall ޓޫލްގެ ޓައިޕް ލިސްޓުގައި އެކަމަނާ ފެނޭ.

## ފްލޯރ، ރޫފް އަދި ސީލިންގ ޓައިޕްތައް

ސޭވް ކުރާ ޓައިޕްތަކުގެ ލިސްޓުގައި ޕްރޮޖެކްޓުގެ ފްލޯރ، ރޫފް އަދި ސީލިންގ ޓައިޕްތައް އަދި އެތަންތަނުގެ ސްޓާޓަރތައް (Floor، Roof، Ceiling ލިޔެފައި) ވެސް ހުރެއެވެ. ޕެކެއްގައި ހަތަރު ގޮތްތައް ހިމެނޭ؛ ކޮންމެ ޓައިޕެއް އޭގެ IFC ކްލާސް ދައްކާ (IfcWallType، IfcSlabType، IfcCoveringType). އެލިމެންޓްތައް ބޭނުން ކުރާ ފްލޯރ، ރޫފް ނުވަތަ ސީލިންގ ޓައިޕެއް ޕެކުން ބަދަލު ނުވޭ: އެ ޓައިޕް އެޑިޓަރުގައި ބަދަލު ކުރޭ.

## ޓައިޕެއް Library އައިޓަމެއްގެ ގޮތުން

ހަމަ އެއް ޓައިޕް ޓިކްކޮށް **Library އައިޓަމެއްގެ ގޮތުން ރައްކާކުރޭ…** ޚިޔާރުކުރޭ. އޭ `.cctype.json` ފައިލެއް ރައްކާ ކުރާ: Types ކިޔުމުގެ Library އައިޓަމެއް، އޭ ޓައިޕް އެކަނި (އޭގެ ލޭޔަރތައް، މެޓީރިއަލްތައް، LOD އަދި ކްލާސިފިކޭޝަން ކޯޑްތައް). ޝެއާކުރުމަށް Library ގައި އަޕްލޯޑުކުރޭ. **Open a pack or an IFC file** އިން އެފަދަ އައިޓަމެއް ވެސް ކިޔަވައި، އޭގެ ޓައިޕް ޕެކެއް ފަދައިން ޕްރޮޖެކްޓަށް އިތުރުކުރާ.

## ހިތުން ރަނގަޅު

- އެހެން ޕްރޮގްރާމުގެ IFC ފައިލެއް މިތާ ހުޅުވޭނެއެވެ. އޭގެ ފާރު ޓައިޕްތަކުން ކޮންމެ މެޓީރިއަލް ލޭޔަރ ހުރި އެއް ކިޔެވެ: ނަން، ލޭޔަރތަކުގެ މެޓީރިއަލްތައް އަދި ތިކުތާތައް އަދި ކޭވިޓީއެއް ފައިލުގެ އަމިއްލަ. ކޯ ކޮންތަކެއް ހެއްޔެވެ އަދި ކޮންމެ ލޭޔަރ ކޮންކަން (ފިނިޝް، ސްޓްރަކްޗަރ، އިންސުލޭޝަން) ފަހަތުން ގުނާ، ޓައިޕް **(guessed)** ލިޔެވޭ، އަދި ފާރު ޓައިޕް އެޑިޓަރުގައި ބަލާށެވެ. އެއްވެސް ލޭޔަރ ނެތް ފާރު ޓައިޕެއް ބާޠިލު ކޮށް ނަން ދެވެއެވެ.
- ޕްރޮޖެކްޓުގައި ކުރިން ހުންނަ މެޓީރިއަލް އޭގެ ގޮތުގައި ހުރެއެވެ. ނަން ހިންގިފައިވާ އާ މެޓީރިއަލަކަށް ނަމުގެ ފަހުން "(pack)" ލިބެއެވެ.
- ފާރުތައް ބޭނުން ކުރާ ޓައިޕެއް ކޮންމެވެސް ޕެކުން ބަދަލު ނުވޭ. ފާރު ޓައިޕް އެޑިޓަރުގައި ބަދަލު ކުރޭ، އޭ ފާރުތައް ރަނގަޅަށް ހަރަކާތް ކުރާ.
- ފާރަކަށް ސެޓްކުރި ކޯޑް ޕެކުން ނުދަނީ: އެ ފާރުގެ މުދަލެވެ. ޓައިޕަށް ސެޓްކުރި ކޯޑް ދާނެއެވެ.
- ފޯމެޓުގައި ނެތް ފީލްޑެއް، މެޓީރިއަލް ނެތް ލޭޔަރެއް، ނުވަތަ ސާދާ ޓެކްސްޓް ނޫން އެއްވެސް ކަމެއް ހުރި ފައިލް ރައްދުކުރެވޭ، އަދި މެސެޖް ކޮންތަނާއި ކީއްކަމަށްތޯ ބުނޭ.
- ހަދާފައެއް ނޫން: ފްލޯރ، ރޫފް އަދި ސީލިންގ ޓައިޕްތައް (މި ވާރޝަނުގައި އެމީހުންގެ ޓައިޕް ނެތް؛ ކޮންމެ އެއްގެ އަމިއްލަ ތިކުތާ)، ފެމިލީތަކަށް ބޭރު ދޮރާއި ކުޑަދޮރު ޓައިޕްތައް، އަދި އެހެން ޕްރޮގްރާމުގެ ފައިލުން ހޭޗާއި ރަން.
