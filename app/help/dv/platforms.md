BimCraft މިހާރުގެ ނުގަޑު ވާރޝަންތަކުގައި Chrome، Edge، Firefox އަދި Safari ގައި ރަން ކުރެވެއެވެ، Mac، Windows އަދި Linux ގައި. 3D ވިއުއަށް WebGL ބޭނުން، ކޮންމެ މިހާރު ބްރައުޒަރަކާ ކުރެވޭ. އެ އެޕްސް އާންމުކޮށް ބޭނުންކުރާ ދެ ކަންތައް [ބްރައުޒަރުތަކާއި ކޮމްޕިއުޓަރުތައް](common:browsers) ބަލާ.

## ފޯލްޑަރެއް ހުޅުވުން

| ބްރައުޒަރ | {{ui:Open a folder}} ކުރާ ކަން | ފޯލްޑަރެއް ދިމާކުރުން | {{ui:Recent folders}} |
|---|---|---|---|
| Chrome، Edge | ބްރައުޒަރުގެ ފޯލްޑަރ ޕިކާ، ދެން "Let site view files?": **View files** ކްލިކް ކުރޭ | ޕްރޮމްޕްޓެއް ނެތި ހުޅުވޭ | ހޯދާފައިވާ ނުވަތަ ދިމާކުރެވުނު ފޯލްޑަރުތަކަށް، ހަ |
| Firefox | ސިސްޓަމުގެ ފޯލްޑަރ ޗޫސާ | ޕްރޮމްޕްޓެއް ނެތި ހުޅުވޭ | ނޫން |
| Safari | ސިސްޓަމުގެ ފޯލްޑަރ ޗޫސާ، **Upload** ބަޓަނާއެކު (އެއްވެސް ކަމެއް އަޕްލޯޑް ނުވޭ) | ޕްރޮމްޕްޓެއް ނެތި ހުޅުވޭ | ނޫން |

ފަހަތުން: Chrome އަދި Edge ފަދައިން File System Access ޕިކަރ ބޭނުން ކުރެއެވެ އަދި ފޯލްޑަރ ހަނދާން ކުރެވެއެވެ. Firefox އަދި Safari ކުރިން ހުރި ފޯލްޑަރ ޗޫސަރ ބޭނުން ކުރެއެވެ، އެއީ ފޯލްޑަރުގެ ހުރިހާ ފައިލެއް އެއްފަހަރާ ދެއެވެ، އަދި ހަނދާން ނުކުރެވޭ. ދިމާކުރެވުނު ފޯލްޑަރ ކޮންމެ ބްރައުޒަރަކުން އެންޓްރީ އިން އެންޓްރީ ކިޔެވެ.

:::chromium
Brave އަދި އެހެން Chromium ބްރައުޒަރުތައް ފޯލްޑަރ ޕިކަރ ނުހިމެނޭ. ބޭހެ BimCraft ސިސްޓަމްގެ ފޯލްޑަރ ޗޫސަރ ބޭނުން ކުރެއެވެ، އަދި ބްރައުޒަރު "Upload *n* files to this site?" އަށް ސުވާލު ކުރެވޭ. އެއްވެސް ކަމެއް އަޕްލޯޑް ނުވޭ؛ ފައިލްތައް ޓެބަށް ނުވަތަ ދާ. ފޯލްޑަރ ދިމާކުރުން އެ ސުވާލު ދޫކުރެވޭ.
:::

## މެކް، ވިންޑޯސް އަދި ލިނަކްސް

- {{key:Mod+S}} އަދި {{key:Mod+Z}} ޝޯޓްކަޓްތައް Mac ގައި Command، Windows އަދި Linux ގައި Ctrl.
- {{key:Ctrl+Shift+F}} (ސްކްރީން މޯޑް) ކޮންޓްރޯލް ކޮންމެ ޕްލެޓްފޯމަކަށް، Mac ކަމަށްވެސް.
- ފައިލް ޑައިލޮގ އަދި ޑައުންލޯޑްސް ފޯލްޑަރ ތިބާގެ ސިސްޓަމުގެ އަމިއްލަ.

## މައުސް، ޓްރެކްޕެޑް އަދި ޓަޗް

| އިންޕުޓް | 3D ވިއު | 2D ޑްރޯއިން |
|---|---|---|
| މައުސް | ގޮތް ފައިސާ ފާނުން ކްލިކް ހުރި ފިރުން ހުރުން، ރައިޓް ފަރާތް ފަރާތުން ހުރުން، ސްކްރޯލް ކުރާ ފިރުން ކުރުން، ކްލިކް ހޮވޭ | އެއްވެސް ހުރުން ހޮވޭ، ސްކްރޯލް ކުރާ ފިރުން ކުރުން، ދެފަހަރު ކްލިކް ފިޓް |
| ޓްރެކްޕެޑް | ކްލިކް ހުރުން ކްރޯބިޓް؛ {{key:Shift}} ނުވަތަ {{key:Mod}} އާއެކު ހުރުން ކުރަން؛ ދެ ކިބާ ސްކްރޯލް ނުވަތަ ޕިންޗް ޒޫމް | ކްލިކް ހުރުން ކުރުން؛ ދެ ކިބާ ސްކްރޯލް ނުވަތަ ޕިންޗް ޒޫމް |
| ޓަޗް | އެއް ކިބާ ކްރޯބިޓް، ދެ ކިބާ ޕިންޗް އަދި ފަން، ޓެޕް ހޮވޭ | އެއް ކިބާ ފަން؛ ޕިންޗް ޒޫމް އަދި ނޫން؛ ޓެޕް {{ui:Fit}} |

Mac ޓްރެކްޕެޑުގައި، ރައިޓް-ކްލިކް ދެ ކިބާ ކްލިކް (ނުވަތަ Control-click). [Keys, mice and trackpads](common:keys) ބަލާ.

ޓެބްލެޓް އަދި ފޯންތައް ސިންގަލް ފައިލް ހުޅުވައި ބަލަން ކުރެވެ، ނަމަވެސް ސްކްރީން ކުޑަ، ގިނަ މޮބައިލް ބްރައުޒަރު ފޯލްޑަރ ނުލާނެ، އަދި ބޮޑު މޮޑެލްތައް އޭގެ މެމަރީއަށް ނުލާނެ. ކޮމްޕިއުޓަރ ވަރަށް ރަނގަޅު.

## ބޮޑު ފައިލް އަދި މެމަރީ

BimCraft ކިޔަވާ ހުރިހާ ކަމެއް ބްރައުޒަރ ޓެބުގެ މެމަރީގައި ހުންނާނެ. ޓެބް ކިހާ ގަނޑު ބޭނުން ކުރެވޭނެ ހެން ބްރައުޒަރާއި ކޮމްޕިއުޓަރުގެ މަތީން، BimCraft ގެ މަތީން ނޫން.

| ފައިލް | ކިހާ ކިޔަވާ | ކޮންކަން އުންމީދުކުރެވޭ |
|---|---|---|
| IFC | ފުރިހަމަ ފައިލް، އަދި އެކަމުން ހަދާ 3D ޖިއޮމެޓްރީ | ކޮމްޕިއުޓަރ އަދި ބްރައުޒަރ މަތީން ބޮޑު، ޑެސްކްޓޮޕް ކުޑަ ދުވާ މެހާ މެގަބައިޓް ގެ މޮޑެލް ލެޕްޓޮޕަށް ވަރަށް ބޮޑު. 1.5 މިލިއަން ތްރިކަނޑަށް ވުރެ ގިނަ ނަމަ ކޮމުގެ ދާރަ ކުޑަކުރެވެ |
| ޕްރޮޖެކްޓް އަދި ފެމިލީ ފައިލް | 40 KB އަށް 100 KB އަށް، ކިޔާ ކިހާވެސް | ވަރަށް ބޮޑު ސެންޓްރަލް މޮޑެލްތައް ވެސް ކުރެވޭ، ނެޓްވޯކް ޑްރައިވަށް ވެސް |
| DWG އަދި DXF | ފުރިހަމަ ފައިލް | ވަރަށް ބޮޑު ޑްރޯއިންގ "This drawing is very large; only part of it is shown." ދައްކާ |
| ފޯލްޑަރތައް | ފައިލް ލިސްޓް، އަދި ކޮންމެ މޮޑެލަކަށް ކޮޅުން ކިލޯބައިޓްތައް | 20,000 ފައިލް އަށް |

ބްރައުޒަރ މެމަރީ ހިއްލައިގެން ދިޔައިރު، ބްރައުޒަރުގެ އަމިއްލަ މެސެޖެއް ދައްކައެވެ ("Aw, Snap!" Chrome ގައި، މިސާލަކަށް). އެހެން ޓެބްތައް ބަންދު ކުރޭ، BimCraft ރީލޯޑް ކޮށް އެމަ ފަރުވާ ކުރޭ، ނުވަތަ ގިނަ މެމަރީ ހުންނާ ކޮމްޕިއުޓަރއެއް ބޭނުން ކުރޭ.
