## ކުރާނެ ކަންތައް

ރަންތައް އިކުއިޕްމަންޓާ ގުޅާ، ފަހުން މޮޑެލް އެއް ގުޅުނު ސިސްޓަމެއްކަމުން ވާނެއްޔޭ: ޕަމްޕެއްގެ އައުޓްލެޓް އެތަނުން ނިކުމޭ ޕައިޕަށް، ޑިފިއުޒަރެއްގެ ނެކް އޭގެ ބްރާންޗް ޑަކްޓަށް. ދެން BimCraft ދަނީ އެއް ގުޅާ ނުވާ ކަންތައް ލިސްޓް ކުރޭ.

## ޕޯޓުން ޑްރޯ ކުރޭ

1. {{ui:Pipe}} ނުވަތަ {{ui:Duct}} ހޮވާ.
2. ހެންދަނޑު ޕޯޓުގެ މަތީ ގޮތަށް ގެންދާ (ކުޑަ ދައިރާތައް؛ ހުޅުވިފައި ހުރި ޕޯޓް އާންމަ ރަނގެއް ކަލަރުން ޑްރޯ ކުރެވެއެވެ). ހެންދަނޑު އޭގެ ކިޑަށް ކޮކް ވެ **ޕޯޓުގައި** ވަނީ ވާ ބުނެ.
3. ކްލިކް: ރަން ޕޯޓުގެ އުސްމިނުން ފަށައިގެން **ސައިޒާއި ސިސްޓަމް ހިއްސާކުރާ** (ޕައިޕް ސިސްޓަމުގެ ހިސާބު މެޓީރިއަލް ކަމުގައި). ސްޓޭޓަސް ލައިން ހިއްސާކުރުންކަން ބަޔާން ކުރޭ.
4. ކުރިއަށް އާދެ ސަރކަލޭޝަން ކުރޭ. ރަން އެހެން ޕޯޓަކަށް ނިންމާ ކުރުން އެ ފަރާތުވެސް ފިކްސް ކުރޭ.

ރަނެއްގެ ކުނި ޕޯޓުގައި **ފިކްސްޑް** ކަމުން: އިކުއިޕްމަންޓް މަތީ ހުއްދަ (Properties ގައި) މައްޗަށް ހިންގާ ނުވަތަ ފެރިގައި ފެންނާ؛ ރަނގެ ފަރާތް އެކަމާއެކު ދާނެ. ރަނގެ އެހެން ކުރީ ތަންތަނުން ހިނގާ ނުވާ. ބޮޑު ހިއްލާއަކަށްފަހު ފުރަތަމަ ފަރާތް ޕޯޓުން އަނެއްކާ ކޮނޑޭނެ: ކުރެއްވުން ކުރިއަށް ފުރަތަމަ ކުރިއަށް ކުރޭ.

## ކަނެކްޝަން ބަލާ

{{ui:Build}} ހުޅުވާ {{ui:Check connections}} ކްލިކް ކުރޭ. ޕާތީގެ ދަށުގައި ލިސްޓް ދައްކާ:

| ލައިން | މާނައަކީ |
|---|---|
| ޕޯޓެއް ކަނެކްޓްވެފައި ނެތް | އިކުއިޕްމަންޓެއްގައި ކަނެކްޝަނެއް ހުންނަ އެއްވެސް ކަމަކާ ހިސާބެއް ނެތް |
| އޭގެ ކޮނޑުގައި އެއްވެސް ކަމެއް ނެތް | ރަނެއް ހަވާގައި ނިމޭ |
| ހަމަވި ޕޯޓްތައް އަސަރު ދުރަށް ކަނަރު ނޫން | ތަންތާއިން ހުންނަ ސައިޒެއް ރަނެއް އެހެން ސައިޒަކަށް (ރެޑިއުސާ ނެތް) ސުންނަ (ޕައިޕެއްގެ ނޮމިނަލް ސައިޒް، ޑަކްޓެއްގެ ޝޭޕް އަދި ފަރާތް) |
| ހަމަވި ޕޯޓްތައް ދެންނެ ސިސްޓަމް ނޫން | މިސާލަކަށް ސަޕްލައި ޑިފިއުޒަރެއްގެ ރިޓާން ޑަކްޓް |
| ޕައިޕް ޑަކްޓަށް ގުޅެފައި | ކަނެކްޝަންތަކުގެ ދެ ބަޔެއް ތަފާތު ގޮތުން އިޢުތިރާފު ވޭ |
| އޭގެ ނެޓްވޯކުގައި ކަމަކަށް ސަޕްލައި ކޮށްދޭ އިކުއިޕްމަންޓެއް ނެތް | ރަނެއް ގުޅާ ކޮންމެ ކަމެއް، ދުރުވެސް، އައުޓްލެޓެއް ނެތް. ޑްރޭންސް، ސްޓޯމް އަދި ވެންޓްސް މި ސުވާލު ނުކުރެވޭ: އެމީހުންގެ ފެން ފިކްސްޗަރުންނެވެ |
| ބޮޑު ހަމަވި ޕޯޓަކީ މޮޑެލްގައި ކުރިން އެކަމެއް ނެތް އިކުއިޕްމަންޓު | އިކުއިޕްމަންޓް ޑިލީޓް ކުރެވިފައި؛ ދެން ކުރެއްވަ ރަން ނުވަތަ ރަން ޑިލީޓް ކުރޭ |

ގަދަ ގޮތްތައް ފުރަތަމަ ފެންނާނެ. ލައިނެއް ކްލިކް ކުރާ ކުރެއްވާ ކަން ހޮވާ. {{ui:Close}} ލިސްޓް ފޮހެލާ. ޗެކް ކުރާ މޮޑެލް ކުރުމުގެ ގޮތުން ކުރެއްވޭ: ކަނެކްޝަން އަދި ސައިޒް ބަލާ، ފްލޯ، ޕްރެޝަރ ނުވަތަ ބެލެންސިން ނުބަލާ.
