BimCraft މިހާރު ފައިލް ކިޔުންކުރާ، ހޯދާ އަދި IFC ޑޭޓާ އެޑިޓް ކުރާ ޕްރޮގްރާމެކެވެ، އަދި ބިލްޑިންގ ނަގާ ފަށާފައި ވާ: ފާރުތައް، ދޮރުތަކާއި ކުޑަދޮރުތައް، ރޫމްތައް، ފްލޯރުތައް، ސީލިންގތައް އަދި ފުރާޅުތައް (see [ފާރު ޑްރޯ ކުރޭ](topic:draw-walls), [ދޮރުތަކާއި ކުޑަދޮރުތައް](topic:doors-and-windows) އަދި [ރޫމްތައް، ފްލޯރުތައް، ސީލިންގތައް އަދި ފުރާޅުތައް](topic:floors-and-roofs)). މިއީ އެކަން ނުކުރާ ކަންތަކުގެ ޞާދިޤު ލިސްޓް، އަދި މިހާރު ބޭނުން ކުރެވޭ ކަންތައް.

## Modeling and authoring

| އަދި ނެތް | މިހާރު ބޭނުން ކުރެވޭ |
|---|---|
| ބީމް ޑްރޯ ކުރުން؛ ސްޓީލް ސެކްޝަންތަކުގެ ތަނބު | ތިޔަ އޮތޯރިންގ ޕްރޮގްރާމް ބޭނުން ކުރޭ، ދެން އޭގެ IFC އެކްސްޕޯޓް މިތަނުގައި ހުޅުވާ. ރެކްޓެންގިއުލަރ އަދި ރައުންޑް ތަނބުތައް މިތަނުގައި ބަހައްޓާވޭ (see [ގްރިޑްސް އަދި ތަނބުތައް](topic:grids-and-columns)); ސްޓްރެއިޓް، L، U، ވައިންޑަރ އަދި ސްޕައިރަލް ސްޓޭރކޭސް އަދި ރެއިލިންގ މިތަނުގައި ޑްރޯ ކުރެވޭ (see [ސްޓޭރކޭސް އަދި ރެއިލިންގ](topic:stairs-and-railings)) |
| ޑޯމަރެއްގެ ފަހަރުގައި ކުޑަދޮރެއް؛ ފުރާޅު ޕްލޭނުގައި ޑޯމަރު އެއް އަތުން ޑްރޯ ކުރެވުނު ޑޯމަރު؛ ކާރުކަނޑު ފުރާޅު؛ ރަނގަޅުކުރެވުނު ފުރާޅުގެ ޓެކްސްޗަރ | ފުރާޅުގެ ޕްލޭނުގެ ކަންތައް އަތުން ޑްރޯ ކުރެވޭ، އަދި ކޮންމެ ފާރަކަށް ޕިޗް: see [ފުރާޅުތައް: ކޮންމެ ފާރަކަށް ޕިޗް، ގޭބަލްތައް، ޝެޑްތައް އަދި ފުރާޅު ޕްލޭނުތައް](topic:roofs) |
| ބަދަލުކުރުން ކުރެވުނު ފާރު، ދޮރު ނުވަތަ ކުޑަދޮރު އެހެން ޕްރޮގްރާމެއް ކުރެވުނު ކަމެއް | ތިޔަ އޮތޯރިންގ ޕްރޮގްރާމް؛ ޑްރޯ ޓޫލުތައް ކުރެވުނު ކަންތައް ބަދަލުކުރޭ |
| ފާރުގެ ޕްރޮފައިލް ކޮނާކޮޅާއި ހުސްކުރުން؛ ފާރުގެ ހުސްތައް ރެކްޓެންގަލް ނޫން؛ 3D ގައި ފާރުގެ ޕްރޮފައިލް ޕޮއިންޓް އިތުރު ކުރުން ނުވަތަ ނަގާލުން | ޕްރޮފައިލް، ޖޮއިން، ސްލޭންޓާއި ހުސްތައް ޕްރޮޕަޓީޒް، އެލެވޭޝަންތަކާއި ސެކްޝަންތަކުގައި، ފާރުގެ ފެނުން ޕަތުން އަދި 3D ގައި ގްރިޕްސްތަކުން ކުރެވޭ، ސްޓްރެއިޓް އަދި ކާރުކަނޑު ފާރުތަކަށް: see [ފާރުގެ ޝޭޕް: އެޓޭޗް، ޕްރޮފައިލް، ސްލޭންޓް އަދި ހުސްތައް](topic:wall-shape) |
| ކާރުކަނޑު ފާރުތަކުގައި: {{ui:ކަނޑާ / ދިގުކުރޭ}} އަދި {{ui:ކޮނި}}، ފްރޭމިންގ، އޮޓޯމެޓިކް ޕްލޭން ޑައިމެންޝަން، އާކް ޖެހި ސްނެޕިންގ (އޭގެ ކޮޅުތަކާއި އާކުގެ މެދު ނުކުތާ) | ސްޓްރެއިޓް ފާރު ޑްރޯ ކުރޭ، ނުވަތަ ސްޓްރެއިޓް ސެގްމަންޓް ބޭނުން ކުރޭ. ކާރުކަނޑު ފާރުތައް [ފާރު ޑްރޯ ކުރޭ](topic:draw-walls) ގައި އެވޭ |
| 3D ގައި ބެހެއްޓި ލައިބްރަރީ އެއްޗެއް ދިމާކުރުން | ޕްލޭނުގައި ދިމާކުރޭ، ނުވަތަ {{ui:ޚާސިއްޔަތުތައް}} ގައި X، Y އަދި Rotation ޓައިޕް ކުރޭ: see [ލައިބްރަރީން ސާމާނު އަދި ފަރުނީޗަރު ބަހައްޓާ](topic:place-from-library) |
| CivilCraft ގެ Landscape ވޯކްސްޕޭސްގެ ނަސާރީ ލައިބްރަރީން ކިޔާ ނަސަލު ބަހައްޓާ | CivilCraft ގައި ނަސަލު ބަހައްޓާ، ނުވަތަ ލައިބްރަރީގެ entourage އިން ގަސް އަދި ގަހަށް ބަހައްޓާ: see [ލައިބްރަރީން ސާމާނު އަދި ފަރުނީޗަރު ބަހައްޓާ](topic:place-from-library) |
| Plant އެޑް-އޮން ގައި (އޮފް ކުރެވިފައި ހުންނަ، އޮން ކުރާ ހިސާބު): ރޫޓް ކުރެވުނު ރަން މޮޑެލަށް ޑްރޯ ކުރުން، ސްޕޫލް ނަމަރު އަލަށް އައިސޮމެޓްރިކްސްގައި، ލައިބްރަރީން ބަހައްޓާފައި ހުންނަ ސާމާނުގެ ލޭއައުޓް ޗެކް | ރަން ޑްރޯ ކުރޭ {{ui:ޕައިޕު}} އިން (see [ޕައިޕު އަދި ޑަކްޓް](topic:pipes-and-ducts)); ލޭއައުޓް ޗެކް އޭޑް-އޮނުގެ އަމިއްލަ ސާމާނު ޓޭބަލް ކިޔަވޭ |
| ފުރާވާ ވާޑާކުންނަށްވާ ފިޓިންގ، ވާލްވް އަދި ސާމާނު (ކެޕޭސިޓީ، ބަރު، މޭކަރުންގެ ކަނެކްޝަން ސައިޒް)؛ ASME B16.9 ޓީ އަދި ރިޑިއުސަރ ދިގުތައް ސްޓީލް ސްޕޫލްތަކުގައި؛ ފިޓިންގް ދެކޮޅު ފުނިހާ ނުވަތަ އަވަސް؛ ސްޕްރިންކްލާ؛ ކޭބަލް ޓްރޭ؛ ސްޓޭކްތައް ފިކްސާ އޮޕްޝަން މަނާ ކުރުން؛ ރަންތަކަށް ހަދާ ތަނަށް ކެޓް ކުރުން؛ ފިޓިންގާ ވޭޓް؛ ޑަކްޓް ސީމް، ގޭޖް އަދި ކަނެކްޓަރ | ޖެނެރިކް ސްޓޭންޑަރޑް ފިޓިންގ، ސިސްޓަމް، ޕްލޭން، ސްކެޖުލް އަދި ޓޭކް އޮފް ހަދާފައިވާ ޕައިޕު އަދި ޑަކްޓް ރަންތައް މިތަނުގައި ޑްރޯ ކުރެވޭ: see [ޕައިޕު އަދި ޑަކްޓް](topic:pipes-and-ducts). ޕޯޓްސް ހުރި ޖެނެރިކް އުޞޫލު ސާމާނު، ކަނެކްޓް ކުރެވުނު ރަންތަކާއި Connections ޗެކް: [ޕޯޓްސްއާ MEP ސާމާނު](topic:mep-equipment)، [ޕައިޕު އަދި ޑަކްޓް ސާމާނަށް ކަނެކްޓް ކުރޭ](topic:mep-connections). ކްލޭޝް ސެޓްތައް، ކްލިއަރަންސް އަދި އޯޕެނިންގ ލިސްޓް: [ޕައިޕު އަދި ޑަކްޓް ސްޓްރަކްޗަރާ ދިމާ ޗެކްކުރޭ](topic:mep-against-structure). ސްޓީލް ސްޕޫލް އަދި ޝީޓް، ޑަކްޓް ކަޓް ލިސްޓް: [ސްޓީލް ޕައިޕު ސްޕޫލް އަދި ސްޕޫލް ޝީޓް](topic:pipe-spools). މޭކަރުންގެ އައިޓަމްތައް ތިޔަ MEP ޕްރޮގްރާމުން IFC ގެ ގޮތުން ގެންނަވާ |
| ޑިޒައިން ކޯޑް ޗެކް: ވެލްޑެޑް އައި ޝޭޕްސް، އައި ޝޭޕްސް ކޮންމެ IFC ޕްރޮފައިލް ނުވަތަ ރޮލްޑް W، S، IPE، HEA ނުވަތަ HEB ސައިޒަކަށް ނުނަންގާ؛ ޓިއުބް، އެންގަލް އަދި ޗެނަލް (ހުރިކަން ނުވަތަ ނުޗެކް ކުރެވޭ)؛ ބަކްލިންގ ނުވަތަ ޑައިނަމިކް ރެސްޕޯންސް (ނޭޗަރަލް ފްރީކްވެންސީ ފިނީ ފައިނައިޓް އެލިމަންޓް ބްލޮކުގައި)؛ ފާރުތަކާއި ސްލެބްތައް އެނާލިސިސްގައި؛ ފަރުތަކާއި ސަރުފޭސްތަކަށް ލޯޑުތައް | {{ui:އެނަލިސިސް}} ޓެބް ބީމުތައް، ތަނބުތަކާއި ބްރޭސްތަކުގެ ފޯސްތަކާއި ރިއެކްޝަންތަކާއި ޑިފްލެކްޝަންތައް ފާޑް-އޯޑަރ އެނާލިސިސްން ދެނީ، ރޯލްޑް އައި ޝޭޕްތައް ޗެކް ކުރެވޭ، އިންޖިނިއަރެއް ރިވިއު ނުކުރާ ހިސާބަށް އެއްކުމަށް: see [ފްރޭމް އެނަލައިޒް ކުރޭ](topic:frame-analysis#design-checks) |
