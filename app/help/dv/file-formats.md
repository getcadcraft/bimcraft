## IFC

| ކިޔަވާ | ތަފްޞީލް |
|---|---|
| ޖިއޮމެޓްރީ | ޝޭޕެއް ހުރި ހުރިހާ އެލިމެންޓެއް، ފައިލް ދޭ ކުލައިން ރަނގަޅު ކޮށް. ރޫމްތަކާއި ސްޕޭސްތައް ފެނޭ ގޮތަށް (see-through) ޑްރޯ ކުރެވޭ، އަދި ފުރަތަމަ ފޮރުވިފައި |
| ސްޓޯރީތައް | ބިމުން އުސްމިނުގެ ތަރުތީބުން ބިލްޑިންގ ސްޓޯރީތައް، އަދި ކޮން އެލިމެންޓް ކޮން ސްޓޯރީގައި. ސްޓޯރީއެއްގައި ނުވާ އެލިމެންޓްތައް "Not on a storey" އަށް ގްރޫޕްކުރެވެއެވެ |
| އެލިމެންޓް ގިނަކަން | ކޮންމެ ބާވަތުގެ އެލިމެންޓް ކިތަން (ފާރު، ދޮރު، ސްލެބް…)، {{ui:Elements}} ގައި ދައްކާ |
| ޕްރޮޖެކްޓް ތަފާސީލް | ޕްރޮޖެކްޓްގެ ނަން، ދިގު ނަން އަދި ފޭޒް؛ ސްކީމާ؛ ފައިލް ހެޑަރުން އެކްސްޕޯޓް ކުރި ޕްރޮގްރާމް، ލިޔުނީ، އަދި އެކްސްޕޯޓް ތާރީޚު |
| އެލިމެންޓް ޑޭޓާ | ނަން، ޓައިޕް، އޮބްޖެކްޓް ޓައިޕް، ޓެގް، ތަފާސީލް، GlobalId؛ އެލިމެންޓުގައި އަދި އޭގެ ޓައިޕުގައި ހުރި ހުރިހާ ޕްރޮޕަޓީ ސެޓް އަދި ކުއާންޓިޓީ ސެޓް |

ބަދަލުކުރެވޭ: ނަން، އޮބްޖެކްޓް ޓައިޕް، ޓެގް، ތަފާސީލް، އަދި ސިންގަލް ޕްރޮޕަޓީ އަގުތައް. އާ IFC ފައިލަކަށް ރައްކާ ކުރެވޭ. IFC2X3، IFC4 އަދި IFC4X3 ސްކީމާތައް ހުޅުވޭ، ބަދަލުގައި BimCraft ގެ އަމިއްލަ IFC އިންޖިން ކިޔަވައި؛ ހަދަން ނެތް ކޮންމެ ކަމެއް {{ui:File}} ޕެނަލްގައި **Not drawn yet** ގައި ލިސްޓުވޭ. މޮޑެލް ހުޅުވުމުން މަރުކަޒަށް ރަވާނާ ކުރެވޭ، އެހެންނަމަ ދުރުގައި ހުންނަ މޮޑެލް ސްކްރީނުގެ މެދުގައި ފެންނާނެ. `.ifczip` އާއި `.ifcxml` ހުޅުވޭ ނޫން.

## ޕްރޮޖެކްޓް އަދި ފެމިލީ ފައިލްތައް

`.rvt` ޕްރޮޖެކްޓްތައް، `.rte` ޕްރޮޖެކްޓް ޓެމްޕްލޭޓްތައް، `.rfa` ފެމިލީތައް އަދި `.rft` ފެމިލީ ޓެމްޕްލޭޓްތައް.

| ކިޔަވާ | ތަފްޞީލް |
|---|---|
| ފައިލް ތަފާސީލް | ރިލީޒް އަދި ބިލްޑް، ވޯކްޝެއަރިންގ، ސެންޓްރަލް މޮޑެލްގެ ފަތު، ފަހުން ރައްކާ ކުރި ފަތު، ޔޫޒަރ ނަން، ލޮކޭލް، ޑޮކިއުމަންޓް GUID |
| ޕްރޮޖެކްޓް ތަފާސީލް | ޕްރޮޖެކްޓްގެ އަމިއްލަ ފީލްޑްތައް (ނަން، ނަންބަރު، ކްލައިންޓް، އެޑްރެސް، ސްޓޭޓަސް…)، އާ ޕްރޮޖެކްޓްގެ ޑިފޯލްޓް ނެތި |
| ފެމިލީ ތަފާސީލް | ފެމިލީ ނަން، ކެޓެގަރީ، ރިލީޒް، ފަހުގެ އަޕްޑޭޓް، އަދި އޭގެ ޕެރަމީޓަރުތައް ގްރޫޕުން |
| ލިންކްތައް | ފައިލް ފަރާތް ކުރާ ލިންކްތަކުގެ މޮޑެލްތައް، CAD ލިންކްތައް، ފޮޓޯތައް އަދި ކީނޯޓް ޓޭބަލްތައް ލިސްޓު |
| ޕްރިވިއު ފޮޓޯ | ފައިލުގައި ރައްކާ ކުރާ ތަމްބްނެއިލް |

ކިޔެވޭ ނޫން: 3D މޮޑެލް، އެލިމެންޓްތައް، ވިއުތައް، ޝީޓްތައް އަދި ޝެޑިއުލްތައް. އެ ތަކެތި ލިޔެވިފައި ނެތް ފޯމެޓެއްގައި ރައްކާވެފައި. BimCraft ކޮންމެ ފައިލަކުން ކިލޯބައިޓް ދިހަތަކެތި ކިޔަވާ، އެހެންކަމުން ފައިލް ސައިޒް ވަރަށް ބޮޑު ކަމެއް ނޫން.

## .pln، .pla، .tpl އަދި .bpn ޕްރޮޖެކްޓް ފައިލްތައް

ތަން ނުކިޔެވޭ: BimCraft ހުޅުވާއިރު އެ ކަން ދައްކައެވެ. މޮޑެލަށް IFC އަދި ޑްރޯއިންގުތަކަށް DWG އެކްސްޕޯޓް ކުރޭ؛ [ޕްރޮޖެކްޓް ފައިލް .pln އަދި .pla ހުޅުވާ](topic:pln-project-files) ބަލާ.

## DWG އަދި DXF

| ކިޔަވާ | ތަފްޞީލް |
|---|---|
| ސްޕޭސްތައް | މޮޑެލް ސްޕޭސް އަދި ހުރިހާ ޝީޓް (ލޭއައުޓް)، ޓެބުގެ ތަރުތީބުން |
| ވިއުޕޯޓްތައް | ކޮންމެ ޝީޓުގެ ވިއުޕޯޓްތައް، އެ ސްކޭލާއި ޓްވިސްޓާއި ފްރީޒްޑް ލޭޔަރުތަކާއެކު |
| ލޭޔަރުތައް | ނަން، ކުލަ، އޮން/އޮފް، ފްރީޒްޑް، ޕްލޮޓް ފްލެގް އަދި ރޮނގުގެ ވަރު |
| އޮބްޖެކްޓްތައް | ރޮނގުތައް، ޕޮލިލައިންތައް، އާކްތައް، ވަށްތައް، އެލިޕްސްތައް، ސްޕްލައިންތައް، ހެޗްތަކާއި ސޮލިޑްތައް، ލިޔުމާއި މަލްޓިލައިން ލިޔުން، ބްލޮކްތަކާއި އެޓްރިބިއުޓްތައް، ޑައިމެންޝަންތައް، ލީޑާތަކާއި މަލްޓިލީޑާތައް، ޓޭބަލްތައް، ނުކުތާތައް، އިމޭޖްތައް |
| ލިންކްކުރެވުނު ޑްރޯއިންގުތައް | އިންސާޓް ކުރެވޭ ތަނުގައި ޑްރޯ ކުރެވޭ، ފައިލްތައް ފެނިފައިވާ ހިނދު |
| ފޮޓޯތައް | ފޮޓޯ ފައިލްތައް ފެނުނު ހިނދު ޑްރޯ ކުރެވޭ (PNG، JPEG، GIF، BMP، WebP؛ TIFF ނޫން) |
| އިކުއިޕްމަންޓް ޓެގްތައް | ފޫޑްސަރވިސް އައިޓަމް ޓެގްތައް (`KCL-ITEM` އެޓްރިބިއުޓްތައް)، އިކުއިޕްމަންޓް ޝެޑިއުލަށް |

އެހެން ކޮންމެ ކަމެއް **Not drawn yet** ގައި ގިނަވޭ، ޝަކުރުން ނުގަނޑައަޅާ. DWG ފޯމެޓްތައް AutoCAD 2000 އިން 2018 އަށް ޗެކް ކުރެވިފައި (R13 އަދި R14 ފައިލްތައް ޤަބޫލު ކުރެވޭ، ނަމަވެސް ޓެސްޓް ސެޓުގައި އެއްވެސް ފައިލެއް ނެތް؛ ހަނދު DWG ހުޅުވޭ ނޫން). {{ui:Drawing}} ޕެނަލް ފޯމެޓް ކޯޑް ދައްކައެވެ (މިސާލަކަށް AC1032). DXF ފައިލްތައް ކޮންމެ ވާރޝަނެއް ހުޅުވޭ، R12 ހިމެނެ. ދެ ފޯމެޓް ހުރިހާ ކުރާ BimCraft ގެ އަމިއްލަ ރީޑަރުންނެވެ، މި ޓެބުގައި. DWG ނުވަތަ DXF އަށް އެއްވެސް ކަމެއް ފަހަތަށް ރައްކާ ނުވެއެވެ.
