Studio ގައި Engine ލިސްޓަށް Unreal Engine ޕްރޮޖެކްޓަކަށް **ލިންކެއް** ހިމެނިދާނެއެވެ. އެއް މަގެއްވެސް: CadCraft އިން Unreal ގެ ފަރާތަށެވެ، އެއިން ފަހަތަށް ނޫނެވެ.

## ސީން ފޮނުވުން

1. Engine ލިސްޓުގައި Unreal އެންޓްރީ ހޮވާ. ފުރަތަމަ ފަހަރަށް Studio ކުރާ ރިކުއެސްޓް: ޕްރޮޖެކްޓުގެ ފޯލްޑަރ (`.uproject` ފައިލް ހުންނަ) ހޮވާ؛ އެ ފޯލްޑަރ Studio ހިފައެވެ.
2. {{ui:ފޮނުވާ}} ކްލިކްކުރޭ. Studio ޕްރޮޖެކްޓުގެ ތެރޭގައި `CadCraft/<file name>/` ލިޔައެވެ: ސީން USD ފައިލަކަށް، ސެޓިންގްސް ފައިލް، ލައިޓް ޕްރޮފައިލްތައް، އަދި ދެ ކުޑަ ލޭޔަރ ފައިލް.
3. މޮޑެލް ބަދަލުކޮށް، ސޭވްކޮށް އަލުން ފޮނުވާ. ހަމައެކަނި ސީން އަދި ސެޓިންގްސް ފައިލް އަލުން ލިޔެވެއެވެ.

## ތިބާގެ އަމިއްލަ އެޑިޓްތައް ރައްކާތެރި

Unreal ހުޅުވާ ސްޓޭޖް އެއް ފަހަރު ހަދާ ރޫޓް ލޭޔަރެއް، އޭގެ ދަށުގައި ދެ ލޭޔަރު: މަތީގައި **ތިބާގެ** (`<name>.user.usda`، ފުރަތަމަ ހުސް، CadCraft ދުވަހަކުވެސް ނުލިޔޭ)، އަދި ދަށުގައި CadCraft ގެ ސީން. ތިބާގެ ލޭޔަރަށް ސޭވްކުރާ އެޑިޓްތައް ސީން އަލުން ފޮނުވާއިރުވެސް ހުރެއެވެ. ތިބާ Unreal ލެވެލުގައި ބަހައްޓާ ލައިޓްތަކާއި އެހެން އެކްޓަރުން ސްޓޭޖުން ބޭރުގައި ވާތީ އެތަކެއް ވެސް ނުބަލެއެވެ.

## Studio ނެތި

ބްރައުޒަރުގައި، ނުވަތަ Studio ން Unreal ނުފެނޭ ކޮމްޕިއުޓަރުގައި، Engine ލިސްޓުގައި **Unreal project folder (.zip)** ހޮވާ {{ui:ރެންޑަރ}} ކްލިކްކުރޭ. ހަމަ ފޯލްޑަރ zip ގެ ގޮތުގައި ސޭވްކުރެއެވެ: ތިބާގެ ޕްރޮޖެކްޓުގެ `CadCraft` ފޯލްޑަރަށް އުނގުޅާ. **ސްޓޭޖް ފައިލްތައް ހިއްސާ ކުރޭ** ފުރަތަމަ ފަހަރަށް ހިފާ ހުރޭ؛ ފަހު ސޭވްތަކަށް ނުހިފާ ހުރުން، ފަހެ zip ގައި ހުންނާނީ ސީން އަދި ސެޓިންގްސް ފައިލް ކޮންމެހެން، އަދި ތިބާގެ އަމިއްލަ ލޭޔަރު ދުވަހަކުވެސް ބަދަލު ނުވެ.

:::note
ސްޓޭޖް ހުޅުވާ، ސަން، ލޭމްޕް، ކެމެރާ އަދި އެކްސްޕޯޒަރ އެޕްލައިކުރާ، ކޮންމެ ފޮނުވުމަށް ފަހުން ދާ، އަދި ކެމެރާއަކު ރެންޑަރ ކުރާ Unreal ޕްލަގ-އިން **އަދި ނުނިކުތީއެވެ**. ނިކުމާ ހަމައަށް Send ފައިލްތައް ޕްރޮޖެކްޓަށް ދާ، އަދި Unreal ގެ އަމިއްލަ USD ޓޫލްތަކުން އެ ފައިލްތައް ހުޅުވޭ ކުރެވޭ. Unreal ގައި އަދި ރަން ކުރެވިފައެއް ނެތެވެ. Windows ފުރަތަމަ ސިސްޓަމެވެ؛ macOS ފަހުން އެވެ.
