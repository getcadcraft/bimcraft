## ކުރާނެ ކަންތައް

ބިއްލިންގ އުފުލޭ ގޮތް ބަލާ: ޝެޑިއުލްގެ ކޮންމެ ޓާސްކެއް އެ ޓާސްކް ބިނާކުރާ އެލެމަންޓްތަކާ ގުޅިފައި، ދުވަހުން ދުވަހަށް ދައްކާ.

## ގޮތްތައް

1. IFC މޮޑެލެއް ހުޅުވައި، ކަނޑު ފަރާތުގެ ޕެނަލުގައި {{ui:4D ޝެޑިއުލް}} ހުޅުވާ.
2. ކޮންމެ ބުރިއަކަށް ހަފްތާއަކު ހުންނަ ޓާސްކް ލިސްޓަކަށް {{ui:ޓެމްޕްލޭޓެއް ޑައުންލޯޑުކުރޭ}} ކްލިކްކުރޭ، އަދި ސްޕްރެޑްޝީޓުގައި ބަދަލުކުރޭ. ނުވަތަ އަމިއްލައަށް ލިޔޭ.
3. {{ui:ޓާސްކް ލިސްޓެއް ހުޅުވާ…}} ކްލިކްކުރޭ، އަދި CSV ޚިޔާރުކުރޭ.
4. ތާރީޚުގެ ސްލައިޑަރ ދަބާ، ނުވަތަ {{ui:ޕްލޭ}} ކްލިކްކުރޭ.

## ޓާސްކް ލިސްޓް

ހެޑަރ ރޯއާއި **Task**، **Start**، **Finish**، **Field** އަދި **Value** ކޮލަމްތައް ހުންނަ CSV ފައިލެކެވެ. ކޮމާ ނުވަތަ semicolon ދެވަރުވެސް މަސައްކަތް ކުރޭ.

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| Level 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| Roof | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| Roof | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- ތާރީޚުތައް YYYY-MM-DD ގޮތުގައި ލިޔޭ.
- ރޯއެއް ޓާސްކް އެއް **Field** ގެ އަގު **Value** ގެ އަގާ ހަމަވާ ކޮންމެ އެލެމަންޓަކާ ގުޅާނެއެވެ. **Field** އަކީ Storey، Class، Name، Type، Material، Tag ނުވަތަ GlobalId ފަދަ ޕްރޮޕަޓީއެއް، ނުވަތަ `Pset_WallCommon.FireRating` ފަދައިން set އަދި name އިން ލިޔެވޭ ޕްރޮޕަޓީއެއް.
- އެއް ޓާސްކަކަށް ގިނަ އެލެމަންޓް ގުޅުމަށް، އެ ޓާސްކް އެއް ތާރީޚުތަކާއެކު ގިނަ ރޯތަކުގައި ލިޔޭ.

## ސްޓޭޖްތައް އަދި ވަޒީފާ ޕެކޭޖްތައް

ޓާސްކްތައް ސްޓޭޖްތަކާއި ވަޒީފާ ޕެކޭޖްތަކަކަށް ގުޅުމަށް **Stage** ކޮލަމް، **Package** ކޮލަމް، ނުވަތަ ދެވަރުވެސް އިތުރުކުރޭ. Phase އަދި WBS ވެސް ކޮލަމް ނަމެއްގެ ގޮތުގައި މަސައްކަތް ކުރޭ.

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| Level 1 slab | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| Level 1 walls | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| Doors | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- ޓާސްކެއް އެއް ސްޓޭޖަކާއި އެއް ޕެކޭޖަކާ ހަމައަށް ގުޅެއެވެ. އެ ޓާސްކްގެ ފަހު ރޯއެއްގައި އެހެން ނަމެއް ލިޔެވިއްޖެނަމަ، އެ ރޯ އޭގެ ލައިން ނަންބަރާއެކު ލިސްޓުކޮށް ބާވައިލެވޭނެއެވެ.
- ދެ ސްޓޭޖެއްގައި އެއް ފެކޭޖް ނަމެވެ ދެ ޕެކޭޖެކެވެ.

ލިސްޓުގައި ގްރޫޕްތައް ހުންނަ ވަގުތު، ތާރީޚުގެ މައްޗަށް {{ui:ފެންނަވާ}} ލިސްޓެއް ފެނިވަޑައިގަންނާނެއެވެ. ސްޓޭޖަކު ނުވަތަ ޕެކޭޖަކު ޚިޔާރުކުރާއިރު އެ ޔުނިޓް ހުރެ ކުރިއަށް ދާނެއެވެ:

- ސްލައިޑަރ އަދި {{ui:ޕްލޭ}} ގްރޫޕުގެ ފުރަތަމަ start ފެށިގެން އެހެން ފަހު finish އާ ހަމައަށް ދަނީ.
- ގްރޫޕުގެ ޓާސްކްތައް ނޫން ޓާސްކްތައް ނުލާ، އެއްޗެހި ފެންނާނީ ގްރޫޕުގެ ޓާސްކްތަކެވެ؛ އެ ގްރޫޕުގެ ބޭރުގައި ހުރި ހުރިހާ އެއްޗެއް ފެންނަނީ ބޮޑު ފެންމިނުން.
- ލިސްޓުގެ ދަށުގައިވާ ލައިނުން އެ ގްރޫޕުގެ ކިތަންމެ ޓާސްކް ނިމިފައި، ކިތަންމެ ކުރިއަށް ދަނީ، އަދި ކިތަންމެ އަދި ދެވޭނެ ހުރިތޯ އެ ތާރީޚުގައި ދައްކާއެވެ.
- {{ui:ހަމަ ސެލެކްޓްކުރޭ}} އެ ގްރޫޕުގެ ހުރިހާ އެލެމަންޓް ޚިޔާރުކޮށްލަނީ، {{ui:ފެންނަވާ}}، {{ui:ކޮޓަރި ކަށަވަރު}} ނުވަތަ ޝެޑިއުލަށް.

ޝެޑިއުލް ފުރިހަމައަށް އަލުން ފެންނަން **Every task** ޚިޔާރުކުރޭ.

## ދައްކާ ކަންތައް

- **Built**: ޓާސްކްތައް ހުރިހާ ނިމިފައިވާ އެލެމަންޓްތައް، އެމީހުންގެ އަމިއްލަ ރަންގުތަކުން.
- **In progress**: އެ ދުވަހު ކުރިއަށް ދާ ޓާސްކެއް ހުންނަ އެލެމަންޓްތައް، އޮކާ ރަންގުން. ޓާސްކެއް ފެށޭ ތާރީޚުން ނިމޭ ތާރީޚާ ހަމައަށް ކުރިއަށް ދަނީ.
- **Not started**: ފެންމިނުން.
- ޓާސްކެއްގެ ތެރެއަކުން ކޮންމެ ޓާސްކަކު ފެނުނު އެލެމަންޓްތަކުގެ އަދަދު ލިސްޓު ދައްކާއެވެ. ކިޔެވޭކަށް ނޫން ނުވަތަ ކަމެއް ނުފެނުނު ރޯތައް އެމީހުންގެ ލައިން ނަންބަރާއެކު ލިސްޓުކުރެވޭނެއެވެ.

## ލިންކްތައް، Gantt ޗާޓް އަދި MS Project

- Microsoft Project XML ފައިލް (`.xml`) ނުވަތަ `Predecessors` ކޮލަމް ހުންނަ CSV ފައިލް ހުޅުވޭ. ލިންކްތައް finish to start، start to start، finish to finish ނުވަތަ start to finish ވެގެން ވާނެއެވެ، ކޮންމެ އެއްގައި ދުވަހުގެ lead ނުވަތަ lag ވެސް ހުންނާނެއެވެ.
- ޓާސްކް ލިސްޓުގެ ދަށުގައި Gantt ޗާޓް ކޮންމެ ޓާސްކަކު ބާރަކަށް ގޭ، ލިންކްތަކަށް އެރޯ ހިމެނޭ. ކްރިޓިކަލް ޕާތުގެ ޓާސްކްތައް ރަތް. ލިންކް ލޫޕެއް، ނުވަތަ ނެތް predecessor ޕެނަލުގައި ލިސްޓުކުރެވޭނެއެވެ.
- {{ui:MS Project XML ގެ ގޮތުގައި ސޭވްކުރޭ}} އަދި {{ui:ގުޅުންތަކާއެކު CSV ސޭވްކުރޭ}} ޝެޑިއުލް އޭގެ ލިންކްތައް ހިމެނިގެން ލިޔެއެވެ.
