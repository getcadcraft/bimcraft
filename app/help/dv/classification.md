## ކުރާނީ ކޮން ކަމެއް

ކޯނޑު، ފުރާޅު، ތަޅުން، ދޮރު، ފަތު އަދި މޮޑެލުގައި ހުރި އެހެން ކޮންމެ އެއްޗަކަށް ކްލާސިފިކޭޝަން ކޯޑެއް ދޭ، ތިން ސިސްޓަމަށް ގަރާފަކޮށް: Uniclass، OmniClass އަދި UniFormat. އެހެން ޑިސިޕްލިންތަކާއި އެހެން ސޮފްޓްވެއާ ކޯޑަށް ބަލާ، ނަމަށް ނޫން، އެހެންކަމުން ކޯޑުތައް IFC ފައިލުގައި ކްލާސިފިކޭޝަން ރެފަރެންސްގެ ގޮތުން ސޭވް ކުރެވޭ، ކޮންމެ BIM ޕްރޮގްރާމަކުން ކިޔެވޭ.

## އެލިމެންޓަކަށް ކޯޑެއް ދޭ

1. އެލިމެންޓެއް (ނުވަތަ ގިނަ) ހޮވައި **ޕްރޮޕަޓީޒް** ހުޅުވާ. {{ui:Classification}} ސެކްޝަން ހުޅުވާ.
2. ސިސްޓަމުގެ ބޮކްސުގައި ކޯޑު ޓައިޕް ކޮށް Enter ފެނެ. ކޯޑް ލިސްޓެއް ލޯޑުވެފައިވާއިރު ކޯޑުގެ ބައެއް ނުވަތަ ކިއްވަ ބަސް ("curtain wall") ޓައިޕް ކޮށް ވަރަށް ގުޅޭ ތަކުން ހޮވާ: ކޯޑުގެ ސުރުޚީ އޮޓޯމެޓިކަލީ ފުރާ.
3. {{ui:Applies to}} ގައި ކޯޑު ކައިރި ކުރޭ: **މި އެލިމެންޓް**، ނުވަތަ **އޭގެ ޓައިޕް (ޓައިޕްގެ ކޮންމެ އެލިމެންޓް)**. ފާރު ޓައިޕެއްގައި ކޯޑެއް ފާރު ހުރި ކޮންމެ ފާރުއަކަށް، އަދި ފަހުން ހަދާ ފާރުތަކަށް ވެސް ބަލާ.
4. {{ui:Clear}} ކޯޑު ފޮހެލުން.

ކޮންމެ ކޯޑަކަށް ފަހުން ސެކްޝަނުން ދައްކާ ކޯޑު ކޮންތަނުން ހިމެނެއެވެ: މި އެލިމެންޓުގައި ދެމައްޗަށް، އޭގެ ޓައިޕުން، ނުވަތަ ކްލާހުގެ ޕްރޮޖެކްޓް ޑިފޯލްޓު. އެލިމެންޓުގެ އަމިއްލަ ކޯޑު އެންމެ ކުރިއަށް، ޓައިޕުން ދެން، ޑިފޯލްޓު އެންމެ މަގު. ގިނަ އެލިމެންޓް ހޮވާއިރު، "varies" ކިޔާ ބޮކްސް މުޅި އެއް ކޯޑު ނޫންކަން ދައްކައެވެ؛ އެއް ކޯޑު ކަނޑައަޅާ ކޮންމެކަމެއް ހުރިހާ އެންމެއަށް ދެނެވޭ. ކޮންމެ ބަދަލެއް ޕްރޮޖެކްޓަކަށް އަނބުރާ ކުރުމުގެ ނުކުތާއެއް.

ލިސްޓް ލޯޑު ނެތްނަމަވެސް ކޯޑު ޓައިޕް ކުރެވޭ. ކޯޑުގެ ސިސްޓަމުގެ ފޯމެޓަށް ނުވަތަ ލޯޑުވެފައިވާ ލިސްޓުގައި ނެތްނަމަ، ހިންޓެއް ދައްކައި ކޯޑު ތިބާ ޓައިޕް ކުރި ގޮތާއެކު ރައްކާ ކުރެއެވެ.

## ޕްރޮޖެކްޓުގެ ސިސްޓަމްތައް ހޮވާ

މޮޑެލް ބާރުން **ޑޭޓާ** ހުޅުވައި {{ui:Classification}} (ނުވަތަ ޕްރޮޕަޓީޒް ސެކްޝަނުގެ {{ui:Project classification…}}) ހޮވާ.

- މި ޕްރޮޖެކްޓް ބޭނުން ކުރާ ސިސްޓަމްތައް ހޮވާ. ޕްރޮޕަޓީޒް އެ ބަޔަށް ފެންނާނީ.
- **Uniclass**: Elements/ functions (EF)، Systems (Ss) އަދި Products (Pr) ޓޭބަލްތައް އެޕާއެކު އަންނައެވެ. އެއީ © NBS، Creative Commons Attribution-NoDerivatives 4.0 ލައިސަންސްގެ މީހުންނަށް އަށްތާ، އެމް ނުބަދަލު ކުރަމެވެ. ޑައިޔަލޮގު ކޮންމެ ޓޭބަލަކުގެ އެޑިޝަންއާއި ކިއުރުން ކިޔެވުނު ދުވަސް ދައްކައެވެ. އެއީ އާ ޓޭބަލްތައް ނޫން: ޕަބްލިޝަރު ކޮންމެ ކުއާޓަރަކަށް އާ ޓޭބަލްތައް އެމީހުންގެ ސައިޓުން ދެއްވާ.
- **OmniClass** އަދި **UniFormat**: އެޕާއެކު ކޯޑު ލިސްޓެއް ނުއަންނާނެ، ކަމަކީ ޕަބްލިޝަރު ލައިސަންސް ނެތި ޓޭބަލް ފަތުރުން ހުއްދަ ނުދޭ. ކޮންމެ ކޯޑެއް ޓައިޕް ކުރޭ، ނުވަތަ ކޮމްޕެނީގެ ލައިސަންސް ޓޭބަލް ލޯޑު ކުރޭ.
- {{ui:Load a table (CSV)…}} ކޮމްޕެނީގެ ޓޭބަލް CSV ފައިލުން ކިޔާ، ކޯޑު ކޮލަމާއި ސުރުޚީ ކޮލަމް އުނދަގުލި (Code, Number ނުވަތަ Identifier ފަދަ ހެޑަރ ރޯ، އަދި Title, Name ނުވަތަ Description ފަދަ ރޯ ސާމާންކޮށް ހޯދެއެވެ؛ ހެޑަރ ނެތްނަމަ ފުރަތަމަ ދެ ކޮލަމް ބޭނުން ކުރެވެއެވެ). ޓޭބަލް މި browser ގައި ހުންނަ، އަދި ޕްރޮޖެކްޓް ފައިލުގައި ނުލިޔެވޭ. ތިބާ ދޫކުރާ ކޯޑުތައްގެ ފައިލް ސޭވް ކުރެވޭ. Uniclass ގެ އާ ޓޭބަލެއް މި ގޮތުން ލޯޑު ކުރެވޭ.
- {{ui:Give elements a default code by their class}} ކޮންމެ ފާރު، ފުރާޅު، ފަތު، ދޮރު، ދޮރު އެތެރެ، ކޮލަމް، ބީމް އަދި ފަރުނީޗަރުގެ ތެރޭގައި އެމީހުންގެ އަމިއްލަ ކޯޑެއް ނެތްނަމަ ތަނެއް ޑިފޯލްޓުގެ Uniclass ކޯޑެއް Elements/ functions ޓޭބަލުން ދެއެވެ. ތިބާ ފަހުން ހަދާ އެލިމެންޓަށް ވެސް ލިބޭ.
- {{ui:Show the codes as columns in the schedules}} ކޮންމެ ސިސްޓަމަކަށް ދޮރު، ފަތު، ފާރު ޓައިޕް ނޫން ނުވަތަ ކޮޓަރި ސްކެޑިއުލް އާއި އޭގެ CSV ގައި ކޮލަމެއް ބައިގެން ދައްކައެވެ. ގިނަ އެލިމެންޓުގެ ރޯއެއްގައި ކޯޑުތައް ވަކި ވަކިވެއްޖެނަމަ "varies" ފެނޭ.

## ދެނެގަތަންޖެހޭ ކަންތައްތައް

- ޑިފޯލްޓު ކޯޑުތައް CadCraft ގެ އަމިއްލަ ފަށައި ހޮވުމެއް، ޕަބްލިޝަރުގެ ނޫން، އަދި ޕްރެކްޓިސިއަނަކުން ޗެކް ނުކުރެވިފައެވެ. ތިބާގެ ޕްރޮޖެކްޓުގެ ސްޓޭންޑަރޑާ ބަލާ.
- ފައިލުގައި ޑިފޯލްޓަކީ ރިއަލް ކްލާސިފިކޭޝަނެއް، "CadCraft default" ސަބަންޑަމް ރިލޭޝަން ނަމުން ފާހަގަ، އަދި އެލިމެންޓަށް ނުވަތަ އޭގެ ޓައިޕަށް އަމިއްލަ ކޯޑެއް ލިބޭ ވަގުތު ކޮންކަން ހުއްޓެއެވެ.
- ފައިލް އިމްޕޯޓް ކުރާއިރު ދުވާ ކޯޑުތައް ކިޔެވެ ދައްކައެވެ، ސިސްޓަމުގެ ނަމުގެ ޙަރުފު ހުރިކަމުން ވެސް. އެހެން ސިސްޓަމެއްގެ (ކޮމްޕެނީގެ އަމިއްލަ) ކޯޑުތައް ލިސްޓް ކުރެވޭ، ކަމަށް ބަދަލު ނުކުރޭ.
- ފައިލް އަލުން ހުޅުވާއިރު، މިތަން ނުވަތަ އެހެން ޕްރޮގްރާމްގައި، ކޯޑުތައް ކިޔެވެ. ޕްރޮޖެކްޓް ނުކުތާއާ IFC5 alpha (IFCX) އެކްސްޕޯޓުން ލޭބަލް ކުރެވޭ، ބަހާ ހުށަހަޅާ ކޯޑު ފަސްކޮށް ފެނޭ.
- ނޫން: ޓޭބަލް ކުރު ހިސާބު ބެލުމަށް ޓްރީ، ހަމަ ގޮތް ކުރޭ ކޯޑު ލެވެލް އަދި ކޮޓަރި، ފައިލުގައި ހުންނާ އެޑިޝަނާ ކޯޑު ފަރާތުން ބަލާ.
