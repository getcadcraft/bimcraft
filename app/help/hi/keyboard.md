BimCraft में कम शॉर्टकट हैं। ज़्यादातर काम माउस और पैनलों से होता है। {{key:Mod}} से लिखे शॉर्टकट Mac पर Command और बाकी जगह Ctrl इस्तेमाल करते हैं। इस सहायता में कुंजियाँ कैसे लिखी जाती हैं, यह जानने के लिए [कुंजियाँ, माउस और ट्रैकपैड](common:keys) देखें।

## हर जगह

| कुंजी | क्या करती है |
|---|---|
| {{key:Ctrl+Shift+F}} | स्क्रीन मोड बदलें: सामान्य, पूर्ण स्क्रीन, और पूर्ण स्क्रीन जिसमें बार छिपे हों। हर प्लेटफ़ॉर्म पर Ctrl, Mac पर भी |
| {{key:Esc}} | पूर्ण स्क्रीन से बाहर आएँ |
| {{key:Mod+,}} | {{ui:सेटिंग्स}} खोलें। देखें [BimCraft सेटिंग्स](topic:settings) |
| {{key:Tab}} | बटन, चेकबॉक्स और मानों के बीच जाएँ। हर कंट्रोल कीबोर्ड से पहुँचा जा सकता है |

## 3D व्यू (IFC मॉडल)

| कुंजी या क्रिया | क्या करती है |
|---|---|
| {{key:F}} | पूरा मॉडल फ़िट करें, तीन-चौथाई व्यू में (वही जो {{ui:फ़िट}} करता है) |
| {{key:Esc}} | चयन हटाएँ, या रखना या पेस्ट करना रोकें |
| क्लिक | पॉइंटर के नीचे का एलिमेंट चुनें; खाली पृष्ठभूमि पर क्लिक करें तो चयन हटे |
| {{key:Mod}}+क्लिक या {{key:Shift}}+क्लिक | चयन में एलिमेंट जोड़ें, या उसे निकालें |
| {{key:H}} | चुने गए एलिमेंट छिपाएँ। देखें [एलिमेंट छिपाएँ, अलग करें और आर-पार देखें](topic:hide-and-isolate) |
| {{key:I}} | केवल चुने गए एलिमेंट दिखाएँ (अलग करें) |
| {{key:T}} | चुने गए एलिमेंट दिखाएँ, बाकी सब आर-पार |
| {{key:Shift+H}} | हर एलिमेंट फिर से दिखाएँ |
| {{ui:चलें}} | इसके बाद {{key:W}} {{key:A}} {{key:S}} {{key:D}} या तीर कुंजियाँ चलने के लिए, {{key:Shift}} दौड़ने के लिए, ड्रैग करके चारों ओर देखें, {{key:Esc}} रोकने के लिए। देखें [मॉडल में चलें](topic:walk) |
| {{key:M}} | दूरियाँ और फ़ेस क्षेत्रफल मापें। देखें [3D में दूरी, फ़ेस क्षेत्रफल और स्थान मापें](topic:measure) |
| बाएँ बटन से ड्रैग | ऑर्बिट |
| दाएँ बटन से ड्रैग | पैन |
| {{key:Shift}} या {{key:Mod}} दबाकर बाएँ बटन से ड्रैग | पैन (ट्रैकपैड पर सुविधाजनक) |
| माउस व्हील घुमाएँ, या बीच के बटन से ड्रैग | ज़ूम |
| ट्रैकपैड पर दो उँगलियों से स्क्रॉल या पिंच | ज़ूम |
| एक उँगली (टच) | ऑर्बिट; टैप चुनता है |
| दो उँगलियाँ (टच) | पिंच करके ज़ूम, साथ सरकाकर पैन |

| {{key:X}} | सेक्शन प्लेन चालू और बंद। देखें [सेक्शन प्लेन से IFC मॉडल काटें](topic:section-plane) |
| {{key:Shift+X}} | चुने गए एलिमेंट के चारों ओर सेक्शन बॉक्स, सेटिंग्स में चुने कमरे के साथ |

{{ui:ऊपर}}, {{ui:सामने}} और {{ui:बगल}} के लिए कोई कुंजी नहीं है; बटन इस्तेमाल करें।

## संपादन

वही कमांड टूलबार में हैं: {{ui:पूर्ववत करें}}, {{ui:फिर से करें}}, {{ui:कॉपी करें}}, {{ui:चिपकाएँ}} और {{ui:और}} मेन्यू, जो हर कुंजी दिखाता है। ये IFC मॉडल के 3D व्यू में काम करते हैं, फ़ील्ड में टाइप करते समय नहीं। देखें [लाइब्रेरी आइटम कॉपी, पेस्ट और डुप्लिकेट करें](topic:copy-paste)।

| कुंजी | क्या करती है |
|---|---|
| {{key:Mod+Z}} | आखिरी बदलाव पूर्ववत करें |
| {{key:Mod+Y}} या {{key:Mod+Shift+Z}} | जो पूर्ववत में वापस लिया गया था, उसे फिर से करें |
| {{key:Mod+C}} | चुने गए एलिमेंट कॉपी करें (उनके नाम और प्रॉपर्टी भी टेक्स्ट के रूप में क्लिपबोर्ड पर जाती हैं) |
| {{key:Mod+X}} | चुने गए एलिमेंट काटें: उन्हें कॉपी करें, फिर हटाएँ |
| {{key:Mod+V}} | जो कॉपी किया था उसे चिपकाएँ: वह पॉइंटर के साथ चलता है, जहाँ जाना है वहाँ क्लिक करें |
| {{key:Mod+Shift+V}} | उसी जगह चिपकाएँ: जहाँ से कट हुआ था, या कॉपी के बाद मूल के बगल में |
| {{key:Mod+D}} | डुप्लिकेट: चुने गए एलिमेंट कॉपी करें और उन्हें चिपकाना शुरू करें |
| {{key:Delete}} | चुने गए एलिमेंट हटाएँ, उनके हिस्सों और खुलावों समेत। देखें [बिल्डिंग एलिमेंट हटाएँ, काटें, कॉपी करें और चिपकाएँ](topic:edit-elements) |
| {{key:Mod+A}} | दिखने वाला हर एलिमेंट चुनें |
| {{key:Esc}} | कुछ न चुनें |

जब पेज पर टेक्स्ट चुना हो, तो {{key:Mod+C}} हमेशा की तरह वह टेक्स्ट कॉपी करता है।

## प्लान व्यू (ड्रॉ)

ये तब काम करते हैं जब {{ui:ड्रॉ}} चालू हो और आप किसी फ़ील्ड में टाइप न कर रहे हों। देखें [दीवारें बनाएँ](topic:draw-walls) और [दरवाज़े और खिड़कियाँ](topic:doors-and-windows)।

| कुंजी या क्रिया | क्या करती है |
|---|---|
| {{key:V}} | {{ui:चुनें}} |
| {{key:W}} | {{ui:दीवार}} |
| {{key:D}} | {{ui:दरवाज़ा}} |
| {{key:N}} | {{ui:खिड़की}} |
| {{key:H}} | {{ui:दरवाज़ा}} या {{ui:खिड़की}} के साथ: कब्ज़े दूसरे सिरे पर |
| दीवार बनाते समय {{key:Shift}} | उसे 0°, 90°, 180° या 270° पर रखें |
| अंक और फ़ुट व इंच के चिह्न (`'` और `"`) | {{ui:लंबाई}} बॉक्स में लंबाई टाइप करना शुरू करें; {{key:Enter}} उसे लागू करता है |
| {{key:Enter}}, {{key:Esc}}, दायाँ क्लिक या डबल-क्लिक | जो दीवार बना रहे हैं उसे खत्म करें; {{key:Esc}} फिर दबाने पर {{ui:चुनें}} पर लौटें |
| {{key:Delete}} | चुनी गई दीवारें, दरवाज़े और खिड़कियाँ हटाएँ; बची दीवारें फिर जुड़ जाती हैं |
| प्लान पर पॉइंटर रखकर {{key:F}} | प्लान फ़िट करें |
| माउस व्हील घुमाएँ | पॉइंटर के आसपास ज़ूम |
| बीच या दाएँ बटन से ड्रैग, या {{key:Space}} दबाकर ड्रैग | पैन; {{ui:चुनें}} चालू हो तो सादा ड्रैग भी पैन करता है |
| {{ui:चुनें}} के साथ दरवाज़ा या खिड़की ड्रैग करें | उसे उसकी दीवार के साथ, या दूसरी दीवार पर सरकाएँ |
| दो उँगलियाँ (टच) | पिंच करके ज़ूम, साथ सरकाकर पैन |

## लाइब्रेरी आइटम रखना और चिपकाना

| कुंजी | क्या करती है |
|---|---|
| {{key:R}} | आइटम को 90° घुमाएँ |
| {{key:Tab}} | दीवार स्नैप चालू और बंद: आइटम की पीठ सबसे पास की दीवार से लगती है |
| **X, Y (mm)** में {{key:Enter}} | टाइप की गई स्थिति पर रखें |
| {{key:Esc}} | रखना या चिपकाना रोकें |

## IFC मान संपादित करना

| कुंजी | क्या करती है |
|---|---|
| {{key:Enter}} | जो मान टाइप किया, उसे रखें |
| {{key:Esc}} | रद्द करें और पुराना मान वापस रखें |
| कहीं और क्लिक | जो मान टाइप किया, उसे रखें |
| {{key:Mod+Z}} | आखिरी बदलाव पूर्ववत करें। केवल तब जब बिना सहेजे बदलाव हों और आप फ़ील्ड में टाइप न कर रहे हों |
| {{key:Mod+Y}} | जो पूर्ववत में वापस लिया गया था, उसे फिर से करें |
| {{key:Mod+S}} | IFC के रूप में सहेजें। केवल तब जब बिना सहेजे बदलाव हों; अन्यथा ब्राउज़र का अपना सहेजने का कमांड खुलता है |

सिर्फ़ कीबोर्ड से संपादित करने के लिए: किसी मान के हाइलाइट होने तक {{key:Tab}} दबाएँ, फिर टाइप करना शुरू करने के लिए {{key:Enter}} दबाएँ।

## 2D ड्रॉइंग (DWG और DXF)

| कुंजी या क्रिया | क्या करती है |
|---|---|
| {{key:F}} | ड्रॉइंग या शीट फ़िट करें |
| {{key:P}} | प्रिंट व्यू चालू और बंद |
| डबल-क्लिक | फ़िट |
| किसी भी बटन से ड्रैग | पैन |
| माउस व्हील घुमाएँ | पॉइंटर पर ज़ूम |
| ट्रैकपैड पर दो उँगलियों से स्क्रॉल या पिंच | पॉइंटर पर ज़ूम। दो उँगलियों से स्क्रॉल पैन नहीं करता |
| एक उँगली (टच) | पैन। ड्रॉइंग के लिए पिंच ज़ूम अभी बनाया नहीं गया है |

## 3D में ड्रॉइंग

| कुंजी या क्रिया | क्या करती है |
|---|---|
| {{key:3}} | 3D चालू और बंद (2D व्यू पर भी) |
| {{key:F}} | एक्सटेंट्स: पूरी ड्रॉइंग |
| बीच या बाएँ बटन से ड्रैग | ऑर्बिट |
| दाएँ बटन से ड्रैग, या {{key:Shift}} दबाकर ड्रैग | पैन |
| माउस व्हील घुमाएँ | पॉइंटर के नीचे की चीज़ की ओर ज़ूम |
| ट्रैकपैड पर दो उँगलियों से स्वाइप | ऑर्बिट; {{key:Shift}} के साथ पैन |
| ट्रैकपैड पर पिंच | ज़ूम |
| एक उँगली (टच) | ऑर्बिट |
| दो उँगलियाँ (टच) | पिंच करके ज़ूम, साथ सरकाकर पैन |

{{key:F}}, {{key:P}} और {{key:3}} तब कुछ नहीं करते जब आप फ़ील्ड में टाइप कर रहे हों, जब उपकरण शेड्यूल दिख रहा हो, या जब आप {{key:Mod}} या {{key:Alt}} दबाए हों।

## फ़ाइलें

| क्रिया | क्या करती है |
|---|---|
| फ़ाइल को पेज पर ड्रैग करें | उसे खोलें |
| फ़ोल्डर को पेज पर ड्रैग करें | उसे प्रोजेक्ट फ़ोल्डर के रूप में खोलें, बिना अनुमति पूछे |
