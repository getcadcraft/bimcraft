## एक IFC एलिमेंट

{{ui:Properties}} पैनल के सबसे ऊपर एलिमेंट का प्रकार "Ifc" उपसर्ग के बिना दिखता है (जैसे "Door", "WallStandardCase", "FurnishingElement") और उसका नाम, या "बेनाम"।

| फ़ील्ड | अर्थ | संपादन योग्य |
|---|---|---|
| Name | एलिमेंट का नाम, अक्सर एक्सपोर्टर से आए फ़ैमिली और टाइप का नाम | हाँ |
| Type | एलिमेंट के टाइप का नाम, जब उसका हो | नहीं |
| Object type | मुक्त-लेख टाइप का विवरण जो कुछ एक्सपोर्टर भरते हैं | हाँ |
| Tag | एलिमेंट का टैग या मार्क; कई एक्सपोर्टर यहाँ एलिमेंट ID लिखते हैं | हाँ |
| Description | मुक्त लेख | हाँ |
| GlobalId | एलिमेंट का स्थायी 22-अक्षर का IFC पहचानकर्ता, उसी एलिमेंट के हर निर्यात में एक जैसा | नहीं |
| Line | इस IFC फ़ाइल में एलिमेंट की लाइन संख्या (`#1234`)। हर निर्यात में यह बदल जाती है | नहीं |

नीचे **प्रॉपर्टी सेट** नाम के अनुसार क्रम से आते हैं:

- हर सेट अपने नाम पर क्लिक करने से खुलता और बंद होता है। पहले तीन खुले होते हैं।
- "(type)" चिह्नित सेट एलिमेंट के टाइप का है: "टाइप प्रॉपर्टी: यहाँ किया गया बदलाव इस टाइप के हर एलिमेंट पर लागू होता है।"
- मात्रा सेट (लंबाइयाँ, क्षेत्रफल, आयतन, गिनतियाँ, वज़न) केवल पढ़ने के लिए हैं।
- सूचियाँ और गणना वाले मान दिखाए जाते हैं, केवल पढ़ने के लिए।
- हाँ/नहीं मान **हाँ** या **नहीं** के रूप में दिखते हैं।
- संख्याएँ प्रदर्शन के लिए चार दशमलव तक गोल की जाती हैं। लंबाइयाँ (लंबाई प्रॉपर्टी या मात्रा की लंबाई) टूलबार पर चुनी गई {{ui:Units}} में दिखती हैं, इकाई चिह्न के साथ, और आप उसी इकाई में या किसी और इकाई चिह्न के साथ नया मान लिख सकते हैं (2.4 m, 8'-0")। BimCraft फ़ाइल की अपनी संख्या वापस लिखता है। बाकी संख्याएँ फ़ाइल में जैसी हैं वैसी दिखती हैं।
- खाली मान *खाली* के रूप में दिखता है। संपादित मान बोल्ड होता है और उसके बगल में नीला बार होता है।

## मान कॉपी करें

{{ui:Properties}} के हर मान के बगल में एक छोटा कॉपी बटन है: उस पर क्लिक करें ताकि वह मान ठीक वैसा ही क्लिपबोर्ड पर चला जाए जैसा दिखता है, उदाहरण के लिए GlobalId, सीरियल नंबर या कोई भी प्रॉपर्टी सेट मान। कॉपी करने से कभी संपादन शुरू नहीं होता।

सबसे ऊपर {{ui:Copy all}} एलिमेंट के हर मान को सेट-दर-सेट टेक्स्ट के रूप में कॉपी करता है, और {{ui:Copy as CSV}} उन्हें group, property और value की पंक्तियों के रूप में कॉपी करता है ताकि स्प्रेडशीट में चिपकाया जा सके; खाली मान रखे जाते हैं, ताकि हर फ़ील्ड की एक पंक्ति हो। यह दूसरे खुले मॉडल के एलिमेंट के लिए भी वैसे ही काम करता है; जब एक से अधिक मॉडल खुले हों, तो CSV की शुरुआत में एक मॉडल कॉलम होता है जो उसकी फ़ाइल का नाम देता है।

## फ़ाइल पैनल (IFC)

| फ़ील्ड | अर्थ |
|---|---|
| File, Size | आपने जो फ़ाइल खोली, उसका नाम और आकार |
| Schema | IFC संस्करण, जैसे IFC2X3 या IFC4 |
| Project | प्रोजेक्ट का नाम और लंबा नाम |
| Phase | प्रोजेक्ट का चरण, यदि एक्सपोर्टर ने लिखा हो |
| Exported from | निर्यात करने वाला प्रोग्राम, फ़ाइल हेडर से |
| Author | फ़ाइल हेडर में लेखक |
| Exported | फ़ाइल हेडर में तारीख और समय |
| Elements | कितने आकार वाले एलिमेंट बनाए गए |
| Triangles | उनके आकार कितने त्रिभुज बनाते हैं; मॉडल कितना भारी है, इसका माप |

## फ़ाइल पैनल (प्रोजेक्ट और फ़ैमिली फ़ाइलें)

| फ़ील्ड | अर्थ |
|---|---|
| Kind | प्रोजेक्ट, प्रोजेक्ट टेम्प्लेट, फ़ैमिली या फ़ैमिली टेम्प्लेट |
| Saved in | वह रिलीज़ जिसने फ़ाइल को आख़िरी बार सहेजा |
| Build | उस रिलीज़ का सटीक बिल्ड |
| Read | फ़ाइल का कितना हिस्सा BimCraft ने पढ़ा, उसके आकार में से |

## ड्रॉइंग पैनल (DWG और DXF)

| फ़ील्ड | अर्थ |
|---|---|
| Format | वह रिलीज़ जिसमें ड्रॉइंग सहेजी गई, उसके फ़ॉर्मैट कोड के साथ, जैसे AC1032 |
| Units | ड्रॉइंग की इन्सर्शन इकाइयाँ, जब सेट हों |
| Entities | कितने ऑब्जेक्ट पढ़े गए |
| Layers | कितनी लेयर |
| Sheets | कितनी शीट (लेआउट), या कोई नहीं |
| Linked drawings | इसकी कितनी लिंक की गई ड्रॉइंग मिलीं और लोड हुईं |
| Equipment | शीटों पर कितने टैग किए गए उपकरण आइटम हैं |

## फ़ोल्डर पैनल

| फ़ील्ड | अर्थ |
|---|---|
| Folder, Files, Size | आपने जो फ़ोल्डर खोला, उसमें कितनी फ़ाइलें हैं और उनका कुल आकार |
| Models | प्रोजेक्ट और फ़ैमिली फ़ाइलें, हर एक उसके बैकअप समेत एक बार गिनी गई |
| CAD drawings, IFC models | हर एक कितने हैं |
| Problems | कितनी मॉडल प्रतियाँ अधूरी या न पढ़ी जा सकने वाली हैं, या कोई नहीं |
