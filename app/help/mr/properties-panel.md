## IFC घटक

{{ui:गुणधर्म}} पॅनेलच्या वरच्या भागात घटकाचा प्रकार "Ifc" उपसर्गाशिवाय दिसतो (उदा. "Door", "WallStandardCase", "FurnishingElement") आणि त्याचे नाव, किंवा "Unnamed" असल्यास "नाव नाही".

| फील्ड | अर्थ | बदलता येते का |
|---|---|---|
| Name | घटकाचे नाव, बहुधा एक्सपोर्टरकडून आलेले फॅमिली आणि प्रकाराचे नाव | होय |
| Type | घटकाच्या प्रकाराचे नाव, असल्यास | नाही |
| Object type | काही एक्सपोर्टर भरणारे मुक्त-मजकूर प्रकार वर्णन | होय |
| Tag | घटकाचा टॅग किंवा खूण; अनेक एक्सपोर्टर इथे घटक ID लिहितात | होय |
| Description | मुक्त मजकूर | होय |
| GlobalId | घटकाचा कायमचा 22-अक्षरी IFC ओळखकर्ता, त्याच घटकाच्या प्रत्येक निर्यातीत सारखा | नाही |
| Line | या IFC फाइलमधील घटकाचा ओळ क्रमांक (`#1234`). तो निर्यातींदरम्यान बदलतो | नाही |

खाली **प्रॉपर्टी सेट्स** नावानुसार क्रमवारीत येतात:

- प्रत्येक सेट त्याच्या नावावर क्लिक केल्यावर उघडतो आणि बंद होतो. पहिले तीन उघडे असतात.
- "(type)" चिन्हांकित सेट घटकाच्या प्रकाराचा असतो: "प्रकार गुणधर्म: इथे केलेला बदल या प्रकारातील प्रत्येक घटकाला लागू होतो."
- प्रमाण सेट (लांबी, क्षेत्रफळ, घनफळ, संख्या, वजन) फक्त वाचनीय असतात.
- यादी आणि निवडक मूल्ये दाखवली जातात, फक्त वाचनीय.
- होय/नाही मूल्ये **होय** किंवा **नाही** म्हणून दिसतात.
- संख्या प्रदर्शनासाठी चार दशांश स्थानांपर्यंत गोल केल्या जातात. लांबी (लांबीचा गुणधर्म किंवा प्रमाणाची लांबी) टूलबारवर निवडलेल्या {{ui:एकके}} मध्ये एककासह दिसते, आणि तुम्ही त्या एककात किंवा दुसऱ्या एकक खुणेसह (2.4 m, 8'-0") नवी संख्या टाइप करू शकता: BimCraft फाइलची स्वतःची संख्या परत लिहिते. इतर संख्या फाइलमध्ये आहेत तशाच दिसतात.
- रिकामे मूल्य *empty* म्हणून दिसते. बदललेले मूल्य ठळक असते आणि बाजूला निळी पट्टी असते.

## मूल्य कॉपी करा

{{ui:गुणधर्म}} मधील प्रत्येक मूल्याच्या बाजूला एक छोटे कॉपी बटण असते: त्यावर क्लिक केल्यास ते मूल्य दाखवल्याप्रमाणेच क्लिपबोर्डवर जाते, उदा. GlobalId, अनुक्रमांक किंवा कोणतेही प्रॉपर्टी सेट मूल्य. कॉपी केल्याने कधीही संपादन सुरू होत नाही.

वर, {{ui:सर्व कॉपी करा}} घटकाची सर्व मूल्ये मजकूर म्हणून, सेटनुसार, कॉपी करते, आणि {{ui:CSV म्हणून कॉपी करा}} गट, गुणधर्म आणि मूल्य अशा ओळींच्या स्वरूपात कॉपी करते, स्प्रेडशीटमध्ये पेस्ट करण्यासाठी; रिकामी मूल्ये ठेवली जातात, त्यामुळे प्रत्येक फील्डला एक ओळ मिळते. हे उघडलेल्या दुसऱ्या मॉडेलमधील घटकासाठीही तसेच चालते; एकापेक्षा जास्त मॉडेल उघडे असल्यास CSV ची सुरुवात त्याच्या फाइलचे नाव देणाऱ्या Model स्तंभाने होते.

## फाइल पॅनेल (IFC)

| फील्ड | अर्थ |
|---|---|
| File, Size | तुम्ही उघडलेली फाइल |
| Schema | IFC आवृत्ती, जसे IFC2X3 किंवा IFC4 |
| Project | प्रकल्पाचे नाव आणि दीर्घ नाव |
| Phase | प्रकल्पाचा टप्पा, एक्सपोर्टरने लिहिला असल्यास |
| Exported from | फाइल हेडरमधून, निर्यात करणारा प्रोग्राम |
| Author | फाइल हेडरमधील लेखक |
| Exported | फाइल हेडरमधील तारीख आणि वेळ |
| Elements | आकार असलेले किती घटक काढले गेले |
| Triangles | त्यांचे आकार किती त्रिकोण बनवतात; मॉडेल किती जड आहे याचे माप |

## फाइल पॅनेल (प्रकल्प आणि फॅमिली फाइल्स)

| फील्ड | अर्थ |
|---|---|
| Kind | Project, Project template, Family किंवा Family template |
| Saved in | शेवटी जतन करणारी आवृत्ती |
| Build | त्या आवृत्तीची अचूक बिल्ड |
| Read | BimCraft ने फाइलचा किती भाग वाचला, फाइलच्या आकारापैकी |

## ड्रॉइंग पॅनेल (DWG आणि DXF)

| फील्ड | अर्थ |
|---|---|
| Format | ड्रॉइंग ज्या आवृत्तीत जतन केले होते ती, तिच्या स्वरूप कोडसह, जसे AC1032 |
| Units | ड्रॉइंगची insertion units, सेट असल्यास |
| Entities | किती ऑब्जेक्ट्स वाचले गेले |
| Layers | किती लेयर्स |
| Sheets | किती शीट्स (लेआउट्स), किंवा None |
| Linked drawings | त्याच्या किती जोडलेल्या ड्रॉइंग्ज सापडल्या आणि लोड झाल्या |
| Equipment | शीट्सवर किती टॅग केलेली उपकरणे आहेत |

## फोल्डर पॅनेल

| फील्ड | अर्थ |

| Models | प्रकल्प आणि फॅमिली फाइल्स, प्रत्येकाच्या बॅकअप्ससह एकदाच मोजलेल्या |

| Problems | किती मॉडेल प्रती अपूर्ण किंवा वाचता न येणाऱ्या आहेत, किंवा None |
