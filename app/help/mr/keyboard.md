BimCraft मध्ये काही शॉर्टकट आहेत. बहुतांश काम माउस आणि पॅनलने होते. {{key:Mod}} सह लिहिलेले शॉर्टकट Mac वर Command वापरतात आणि इतरत्र Ctrl. ही मदत कशी लिहिली आहे ते पाहण्यासाठी [की, माउस आणि ट्रॅकपॅड](common:keys) पहा.

## सर्वत्र

| की | काय करते |
|---|---|
| {{key:Ctrl+Shift+F}} | स्क्रीन मोड बदला: सामान्य, फुल स्क्रीन, बार लपवलेली फुल स्क्रीन. प्रत्येक प्लॅटफॉर्मवर Ctrl, Mac सह |
| {{key:Esc}} | फुल स्क्रीनमधून बाहेर पडा |
| {{key:Mod+,}} | {{ui:Settings}} उघडा. [BimCraft सेटिंग्ज](topic:settings) पहा |
| {{key:Tab}} | बटणे, चेकबॉक्स आणि मूल्यांदरम्यान हलवा. प्रत्येक नियंत्रण कीबोर्डने गाठता येते |

## 3D दृश्य (IFC मॉडेल)

| की किंवा कृती | काय करते |
|---|---|
| {{key:F}} | संपूर्ण मॉडेल फिट करा, तीन-चतुर्थांश दृश्य ({{ui:Fit}} प्रमाणेच) |
| {{key:Esc}} | निवड काढा, किंवा ठेवणे किंवा पेस्ट करणे थांबवा |
| क्लिक | पॉइंटरखालील एलिमेंट निवडा; रिकाम्या पार्श्वभूमीवर क्लिक करून निवड काढा |
| {{key:Mod}}+क्लिक किंवा {{key:Shift}}+क्लिक | निवडीत एलिमेंट जोडा किंवा त्यातून काढा |
| {{key:H}} | निवडलेले एलिमेंट लपवा. [एलिमेंट्स लपवा, वेगळे करा आणि आरपार पहा](topic:hide-and-isolate) पहा |
| {{key:I}} | फक्त निवडलेले एलिमेंट दाखवा (वेगळे करा) |
| {{key:T}} | निवडलेले एलिमेंट दाखवा, बाकी सर्व पारदर्शक |
| {{key:Shift+H}} | प्रत्येक एलिमेंट पुन्हा दाखवा |
| {{ui:Walk}} | मग {{key:W}} {{key:A}} {{key:S}} {{key:D}} किंवा बाण फिरवा, {{key:Shift}} धावते, ड्रॅग करून आजूबाजूला पहा, {{key:Esc}} थांबवते. [मॉडेलमधून फिरा](topic:walk) पहा |
| {{key:M}} | अंतर आणि फेस क्षेत्रफळ मोजा. [3D मध्ये अंतर, फेस क्षेत्रफळ आणि स्थान मोजा](topic:measure) पहा |
| डाव्या बटणाने ड्रॅग | ऑर्बिट |
| उजव्या बटणाने ड्रॅग | पॅन |
| {{key:Shift}} किंवा {{key:Mod}} आणि डाव्या बटणाने ड्रॅग | पॅन (ट्रॅकपॅडवर सोयीचे) |
| चाक फिरवा, किंवा मधल्या बटणाने ड्रॅग | झूम |
| ट्रॅकपॅडवर दोन बोटांचे स्क्रोल किंवा पिंच | झूम |
| एक बोट (टच) | ऑर्बिट; टॅप निवडते |
| दोन बोटे (टच) | पिंच करून झूम, एकत्र हलवून पॅन |

| {{key:X}} | सेक्शन प्लेन चालू आणि बंद. [सेक्शन प्लेनने IFC मॉडेल कापा](topic:section-plane) पहा |
| {{key:Shift+X}} | निवडलेल्या एलिमेंट्सभोवती सेक्शन बॉक्स, सेटिंग्जमधील खोलीसह |

{{ui:Top}}, {{ui:Front}} आणि {{ui:Side}} साठी कोणत्याही की नाहीत; बटणे वापरा.

## संपादन

त्याच कमांड टूलबारमध्ये आहेत: {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}} आणि {{ui:More}} मेनू, जो प्रत्येक की दाखवतो. त्या IFC मॉडेलच्या 3D दृश्यात काम करतात, फील्डमध्ये टाइप करताना नाही. [लायब्ररी आयटम कॉपी, पेस्ट आणि डुप्लिकेट करा](topic:copy-paste) पहा.

| की | काय करते |
|---|---|
| {{key:Mod+Z}} | शेवटचा बदल पूर्ववत करा |
| {{key:Mod+Y}} किंवा {{key:Mod+Shift+Z}} | Undo ने मागे घेतलेले पुन्हा करा |
| {{key:Mod+C}} | निवडलेले एलिमेंट्स कॉपी करा (त्यांची नावे आणि गुणधर्म मजकूर म्हणून क्लिपबोर्डवरही जातात) |
| {{key:Mod+X}} | निवडलेले एलिमेंट्स कट करा: कॉपी करा, मग हटवा |
| {{key:Mod+V}} | तुम्ही कॉपी केलेले पेस्ट करा: ते पॉइंटरसोबत हलते, जिथे जायचे तिथे क्लिक करा |
| {{key:Mod+Shift+V}} | जिथून कट झाले तिथे पेस्ट करा, किंवा कॉपीनंतर मूळांच्या बाजूला |
| {{key:Mod+D}} | डुप्लिकेट: निवडलेले एलिमेंट्स कॉपी करा आणि पेस्ट सुरू करा |
| {{key:Delete}} | निवडलेले एलिमेंट्स, त्यांचे भाग आणि ओपनिंगसह हटवा. [बिल्डिंग एलिमेंट्स हटवा, कट, कॉपी आणि पेस्ट करा](topic:edit-elements) पहा |
| {{key:Mod+A}} | दाखवलेले प्रत्येक एलिमेंट निवडा |
| {{key:Esc}} | काहीही निवडू नका |

पृष्ठावर मजकूर निवडलेला असताना {{key:Mod+C}} नेहमीप्रमाणे तो मजकूर कॉपी करते.

## प्लॅन दृश्य (काढा)

हे {{ui:Draw}} चालू असताना आणि तुम्ही फील्डमध्ये टाइप करत नसताना काम करतात. [भिंती काढा](topic:draw-walls) आणि [दरवाजे आणि खिडक्या](topic:doors-and-windows) पहा.

| की किंवा कृती | काय करते |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | {{ui:Door}} किंवा {{ui:Window}} सह: कब्जे दुसऱ्या टोकाला |
| भिंत काढताना {{key:Shift}} | ती 0°, 90°, 180° किंवा 270° वर ठेवते |
| अंक आणि फूट व इंच खुणा (`'` आणि `"`) | {{ui:Length}} बॉक्समध्ये लांबी टाइप करणे सुरू करा; {{key:Enter}} ती वापरते |
| {{key:Enter}}, {{key:Esc}}, उजवे-क्लिक किंवा डबल-क्लिक | काढत असलेली भिंत संपवा; {{key:Esc}} पुन्हा दाबल्यास {{ui:Select}} वर परत जा |
| {{key:Delete}} | निवडलेल्या भिंती, दरवाजे आणि खिडक्या हटवा; उरलेल्या भिंती पुन्हा जोडल्या जातात |
| पॉइंटर प्लॅनवर असताना {{key:F}} | प्लॅन फिट करा |
| चाक फिरवा | पॉइंटरभोवती झूम |
| मधले किंवा उजवे बटण ड्रॅग करा, किंवा {{key:Space}} आणि ड्रॅग | पॅन; {{ui:Select}} चालू असताना साधे ड्रॅगही पॅन करते |
| {{ui:Select}} सह दरवाजा किंवा खिडकी ड्रॅग करा | त्याच्या भिंतीवर किंवा दुसऱ्या भिंतीवर हलवा |
| दोन बोटे (टच) | पिंच करून झूम, एकत्र हलवून पॅन |

## लायब्ररी आयटम ठेवणे आणि पेस्ट करणे

| की | काय करते |
|---|---|
| {{key:R}} | आयटम 90° फिरवा |
| {{key:Tab}} | भिंत स्नॅप चालू आणि बंद: आयटमची मागील बाजू जवळच्या भिंतीला टेकते |
| **X, Y (mm)** मध्ये {{key:Enter}} | टाइप केलेल्या स्थानी ठेवा |

## IFC मूल्ये संपादित करणे

| की | काय करते |
|---|---|
| {{key:Enter}} | तुम्ही टाइप केलेले मूल्य ठेवा |
| {{key:Esc}} | रद्द करा आणि जुने मूल्य परत ठेवा |
| इतरत्र क्लिक | तुम्ही टाइप केलेले मूल्य ठेवा |
| {{key:Mod+Z}} | शेवटचा बदल पूर्ववत करा. फक्त तुमचे जतन न केलेले बदल असताना आणि फील्डमध्ये टाइप करत नसताना |
| {{key:Mod+Y}} | Undo ने मागे घेतलेले पुन्हा करा |
| {{key:Mod+S}} | IFC म्हणून जतन करा. फक्त जतन न केलेले बदल असताना; अन्यथा ब्राउझरची स्वतःची जतन कमांड उघडते |

फक्त कीबोर्डने संपादन करण्यासाठी: मूल्य हायलाइट होईपर्यंत {{key:Tab}} दाबा, मग टाइप करणे सुरू करण्यासाठी {{key:Enter}} दाबा.

| {{key:P}} | प्रिंट दृश्य चालू आणि बंद |

| एक बोट (टच) | पॅन. ड्रॉइंगसाठी पिंच झूम अद्याप तयार नाही |

## 3D मधील ड्रॉइंग

| की किंवा कृती | काय करते |
|---|---|
| {{key:3}} | 3D चालू आणि बंद (2D दृश्यावरही) |
| {{key:F}} | एक्स्टेंट्स: संपूर्ण ड्रॉइंग |
| मधल्या किंवा डाव्या बटणाने ड्रॅग | ऑर्बिट |
| उजव्या बटणाने ड्रॅग, किंवा {{key:Shift}} आणि ड्रॅग | पॅन |
| चाक फिरवा | पॉइंटरखाली असलेल्या दिशेने झूम |
| ट्रॅकपॅडवर दोन बोटांचा स्वाइप | ऑर्बिट; {{key:Shift}} सह पॅन |
| ट्रॅकपॅडवर पिंच | झूम |
| एक बोट (टच) | ऑर्बिट |
| दोन बोटे (टच) | पिंच करून झूम, एकत्र हलवून पॅन |

{{key:F}}, {{key:P}} आणि {{key:3}} फील्डमध्ये टाइप करत असताना, उपकरण शेड्यूल दाखवत असताना, किंवा {{key:Mod}} किंवा {{key:Alt}} धरलेले असताना काहीही करत नाहीत.
