दोन व्यक्ती एकाच इमारतीची प्रत घेतात, एक पूर्व विंग काढतो आणि एक पश्चिम; नंतर त्या प्रती एक व्हायला हव्यात. त्यांनी वेगवेगळ्या वस्तूंना स्पर्श केला असेल, तर माणसाऐवजी प्रोग्राम ते करू शकतो.

## हे कसे काम करते

IFC फाइलमधील प्रत्येक भिंत, दरवाजा, लेव्हल, खोली आणि प्रॉपर्टी संचाला एक GlobalId असतो जो कधीही बदलत नाही. मर्ज त्या id वरून वस्तू शोधते, फाइल त्यांना देत असलेल्या क्रमांकावरून नाही (`#123`), कारण प्रोग्राम सेव्ह करतो तेव्हा क्रमांक बदलतात. वस्तूला जोडलेले, पण स्वतःचा id नसलेले भाग (placements, shapes, units) त्यात असलेल्या गोष्टींवरून तुलना केले जातात.

दोन्ही प्रती एकाच IFC आवृत्तीच्या असणे आवश्यक आहे (2x3, 4 किंवा 4.3). मर्ज तुमची फाइल जशी आहे तशी, तिचा क्रम आणि क्रमांकासह ठेवते, आणि जे नवीन आहे ते जोडते, त्यामुळे मर्जचा git diff फक्त मर्जने बदललेले दाखवतो.

## सेटअप

Git ला प्रत्येक repository साठी एकदा दोन ओळी लागतात:

```
# .gitattributes
*.ifc merge=cadcraft

# एकदा, प्रत्येक संगणकावर
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git शिवाय, `cadcraft merge <base> <ours> <theirs>` चालवा. Fossil आणि Mercurial त्याच तीन फाइल्स त्यांच्या स्वतःच्या merge-tool सेटिंगमध्ये घेतात. काहीही अपलोड होत नाही; सर्व काही तुमच्या संगणकावर चालते.

## नियम

- एका बाजूला बदललेला गुणधर्म घेतला जातो. दोन्ही बाजूंनी सारखा बदल असल्यास तो एकदाच घेतला जातो.
- एकाच गुणधर्माचे दोन प्रकारे बदल (एकाच लेव्हलचे दोन प्रकारे नाव बदलणे) म्हणजे **conflict**: तुमची बाजू राहते आणि अहवालात दोन्ही यादी केलेले असतात. निकाल उघडा आणि हाताने दुरुस्त करा.
- गोष्टींची यादी (लेव्हलच्या भिंती, संचाचे गुणधर्म) संच म्हणून मर्ज होते: कोणत्याही बाजूने जोडलेले ठेवले जाते आणि कोणत्याही बाजूने काढलेले काढले जाते. एकाच लेव्हलला भिंती जोडणाऱ्या दोन व्यक्तींमध्ये conflict होत नाही.
- कोणत्याही बाजूने जोडलेली वस्तू तिच्या आकार आणि गुणधर्मांसह ठेवली जाते. एका बाजूने काढलेली आणि दुसरीकडे न बदललेली: काढलेली. एका बाजूने काढलेली आणि दुसरीकडे बदललेली: काढलेली, आणि अहवालात नोंद होते.
- फाइलची वेळ-खूण आणि लेखक, आणि प्रत्येक वस्तूचा owner history, तुमचाच राहतो.

भूमितीचा संपूर्ण मर्ज होतो: भिंतीचा आकार एका बाजूने येतो, कधीही बिंदू-बिंदू मिसळला जात नाही. Zipped IFC आणि IFCX फाइल्स मर्ज होत नाहीत. मर्जनंतर, सेव्ह करण्यापूर्वी BimCraft मध्ये निकाल उघडा आणि {{ui:समस्या}} पॅनल पहा.
