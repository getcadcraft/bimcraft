BimCraft ten poucos atallos. A maioría do traballo fáise co rato e cos paneis. Os atallos escritos con {{key:Mod}} usan Command nun Mac e Ctrl no resto. Vexa [Teclas, ratos e paneis táctiles](common:keys) para ver como se escriben as teclas nesta axuda.

## En todas partes

| Tecla | Que fai |
|---|---|
| {{key:Ctrl+Shift+F}} | Cambiar os modos de pantalla: normal, pantalla completa e pantalla completa con as barras ocultas. Ctrl en todas as plataformas, incluído un Mac |
| {{key:Esc}} | Saír da pantalla completa |
| {{key:Mod+,}} | Abrir {{ui:Configuración}}. Vexa [Configuración de BimCraft](topic:settings) |
| {{key:Tab}} | Moverse entre botóns, caixas de verificación e valores. Pódese chegar a todos os controis co teclado |

## Vista 3D (modelos IFC)

| Tecla ou acción | Que fai |
|---|---|
| {{key:F}} | Axustar todo o modelo, en vista de tres cuartos (igual que {{ui:Axustar}}) |
| {{key:Esc}} | Limpar a selección, ou deixar de colocar ou pegar |
| Clic | Escoller o elemento baixo o punteiro; clic no fondo baleiro para limpar |
| {{key:Mod}}+clic ou {{key:Shift}}+clic | Engadir un elemento á selección, ou quitalo |
| {{key:H}} | Ocultar os elementos escollidos. Vexa [Ocultar, illar e ver a través de elementos](topic:hide-and-isolate) |
| {{key:I}} | Amosar só os elementos escollidos (illar) |
| {{key:T}} | Amosar os elementos escollidos, e o resto a través |
| {{key:Shift+H}} | Amosar de novo todos os elementos |
| {{ui:Camiñar}} | Despois {{key:W}} {{key:A}} {{key:S}} {{key:D}} ou as frechas camiñan, {{key:Shift}} corre, arrastrar mira ao redor, {{key:Esc}} para. Vexa [Camiñar por un modelo](topic:walk) |
| {{key:M}} | Medir distancias e áreas de caras. Vexa [Medir distancias, áreas de caras e posicións en 3D](topic:measure) |
| Arrastrar co botón esquerdo | Orbitar |
| Arrastrar co botón dereito | Desprazar |
| {{key:Shift}} ou {{key:Mod}} e arrastrar co botón esquerdo | Desprazar (útil nun panel táctil) |
| Desprazar a roda, ou arrastrar co botón central | Zoom |
| Desprazamento con dous dedos ou pinzamento nun panel táctil | Zoom |
| Un dedo (tacto) | Orbitar; un toque escolle |
| Dous dedos (tacto) | Pinzamento para facer zoom, mover xuntos para desprazar |

| {{key:X}} | Plano de sección activado e desactivado. Vexa [Cortar un modelo IFC cun plano de sección](topic:section-plane) |
| {{key:Shift+X}} | Caixa de sección ao redor dos elementos escollidos, co espazo libre configurado en {{ui:Configuración}} |

Non hai teclas para {{ui:Superior}}, {{ui:Fronte}} e {{ui:Lateral}}; use os botóns.

## Editar

Os mesmos comandos están na barra de ferramentas: {{ui:Desfacer}}, {{ui:Refacer}}, {{ui:Copiar}}, {{ui:Pegar}} e o menú {{ui:Máis}}, que amosa cada tecla. Funcionan na vista 3D dun modelo IFC, non mentres escribe nun campo. Vexa [Copiar, pegar e duplicar elementos da biblioteca](topic:copy-paste).

| Tecla | Que fai |
|---|---|
| {{key:Mod+Z}} | Desfacer o último cambio |
| {{key:Mod+Y}} ou {{key:Mod+Shift+Z}} | Refacer o que Desfacer retirou |
| {{key:Mod+C}} | Copiar os elementos escollidos (os seus nomes e propiedades tamén van ao portapapeis como texto) |
| {{key:Mod+X}} | Cortar os elementos escollidos: copiádeos e logo eliminaos |
| {{key:Mod+V}} | Pegar o que copiou: segue o punteiro; prema onde debe ir |
| {{key:Mod+Shift+V}} | Pegar no mesmo sitio: onde estaba un corte, ou xunto aos orixinais despois dunha copia |
| {{key:Mod+D}} | Duplicar: copiar os elementos escollidos e empezar a pegalos |
| {{key:Delete}} | Eliminar os elementos escollidos, coas súas partes e buratos. Vexa [Eliminar, cortar, copiar e pegar elementos de edificio](topic:edit-elements) |
| {{key:Mod+A}} | Escoller todos os elementos amosados |
| {{key:Esc}} | Non escoller ningún |

Cando hai texto seleccionado na páxina, {{key:Mod+C}} copia ese texto como de costume.

## Vista en planta (Debuxar)

Estes funcionan mentres {{ui:Debuxar}} está activado e non escribe nun campo. Vexa [Debuxar muros](topic:draw-walls) e [Portas e xanelas](topic:doors-and-windows).

| Tecla ou acción | Que fai |
|---|---|
| {{key:V}} | {{ui:Seleccionar}} |
| {{key:W}} | {{ui:Muro}} |
| {{key:D}} | {{ui:Porta}} |
| {{key:N}} | {{ui:Xanela}} |
| {{key:H}} | Con {{ui:Porta}} ou {{ui:Xanela}}: bisagras no outro extremo |
| {{key:Shift}} mentres debuxa un muro | Mantelo en 0°, 90°, 180° ou 270° |
| Díxitos e as marcas de pé e de polgada (`'` e `"`) | Comezar a escribir unha lonxitude na caixa {{ui:Lonxitude}}; {{key:Enter}} úsaa |
| {{key:Enter}}, {{key:Esc}}, clic dereito ou dobre clic | Rematar o muro que debuxa; {{key:Esc}} de novo volve a {{ui:Seleccionar}} |
| {{key:Delete}} | Eliminar os muros, portas e xanelas escollidos; os muros que quedan únense de novo |
| {{key:F}} co punteiro sobre a planta | Axustar a planta |
| Desprazar a roda | Zoom ao redor do punteiro |
| Arrastrar co botón central ou dereito, ou {{key:Space}} e arrastrar | Desprazar; con {{ui:Seleccionar}} activado, un arrastre simple tamén despraza |
| Arrastrar unha porta ou xanela con {{ui:Seleccionar}} | Movela ao longo do seu muro, ou ata outro muro |
| Dous dedos (tacto) | Pinzamento para facer zoom, mover xuntos para desprazar |

## Colocar e pegar elementos da biblioteca

| Tecla | Que fai |
|---|---|
| {{key:R}} | Xirar o elemento 90° |
| {{key:Tab}} | Axuste ao muro activado e desactivado: a parte traseira do elemento vai contra o muro máis próximo |
| {{key:Enter}} en **X, Y (mm)** | Colocar na posición escrita |
| {{key:Esc}} | Deixar de colocar ou pegar |

## Editar valores IFC

| Tecla | Que fai |
|---|---|
| {{key:Enter}} | Manter o valor escrito |
| {{key:Esc}} | Cancelar e repoñer o valor anterior |
| Clic noutro lugar | Manter o valor escrito |
| {{key:Mod+Z}} | Desfacer o último cambio. Só mentres hai cambios sen gardar e non se escribe nun campo |
| {{key:Mod+Y}} | Refacer o que Desfacer retirou |
| {{key:Mod+S}} | Gardar como IFC. Só mentres hai cambios sen gardar; se non, abre o comando de gardar do navegador |

Para editar só co teclado: prema {{key:Tab}} ata que un valor quede resaltado, despois prema {{key:Enter}} para comezar a escribir.

## Debuxos 2D (DWG e DXF)

| Tecla ou acción | Que fai |
|---|---|
| {{key:F}} | Axustar o debuxo ou a folla |
| {{key:P}} | Vista de impresión activada e desactivada |
| Dobre clic | Axustar |
| Arrastrar con calquera botón | Desprazar |
| Desprazar a roda | Zoom no punteiro |
| Desprazamento con dous dedos ou pinzamento nun panel táctil | Zoom no punteiro. O desprazamento con dous dedos non despraza |
| Un dedo (tacto) | Desprazar. O zoom por pinzamento aínda non está feito para debuxos |

## Debuxos en 3D

| Tecla ou acción | Que fai |
|---|---|
| {{key:3}} | 3D activado e desactivado (tamén na vista 2D) |
| {{key:F}} | Extensións: todo o debuxo |
| Arrastrar co botón central ou esquerdo | Orbitar |
| Arrastrar co botón dereito, ou {{key:Shift}} e arrastrar | Desprazar |
| Desprazar a roda | Zoom cara ao que hai baixo o punteiro |
| Desprazamento con dous dedos nun panel táctil | Orbitar; con {{key:Shift}}, desprazar |
| Pinzamento nun panel táctil | Zoom |
| Un dedo (tacto) | Orbitar |
| Dous dedos (tacto) | Pinzamento para facer zoom, mover xuntos para desprazar |

{{key:F}}, {{key:P}} e {{key:3}} non fan nada mentres escribe nun campo, mentres se amosa o cadro de equipamento, ou cando mantén premida {{key:Mod}} ou {{key:Alt}}.
