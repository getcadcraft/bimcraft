BimCraft роҳҳои кӯтоҳ кам дорад. Бештари корро бо мушк ва панелҳо мекунед. Роҳҳои кӯтоҳе, ки бо {{key:Mod}} навишта шудаанд, дар Mac Command ва дар ҷои дигар Ctrl истифода мешаванд. Ба [Калидҳо, мушкҳо ва трекпадҳо](common:keys) нигаред, то бидонед, ки калидҳо дар ин роҳнамо чӣ гуна навишта мешаванд.

## Ҳама ҷо

| Калид | Чӣ мекунад |
|---|---|
| {{key:Ctrl+Shift+F}} | Гардиши реҷаҳои экран: муқаррарӣ, экрани пурра, экрани пурра бо панелҳои пинҳон. Ctrl дар ҳар система, аз ҷумла Mac |
| {{key:Esc}} | Аз экрани пурра баромадан |
| {{key:Mod+,}} | Кушодани {{ui:Танзимот}}. Ба [Танзимоти BimCraft](topic:settings) нигаред |
| {{key:Tab}} | Ҳаракат байни тугмаҳо, қуттиҳои интихоб ва арзишҳо. Ҳар идора бо клавиатура дастрас аст |

## Намуди 3D (моделҳои IFC)

| Калид ё амал | Чӣ мекунад |
|---|---|
| {{key:F}} | Ҷо кардани тамоми модел, намуди се-чоряк (ҳамон тавре ки {{ui:Ҷо кардан}}) |
| {{key:Esc}} | Тоза кардани интихоб, ё бас кардани ҷойгиркунӣ ё гузоштан |
| Клик | Интихоби унсуре, ки зери ишора аст; клик дар пасзамини холӣ интихобро тоза мекунад |
| {{key:Mod}}+клик ё {{key:Shift}}+клик | Илова ба интихоб ё берун гирифтани унсур |
| {{key:H}} | Пинҳон кардани унсурҳои интихобшуда. Ба [Пинҳон, ҷудо ва шаффоф дидани унсурҳо](topic:hide-and-isolate) нигаред |
| {{key:I}} | Танҳо унсурҳои интихобшударо нишон додан (ҷудо кардан) |
| {{key:T}} | Унсурҳои интихобшударо нишон додан, ҳама дигарҳо шаффоф |
| {{key:Shift+H}} | Ҳама унсурҳоро боз нишон додан |
| {{ui:Сайр}} | Пас аз он {{key:W}} {{key:A}} {{key:S}} {{key:D}} ё тирҳо роҳ рафтан, {{key:Shift}} давидан, кашидан нигоҳ карданро мегардонад, {{key:Esc}} бас мекунад. Ба [Роҳ рафтан дар модел](topic:walk) нигаред |
| {{key:M}} | Чен кардани масофаҳо ва масоҳати рӯҳо. Ба [Чен кардани масофаҳо, масоҳати рӯҳо ва мавқеъҳо дар 3D](topic:measure) нигаред |
| Кашидан бо тугмаи чап | Гардиш |
| Кашидан бо тугмаи рост | Ҷойивазкунӣ |
| {{key:Shift}} ё {{key:Mod}} ва кашидан бо тугмаи чап | Ҷойивазкунӣ (барои трекпад қулай) |
| Чарх задани чарх ё кашидан бо тугмаи миёна | Калонкунӣ |
| Скролли ду ангушт ё печондан дар трекпад | Калонкунӣ |
| Як ангушт (ламс) | Гардиш; як пахш интихоб мекунад |
| Ду ангушт (ламс) | Печондан барои калонкунӣ, якҷоя ҳаракат барои ҷойивазкунӣ |

| {{key:X}} | Ҳавопаи буриш фаъол ва ғайрифаъол. Ба [Буридани модели IFC бо ҳавопаи буриш](topic:section-plane) нигаред |
| {{key:Shift+X}} | Қуттии буриш дар атрофи унсурҳои интихобшуда, бо ҳуҷра дар Танзимот |

Барои {{ui:Боло}}, {{ui:Пеш}} ва {{ui:Аз паҳлу}} калид нест; тугмаҳоро истифода баред.

## Таҳрир

Фармонҳои ҳамон дар панели абзорӣ ҳастанд: {{ui:Баргардондан}}, {{ui:Такрор кардан}}, {{ui:Нусха бардоштан}}, {{ui:Гузоштан}} ва менюи {{ui:Бештар}}, ки ҳар калидро нишон медиҳад. Онҳо дар намуди 3D-и модели IFC кор мекунанд, на ҳангоми навиштан дар майдон. Ба [Нусха бардоштан, гузоштан ва дубора сохтани ашёи китобхона](topic:copy-paste) нигаред.

| Калид | Чӣ мекунад |
|---|---|
| {{key:Mod+Z}} | Баргардондани тағйироти охирин |
| {{key:Mod+Y}} ё {{key:Mod+Shift+Z}} | Такрор кардани он чи Баргардондан гирифт |
| {{key:Mod+C}} | Нусха бардоштани унсурҳои интихобшуда (номҳо ва хосиятҳояшон ҳамчунин ҳамчун матн ба буфери мубодила мераванд) |
| {{key:Mod+X}} | Буридани унсурҳои интихобшуда: нусха бардоштан, сипас нест кардан |
| {{key:Mod+V}} | Гузоштани он чи нусха бардоштед: ба ишора пайравӣ мекунад, клик кунед, ки ба куҷо меравад |
| {{key:Mod+Shift+V}} | Гузоштан дар ҷои худаш: ҷое, ки буридан аз он омада буд, ё дар паҳлӯи асл пас аз нусха |
| {{key:Mod+D}} | Дубора сохтан: унсурҳои интихобшударо нусха бардоред ва гузоштани онҳоро оғоз кунед |
| {{key:Delete}} | Нест кардани унсурҳои интихобшуда, бо қисмҳо ва кушодаҳояшон. Ба [Нест кардан, буридан, нусха бардоштан ва гузоштани унсурҳои сохтмонӣ](topic:edit-elements) нигаред |
| {{key:Mod+A}} | Интихоби ҳама унсурҳои нишондодашуда |
| {{key:Esc}} | Ҳеҷ интихоб накардан |

Вақте ки матн дар саҳифа интихоб шудааст, {{key:Mod+C}} матнро мисли одатӣ нусха мекунад.

## Намуди нақша (Кашидан)

Инҳо вақте кор мекунанд, ки {{ui:Кашидан}} фаъол аст ва шумо дар майдон матн намеравед. Ба [Кашидани деворҳо](topic:draw-walls) ва [Дарҳо ва тирезаҳо](topic:doors-and-windows) нигаред.

| Калид ё амал | Чӣ мекунад |
|---|---|
| {{key:V}} | {{ui:Интихоб кардан}} |
| {{key:W}} | {{ui:Девор}} |
| {{key:D}} | {{ui:Дар}} |
| {{key:N}} | {{ui:Тиреза}} |
| {{key:H}} | Бо {{ui:Дар}} ё {{ui:Тиреза}}: лӯлаҳо дар сари дигар |
| {{key:Shift}} ҳангоми кашидани девор | Онро дар 0°, 90°, 180° ё 270° нигоҳ медорад |
| Рақамҳо ва нишонаҳои фут ва дюйм (`'` ва `"`) | Ба қуттии {{ui:Дарозӣ}} дарозиро навиштан оғоз кунед; {{key:Enter}} онро истифода мебарад |
| {{key:Enter}}, {{key:Esc}}, клики рост ё дуқатор | Деворро, ки мекашед, бас мекунад; {{key:Esc}} такрор ба {{ui:Интихоб кардан}} бармегардад |
| {{key:Delete}} | Нест кардани деворҳо, дарҳо ва тирезаҳои интихобшуда; деворҳои боқимонда боз пайваст мешаванд |
| {{key:F}} бо ишора дар нақша | Ҷо кардани нақша |
| Скролли чарх | Калонкунӣ дар атрофи ишора |
| Кашидан бо тугмаи миёна ё рост, ё {{key:Space}} ва кашидан | Ҷойивазкунӣ; бо {{ui:Интихоб кардан}} фаъол, кашидани оддӣ низ ҷойивазкунӣ мекунад |
| Кашидани дар ё тиреза бо {{ui:Интихоб кардан}} | Онро дар девораш ё ба девори дигар ҳаракат додан |
| Ду ангушт (ламс) | Печондан барои калонкунӣ, якҷоя ҳаракат барои ҷойивазкунӣ |

## Ҷойгир ва гузоштани ашёи китобхона

| Калид | Чӣ мекунад |
|---|---|
| {{key:R}} | Ашёро 90° чарх занед |
| {{key:Tab}} | Пайвастшавӣ ба девор фаъол ва ғайрифаъол: пушти ашё ба девори наздиктарин меояд |
| {{key:Enter}} дар **X, Y (mm)** | Ҷойгир кардан дар мавқеи навишташуда |
| {{key:Esc}} | Бас кардани ҷойгиркунӣ ё гузоштан |

## Таҳрири арзишҳои IFC

| Калид | Чӣ мекунад |
|---|---|
| {{key:Enter}} | Арзишеро, ки навиштед, нигоҳ доштан |
| {{key:Esc}} | Бекор кардан ва арзиши кӯҳнаро баргардондан |
| Клик дар ҷои дигар | Арзиши навиштаатонро нигоҳ доштан |
| {{key:Mod+Z}} | Баргардондани тағйироти охирин. Танҳо вақте, ки тағйироти захиранашуда доред ва дар майдон матн намеравед |
| {{key:Mod+Y}} | Такрор кардани он чи Баргардондан гирифт |
| {{key:Mod+S}} | Захира ҳамчун IFC. Танҳо вақте, ки тағйироти захиранашуда доред; вагарна фармони захираи браузер кушода мешавад |

Барои таҳрир бо танҳо клавиатура: {{key:Tab}}-ро пахш кунед, то арзиш ранга нишон дода шавад, сипас барои оғози навиштан {{key:Enter}}-ро пахш кунед.

## Нақшаҳои 2D (DWG ва DXF)

| Калид ё амал | Чӣ мекунад |
|---|---|
| {{key:F}} | Ҷо кардани нақша ё варақ |
| {{key:P}} | Намуди чоп фаъол ва ғайрифаъол |
| Дуқатор | Ҷо кардан |

| Як ангушт (ламс) | Ҷойивазкунӣ. Калонкунии печонидан барои нақшаҳо ҳанӯз сохта нашудааст |

## Нақшаҳо дар 3D

| Калид ё амал | Чӣ мекунад |
|---|---|
| {{key:3}} | 3D фаъол ва ғайрифаъол (ҳамчунин дар намуди 2D) |
| {{key:F}} | Ҳудуд: тамоми нақша |
| Кашидан бо тугмаи миёна ё чап | Гардиш |
| Кашидан бо тугмаи рост ё {{key:Shift}} ва кашидан | Ҷойивазкунӣ |
| Скролли чарх | Калонкунӣ ба сӯи чизе, ки зери ишора аст |
| Ҳаракати ду ангушт дар трекпад | Гардиш; бо {{key:Shift}}, ҷойивазкунӣ |
| Печондан дар трекпад | Калонкунӣ |
| Як ангушт (ламс) | Гардиш |
| Ду ангушт (ламс) | Печондан барои калонкунӣ, якҷоя ҳаракат барои ҷойивазкунӣ |

{{key:F}}, {{key:P}} ва {{key:3}} ҳеҷ коре намекунанд, вақте ки дар майдон матн менависед, вақте ки ҷадвали таҷҳизот нишон дода мешавад ё вақте ки {{key:Mod}} ё {{key:Alt}}-ро нигоҳ медоред.
