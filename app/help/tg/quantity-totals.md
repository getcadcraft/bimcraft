## Чӣ хоҳед кард

Аз модел ҷамъҳоро гиред: дарозии деворҳо дар ҳар ошёна, шумораи дарҳо барои ҳар намуд, ҳаҷми плита барои ҳар мавод, арзиши ҳар зона.

## Қадамҳо

1. Модели IFC-ро кушоед.
2. {{ui:Quantity totals}}-ро дар панели чап кушоед.
3. Дар {{ui:Count}} интихоб кунед: {{ui:Every element}} ё танҳо интихобшудаҳо.
4. Зери {{ui:Group by}} хосиятеро интихоб кунед, масалан {{ui:Class}}. {{ui:Add a group}}-ро пахш кунед, то боз то се маротиба тақсим кунед, масалан аз рӯи {{ui:Storey}}.
5. Зери {{ui:Add up}} рақамҳоро барои ҷамъ ишора кунед. Маҷмӯаҳои миқдории модел дар аввал ишора шудаанд.
6. {{ui:Download CSV}}-ро пахш кунед, то ҷадвал дар барномаи ҷадвал кушода шавад.

## Чиро бояд бинед

- Барои ҳар гурӯҳ як сатр бо шумораи элементҳо ва ҳар ҷамъ, ва сатри умумӣ.
- Элементҳои бе арзиш шумурда мешаванд, вале ба ҷамъ чизе илова намекунанд. Вақте ин рӯй диҳад, CSV сутуни «left out»-ро дар паҳлуи ҷамъ илова мекунад, то шумо шумораи онҳоро бинед.
- Рақамҳо дар воҳидҳои худи файл ҳастанд, ҳамонтавре ки файл онҳоро нигоҳ медорад, аксаран миллиметр барои дарозиҳо.

## Як сатр барои ҳар элемент ё фазоҳо

{{ui:Show}}-ро иваз кунед:

- **Як сатр барои ҳар элемент**: ҳар элемент дар сатри худаш, бо хосиятҳо зери {{ui:Columns}} ва рақамҳо зери {{ui:Add up}}. CSV бо GlobalId-и ҳар элемент оғоз мешавад. Барои интихоби он элемент, арзиши аввалини сатрро пахш кунед.
- **Фазоҳо**: ҳар ҳуҷра бо рақам, номаш, ошёнааш, масоҳат ва ҳаҷмаш, ва ҷамъҳояшон. Масоҳат ва ҳаҷм аз миқдорҳои фазо мебошанд, тавре ки файл онҳоро мегӯяд. Вақте ки файл онҳоро надорад, онҳо аз шакли фазо дар м² ва м³ чен карда мешаванд ва бо хати моил нишон дода мешаванд; CSV мегӯяд, ки кадом аст.

## Инфрасохтор (IFC 4.3)

Дар рӯйхати намудҳо **Infrastructure (IFC 4.3)** -ро интихоб кунед, то роҳҳо, роҳҳои оҳан, пулҳо ва корҳои баҳрӣ ба ҳар синф ва намуд ҷамъ шаванд, бо дарозӣ, масоҳат ва ҳаҷме, ки худи файл мегӯяд. Миқдоре, ки файл намегӯяд, холӣ гузошта мешавад ва ҳеҷ гоҳ ҳисоб карда намешавад. **Send infrastructure quantities to TakeoffCraft** файли `.quantities.json` захира мекунад, ки TakeoffCraft онро ҳамчун миқдорҳои навъдор мекушояд.
