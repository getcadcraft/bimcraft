{{ui:Render}} дар болои {{ui:Mode}} интихоби **Муҳаррик** дорад. Муҳаррикҳои худамон ҳамеша ҳастанд ва ҳама ҷо кор мекунанд; иловаҳо метавонанд бештар илова кунанд ва дар CadCraft Studio рӯйхат инчунин барномаҳоеро дар бар мегирад, ки саҳнаро ба дӯш мегиранд.

| Муҳаррик | Чӣ мекунад | Дар куҷо |
|---|---|---|
| Дарунсохт: Тез | Тасвири зуд: рӯшноии рӯз, сояҳои нарм, намуди шиша ва металл, дар чанд сония | Браузер ва Studio |
| Дарунсохт: Path tracer | Нури аз сатҳҳо бозтобанда дар корти графикӣ ё процессори шумо, навбати рендер ва компютерҳои дигари шабакаи шумо | Браузер ва Studio |
| Муҳаррики илова | Тасвирро мекашад ва бармегардонад: нигаред ба [Тасвирро бо барномаи дигар кашидан](topic:render-other-program) | Браузер (муҳаррике, ки бо JavaScript навишта шудааст) ё Studio (муҳаррике, ки барномаро иҷро мекунад) |
| Барномае, ки саҳнаро ба дӯш мегирад | Studio саҳнаро дар папкаи худ мегузорад ва онро мувофиқ нигоҳ медорад | Studio |
| Кушодан дар … | Саҳнаро захира мекунад ва дар барнома мекушояд; ҳеҷ чиз баргашта намеояд: нигаред ба [Саҳнаро дар барномаи дигар кушодан](topic:render-open-in) | Веб файлро захира мекунад |

## Тарзи интихоб

- Интихоби Тез ё Path tracer ҳолати {{ui:Mode}}-ро низ иваз мекунад ва баръакс. Ҳеҷ чизи дигари равзана барои онҳое, ки муҳаррики дигар истифода намебаранд, тағйир намеёбад.
- Муҳаррике, ки дастрас нест, дар рӯйхат бо сабаб мемонад («ёфт нашуд», «версияи навтар лозим аст»); онро интихоб кардан мумкин нест. Дар браузер муҳаррике, ки танҳо дар Studio кор мекунад, «файлро захира мекунад» нишон медиҳад: пас {{ui:Render}} саҳна ва танзимоти онро ба файле захира мекунад, ки шумо ба он барнома мебаред.
- Интихоб бо танзимоти рендери файл захира мешавад ва муҳаррике, ки охирон интихоб кардед, барои файлҳое, ки интихоби худро надоранд, муҳаррики оғозкунанда мешавад.
- Тасвир аз барномаи дигар мегӯяд, ки кадом барнома ва версияи онро кашидааст, дар равзана ва дар навбати рендер. Ваъдаҳои саҳифаи [Рендер](topic:render) танҳо ба муҳаррикҳои **худамон** дахл доранд: барномаи дигар рӯшноӣ, ранг ва намунагириро ба тарзи худаш мекунад, бинобар ин ду тасвири як саҳна дар камера, офтоб, чароғҳо ва ошкоршавӣ монанданд, на пиксел ба пиксел.

## Чӣ ба ҳар муҳаррик дода мешавад

Саҳна ба барномаи дигар ҳамчун **бастабандӣ** мерасад: модел ҳамчун файли USD (ҳамон файле, ки [Захира ҳамчун USD](topic:usd) менависад) ва файли танзимот, ки чизҳоеро дар бар мегирад, ки ба воридкунандаи USD бовар кардан мумкин нест: арзишҳои дақиқи мавод, чароғҳое, ки равшананд, бо қувват ва профили нурашон, офтоб, осмон, ошкоршавӣ ва камера, тавре ки равзана онро мекашад. Ҳеҷ чиз ба ҷое фиристода намешавад.

## Навбати рендер

Тасвир барои барномаи дигар метавонад мисли муҳаррикҳои худамон дар [навбати рендер](topic:render#the-render-queue) интизор шавад; кори он ба ёд медорад, ки барои кадом муҳаррик аст.
