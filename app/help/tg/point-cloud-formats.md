## Чӣ дар ин ҷо кушода мешавад

Инҳоро бо {{ui:Open}} ё бо андохтани онҳо ба саҳифа кушоед (мавзӯъи нишон додани абри нуқтаҳо дар паҳлӯи модел -ро бинед):

| Формат | Пасванд | Чӣ хонда мешавад |
|---|---|---|
| LAS, LAZ | `.las`, `.laz` | LAS 1.0–1.4: нуқтаҳо, рангҳо, шиддат, синфҳои LiDAR, системаи координатҳо. LAZ то 1 GB. |
| E57 | `.e57` | Ҳар скан дар файл, ҳар кадом бо ҷойгиршавии худ; рангҳо, ё шиддат агар файл рангҳо надошта бошад. Тасвирҳо дар файл гузошта мешаванд (гуфта мешавад). Фаъло то 6 миллион нуқта ва 512 MB: сканҳои калонтарро ҳамчун LAS ё LAZ содир кунед. |
| PLY | `.ply` | Матн ва дуӣ (ҳарду тартиби баиҳо): x y z-и нуқтаҳо, рангҳо ва шиддат. Рӯяҳо гузошта мешаванд (гуфта мешавад). |
| PCD | `.pcd` | Матн ва дуӣ: x y z, рангҳои якҷоя ё ҷудо, шиддат. Файлҳои фишурдаи PCD ҳанӯз хонда намешаванд: онҳоро ҳамчун дуӣ ё матн захира кунед. |
| PTX | `.ptx` | Як ё чанд скан, ҳар кадом бо трансформатсияи худ; нуқтаҳое, ки скактор чен накардааст, гузошта мешаванд. Метр. |
| PTS, XYZ | `.pts`, `.xyz` | Матн: x y z, бо шиддат ва рангҳо агар сутунҳо бошанд. |

## Файлҳое, ки танҳо барномаи скактор мехонад

Баъзе файлҳои скан формати хоси созандаи скактор мебошанд, бе тавсифи нашршуда ва бе хонандаи кушод. BimCraft онҳоро хонда наметавонад ва кушодани ҳар кадоми онҳо корт нишон медиҳад, ки мегӯяд он чист ва чӣ бояд кард. Скан аз барномаи созанда ҳамчун E57 ё LAS (ё PTX, PTS) содир кунед ва сипас файли содиротро кушоед.

| Файл | Пасванд | Аз кадом барнома содир кунед |
|---|---|---|
| Лоиҳаи ReCap | `.rcp` | ReCap: лоиҳаро кушоед ва содир кунед. Лоиҳа танҳо ба сканҳои худ ишора мекунад, пас танҳо нусхабардории `.rcp` нуқта намедиҳад. |
| Скани ReCap | `.rcs` | ReCap: лоиҳаеро, ки скан ба он тааллуқ дорад, кушоед ва содир кунед. |
| Скани FARO | `.fls` | FARO SCENE. |
| Скани Leica | `.lgs` | Leica Cyclone REGISTER 360. |
| Скани Trimble | `.tzf` | Trimble RealWorks ё Trimble Business Center. |
| Скани Z+F | `.zfs` | Z+F LaserControl. |

:::tip
Вақте ки содирот формат мепурсад, LAS ё LAZ ҳама чиро, ки BimCraft нишон медиҳад (рангҳо, шиддат, синфҳо ва системаи координатҳо), дар файли хурдтарин нигоҳ медорад.
:::

## Чаро ин файлҳо хонда намешаванд

Ин формат нашр нашудаанд ва ягона роҳи хондани онҳо китобхонаи худи барномаи ҳар созанда аст, бо шартҳои худаш. BimCraft танҳо форматҳоеро мехонад, ки бо коди худаш дар компютери шумо хонда метавонад, пас скан ҳеҷ гоҳ барои кушодан ба ҷое фиристода намешавад.
