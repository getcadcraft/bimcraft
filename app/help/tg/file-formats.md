## IFC

| Хонда мешавад | Тафсилот |
|---|---|
| Геометрия | Ҳар унсур бо шакл, рангаш мисли файл мегӯяд. Ҳуҷраҳо ва фазоҳо шаффоф кашида мешаванд ва аввал пинҳонанд |
| Ошёнаҳо | Ошёнаҳои бино дар тартиби баландӣ ва он ки кадом унсурҳо дар ҳар кадом ҳастанд. Унсурҳое ки дар ягон ошёна нестанд, ҳамчун «Дар ошёна нест» гурӯҳ мешаванд |
| Шумораи унсурҳо | Чанд унсур аз ҳар навъ (деворҳо, дарҳо, плитаҳо…), дар {{ui:Унсурҳо}} нишон дода мешаванд |
| Маълумоти лоиҳа | Номи лоиҳа, номи пурра ва марҳала; схема; барномаи содиркунанда, муаллиф ва санаи содирот аз сарлавҳаи файл |
| Маълумоти унсур | Ном, навъ, навъи объект, тег, тавсиф, GlobalId; ҳар маҷмӯаи хосият ва маҷмӯаи миқдор дар унсур ва навъи он |

Таҳриршаванда: ном, навъи объект, тег, тавсиф ва арзишҳои хосияти ягона. Ҳамчун файли нави IFC захира мешавад. Схемаҳои IFC2X3, IFC4 ва IFC4X3 кушода мешаванд ва бо муҳаррики IFC-и худи BimCraft хонда мешаванд; ҳар чизе ки то ҳол кашида наметавонад, дар панели **Ҳанӯз кашида нашудааст** дар {{ui:Файл}} оварда мешавад. Модел ҳангоми кушодан ба нуқтаи сифр кӯчонида мешавад, пас модели аз он дур ҷойгиршуда бо вуҷуди ин дар марказ нишон дода мешавад. `.ifczip` ва `.ifcxml` кушода намешаванд.

## Файлҳои лоиҳа ва оила

Лоиҳаҳои `.rvt`, шаблонҳои лоиҳаи `.rte`, оилаҳои `.rfa` ва шаблонҳои оилаи `.rft`.

| Хонда мешавад | Тафсилот |
|---|---|
| Маълумоти файл | Нашр ва версия, ҳамкорӣ, роҳи модели марказӣ, роҳи охирин захирашуда, номи корбар, минтақа, GUID-и ҳуҷҷат |
| Маълумоти лоиҳа | Майдонҳои худи лоиҳа (ном, рақам, муштарӣ, нишонӣ, ҳолат…), бе пешфарзҳои лоиҳаи нав |
| Маълумоти оила | Номи оила, категория, нашр, навсозии охирин ва параметрҳояш аз рӯи гурӯҳ |
| Пайвандҳо | Рӯйхати моделҳои пайвандшуда, пайвандҳои CAD, тасвирҳо ва ҷадвалҳои калидвожаҳо, ки файл ба онҳо ишора мекунад |
| Тасвири пешнамо | Тасвири хурди захирашуда дар файл |

Хонда намешавад: модели 3D, унсурҳо, намудҳо, варақҳо ва ҷадвалҳо. Онҳо дар формати ҳуҷҷатгузорӣнашуда захира мешаванд. BimCraft аз ҳар файл фақат чанд даҳ килобайт мехонад, аз ин рӯ андозаи файл кам аҳамият дорад.

## Файлҳои лоиҳаи .pln, .pla, .tpl ва .bpn

Ҳоло хонда намешаванд: BimCraft ҳангоми кушодани ҳар кадоми онҳо ин гуфта мешавад. Барои модел IFC ва барои нақшаҳо DWG содир кунед; ниг. [Кушодани файлҳои лоиҳаи .pln ва .pla](topic:pln-project-files).

## DWG ва DXF

| Хонда мешавад | Тафсилот |
|---|---|
| Фазоҳо | Фазои модел ва ҳар варақ (тарҳбандӣ), бо тартиби барғак |
| Намоишгоҳҳо | Намоишгоҳҳои ҳар варақ, бо миқёс, гардиш ва қабатҳои яхкардашуда |
| Қабатҳо | Ном, ранг, рӯшан/хомӯш, яхкардашуда, аломати чоп ва вазни хат |
| Объектҳо | Хатҳо, полихатҳо, камонҳо, давраҳо, эллипсҳо, сплайнҳо, штрихгузориҳо ва ҷисмҳо, матн ва матни бисёрсатрӣ, блокҳо ва атрибутҳо, андозаҳо, ишоратҳо ва мултиишоратҳо, ҷадвалҳо, нуқтаҳо, тасвирҳо |
| Нақшаҳои пайвандшуда | Кашида мешаванд, дар ҷое ки дохил шудаанд, вақте файлҳояшон ёфт шаванд |
| Тасвирҳо | Аз файлҳои тасвир кашида мешаванд, вақте ёфт шаванд (PNG, JPEG, GIF, BMP, WebP; TIFF не) |
| Тегҳои таҷҳизот | Тегҳои ашёи хӯроквориӣ (атрибутҳои `KCL-ITEM`), барои ҷадвали таҷҳизот |

Ҳар чизи дигар дар **Ҳанӯз кашида нашудааст** шумурда мешавад ва ҳеҷ гоҳ тахмин карда намешавад. Форматҳои DWG аз AutoCAD 2000 то 2018 санҷида шудаанд (файлҳои R13 ва R14 низ қабул мешаванд, аммо дар маҷмӯаи санҷиш ягонаашон набуд; DWG-и кӯҳна кушода намешаванд); панели {{ui:Нақша}} рамзи форматро нишон медиҳад (мисли AC1032). Файлҳои DXF-и ҳар версия, аз ҷумла R12, кушода мешаванд. Ҳарду аз ҷониби хонандаҳои худи BimCraft, дар ин барғак хонда мешаванд. Ҳеҷ чиз ба DWG ё DXF захира намешавад.

## Дар ҷузвдон

| Навъ | Пасвандҳо | Дар ҳисобот |
|---|---|---|
| Моделҳо | `.rvt` `.rfa` `.rte` `.rft` | Бо нусхаҳои рақамдор гурӯҳбандӣ шудаанд, солимӣ санҷида шудааст, корти маълумот хонда шудааст, пайвандҳо санҷида шудаанд |
| IFC | `.ifc` | Рӯйхат мешавад; дар 3D кушода мешавад |
| CAD | `.dwg` `.dxf` `.dgn` | Бо моделҳое, ки онҳоро пайваст мекунанд, рӯйхат мешавад; DWG ва DXF дар 2D кушода мешаванд, DGN не |
| Партовҳо | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | Дар зери **Ҷудо гузошта шудааст** рӯйхат мешавад |
| Ҷузвдонҳои нигоҳдорӣ | `*_backup`, `*_log`, `Revit_temp`, ҷузвдонҳои пинҳон | Дар зери **Ҷудо гузошта шудааст** рӯйхат мешавад, хонда намешавад |

Ниг. [Ҳисоботи ҷузвдон: нақшҳо, ҳолатҳо ва пайвандҳо](topic:folder-roles).
