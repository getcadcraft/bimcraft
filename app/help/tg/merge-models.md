Ду нафар нусхаи як бино мегиранд: яке қанотҳои шарқиро мекашад ва дигаре ғарбиро, ва баъдан нусхаҳо бояд ба як чиз табдил ёбанд. Агар онҳо объектҳои гуногунро таҳрир кардаанд, барнома ба ҷои одам инро карда метавонад.

## Чӣ коркардро мекунад

Ҳар девор, дар, сатҳ, ҳуҷра ва маҷмӯаи хосиятҳо дар файли IFC GlobalId дорад, ки ҳеҷ гоҳ тағйир намеёбад. Якҷоякунӣ объектҳоро бо ҳамин id ҷустуҷӯ мекунад, на бо рақами, ки файл ба онҳо медиҳад (`#123`), зеро рақамҳо ҳангоми захиркунии барнома тағйир меёбанд. Ҷузъҳои овезон аз объекте, ки id-и худашон надоранд (ҷойгиркунӣ, шаклҳо, воҳидҳо), бо мундариҷаи худашон муқоиса мешаванд.

Ҳарду нусха бояд як версияи IFC дошта бошанд (2x3, 4 ё 4.3). Якҷоякунӣ файли шуморо, тартиб ва рақамҳои онро тавре ки ҳаст, нигоҳ медорад ва чизи навро илова мекунад, аз ин рӯ git diff-и якҷоякунӣ танҳо он чизеро нишон медиҳад, ки якҷоякунӣ тағйир додааст.

## Танзим

Git барои як омбор ду сатр талаб мекунад:

```
# .gitattributes
*.ifc merge=cadcraft

# як маротиба, дар ҳар компютер
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Бе git, `cadcraft merge <base> <ours> <theirs>`-ро иҷро кунед. Fossil ва Mercurial ҳамон се файлро дар танзимоти асбоби якҷоякунии худашон қабул мекунанд. Ҳеҷ чиз боргузорӣ намешавад; ҳама дар компютери шумо иҷро мешаванд.

## Қоидаҳо

- Хосияте, ки танҳо дар як тараф тағйир ёфтааст, гирифта мешавад. Ҳамон тағйир дар ҳарду тараф як бор гирифта мешавад.
- Ҳамон хосият ду роҳ тағйир ёфтааст (ҳамон сатҳ ду роҳ номгузорӣ шудааст) — ин **ихтилоф** аст: тарафи шумо мемонад ва ҳисобот ҳарду тарафро рӯйхат мекунад. Натиҷаро кушоед ва бо дасти худ дуруст кунед.
- Рӯйхати чизҳо (деворҳои як сатҳ, хосиятҳои маҷмӯа) ҳамчун маҷмӯа якҷоя мешавад: он чизе, ки ҳар тараф илова кардааст, нигоҳ дошта мешавад ва он чизе, ки ҳар тараф нест кардааст, нест карда мешавад. Ду нафар, ки ҳар кадом ба як сатҳ девор илова мекунанд, ихтилоф намедиҳанд.
- Объекте, ки дар ҳар тараф илова шудааст, бо шакл ва хосиятҳояш нигоҳ дошта мешавад. Дар як тараф нест шуда ва дар дигар дастнашуда: нест карда мешавад. Дар як тараф нест шуда ва дар дигар тағйир ёфта: нест карда мешавад ва гузориш дода мешавад.
- Вақт ва муаллифи файл ва таърихи соҳибии ҳар объект аз они шумо мемонанд.

Геометрия пурра якҷоя мешавад: шакли девор аз як тараф меояд, ҳеҷ гоҳ нуқта ба нуқта омехта намешавад. Файлҳои IFC ва IFCX-и фишурдашуда якҷоя намешаванд. Пас аз якҷоякунӣ натиҷаро дар BimCraft кушоед ва панели {{ui:Мушкилот}}-ро пеш аз захира кардан бинед.
