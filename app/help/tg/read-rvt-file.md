## Чӣ хоҳед кард

Бидонед, ки дар файли лоиҳа ё оила чӣ аст, бе кушодани он дар Revit: кадом нашр онро захира кардааст, оё кори якҷоя дорад, маълумоти лоиҳа ва ба чӣ пайваст мешавад. Ин вақте муфид аст, ки файл аз дигаре меояд ва шумо бояд бидонед, ки онро дар кадом нашр кушодан лозим аст.

## Қадамҳо

1. {{ui:Choose a file}}-ро пахш кунед.
2. Файли `.rvt`, `.rfa`, `.rte` ё `.rft` -ро интихоб кунед.
3. Лаҳзае интизор шавед. Хати ҳолат «Файл хонда мешавад…» ва сипас «Кушода шуд: *номи файл*»-ро нишон медиҳад.
4. Дар боло, дар саргаҳи корт, тасвири пешнамоиши захиршуда дар файл, навъи файл ва нашре, ки онро захира кардааст, ва номи лоиҳаро бинед.
5. Поён гардонед, то бахшҳои корт хонда шаванд.

## Чиро бояд бинед

Корт дар миёна, бо ин бахшҳо, вақте ки файл онҳоро дорад:

| Бахш | Чиро мегӯяд |
|---|---|
| File | Номи файл, андоза, навъ (лоиҳа, шаблони лоиҳа, оила ё шаблони оила), нашр ва сохтае, ки онро захира кардааст, кори якҷоя, роҳи модели марказӣ, он ҷое ки охирин бор захира шуд, кӣ захира кардааст, забон ва GUID-и ҳуҷҷат |
| Project information | Майдонҳои худи лоиҳа, ба монанди ном, рақам, мизоҷ, нишонӣ ва ҳолат. Майдонҳое, ки ҳанӯз дар арзишҳои пешфарзии лоиҳаи нав ҳастанд, гузошта мешаванд. |
| Family, Family: … | Барои оила: номи он, категория, нашр, навсозии охирин ва параметрҳояш, гурӯҳ ба гурӯҳ |
| Linked and referenced files | Ҳар модели пайваст, пайванди CAD, тасвир ва ҷадвали калидҳо, ки файл ба онҳо ишора мекунад, бо роҳи захиршудаашон |

Дар чап панели {{ui:File}} далелҳои асосиро такрор мекунад ва **Read**-ро илова мекунад: BimCraft чӣ қадари файлро хонд, маъмулан тақрибан 40 KB аз файле, ки чандин MB аст. Дар рост панели {{ui:Properties}} мегӯяд, ки хосиятҳои элементҳо модели 3D-ро талаб мекунанд.

## Чаро 3D нест

Модели 3D ва элементҳои дохили файли лоиҳа дар формати ҳуҷҷатнашуда захира мешаванд. BimCraft танҳо қисмҳои файлро мехонад, ки ҳуҷҷатӣ ё ошкоро хонда мешаванд: маълумоти файл, маълумоти лоиҳа, маълумоти оила, рӯйхати пайвандҳо ва тасвири пешнамоиш. Бақияро тахмин намезанад. Барои дидани модел дар 3D ва хондани хосиятҳои элементҳо, IFC-ро аз барномае, ки файлро сохтааст, содир кунед. [Файли лоиҳаро тавассути IFC ба 3D овардан](topic:rvt-to-ifc) -ро бинед.

## Иштибоҳҳои маъмул

- **Интизори 3D.** Ба боло нигаред.
- **Пайвандҳо танҳо роҳи захиршудаашонро нишон медиҳанд.** Файле, ки танҳо кушода мешавад, наметавонад санҷад, ки пайвандҳояш ҳастанд. Ба ҷои он ҷузвдоне, ки он дар он ҷост, кушоед; BimCraft ҳар пайвандро ёфта ё наёфта нишон медиҳад: [Кушодани тамоми ҷузвдони лоиҳа](topic:open-project-folder).
- **«Ин файл ношуда аст…»** Файл ҳангоми нусхабардорӣ, боргузорӣ ё ҳамоҳангсозӣ бурида шудааст. Файле дар анбори абрӣ, ки ҳанӯз «танҳо онлайн» аст, ҳамин тавр мекунад. BimCraft бо вуҷуди ин онро мекушояд ва танҳо он чиро нишон медиҳад, ки барқарор шуд: огоҳии зарди боло дар корт, бахши **Аз ин файл барқарор шуд** бо қисмҳое, ки ҳар байти онҳо дар файл аст, ва **Дар файл нест** барои боқӣ. Барои қисми гум ҳеҷ чиз пур карда намешавад, пас нашр, тасвири пешнамоиш ё маълумоти лоиҳа вақте гум шуда метавонанд, ки онҳо пас аз буридан захира шуда бошанд. Агар ҳатто феҳристи мундариҷаи файл бурида шуда бошад, ҳеҷ чиз кушода намешавад. Нусхаи аслиро аз нав нусхабардорӣ кунед ва файли пурраро аз нав кушоед.
- **«Дар ин файл тасвири пешнамоиш нест».** Баъзе файлҳо бе он захира мешаванд. Ин муқаррарӣ аст.
- **Кушодани захиранусха ба хато.** Файлҳое, ки ба монанди `Tower.0004.rvt` рақамгузорӣ шудаанд, захиранусхаҳои рақамдор мебошанд. Кушодани ҷузвдон онҳоро бо моделашон якҷоя мекунад.
