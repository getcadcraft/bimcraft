BimCraft дар версияҳои ҷории Chrome, Edge, Firefox ва Safari, дар Mac, Windows ва Linux кор мекунад. Намуди 3D WebGL-ро талаб мекунад, ки ҳар браузери ҷорӣ дорад. Барои он ки барномаҳо умуман чӣ лозим доранд, [Браузерҳо ва компютерҳо](common:browsers) -ро бинед.

## Кушодани ҷузвдон

| Браузер | {{ui:Open a folder}} чӣ мекунад | Кашидани ҷузвдон ба ин ҷо | {{ui:Recent folders}} |
|---|---|---|---|
| Chrome, Edge | Интихобгари ҷузвдони браузер, сипас «Ба сайт файлҳоро нишон додан иҷозат дода шавад?»: **View files** -ро пахш кунед | Бе пурсиш кушода мешавад | Ҳа, барои ҷузвдонҳое, ки интихоб ё кашида шудаанд |
| Firefox | Интихобгари ҷузвдони система | Бе пурсиш кушода мешавад | Не |
| Safari | Интихобгари ҷузвдони система, бо тугмаи **Upload** (ҳеҷ чиз боргузорӣ намешавад) | Бе пурсиш кушода мешавад | Не |

Дар паси парда: Chrome ва Edge интихобгари File System Access -ро истифода мебаранд ва ҷузвдонро ба ёд нигоҳ дошта метавонанд. Firefox ва Safari интихобгари кӯҳнаи ҷузвдонро истифода мебаранд, ки ҳамаи файлҳоро якбора медиҳад ва ба ёд гирифта намешавад. Ҷузвдони кашидашуда дар ҳар браузер ба тартиби ҳар воҳид хонда мешавад.

:::chromium
Brave ва баъзе браузерҳои дигари Chromium интихобгари ҷузвдонро хомӯш мекунанд. Пас BimCraft интихобгари ҷузвдони системаро истифода мебарад ва браузер метавонад пурсад: «Ба ин сайт *n* файл боргузорӣ шавад?». Ҳеҷ чиз боргузорӣ намешавад; файлҳо танҳо ба варақа мераванд. Кашидани ҷузвдон ин пурсишро аз байн мебарад.
:::

## Mac, Windows ва Linux

- Миёнбурҳое, ки {{key:Mod+S}} ва {{key:Mod+Z}} навишта шудаанд, дар Mac Command ва дар Windows ва Linux Ctrl мебошанд.
- {{key:Ctrl+Shift+F}} (ҳолатҳои экран) дар ҳар система Control аст, аз ҷумла дар Mac.
- Равзанаҳои файл ва ҷузвдони зеркашиҳо аз они системаи шумо мебошанд.

## Муш, трекпад ва ламс

| Воридшавӣ | Намуди 3D | Нақшаи 2D |
|---|---|---|
| Муш | Кашидан бо тугмаи чап мечархонад, бо тугмаи рост ҷойивазкунӣ мекунад, чарх калон мекунад, пахш интихоб мекунад | Ҳар кашиш ҷойивазкунӣ мекунад, чарх калон мекунад, дупахш {{ui:Fit}} мекунад |
| Трекпад | Кашидан бо пахш мечархонад; {{key:Shift}} ё {{key:Mod}} ва кашидан ҷойивазкунӣ мекунад; скроли ду ангушт ё печондан калон мекунад | Кашидан бо пахш ҷойивазкунӣ мекунад; скроли ду ангушт ё печондан калон мекунад |
| Ламс | Як ангушт мечархонад, ду ангушт печонда ҷойивазкунӣ мекунад, пахш интихоб мекунад | Як ангушт ҷойивазкунӣ мекунад; ҳанӯз печондан нест; пахш {{ui:Fit}} |

Дар трекпади Mac, клики рост клики ду ангушт (ё Control-клик) аст. [Калидҳо, мушҳо ва трекпадҳо](common:keys) -ро бинед.

Планшетҳо ва телефонҳо файлҳои ягонаро кушода ва дида метавонанд, аммо экран хурд аст, бисёре аз браузерҳои мобилӣ ҷузвдонҳоро интихоб карда наметавонанд ва моделҳои калон дар хотираашон ҷо намешаванд. Компютер беҳтар кор мекунад.

## Файлҳои калон ва хотира

Ҳар он чи BimCraft мехонад, дар хотираи варақаи браузер меистад. Браузер чӣ қадар хотира истифода бурда метавонад, пеш аз ҳама ба браузер ва компютери шумо вобаста аст, на ба BimCraft.

| Файл | Чӣ қадар хонда мешавад | Чӣ интизор шудан лозим |
|---|---|---|
| IFC | Файли пурра ва геометрияи 3D-и аз он сохташуда | Андоза ба компютер ва браузер вобаста аст; модели чанд сад мегабайт барои ноутбук зиёд буда метавонад. Аз 1,5 миллион секунҷа зиёд бошад, қиррҳо хомӯш мешаванд |
| Файлҳои лоиҳа ва оила | Тақрибан 40 KB то 100 KB, новобаста аз андоза | Ҳатто моделҳои марказии хеле калон дар як лаҳза кушода мешаванд, инчунин аз диски шабакавӣ |
| DWG ва DXF | Файли пурра | Нақшаҳои хеле калон паёми «Ин нақша хеле калон аст; танҳо қисме аз он нишон дода мешавад.» -ро нишон медиҳанд |
| Ҷузвдонҳо | Рӯйхати файлҳо ва чанд KB барои ҳар модел | То 20 000 файл |

Агар варақа хотира тамом кунад, браузер саҳифаи хатои худро нишон медиҳад (масалан, дар Chrome «Aw, Snap!»). Варақаҳои дигарро пӯшед, BimCraft-ро аз нав боркунӣ кунед ва бори дигар кӯшиш кунед, ё компютере бо хотираи бештар истифода баред.
