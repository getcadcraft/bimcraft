## Чӣ хоҳед кард

Файли лоиҳаро ба файли IFC табдил диҳед, ки дар BimCraft чарх занед, санҷед, тафтиш кунед ва таҳрир кунед. BimCraft ҳоло модели 3D-ро дар файли `.rvt` намехонад, пас содирот дар барномае анҷом меёбад, ки онро сохтааст (Revit); BimCraft натиҷаро мекушояд.

## Қадамҳо

1. Лоиҳаро дар барномае кушоед, ки онро сохтааст. Корти BimCraft версияеро номбар мекунад, ки дар он захира шудааст.
2. Намуди 3D-ро кушоед, ки нишон медиҳад, чиро содир кардан мехоҳед.
3. Интихоб кунед **File > Export > IFC**.
4. Дар диалоги содирот танзимотро (ё **Modify setup…**) бо танзимоти зерин интихоб кунед.
5. Папка ва номи файлро интихоб кунед ва содир кунед.
6. Дар BimCraft {{ui:Файлро интихоб кунед}}-ро клик кунед ва файли нави `.ifc`-ро интихоб кунед. Моделҳои пайвастшуда, ки ҳамчун файлҳои алоҳида содир шуданд, бо {{ui:Илова кардани модел}} ба ҳамон саҳна мекушоянд.

## Танзимоте, ки дар ин ҷо беҳтар кор мекунанд

| Танзимот дар содиркунанда | Интихоб кунед | Чаро |
|---|---|---|
| Версияи IFC | **IFC4 Reference View** барои дидан, санҷидан ва ҳисоб; **IFC2X3 Coordination View 2.0** вақте ки дигарон IFC2X3 лозим доранд | Ҳарду пурра кушода мешаванд. **IFC4 Design Transfer View** низ кушода мешавад, бо шаклҳои дақиқтар, аммо файл калонтар ва сусттар аст. |
| Навъи файл | **IFC** (соф) | BimCraft `.ifczip` ё `.ifcxml`-ро намекушояд. |
| Марҳила / элементҳои намоён | Марҳилаи мақсаднок ва **Export only elements visible in view**, вақте ки намуди 3D-ро барои он танзим мекунед | Чизҳоеро, ки шумо қасдан пинҳон кардаед, партофта мешаванд. |
| Маҷмӯаҳои хосият | **Export Revit property sets** ва **Export IFC common property sets** | Онҳо маҷмӯаҳое мешаванд, ки BimCraft дар {{ui:Хосиятҳо}} нишон медиҳад ва {{ui:Ҷустуҷӯ}}, {{ui:Ранг}} ва {{ui:Санҷишҳои модел}} истифода мебаранд. |
| Миқдорҳои асосӣ | **Export base quantities** | {{ui:Ҷамъи миқдорҳо}} ва ҷадвалҳо онҳоро истифода мебаранд (дарозӣ, масоҳат, ҳаҷм) ба ҷои тахмин. |
| Ҳуҷраҳо ва масоҳатҳо | **Export rooms in 3D views** (ё варианти Rooms / Spaces) | Ҳуҷраҳо ҳамчун фазоҳо меоянд: барои дидани онҳо клик кунед {{ui:Фазоҳо}}. |
| Файлҳои пайвастшуда | **Export linked files as separate IFCs** | Ҳар пайванд файли худаш мешавад; онҳоро бо {{ui:Илова кардани модел}} якҷоя кушоед ва онҳо рост меоянд. |
| Пойгоҳи координатҳо | **Shared coordinates** (ё нуқтаи тадқиқот) | Он гоҳ файл ҷойгоҳи худро дар харита дорад (IfcMapConversion), ки Measure › Location, қабатҳои харита дар замин ва абрҳои нуқта, ки бо координатҳои харита ҷойгир шудаанд, кор мекунанд. Нуқтаи асосии лоиҳа модели наздики нуқтаи сифрро нигоҳ медорад, вале бе ҷойгоҳи харитаи худ. |
| Ҷудо кардани деворҳо ва сутунҳо аз рӯи сатҳ | Фаъол, вақте ки миқдорҳоро аз рӯи ошёна мегиред | Қисми ҳар ошёна элементи алоҳида мешавад. |

## Чӣ бояд бинед

Модел дар 3D, ошёнаҳо аз сатҳҳои лоиҳа гирифта шуда, ва маълумоти лоиҳа дар панели {{ui:Файл}}. **Exported from** номи содиркунандаро нишон медиҳад.

## Чӣ содирот нигоҳ медорад ва чӣ не

- **Нигоҳ дошта мешавад**: геометрия, ошёнаҳо, навъҳои элемент, номҳо, намудҳо, аксари параметрҳо (ҳамчун маҷмӯаҳои хосият), миқдорҳои асосӣ вақте ки талаб шудааст, ҳуҷраҳо ҳамчун фазоҳо, ва ҷойгоҳи харита бо координатҳои умумӣ.
- **Нигоҳ дошта намешавад**: намудҳо, варақҳо, шарҳ, оилаҳо ҳамчун оилаҳои таҳрирпазир, worksets ва design options. Файли IFC суратии элементҳои модел аст, на лоиҳа. Барои варақҳо, DWG-ро содир кунед ва дар намуди 2D кушоед.

## Иштибоҳҳои маъмул

- **Параметрҳо дар BimCraft нестанд.** Варианти маҷмӯаҳои хосияти болоро фаъол кунед ва дубора содир кунед.
- **Ҳуҷраҳо нестанд.** Варианти ҳуҷраҳоро фаъол кунед, пас клик кунед {{ui:Фазоҳо}}.
- **Захира ҳамчун `.ifczip`.** IFC-и соф интихоб кунед ё `.ifczip`-ро кушоед.
- **Ҷойгоҳи харита нест.** Бо координатҳои умумӣ содир кунед; санҷед, ки нуқтаи тадқиқоти лоиҳа гузошта шудааст.
- **Интизори баргардонидани таҳрирҳо.** Таҳрирҳое, ки дар BimCraft захира мекунед, ба файли нави IFC дохил мешаванд, на ба файли лоиҳа.
