Агар Revit-ро медонед, аксарияти BimCraft аз рӯи калимаҳо ошно ба назар мерасад, аммо аз рӯи доираи кор ношинос. Фарқи асосии яккаву ягона: **ин версия моделҳоро мехонад ва месанҷад ва маълумоти IFC-ро таҳрир мекунад. Он ҳоло мисли Revit муаллифӣ намекунад.** Шумо наметавонед деворҳоро кашед, оилаҳоро ҷойгир кунед, намудҳо ё варақаҳо созед ё файли лоиҳа захира кунед. Чизе, ки шумо карда метавонед, ин аст: кушодани қариб ҳар файли биноӣ дар ҳар компютер бо браузер, дидани он чи дар он аст, санҷидани тамоми ҷузвдони лоиҳа ва ислоҳи маълумот дар модели IFC.

## Одатҳои мувофиқшуда

| Агар одат кардаед ба | Дар BimCraft |
|---|---|
| Кушодани `.rvt` дар Revit барои дидани модел | BimCraft `.rvt`-ро ҳамчун корти файл мекушояд: нашр, маълумоти лоиҳа, пайвандҳо, пешнамо. Барои модели 3D, IFC содирот кунед ва онро кушоед. [Файли лоиҳа ё оиларо хонед](topic:read-rvt-file) |
| Пеш аз кушодан санҷидани он ки файл дар кадом нашр захира шудааст | Корт дар боло матни "захира шуда дар Revit …"-ро нишон медиҳад, бе навсозӣ ё дасткорӣ кардани файл |
| Браузери лоиҳа | Браузери намудҳо ва варақаҳо нест. Модели IFC {{ui:Ошёнаҳо}} ва {{ui:Унсурҳо}}-ро дорад; нақша табҳои варақаҳо дорад |
| Палитраи хосиятҳо | Панели {{ui:Хосиятҳо}} дар тарафи рост, барои унсуре, ки клик кардед. Маҷмӯаҳои хосияти IFC ба ҷои гурӯҳҳои параметр |
| Параметрҳои намуна ва навъ | Маҷмӯаҳои хосияти намуна, ва маҷмӯаҳое, ки бо "(навъ)" нишон дода шудаанд. Тағйири навъ ба ҳар унсури навъ татбиқ мешавад, мисли Revit. [Хосияти навъро барои ҳар унсури навъ иваз кунед](topic:type-vs-instance) |
| Edit Type | Диалог нест: ба қимат дар маҷмӯаи "(навъ)" клик кунед ва нависед |
| Интихоби бисёр унсурҳо, филтрҳо, Select All Instances | Як унсур дар як вақт. Ҳанӯз сохта нашудааст |
| Куби намуд ва чархи навигатсия | Куби намуд дар кунҷи поёни рост, чор тугма ({{ui:Ҷо кардан}}, {{ui:Боло}}, {{ui:Пеш}}, {{ui:Аз паҳлу}}) ва гардиши озод. Чархи навигатсия нест |
| Shift ва кашидани тугмаи миёна барои гардиш, кашидани тугмаи миёна барои ҷойивазкунӣ | Кашидани тугмаи чап гардиш мекунад, кашидани тугмаи рост (ё {{key:Shift}} ва кашидан) ҷойивазкунӣ мекунад, чарх калонкуниро иҷро мекунад. Услуби меню {{ui:Лентаи BIM}} ба ҷойивазкунии тугмаи миёна ва {{key:Shift}} бо тугмаи миёна барои гардиш иваз мекунад. [Меню, тугмаҳо ва мушро](topic:menus-keys-and-mouse) |
| Нақшаҳои фарш, буриш, қуттиҳои буриш | Як ҳавопаймои {{ui:Буриш}} дар як вақт ({{key:X}}); қуттии буриш ё нақшаҳои 2D нест. [Модели IFC-ро бо ҳавопаймои буриш буред](topic:section-plane) |
| Пинҳон кардан дар намуд, ҷудо кардан, намоиш/графика | {{ui:Ошёнаҳо}} фаъол ва хомӯш, {{ui:Фазоҳо}} ва {{ui:Канорҳо}}. Пинҳон кардани ҳар унсур ҳанӯз нест |
| Ҳуҷраҳо | Фазоҳои IFC, дар аввал пинҳон. Ба {{ui:Фазоҳо}} клик кунед |

| Баргардондан бо {{key:Mod+Z}} | Дар тағйироти IFC то захира кардан кор мекунад. [Хосиятҳои IFC-ро иваз кунед ва нусхаи таҳриршударо захира кунед](topic:edit-ifc-properties) |

| Аудит ё кушодани файл барои дидани вайроншавӣ | Ҳисоботи ҷузвдон ҳар нусха ва нусхаи эҳтиётро барои бурида шуданаш тафтиш мекунад, дар чанд сония. [Ҷузвдонро барои нусхаҳои вайроншуда санҷед](topic:check-folder-health) |
| Интихоби файли дуруст аз ҷузвдони нотартиб | Қуттии {{ui:Аз ин оғоз кунед}} яктоеро бо сабабҳо пешниҳод мекунад |

Агар шумо асосан моделҳоро барои санҷидан мекушоед, мисли барнома барои санҷиш ё дидани IFC, услуби меню {{ui:Бинанда}}-ро интихоб кунед: асбобҳои дидан ва санҷиш пеш меоянд, ва асбобҳои сохтмонӣ дар як меню интизор мешаванд. Нигаред ба [Меню, тугмаҳо ва мушро](topic:menus-keys-and-mouse).

| Агар одат кардаед ба | Дар BimCraft |
|---|---|
| Табҳои модел ва тарҳбандӣ дар поён | Табҳо дар болои нақша: {{ui:Model}} ва як барои ҳар варақа |
| ZOOM Extents, дуҷониба клик кардани чарх | Дуҷониба клик, {{key:F}} ё {{ui:Ҷо кардан}} |
| Ҷойивазкунӣ бо тугмаи миёна | Кашед бо ҳар тугма |
| Менеҷери қабатҳо | Рӯйхати {{ui:Қабатҳо}}: ишора гузоред, то нишон дода шавад, ишораро бардоред, то пинҳон шавад, {{ui:Ҳама фаъол}} ва {{ui:Ҳама хомӯш}} |
| Менеҷери xref | **Нақшаҳои пайвастшуда** дар тарафи рост, бо **Нишон дода шуд** ё **Ёфт нашуд**, ва {{ui:Нақшаҳои пайвастшударо илова кунед…}} |
| Пешнамоиши чоп | {{ui:Намуди чоп}} ё {{key:P}}: сиёҳ дар сафед бо вазни хатҳо. Чоп намекунад |
| Истихроҷи маълумот аз атрибутҳои блок | Варақаи {{ui:Таҷҳизот}} барои нақшаҳои хӯроквории тамғагузошта, бо {{ui:Зеркашии CSV}} |
| Ченкунӣ, кашидан, таҳрир, захира ҳамчун | Дар BimCraft нест. Барномаи нақшакашии CadCraft мекашад ва таҳрир мекунад |

## Фарқиятҳое, ки одамонро ба ташвиш меоранд

- **Он дар браузер кор мекунад ва браузер ба файлҳои шумо эҳтиёткор аст.** BimCraft танҳо файлҳо ва ҷузвдонҳоеро мехонад, ки шумо ба он медиҳед, бо интихоб кардан ё кашидан ба он. Худаш файлро кушода наметавонад ва ба ҷои онҳо захира карда наметавонад. Ҳар захира зеркашӣ аст.
- **Чизе боргузорӣ намешавад.** Калимаи "боргузорӣ" дар диалогҳои ҷузвдон дар баъзе браузерҳо калимаи худи браузер аст. Файлҳо дар компютери шумо мемонанд.
- **IFC формати модел аст.** Файли лоиҳа ҳамчун корт кушода мешавад, зеро мундариҷаи 3D-и он ҳуҷҷатгузорӣ нашудааст. IFC-ро ҳамчун роҳе бигиред, ки моделҳо ба BimCraft меоянд.
- **Таҳрирҳо ҳангоми навиштан нусхабардорӣ мешаванд.** Иваз кардани қимати як унсур ҳеҷ гоҳ ҳамсояҳояшро тағйир намедиҳад, ҳатто агар содиркунанда ин қиматро байни онҳо мубодила карда бошад. Хосиятҳои навъ истисноҳои қасдан мебошанд.
- **Лоиҳа ва намудҳо нест.** BimCraft як файлро дар як вақт нишон медиҳад ва пас аз пӯшидани варақаи браузер дар бораи он чизе ба хотир намегирад, ба ғайр аз номҳои ҷузвдонҳои охирин дар Chrome ва Edge.
- **Тугмаҳои Mac.** Ҷое ки тугмаҳои кӯтоҳи Windows-и Revit {{key:Ctrl}}-ро истифода мебаранд, тугмаҳои кӯтоҳи BimCraft {{key:Mod}}-ро истифода мебаранд: дар Mac — Command.
- **Одатҳои мушатон.** Гардиш тугмаи чап аст, на Shift ва тугмаи миёна, магар шумо услуби меню {{ui:Лентаи BIM}}-ро интихоб кунед ё тугмаҳоро худатон дар [Меню, тугмаҳо ва мушро](topic:menus-keys-and-mouse) танзим кунед.

Барои он чи имрӯз ба ҷои он истифода бурдан мумкин, нигаред ба [Чӣ ҳоло сохта нашудааст](topic:not-built-yet).
