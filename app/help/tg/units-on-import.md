## Чӣ корро мекунед

Файлеро меоред ва мутмаин мешавед, ки бо андозаи дуруст меояд.

## Қадамҳо

1. Файлро мисли маъмул кушоед ё илова кунед: {{ui:Кушода}}, {{ui:Файлҳо}}-и Китобхона, {{ui:Абрҳои нуқтаҳо}} ё Сохтан › Аз нақша.
2. Агар файл воҳидҳои худро эълон кунад, чизе пурсида намешавад. Сатри ҳолат мегӯяд, ки файл кадом воҳидҳоро эълон мекунад.
3. Агар не, диалог **Воҳидҳои** файлро мепурсад. Интихоб кунед, ки як воҳид дар файл чӣ аст ва {{ui:Ин воҳидҳоро истифода бурдан}}-ро клик кунед. То ҷавоби шумо ҳеҷ чиз ҷойгир намешавад.
4. {{ui:Бекор кардан}} (ё {{key:Esc}}) ҳеҷ чизро воред намекунад.

## Кадом файлҳо воҳидҳои худро эълон мекунанд

- **IFC**: воҳиди дарозии худро эълон мекунад ва "Кушода" мегӯяд, кадомаш. IFC-е, ки ҳеҷ чизро эълон намекунад, пеш аз кушодан пурсида мешавад; ҷавоби шумо ба модел навишта мешавад, то файл пас аз захира кардан онро як бор эълон кунад.
- **DWG ва DXF**: воҳидҳои воридкунии нақша. Нақшае, ки онҳоро надорад, пурсида мешавад (файлҳои Китобхона, Сохтан › Аз нақша, замин аз ҳамворӣ).
- **Рӯйхати нуқтаҳо** барои замин: воҳидҳоро эълон намекунанд. Аз шумо пурсида мешавад.
- **Абрҳои нуқтаҳо**: LAS ва LAZ бо системаи координатҳо, E57, PTX ва PLY воҳидҳои худро эълон мекунанд. Дигарҳо пурсида мешаванд.
- **OBJ ва STL**: ҳеҷ гоҳ воҳид эълон намекунанд. Аз шумо пурсида мешавад.
- **glTF ва GLB**: метр, мувофиқи қоидаи худи формат.
- **Тасвирҳо**: андозаи худ надоранд. Тасвир ба намуд мувофиқ карда мешавад ва андозаашро бо Миқёс бо ду нуқта танзим мекунед. Андозае, ки медиҳед, барои он файл нигоҳ дошта мешавад: вақте боз ҷойгир шавад, бо он андоза меояд ва сатри ҳолат инро мегӯяд.
- **Иловаи Абрҳои нуқтаҳо**: вақте абре месозед, ки файлаш воҳиде эълон намекунад, мепурсад ва рақамҳои абрро бо воҳиде, ки абр дорад, нишон медиҳад.

## Хуб донистан

- Ҷавоб барои он файл (номаш, андоза ва санааш) дар ин компютер, дар ҳама барномаҳои CadCraft ба хотир гирифта мешавад. Дафъаи навбатӣ, ки ҳамон файл меояд, пурсида намешавад ва сатри ҳолат мегӯяд, ки воҳидҳои ба хотир мондашуда истифода шуданд.
- Барои он ки боз пурсида шавад: палитраи фармон ({{key:Mod+K}}) › **Боз пурсидан барои воҳидҳои файлҳои воридшуда**.
- Воҳидҳое, ки воридкунӣ аллакай дорад (Воҳидҳои Китобхона, Воҳидҳои панели абр, Воҳидҳои нақша дар Сохтан аз нақша) баъд аз он ҳам воҳидҳоро тағйир медиҳанд. Рӯйхати воҳидҳои абзори замин акнун танҳо нуқтаи оғози пурсиш аст.
