## Элементи IFC

Дар боло панели {{ui:Properties}} навъи элементро бе пешванди «Ifc» нишон медиҳад (масалан «Door», «WallStandardCase», «FurnishingElement») ва номашро, ё «Unnamed» агар ном надошта бошад.

| Майдон | Маънӣ | Таҳриршаванда |
|---|---|---|
| Name | Номи элемент, аксар вақт номи оила ва намуд аз содиркунанда | Ҳа |
| Type | Номи намуди элемент, агар он дошта бошад | Не |
| Object type | Тавсифи навъи озоди матнӣ, ки баъзе содиркунандагон пур мекунанд | Ҳа |
| Tag | Тег ё нишони элемент; бисёр содиркунандагон ID-и элементро ин ҷо менависанд | Ҳа |
| Description | Матни озод | Ҳа |
| GlobalId | Идентификатори доимии 22-рақамии IFC-и элемент, дар ҳар содироти ҳамон элемент якхела | Не |
| Line | Рақами сатри элемент (`#1234`) дар ин файли IFC. Дар байни содиротҳо тағйир меёбад | Не |

Дар поён **маҷмӯаҳои хосиятҳо** бо номашон ҷудо шуда меоянд:

- Ҳар маҷмӯа бо пахши номаш кушода ва пӯшида мешавад. Се аввалин кушода мебошанд.
- Маҷмӯае, ки «(type)» дорад, ба намуди элемент тааллуқ дорад: «Хосияти намуд: тағйирот ба ҳар элементи ин намуд татбиқ мешавад».
- Маҷмӯаҳои миқдорҳо (дарозӣ, масоҳат, ҳаҷм, шумора, вазн) танҳо хониш мешаванд.
- Рӯйхатҳо ва арзишҳои шумориш нишон дода мешаванд, танҳо хониш.
- Арзишҳои Ҳа/Не ҳамчун **Ҳа** ё **Не** нишон дода мешаванд.
- Рақамҳо барои намоиш то чор рақами аъшорӣ давр карда мешаванд. Дарозиҳо (хосияти дарозӣ ё дарозии миқдор) дар {{ui:Units}}-и интихобшуда дар асбобҳо нишон дода мешаванд, бо нишони воҳид дар паҳлӯ, ва шумо метавонед арзиши навро бо ҳамон воҳид ё бо нишони дигари воҳид (2.4 m, 8'-0") дарҷ кунед: BimCraft рақами худи файлро бармегардонад. Рақамҳои дигар ҳамон тавре нишон дода мешаванд, ки файл дорад.
- Арзиши холӣ ҳамчун *холӣ* нишон дода мешавад. Арзиши таҳриршуда ғафс аст ва дар паҳлӯяш мизи кабуд дорад.

## Нусхабардории арзиш

Ҳар арзиш дар {{ui:Properties}} тугмаи хурди нусхабардорӣ дорад: онро пахш кунед, то арзиш ҳамон тавре ки нишон дода шудааст, ба буфер гузошта шавад, масалан GlobalId, рақами серияӣ ё ҳар арзиши маҷмӯаи хосият. Нусхабардорӣ ҳеҷ гоҳ таҳрирро оғоз намекунад.

Дар боло {{ui:Copy all}} ҳар арзиши элементро ҳамчун матн, маҷмӯа ба маҷмӯа, нусха мебардорад ва {{ui:Copy as CSV}} онҳоро ҳамчун сатрҳои гурӯҳ, хосият ва арзиш нусха мебардорад, то дар ҷадвал часпонед; арзишҳои холӣ нигоҳ дошта мешаванд, то ҳар майдон сатр дошта бошад. Ин барои элементи модели дигари кушодашуда низ ҳамин тавр кор мекунад; вақте ки зиёда аз як модел кушода аст, CSV бо сутуни Model оғоз мешавад, ки номи файлро нишон медиҳад.

## Панели File (IFC)

| Майдон | Маънӣ |
|---|---|
| File, Size | Файле, ки кушодаед |
| Schema | Версияи IFC, масалан IFC2X3 ё IFC4 |
| Project | Номи лоиҳа ва номи пурраи он |
| Phase | Марҳалаи лоиҳа, агар содиркунанда навиштааст |
| Exported from | Барномаи содиркунанда, аз сарлавҳаи файл |
| Author | Муаллиф дар сарлавҳаи файл |
| Exported | Сана ва вақт дар сарлавҳаи файл |
| Elements | Чанд элемент бо шакл кашида шудааст |
| Triangles | Шаклҳои онҳо чанд секунҷа мешаванд; ўлчови вазнинии модел |
