{{ui:USD}} дар абзор он чиро, ки кушода аст, ҳамчун як файли USD менависад (ҳама моделҳо, моделҳои федеративӣ, ки онҳоро дар ҷое ки ҷойгир кардаед).

## Содирот

1. {{ui:USD}}-ро дар абзор интихоб кунед.
2. {{ui:Матн (.usda)}}, {{ui:Бинарӣ (.usdc)}} ё {{ui:Бастаи (.usdz)}}-ро интихоб кунед.
3. Файл зеркашӣ мешавад. Сатри ҳолат мегӯяд, ки чанд унсур ворид шуд.

## Дар файл чӣ ҳаст

| Дар модели IFC | Дар файли USD |
|---|---|
| Сайт, бино, ошёнаҳо | Гурӯҳҳои ҷойгиршуда, ошёнаҳо бо тартиби баландӣ |
| Ҳар унсур | Як prim зери ошёна ва фан (Меъморӣ, Сохтор, MEP, Ҷиҳозгузорӣ, Сайт, Фазоҳо, Дигар), бо геометрияаш ҳамчун mesh |
| Синф, GlobalId, ном, навъ, тамға | Атрибутҳо бо номҳои `ifc:class`, `ifc:globalId`, `ifc:name` ва ғайра |
| Маҷмӯаҳои хосият ва миқдор | Як атрибут барои ҳар хосият; дарозӣ, масоҳат ва ҳаҷм бо метр, метри мураббаъ ва метри кубӣ |
| Ранг | Маводҳо (бо шаффофият) |
| Фазоҳо | Нигоҳ дошта мешаванд, ҳамчун роҳнамо қайд мешаванд, то рендерҳо онҳоро нодида гиранд |

Геометрия дар координатҳои худи файли IFC меистад. Тарҳи ҷойгиршавӣ аз қоидаҳои навиштаи USD-и CadCraft барои биноҳо пайравӣ мекунад.
