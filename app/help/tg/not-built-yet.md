BimCraft ҳоло хонандаи файлҳо, санҷандаи модел ва таҳриргари маълумоти IFC аст, ки ба кашидани бинҳо шурӯъ кардааст: деворҳо, дарҳо ва тирезаҳо, ҳуҷраҳо, фаршҳо, шифтҳо ва бомҳо (нигаред ба [Деворҳоро кашед](topic:draw-walls), [Дарҳо ва тирезаҳо](topic:doors-and-windows) ва [Ҳуҷраҳо, фаршҳо, шифтҳо ва бомҳо](topic:floors-and-roofs)). Ин рӯйхати ростқавли чизҳост, ки то ҳол намекунад, бо он чӣ бояд ба ҷояш истифода шавад.

## Моделсозӣ ва муаллифӣ

| Ҳанӯз не | Имрӯз ба ҷои он |
|---|---|
| Кашидани балкаҳо; сутунҳои профили пӯлодӣ | Барномаи муаллифии худро истифода баред, сипас содироти IFC-ро дар ин ҷо кушоед. Сутунҳои росткунҷа ва доиравӣ дар ин ҷо ҷойгир карда мешаванд (нигаред ба [Тӯрҳо ва сутунҳо](topic:grids-and-columns)); зинаҳои рост, L-шакл, U-шакл, гардиш ва мурдорӣ, ва панҷарашаҳо дар ин ҷо кашида мешаванд (нигаред ба [Зинаҳо ва панҷарашаҳо](topic:stairs-and-railings)) |
| Тиреза дар пешонии хонаи бомӣ; бомҳо дар ҳавопораҳое, ки бо даст кашида шудаанд; бомҳои хамшуда; қабати бом бо бофтаи рендершуда | Ҳавопораҳои бом бо кунҷҳои худ кашида мешаванд ва барои ҳар девор нишебӣ: нигаред ба [Бомҳо: нишебӣ барои ҳар девор, фронтонҳо, сарпӯшҳо ва ҳавопораҳои бом](topic:roofs) |
| Тағйир додани деворҳо, дарҳо ё тирезаҳое, ки барномаи дигар сохтааст | Барномаи муаллифии шумо; асбобҳои кашидан танҳо он чизеро тағйир медиҳанд, ки худашон кашидаанд |
| Профилҳои деворҳо бо ҳошиёгӣ ё сурохиҳо; кушодагиҳои девор, ки росткунҷа нестанд; илова ё хориҷ кардани нуқтаҳои профили девор дар намуди 3D | Профил, пайваст, нишеб ва кушодагиҳо дар {{ui:Хосиятҳо}}, дар фасад ва буриш, дар намуди рӯи девор ва бо дастгираҳо дар 3D кор мекунанд, барои деворҳои рост ва хамшуда: нигаред ба [Девор шакл диҳед: пайваст, профил, нишеб ва кушодагиҳо](topic:wall-shape) |
| Дар деворҳои хамшуда: {{ui:Кӯтоҳ / дароз кардан}} ва {{ui:Кунҷ}}, чаҳорчӯба, андозаҳои худкори нақша, часпидан дар роҳи камон (ба канорҳо ва миёнаи камон часпида мешавад) | Девори рост кашед барои инҳо, ё сегментҳои рост истифода баред. Деворҳои хамшуда дар [Деворҳоро кашед](topic:draw-walls) ҳастанд |
| Кашидани ашёи китобхонаи ҷойгиршуда дар намуди 3D | Онро дар нақша кашед ё X, Y ва Гардишро дар {{ui:Хосиятҳо}} нависед: нигаред ба [Таҷҳизот ва мебелро аз китобхона ҷойгир кунед](topic:place-from-library) |
| Ҷойгир кардани гиёҳҳо аз китобхонаи гиёҳҳои фазои Landscape-и CivilCraft | Онҳоро дар CivilCraft шинонед, ё дарахт ва бутаҳоро аз атрофсозии китобхона (entourage) ҷойгир кунед: нигаред ба [Таҷҳизот ва мебелро аз китобхона ҷойгир кунед](topic:place-from-library) |
| Дар иловаи Plant (то фаъол кардан хомӯш): кашидани хати роҳдаршуда ба модел, рақамҳои катушка дар изометрияҳояш, санҷиши тарҳи таҷҳизоте, ки аз китобхона ҷойгир шудааст | Хатро бо {{ui:Қубур}} кашед (нигаред ба [Қубурҳо ва каналҳо](topic:pipes-and-ducts)); санҷиши тарҳ ҷадвали таҷҳизоти худи иловаро мехонад |
| Гардондан, инъикос ё массив кардани деворҳо, дарҳо ва тирезаҳои алоҳидаи кашидашуда (деворҳо бо {{ui:Кӯчонидан}}, Офсет ва Кашидани қуттӣ кӯчонида ва нусха мешаванд: нигаред ба [Шаклҳои девор, буридан, офсет, кашидан ва қулф](topic:wall-tools)); услуби пайваст (butt, square off) дар кунҷҳо бо девори хамшуда ё се девор ва зиёда (нигаред ба [Шаклҳои девор, буридан, офсет, кашидан ва қулф](topic:wall-tools)); асбоби Матн; деворҳои пардагӣ | Ҳамаи чизҳоро дар сатҳ бо {{ui:Нусхабардории ин сатҳ…}} нусха кунед (нигаред ба [Деворҳоро кашед](topic:draw-walls#levels)); вагарна дубора кашед |
| Қабатҳои таркиби девор, ки дар нақша ва буриш кашида мешаванд; андозаҳо дар буриш ва фасад; андозаҳои истинодӣ ба дарҳо, тирезаҳо ва ҷузъҳои дигар; таркибҳо ва мембраналар дар ҷадвалҳо ва миқдорҳо; китобхонаи маводе, ки байни лоиҳаҳо муштарак аст; афзалияти қабат дар буриш, фасад ва 3D ва дар нуқтаҳои се девор ва зиёда (дар нақша кунҷҳо, пайвастҳои T ва ҳамдигарбуриҳои ду девор бо афзалияти қабат тоза мешаванд: нигаред ба [Шаклҳои девор, буридан, офсет, кашидан ва қулф](topic:wall-tools)); қабатҳои печонидашуда ё тағйирёбанда; таҳрири таркиби деворе, ки барномаи дигар сохтааст | Қабатҳо дар навъи девор ва пешнамоиши он ҳастанд ({{ui:Таркиби деворҳо…}}); деворҳо ҳамчун як пӯшиш чен карда мешаванд: нигаред ба [Таркиби деворҳо ва андозаҳои истинодӣ](topic:wall-assemblies) |
| Тағйир додани шакл ё андозаи унсур (ба ғайр аз деворҳо, дарҳо ва тирезаҳои дар ин ҷо кашидашуда ва унсурҳое, ки аз оила ҷойгир шудаанд) | Барномаи муаллифии шумо. Нест кардан, буридан, нусха ва часпондан дар ин ҷо кор мекунанд: нигаред ба [Унсурҳои биноро нест, бурида, нусха ва часпонед](topic:edit-elements) |
| Нест кардани ошёнаҳо, фазоҳо, биноҳо ё майдон | Унсурҳои дар онҳоро нест кунед |
| Гузоштани унсурҳои бино ба модели дигар | Дар як модел нусха бардоред ва гузоред; ашёи китобхонаи ҷойгиршуда ба ҳар модел гузошта мешавад |
| Иловаи хосиятҳои нав ё маҷмӯаи хосиятҳо | Арзишҳои мавҷударо дар ин ҷо пур кунед, ё параметрро дар барномаи муаллифии худ илова карда, аз нав содир кунед |
| Таҳрири миқдорҳо, рӯйхатҳо, шумурдаҳо | Барномаи муаллифии шумо |
| Захира кардани файлҳои лоиҳаи барномаҳои дигар | BimCraft IFC-ро захира мекунад (ва файлҳои оилаи худро: нигаред ба [Оилаҳо ва андозаҳои онҳо](topic:families)) |
| Оилаҳо: китобхонаи оилаҳо, ки аз нақша ҷойгир ва байни лоиҳаҳо муштарак мешаванд (Китобхона); нуқтаи фаъол (hotspot), ки дар намуди 3D-и унсури ҷойгиршуда кашида мешавад (онҳо дар пешнамоиши муҳаррири оила ва дар нақша кашида мешаванд); сатҳҳои тафсилот, ки барои намуд интихоб мешаванд (як сатҳ барои лоиҳа; варақҳо ба миқёс интихоб мекунанд); гардиши дар сатҳи амудӣ дар дохили оилаи дигар, ки бо чоряк гардиш мегардад; рамзҳои нақшаи дарҳо ва тирезаҳо (онҳо рамзи нақшаи оғозкунандаи худро мекашанд) | Оилаҳо бо параметрҳои навъдор, формулаҳо, рамзи нақшаи худ, нуқтаҳои фаъол, такрор, сатҳҳои тафсилот, оилаҳо дар дохили оилаҳо, андозаҳо аз ҷадвал ва параметрҳои ҳар унсур дар ин ҷо сохта мешаванд: нигаред ба [Таҳрири оила](topic:family-editor) ва [Оилаҳо ва андозаҳои онҳо](topic:families). Барои оғоз аз оила нусха бардоред |
| Таҳрири навъҳои барномаҳои дигар ҳамчун оила; табдил додани ашёи китобхона ба оила | Навъҳои барномаҳои дигар ба таври тахминӣ гурӯҳбандӣ шуда, унсурҳояшон интихоб мешаванд. Ашёи китобхона ҳамон тавр ҷойгир карда мешавад |
| Ҷузъҳо, клапанҳо ва таҷҳизоти истеҳсолкунандагон (ҳаҷм, вазн, андозаҳои пайвасти истеҳсолкунанда); дарозии тии ASME B16.9 ва редуктор дар катушкаҳои пӯлодӣ; талафоти фишор дар ҷузъҳо, ҷараён ва мувозинат; спринклерҳо; лотокҳои кабелӣ; ҳисоби стекҳо ва вентҳо бо воҳидҳои ҷузъ; кашидани кунҷҳои хат; озод кардани охири хат, ки ба порт пайваст аст (ба ғайр аз нест кардани таҷҳизот); портҳо дар ашёи китобхонаи ҷойгиршуда аз панели Китобхона; вазни ҷузъҳо; дарзҳо, ченакҳо ва пайвандакҳои канали ҳаво | Хатҳои қубур ва канал бо ҷузъҳои стандартии умумӣ, системаҳо, нақшаҳо, ҷадвалҳо ва ҳисоби ҳаҷм дар ин ҷо кашида мешаванд: нигаред ба [Қубурҳо ва каналҳо](topic:pipes-and-ducts). Таҷҳизоти умумӣ бо портҳо, хатҳои пайвастшуда ва санҷиши пайвастшавӣ: [Таҷҳизоти MEP бо портҳо](topic:mep-equipment), [Пайваст кардани қубурҳо ва каналҳо ба таҷҳизот](topic:mep-connections). Маҷмӯаҳои бархӯрд, фосилаҳо ва рӯйхати кушодагиҳо: [Санҷидани қубурҳо ва каналҳо бо сохтор](topic:mep-against-structure). Катушкаҳои пӯлодӣ ва варақҳо, рӯйхати буридани канали ҳаво: [Катушкаҳои қубури пӯлодӣ ва варақҳои катушка](topic:pipe-spools). Ашёи истеҳсолкунандагонро аз барномаи MEP-и худ ҳамчун IFC биёред |
| Санҷишҳои меъёрии тарроҳӣ барои I-шаклҳои пайвандшуда, барои I-шаклҳое, ки номи профили IFC-ашон ҳамчун андозаи пӯлодии W, S, IPE, HEA ё HEB гуфта нашудааст, ва барои қубурҳо, кунҷҳо ва каналҳо (онҳо ҳамчун санҷидашуда нестанд бармегарданд); хамшавӣ ё динамикӣ (басомадҳои табиӣ дар блоки Finite elements аст) (тартиби дуюм танҳо P-Delta аст: эластикӣ, хамшаванда, бе коҳиши сахтӣ); деворҳо ва плитаҳо дар таҳлил; бор аз сатҳҳо (ба ғайр аз як фишор дар ҳар плитаи бетонӣ) | Варақаи {{ui:Таҳлил}} нерӯҳо, реаксияҳо ва хамиданро барои тирҳо, сутунҳо ва бандҳо бо таҳлили тартиби аввал медиҳад ва I-шаклҳои пӯлодиро месанҷад, ҳамчун ёрдам то он ки муҳандис санҷад: нигаред ба [Таҳлили чаҳорчӯбаи сохторӣ](topic:frame-analysis#design-checks) |

## Намоиш додани моделҳо

| Ҳанӯз не | Имрӯз ба ҷои он |
|---|---|
| 3D аз файлҳои лоиҳа | Содироти IFC ва кушоед. Нигаред ба [Файли лоиҳаро тавассути IFC ба 3D гиред](topic:rvt-to-ifc) |
| Фасадҳои дохилӣ дар маҷмӯаи тасвирҳои сохташуда (аз хосиятҳои ҳуҷра ва варақҳои худатон сохта мешаванд); андозаҳои шумо дар фасад ва буриш (нишонаҳои сатҳ, баландӣ, паҳнӣ ва тамғаҳои дар/тиреза кашида мешаванд; ёддоштҳо дар намуд навишта мешаванд: нигаред ба [Таҳрир дар фасад ва буриш](topic:edit-in-elevations)); кашидани деворҳо дар фасад (онҳо дар ҳавопаймаи буриш кашида мешаванд); қолабҳои дастаҷамъӣ тавассути Studio | Маҷмӯаи тасвирҳо аз модел: нигаред ба [Фасадҳо, буришҳо ва варақҳо](topic:sheets). Барои ҳар модели IFC: як ҳавопаймаи {{ui:Буриш}} ё қуттии буриш; нигаред ба [Модели IFC-ро бо ҳавопаймаи буриш бурред](topic:section-plane) |
| Намудҳои ишора, намудҳои тафсилот, намудҳои нақшакашӣ ва афсонаҳо; хатҳо ва штрихи нақшакашӣ дар намуд; буридани фасад ё буриш; қолабҳои намуд барои фасад, буриш, нақшаҳои шифт ва намудҳои 3D; нақшаҳои шифт дар маҷмӯаи тасвирҳои сохташуда; маҷмӯаи варақҳои шумо дар як PDF | Нақшаҳо ва нақшаҳои шифт диапазони намуд, минтақаи буридан, миқёс ва пӯшиш доранд (нақшаҳо инчунин қолаб доранд), ва варақҳои шумо нақшаҳо, нақшаҳои шифт, фасадҳо, буришҳо ва ҷадвалҳоро мегиранд, ки ҳар кадом ҳамчун PDF захира мешаванд: нигаред ба [Намудҳо, диапазонҳои намуд ва варақҳои шумо](topic:views-and-sheets) |
| Баъд чароғи ҷойгиршударо ба шифт бардоштан; шифтҳои нишебдор ё зинадор; нақшҳои шифт ба ғайр аз панҷ тӯр; рамзи худи чароғ дар нақшаи шифт | Онро бо **Насб: Дар шифт** ҷойгир кунед; нақшаи шифт ашёро аз шакли худаш мекашад: нигаред ба [Таҷҳизот ва мебелро аз китобхона ҷойгир кунед](topic:place-from-library) |
| Бо дигарон мубодилаи маҷмӯаҳои ҷустуҷӯ, маҷмӯаҳо дар файли IFC | Маҷмӯаҳо дар ин браузер мемонанд; нигаред ба [Унсурҳоро аз рӯи синф, ном ё хосият ёбед](topic:find) |
| Ченкунии кунҷҳо ё дар роҳи чанднуқта | Ҳар қисмро бо {{ui:Ченкунӣ}} чен кунед: нигаред ба [Масофаҳо, масоҳати рӯ ва ҷойгиршавиро дар 3D чен кунед](topic:measure) |
| Бофтаҳо дар намуди зиндаи 3D | Маводи рангшуда рангашонро дар намуд ва бофтаашонро дар тасвирҳои рендершуда нишон медиҳанд: нигаред ба [Тасвири модел рендер кунед](topic:render) |
| Бархӯрдҳои фосилавии (мулоим) дар байни ҳар ду маҷмӯа, гурӯҳҳои бархӯрд, захираи натиҷаҳои бархӯрд | Санҷиши {{ui:Санҷиши бархӯрд}}-ро гузаронед ва барои муҳимтаринҳо масъала созед: нигаред ба [Бархӯрдҳоро санҷед](topic:clash-check). Қубурҳо ва каналҳо бо сохтор {{ui:Санҷиши фосилаҳо}} доранд: нигаред ба [Санҷидани қубурҳо ва каналҳо бо сохтор](topic:mep-against-structure) |
| Захира кардани чанд модел ҳамчун як маҷмӯа, ё таҳрири ду модел якбора | Як модел дар як вақт таҳрир кунед; ҳар кадом файли худашро захира мекунад |
| Таъйин кардани масъалаҳо, мӯҳлатҳо, тамғаҳо, якчанд нуқтаи назар барои як масъала, таҳрири масъала | Як намуд барои як масъала; нигаред ба [Масъалаҳо ва файлҳои BCF](topic:issues-bcf) |
