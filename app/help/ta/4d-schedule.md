## நீங்கள் செய்வது

கட்டடம் எழுவதைப் பார்: உங்கள் அட்டவணையில் உள்ள ஒவ்வொரு பணியும் அது கட்டும் கூறுகளுடன் இணைக்கப்பட்டு, நாள் நாளாகக் காட்டப்படும்.

## படிகள்

1. IFC மாதிரியைத் திறந்து இடது பலகத்தில் {{ui:4D அட்டவணை}} ஐத் திற.
2. ஒவ்வொரு மாடிக்கும் ஒரு வாரம் கொண்ட பணிப்பட்டியலுக்கு {{ui:வார்ப்புருவைப் பதிவிறக்கு}} என்பதைச் சொடுக்கி, அதை விரிதாளில் மாற்று. அல்லது உங்களுடையதை எழுது.
3. {{ui:பணிப்பட்டியலைத் திற…}} என்பதைச் சொடுக்கி CSV ஐத் தேர்ந்தெடு.
4. தேதி நகர்த்தியை இழு, அல்லது {{ui:இயக்கு}} என்பதைச் சொடுக்கு.

## பணிப்பட்டியல்

தலைப்பு வரியும் **Task**, **Start**, **Finish**, **Field** மற்றும் **Value** நெடுவரிசைகளும் கொண்ட ஒரு CSV. கமாக்களும் அரைப்புள்ளிகளும் இரண்டுமே வேலை செய்யும்.

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| Level 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| Roof | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| Roof | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- தேதிகளை YYYY-MM-DD வடிவில் எழுது.
- ஒரு வரி, அதன் **Field** மதிப்பு **Value** ஐ சரியாகக் கொண்டிருக்கும் ஒவ்வொரு கூறுடனும் பணியை இணைக்கும். Field என்பது Storey, Class, Name, Type, Material, Tag அல்லது GlobalId போன்ற ஒரு பண்பு, அல்லது `Pset_WallCommon.FireRating` போல அதன் தொகுப்பு மற்றும் பெயருடன் எழுதப்பட்ட எந்தப் பண்பும்.
- கூடுதல் கூறுகளை இணைக்க, அதே தேதிகளுடன் அதே பணியை மேலும் வரிகளில் திரும்ப எழுது.

## கட்டங்களும் பணிப் பொதிகளும்

பணிகளைக் கட்டங்களிலும் பணிப் பொதிகளிலும் தொகுக்க **Stage** நெடுவரிசை, **Package** நெடுவரிசை, அல்லது இரண்டையும் சேர். Phase மற்றும் WBS என்பனவும் நெடுவரிசைப் பெயர்களாக வேலை செய்யும்.

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| Level 1 slab | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| Level 1 walls | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| Doors | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- ஒரு பணி ஒரு கட்டத்திலும் ஒரு பணிப் பொதியிலும் மட்டுமே இருக்கும். அதே பணியின் பின்வரும் வரி வேறொன்றைக் குறிப்பிட்டால், அந்த வரி அதன் வரி எண்ணுடன் பட்டியலிடப்பட்டு விடுபடும்.
- இரண்டு கட்டங்களில் ஒரே பணிப் பொதிப் பெயர் இருந்தால், அது இரண்டு பணிப் பொதிகள்.

பட்டியலில் குழுக்கள் இருந்தால், தேதிக்கு மேலே {{ui:காட்டு}} பட்டியல் தோன்றும். ஒரு கட்டத்தையோ பணிப் பொதியையோ தேர்ந்தெடுத்தால் அது ஒன்றாக இயங்கும்:

- நகர்த்தியும் {{ui:இயக்கு}} பொத்தானும் குழுவின் முதல் தொடக்கத்திலிருந்து கடைசி முடிவு வரை இயங்கும்,
- குழுவின் பணிகள் மட்டுமே பட்டியலிடப்பட்டு வண்ணம் தீட்டப்படும்; குழுவுக்கு வெளியே உள்ள அனைத்தும் ஊடுருவும் நிலையில் இருக்கும்,
- பட்டியலுக்குக் கீழுள்ள வரி, அந்தத் தேதியில் அதன் பணிகளில் எத்தனை முடிந்தவை, நடந்துகொண்டிருப்பவை, இனி வரவிருப்பவை என்பதைக் கூறும்,
- {{ui:அதன் கூறுகளைத் தேர்ந்தெடு}} குழுவின் ஒவ்வொரு கூறையும் தேர்ந்தெடுக்கும், {{ui:காட்டு}}, {{ui:குறுக்குவெட்டு}} அல்லது ஓர் அட்டவணைக்காக.

முழு அட்டவணையையும் மீண்டும் காண **ஒவ்வொரு பணியும்** என்பதைத் தேர்ந்தெடு.

## நீங்கள் காண்பவை

- **கட்டப்பட்டது**: எல்லாப் பணிகளும் முடிந்த கூறுகள், அவற்றின் சொந்த வண்ணங்களில்.
- **நடந்துகொண்டிருக்கிறது**: அன்று நடந்துகொண்டிருக்கும் பணி உள்ள கூறுகள், ஓச்சர் நிறத்தில். ஒரு பணி அதன் தொடக்கத் தேதியிலிருந்து முடிவுத் தேதி வரை நடந்துகொண்டிருக்கும்.
- **இன்னும் தொடங்கவில்லை**: ஊடுருவும் நிலையில்.
- எந்தப் பணியிலும் இல்லாத கூறுகள் இருந்தபடியே இருக்கும். ஒவ்வொரு பணியும் எத்தனை கூறுகளைக் கண்டறிந்தது என்பதை பட்டியல் காட்டும். படிக்க முடியாத அல்லது எதையும் கண்டறியாத வரிகள் அவற்றின் வரி எண்களுடன் பட்டியலிடப்படும்.

## இணைப்புகள், கேன்ட் விளக்கப்படம் மற்றும் MS Project

- `Predecessors` நெடுவரிசை உள்ள Microsoft Project XML கோப்பை (`.xml`) அல்லது CSV ஐத் திற. இணைப்புகள் முடிவிலிருந்து தொடக்கம், தொடக்கத்திலிருந்து தொடக்கம், முடிவிலிருந்து முடிவு, அல்லது தொடக்கத்திலிருந்து முடிவு வரை இருக்கலாம்; ஒவ்வொன்றும் நாட்களில் முன்கூட்டியோ தாமதமாகவோ இருக்கலாம்.
- பணிப் பட்டியலுக்குக் கீழே, கேன்ட் விளக்கப்படம் ஒவ்வொரு பணியையும் இணைப்புகளுக்கான அம்புக்குறிகளுடன் ஒரு பட்டையாக வரையும். முக்கியப் பாதையிலுள்ள பணிகள் சிவப்பு. இணைப்பு வளையமோ இல்லாத முன்னோடிப் பணியோ பலகத்தில் பட்டியலிடப்படும்.
- {{ui:MS Project XML ஆகச் சேமி}} மற்றும் {{ui:இணைப்புகளுடன் CSV ஐச் சேமி}} அட்டவணையை அதன் இணைப்புகளுடன் மீண்டும் எழுதும்.
