தற்போதைய பதிப்புகளில் Chrome, Edge, Firefox மற்றும் Safari உலாவிகளில், Mac, Windows மற்றும் Linux இல் BimCraft இயங்குகிறது. 3D காட்சிக்கு WebGL தேவை; அதை ஒவ்வொரு தற்போதைய உலாவியும் கொண்டுள்ளது. ஆப்களுக்குப் பொதுவாகத் தேவையானவை பற்றி [உலாவிகளும் கணினிகளும்](common:browsers) ஐப் பார்க்கவும்.

## கோப்புறையைத் திறத்தல்

| உலாவி | {{ui:கோப்புறையைத் திற}} செய்வது | கோப்புறையை இழுத்து விடுதல் | {{ui:சமீபத்திய கோப்புறைகள்}} |
|---|---|---|---|
| Chrome, Edge | உலாவியின் கோப்புறைத் தேர்வி, பிறகு "இந்தத் தளம் கோப்புகளைப் பார்க்கலாமா?": **கோப்புகளைப் பார்** என்பதைச் சொடுக்கவும் | எந்தக் கேள்வியும் இல்லாமல் திறக்கும் | ஆம், தேர்ந்தெடுக்கப்பட்ட அல்லது இழுக்கப்பட்ட கோப்புறைகளுக்கு |
| Firefox | கணினியின் கோப்புறைத் தேர்வி | எந்தக் கேள்வியும் இல்லாமல் திறக்கும் | இல்லை |
| Safari | கணினியின் கோப்புறைத் தேர்வி, **பதிவேற்று** பொத்தானுடன் (எதுவும் பதிவேற்றப்படாது) | எந்தக் கேள்வியும் இல்லாமல் திறக்கும் | இல்லை |

உள்ளே நடப்பது: Chrome மற்றும் Edge File System Access தேர்வியைப் பயன்படுத்துகின்றன; அவை கோப்புறையை நினைவில் வைத்துக்கொள்ளலாம். Firefox மற்றும் Safari பழைய கோப்புறைத் தேர்வியைப் பயன்படுத்துகின்றன; அது கோப்புறையிலுள்ள எல்லாக் கோப்புகளையும் ஒரே நேரத்தில் கொடுக்கும், நினைவில் வைக்க முடியாது. இழுத்து விடப்பட்ட கோப்புறை ஒவ்வொரு உலாவியிலும் ஒவ்வொரு உள்ளீடாகப் படிக்கப்படும்.

:::chromium
Brave மற்றும் வேறு சில Chromium உலாவிகள் கோப்புறைத் தேர்வியை அணைத்து விடுகின்றன. அப்போது BimCraft கணினியின் கோப்புறைத் தேர்வியைப் பயன்படுத்துகிறது, மேலும் உலாவி "இந்தத் தளத்திற்கு *n* கோப்புகளைப் பதிவேற்றவா?" எனக் கேட்கலாம். எதுவும் பதிவேற்றப்படாது; கோப்புகள் தாவலுக்கு மட்டுமே செல்லும். கோப்புறையை இழுத்து விடுவதன் மூலம் அந்தக் கேள்வியைத் தவிர்க்கலாம்.
:::

## Mac, Windows மற்றும் Linux

- {{key:Mod+S}} மற்றும் {{key:Mod+Z}} என எழுதப்பட்ட குறுக்குவழிகள் Mac இல் Command, Windows மற்றும் Linux இல் Ctrl ஆகும்.
- {{key:Ctrl+Shift+F}} (திரை முறைகள்) எல்லாத் தளங்களிலும் Control தான், Mac உட்பட.
- கோப்பு உரையாடல்களும் பதிவிறக்கக் கோப்புறையும் உங்கள் கணினியுடையவை.

## சுட்டி, டிராக்பேட் மற்றும் தொடுதல்

| உள்ளீடு | 3D காட்சி | 2D வரைபடம் |
|---|---|---|
| சுட்டி | இடது-இழுத்தல் சுற்றும், வலது-இழுத்தல் நகர்த்தும், சக்கரம் பெரிதாக்கும், சொடுக்கு தேர்ந்தெடுக்கும் | எந்த இழுத்தலும் நகர்த்தும், சக்கரம் பெரிதாக்கும், இருமுறை சொடுக்கினால் பொருந்தும் |
| டிராக்பேட் | சொடுக்கி-இழுத்தல் சுற்றும்; {{key:Shift}} அல்லது {{key:Mod}} மற்றும் இழுத்தல் நகர்த்தும்; இரண்டு விரல் உருட்டல் அல்லது கிள்ளுதல் பெரிதாக்கும் | சொடுக்கி-இழுத்தல் நகர்த்தும்; இரண்டு விரல் உருட்டல் அல்லது கிள்ளுதல் பெரிதாக்கும் |
| தொடுதல் | ஒரு விரல் சுற்றும், இரண்டு விரல்கள் கிள்ளி நகர்த்தும், தட்டுதல் தேர்ந்தெடுக்கும் | ஒரு விரல் நகர்த்தும்; இன்னும் கிள்ளிப் பெரிதாக்கம் இல்லை; {{ui:பொருத்து}} ஐத் தட்டவும் |

Mac டிராக்பேடில், வலது-சொடுக்கு என்பது இரண்டு விரல் சொடுக்கு (அல்லது Control உடன் சொடுக்குதல்). [விசைகள், சுட்டிகள் மற்றும் டிராக்பேட்கள்](common:keys) ஐப் பார்க்கவும்.

டேப்லெட்டுகளும் தொலைபேசிகளும் தனிக் கோப்புகளைத் திறந்து பார்க்கலாம்; ஆனால் திரை சிறியது, பல மொபைல் உலாவிகளால் கோப்புறைகளைத் தேர்ந்தெடுக்க முடியாது, பெரிய மாதிரிகள் அவற்றின் நினைவகத்தில் பொருந்தாமல் போகலாம். கணினி சிறப்பாக வேலை செய்யும்.

## பெரிய கோப்புகளும் நினைவகமும்

BimCraft படிக்கும் எல்லாமே உலாவித் தாவலின் நினைவகத்தில் இருக்கும். ஒரு தாவல் எவ்வளவு பயன்படுத்தலாம் என்பது BimCraft ஐ விட உலாவி மற்றும் உங்கள் கணினியைப் பொறுத்தது.

| கோப்பு | எவ்வளவு படிக்கப்படுகிறது | எதை எதிர்பார்க்கலாம் |
|---|---|---|
| IFC | முழுக் கோப்பு, அதிலிருந்து உருவாக்கப்பட்ட 3D வடிவவியலுடன் | எவ்வளவு பெரியது என்பது உங்கள் கணினி மற்றும் உலாவியைப் பொறுத்தது; பல நூறு மெகாபைட் மாதிரி மடிக்கணினிக்கு அதிகமாக இருக்கலாம். 1.5 million முக்கோணங்களுக்கு மேல் இருந்தால், விளிம்புகள் அணைக்கப்படும் |
| திட்டக் கோப்புகளும் குடும்பக் கோப்புகளும் | கோப்பின் அளவு எதுவாக இருந்தாலும் சுமார் 40 KB முதல் 100 KB வரை | மிகப் பெரிய மைய மாதிரிகள் கூட சில நொடிகளில் திறக்கும்; பிணைய இயக்ககத்திலிருந்தும் |
| DWG மற்றும் DXF | முழுக் கோப்பு | மிகப் பெரிய வரைபடங்கள் "இந்த வரைபடம் மிகப் பெரியது; அதன் ஒரு பகுதி மட்டுமே காட்டப்படுகிறது." எனக் காட்டும் |
| கோப்புறைகள் | கோப்புப் பட்டியல், மாதிரி ஒன்றுக்கு சில கிலோபைட்டுகள் | 20,000 கோப்புகள் வரை |

ஒரு தாவலின் நினைவகம் தீர்ந்துவிட்டால், உலாவி தனது சொந்தப் பிழைப் பக்கத்தைக் காட்டும் (எடுத்துக்காட்டாக, Chrome இல் "Aw, Snap!"). மற்ற தாவல்களை மூடவும், BimCraft ஐ மீண்டும் ஏற்றி முயற்சிக்கவும், அல்லது அதிக நினைவகம் உள்ள கணினியைப் பயன்படுத்தவும்.
