ஒரு துணை நிரல் (அமைப்புகள் › துணை நிரல்கள்) {{ui:ரெண்டர்}} இன் எஞ்சின் பட்டியலில் ஓர் எஞ்சினைச் சேர்க்க முடியும். துணை நிரல் எழுதுபவர்களுக்கான முழு உரை, துணை நிரல் விவரக்குறிப்பின் 16வது பிரிவில் உள்ளது; சுருக்கமாக:

- துணை நிரல் ஓர் எஞ்சினைப் பதிவு செய்கிறது: அதன் சொந்த முன்னொட்டுடன் தொடங்கும் id, ஒரு பெயர், விருப்ப அமைப்புகள், மற்றும் **அல்லது** ஒரு நிரலை இயக்குவது **அல்லது** படத்தை வரையும் ஒரு JavaScript செயல்பாடு.
- ஒரு நிரலை இயக்கும் எஞ்சினுக்கு **`engine.run`** அனுமதி தேவை; அது நிறுவுவதற்கு முன்னும் அமைப்புகளிலும் காட்டப்படும். அது Studio இல் மட்டுமே இயங்கும்; உலாவியில் அது சேமிக்க வேண்டிய ஒரு கோப்பாகக் காட்டப்படும்.
- துணை நிரல் நிரலின் பெயரைக் குறிப்பிடுகிறது (ஒரு வெற்றுக் கோப்புப் பெயர்: ஒருபோதும் ஷெல் அல்ல), **கையொப்பமிடப்பட்ட துணை நிரலுக்குள்** இருக்கும் ஒரு ஸ்கிரிப்ட், மற்றும் இட ஒதுக்கிகள் மற்றும் எளிய சொற்களால் ஆன வாதங்கள். Studio நிரலைக் கண்டறியும், அல்லது ஒரு முறை அதைச் சுட்டிக்காட்டும்படி கேட்கும்.
- ஒரு துணை நிரல் முதல் முறையாக ஒரு நிரலை இயக்கும்போது, **Studio அதன் சொந்த உரையாடலில் உங்களிடம் கேட்கும்**: எந்த துணை நிரல், எந்த நிரல், மற்றும் ஒரு ஸ்கிரிப்ட் நிரல் செய்யக்கூடிய எதையும் செய்ய முடியும் என்பது. நம்பும் துணை நிரலுக்கு மட்டும் அனுமதியுங்கள். உங்கள் பதில் அந்தத் துணை நிரலுக்கும் நிரலுக்கும் நினைவில் வைக்கப்படும்.
- தொகுப்பு (காட்சி USD ஆகவும், அது கேட்கும்போது glTF கோப்புடன் அமைப்புகள் கோப்பாகவும்) மற்றும் துணை நிரலின் ஸ்கிரிப்ட் ஒரு புதிய தற்காலிகக் கோப்புறையில் வைக்கப்படும், நிரல் அங்கே இயங்கும், படம் துணை நிரலின் எஞ்சின் பெயருடன் குறிக்கப்பட்டுத் திரும்பும்.

:::note
துணை நிரல்கள் துணை நிரல் API 1.4 இலிருந்துதான் ரெண்டர் எஞ்சின்களைச் சேர்க்க முடியும். திறந்த மூல கட்டளை-வரி ரெண்டரருக்கான வேலை செய்யும் எடுத்துக்காட்டு அதன் சொந்த களஞ்சியத்தில் உள்ளது; அந்த ரெண்டரரில் அது இன்னும் இயக்கப்படவில்லை.
:::
