## ஒரு IFC கூறு

{{ui:பண்புகள்}} பலகத்தின் மேல் பகுதி கூறின் வகையை "Ifc" முன்னொட்டு இல்லாமல் காட்டும் (எடுத்துக்காட்டாக "Door", "WallStandardCase", "FurnishingElement") மற்றும் அதன் பெயரையும், பெயர் இல்லையென்றால் "பெயரிடப்படாதது" என்பதையும் காட்டும்.

| புலம் | பொருள் | திருத்தக்கூடியதா |
|---|---|---|
| பெயர் | கூறின் பெயர், பெரும்பாலும் ஏற்றுமதியாளரிடமிருந்து குடும்பம் மற்றும் வகையின் பெயர் | ஆம் |
| வகை | கூறின் வகையின் பெயர், அது ஒன்று இருந்தால் | இல்லை |
| பொருள் வகை | சில ஏற்றுமதியாளர்கள் நிரப்பும் இலவச-உரை வகை விளக்கம் | ஆம் |
| குறி | கூறின் குறி அல்லது அடையாளம்; பல ஏற்றுமதியாளர்கள் கூறின் ID ஐ இங்கே எழுதுவார்கள் | ஆம் |
| விவரம் | இலவச உரை | ஆம் |
| GlobalId | கூறின் நிரந்தர 22-எழுத்து IFC அடையாளம், அதே கூறின் ஒவ்வொரு ஏற்றுமதியிலும் ஒன்றே | இல்லை |
| வரி | இந்த IFC கோப்பில் கூறின் வரி எண் (`#1234`). ஏற்றுமதிகளுக்கு இடையே அது மாறும் | இல்லை |

கீழே **பண்புத் தொகுப்புகள்** பெயர் வரிசையில் வரும்:

- ஒவ்வொரு தொகுப்பும் அதன் பெயரைச் சொடுக்கும்போது திறந்து மூடும். முதல் மூன்று திறந்திருக்கும்.
- **(வகை)** எனக் குறிக்கப்பட்ட தொகுப்பு கூறின் வகைக்குச் சொந்தமானது: "வகைப் பண்பு: இங்கே செய்யும் மாற்றம் இந்த வகையின் ஒவ்வொரு கூறுக்கும் பொருந்தும்."
- அளவுத் தொகுப்புகள் (நீளங்கள், பரப்பளவுகள், கனஅளவுகள், எண்ணிக்கைகள், எடைகள்) படிக்க மட்டுமே.
- பட்டியல்களும் கணக்கிடப்பட்ட மதிப்புகளும் காட்டப்படும், படிக்க மட்டுமே.
- ஆம்/இல்லை மதிப்புகள் **ஆம்** அல்லது **இல்லை** எனக் காட்டப்படும்.
- எண்கள் நான்கு தசம இடங்களுக்கு வட்டமிடப்பட்டுக் காட்டப்படும். நீளங்கள் (நீள பண்பு அல்லது அளவின் நீளம்) கருவிப்பட்டியில் தேர்ந்தெடுத்த {{ui:அலகுகள்}} இல், அலகுக் குறியுடன் காட்டப்படும்; அந்த அலகில் அல்லது வேறு அலகுக் குறியுடன் (2.4 m, 8'-0") புதிய எண்ணை தட்டச்சு செய்யலாம்: BimCraft கோப்பின் சொந்த எண்ணை மீண்டும் எழுதும். மற்ற எண்கள் கோப்பில் உள்ளபடி காட்டப்படும்.
- காலியான மதிப்பு *காலி* எனக் காட்டப்படும். திருத்தப்பட்ட மதிப்பு தடிமனாகவும் அருகில் நீல பட்டையுடனும் இருக்கும்.

## ஒரு மதிப்பை நகலெடு

{{ui:பண்புகள்}} இல் ஒவ்வொரு மதிப்பின் அருகிலும் ஒரு சிறிய நகல் பொத்தான் உண்டு: அதைச் சொடுக்கினால் அந்த மதிப்பு திரையில் காட்டப்படுவது போலவே இடைநிலைப் பலகைக்குச் செல்லும்; எடுத்துக்காட்டாக GlobalId, வரிசை எண் அல்லது எந்தப் பண்புத் தொகுப்பு மதிப்பும். நகலெடுப்பது ஒருபோதும் திருத்தத்தைத் தொடங்காது.

மேலே {{ui:அனைத்தையும் நகலெடு}} ஒரு கூறின் ஒவ்வொரு மதிப்பையும் உரையாக, தொகுப்பு தொகுப்பாக நகலெடுக்கும்; {{ui:CSV ஆக நகலெடு}} குழு, பண்பு மற்றும் மதிப்பு வரிசைகளாக நகலெடுக்கும், விரிதாளில் ஒட்டுவதற்கு; காலி மதிப்புகள் ஒவ்வொரு புலத்துக்கும் ஒரு வரிசை இருக்கும்படி வைக்கப்படும். இது திறந்திருக்கும் வேறு மாதிரியின் கூறுக்கும் அதேபோல் செயல்படும்; ஒன்றுக்கும் மேற்பட்ட மாதிரிகள் திறந்திருந்தால், CSV ஒரு Model நெடுவரிசையுடன் தொடங்கும், அதில் அதன் கோப்புப் பெயர் இருக்கும்.

| புலம் | பொருள் |
|---|---|
| கோப்பு, அளவு | நீங்கள் திறந்த கோப்பு |
| திட்ட வரையறை | IFC பதிப்பு, எடுத்துக்காட்டாக IFC2X3 அல்லது IFC4 |
| திட்டம் | திட்டத்தின் பெயரும் நீண்ட பெயரும் |
| கட்டம் | திட்டக் கட்டம், ஏற்றுமதியாளர் ஒன்றை எழுதியிருந்தால் |
| ஏற்றுமதி செய்தது | கோப்புத் தலைப்பிலிருந்து, ஏற்றுமதி செய்த நிரல் |
| ஆசிரியர் | கோப்புத் தலைப்பிலுள்ள ஆசிரியர் |
| ஏற்றுமதி செய்த நேரம் | கோப்புத் தலைப்பிலுள்ள தேதியும் நேரமும் |
| கூறுகள் | வடிவத்துடன் வரையப்பட்ட கூறுகள் எத்தனை |
| முக்கோணங்கள் | அவற்றின் வடிவங்கள் உருவாக்கும் முக்கோணங்கள்; மாதிரி எவ்வளவு கனமானது என்பதற்கான அளவு |
