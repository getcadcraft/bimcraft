ஒருவர் அதே கட்டடத்தின் ஒரு நகலை எடுக்கிறார், ஒருவர் கிழக்குப் பகுதியையும் மற்றொருவர் மேற்குப் பகுதியையும் வரைகிறார், பின்னர் நகல்கள் ஒன்றாக வேண்டும். அவர்கள் வெவ்வேறு பொருட்களைத் தொட்டிருந்தால், ஒரு நிரல் ஒரு நபருக்குப் பதிலாக அதைச் செய்ய முடியும்.

## இது எப்படி வேலை செய்கிறது

IFC கோப்பில் உள்ள ஒவ்வொரு சுவர், கதவு, மட்டம், அறை மற்றும் பண்புத் தொகுப்புக்கும் ஒருபோதும் மாறாத GlobalId உண்டு. இணைப்பு கோப்பு கொடுக்கும் எண்ணால் (`#123`) அல்ல, அந்த ஐடியால் பொருள்களைத் தேடுகிறது, ஏனெனில் ஒரு நிரல் சேமிக்கும்போது எண்கள் மாறும். ஒரு பொருளிலிருந்து தொங்கும், தனக்கென ஐடி இல்லாத பகுதிகள் (இடங்கள், வடிவங்கள், அலகுகள்) அவை கொண்டுள்ளவற்றால் ஒப்பிடப்படுகின்றன.

இரு நகல்களும் ஒரே IFC பதிப்பாக இருக்க வேண்டும் (2x3, 4 அல்லது 4.3). இணைப்பு உங்கள் கோப்பை அது இருப்பது போலவே, அதன் வரிசையும் எண்களும் உட்பட வைத்திருக்கிறது, புதியதைச் சேர்க்கிறது; ஆகவே இணைப்பின் git diff காட்டுவது இணைப்பு மாற்றியதை மட்டுமே.

## அமைக்கவும்

Git-க்கு ஒரு களஞ்சியத்துக்கு ஒரு முறை இரண்டு வரிகள் தேவை:

```
# .gitattributes
*.ifc merge=cadcraft

# ஒரு முறை, ஒவ்வொரு கணினியிலும்
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git இல்லாமல், `cadcraft merge <base> <ours> <theirs>` ஐ இயக்குங்கள். Fossil மற்றும் Mercurial அதே மூன்று கோப்புகளை அவற்றின் சொந்த இணைப்புக் கருவி அமைப்பில் எடுக்கின்றன. எதுவும் பதிவேற்றப்படுவதில்லை; எல்லாம் உங்கள் கணினியிலேயே இயங்குகிறது.

## விதிகள்

- ஒரு பக்கத்தில் மட்டும் மாற்றப்பட்ட பண்பு எடுக்கப்படுகிறது. இரு பக்கங்களிலும் ஒரே மாற்றம் ஒருமுறை எடுக்கப்படுகிறது.
- ஒரே பண்பு இரு வழிகளில் மாற்றப்பட்டால் (அதே மட்டம் இரு வழிகளில் மறுபெயரிடப்பட்டால்) அது **முரண்பாடு**: உங்கள் பக்கம் இருக்கும், அறிக்கை இரண்டையும் பட்டியலிடும். முடிவைத் திறந்து கையால் சரிசெய்யுங்கள்.
- பொருட்களின் பட்டியல் (ஒரு மட்டத்தின் சுவர்கள், ஒரு தொகுப்பின் பண்புகள்) ஒரு தொகுப்பாக இணைகிறது: எந்தப் பக்கம் சேர்த்ததும் இருக்கும், எந்தப் பக்கம் நீக்கியதும் நீக்கப்படும். ஒரே மட்டத்தில் இருவர் தனித்தனியாகச் சுவர்கள் சேர்ப்பது முரண்பாடாகாது.
- ஏதேனும் ஒரு பக்கத்தில் சேர்க்கப்பட்ட பொருள் அதன் வடிவம் மற்றும் பண்புகளுடன் வைக்கப்படும். ஒரு பக்கத்தில் நீக்கப்பட்டு மறுபக்கம் தொடப்படாமல் இருந்தால்: நீக்கப்படும். ஒரு பக்கத்தில் நீக்கப்பட்டு மறுபக்கம் மாற்றப்பட்டால்: நீக்கப்படும், மேலும் அறிவிக்கப்படும்.
- கோப்பின் நேர முத்திரையும் ஆசிரியரும், ஒவ்வொரு பொருளின் உரிமையாளர் வரலாறும் உங்களுடையதாகவே இருக்கும்.

வடிவவியல் முழுவதுமாக இணைக்கப்படுகிறது: ஒரு சுவரின் வடிவம் ஒரு பக்கத்திலிருந்து வருகிறது, புள்ளி புள்ளியாகக் கலக்கப்படுவதில்லை. ஜிப் செய்யப்பட்ட IFC மற்றும் IFCX கோப்புகள் இணைக்கப்படுவதில்லை. ஓர் இணைப்புக்குப் பிறகு, சேமிக்கும் முன் BimCraft-இல் முடிவைத் திறந்து சிக்கல்கள் பலகத்தைப் பாருங்கள்.
