BimCraft-இல் சில குறுக்குவழிகளே உள்ளன. பெரும்பாலான வேலைகள் சுட்டியாலும் பலகங்களாலும் செய்யப்படுகின்றன. {{key:Mod}} எனக் எழுதப்பட்ட குறுக்குவழிகள் Mac-இல் Command-ஐயும் மற்ற இடங்களில் Ctrl-ஐயும் பயன்படுத்தும். இந்த உதவியில் விசைகள் எப்படி எழுதப்பட்டுள்ளன என்பதற்கு [விசைகள், சுட்டிகள் மற்றும் டிராக்பேடுகள்](common:keys) பார்க்கவும்.

## எல்லா இடங்களிலும்

| விசை | என்ன செய்யும் |
|---|---|
| {{key:Ctrl+Shift+F}} | திரை முறைகளைச் சுழற்று: சாதாரணம், முழுத்திரை, பட்டிகள் மறைந்த முழுத்திரை. எல்லா தளங்களிலும் Ctrl, Mac உட்பட |
| {{key:Esc}} | முழுத்திரையிலிருந்து வெளியேறு |
| {{key:Mod+,}} | {{ui:அமைப்புகள்}} திற. பார்க்க [BimCraft அமைப்புகள்](topic:settings) |
| {{key:Tab}} | பொத்தான்கள், தேர்வுப்பெட்டிகள் மற்றும் மதிப்புகளுக்கு இடையே நகர். ஒவ்வொரு கட்டுப்பாட்டையும் விசைப்பலகையால் அடையலாம் |

## 3D காட்சி (IFC மாதிரிகள்)

| விசை அல்லது செயல் | என்ன செய்யும் |
|---|---|
| {{key:F}} | முழு மாதிரியையும் பொருத்து, முக்கால் பார்வை (அதே {{ui:பொருத்து}}) |
| {{key:Esc}} | தேர்வை அழி, அல்லது வைப்பதையோ ஒட்டுவதையோ நிறுத்து |
| சொடுக்கு | சுட்டிக்குக் கீழுள்ள உறுப்பைத் தேர்ந்தெடு; காலி பின்னணியில் சொடுக்கினால் தேர்வு நீங்கும் |
| {{key:Mod}}+சொடுக்கு அல்லது {{key:Shift}}+சொடுக்கு | தேர்வில் ஓர் உறுப்பைச் சேர் அல்லது அதை நீக்கு |
| {{key:H}} | தேர்ந்தெடுத்த உறுப்புகளை மறை. பார்க்க [உறுப்புகளை மறை, தனிமைப்படுத்து மற்றும் ஊடுருவிப் பார்](topic:hide-and-isolate) |
| {{key:I}} | தேர்ந்தெடுத்த உறுப்புகளை மட்டும் காட்டு (தனிமைப்படுத்து) |
| {{key:T}} | தேர்ந்தெடுத்த உறுப்புகளைக் காட்டு, மற்ற அனைத்தும் ஊடுருவும் |
| {{key:Shift+H}} | ஒவ்வோர் உறுப்பையும் மீண்டும் காட்டு |
| {{ui:நடைசுற்று}} | பிறகு {{key:W}} {{key:A}} {{key:S}} {{key:D}} அல்லது அம்புக்குறிகள் நடக்க வைக்கும், {{key:Shift}} ஓடச் செய்யும், இழுத்தல் சுற்றிப் பார்க்கும், {{key:Esc}} நிறுத்தும். பார்க்க [மாதிரியில் நடந்து செல்](topic:walk) |
| {{key:M}} | தூரங்களையும் முகப் பரப்பளவுகளையும் அளவிடு. பார்க்க [3D-இல் தூரங்கள், முகப் பரப்பளவுகள் மற்றும் இடங்களை அளவிடு](topic:measure) |
| இடது பொத்தானுடன் இழு | சுற்றிவளை |
| வலது பொத்தானுடன் இழு | நகர்த்து |
| {{key:Shift}} அல்லது {{key:Mod}} பிடித்து இடது பொத்தானுடன் இழு | நகர்த்து (டிராக்பேடிற்கு வசதியானது) |
| சக்கரத்தை உருட்டு, அல்லது நடு பொத்தானுடன் இழு | பெரிதாக்கு |
| டிராக்பேடில் இரு-விரல் உருட்டல் அல்லது கிள்ளு | பெரிதாக்கு |
| ஒரு விரல் (தொடுதல்) | சுற்றிவளை; ஒரு தட்டு தேர்ந்தெடுக்கும் |
| இரு விரல்கள் (தொடுதல்) | கிள்ளிப் பெரிதாக்கு, ஒன்றாக நகர்த்தினால் நகர்த்து |

| விசை | என்ன செய்யும் |
|---|---|
| {{key:X}} | வெட்டு விமானம் இயக்கம்/நிறுத்தம். பார்க்க [வெட்டு விமானத்தால் IFC மாதிரியை வெட்டு](topic:section-plane) |
| {{key:Shift+X}} | தேர்ந்தெடுத்த உறுப்புகளைச் சுற்றி வெட்டுப் பெட்டி, அமைப்புகளில் அமைக்கப்பட்ட அறையுடன் |

{{ui:மேல்}}, {{ui:முன்}} மற்றும் {{ui:பக்கம்}}க்கு விசைகள் இல்லை; பொத்தான்களைப் பயன்படுத்து.

## திருத்து

அதே கட்டளைகள் கருவிப்பட்டியிலும் உள்ளன: {{ui:செயல்தவிர்}}, {{ui:மீண்டும்செய்}}, {{ui:நகலெடு}}, {{ui:ஒட்டு}} மற்றும் {{ui:மேலும்}} பட்டி, அது ஒவ்வொரு விசையையும் காட்டும். அவை IFC மாதிரியின் 3D காட்சியில் வேலை செய்யும்; புலத்தில் தட்டச்சு செய்யும்போது அல்ல. பார்க்க [நூலக உருப்படிகளை நகலெடு, ஒட்டு மற்றும் நகலாக்கு](topic:copy-paste).

| விசை | என்ன செய்யும் |
|---|---|
| {{key:Mod+Z}} | கடைசி மாற்றத்தைச் செயல்தவிர் |
| {{key:Mod+Y}} அல்லது {{key:Mod+Shift+Z}} | செயல்தவிர் திரும்பப் பெற்றதை மீண்டும்செய் |
| {{key:Mod+C}} | தேர்ந்தெடுத்த உறுப்புகளை நகலெடு (அவற்றின் பெயர்களும் பண்புகளும் உரையாக இடைநிலைப் பலகைக்கும் செல்லும்) |
| {{key:Mod+X}} | தேர்ந்தெடுத்த உறுப்புகளை வெட்டு: நகலெடுத்து, பிறகு நீக்கு |
| {{key:Mod+V}} | நகலெடுத்ததை ஒட்டு: அது சுட்டியைப் பின்தொடரும்; அது போக வேண்டிய இடத்தில் சொடுக்கு |
| {{key:Mod+Shift+V}} | அதே இடத்தில் ஒட்டு: வெட்டிய இடத்தில், அல்லது நகலெடுத்த பிறகு அசல்களுக்கு அருகில் |
| {{key:Mod+D}} | நகலாக்கு: தேர்ந்தெடுத்த உறுப்புகளை நகலெடுத்து அவற்றை ஒட்டத் தொடங்கு |
| {{key:Delete}} | தேர்ந்தெடுத்த உறுப்புகளை, அவற்றின் பகுதிகள் மற்றும் துவாரங்களுடன் நீக்கு. பார்க்க [கட்டட உறுப்புகளை நீக்கு, வெட்டு, நகலெடு மற்றும் ஒட்டு](topic:edit-elements) |
| {{key:Mod+A}} | காட்டப்படும் ஒவ்வோர் உறுப்பையும் தேர்ந்தெடு |
| {{key:Esc}} | எதையும் தேர்ந்தெடுக்காதே |

பக்கத்தில் உரை தேர்ந்தெடுக்கப்பட்டிருக்கும்போது, {{key:Mod+C}} வழக்கம் போல் அந்த உரையை நகலெடுக்கும்.

## திட்டக் காட்சி (வரை)

{{ui:வரை}} இயக்கத்தில் இருக்கும்போதும், நீங்கள் புலத்தில் தட்டச்சு செய்யாதபோதும் இவை வேலை செய்யும். பார்க்க [சுவர்களை வரை](topic:draw-walls) மற்றும் [கதவுகளும் சன்னல்களும்](topic:doors-and-windows).

| விசை அல்லது செயல் | என்ன செய்யும் |
|---|---|
| {{key:V}} | {{ui:தேர்ந்தெடு}} |
| {{key:W}} | {{ui:சுவர்}} |
| {{key:D}} | {{ui:கதவு}} |
| {{key:N}} | {{ui:சன்னல்}} |
| {{key:H}} | {{ui:கதவு}} அல்லது {{ui:சன்னல்}} தேர்வில்: கீல்கள் மறு முனையில் |
| சுவர் வரையும்போது {{key:Shift}} | சுவரை 0°, 90°, 180° அல்லது 270° கோணத்தில் வை |
| இலக்கங்களும் அடி, அங்குலக் குறிகளும் (`'` மற்றும் `"`) | {{ui:நீளம்}} பெட்டியில் நீளத்தைத் தட்டச்சு செய்யத் தொடங்கு; {{key:Enter}} அதைப் பயன்படுத்தும் |
| {{key:Enter}}, {{key:Esc}}, வலது சொடுக்கு அல்லது இரட்டைச் சொடுக்கு | வரைந்துகொண்டிருக்கும் சுவரை முடி; {{key:Esc}} மீண்டும் அழுத்தினால் {{ui:தேர்ந்தெடு}}க்குத் திரும்பும் |
| {{key:Delete}} | தேர்ந்தெடுத்த சுவர்கள், கதவுகள் மற்றும் சன்னல்களை நீக்கு; மீதமுள்ள சுவர்கள் மீண்டும் இணையும் |
| சுட்டி வரைபடத்தின் மேல் இருக்கும்போது {{key:F}} | வரைபடத்தைப் பொருத்து |
| சக்கரத்தை உருட்டு | சுட்டியைச் சுற்றி பெரிதாக்கு |
| நடு அல்லது வலது பொத்தானுடன் இழு, அல்லது {{key:Space}} அழுத்தி இழு | நகர்த்து; {{ui:தேர்ந்தெடு}} இயக்கத்தில் இருந்தால், வெறும் இழுத்தலும் நகர்த்தும் |
| {{ui:தேர்ந்தெடு}} உடன் கதவை அல்லது சன்னலை இழு | அதன் சுவரில் நகர்த்து, அல்லது மற்றொரு சுவருக்கு நகர்த்து |
| இரு விரல்கள் (தொடுதல்) | கிள்ளிப் பெரிதாக்கு, ஒன்றாக நகர்த்தினால் நகர்த்து |

| {{key:Mod+Y}} | செயல்தவிர் திரும்பப் பெற்றதை மீண்டும்செய் |
| {{key:Mod+S}} | IFC ஆக சேமி. சேமிக்கப்படாத மாற்றங்கள் இருக்கும்போது மட்டும்; இல்லையெனில் உலாவியின் சொந்த சேமி கட்டளை திறக்கும் |

விசைப்பலகையை மட்டும் பயன்படுத்தித் திருத்த: ஒரு மதிப்பு தேர்ந்தெடுக்கப்படும் வரை {{key:Tab}} அழுத்து, பிறகு தட்டச்சு செய்யத் தொடங்க {{key:Enter}} அழுத்து.

## 2D வரைபடங்கள் (DWG மற்றும் DXF)

| விசை அல்லது செயல் | என்ன செய்யும் |
|---|---|
| {{key:F}} | வரைபடத்தையோ தாளையோ பொருத்து |
| {{key:P}} | அச்சுக் காட்சி இயக்கம்/நிறுத்தம் |
| இரட்டைச் சொடுக்கு | பொருத்து |
| எந்தப் பொத்தானுடனும் இழு | நகர்த்து |
| சக்கரத்தை உருட்டு | சுட்டியில் பெரிதாக்கு |
| டிராக்பேடில் இரு-விரல் உருட்டல் அல்லது கிள்ளு | சுட்டியில் பெரிதாக்கு. இரு-விரல் உருட்டல் நகர்த்தாது |
| ஒரு விரல் (தொடுதல்) | நகர்த்து. வரைபடங்களுக்குக் கிள்ளிப் பெரிதாக்கல் இன்னும் உருவாக்கப்படவில்லை |

## 3D-இல் வரைபடங்கள்

| விசை அல்லது செயல் | என்ன செய்யும் |
|---|---|
| {{key:3}} | 3D இயக்கம்/நிறுத்தம் (2D காட்சியிலும்) |
| {{key:F}} | எல்லைகள்: முழு வரைபடம் |
| நடு அல்லது இடது பொத்தானுடன் இழு | சுற்றிவளை |
| வலது பொத்தானுடன் இழு, அல்லது {{key:Shift}} பிடித்து இழு | நகர்த்து |
| சக்கரத்தை உருட்டு | சுட்டியின் கீழுள்ளதை நோக்கி பெரிதாக்கு |
| டிராக்பேடில் இரு-விரல் உருட்டல் | சுற்றிவளை; {{key:Shift}} உடன், நகர்த்து |
| டிராக்பேடில் கிள்ளு | பெரிதாக்கு |
| ஒரு விரல் (தொடுதல்) | சுற்றிவளை |
| இரு விரல்கள் (தொடுதல்) | கிள்ளிப் பெரிதாக்கு, ஒன்றாக நகர்த்தினால் நகர்த்து |

{{key:F}}, {{key:P}} மற்றும் {{key:3}} நீங்கள் புலத்தில் தட்டச்சு செய்யும்போதும், உபகரண அட்டவணை காட்டப்படும்போதும், அல்லது {{key:Mod}} அல்லது {{key:Alt}} பிடித்திருக்கும்போதும் எதுவும் செய்யாது.
