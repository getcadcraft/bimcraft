## IFC

| படிப்பது | விவரங்கள் |
|---|---|
| வடிவியல் | வடிவம் கொண்ட ஒவ்வொரு கூறும், கோப்பு கூறும் நிறத்தில். அறைகளும் இடங்களும் ஊடுருவும் வகையில் வரையப்பட்டு, முதலில் மறைக்கப்பட்டிருக்கும் |
| மாடிகள் | கட்டிட மாடிகள் உயர வரிசையில், ஒவ்வொன்றின் மீதுள்ள கூறுகளுடன். எந்த மாடியிலும் இல்லாத கூறுகள் "மாடியில் இல்லை" எனத் தொகுக்கப்படும் |
| கூறு எண்ணிக்கைகள் | ஒவ்வொரு வகைக் கூறும் எத்தனை (சுவர்கள், கதவுகள், அடுக்குகள்…), **கூறுகள்** இல் காட்டப்படும் |
| திட்டத் தகவல்கள் | திட்டப் பெயர், நீண்ட பெயர் மற்றும் கட்டம்; திட்டம்; கோப்புத் தலைப்பிலிருந்து ஏற்றுமதி செய்த நிரல், ஆசிரியர் மற்றும் ஏற்றுமதி தேதி |
| கூறு தரவு | பெயர், வகை, பொருள் வகை, குறி, விவரம், GlobalId; கூறிலும் அதன் வகையிலும் உள்ள ஒவ்வொரு பண்புத் தொகுப்பும் அளவுத் தொகுப்பும் |

திருத்தக்கூடியவை: பெயர், பொருள் வகை, குறி, விவரம், மற்றும் ஒற்றைப் பண்பு மதிப்புகள். புதிய IFC கோப்பாகச் சேமிக்கப்படும். IFC2X3, IFC4 மற்றும் IFC4X3 திட்டங்கள் திறக்கும், BimCraft-இன் சொந்த IFC இயந்திரத்தால் படிக்கப்படும்; அது இன்னும் வரைய முடியாதவை {{ui:File}} பலகத்தில் **இன்னும் வரையப்படவில்லை** இன் கீழ் பட்டியலிடப்படும். மாதிரி திறக்கும்போது தோற்றப் புள்ளிக்கு நகர்த்தப்படும், எனவே தொலைவில் வைக்கப்பட்ட மாதிரியும் திரையின் நடுவில் தெரியும். `.ifczip` மற்றும் `.ifcxml` திறக்காது.

## திட்டம் மற்றும் குடும்பக் கோப்புகள்

`.rvt` திட்டங்கள், `.rte` திட்ட வார்ப்புருக்கள், `.rfa` குடும்பங்கள் மற்றும் `.rft` குடும்ப வார்ப்புருக்கள்.

| படிப்பது | விவரங்கள் |
|---|---|
| கோப்புத் தகவல் | வெளியீடு மற்றும் கட்டம், பகிர்வு வேலை, மைய மாதிரியின் பாதை, கடைசியாகச் சேமித்த பாதை, பயனர் பெயர், மொழி, ஆவண GUID |
| திட்டத் தகவல் | திட்டத்தின் சொந்தப் புலங்கள் (பெயர், எண், வாடிக்கையாளர், முகவரி, நிலை…), புதிய-திட்ட இயல்புநிலைகள் இல்லாமல் |
| குடும்பத் தகவல் | குடும்பப் பெயர், வகை, வெளியீடு, கடைசிப் புதுப்பிப்பு, மற்றும் அதன் அளபுருக்கள் குழுவாக |
| இணைப்புகள் | கோப்பு சுட்டிக்காட்டும் இணைக்கப்பட்ட மாதிரிகள், CAD இணைப்புகள், படங்கள் மற்றும் குறிப்பு அட்டவணைகளின் பட்டியல் |
| முன்னோட்டப் படம் | கோப்பில் சேமிக்கப்பட்ட சிறுபடம் |

படிக்கப்படாதவை: 3D மாதிரி, கூறுகள், காட்சிகள், தாள்கள் மற்றும் அட்டவணைகள். அவை ஆவணப்படுத்தப்படாத வடிவத்தில் சேமிக்கப்பட்டுள்ளன. BimCraft ஒவ்வொரு கோப்பிலிருந்தும் சில பத்து கிலோபைட்டுகளை மட்டுமே படிக்கிறது, எனவே கோப்பின் அளவு பெரிதாக முக்கியமல்ல.

## .pln, .pla, .tpl மற்றும் .bpn திட்டக் கோப்புகள்

இன்னும் படிக்கப்படவில்லை: நீங்கள் ஒன்றைத் திறக்கும்போது BimCraft அதைக் கூறும். மாதிரிக்கு IFC ஐயும் வரைபடங்களுக்கு DWG ஐயும் ஏற்றுமதி செய்யவும்; பார்க்க: [.pln மற்றும் .pla திட்டக் கோப்புகளைத் திற](topic:pln-project-files).

## DWG மற்றும் DXF

| படிப்பது | விவரங்கள் |
|---|---|
| இடங்கள் | மாதிரி வெளி மற்றும் ஒவ்வொரு தாளும் (அமைப்பு), தாவல் வரிசையில் |
| காட்சிச் சாளரங்கள் | ஒவ்வொரு தாளின் காட்சிச் சாளரங்களும், அவற்றின் அளவுகோல், சுழற்சி மற்றும் உறைந்த அடுக்குகளுடன் |
| அடுக்குகள் | பெயர், நிறம், இயக்க/அணை, உறைந்த நிலை, வரைதல் குறி மற்றும் கோட்டுத் தடிமன் |
| பொருட்கள் | கோடுகள், பலகோடுகள், வில்கள், வட்டங்கள், நீள்வட்டங்கள், ஸ்ப்லைன்கள், ஹேட்ச்கள் மற்றும் திடப்பொருட்கள், உரை மற்றும் பலவரி உரை, தொகுதிகளும் பண்புக்கூறுகளும், பரிமாணங்கள், வழிகாட்டிக் கோடுகள் மற்றும் பல வழிகாட்டிக் கோடுகள், அட்டவணைகள், புள்ளிகள், படங்கள் |
| இணைக்கப்பட்ட வரைபடங்கள் | அவை செருகப்பட்ட இடத்தில் வரையப்படும், அவற்றின் கோப்புகள் கண்டறியப்பட்டால் |
| படங்கள் | படக் கோப்புகளிலிருந்து வரையப்படும், கண்டறியப்பட்டால் (PNG, JPEG, GIF, BMP, WebP; TIFF அல்ல) |
| உபகரணக் குறிகள் | உணவக உருப்படிக் குறிகள் (`KCL-ITEM` பண்புக்கூறுகள்), உபகரண அட்டவணைக்காக |

மற்றவை **இன்னும் வரையப்படவில்லை** இல் எண்ணப்படும், ஒருபோதும் யூகிக்கப்படுவதில்லை. சோதிக்கப்பட்ட DWG வடிவங்கள் AutoCAD 2000 முதல் 2018 வரை (R13 மற்றும் R14 கோப்புகளும் ஏற்கப்படும், ஆனால் சோதனைத் தொகுப்பில் எதுவும் இல்லை; பழைய DWG-கள் திறக்காது); {{ui:Drawing}} பலகம் வடிவக் குறியீட்டைக் காட்டும் (AC1032 போன்றது). எல்லாப் பதிப்புகளின் DXF கோப்புகளும் திறக்கும், R12 உட்பட. இரண்டும் BimCraft-இன் சொந்தப் படிப்பிகளால், இந்தத் தாவலில் படிக்கப்படுகின்றன. DWG அல்லது DXF க்குள் எதுவும் மீண்டும் சேமிக்கப்படுவதில்லை.

## ஒரு கோப்புறையில்

| வகை | நீட்டிப்புகள் | அறிக்கையில் |
|---|---|---|
| மாதிரிகள் | `.rvt` `.rfa` `.rte` `.rft` | எண்ணிடப்பட்ட காப்பு நகல்களுடன் தொகுக்கப்பட்டவை, ஆரோக்கியம் சரிபார்க்கப்பட்டவை, அட்டை படிக்கப்பட்டது, இணைப்புகள் சரிபார்க்கப்பட்டவை |
| IFC | `.ifc` | பட்டியலிடப்பட்டது; 3D இல் திறக்கும் |
| CAD | `.dwg` `.dxf` `.dgn` | அவற்றை இணைக்கும் மாதிரிகளுடன் பட்டியலிடப்பட்டவை; DWG மற்றும் DXF 2D இல் திறக்கும், DGN திறக்காது |
| மீதமானவை | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | **ஒதுக்கிவை** இன் கீழ் பட்டியலிடப்பட்டவை |
| பராமரிப்புக் கோப்புறைகள் | `*_backup`, `*_log`, `Revit_temp`, மறைக்கப்பட்ட கோப்புறைகள் | **ஒதுக்கிவை** இன் கீழ் பட்டியலிடப்பட்டவை, படிக்கப்படாதவை |
