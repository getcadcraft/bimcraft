## 実行すること

壁ツールのレシピで壁を作成・変更します。どれも、角を指定して壁を描くのと同じように終わります。角は自動的に接続され、接続は保存され、変更全体が **変更** の1つの操作となり、{{ui:元に戻す}} で取り消せます。壁は同一性を保ちます。分割、オフセット、ストレッチした壁も同じ壁のままで、ドア、窓、寸法も残ります。

## 長方形、多角形、円弧を描く

{{ui:作図}} をオンにして、作図グループの {{ui:形状}} を開きます（または壁の行の **形状** 一覧から形状を選びます）。壁の行には、壁タイプ、図面の参照、外側の面、上端が表示されます。これは {{ui:壁}} ツールと同じです。その後、クリックするか点を入力します（x,y ・ @dx,dy ・ @長さ<角度 ・ ポインターの方向への長さ）。

- **長方形**: 対角の2つの角。4つの壁、4つの角の接続、1操作です。
- **回転した長方形**: 最初の辺の始点と終点（これで向きと長さが決まる）、その後3回目のクリックで他方の辺を決めます。
- **多角形**: 中心、その後角（**内接**）または辺の中点（**外接**）。先に **辺の数**（3〜64）を設定します。
- **円弧（中心）**: 中心、始点（これで半径が決まる）、終点。**回り方向**: 短い方向、反時計回り、または時計回り。円の 3/4 にわたる円弧は、2つの壁として描かれます。
- **接線円弧**: 壁の端をクリックし、その後円弧の終わる位置をクリックします。円弧は、壁の端から壁自身の向きに出ます。

閉じた形状は、外側が外に向きます。**外側の面** または **内側の面** に描く場合は、クリックした面が動かない面になります。

## 既存の線に沿って壁を作る

- **線を指定**: 線をクリックすると、その上に壁ができます。{{key:Tab}} を押す（またはクリック中に {{key:Shift}} を押したままにする）と、端と端でつながった線全体を選びます。対象の線は、このビューの製図線、トレースの参照、通り芯です。
- **輪郭をトレース**: それらの線、または壁で囲まれた領域の内側をクリックします。壁は、クリックした位置を囲む最小の領域に沿って作られます。

## 描く前に設定: オフセットと結合

壁の行には、{{ui:壁}} ツールと形状で使う項目がさらに2つあります。

- **オフセット**: クリックした線からこの距離だけ離して壁を描きます。描く方向に見て、左側は +、右側は −。
- **結合**: オフにすると、接続されていない壁を描きます。その端には **結合を禁止** が設定され、どこへ移動しても自由なままになります（[壁の変更](topic:change-a-wall-or-door) を参照）。

## 分割、部分の削除、再結合

編集グループの {{ui:壁}} を開きます。

- **分割**: 切断する位置で壁をクリックするか、始点からの距離を入力します。壁と交差する壁の近くでは、切断位置は交差する点に吸着します。2つの部分は同じタイプで、端と端で接続されたままです。**隙間** は、切断位置を中心に、その長さの空間を残します。**自由端** は、代わりに切断した端に **結合を禁止** を設定します（設定 › BimCraft › 壁 › **壁を分割するとき** で、初期状態でどちらにチェックが付くかを決められます）。ドアまたは窓は、それが配置されている部分と一緒に移動します。その中を切断することはできません。
- **区間を削除**: 区間の始点と終点をクリックします。その区間にあるドアも一緒に削除されます。
- **結合し直す**: 1つの壁の2つの部分（一直線上にあり、同じタイプ）をクリックします。それらは再び1つの壁になり、最初にクリックした方の壁として残り、両方のドアを持ちます。

## 結合スタイル、結合の禁止、レイヤー優先度

編集グループの {{ui:壁}} を開きます。

- **結合スタイル**: 直線の壁2本が終わる角をクリックします。クリックごとに次のスタイルに切り替わります。**留め**（両端を、内側の角から外側の角へ向かう線で切る。すべての角の初期値）、**突き合わせ**（1つの壁が、もう一方の壁の外側の面まで貫通し、その側面で止まる）、**直角に切り揃え**（突き合わせと同じですが、貫通する壁の端が直角に切られる。直角では突き合わせと同じに見えます）。**次**、または {{key:Tab}} で、貫通する壁を入れ替えます。バーの **スタイル** 一覧には、最後にクリックした角のスタイルが表示されます。同じ2つの選択肢は、1つの壁の **プロパティ** にもあります: **始点 / 終点の結合スタイル** と **貫通する壁**。それぞれの変更は **変更** の1操作です。平面図、3Dの本体、部屋、数量は、それに追従します。
- T字では、辺が接する方の壁が常に貫通します。2つの壁が交差する場合、クリック（または **プロパティ** の **交差部で連続**）で、どちらの壁を連続させるかを決めます。それによって、交差部を通るレイヤーがどちらの壁のものになるかが決まります。
- スタイルは結合に属します。壁が動いても残り、結合がなくなったときだけ消えます（壁が削除された場合、その端で分割された場合、または端に **結合を禁止** が設定された場合）。曲線の壁との角、または3つ以上の壁が集まる場所では、留めのままです。約30度より鋭い角、または約150度より平らな角も、留めに戻ります。
- **結合を禁止**: 壁の端の近くをクリックします。その端は解放され、壁がどこへ移動しても何も接続されません。もう一度クリックするまで続きます。ツールがオンの間、自由端はバツ印で表示されます。同じスイッチは、**プロパティ** の **始点で結合 / 終点で結合** です。
- **レイヤー優先度**: レイヤーを持つ壁が交わる場合、強いレイヤーが弱いレイヤーを切ります。そのため芯は芯につながり、仕上げは強いレイヤーで止まります。各レイヤーには 0 から 999 までの優先度があり、初期値はレイヤーの機能から決まります（構造 800、下地 600、断熱 400、防水層 300、仕上げ 200、空気層 100）。{{ui:レイヤー優先度}} は壁の構成を開き、**優先度** の列でレイヤーごとの数値を設定します。優先度が同じレイヤーは互いに止まり、線は異なる材料の間にのみ描かれます。これは中または細の詳細度の平面図で、角、T字の接合、直線の壁2本の交差部に表示されます。設定 › BimCraft › 壁 › **壁が接する箇所のレイヤーを整理** をオフにすると無効になります。これは壁の内部に描かれる内容だけを変えます。壁の輪郭と数量は、結合スタイルによるままです。

## 多くの壁のタイプを入れ替える

スケッチ平面図から実施図面に移るのは、大部分がタイプの変更です。汎用の壁が具体的な構成になります。何も描き直す必要はありません。

1. 壁を選択します（1つ、または {{key:Ctrl}} や {{key:Shift}} で複数）。
2. **プロパティ** の 壁タイプ の下で **タイプを入れ替え…** を押します（または編集グループの {{ui:壁}} を開き、{{ui:タイプを入れ替え}} を選びます。同じ一覧が開きます）。一覧は **プロパティ** の中、選択した壁のブロックの中に開きます。ダイアログではなく、何も覆いません。一覧が開いている間も、平面図、3Dビュー、選択は動作し、選んだ壁に従います。
3. 一覧には、すべての壁タイプが厚さと LOD タグとともに表示されます（例: "Wall 230 generic, LOD 200" と "230 clay brick, plastered both sides, LOD 300"）。選択した壁が現在持つタイプには印が付きます。**検索** に入力して絞り込めます。名前、厚さ、または `lod 300` と入力します。
4. タイプをクリックします。選択したすべての壁が1操作で変わるため、1回の {{ui:元に戻す}} で入れ替え全体を取り消せます。小さな × で一覧を閉じます。

各壁は位置線を保持します。中心線の壁は両側に広がります。位置線が面の壁は、その面を保ったまま反対側に広がり、接続された壁は角で追従します。入れ替えた壁に固定された壁も一緒に追従します。ドアと窓は壁の中に留まり、新しい厚さに合わせて切り直されます。

入れ替え後、一覧には **移動内容** が表示されます。変わった壁の数と変更先、入れ替え前後の厚さと LOD、位置線を保つために横にずれた壁、追従した接続壁、再度配置されたドアと窓、面積が変わった各部屋（前後の面積付き）です。ステータスバーには同じ内容が1行で表示されます。レポートは情報を示すだけで、入れ替えを止めることはありません。**プロパティ › 壁タイプ** でタイプを選んだ場合も、同じ入れ替えと同じレポートになります。

入れ替えを止める場合は2つだけあり、その場合は何も変更されません。1つ目は、壁に収まらなくなるドアや窓です（角に追従して壁が短くなる場合。先にドアを狭くするか、角から離してください）。2つ目は、入れ替えによって壊れてしまう固定です（中心線で通り芯に固定されているが、位置線が面である壁。固定を解除するか、位置線を中心線に戻してください）。

BimCraft に接続したアシスタントも、同じ入れ替えを行えます（ツール `wall_types_list` と `walls_swap_type`）。同じレポートが返されます。

壁タイプの LOD タグは、壁の構成エディターで設定します。[壁の構成](topic:wall-assemblies) を参照してください。

## オフセットとボックスストレッチ

- **オフセット**: 壁をクリックし、移動させる側をクリックするか、距離を入力します。壁は自身に対して直角に動き、接続された壁は伸びます。平行なコピーを作るには **コピー** にチェックを付けます（元の壁とは接続されません）。
- **ボックスでストレッチ**: 箱の2つの角をクリックし、その後移動元の点と移動先の点をクリックします。箱の内側にあるすべての壁の端が移動します。完全に内側にある壁は移動し、それに突き当たる壁も一緒に移動します。箱を横切る壁は伸縮します。

## 寸法の編集とロック

参照寸法（注釈 › {{ui:参照寸法}}）を選び、**プロパティ** に値を入力します。2つ目の参照の壁が自身に対して直角に動き、最初の参照は保たれ、接続された壁が追従します。**この寸法をロック** にチェックを付けると値を保持できます。後でどちらかの壁が動くと、もう一方が追従します。ロックされた値は、チェックを外すまで直接入力で変更できません。

## 整列とロック

**整列してロック**: 壁の面（または、壁の中央付近の中心線）、または通り芯をクリックし、その後その線に合わせる壁の面をクリックします。壁はその線の上へ直角に移動します。整列を維持するには、まず **ロック** にチェックを付けます。平面図に南京錠が表示され、一方の壁が動くと、もう一方が追従します。壁の **プロパティ** には、その **ロック** が一覧で表示され、それぞれに **ロック解除** があります。

## 壁を通り芯にロックする

通り芯に沿って走る壁、または端が通り芯の上にある壁を選び、**プロパティ** › **通り芯にロック** で通り芯を選びます。その後 {{ui:通り芯}} ツールで通り芯を指定し、{{ui:移動量}} に距離を入力します。線は自身に対して直角に動き、その線にロックされた壁は、接続された壁と一緒に1つの操作で追従します。通り芯にロックされた壁は、それ自体では通り芯から離れられません（通り芯を動かすか、壁のロックを解除してください）。ロックされた壁が直角のままいられなくなるように通り芯が回転される場合は、拒否されます。通り芯の名前を変えてもロックは残りますが、削除するとロックも消えます。

## 長さ: どちら側を保つか、何を計測するか

- **伸ばす起点**（1つの壁の **プロパティ**）: **始点を保つ**（終点が動く）、**終点を保つ**（始点が動く）、または **中心を保つ**（両端がそれぞれ半分動く）。長さを入力している間、平面図は保持される点を示します。動く端で接続された壁は、自身に対して直角に動き、角度を保ちます。
- **計測基準**（平面図の寸法の横、**プロパティ**、設定 › BimCraft › 壁）: 中心線、内側の面、または外側の面。長さの欄と平面図の壁の寸法は同じものを読むので、一致します。初期値は中心線です。
- 結合を解いて壁を移動させる（結合は外れ、壁は同一性を保つ）には、中央のグリップをドラッグしながら {{key:Alt}} を押します。

## 知っておくと良いこと

- これらの操作は、壁ツールの仕様書（4〜9ページ）に基づいています。結合スタイルとレイヤー優先度は直線の壁のために作られています。レイヤー優先度は平面図にのみ表示されます（断面図、立面図、3Dでは壁は1つの本体なので表示されません）。また、3つ以上の壁の節点には表示されず、膜は引き継がれません。
- 結合のスタイルは、IFC ファイル内の結合の記録（`IfcRelConnectsPathElements` の名前。例: `CadCraft join L butt 1`）に保存されます。そのため、他のプログラムでも結合が読み取られ、古いファイルは留めで開きます。
- 固定と結合は IFC ファイルに保存されます（固定はプロジェクトの `CadCraft_WallHolds`、結合は `IfcRelConnectsPathElements`）。そのため、ファイルを開き直しても残ります。
- 曲線の壁は、分割、再結合、部分の削除ができます。オフセットや固定はできません。
