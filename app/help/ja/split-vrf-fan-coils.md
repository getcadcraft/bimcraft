## 作業内容

分割型、マルチスプリット型、またはVRFシステムのユニットと、ファンコイルをモデルに配置し、冷媒配管セットで結びます。冷媒配管セットは、ユニットのポートに固定されたACR銅管の液管とガス管です。ユニットは[ポートを持つMEP機器](topic:mep-equipment)と同じように扱えます。同じバー、プロパティ、ポート、[接続](topic:mep-connections)を使います。

:::note
これは製図と調整のための補助機能です。ユニットは、入力した値で寸法が決まる汎用の形状で、特定メーカーの製品ではありません。配管サイズは、R410AとR32の機器の**代表的な参考値**の表から求めたもので、どのメーカーの値でもありません。実際のサイズは、各メーカーの施工マニュアルで決まります。配管が長い場合や高低差が大きい場合は、サイズが変わります。お使いのユニットに合わせて、表を変更するか、サイズを直接入力してください。
:::

## ユニットを配置する

1. {{ui:作図}}をオンにし、{{ui:ビルド}}を開いて{{ui:機器}}を選択します。
2. 種類を選び、値を設定します。

| 種類 | 設定する項目 | ポート |
|---|---|---|
| 分割型室内機、壁掛け形 | 能力、液管とガス管、長さ、奥行き、高さ、ドレン口のサイズ | 冷媒の液管とガス管、ドレン排水（壁に近い右端） |
| 分割型室内機、カセット形 | 能力、液管とガス管、パネル、本体、高さ、ドレン口のサイズ | 冷媒の液管とガス管、ドレン排水（片側の上寄り） |
| 分割型室内機、ダクト形 | 能力、液管とガス管、長さ、幅、高さ、給気と還気の開口、ドレン口のサイズ | 給気ダクト出口、還気ダクト入口、冷媒の液管とガス管、ドレン排水 |
| 分割型室外機 | 能力、液管とガス管、幅、奥行き、高さ | 冷媒の液管とガス管（右側） |
| VRF室外機 | 能力、液管とガス管、幅、奥行き、高さ | 冷媒の液管とガス管（前面の低い位置） |
| Refnetジョイント | 液管またはガス管、各分岐の負荷、各端の配管 | 入口、分岐A、分岐B |
| ファンコイルユニット | 2管式または4管式、長さ、幅、高さ、給気と還気の開口、コイル配管と系統、暖房配管、ドレン口のサイズ | 給気ダクト出口、還気ダクト入口、コイルの入口と出口、暖房の入口と出口（4管式）、ドレン排水 |

3. **取付高さ**を設定します。レベルより上にあるユニットの基部の高さです。壁掛け形の基部は下面です（多くは2100 mm）。カセット形は天井面です。Refnetは配管の中心線の高さです。
4. 配置する場所をクリックします（{{key:R}}で90°回転します）。

**能力**は、ユニットの公称冷房能力（kW）です。その横にBtu/hも表示されます。**液管**と**ガス管**を「表から」のままにすると、ユニットの接続は、その能力に対応する表のサイズを使います。ユニット固有のサイズを使うには、配管サイズを選択します。Refnetの入口は両方の分岐を合わせた能力でサイズが決まり、各分岐は自身の負荷でサイズが決まります。

冷媒ポートは双方向に機能します（ヒートポンプはどちらの方向にも動作します）。ドレン排水は、他の排水と同じく配管サイズとして扱います。

## 冷媒配管セットを描く

1. 2つの要素を選択します（2つ目は{{key:Shift}}+クリック）。室外機と室内機（単一分割型）、または室外機とRefnet、Refnetと室内機、またはRefnet同士（VRF）です。
2. {{ui:ビルド}}を開き、{{ui:冷媒配管セット}}を選択します。

BimCraftは、接続先のポートから、液管とガス管の配管を、各ポートから外へ、共通の高さまで描きます。配管はACR銅管です（1-5/8 in以下は焼なましコイル管、それより大きい場合は引き抜き管）。描画全体は、{{ui:元に戻す}}の1ステップになります。Refnetは、室外機側から入口へ、そして室内機方向の分岐から出る、自身の配管だけを接続します。各配管は、下流側の端（室内機、またはRefnetの入口）のサイズになります。もう一方の端のポートが別のサイズの場合、{{ui:接続をチェック}}に表示されます。そこが径違い継手を設置する箇所です。室内機同士を接続するには、その間にRefnetが必要です。

配管は、後から他の配管と同じように移動できます。その端は、ポートに残ったままです。階をまたぐ配管は{{ui:配管}}で描きます。冷媒ポートから開始した配管は、その系統、ACR銅管、そのサイズを引き継ぎます。

## 冷媒配管セットの表を変更する

{{ui:ビルド}}を開き、{{ui:冷媒配管セットのサイズ}}を選択します。各行は、次のことを示します。この能力（kW）まで、この液管、そしてこのガス管です。

| 上限 | 液管 | ガス管 |
|---|---|---|
| 2.8 kW | Ø6.35 (1/4") | Ø9.52 (3/8") |
| 5.6 kW | Ø6.35 (1/4") | Ø12.7 (1/2") |
| 16 kW | Ø9.52 (3/8") | Ø15.88 (5/8") |
| 22.4 kW | Ø9.52 (3/8") | Ø19.05 (3/4") |
| 33 kW | Ø9.52 (3/8") | Ø22.22 (7/8") |
| 47 kW | Ø12.7 (1/2") | Ø28.58 (1-1/8") |
| 71 kW | Ø15.88 (5/8") | Ø28.58 (1-1/8") |
| 104 kW | Ø19.05 (3/4") | Ø34.92 (1-3/8") |
| 180 kW | Ø19.05 (3/4") | Ø41.28 (1-5/8") |

これらは開始点となる代表値です。行を変更、追加、削除し、{{ui:保存}}を選択してください。表はモデルに保存されるため、そのファイルで作業する全員が同じ表を使います。{{ui:元に戻す}}で戻すこともできます。{{ui:典型値を使用}}で、開始時の表に戻ります。既に配置された要素は、変更するまで現在のポートを維持します。

## IFCファイル

分割型とVRFの室内機と室外機は、タイプSPLITSYSTEMのIfcUnitaryEquipmentです。オブジェクトタイプで、どの機器かを示します（"Split indoor unit, wall-mounted"、"Split indoor unit, ceiling cassette"、"Split indoor unit, ducted"、"Split outdoor unit"、"VRF outdoor unit"）。ファンコイルは、タイプAIRHANDLERのIfcUnitaryEquipmentで、オブジェクトタイプは"Fan coil unit"です。IFC4にはファンコイルのタイプがないためです。1つの部屋のファン、コイル、フィルターを表すのがAIRHANDLERです。Refnetジョイントは、タイプJUNCTION（"Refnet joint"）のIfcPipeFittingです。IFC2X3ファイルでは、対応するタイプのIfcEnergyConversionDeviceとIfcFlowFittingになります。

冷媒のポートと配管は、REFRIGERATION系統に入ります（液管用とガス管用の2つ）。ドレンはDRAINAGE系統に入ります。ACR配管は、外径で名前が付けられます。冷媒配管セットの表は、プロジェクトのプロパティセットCadCraft_HvacLineSetsです。
