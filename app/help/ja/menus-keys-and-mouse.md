BimCraft のコマンドは、どの方法で呼び出しても同じように動作します。**メニュースタイル**は、コマンドを画面上のどこに置くか、どの名前で表示するか、どのキーで実行するかを決めるだけなので、いつもの操作の癖をそのまま使い続けられます。{{ui:設定}} ({{key:Mod+,}}) › {{ui:BimCraft}} › {{ui:メニュー、キー、マウス}} で選択します。変更はすぐに反映され、このブラウザーに記憶されます。

## 5種類のスタイル

| スタイル | 内容 |
|---|---|
| {{ui:CadCraft}} | BimCraft 独自のツールバーとキー（{{key:W}} 壁、{{key:D}} ドア、{{key:N}} 窓、{{key:X}} 断面、{{key:F}} 全体表示）。最初に表示されるスタイルです。 |
| {{ui:ホームデザイン}} | メニューバー（ファイル、編集、ビルド、ライブラリ、3D、CAD、ツール、表示）と、住宅設計プログラムのように建築ツールを並べた行を表示します。単キーは同じで、{{key:Mod+L}} でライブラリ、{{key:F9}} で 3D ビュー、{{key:F10}} で平面、{{key:F11}} で両方を表示します。 |
| {{ui:BIMリボン}} | 大きなボタンのタブ（建築、挿入、注釈、修正、表示、出力）と、ファイルメニュー、右側のクイックボタン。2文字キーは、{{key:W}} の後に {{key:A}} で壁、{{key:D}} {{key:R}} でドア、{{key:W}} {{key:N}} で窓、{{key:S}} {{key:C}} で断面、{{key:Z}} {{key:F}} で全体表示です。中ボタンでパンし、{{key:Shift}} と中ボタンでオービットします。 |
| {{ui:製図クラシック}} | 小さなリボンとコマンドラインを表示します。コマンドを入力する人向けです。WALL、DOOR、WINDOW、ROOF、U (元に戻す)、ZOOM、SECTION、PLOT、INSERT、HELP。どこでも入力を始めると文字はコマンドラインに入ります。{{key:Enter}} で実行し、何も入力せずに {{key:Enter}} を押すと直前のコマンドを繰り返します。{{key:Esc}} で入力を消去します。 |
| {{ui:ビューアー}} | モデルを描くためではなく、開いて確認するためのスタイルです。{{ui:ファイル}}、{{ui:表示}}、{{ui:表示}}、{{ui:チェック対象}}、{{ui:編集}}の各メニューと、表示用のツールの行（全体表示、上面、正面、側面、断面、計測、非表示、分離表示、透過表示、すべて表示、ウォークスルー）があります。建築ツールは末尾の{{ui:モデル}}メニューにあります。BimCraft 独自のスタイルと同じキーを使います。 |

メニューとリボンは、モデルを開くか新しい建物を作成すると表示されます。それより前は、左側のパネルでファイルを開いたり、建物を作成したりします。

:::tip
選んだスタイルに含まれない BimCraft 独自のキーは何もしません。その場合、ステータス行にそのコマンドの移動先が表示されます（「BIMリボンでは、断面はSCです」）。{{key:Delete}}、{{key:Esc}}、{{key:Enter}}、{{key:Tab}}、{{key:Space}} と矢印キーは、常に同じ動作をします。実行中のツールは独自のキーを保持します。配置中は {{key:R}} と {{key:Tab}}、歩行中は {{key:W}} {{key:A}} {{key:S}} {{key:D}}、ドアと窓のツールでは {{key:H}}、長さを入力中は数字キーです。
:::

## 自分好みに設定する

1. 希望に最も近いスタイルを選び、{{ui:カスタマイズ…}}をクリックします。
2. {{ui:キーとメニュー}}で、コマンドを探します（検索ボックスが使えます）。{{ui:キーを追加}}をクリックしてキーを押します。2文字キーの場合は、続けて2つのキーを押します。キーを外すには、そのキーをクリックします。
3. メニューバーまたはリボンを使う場合、{{ui:配置場所}}で、コマンドを別のメニューまたはパネル、あるいは{{ui:キーのみ}}に移動できます。
4. {{ui:マウス}}で、ホイールの動作、平面をパンするボタン、3D ビューで各ボタンが行う動作を設定します。
5. 名前を付けて{{ui:保存}}をクリックします。

組み込みのスタイルを保存すると、自分専用のコピーが作成されます（「マイホームデザイン」）。組み込みのスタイルは変更されません。1つのキーを2つのコマンドに割り当てた場合や、2文字キーを入力する前に実行されてしまうキーは、赤で表示され、保存する前に修正が必要です。

## マウス

- **マウスホイール**: {{ui:上に回すとズームイン}}（初期設定）または{{ui:上に回すとズームアウト}}に設定できます。速さも設定できます。トラックパッドのピンチ操作は、指の動きどおりにズームします。
- **平面と図面をパンする**: 左、中、右のいずれかのボタンで行えます。{{key:Space}} を押しながらドラッグしてもパンできます。左ドラッグは、クリックで選択や作図をしない場所でのみパンします。
- **3D ビューでのドラッグ**: {{ui:ビューごとの既定}}を選ぶと、BimCraft の既定のボタン（左でオービット、右でパン）を使います。あるいは、各ボタンをオービット、パン、ズーム、または何もしないに設定できます。{{key:Shift}} を押しながらボタンを使うと、オービットとパンが入れ替わります。ドラッグせずにクリックした場合は、選択します。

## 別の場所でも使う

{{ui:エクスポート}}は、使用中のスタイルを小さな `.ccinput.json` ファイルとして保存します。{{ui:インポート…}}は、別のコンピューターや同僚から受け取ったファイルを追加します。インポートしたファイルで指定できるのは BimCraft 独自のコマンドだけです。このバージョンにないコマンドや、ここでは動作しないキーなど、それ以外の項目は除外され、その件数がステータス行に表示されます。{{ui:このスタイルを削除}}は、自分で作成したスタイルを削除します。

:::note
これらの設定はこのブラウザーに保存されます。スタイルカードの下にある{{ui:すべてのアプリでこのスタイルを使う}}を選ぶと、すべてのアプリが対応するスタイルで開きます（それぞれ独自のツールバー、メニューバー、リボン、または製図クラシック）。{{ui:ビューアー}}は BimCraft だけのスタイルで、他のアプリには対応するものがありません。対応するスタイルがないアプリは、独自のスタイルを維持します。あるアプリで別のスタイルを選ぶと、そのアプリだけが変更されます。
:::
