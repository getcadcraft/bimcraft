## IFC 要素

{{ui:Properties}} パネルの上部には、「Ifc」の接頭辞を除いた要素の種類(例: "Door"、"WallStandardCase"、"FurnishingElement")と、その名前(名前がない場合は「名前なし」)が表示されます。

| 欄 | 意味 | 編集可否 |
|---|---|---|
| 名前 | 要素の名前。多くの場合、エクスポーターによるファミリー名とタイプ名 | はい |
| タイプ | 要素のタイプの名前(タイプがある場合) | いいえ |
| オブジェクトタイプ | 一部のエクスポーターが入力する自由形式のタイプの説明 | はい |
| タグ | 要素のタグまたは符号。多くのエクスポーターでは、ここに要素 ID を書き込みます | はい |
| 説明 | 自由形式のテキスト | はい |
| GlobalId | 要素の永続的な 22 文字の IFC 識別子。同じ要素のどの書き出しでも同じです | いいえ |
| 行 | この IFC ファイル内での要素の行番号(`#1234`)。書き出しごとに変わります | いいえ |

続いて、名前順に並んだ**プロパティセット**が表示されます:

- 各セットは、その名前をクリックすると開閉します。最初の 3 つは開いています。
- 「(type)」が付いたセットは要素のタイプに属します: 「タイプのプロパティ: ここでの変更は、このタイプのすべての要素に適用されます。」
- 数量セット(長さ、面積、体積、個数、重量)は読み取り専用です。
- リストと列挙値は表示されますが、読み取り専用です。
- はい/いいえの値は **はい** または **いいえ** として表示されます。
- 数値は表示のため小数点以下 4 桁に丸められます。長さ(長さのプロパティや数量の長さ)は、ツールバーで選んだ {{ui:Units}} で、単位を添えて表示されます。新しい値は、その単位で、または別の単位記号(2.4 m、8'-0")で入力できます。BimCraft はファイル自身の数値を書き戻します。その他の数値は、ファイルが持つとおりに表示されます。
- 空の値は *空* と表示されます。編集された値は太字で、横に青いバーが付きます。

## 値をコピーする

{{ui:Properties}} のすべての値には、横に小さなコピーボタンがあります。クリックすると、その値が表示どおりにクリップボードに入ります。例えば GlobalId、シリアル番号、任意のプロパティセットの値です。コピーで編集が始まることはありません。

上部の {{ui:Copy all}} は、要素のすべての値をセットごとにテキストとしてコピーします。{{ui:Copy as CSV}} は、グループ、プロパティ、値の行としてコピーし、表計算ソフトに貼り付けられます。空の値も保持されるため、すべての欄に行があります。開いている別のモデルの要素でも同じように動作します。複数のモデルが開いている場合、CSV の先頭にはファイル名を示すモデル列が付きます。

## ファイルパネル (IFC)

| 欄 | 意味 |
|---|---|
| ファイル、サイズ | 開いたファイル |
| スキーマ | IFC のバージョン(IFC2X3 や IFC4 など) |
| プロジェクト | プロジェクトの名前と正式名 |
| フェーズ | エクスポーターが書き込んだ場合のプロジェクトのフェーズ |
| 書き出し元 | ファイルヘッダーに記載された書き出しプログラム |
| 作成者 | ファイルヘッダーの作成者 |
| 書き出し日時 | ファイルヘッダーの日付と時刻 |
| 要素 | 形状を持ち、描画された要素の数 |
| 三角形 | 形状が構成する三角形の数。モデルの重さの目安 |

## ファイルパネル (プロジェクトとファミリーファイル)

| 欄 | 意味 |
|---|---|
| 種類 | プロジェクト、プロジェクトテンプレート、ファミリー、またはファミリーテンプレート |
| 保存バージョン | ファイルを最後に保存したリリース |
| ビルド | そのリリースの正確なビルド |
| 読み取り | ファイルのサイズのうち、BimCraft が読み取った量 |

## 図面パネル (DWG と DXF)

| 欄 | 意味 |
|---|---|
| 形式 | 図面が保存されたリリース。AC1032 などの形式コード付き |
| 単位 | 図面の挿入単位(設定されている場合) |
| オブジェクト | 読み取られたオブジェクトの数 |
| レイヤー | レイヤーの数 |
| シート | シート(レイアウト)の数、または「なし」 |
| 外部参照 | 見つかって読み込まれた外部参照図面の数 |
| 機器 | シート上にあるタグ付き機器の数 |

## フォルダーパネル

| 欄 | 意味 |
|---|---|
| フォルダー、ファイル、サイズ | 開いたフォルダー、そこに含まれるファイル数、合計サイズ |
| モデル | プロジェクトとファミリーのファイル。各バックアップは 1 回ずつ数えられます |
| CAD 図面、IFC モデル | それぞれの数 |
| 問題 | 不完全または読み取れないモデルのコピーの数、または「なし」 |
