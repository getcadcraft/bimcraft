## 行うこと

案件で受け取ったプロジェクトフォルダー全体を開き、BimCraftに整理させます。どのモデルがあるか、どのコピーがバックアップか、何が何にリンクしているか、どのファイルが破損しているか、そして最も開きたいと思われるファイルはどれか、を判断させます。

各モデルカードに必要な数キロバイトだけが読み取られるため、ネットワークドライブや同期されたクラウドフォルダーでも問題ありません。

## 手順

:::chromium
1. 左側の{{ui:フォルダーを開く}}をクリックします（または空の画面の中央）。
2. 開いたウィンドウでプロジェクトフォルダーを選び、**選択**（システムによっては **アップロード** または **開く**）をクリックします。
3. ブラウザーに「このサイトにファイルの表示を許可しますか？」と尋ねられたら、**ファイルを表示** をクリックします。これはタブがフォルダーを読み取ることを許可するだけで、アップロードは行われません。
4. ステータス行が「フォルダーを一覧化中: … ファイル」、次に「Revitファイルを確認中: … / …」と数えるのを待ちます。
:::

:::firefox
1. 左側の{{ui:フォルダーを開く}}をクリックします（または空の画面の中央）。
2. 開いたウィンドウでプロジェクトフォルダーを選び、確認します。Firefoxは、ページがフォルダー内のファイルを読み取ってよいかの確認を求めることがあります。ファイルはお使いのコンピューターに残ります。
3. ステータス行に「フォルダーを読み込み中: … ファイル」、次に「Revitファイルを確認中: … / …」と表示されるまで待ちます。
:::

:::safari
1. 左側の{{ui:フォルダーを開く}}をクリックします（または空の画面の中央）。
2. 開いたウィンドウでプロジェクトフォルダーを選び、**アップロード** をクリックします。名前に反して、ファイルがMacの外に出ることはありません。ファイルはタブに渡されるだけです。
3. ステータス行に「フォルダーを読み込み中: … ファイル」、次に「Revitファイルを確認中: … / …」と表示されるまで待ちます。
:::

フォルダーを{{pick:mac=Finder|windows=エクスプローラー|linux=お使いのファイルマネージャー}}からページへドラッグすることもできます。ドラッグしたフォルダーは、どのブラウザーでも権限の確認なしに開きます。

## 表示される内容

フォルダーのレポートが中央に表示されます。

- フォルダー名、モデル、CAD図面、IFCモデル、ファイルの数、および合計サイズ。
- 不完全なファイルや、フォルダー内にないリンク先ファイルがある場合は、赤または黄色の注意。
- {{ui:ここから開始}}ボックス: BimCraftが開くよう提案するファイルと、その理由。
- **モデル**: モデルごとに1行で、そのバックアップがその下にグループ化されます。
- **リンクおよび参照ファイル**、**IFCモデル**、**CAD図面**、そして（フォルダーにある場合）**除外済み**。

左側の{{ui:フォルダー}}パネルが要約を示します。すべてのコピーが正常な場合、**問題点** には「なし」と表示されます。

## 「ここから開始」ボックスを使う

ボックスは1つのファイルを示し、その理由を述べます。例:

- 「このフォルダーで最も新しく保存された作業（Mar 3, 2025）。」
- 「*Consultant.rvt* は他のモデルにリンクされているため、編集するファイルではなく背景です。」
- 「*Tower.rvt* は最も適切に見えますが、破損しています。最後の正常なコピーは…の日付のものです。」
- 「これは中央モデルです。Revitで「Create New Local」を使って開き、ローカルコピーで作業してください。」

1. 理由を読みます。
2. そのファイルのカードを読むには{{ui:カードを開く}}をクリックするか、**モデル** でその行を見つけるには{{ui:一覧で表示}}をクリックします。
3. 頼る前に、プロジェクトを最後に扱った人に確認してください。ボックスにもそのように書かれています。これは名前、日付、リンクからの推測にすぎません。

## レポートからファイルを開く

1. モデルの名前をクリックすると、そのカードが開きます。カードは各リンクをフォルダーと照合します。
2. {{ui:戻る}}とカード上部のフォルダー名（または左側の{{ui:フォルダーに戻る}}）をクリックして戻ります。
3. **IFCモデル** の下にあるIFCファイルをクリックすると、3Dで開きます。
4. **CAD図面** の下にあるDWGまたはDXFをクリックすると、2Dで開きます。そのリンクされた図面や画像は、フォルダー内から自動的に見つけられます。

## 後でフォルダーを再度開く

:::chromium
{{ui:フォルダーを開く}}またはドラッグで開いたフォルダーは、左側の{{ui:最近使ったフォルダー}}に表示されます。{{ui:再開}}とフォルダー名をクリックすると、選び直さずに再び開けます。ブラウザーを再起動すると、ChromeまたはEdgeがもう一度尋ねます。「毎回許可」を選ぶと、今後は尋ねなくなります。この一覧はこのブラウザーにのみ保存され、どこにも送信されません。×をクリックすると、そのフォルダーを一覧から削除します。
:::

:::firefox safari
このブラウザーは、訪問ごとにフォルダーを記憶できません。{{ui:フォルダーを開く}}からフォルダーを選び直すか、ドラッグしてください。
:::

## よくある間違い

- **大きすぎるフォルダーを選ぶ。** 20,000を超えるファイルがある場合: 「このフォルダーには20,000を超えるファイルがあります。1つのプロジェクトなど、より小さいフォルダーを選んでください。」 ドライブ全体ではなく、プロジェクトフォルダーを選んでください。
- **複数のプロジェクトの親フォルダーを選ぶ。** {{ui:ここから開始}}ボックスは、プロジェクトをまたいで選んでしまいます。1つのプロジェクトを選んでください。
- **Revit独自のフォルダーが無視されているように見える。** `*_backup`、`*_log`、`Revit_temp` フォルダーは整理用のフォルダーであり、**除外済み** に一覧され、読み取られません。
- **カードからモデルが3Dで開くと期待する。** プロジェクトファイルはカードだけです。そのIFC書き出しファイルを開いてください。
- **スマートフォンとタブレット。** 多くのモバイルブラウザーはフォルダーを選べません。コンピューターを使ってください。
