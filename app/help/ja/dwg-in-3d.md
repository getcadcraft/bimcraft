## 作業内容

図面のモデル空間を3Dで表示します。線とポリラインは実際の高さに配置され、厚さのあるオブジェクトは壁として立ち上がり、3Dフェース、メッシュ、3Dブロックは周囲を回転できる面として表示されます。シートは2Dのままです。

## 手順

1. DWGまたはDXFを開きます。[DWGまたはDXFの図面を表示する](topic:view-dwg)を参照してください。**図面を開くとき**の設定が{{ui:モデル (2D)}}になっていない限り、3Dで開きます。({{ui:設定}} › {{ui:BimCraft}} の順)
2. 2D表示から、図面の上のバーで{{ui:3D}}をクリックするか、{{key:3}}を押します。
3. 初回は少し待ちます。ステータスバーに「図面を3Dで作成中…」と表示され、その後、表示される線と面の数が表示されます。
4. 軌道回転、パン、ズームを行います（下の表を参照）。
5. 2番目のバーでビューをクリックします: {{ui:等角}}、{{ui:上}}、{{ui:下}}、{{ui:前}}、{{ui:後}}、{{ui:左}}、または{{ui:右}}。
6. {{ui:パースペクティブ}}をクリックすると、パースペクティブ表示と平行表示を切り替えます。
7. {{ui:範囲}}をクリックするか{{key:F}}を押すと、図面全体を再び表示します。
8. {{ui:3D}}をもう一度クリックするか、{{key:3}}を押すか、{{ui:モデル}}またはシートのタブをクリックして、2D表示に戻ります。

## 表示される内容

- モデル空間を3Dで、Z軸が上、図面自体の色で表示します。面は辺よりわずかに明るく表示されます。
- {{ui:レイヤー}}でオフにしたレイヤーは、3D表示からも消えます。
- 右側には、線と面の数、図面のX、Y、Zの大きさ、**2Dビューのみ**、**未描画**が表示されます。

## 断面平面で切断する

3Dバーの{{ui:断面}}をクリックするか、{{key:X}}を押します。その下のバーはIFCモデルと同様に動作します（[断面平面でIFCモデルを切断する](topic:section-plane)を参照）。{{ui:上}}、{{ui:前}}、または{{ui:側面}}から切断し、オフセットをドラッグまたは入力します（ここでは図面自体の単位を使用します）。{{ui:反転}}で反対側を残します。断面平面で切り取られた部分は選択できません。2Dに戻ると切断は解除されます。

## オブジェクトのプロパティを確認する

3D表示でオブジェクトをクリックします。選択色に変わり、{{ui:プロパティ}}にファイルが保持する情報が表示されます: 種類、レイヤー、色、線種、ハンドル。その後、そのオブジェクト固有のデータ（線の始点・終点・長さ、円の中心と半径、3Dフェースの頂点、ブロック参照のブロック・挿入点・尺度・回転・属性値）が表示されます。

- ブロック参照は全体として選択されます。その中にネストされたブロックも含みます。
- 線から数ピクセル離れた位置をクリックすると、その線が選択されます。
- {{key:Mod}}を押しながらクリックすると、オブジェクトを追加選択、または選択から外せます。{{ui:プロパティ}}には種類ごとの数が表示されます。
- {{key:Esc}}を押すか、何もない場所をクリックすると、選択が解除されます。
- オフにしたレイヤーのオブジェクトは選択できません。

## 移動

:::mouse
| 操作 | 方法 |
|---|---|
| 軌道回転 | 中ボタンでドラッグ、または左ボタンでドラッグ |
| パン | 右ボタンでドラッグ、または{{key:Shift}}を押しながらドラッグ |
| ズーム | ホイールをスクロールします。ポインターの下の位置に向かってズームします |
| 全体を表示 | {{ui:範囲}}または{{key:F}} |
| 側面から見る | 右下隅のビューキューブの面、辺、または角をクリック |
:::

ビューキューブは、{{ui:設定}}で軸アイコンに切り替えたり、非表示にしたりできます。[BimCraftの設定](topic:settings)を参照してください。

:::mac mouse
トラックパッドでは、2本指でスワイプして軌道回転し、{{key:Shift}}を押しながらスワイプしてパンし、ピンチでズームします。
:::

:::touch
1本指でドラッグして軌道回転します。2本指でピンチしてズームし、2本指を同時に動かしてパンします。
:::

## 3Dで描画される内容

| 図面内 | 3D |
|---|---|
| 線、3Dポリライン | 実際の高さ |
| ポリライン、円、円弧、楕円 | 自身の平面内、標高に配置され、図面が傾いている場合は傾いて表示 |
| 線、ポリライン、円、円弧の厚さ | その高さの壁。円は上下が閉じられます |
| 3Dフェース、ポリフェイスメッシュ、ポリゴンメッシュ | 表示される辺を持つシェード付きの面 |
| ブロック | 3Dで配置、回転、拡大縮小。ネストされたブロックも含みます |
| ハッチング | その輪郭 |
| 通常の2D線 | 描かれた場所に平らに表示 |

## 2Dビューのみ

文字、マルチテキスト、ブロックの表示属性は、3Dでそれぞれの平面内と高さに描かれ、クリックで選択できます。幅のあるポリラインは、その幅を平らな帯として表示します。マルチ引出線、画像、ハッチングパターンは**2Dビューのみ**として数えられます。これらは{{ui:モデル}}タブまたはシートで確認してください。

## 未描画

ACISボディとして保存されたソリッドと面（3Dソリッド、ボディ、リージョン、サーフェス）およびサブディビジョンメッシュは、**未描画**の下に数とともに一覧表示されます。これらはスキップされ、推測で描かれることはありません。

## よくある間違い

- **すべてが平らに見える。** 図面は2Dです。線には高さがありません。{{ui:前}}をクリックして確認してください。平らな図面は線として表示されます。
- **ソリッドモデルが何も表示されない。** ソリッドモデラーで作成されたソリッドはACISボディであり、**未描画**に一覧表示されます。作成元のプログラムからIFCまたは3Dフェースとして書き出してください。
- **図面が中央の小さな塊になっている。** モデル空間の遠くにあるもの（例: 古い平面図のコピー）によって範囲が大きくなっています。見たい場所をホイールでズームしてください。
