## コピーの状態

すべてのコピー（メインファイルと番号付きバックアップの両方）には、ヘッダーのチェックが行われます。

| ラベル | 意味 |
|---|---|
| **完全** | ファイルのヘッダーとインデックスがファイル内に収まっています |
| **不完全** | ファイルが、自身のインデックスが示す長さより短くなっています。コピー、アップロード、同期の途中で切り捨てられたか、まだ「オンラインのみ」のクラウドファイルです |
| **読み取り不可** | ファイルが有効な複合ファイルではないか、読み取れませんでした |

**ステータス**列では、モデルに **完全** と表示されます。1つ以上のコピーが壊れていても、別のコピーが正常な場合は、黄色で「*n* 件の不完全」と表示されます。正常なコピーが1つもない場合は、赤色で **不完全** と表示されます。

## バックアップ

`Name.0001.rvt`、`Name.0002.rvt` などの名前のファイルは、`Name.rvt` の番号付きバックアップです。モデルごとにまとめられ、**すべての … コピー** に新しい順に表示されます。カードは、メインファイルが完全であればそこから読み込まれ、そうでなければ最新の完全なバックアップから読み込まれます（「最新の完全なコピー」）。

## 役割

モデル名の下に斜体で表示されます。

| 役割 | 意味 |
|---|---|
| *他のモデル*によるリンク: 背景 | フォルダー内の別のモデルがこのモデルにリンクしているため、コンサルタントのモデルなど、ほかの人の背景である可能性が高いです |
| スターターまたは無題のファイル | Blank、Template、Default、Untitled、Project1 などの名前です。開始用のテンプレート、またはきちんと名前を付けられなかったファイルです |
| 中心モデル | 共同作業用の中心モデルです。作業はここではなく、ローカルコピーで行われます |
| ファミリ（部品） | `.rfa` または `.rft` ファイルです。プロジェクトではなく、部品です |
| バックアップのみ | メインファイルがなく、番号付きのバックアップだけが残っています |

## 「ここから開始」の選び方

BimCraft は、熟練したユーザーが行うのと同じ判断を適用します:

1. 候補は、読み取り可能なプロジェクトファイル（`.rvt`、`.rte`）のうち、ほかのモデルからリンクされておらず、スターターではないものです。
2. 中心モデルとバックアップのみのモデルは、ほかに適切なものがない場合にのみ候補になります。
3. 候補のうち、最も最近保存されたものが選ばれます。

ボックスには選択理由が一覧され、一見適切に見えるファイルが破損している場合、ほかのモデルが背景である場合、選ばれたものが中心モデルである場合に警告します。これはあくまで推定です。プロジェクトに最後に関わった人に確認してください。

## リンクの状態

| ラベル | 意味 |
|---|---|
| **このフォルダー内** | 保存された相対パス、またはフォルダー内の保存された完全パスの末尾で見つかりました |
| **同名のファイルあり** | パスには見つかりませんでしたが、同じ名前のファイルがフォルダー内にあります。正しいファイルか確認してください |
| **ライブラリファイル** | キーノートまたはアセンブリコードの表です。各コンピューターのプログラムに付属しています |
| **このフォルダー内にない** | フォルダー内のどこにも見つかりません |

**モデル**の **検出されたリンク** 列には、フォルダー内にあると想定されるリンクのうち、いくつ見つかったかが表示されます（ライブラリファイルは数えません）。

## 除外されたファイル

| 項目 | 意味 |
|---|---|
| Revit の管理用フォルダー（読み取りません） | `*_backup`、`*_log`、`Revit_temp` フォルダー、および非表示フォルダーと `__MACOSX` |
| ロック、ログ、バックアップの残り | `.dwl`、`.dwl2`、`.bak`、`.err`、`.log`、`.tmp`、`.sv$`、`.ac$`、`.lck`、`.slog` ファイル |
| その他のファイル | それ以外のすべて（先頭の40件は名前が表示されます） |
