## 作業内容

IFCモデルのデータを修正します。要素の名前を変更し、タグを修正し、プロパティ値を変更します。その後、変更を加えた新しいIFCファイルを保存します。開いたファイルは変更されることはありません。

## 変更できる内容

| フィールド | 編集可能 |
|---|---|
| 名前、オブジェクトタイプ、タグ、説明 | はい |
| 単一のプロパティ値（テキスト、数値、はい/いいえ） | はい |
| タイププロパティ（"(type)"と表示されたセット） | はい。変更はその種類のすべての要素に適用されます |
| タイプ、GlobalId、行 | いいえ |
| 数量（長さ、面積、体積、個数） | いいえ |
| リスト、列挙、その他の複数パートの値 | いいえ |
| ジオメトリ、位置、要素の追加または削除 | いいえ |

## 手順

1. IFCモデルを開き、変更したい要素をクリックします。
2. {{ui:プロパティ}}パネルで、変更したい値をクリックします。テキストボックスに変わります。空の値は*空*と表示されます。
3. 新しい値を入力します。
4. {{key:Enter}}を押すか、別の場所をクリックして確定します。{{key:Esc}}を押すとキャンセルします。
5. 値を確認します。太字になり、横に青いバーが付きます。これは編集された値を示します。
6. 左側の{{ui:変更}}セクションを確認します。変更は「*要素*: *フィールド*、旧値から新値へ」として一覧表示されます。
7. 他の値や他の要素についても繰り返します。
8. {{ui:IFCとして保存}}をクリックします（保留中の変更数を表示します。例: 「IFCとして保存 (3)」）。または{{key:Mod+S}}を押します。
9. ダウンロードフォルダーで「*original name* (edited).ifc」を探します。

## 表示される内容

ステータスバーに「*name* (edited).ifc を *n* 件の変更とともに保存しました（… バイト）。元のファイルは変更されていません。」と表示されます。{{ui:変更}}一覧は空になり、次の作業に備えます。

## 値の種類

- **テキスト**: 入力したものはそのまま保持されます。名前、オブジェクトタイプ、タグ、説明を消去すると、値が削除されます。
- **数値**: ファイルの単位で、`2.4`や`1200`のような単純な数字を入力します。単位記号は使用しません。それ以外の場合は「数値を入力してください。」と表示されます。
- **整数**（個数、整数値）: 小数を入力すると「整数を入力してください。」と表示されます。
- **はい/いいえ**: 値は「はい」と「いいえ」のメニューになります。

各値はIFCの型を保持するため、数値は数値のまま保たれ、他のプログラムでも正しく読み取られます。

## 元に戻す

1. {{ui:変更}}セクションの{{ui:元に戻す}}をクリックするか、フィールドに入力していない状態で{{key:Mod+Z}}を押します。
2. さらに元に戻すには繰り返します。元に戻すたびに、最新の変更が削除されます。

保存の後は元に戻せません。保存すると一覧は最初からやり直しになります。保存されたファイルには、すべての変更が含まれています。

## 1つの要素だけが変わる理由

エクスポーターはデータを共有して容量を節約します。1つのプロパティセットを20個のドアが共有していたり、1つの値（「耐火性能: 60 min」）が90個のセットに記載されていたりすることがあります。BimCraftが単純に共有の値を変更すると、それを共有するすべての要素が変わってしまいます。

そこでBimCraftは書き込む前にコピーします。

- 編集するプロパティセットが他の要素と共有されている場合、その要素には独自のコピーが割り当てられ、コピーのみが変更されます。
- 値が他のセットと共有されている場合、そのセットには値の独自のコピーが割り当てられます。

隣接する要素は以前のデータを保持します。これは*コピーオンライト*と呼ばれます。ファイルに小さなエントリがいくつか追加されますが、すべてのIFCプログラムで通常どおり読み取れます。

**タイププロパティは意図的な例外です。** "(type)"と表示されたセットは要素のタイプに属し、IFCではその種類のすべての要素がそこから読み取ります。それを変更するとタイプが変わり、その種類のすべての要素が新しい値を表示します。{{ui:変更}}一覧では、このような編集に"(type)"が付きます。[タイプのプロパティを同じ種類のすべての要素で変更する](topic:type-vs-instance)を参照してください。

## 変更前の警告

- 保存されていない変更がある状態で別のファイルを開くと、「*file* に *n* 件の保存されていない変更があります。破棄しますか?」と確認されます。キャンセルをクリックして作業を続け、保存してください。
- 保存されていない変更があるタブを閉じるか再読み込みすると、ブラウザーがページを離れるかどうかを確認します。

## よくある間違い

- **単位を入力する。** `2400 mm`は拒否されます。`2400`と入力してください。
- **1つの要素のつもりでタイププロパティを変更する。** 入力前に"(type)"の注記を確認してください。1つの要素だけを変えたい場合は、インスタンスのプロパティ、またはそのタグや名前を変更してください。
- **元のファイルが変わると思う。** 保存すると常に新しいファイルがダウンロードされます。元のファイルを置き換えたい場合は手動で行い、コピーを保管してください。
- **変更がないのに{{key:Mod+S}}を押す。** BimCraftは保存すべき内容がある場合にのみ保存します。それ以外の場合、ブラウザーの「ページを保存」が開くことがあります。閉じてください。
- **2回保存して、2つの小さなファイルを期待する。** 保存のたびに、モデルを開いてからのすべての編集が含まれます。
- **編集内容がプロジェクトファイルに戻ると思う。** BimCraftはIFCのみを書き込みます。編集したIFCを、通常のIFCの取り込みと同じように作成ソフトウェアに取り込んでください。
