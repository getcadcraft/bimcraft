## IFC

| 読み取り | 詳細 |
|---|---|
| 形状 | 形状を持つすべての要素。ファイルの指定どおりの色で描かれます。部屋とスペースは透過表示され、最初は非表示です |
| 階 | 高さの順の建物の階と、各階にある要素。どの階にもない要素は "階に属さない" にまとめられます |
| 要素数 | 種類ごとの要素数 (壁、ドア、スラブなど)。**要素** に表示されます |
| プロジェクト情報 | プロジェクト名、正式名称、フェーズ。スキーマ、ファイルヘッダーの出力プログラム、作成者、出力日 |
| 要素データ | 名前、種類、オブジェクト型、タグ、説明、GlobalId。要素とそのタイプに付いたすべてのプロパティセットと数量セット |

編集できるもの: 名前、オブジェクト型、タグ、説明、および単一のプロパティ値。新しいIFCファイルとして保存されます。スキーマ IFC2X3、IFC4、IFC4X3 は、BimCraft独自のIFCエンジンで開きます。まだ描けないものは、{{ui:ファイル}} パネルの **未描画** に一覧表示されます。モデルは開くときに原点へ移動されるため、原点から離れて配置されたモデルも画面の中央に表示されます。`.ifczip` と `.ifcxml` は開けません。

## プロジェクトファイルとファミリファイル

`.rvt` プロジェクト、`.rte` プロジェクトテンプレート、`.rfa` ファミリ、`.rft` ファミリテンプレート。

| 読み取り | 詳細 |
|---|---|
| ファイル情報 | リリースとビルド、ワークシェアリング、セントラルモデルのパス、最後に保存されたパス、ユーザー名、ロケール、ドキュメントGUID |
| プロジェクト情報 | プロジェクト自身の項目 (名前、番号、クライアント、住所、ステータスなど)。新規プロジェクトの既定値は除きます |
| ファミリ情報 | ファミリ名、カテゴリ、リリース、最終更新、グループごとのパラメーター |
| リンク | ファイルが参照するリンクモデル、CADリンク、画像、キーノート表の一覧 |
| プレビュー画像 | ファイル内に保存されたサムネイル |

読み取らないもの: 3Dモデル、要素、ビュー、シート、集計表。これらは文書化されていない形式で保存されています。BimCraftは各ファイルから数十 KB だけを読み取るため、ファイルサイズはほとんど影響しません。

## .pln、.pla、.tpl、.bpn プロジェクトファイル

まだ読み取れません。BimCraftは開いたときにその旨を表示します。モデルはIFC、図面はDWGとして書き出してください。[.pln と .pla のプロジェクトファイルを開く](topic:pln-project-files) を参照してください。

## DWG と DXF

| 読み取り | 詳細 |
|---|---|
| 空間 | モデル空間と各シート (レイアウト)、タブの順 |
| ビューポート | 各シートのビューポート。尺度、回転、フリーズしたレイヤー付き |
| レイヤー | 名前、色、オン / オフ、フリーズ、印刷フラグ、線の太さ |
| オブジェクト | 線分、ポリライン、円弧、円、楕円、スプライン、ハッチングとソリッド、文字とマルチテキスト、ブロックと属性、寸法、引出線とマルチ引出線、表、点、画像 |
| 外部参照 | 挿入された位置に描かれます。ファイルが見つかった場合 |
| 画像 | 画像ファイルが見つかった場合に描かれます (PNG、JPEG、GIF、BMP、WebP。TIFF は不可) |
| 機器タグ | 厨房機器のタグ (`KCL-ITEM` 属性)。機器集計表用 |

それ以外のものは **未描画** として数えられ、推測されることはありません。DWG は AutoCAD 2000 から 2018 の形式が確認済みです (R13 と R14 のファイルも受け付けますが、テストセットにはありませんでした。それ以前のDWGは開けません)。{{ui:図面}} パネルには、AC1032 などの形式コードが表示されます。DXF は、R12 を含むすべてのバージョンが開けます。どちらも、このタブ内のBimCraft独自のリーダーで読み取られます。DWG や DXF へ保存し直すことはありません。

## フォルダー内

| 種類 | 拡張子 | レポートでの扱い |
|---|---|---|
| モデル | `.rvt` `.rfa` `.rte` `.rft` | 番号付きのバックアップとまとめて表示され、状態を確認、カード情報を読み取り、リンクを確認 |
| IFC | `.ifc` | 一覧に表示。3D で開きます |
| CAD | `.dwg` `.dxf` `.dgn` | これらを外部参照するモデルとともに一覧表示。DWG と DXF は 2D で開き、DGN は開きません |
| 残存ファイル | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | **退避** に一覧表示 |
| 管理フォルダー | `*_backup`、`*_log`、`Revit_temp`、非表示のフォルダー | **退避** に一覧表示。読み取りはしません |

[フォルダーレポート: 役割、状態、リンク](topic:folder-roles) を参照してください。
