## 作業内容

`.pln`(プロジェクト)、`.pla`(ライブラリを含むアーカイブ)、`.tpl`(テンプレート)、`.bpn`(バックアップ)として保存されたプロジェクトを BimCraft に読み込みます。これらは Archicad 独自のファイルです。

## 現在開けるもの

- **プロジェクトファイル自体はまだ開けません。** 形式が公開されておらず、BimCraft はまだこれを読み取れません。開こうとすると、BimCraft はその旨を表示し、このページを案内します。
- **BimCraft はファイルの先頭バイトを確認します。** バージョン 17 以降の Archicad プロジェクトは同じ短い署名で始まるため、BimCraft はファイルが Archicad プロジェクトであることを確実に判定できます。Archicad の名前が付いていても、この署名で始まらないファイルは、名前を変更された、破損している、または古いバージョンのものである可能性が高いです。この署名だけでは、プロジェクト、アーカイブ、テンプレートを区別できません。
- **IFC の書き出しは完全に開けます。** 3D のモデル、階、ゾーンのスペースとしての表示、要素データ、プロパティセットと分類を含み、すべての BimCraft のツールを使えます。
- **DWG の書き出しは** レイヤーとレイアウトを含めて 2D ビューと {{ui:3D}} で開けます。編集するには {{ui:Edit in CadCraft}} を使います。

または、ビュー、レイアウト、プロパティグループを含むプロジェクト全体を 1 つの zip として読み込めます: [プロジェクトバンドルを開く](topic:open-project-bundle) を参照してください。

## IFC を書き出す(モデル)

1. Archicad でプロジェクトを開きます。
2. **ファイル > 名前を付けて保存** を選び、ファイルの種類として **IFC** を選びます。
3. IFC 変換設定(IFC の書き出し設定の一式に対する Archicad の名称)を選びます。**IFC4 Reference View** または **IFC2X3 Coordination View 2.0** の設定が BimCraft に適しています。IFC4X3 も開けます。
4. 書き出す内容を選びます。プロジェクト全体、または表示中の階にある要素だけです。
5. 保存してから、BimCraft で {{ui:Choose a file}} をクリックし、`.ifc` ファイルを選びます。

書き出す前に、変換設定で次の項目を確認してください:

- **ゾーン**: 部屋がスペースとして読み込まれるように書き出します。BimCraft で {{ui:Spaces}} をクリックすると表示されます。
- **プロパティと分類**: {{ui:Properties}} に表示され、{{ui:Find}}、{{ui:Color}}、{{ui:Quantity totals}} で使えるように書き出します。
- **通常の `.ifc`**(`.ifczip` や `.ifcxml` ではありません)。BimCraft が開けるのは通常の `.ifc` だけです。

## DWG を書き出す(図面)

1. 必要な平面、断面、またはレイアウトを開きます。
2. **ファイル > 名前を付けて保存** を選び、ファイルの種類として **DWG** を選びます。
3. DXF-DWG 変換設定を選んで保存します。
4. シートのセット全体を書き出すには、レイアウトブックからレイアウトを保存するか、DWG として公開します。
5. BimCraft で `.dwg` を開きます。書き出しでリンクされた図面は、同じフォルダーにあれば一緒に開きます。[リンクされた図面と画像](topic:dwg-linked-files) を参照してください。

## トラブルシューティング

- **「… は Archicad プロジェクトです。先頭バイトにその記載があります。」** 上記のとおりに IFC または DWG を書き出し、そのファイルを開きます。
- **「… は Archicad ファイルと同じ名前ですが、同じ先頭では始まっていません。」** ファイルの入手元を確認してください。別の種類のファイルに名前を変えただけかもしれません(実際の拡張子で開いてみてください)。コピーが完了しなかったのかもしれません。またはバージョン 17 より前のプロジェクトかもしれません。可能であれば Archicad で開き、IFC または DWG を書き出します。
- **モデルが部屋なしで開きます。** ゾーンが書き出されていません。IFC 変換設定でオンにし、もう一度書き出してください。
- **開口部が切り抜かれていません。** BimCraft は **{{ui:File}}** パネルの **まだ描画されていません** でその旨を示します。もう一度書き出してください。それでも変わらない場合は、モデルを作成したプログラムで開き、そこで開口部を確認してください。
- **DWG の文字の見た目が違います。** 書き出しで BimCraft にないフォントが保持されている可能性があります。BimCraft は文字を標準的なサンセリフフォントで描画します。

また、[IFC を使ってプロジェクトファイルを 3D で読み込む](topic:rvt-to-ifc) と [BimCraft が各形式から読み取るもの](topic:file-formats) も参照してください。
