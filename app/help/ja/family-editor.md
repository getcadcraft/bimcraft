## エディターを開く

ファミリ ({{ui:ビルド}} › {{ui:ファミリ…}}、またはプロジェクトブラウザーの **ファミリ**) を開き、{{ui:ファミリを編集}} をクリックします。何もないところから始めるには、{{ui:新規ファミリ}} をクリックします。名前を付け、種類 (ドア、窓、家具、設備器具、またはその他) を指定します。ドアまたは窓の場合は、平面シンボルと開き勝手の元になるスターターも選びます。エディターは、いくつかのパラメーターと1つのソリッドを持つファミリで開きます。

スターターファミリを編集すると、変更はこのモデルだけに保存されます。他のモデルでは、スターターはそのままです。

{{ui:ファミリを保存}} をクリックするまで、モデルは変わりません。エディターには独自の元に戻す / やり直しがあります (名前の横の矢印ボタン、または {{key:Mod+Z}} と {{key:Mod+Y}})。保存は、モデルの元に戻す操作として1回分になります。

## パラメーター

{{ui:パラメーター}} タブには、ファミリのパラメーターが一覧表示されます。各パラメーターには、名前、種類、既定値があります。種類は次のとおりです: **長さ** (ミリメートル)、**角度** (度)、**数値**、**整数**、**はい / いいえ**、**ペン** (1–16)、そして数値ではなく語句を保持する3種類: **テキスト**、**材料** (プロジェクトの材料の1つ)、**塗りつぶし** (平面の塗りつぶし)。語句は数式では使われません。語句は、ソリッドに色を付けたり (その **材料**)、シンボルの部品を塗りつぶしたり、シンボルのテキストで `{Name}` として表示されたりします。**要素ごと** のボックスをオンにすると、そのパラメーターはサイズではなく、配置された各要素が個別に設定するものになります。

- **数式** は、他のパラメーターに従わせます。例: `Width / 30` や `if(Width > 1200, 2, 1)`。数式の長さはミリメートルです。単位を書くこともできます: `3'`、`6in`、`50cm`。
- パラメーターの名前を変更すると、それを使用しているすべての数式と欄でも名前が変わります。使用中のパラメーターは削除できません。
- ソリッドの **材料** は、プロジェクトの材料の色 (または材料パラメーターの色) を使います。**表示対象** は、粗い詳細レベルではソリッドを非表示にします。**繰り返し** はコピーを作ります。数 (数値または整数パラメーター、1～200) と、x、y、z 方向のコピー間の間隔です。繰り返されたソリッドは、板、棒、穴の列になります。切り取りで使う場合、コピーはまとめて切り取られます。
- ドアまたは窓のファミリは、壁から2つの名前も受け取ります: `WallThickness` と `Face` (1 または −1、ドアが開く側)。

## ソリッド

{{ui:ソリッド}} タブには、ソリッドが一覧表示されます。直方体、押し出し、回転、スイープを追加できます:

| ソリッド | 設定する内容 |
|---|---|
| 直方体 | 2つの角: x0 から x1、y0 から y1、z0 から z1 |
| 押し出し | 作業面 (平面、正面、側面) 上のプロファイル、平面の位置、奥行き |
| 回転 | プロファイル、平面上の軸、360° までの角度 |
| スイープ | 点のパスと半径 (棒またはレール) |

すべての数値は、入力した数値またはパラメーターの式にできます。各ソリッドには色と **表示条件** があります。空欄にすると常に表示されます。はい / いいえのパラメーターの名前 (または `Shelves >= 3` のような比較式) を入力すると、その条件のときだけ表示されます。これが表示パラメーターです。

### プロファイルを描く

押し出しまたは回転のプロファイルは、プレビューの下にある作業面に描かれます:

- 紙面をクリックすると、選択した点の後ろに点が追加されます。
- 点をドラッグして移動します。点は格子にスナップします。{{key:Shift}} を押したままにすると、自由に配置できます。
- 線分上の小さな四角をクリックすると、そこに点が追加されます。{{key:Shift}} を押しながらクリックすると、その線分が円弧になります (もう一度クリックすると反対向きになり、さらにもう一度で直線に戻ります)。
- 点をダブルクリックすると削除されます。

中空の点はパラメーターで設定されます。ドラッグではなく、表で変更してください。

## ブール

{{ui:ブール}} タブでは、1つ目のソリッドから2つ目のソリッドを切り取るか、結合します。ブールの結果は、もう一度切り取るか結合できます。ブールで使われたソリッドは、その一部としてのみ描かれます。

2つ目のソリッドがはい / いいえのパラメーターで非表示になっている場合、1つ目はそのまま残ります。1つ目が非表示の場合、結果も非表示になります。

## 平面シンボル

{{ui:平面シンボル}} タブでは、ソリッドの切り口の代わりに、このファミリについて平面図に表示される内容を描きます。ファミリ独自の軸上の線、長方形、円、円弧、ポリゴン、テキストです。各部品には次の設定があります: **ペン** (1～16、式またはペンパラメーター)、**塗りつぶし** (なし、ソリッド、斜線、クロス、コンクリート、断熱、土、または塗りつぶしパラメーター)、**表示条件** の式、ベースより上の mm 単位の **切断範囲** (平面の切断が範囲内にあると通常の太さで描かれ、その下では細く、その上では破線で描かれます。切断線より上のキャビネットは破線で表示されます)、詳細レベル、繰り返し。テキストでは、パラメーターを `{Name}` と書けます。**平面図の表示:** **ソリッドの切断** は、シンボルをファミリに残したまま、平面図でソリッドの切断を描き続けます。他のプログラムは、このシンボルをファミリの平面形状 (線と形状。テキストはBimCraft内にのみ残ります) として読み取ります。

## 内部のファミリ

{{ui:内部のファミリ}} タブでは、別のファミリをこのファミリの内部に配置します。例: テーブルの脚、ドアの取っ手。ファミリを選び、配置位置 (x、y、z)、回転角度 (4分の1回転のみ: 0、90、180、270)、表示条件、そして値を入力します。値は1行に1つずつ `Height = Height - 40` のように書きます。内部のファミリを保存すると、このファミリも描き直されます。他のファミリに保持されているファミリは削除できません。ファミリは自分自身を含むことはできず、他のファミリを経由しても同様です。入れ子は4階層までです。

## ホットスポット

ホットスポットは、パラメーターを変更するためにドラッグできる点または辺です。{{ui:ホットスポット}} タブで追加し、ドラッグする軸と変更する数値パラメーターを選び、位置をソリッドと同じ式で書きます。プレビューでは、ハンドルの下の **ホットスポット** を選ぶとドラッグできます。平面図で配置された要素 ({{ui:選択}} で選択) の上では、x と y のホットスポットがグリップとして表示されます。1つをドラッグすると、その間の数式を通して、ホットスポットをそこに置くサイズに要素が変わります。元に戻すを1回実行すると元に戻ります。ホットスポットは、駆動されるパラメーター、はい / いいえ、語句は変更できません。

3Dビューでは、同じホットスポットが選択した要素のグリップとして表示されます。上下方向 (z 軸) のものも表示されます。平面図では描けないためです。要素を選択し、その軸方向にグリップをドラッグして手を離すと、ホットスポットをそこに置くサイズに要素が変わります。これは元に戻す1回分です。断面ボックスを表示している間は、同じグリップを使うため、グリップは非表示になります。

## コネクタ

床に配置されたファミリ (家具、設備器具、その他) には、{{ui:コネクタ}} タブがあります。これは、パイプやダクトが要素に接続する点です。洗面器の水栓や排水口のような点です。{{ui:コネクタを追加}} をクリックして、次を設定します:

- **種類**: パイプまたはダクトと、その **系統** (冷水、排水、給気など)。
- **x**、**y**、**z**: ファミリ独自の軸上の位置。ソリッドの数値と同様に、各値は数値またはパラメーターの式にできるため、サイズに合わせてコネクタも移動します。
- **出口方向**: パイプまたはダクトが出る方向で、ファミリの軸のいずれかに沿います (洗面器の下の排水は **下** です)。
- **サイズ (mm)**: パイプの呼び径 (DN) または丸ダクトの直径。
- **流れ**: 供給されるコネクタ (水栓など) は **入り**、排水するコネクタは **出し**。

プレビューでは、各コネクタを出口方向の矢印付きのリングとして描きます。ドアと窓にはコネクタがありません。

配管器具の場合は、**配管器具** の下でどの器具かを選びます (便器、洗面器、流し台、シャワー、洗濯流し)。スターターの器具には、すでにこれが設定されています。

ファミリから配置されたすべての要素は、そのコネクタをIFCファイル内のポートとして受け取ります。要素のサイズが変わるとき、またはファミリを保存するときに作り直されます。IFCのシステムを読み取る他のプログラムでは、各パイプやダクトがどこに属するかが分かります。

## プレビューとハンドル

プレビューは、モデルに保存するのと同じコードでIFCとして書かれたファミリを、描き直したものです。他のプログラムが受け取るものが、そのまま見えます。その下の **表示するサイズ** で、プレビューが使うパラメーター値を設定します。

**ハンドル** はプレビュー上の点です。**サイズ** は、幅、奥行き、高さのハンドルを表示します。**選択したソリッド** は、選んだソリッドの各面にハンドルを表示します。ハンドルはドラッグできます:

- パラメーターで設定された面では、表示されるサイズが変わります (ファミリの数式は保持されます)。
- 数値で設定された面では、その数値が変わります。

## 保存

{{ui:ファミリを保存}} は、ファミリを確認し、すべてのサイズを描き直して、そのすべての要素を作り直します。これは、元に戻す1回分の操作です。変更でサイズを描けない場合 (たとえば、そのサイズでソリッドの幅がなくなる場合)、何も保存されず、エディターはそのサイズを示します。

同じファミリをエディターで開いている間に、他の人が保存した場合 (Live のチームワークセッション、または別のウィンドウ)、{{ui:ファミリを保存}} は拒否され、その旨が表示されます。相手の変更をあなたの変更で置き換えることはありません。エディターを閉じ、ファミリを開き直して相手の変更を確認してから、もう一度変更してください。

:::note
形状は、IFC自身のソリッドとして保存されます: 押し出し、回転、スイープされた円筒、ブールの結果です。三角形のリストには変換されないため、ファイルは小さく保たれ、他のプログラムも形状を形状として読めます。円弧を含むプロファイルは、IFC4では円弧で保存されます。IFC2X3ではプロファイルに円弧のセグメントがないため、そこでは円弧は短い直線に分割されて保存されます。
:::
