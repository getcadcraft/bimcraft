## 行うこと

BIMプロジェクトの整理の仕方で作業します。すべてのビューを1つの一覧にまとめ、各平面図を希望の位置で切断し、テンプレートで複数の平面図に同じ設定を使い、自分でレイアウトするシートを用意します。

## プロジェクトブラウザー

1. {{ui:作図}}をオンにします。左パネルのモデルの下に{{ui:プロジェクトブラウザー}}があります。
2. 一覧には次が含まれます:
   - **平面図**: 各階。クリックするとその平面図を表示します。横のスライダーボタンで、ビュー範囲を設定します（後述）。テンプレートに従う平面図には、テンプレート名が表示されます。
   - **天井伏図**: 各階の反射天井伏図（後述）。
   - **コールアウト**: 各コールアウトと、それが描かれているビュー、および{{ui:新しいコールアウト}}。**見つかりません**には、ビューが存在しなくなったコールアウトが一覧表示されます。
   - **立面図**と**断面図**: 4つの側面とすべての断面線。クリックすると、それらが描かれている図面一式を開きます。
   - **3Dビュー**: {{ui:ビュー}}で保存したビュー。
   - **集計表**: クリックすると、平面図の下に表示されます。
   - **シート**: 作成したシート、{{ui:新しいシート}}、およびモデルから作成したセット全体の{{ui:図面セット…}}。
   - **ビューテンプレート**（{{ui:新しいテンプレート}}付き）、および**リンク**（リンクされたモデル）。

## 平面図のビュー範囲を設定する

1. **平面図**で、階の横のスライダーボタンをクリックします。
2. その階より上の高さを設定します:
   - **切断位置**: 平面図が壁、ドア、窓を切断する位置（変更しない限り1200 mm、約4 ft）。
   - **上端**: 切断位置より上で、上端より下にあるもの（ハイキャビネット、梁など）は破線で描かれます。空欄にすると、階の高さになります。
   - **下端**と**下端より下の深さ**: 切断位置より低いものは、下端まで細い線で描かれ、さらにその下の深さまで描かれます。
3. **この平面図に表示**の下で、この平面図から除外するもの（家具、部屋、柱など）のチェックを外します。
4. 個別の要素を除外するには、平面図または3Dビューで選択し、ダイアログを開いて{{ui:ここで選択したものを非表示}}をクリックします。{{ui:すべて表示}}で元に戻します。
5. {{ui:この設定を使用}}をクリックします。

平面図はすぐに再切断され、図面一式とシートもそれに従います。点群のスライスも切断位置に従います。

## 平面図のトリミング、縮尺、別の階を下に表示する

3つはすべて同じダイアログにあります（階の横のスライダーボタン）:

- **縮尺**: 平面図が印刷される縮尺（平面図のバーの{{ui:印刷}}）、およびシートに配置されるときの縮尺。**全体表示**は、収まる最大の標準縮尺を選びます。
- **トリミング領域**: {{ui:平面図上に描く…}}をクリックし、平面図上で1つの角と対角の角をクリックします（{{key:Esc}}で終了）。領域外の平面図は画面上で薄く覆われて表示されますが、そこでも作業できます。印刷、シート、図面一式では、領域内のみが表示されます。{{ui:クリア}}でトリミングを解除します。{{ui:全体表示}}でトリミング領域に合わせます。
- **下敷き**: 別の階を選びます。その壁、切断された要素、ドア、窓が、この平面図の下に薄く描かれるので、上下の階と位置を合わせられます。ここでは選択できず、印刷時は薄いグレーで表示されます。

ビューテンプレートは、縮尺を高さとカテゴリとともに保持します。トリミング領域と下敷きは、常に1つの平面図だけに属します。

## 階の天井伏図

各階には、平面図の横に反射天井伏図があります。床の平面図を下から見た図で、天井とそこから吊るされるものを配置するためのものです。

1. **天井伏図**の下で階をクリックするか、平面図のバーで階の横の{{ui:天井伏図}}を選びます。
2. 壁は2300 mm（約7'-6"）で切断されます。切断位置より上で、階の高さより下にあるものが描かれます: グリッドと高さタグ（`CLG 2438`）付きの天井、照明、梁。ドア、窓、切断位置より下にあるものは除外されます。
3. 天井を作成するには、平面図と同様に{{ui:天井}}を使用し、選択してプロパティで**パターン**を選びます。[部屋、床、天井、屋根](topic:floors-and-roofs)を参照してください。
4. そこから照明を吊るすには、天井伏図を表示したままライブラリから項目を配置します。項目は**天井に**に入ります。[ライブラリから機器と家具を配置する](topic:place-from-library)を参照してください。
5. 天井伏図の横のスライダーボタンで、切断位置と上端、縮尺、カテゴリ、トリミング領域、下敷きを、平面図と同じように設定します。天井伏図はビューテンプレートを使用しません。

天井伏図は、平面図と同じ向きで描かれます（反射された平面図で、鏡像ではありません）。切断位置より低い天井は描かれません。その場合は、その階の天井伏図の切断位置を下げてください。天井伏図は、平面図と同様に独自のシートに配置されます。図面一式は、自動では追加しません。

## コールアウトを作成する

コールアウトは、平面図の一部を大きく、独自の縮尺でビューとして表示します。例: キッチン、階段、壁の隅。

1. それが属する平面図、天井伏図、またはコールアウトを表示します。
2. 平面図のバーで{{ui:注釈}} › {{ui:コールアウト}}を選びます（またはブラウザーの{{ui:新しいコールアウト}}）。領域の1つの角と対角の角をクリックします。{{key:Esc}}で終了します。
3. コールアウトは1:20（フィートとインチでは1/2" = 1'-0"）で作成されます。その矩形と丸いタグが平面図に描かれます。
4. {{ui:選択}}でタグをクリックするか、ブラウザーのコールアウトをクリックして開きます。平面図にはその領域だけが、コールアウトの縮尺で表示されます。バーには{{ui:コールアウト:}}と名前が表示されます。{{ui:上へ}}で、コールアウトが描かれているビューに戻ります。
5. その横のスライダーボタン（ブラウザーまたはバー）で、名前の変更、縮尺の変更、矩形の再描画、または削除ができます。

コールアウトには、そのビューが表示する内容が表示されます: 同じ切断位置、同じカテゴリ、天井伏図の天井。コールアウトのコールアウトも同様に機能します。コールアウトは、平面図と同様にシートに配置します。そのタグには、位置が表示されます（`1 / A-501`: シートA-501の最初のビュー）。コールアウトの{{ui:印刷}}は、その領域だけをコールアウトの縮尺で印刷します。

コールアウトを削除すると、その中に描かれたコールアウト、およびその中に描かれた線とハッチングも削除されます（事前に確認されます）。コールアウトが描かれている階を削除すると、そのコールアウトは、削除するまで**見つかりません**の下に残り、それを配置しているシートにも見つからないと報告されます。

## 1つのビューに線とハッチングを描く

製図は、1つのビューだけに属する2Dの作業です。線による注記、コンクリートや土のハッチングされた領域、塗りつぶし領域などが該当します。3Dビューや、別の平面図には表示されません。

1. 描き込む先の平面図、天井伏図、またはコールアウトを表示します。
2. 平面図のバーの{{ui:注釈}}から選びます:
   - {{ui:行}}: 始点と終点をクリックします。次の線は、前の線の終点から始まります。{{key:Enter}}で新たに開始します。
   - {{ui:ポリライン}}: 点をクリックします。{{key:Enter}}またはダブルクリックで終了し、最初の点をクリックすると閉じます。
   - {{ui:長方形}}: 対角の2つの角。
   - {{ui:ハッチング領域}}: バーで**パターン**（塗りつぶし、斜線、クロスハッチ、コンクリート、断熱、土）と縮尺を選び、角をクリックします。{{key:Enter}}、ダブルクリック、または最初の角のクリックで閉じます。{{ui:部屋を塗りつぶす}}をオンにすると、部屋内で1回クリックするだけで、その輪郭がハッチングされます。
3. 点は壁と同様にスナップします。{{key:Shift}}で線を直角に保ち、壁と同様に長さを入力できます。{{key:Backspace}}で最後の点を取り消します。

平面図で{{ui:選択}}を使って線またはハッチングを選びます。プロパティでハッチングのパターンと縮尺を変更でき、{{ui:移動…}}もあります（移動元の点をクリックし、移動先をクリックします）。{{key:Delete}}で削除します。各線、ハッチング、変更は1つの操作です。

線とハッチングは、平面図とともに印刷され、平面図と一緒にシートに配置され、図面一式に含まれます。ビュー範囲の**注釈**のチェックを外すと、そのビューからは除外されます。

## ビューテンプレートに設定を保存する

1. ブラウザーの{{ui:新しいテンプレート}}、または平面図のビュー範囲の{{ui:テンプレートとして保存…}}をクリックします（その平面図はそのテンプレートを使うようになります）。
2. 名前を付け、高さとカテゴリを設定し、{{ui:テンプレートを保存}}をクリックします。
3. どの平面図のビュー範囲でもテンプレートを選びます。平面図は高さとカテゴリを取得します。テンプレートを変更すると、それを使うすべての平面図が変わります。1つずつ非表示にした要素は、それぞれの平面図では非表示のままです。
4. ブラウザーでテンプレートをクリックして、変更、名前変更、削除ができます。テンプレートを削除すると、その平面図は設定を独自のものとして保持します。

## 独自のシートを配置する

1. {{ui:新しいシート}}をクリックします。番号とタイトルを入力し、用紙を選びます。
2. 平面図、天井伏図、コールアウト、立面図、断面図、または集計表の横で{{ui:追加}}をクリックします。シートの中央に配置されます。
3. 希望の位置にドラッグします。選択した状態で**縮尺**を選ぶか、平面図自身の縮尺（平面図にある場合）のままにします。それ以外の場合は、シートの3分の1に収まる縮尺になります。{{ui:シートから外す}}で取り除きます。
4. {{ui:シートを保存}}をクリックします。**シート**の下に表示されます。後で変更するには、それをクリックします。
5. {{ui:PDFとしてダウンロード}}で、そのシートを1ページとして保存します。

## 表示される内容

- 平面図は指定した高さで切断され、切断位置より上は破線で、除外したものは非表示になります。
- トリミングした平面図は、画面上では領域の外が覆われ、紙面では領域に切り取られ、指定した縮尺で表示されます。
- 天井伏図には、天井のグリッドと高さタグ、天井の照明が表示されます。
- コールアウトには、平面図上の矩形とタグがあり、それぞれ独自の縮尺で開きます。
- 線とハッチングは、描いたビューにのみ表示されます。
- シートは、開くたびにモデルから描き直されるので、常にモデルと一致します。階または断面線が削除されたビューは、描かれずに報告されます。
- ここでのすべての変更は1つの操作です: {{key:Mod+Z}}で元に戻ります。

:::note
これらはすべて、他のプログラムが変更しないプロパティセットとしてIFCファイルに保存されます。各階のビュー範囲と天井伏図は階に、テンプレート、コールアウト、独自のシートはプロジェクトに保存されます。線とハッチングは、その階のIFC注釈なので、他のプログラムでは2Dの曲線およびハッチング領域（パターンごとの独自の描画）として見えますが、どのビューに属するかは分かりません。
:::

:::tip
ほかのBIMプログラムでは、切断位置をビュー範囲または切断面、テンプレートをビューテンプレートまたはビュー設定、製図線を詳細線、ハッチング領域を塗りつぶし領域と呼びます。考え方は同じです。ビュー設定はそれらのプログラムには引き継がれません。
:::
