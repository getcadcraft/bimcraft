## 作業内容

工程表の各タスクを、施工する要素にリンクし、日ごとに表示して、建物が建っていく様子を確認します。

## 手順

1. IFCモデルを開き、左パネルで{{ui:4D工程}}を開きます。
2. {{ui:テンプレートをダウンロード}}をクリックして、階ごとに1週間を割り当てたタスク一覧を取得し、表計算ソフトで変更します。または、独自に作成します。
3. {{ui:タスク一覧を開く…}}をクリックして、CSVを選択します。
4. 日付スライダーをドラッグするか、{{ui:再生}}をクリックします。

## タスク一覧

ヘッダー行を含むCSVで、列は **Task**、**Start**、**Finish**、**Field**、**Value** です。カンマでもセミコロンでも区切れます。

| Task | Start | Finish | Field | Value |
|---|---|---|---|---|
| Level 1 | 2026-11-02 | 2026-11-13 | Storey | Level 1 |
| Roof | 2026-11-16 | 2026-11-20 | Class | IfcRoof |
| Roof | 2026-11-16 | 2026-11-20 | Pset_WallCommon.IsExternal | Yes |

- 日付はYYYY-MM-DD形式で書きます。
- 1行は、**Field** の値が **Value** と完全に一致するすべての要素にタスクをリンクします。Field には、Storey、Class、Name、Type、Material、Tag、GlobalId などのプロパティ、またはプロパティセットと名前をつなげた `Pset_WallCommon.FireRating` のような形式のプロパティを指定します。
- 同じ日付で行を追加して同じタスクを繰り返すと、そのタスクにより多くの要素をリンクできます。

## 段階と作業パッケージ

**Stage** 列、**Package** 列、またはその両方を追加して、タスクを段階と作業パッケージにまとめます。Phase と WBS も列名として使えます。

| Task | Start | Finish | Field | Value | Stage | Package |
|---|---|---|---|---|---|---|
| Level 1 slab | 2026-11-02 | 2026-11-04 | Class | IfcSlab | Structure | Frame |
| Level 1 walls | 2026-11-05 | 2026-11-13 | Storey | Level 1 | Structure | Frame |
| Doors | 2026-11-30 | 2026-12-04 | Class | IfcDoor | Fit-out | Joinery |

- タスクは1つの段階と1つの作業パッケージに属します。同じタスクの後の行で別の名前を指定すると、その行は行番号とともに一覧に示され、除外されます。
- 2つの段階で同じパッケージ名を使うと、それぞれ別のパッケージになります。

一覧にグループがある場合、日付の上に{{ui:表示}}の一覧が表示されます。段階または作業パッケージを選ぶと、その単位として再生されます:

- スライダーと{{ui:再生}}は、グループの最初の開始日から最後の完了日までを対象に動きます。
- グループのタスクだけが一覧に表示され、色が付きます。グループ外の要素は透過表示になります。
- 一覧の下の行に、その日時点で完了、施工中、未着手のタスク数が表示されます。
- {{ui:そのグループの要素を選択}}で、グループのすべての要素を選択します。{{ui:表示}}、{{ui:断面}}、または集計表に使えます。

**すべてのタスク**を選ぶと、工程表全体の表示に戻ります。

## 見える状態

- **施工済み**: すべてのタスクが完了した要素。それぞれ本来の色で表示されます。
- **施工中**: その日に施工中のタスクがある要素。黄土色で表示されます。タスクは開始日から完了日まで施工中になります。
- **未着手**: 透過表示されます。
- どのタスクにも含まれない要素は、そのままの状態です。一覧には、各タスクが見つけた要素の数が表示されます。読み取れなかった行、または何も見つからなかった行は、行番号とともに一覧に示されます。

## リンク、ガントチャート、MS Project

- Microsoft Project XMLファイル(`.xml`)、または `Predecessors` 列を持つCSVを開きます。リンクは、完了-開始、開始-開始、完了-完了、開始-完了のいずれかで、それぞれ日数のリード(先行)またはラグ(遅延)を指定できます。
- タスク一覧の下のガントチャートは、各タスクを棒で描き、リンクを矢印で示します。クリティカルパス上のタスクは赤で表示されます。リンクのループや存在しない先行タスクは、パネルに一覧表示されます。
- {{ui:MS Project XMLとして保存}}と{{ui:リンク付きのCSVを保存}}は、リンクを含めて工程表を書き戻します。
