図面によっては、短いリストにない地図座標系で描かれているものがあります。たとえば、UTM ゾーン、国家グリッド、テキストの定義として書かれた投影法などです。{{ui:Measure}} › {{ui:Coordinate system…}} で、モデルがどれを使うかを指定できます。

## モデルの座標系を選ぶ

1. モデルを開き、{{ui:Measure}} を選び、次に {{ui:Coordinate system…}} を選びます。
2. 検索ボックスに入力します。次のいずれも使えます:
   - EPSG 番号: `32633` または `EPSG:2277`;
   - UTM ゾーン: `UTM 33N`、`UTM 20 S`、`NAD83 UTM 15N`、`ETRS89 UTM 32N`;
   - 名称の単語: `lambert 93`、`mga zone 56`、`texas central`;
   - 投影法の定義: `+proj=tmerc +lat_0=0 +lon_0=9 +k=0.9996 +x_0=500000 +y_0=0 +ellps=WGS84 +units=m`。必要に応じて先頭に名前を付けます（`My grid = +proj=…`）;
   - `.prj` ファイルのテキスト。または {{ui:Load a .prj file…}} を使用します。
3. 結果を選び、{{ui:Use this system}} を選びます。

選択内容はモデルに保存されます（プロジェクトの `CadCraft_CRS` という名前のプロパティセット）。そのため、モデルと一緒に再び開かれます。保持するにはモデルを保存してください。{{ui:Take it off the model}} を選ぶと、ファイルに記載された内容に戻ります。

定義が一覧にある EPSG 座標系と同じ座標を与える場合、BimCraft はその旨を表示し、そのコードを使用します。一覧にある複数の座標系が同じ計算式を共有する場合は、ほかのものも併せて表示します。

## マイ投影法

貼り付けた定義、または読み込んだ `.prj` は、{{ui:Keep in My projections}} で保存できます。この一覧はこのデバイス（このブラウザー）に保存され、次回座標系の選択画面を開いたときに表示されます。

## 使用される場所

- {{ui:Measure}} › {{ui:Location}} は、指定した点を、モデルの座標系を通して緯度と経度に変換します。以前は、ファイルが EPSG コードなしで地図座標系を指定している場合、注記とともに停止していました。座標系を保存すると、結果を表示します。
- モデルの下にある地図レイヤーも、同じ座標系を使用します。別の座標系にある点群または地形ファイルには、モデルの座標系への変換が提案されます（下記参照）。
- {{ui:Settings}} › {{ui:BimCraft}} › {{ui:Location}} › {{ui:Choose another system…}} では、{{ui:Location}} が報告する内容を設定します。モデル自身の座標系に加えて、任意の一覧にある地理座標系の緯度と経度、または任意の投影座標系の東距と北距を報告できます。

## まだ地図上にないモデル

ファイルに地図変換がない場合、座標系を選ぶと {{ui:Place this model on the map}} が開きます。{{ui:Measure}} › {{ui:Map origin…}} からも開けます。

1. 座標系で、モデルの原点を東距と北距で指定するか、緯度と経度を入力して {{ui:Convert to eastings and northings}} を選びます。
2. 格子北への回転（度、反時計回り。0 はモデルの Y 軸が格子北を指すことを意味します）と、原点の高さを指定します。
3. 縮尺は、モデルと地図の単位の差から始まります（メートル格子上のミリメートル単位のモデルの場合は 0.001）。地表から格子への合成係数の場合にのみ変更してください。
4. {{ui:Place on the map}} を選びます。元に戻す操作1回で、IfcProjectedCRS と IfcMapConversion（IFC4）が書き込まれます。モデル自体は移動しません。

IFC2X3 ファイルには、どちらのエンティティもありません。BimCraft は、その標準が許容する方法で同じ数値を書き込みます。プロジェクトに buildingSMART のプロパティセット `ePSet_MapConversion` と `ePSet_ProjectedCRS`、敷地の緯度と経度、真北を書き込みます。ダイアログにはその旨が表示されます。保持するにはモデルを保存してください。

## すでに地図上にあるモデル

ファイルがすでに地図上に配置されていて、別の座標系を選ぶと、BimCraft は次のように確認します:

- {{ui:Only change what Location reports}} は、ファイル自身の地理参照を保持し、{{ui:Location}}、地図レイヤー、点群には選んだ座標系を使用します（この場合、モデルの数値は新しい座標系の値として読まれます）。
- {{ui:Move the model to this system}} は地理参照を書き換えます。原点を新しい投影法で通し（東距、北距、高さ、回転、縮尺）、IfcProjectedCRS（名称、測地系、投影法、ゾーン、単位）を書き換えるため、保存されたIFCには新しい座標系が記されます。地球上の位置は同じままです。原点の緯度と経度は保持されます。モデル内の要素は変わりません。変わるのは地理参照だけです。

ダイアログは、選ぶ前に古い原点と新しい原点を表示します。そこへ移動して戻すと、原点は1 mm 以内に戻ります。

## 別の座標系の点群と地形

点群や測量ファイルは、独自の座標系（LAS、LAZ、E57、GeoTIFF）を持つか、座標系を持ちません。モデルの座標系と異なる場合、BimCraft は {{ui:Reproject into the model's system}} を提示します。点はバッチで移動されます（多い場合はワーカーで処理され、ページが操作可能なまま保たれます）。コンピューター上のファイルは変更されず、ステータス行に実行内容が表示されます。元の座標系に戻すには、ファイルを開き直します。すでに開いている点群は、点群バーの {{ui:Reproject to the model…}} で同じことができます。

ファイルに座標系の指定がない場合、BimCraft は {{ui:Which system is this file in?}} と確認します。{{ui:Choose the system…}} で選ぶと、その回答はこのデバイス上で、そのファイルについて記憶されます。{{ui:Keep the file's own system}} を選ぶと、点はそのままになります。

## 近似値の扱い

問題はダイアログと **問題** パネルに一覧され、黙って処理されることはありません:

- システムが対象としている領域の外の場所: 計算は行えますが、ゆがみが大きくなります。
- グリッドファイル（NADCON、NTv2 など）が必要な測地系の変換は利用できません。測地系の異なる座標系は、EPSG レジストリに記載されたグリッドを使わない変換で移動し、結果は記載された精度の範囲で近似となります。その精度はメートル単位でメッセージに表示されます。
- 投影できない点は除外され、件数が数えられます。サイズ上限を超えるファイルは、上限を明記したうえで拒否されます。

:::tip
地図座標には、地図変換が必要です。地図変換のないファイルは、{{ui:Map origin…}} で地図上に配置してください。
:::

:::note
グリッドファイルなしで測地系の間を移動すると、精度は数メートル程度です。位置情報の結果では、カタログが分かる場合にその差を表示します。
:::
