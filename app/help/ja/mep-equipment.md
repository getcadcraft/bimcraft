## 作業内容

配管とダクトの端に機器を配置します。各機器は汎用の形状で、入力した値によって寸法が決まります。接続部は**ポート**として表されます。ポートには、配管やダクトがどこで接続されるか、どの系統か、流れの方向、寸法があります。ポートから描いた配管とダクトは、そのポートの寸法と系統を引き継ぎ、そこに固定されます。詳しくは [配管とダクトを機器に接続する](topic:mep-connections)を参照してください。

:::note
これは製図と調整のための補助で、寸法は技術者が決めます。機器はメーカーの製品ではないため、能力、重量、メーカーの接続寸法は含まれません。必要な場合は、MEP プログラムからメーカーのモデルを IFC でインポートしてください。
:::

## 機器を配置する

1. {{ui:作図}}をオンにし、{{ui:ビルド}}を開いて{{ui:機器}}を選びます。
2. バーで種類を選び、寸法を入力します。種類ごとに必要な項目が異なります。

| 種類 | 入力する項目 | ポート |
|---|---|---|
| エアハンドラー | 長さ、幅、高さ。給気と還気の開口。コイル配管の寸法と系統。ドレンの寸法 | 給気ダクトの出口、還気ダクトの入口、コイルの入口と出口、ドレン排水口 |
| インラインファン | 直径、長さ、系統 | ダクトの入口と出口 |
| ポンプ | 配管寸法、系統 | 入口と出口 |
| ボイラー | 長さ、幅、高さ、配管寸法、ガス寸法、煙道の直径 | 暖房の供給出口と還水入口、ガス入口、煙道出口 |
| 給湯器 | 直径、高さ、配管寸法、ガスまたは電気 | 給水入口、給湯出口（ガスで燃焼する場合は、ガス入口と煙道も） |
| 末端ユニット | 長さ、幅、高さ、丸い入口、出口の幅と高さ | 給気の入口と出口 |
| ディフューザー | 前面、ネック、系統 | そのネック（空気の入口） |
| グリル | 前面の幅と高さ、ネックの幅と高さ、系統 | そのネック（還気または排気ダクトへの空気の出口） |
| タンク | 直径、高さ、配管寸法、系統 | 上部の入口、下部付近の出口 |
| ラジエーター | 長さ、高さ、奥行き、配管寸法、系統 | 一端の上部から入る往き、他端の下部から出る還り |
| コンベクター／パネルヒーター | 長さ、高さ、奥行き、配管寸法、系統 | 一端から入る往き、他端から出る還り |
| メーカーのファミリー | ファミリー（[配管仕様、バルブ、ダンパー、メーカーのファミリー](topic:pipe-specs)を参照） | そのファミリーに与えられたポート |

3. **基準高さ**（階からの基部の高さ）を設定します。ディフューザーとグリルの高さは前面の高さです。天井の高さを入力してください。
4. 必要に応じて**タグ**を入力します（例: `AHU-1`）。同じ種類の次の機器には、次の番号が付きます。
5. 平面上でポインターを動かすと、設置面積とポートがついてきます。{{key:R}} を押すと 90° 回転します。クリックして配置します。

配管の寸法は鋼管の呼び径（ASME B36.10M）です。別の材質のポンプから引き出した配管は、同じ呼び径をその材質で使用します。

## 変更と削除

平面または 3D ビューで選択します。プロパティには、入力したすべての寸法、タグ、X、Y、高さ、回転、および各ポート（寸法、系統、流れの方向、何かが接続されているかどうか）が表示されます。変更はそれぞれ{{ui:元に戻す}}の1ステップになります。ポートに固定された経路は、機器と一緒に移動します。{{key:Delete}} で削除します。削除された機器に固定されていた経路は残り、接続チェックで一覧表示されます。

## IFC ファイル

各種類は対応する IFC クラスとして保存されます。IfcUnitaryEquipment（エアハンドラー）、IfcFan、IfcPump、IfcBoiler（ボイラー。給湯器は、タイプが water で、オブジェクトタイプが「Water heater」の IfcBoiler になります）、IfcAirTerminalBox（末端ユニット）、IfcAirTerminal（ディフューザー、グリル）、IfcTank。同じ種類の機器は、タイプと寸法を共有します。IFC2X3 ファイルでは、対応するタイプを持つ IfcEnergyConversionDevice、IfcFlowMovingDevice、IfcFlowController、IfcFlowTerminal、IfcFlowStorageDevice が使われます。各ポートは、接続位置に配置された IfcDistributionPort で、外側を向き、流れの方向と系統を持ちます。他のプログラムは、どの経路がどのポートに接続されているかを読み取れます。機器は、各ポートの系統に属し、配置された各ライブラリ項目のライブラリ項目セットを持ちます。
