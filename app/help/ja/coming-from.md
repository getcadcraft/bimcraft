Revit に慣れている場合、BimCraft は言葉の上ではほとんど馴染みがあるでしょう。一方、作業範囲は異なります。最も重要な違いは次のとおりです。**このビルドはモデルの読み込みと確認、および IFC データの編集を行います。Revit のような作成機能はまだありません。** 壁を描いたり、ファミリを配置したり、ビューやシートを作成したり、プロジェクト ファイルを保存したりすることはできません。できることは、ブラウザーがあればどのコンピューターでもほぼすべての建物ファイルを開き、中身を確認し、プロジェクト フォルダー全体を点検し、IFC モデルのデータを修正することです。

## 操作の対応

| 使い慣れた操作 | BimCraft での操作 |
|---|---|
| Revit で `.rvt` を開いてモデルを見る | BimCraft では `.rvt` をファイル カードとして開きます。リリース、プロジェクト情報、リンク、プレビューが表示されます。3D モデルは IFC として書き出してから開いてください。[プロジェクト ファイルまたはファミリ ファイルを読む](topic:read-rvt-file) |
| ファイルを開く前に、どのリリースで保存されたかを確認する | カードの上部に「Revit … で保存」と表示されます。ファイルをアップグレードしたり変更したりすることはありません。 |
| プロジェクト ブラウザ | ビューやシートのブラウザーはありません。IFC モデルには {{ui:Storeys}} と {{ui:Elements}} の一覧があり、図面にはシートのタブがあります。 |
| プロパティ パレット | 右側の {{ui:Properties}} パネルで、クリックした要素のプロパティを表示します。パラメーター グループの代わりに IFC のプロパティセットを使います。 |
| インスタンス パラメーターとタイプ パラメーター | インスタンスのプロパティセットと、「(タイプ)」と表示されたセットです。タイプの変更は、Revit と同じように、そのタイプのすべての要素に適用されます。[タイプのプロパティを、タイプのすべての要素で変更する](topic:type-vs-instance) |
| タイプ編集 | ダイアログはありません。「(タイプ)」のセットで値をクリックして入力します。 |
| 多数の要素の選択、フィルター、すべてのインスタンスを選択 | 一度に 1 つの要素のみ扱えます。まだ作成されていません。 |
| ViewCube とナビゲーション ホイール | 右下隅の ViewCube、4 つのボタン ({{ui:Fit}}、{{ui:Top}}、{{ui:Front}}、{{ui:Side}})、自由な回転。ナビゲーション ホイールはありません。 |
| Shift キーと中ボタンのドラッグで回転、中ボタンのドラッグでパン | 左ドラッグで回転、右ドラッグ (または {{key:Shift}} キーを押しながらドラッグ) でパン、ホイールでズームします。{{ui:BIMリボン}} のメニュー スタイルでは、中ボタンのドラッグでパン、中ボタンと {{key:Shift}} キーで回転に切り替わります。[メニュー、キー、マウス](topic:menus-keys-and-mouse) |
| 平面図、断面図、断面ボックス | 一度に 1 つの {{ui:Section}} 平面を使えます ({{key:X}})。断面ボックスと 2D 平面図はありません。[断面平面で IFC モデルを切断する](topic:section-plane) |
| 表示での非表示、分離、表示設定 | {{ui:Storeys}} と {{ui:Spaces}}、{{ui:Edges}} のオン・オフ。要素ごとの非表示はまだありません。 |
| 部屋 | IFC のスペースで、初期状態では非表示です。{{ui:Spaces}} をクリックします。 |
| 保存、名前を付けて保存、セントラル モデルとの同期 | {{ui:Save as IFC}} で新しい IFC ファイルをダウンロードします。元のファイルは変更されません。セントラル モデルもワークシェアリングもありません。 |
| {{key:Mod+Z}} で元に戻す | 保存するまでの IFC の編集に対して動作します。[IFC のプロパティを変更し、編集したコピーを保存する](topic:edit-ifc-properties) |
| リンクの管理 | プロジェクト フォルダーを開きます。すべてのリンクがチェックされ、**このフォルダー内**、**同名のファイルあり**、**ライブラリ ファイル**、または**このフォルダー内にない**と表示されます。[プロジェクト フォルダー全体を開く](topic:open-project-folder) |
| 監査、またはファイルが破損していないか確認するためにファイルを開く | フォルダーのレポートが、すべてのコピーとバックアップを数秒で確認し、途中で切れていないかを調べます。[フォルダーの破損したコピーを確認する](topic:check-folder-health) |
| 雑然としたフォルダーから適切なファイルを選ぶ | {{ui:Start here}} ボックスが理由とともに候補を提案します。 |

主にモデルを確認するために開く場合、たとえばモデル確認や IFC 表示のプログラムと同じように使う場合は、{{ui:Viewer}} のメニュー スタイルを選んでください。表示と確認のツールが先頭に来て、作成用のツールは 1 つのメニューにまとめられます。[メニュー、キー、マウス](topic:menus-keys-and-mouse)を参照してください。

## DWG ファイルを表示する場合

AutoCAD や DWG ビューアーで DWG を開いている場合は、次のとおりです。

| 使い慣れた操作 | BimCraft での操作 |
|---|---|
| 下部のモデル タブとレイアウト タブ | 図面の上のタブ: {{ui:Model}} と、シートごとのタブ |
| ZOOM の範囲、ホイールのダブルクリック | ダブルクリック、{{key:F}}、または {{ui:Fit}} |
| 中ボタンでパン | どのボタンでもドラッグ |
| レイヤー マネージャー | {{ui:Layers}} の一覧。チェックで表示、チェックを外すと非表示。{{ui:All on}} と {{ui:All off}} があります。 |
| 外部参照マネージャー | 右側の**リンクされた図面**。**表示中**または**見つかりません**と表示され、{{ui:Add linked drawings…}} があります。 |
| 印刷プレビュー | {{ui:Print view}} または {{key:P}}。白地に黒で、線の太さを反映して表示します。印刷は行いません。 |
| ブロック属性のデータ抽出 | 符号付きの厨房設備図面用の {{ui:Equipment}} タブ。{{ui:Download CSV}} で書き出せます。 |
| 計測、作図、編集、名前を付けて保存 | BimCraft にはありません。作図と編集は CadCraft の作図アプリで行います。 |

## 戸惑いやすい違い

- **ブラウザーで動作します。ブラウザーはファイルを慎重に扱います。** BimCraft は、ユーザーが選んだ、またはドラッグしたファイルとフォルダーのみを読み込めます。自分でファイルを開くことはできず、ファイルを上書き保存することもできません。保存はすべてダウンロードになります。
- **何もアップロードされません。** 一部のブラウザーのフォルダー ダイアログにある「アップロード」という表記は、ブラウザー独自の表現です。ファイルはお使いのコンピューターに残ります。
- **モデルの形式は IFC です。** プロジェクト ファイルは、3D の内容が公開されていないため、カードとして開きます。BimCraft にモデルを読み込むには、IFC を使ってください。
- **編集は書き込み時にコピーされます。** 1 つの要素の値を変更しても、隣の要素は変わりません。書き出しプログラムがその値を要素間で共有していた場合も同様です。タイプのプロパティだけは意図的な例外です。
- **プロジェクトもビューもありません。** BimCraft は一度に 1 つのファイルを表示し、タブを閉じた後はそのファイルについて何も記憶しません。ただし、Chrome と Edge では最近使ったフォルダーの名前を記憶します。
- **Mac のキー。** Revit の Windows のショートカットで Ctrl を使う操作は、BimCraft では {{key:Mod}} を使います。Mac では Command です。
- **マウスの操作。** {{ui:BIMリボン}} のメニュー スタイルを選んだ場合、またはボタンを [メニュー、キー、マウス](topic:menus-keys-and-mouse) で設定した場合を除き、回転は Shift キーと中ボタンではなく左ボタンです。

今日使える代わりの方法については、[まだ作成されていない機能](topic:not-built-yet)を参照してください。
