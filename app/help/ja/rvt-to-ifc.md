## 作業内容

プロジェクトファイルを、BimCraftで回転表示、確認、チェック、編集できるIFCファイルに変換します。BimCraftはまだ`.rvt`ファイル内の3Dモデルを読み取れないため、エクスポートはファイルを作成したプログラム（Revit）で行い、BimCraftで結果を開きます。

## 手順

1. プロジェクトを作成したプログラムで開きます。BimCraftのカードには、保存されたリリース名が表示されます。
2. エクスポートしたい内容を表示している3Dビューを開きます。
3. **ファイル > エクスポート > IFC**を選択します。
4. エクスポートダイアログで、以下の設定を含むセットアップを選択します（または**Modify setup…**）。
5. フォルダーとファイル名を選び、エクスポートします。
6. BimCraftで{{ui:ファイルを選択}}をクリックし、新しい`.ifc`ファイルを選びます。個別のファイルとしてエクスポートされたリンクモデルは、{{ui:モデルを追加}}を使うと、同じシーンに開けます。

## BimCraftで最適に開ける設定

| エクスポーターの設定 | 選択 | 理由 |
|---|---|---|
| IFCバージョン | 確認、チェック、数量拾い出しには**IFC4 Reference View**。他の人がIFC2X3を必要とする場合は**IFC2X3 Coordination View 2.0** | どちらも完全に開けます。**IFC4 Design Transfer View**も開けますが、形状がより正確になる一方、ファイルが大きく、処理が遅くなります。 |
| ファイルの種類 | **IFC**（通常の形式） | BimCraftは`.ifczip`や`.ifcxml`を開けません。 |
| フェーズ / 表示されている要素 | 対象のフェーズと、3Dビューの設定時に**Export only elements visible in view** | 意図的に非表示にしたものは除外されます。 |
| プロパティセット | **Export Revit property sets**と**Export IFC common property sets** | これらは、BimCraftの{{ui:プロパティ}}に表示されるプロパティセットになり、{{ui:検索}}、{{ui:色}}、{{ui:モデルチェック}}で使用されます。 |
| 基本数量 | **Export base quantities** | {{ui:数量集計}}と集計表は、推測ではなく、これらの値（長さ、面積、体積）を使用します。 |
| 部屋と面積 | **Export rooms in 3D views**（または Rooms / Spaces オプション） | 部屋はスペースとして読み込まれます。表示するには{{ui:スペース}}をクリックします。 |
| リンクされたファイル | **Export linked files as separate IFCs** | 各リンクは個別のファイルになります。{{ui:モデルを追加}}で一緒に開くと、位置が揃います。 |
| 座標の基準 | **Shared coordinates**（または測量点） | この場合、ファイルは地図上の位置（IfcMapConversion）を保持するため、測定 › 位置、地表の地図レイヤー、地図座標で配置された点群が機能します。プロジェクト基準点を使うと、モデルは原点付近に保たれますが、地図上の位置は保持されません。 |
| Split walls and columns by level | 階ごとに数量を拾い出す場合はオン | 各階の部分が、それぞれ個別の要素になります。 |

## 表示される内容

3Dのモデルが表示されます。階はプロジェクトのレベルから取得され、プロジェクト情報は{{ui:ファイル}}パネルに表示されます。**エクスポート元**には、エクスポーターの名前が表示されます。

## エクスポートで保持される内容と保持されない内容

- **保持される**: ジオメトリ、階、要素の種類、名前、タイプ、ほとんどのパラメーター（プロパティセットとして）、指定した場合の基本数量、スペースとしての部屋、共有座標による地図上の位置。
- **保持されない**: ビュー、シート、注釈、編集可能なファミリとしてのファミリ、ワークセット、デザインオプション。IFCファイルは、プロジェクトではなくモデル要素のスナップショットです。シートについては、DWGをエクスポートし、2Dビューで開いてください。

## よくある間違い

- **BimCraftでパラメーターが表示されない。** 上記のプロパティセットのオプションをオンにして、再度エクスポートします。
- **部屋が表示されない。** 部屋のオプションをオンにしてから、{{ui:スペース}}をクリックします。
- **`.ifczip`で保存する。** 通常のIFCを選択するか、`.ifczip`を解凍します。
- **地図上の位置がない。** 共有座標でエクスポートし、プロジェクトの測量点が設定されているか確認します。
- **編集が元のプロジェクトに反映されると思い込む。** BimCraftで保存した編集は、プロジェクトファイルではなく、新しいIFCファイルに保存されます。
