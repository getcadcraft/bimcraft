## 作業内容

配管とダクトを機器に接続して、モデルを1つの連結された系統にします。例えば、ポンプの吐出口を出ていく配管に、ディフューザーのネックを分岐ダクトに接続します。その後、BimCraft に、接続されていない箇所を一覧表示させられます。

## ポートから描く

1. {{ui:配管}}または{{ui:ダクト}}を選びます。
2. ポインターを機器のポート（小さな円。開いたポートは警告色で表示されます）に合わせます。ポインターがポートにスナップし、**ポート上**と表示されます。
3. クリックします。経路はポートの高さから始まり、**ポートの寸法と系統を引き継ぎます**（配管は、系統の通常の材質も引き継ぎます）。ステータス行に、引き継いだ内容が表示されます。
4. 通常どおり描画を続けます。別のポートで経路を終えると、その端も固定されます。

経路のポート側の端は、そのポートに**固定**されます。機器を移動または回転（プロパティで）すると、経路の端もそれに追従します。経路を編集しても、その端はポートに留まります。経路の他の角はそのままの位置にあるため、大きく移動した後は、最初の区間がポートから斜めに外れることがあります。その場合は、次の角も移動してください。

## 接続を確認する

{{ui:ビルド}}を開き、{{ui:接続をチェック}}をクリックします。バーの下の一覧に、次の内容が表示されます。

| 行 | 意味 |
|---|---|
| 接続されていないポート | 機器に、何も描かれていない接続があります |
| 端に何もない | 経路が空中で終わっています |
| 寸法の異なる接続ポート | 異なる寸法の経路が、レデューサーなしでポートまたは経路に接続されています（配管の呼び径、ダクトの形状と辺の長さ） |
| 系統の異なる接続ポート | 例えば、給気ディフューザーに接続された還気ダクト |
| 配管とダクトの接続 | 異なる種類の2つの接続が接続されています |
| そのネットワークに、これを供給する機器がない | 経路が接続されているもののうち、どれだけ遠くても、出口を持つものがありません。排水、雨水、通気はこのチェックの対象外です。その水は器具から供給されるためです |
| 現在のモデルにない機器のポートに固定されている | 機器が削除されました。端を描き直すか、経路を削除してください |

エラーが先に表示されます。行をクリックすると、その行が指す対象を選択します。{{ui:閉じる}}で一覧を非表示にします。このチェックは、描かれたとおりのモデルを読み取り、接続と寸法のみを確認します。流量、圧力、バランスは確認しません。
