ライブビューは、リアルタイムの見た目でモデルを表示します。敷地の場所と日付に基づく空と太陽、太陽による影、要素に設定した塗装や材料、照明、壁や床から跳ね返る光が含まれます。操作に追従します。3Dビューを回転すると、ライブビューも回転します。モデルを変更すると、少し遅れて変更が表示されます。データがアップロードされることはありません。

[画像をレンダリング](topic:render)と同じシーン、塗装、照明、太陽を描画します。完成した画像が必要な場合は、そちらを使用してください。

## 開く

1. モデルを開き、ツールバーで{{ui:ライブビュー}}を選びます。パネルがアプリの上、右下に開きます。
2. タイトルバーをドラッグして移動し、角を引っ張って大きくします。
3. 横にあるボタンの{{ui:ライブビューを新しいウィンドウで開く}}、またはパネル内の{{ui:新しいウィンドウ}}を選ぶと、2画面目用に独立したウィンドウへ移動します。ブラウザーがポップアップウィンドウをブロックしている場合は、パネルとして開きます。
4. {{ui:閉じる}}で閉じます。

## 操作項目

| 操作項目 | 機能 |
|---|---|
| {{ui:ビューに追従}} | オン: ライブビューは3Dビューと同じ方向を向きます。歩行中はオフになります |
| {{ui:ウォークスルー}} | モデル内を歩いて移動します（下記参照） |
| {{ui:重力}} | 歩行中: 床に立ち、階段を上ります。オフ: 飛行します |
| {{ui:時刻}} | 一日の時刻です。ドラッグすると太陽が移動します |
| {{ui:月}} | 月です。冬と夏の太陽の位置を確認できます |
| {{ui:品質}} | {{ui:このコンピューターに合わせる}}、または{{ui:低}}、{{ui:中}}、{{ui:高}} |

下部の行には、ビューを描画する方式（WebGPUまたはWebGL 2）、品質、跳ね返り光が表示されます。

## モデル内を歩く

1. 3Dビューを立ちたい位置に向け、{{ui:ウォークスルー}}を選びます。ビューの視点の下にある床の上に、身長1.6 mで立った状態になります。
2. ライブビューをクリックしてから、{{key:W}} {{key:A}} {{key:S}} {{key:D}}または矢印キーを使います。{{key:Shift}}を押したままにすると走ります。ドラッグして周囲を見回します。
3. 40 cm以下の段差は上ります（階段）。それより高いものは壁として扱われます。壁は進行を止め、壁に沿って滑るように移動します。
4. {{ui:重力}}をオフにすると飛行します。{{key:E}}で上昇、{{key:Q}}で下降します。
5. {{key:Esc}}で歩行を停止します。

## 跳ね返り光

日なたの壁から床に跳ね返る光や、部屋の内部の暗い部分の光は、すべてのプロセッサーコアを使ってバックグラウンドで計算されます。計算中は、下部の行に{{ui:跳ね返り光: 40 %}}と表示されます。計算が完了すると、ビューに反映されます。変更があると、計算が再び始まります。

:::note
これはライブビュー向けの近似であり、レンダリングされた画像ではありません。点と点の間の小さな細部には、近くの点の跳ね返り光が適用されます。
:::

:::note
ブラウザーによって対応状況が異なります。ブラウザーがWebGPUに対応している場合、ライブビューはWebGPUを使用します。それ以外の場合はWebGL 2を使用し、見た目は同じです。どちらにも対応していない場合は、パネルにその旨が表示されます。
:::
