ツールバーの {{ui:Collada}} (メニューとリボンのスタイルでは、[ファイル] メニューの {{ui:Collada (.dae, .kmz)を書き出し…}}) を使うと、開いている内容を Collada 1.4.1 形式で書き出します。表示されているすべてのモデルが対象になり、統合されたモデルは配置したとおりの位置で書き出されます。

## エクスポート

1. {{ui:Collada}} を選びます。
2. 形式を選びます。
   - {{ui:Collada file (.dae), for Blender and other 3D programs}}。
   - {{ui:Google Earth package (.kmz): the model placed where it is on the map}}。モデルに位置情報がある場合のみ表示されます。
3. オプションを選んでから {{ui:エクスポート}} を押します。ファイルがダウンロードされ、ステータスバーに書き出された要素の数が表示されます。

| オプション | 機能 |
|---|---|
| {{ui:Write the location into the file}} | ファイルの原点の緯度、経度、高さ、方位を .dae に追加します |
| {{ui:高さ}} | {{ui:On the ground: the model’s level 0 sits on the terrain}}、または {{ui:The model’s own height above sea level}} |
| {{ui:Include rooms and spaces}} | スペースも書き出します (既定では除外されます) |
| {{ui:Include hidden elements}} | 非表示にした要素も書き出します (既定では表示中の要素のみ書き出されます) |

## ファイルの内容

| モデル内 | Collada ファイル内 |
|---|---|
| 建物、階 | 入れ子のノード。階は標高順に並びます。どの階にも属さない要素は「未配置」の下に入ります |
| 各要素 | 要素ごとに 1 つのノードと独自のメッシュを持ちます。名前はモデルの名前どおりです (名前がない場合はクラスとタグ) |
| クラス、GlobalId、事前定義タイプ | ノードの追加データ (IFC プロファイル) に、正確な名前とともに入ります (ModelCraft プロファイル) |
| 色 | 透明度つきのマテリアルになります |
| 単位と軸 | メートル単位、Z 軸が上。手前のモデルのレベル0 は高さ 0 になります |

モデルは地上座標の原点付近に置かれるため、単精度で動作するプログラムでもちらつきなく表示されます。ModelCraft も同じ書き出し処理で Collada ファイルを作成し、これらのファイルを要素名つきで開きます。

## 位置情報の取得元

位置情報は手前のモデルから取得されます。これは {{ui:計測}} で点の緯度と経度を求めるときと同じ方法です。

- モデルの座標系を通じた地図の変換 (IFC4 の IfcMapConversion、または IFC2X3 のプロパティセット)。モデル用に選んだ座標系は、ファイルで指定された座標系より優先されます。
- それ以外の場合は、敷地の緯度と経度を使います (おおよその値で、敷地全体の範囲では十分です)。

方位は実測値を使い、地図の回転、真北、地図の子午線収束角を考慮します。モデルに位置情報を設定するには、[計測] の {{ui:地図上の原点…}} を使います。

## 他のプログラムでの利用

- **Google Earth** は .kmz を読み込みます。モデルは位置情報の場所に、北を向いた状態で表示されます。通常の .dae には Google Earth が位置を読み取れる情報がないため、.kmz を使ってください。
- **Blender** (4.x 以前): [ファイル] > [インポート] > Collada (.dae) を選びます。要素はそれぞれ、マテリアルを持つ独立したオブジェクトとして読み込まれます。位置情報はファイルの追加データに保存されますが、Blender はこれを読み取りません。Blender 5.0 では組み込みの Collada インポーターが削除されました。その場合は {{ui:USD}} または glTF 書き出しを使うか、.dae を Blender 4.5 で開いて .blend として保存してください。

当社のテストでは、すべてのファイルを Collada 1.4.1 スキーマで検証し、独立した Collada リーダーで読み戻して確認しました。ただし、Blender や Google Earth で開いて確認はしていません。
