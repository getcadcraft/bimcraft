{{ui:Render}} はツールバーにあり、3Dビューの昼光のような画像を作成します。空、敷地の緯度に応じた太陽の位置、やわらかい影、全天からの光（隅を暗くする）、ガラスや金属に見える色合いです。モデルとファイルは変更されません。

## ビューをレンダリングする

1. 画像にしたいとおりに3Dビューを設定します: 軌道回転とズーム、不要な階や要素の非表示、画像に断面を見せたい場合は [断面](topic:section-plane) の設定。
2. ツールバーの {{ui:Render}} をクリックします。
3. 押されたものが望みと違う場合は {{ui:Scene}} を選び（[シーンプリセット](topic:render#scene-presets-a-good-picture-in-one-click) を参照）、{{ui:Size}} を選んでから、ダイアログの {{ui:Render}} をクリックします。

   画像はレンダリングに合わせて描き込まれ、パスごとになめらかになります。{{ui:Stop}}（または {{key:Esc}}）で途中で終了し、それまでの画像を保持します。

4. {{ui:Save}} をクリックしてPNGとしてダウンロードします。別の形式が必要なら {{ui:Save as}} を使います（[画像を保存する](topic:render#save-the-picture) を参照）。名前はモデルのファイル名に基づきます。

:::tip
カメラを確認するには、まず {{ui:ビューのサイズ}} で {{ui:下書き}} を描き、最終画像は大きいサイズで {{ui:良好}} または {{ui:最高}} を描きます。
:::

## シーンプリセット: ワンクリックで良い画像

ダイアログ上部には4つの {{ui:Scene}} ボタンがあります。それぞれ、空、明るさ、地面、輪郭線、品質、太陽を1クリックで設定します。そのため、最初の画像の前に覚えることはありません。1つクリックしてから {{ui:Render}} をクリックします。

| シーン | 設定内容 | 用途 |
|---|---|---|
| {{ui:外観}} | 快晴、モデル自身の太陽、地面オン | 外から見た建物 |
| {{ui:内観}} | 曇り空（均一な光、強い日差しの斑点なし）、半段明るく | 部屋の内側から見たビュー |
| {{ui:断面ビュー}} | 白いスタジオ、地面なし、高速レンダリングでの輪郭線 | 断面で切られたモデル |
| {{ui:夜間}} | 太陽は沈む（敷地のある半球の真冬の真夜中）、1段明るく | モデルを照らすランプ。ランプがなければ画像は暗い |

- {{ui:このビューに合わせて選択}} が代わりに選びます: 断面カットがオンなら {{ui:断面ビュー}}、カメラがモデルの内側にあるなら {{ui:内観}}、それ以外は {{ui:外観}}。ダイアログを初めて開くと、この方法で自動的に始まります。
- 下の各設定はそのまま変更できます。シーンが設定した値を1つでも変更すると、どのボタンも押された状態ではなくなり、ボタンの下の行に、設定が独自のものであることが表示されます。シーンをもう一度クリックすると、その値に戻ります。
- シーンは、エンジン、モード、サイズ、材料、カメラ、ランプには影響しません。

:::note
シーンは ModelCraft と BimCraft で同じ値を設定します。完成した画像の見た目は、モデルとグラフィックスカードによって異なります。
:::

## 画像に写るもの

3Dビューで中身が見えているものが描画されます。非表示や透過表示の要素、非表示の階やモデルは除外され、{{ui:スペース}} がオンのときのみ部屋が表示されます。断面平面または断面ボックスは、ビューと同様に画像を切ります。要素は独自の色で表示されます。プロパティによる色分け（{{ui:色}} タブ）は使われません。

## 設定

| 設定 | 内容 |
|---|---|
| {{ui:サイズ}} | ビューのサイズ、ビューのサイズの2倍、フルHD、4K、または正方形 |
| {{ui:モード}} | {{ui:高速}}、または下記の {{ui:高品質(パストレーシング)}} と、その {{ui:時間制限}} |
| {{ui:品質}} | 平均化されるパス数（高品質ではサンプル数）: {{ui:下書き}} 16、{{ui:良好}} 64、{{ui:最高}} 256。パスを増やすと影と輪郭がなめらかになりますが、時間がかかります |
| {{ui:空}} | {{ui:快晴}}、{{ui:曇り}}、{{ui:夕暮れ}}、または {{ui:白いスタジオ}}（単色の白い背景） |
| {{ui:太陽}} | ファイルがサイトに与える緯度（IfcSite）での6月21日 15:00。モデルの真北に合わせます。別の日時にするには {{ui:この画像には別の日付と時刻を使う}} をオンにします |
| {{ui:明るさ}} | 段階（stop）単位で明るくまたは暗く |
| {{ui:モデルの下の地面}} | モデルの最低点にある地面。影を受け、地平線に溶け込みます |
| {{ui:エッジを描画}} | 要素のエッジを画像の上に細い線で描きます |

選んだ時刻に太陽が地平線の下にあるとき、夜です: 空は暗くなり、モデルのランプが照らします。

## ランプ

モデル内のすべての照明器具は、画像ではランプになります。IFCファイル内の照明器具（IfcLightFixture、または照明器具として型付けされた要素）で、ライブラリから配置したものも含みます。各ランプは器具のすぐ下から下向きに照らします。ファイルに器具のワット数が書かれていれば、明るさはそれに従います。そうでなければ800ルーメン、暖かい白色です。

ダイアログは {{ui:ランプ}} の下にランプを一覧表示します。チェックを外すとオフになり、ルーメンで明るさを入力することもできます。これらの変更はIFCに保存されます（器具の `CadCraft_Light` プロパティセット。プロパティでも変更可能）。{{key:Ctrl+Z}} で元に戻せます。

ファイルにサイトの位置が書かれていない場合、太陽は北緯40° に置かれ、ダイアログにその旨が表示されます。時刻はサイトの時刻で、経度から算出されるため、時計の設定が異なる場所では1時間ずれることがあります。

これらの設定は、次の画像のためにこのブラウザーに保持されます。IFCファイルには保存されません。

## ガラスとその他の材料

{{ui:材料}} の下で、画面上のすべての色に見た目を設定できます: {{ui:マット}}、{{ui:サテン}}、{{ui:光沢}}、{{ui:メタル}}、{{ui:鏡面メタル}}、{{ui:ガラス}}、{{ui:すりガラス}}。IFCファイルで透明とされた色（窓の板ガラスなど）は、最初は {{ui:ガラス}} になります。

:::note
{{ui:高速}} モードでは、ガラスと金属はモデルの残りではなく空を映し、光はガラスを通って曲がりません。下の {{ui:高品質(パストレーシング)}} モードでは、両方が行われます。
:::

## 高品質

光をカメラが見るように追う画像には、{{ui:モード}}›{{ui:高品質(パストレーシング)}} を選びます:

- 光は面の間で跳ね返るため、窓から、またはランプで照らされた部屋は全体が照らされ、色は隣の面にもにじみます。
- ガラスは本物のガラスです。光はガラスを通って曲がり、モデルを映します。
- 金属と鏡面の表面は、モデルの残りを映します。
- 光パネルはパネルとして光り、やわらかい影を落とします。

{{ui:高速}} よりずっと遅くなります。各パスで、すべてのピクセルの光を再び追跡するからです。画像は粒状で始まり、サンプルが積み重なるにつれて鮮明になるので、小さく始めてください（{{ui:ビューのサイズ}}、{{ui:下書き}}）。そして {{ui:時間制限}} を選びます。時間が切れると、それまでの画像が保持されます。{{ui:停止}} でも保持されます。最初のパスは、ブラウザーがパストレーサーを準備する間待ちます。

ブラウザーがWebGPUを持つ場合、パストレーサーは CadCraft 独自のもので、グラフィックスカードで動作します。画像の下の行にその旨が表示されます。{{ui:停止}} または時間制限のあとは、{{ui:再開}} で同じ画像を全サンプルに達するまで続けられます。設定を変えたり {{ui:Render}} をもう一度押すと、最初からやり直します。WebGPUがない場合、画像は代わりにWebGLでパストレーシングされ（その旨が表示されます）、{{ui:再開}} は提供されません。

:::linux
LinuxのFirefoxやほとんどのChrome環境には、まだWebGPUがありません。そのため、そこでは高品質にWebGLが使われます。
:::

このモードでは、エッジは描画されず、テクスチャーは色と粗さを示しますが凹凸は示しません。断面による切断は、画像の開始前にモデルに対して行われます。

{{ui:ノイズ除去（サンプル後に残る粒状ノイズを除去）}} はデフォルトでオンです。画像が完成するか停止すると、残った粒状ノイズは、このために作られたニューラルネットワーク（Intel Open Image Denoise の公開されたネットワーク。お使いのコンピューター上で、グラフィックスカードで、なければプロセッサーで実行）によって除去されます。{{ui:表示}}›{{ui:ノイズ除去前の画像}} は、描画されたままの状態を表示します。

## グラフィックスカード上の空と配光プロファイル

WebGPUでは、高品質にさらに2つの空があります:

- {{ui:物理ベースの空}} は、太陽の高さから昼光を計算します。頭上は濃い青、地平線付近は淡い帯、太陽は低くなるほど暖かく暗くなります。{{ui:かすみ}} は、非常に澄んだ日（2）からかすんだ日（10）まで変えられます。
- {{ui:空の画像（HDRI）}} は、実在の場所のパノラマ画像でモデルを照らします。{{ui:画像を選択…}} で正距円筒図法の `.hdr` または `.exr` ファイルを選びます。{{ui:回転}} でモデルの周りを回し、{{ui:画像の明るさ}} で明るくまたは暗くします。画像は独自の太陽を持つため、モデルの太陽は加えられません。ページを開いている間のみ保持されます。再度開いたら、選び直してください。

{{ui:ランプ}} 一覧の各ランプは、メーカーの配光プロファイルを使えます。{{ui:IES プロファイル…}} は IES（LM-63）ファイルを読み、そのランプは器具に応じた方法で光を放ちます（細いダウンライト、壁洗い器など）。その名前を持つすべてのランプがそれを使い、ランプは独自の明るさを保ちます。プロファイル名をクリックすると使用が停止されます。

透明なガラスの窓は、空の光が部屋に入りやすくします。

{{ui:高速}} モードとWebGLのパストレーサーは、{{ui:物理ベースの空}} と {{ui:空の画像（HDRI）}} を快晴として表示し、配光プロファイルは無視します。

## カメラ

{{ui:カメラ}} は、写真のように画像を設定します:

- {{ui:地表面粗度区分}}: {{ui:明るさスライダー}} のままにするか、{{ui:カメラの設定}} を選び、カメラのように {{ui:絞り（F 値）}}、{{ui:シャッター速度}}、{{ui:ISO}} を設定します。その横のEVは一般的な露出値です。f/16、1/100 秒、ISO 100 は晴天に相当します。暗いシーンでは、絞りを開く、シャッターを遅くする、またはISOを上げる必要があります。これはすべてのモードで動作します。
- {{ui:被写界深度}} は、{{ui:ピント距離（m）}} より手前または奥にあるものをぼかします。これは、そのF値のレンズがそうするのと同じです（空欄にすると、ビューの中央にあるものにピントが合います）。{{ui:絞りの形状}} で、ピントの外れたハイライトを丸形または羽根形にします。
- {{ui:2 点透視（垂直線は垂直のまま）}} は、建築用のティルトシフトレンズと同様にカメラを水平にし、画像をずらします。建物を見上げたり見下ろしたりしても、壁が傾いて見えません。
- {{ui:ホワイトバランス}} は、どの光の色を白として見せるかを設定します。暖かいランプの光には低く（例: 3000 K）、日陰や曇りの日には高くします。
- {{ui:突出し}}: {{ui:360° パノラマ}} は、カメラの周りのすべてを2:1の画像にし、パノラマビューア用です。{{ui:360° ステレオ パノラマ}} は、ヘッドセット用に左目と右目のパノラマを重ねます。{{ui:キューブマップ（6 面）}} は、3 × 2 のグリッドに6つの正方形のビューを作ります。幅は {{ui:サイズ}} から決まります。

突出し、被写界深度、2点透視、ホワイトバランスは、グラフィックスカードのパストレーサー（WebGPU）を必要とするため、{{ui:高品質(パストレーシング)}} でのみ表示されます。

## 画像の仕上げ

{{ui:画像}} は高品質の画像を写真のように階調補正します。どのコントロールも、再レンダリングなしで完成画像を即座に変更します:

- {{ui:見た目（ビュー変換）}}: {{ui:ACES フィルミック}}（従来どおりの画像）、{{ui:AgX}}（より柔らかく、非常に明るい光で色を保持）、{{ui:フィルミック}}（穏やかなフィルム曲線）、または {{ui:標準}}（素のまま。明るい光は白に飽和）。
- {{ui:コントラスト}} と {{ui:ハイライトの圧縮}}（非常に明るい部分のディテールを取り戻します）。
- {{ui:ブルーム}}（明るい光の周りのやわらかい光）、{{ui:グレア}} と、その {{ui:グレアの筋}}（最も明るい点から出る星形の光線）、{{ui:ビネット}}（暗い隅）。
- {{ui:カラーテーブル（.cube）…}} は `.cube` ファイルから色の階調を適用します。その {{ui:カラーテーブルの強さ}} も設定できます。空の画像と同様に、ページを開いている間のみ保持されます。

## 画像を保存する

{{ui:名前を付けて保存}} は {{ui:保存}} の隣にあり、ファイルを選びます: 共有用の {{ui:PNG}}、{{ui:JPEG}}、{{ui:WebP}}（JPEG と WebP はブラウザーが書き込める場合のみ）。さらに、グラフィックスカードでの高品質レンダリングの後には次も使えます:

- {{ui:PNG、16 ビット}}: 階調の段階がより細かい、階調補正済みの画像。印刷や後加工用です。
- {{ui:EXR、すべてのレイヤー（32 ビット浮動小数点）}}: 描画されたままの画像（リニアの光、階調補正なし）で、すべてのレンダー要素とライトグループが独立したレイヤーになります。コンポジット用です。
- {{ui:レンダーファイル（.ccrender、後で再調整可能）}}: ダイアログが画像を再度ミックスして階調補正するのに必要なすべて。{{ui:レンダーファイルを開く…}} で、ミックスと階調補正を保ったまま、レンダリングせずに戻せます。

## レンダリング後にライトをミックスする

{{ui:Render}} を押す前に、{{ui:ライトミックス（レンダー後に各ライトの色と明るさを変更）}} をオンにします。画像が完成したら（または停止したら）、{{ui:画像をミックス}} でそのライトをグループ単位で一覧表示します: 空、太陽、名前ごとのランプ（同じ名前のランプはすべて1グループ）。グループをオフにする、色を付ける、明るくまたは暗くすると、画像は再レンダリングなしで即座に変わります。{{ui:ミックスを保存}} は、ミックスに名前を付けて後で選び直せるように保持します。{{ui:レンダー時のまま}} は、作られたままの画像に戻します。{{ui:保存}} はミックス済みの画像を保存します。

{{ui:レンダー要素（アルベド、法線、深度、拡散反射、鏡面反射、透過、発光、ID）}} は、画像の各部分も保持します。{{ui:表示}} で、ビューを1つの要素に切り替えます: 表面の色（アルベド）、法線、深度、拡散反射、鏡面反射、透過した光（それぞれ直接と間接）、発光と空、マスク作成用のオブジェクトごとまたは材料ごとの色。

どちらもグラフィックスカード上に追加のレイヤーを保持します。大きいサイズでは、グラフィックスカードに空きがないことがあります。ダイアログがその旨を表示し、小さいサイズなら動作します。

## 霧、煙、ノイズ、コースティクス

これらは {{ui:霧、煙、ノイズ}} にあり、グラフィックスカード上の {{ui:高品質(パストレーシング)}} で動作します。他のエンジンでは使えません。

- {{ui:霧とかすみ}} は、空気を一定の高さまで、太陽、空、ランプが照らす霞で満たします。{{ui:見通せる距離(メートル)}} で濃さを設定します（約100 m は薄いかすみ、20 m は濃い霧）。{{ui:地面からの霧の高さ(メートル)}} で霧の上端を決め、{{ui:光の筋}} で霞が光源の方向へどれだけ光るかを設定します。日光は霧の上面から抜けるため、窓や建物の間から日が差すと、光の筋として見えます。
- {{ui:煙または雲}} は、霧と同様に照らされる煙または雲のボリューム1つを追加します。{{ui:種類}} は {{ui:雲}}、{{ui:煙の柱}}、{{ui:ボリュームファイル(.ccvol)から}}（CadCraft 独自のグリッド形式）から選びます。{{ui:詳細度}} と {{ui:ばらつき}} は作られた雲または煙の柱を変更し、{{ui:一番長い辺の長さ(m、0 はモデルの大きさ)}}、{{ui:X方向に移動(m)}}、{{ui:Y方向に移動(m)}}、{{ui:Z方向に移動(m)}}、{{ui:回転}} で配置します（モデルの中央から始まります）。{{ui:厚さ}} は密度を上げ、{{ui:前方の輝き}} は光源に向かって明るくし、{{ui:色}} は色合いを付けます。ボリュームファイルは、空の画像と同様に、ページを開いている間のみ保持されます。
- {{ui:画像がきれいになった箇所では早めに止める(アダプティブサンプリング)}} は、落ち着いたピクセルにそれ以上のサンプルを与えません。{{ui:許容するノイズ}} は、ピクセルが止まるときに残る粒状ノイズの量です。画像の下の行には、ピクセルあたりの平均サンプル数が表示されます。
- {{ui:コースティクス(ガラスで屈折した光や鏡で反射した光)}} は、ランプと太陽からの光を追跡します。そのため、ガラス玉の下の明るい斑点や、鏡の光が壁に映るところが、粒状ではなくきれいに出ます。霧、煙、ライトミックス、レンダー要素がオンの間はオフになり、360° 画像用ではありません。

## レンダーキュー

ダイアログの {{ui:レンダーキュー}}: {{ui:この画像をキューに追加}} は画像の設定とビューを保持し、{{ui:キューを開始}} は待機中のものを、このコンピューター上で1つずつ連続してレンダリングします。ページを閉じてもキューは保持されます。同じモデルを開けば続けられます。{{ui:保存}} は完成したものをダウンロードし、{{ui:削除}} と {{ui:完了した項目を消去}} で一覧を整理します。キューは高品質でレンダリングするため、WebGPUが必要です。

## 所要時間

画像はお使いのコンピューターで、そのグラフィックスカードによって作られます。何もアップロードされません。時間はパス数とピクセル数に比例して増えます: {{ui:最高}} は {{ui:下書き}} の16倍のパス数を持ち、4K画像はフルHDの約4倍のピクセル数です。大きなモデルは、パスごとにより長くかかります。
