BimCraftは、CadCraftファミリーの建物モデルアプリです。このビルドでは、建築ファイルを**開き、読み取り、検査**し、**IFCモデルのデータを編集**します。新しい要素の作図やモデリングは、まだできません。モデルビューアー兼チェッカーで、IFCファイルの名前、タグ、プロパティ値を修正することもできる、と考えてください。

開けるもの:

| ファイル | 得られるもの |
|---|---|
| IFC(`.ifc`) | 3Dの完全なモデル: 軌道回転、階、要素のプロパティ、名前とプロパティ値の編集 |
| プロジェクトファイルとファミリファイル(`.rvt`、`.rfa`、`.rte`、`.rft`) | ファイルカード: 保存されたリリース、プロジェクト情報、プレビュー画像、リンクされたファイル。3Dはありません。 |
| DWGとDXF | 2Dの図面: モデル空間とすべてのシート、レイヤー、リンクされた図面、印刷ビュー、タグ付きの厨房設備図面向けの機器集計表 |
| プロジェクトフォルダー | フォルダー内のすべてのモデルのレポート: バックアップ、リンク、破損したコピー、どのファイルから始めるかの提案 |

すべてブラウザー内、お使いのコンピューター上で行われます。**何もアップロードされません。**詳細は[BimCraftが開く、保存するファイル](topic:files)を参照してください。

## BimCraftを開く

1. 最近のブラウザーでBimCraftを開きます。Chrome、Edge、Firefox、Safariのいずれでも動作します。違いは[ブラウザー、デバイス、メモリ](topic:platforms)に載っています。
2. 「建築モデルを開く。」と表示された空の画面が出るまで待ちます。

:::note
BimCraftはブラウザー内で動作し、デスクトップではCadCraft Studioの中で、ほかのアプリとともに動作します。クラウドへの保存はまだ利用できません。ファイルはお使いのコンピューターから開き、コピーをそこに保存します。
:::

## 最初のモデルを開く

BimCraftでできることを最も手早く確認するには、IFCファイルを使います。

1. 画面中央の{{ui:ファイルを選択}}をクリックします。
2. {{pick:mac=Finder|windows=エクスプローラー|linux=ファイルマネージャー}}で`.ifc`ファイルを選んで確定します。
3. 画面下部のステータス行が「IFCエンジンを起動しています…」、続いて「ジオメトリを構築しています」と表示している間、待ちます。

中央に3Dのモデル、左に{{ui:ファイル}}パネルと{{ui:階}}の一覧、右に空の{{ui:プロパティ}}パネルが表示されるはずです。ステータス行の最後には「開きました」と要素の数が表示されます。

:::tip
{{pick:mac=Finder|windows=エクスプローラー|linux=ファイルマネージャー}}からファイルをページに直接ドラッグすることもできます。ドラッグ中は、画面に「ドロップして開く」と表示されます。
:::

:::offline
IFCエンジンは、BimCraftをオフライン用に保存していない限り、IFCモデルを初めて開くときにサイトから読み込まれます。DWGとDXFの図面、プロジェクトファイル、フォルダーには追加のものは必要ありません。そのリーダーはアプリの一部です。アプリバーのボタンに{{ui:オフライン対応済み}}と表示されていれば、すべてオフラインで開けます。そうでない場合は、このタブですでに開いたものがない限り、再接続するまでIFCモデルは開けません。[オンラインとオフライン](topic:online-offline)を参照してください。
:::

:::online
接続のない場所へ出かけますか? アプリバーの{{ui:オフライン用に保存}}をクリックし、{{ui:オフライン対応済み}}になるまで待ちます。保存されるコピー(約11 MB)にはIFCエンジンが含まれます。[オフラインで使う](common:offline)を参照してください。
:::

## 見て回る

:::mouse
1. マウスの左ボタンでドラッグすると、モデルの周りを軌道回転します。
2. ホイールをスクロールするとズームします。
3. 右ボタンでドラッグするとパンします。Macのトラックパッドでは、代わりに{{key:Shift}}キーを押しながらドラッグします。
4. {{key:F}}キーを押すか{{ui:全体表示}}をクリックすると、モデル全体をもう一度表示します。
:::

:::touch
1. 1本の指でドラッグすると軌道回転します。
2. 2本の指でピンチするとズームし、2本の指をそろえて動かすとパンします。
3. {{ui:全体表示}}をタップすると、モデル全体をもう一度表示します。
:::

## 実際に1つやってみる: タグを修正する

1. モデル内の壁、ドア、または任意の要素をクリックします。青くなり、右側にプロパティが表示されます。
2. {{ui:プロパティ}}パネルで、**タグ**の横の値をクリックします。
3. 新しいタグを入力して{{key:Enter}}キーを押します。
4. 左側に開いた{{ui:変更}}セクションを見ます。変更内容が、古い値と新しい値とともに一覧表示されています。

## コピーを保存する

1. {{ui:変更}}セクションの{{ui:IFCとして保存}}をクリックするか、{{key:Mod+S}}を押します。
2. ダウンロードフォルダーで新しいファイルを探します。名前は元のファイル名に「 (edited)」が付いたもので、たとえば`Clinic (edited).ifc`です。

元のファイルが変更されることはありません。編集の詳細は、[IFCのプロパティを変更して編集済みのコピーを保存する](topic:edit-ifc-properties)で説明しています。
