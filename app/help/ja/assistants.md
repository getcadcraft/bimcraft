## 学習内容

AIアシスタント(MCPに対応した任意のアシスタント)に、開いているIFCモデルを参照させ、その中に描かせる方法を説明します。できること・できないこと、そして停止する方法も含みます。

## BimCraftでアシスタントができること

| 要求 | 結果 | 必要な権限 |
|---|---|---|
| 要素を検索する | **検索**と同じように、クラス、階、名前、またはプロパティの値で要素の一覧を取得します | 読み取り |
| プロパティを読み取る | 1つの要素の属性、タイプ、プロパティセット、数量を取得します。**プロパティ**に表示される内容と同じです | 読み取り |
| モデルを説明する、壁を一覧にする | レベル、壁、ドア、窓、部屋、床、通り芯、柱と、各壁の端部、タイプ、高さを取得します | 読み取り |
| 分離、透過、非表示、表示 | {{ui:表示}}メニューを使ったかのように、3Dビューが変わります | ビューの変更と作図 |
| 壁、ドア、窓、床、レベル、または通り芯を描く | {{ui:作図}}ツールを使ったかのようにモデルが変わります。壁は接続され、部屋、床、屋根はそれに従います | ビューの変更と作図 |
| 名前またはプロパティの値を変更する | 1つの要素の名前、説明、オブジェクトタイプ、タグ、または1つのプロパティの値。他の要素と共有されている値は、先にそのアセット用にコピーされます。タイプの値は、アシスタントがそう指示した場合にのみ変更されます。そのタイプのすべての要素が従うためです | ビューの変更と作図 |
| 移動、削除、壁・ドア・窓の変更 | 要素は、ホストしている要素とともに移動または削除されます。{{ui:作図}}ツールで描いた壁は、端部またはタイプで変更されます。ドアと窓は、位置、サイズ、タイプで変更されます。部屋と接合部はそれに従います | ビューの変更と作図 |
| 集計表の設定、配置、読み取り | 「階ごとの、耐火性能と建具金物を含むドアの集計表」のように、アシスタントが集計表の名前、列(プロパティまたはタグが列になります)、グループ化を指定します。BimCraftはモデルから集計表を作成して配置し、アシスタントが指定しなかった内容は事務所の標準から補います。設定は**集計表**の一覧に加わります。返される各行には要素の名前が含まれるため、アシスタントは要素を選択できます | 読み取り(読み取りのみ)、設定の保存にはビューの変更と作図 |
| 集計表を書き出す | Google スプレッドシートに貼り付けるための、CSV、Excel、またはタブ区切りテキスト(Googleには何も送信されません) | 書き出し |
| 部屋の仕上げを読み取り、設定する | 仕上げタイプ、各部屋の床、壁、天井の仕上げ、ゾーン。面積、タイル数、下地の体積は、仕上げ集計表から算出されます | 読み取り。設定にはビューの変更と作図 |
| 要素を選択し、自身の操作を元に戻す | 要素はビューで選択されます。アシスタントの最後の操作が取り消されます | ビューの変更と作図 |
| 保存 | {{ui:IFCとして保存}}で作成されるように、すべての変更を含む新しいIFCファイルを作成します(元のファイルは変更されません) | 保存 |
| USDを書き出す | 開いているモデルを、ツールバーの{{ui:USD}}で書き出すのと同じように、OpenUSD(.usda、.usdc、.usdz)として書き出します | 書き出し |
| 画像をレンダリングし、レンダリングキューを実行する | 3Dビューの画像を、他の設定を指定しない限り、{{ui:レンダリング}}ダイアログがレンダリング設定を使って作成するのと同じように作成します。または、ダイアログのキューに高品質の画像を追加し、順番にレンダリングします(キューにはWebGPUが必要です)。モデルは変更されません([画像をレンダリングする](topic:render)) | 書き出し |

各変更は、**変更履歴**に「アシスタント: …」という名前の1つの操作として記録されます(例: 「アシスタント: 壁を4つ追加」)。そのため、{{key:Mod+Z}}でその操作全体を取り消せます。また、どのアシスタントの操作かを確認できます。ウィンドウ内からファイルを開くことはできません。開いているモデルを操作します。

## 有効にする

アシスタントは、お使いのコンピューター上のCadCraft Studioを通じてBimCraftに接続します。通常のブラウザーからは接続できません。

1. {{ui:設定}}を開き、**BimCraft**タブを選びます。
2. **アシスタント**の下で、**AIアシスタントとスクリプトによるBimCraftの使用を許可する**をチェックします。
3. **読み取り**は、あらかじめチェックされています。アシスタントに要素の分離表示、非表示、作図を許可する場合は**ビューの変更と作図**もチェックします。モデルを新しいファイルとして保存させる場合は**保存**をチェックします。
4. Studioでアシスタントを接続します(Studioには、アドレスと、貼り付けるべき設定が表示されます)。

## アシスタントの接続中

右パネルの上部に、接続されているアシスタントと、そのアシスタントができることが表示されます。{{ui:切断}}をクリックすると、すぐにセッションが終了します。続けるには、もう一度接続が必要です。

設定の**アシスタント**の下にある**アクティビティ**には、アシスタントが行ったすべての呼び出しが、新しいものから順に、成功したかどうかとともに一覧表示されます。

:::tip
平易な言葉で依頼できます。例: 「1階の外壁を分離表示して」「耐火性能が設定されていないドアはどれですか？」「1階に6 m × 4 mの部屋を描き、南側の壁にドアを付けて」。アシスタントは要素を検索して、ビューに表示するか、描きます。
:::

## ウィンドウなし: スクリプトとコマンドライン

同じ作図ツールは、ウィンドウを開かずに、指定したフォルダーにあるIFCファイルに対して使えます。CadCraftのMCPサーバーとコマンドラインを使えば、新しい建物を作成したり、IFCファイルを開いてその内容を説明したり、壁、ドア、窓、床、レベル、通り芯を追加したり、取り消したり、新しい `.ifc` ファイルとして保存したりできます。どのフォルダーを使えるか、また変更や保存をしてよいかは、お使いの側で決めます。

## 無効にする

**AIアシスタントとスクリプトによるBimCraftの使用を許可する**のチェックを外します。すべてのアシスタントはすぐに切断され、設定は次回のために保持されます。
