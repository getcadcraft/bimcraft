## 学べること

AIアシスタント（MCPに対応しているものならどれでも）に、開いている IFC モデルを参照させ、そのモデルに作図させる方法を説明します。アシスタントにできること、できないこと、そして停止する方法も扱います。

## BimCraftでアシスタントにできること

| 要求する操作 | 何が起きるか | 必要な権限 |
|---|---|---|
| 要素を検索 | クラス、階、名前、プロパティ値で要素の一覧を取得します。{{ui:検索}} と同じ動作です | 読み取り |
| プロパティを読み取る | 1つの要素の属性、タイプ、プロパティセット、数量を取得します。{{ui:プロパティ}} に表示される内容と同じです | 読み取り |
| モデルを説明、壁を一覧化 | レベル、壁、ドア、窓、部屋、床、通り芯、柱を取得し、各壁の端部、タイプ、高さも取得します | 読み取り |
| 分離表示、透過表示、非表示、表示 | {{ui:表示}} メニューを使ったときと同じように、3Dビューが変わります | 表示の変更と作図 |
| 壁、ドア、窓、床、レベル、通り芯を作図 | {{ui:作図}} ツールを使ったときと同じように、モデルが変わります。壁は接合され、部屋、床、屋根は追従します | 表示の変更と作図 |
| 名前またはプロパティ値を変更 | 1つの要素の名前、説明、オブジェクトタイプ、タグ、または1つのプロパティ値を変更します。他の要素と共有している値は、先にそのアシスタント用にコピーされます。タイプの値は、アシスタントがそう指示したときだけ変わります。そのタイプのすべての要素が追従するためです | 表示の変更と作図 |
| 移動、削除、壁、ドア、窓の変更 | 要素は、そこに配置されているもの（ホスト要素）と一緒に移動または削除されます。作図ツールで描いた壁は端部やタイプで変更され、ドアと窓は位置、サイズ、タイプで変更されます。部屋と接合部も追従します | 表示の変更と作図 |
| 集計表の設定、整理、読み取り | 「階別の建具表、防火性能と建具金物を含む」のように指定します。アシスタントは集計表の名前、列（プロパティまたはタグが列になります）、グループ化を指定します。BimCraft はモデルから値を入れて整形します。アシスタントが指定しなかった項目は、事務所の標準に従います。設定は集計表の一覧に追加されます。返される各行には要素名が含まれるため、アシスタントは要素を選択できます | 読み取りで読み取り。設定を保存するには表示の変更と作図 |
| 集計表を書き出す | CSV、Excel、またはタブ区切りテキストで書き出し、Google Sheets に貼り付けられます（Googleには何も送信されません） | 書き出し |
| 部屋の仕上げを読み取り、設定 | 仕上げタイプ、各部屋の床、壁、天井の仕上げ、ゾーンを扱います。面積、タイル数、下地の体積は、そのあと仕上げ表から求められます | 読み取り。設定するには表示の変更と作図 |
| 要素を選択、自分の操作を元に戻す | 要素はビューで選択されます。アシスタントの最後の操作は取り消されます | 表示の変更と作図 |
| 保存 | {{ui:IFCとして保存}} で作成するのと同じように、すべての変更を含む新しい IFC ファイルを保存します（元のファイルは変更されません） | 保存 |
| USDを書き出す | 開いているモデルを OpenUSD（.usda、.usdc、.usdz）として、ツールバーの {{ui:USD}} で書き出すのと同じように書き出します | 書き出し |
| 画像をレンダリング、レンダリングキューを実行 | 3Dビューの画像を、{{ui:レンダリング}} ダイアログで作成するのと同じように、レンダリングの設定に従って作成します（別の指定がない場合）。または、高品質の画像をダイアログのキューに追加し、順番にレンダリングします（キューには WebGPU が必要です）。モデルは変更されません（[画像をレンダリングする](topic:render)） | 書き出し |

アシスタントが行う変更は、それぞれ **変更** の1つの操作になり、「アシスタント: …」（例：「アシスタント: 壁を4個追加」）という名前が付きます。そのため {{key:Mod+Z}} で、その操作全体を元に戻せます。また、どの操作がアシスタントによるものかも確認できます。ウィンドウ内ではファイルを開けません。モデルを開くのはあなたで、アシスタントは開いているモデルを扱います。

## 有効にする

アシスタントは、お使いのコンピューター上の CadCraft Studio を経由して BimCraft に接続します。通常のブラウザーからは接続できません。

1. {{ui:設定}} を開き、**BimCraft** タブを選択します。
2. **アシスタント** の下で、**AIアシスタントとスクリプトによる BimCraft の使用を許可** にチェックを入れます。
3. **読み取り** はあらかじめチェックされています。アシスタントに要素の分離表示、非表示、作図を許可する場合は **表示の変更と作図** にもチェックを入れます。モデルを新しいファイルとして保存させる場合は **保存** にチェックを入れます。
4. Studio でアシスタントを接続します（Studio にアドレスと、アシスタントに貼り付ける設定が表示されます）。

## アシスタントの接続中

右パネルの上部に、接続中のアシスタントと、そのアシスタントにできることが表示されます。{{ui:切断}} をクリックすると、すぐにセッションを終了します。続けるには、アシスタントを再接続する必要があります。

設定の **アシスタント** の下にある **操作履歴** には、アシスタントが行ったすべての呼び出しが、新しい順に、成功したかどうかとともに表示されます。

:::tip
「レベル1の外壁を分離表示して」、「防火性能が設定されていないドアはどれですか？」、「レベル1に、南側の壁にドアがある6m×4mの部屋を作図して」のように、普通の言葉で指示してください。アシスタントは要素を見つけてビューに表示するか、作図します。
:::

## ウィンドウを開かずに使う: スクリプトとコマンドライン

ウィンドウを開かなくても、指定したフォルダー内の IFC ファイルに同じ作図ツールを使えます。CadCraftのMCPサーバーとコマンドラインでは、新しい建物を開始する、または IFC ファイルを開く、説明を取得する、壁、ドア、窓、床、レベル、通り芯を追加する、元に戻す、新しい `.ifc` ファイルとして保存する、といった操作ができます。スクリプト向けには、さらに4つのツールがあります。`ifc_batch` は最大200の編集ステップを1つにまとめて実行します（すべて実行されるか、すべて実行されないかのどちらかです。1回の元に戻す操作でバッチ全体が取り消され、拒否されたステップがあると残りを取り消して、そのステップ名を示します）。`ifc_describe` はレベルと、各壁のドアと窓を一覧にします。`ifc_render_png` はウィンドウなしで、モデルの平面シェーディングによる確認用画像（マテリアル、テクスチャ、影なし）を書き出します。`usd_export` は `.usda`、`.usdc`、`.usdz` を書き出します。コマンドラインでは、`cadcraft bim script.json --from model.ifc -o out.ifc` でステップのスクリプトを実行します。`--usd`、`--png`、`--plan` を使うと、同じ実行から USD ファイル、画像、平面図を書き出せます。どのフォルダーを使えるか、また何かを変更または保存してよいかは、あなたが決めます。

## 無効にする

**AIアシスタントとスクリプトによる BimCraft の使用を許可** のチェックを外します。すべてのアシスタントは直ちに切断され、設定は次回のために保存されます。
