## 作業内容

Revit で開かずに、プロジェクトまたはファミリーファイルの内容を調べます。どのリリースで保存されたか、ワークシェアされているか、プロジェクト情報、何にリンクしているかを確認できます。誰かから届いたファイルを、どのリリースで開けばよいかを知りたいときに便利です。

## 手順

1. {{ui:Choose a file}} をクリックします。
2. `.rvt`、`.rfa`、`.rte`、または `.rft` ファイルを選びます。
3. 少し待ちます。ステータス行に「ファイルを読み込んでいます…」と表示され、その後「*ファイル名* を開きました」と表示されます。
4. カードの上部を確認します: ファイルに保存されたプレビュー画像、ファイルの種類と保存されたリリース、プロジェクト名。
5. 下にスクロールして、カードのセクションを読みます。

## 表示される内容

中央のカードには、ファイルに含まれる場合、次のセクションがあります:

| セクション | 内容 |
|---|---|
| ファイル | ファイル名、サイズ、種類(プロジェクト、プロジェクトテンプレート、ファミリー、またはファミリーテンプレート)、保存されたリリースとビルド、ワークシェア、セントラルモデルのパス、最後に保存された場所、保存した人、ロケールとドキュメント GUID |
| プロジェクト情報 | 名前、番号、クライアント、住所、ステータスなど、プロジェクト自身の欄。新規プロジェクトの初期値のままの欄は除外されます。 |
| ファミリー、ファミリー: … | ファミリーの場合: 名前、カテゴリ、リリース、最終更新日、およびそのパラメーター(グループごと) |
| リンクされたファイルと参照ファイル | ファイルが指すすべてのリンクモデル、CAD リンク、画像、キーノート表。保存されたパス付き |

左側の {{ui:File}} パネルは主要な情報を繰り返し、**Read** を追加します。これは BimCraft が実際に読み取ったファイルの量で、数メガバイトのファイルのうち通常は約 40 KB です。右側の {{ui:Properties}} パネルには、要素のプロパティには 3D モデルが必要だと表示されます。

## 3D が表示されない理由

3D モデルとプロジェクトファイル内の要素は、文書化されていない形式で保存されています。BimCraft は、文書化されているか、明らかに読み取れる部分だけを読みます: ファイル情報、プロジェクト情報、ファミリーデータ、リンク一覧、プレビュー画像。残りを推測することはしません。3D でモデルを見て要素のプロパティを読むには、ファイルを作成したプログラムから IFC を書き出してください。[IFC を使ってプロジェクトファイルを 3D で読み込む](topic:rvt-to-ifc) を参照してください。

## よくある間違い

- **3D を期待する。** 上記を参照してください。
- **リンクには保存されたパスだけが表示される。** 単独で開いたファイルは、リンクが存在するかを確認できません。代わりにそのファイルがあるフォルダーを開くと、BimCraft は各リンクを見つかった、または見つからないとマークします: [プロジェクトフォルダー全体を開く](topic:open-project-folder)。
- **「このファイルは不完全です…」** コピー、アップロード、または同期の途中でファイルが途切れています。「オンラインのみ」のクラウドドライブ上のファイルも同様です。BimCraft はそれでもファイルを開き、回復された部分だけを表示します: カードの上部に黄色の注意表示、すべてのバイトがファイル内にある部分を一覧する **ファイルから回復した内容** セクション、残りの部分については **ファイルにない内容**。欠けた部分には何も補われないため、途切れた位置より後に保存されていた場合、リリース、プレビュー画像、プロジェクト情報が欠けることがあります。ファイルの内容一覧そのものが途切れている場合は、何も開けません。元のファイルを再度コピーし、完全なファイルとして開き直してください。
- **「このファイルにはプレビュー画像がありません」。** 画像なしで保存されたファイルもあります。これは正常です。
- **誤ってバックアップを開く。** `Tower.0004.rvt` のような名前のファイルは、番号付きのバックアップです。フォルダーを開くと、それらがモデルごとにまとめられます。
