BimCraftのショートカットは多くありません。ほとんどの作業はマウスとパネルで行います。{{key:Mod}}と書かれたショートカットは、Mac では Command、それ以外では Ctrl を使います。このヘルプでのキーの書き方については、[キー、マウス、トラックパッド](common:keys)を参照してください。

## 共通

| キー | 動作 |
|---|---|
| {{key:Ctrl+Shift+F}} | 画面モードを切り替えます: 通常、全画面、バーを隠した全画面。Mac を含むすべてのプラットフォームで Ctrl を使います |
| {{key:Esc}} | 全画面表示を終了します |
| {{key:Mod+,}} | {{ui:Settings}}を開きます。[BimCraftの設定](topic:settings)を参照してください |
| {{key:Tab}} | ボタン、チェックボックス、値の間を移動します。すべてのコントロールをキーボードで操作できます |

## 3Dビュー（IFCモデル）

| キーまたは操作 | 動作 |
|---|---|
| {{key:F}} | モデル全体を3/4の視点で全体表示します（{{ui:Fit}}と同じ） |
| {{key:Esc}} | 選択を解除するか、配置または貼り付けを中止します |
| クリック | ポインターの下にあるエレメントを選択します。背景の何もない場所をクリックすると選択を解除します |
| {{key:Mod}}+クリックまたは{{key:Shift}}+クリック | エレメントを選択に追加するか、選択から外します |
| {{key:H}} | 選択したエレメントを非表示にします。[エレメントを非表示、分離、透過表示する](topic:hide-and-isolate)を参照してください |
| {{key:I}} | 選択したエレメントのみを表示します（分離） |
| {{key:T}} | 選択したエレメントを表示し、それ以外は透過表示にします |
| {{key:Shift+H}} | すべてのエレメントを再び表示します |
| {{ui:Walk}} | 続けて{{key:W}} {{key:A}} {{key:S}} {{key:D}}または矢印キーで移動します。{{key:Shift}}で走ります。ドラッグで周囲を見回します。{{key:Esc}}で停止します。[モデル内を歩く](topic:walk)を参照してください |
| {{key:M}} | 距離と面の面積を計測します。[3Dでの距離、面積、位置の計測](topic:measure)を参照してください |
| 左ボタンでドラッグ | 回転 |
| 右ボタンでドラッグ | パン |
| {{key:Shift}}または{{key:Mod}}を押しながら左ボタンでドラッグ | パン（トラックパッドで便利です） |
| マウスホイールを回す、または中ボタンでドラッグ | ズーム |
| トラックパッドで2本指スクロールまたはピンチ | ズーム |
| 1本指（タッチ） | 回転。タップで選択します |
| 2本指（タッチ） | ピンチでズーム、同時に動かしてパン |

| {{key:X}} | 断面平面のオン/オフ。[IFCモデルを断面平面で切断する](topic:section-plane)を参照してください |
| {{key:Shift+X}} | 選択したエレメントの周りに断面ボックスを作成します。周囲の余白は設定で指定します |

{{ui:Top}}、{{ui:Front}}、{{ui:Side}}のキーはありません。ボタンを使ってください。

## 編集

同じコマンドはツールバーにもあります: {{ui:Undo}}、{{ui:Redo}}、{{ui:Copy}}、{{ui:Paste}}、そして各キーを表示する{{ui:More}}メニューです。これらはIFCモデルの3Dビューで動作し、欄に入力中は動作しません。[ライブラリ項目のコピー、貼り付け、複製](topic:copy-paste)を参照してください。

| キー | 動作 |
|---|---|
| {{key:Mod+Z}} | 直前の変更を元に戻します |
| {{key:Mod+Y}}または{{key:Mod+Shift+Z}} | 元に戻したものをやり直します |
| {{key:Mod+C}} | 選択したエレメントをコピーします（名前とプロパティもテキストとしてクリップボードに入ります） |
| {{key:Mod+X}} | 選択したエレメントを切り取ります。コピーしてから削除します |
| {{key:Mod+V}} | コピーしたものを貼り付けます。ポインターに追従するので、置く場所をクリックします |
| {{key:Mod+Shift+V}} | 同じ位置に貼り付けます。切り取った場合は元の位置、コピーした場合は元のものの横に貼り付けます |
| {{key:Mod+D}} | 複製します。選択したエレメントをコピーし、貼り付けを開始します |
| {{key:Delete}} | 選択したエレメントを、その部品と開口とともに削除します。[建物エレメントの削除、切り取り、コピー、貼り付け](topic:edit-elements)を参照してください |
| {{key:Mod+A}} | 表示されているすべてのエレメントを選択します |
| {{key:Esc}} | 選択をすべて解除します |

ページでテキストを選択しているときは、{{key:Mod+C}}で通常どおりそのテキストをコピーします。

## 平面ビュー（作図）

これらは{{ui:Draw}}がオンで、欄に入力していないときに動作します。[壁の作図](topic:draw-walls)と[ドアと窓](topic:doors-and-windows)を参照してください。

| キーまたは操作 | 動作 |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | {{ui:Door}}または{{ui:Window}}の場合: ちょうつがいを反対側の端に付けます |
| 壁の作図中に{{key:Shift}} | 壁を0°、90°、180°、270°に保ちます |
| 数字、フィートとインチの記号（`'` と `"`） | {{ui:Length}}欄に長さの入力を始めます。{{key:Enter}}で確定します |
| {{key:Enter}}、{{key:Esc}}、右クリック、またはダブルクリック | 作図中の壁を終了します。もう一度{{key:Esc}}で{{ui:Select}}に戻ります |
| {{key:Delete}} | 選択した壁、ドア、窓を削除します。残った壁はつなぎ直されます |
| ポインターが平面図上にあるときの{{key:F}} | 平面図を全体表示します |
| マウスホイールを回す | ポインター位置を中心にズームします |
| 中ボタンまたは右ボタンでドラッグ、または{{key:Space}}を押しながらドラッグ | パン。{{ui:Select}}がオンのときは、ただのドラッグでもパンします |
| {{ui:Select}}でドアまたは窓をドラッグ | 壁に沿って、または別の壁へ移動します |
| 2本指（タッチ） | ピンチでズーム、同時に動かしてパン |

## ライブラリ項目の配置と貼り付け

| キー | 動作 |
|---|---|
| {{key:R}} | 項目を90°回転します |
| {{key:Tab}} | 壁へのスナップのオン/オフ: 項目の背面が最も近い壁に付きます |
| **X, Y (mm)**欄で{{key:Enter}} | 入力した位置に配置します |
| {{key:Esc}} | 配置または貼り付けを中止します |

## IFC値の編集

| キー | 動作 |
|---|---|
| {{key:Enter}} | 入力した値を確定します |
| {{key:Esc}} | キャンセルし、元の値に戻します |
| 別の場所をクリック | 入力した値を確定します |
| {{key:Mod+Z}} | 直前の変更を元に戻します。未保存の変更があり、欄に入力していないときのみ動作します |
| {{key:Mod+Y}} | 元に戻したものをやり直します |
| {{key:Mod+S}} | IFCとして保存します。未保存の変更があるときのみ動作します。それ以外の場合は、ブラウザー自身の保存コマンドが開きます |

キーボードだけで編集するには、値がハイライトされるまで{{key:Tab}}を押し、次に{{key:Enter}}を押して入力を始めます。

## 2D図面（DWGおよびDXF）

| キーまたは操作 | 動作 |
|---|---|
| {{key:F}} | 図面またはシートを全体表示します |
| {{key:P}} | 印刷ビューのオン/オフ |
| ダブルクリック | 全体表示 |
| 任意のボタンでドラッグ | パン |
| マウスホイールを回す | ポインター位置でズーム |
| トラックパッドで2本指スクロールまたはピンチ | ポインター位置でズーム。2本指スクロールではパンしません |
| 1本指（タッチ） | パン。図面のピンチズームはまだ作成されていません |

## 3Dでの図面

| キーまたは操作 | 動作 |
|---|---|
| {{key:3}} | 3Dのオン/オフ（2Dビューでも同じ） |
| {{key:F}} | 範囲: 図面全体 |
| 中ボタンまたは左ボタンでドラッグ | 回転 |
| 右ボタンでドラッグ、または{{key:Shift}}を押しながらドラッグ | パン |
| マウスホイールを回す | ポインターの下にあるものに向けてズーム |
| トラックパッドで2本指スワイプ | 回転。{{key:Shift}}を押すとパン |
| トラックパッドでピンチ | ズーム |
| 1本指（タッチ） | 回転 |
| 2本指（タッチ） | ピンチでズーム、同時に動かしてパン |

{{key:F}}、{{key:P}}、{{key:3}}は、欄に入力しているとき、機器表を表示しているとき、または{{key:Mod}}か{{key:Alt}}を押しているときは何もしません。

## ファイル

| 操作 | 動作 |
|---|---|
| ファイルをページにドラッグ | 開きます |
| フォルダーをページにドラッグ | 権限の確認なしで、プロジェクトフォルダーとして開きます |
