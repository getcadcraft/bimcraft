IFC5 alpha（ファイル拡張子 {{ui:.ifcx}}）は、buildingSMARTが現在設計中のファイル形式です。まだ確定しておらず、ファイルとその読み取り方は変わる可能性があります。そのため、これは実験的機能であり、先にお読みいただくことをお勧めします。

## 有効にする

1. {{ui:設定}}を選択し、BimCraftタブの{{ui:IFC5 alpha (IFCX)}}セクションを開きます。
2. {{ui:IFC5 alpha (IFCX) - 形式はまだ変わります。先にお読みください}}にチェックを入れます。

既定では無効です。無効の間、.ifcxファイルは、このページを案内する文とともに拒否されます。{{ui:IFC5 alpha (.ifcx)を開く…}}と{{ui:IFC5アルファ版}}の書き出しボタンは、有効にすると表示されます。

## 開く

- {{ui:ファイルまたはフォルダーを開く}}で .ifcx ファイルを選択します（開いているモデルを置き換えます。編集がある場合は、通常の確認が表示されます）。または
- {{ui:IFC5 alpha (.ifcx)を開く…}}を選択し、複数のファイル（ファイル、そのレイヤー、インポートするスキーマファイル）を一緒に選びます。モデルが既に開いている場合、ファイルはその横に**追加されます**。モデル一覧の x をクリックすると、そのファイルは取り除かれます。これが元に戻す操作です。

IFCXファイルは、ノード（パス、その子、継承する内容、属性）を一覧にします。複数のファイルが同じノードを記述することがあります。後のファイル（レイヤー）は前のファイルの属性を上書きし、nullの子は子要素を削除します。BimCraftはそれらを合成し、結果を小さなIFC4モデルとして描画します。プロジェクト、敷地、建物、階、要素（名前、クラス、プロパティ、数量、色、メッシュ付き）です。

ネットワークからは何も取得されません。ファイルがインポートするスキーマファイル（例: `ifc@v5a.ifcx`）は、ファイルと一緒に選択された場合のみ使用されます。選択されていない場合、レポートにその旨が表示され、属性は型チェックなしで読み取られます。

### レポート

開いた後、レポートには読み取りで見つかった内容が一覧表示されます。スキーマに一致しないデータ、指定されていないスキーマファイル、ここではIFCの意味を持たない属性などです。対応付けのない属性は、削除されずにモデル内に**保持され**、書き出し時に書き戻されます。

## 対応関係

| IFCXファイル内 | BimCraft内 |
|---|---|
| IFCクラス（project、site、building、storey、wall など）を持つノード | 対応するIFC4要素。この読み取りが認識しないクラスは、building element proxyになります。 |
| ノードが親の下に持つ名前 | 要素名 |
| 数量の種類（Length、Area、Volume、Mass など）を持つ属性 | `Qto_IFCX`という名前のIFC4数量セット（IFC4の数量は、IFC4の`Qto_*`セットのまま） |
| その他のプロパティ属性 | `Pset_IFCX`という名前のプロパティセット |
| メッシュと変換の属性 | 要素の三角形と配置。非表示のメッシュは描画されません |
| 色、不透明度、材料、分類 | 要素のサーフェススタイル、材料、分類 |

単位はメートルとして扱われ、Z軸は上向きです。alpha版では、単位は後で文書化されると記載されています。

## 書き出し

ツールバーの{{ui:IFC5アルファ版}}を選択し、注意書きを読んでから、{{ui:.ifcxを書き出す}}を選択します。ファイルには当社のヘッダー（作成者 CadCraft、バージョン ifcx_alpha）が含まれ、それがalpha形式であることが記載されています。各モデルは独自のファイル座標系で、メートル単位で書き出されます。名前、クラス、プロパティセット、数量（種類付きの属性として）、色、三角形が含まれます。レイヤーと継承は平坦化されて書き出されます。送付先のプログラムで、ファイルを確認してください。

## 制限

- 曲線の形状（曲線、サーフェス）は読み取られません。三角形メッシュのみです。
- 壁の中にネストされたドアと窓は階の上に配置され、元の壁とはリンクされません。
- IFC4の`Qto_*`セット名は、独自の属性グループ（`cadcraft::qto::…`）として保持されます。標準のalphaスキーマには数量名が少ししかありません。
- 形式は変わる可能性があるため、今日作成したファイルは明日には読み込めない場合があります。
