## IFC तत्त्व

{{ui:गुणहरू}} प्यानलको माथिल्लो भागले तत्त्वको किसिम "Ifc" उपसर्ग बिना देखाउँछ (उदाहरणका लागि "Door", "WallStandardCase", "FurnishingElement") र यसको नाम, वा "नामविहीन"।

| फिल्ड | अर्थ | सम्पादन योग्य |
|---|---|---|
| Name | तत्त्वको नाम, प्रायः निर्यातकर्ताबाट आएको फ्यामिली र प्रकारको नाम | हो |
| Type | तत्त्वको प्रकारको नाम, भए | होइन |
| Object type | केही निर्यातकहरूले भर्ने स्वतन्त्र पाठमा प्रकारको वर्णन | हो |
| Tag | तत्त्वको ट्याग वा चिन्ह; धेरै निर्यातकहरूले यहाँ तत्त्वको ID लेख्छन् | हो |
| Description | स्वतन्त्र पाठ | हो |
| GlobalId | तत्त्वको स्थायी 22-अक्षरको IFC पहिचानकर्ता, एउटै तत्त्वको हरेक निर्यातमा उही | होइन |
| Line | यस IFC फाइलमा तत्त्वको लाइन नम्बर (`#1234`)। निर्यातदेखि निर्यातसम्म बदलिन्छ | होइन |

तल **प्रोपर्टी सेट** आउँछन्, नाम अनुसार क्रमबद्ध:

- प्रत्येक सेट यसको नाममा क्लिक गर्दा खुल्छ र बन्द हुन्छ। पहिलो तीन खुल्ला हुन्छन्।
- "(type)" चिन्ह लागेको सेट तत्त्वको प्रकारको हो: "प्रकार प्रोपर्टी: यहाँको परिवर्तन यस प्रकारका हरेक तत्त्वमा लागू हुन्छ।"
- परिमाण सेटहरू (लम्बाइ, क्षेत्रफल, आयतन, गणना, तौल) केवल पढ्न मिल्ने हुन्छन्।
- सूची र गणनायुक्त मानहरू देखाइन्छन्, केवल पढ्न मिल्ने।
- हो/होइन मानहरू **हो** वा **होइन** का रूपमा देखिन्छन्।
- संख्याहरू प्रदर्शनका लागि चार दशमलवमा गोलाकार गरिन्छन्। लम्बाइहरू (लम्बाइको प्रोपर्टी वा परिमाणको लम्बाइ) टूलबारमा छानिएको {{ui:एकाइहरू}} मा देखिन्छन्, तिनको छेउमा एकाइसहित; तपाईंले त्यही एकाइमा वा अर्को एकाइ चिन्ह (2.4 m, 8'-0") सहित नयाँ मान टाइप गर्न सक्नुहुन्छ: BimCraft ले फाइलकै संख्या फेरि लेख्छ। अन्य संख्याहरू फाइलमा भएजस्तै देखिन्छन्।
- खाली मान *खाली* भनेर देखिन्छ। सम्पादन गरिएको मान बोल्ड हुन्छ र छेउमा निलो पट्टी हुन्छ।

## मान प्रतिलिपि गर्नुहोस्

{{ui:गुणहरू}} मा हरेक मानको छेउमा सानो प्रतिलिपि बटन हुन्छ: त्यसमा क्लिक गर्दा देखिएजस्तै त्यो मान क्लिपबोर्डमा राखिन्छ, जस्तै GlobalId, सिरियल नम्बर वा कुनै पनि प्रोपर्टी सेटको मान। प्रतिलिपि गर्दा सम्पादन सुरु हुँदैन।

माथि, {{ui:सबै प्रतिलिपि गर्नुहोस्}} ले तत्त्वका सबै मानहरू सेट-सेटअनुसार पाठका रूपमा प्रतिलिपि गर्छ, र {{ui:CSV का रूपमा प्रतिलिपि गर्नुहोस्}} ले तिनलाई समूह, प्रोपर्टी र मानका पङ्क्तिहरूका रूपमा प्रतिलिपि गर्छ, स्प्रेडसिटमा टाँस्नका लागि। खाली मानहरू राखिन्छन्, ताकि हरेक फिल्डको पङ्क्ति होस्। यो खुला रहेको अर्को मोडेलको तत्त्वका लागि पनि उस्तै काम गर्छ; एकभन्दा बढी मोडेल खुला छन् भने, CSV ले तिनको फाइल नाम भएको Model स्तम्भबाट सुरु हुन्छ।

## IFC फाइल प्यानल

| फिल्ड | अर्थ |
|---|---|
| File, Size | तपाईंले खोल्नुभएको फाइल |
| Schema | IFC संस्करण, जस्तै IFC2X3 वा IFC4 |
| Project | परियोजनाको नाम र लामो नाम |
| Phase | परियोजना चरण, निर्यातकर्ताले लेखेको भए |
| Exported from | फाइल हेडरबाट, निर्यात गर्ने प्रोग्राम |
| Author | फाइल हेडरमा लेखक |
| Exported | फाइल हेडरमा मिति र समय |
| Elements | आकार भएका कति तत्त्व कोरिए |
| Triangles | तिनका आकारले बनाउने त्रिभुज; मोडेल कति भारी छ भन्ने नाप |

## फाइल प्यानल (परियोजना र फ्यामिली फाइलहरू)

| फिल्ड | अर्थ |
|---|---|
| Kind | परियोजना, परियोजना टेम्प्लेट, फ्यामिली वा फ्यामिली टेम्प्लेट |
| Saved in | फाइललाई अन्तिम पटक बचत गर्ने संस्करण |
| Build | त्यो संस्करणको सटीक बिल्ड |
| Read | फाइलको आकारको तुलनामा BimCraft ले फाइलको कति भाग पढ्यो |

## ड्राइङ प्यानल (DWG र DXF)

| फिल्ड | अर्थ |
|---|---|
| Format | ड्राइङ जुन संस्करणमा बचत गरिएको थियो, यसको ढाँचा कोडसहित, जस्तै AC1032 |
| Units | ड्राइङका इन्सर्सन एकाइहरू, सेट गरिएको भए |
| Entities | कति वस्तुहरू पढियो |
| Layers | कति लेयर छन् |
| Sheets | कति सिट (लेआउट) छन्, वा कुनै पनि छैन |
| Linked drawings | लिङ्क गरिएका ड्राइङहरूमध्ये कति भेटिए र लोड भए |
| Equipment | सिटमा ट्याग गरिएका कति उपकरण वस्तु छन् |

## फोल्डर प्यानल

| फिल्ड | अर्थ |

| Models | परियोजना र फ्यामिली फाइलहरू, प्रत्येकका ब्याकअपहरू एक पटक गनिएर |
