BimCraft मा थोरै सर्टकट छन्। अधिकांश काम माउस र प्यानलद्वारा हुन्छ। {{key:Mod}} लेखिएका सर्टकटहरूमा Mac मा Command र अन्यत्र Ctrl प्रयोग हुन्छ। यो मद्दत पृष्ठमा कुञ्जीहरू कसरी लेखिन्छन् भन्ने कुराका लागि [कुञ्जी, माउस र ट्र्याकप्याड](common:keys) हेर्नुहोस्।

## सबैतिर

| कुञ्जी | के गर्छ |
|---|---|
| {{key:Ctrl+Shift+F}} | स्क्रिन मोडहरू घुमाउनुहोस्: सामान्य, पूर्ण स्क्रिन, बारहरू लुकाइएको पूर्ण स्क्रिन। Mac सहित सबै प्लेटफर्ममा Ctrl |
| {{key:Esc}} | पूर्ण स्क्रिनबाट बाहिर निस्कनुहोस् |
| {{key:Mod+,}} | {{ui:Settings}} खोल्नुहोस्। [BimCraft सेटिङ्स](topic:settings) हेर्नुहोस् |
| {{key:Tab}} | बटन, चेकबक्स र मानहरू बीच सर्नुहोस्। हरेक नियन्त्रणमा किबोर्डबाट पुग्न सकिन्छ |

## 3D दृश्य (IFC मोडेल)

| कुञ्जी वा कार्य | के गर्छ |
|---|---|
| {{key:F}} | सम्पूर्ण मोडेल फिट गर्नुहोस्, तीन-चौथाइ दृश्य ({{ui:Fit}} जस्तै) |
| {{key:Esc}} | चयन हटाउनुहोस्, वा राख्ने वा टाँस्ने काम रोक्नुहोस् |
| क्लिक | मुनि रहेको तत्व छान्नुहोस्; खाली पृष्ठभूमिमा क्लिक गरेर हटाउनुहोस् |
| {{key:Mod}}+क्लिक वा {{key:Shift}}+क्लिक | छानोमा तत्व थप्नुहोस् वा झिकनुहोस् |
| {{key:H}} | छानिएका तत्वहरू लुकाउनुहोस्। [लुकाउने, अलग गर्ने र आरपार हेर्ने तत्वहरू](topic:hide-and-isolate) हेर्नुहोस् |
| {{key:I}} | केवल छानिएका तत्वहरू देखाउनुहोस् (अलग गर्नु) |
| {{key:T}} | छानिएका तत्वहरू देखाउनुहोस्, बाँकी सबै आरपार |
| {{key:Shift+H}} | हरेक तत्व फेरि देखाउनुहोस् |
| {{ui:Walk}} | त्यसपछि {{key:W}} {{key:A}} {{key:S}} {{key:D}} वा तीर कुञ्जीले हिँड्नुहोस्, {{key:Shift}} ले दौडाउँछ, तान्दा वरिपरि हेर्छ, {{key:Esc}} ले रोक्छ। [मोडेलभित्र हिँड्नुहोस्](topic:walk) हेर्नुहोस् |
| {{key:M}} | दूरी र फेसको क्षेत्रफल नाप्नुहोस्। [3D मा दूरी, फेसको क्षेत्रफल र स्थान नाप्नुहोस्](topic:measure) हेर्नुहोस् |
| बायाँ बटन तान्नुहोस् | अर्बिट |
| दायाँ बटन तान्नुहोस् | प्यान |
| {{key:Shift}} वा {{key:Mod}} र बायाँ बटन तान्नुहोस् | प्यान (ट्र्याकप्याडमा उपयोगी) |
| माउस ह्वील घुमाउनुहोस्, वा बीचको बटन तान्नुहोस् | जुम |
| ट्र्याकप्याडमा दुई-औंला स्क्रोल वा पिन्च | जुम |
| एक औंला (टच) | अर्बिट; ट्याप गरेर छान्नुहोस् |
| दुई औंला (टच) | पिन्च गरेर जुम; सँगै सार्दा प्यान |

| {{key:X}} | सेक्सन प्लेन खुला/बन्द। [IFC मोडेल सेक्सन प्लेनले काट्नुहोस्](topic:section-plane) हेर्नुहोस् |
| {{key:Shift+X}} | छानिएका तत्वहरू वरिपरि सेक्सन बाकस, सेटिङ्समा सेट गरिएको कोठासहित |

{{ui:Top}}, {{ui:Front}} र {{ui:Side}} का लागि कुनै कुञ्जी छैन; बटनहरू प्रयोग गर्नुहोस्।

## सम्पादन

उही आदेशहरू टुलबारमा छन्: {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}} र {{ui:More}} मेनु, जसले हरेक कुञ्जी देखाउँछ। तिनीहरू IFC मोडेलको 3D दृश्यमा काम गर्छन्, फिल्डमा टाइप गर्दा होइन। [लाइब्रेरी वस्तुहरू प्रतिलिपि गर्नुहोस्, टाँस्नुहोस् र डुप्लिकेट गर्नुहोस्](topic:copy-paste) हेर्नुहोस्।

| कुञ्जी | के गर्छ |
|---|---|
| {{key:Mod+Z}} | अन्तिम परिवर्तन पूर्ववत् गर्नुहोस् |
| {{key:Mod+Y}} वा {{key:Mod+Shift+Z}} | पूर्ववत्ले फिर्ता लिएको पुनः गर्नुहोस् |
| {{key:Mod+C}} | छानिएका तत्वहरू प्रतिलिपि गर्नुहोस् (तिनका नाम र गुणहरू पनि पाठको रूपमा क्लिपबोर्डमा जान्छन्) |
| {{key:Mod+X}} | छानिएका तत्वहरू काट्नुहोस्: पहिले प्रतिलिपि गर्नुहोस्, त्यसपछि मेटाउनुहोस् |
| {{key:Mod+V}} | प्रतिलिपि गरेको कुरा टाँस्नुहोस्: यो माउसको पछि लाग्छ, जहाँ जान्छ त्यहाँ क्लिक गर्नुहोस् |
| {{key:Mod+Shift+V}} | ठाउँमै टाँस्नुहोस्: काटिएको ठाउँमा, वा प्रतिलिपि गरेपछि मूलसँगै छेउमा |
| {{key:Mod+D}} | डुप्लिकेट: छानिएका तत्वहरू प्रतिलिपि गर्नुहोस् र टाँस्न सुरु गर्नुहोस् |
| {{key:Delete}} | छानिएका तत्वहरू मेटाउनुहोस्, तिनका भागहरू र खुला ठाउँहरूसहित। [निर्माण तत्वहरू मेटाउनुहोस्, काट्नुहोस्, प्रतिलिपि गर्नुहोस् र टाँस्नुहोस्](topic:edit-elements) हेर्नुहोस् |
| {{key:Mod+A}} | देखाइएका सबै तत्वहरू छान्नुहोस् |
| {{key:Esc}} | कुनै पनि नछान्नुहोस् |

पृष्ठमा पाठ छानिएको छ भने {{key:Mod+C}} ले सामान्य रूपमा त्यो पाठ प्रतिलिपि गर्छ।

## प्लान दृश्य (Draw)

यी {{ui:Draw}} खुला हुँदा र तपाईं फिल्डमा टाइप नगर्दा काम गर्छन्। [पर्खाल कोर्नुहोस्](topic:draw-walls) र [ढोका र झ्याल](topic:doors-and-windows) हेर्नुहोस्।

| कुञ्जी वा कार्य | के गर्छ |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | {{ui:Door}} वा {{ui:Window}} सँग: हिन्जहरू अर्को छेउमा |
| पर्खाल कोर्दा {{key:Shift}} | पर्खाललाई 0°, 90°, 180° वा 270° मा राख्नुहोस् |
| अंकहरू र फुट र इन्चका चिन्हहरू (`'` र `"`) | {{ui:Length}} बक्समा लम्बाइ टाइप गर्न सुरु गर्नुहोस्; {{key:Enter}} ले त्यो प्रयोग गर्छ |
| {{key:Enter}}, {{key:Esc}}, दायाँ-क्लिक वा डबल-क्लिक | तपाईंले कोरिरहेको पर्खाल समाप्त गर्नुहोस्; {{key:Esc}} फेरि दबाउँदा {{ui:Select}} मा फर्किन्छ |
| {{key:Delete}} | छानिएका पर्खाल, ढोका र झ्याल मेटाउनुहोस्; बाँकी पर्खालहरू फेरि जोडिन्छन् |
| प्लानमाथि माउस हुँदा {{key:F}} | प्लान फिट गर्नुहोस् |
| माउस ह्वील घुमाउनुहोस् | माउसको ठाउँ वरिपरि जुम |
| बीचको वा दायाँ बटन तान्नुहोस्, वा {{key:Space}} थिचेर तान्नुहोस् | प्यान; {{ui:Select}} खुला हुँदा सामान्य तान्दा पनि प्यान हुन्छ |
| {{ui:Select}} सँग ढोका वा झ्याल तान्नुहोस् | यसलाई त्यसको पर्खालमा, वा अर्को पर्खालमा सार्नुहोस् |
| दुई औंला (टच) | पिन्च गरेर जुम; सँगै सार्दा प्यान |

## IFC मानहरू सम्पादन

| कुञ्जी | के गर्छ |
|---|---|
| {{key:Enter}} | तपाईंले टाइप गरेको मान राख्नुहोस् |
| {{key:Esc}} | रद्द गर्नुहोस् र पुरानो मान फिर्ता राख्नुहोस् |
| अन्यत्र क्लिक गर्नुहोस् | तपाईंले टाइप गरेको मान राख्नुहोस् |
| {{key:Mod+Z}} | अन्तिम परिवर्तन पूर्ववत् गर्नुहोस्। केवल नबचत गरिएका परिवर्तन छँदा र फिल्डमा टाइप नगर्दा |
| {{key:Mod+Y}} | पूर्ववत्ले फिर्ता लिएको पुनः गर्नुहोस् |
| {{key:Mod+S}} | IFC रूपमा बचत गर्नुहोस्। केवल नबचत गरिएका परिवर्तन छँदा; अन्यथा ब्राउजरको आफ्नै बचत आदेश खुल्छ |

किबोर्डबाट मात्र सम्पादन गर्न: मान हाइलाइट नभएसम्म {{key:Tab}} थिच्नुहोस्, त्यसपछि टाइप गर्न सुरु गर्न {{key:Enter}} थिच्नुहोस्।
