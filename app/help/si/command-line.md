## ඔබ කරන දේ

පළමුව පෙට්ටියක ක්ලික් කිරීමෙන් තොරව, ඒවායේ නම් type කර මෙවලම් ධාවනය කරන්න.

## පියවර

1. විධාන රේඛාවක් ඇති පිරිසැලසුමක් තෝරන්න: {{ui:Settings}} විවෘත කරන්න, {{ui:Global}} තෝරන්න, ඉන්පසු {{ui:Layout}}, සහ **Duncan** (හෝ **Rhino**) තෝරන්න. රේඛාව කවුළුවේ පහළ ඇති තත්ව තීරුවේ වාඩි වේ.
2. දර්ශකය ඕනෑම තැනක සහ කිසිම පෙට්ටියක් භාවිතයේ නැති විට, `wall` type කරන්න. අකුරු විධාන රේඛාවේ දිස් වන අතර, ඊට ඉහළින් ඇති ලැයිස්තුව ගැලපෙන විධාන පෙන්වයි.
3. {{key:Enter}} ඔබන්න. Wall මෙවලම ආරම්භ වේ.
4. විධාන රේඛාව ක්ලික් කරන්න (හෝ නැවත යතුරක් ඔබන්න). රේඛාව හිස් විට, ලැයිස්තුව ඔබ පෙර type කළ විධාන පෙන්වයි. {{key:Up}} සහ {{key:Down}} ඒවා හරහා යයි; {{key:Enter}} පෙන්වන එක ධාවනය කරයි.

## ඔබට type කළ හැක්කේ

- භාවිතා වන මෙනු විලාසයේ විධාන වචනය, එය ඒවා ඇති තැන (`WALL`, `WA`, `DOOR` Drafting විලාසයේ).
- විධානයේ යතුර, වචනයක් ලෙස: `W` ඉන්පසු {{key:Enter}} හෝ {{key:Space}} යනු Wall වේ, `D` යනු Door වේ.
- විධානයේ නම, එහි හිස්තැන් සමඟ හෝ නැතිව: `split wall`, `wallrectangle`.
- වචනයේ හෝ නමේ ආරම්භය, එක් විධානයක් පමණක් එලෙස ආරම්භ වන විට.
- වෙනත් ඕනෑම දෙයක් type කළ දෙය සමඟ විධාන සෙවුම විවෘත කරයි.

## දැන ගත යුතු දේ

- {{key:Esc}} රේඛාව හිස් කර යතුරු ඇඳීමට ආපසු දෙයි.
- මෙම පිරිසැලසුම්වලදී තනි අකුරක් තනිවම මෙවලමක් ආරම්භ නොකරයි: එය {{key:Enter}} හෝ {{key:Space}} සඳහා රේඛාවේ බලා සිටී. {{key:Ctrl}} සහිත යතුරු, ක්‍රියාකාරී යතුරු, {{key:Delete}} සහ {{key:Esc}} පෙර පරිදිම ක්‍රියා කරයි. අනෙක් පිරිසැලසුම්වල කිසිවක් වෙනස් නොවේ.
- Draw මෙවලමක් ධාවනය වන විට, අංක මෙවලම සඳහා තබා ගනී (type කළ දිගක්).
- පෙට්ටියක, සංවාදයක හෝ සැකසීම් තුළ type කිරීම එහි රැඳේ.
- ඉතිහාසය මෙම පරිගණකයේ තබා ගනී, යෙදුමට විධාන 50 බැගින්.
