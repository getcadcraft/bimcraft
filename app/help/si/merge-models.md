පුද්ගලයන් දෙදෙනෙක් එකම ගොඩනැගිල්ලේ පිටපතක් ගන්නා අතර, එක් අයෙක් නැගෙනහිර පැත්ත අඳින අතර එක් අයෙක් බටහිර පැත්ත අඳියි, පසුව පිටපත් එකක් බවට පත් විය යුතුය. ඔවුන් විවිධ වස්තූන් ස්පර්ශ කර ඇත්නම්, පුද්ගලයෙකු වෙනුවට වැඩසටහනකට එය කළ හැක.

## එය ක්‍රියා කරන ආකාරය

IFC ගොනුවක සෑම බිත්තියකට, දොරකට, මට්ටමකට, කාමරයකට සහ ගුණාංග කට්ටලයකට කිසිවිටක නොවෙනස් වන GlobalId එකක් ඇත. ඒකාබද්ධ කිරීම වස්තූන් සොයන්නේ ගොනුව ඒවාට දෙන අංකයෙන් (`#123`) නොව, එම id මගිනි, මන්ද වැඩසටහනක් සුරකින විට අංක වෙනස් වේ. තමන්ගේම id නැති (ස්ථානගත කිරීම්, හැඩතල, ඒකක) වස්තුවකට එල්ලී ඇති කොටස් ඒවායේ ඇති දේ මගින් සසඳයි.

පිටපත් දෙකම එකම IFC අනුවාදයේ විය යුතුය (2x3, 4 හෝ 4.3). ඒකාබද්ධ කිරීම ඔබේ ගොනුව එලෙසම, එහි අනුපිළිවෙල සහ එහි අංක තබා ගන්නා අතර, නව දේ එකතු කරයි, එබැවින් ඒකාබද්ධ කිරීමේ git diff එක ඒකාබද්ධ කිරීම වෙනස් කළ දේ පමණක් පෙන්වයි.

## සකසන්න

Git හට සෑම repository එකකටම වරක් රේඛා දෙකක් අවශ්‍ය වේ:

```
# .gitattributes
*.ifc merge=cadcraft

# එක් වරක්, සෑම පරිගණකයකම
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

git නොමැතිව, `cadcraft merge <base> <ours> <theirs>` ධාවනය කරන්න. Fossil සහ Mercurial එම ගොනු තුන ඒවායේම ඒකාබද්ධ-මෙවලම් සැකසීමේ ගනී. කිසිවක් උඩුගත නොවේ; එය සියල්ල ඔබේ පරිගණකයේ ක්‍රියා කරයි.

## නීති

- එක් පැත්තක පමණක් වෙනස් කළ ගුණාංගය ගනු ලැබේ. දෙපැත්තේම එකම වෙනස එක් වරක් ගනු ලැබේ.
- එකම ගුණාංගය ක්‍රම දෙකකින් වෙනස් කළ (එකම මට්ටම ක්‍රම දෙකකින් නම් කළ) **ගැටුමකි**: ඔබේ පැත්ත රැඳේ සහ වාර්තාව දෙකම ලැයිස්තුගත කරයි. ප්‍රතිඵලය විවෘත කර එය අතින් නිවැරදි කරන්න.
- දේවල් ලැයිස්තුවක් (මට්ටමක බිත්ති, කට්ටලයක ගුණාංග) කට්ටලයක් ලෙස ඒකාබද්ධ වේ: කුමන පැත්තක් එකතු කළද එය තබා ගන්නා අතර කුමන පැත්තක් ඉවත් කළද එය ඉවත් කරයි. පුද්ගලයන් දෙදෙනෙකු එකම මට්ටමට බිත්ති එකතු කිරීම ගැටුමක් නොවේ.
- කුමන පැත්තක හෝ එකතු කළ වස්තුවක් එහි හැඩය සහ ගුණාංග සමඟ තබා ගනු ලැබේ. එක් පැත්තක ඉවත් කර අනෙක් පැත්තේ ස්පර්ශ නොකළ: ඉවත් කරයි. එක් පැත්තක ඉවත් කර අනෙක් පැත්තේ වෙනස් කළ: ඉවත් කරන අතර වාර්තා කරයි.
- ගොනුවේ කාල මුද්‍රාව සහ කර්තෘ, සහ සෑම වස්තුවක හිමිකම් ඉතිහාසය, ඔබට අයත්ව පවතී.

ජ්‍යාමිතිය සම්පූර්ණයෙන් ඒකාබද්ධ වේ: බිත්තියක හැඩය එක් පැත්තකින් පැමිණේ, කිසිවිට ලක්ෂ්‍යයෙන් ලක්ෂ්‍යයට මිශ්‍ර නොවේ. සම්පීඩිත (zip) IFC සහ IFCX ගොනු ඒකාබද්ධ නොවේ. ඒකාබද්ධ කිරීමෙන් පසු, ප්‍රතිඵලය BimCraft හි විවෘත කර සුරකීමට පෙර ගැටලු පැනලය බලන්න.
