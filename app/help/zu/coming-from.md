Uma wazi i-Revit, iningi le-BimCraft lizokuzwakala lijwayelekile ngamagama, lishaye ngokuphelele ngobubanzi. Umehluko obaluleke kakhulu: lolu hlobo lufunda futhi luhlola amamodeli futhi lulungise idatha ye-IFC. **Alukwazi ukudweba njenge-Revit okwamanje.** Awukwazi ukudweba udonga, ukubeka imindeni, ukwenza izibuko noma amashidi, noma ukulondoloza ifayela leprojekthi. Okungenzeka ukwenza ukuvula cishe noma yisiphi isakhiwo ngalo nakanoma yikuphi, ukubona okukuwo, ukuhlola ifolda yonke yephrojekthi, nokulungisa idatha kumodeli ye-IFC.

## Izinkambiso ezihlelelwe

| Uma ujwayele | Ku-BimCraft |
|---|---|
| Ukuvula i-`.rvt` ku-Revit ukuze ubone imodeli | I-BimCraft ivula i-`.rvt` njengekhadi lefayela: ukukhishwa, ulwazi lwephrojekthi, izixhumanisi, isibonelo. Ngemodeli ye-3D, thumela i-IFC bese uyivula. [Funda ifayela lephrojekthi noma lomndeni](topic:read-rvt-file) |
| Ukuhlola ukuthi ifayela lagcinwa ekukhishweni kuphi ngaphambi kokulivula | Ikhadi lithi "igcinwe ku-Revit …" phezulu, ngaphandle kokuthuthukisa noma ukuthinta ifayela |
| Isiphequluli sephrojekthi | Akukho siphequluli sezibuko namashidi. Imodeli ye-IFC inezinhlu {{ui:Izitezi}} kanye {{ui:Izinto}}; idwebo linamathebhu eshidi |
| Ipharetha yezici | Iphaneli {{ui:Izici}} ngakwesokudla, yento oyichofozile. Amasethi ezici e-IFC esikhundleni samaqembu wamapharamitha |
| Amapharamitha wesibonelo nohlobo | Amasethi ezici wesibonelo, namasethi amakhonjwa ngokuthi "(type)". Ukushintsha kohlobo kusebenza kuzo zonke izinto zohlobo, njenge-Revit. [Shintsha isici sohlobo kuzo zonke izinto zohlobo](topic:type-vs-instance) |
| Hlela uhlobo | Akukho ibhokisi lencazelo: chofoza inani kusethi ethi "(type)" bese uthayipha |
| Ukukhetha izinto eziningi, izihlungi, Khetha wonke amasibonelo | Into eyodwa ngesikhathi. Akukakhiwa okwamanje |
| Ikyubu lokubuka nevili lokuzula | Ikyubu lokubuka ekhoneni elingezansi kwesokudla, izinkinobho ezine ({{ui:Lwanele}}, {{ui:Phezulu}}, {{ui:Phambili}}, {{ui:Uhlangothi}}) nokuzungeza okukhululekile. Akukho vili lokuzula |
| Shift nokudonsa ngenkinobho ephakathi ukuzungeza, ukudonsa ngenkinobho ephakathi ukushelelisa | Ukudonsa ngenkinobho yesokunxele kuzungeza, ukudonsa ngenkinobho yesokudla (noma {{key:Shift}} nokudonsa) kushelelisa, insudo izondeza. Isitayela semenyu {{ui:Ibha ye-BIM}} sishintshela ekushelelisweni ngenkinobho ephakathi nokuzungeza nge-{{key:Shift}} nenkinobho ephakathi. [Imenyu, okhiye nembewu](topic:menus-keys-and-mouse) |
| Amaplani wamaphansi, izigaba, amabhokisi ezigaba | Ipuleni eyodwa {{ui:Isigaba}} ngesikhathi ({{key:X}}); akukho bhokisi lesigaba noma amaplani e-2D. [Sika imodeli ye-IFC ngendiza yesigaba](topic:section-plane) |
| Ukufihla ekubukeni, ukuhlukanisa, ukubonakala/izinhlobo zokubonakala | {{ui:Izitezi}} ziyavulwa nevaliwe, {{ui:Izindawo}} ne-{{ui:Imiphetho}}. Akukho ukufihla ngokwento okwamanje |
| Amagumbi | Izindawo ze-IFC, zifihliwe ekuqaleni. Chofoza {{ui:Izindawo}} |
| Londoloza, Londoloza njenge, hlanganisa nesikhungo | {{ui:Gcina njenge-IFC}} ilanda ifayela le-IFC elisha. Umthombo awushintshi. Akukho sikhungo, akukho ukwabelana ngomsebenzi |
| Hlehlisa nge-{{key:Mod+Z}} | Isebenza ezinguqukweni ze-IFC kuze kube yilapho ulondoloza. [Shintsha izici ze-IFC bese ulondoloza ikhophi eshintshiwe](topic:edit-ifc-properties) |
| Phatha izixhumanisi | Vula ifolda yephrojekthi: wonke amaxhumanisi ahlolwa futhi amakhonjwa nge-**Kule folda**, **Igama elifanayo litholakele**, **Ifayela lomtapo** noma **Akukho kule folda**. [Vula ifolda yephrojekthi yonke](topic:open-project-folder) |
| Ukuhlola, noma ukuvula ifayela ukubona ukuthi lonakele yini | Umbiko wefolda uhlola yonke ikhophi nokhokho ukuthi awaphelelanga, ngemizuzwana. [Hlola ifolda ukuze uthole amakhophi alimele](topic:check-folder-health) |
| Ukukhetha ifayela elifanele kufolda ehlelekile | Ibhokisi {{ui:Qala lapha}} liphakamisa elilodwa, linezizathu |

Uma uvula amamodeli ikakhulu ukuze uwahlole, njengohlelo lokuhlola noma lokubuka i-IFC, khetha isitayela semenyu {{ui:Isibukeli}}: amathuluzi okubuka nokuhlola aza phambili, amathuluzi okwakha asala ngaphakathi kwemenyu eyodwa. Bona [Imenyu, okhiye nembewu](topic:menus-keys-and-mouse).

## Ukusuka ekubukeni amafayela e-DWG

Uma uvula ama-DWG ku-AutoCAD noma isibukeli se-DWG:

| Uma ujwayele | Ku-BimCraft |
|---|---|
| Amathebhu emodeli nesakhiwo ngaphansi | Amathebhu aphezu komdwebo: {{ui:Imodeli}} kanye nelilodwa ngalinye leshidi |
| ZOOM Extents, chofoza kabili insudo | Chofoza kabili, {{key:F}} noma {{ui:Lwanele}} |
| Shelelisa ngenkinobho ephakathi | Donsa ngenkinobho noma iyiphi |
| Isiphathi songqimba | Uhlu {{ui:Izingqimba}}: khonza ukuze ubonise, khipha ukuze ufihle, {{ui:Konke kuvuliwe}} kanye {{ui:Konke kuvaliwe}} |
| Isiphathi se-xref | **Amadwebo axhunyiwe** ngakwesokudla, anokuthi **Iyabonakala** noma **Akutholakalanga**, kanye {{ui:Engeza amadwebo axhunyiwe…}} |
| Ukubuka ngaphambi kokuprinta | {{ui:Ukubuka kokuphrinta}} noma {{key:P}}: okumnyama ephepheni elimhlophe nobubanzi bemigqa. Akuphrintwa |
| Ukukhishwa kwedatha yezici zebhulokhi | Ithebhu {{ui:Izinsiza}} yemidwebo yokudla enamathegi, nge-{{ui:Landa i-CSV}} |
| Linganisa, dweba, hlela, gcina njenge | Akukho ku-BimCraft. Uhlelo lokudweba lwe-CadCraft luyadweba luhlele |

## Umehluko ohlupha abantu

- **Isebenza kusiphequluli, futhi isiphequluli sinakekela amafayela akho.** I-BimCraft ingafunda kuphela amafayela namafolda owanikeza wona, ngokuwakhetha noma ngokuwahudula ngaphakathi. Ayikwazi ukuvula ifayela ngokwayo, futhi ayikwazi ukulondoloza phezu kwalo. Yonke into elondolozwayo ilandwa.
- **Akulayishwa lutho.** Amagama ethi "upload" kwezinye izingxoxo zamafolda zesiphequluli ngamagama asesiphequluli. Amafayela ahlala kukhompyutha yakho.
- **I-IFC yifomethi yemodeli.** Ifayela leprojekthi livula njengekhadi ngoba okuqukethwe kwalo kwe-3D akuchazwanga. Thatha i-IFC njengendlela amamodeli angena ngayo ku-BimCraft.
- **Ukuhlela kwenza ikhophi.** Ukushintsha inani lesinto kakukaze kushintshe izakhi eziseduze, ngisho noma umthumeli wabelana ngalelo nani phakathi kwazo. Izici zohlobo yikhethelo elihlosiwe.
- **Akukho phrojekthi, akukho mibono.** I-BimCraft ibonisa ifayela elilodwa ngesikhathi futhi ayikhumbuli lutho ngalo ngemva kokuvala ithebhu, ngaphandle kwamagama wamafolda amuva ku-Chrome ne-Edge.
- **Okhiye bekaMac.** Lapho okhiye be-Revit beWindows besebenzisa i-Ctrl, okhiye be-BimCraft basebenzisa {{key:Mod}}: i-Command kuMac.
- **Izinkinobho zakho zembewu.** Ukuzungeza kuyinkinobho yesokunxele, hhayi i-Shift nenkinobho ephakathi, ngaphandle uma ukhetha isitayela semenyu {{ui:Ibha ye-BIM}} noma usetha izinkinobho ngokwakho ku-[Imenyu, okhiye nembewu](topic:menus-keys-and-mouse).
