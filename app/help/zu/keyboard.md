BimCraft inezinqamuleli ezimbalwa. Iningi lomsebenzi lenziwa ngembewu namapanele. Izinqamuleli ezibhalwe nge-{{key:Mod}} zisebenzisa i-Command ku-Mac ne-Ctrl kwezinye. Bona [Okhiye, imbewu namapedi okuthinta](common:keys) ukuthi okhiye babhalwa kanjani kule usizo.

## Yonke indawo

| Ukhiye | Okwenzayo |
|---|---|
| {{key:Ctrl+Shift+F}} | Gingqa phakathi kwezimo zesikrini: ejwayelekile, isikrini esigcwele, isikrini esigcwele nezimpaphe zifihliwe. Ctrl kuyo yonke imishini, kufaka ne-Mac |
| {{key:Esc}} | Phuma esikrinini esigcwele |
| {{key:Mod+,}} | Vula {{ui:Settings}}. Bona [Izilungiselelo ze-BimCraft](topic:settings) |
| {{key:Tab}} | Hambisa phakathi kwezinkinobho, amabhokisi okuhlola nezinani. Yonke ilawulo ingafinyelelwa ngekhibhodi |

## Umbono we-3D (amamodeli e-IFC)

| Ukhiye noma isenzo | Okwenzayo |
|---|---|
| {{key:F}} | Lwanisa imodeli yonke, umbono wamakona amathathu (njengo-{{ui:Fit}}) |
| {{key:Esc}} | Susa ukukhethwa, noma yeka ukubeka noma ukunamathisela |
| Chofoza | Khetha isakhi esingaphansi kwesikhombi; chofoza ingemuva elingenalutho ukuze ususe |
| {{key:Mod}}+chofoza noma {{key:Shift}}+chofoza | Engeza isakhi ekukhetheni, noma usikhiphe |
| {{key:H}} | Fihla izakhi ezikhethiwe. Bona [Fihla, khipha bodwa nobone ngokudlulisa izakhi](topic:hide-and-isolate) |
| {{key:I}} | Bonisa izakhi ezikhethiwe kuphela (khipha bodwa) |
| {{key:T}} | Bonisa izakhi ezikhethiwe, konke okunye kubonakale ngokudlulisa |
| {{key:Shift+H}} | Bonisa zonke izakhi futhi |
| {{ui:Walk}} | Bese {{key:W}} {{key:A}} {{key:S}} {{key:D}} noma imitshingo ihamba, {{key:Shift}} igijima, ukudonsa kubheka ngokuzungeza, {{key:Esc}} iyima. Bona [Hamba emodelini](topic:walk) |
| {{key:M}} | Linganisa izibalo nezindawo zobuso. Bona [Linganisa izibalo, izindawo zobuso nezindawo nge-3D](topic:measure) |
| Donsa ngenkinobho yesobunxele | Zungeza |
| Donsa ngenkinobho yesokudla | Shelelisa |
| {{key:Shift}} noma {{key:Mod}} bese udonsa ngenkinobho yesobunxele | Shelelisa (kulula epedini lokuthinta) |
| Skrola iwhili, noma donsa ngenkinobho ephakathi | Sondeza |
| Skrola ngeminwe emibili noma ucindezele ipedi lokuthinta | Sondeza |
| Umunwe owodwa (ukuthinta) | Zungeza; ukuthepha kukhetha |
| Iminwe emibili (ukuthinta) | Cindezela ukuze usondeze, hambisa ndawonye ukuze ushelelise |

| {{key:X}} | Vula nevala indiza yesigaba. Bona [Sika imodeli ye-IFC ngendiza yesigaba](topic:section-plane) |
| {{key:Shift+X}} | Ibhokisi lesigaba elizungeze izakhi ezikhethiwe, negumbi elisethwe ku-Izilungiselelo |

Awekho okhiye be-{{ui:Top}}, {{ui:Front}} ne-{{ui:Side}}; sebenzisa izinkinobho.

## Hlela

Imiyalo efanayo itholakala kwithuluzi: {{ui:Undo}}, {{ui:Redo}}, {{ui:Copy}}, {{ui:Paste}} nemenyu ethi {{ui:More}}, ebonisa ukhiye ngamunye. Zisebenza embonweni we-3D wemodeli ye-IFC, hhayi lapho uthayipha kusimo. Bona [Kopisha, namathisela futhi uphinde izinto zomtapo](topic:copy-paste).

| Ukhiye | Okwenzayo |
|---|---|
| {{key:Mod+Z}} | Hlehlisa ushintsho lwamuva |
| {{key:Mod+Y}} noma {{key:Mod+Shift+Z}} | Phinda wenze lokho okuthathwe yi-Undo |
| {{key:Mod+C}} | Kopisha izakhi ezikhethiwe (amagama nezimfanelo zazo nazo ziyathunyelwa ebhodini lokopisha njengombhalo) |
| {{key:Mod+X}} | Sika izakhi ezikhethiwe: zikopishe, bese uzisusa |
| {{key:Mod+V}} | Namathisela okukopishile: kulandela ipoyinta, chofoza lapho kufanele khona |
| {{key:Mod+Shift+V}} | Namathisela endaweni efanayo: lapho okusikiwe kwavela khona, noma eceleni kwemvelaphi ngemuva kokukopisha |
| {{key:Mod+D}} | Phinda: kopisha izakhi ezikhethiwe bese uqala ukuzinamathisela |
| {{key:Delete}} | Susa izakhi ezikhethiwe, kanye nezingxenye zazo nokuvulwa kwazo. Bona [Susa, sika, kopisha namathisela izakhi zokwakha](topic:edit-elements) |
| {{key:Mod+A}} | Khetha zonke izakhi ezibonisiwe |
| {{key:Esc}} | Khetha lutho |

Uma umbhalo ukhethiwe ekhasini, {{key:Mod+C}} ikopisha lowo mbhalo njengoba ijwayelekile.

## Umbono wepulani (Dweba)

Lokhu kusebenza ngenkathi {{ui:Draw}} ivuliwe futhi ungathayiphi kusimo. Bona [Dweba udonga](topic:draw-walls) kanye [Iminyango namawindi](topic:doors-and-windows).

| Ukhiye noma isenzo | Okwenzayo |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:W}} | {{ui:Wall}} |
| {{key:D}} | {{ui:Door}} |
| {{key:N}} | {{ui:Window}} |
| {{key:H}} | Ngo-{{ui:Door}} noma {{ui:Window}}: izigxobo ekugcineni okunye |
| {{key:Shift}} ngesikhathi udweba udonga | Liyigcine ku-0°, 90°, 180° noma 270° |
| Amadijithi nezimpawu zamafiti nezinhlamvu (`'` ne-`"`) | Qala ukuthayipha ubude ebhokisini le-{{ui:Length}}; {{key:Enter}} iyasebenzisa |
| {{key:Enter}}, {{key:Esc}}, chofoza ngesokudla noma chofoza kabili | Qeda udonga odudayo; {{key:Esc}} futhi ibuyela ku-{{ui:Select}} |
| {{key:Delete}} | Susa udonga, iminyango namawindi okukhethiwe; izindonga ezisele zihlanganiswa futhi |
| {{key:F}} nepoyinta phezu kwepulani | Lwanisa ipulani |
| Skrola iwhili | Sondeza ngakwepoyinta |
| Donsa ngenkinobho ephakathi noma yesokudla, noma {{key:Space}} bese udonsa | Shelelisa; ne-{{ui:Select}} ivuliwe, ukudonsa okujwayelekile nakho kuyashelelisa |
| Donsa umnyango noma iwindi ne-{{ui:Select}} | Hambisa ngodonga lwalo, noma uye kwelinye udonga |
| Iminwe emibili (ukuthinta) | Cindezela ukuze usondeze, hambisa ndawonye ukuze ushelelise |

## Ukubeka nokunamathisela izinto zomtapo

| Ukhiye | Okwenzayo |
|---|---|
| {{key:R}} | Phendula into ngama-90° |
| {{key:Tab}} | Ukubamba udonga kuvulwe nakuvaliwe: ingemuva lento libamba udonga oseduze |
| {{key:Enter}} ku-**X, Y (mm)** | Beka endaweni ethayipheke |
| {{key:Esc}} | Yeka ukubeka noma ukunamathisela |

## Ukuhlela amanani e-IFC

| Ukhiye | Okwenzayo |
|---|---|
| {{key:Enter}} | Gcina inani othayiphile |
| {{key:Esc}} | Khansela ubuyisele inani elidala |
| Chofoza kwenye indawo | Gcina inani othayiphile |
| {{key:Mod+Z}} | Hlehlisa ushintsho lwamuva. Kuphela uma unoshintsho olungalondolozwanga futhi awuthayiphi ensimini |
| {{key:Mod+Y}} | Phinda wenze lokho okuthathwe yi-Undo |
| {{key:Mod+S}} | Londoloza njenge-IFC. Kuphela uma unoshintsho olungalondolozwanga; ngaphandle kwalokho kuvulwa umyalo wokulondoloza wesiphequluli |

Ukuhlela ngekhibhodi kuphela: cindezela {{key:Tab}} kuze kugqanyiswe inani, bese ucindezela {{key:Enter}} ukuqala ukuthayipha.

## Imidwebo ye-2D (DWG ne-DXF)

| Ukhiye noma isenzo | Okwenzayo |
|---|---|
| {{key:F}} | Lwanisa umdwebo noma ishidi |
| {{key:P}} | Umbono wokuphrinta uvuliwe nuvaliwe |
| Chofoza kabili | Lwanisa |
| Donsa ngayo yonke inkinobho | Shelelisa |
| Skrola iwhili | Sondeza ngakwepoyinta |
| Skrola ngeminwe emibili noma ucindezele ipedi lokuthinta | Sondeza ngakwepoyinta. Ukuskrola ngeminwe emibili akushelelisi |
| Umunwe owodwa (ukuthinta) | Shelelisa. Ukusondeza ngokucindezela akukakwakhiwa imidwebo |

## Imidwebo nge-3D

| Ukhiye noma isenzo | Okwenzayo |
|---|---|
| {{key:3}} | 3D ivuliwe nivaliwe (futhi nakumbono we-2D) |
| {{key:F}} | Imikhawulo: umdwebo wonke |
| Donsa ngenkinobho ephakathi noma yesobunxele | Zungeza |
| Donsa ngenkinobho yesokudla, noma {{key:Shift}} bese udonsa | Shelelisa |
| Skrola iwhili | Sondeza ngasebezweni elingaphansi kwepoyinta |
| Ukushayela ngeminwe emibili epedini lokuthinta | Zungeza; ne-{{key:Shift}}, shelelisa |
| Ukucindezela ngeminwe epedini lokuthinta | Sondeza |
| Iminwe emibili (ukuthinta) | Cindezela ukuze usondeze, hambisa ndawonye ukuze ushelelise |

{{key:F}}, {{key:P}} kanye {{key:3}} azenzi lutho lapho uthayipha ensimini, lapho uhlu lwezinsiza luvuliwe, noma uma ubamba {{key:Mod}} noma {{key:Alt}}.
