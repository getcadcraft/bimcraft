I-BimCraft iyisicelo semodeli yesakhiwo somndeni we-CadCraft. Kulokhu kwakhiwo **iyavula, ifunde futhi ihlole** amafayela wesakhiwo, futhi **ihlele idatha kumamodeli e-IFC**. Ayidwebi noma imodelise izinto ezintsha okwamanje. Cabanga ngayo njengombukisi nomhloli wemodeli, osebenza nokulungisa amagama, amathegi nezinani zezici kufayela le-IFC.

Okuvulayo:

| Ifayela | Okuthola |
|---|---|
| IFC (`.ifc`) | Imodeli ephelele ku-3D: ukuzungeza, izitezi, izici zezinto, nokuhlelwa kwamagama nezinani zezici |
| Amafayela ephrojekthi nomndeni (`.rvt`, `.rfa`, `.rte`, `.rft`) | Ikhadi lefayela: ukukhishwa okwalondolozwa kuso, ulwazi lwephrojekthi, isithombe sokubuka namafayela axhunyiwe. Akukho 3D. |
| DWG ne-DXF | Umdwebo ku-2D: indawo yemodeli nalo lonke ishidi, izingqimba, imidwebo exhunyiwe,ombono wokuphrinta, nohlu lwezinsiza lwemidwebo yokudla egcwele amathegi |
| Ifolda yephrojekthi | Umbiko wawo wonke amamodeli efolda: okusekelwe, izixhumanisi, amakhophi alimele, nesiphakamiso sefayela okufanele uqale ngalo |

Konke kwenzeka kwisiphequluli sakho, ekhompyutheni yakho. **Akukho okulayishwa.** Bona [Amafayela avulwa futhi agcinwa yi-BimCraft](topic:files) ukuze uthole imininingwane.

## Vula i-BimCraft

1. Vula i-BimCraft kusiphequluli samanje. I-Chrome, i-Edge, i-Firefox ne-Safari zonke ziyasebenza; [Izisekeli, amadivayisi nenkumbulo](topic:platforms) ibala umehluko.
2. Linda isikrini esingenalutho esithi "Vula imodeli yesakhiwo."

:::note
I-BimCraft isebenza kusiphequluli, nasedeskithophu ngaphakathi kwe-CadCraft Studio, kanye nezinye izinhlelo. Ukulondoloza ku-cloud akukatholakali okwamanje: uvula amafayela ekhompyutheni yakho bese ubuyisela amakhophi kuyo.
:::

## Vula imodeli yakho yokuqala

Indlela esheshayo yokubona ukuthi i-BimCraft yenzani ifayela le-IFC.

1. Chofoza {{ui:Khetha ifayela}} maphakathi nesikrini.
2. Khetha ifayela le-`.ifc` ku-{{pick:mac=Finder|windows=File Explorer|linux=isiphathi sefayela sakho}} bese uqinisekisa.
3. Linda umugqa wesimo ongaphansi kwesikrini uthi "Iqalisa injini ye-IFC…", bese "Yakha ijiyomethri".

Uzobona imodeli ku-3D maphakathi, ipaneli ethi {{ui:Ifayela}} nohlu lwe-{{ui:Izitezi}} ngakwesokunxele, kanye nepaneli ethi {{ui:Izici}} engenalutho ngakwesokudla. Umugqa wesimo uphela ngo-"Vuliwe" nenani lezinto.

:::tip
Ungaphinda uhudulele ifayela usuka ku-{{pick:mac=Finder|windows=File Explorer|linux=isiphathi sefayela sakho}} uliyise ngqo ekhasini. Isikrini sithi "Lahla ukuze uvule" ngenkathi uhudula.
:::

:::offline
Injini ye-IFC ilayisha kusuka esayithini ngokuqala lapho uvula imodeli ye-IFC koqala, ngaphandle uma i-BimCraft yalondolozwa ukuze isetshenziswe ngaphandle kwe-inthanethi. Imidwebo ye-DWG ne-DXF, amafayela ephrojekthi namafolda akudingi okwengeziwe: abafundi bawo bayingxenye yohlelo. Uma inkinobho yebha yohlelo ithi {{ui:Ilungele ukusetshenziswa ngaphandle kwe-inthanethi}}, konke kuvuleka ngaphandle. Uma kungenjalo, amamodeli e-IFC ngeke avuleke uze uxhume kabusha, ngaphandle uma kade ekhishwe kuleyo thebhu. Bona [Ku-inthanethi nangaphandle kwe-inthanethi](topic:online-offline).
:::

:::online
Uyaya endaweni engenaxhumano? Chofoza {{ui:Londoloza ngaphandle kwe-inthanethi}} ebhareni lohlelo bese ulinda {{ui:Ilungele ukusetshenziswa ngaphandle kwe-inthanethi}}. Ikhophi elilondoloziwe (cishe 11 MB) lifaka injini ye-IFC. Bona [Ukusebenza ngaphandle kwe-inthanethi](common:offline).
:::

## Buka ozungezile

:::mouse
1. Hudula ngenkinobho yesokunxele yemouse ukuze uzungeze imodeli.
2. Skrola ivili ukuze usondeze.
3. Hudula ngenkinobho yesokudla yemouse ukuze ushelelise. Ku-trackpad ye-Mac, bamba {{key:Shift}} uhudule kunalokho.
4. Cindezela {{key:F}} noma chofoza {{ui:Lwanele}} ukuze ubuyele ekubukeni imodeli yonke.
:::

:::touch
1. Hudula ngomunwe owodwa ukuze uzungeze.
2. Hlanganisa iminwe emibili ukuze usondeze, bese uhambisa iminwe emibili ndawonye ukuze ushelelise.
3. Thepha {{ui:Lwanele}} ukuze ubuyele ekubukeni imodeli yonke.
:::

## Yenza into eyodwa eyisisekelo: lungisa ithegi

1. Chofoza udonga, umnyango noma noma yiyiphi into emodelini. Iba luhlaza okwesibhakabhaka, nezici zayo zivela ngakwesokudla.
2. Kupaneli ethi {{ui:Izici}}, chofoza inani eliseduze kwe-**Ithegi**.
3. Bhala ithegi elisha bese ucindezela {{key:Enter}}.
4. Bheka isigaba se-{{ui:Izinguquko}} esivulekile ngakwesokunxele: inguquko yakho ibhalwe nenani elidala nelisha.

## Londoloza ikhophi

1. Chofoza {{ui:Gcina njenge-IFC}} esigabeni se-{{ui:Izinguquko}}, noma cindezela {{key:Mod+S}}.
2. Thola ifayela elisha kufolda yakho yokulanda. Libizwa ngegama lokuqala kwengezwe " (edited)", isibonelo `Clinic (edited).ifc`.

Ifayela lakho lokuqala alisoze lishintshwe. [Shintsha izici ze-IFC ulondoloze ikhophi eshintshiwe](topic:edit-ifc-properties) ichaza ukuhlela ngokugcwele.
