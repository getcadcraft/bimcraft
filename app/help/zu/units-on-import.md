## Okuzokwenza

Ngenisa ifayela bese uqinisekisa ukuthi lingena ngosayizi ofanele.

## Izinyathelo

1. Vula noma engeza ifayela njengoba ujwayelekile: {{ui:Ivulekile}}, {{ui:Amafayela}} yelayibrari, {{ui:Amafu wamaphoyinti}}, noma Build › Kusuka emdwebeni.
2. Uma ifayela lisho izinyunithi zalo, akukho okubuzwayo. Umugqa wesimo uyakusho ukuthi yiziphi izinyunithi ifayela elizishongo.
3. Uma lingazishongi, ingxoxo ibuza **Izinyunithi zefayela**. Khetha ukuthi iyiphi iyunithi eyodwa kufayela, bese uchofoza {{ui:Sebenzisa lezi zinyunithi}}. Akukho okubekwayo ngaphambi kokuthi uphendule.
4. {{ui:Khansela}} (noma {{key:Esc}}) akulethi lutho.

## Yiziphi izifayela ezishongo izinyunithi zazo

- **IFC**: ishongo yunithi yobude bayo, futhi "Ivuliwe" isho ukuthi yiyiphi. I-IFC engashongi lutho ibuzwa ngaphambi kokuthi ivulwe; impendulo yakho ibhalwa kumodeli, ngakho ifayela liyishongo kanye lapho ulondoloza.
- **DWG ne-DXF**: izinyunithi zokufaka zomdwebo. Umdwebo ongazo ubuzwa (amafayela elayibrari, Build › Kusuka emdwebeni, umhlaba kusuka kumakhonthuwa).
- **Uhlu lwamaphoyinti** komhlaba: alishongi zinyunithi. Uyabuzwa.
- **Amafu wamaphoyinti**: i-LAS ne-LAZ enohlelo lwamakhoordinethi, i-E57, i-PTX ne-PLY zishongo zazo. Ezinye ziyabuzwa.
- **OBJ ne-STL**: azikaze zishongo izinyunithi. Uyabuzwa.
- **glTF ne-GLB**: amamitha, ngomthetho wefomethi ngokwayo.
- **Izithombe**: azinosayizi wazo. Isithombe sifakwa ekubukeni bese usetha usayizi wazo nge-Scale by two points. Usayizi onikeza ukhunjulwa kulelo fayela: uma sibekwa futhi, singena ngalowo sayizi, nomugqa wesimo uyakusho lokho.
- **Okwengeziwe kwamafu wamaphoyinti**: iyabuza uma wakha ifu elingashongi yunithi, futhi ilebhula izinombolo zefu ngeyunithi elilethayo.

## Okuhle ukwazi

- Impendulo ikhunjulwa kulelo fayela (igama, usayizi nosuku) kulelo khompyutha, kuzo zonke izinhlelo ze-CadCraft. Ngesikhathi esilandelayo lapho ifayela elifanayo lingena, awubuzwa, nomugqa wesimo uyakusho ukuthi izinyunithi ezikhunjuliwe zisetshenzisiwe.
- Ukuze ubuzwe futhi: i-command palette ({{key:Mod+K}}) › **Buza futhi izinyunithi zamafayela angeniswayo**.
- Uhlu lwezinyunithi olusuke seluqala ukungeniswa (Izinyunithi zelayibrari, Izinyunithi zebha lefu, Izinyunithi zomdwebo ku-Kusuka emdwebeni) luseshintsha izinyunithi emva kwalokho. Uhlu lwezinyunithi lwethuluzi lomhlaba manje lulokho okuqala ngakho umbuzo kuphela.
