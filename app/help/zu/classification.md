## Okuzokwenza

Beka ikhodi yokuhlukaniswa ezindongeni, emafolweni, kuphahla, emasilaweni, emawindini nakho konke okunye kumodeli, ezinhlelweni ezintathu ngakunye: Uniclass, OmniClass ne-UniFormat. Ezinye izigaba nezinhlelo zesofthiwe zincika ekhodini, hhayi egameni, ngakho amakhodi agcinwa kufayela le-IFC njengezinkomba zokuhlukaniswa ezifundwa yinoma iyiphi inhlelo ye-BIM.

## Nika into ikhodi

1. Khetha into (noma ezimbalwa) bese uvula **Iprophathi**. Vula isigaba esithi {{ui:Classification}}.
2. Bhala ikhodi ebhokisini lohlelo lwayo bese ucindezela Enter. Uma uhlu lwamakhodi selulayishiwe, bhala ingxenye yekhodi noma amagama ambalwa ("curtain wall") bese ukhetha okufanayo: isihloko sekhodi sigcwaliswa wena.
3. {{ui:Applies to}} ichaza ukuthi ikhodi iya kuphi: **Le nto**, noma **Uhlobo lwayo (yonke into yohlobo)**. Ikhodi kuhlobo lodonga ifundwa wonke amadonga alolohlobo, nalawo ozawadweba kamuva.
4. {{ui:Sula}} isusa ikhodi.

Ngaphansi kwekhodi ngayinye isigaba sitshela ukuthi itholakala kuphi: isethwe kule nto, isuka ohlobeni lwayo, noma i-default yephrojekthi yesigaba sayo. Ikhodi yento yayo ngokwayo ihlala ibaluleke kunekhodi yohlobo lwayo, nekhodi yohlobo ibaluleke kunezenzakalelo. Uma kukhethwe izinto eziningi, ibhokisi elithi "ahlukile" lisho ukuthi azabelani ngekhodi eyodwa; ukubhala eyodwa iyinika zonke. Ushintsho ngalunye kuyisinyathelo esisodwa sokuhlehlisa.

Ikhodi ingabhalwa njalo, noma uhlu lulayishiwe noma akulayishiwe. Uma ingafani nekhodi yalolu hlelo, noma ingekho ohlwini olulayishiwe, isaziso siyakusho lokho futhi ikhodi igcinwa njengoba uyibhalile.

## Khetha izinhlelo zephrojekthi

Vula **Idatha** ebhareni lemodeli bese ukhetha {{ui:Classification}} (noma {{ui:Project classification…}} esigabeni se-Iprophathi).

- Thikha izinhlelo ephrojekthi esetshenziswa. Iprophathi ibonisa kuphela lezo.
- **Uniclass**: amathebula e-Elements/ functions (EF), Systems (Ss) nawe-Products (Pr) afika ne-app. Ayi-© NBS, alayisensiwe nge-Creative Commons Attribution-NoDerivatives 4.0, futhi adluliselwa engashintshiwe. Ingxoxo ibonisa inguqulo yethebula ngalinye nosuku lokuthi lafundwa ngalo. Awona amathebula amasha kakhulu: umshicileli uwashicilela njalo ngekota kusayithi lakhe.
- **OmniClass** ne-**UniFormat**: akukho uhlu lwamakhodi olufika ne-app, ngoba umshicileli wabo akavumeli amathebula ukudluliselwa ngaphandle kwelayisensi. Bhala noma yiliphi ikhodi, noma layisha ithebula elilayisensiwe lomtapo wakho.
- {{ui:Load a table (CSV)…}} ifunda ithebula lomtapo wakho kufayela le-CSV elinekholomu yekhodi nekholomu yesihloko (umugqa wekhanda othi Code, Number noma Identifier kanye no-Title, Name noma Description utholakala wodwa; uma kungekho, kusetshenziswa amakholomu amabili okuqala). Ithebula lihlala kulesi sisheshi sebhrawuza futhi alifakwa ephrojekthini. Amakhodi owabelayo kuphela ayagcinwa kufayela. Ungalayisha ithebula elisha le-Uniclass ngale ndlela.
- {{ui:Give elements a default code by their class}} inika wonke udonga, ifolo, uphahla, umnyango, ifasitele, isitebhisi, indlela ethambile, insika, ibhimu nento yefenisha ikhodi yokuqala ye-Uniclass kusuka kuthebula le-Elements/ functions uma lingenayo eyayo. Izinto ozidweba kamuva nazo ziyayithola.
- {{ui:Show the codes as columns in the schedules}} yengeza ikholomu eyodwa ngohlelo ngalunye kumashejuli we-Iminyango, Amawindi, Izindonga ngohlobo kanye Namagumbi nakwi-CSV yawo. Umugqa wezinto ezimbalwa ubonisa "ahlukile" uma amakhodi azo ehlukile.

## Okufanele ukwazi

- Ama-default amakhodi ayisinqumo sokuqala se-CadCraft, hhayi se-publisher, futhi awakahlolwa ngumuntu oyisazi. Hlola wona ngokumelene nezinga lephrojekthi yakho.
- Efayelini, i-default iwukuhlukaniswa okuqinile, imakwe ngegama lobudlelwano elithi "CadCraft default", futhi iyanyamalala uma into noma uhlobo lwayo sekutholile ikhodi yayo.
- Amakhodi asevele efayelini eyethulwe ayafundwa abonakale, nanoma yiliphi igama lesigaba elisetshenziswa yenye inhlelo. Amakhodi wanoma yiluphi uhlelo olunye (lwehhovisi) ayalandwa futhi aziwathintwa.
- Amakhodi ayafundwa futhi uma ifayela livulwa futhi, lapha noma kwenye inhlelo. Aphinde afakwe ku-IFC5 alpha (IFCX) uma leyo ngoyokuhlola ivuliwe, ngaphandle kwekhodi esethwe kuphahla.
- Akwakhiwe okwamanje: umthi wokuphequlula ithebula ngezinga ngezinga, amakhodi emazingeni namakamelo njengezenzakalelo zephrojekthi, nokuhlola ikhodi ngokuhambisana nenguqulo echazwe kufayela.
