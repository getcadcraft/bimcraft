## IFC

| Kufundwa | Imininingwane |
|---|---|
| Ijiyomethri | Yonke into enesimo, inombala njengoba ifayela lisho. Amagumbi nezikhala zidwetshwa zingabonakali futhi zifihliwe ekuqaleni |
| Izitezi | Izitezi zakhiwo ngokulandelana kokuphakama, nokuthi yiziphi izinto ezisemagatsheni ngamunye. Izinto ezingasesitezini azilungiselelwe ngaphansi kwe-"Not on a storey" |
| Inani lezinto | Izinto zangaphezu kohlobo ngalunye (izindonga, iminyango, izilingo…), ezibonakala ku-{{ui:Elements}} |
| Ulwazi lwephrojekthi | Igama leprojekthi, igama elide, nesigaba; isikimu, uhlelo oluthumela, umbhali nosuku lokuthumela kusuka ekhanda lefayela |
| Idatha yento | Igama, uhlobo, uhlobo lwento, ithegi, incazelo, GlobalId; yonke isethi yezici nesethi yezinani esemayinteni nasohlobeni lwayo |

Okuhlelekayo: igama, uhlobo lwento, ithegi, incazelo, nezinani zesici ezisodwa. Igcinwa njengefayela elisha le-IFC. Izikimu i-IFC2X3, i-IFC4 kanye ne-IFC4X3 ziyavuleka, zifundwa yi-injini ye-IFC yangaphakathi ye-BimCraft; yonke into engakayikwazi ukudweba ibhalwa ngaphansi kwe-**Not drawn yet** ephaneli ethi {{ui:File}}. Imodeli ihanjiswa ukuya kumsuka lapho ivulwa, ngakho imodeli ebekwe kude nawo isavela phakathi kwesikrini. Ama-`.ifczip` no-`.ifcxml` akavuleki.

## Amaphrojekthi nemindeni

Amaphrojekthi e-`.rvt`, amathempleti amaphrojekthi e-`.rte`, imindeni e-`.rfa` kanye namathempleti emindeni e-`.rft`.

| Kufundwa | Imininingwane |
|---|---|
| Ulwazi lwefayela | Ukukhishwa nokwakhiwa, ukusebenza ngokuhlanganyela, indlela yemodeli ephakathi, indlela yokugcinwa kokugcina, igama lomsebenzisi, ulimi, i-GUID yedokhumenti |
| Ulwazi lweprojekthi | Izinkambu zephrojekthi ngokwayo (igama, inombolo, ikhasimende, ikheli, isimo…), ngaphandle kwezinkomba zokuzenzakalela zephrojekthi emisha |
| Ulwazi lomndeni | Igama lomndeni, isigaba, ukukhishwa, isibuyekezo sokugcina, namapharamitha ayo ngamaqembu |
| Izixhumanisi | Uhlu lwemodeli exhunyiwe, izixhumanisi ze-CAD, izithombe namathebhulu ezinkomba okutholwe kufayela |
| Isithombe sokubuka kuqala | Isithonjana esigcinwe kufayela |

Akufundwa: imodeli ye-3D, izinto, imibono, amashidi nohlu. Zigcinwa ngefomethi engakachazwa. I-BimCraft ifunda amakhilobhayithi ambalwa nje kusuka kwifayela ngalinye, ngakho usayizi wefayela ngokuvamile awubalulekile.

## Amafayela .pln, .pla, .tpl kanye .bpn

Akufundwa okwamanje: i-BimCraft iyasho lokho lapho uyivula. Yisa ngaphandle i-IFC yemodeli kanye ne-DWG yemidwebo; bona [Vula amafayela ephrojekthi e-.pln nawe-.pla](topic:pln-project-files).

## DWG ne-DXF

| Kufundwa | Imininingwane |
|---|---|
| Izikhala | Isikhala semodeli nalo lonke ishidi (ukwakheka), ngokulandelana kwamathebhu |
| Ukubuka | Ukubuka kwalo shidi ngalinye, ngesikali sakho, ukuphendulwa nezendlela ezifriziwe |
| Amaleya | Igama, umbala, ukuvuleka/ukuvalwa, ukufriza, isibonakaliso sokuphrinta nobukhulu bomugqa |
| Izinto | Imigqa, ama-polyline, ama-arc, izindilinga, ama-ellipse, ama-spline, ukugcwaliswa, umbhalo nombhalo wemigqa eminingi, amabhulokhi namakhoyi, izilinganiso, ama-leader namamulti-leader, amathebhu, amaphoyinti, izithombe |
| Imidwebo exhunyiwe | Idwetshwa lapho ifakwe khona, uma amafayela ayo etholakala |
| Izithombe | Zidwetshwa kusuka kumafayela ezithombe uma etholakele (PNG, JPEG, GIF, BMP, WebP; hhayi TIFF) |
| Amathegi ezinsiza | Amathegi ezinsiza zokudla (izici ze-`KCL-ITEM`), ohlwini lwezinsiza |

Okunye konke kubalwa ngaphansi kwe-**Not drawn yet**, kungaqagelwa. Ifomethi ye-DWG ukusuka ku-AutoCAD 2000 kuya ku-2018 yiyona ehloliwe (amafayela e-R13 ne-R14 nawo ayamukelwa, kodwa ayikho esethini yokuhlola; ama-DWG amadala akavuleki); iphaneli ethi {{ui:Drawing}} ibonisa ikhodi yefomethi (njengo-AC1032). Amafayela e-DXF weziguqulo zonke ayavuleka, e-R12 nawo. Kokubili kufundwa ngabafundi bangaphakathi be-BimCraft kule thebhu. Akukho okulondolozwa kubuyele ku-DWG noma i-DXF.

## Ngaphakathi kwefolda

| Uhlobo | Okwelulekiwe | Kumbiko |
|---|---|---|
| Amamodeli | `.rvt` `.rfa` `.rte` `.rft` | Ahlelwe nezikhadi zokusekela ezinenombolo, ahlolwa impilo, ikhadi lifundwe, nezixhumanisi ziyahlolwa |
| IFC | `.ifc` | Ibhalwe ohlwini; ivula ku-3D |
| CAD | `.dwg` `.dxf` `.dgn` | Ibhalwe ohlwini ngamamodeli awaxhumanisayo; i-DWG ne-DXF zivula ku-2D, i-DGN ayivuleki |
| Izinsalela | `.dwl` `.dwl2` `.bak` `.err` `.log` `.tmp` `.sv$` `.ac$` `.lck` `.slog` | Zibalwa ngaphansi kwe-**Set aside** |
| Amafolda okugcina | `*_backup`, `*_log`, `Revit_temp`, amafolda afihliwe | Abalwa ngaphansi kwe-**Set aside**, akufundwa |

Bheka [Umbiko wefolda: izindima, izimo nezixhumanisi](topic:folder-roles).
