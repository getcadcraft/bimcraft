I-BimCraft namuhla iyisifundi, isihloli nomhleli wedatha ye-IFC esesiqalile ukudweba izakhiwo: izindonga, iminyango namafasitela, amagumbi, amafulowa, izilingi nophahla (bheka [Dweba izindonga](topic:draw-walls), [Iminyango namafasitela](topic:doors-and-windows) kanye [Amagumbi, amafulowa, izilingi nophahla](topic:floors-and-roofs)). Lolu uhlu oluqotho lokungakwenzi okwamanje, nokufanele kwenziwe esikhundleni salo.

## Ukumodela nokubhala

| Akusakwenziwa | Esikhundleni salokho, namuhla |
|---|---|
| Ukudweba amabhimu; insika zensimbi | Sebenzisa uhlelo lwakho lokubhala, bese uvula i-export yalo ye-IFC lapha. Insika ezingqo namasekhono zifakwa lapha (bheka [Gridi nensika](topic:grids-and-columns)); izitebhisi ezingqo, ezinesimo se-L, U, winder ne-spiral nezinhlaka zokuphephela kudwetshwa lapha (bheka [Izitebhisi nezinhlaka zokuphephela](topic:stairs-and-railings)) |
| Ifasitela ebusweni be-dormer; ama-dormer ezindizeni zophahla adwetshwe ngesandla; uphahla oluthambile; ukumbozwa kophahla okunesakhiwo esiboniswe | Izindiza zophahla ezidwetshwe ngamakhoni awo, nokuthambeka kodonga ngalunye: bheka [Uphahla: ukuthambeka kodonga ngalunye, amagable, izindlu nezindiza zophahla](topic:roofs) |
| Ukushintsha izindonga, iminyango noma amafasitela okwenziwe yenye inhlelo | Uhlelo lwakho lokubhala; amathuluzi okudweba ashintsha kuphela lokho akudwetshile |
| Iphrofayili yodonga enemiphetho noma izimbobo; izimbobo zodonga ezingesona amakhonapha; ukwengeza noma ukususa amaphoyinti ephrofayili yodonga ku-3D view | Iphrofayili, ukunamathela, ukuthambeka nezimbobo kusebenza ku-{{ui:Izici}}, ezinhlangothini nasezigabeni, ebusweni bodonga nangamabanga ku-3D, kwezindonga ezigoqekile nezigobile: bheka [Yenza udonga: ukunamathela, iphrofayili, ukuthambeka nezimbobo](topic:wall-shape) |
| Ezindongeni ezigoqekile: {{ui:Sika / eleza}} no-{{ui:Ikhona}}, ukwakha ngezakhiwo, izilinganiso zepulani ezizenzakalelayo, ukubamba ngokuhambisana nomsedwa (ibamba emaphethelweni alo nasemaphakathi womsedwa wawo) | Dweba udonga oluqondile kulokho, noma sebenzisa izigaba ezingqo. | Ku-add-on ye-Plant (icishwe kuze kuvulwe): ukudweba umugqa ohanjiswayo ungene emodelini, izinombolo zamaspool kwama-isometric awo, ukuhlola kokwakheka kwezinto ezibekwe ethaleni | Dweba umugqa nge-{{ui:Ipayipi}} (bheka [Amapayipi namapayipi omoya](topic:pipes-and-ducts)); ukuhlola kokwakheka kufunda ithebula lezinto le-add-on ngokwalo |
| Ukujikeleza, ukubonakalisa noma ukuhlela izindonga, iminyango namafasitela adwetshwe ngokwahlukana (izindonga ziyahanjiswa, zikopishwe nge-{{ui:Hambisa}}, Offset noma box stretch: bheka [Izimo zodonga, ukuhlukanisa, ukubeka kude, ukweluleka nokukhiya](topic:wall-tools)); isitayela sokuxhumana (butt, square off) emakhoneni nodonga oluthambile noma izindonga ezintathu noma ngaphezulu (bheka [Izimo zodonga, ukuhlukanisa, ukubeka kude, ukweluleka nokukhiya](topic:wall-tools)); ithuluzi lombhalo; izindonga zesikhwama | Kopisha konke okusezingeni nge-{{ui:Kopisha leli zinga…}} (bheka [Dweba izindonga](topic:draw-walls#levels)); noma uzidwebe futhi |
| Izendlalelo zokwakheka kodonga ezidwetshwe epulanini nasesigabeni; izilinganiso ezigabeni nasezinhlangothini; izilinganiso zezinto zokubhekisela ezindaweni zamafasitela, iminyango nezinye izingxenye; ukwakheka nezinzwa ezikushaywa ku-schedules nokuthola inani; ilabhulali yezinto ezabiwa phakathi kwamaphrojekthi; ukubaluleka kwezendlalelo ezigabeni, ezinhlangothini nasku-3D nasezixhumanweni zezindonga ezintathu noma ngaphezulu (epulanini, amakhona, izixhumanisi ze-T nokuwelana kwezindonga ezimbili kuhlanzwa ngokubaluleka kwezendlalelo: bheka [Izimo zodonga, ukuhlukanisa, ukubeka kude, ukweluleka nokukhiya](topic:wall-tools)); izendlalelo ezifakiwe noma ezihlukahlukene; ukuhlela ukwakheka kodonga olwenziwe yenye inhlelo | Izendlalelo zisohlotsheni lodonga nasembonweni walo ({{ui:Izakhiwo zodonga…}}); izindonga zilinganiswa njengenvelopu eyodwa: bheka [Izakhiwo zodonga nezinkomba zezilinganiso](topic:wall-assemblies) |
| Ukushintsha ukwakheka noma usayizi wento (ngaphandle kwezindonga, iminyango namafasitela adwetshwe lapha, nezinto ezibekwe emndenini) | Uhlelo lwakho lokubhala. Ukususa, ukusika, ukukopisha namathisela kusebenza lapha: bheka [Susa, sika, kopisha namathisela izinto zesakhiwo](topic:edit-elements) |
| Ukususa izitezi, izindawo, izakhiwo noma isayithi | Susa izinto ezikuzo |
| Ukunamathelisa izinto zesakhiwo kwenye imodeli | Kopisha futhi unamathisele ngaphakathi kwemodeli eyodwa; izinto zethala ezibekiwe zinamathela kunoma iyiphi imodeli |
| Ukwengeza izici ezintsha noma amasethi ezici | Gcwalisa amanani akhona lapha, noma engeza iparamitha kuhlelo lwakho lokubhala bese uyithumela futhi |
| Ukuhlela izinani, izinhlu, izinhlobo | Uhlelo lwakho lokubhala |
| Ukugcina amafayela wephrojekthi wezinye izinhlelo | I-BimCraft igcina i-IFC (nemindeni yayo: bheka [Imindeni nosayizi bayo](topic:families)) |
| Imindeni: ithala lemindeni elibekwa kusuka epulanini nelabelwana phakathi kwamaphrojekthi (Library), i-hotspot ehudulwa ku-3D view yento ebekiwe (ihudulwa kwi-preview yomhleli womndeni nasepulanini), amazinga emininingwane akhethwa ngombono (izinga elilodwa lephrojekthi; amashidi akhetha ngesikali), i-revolve endizeni eme ngaphakathi komndeni owodwa ejikelezwe ngekota, izimpawu zepulani zezigxobo nezamafasitela zazo (zidweba izimpawu zesisekelo sazo) | Imindeni enezici ezibhalwe ngohlobo, izifomula, isimpawu sepulani sayo, ama-hotspot, okuphindayo, amazinga emininingwane, imindeni ngaphakathi kwemindeni, usayizi ngethebula nezici ngento ngayinye zenziwa lapha: bheka [Hlela umndeni](topic:family-editor) no-[Imindeni nosayizi bayo](topic:families). Phinda umndeni ukuze uqale kuwo |
| Ukuhlela izinhlobo zezinye izinhlelo njengemindeni; ukuguqula into yethala ibe umndeni | Izinhlobo zezinye izinhlelo ziyadwetshwa, ziqoqwe ngokuqagela, nezinto zazo ziyakhethwa. Izinto zethala ziyabekwa njengoba zinjalo |
| Izinto zabakhiqizi, amavalvu nemishini (amandla, isisindo, usayizi wokuxhuma wabakhiqizi); izindlela ze-ASME B16.9 zamathee nezinciphisi kumaspool ensimbi; ukulahleka kwengcindezi ngokuhamba kwezinto, imigeleko nokulinganisa; ama-sprinkler; amathreyi wezingcingo; ukulinganisa izitaki nokuphefumula ngamayunithi wezinto; ukudonsa amakhoni womugqa; ukusika izimbobo ezindongeni nasemafulowa; ukuvumela ukuphela komugqa okubanjwe kuport (ngaphandle kokususa imishini); amaport ezinto zethala ezibekwe ephaneli yethala; isisindo sezinto; izimpande, amaghequ nezixhumanisi zomoya | Izinhlelo zomugqa wepayipi nomoya nezinhlobo ezijwayelekile, izinhlelo, amapulani, amathebula nethakhi kwenziwa lapha: bheka [Amapayipi namapayipi omoya](topic:pipes-and-ducts). Imishini enamaport, imigqa exhunyiwe nokuhlola kokuxhuma: [Imishini ye-MEP enamaport](topic:mep-equipment), [Xhuma amapayipi namapayipi omoya emishini](topic:mep-connections). Amasethi okungqubuzana, izindawo zokusondela nohlu lwemingxunyeni: [Hlola amapayipi namapayipi omoya nesakhiwo](topic:mep-against-structure). Amaspool ensimbi namashidi, uhlu lokusika lwamapayipi omoya: [Amaspool epayipi lensimbi namashidi amaspool](topic:pipe-spools). Lethe izinto zabakhiqizi kusuka ohlelweni lwakho lwe-MEP njenge-IFC |
| Ukuhlolwa kwamakhodi okwakha ama-I-shape aweldiwe, ama-I-shape angabizwa ngegama lephrofayili ye-IFC njengosayizi we-W, S, IPE, HEA noma HEB, namatyubhu, ama-angle namachannel (ayabuyela engahlolwanga); ukugoba noma impendulo esebenzayo (ukuqhubeka kwemvelo kusebhlokini lwe-Finite elements) (ukwesibili kuyi-P-Delta kuphela: elastic, flexural, akukho ukunciphisa ukuqina); izindonga namafulowa ekuhlaziyweni; izilayishi ezenziwe ngezindawo (ngaphandle kwengcindezi eyodwa kuwo wonke amafulowa we-concrete) | Ithebhu le-{{ui:Ukuhlaziya}} linikeza izimpoqo, ukusekela nokuguquka kwamabhimu, insika namabhureji ngokuhlaziywa kokuqala futhi lihlola ama-I-shape akhiqizwe ngomshini, njengosizo kuze kube unjiniyela ekubuyekeze: bheka [Hlaziya uhlaka lokwakha](topic:frame-analysis#design-checks) |
