## Okuzokwenziwa

Thola ukuthi kukhona ini efayeleni lephrojekthi noma lomndeni ngaphandle kokulivula ku-Revit: ukuthi yisiphi isikhundla esalilondoloza, uma lisebenza ngokuhlanganyela, ulwazi lweprojekthi nokuthi lixhumene nini. Kuyasiza uma ifayela lifika kuwe livela kwenye indawo futhi udinga ukwazi ukuthi kufanele livulwe kwisikhundla sini.

## Izinyathelo

1. Chofoza {{ui:Khetha ifayela}}.
2. Khetha ifayela le-`.rvt`, `.rfa`, `.rte` noma `.rft`.
3. Linda isikhashana. Umugqa wesimo uthi "Ifunda ifayela…" bese "Livuliwe *igama lefayela*".
4. Phezulu kwekhadi, bheka isithombe sokubuka esilondolozwe efayeleni, uhlobo lwefayela nokukhishwa elalondolozwe kuso, negama lephrojekthi.
5. Skrola phansi ufunde izigaba zekhadi.

## Okufanele ubone

Ikhadi maphakathi, nalezi zigaba uma ifayela lizibamba:

| Isigaba | Lokho okusitshela kho |
|---|---|
| File | Igama lefayela, usayizi, uhlobo (iphrojekthi, ithempulethi yephrojekthi, umndeni noma ithempulethi yomndeni), ukukhishwa nebhildi elalondolozwe kuzo, ukusebenza ngokuhlanganyela, indlela yemodeli emaphakathi, lapho kwalondolozwa khona okokugcina, ubani owalondoloza, ulimi, indawo ne-GUID yedokhumenti |
| Project information | Izinkambu zephrojekthi ezakhe, njengegama, inombolo, iklayenti, ikheli nesimo. Izinkambu ezisahlala kwizinkomba zokuqala zephrojekthi entsha ziyashiywa. |
| Family, Family: … | Ngomndeni: igama, isigaba, ukukhishwa, ukubuyekezwa kokugcina namapharamitha wawo, iqembu ngeqembu |
| Linked and referenced files | Yonke imodeli exhunyiwe, isixhumanisi se-CAD, isithombe nethebula lezitshoyo ifayela elibhekisela kuzo, nendlela yazo elondoloziwe |

Ephaneli ye-{{ui:File}} ngakwesobunxele iphinda izinhlobo ezibalulekile futhi yengeze **Kufundwe**: ingakanani ingxenye yefayela i-BimCraft eyifundile, ngokuvamile cishe i-40 KB kwefayela elinamamegabhithi amaningi ngosayizi. Ephaneli ye-{{ui:Properties}} ngakwesokudla isho ukuthi izici zezinto zidinga imodeli ye-3D.

## Kungani kungekho i-3D

Imodeli ye-3D nezinto ezisefayeleni lephrojekthi zigcinwe ngefomethi engachazwanga. I-BimCraft ifunda kuphela izingxenye zefayela ezichazwe noma ezifundeka kalula: ulwazi lwefayela, ulwazi lweprojekthi, idatha yomndeni, uhlu lwezixhumanisi nesithombe sokubuka. Ayiqagele okunye. Ukuze ubone imodeli ye-3D nokufunda izici zezinto, thumela i-IFC kuhlelo olwenza ifayela. Bheka [Thola ifayela lephrojekthi ku-3D nge-IFC](topic:rvt-to-ifc).

## Okuvamise ukwenziwa kabi

- **Ukulindela i-3D.** Bheka ngenhla.
- **Izixhumanisi zibonisa indlela yazo elondoloziwe kuphela.** Ifayela elivulwa lodwa alikwazi ukuhlola ukuthi izixhumanisi zikhona. Vula ifolda lapho lihlala khona: i-BimCraft iyamaka ngalinye njengelitholakele noma kungatholakali. Bheka [Vula ifolda yonke yephrojekthi](topic:open-project-folder).
- **"Lolu fayela alupheli…"** Ifayela liqunywe ngenkathi likhopishelwa, lilayishwa noma livunyelwa. Ifayela ledrayivu yefu elisesimweni "online only" nalo lenza lokhu. I-BimCraft isavula futhi ibonise okutholakele kuphela: isaziso esiphuzi phezulu kwekhadi, isigaba esithi **Kutholakele kulolu fayela** esilanda izingxenye ezinayo zonke amabhithi aseleyo kulo fayela, nesithi **Akukho kulolu fayela** kwezinye. Akukho okugcwaliswayo engxenyeni eshoweyo, ngakho ukukhishwa, isithombe sokubuka noma ulwazi lweprojekthi kungashoda uma belondolozwe ngaphesheya kwalelo phoyinti elishoweyo. Uma uhlu lwezinto zefayela lunqunyiwe, akukho okuvulekayo. Kopisha ifayela kabusha bese uliphinda ukuze uthole ifayela eliphelele.
- **"Kulolu fayela akukho isithombe sokubuka"** Amanye amafayela alondolozwa engenalo. Lokho kujwayelekile.
- **Ukuvula ukusekelwa ngephutha.** Amafayela aqanjwe njengo-`Tower.0004.rvt` ngamabhaki anenombolo. Ukuvula ifolda kuwahlanganisa nemodeli yawo.
