Energy code check compares a house with an energy code's prescriptive package and its mandatory minimums. The code's numbers are data, in a code pack made from the authority's own documents. The first pack is California's 2025 Energy Code (Title 24, Part 6) for newly built single-family houses.

Type the site's ZIP code and the add-on finds the climate zone. It reads the exterior wall types, windows, doors and floor area from the model. You state what the model cannot know: what is between the studs, the attic insulation, the windows' rated U-factor and SHGC. It then lists, row by row, what meets the code's figure, what does not, and what could not be checked, each with the table or section it comes from. It is a guide for the designer. It does not produce a certificate of compliance.
