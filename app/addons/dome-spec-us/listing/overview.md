This is the United States spec for the Dome generator: a data pack of what the codes set for a thin concrete shell. Cover, concrete strength, the minimum steel ratio, bar spacing, and the rules on buckling, analysis and tension steel come from ACI 318.2, the thin shell code, read in its 2014 edition, the only one whose full text is free to read. Cover against earth is from ACI 318-19. What the International Building Code says about sprayed concrete, loads, foam insulation and frost was read in one state's adoption. Switch it on and pick it in the Dome generator's Spec section: its values fill the boxes you left empty, and the design is checked against the ones it holds as numbers.

Every value names its code and section, and says whether we read it in the code's own text, in a document that quotes the code, or could not read it at all (then there is no value). No minimum shell thickness was read: the 2014 code sets none, and the newer editions have a section on it that could not be read. The building code waives the thermal barrier over foam only where concrete covers it on each face; a sprayed dome has concrete on one face, which is a question for your building official. It is not a substitute for the codes, and a licensed engineer must design and check the dome.
