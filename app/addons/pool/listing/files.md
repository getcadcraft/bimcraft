Writes an IFC4 file of the pool (elements in their own classes with colours, a CadCraft_Pool property set, base quantities and materials; the pipes connected through ports, faceted solids for sloping parts of any outline, bars as reinforcing bars), a Markdown calculation page for the report binder, and a CSV file of the figures and quantities with where each figure came from. In BimCraft it writes elements into the open model, saved with it. In CadCraft it writes polylines, lines, text and dimensions on POOL- layers, which export to DXF and DWG. It reads nothing but what you type and the spec packs of the side add-ons you switched on.
