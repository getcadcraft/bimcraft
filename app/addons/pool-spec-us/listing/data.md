The pack is made from research done on 2026-11-19, kept in the source as tools/pool/research/us.json: for every rule the value, the standard, the clause, the page it was read on and the sentence read. No value was typed from memory. Values are in SI units; the pack says so where a value was converted. No United States code read is written for pool shells: the pool code sends structure to the building code, and the shotcrete association points to ACI 350. Most ACI values were read in documents that quote ACI, because ACI's text is not free to read. The pool code was read as one state's adoption; your state or county may have another edition or amendments.
