This is the United States spec for the Pool generator: a data pack of the values that norms set for a concrete pool shell and its water circulation, taken from ACI 318 and ACI 350 (cover, strength, water to cement ratio, shrinkage steel, bar spacing), the American Shotcrete Association's pool position statements, the International Swimming Pool and Spa Code 2021 (turnover, pipe velocity, skimmers, inlets, suction outlets, barrier, deck slope), and the CDC Model Aquatic Health Code 2024 (filter rate, deck width, slip resistance). Switch it on and pick it in the Pool generator's Spec section: its values fill the boxes you left empty, and the design is checked against them.

Every value names its standard and clause, and says whether we read it in the standard's own text, in a document that quotes the standard, or could not read it at all (then there is no value). No United States code read is written for pool shells: the pool code sends structure to the building code, and the shotcrete association points to ACI 350. Most ACI values were read in documents that quote ACI, because ACI's text is not free to read. The pool code was read as one state's adoption; your state or county may have another edition or amendments. It is not a substitute for the standards, and a licensed engineer must design and check the pool.
